ඇඩෝනයකට (සැකසීම් › ඇඩෝන) {{ui:Render a picture…}} හි Engine ලැයිස්තුවට එන්ජිමක් එකතු කළ හැක. ඇඩෝන කතුවරුන් සඳහා සම්පූර්ණ පාඨය ඇඩෝන පිරිවිතරයේ 16 වන කොටසයි; කෙටියෙන්:

- ඇඩෝනය එන්ජිමක් ලියාපදිංචි කරයි: තමාගේම නමින් ආරම්භ වන id එකක්, නමක්, විකල්ප සැකසුම් සහ **හෝ** ධාවනය කළ යුතු වැඩසටහනක් **හෝ** පින්තූරය ඇඳන JavaScript ශ්‍රිතයක්.
- වැඩසටහනක් ධාවනය කරන එන්ජිමකට **`engine.run`** අවසරය අවශ්‍යයි, එය ස්ථාපනයට පෙර සහ සැකසීම් හි පෙන්වයි. එය Studio තුළ පමණක් ක්‍රියා කරයි; බ්‍රවුසරයේ එය සුරකින ගොනුවක් ලෙස පෙන්වයි.
- ඇඩෝනය වැඩසටහනේ නම දක්වයි (සරල ගොනු නමක්; කිසි විටෙක shell නොවේ), **අත්සන් කළ ඇඩෝනය තුළ** ඇති script එකක්, සහ placeholders සහ සරල වචන වලින් සමන්විත තර්ක. Studio වැඩසටහන සොයා ගනී, නැතහොත් එක් වරක් එයට යොමු කරන ලෙස ඉල්ලයි.
- ඇඩෝනයක් වැඩසටහනක් පළමු වරට ධාවනය කරන විට, **Studio එහි තමන්ගේම සංවාදයෙන් ඔබෙන් අසයි**: කුමන ඇඩෝනය, කුමන වැඩසටහන, සහ script එකකට වැඩසටහනට කළ හැකි ඕනෑම දෙයක් කළ හැකි බව. විශ්වාස කරන ඇඩෝනයකට පමණක් එය ඉඩ දෙන්න. ඔබේ පිළිතුර එම ඇඩෝනයට සහ වැඩසටහනට මතක තබා ගනී.
- පැකේජය (USD ලෙස දර්ශනය සහ සැකසුම් ගොනුව, ඇඩෝනය ඉල්ලන විට glTF ගොනුව සමඟ) සහ ඇඩෝනයේ script එක නව තාවකාලික ෆෝල්ඩරයකට යයි, වැඩසටහන එහි ධාවනය වේ, සහ පින්තූරය ඇඩෝනයේ එන්ජින් නාමයෙන් සලකුණු වී ආපසු පැමිණේ.
