Робочий простір **Сітка** редагує [сітку](topic:meshes) точка за точкою: її вершини, ребра та грані. Геометрія витягування/втягування лишається в робочому просторі **Модель**.

## Відкрити

- Виберіть {{ui:Сітка}} у списку {{ui:Робочий простір}} ліворуч на панелі інструментів. Вибрана сітка відкривається для редагування; вибрану групу або компонент спершу перетворюють на сітку (один крок скасування).
- Або двічі клацніть сітку чи, з клавішами моделера, виберіть її та натисніть {{key:Tab}}.
- Коли нічого не вибрано, панель пропонує сітки для додавання: площина, сітка, куб, коло, циліндр, конус, сфера, ico-сфера і тор. Нова сітка з’являється там, куди дивиться вигляд, і відкривається для редагування.

{{ui:До моделі}} (або список, {{key:Tab}} з клавішами моделера, {{key:Esc}}, коли нічого не вибрано, з клавішами витягування/втягування) повертає до моделі з вибраною сіткою. Поки відкрито робочий простір «Сітка», решта моделі пригашена, а інструменти креслення моделі прибрано.

## Вибір

| Дія | Для чого |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | Вибрати вершини, ребра або грані |
| Клацання | Вибрати один; {{key:Shift}}+клацання додає або знімає |
| Перетягування рамки | Вибрати те, що всередині й видно; {{key:Shift}} додає, {{key:Ctrl}} знімає |
| {{key:Alt}}+клацання по ребру або подвійне клацання по ньому | Його петля ребер (петля граней у режимі граней; вся межа на відкритому ребрі) |
| {{key:Ctrl}}+{{key:Alt}}+клацання по ребру | Його кільце ребер |
| Потрійне клацання | Усе, з’єднане з ним |

Група {{ui:Вибрати}} також має {{ui:Усі}}, {{ui:Зв'язані}}, {{ui:Петля}}, {{ui:Кільце}}, {{ui:Ще}} і {{ui:Менше}}.

## Переміщення, поворот, масштаб

{{ui:Перемістити}}, {{ui:Повернути}} і {{ui:Масштабувати}} починаються від покажчика: рухайте його, потім клацніть або натисніть {{key:Enter}}, щоб покласти вибране на місце, або {{key:Esc}}, щоб скасувати. {{key:X}}, {{key:Y}} або {{key:Z}} (або клавіші зі стрілками) фіксують вісь. Введіть відстань, кут або множник для точного значення — [обчислення](topic:value-box#calculations) теж працюють.

**Пропорційне редагування** ({{ui:Пропорційно}}, або на панелі): вершини поблизу вибраного слідують за переміщенням, тим слабше, чим далі вони, до заданого радіуса, із обраним спадом. Увімкніть {{ui:Лише вздовж сітки}}, щоб вимірювати вздовж ребер, а не по прямій.

{{ui:Ковзання}} переміщує вибрану петлю ребер уздовж сусідніх ребер.

## Зміна форми

| Інструмент | Що робить |
|---|---|
| {{ui:Видавити}} | Витягує вибрані грані вздовж їхньої нормалі з новими бічними гранями (або робить грані з відкритих меж). Введіть відстань |
| {{ui:Врізати}} | Смуга всередині контуру вибраних граней; натисніть {{key:I}} ще раз для кожної грані окремо |
| {{ui:Фаска}} | Знімає вибрані ребра (або, {{key:Ctrl}}+{{key:Shift}}+{{key:B}}, вершини) на вказану ширину; колесо або клавіші плюс і мінус додають сегменти для округлого ребра |
| {{ui:Розрізати петлею}} | Наведіть на ребро: нові петлі через кільце чотирикутних граней; колесо задає кількість; клацніть, щоб розрізати |
| {{ui:Ніж}} | Клацайте по точках на ребрах або кутах; {{key:Enter}} розрізає прямо через грані між ними, як ви їх бачите |
| {{ui:Розсікти}} | Проведіть лінію на екрані: вибрані грані (або всі) розрізаються по ній |
| {{ui:Обертати}} | Повертає вибрані грані або відкриті ребра навколо синьої осі кроками (колесо їх задає); повний оберт замикає |
| {{ui:Поділити}} | Розрізає вибрані ребра навпіл; цілі грані стають сіткою |
| {{ui:Злити}} | Вибрані вершини стають однією, у їхньому центрі |
| {{ui:Розчинити}} | Прибирає вибране, але зберігає поверхню: грані з’єднуються |
| {{ui:Заповнити}} | Грань поперек вибраної відкритої межі (або між двома відкритими ребрами) |
| {{ui:Заповнити сіткою}} | Заповнює відкриту межу з парною кількістю ребер сіткою чотирикутників |
| {{ui:Зʼєднати мостом}} | З’єднує дві вибрані відкриті петлі ребер гранями |
| {{ui:Складка}} | Наскільки різко вибрані ребра лишаються, коли сітку згладжує поверхня поділу: рухайте від центру, використовуйте колесо (кроки по 0.1) або введіть значення від 0 до 1. Панель показує складку вибраних ребер і приймає введене значення. Складкові ребра малюються пурпуровим кольором |
| {{ui:Віддзеркалити}}, {{ui:Згладжування}}, {{ui:Видалити}} | Перевертають грані; згладжують вершини до їхніх сусідів; видаляють за режимом вибору |

Кожна дія — один крок скасування. Координати текстури, кольори й ваги переходять на нові грані та вершини.

## Перебудова сітки

{{ui:Перебудувати сітку}} створює всю сітку заново з рівних трикутників одного розміру, який ви задаєте під час натискання (менший розмір — точніше, але повільніше). Вона закриває отвори, з’єднує частини, що перетинаються, і вирівнює сітку, яку розтягнуло ліплення. Гострі ребра стають трохи округлими. UV, розфарбування та складки починаються заново. Один крок скасування.

## Ретопологія

Щоб побудувати нову, чистішу сітку поверх детальної (скульптури, скану), виберіть детальну в {{ui:Ретопологія}} › **Побудувати на** на панелі, потім:

- **Прив’язувати переміщені точки до неї:** точки, які ви переміщуєте, і ребра, які видавлюєте, лягають на її поверхню.
- **Покласти вибрані точки на неї** переміщує вибрані точки на неї зараз (один крок скасування).
- **Показувати ребра цієї сітки попереду** малює сітку, яку ви будуєте, поверх поверхні, щоб її було видно.

## Налаштувати останню операцію

Після {{ui:Врізати}}, {{ui:Фаска}}, {{ui:Розрізати петлею}}, {{ui:Поділити}}, {{ui:Згладжування}}, {{ui:Заповнити сіткою}} або {{ui:Обертати}} панель показує її налаштування (ширину, сегменти, профіль, розрізи …). Змініть одне — і операція виконується знову з початку, все ще як один крок скасування.
