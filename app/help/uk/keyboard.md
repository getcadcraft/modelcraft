Це клавіші стилю push-pull, з яких починає ModelCraft. Про інший стиль див. [Клавіші Modeler](topic:keyboard#modeler-keys) нижче та [Налаштування ModelCraft](topic:settings).

Комбінації працюють, коли має фокус 3D-вид або кнопка на панелі інструментів. Якщо ви щойно ввели текст у полі панелі або змінили список у {{ui:Стиль}}, спершу клацніть у 3D-виді, інакше клавіші підуть до цього поля. Див. [Клавіші, миші та тачпади](common:keys), щоб дізнатися, як записуються клавіші на кожному комп'ютері.

## Esc

{{key:Esc}} відступає на один рівень кожного разу, коли ви його натискаєте:

1. Скасовує те, що інструмент робить зараз (лінію, що малюється, витягування, переміщення). Усе повертається.
2. Перемикає на {{ui:Вибрати}}.
3. Скидає вибір.
4. Закриває групу, яку ви редагуєте.

Він також зупиняє відтворення сцен. У полі значення {{key:Esc}} очищає введене і повертає до виду.

## Поки працює інструмент

| Клавіша | Дія |
|---|---|
| Цифра або один із символів `. , - ' " [ < * /` | Починає введення в полі значення |
| {{key:Enter}} | Застосовує введене в полі значення |
| {{key:Right}} | Блокує на червоній осі (натисніть ще раз, щоб розблокувати) |
| {{key:Left}} | Блокує на зеленій осі |
| {{key:Up}} | Блокує на синій осі |
| {{key:Down}} | Блокує паралельно до останнього ребра, над яким ви водили покажчик перед першим клацанням |
| Утримувати {{key:Shift}} | Утримує напрямок, до якого ви прив'язані, поки клавішу затиснуто |
| {{key:Ctrl}}, {{key:Mod}} або {{key:Alt}} (Перемістити) | Перемикає між переміщенням і копіюванням |

Блокування стрілками працюють у {{ui:Лінія}}, {{ui:Прямокутник}}, {{ui:Коло}}, {{ui:Багатокутник}}, {{ui:Перемістити}}, {{ui:Масштабувати}} і {{ui:Рулетка}} (коли вимірюєте від точки), після першого клацання. {{ui:Витягнути/втягнути}} завжди рухається вздовж напрямку грані і не має блокувань. У {{ui:Повернути}} стрілки після першого клацання показують повідомлення «Заблоковано», але не змінюють поворот.

## Миша

| Дія | Результат |
|---|---|
| Клацання | Використовує поточний інструмент |
| Натиснути, перетягнути, відпустити | Те саме, що два клацання (для інструментів малювання); вибір рамкою (для {{ui:Вибрати}}); стирання по дорозі (для {{ui:Гумка}}) |
| Подвійне клацання | {{ui:Вибрати}}: грань з її ребрами, ребро з його гранями, відкриває групу; порожнє місце закриває групу. {{ui:Витягнути/втягнути}}: повторює останню відстань |
| Потрійне клацання | {{ui:Вибрати}}: усе пов'язане |
| {{key:Shift}} + клацання | {{ui:Вибрати}}: перемикає вхід і вихід із вибору |
| {{key:Mod}} + клацання | {{ui:Вибрати}}: додає до вибору |
| {{key:Shift}} + {{key:Mod}} + клацання | {{ui:Вибрати}}: прибирає з вибору |
| Перетягування середньою кнопкою | Орбіта, з будь-яким інструментом |
| {{key:Shift}} + перетягування середньою кнопкою | Зсув, з будь-яким інструментом |
| Перетягування правою кнопкою | Зсув, з будь-яким інструментом |
| Колесо | Масштаб до покажчика |

Контекстного меню правою кнопкою немає.

## Тачпад

Що робить двопалцевий змах, залежить від {{ui:Налаштування}} › {{ui:ModelCraft}} › Прокручування:

| Жест | Тачпад (або визначено) | Колесо миші |
|---|---|---|
| Двопалцевий змах | Орбіта | Масштаб до покажчика |
| {{key:Shift}} + двопалцевий змах | Зсув | Масштаб |
| Щипок | Масштаб до покажчика | Масштаб до покажчика |
| Натиснути двома пальцями й перетягнути (утримуючи вторинне клацання) | Зсув | Зсув |

Див. [Орбіта, зсув і масштаб](topic:orbit-pan-zoom#on-a-trackpad) і [Налаштування ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

| {{key:Shift+D}} | Дублювати й перемістити копію |
| {{key:X}} або {{key:Delete}} | Стерти вибране |
| {{key:A}} / {{key:Alt+A}} | Вибрати все / не вибрати нічого |
| {{key:Tab}} | Відкрити вибрану групу або компонент; ще раз — закрити |

| Цифрова клавіатура {{key:5}} | Перспектива увімк./вимк. |

## Сенсорний екран

| Жест | Дія |
|---|---|
| Торкання | Клацання поточним інструментом |
| Подвійне торкання | Подвійне клацання |
| Натиснути, перетягнути, відпустити | Те саме, що натиснути, перетягнути, відпустити мишею |
| Два пальці: щипок | Масштаб |
| Два пальці: рухати разом | Зсув ({{ui:Налаштування}} › {{ui:ModelCraft}} › Сенсорний екран може зробити це орбітою) |
| Три пальці: рухати разом | Орбіта (Зсув, коли два пальці обертають) |
| Утримати один палець нерухомо | Завершує інструмент, як {{key:Enter}}; коли нічого не відбувається, далі перетягнути для орбіти |
| Другий палець під час дії одним пальцем | Скасовує цю дію |
| Інструмент {{ui:Орбіта}}, потім перетягнути одним пальцем | Орбіта |

Щоб ввести значення на сенсорному екрані, торкніться поля значення внизу, введіть текст і натисніть Enter (або Go) на клавіатурі.

## Де знаходиться Перемістити

Перемістити — це інструмент {{ui:Перемістити}}, клавіша {{key:M}}: виберіть, що рухати, клацніть базову точку, потім другу точку або введіть відстань. Див. [Переміщення, копіювання та масиви](topic:move-copy).
