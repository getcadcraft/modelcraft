{{ui:Render a picture…}} ގައި Mode ގެ މައްޗަށް **Engine** ނިންމުމެއް އޮވެއެވެ. އަމިއްލަ ދެ އިންޖިން ކޮންމެ ވަގުތެއްގައި ހުރި ކޮންމެ ތަނެއްގައި ވޭ؛ އެޑް-އޮންތަކުން އިތުރު ދިނެވޭ، އަދި CadCraft Studio ގައި ލިސްޓުގައި ސީން ހޯދާ ޕްރޮގްރާމްތަކެއް ވެސް ހުރެއެވެ.

|---|---|---|

| ބިލްޓިން: Path tracer | ފަކުރު ބައިތަކާ ދެމެދު ނޫރު ބައްދާ ދުވޭ، ތިޔަ ގްރާފިކްސް ކާޑު ނުވަތަ ޕްރޮސެސަރުގައި؛ ރެންޑަރ ކިއު އަދި ކޮމްޕިއުޓަރުތައް ނެޓްވޯކުގައި | ބްރައުޒަރ އަދި Studio |

## ނިންމުން ދާ ގޮތް

- Fast ނުވަތަ Path tracer ނިންމާއިރު Mode ވެސް އެއާއެކު ބަދަލުވޭ، އަދި އެހެން ފަހަރުވެސް. ނެތް ރަންގަނޑެއް އަދި ރަތް ސީމާއެއް ލިބެނީ އެހެން އިންޖިން ބޭނުން ނުކުރާ މީހުންނަށް ހަމައެކަނި ދަނީ.
- ނެތް އިންޖިން ލިސްޓުގައި ހުންނާނެ މި ސަބަބުން ("not found"، "needs a newer version"); ވަޅު ނުލެވޭ. ވެބް ގައި Studio އަށް ހުއްޓުން ހުންނަ އިންޖިން ފަހަރު "saves a file" ފެންނާނެ: {{ui:Render a picture…}} ކިޔުން ސީން އަދި ސެޓިންގްސް ފައިލަކަށް ސޭވް ކުރޭ، އެ ފައިލް އެ ޕްރޮގްރާމަށް ގެންދާނެ.
- ނިންމި ނިންމުން ފައިލްގެ ރެންޑަރ ސެޓިންގްސް އިން ސޭވް ކުރެވޭ، އަދި ފަހުން ނިންމި އިންޖިން އެ ފައިލްތަކަށް ނިމޭ ފަހަރު ފެށޭ އިންޖިން.
- އެހެން ޕްރޮގްރާމެއްގެ ފޮޓޯ ކިޔާ ފެންނާނެ ކޮން ޕްރޮގްރާމެއް ހެދިފައި ކަމާއި އޭގެ ވާރޝަން، ޑައިލޮގ އަދި ރެންޑަރ ކިއުގައި. [Render](topic:render) ޕޭޖުގެ ވަޢުދުތައް **އަމިއްލަ** އިންޖިންތަކަށް ހަމައެކަނި: އެހެން ޕްރޮގްރާމެއް ލައިޓް، ޓޯން އަދި ސެމްޕްލް އެކަކުރެވެ، ފަހެ ހަމަ ސީނެއްގެ ދެ ފޮޓޯ ކެމެރާ، ސަން، ލަމްޕް އަދި އެކްސްޕޯޒަރުން އެއްގޮތް، ނަމަވެސް ފިކްސެލް ފިކްސެލް އެއްގޮތެއް ނޫން.

## ކޮންމެ އިންޖިނަކަށް ދެވޭ ކަންކަން

ސީން އެހެން ޕްރޮގްރާމަށް **ޕެކޭޖް** ގެ ގޮތުގައި ދެވެ: މޮޑެލް USD ފައިލުގެ ގޮތުގައި ([Save as USD](topic:usd) ލިޔާ އެއް ފައިލް)، އަދި ސެޓިންގްސް ފައިލް، އެ ކަން USD އިމްޕޯޓަރަށް ބަރޯސާ ނުކުރެވޭ: ރަނގަޅު މެޓީރިއަލް އަގުތައް، ފާއުލަތަށް ހިމޭ ލަމްޕްތައް އެއްގޮތުން ބާވަތް އަދި ސްލޮޓެއް، ސަން، އުޅަނދު ސްކައި، އެކްސްޕޯޒާއި ކެމެރާ ޑައިލޮގުން އެ ގޮތަށް. އެއްވެސް ތަނަކަށް ހުރެހިނގު ނުވޭ.

## ރެންޑަރ ކިއު

ބޭރު ޕްރޮގްރާމަށް ފޮޓޯ ނުވަތަ އެނިމޭޝަން [ރެންޑަރ ކިއު](topic:render#the-render-queue) ގައި އަމިއްލަ ފަދައިން ހުރެދެވޭ؛ އެ ޖޮބް އެ އިންޖިނަށް ޙަވާލުކުރެވިފައި ހުރި ގޮތް ހަނދާންކުރާ. އެނިމޭޝަނެއް ޕްރޮގްރާމް ދިމާއަށް އެކުވެރި ގޮތުން ދަނީ.

:::note
ޕްރޮގްރާމް އެކުން ބެއްލެވޭ، ފޮޓޯ ކުރާ ޕްރޮގްރާމްތަކަށް ކެމެރާ ބޭރުން ހުރި ސީން އަދި ސްކައި ފޮޓޯ (ސްކައި ރަތް ބޭނުން ކުރެވޭ) ހިއްލާ ނުވޭ. އެހެން ޕްރޮގްރާމްތަކުގައި ކުރާ އެއްވެސް ކަމެއް މޮޑެލަށް ފަސް ނުވޭ.
:::
