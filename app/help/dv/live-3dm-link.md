މޮޑެލް ހަދާ ތަނުގައި ހަދަވާ، އަދި ނިންމާ ކަންތައް މިތަނުގައި ބޭނުންކުރޭ: ރެންޑަރު ކުރުމަށް، ރޯޝަން ކުރުމަށް، ނުވަތަ އޭގެ ވަށައި ސީން ހަދަން. އެހެން ޕްރޮގްރާމްގެ ކޮންމެ ބަދަލެއް ModelCraft ގައި ގްރޫޕެއް އެއް އަލުން އަޕްޑޭޓުވޭ.

:::note
ގުޅުމަށް **CadCraft Studio** އެއް ކޮމްޕިއުޓަރުގައި ހުރުން ބޭނުންވޭ. ބްރައުޒަރ ޓެބެއް ގުޅުން ނަގަން ނުކުރެއެވެ. އިންޓަނެޓުން އެއްވެސް ކަމެއް ނުދެވޭ: ސްކްރިޕްޓް ކުރަނީ Studio އާ މި ކޮމްޕިއުޓަރުގެ އެކަމުގެ އެޑްރެސް މެދުވެރިކޮށް، ޓޯކަނަކާއެކު.
:::

:::warning
މި ގުޅުން ސްކްރިޕްޓުގެ ފައިލް ލިޔުންތެރިއާއި އެހެން ޕްރޮގްރާމަށް ބަދަލުވާ ރޫޕާއެކު ޓެސްޓުކޮށްފައިވެއެވެ، Rhino ނުވަތަ Grasshopper ތެރޭގައި އަދި ނޫން. އެތަނުގައި ކުށެއް ވާނަމަ، އޭގެ ޖަވާބު އަހާށެވެ.
:::

## ސެޓަޕް

1. Studio ގައި ModelCraft ހުޅުވާ. {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}} ގައި، **AI އެސިސްޓަންޓުންނާ ސްކްރިޕްޓްތަކުން ModelCraft ބޭނުންކުރުމަށް ހުއްދަ ދޭ** ޓިކް ކޮށް، ފަހުން **{{ui:Edit}}**.
2. Studio ގައި {{ui:Connect an assistant}} ޚިޔާރުކުރޭ. އެތަނުން އެޑްރެސް އަދި ތިރީގައި ޕޭސްޓް ކުރާ ޓޯކަން ފެންނާނެއެވެ.
3. ސްކްރިޕްޓް ޑައުންލޯޑުކުރޭ: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino އިން

1. Rhino ގެ ސްކްރިޕްޓް އެޑިޓަރުގައި `cadcraft_link.py` ރަން ކުރޭ (Rhino 8 ގައި Python 3).
2. ފުރަތަމަ ފަހަރު، އެޑްރެސް އަދި ޓޯކަން ޕޭސްޓް ކުރޭ. އެ `.cadcraft-link.json` ފައިލުގައި ކަމުގައި ހިފާފައި، ތިޔަ ހޯމް ފޯލްޑަރުގައި، މޮޑެލުގައި ކެތްތެރި ނުވާނެ. Studio ކޮންމެ ފަހަރަކު ފެށުމުން އާ ޓޯކަނެއް ހަދާތީ، ސްކްރިޕްޓް އެވަގުތު އަލުން ސުވާލުކުރާނެއެވެ.

މޮޑެލް މުޅިން ގްރޫޕަކަށް ގެނެވެއެވެ، ފައިލްގެ ނަމަށް އަދި ފަހަތުގައި ނަމެއް ހުންނަ ("chair (linked)" ފަދައިން). ފަހުން، ކޮންމެ ބަދަލެއް ކުޑަ ވަގުތަކަށް ފަސްކުރުމުން ގެނެވޭ، އަދި ބަދަލުވި އޮބްޖެކްޓްތައް މެނީ ފޮނުވާނެއެވެ. ނިމުމަށް ސްކްރިޕްޓް އަލުން ރަން ކުރޭ.

## Grasshopper އިން

ފުރަތަމަ Rhino ގައި ސްކްރިޕްޓް އެއް ފަހަރު ރަން ކުރޭ، އެހެންކަމުން އެޑްރެސް އަދި ޓޯކަން ރައްކާކުރެވޭ.

1. Script component (Python 3) އެއް ހިންގުވާ، އަދި `cadcraft_link.py` ފުރިހަމައަށް އޭގައި ޕޭސްޓް ކުރޭ.
2. މި އިންޕުޓްތައް ދޭ: `G` (ޖިއޮމެޓްރީ، ލިސްޓް އެކްސެސްއާއެކު)، `N` (ނަމެއް، އިޚްތިޔާރީ)، `On` (ބޫލިއަން ޓޮގަލް)، އަދި `Target` (އިޚްތިޔާރީ: `model` ނުވަތަ `part`، ދެ އެޕް ހުޅުވާފައި ހުންނަނަމަ).
3. `On` ކަނޑައަޅާ true އަށް.

ކޮންމެ ސޮލްވެއްގައި `G` ފޮނުވައި، ފަހުން ފޮނުވި ކުރިން ހުރި ތަންތަން ބަދަލުކުރެއެވެ، އެހެންކަމުން ސްލައިޑަރ ދަރަނި ކުރުމުން މިތަނުގެ ގްރޫޕް އަޕްޑޭޓުވެއެވެ. އޭގެ އައުޓްޕުޓް `a` އިން ވާ ކަންތައް ފެންނާނެއެވެ. ކޮންމެ component އަކަށް އޭގެ ޚާއްޞަ ގްރޫޕެއް ވެއެވެ.

## ގްރޫޕާއެކު ކުރެވޭ ކަންތައް

- **ހިއްލާ، ޓެގ ޖަހާ، އެގިރުމުގައި ހަދާ.** ގްރޫޕް ހިނދަކު އަދި އޭގެ ޓެގ ހިސާބުން ހުރި ތަން ކޮންމެ އަޕްޑޭޓެއްގައި ހުރިކަމުން، އެގޮސް އެހެން ކުރީ ހުންނަ ކޮންމެ ކަމެއް ވެސް ހުރެއެވެ.
- **އެތެރޭގައި ބަދަލު ނުކުރޭ.** ކޮންމެ އަޕްޑޭޓެއްގައި ގްރޫޕުގެ ތެރޭގައި ހުރި ކަންތައް ބަދަލުވެއެވެ. އެ އޮބްޖެކްޓްތައް އެހެން ޕްރޮގްރާމުގެ ހޮވުން އެވެ.
- **އަންފޫ ކުރޭ (Undo).** ދެ ސެކަންޑުގެ އެތެރޭގައި ހުރި އަޕްޑޭޓްތައް އެއް އަންފޫ ފިޔަވަޅަކަށް ފައިދާވެއެވެ، އެހެންކަމުން {{key:Mod+Z}} އިން ހުރިހާ ދަރަނި އެއްފަހަރާ އަނބުރާ ލެވޭނެއެވެ. ފަހު އަޕްޑޭޓް މޮޑެލް ފަހުން ފެންނާނެއެވެ.
- **ރައްކާކުރޭ.** ރައްކާކުރެވޭ ފައިލް ގުޅުން ރައްކާކުރެއެވެ. ފައިލް އަލުން ހުޅުވުމަށްފަހު ސްކްރިޕްޓް އަލުން ރަން ކުރޭ، އަދި އެއަށްފަހު އެ ގްރޫޕް އަޕްޑޭޓުވެއެވެ.

## ފޮނުވާ ކަންތައް

މެޝް، ޕޮލިސާފޭސް، ސާފޭސް އަދި އެކްސްޓްރޫޝަން ފެންނާނީ ސްކްރީނުގައި ފެންނަ މެޝް ގޮތުގައި، SubD އޭގެ މެޝް ގޮތުގައި، ކާވްޒް އެޖް ގޮތުގައި، ބްލޮކްތައް އެކަނި އޮބްޖެކްޓް ގޮތުގައި ތަންތަނުގައި (ކޮމްޕޯނަންޓް ގޮތުގައި ނޫން)، ލޭޔަރ ޓެގުގެ ގޮތުގައި، ކުލަ އަދި ޔުނިޓް ހިސާބުން. ޖަވާބަށް [.3dm މޮޑެލް ގެނެސް](topic:import-3dm-files) ބައްލަވާށެވެ.

ނުފޮނުވޭ: ޕޮއިންޓްތައް، ޓެކްސްޓް، ޑައިމެންޝަންތައް، ލައިޓްތައް ފަދަ ކަންތައް، އެހެން ޕްރޮގްރާމުގައި އެގެ ޢަދަދު ފާހަގަކުރާ.

**އެއް މަގުން މާތް.** މިތަނުގެ ބަދަލުތައް އެހެން ޕްރޮގްރާމަށް ނުދެވޭ.

## ކުށެއް ވާނަމަ

- **"No ModelCraft or PartCraft window allows it":** ސެޓަޕްގެ ފުރަތަމަ ފިޔަވަޅު ކުރޭ.
- **"Studio refused the token":** Studio އަލުން ފަށައިފި. އާ ޓޯކަން ކޮޕީ ކޮށް ސްކްރިޕްޓް އަލުން ރަން ކުރޭ. Grasshopper އަށް، ފުރަތަމަ Rhino ގައި ރަން ކުރޭ.
- **"Cannot reach CadCraft Studio":** Studio ނުހިންގާ، ނުވަތަ އެޑްރެސް ބަދަލުވެއެވެ.
