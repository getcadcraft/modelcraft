{{ui:Select}} ({{key:Space}}) އަކީ ModelCraft ފަށާ ޓޫލް، އަދި {{key:Esc}} ދެއްކުމުން އެތަނަށް އަންނާ ޓޫލް އެވެ. ޚިޔާރުކުރެވުނު އެއްޗިހި ނީލް ކުލަ ވެއެވެ، އަދި ކަނާތުގައި {{ui:Entity info}} ގައި އެއްޗިހި ކޮންކަމެއްކަން ދައްކާ.

## ކްލިކް

| މިކަން ކުރޭ | ޚިޔާރުކުރެވޭ |
|---|---|
| ފޭސެއް ނުވަތަ އެޖެއް ކްލިކް ކުރޭ | އެ ފޭސް ނުވަތަ އެޖް |
| ގްރޫޕެއް ނުވަތަ ކޮމްޕޯނަންޓް ކްލިކް ކުރޭ | މުޅި ގްރޫޕް ނުވަތަ ކޮމްޕޯނަންޓް |
| ފޭސެއް ދެފަހަރު ކްލިކް ކުރޭ | އެ ފޭސް އަދި އޭގެ އެޖްތައް |
| އެޖެއް ދެފަހަރު ކްލިކް ކުރޭ | އެ އެޖް އަދި އޭގެ ދެފަރާތުގެ ފޭސްތައް |
| ގްރޫޕެއް ނުވަތަ ކޮމްޕޯނަންޓް ދެފަހަރު ކްލިކް ކުރޭ | ތަހުރީރު ކުރުމަށް ހުޅުވޭ (see [ގްރޫޕްތަކާއި ކޮމްޕޯނަންޓްތައް](topic:groups-components)) |
| ފޭސެއް ނުވަތަ އެޖެއް ތިންފަހަރު ކްލިކް ކުރޭ | އެއާ ގުޅުންހުރި ހުރިހާ އެއްޗެއް: މުޅި އޮބްޖެކްޓް |
| ހުސް ތަނެއް ކްލިކް ކުރޭ | އެއްވެސް އެއްޗެއް ނޫން (ޚިޔާރު ސާފުވޭ) |
| ގްރޫޕެއް ތަހުރީރު ކުރަމުން ހުސް ތަނެއް ދެފަހަރު ކްލިކް ކުރޭ | އެ ގްރޫޕް ބަންދުވޭ |

އެޖްތައް ފޭސްތަކަށްވުރެ ފަސޭހައިން ހިޓް ކުރެވޭ: ފޮއިންޓަރ އެޖެއްގެ ކުޑަ ޕިކްސެލް ކޮޅެއް ތެރޭގައި ހުންނައިރު، ކްލިކަކުން އެޖް ނަގާ.

## ބޮކްސް ޑްރެގް ކުރޭ

- **ލެފްޓުން ރައިޓަށް** ސޮލިޑް ބޮކްސް ގަދަކުރޭ: **ކޮޅު** ޚިޔާރު. ބޮކްސުގެ ތެރޭގައި ފުރިހަމައަށް ހުންނަ އެއްޗިހި ނަމަ ޚިޔާރުކުރެވޭ.
- **ރައިޓުން ލެފްޓަށް** ޑޭޝްޑް ބޮކްސް ގަދަކުރޭ: **ގުޅުން** ޚިޔާރު. ބޮކްސް ގުޅޭ ކޮންމެ އެއްޗެއް ޚިޔާރުކުރެވޭ، އަދި ފޭސެއް ބޮކްސުގެ ތެރޭގައި ފުރިހަމައަށް ހުންނާނަމަ އެ ފޭސް ޚިޔާރުކުރެވޭ.

ގްރޫޕެއް ނުވަތަ ކޮމްޕޯނަންޓް އެއް އެއްޗަކަށް ގުނެވޭ: ކޮޅު ގެ ތެރޭގައި ފުރިހަމައަށް ހުންނަންޖެހޭ، ގުޅުން ގެ ތެރޭގައި ހަމަ ގުޅިފައި ހުންނަންވީ.

## އިތުރުކުރޭ އަދި ހޮވާ

ކްލިކް ނުވަތަ ޑްރެގް ކުރާއިރު ކީއެއް ހިފާށެވެ:

| ކީ | އަސަރު |
|---|---|
| {{key:Shift}} | ޓޮގަލް: ޚިޔާރުކުރެވިފައި ނެތް އެއްޗިހި އިތުރުކުރޭ، ޚިޔާރުކުރެވިފައިވާ އެއްޗިހި ހޮވާ |
| {{key:Mod}} | އިތުރުކުރޭ |
| {{key:Shift}} އަދި {{key:Mod}} އެކުގައި | ހޮވާ |

މޮޑެލްގެ ހުރިހާ އެއްޗެއް ޚިޔާރުކުރުމަށް (ނުވަތަ ތަހުރީރު ކުރަމުންދާ ގްރޫޕުގެ ހުރިހާ އެއްޗެއް) {{key:Mod+A}} ފްރެސް ކުރޭ.

## ޚިޔާރު ސާފުކުރޭ

{{key:Esc}} ފްރެސް ކުރޭ ({{ui:Select}} ޓޫލުގެ ގޮތުގައި)، ނުވަތަ ހުސް ތަނެއް ކްލިކް ކުރޭ.

## ޚިޔާރުކުރެވިފައިވާ އެއްޗިހި ފޮހެލާ

{{key:Delete}} ނުވަތަ {{key:Backspace}} ފްރެސް ކުރޭ. ޚިޔާރުގައި ހުންނަ ފޭސް، އެޖް، ގްރޫޕް އަދި ގައިޑް އެއް ފަހަރާ ފޮހެލެވޭ؛ {{key:Mod+Z}} އިން އެތަންތަން އަނބުރާ ގެނެސްދެވޭ.

އެޖެއް ފޮހެލުމުން، އެ އެޖް ބޭނުންވާ ފޭސްތައް ފޮހެލެވޭ، ނަމަވެސް އެ އެޖް ދެ ފޭސް ވަކިކުރީ އެއް ޕްލޭނުގައި ހުންނަ ފޭސްތަކެއްނަމަ، އެ ދެ ފޭސް އެކަކަށް ގުޅެއެވެ. ފޭސެއް ފޮހެލުމުން އޭގެ އެޖްތައް ބާކީ ހުންނާނެ. [ފޮހެލާ އަދި ސާފުކުރޭ](topic:erase) ބަލާ.

## ގްރޫޕެއްގެ ތެރޭގައި ޚިޔާރުކުރޭ

ގްރޫޕަކަށް ކްލިކް ކުރުމުން މުޅި ގްރޫޕް ޚިޔާރުކުރެވޭ. އެތެރޭގެ ފޭހެއް ޚިޔާރުކުރުމަށް، ގްރޫޕް ދެފަހަރު ކްލިކް ކޮށް ހުޅުވައި، ދެން ކްލިކް ކުރޭ. ގްރޫޕެއް ހުޅުވާފައި ހުންނަ ވަގުތު، ކްލިކްތައް ރަނގަޅުވަނީ އެތެރޭގެ އެއްޗިހިންނަށެވެ؛ އެހެން ހުރިހާ އެއްޗެއް ފެތުރިފައި ހުންނެވެ. އެއްވެސް އެއްޗެއް ޚިޔާރުކުރެވިފައި ނުހުރިއިރު {{key:Esc}} ފްރެސް ކުރޭ، ނުވަތަ ހުސް ތަނެއް ދެފަހަރު ކްލިކް ކުރޭ، ގްރޫޕް ބަންދުކުރުމަށް.

ކަނާތުގައި ހުންނަ {{ui:Outliner}} ން ގްރޫޕްތަކާއި ކޮމްޕޯނަންޓްތައް ނަމުން ޚިޔާރުކުރެވޭ، އެއީ އެހެން އެއްޗިހި ފަހަތުން ފޮރުވިފައި ހުންނައިރު އެއްޗެއް ހޯދުމަށް ފައިދާ.
