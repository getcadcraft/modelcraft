ModelCraft އަކީ ކުރީ ބިލްޑެކެވެ. މި ޞަފްހާއެއް އަދިވެސް ނުކުރާ ކަންތައް ލިސްޓު ކުރައްވައި، މިއަދު އެ މަސައްކަތް ކުރެވޭ ކުރު ގޮތް ދައްކަނީ، އެހެންކަމުން އެ ހޯދަން ނުދަންނަވާށެވެ.

| ސްލޭޓަކަށް އެއް ދަރުމަލަށް ވަކިން ސައިޒް ބަދަލުކުރުން، ނުވަތަ ކޮނަ ނޫން ޑައިމެންޝަން ކޮތަރުން | ޑައިމެންޝަން ކޮނަތަކަށް، ކަނޑެއް ނުވަތަ ރަތް، ހަރި، ނީލް ދިމާއަށް ބަހާ |

## އެނިމޭޝަން

| އަދިވެސް ނޫން | މިއަދު ކުރެވޭ ގޮތް |
|---|---|
| ފަރާތްތަކާއި ކަނޑުތަކާއި، ސޫރުގެ ވަގުތު، ސްޓައިލް ނުވަތަ ފޮރުވާފައިވާ ތަންތަން އެނިމޭޓް ކުރުން | ހިއްލާ ކުރާ ބައި ގްރޫޕް ނުވަތަ ކޮމްޕޯނަންޓް ކުރޭ؛ އެހެން ވަގުތަކަށް އަލަށް ވީޑިއޯ ރެންޑަރ ކުރޭ |
| ޑްރޯ ކުރެވުނު މަގަކަށް ފޮލޯ ކުރާ ކެމެރާ، ނުވަތަ ހިއްލާ އެއްޗަކަށް ބަލާ ކެމެރާ | ކެމެރާ ކީ ގަދަ ދައުރުތަކަށް ބެހެއްޓޭ ([Animate](topic:animation)) |
| ވީޑިއޯގައި ސައުންޑް، އަދި WebGPU ނެތް ހަމަ ގުណ ހައި ކުލިޓީގެ (path-traced) ވީޑިއޯ | ވީޑިއޯ އެޑިޓަރުން ސައުންޑް އެޑް ކުރޭ؛ WebGPU ނެތީމަ ވީޑިއޯ ފާސްޓް ރެންޑަރާ ރެންޑަރ ކުރޭ ([Render the video](topic:animation#render-the-video)) |
| ރެންޑަރ ވީޑިއޯގައި އެނިމޭޝަން ލޭމްޕް (ބްރައިޓްނެސް، ސްޕްރެޑް، ރަން)، ނުވަތަ ކެމެރާ ކީތަކަށް ނުވާ ލެންސް އެންގަލް، މެޓީރިއަލް ނުވަތަ ރެންޑަރ ސެޓިންގްސް އެނިމޭޓް ކުރުން | ލޭމްޕްތައް ވިއުގައި އެނިމޭޓް ކުރޭ؛ ވީޑިއޯއަށް ކެމެރާ ކީ ނުވަތަ ޒޫމަށް ކީ ހަދާ؛ ލޭމްޕް ސެޓިންގް ވަކި ވަކި ވީޑިއޯ ރެންޑަރ ކުރޭ ([Animate any property](topic:animate)) |
| އެއް ފަރާތުން އަނެއް ފަރާތަށް ވެއިޓްސް ނުވަތަ ބޯން މިރާރ ކުރުން، ފެންނާ ބޯން އިންވެލޯޕްސް، ފުރުވާ ފަރާތްތަކަށް ވެއިޓްސް ކުރުން (ފަރާތް ފަރާތަށް ފެންނޭ)، ވެއިޓްސް ރެންޑަރ ކުރުމުން ޕޯޒް ކުރި މެޝް ފެންނުން | ދެފަރާތް ފަރާތް ކުރޭ، ނުވަތަ ފަރާތެއް ހަދާ Mirror މޮޑިފަޔަރ ބޭނުންކޮށް ޕޫރުގައި އާކްމޭޗަރ ކުރޭ؛ ވެއިޓްސް ފަރާތު ފަސޭ ކުރޭ Pose ގައި ހިމާނަން |
| glTF، FBX ނުވަތަ USD ފައިލުންނާއި ކާ ބޯންސް އާކްމޭޗަރ ކަމުގައި ކިޔަވާ، ނުވަތަ އެ ފައިލްތަކަށް އާކްމޭޗަރ ލިޔުން | ސްކިންކުރެވުނު މޮޑެލްތައް ފައިލުގެ ވެއިޓްސްާ އަދި ނިލި ގޮތުން ނިންމާލޭ؛ ބޯންސް ފައިލުގެ ޖޯއިންޓް އޯޑަރުން ދަމާ، ދެން {{ui:Use the file's weights}} ([Animate](topic:animate)) |
| IK ޓާގެޓް ނުވަތަ ޕޯލް ވިއުން ދުލުން، ކޮންސްޓްރެއިންޓުގެ ޝޭޕް ސެޓިން (ލޯކަލް ނުވަތަ ވޯލްޑް)، IK ޗޭން ސްޓްރެޗް ކުރުން، ކާރުވް މަތީގެ IK | ޓާގެޓުގެ ނުކުތާ ލިޔޭ، ނުވަތަ އެއްޗަކަށް ބަލާ އެ އެއްޗެއް ހިއްލާ ކުރޭ؛ ޗޭންތައް އެމީހުންގެ ދިގުމިންތަކުގައި ކިބައިން ބޭހަ ކުރޭ |
| ކްލޮތް، ފްލޫއިޑް، ސޮފްޓް ބޮޑީ، ރިޖިޑް ބޮޑީތަކާ ދެމެދު ޖޮއިންޓް އަދި ހިންޖް، އެއް ޝޭޕް ރިޖިޑް ބޮޑީގެ ރަގަޅު ފިޔަކާ ފެތުން (ބޮކްސް އަދި ބޯލްތަކުން ފަރުވާ ދިލޭ)، ލައިވް ސިމިއުލޭޝަން ކުރަމުން އެނިމޭޝަން ކުރުން، ފަށާ ސްޕީޑް ނުވަތަ ސްޕިން (ބޮޑީތައް ރެސްޓުން ފަށާ) | ރިޖިޑް ބޮޑީތައް ބޭކުކޮށް ކީތައް ކޮށް ކުރޭ؛ ކީތަކުން ހިންޖް ހަދާ؛ ކޮޅު ޝޭޕެއް ބޮކްސް (ގްރޫޕްތައް) ކަމުގައި ބެހޭ |
| އެނިމޭޝަން glTF ނުވަތަ އެހެން މޮޑެލް ފައިލްތަކަށް އެކްސްޕޯޓް ކުރުން | ވީޑިއޯ ރެންޑަރ ކުރޭ؛ `.modelcraft` ފައިލާއި، ModelCraft ސޭވްކުރި [USD ފައިލް](topic:usd) ModelCraft އަށް ފަހަރު ކުރޭ |
| VR ގައި ތަރުޖަމާ ކުރުން ނުވަތަ ތިރި ޓައިޓަލް ޓައިޕްކުރުން، ފޮނޑީ ވޮއިސް ނޯޓްސް، VR ގައި ސެކްޝަން ޕްލޭން ދެމި ހިއްލާކުރުން | ޕްރޮބްލަމް VR ގައި ބެހެއްޓި ހަމަ ލިޔުން BCF ޕްރޮގްރާމްގައި ލިޔޭ؛ ވިއުގައި ސެކްޝަން ޕްލޭން ދާންކުރުމުގެ ކުރިން ސެޓް ކުރޭ: [VR headset ގައި މޮޑެލް ރިވިއު ކުރޭ](topic:vr-review) |

| ޝޭޕްގެ ގޮތަށް ހަތަރު ކުނޑާއި ފަރާތްތަކަށް ރީމެޝް ކުރުން | {{ui:Remesh}} (ތިން ކުނޑު ރަނގަޅު)، ދެން [Retopology](topic:mesh-edit#retopology) އިން އަލުން ހަދާ |

| ވާޓިސް، އެޖް ނުވަތަ ފަރާތްތައް ކޮޕީ އަދި ޕޭސްޓް ކުރުން، ފަރާތެއްގެ ތެރޭގައި ނިމޭ ނައިފް ކަނޑު، ފަރާތެއް ނެތް ވަޔަރ އެޖްތައް | މޮޑެލްގައި މެޝް ޑުޕްލިކޭޓް ކުރޭ؛ އެޖް އިން އެޖަށް ނައިފް ކުރޭ؛ ފަތް އެޖްތައް ފަރާތްތަކަށް [Extrude](topic:mesh-edit#change-the-shape) ކުރޭ |

## ރެންޑަރކުރުން

| އަދިވެސް ނޫން | މިއަދު ކުރެވޭ ގޮތް |
|---|---|
| ވިއުގައި ރެންޑަރކުރުން ({{ui:Render}} ވޯކްސްޕޭސް)، ރެންޑަރ ކިއު، އަދި ކެމެރާ، ސްކައި ފޮޓޯ، ފޮގް އަދި ލައިޓް މިކްސިން އޮޕްޝަންތައް WebGPU ނެތީމަ | {{ui:Render a picture…}} ގައި {{ui:High quality}} ބޭނުން ކުރާ ހިސާބުން WebGL path tracer ކުރެވޭ، އެ އޮޕްޝަންތަކެއް ނެތި ([Render a picture](topic:render#high-quality)) |
| ރެންޑަރ ފޮޓޯ އެހެން ޕްރޮގްރާމަކުން ޑްރޯ ކުރުން (ރެންޑަރ އިންޖިން އެޑް-އޮން ނެތި)، ޕެނަރަމާ ނުވަތަ ސްޓެރިއޯ ކެމެރާ، އަދި ސްކައި ފޮޓޯ އެހެން ޕްރޮގްރާމަކުން؛ Unreal Engine ޕްލަގް އިން (ފައިލްތައް ލިޔެވޭ، އެ ފައިލް ހުޅުވާ ޕްލަގް އިން ރިލީސް ނުކުރެވޭ) | އަމިއަލް Fast އަދި Path tracer އިންޖިން؛ އެޑް-އޮނެއްގެ އިންޖިން؛ ([draw the picture with another program](topic:render-other-program))؛ USD، glTF ނުވަތަ Unreal ފޮލްޑަރ ފައިލް Engine ލިސްޓުން ނެގުން |
| {{ui:Render a picture…}} ގައި ޕްލާންޓްސް އަދި ރޮކްސް ސްކެޓަރ ކުރުން | ވިއު ޔާގެ [live view](topic:live-view) ގައި، އޭގެ ޕެނަރޭމާ، ވިއުއާ އަދި ވީޑިއޯ ފެނޭ |

## މެޓީރިއަލް އާއި ރަން

| އަދިވެސް ނޫން | މިއަދު ކުރެވޭ ގޮތް |
|---|---|
| ބޭސް ކަލަރާއި ރޯފްނެސް، މެޓަލްނެސް، ހިސާބު، ނޯމަލް އަދި އެމިޝަން ފަރަގު ނޫން ކަންތައްތައް ހައި ކުލިޓީ ފޮޓޯތަކުގައި ފަރާތުގައި ބަދަލުވުން (އެމީހުން ސަރާސަރި ހިސާބު ބޭނުން ކުރާ) | [Make materials with nodes](topic:shading): ނަމަވެސް ލިންކް ކުރޭ، ވިއުގައި ބަދަލުވާތީ ފެންނާނެ |
| Push/pull ފަރާތްތަކުގެ މައްޗަށް ޑިސްޕްލޭސްމަންޓް | އޮބްޖެކްޓް މެޝަށް ބަދަލު ކޮށް ޑިސްޕްލޭސްމަންޓް ކުރޭ |
| އެޕުން ލައިބްރަރީއަށް ތިޔަ މެޓީރިއަލް ޝެއާ ކުރުން، ނުވަތަ ޕެކްޑް (ARM/ORM) ނުވަތަ EXR މެޕް އިމްޕޯޓްކޮށް ޓެކްސްޗަރ ސެޓް ކުރުން | ފައިލުގައި ހިފާ؛ ވަކި މެޕްތައް PNG ނުވަތަ JPEG އިމްޕޯޓް ކުރޭ |
| ލައިވް TeamWork ސެޝަންތަކުގައި ފައިލްގެ މެޓީރިއަލްތައް (އެ ހިފީ ކޮމްޕިއުޓަރަށް) | ފައިލް ސޭވް ކުރޭ އަދި ޝެއާ ކުރޭ |
| Push/pull ފަރާތްތަކަށް ވަރަކަށް އަތް ނުދެވޭ ގޮތް، ނުވަތަ ދިމާ ފަރާތް ހަތަރު ފަރާތް މެދު ޓެކްސްޗަރ ފެންނާއިރު | ކުރު ފަރާތްތަކެއް ކޮންމެ ބައިގައި ބަހާ؛ ތިރީ ތަން ރަނގަޅުކޮށް ރަނގަޅު ކުރޭ |
| ގުޅި ފަރާތް ރުއި ހަރާމު، ނުވަތަ ބޭރު ކުރެވޭ ފިދާފައި ނުވާ ފަރާތް | ކޮނބުން ކަނޑާ ފަރާތް ހަދާ؛ ވަނަކަން ކުރާ ފަރާތް ކަން ކުރޭ |
| Collada، STL، PLY، 3MF، IFC، DWG އަދި DXF އެކްސްޕޯޓްގައި ޓެކްސްޗަރ، ނުވަތަ ފައިލުގެ މެޓީރިއަލްތަކުގެ ނޯޑް ގްރާފް | އެ ފޯމެޓްތަށް މެޓީރިއަލްގެ ކަލަރު ލިބޭ؛ glTF އަދި OBJ ތަކަށް އިމްޕޯޓުކުރި ޓެކްސްޗަރ ލިބޭ؛ [MaterialX](topic:shading#materialx) ގައި މެޓީރިއަލް ވަކިން އެކްސްޕޯޓް ކުރޭ؛ [USD](topic:usd) ގެ މުޅި މޮޑެލް ModelCraft އަށް ބާއްތަފައި |

## ފައިލްތައް

| އަދިވެސް ނޫން | މިއަދު ކުރެވޭ ގޮތް |
|---|---|
| SketchUp ފައިލް ސޭވްކުރުން، އަދި އެމީހުންގެ ޓެކްސްޓް އަދި ޑައިމެންޝަން | [Import](topic:import-sketchup-files) ފަރާތް، ކަލަރާ އަދި ޓެކްސްޗަރ ބާއްތަފައި؛ SketchUp އަށް އަނބުރާ ދިއުމަށް Collada (`.dae`) އެކްސްޕޯޓް ކުރޭ |
| DWG އަދި DXF އެކްސްޕޯޓުގައި ޑައިމެންޝަން އަދި ގައިޑްސް | އެކްސްޕޯޓް ކުރުމަށްފަހު CAD ޕްރޮގްރާމްގައި އިތުރު ކުރޭ |
| DWG އަދި DXF ގެ ނުކުތާ، ޓޭބަލް އަދި މަލްޓީލީޑާ | ގިނަކޮށް ގުޅުމާ ފަސްކުރެވެއެވެ؛ ލިޔުން ސިންގަލް-ސްޓްރޮކް ލެޓަރިން ގޮތުން އަންނަ، ޑްރޯއިންގްގެ ފޮންޓް ނޫން |

## ކާރުކުރުން

Undo ކޮންމެ ސްޓެޕަކަށް މޮޑެލް ކޮޕީއެއް ދައުވެއެވެ ([mesh](topic:meshes) ހަމަ ބަދަލުވި ބައި ތެރޭގައި ހިފާ)، އެހެންކަމުން ބޮޑު ބަނިކުރުން push/pull ޖިއޮމެޓްރީ ފުރުވޭ ކޮށް ކޮންމެ އެޑިޓެއް ފަސް ކުރެއެވެ. އިމްޕޯޓް ހުރިތަން ހަލުވިކަމުން ހިފާ، ފޮޓޯ ފާފަ ހަދާ ހިސާބުން ހިސްޓަރީ ފަޅާލާ.

## އެޕްސް އަދި ޕްލެޓްފޯމްތައް

- **ޑެސްކްޓޮޕް:** ModelCraft ބްރައުޒަރުގައި Mac، Windows އަދި Linux ގައި ހިންގެއެވެ، އަދި CadCraft Studio ގައި، އެއީ އެއް އިންސްޓޯލް ގައި އަށް އެޕް ހުރި ޑެސްކްޓޮޕް އެޕެކެވެ. Android ގައި CadCraft Studio އެޕީ APK އިން ވާ ހިސާބު getcadcraft.com/download. iPad ނުވަތަ iPhone ބިލްޑެއް އަދިވެސް ނެތް.
