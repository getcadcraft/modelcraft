## 你將學到的內容

如何讓 AI 助理（或你自己寫的指令稿）與 ModelCraft 協作，以及如何決定它可以修改哪些內容。

ModelCraft **本身沒有 AI**，也不會把任何資料傳送到其他地方。助理由你提供：任何支援模型情境協定（MCP）的程式都可以。ModelCraft 只提供工具，由你決定開放哪些工具。

## 啟用

1. 開啟 {{ui:設定}}（應用程式列上的齒輪，或 {{key:Mod+,}}），然後前往 {{ui:ModelCraft}} 索引標籤。
2. 在 {{ui:助理}} 下勾選 **讓 AI 助理與指令稿使用 ModelCraft**。在勾選之前，此功能為關閉狀態。
3. 選擇它可以執行的動作：**讀取** 預設已勾選；只有在需要時才勾選 **編輯**、**儲存** 或 **匯出**。

未勾選權限之外的工具不會提供給助理；即使助理仍要求使用，ModelCraft 也會拒絕，並將此紀錄寫入活動紀錄。關閉開關會立即結束所有連線；{{ui:重設 ModelCraft 設定}} 也會將其關閉。

## 連線你的助理

助理透過你電腦上的 **CadCraft Studio** 連線：Studio 會執行一個只有這台電腦能連到的小型伺服器，並以每次啟動時產生的權杖加以保護。在 Studio 中選擇 {{ui:連線助理}}，然後將位址與權杖複製到你的助理中（Studio 會顯示要貼上的確切設定）。切勿分享權杖。

:::note
瀏覽器分頁無法為助理開啟連線：在瀏覽器版應用程式中，此開關在你使用電腦上的 CadCraft Studio 之前不會有任何作用。
:::

## 你隨時掌控

- **每個變更都是一個復原步驟**，並以助理為該變更取的名稱標示（例如「助理：方盒」）。{{key:Mod+Z}} 會將助理的最後一次變更整體復原。
- **你會知道何時已有連線。** 連線期間，應用程式列上的按鈕會顯示助理名稱；點擊它即可查看其可執行的動作，或 **中斷連線**。
- **活動。** {{ui:設定}} › {{ui:ModelCraft}} › {{ui:助理}} › {{ui:活動}} 會列出每一次呼叫：時間、使用的工具，以及已完成或已拒絕。{{ui:儲存紀錄}} 會保留一份副本。

## 助理可以要求的項目

| 工具 | 權限 | 功能 |
|---|---|---|
| `app_info`, `model_describe` | 讀取 | 模型的單位、尺寸，以及每個群組與元件的位置、是否為封閉實體，以及其體積 |
| `view_screenshot` | 讀取 | 目前所見 3D 視圖的圖片 |
| `box_add`, `cylinder_add` | 編輯 | 以你或助理指定的位置與尺寸，新增一個方盒或圓柱作為新群組（「3m」、「10'」或模型單位的數字） |
| `instance_move`, `instances_erase` | 編輯 | 移動或刪除群組與元件 |
| `faces_list`, `materials_list` | 讀取 | 群組或獨立幾何的面（各面的方向、面積與中心）；可用來上色的材料與顏色 |
| `push_pull` | 編輯 | 推或拉一個面，與 {{ui:推拉}} 相同 |
| `paint` | 編輯 | 以顏色或材料為面或整個群組上色 |
| `group_make` | 編輯 | 將獨立的面與群組建立為群組或元件 |
| `scene_add`, `scene_show` | 編輯 | 將視圖儲存為場景；前往已儲存的場景 |
| `mesh_add` | 編輯 | 可作為起點的網格物件（立方體、球體、圓柱……），與網格工作區新增的方式相同 |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | 讀取 / 編輯 | 網格的修改器堆疊：鏡射、陣列、細分、斜角等其他修改器；不會永久套用任何內容 |
| `usd_export` | 匯出 | 以 OpenUSD（.usda、.usdc 或 .usdz）格式輸出模型，與將模型儲存為 USD 的結果相同（[USD](topic:usd)）；輸出至你在 Studio 中允許的資料夾，否則為下載 |
| `render_still` | 匯出 | 視圖或已儲存場景的算圖圖片，與 {{ui:算圖}} 對話方塊中的 {{ui:算圖}} 按鈕產生的結果相同，並使用你的算圖設定，除非助理要求其他設定（場景預設：外部、內部、剖面、夜間或自動；快速或高品質、尺寸、取樣數、天空）；可供助理檢視的 PNG，或是儲存在你於 Studio 中允許之資料夾中的 PNG、EXR 或算圖檔（[算出圖片](topic:render)） |
| `render_queue` | 匯出 | 將高品質圖片加入算圖對話方塊的佇列（視圖或已儲存場景），並執行佇列；完成的圖片會輸出至你允許的資料夾，或保留在算圖對話方塊的 {{ui:算圖佇列}} 中供你查看。需要 WebGPU |
| `link_push` | 編輯 | 更新從其他程式連結的模型（參閱[讓 .3dm 模型保持即時](topic:live-3dm-link)） |
| `link_status` | 讀取 | 說明連結的模型是否仍然存在，以及最後一次更新的時間 |
| `undo` | 編輯 | 復原其自身的步驟 |

助理建立的實體會以群組形式加入，因此不會與你繪製的內容合併。沒有任何工具可以儲存模型：儲存仍由你負責，而匯出或算圖則需要勾選 **匯出**。算圖不會改變模型；算圖已儲存的場景時，視圖會移至該場景，與 {{ui:場景}} 的行為相同。

## 如果無法運作

- **助理看不到任何 ModelCraft 工具：** 確認此視窗中的開關已開啟，且該視窗已在 Studio 中開啟。
- **「需要編輯權限」：** 在 {{ui:助理}} 下勾選 **編輯**，然後再次要求。
- **「401」或「token」錯誤：** 權杖已變更（Studio 重新啟動，或 {{ui:新權杖}}）。將新權杖複製到助理的設定中。
