視圖方塊位於 3D 視圖的右上角。它會隨視圖一起旋轉，因此總是顯示你目前的觀看方向：{{ui:俯視}} 朝上，{{ui:前視}} 朝南（當你看著它時，你是朝北看，沿綠色軸），{{ui:右視}} 朝東（紅色軸）。在你指向它之前，它會保持半透明。

## 從一側、一條邊或一個角查看

1. 將指標指向方塊。指標下方的部分會亮起：面的中央、邊（會在共用該邊的兩個面上亮起），或角（會在三個面上亮起）。
2. 點擊它。視圖會轉向並從該處查看，同時保持相同的中心與縮放。

共有 26 個可點擊的位置：6 個面（{{ui:俯視}}、{{ui:仰視}}、{{ui:前視}}、{{ui:後視}}、{{ui:左視}}、{{ui:右視}}）、12 條邊與 8 個角。角會提供經典的四分之三視圖；邊則會介於兩個面之間。

點擊 {{ui:前視}} 與工具列中的 {{ui:視圖}}、{{ui:前視}} 相同，只是不會進行符合視窗的縮放。{{ui:視圖}} 仍會縮放至整個模型。

## 拖曳方塊以環繞

拖曳方塊即可旋轉視圖，與在視圖本身中環繞的效果相同。拖曳永遠不會被視為點擊，因此你可以在方塊的任何位置抓取。

## 指北針環

方塊下方的環標示 N、E、S 與 W。

- **拖曳環**，使模型繞垂直軸旋轉，就像放在轉盤上一樣。環會跟隨指標移動。
- **點擊字母**即可從該側查看，並保持你向下俯視的角度。在正上方的視圖中，你點擊的字母會移至螢幕底部。

## 正面視圖：箭頭

當你正對著某個面時，方塊周圍會出現小箭頭：

- 四個**三角形**會將該側的面帶到正面：方塊上方的三角形指向原本位於頂部的面，依此類推。
- 右上角的兩個**弧形箭頭**會將畫面順時針或逆時針旋轉四分之一圈，但不會改變你所看的面。可用它們旋轉平面圖，使一道長牆橫跨螢幕。

## 首頁

方塊左上角的房屋按鈕會返回四分之三的 {{ui:等角}} 視圖，並將整個模型符合視窗。方塊具有鍵盤焦點時，按下 {{key:Home}} 也會執行相同的動作。

## 使用鍵盤

按 {{key:Tab}} 移至方塊，然後：

| 按鍵 | 功能 |
|---|---|
| {{key:left}} / {{key:right}} | 以八分之一圈為步進，選取方塊周圍的一側、邊或角（螢幕閱讀器會朗讀所選項目） |
| {{key:up}} / {{key:down}} | 選取較高或較低的項目，最高到 {{ui:俯視}}，最低到 {{ui:仰視}} |
| {{key:Enter}} 或 {{key:Space}} | 從所選項目查看 |
| {{key:Shift+left}} / {{key:Shift+right}} | 使視圖繞垂直軸旋轉四分之一圈 |
| {{key:Home}} | 首頁視圖 |
| {{key:Esc}} | 離開方塊 |

在方塊上按下的按鍵只作用於方塊：它們不會啟動 ModelCraft 工具。

## 改用座標軸圖示或不顯示

開啟 {{ui:設定}}（{{key:Mod+,}}）、{{ui:ModelCraft}} 索引標籤，並將 **角落指示器** 設為 {{ui:視圖方塊}}（預設值）、{{ui:座標軸圖示}}（左下角的小型 X、Y、Z 標記：X 為紅色，Y 為綠色，Z 為藍色）或 {{ui:無}}。此瀏覽器會記住你的選擇。請參閱 [ModelCraft 設定](topic:settings#corner-indicator)。

:::note
ModelCraft 沒有滾轉功能：除了正上方與正下方的視圖外，螢幕上的上方永遠是模型中的上方。方塊與弧形箭頭可以旋轉平面圖視圖；但無法將側視圖傾倒至其一邊。
:::
