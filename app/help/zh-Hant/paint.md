色彩可協助區分模型的各個部分，而**材質**（磚塊、壁板、屋頂材料、木材、石材、磁磚、混凝土、灰泥、草地、玻璃、金屬）能讓模型看起來像其實際建造所用的材料。兩者的上色方式相同。

## 選擇色彩

{{ui:色彩}}區段位於右側，顯示一排單色、{{ui:預設}}（畫有斜線的那一個：無色彩），以及用來選取其他色彩的{{ui:+}}色票。按一下即可將其設為目前色彩。上色工具會以目前色彩開始。

## 上色

1. 按{{key:B}}（{{ui:上色}}），或在未選取任何物件時按一下色彩。（若已選取物件，按一下色彩會立即為選取的物件上色。）
2. 按一下面即可為其上色。
3. 按一下群組或元件，即可為該副本上色：沒有自己色彩的面會採用此色彩。在其中自行上色的面則保留原色彩。

若要一次為多個物件上色，請先選取它們，再按一下色彩；或使用{{ui:上色}}按一下其中任一物件。這是一個復原步驟。

| 按住 | 再按一下面 | 上色範圍 |
|---|---|---|
| — | | 該面 |
| {{key:Ctrl}} | | 所有與其相連且顏色相同的面 |
| {{key:Shift}} | | 目前所處群組中所有該顏色的面 |
| {{key:Alt}} | | 不上色：改為吸取該色彩 |

若要將面還原為無色彩，請選擇{{ui:預設}}並按一下該面。

## 使用材質上色

{{ui:材質}}區段位於{{ui:色彩}}之下，依類別列出材質庫：磚塊與砌塊、壁板、屋頂材料、木材、石材、磁磚、混凝土、灰泥、地面、玻璃與金屬。將游標移到色票上可看到名稱。按一下材質後，即可像使用色彩一樣上色：按{{key:B}}，再按一下面、群組或元件；或先選取，再按一下材質。

- 在**著色**樣式中，面會顯示材質的貼圖。隱藏線、線框與 X 光則顯示其色彩。
- 貼圖會沿每個面**水平**與**向上**排列：磚的砌層在每面牆上都保持水平，屋瓦沿屋頂斜面向下排列，地板上的木板沿紅軸方向排列。貼圖為實際尺寸（一塊磚約長 215 mm），因此在任何距離下都能正確顯示。
- 在[算圖圖片](topic:render)中，材質會保留其貼圖、粗糙度，以及玻璃與金屬的光澤。
- 使用{{ui:上色}}時按住{{key:Alt}}並按一下，也會吸取面的材質。

這些貼圖由 ModelCraft 自行繪製，因此可離線使用，且可免費用於任何用途（CC0）。

## 元件與色彩

在元件**內部**的面上所上的色彩，會顯示在每個副本上，因為副本共用同一份定義。在元件關閉的情況下，從外部對**副本**上的色彩只屬於該副本，因此同一元件的兩個副本可以有不同色彩。{{ui:實體資訊}}會顯示選取的面、群組或元件的色彩。

## 檔案中的色彩

- ModelCraft 檔案會保留每個色彩與每種材質。
- 其他格式會以**材質的色彩**（遠看的外觀）取代貼圖：glTF、Collada、OBJ、DWG 與 DXF，以及 3D 列印檢查。在 glTF、Collada 與 OBJ 中，材質會保留其名稱，例如 `Material_brick-red`。
- **glTF (.glb)** 與 **Collada (.dae)**：每個色彩會成為一個材質。以不同色彩顯示的元件會依每種色彩各寫入一次。glTF 也會將匯入的貼圖寫為貼圖。
- **OBJ**：匯出時會下載兩個檔案，即 `.obj` 與含色彩的 `.mtl` 材質檔。請將它們放在同一資料夾。若有匯入的貼圖，`.obj`、`.mtl` 與圖片會合併為一個 `.zip`。
- **DWG** 保留精確的色彩；**DXF** 使用 255 種標準 CAD 色彩中最接近的一種。
- **STL** 與 **PLY** 會攜帶色彩：STL 採用 VisCAM / SolidView 慣例（不讀取此慣例的程式會忽略它），PLY 則為每個點的色彩。請參閱[詳細檔案格式](topic:formats)。

:::tip
要模擬螢幕，請在[偏移](topic:draw-faces)正面後，將框架上色為炭灰色，玻璃上色為藍色。
:::
