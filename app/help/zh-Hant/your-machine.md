開啟{{ui:設定}}（{{key:Mod+,}}），停留在本應用程式自己的索引標籤上，並捲動到{{ui:算圖}}。{{ui:你的電腦}}列出瀏覽器允許本應用程式用於算圖的項目。其中的內容都不會離開這台電腦。

| 項目 | 說明 |
|---|---|
| {{ui:顯示卡}} | 瀏覽器回報的顯示卡。「WebGPU」表示可以完成所有算圖工作；「WebGL 2 only」表示即時檢視和{{ui:算出圖片…}}會使用它（以 WebGL 路徑追蹤器達到高品質），但不提供在檢視中算圖與算圖佇列（需要 WebGPU）；若為軟體替代方案，則所有工作都由處理器執行 |
| {{ui:處理器}} | 瀏覽器回報的處理器核心數量 |
| {{ui:記憶體}} | 瀏覽器有提供時，約為這台電腦的記憶體容量。部分瀏覽器不提供 |
| {{ui:共享記憶體}} | 頁面是否可在其工作執行緒之間共享記憶體。開啟時，每個核心都能處理同一份場景；關閉時，每個核心都需要各自的副本，因此大型場景同時能使用的核心較少 |
| {{ui:快速處理器程式碼}} | 瀏覽器是否執行較快的 WebAssembly 程式碼。未啟用時會改用較慢的備用方案 |
| {{ui:等級}} | {{ui:顯示卡，高階}}、{{ui:顯示卡，基本}}或{{ui:僅處理器}}，原因顯示於其下方 |

## 等級

等級決定[即時檢視](topic:live-view)的起始模式（{{ui:依這台電腦}}）、繪製的散佈項目數量，以及[細分曲面](topic:modifiers#subdivision-surface)在檢視中可顯示的面數，使只有內建顯示晶片或完全沒有顯示卡的筆電仍能保持流暢。內建或手機用的顯示晶片，或記憶體為4 GB以下時，一律不會取得{{ui:顯示卡，高階}}。

:::note
瀏覽器之間各有不同。同一台電腦在一個瀏覽器中可能顯示 WebGPU，在另一個瀏覽器中則顯示「WebGL 2 only」。在Linux上，多數瀏覽器尚未提供 WebGPU。
:::
