**修飾器**可改變網格的顯示方式，而不改變網格本身。將零件的一半鏡射，即可只建模該一半；以細分曲面將方塊變圓，同時仍可繼續編輯該方塊。修飾器置於**堆疊**中，依由上至下的順序運作。所見、匯出、列印與算圖的內容，是網格加上所有已啟用的修飾器後的結果。

## 新增修飾器

1. 選取網格。在模型工作區中，其**修飾器**區段位於{{ui:Entity info}}中；在網格工作區中，則位於右側面板中。
2. 從{{ui:Add a modifier…}}中選取一個修飾器。它會加入堆疊的最下方。
3. 在其名稱下方變更設定。長度與數值方塊接受相同的值，因此`600mm`、`2'6"`與`(6m)/4`皆可使用。

每次變更都是一個復原步驟：{{key:Mod+Z}}可將其取消。

## 各修飾器上的按鈕

- 勾選框可開啟或關閉修飾器。
- 螢幕按鈕可在視圖中顯示或隱藏它（它仍會保留在堆疊中）。
- 攝影機按鈕可在算出的圖片與影片中顯示或隱藏它，因此修飾器可僅用於算圖（或僅用於視圖）。
- 箭頭可將其在堆疊中上移或下移。順序很重要：先鏡射後細分，接縫會平滑；先細分後鏡射則不會。
- {{ui:Apply}}會將形狀納入網格本身：位於其上方的修飾器與此修飾器會套用到網格本身，並離開堆疊。為一個復原步驟。
- 叉號可移除它。

## 修飾器

| 修飾器 | 作用 |
| --- | --- |
| Scale | 以物件原點為基準縮放，紅、綠、藍各自可設定倍率。也適用於群組或元件。 |
| Mirror | 沿紅、綠或藍軸，通過網格原點新增鏡射副本，並在兩半相接處接合。 |
| Array | 沿直線（步距為其自身大小乘以所設定的數值，再加上固定步距）、繞軸或沿模型中的曲線複製。群組或元件僅適用直線陣列。 |
| Subdivision surface | 以 Catmull-Clark 細分平滑網格，銳利的邊會保持摺痕。算圖可使用比視圖更多的層級。 |
| Bevel | 將每個比所設定角度更銳利的邊變圓。 |
| Solidify | 為曲面賦予厚度，並封閉邊緣。 |
| Boolean | 與模型中另一物件相減、聯集或保留重疊部分。兩者都必須是封閉實體。 |
| Displace | 以平滑雜訊將曲面向內或向外移動。相同的種子值每次都會產生相同的凸起。 |
| Weld | 將距離小於指定值的頂點焊接。 |
| Decimate | 保留一部分三角形，優先移除對形狀影響最小的三角形。 |
| Smooth | 使頂點朝相鄰頂點鬆弛。 |
| Lattice | 以籠子使網格彎曲：移動籠子的點，網格便會跟隨。 |
| Curve deform | 沿模型中的曲線，依紅、綠或藍軸使網格彎曲。 |
| Shrinkwrap | 將每個頂點移至另一物件上最近的點。 |

## 在群組或元件上

群組或元件同樣可保留一份配方，因此燈罩可以是一個**縮放**，加上該燈罩的一組**陣列**；變更一個數值即可改變整盞燈。

1. 選取群組或元件。在{{ui:Entity info}}中，其**修飾器**區段會列出堆疊（起初為空）。
2. 從{{ui:Add a modifier…}}中選取{{ui:Scale}}或{{ui:Array}}。群組會成為一個元件，即**原件，由堆疊放置**。原件會保留：編輯它時，所有副本會立即跟隨。
3. 縮放需為紅、綠、藍各設定一個倍率（`1, 1, 2` 會使高度加倍）。陣列需設定副本數量、以目前結果尺寸的比例表示的步距，以及以長度表示的額外步距。

堆疊會依由上至下的順序，以原件自身的軸、以其原點為基準運作，因此順序很重要：先陣列三個相距 3 m 的副本，再於紅軸上縮放 2 倍，會使副本相距 6 m；若先縮放、再陣列，則副本會保持相距 3 m。勾選框、箭頭與叉號的作用與網格相同；但單一修飾器上的視圖與攝影機按鈕以及套用，則不適用，因為群組上的堆疊是一個整體。

- {{ui:Edit source}}會就地開啟原件。變更會顯示於每個副本；關閉後即返回原本的位置。
- {{ui:Bake modifiers}}會將結果轉為一般的邊與面，並移除堆疊，為一個復原步驟。彼此重疊的副本會保持為獨立的幾何：烘焙並非聯集。
- 元件的副本共用同一配方；{{ui:Make unique}}會將其分開（原件仍維持共用）。
- 堆疊會儲存於檔案中，可隨複製貼上與復原一併帶入；清除未使用項目會保留原件。不認識修飾器的程式仍會顯示副本。
- 在烘焙之前，結果無法開啟、分解、調整大小或拉伸：下次變更時會被重建。各項操作都會明確說明此限制。
- 上限為 32 個修飾器與 1,000 個副本。設為可拉伸的元件（Stretch）與堆疊目前尚無法共用同一定義。

## 細分曲面

細分會以 Catmull-Clark 方式平滑網格：每個面都會變成四邊形的面，每一層級都會使面數變為四倍。方塊經過兩或三個層級後，即呈現為圓潤的形狀，且仍可繼續編輯該方塊。

- **視圖中的層級**設定其平滑程度。
- **算圖中的層級**設定算出的圖片與影片的平滑程度；算圖可使用比視圖更多的層級。
- **算圖使用真實平滑曲面**會將算圖網格的頂點放在各層級趨近的極限曲面上，因此即使只有兩層，算圖也會與更多層一樣平滑。
- **摺痕**可使邊保持銳利：在網格工作區中選取邊，並使用{{ui:Crease}}（1 保持銳利，0.5 略為變圓，0 為平滑）。參見[編輯網格](topic:mesh-edit)。
- **大型網格的視圖層級會降低：**當所要求的層級會產生超出此電腦視圖可順暢處理的面數時，視圖會顯示較低的層級，並說明為何。{{ui:Apply}}一律使用所有層級。可處理的面數取決於{{ui:Settings}} › 算圖 › 此電腦的等級。
- 開放邊界會保留其角點，並維持在其邊所在的線上。

## 以格架籠彎曲

1. 新增{{ui:Lattice}}修飾器，然後按{{ui:Add a lattice cage round the mesh}}。網格周圍會出現 3 × 3 × 3 個控制點的籠，以線框繪製。
2. 在網格工作區中開啟籠子（按兩下），並移動其控制點。網格會平滑地跟隨。

:::tip
籠子與其他網格並無不同：完成後可使用其標籤將其隱藏。
:::

## 大型網格

小型堆疊會立即計算。大型堆疊會在電腦的每個核心上於背景計算：在新結果完成之前，視圖會持續顯示上一次的結果。布林運算第一次使用時會載入實體建模程式；視圖會短暫顯示此訊息。

## 修飾器尚未提供的功能

- 置換、平滑與收縮包裹的每頂點權重（在網格上繪製的衰減）。
- 除縮放與直線陣列外，推拉幾何（群組與元件）上的其他修飾器：請先將其轉換為網格（{{ui:Convert to mesh}}）。群組上的鏡射、環形或曲線陣列、彎曲與錐化將於之後推出。
