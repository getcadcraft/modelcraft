若你曾在 SketchUp 中建模，ModelCraft 會讓你感覺熟悉：同樣的面與推拉概念、同樣的工具按鍵、無需點按即可輸入的數值框、以紅、綠、藍座標軸進行推論、群組、元件、大綱、實體資訊與場景。本頁列出可直接對應的項目，更重要的是，也列出不能直接對應的項目。

## 可延續的習慣

| 你已習慣的操作 | 在 ModelCraft 中 |
|---|---|
| 按 Space 選取，L 直線，R 矩形，C 圓 | 相同：{{key:Space}}、{{key:L}}、{{key:R}}、{{key:C}} |
| 按 P 推拉、M 移動、Q 旋轉、S 縮放、E 橡皮擦、T 捲尺 | 相同：{{key:P}}、{{key:M}}、{{key:Q}}、{{key:S}}、{{key:E}}、{{key:T}} |
| 按 O 環繞、H 平移、Z 縮放、Shift+Z 範圍縮放 | 相同：{{key:O}}、{{key:H}}、{{key:Z}}、{{key:Shift+Z}} |
| 按 G 建立元件 | 相同：{{key:G}}。{{key:Shift+G}}建立群組 |
| 不點按量測盒即可直接輸入 | 相同，在底部的數值框中輸入。按{{key:Enter}} |
| 輸入 `4m,3m` 繪製矩形，`12s` 設定邊長 | 相同 |
| 移動複製後輸入 `3x` 或 `/3` | 相同；`*3` 也可以 |
| 輸入 `[x,y,z]` 或 `<dx,dy,dz>` 指定點或偏移 | 相同 |
| 在英制英吋模型中直接輸入裸數字即得英吋 | 相同 |
| 中鍵拖曳環繞，Shift+中鍵拖曳平移，滾輪在游標處縮放 | 相同 |
| 用推拉工具連按兩下以重複距離 | 相同 |
| 方向鍵鎖定紅、綠、藍與平行 | 相同：{{key:Right}} 紅，{{key:Left}} 綠，{{key:Up}} 藍，{{key:Down}} 平行 |
| 按住 Shift 鎖定推論 | 相同 |
| 移動時按 Ctrl（Mac 上為 Option）複製 | {{key:Ctrl}}、{{key:Mod}} 或 {{key:Alt}}，任何電腦皆可 |
| Shift 切換，Ctrl 加入，Shift+Ctrl 從選取中移除 | 相同按鍵；在 Mac 上，凡寫 Ctrl 處請改用 {{key:Mod}} |
| 由左至右為視窗，由右至左為交叉 | 相同 |
| 標註工具標示長度 | {{key:D}}，且更多：在標註中輸入新長度，模型會調整至該長度。請參閱[標註與調整大小](topic:dimensions) |
| 連按兩下面以選取面與其邊；連按三下以選取所有相連的物件 | 相同 |
| 連按兩下群組以編輯；Esc 結束 | 相同 |
| 在面上畫線以分割它；刪除共面之間的邊以修補它們 | 相同 |
| 將視窗矩形推過牆以切割它 | 相同 |
| 背面以藍灰色顯示；反轉面 | 相同顏色；{{ui:反轉面}}位於{{ui:實體資訊}}中 |
| 場景是視埠上方的索引標籤，Page Up 與 Page Down | 相同，並在{{ui:場景}}面板中使用{{ui:播放}} |
| 依日期、時間、緯度與經度計算陰影，北向以綠色顯示 | 相同，位於{{ui:樣式}}面板中 |

## 容易讓人出錯的差異

### 儲存即下載

沒有會覆寫你所開啟檔案的「儲存」，沒有可輸入名稱的「另存新檔」對話框，也沒有自動儲存與備份檔案。{{ui:儲存}}（{{key:Mod+S}}）每次都會下載一個全新的 `.modelcraft` 檔案，通常儲存到你的下載資料夾。請經常儲存，並自行重新命名或移動檔案。請參閱[開啟、儲存、匯入與匯出](topic:files)。

### 可匯入 .skp 檔案，但無法儲存

{{ui:匯入}}會在頁面內以 ModelCraft 自有的讀取器讀取 SketchUp 檔案：群組、元件、顏色、面上的材質貼圖、標籤與柔化邊都會一併帶入。請參閱[檔案格式詳解](topic:formats#skp-files)。ModelCraft 無法儲存 `.skp`：若要轉回，請從 ModelCraft 匯出 Collada，然後在 SketchUp 中匯入。

### 沒有右鍵選單

右鍵拖曳可平移；按右鍵不會有任何反應。你在右鍵選單中會找到的指令，位於{{ui:實體資訊}}（{{ui:反轉面}}、{{ui:編輯}}、{{ui:分解}}、{{ui:獨立化}}、{{ui:建立元件}}）以及工具列的{{ui:整理}}群組中。

### 單位位於狀態列

沒有「模型資訊」或範本選擇。單位選擇器位於右下角。新模型會依瀏覽器的語言設定，在美國使用英呎與英吋，其他地區則使用公釐。小數一律使用句點：`2.5m`，絕不會是 `2,5m`，因為逗號一律用來分隔數值。

### 塗料有自己的材質

{{ui:上色}}（{{key:B}}）可塗上實心顏色，以及{{ui:材質}}區段中的材質：磚、壁板、屋面、木材、石材等，由 ModelCraft 繪製。目前尚無法將你自己的圖片載入為材質；隨匯入檔案而來的貼圖會保留下來。請參閱[用顏色與材質上色](topic:paint)。

### 縮放是等比例的，沒有夾點

縮放不會顯示帶有夾點的方盒。按一下保持不動的點（參考點），然後輸入新尺寸或倍率。它會在所有方向上等比例縮放。若要在單一方向拉伸，請使用推拉或移動面，或在{{ui:實體資訊}}中重新輸入群組的寬度、深度或高度，或[以標註調整大小](topic:dimensions)。

### 旋轉會依你點按的位置決定其平面

沒有會隨你以方向鍵在面上移動而黏附於面的量角器來挑選平面。在面上點按中心即可在該面的平面內轉動，或在地面上點按即可繞垂直軸轉動。在第一次點按之前，方向鍵會先環繞視角。

### 來自你經過的點的推論

ModelCraft 會從**你的起點**沿座標軸方向鎖點，並鎖定指標下方的點、邊與面。它不會追蹤你只是懸停經過的點所形成的方向（虛線的「從點」推論）。若要與遠處的角點對齊，請以方向鍵鎖定該軸，然後懸停在該角點上：被鎖定的點會滑動以與其對齊。或放置[輔助線](topic:guides-measure)。

### 平行使用你在開始前經過的邊

平行與垂直推論使用指標在**第一次點按之前**最後越過的邊，而不是你繪製時懸停經過的邊。請參閱[推論與鎖點](topic:inference#parallel-and-perpendicular)。

### 群組的複本彼此連結

以{{ui:移動}}複製群組會建立同一群組的第二個放置，因此編輯其中一個會同時改變兩者，如同元件一樣。SketchUp 的群組則是彼此獨立的。請參閱[疑難排解](topic:troubleshooting#editing-one-group-changed-another)。

### 空白鍵不會平移

{{key:Space}}會選擇{{ui:選取}}，與 SketchUp 相同。在某些其他網頁應用程式中，按住空白鍵會平移；這裡則不會。請改用右鍵拖曳平移。

### 雙指捲動會縮放

在觸控板上，請設定{{ui:設定}} › {{ui:ModelCraft}} › 捲動為觸控板：雙指環繞，{{key:Shift}}加雙指平移，捏合縮放。請參閱[環繞、平移與縮放](topic:orbit-pan-zoom#on-a-trackpad)。

若你習慣的是 Blender 的按鍵而非 SketchUp 的，請選擇{{ui:建模}}功能表樣式：{{key:G}}、{{key:R}}與{{key:S}}會同時作用於所選項目，{{key:E}}擠出（推拉），{{key:Shift+D}}複製，而頂部的功能表列（檔案、編輯、檢視、選取、新增、物件、網格）會取代工具列。若你來自 SketchUp，{{ui:推拉}}樣式會提供類似其自身的功能表列，且使用相同的工具按鍵。請參閱[功能表、按鍵與滑鼠](topic:menus-keys-and-mouse)。

### 相互推入的實體不會切割

推拉會穿過同一物件中其後的面進行切割，但兩個相互推入的獨立實體不會相交。沒有「相交面」或「實體工具」。

### 缺少的功能

徒手繪製、修剪、分割與外殼、自有圖片材質、外掛，以及用於圖紙的配置工具，都不在此版本中。[尚未實作的功能](topic:not-built-yet)列出了替代做法。

## 瀏覽器保留的快速鍵

ModelCraft 在瀏覽器中執行，因此部分快速鍵屬於瀏覽器，而非應用程式。{{key:Mod+N}}會開啟瀏覽器視窗（請改用{{ui:新增}}），{{key:Mod+W}}會關閉分頁。若有尚未儲存的變更，瀏覽器會在關閉前詢問。請參閱[按鍵、滑鼠與觸控板](common:keys#shortcuts-the-browser-keeps)。
