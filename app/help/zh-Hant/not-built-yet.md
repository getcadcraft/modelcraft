ModelCraft 是早期版本。本頁列出尚未支援的功能，讓你不必到處尋找，並提供目前最接近的完成方式。

## 繪圖工具

| 尚未支援 | 目前的替代做法 |
|---|---|
| 手繪 | 用{{ui:Curve}}點擊各點 |
| 繪製後變更圓弧或圓的分段數 | 刪除後，輸入`24s`再重新繪製 |
| 為 [3D 文字](topic:text3d) 選擇字型，或在放置後編輯其文字 | 刪除後重新新增文字 |
| 在角度標註中輸入數字以變更角度，或從圓的標註變更圓柱大小 | 以{{ui:Rotate}}旋轉邊線；以{{ui:Scale}}縮放圓柱 |
| 匯出的模型檔案中的標註 | 標註會顯示在視圖的圖片、列印與 PDF 中；模型檔案只包含幾何 |
| 修剪、分割與外殼 | 以[聯集、減去與交集](topic:solids)封閉群組，或[交集面](topic:intersect)後刪除不需要的部分 |
| 以方向鍵選擇旋轉軸 | 在朝向旋轉軸應指向的方向之面上，點擊{{ui:Rotate}}的中心 |
| 同時鎖定多個推斷 | 以方向鍵鎖定一個方向，然後對齊到一點 |
| 沿斜線調整大小，或從不在角落上的標註端點調整大小 | 將標註放在兩個角點上、沿邊線，或沿紅、綠、藍方向 |

## 動畫

| 尚未支援 | 目前的替代做法 |
|---|---|
| 為面、邊線、太陽的時間、樣式或隱藏內容製作動畫 | 將移動的部分做成群組或元件；若要另一個時間的日照，請另外算出一部影片 |
| 沿繪製路徑移動的攝影機，或追蹤移動物件的攝影機 | 沿途設定更多攝影機關鍵影格（[動畫](topic:animation)） |
| 影片中的聲音，以及沒有 WebGPU 時的高品質（路徑追蹤）影片 | 在影片編輯器中加入聲音；沒有 WebGPU 時，以快速算圖器算出影片（[算出影片](topic:animation#render-the-video)） |
| 算圖影片中的動畫燈光（亮度、擴散、顏色），在影片中未使用攝影機關鍵影格而動畫化的鏡頭角度，動畫化材質或算圖設定 | 燈光會在視圖中動畫化；若影片需要縮放效果，也請為攝影機設定關鍵影格；不同燈光設定請分別算出影片（[為任何屬性製作動畫](topic:animate)） |
| 在面之間從一側鏡射權重或骨骼到另一側，可見的骨骼包覆，逐點以著色顯示權重（目前以逐面顯示），在繪製權重時看到姿勢網格 | 兩側都繪製權重，或只做一半並在加入骨架前使用「鏡像」修飾器；切換「繪製權重」與「姿勢」來檢查 |
| 從 glTF、FBX 或 USD 檔案讀取為骨架的骨骼，以及寫入那些檔案的骨架 | 蒙皮模型會以靜止狀態匯入並使用檔案的權重；依檔案的關節順序加入骨骼，然後使用{{ui:Use the file's weights}}（[動畫](topic:animate)） |
| 以拖曳方式在視圖中移動 IK 目標或極點，選擇限制條件自身的空間（局部或世界），拉伸 IK 鏈，沿曲線的 IK | 輸入目標的點，或對準物件後移動該物件；讓鏈條保持其長度 |
| 布料、流體、軟體、剛體之間的關節與鉸鏈、以物件的精確形狀進行碰撞（僅以方塊與球體包圍）、播放時的即時模擬，以及起始速度或旋轉（物體以靜止開始） | 烘焙剛體並播放關鍵影格；以關鍵影格製作鉸鏈；把不規則形狀分割成方塊（群組） |
| 將動畫匯出為 glTF 或其他模型檔案 | 算出影片；ModelCraft 儲存的`.modelcraft`檔案與 [USD 檔案](topic:usd)僅供 ModelCraft 使用 |
| 在 VR 中於問題上輸入註解或標題、語音備忘、在 VR 中手動移動剖面平面 | 在 VR 中放置問題，然後在 BCF 程式中加入其文字；進入 VR 前在視圖中設定剖面平面：參閱[在 VR 頭戴裝置中檢視模型](topic:vr-review) |
| 在 VR 中看到桌邊的人（只顯示在 VR 中的人），錄製 VR 漫步 | 讓他們在 VR 中加入，或為漫步製作[動畫](topic:animation) |

## 網格

| 尚未支援 | 目前的替代做法 |
|---|---|
| 依層級雕刻（多解析度），以及 Detail 移除已變得極小的三角形 | 對已細分的網格進行[雕刻](topic:sculpt)；以{{ui:Remesh}}重新均勻化 |
| 重新網格化為沿形狀延伸的四邊形面 | {{ui:Remesh}}（均勻三角形），然後以[重新拓撲](topic:mesh-edit#retopology)重建 |
| 為 Displace、Smooth 與 Shrinkwrap 等修飾器在頂點上繪製權重（這些修飾器作用於整個網格） | 套用修飾器，然後對需要的部分進行雕刻或編輯 |
| 複製與貼上頂點、邊線或面，在面內結束的刀切，沒有面的線狀邊 | 在模型中複製網格；從邊線到邊線進行刀切；將開放邊線[擠出](topic:mesh-edit#change-the-shape)成面 |

## 整理與檢視

| 尚未支援 | 目前的替代做法 |
|---|---|
| 以 DWG 與 DXF 場地平面的圖層作為標籤 | 場地平面會以一個群組匯入：將其分解，然後把要標記的部分組成群組 |
| 同時進行多個剖面切割、剖面框，或將剖面輪廓匯出為圖形 | 每次只切割一個[剖面平面](topic:sections)；將視圖匯出為圖片 |
| 以虛線顯示軟邊，或在拖曳滑桿時軟化 | 在「實體資訊」中[依角度軟化](topic:soften)，並復原以嘗試其他角度 |
| 可搜尋的線上模型程式庫，或可選擇選項（顏色、樣式）的元件 | [入門程式庫](topic:starter)；匯入 Collada、OBJ 或 glTF 模型；將副本[拉伸](topic:stretch)至所需尺寸 |
| 從植物程式庫放置植物 | 在[即時視圖](topic:live-view#scatter-plants-rocks-and-people)中[散佈](topic:live-view#scatter-plants-rocks-and-people)植物，或放置入門程式庫中的樹 |
| 群組的獨立副本 | 將其做成元件，然後使用{{ui:Make unique}}（參閱[疑難排解](topic:troubleshooting#editing-one-group-changed-another)） |

## 算圖

| 尚未支援 | 目前的替代做法 |
|---|---|
| 在視圖中算圖（{{ui:Render}} 工作區）、算圖佇列，以及沒有 WebGPU 時的攝影機、天空圖片、霧與燈光混合選項 | 在{{ui:Render a picture…}}中選擇{{ui:High quality}}，即可使用那裡的 WebGL 路徑追蹤器，但沒有這些選項（[算出圖片](topic:render#high-quality)） |
| 其他程式在沒有算圖引擎附加元件時繪製算圖圖片（CadCraft 從不執行採 GNU GPL 授權的程式）；全景或立體攝影機，以及透過其他程式的天空圖片；Unreal Engine 外掛程式（檔案會寫出，但開啟它們的外掛程式尚未發布） | 我們自己的 Fast 與 Path tracer 引擎；附加元件的引擎（[以其他程式繪製圖片](topic:render-other-program)）；從引擎清單中選擇 USD、glTF 或 Unreal 資料夾檔案，帶到任何程式 |
| 在{{ui:Render a picture…}}中散佈的植物與岩石 | 它們會顯示在[即時視圖](topic:live-view)、其全景、檢視器與影片中 |

## 材質與色彩

| 尚未支援 | 目前的替代做法 |
|---|---|
| 高品質圖片中，除基本色、粗糙度、金屬度、不透明度、法線與發光之外的輸入，在曲面上的變化（使用其平均值） | [以節點製作材質](topic:shading)：仍可連結，視圖中會顯示其變化 |
| 推拉面上的置換 | 將物件轉換為網格以進行置換 |
| 從應用程式將你自己的材質分享到程式庫，以及匯入的貼圖組中的打包（ARM/ORM）或 EXR 貼圖 | 保留於檔案中；將個別貼圖匯入為 PNG 或 JPEG |
| 即時 TeamWork 工作階段中檔案的材質（它們會留在製作它們的電腦上） | 儲存檔案並分享 |
| 貼花彎曲於曲面周圍，貼花的復原，或跨接縫同時繪製多個面的貼圖 | 在每個部分放置較小的貼花；在接縫的每一側分別繪製 |
| 烘焙至推拉面、把多個物件烘焙為一張圖片、手動塑形的外框，或來自燈光的烘焙光照 | 轉換為網格後展開；分別烘焙每個物件；提高搜尋距離；以算圖算出燈光的圖片 |
| 繪製粗糙度、金屬度或高度，以圖片（印章）繪製，以及大於 512 × 512 的貼圖繪製 | 在此繪製基本色；以圖片編輯器製作其他貼圖，然後將其作為貼圖組匯入 |
| Collada、STL、PLY、3MF、IFC、DWG 與 DXF 匯出中的貼圖，以及已匯出模型中檔案本身材質的節點圖 | 這些格式會取得各材質的顏色；glTF 與 OBJ 會保留匯入的貼圖；可將單一材質匯出為 [MaterialX](topic:shading#materialx)；[USD](topic:usd) 會為 ModelCraft 保留整個模型 |
| Collada 檔案中的貼圖 | 匯入時會計數並略過；`.skp` 與 `.glb` 檔案中的貼圖會匯入 |

## 檔案

| 尚未支援 | 目前的替代做法 |
|---|---|
| 儲存 SketchUp 檔案，以及其中的文字與標註 | [匯入](topic:import-sketchup-files)會保留面、顏色與貼圖；匯出 Collada（`.dae`）即可回到 SketchUp |
| DWG 與 DXF 匯出中的標註與參考線 | 匯出後在 CAD 程式中加入 |
| DWG 與 DXF 中的點、表格與多重引線 | 會被計數並略過；文字會以單線字匯入，而非圖面的字型 |
| DWG 與 DXF 中的曲面、網格、表格與多重引線；位於掃掠、放樣或其他自由曲面上的 3D 實體的面 | 同樣會被計數並略過（3D 實體本身會匯入）。請從 CAD 程式將這些部分匯出為 OBJ 或 Collada，然後匯入 |
| IFC 類型、屬性或材質 | IFC 匯出包含[樓層](topic:formats#ifc-ifc)與一般元素；其餘請在 BIM 程式中加入 |
| 直接將模型傳送到 BimCraft | 匯出{{ui:IFC for BimCraft (.ifc)}}，然後在 BimCraft 中開啟 |
| glTF 與 STL 中的鬆散邊線 | 線稿請使用 OBJ 或 Collada |
| glTF 與 FBX 材質中，除基本色以外的部分（金屬、粗糙度、法線貼圖、玻璃、清漆、光澤……） | 會被讀取並列出；ModelCraft 保留基本色或貼圖。請在[著色工作區](topic:shading)中重建外觀 |
| glTF 骨骼、動畫與變形目標 | 蒙皮模型會以靜止姿態匯入；請在[時間軸](topic:animation)中製作動畫 |
| STEP 檔案中的顏色與組合件的零件名稱 | 零件會以其真實尺寸作為網格匯入；匯入後[上色](topic:paint)並命名 |
| `.3dm` 檔案中的 SubD 物件、文字、標註與燈光 | 參閱[略過的內容](topic:import-3dm-files#what-is-left-out-and-said)；在製作該檔案的程式中將 SubD 轉換為網格 |
| glTF 中的 KTX2 貼圖與材質變體 | 以 PNG 或 JPEG 貼圖匯出；使用預設變體 |
| 寫入 glTF 實例化（EXT_mesh_gpu_instancing） | 元件只寫入一次，並放置多次，所有檢視器都能讀取 |
| Alembic 動畫（快取的每個取樣）、Alembic 點與曲線，以及寫入 Alembic | 會匯入第一個取樣；請在[時間軸](topic:animation)中製作動畫；請改寫成 glTF、USD 或 OBJ |
| OBJ 材質中的凹凸與法線貼圖 | 只匯入彩色圖片（`map_Kd`） |
| FBX 骨骼與動畫、FBX 匯出、FBX 6 檔案 | 蒙皮模型會以靜止狀態匯入；匯出 glTF；將舊檔案儲存為 FBX 2011 或更新版本 |
| Collada 蒙皮、變形、攝影機、燈光、look-at 與斜切變換、外部參照 | 匯入時會略過，並在訊息中計數 |
| 備份檔案 | {{ui:Save as}}（{{key:Mod+Shift+S}}）會儲存另一份副本。當機後，ModelCraft 會提供尚未儲存的內容供你復原（「要復原尚未儲存的內容嗎？」） |
| 雲端儲存與電腦之間的同步 | 尚未提供。請將檔案儲存到電腦，再複製到需要的位置 |

## 3D列印

| 尚未支援 | 目前的替代做法 |
|---|---|
| 實際的切片器支撐（介面、底筏、確切的支撐圖樣） | [支撐預覽](topic:print-tools#supports-preview)會顯示位置與大約用量；切片器的預覽則會顯示實際支撐 |
| 解開自我穿越的零件，或三個以上面相交的邊線 | [修復](topic:print-tools#repair)會列出這些項目及其位置；使用[交集面](topic:intersect)並刪除內部的部分 |
| 中空內部的填充圖樣與格狀結構 | [挖空](topic:print-tools#hollow)會將其保留為空；切片器會為實心零件加入填充 |
| 小於噴嘴能列印的細節（牆除外） | [壁厚](topic:print-tools#wall-thickness)會找出薄壁；其餘部分請參閱切片器的層預覽 |

## 效能

復原會為每個步驟保留模型的一份副本（[網格](topic:meshes)只保留變更的部分），因此非常大的推拉幾何匯入會讓每次編輯變慢。請保持匯入精簡，並儲存後重新開啟以清除歷史紀錄。

## 應用程式與平台

- **桌面：**ModelCraft 可在 Mac、Windows 與 Linux 的瀏覽器中執行，也可在 CadCraft Studio（單一安裝即包含全部八個應用程式的桌面應用程式）中執行。在 Android 上，CadCraft Studio 可從 getcadcraft.com/download 的 APK 安裝。目前尚無 iPad 或 iPhone 版本。
- **觸控：**手指操作請參閱[環繞、平移與縮放](topic:orbit-pan-zoom)。筆的壓力在[雕刻](topic:sculpt)中設定筆刷；其他地方不使用壓力與筆的傾斜。
- **圖紙：**ModelCraft [每頁列印一個視圖](topic:export-model#print-the-view-or-save-it-as-a-pdf)；沒有包含多個視圖或標題欄的圖紙配置。若需要按比例的圖面，請匯出為適合 CadCraft 使用的 DWG/DXF。
