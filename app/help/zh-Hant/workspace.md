由上到下：應用程式列、工具列、三欄（左側面板、3D 檢視、右側面板）與狀態列。

## 應用程式列

最上方的細長列屬於每一個 CadCraft 應用程式。上面有應用程式名稱與版本、{{ui:關於ModelCraft}}、螢幕模式按鈕，以及{{ui:圖紙}} / {{ui:模型}}切換。

- {{ui:圖紙}}是淺色主題，{{ui:模型}}是深色主題。3D 檢視的顏色會隨之改變；你的模型不會改變。
- 螢幕模式按鈕（一開始顯示{{ui:全螢幕}}）與{{key:Ctrl+Shift+F}}會依序切換三種模式：一般、全螢幕，以及隱藏各列的全螢幕。隱藏各列時，指向螢幕上緣（或在該處輕點）即可叫回。按{{key:Esc}}可離開全螢幕。

:::note
{{key:Ctrl+Shift+F}}在每種電腦上都使用 Control 鍵，Mac 也一樣。在 iPhone 上，瀏覽器沒有全螢幕，所以該按鈕只會隱藏與顯示各列。
:::

## 工具列

工具列分成加上標示的群組。把指標停在按鈕上可看到它的名稱與按鍵。

在最左側，{{ui:工作區}}清單可切換工具列與右側面板的用途：{{ui:模型}}（推拉建模，下方導覽的內容）、{{ui:網格}}（[編輯網格](topic:mesh-edit)）、{{ui:曲線}}（[曲線物件](topic:curves)）、{{ui:UV}}（[排列 UV](topic:uv)）、{{ui:雕塑}}（[雕塑](topic:sculpt)）、{{ui:著色}}（[用節點製作材質](topic:shading)）、{{ui:動畫}}（[製作動畫](topic:animate)）與{{ui:算圖}}（[在檢視中算圖](topic:render#render-in-the-view)）。

| 群組 | 按鈕 |
|---|---|
| 檔案 | {{ui:新增}}、{{ui:開啟}}、{{ui:儲存}}、{{ui:匯入}}、{{ui:匯出}}（格式功能表） |
| 繪圖 | {{ui:直線}}（{{key:L}}）、{{ui:矩形}}（{{key:R}}）、{{ui:圓}}（{{key:C}}）、{{ui:多邊形}}（{{key:N}}） |
| 修改 | {{ui:選取}}（{{key:Space}}）、{{ui:推拉}}（{{key:P}}）、{{ui:移動}}（{{key:M}}）、{{ui:旋轉}}（{{key:Q}}）、{{ui:縮放}}（{{key:S}}）、{{ui:橡皮擦}}（{{key:E}}）、{{ui:卷尺}}（{{key:T}}） |
| 組織 | {{ui:元件}}（{{key:G}}）、{{ui:群組}}（{{key:Shift+G}}）、{{ui:分解}} |
| 編輯 | {{ui:復原}}（{{key:Mod+Z}}）、{{ui:取消復原}}（{{key:Mod+Y}}）、{{ui:複製}}（{{key:Mod+C}}）、{{ui:貼上}}（{{key:Mod+V}}）、{{ui:更多}}（功能表：剪下、複製、貼上、原位貼上{{key:Mod+Shift+V}}、建立副本{{key:Mod+D}}、刪除、全選、取消全選，以及按鍵風格） |
| 攝影機 | {{ui:環繞}}（{{key:O}}）、{{ui:平移}}（{{key:H}}）、{{ui:縮放}}（{{key:Z}}）、{{ui:範圍}}（{{key:Shift+Z}}）、{{ui:視圖}}（功能表） |

這裡顯示的是推拉樣式的按鍵；若在 [ModelCraft 設定](topic:settings)中選了建模樣式，提示文字會改顯示建模樣式的按鍵。正在使用的工具顯示為按下的狀態。在窄螢幕上，工具列可左右捲動。

{{ui:視圖}}功能表有{{ui:等角}}、{{ui:俯視}}、{{ui:前視}}、{{ui:右視}}、{{ui:後視}}、{{ui:左視}}與{{ui:仰視}}，每個都會符合模型範圍；另有{{ui:透視}}，可在透視與平行投影之間切換。

## 3D 檢視

畫面中間。紅、綠、藍三條線是座標軸：紅與綠位於地面上，藍色朝上，**北方是綠軸**。三者相交處是原點。

- 一開始會有一張標題為「開始建模」的卡片，列出最初幾個按鍵。選取繪圖工具或在檢視中按一下後就會消失。
- 工具運作時，檢視會顯示**推斷標記**：指標貼齊處的小型彩色形狀（端點是綠色圓形，中點是青色圓形，邊上是紅色方形，面上是藍色菱形）。見[推斷與鎖點](topic:inference)。
- 選取的物件會變成藍色。從背面看到的面是藍灰色。
- 開啟群組進行編輯時，群組以外的一切都會淡出，座標軸也會移到該群組自己的座標軸。
- 模型有場景時，檢視頂端會出現一排場景索引標籤。
- 把檔案拖放到檢視的任意位置即可開啟或匯入。

## 左側面板

**{{ui:大綱}}**列出模型中的群組與元件，巢狀關係與模型中一致。使用超過一次的元件會顯示次數，例如「Window (4)」。

- 按一下名稱可選取。按兩下可開啟進行編輯。
- **依名稱尋找**（有兩個或更多群組時才會顯示）只保留名稱相符的列，連同它們所在的群組。按{{key:Esc}}可清除。
- 列尾的**眼睛**會隱藏或顯示該群組或元件（與{{ui:編輯}} › {{ui:更多}} › {{ui:隱藏}}相同）。標籤圖示表示它被其[標籤](topic:tags)隱藏。
- **就地重新命名：**按一下某列，按{{key:F2}}，輸入，再按{{key:Enter}}（按{{key:Esc}}則保留舊名稱）。
- **拖曳某一列**到另一個群組那一列的中央，可移入該群組；拖到某列的上緣或下緣，可放到該列之前或之後；拖到{{ui:大綱}}標題上，可移到最上層。它在模型中的位置不變，並保留其顏色、標籤與名稱。群組不能放進自己內部。每次移動都是一個復原步驟。見[在大綱中重新排列](topic:groups-components#rearrange-in-the-outliner)。
- 在群組內部編輯時，會有一行寫著「正在編輯：模型 › …」，並出現{{ui:關閉群組}}按鈕，按下後會一次關閉所有開啟的層級。

**{{ui:元件}}**列出每個元件定義及已放置的副本數（「3×」），並有{{ui:放置}}按鈕，可在你按下的位置再加上一個副本。

## 右側面板

**{{ui:實體資訊}}**說明所選的物件。標題會隨之變化，指出那是什麼：

| 標題 | 顯示內容 | 按鈕 |
|---|---|---|
| 模型（未選取任何物件） | 面、邊、群組、元件及其放置數量、參考線、整體大小 | {{ui:刪除所有參考線}}（有參考線時） |
| 面 | 面積、孔的數量 | {{ui:反轉面}} |
| 邊 | 長度 | 無 |
| 群組或元件 | 名稱（輸入可重新命名）、放置次數、是否為封閉實體、體積、大小 | {{ui:編輯}}、{{ui:分解}}、{{ui:獨立化}}（放置超過一次的元件）、{{ui:建立元件}}（群組） |
| 參考點或參考線 | 無 | {{ui:刪除}} |
| 多個物件 | 面、邊、群組與參考線的數量，面的總面積 | {{ui:建立元件（G）}}、{{ui:建立群組（Shift+G）}} |

**{{ui:樣式}}**設定模型的繪製方式：{{ui:面}}（{{ui:著色}}、{{ui:隱藏線}}、{{ui:線框}}、{{ui:透視}}）、{{ui:顯示邊線}}，以及{{ui:日照陰影}}（含太陽的日期、時間與位置）。見[樣式與日照陰影](topic:styles-shadows)。

**{{ui:場景}}**用來儲存視圖：{{ui:新增場景}}、場景清單，以及{{ui:上一個}}、{{ui:播放}}與{{ui:下一個}}。見[把視圖儲存為場景](topic:scenes)。

## 狀態列

沿著底部，由左至右：

1. **提示：**工具接下來需要什麼，或指標貼齊到什麼（「端點」、「在紅軸上」）。
2. **訊息：**剛剛發生了什麼（「已復原推拉。」、「已匯入 site.dxf：地面上有 1697 條邊，位於一個群組中。」），或為什麼某件事沒有成功。
3. **數值方塊：**其標籤隨工具而變（{{ui:長度}}、{{ui:尺寸}}、{{ui:半徑}}、{{ui:邊數}}、{{ui:距離}}、{{ui:角度}}、{{ui:比例}}、{{ui:偏移}}）。作業時顯示即時大小，並接受你輸入的內容。見[在數值方塊中輸入精確尺寸](topic:value-box)。
4. **按鍵風格：**{{ui:按鍵：推拉}}或{{ui:按鍵：建模}}會同時切換鍵盤快速鍵與滑鼠按鈕（與 [ModelCraft 設定](topic:settings)中相同）。
5. **{{ui:貼齊}}與{{ui:碰撞}}：**貼齊到點、邊與座標軸，以及實體在接觸處停下。劃掉表示關閉。按一下可切換。見 [ModelCraft 設定](topic:settings)。
6. **單位選擇器：**長度顯示所用的單位。見[入門](topic:getting-started#check-the-units-first)。

## 在窄螢幕上

寬度低於約 760 像素時（手機或窄視窗），3D 檢視會佔據整個螢幕。工具列變成可左右捲動的單一列，面板則從螢幕底部的列以工作表形式開啟。
