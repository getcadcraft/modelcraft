The [時間軸](topic:animation)會移動攝影機以及整個群組和元件。**動畫**工作區能設定的範圍更廣，時間軸也多了兩個檢視，用來塑造並重複使用你設定的內容。

## 開啟

在工具列的工作區清單中選擇{{ui:動畫}}。時間軸會在視埠下方開啟，工具列會顯示動畫群組（{{ui:關鍵影格}}、{{ui:播放}}、{{ui:時間軸}}），右側面板則列出播放頭位置可設定的項目。

## 設定屬性的關鍵影格

面板會列出播放頭位置的以下項目：

- **所選物件**：其{{ui:放置}}、{{ui:旋轉（°）}}與{{ui:尺寸}}，各為三個數字。輸入數字後按{{key:Enter}}：它會在播放頭位置設定關鍵影格，物件也會移到該處。列旁的菱形會以目前數值設定關鍵影格；實心菱形表示播放頭位置已有關鍵影格。
- **燈**：每盞燈的{{ui:亮度（lm）}}、{{ui:擴散角（°）}}（聚光燈）與{{ui:顏色}}。
- **攝影機**：{{ui:鏡頭視角（°）}}，用於攝影機移動時的縮放。

{{ui:為變換設定關鍵影格}}（或{{key:I}}）會同時為每個所選群組或元件的位置、旋轉與尺寸設定關鍵影格；{{ui:關鍵視角}}（或{{key:K}}）則為攝影機設定關鍵影格。開啟{{ui:自動關鍵影格}}後，以此方式設定過位置、旋轉與尺寸關鍵影格的群組，每次移動時都會自動新增一個關鍵影格。

旋轉由三個角度組成，依序繞 X、Y、Z 軸。超過 180° 的旋轉會沿同一方向持續（190° 仍為 190°，不會變成 −170°），因此輪子可以轉動多圈。

:::tip
在時間軸上以{{ui:關鍵所選}}設定關鍵影格的群組，會得到整體位置的關鍵影格。該列上的曲線按鈕會將其轉為位置、旋轉與尺寸的曲線（每個關鍵影格的位置相同），方便你在{{ui:曲線}}中調整。
:::

## 形態鍵（變形）

**形態鍵**是同一個[網格](topic:meshes)的另一種形狀：例如臉上的微笑、門的凸起、彎曲的葉片。其滑桿會從網格原本的形狀（0）混合到該形狀（1）；多個形態鍵會疊加。

1. 在動畫工作區中選擇網格：面板會顯示其{{ui:形態鍵}}。
2. 按一下{{ui:新增形態鍵}}。ModelCraft 會切換到[網格工作區](topic:mesh-edit)並編輯新的形態鍵：移動點、拉伸、雕刻，將網格改成你想要的形狀。
3. 回到{{ui:動畫}}並按一下{{ui:完成}}。網格會恢復原狀，而形態鍵保留你的變更。

接著拖曳該形態鍵的滑桿（或輸入數值）以混合。菱形會在播放頭位置設定數值的關鍵影格，因此形態鍵可以隨時間逐漸出現與消失；一旦它有軌道，在播放頭位置輸入的新數值會被記錄為關鍵影格。鉛筆可再次編輯形態鍵的形狀（在{{ui:完成}}之前網格會完整顯示該形狀；按{{ui:取消}}則保留形態鍵原來的樣子）；眼睛可關閉形態鍵；垃圾桶會將其移除。

在編輯形態鍵時新增的頂點屬於網格本身：它會留在你放置的位置，並存在於每個形狀中。

:::note
形態鍵會先移動網格，再套用其[修改器](topic:modifiers)：細分修改器會讓混合後的形狀變得平滑。算出的圖片與影片會在每個影格顯示形態鍵。
:::

## 骨架：讓網格彎曲的骨骼

**骨架**是位於[網格](topic:meshes)內的一組骨骼。擺動骨骼時網格會跟著移動，每個點移動的幅度由其**權重**決定。

1. 在動畫工作區中選擇網格，並在面板中按一下{{ui:新增骨架}}（或在{{ui:骨架綁定}}群組中按{{ui:新增骨骼}}）：第一根骨骼會從網格底部沿其中央向上延伸。
2. 選取一根骨骼後，按{{ui:新增子骨骼}}會從其末端加入下一根。在面板中設定任一骨骼的{{ui:頭部}}、{{ui:末端}}、{{ui:翻轉（°）}}，以及它{{ui:附屬於}}哪一根；附屬於其他骨骼的骨骼會跟著它移動。若某骨骼只用來引導其他骨骼，請取消勾選{{ui:帶動網格}}。
3. 按一下{{ui:自動權重}}：每根骨骼會接管離它最近的點，而其影響會平滑地散布到網格上，因此兩根骨骼之間的點會共同承受。{{ui:僅最近的骨骼}}是較快速、界線較分明的分配方式。

**擺姿勢**：使用{{ui:擺姿勢}}（{{key:P}}）調整骨骼：按一下骨骼以選取，拖曳可繞視角軸旋轉，按住{{key:Shift}}拖曳則可移動。也可以在{{ui:擺姿勢}}下輸入其{{ui:放置}}、{{ui:旋轉（°）}}與{{ui:尺寸}}；旋轉以骨骼自身的軸為準，從其靜止狀態起算。菱形以及{{ui:為整個姿勢設定關鍵影格}}會在播放頭位置設定姿勢的關鍵影格；一旦骨骼有關鍵影格，擺動它時就會在該處自動設定關鍵影格。{{ui:重設此骨骼}}與{{ui:重設姿勢}}會讓骨骼回到靜止狀態。

**繪製權重**（{{key:W}}）用於所選骨骼：網格以靜止狀態顯示，每個面依骨骼影響的強度上色——紅色為全部，藍色為無。繪製可增加影響（按住{{key:Mod}}會減去，{{key:Shift}}則平滑）；{{ui:大小（px）}}與{{ui:強度}}設定筆刷。勾選{{ui:讓每個點的權重總和保持為 1}}後，提高某根骨骼的權重時，其他骨骼會相應減少。每次筆畫都是模型復原的一個步驟。

{{ui:皮膚}}決定介於骨骼之間的點如何移動：{{ui:線性（快速）}}會混合骨骼的移動，彎曲的關節會稍微收窄；{{ui:雙四元數（關節處保持體積）}}則改為繞關節旋轉該點，因此手肘或膝蓋能保持厚度（此時骨骼的尺寸不會拉伸皮膚）。

:::note
形態鍵先套用，接著是骨架，最後是[修改器](topic:modifiers)。視角、圖片與影片都會顯示擺好姿勢的網格；網格的權重隨網格一起儲存，骨骼及其姿勢則隨動畫儲存。
:::

## IK 與限制條件

**限制條件**會在關鍵影格之後依某項規則移動骨骼或物件。選取物件（若在骨架中則選取骨骼），然後在{{ui:限制條件…}}下新增限制條件；多個限制條件會依列出的順序執行（箭頭可以改變順序）。每個限制條件都有{{ui:影響程度}}（0 至 1，與其他屬性一樣可用菱形設定關鍵影格）以及開關。

| 限制條件 | 適用於 | 作用 |
|---|---|---|
| {{ui:伸展（IK）}} | 骨骼 | 該骨骼及其附屬的骨骼（{{ui:鏈中的骨骼}}）會彎曲，使其末端抵達目標。若有兩根骨骼與{{ui:極點（彎曲方向朝向它）}}，手肘或膝蓋會朝向極點；較長的鏈會平滑地彎曲。超出範圍時，鏈會直接朝向目標伸直。 |
| {{ui:注視}} | 兩者皆可 | 旋轉，使{{ui:指向的軸}}朝向目標，同時盡量讓{{ui:保持朝上的軸}}保持朝上。 |
| {{ui:複製變換}} | 兩者皆可 | 採用目標的位置、旋轉或尺寸（勾選的項目）。 |
| {{ui:限制}} | 兩者皆可 | 依各軸將自身的位置、旋轉（度數）或尺寸保持在{{ui:最小}}與{{ui:最大}}之間；留空某組則該軸不受限。 |
| {{ui:子項目}} | 兩者皆可 | 如同附屬於目標般跟隨移動，以選取目標時兩者的位置為基準。 |
| {{ui:沿路徑}} | 物件 | 在[曲線物件](topic:curves)上以{{ui:沿曲線}}定位（0 為起點，1 為終點；設定關鍵影格即可沿路徑移動），並勾選{{ui:沿曲線轉向}}使其朝向路徑方向。 |

目標可以是開啟群組中的另一個物件、同一骨架中的一根骨骼，或你輸入的{{ui:一個點}}（物件的點使用模型座標，骨骼的點使用其網格座標）。若是 IK 腿部，請將目標放在腳應在的位置並為目標設定關鍵影格，或為{{ui:影響程度}}設定關鍵影格，以在關鍵影格與 IK 之間交接腿部的控制。

:::tip
看向某個沿路徑移動之物件的另一個物件，會看到該物件位於路徑上：ModelCraft 會先計算所有目標，與物件的順序無關。
:::

## 物理：掉落、堆疊與碰撞

讓物件掉落並彼此碰撞，然後將結果保留為關鍵影格。

1. 選取一個群組、元件或網格，並在{{ui:物理}}下設定其{{ui:剛體}}：{{ui:掉落並碰撞}}（會移動）或{{ui:固定不動，阻擋其他物體}}（例如桌子、牆或坡道）。為會掉落的物件設定{{ui:形狀}}——{{ui:方塊（其邊界）}}或{{ui:球（依邊界取圓）}}——以及其{{ui:質量（kg）}}、{{ui:摩擦力}}與{{ui:彈跳}}（0 表示悶響，1 表示彈回原高度）。
2. 在{{ui:整個模型}}下設定{{ui:自（s）}}與{{ui:至（s）}}、{{ui:重力（m/s²，向下）}}，以及是否有{{ui:可著地的地面}}（並設定其高度）。
3. 按一下{{ui:烘焙物理}}（在面板中或{{ui:物理}}群組中）。每個會掉落的物件在兩個時間點之間的每一個影格都會獲得位置、旋轉與尺寸的關鍵影格；播放方式與一般動畫相同。

再次烘焙會取代那些關鍵影格；{{ui:移除已烘焙的關鍵影格}}則會將其移除。物件在{{ui:自（s）}}時從靜止開始，位置由其關鍵影格、曲線與限制條件決定（之前的關鍵移動不會延續到掉落中）。提高{{ui:每影格步數}}可讓高堆疊更穩定；狀態列會在結束時說明是否仍有物件在移動。

:::note
形狀為每個物件邊界上的方塊或球；方塊會以其角、邊中點與面中點接觸，因此方塊會如預期般堆疊與傾倒。布料、流體、物件之間的接頭以及精確形狀尚未實作。
:::

## 驅動器

**驅動器**會依其他事物來設定形態鍵，而非手動設定：開啟形態鍵的驅動器（計算機按鈕），撰寫一個**運算式**，並為其中的每個名稱指定其讀取的內容（{{ui:讀取}}）：以秒為單位的時間、影格、物件的位置、旋轉或尺寸（沿 X、Y 或 Z）、燈的亮度，或另一個形態鍵。例如，若 `v` 讀取門繞 Z 軸的旋轉，`clamp(v / 90, 0, 1)` 會隨門的開啟而開啟某個形狀。

運算式可使用數字、名稱、`+ - * / % ^` 與括號，以及函式 `sin cos tan asin acos atan atan2 abs sqrt exp log floor ceil round sign pow min max clamp lerp smoothstep rad deg`，並可使用 `pi` 與 `e`。錯誤會被指出，且不會有任何變更。受驅動的關鍵影格其滑桿會顯示驅動器的數值；在移除驅動器之前，驅動器會優先於關鍵影格的軌道。

## 選取與變更關鍵影格（關鍵影格檢視）

{{ui:關鍵影格}}為每條軌道顯示一列：攝影機、每個移動中的群組，以及每個屬性（「燈 2 · 亮度（lm）」；屬性的關鍵影格為圓形）。

- 按一下關鍵影格即可選取；按住{{key:Shift}}或{{key:Mod}}點按可在選取中加入或移除關鍵影格。在各列上按住{{key:Shift}}拖曳可畫出一個框，加入其中的所有關鍵影格。
- 拖曳所選關鍵影格可一起移動；{{key:Left}} / {{key:Right}}可移動一個影格（按住{{key:Shift}}為十個影格）。
- {{key:Mod+C}}複製所選關鍵影格，{{key:Mod+V}}會從播放頭位置將其貼到相同的軌道上（另一個 ModelCraft 索引標籤也可以貼上）。
- {{ui:拉伸}}會以播放頭為中心，依旁邊的數字將所選關鍵影格向外展開（2 表示間距加倍；0.5 會將其拉近）。
- 緩動清單設定每個所選關鍵影格如何移動。

## 塑造曲線（曲線檢視）

{{ui:曲線}}是每個數字隨時間變化的圖表：時間沿橫軸，數值沿縱軸。勾選左側清單中要顯示的曲線（X、Y、Z 分別為紅、綠、藍）。

- 按一下關鍵影格（一個方塊）以選取，按住{{key:Shift}}再點按可加選，或拖曳框選。拖曳所選的關鍵影格以變更其時間與數值；選取多個時，拖曳會沿時間方向一起移動。
- 被選取的關鍵影格會顯示其兩個**控制把手**。拖曳其中一個即可調整該側的曲線。{{ui:控制把手}}決定它們的行為：{{ui:自動}}（周圍的關鍵影格之間為平滑的曲線）、{{ui:指向下一個關鍵影格}}、{{ui:對齊}}（兩個把手保持在一直線上，因此曲線沒有角）或{{ui:自由}}。
- {{ui:來自所選關鍵影格}}設定每個所選關鍵影格如何移向下一個：{{ui:曲線（控制把手）}}、{{ui:平滑}}、{{ui:等速}}、{{ui:緩入緩出}}或{{ui:保持}}。
- {{ui:之前}}與{{ui:之後}}設定曲線在其關鍵影格之外的行為：{{ui:保持}}（停在第一個或最後一個數值）、{{ui:重複}}、{{ui:來回}}，或{{ui:重複並接續}}（每次重複都從上一次結束的地方開始：輪子會持續滾動，行走的人會持續前進）。
- 滾輪可縮放（按住{{key:Mod}}：僅縮放數值；按住{{key:Shift}}：僅縮放時間）；以中鍵拖曳或按住{{key:Alt}}拖曳可平移；{{ui:全部顯示}}或{{key:Home}}可讓所有顯示的曲線符合視窗。在空白處按一下即可將播放頭移到該處。{{key:Delete}}會刪除所選的關鍵影格。

控制把手會避免在時間上彼此交叉，因此曲線不會倒退。

## 重複使用動畫（片段檢視）

**片段**會在時間軸上播放已儲存的動畫（**動作**）。片段會依序混合，較下方的列會覆蓋在較上方的列之上；時間軸本身的軌道則位於所有片段之上。

1. 照常為群組與燈設定關鍵影格，然後在{{ui:片段}}中按一下{{ui:製作片段}}並為動作命名。這些軌道會成為該動作，而片段會在原本的位置播放它（攝影機仍留在時間軸上）。
2. 若要再次使用，請選取該動作並按一下{{ui:加入片段}}：新片段會從播放頭位置開始。
3. 沿其列拖曳片段即可移動；按一下片段可設定{{ui:開始（s）}}、{{ui:速度}}（2 表示兩倍速）、{{ui:重複次數}}、{{ui:影響程度}}（0 至 1）、{{ui:混合}}（{{ui:取代}}，或{{ui:疊加於上}}其前方的片段）、{{ui:片段之外}}（無、保持其結束狀態，或保持兩端），以及{{ui:靜音}}。箭頭可以改變順序；垃圾桶會將其移除（若沒有任何片段再使用某個動作，該動作也會一併移除）。

影響程度未達 100% 的片段，會與其下方的內容混合：即其前一個片段，或不含動畫時的燈或放置狀態。

## 各項在何處播放

| 內容 | 在檢視中 | 在算出的影片中 |
|---|---|---|
| 攝影機關鍵影格，以及搭配攝影機關鍵影格的鏡頭視角 | 是 | 是 |
| 位置、旋轉與尺寸（關鍵影格、曲線、片段） | 是 | 是 |
| 燈的亮度、擴散角與顏色 | 是 | 尚未支援：影片使用開始時燈的狀態（參見[尚未實作的功能](topic:not-built-yet)） |
| 沒有攝影機關鍵影格時的鏡頭視角 | 是 | 尚未支援：也請為攝影機設定關鍵影格 |
| 形態鍵與驅動器 | 是 | 是 |
| 骨架（擺好姿勢的網格） | 是 | 是 |
| IK 與限制條件 | 是 | 是 |
| 烘焙的物理（關鍵影格） | 是 | 是 |

所有內容都會與動畫的其他部分一起儲存在 `.modelcraft` 檔案中，時間軸的{{ui:復原}}與{{ui:取消復原}}可以還原其中任何變更。
