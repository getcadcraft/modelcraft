ModelCraft 在你的電腦上讀取與寫入檔案。不會上傳任何內容：你開啟的檔案在瀏覽器內讀取，儲存的檔案則是一次下載。見[檔案的去向](common:your-files)。

## 格式一覽

| 格式 | 開啟 | 匯入 | 匯出 | 用途 |
|---|---|---|---|---|
| ModelCraft（`.modelcraft`） | 可 | 否 | {{ui:儲存}} | 你的工作檔案，保留一切內容。 |
| USD（`.usd`、`.usda`、`.usdc`、`.usdz`） | 可 | 可 | {{ui:另存新檔}}、{{ui:匯出}} | 算圖與場景組合程式。ModelCraft 自己的 USD 保留一切內容。見[儲存、開啟與匯出 USD](topic:usd)。 |
| SketchUp（`.skp`） | 否 | 可 | 否 | 帶入 SketchUp 的模型。保留群組、元件、顏色、面上的貼圖、標籤與軟化邊。見[帶入 SKP 模型](topic:import-sketchup-files)。 |
| Collada（`.dae`） | 否 | 可 | 可 | 與其他 3D 建模軟體交換模型。保留群組、元件與顏色。 |
| OBJ（`.obj`） | 否 | 可 | 可 | 算圖與視覺化程式。 |
| glTF（`.glb`、`.gltf`） | 否 | 可 | 僅 `.glb` | 網頁檢視器、遊戲引擎、AR。 |
| STL（`.stl`） | 否 | 可 | 可 | 3D 列印（以公釐計）。 |
| PLY（`.ply`） | 否 | 可 | 可 | 帶顏色的網格：掃描、彩色列印。 |
| FBX（`.fbx`） | 否 | 可 | 否 | 來自動畫與遊戲程式的模型（FBX 2011 及更新版本）。 |
| Alembic（`.abc`） | 否 | 可 | 否 | 幾何快取，取其第一個取樣。 |
| STEP（`.step`、`.stp`） | 否 | 可 | 否 | 來自零件建模軟體與供應商的零件，以真實大小的封閉網格匯入。見[檔案格式](topic:formats)。 |
| `.3dm` | 否 | 可 | 否 | NURBS 模型：多重曲面、網格、曲線、區塊與圖層，匯入為網格、邊、元件與標籤。見[帶入 .3dm 模型](topic:import-3dm-files)。 |
| 3MF（`.3mf`） | 否 | 否 | 可 | 帶顏色的 3D 列印（以公釐計）。來自{{ui:檢查 3D 列印（STL 或 3MF）…}}：見[準備好模型以供 3D 列印](topic:print-3d)。 |
| IFC（`.ifc`） | 否 | 否 | 可 | BIM 程式，以及 BimCraft。 |
| DWG（`.dwg`） | 否 | 可 | 可 | 作為建模底圖的基地平面圖或樓層平面圖；把模型送到 CAD 程式。 |
| DXF（`.dxf`） | 否 | 可 | 可 | 同上，適用於任何 CAD 程式。 |

[檔案格式詳解](topic:formats)列出每種格式究竟保留與捨棄哪些內容。

## ModelCraft 檔案

`.modelcraft` 檔案保留整個模型：幾何、群組、元件、參考線、場景、單位，以及儲存時所用的攝影機與樣式。不保留復原歷程。

### 開啟模型

1. 在{{ui:檔案}}群組中按{{ui:開啟}}，或按{{key:Mod+O}}。
2. 若畫面上的模型有尚未儲存的變更，ModelCraft 會詢問：「此模型有未儲存的變更。要先儲存副本嗎？」請選擇{{ui:儲存副本}}、{{ui:捨棄變更}}或{{ui:取消}}。
3. 選取該 `.modelcraft` 檔案。

模型會以儲存時的單位與攝影機開啟。也可以把 `.modelcraft` 檔案拖放到 3D 檢視上，或在起始卡片的最近檔案清單中按一下（適用於能重新開啟檔案的瀏覽器，以及桌面應用程式）。

:::desktop
在桌面應用程式中，按兩下 `.modelcraft` 檔案就會在 ModelCraft 中開啟；對 Collada、OBJ、glTF、DWG 或 DXF 檔案使用**開啟方式**也一樣（會匯入到新模型中）。
:::

### 儲存模型

按{{ui:儲存}}或按{{key:Mod+S}}。瀏覽器會下載 `<name>.modelcraft`，其中名稱是你開啟的檔案名稱；新模型則為「Untitled」。

:::desktop
在桌面應用程式中，{{ui:儲存}}會直接寫入你開啟的檔案。新模型會詢問儲存位置。
:::

- {{ui:另存新檔}}（{{key:Mod+Shift+S}}）會把副本存成 `.modelcraft` 檔案或 [USD](topic:usd)；瀏覽器若支援，會詢問名稱與位置。否則請為下載的檔案重新命名：開啟已重新命名的檔案後，下一次儲存就會使用新名稱。
- 每次儲存都是一次新的下載。依瀏覽器的設定，檔案會直接進入下載資料夾，或詢問儲存位置。若該處已有同名檔案，多數瀏覽器會加上編號，例如 `Untitled (1).modelcraft`。

:::chromium
若要每次都選擇資料夾，請開啟瀏覽器的設定，搜尋「下載」，並開啟「下載前先詢問儲存位置」。
:::

:::firefox
若要每次都選擇資料夾，請開啟**設定**，再開啟**一般**，並在「下載」下選擇「總是詢問儲存檔案的位置」。
:::

:::safari
若要變更下載的存放位置，請開啟 **Safari**，再開啟**設定**，再開啟**一般**，並設定「檔案下載位置」。
:::

### 開始新模型

按{{ui:新增}}。若有尚未儲存的變更，ModelCraft 會先詢問。新模型從空白開始，採用你所在地區的單位（美國為英尺與英吋，其他地區為公釐），沒有場景。

### 儲存之前瀏覽器就關閉了

每次變更後幾秒，ModelCraft 會在瀏覽器中保留一份尚未儲存內容的副本。若在儲存前索引標籤或瀏覽器就關閉，下次開啟 ModelCraft 時會詢問「要復原尚未儲存的內容嗎？」。復原會把模型開啟成原來的樣子，但尚未儲存成檔案：請儲存以保留。見[復原尚未儲存的內容](common:recover)。

### 從 CadCraft：在 ModelCraft 中開啟

在 CadCraft 繪圖應用程式中，依序選擇**檢視**、**更多**、**在 ModelCraft 中開啟**，會把開啟中的圖形以 DWG 形式在新的索引標籤交給 ModelCraft。它的呈現方式與匯入 DWG 相同：直線位於地面，放在一個群組中，可直接在上面建模。不會上傳任何內容；檔案經由瀏覽器自己的儲存空間傳遞。

## 匯入

匯入會把檔案加入你開啟中的模型，不會取代它。

1. 在{{ui:檔案}}群組中按{{ui:匯入}}，或把檔案拖放到 3D 檢視上。
2. 選取 SketchUp、Collada、OBJ、glTF、FBX、PLY、STL、Alembic、STEP、`.3dm`、USD、DWG 或 DXF 檔案。

   檔案會以**一個群組**的形式進來並呈選取狀態，檢視會縮放以顯示它。狀態列會說明匯入了什麼，並列出無法匯入的項目，例如「未匯入：2 texture」。

3. 若要直接處理其幾何，請在群組上按兩下以進入編輯，或按{{ui:分解}}。

幾件須知的事：

- **大小與向上方向：**Collada 檔案會註明其單位與哪個軸朝上，ModelCraft 會自動換算。glTF 一律使用公尺。OBJ 檔案不帶單位：ModelCraft 以公尺、Y 軸朝上讀取。若 OBJ 進來時大了或小了 1000 倍，請用[縮放](topic:rotate-scale)，並輸入 `0.001` 或 `1000` 之類的倍數。
- **DWG 與 DXF** 以地面上的線（邊）匯入，而不是面。若圖形沒有註明單位，會出現標題為「圖形單位」的對話方塊，詢問一個圖形單位是多少。見[在基地平面圖上建模](topic:site-plan)。
- **限制：**超過 300 MB 的檔案拒絕匯入，超過 200 MB 的檔案拒絕開啟。頂點或面超過 200 萬個的檔案會因過大而被拒絕。

## 匯出

1. 在{{ui:檔案}}群組中按{{ui:匯出}}。
2. 選擇格式：{{ui:glTF 二進位（.glb）}}、{{ui:Collada（.dae）}}、{{ui:OBJ（.obj）}}、{{ui:供列印用的 STL（.stl，毫米）}}、{{ui:含色彩的 PLY（.ply）}}、{{ui:USD（.usda、.usdc、.usdz）…}}、{{ui:供 BimCraft 使用的 IFC（.ifc）}}、{{ui:供 CAD 使用的 DWG（.dwg，2004）}}或{{ui:供 CAD 使用的 DXF（.dxf，R12）}}。

瀏覽器會下載檔案，檔名同模型。匯出的是整個模型，而不只是選取的部分。空的模型不會匯出：「模型是空的：請先繪製一些內容。」見[匯出模型給其他程式](topic:export-model)。

## 線上與離線

ModelCraft 的一切都在你的電腦上執行，因此應用程式載入後，建模、開啟、儲存、匯入與匯出都不需要網路連線。

若要在完全沒有網路連線時開啟 ModelCraft，請在線上時先儲存供離線使用：

1. 按頂端應用程式列的{{ui:儲存供離線使用}}。
2. 儲存期間，按鈕會持續計數（「儲存中40/212」）。ModelCraft 會儲存自己的檔案（包括 DWG 讀取器）、這份說明與 3D 程式庫，所以可能需要一些時間。
3. 當按鈕顯示{{ui:可離線使用}}時，ModelCraft 就能在同一個網址、沒有網路連線時開啟，DWG 匯入也能離線運作。

之後按{{ui:可離線使用}}可選擇{{ui:重新儲存（取得最新版本）}}或{{ui:移除離線副本}}。若按鈕顯示{{ui:無法儲存}}，表示有些檔案沒有下載成功：請檢查網路連線並再按一次重試。{{ui:無法離線使用}}表示這個瀏覽器視窗無法保留副本（私密視窗與部分受管理的電腦）。見[離線工作](common:offline)。

目前尚無雲端儲存。每個模型都存放在你儲存的位置。

:::offline
目前離線。你可以繼續建模與儲存。除非應用程式列顯示{{ui:可離線使用}}，否則在重新連上網路之前，請不要重新載入這個索引標籤。
:::
