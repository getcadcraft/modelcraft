ModelCraft 讀寫電腦上的檔案。不會上傳任何內容：開啟的檔案會在瀏覽器內讀取，儲存的檔案則是一次下載。請參閱[檔案存放位置](common:your-files)。

## 格式一覽

| 格式 | 開啟 | 匯入 | 匯出 | 用途 |
|---|---|---|---|---|
| ModelCraft (`.modelcraft`) | 是 | 否 | {{ui:儲存}} | 工作檔，保留所有內容。 |
| USD (`.usd`, `.usda`, `.usdc`, `.usdz`) | 是 | 是 | {{ui:另存為}}、{{ui:匯出}} | 渲染與場景組合程式使用。ModelCraft 自己的 USD 會保留所有內容。請參閱[儲存、開啟與匯出 USD](topic:usd)。 |
| SketchUp (`.skp`) | 否 | 是 | 否 | 匯入 SketchUp 的模型。保留群組、元件、色彩、面上的貼圖、標籤與柔化邊。請參閱[匯入 SKP 模型](topic:import-sketchup-files)。 |
| Collada (`.dae`) | 否 | 是 | 是 | 與其他 3D 建模程式交換模型。保留群組、元件與色彩。 |
| OBJ (`.obj`) | 否 | 是 | 是 | 渲染與視覺化程式。 |
| glTF (`.glb`, `.gltf`) | 否 | 是 | 僅 `.glb` | 網頁檢視器、遊戲引擎、AR。 |
| STL (`.stl`) | 否 | 是 | 是 | 3D 列印（以 mm 為單位）。 |
| PLY (`.ply`) | 否 | 是 | 是 | 帶色彩的網格：掃描、彩色列印。 |
| FBX (`.fbx`) | 否 | 是 | 否 | 動畫與遊戲程式的模型（FBX 2011 及更新版本）。 |
| Alembic (`.abc`) | 否 | 是 | 否 | 幾何快取，取第一個取樣。 |
| STEP (`.step`, `.stp`) | 否 | 是 | 否 | 零件建模程式與供應商提供的零件，以實際尺寸的封閉網格匯入。請參閱[檔案格式](topic:formats)。 |
| `.3dm` | 否 | 是 | 否 | NURBS 模型：多重曲面、網格、曲線、區塊與圖層，會以網格、邊、元件與標籤匯入。請參閱[匯入 .3dm 模型](topic:import-3dm-files)。 |
| 3MF (`.3mf`) | 否 | 否 | 是 | 3D 列印，含色彩（以 mm 為單位）。由{{ui:檢查 3D 列印（STL 或 3MF）…}}產生：請參閱[準備 3D 列印模型](topic:print-3d)。 |
| IFC (`.ifc`) | 否 | 否 | 是 | BIM 程式與 BimCraft。 |
| DWG (`.dwg`) | 否 | 是 | 是 | 可在上面建模的基地圖或平面圖；將模型送到 CAD 程式。 |
| DXF (`.dxf`) | 否 | 是 | 是 | 同上，適用於任何 CAD 程式。 |

[詳細檔案格式](topic:formats)列出每種格式保留與不保留的內容。

## ModelCraft 檔案

`.modelcraft` 檔案會保留整個模型：幾何、群組、元件、輔助線、場景、單位，以及儲存時使用的相機與樣式。它不會保留復原紀錄。

### 開啟模型

1. 按一下{{ui:檔案}}群組中的{{ui:開啟}}，或按{{key:Mod+O}}。
2. 若畫面上的模型有尚未儲存的變更，ModelCraft 會詢問：「此模型有尚未儲存的變更。要先儲存副本嗎？」選擇{{ui:儲存副本}}、{{ui:捨棄變更}}或{{ui:取消}}。
3. 選取 `.modelcraft` 檔案。

模型會以儲存時的單位開啟，並使用儲存時的相機。也可以將 `.modelcraft` 檔案拖放到 3D 檢視區，或在開始卡片的最近檔案清單中按一下（可重新開啟檔案的瀏覽器，以及桌面應用程式）。

:::desktop
在桌面應用程式中，連按兩下 `.modelcraft` 檔案會在 ModelCraft 中開啟；在 Collada、OBJ、glTF、DWG 或 DXF 檔案上使用**開啟方式**也會如此（檔案會匯入新模型）。
:::

### 儲存模型

按一下{{ui:儲存}}或按{{key:Mod+S}}。瀏覽器會下載 `<name>.modelcraft`，其中名稱為開啟的檔案名稱；新模型則為 "Untitled"。

:::desktop
在桌面應用程式中，{{ui:儲存}}會直接寫入開啟的檔案。新模型會詢問儲存位置。
:::

- {{ui:另存為}}（{{key:Mod+Shift+S}}）會將副本儲存為 `.modelcraft` 檔案或 [USD](topic:usd)；若瀏覽器支援，會詢問名稱與位置。否則請重新命名下載的檔案：在開啟更名後的檔案後，下一次儲存會使用新名稱。
- 每次儲存都會是新的下載。視瀏覽器設定，檔案會直接存到下載資料夾，或詢問儲存位置。若該名稱的檔案已存在，多數瀏覽器會加上編號，例如 `Untitled (1).modelcraft`。

:::chromium
若要每次都選擇資料夾，請開啟瀏覽器設定，搜尋「下載」，然後開啟「下載前詢問每個檔案的儲存位置」。
:::

:::firefox
若要每次都選擇資料夾，請開啟**設定**，再到**一般**，在「下載」下選擇「每次都詢問要將檔案儲存至何處」。
:::

:::safari
若要變更下載位置，請開啟**Safari**，然後是**設定**，然後是**一般**，設定「檔案下載位置」。
:::

### 新增模型

按一下{{ui:新增}}。若有尚未儲存的變更，ModelCraft 會先詢問。新模型會以所在地區的單位開始（美國為 ft 與 in，其他地區為 mm），且沒有場景。

### 儲存前瀏覽器關閉時

ModelCraft 會在每次變更後幾秒，將尚未儲存的工作保留一份複本於瀏覽器中。此複本在背景寫入，因此大型模型不會因此拖慢操作。若在儲存前分頁或瀏覽器關閉，下次開啟 ModelCraft 時會詢問「要復原尚未儲存的內容嗎？」。復原會以關閉前的狀態開啟模型，但尚未存成檔案：請儲存以保留。請參閱[復原尚未儲存的內容](common:recover)。

### 從 CadCraft：在 ModelCraft 中開啟

在 CadCraft 繪圖應用程式中，依序選擇**檢視**、**{{ui:更多}}**、**在 ModelCraft 中開啟**，即可在新分頁中將開啟的圖形交給 ModelCraft，以 DWG 形式傳送。它的進入方式與匯入的 DWG 相同：線條位於地面上、位於群組中，可直接在上面建模。不會上傳任何內容；檔案會經過瀏覽器自身的儲存空間。

## 匯入

匯入會將檔案加入目前開啟的模型，而不會取代它。

1. 按一下{{ui:檔案}}群組中的{{ui:匯入}}，或將檔案拖放到 3D 檢視區。
2. 選取 SketchUp、Collada、OBJ、glTF、FBX、PLY、STL、Alembic、STEP、`.3dm`、USD、DWG 或 DXF 檔案。

   檔案會以**一個群組**進入，並處於選取狀態，檢視區會縮放以顯示該群組。狀態列會說明匯入了什麼，並列出無法匯入的項目，例如「未匯入：2 個貼圖」。

3. 若要直接編輯其幾何，請連按兩下群組以進入編輯，或按一下{{ui:分解}}。

注意事項：

- **大小與朝上方向：**Collada 檔案會說明其單位及哪一軸朝上，ModelCraft 會進行轉換。glTF 一律以 m 為單位。OBJ 檔案不含單位：ModelCraft 會以 m 讀取，且 Y 軸朝上。若 OBJ 匯入後大了或小了 1000 倍，請使用[縮放](topic:rotate-scale)，比例係數如 `0.001` 或 `1000`。
- **DWG 與 DXF** 會以地面上的線（邊）匯入，而非面。若圖形未說明單位，會出現標題為「圖形單位」的對話方塊，詢問一個圖形單位代表多少。請參閱[在基地圖上建模](topic:site-plan)。
- **限制：**超過 300 MB 的檔案無法匯入，超過 200 MB 的檔案無法開啟。頂點或面超過 200 萬的檔案會因過大而被拒絕。超過 64 MB 的 OBJ 會在讀取前被拒絕。文字檔（Collada、OBJ、ASCII STL、USD 文字）會分段讀取，每段約 4 MB，因此沒有任何單一文字區塊會容納整個檔案；在我們的測試中，一個 16 MB 的 OBJ 在開啟時使用了約 0.5 GB 記憶體。

## 匯出

1. 按一下{{ui:檔案}}群組中的{{ui:匯出}}。
2. 選擇格式：{{ui:glTF 二進位（.glb）}}、{{ui:Collada（.dae）}}、{{ui:OBJ（.obj）}}、{{ui:供列印用的 STL（.stl，毫米）}}、{{ui:含色彩的 PLY（.ply）}}、{{ui:USD（.usda、.usdc、.usdz）…}}、{{ui:供 BimCraft 使用的 IFC（.ifc）}}、{{ui:供 CAD 使用的 DWG（.dwg，2004）}}或{{ui:供 CAD 使用的 DXF（.dxf，R12）}}。

瀏覽器會下載檔案，檔名與模型相同。匯出的是整個模型，而非僅選取的部分。glTF、Collada 與 OBJ 檔案會在背景寫入，因此大型模型匯出時 ModelCraft 仍可繼續運作；檔案準備好後才會開始下載。空模型不會匯出：「模型是空的：請先畫些內容。」請參閱[將模型匯出至其他程式](topic:export-model)。

## 線上與離線

ModelCraft 的所有功能都在電腦上執行，因此應用程式載入後，建模、開啟、儲存、匯入與匯出都能在無連線的情況下運作。

若要在完全沒有連線的情況下開啟 ModelCraft，請在連線時將它儲存供離線使用：

1. 按一下應用程式列頂端的{{ui:儲存供離線使用}}。
2. 儲存時，按鈕會顯示進度（「儲存中 40／212」）。ModelCraft 會儲存自己的檔案（包括 DWG 讀取器）、本說明與 3D 程式庫，因此可能需要一段時間。
3. 當按鈕顯示{{ui:可離線使用}}時，ModelCraft 即可在無連線的情況下從同一位址開啟，DWG 匯入也可離線使用。

稍後按一下{{ui:可離線使用}}，可選擇{{ui:重新儲存（取得最新版本）}}或{{ui:移除離線副本}}。若按鈕顯示{{ui:無法儲存}}，表示有部分檔案未下載：請檢查連線，然後再按一下即可重試。{{ui:無法離線使用}}表示此瀏覽器視窗無法保留副本（私密視窗與部分受管理的電腦）。請參閱[離線工作](common:offline)。

雲端儲存尚未提供。每個模型都保存在儲存的位置。

:::offline
目前處於離線狀態。可以繼續建模與儲存。除非應用程式列顯示{{ui:可離線使用}}，否則請在恢復連線前不要重新載入此分頁。
:::

## 桌面應用程式

:::desktop
正在 CadCraft Studio 中使用 ModelCraft。CadCraft Studio 是包含全部八個應用程式的桌面應用程式。檔案會在選擇的位置開啟與儲存。
:::

:::web
ModelCraft 可在 Mac、Windows 與 Linux 的瀏覽器中執行，也可在 CadCraft Studio 中執行。CadCraft Studio 是以單一安裝包含全部八個應用程式的桌面應用程式，可從 getcadcraft.com/download 取得。
:::
