繪圖或編輯工具運作時，ModelCraft 會檢查游標下方的內容，並貼齊附近最有用的對象。標記會顯示找到的對象，左下角的提示則會標示其名稱。

## 標記與提示

| 提示 | 標記 | 貼齊對象 |
|---|---|---|
| 端點 | 綠色圓圈 | 邊的端點 |
| 中點 | 青色圓圈 | 邊的中間 |
| 面的中心 | 藍色圓圈 | 游標下方面的中央 |
| 輔助點 | 灰色 | 卷尺留下的輔助點 |
| 原點 | 赭色 | 紅、綠、藍軸的交會處 |
| 在紅軸上 / 在綠軸上 / 在藍軸上 | 該顏色的線 | 從起點沿該方向延伸的線 |
| 與邊平行 / 與邊垂直 | 洋紅色線 | 從起點出發，與所記憶的邊平行或垂直的線（見下文） |
| 已鎖定 | 洋紅色線 | 以方向鍵或 Shift 鎖定的方向 |
| 在邊上 | 紅色方塊 | 沿邊的任何位置 |
| 在輔助線上 | 灰色 | 沿輔助線的任何位置 |
| 在面上 | 藍色菱形 | 面上的任何位置 |
| 在平面上 | 無 | 游標位於空白處時，起始所在的平面 |
| 在地面上 | 無 | 地面（紅綠平面），當其他位置皆無物件時 |

當從起點出發的軸線與邊或輔助線相交時，ModelCraft 會貼齊交點，提示會同時標示兩者，例如「在紅軸上，在邊上」。

## 貼齊的優先順序

1. **約 12 像素內的點**：先為端點，其次為輔助點、中點、游標下方面的中心與原點。
2. **從起點出發的方向**：紅、綠、藍軸，以及與所記憶的邊平行或垂直的方向。
3. **在邊上**或**在輔助線上**。
4. **在面上。**
5. **繪圖平面**，或地面。

被面遮住的物件永遠不會被貼齊。請環繞視圖，以便看到所需的點。

## 從一點在面上繪製

從角點、中點、邊或面的中心開始繪製的{{ui:矩形}}、{{ui:圓}}或{{ui:多邊形}}，會以**游標下方面所在的平面**繪製，並切割該面。一條邊屬於兩個面，因此游標位於邊的哪一側即決定所屬的面：若要在長方盒的端面上繪製，請從其中一條邊的中點開始，並將游標置於端面內側。

## 平行與垂直

ModelCraft 會記住**第一次點擊前，游標最後經過的邊**。從角點或邊開始也算是經過該邊。工具開始運作後，之後游標經過的其他邊不會取代它。

若要繪製與既有邊平行的直線：

1. 按 {{key:L}}，並將游標移到要對齊的邊上。
2. 移到起點，若可能，途中避免經過其他邊，然後點擊。
3. 沿與該邊平行的方向移動。直線會變為洋紅色，提示會顯示「與邊平行」。垂直的做法相同，但需在所繪製的平面內進行。

若記住的是錯誤的邊，按 {{key:Esc}}，將游標移到正確的邊上，再重新開始。

## 鎖定方向

工具的第一次點擊後，可將下一點保持在同一直線上：

| 按鍵 | 鎖定至 |
|---|---|
| {{key:Right}} | 紅軸 |
| {{key:Left}} | 綠軸 |
| {{key:Up}} | 藍軸（垂直向上） |
| {{key:Down}} | 與所記憶的邊平行（見上文） |

再按相同的方向鍵即可解除鎖定。狀態列會顯示「已鎖定至紅軸。再按相同方向鍵即可解除鎖定。」

鎖定時，點會沿著該直線滑向游標所在的位置，並且仍會與游標經過的點對齊：將游標移到另一個盒子的角點上，即可沿紅軸繪製直線，且長度恰好到該角點。

**{{key:Shift}}** 會鎖定目前貼齊的任何方向（軸向或平行方向），按住期間持續有效。放開即解除鎖定。

鎖定可用於{{ui:直線}}、{{ui:矩形}}、{{ui:圓}}、{{ui:多邊形}}、{{ui:移動}}、{{ui:縮放}}與{{ui:卷尺}}。第一次點擊前，方向鍵會改為環繞視圖。

## 在群組內

在群組或元件內編輯時，座標軸會是該群組自己的座標軸（它們會隨群組移動，若群組旋轉，也會跟著旋轉）。貼齊仍會找到群組外部的點與邊，因此可以與模型的其他部分對齊。
