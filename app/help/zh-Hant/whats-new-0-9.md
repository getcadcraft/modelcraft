以下是 ModelCraft 0.9 相較於 0.8.1 的變更。ModelCraft 現已能連接印表機與工廠現場：可將物件放上列印平台直接傳送而無需匯出，可切片成絲材或樹脂，也可規劃物料搬運產線。這是 CadCraft Studio 0.9 及其八個應用程式；以下大部分新功能為外掛。

## 新增

### 3D 列印

- **列印階段。** 在工具列中按 {{ui:列印階段}}。將程式庫項目加入印表機的列印平台、排列它們、檢視切片後的各層，然後按 {{ui:傳送至 3D 印表機}}，無需匯出 STL。它屬於 3D 列印外掛，預設為開啟，且可像其他外掛一樣移除。請見 [將物件放到列印平台並傳送至印表機](topic:print-stage)。
- **自家的絲材切片器。** {{ui:CadCraft basic（內建，最快）}} 是卡片中**切片器**清單內的切片器：包括外壁、表皮、填充、支撐與裙邊，並在背景工作程式上執行，讓頁面保持可用。傳送前，可用**層**滑桿透過 {{ui:預覽層}} 檢視各層。Ender-3 與 Prusa MK4 等樣式的印表機設定檔帶有各自的起始 G-code。
- **傳送。** 可透過 USB（電腦上的 Chrome 或 Edge，並保持頁面開啟），或傳送到網路上的 Klipper（Moonraker）、OctoPrint 或 PrusaLink。未經點擊，不會連線或傳送；傳送前會先詢問。
- **其他切片器。** Kiri:Moto、PrusaSlicer 與 OrcaSlicer 各自為獨立外掛，預設為關閉；可從卡片或 {{ui:設定}} › {{ui:外掛}} 新增。PrusaSlicer 與 OrcaSlicer 會使用從 CadCraft Studio 安裝的副本。Bambu Lab 印表機外掛會使用 OrcaSlicer 及其 P2S 預設值進行切片，且需要在電腦上使用 Studio。
- **樹脂列印。** 樹脂外掛（預設為關閉）會產生印表機螢幕用的層圖片，具備中空與通氣孔、筏座與支撐、層預覽，以及時間、樹脂用量與成本。檔案格式外掛可寫入 Elegoo GOO、SL1、Chitubox（CBDDLP 與 CTB 2 至 5）以及 Anycubic（PWMX 與 PWS）。樹脂曝光測試會產生五種曝光值的階梯。請見 [為樹脂印表機切片](topic:resin-printing)。
- **未變更。** {{ui:匯出}} › {{ui:檢查 3D 列印（STL 或 3MF）…}}、列印工具與列印用分割，與 0.8 中的運作方式相同。請見 [準備 3D 列印模型](topic:print-3d)。

### 物料流、數位孿生與工廠現場

這三項都是外掛，需在 {{ui:設定}} › {{ui:外掛}} 中開啟後才會啟用，開啟後各自有說明。

- **物料流。** 名為「物料流」的面板會在 3D 視圖中配置輸送帶、工作站、緩衝區與 AGV 路徑，執行可重現的模擬，播放結果，並顯示產能、交期與排隊情形，結果可儲存為 CSV。訂單可來自 CSV 檔案。機器人單元可進行檢查與匯出。PLC 連線提供模擬模式，以及透過 Modbus TCP 的實機模式（僅能在 CadCraft Studio 中使用）。
- **數位孿生。** 讀取物料流配置，並在其上執行模擬 PLC，可強制觸發故障、進行庫存測試、版面比較與物料清單。
- **工廠現場。** 將工作站轉為機器與單元，可即時讀取或從模擬器讀取，並維護工作佇列與簡易 OEE。此功能僅讀取：此版本無法寫入任何機器或 PLC。

### 曲面、模型與圖面

- **NURBS 上的圓角、加厚與布林運算。** {{ui:曲面}} 面板提供 {{ui:面與面之間圓角}}、{{ui:一次圓角多條邊}}、{{ui:加厚為實體}}，以及聯集、差集與交集，每項皆顯示量測偏差。請見 [自由曲面（NURBS）](topic:nurbs-surfaces)。
- **將曲面擬合至掃描。** 選取掃描網格，在 **掃描** 群組中使用 {{ui:將曲面擬合至掃描}}，然後使用 {{ui:將曲面縫合為實體}}。這是初步擬合，並非完整的逆向工程套件。
- **與 .3dm 建模器的即時連結。** 單向，來自 Rhino 8 或 Grasshopper，需要同一台電腦上安裝 CadCraft Studio。請見 [保持 .3dm 模型即時連結](topic:live-3dm-link)。
- **在現場檢視模型。** {{ui:視圖}} 選單中的 {{ui:現場檢視（AR，手機）}}，可在搭載 Chrome 的 Android 手機上使用。請見 [以 Android 手機在現場檢視模型（AR）](topic:ar-on-site)。
- **圓弧方法。** {{ui:圓弧方法}} 下拉選單提供十種畫圓弧的方式，包括 {{ui:三點}} 與 {{ui:起點、圓心、終點}}。
- **更多單位。** 在輸入含單位的數值時，可辨識重量（kg、lb、t、ton）與溫度（°C、°F、K 與 °R）。

## 所有應用程式

- **工具提示。** 按鈕上的懸停文字與被截斷的標籤，皆以 Bootstrap 工具提示顯示。
- **可關閉的入門提示。** 空白繪圖區上的提示卡片有一個小型關閉按鈕（×）。關閉後會保持關閉，指令面板可再次顯示它。
- **可捲動的索引標籤列。** 面板的索引標籤列若放不下，會捲動而非被截斷。
- **索引標籤標題。** 開啟文件時，瀏覽器分頁會以文件名稱開頭，接著是 ModelCraft 與 CadCraft。未儲存時，前面會先顯示一個圓點。
- **版面配置。** {{ui:設定}} › {{ui:一般}} › 版面配置 會在下拉式清單中列出各版面配置，可選擇僅對此應用程式使用某個版面配置，並提供重設版面配置的按鈕。
- **語言。** 設定中的語言清單依建置版本所含的語言檔案而定。英文以外的語言皆為機器翻譯草稿。
- **即時協作與程式庫。** Live TeamWork 會顯示即時游標與名稱；程式庫集合會為每個應用程式提供預設集合。

## 已修正

- 動畫播放時，{{ui:播放}} 會變為 {{ui:暫停}}；時間軸開啟時，{{key:Space}} 可播放與暫停。
- 當顯示卡無法啟動路徑追蹤器時，靜態算圖會退回 WebGL。即時算圖檢視仍可能顯示錯誤；此項未在具有該驅動程式的 Windows 電腦上測試。
- 物料流實機模式在 PLC 例外回應後中斷連線，現已可再次連線。

## 目前的限制

- 尚未在實體印表機上列印過任何東西：無論是絲材、樹脂，或透過 Bambu Connect 皆然。樹脂檔案僅經 CadCraft 自家的讀取器讀回檢查。
- 數位孿生與工廠現場僅以模擬器與已知答案測試，未接入實際 PLC、產線或通訊協定。它們是檢查輔助工具，並非安全驗證。物理計算僅涵蓋箱體，最多八項負載。
- Rhino 與 Grasshopper 的連結從未在實際程式中執行過。
- 英文以外的語言為機器翻譯草稿。

## 較早版本：0.8 與 0.8.1

以下是 ModelCraft 0.8（2026-11-01）與 0.8.1（2026-11-02）相較於 0.7 的變更。{{ui:算出圖片…}} 對話方塊現在可將場景傳送至其他程式，{{ui:曲面}} 面板可建立平滑的自由曲面，而已連接的 AI 助理可用一句話設定整個場景。

### 新增

**算圖**

- **引擎選擇。** {{ui:算出圖片…}} 在模式上方有一個**引擎**清單。我們自有的兩種引擎「快速」與路徑追蹤器為預設，在任何地方皆可使用。其他項目會將場景儲存為套件（模型為 USD 檔案，另加一個設定檔，記錄精確的材質數值、已開啟的燈光、太陽、天空、曝光與相機），以便帶到其他程式中使用。由其他程式繪製的圖片會標示是哪個程式與版本所製作。請見 [選擇由哪個程式繪製圖片](topic:render-engines)。
- **用其他程式開啟。** 引擎清單可將場景儲存為 USD 檔案、glTF 檔案（`.glb`）或 Unreal 專案資料夾（`.zip`），可在瀏覽器與 CadCraft Studio 中使用。在 Studio 中，還可啟動 usdview 或電腦上該檔案的預設程式。請見 [在其他程式中開啟場景](topic:render-open-in)。
- **從 Studio 傳送至遊戲引擎。** Studio 會將場景寫入 Unreal Engine 專案，並在每次傳送時保持同步，僅單向。使用者自行的編輯存放在 CadCraft 永不寫入的圖層中。請見 [將場景傳送至遊戲引擎](topic:render-unreal)。
- **來自外掛的引擎。** 外掛可在清單中新增引擎。以 JavaScript 撰寫的引擎會在瀏覽器與 Studio 中繪圖；執行外部程式的引擎則需要在 Studio 中明確同意。請見 [用其他程式繪製圖片](topic:render-other-program) 與 [以外掛新增算圖引擎](topic:render-engine-addons)。
- **說出場景。** 對已連接的 AI 助理說「黃昏、小雨、秋天的樹、廣場上的人」，ModelCraft 會在一步內完成設定：太陽會依日期與時間移動，陰影隨之改變；天空改變，出現潮濕表面，樹木與人會以真實物件放置，並附上可隱藏、移動或刪除的標籤。時段、日期或季節，以及天氣（晴朗、陰天、霧、小雨、雨、暴風雨）也可單獨使用，而後續的要求會變更同一個場景。霧會顯示在顯示卡繪製的高品質圖片中；其他引擎則顯示天空、光線與潮濕表面。雨不會以落下的條紋描繪。

**材質**

- **從一張照片建立材質。** 提供一張表面照片（牆面、地板、石材），ModelCraft 會製作可平鋪的材質：照片上的光線被平坦化、邊緣會接合，並由照片推算出顏色貼圖、粗糙度貼圖與法線貼圖。這只是對自有照片做的一般影像處理，不使用訓練過的模型。粗糙度為估計值。平整、正方、正面拍攝的照片能得到最佳貼圖；磚塊等強烈圖案可能在接縫處留下模糊的鬼影，因為接縫已被混合。

**曲面**

- **自由曲面。** {{ui:曲面}} 面板可建立 NURBS 曲線與未修剪曲面：通過點的曲線、放樣、直紋、拉伸、旋轉、沿一或兩條導軌掃掠、由曲線網格生成曲面、由四條邊建立曲面片，以及匹配與混接。每條共用邊都會以 G0、G1 或 G2（間隙、角度、曲率跳變）在精確曲面上量測；比你要求更差的邊會以 **匹配** 修正項目出現在問題面板中。斑馬紋與曲率色彩由精確曲面繪製。STEP 與 IGES 檔案可匯出與匯入。請見 [自由曲面（NURBS）](topic:nurbs-surfaces)。

**場地與房間**

- **將手繪草圖照片放到地面。** {{ui:檔案}} › {{ui:匯入草圖照片…}} 可將手機拍攝的手繪草圖，依指定比例轉為地面上的邊線：為一個群組，每種筆色各有一個標籤。紙張會在電腦上自動偵測並校正，不會傳送至任何地方。請見 [在場地平面圖上建模](topic:site-plan)。
- **佈置房間。** 選取地板，然後使用 {{ui:整理}} › {{ui:為房間配置家具…}}。臥室、客廳、餐廳、廚房、浴室或辦公室家具會依規則放置：靠牆擺放，並與門窗保持距離，全部位於同一群組中，可一步移除。這是預設配置，供檢視用，並非設計成果。請見 [初始程式庫](topic:starter)。

**3D 列印**

- **斜切。** 列印用分割可將切面傾斜最多 60 度，讓零件有更大的黏合面積。連接件與切面垂直。請見 [分割模型以列印](topic:print-split)。
- **問題面板中的列印檢查。** 3D 列印檢查的結果會顯示在問題面板中，並在模型上標示標記；可從面板直接按**修復**進行修正。請見 [支撐、壁厚、中空與修復](topic:print-tools)。

**所有應用程式**

- **語言。** 說明與應用程式提供 54 種語言。其中 10 種為新增：立陶宛語、拉脫維亞語、波士尼亞語、馬拉地語、泰盧固語、阿爾巴尼亞語、南非荷蘭語、菲律賓語、斯瓦希里語與烏茲別克語。英文以外的語言在母語人士審閱前皆為機器翻譯草稿，說明主題可能仍為英文。
- **輸入裝置。** 觸控板、觸控筆、3D 滑鼠、遊戲控制器與 MIDI 控制器可操作所有應用程式，或僅操作其中一個。
- **工具列列數。** {{ui:設定}} › {{ui:一般}} › 工具列列數 可設定為換行（與之前相同）、2 列或 1 列。放不下的工具列會橫向捲動，而非佔用繪圖區的空間。換行仍為預設。
- **屬性格線。** ModelCraft 的燈光欄位使用共用格線：可摺疊分類、標籤與數值欄，以及緊湊密度。像 `2*450` 這樣的算術運算仍然可用。
- **問題。** 問題面板（應用程式列上的警告按鈕）由所有應用程式共用。在 ModelCraft 中，它包含列印檢查與曲面連續性警告。
- **即時協作。** Live TeamWork 工作階段會顯示每位成員的位置。請見 [使用 Live TeamWork 共同建模](topic:work-live)。
- **外掛。** 外掛可如上所述新增算圖引擎。
- **連接 AI。** 八個應用程式的工具合約與檢查皆已通過，共有 454 種工具。尚未承諾提供：Studio 內的一鍵連接、供瀏覽器助理使用的代管連接器、Studio 內使用自有金鑰，以及已發佈的套件。這些應用程式本身不含任何 AI。請見 [搭配 AI 助理使用 ModelCraft](topic:use-with-ai-assistants)。

### 0.8.1 已修正

- **DWG 類別區段。** DWG 檔案的類別區段曾被讀取為錯誤的型別，可能導致匯入時檔案損壞。現在已正確讀取，適用於 ModelCraft 及其他讀取 DWG 的應用程式。
- **直向平板電腦。** 多餘的網格高度會分配給畫布，且版面配置在 760 像素寬或以下時開始生效。ModelCraft 的樣式表也包含此變更。
- **Studio 中的語言。** CadCraft Studio 與套裝版本可在執行時切換語言；之前僅支援英文。尚未在所有平台上測試：若語言未切換，請告訴我們。

### 此版本尚未提供

- **未進行程式碼簽署。** Windows 可能顯示 SmartScreen：選擇{{ui:更多資訊}}，然後選擇{{ui:仍要執行}}。在 Mac 上，以右鍵點選並選擇{{ui:開啟}}。Store 版本暫緩發佈，iPad 與 iPhone 版本未針對 0.8.1 重新建置。
- 未使用算圖引擎外掛時由其他程式繪製圖片；全景或立體相機；透過其他程式的天空圖片；以及用來開啟 Unreal 舞台的外掛，皆尚未提供。檔案已寫入；外掛尚未發佈，也未在 Unreal 中執行過。
- 自由曲面：未量測或宣告 G3 與 A 級，修剪與實體將於之後推出。
- 由其他程式繪製的圖片與我們的圖片並非逐像素相同：僅相機、太陽、燈光與曝光一致。
- 0.8.1 對於 Studio 語言切換的修正尚未在所有平台上測試。

其他內容請見 [尚未實作](topic:not-built-yet)。上一版本請見 [0.7 新功能](topic:whats-new-0-7)。
