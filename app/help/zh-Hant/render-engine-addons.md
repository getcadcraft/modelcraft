外掛（設定 › 外掛）可以在 {{ui:Render a picture…}} 的引擎清單中加入一個引擎。外掛作者的完整說明位於外掛規格的第 16 節；簡要如下：

- 外掛會註冊一個引擎，其 id 以外掛自身的 id 開頭，並包含名稱、可選的設定，以及**要執行的程式**或**在 JavaScript 中繪製圖片的函式**兩者之一。
- 執行程式的引擎需要 **`engine.run`** 權限，該權限會在安裝前與設定中顯示。它只在 Studio 中執行；在瀏覽器中則顯示為可儲存的檔案。
- 外掛會指定程式（一個純粹的檔名，絕不使用 shell）、一個**位於已簽署外掛內**的指令稿，以及由佔位符與一般文字組成的參數。Studio 會找到該程式，或要求你指定一次其位置。
- 外掛第一次執行程式時，**Studio 會在其自己的對話方塊中詢問你**：是哪個外掛、哪個程式，以及指令稿可以執行該程式能做的任何事。只允許你信任的外掛執行。你的回答會針對該外掛與程式記住。
- 封裝（場景的 USD 檔與設定檔，外掛要求時還包括 glTF 檔）與外掛的指令稿會放入新的暫存資料夾，程式在該資料夾中執行，完成後圖片會以外掛的引擎名稱標記並回傳。

:::note
外掛只能從外掛 API 1.4 起新增算圖引擎。一個開放原始碼命令列算圖器的實作範例位於其自己的儲存庫中；該範例尚未在該算圖器中實際執行。
:::
