{{ui:算出圖片…}}會把目前視圖製作成一張像日光而非草圖的圖片：有天空、依模型位置與日期而定的太陽、柔和陰影、整個天空的光線（會使角落與縫隙變暗），以及可呈現玻璃、金屬或光澤漆面效果的色彩。模型本身不會被改變。

## 算圖視圖

1. 依想要的圖片調整視圖：環繞、縮放、選擇[場景](topic:scenes)、隱藏不應顯示的部分。圖片會使用該視圖自己的攝影機。
2. 在{{ui:檔案}}群組中按一下{{ui:匯出}}，然後按一下{{ui:算出圖片…}}。
3. 如果按下的{{ui:場景}}不符合需求，選擇其他{{ui:場景}}（見[場景預設](topic:render#scene-presets-a-good-picture-in-one-click)），選擇{{ui:尺寸}}，然後按一下{{ui:算圖}}。

   圖片會在算圖時逐步成形，並隨每一輪而變得更平滑。{{ui:停止}}（或{{key:Esc}}）會提早結束，並保留目前完成的圖片。

4. 按一下{{ui:儲存}}以下載（除非{{ui:另存為}}另有指定，否則為 PNG）。

:::tip
先以{{ui:視圖大小}}的{{ui:草稿}}檢查攝影機與外觀，再以較大的尺寸算出{{ui:良好}}或{{ui:最佳}}品質作為最終圖片。
:::

## 場景預設：一鍵得到好圖片

對話框頂端有四個{{ui:場景}}按鈕。每一個都會在一次按下時設定天空、亮度、地面、邊線、品質與太陽，因此在第一張圖片前不需要學習任何設定。按下其中一個，然後按{{ui:算圖}}。

| {{ui:場景}} | 設定內容 | 用途 |
|---|---|---|
| {{ui:外部}} | 晴空、模型自己的太陽、開啟地面 | 從外部看建築 |
| {{ui:內部}} | 陰天天空（光線均勻，沒有明顯的太陽光斑），亮度提高半級 | 從房間內部看 |
| {{ui:剖面視圖}} | 白色攝影棚、無地面、快速算圖時顯示邊線 | 被剖面切割的模型 |
| {{ui:夜間}} | 太陽下山（以基地所在半球的仲冬午夜為準），亮度提高一級 | 以燈具照亮模型。沒有燈具時圖片會很暗 |

- {{ui:依此視圖選擇}}會為你選擇：剖面切割開啟時選{{ui:剖面視圖}}，攝影機位於模型內部時選{{ui:內部}}，其他情況選{{ui:外部}}。第一次開啟對話框時會自動以此方式開始。
- 下方的所有設定都保留，並可修改。一旦你更改某個場景所設定的項目，就不會再有按鈕處於按下狀態，按鈕下方的文字會說明這些設定已是你自己的。再次按下場景即可將其數值還原。
- 場景不會改動引擎、模式、尺寸、材質、攝影機或燈具。

:::note
場景在 ModelCraft 與 BimCraft 中給出相同的數值。完成圖片的外觀取決於你的模型與顯示卡。
:::

## 設定

| 設定 | 作用 |
|---|---|
| {{ui:尺寸}} | 視圖的尺寸、兩倍視圖尺寸、Full HD、4K 或正方形。固定尺寸會保留視圖的攝影機，並在兩側顯示或多或少的內容 |
| {{ui:模式}} | {{ui:快速}}，或下方的{{ui:高品質（路徑追蹤）}}及其{{ui:時間上限}} |
| {{ui:品質}} | 平均多少輪（在高品質模式中為取樣數）：{{ui:草稿}} 16、{{ui:良好}} 64、{{ui:最佳}} 256。輪數越多，陰影與邊緣越平滑，但耗時越長 |
| {{ui:天藍}} | {{ui:晴空}}、{{ui:陰天}}（柔和光線、淡陰影）、{{ui:黃昏}}（低角度、暖色光）或{{ui:白色攝影棚}}（純白背景） |
| {{ui:太陽}} | 太陽來自{{ui:樣式}}中的日期、時間與地點（太陽設定）。勾選{{ui:此圖片使用其他日期與時間}}，可在不改變模型樣式的情況下嘗試另一個時間 |
| {{ui:亮度}} | 以級（stops）為單位，調亮或調暗 |
| {{ui:模型下方的地面}} | 承接陰影並淡入地平線的地面。模型若是懸浮的，關閉即可 |
| {{ui:繪製邊線}} | 在圖片上以細線繪製模型的邊線，呈現繪製的效果 |

當所選時間太陽位於地平線以下時即為夜間：天空變暗，模型會由其[燈具](topic:lights)照亮。對話框會說明此情況。

設定會保存在 `.modelcraft` 檔案中，因此同一模型的下一張圖片會從上次停止的地方開始。

## 讓顏色呈現玻璃或金屬質感

在{{ui:材質}}下，畫面上的每種顏色都有一種質感：{{ui:啞光}}、{{ui:緞面}}、{{ui:光澤}}、{{ui:金屬}}、{{ui:拋光金屬}}、{{ui:玻璃}}或{{ui:磨砂玻璃}}。{{ui:未上色的面}}是沒有自己顏色的面。

要讓窗戶呈現玻璃效果，先把窗格[上色](topic:paint)為同一種顏色，再將該顏色設為{{ui:玻璃}}。玻璃會讓天空及其後的景物透出來，並帶有其顏色的色調，同時反射天空。

:::note
在{{ui:快速}}模式中，玻璃與金屬只反射天空，不反射模型的其餘部分，光線也不會穿過玻璃折射。下方的{{ui:高品質（路徑追蹤）}}模式兩者皆會處理。
:::

## 高品質

選擇{{ui:模式}} › {{ui:高品質（路徑追蹤）}}，可得到依照相機所見的光線路徑來製作的圖片：

- 光線會在表面之間反彈，因此透過窗戶或由燈具照亮的房間會四周受光，顏色也會滲到鄰近的表面上；
- 玻璃是真正的玻璃：光線會穿過它折射，並且它會反射模型；
- 金屬與拋光表面會反射模型的其餘部分；
- 光面板會以面板的方式發光，並帶有柔和陰影。

它比{{ui:快速}}慢得多：每一輪都會重新追蹤每個像素的光線。圖片一開始會有顆粒感，隨取樣累積而逐漸清晰，因此請從小尺寸（{{ui:視圖大小}}、{{ui:草稿}}）開始，並設定{{ui:時間上限}}：時間用完時，會保留目前完成的圖片。按下{{ui:停止}}也會保留它。第一輪會等待瀏覽器準備路徑追蹤器。

在瀏覽器支援 WebGPU 的情況下，路徑追蹤器是 CadCraft 自己的，並在顯示卡上執行；圖片下方的文字會顯示{{ui:在顯示卡上路徑追蹤（WebGPU）}}。按下{{ui:停止}}或達到時間上限後，{{ui:繼續}}會接著完成同一張圖片，直到取得所有取樣；變更設定或再次按下{{ui:算圖}}則會重新開始。沒有 WebGPU 時，圖片會改用 WebGL 進行路徑追蹤（文字會說明此情況），且不提供{{ui:繼續}}。

:::linux
Linux 上的 Firefox 與多數 Chrome 設定目前還沒有 WebGPU，因此高品質模式在那裡會使用 WebGL。
:::

在此模式中不繪製邊線，材質庫貼圖只顯示其色彩與粗糙度，不顯示凹凸（[以節點製作的材質](topic:shading#in-high-quality-pictures)會顯示其法線與凹凸），且會在圖片開始前先對模型進行剖面切割。

{{ui:降噪（清除取樣後殘留的雜訊顆粒）}}預設為開啟：圖片完成或停止後，殘留的顆粒會由為此設計的神經網路清除（Intel Open Image Denoise 公開發布的網路，於你自己的電腦上執行：優先使用顯示卡，否則使用處理器）。取樣數少的圖片也能得到乾淨的結果；{{ui:顯示}} › {{ui:降噪前的影像}}會顯示算圖後未降噪的圖片。

## 在視圖中算圖

{{ui:算圖}}工作區會直接在視圖中執行路徑追蹤器：環繞、編輯模型或變更燈具，它都會立即重新開始。{{ui:區域}}：拖曳出一個矩形，只算圖該範圍；{{ui:整個視圖}}則返回全部。{{ui:對焦}}：按一下應保持清晰的位置，景深就會對焦於該處。{{ui:細節}}設定算圖的視圖像素數（越少越快）。{{ui:暫停}}會停止，並可繼續。此功能需要 WebGPU：沒有時，工作區會說明此情況，而{{ui:匯出}} › {{ui:算出圖片…}}仍可使用。

## 顯示卡上的天空與光線設定檔

有了 WebGPU，高品質模式還提供兩種天空：

- {{ui:物理天空}}依太陽高度推算日光：頭頂為深藍色，地平線附近為淡色帶，太陽在低角度時會變得更暖且更暗。{{ui:霧度}}可從非常晴朗的日子（2）調到較朦朧的日子（10）。
- {{ui:天空影像（HDRI）}}以真實地點的全景圖片照亮模型。{{ui:選擇影像…}}會選取等距長方投影的 `.hdr` 或 `.exr` 檔；{{ui:旋轉}}可使其繞模型旋轉，{{ui:影像亮度}}則可調亮或調暗。該圖片本身帶有太陽，因此不會再加入模型的太陽。它只在頁面保持開啟時保留：重新開啟後，需要再次選擇。

{{ui:燈具}}清單中的每盞燈都可套用廠商的配光檔：{{ui:IES 配光檔…}}會讀取 IES（LM-63）檔，之後該燈具會依其實際方式投射光線（例如窄光束筒燈、牆面洗牆燈）。同名的每盞燈都會使用它，而燈具仍保有自己的亮度。按一下配光檔的名稱即可停止使用。

採用透明玻璃的窗戶有助於天空的光線進入室內，因此在天空下拍攝的室內圖片會更快成形。

{{ui:快速}}模式與 WebGL 路徑追蹤器會將{{ui:物理天空}}與{{ui:天空影像（HDRI）}}顯示為晴空，並忽略配光檔。

## 攝影機

{{ui:視角}}會像拍照一樣設定圖片：

- {{ui:曝光}}：保留{{ui:亮度滑桿}}，或選擇{{ui:相機設定}}，並像在相機上一樣設定{{ui:光圈（f 值）}}、{{ui:快門速度}}與{{ui:ISO}}；旁邊的 EV 即一般的曝光值。f/16、1/100 秒與 ISO 100 相當於晴天；較暗的場景需要較大光圈、較慢快門或較高 ISO。此功能在所有模式中都可用。
- {{ui:景深}}會依該光圈鏡頭的特性，模糊比{{ui:對焦距離（公尺）}}更近或更遠的部分（留空則對焦於視圖中央的物件）；{{ui:光圈形狀}}可使焦外的亮點呈圓形或多葉形。
- {{ui:兩點透視（垂直線保持垂直）}}會調平攝影機並平移圖片，如同建築移軸鏡頭，因此仰望或俯視建築時，牆面不會傾斜。
- {{ui:白平衡}}設定哪一種光色會呈現為白色：較低（例如 3000 K）適合暖色燈光，較高適合陰影與陰天。
- {{ui:投影}}：{{ui:360° 全景}}會為全景檢視器製作 2:1 的圖片，涵蓋攝影機四周的所有景物；{{ui:360° 立體全景}}會上下並列左眼與右眼的全景，供頭戴裝置使用；{{ui:立方體貼圖（6 面）}}會以 3 × 2 的格線製作六個正方形視圖。寬度取自{{ui:尺寸}}。

投影、景深、兩點透視與白平衡需要顯示卡上的路徑追蹤器（WebGPU），因此只在{{ui:高品質}}中顯示。

## 完成圖片

{{ui:影像}}會像調整照片一樣為高品質圖片調色，而且每個控制項都會立即改變完成的圖片，無需重新算圖：

- {{ui:外觀（view transform）}}：{{ui:ACES filmic}}（與先前相同）、{{ui:AgX}}（較柔和，在非常亮的光線下保留色彩）、{{ui:Filmic}}（柔和的膠片曲線）或{{ui:標準}}（平淡，過亮的光會裁切為白色）。
- {{ui:對比}}與{{ui:高光壓縮}}（還原非常亮部分的細節）。
- {{ui:泛光（Bloom）}}（亮光周圍的柔和光暈）、{{ui:眩光}}及其{{ui:眩光光芒}}（從最亮點射出的星形光線），以及{{ui:暈影}}（較暗的角落）。
- {{ui:色彩表（.cube）…}}會依 `.cube` 檔套用色彩分級，並搭配其{{ui:色彩表強度}}；與天空影像一樣，僅在頁面保持開啟時保留。

## 儲存圖片

{{ui:另存為}}位於{{ui:儲存}}旁，用於選擇檔案：{{ui:PNG}}、{{ui:JPEG}}或{{ui:WebP}}適合分享（JPEG 與 WebP 僅在瀏覽器可寫入時提供）；在顯示卡上完成高品質算圖後，還提供：

- {{ui:PNG，16 位元}}：經調色的圖片，色階更細緻，適合列印或後續編輯。
- {{ui:EXR，所有圖層（32 位元浮點數）}}：算圖結果（線性光、未調色），每個算圖元素與燈光群組各為一個圖層，供合成程式使用。
- {{ui:算圖檔（.ccrender，之後可再調色）}}：對話框重新混合與調色圖片所需的一切。{{ui:開啟算圖檔…}}可在不重新算圖的情況下，帶回其混合與調色設定。

## 算圖後混合光線

在按下{{ui:算圖}}前開啟{{ui:光線混合（算圖後可變更每盞燈的顏色與亮度）}}。圖片完成（或停止）後，{{ui:混合影像}}會依群組列出其光線：天空、太陽，以及依名稱分組的燈具（同名的每盞燈為一組）。關閉某個群組、為它指定顏色，或使其更亮或更暗，圖片都會立即改變，無需重新算圖。{{ui:儲存混合}}會以名稱保存混合設定，供日後選擇；{{ui:算圖結果}}則會回到原始製作的圖片。{{ui:儲存}}會儲存混合後的圖片。

{{ui:算圖元素（反照率、法線、深度、漫反射、鏡面反射、透射、自發光、ID）}}同樣會保留圖片的各個部分。{{ui:顯示}}會將視圖切換為其中一種：表面色彩（反照率）、法線、深度、漫反射、鏡面反射與透射光（各為直接與間接光）、發光的部分與天空，以及依物件或依材質指定的色彩，用於製作遮罩。

兩者都會在顯示卡上保留額外圖層。尺寸較大時，顯示卡記憶體可能不足；對話框會說明此情況，改用較小的尺寸即可。

## 算圖佇列

在高品質設定完成後，{{ui:算圖佇列}}下的{{ui:將此影像加入佇列}}會以目前的設定保存圖片；影片對話框中的{{ui:將此動畫加入佇列}}則會對整段動畫做同樣的事，逐格以路徑追蹤算圖。{{ui:開始佇列}}會在這台電腦上依序算圖，每張完成後，其旁的{{ui:儲存}}會下載它。關閉頁面後佇列會保留：開啟同一模型，它會從停止的地方繼續。佇列需要 WebGPU。

## 霧、煙、雜訊與焦散

這些設定位於{{ui:霧、煙與雜訊}}中，在顯示卡上的{{ui:高品質}}模式下有效；其他引擎則不提供。

- {{ui:霧與薄霧}}會以一層霧氣填滿至某個高度的空氣，霧氣會受太陽、天空與燈具照亮。{{ui:可見距離（公尺）}}設定霧的濃度（約 100 m 為淡薄霧，20 m 為濃霧），{{ui:霧高於地面的高度（公尺）}}為霧的終止高度，而{{ui:光束}}則決定霧氣朝光源方向發光的程度。陽光會在霧的頂端離開霧層，因此當陽光穿過窗戶或建築之間時，你會看到如光束般的光柱。
- {{ui:煙或雲}}加入一個受霧同樣光照的煙或雲體積。{{ui:種類}}可選{{ui:雲}}、{{ui:煙柱}}或{{ui:來自體積檔（.ccvol）}}（CadCraft 自己的網格格式）。{{ui:細節}}與{{ui:變化}}可變更已製作的雲或煙柱；{{ui:最長邊的大小（公尺，0 = 模型大小）}}、{{ui:移動X（m）}}、{{ui:移動Y（m）}}、{{ui:移動Z（m）}}與{{ui:旋轉}}用於定位（一開始位於模型中央）；{{ui:厚度}}使其更濃密，{{ui:前向光暈}}使其朝光源方向更亮，{{ui:色彩}}為其上色。體積檔與天空影像一樣，僅在頁面保持開啟時保留。
- {{ui:影像乾淨處提早停止（自適應取樣）}}會停止為已穩定的像素分配更多取樣，使圖片其餘部分更快完成。{{ui:可接受的雜訊}}為像素停止時仍可保留的顆粒量。圖片下方的文字會說明每個像素平均得到多少取樣。
- {{ui:焦散（光線經玻璃折射或經鏡面反射）}}會追蹤來自燈具與太陽的光線，使玻璃球下的亮斑或鏡面投射在牆上的光點呈現乾淨，而非顆粒狀。在霧、煙、{{ui:算圖後混合光線}}或算圖元素開啟時，它會關閉；它是為圖片而設計，不適用於 360° 圖片、動畫或算圖工作區。

## 所需時間

圖片由你自己的電腦及其顯示卡製作；不會上傳任何內容。所需時間取決於該顯示卡。時間會隨輪數與像素增加：{{ui:最佳}}的輪數是{{ui:草稿}}的 16 倍，4K 圖片的像素約為 Full HD 的四倍。沒有顯示卡的電腦仍可算圖，只是速度較慢。

:::note
若對話框表示瀏覽器無法算圖，代表瀏覽器不支援 WebGL 2。請更新瀏覽器，或在其設定中開啟硬體加速。
:::
