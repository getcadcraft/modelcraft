以下是推拉按鍵，即 ModelCraft 預設的按鍵。另一種樣式請參見下方的 [Modeler 按鍵](topic:keyboard#modeler-keys)，以及 [ModelCraft 設定](topic:settings)。

快速鍵在 3D 視圖或工具列按鈕具有焦點時才會生效。若剛在面板欄位中輸入文字，或變更了{{ui:樣式}}中的清單，請先點擊 3D 視圖，否則按鍵會輸入到該欄位中。關於各電腦上按鍵的寫法，參見[按鍵、滑鼠與觸控板](common:keys)。

## Esc

每次按下 {{key:Esc}} 會退出一層：

1. 取消工具正在進行的動作（正在繪製的直線、推拉或移動）。所有內容都會恢復原狀。
2. 切換為{{ui:選取}}。
3. 清除選取。
4. 關閉正在編輯的群組。

也會停止播放場景。在數值框中，{{key:Esc}} 會清除輸入的內容並回到視圖。

## 工具運作中

| 按鍵 | 功能 |
|---|---|
| 數字，或 `. , - ' " [ < * /` 之一 | 開始在數值框中輸入 |
| {{key:Enter}} | 套用數值框中輸入的內容 |
| {{key:Right}} | 鎖定至紅軸（再按一次即解除鎖定） |
| {{key:Left}} | 鎖定至綠軸 |
| {{key:Up}} | 鎖定至藍軸 |
| {{key:Down}} | 鎖定為與第一次點擊前最後經過的邊平行 |
| 按住 {{key:Shift}} | 按住期間，鎖定目前貼齊的方向 |
| {{key:Ctrl}}、{{key:Mod}} 或 {{key:Alt}}（{{ui:移動}}） | 在移動與複製之間切換 |

方向鍵鎖定可用於{{ui:直線}}、{{ui:矩形}}、{{ui:圓}}、{{ui:多邊形}}、{{ui:移動}}、{{ui:縮放}}與{{ui:卷尺}}（從某點量測時），需在第一次點擊後使用。{{ui:推拉}}一律沿面的方向移動，沒有鎖定功能。在{{ui:旋轉}}中，第一次點擊後方向鍵會顯示「已鎖定」訊息，但不會改變旋轉角度。

## 其他時候的方向鍵

當沒有工具正在進行動作時，方向鍵會移動視角：

| 按鍵 | 功能 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 環繞 |
| {{key:Shift}} 搭配方向鍵 | 平移 |

## 滑鼠

| 操作 | 功能 |
|---|---|
| 點擊 | 使用目前的工具 |
| 按住、拖曳、放開 | 與兩次點擊相同（用於繪圖工具）；框選（用於{{ui:選取}}）；沿途刪除（用於{{ui:橡皮擦}}） |
| 連按兩下 | {{ui:選取}}：面連同其邊、邊連同其面，連按兩下可開啟群組；在空白處連按兩下則關閉群組。{{ui:推拉}}：重複上一次的距離 |
| 三次點擊 | {{ui:選取}}：所有相連的物件 |
| {{key:Shift}} + 點擊 | {{ui:選取}}：加入或移出選取 |
| {{key:Mod}} + 點擊 | {{ui:選取}}：加入選取 |
| {{key:Shift}} + {{key:Mod}} + 點擊 | {{ui:選取}}：從選取中移除 |
| 按住滑鼠中鍵拖曳 | 任何工具皆可環繞 |
| {{key:Shift}} + 按住滑鼠中鍵拖曳 | 任何工具皆可平移 |
| 按住滑鼠右鍵拖曳 | 任何工具皆可平移 |
| 滾輪 | 朝游標方向縮放 |

沒有右鍵選單。

## 觸控板

雙指滑動的作用取決於{{ui:設定}} › {{ui:ModelCraft}} › 捲動：

| 手勢 | 觸控板（或推算結果） | 滑鼠滾輪 |
|---|---|---|
| 雙指滑動 | 環繞 | 朝游標方向縮放 |
| {{key:Shift}} + 雙指滑動 | 平移 | 縮放 |
| 捏合 | 朝游標方向縮放 | 朝游標方向縮放 |
| 雙指按住並拖曳（按住次要點擊） | 平移 | 平移 |

參見[環繞、平移與縮放](topic:orbit-pan-zoom#on-a-trackpad)，以及[ModelCraft 設定](topic:settings#scrolling-mouse-wheel-or-trackpad)。

## 觸控螢幕

| 手勢 | 功能 |
|---|---|
| 輕觸 | 以目前的工具點擊一次 |
| 連續輕觸兩下 | 連按兩下 |
| 按住、拖曳、抬起 | 與滑鼠按住、拖曳、放開相同 |
| 雙指捏合 | 縮放 |
| 雙指同時移動 | 平移（{{ui:設定}} › {{ui:ModelCraft}} › 觸控螢幕 可改為環繞） |
| 三指同時移動 | 環繞（雙指用於環繞時則為平移） |
| 單指停留不動 | 如 {{key:Enter}} 般完成工具；若無任何動作，則接著拖曳以環繞 |
| 單指動作進行中再加一指 | 取消該動作 |
| {{ui:環繞}}工具，然後以單指拖曳 | 環繞 |

在觸控螢幕上輸入數值時，點擊底部的數值框、輸入數值，然後按鍵盤上的 {{key:Enter}}（或「前往」）鍵。

## 移動工具的位置

移動位於{{ui:移動}}工具中，按鍵為 {{key:M}}：選取要移動的物件，點擊基點，然後點擊第二點或輸入距離。參見[移動、複製與建立陣列](topic:move-copy)。
