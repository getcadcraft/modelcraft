{{ui:Render a picture…}} 在模式上方有一個 **引擎** 選項。我們自己的兩個引擎始終可用，並且在任何地方都能運作；外掛可以新增更多引擎，而在 CadCraft Studio 中，清單中還會列出接管場景的程式。

| 引擎 | 功能 | 適用環境 |
|---|---|---|
| 內建：快速 | 快速靜態圖：日光、柔和陰影、玻璃與金屬外觀，數秒即可完成 | 瀏覽器與 Studio |
| 內建：路徑追蹤器 | 光線在表面之間反彈，於你的顯示卡或處理器上運算，支援算圖佇列及網路上的其他電腦 | 瀏覽器與 Studio |
| 外掛的引擎 | 繪製圖片並回傳：請參閱[以其他程式繪製圖片](topic:render-other-program) | 瀏覽器（以 JavaScript 撰寫的引擎）或 Studio（執行程式的引擎） |
| 接管場景的程式 | Studio 會將場景放入其資料夾並保持同步 | Studio |
| 在…中開啟… | 儲存場景並在程式中開啟；不會回傳任何內容：請參閱[在其他程式中開啟場景](topic:render-open-in) | 網頁會儲存檔案 |

## 選擇的行為

- 選擇「快速」或「路徑追蹤器」會同時變更模式，反之亦然。對於從不使用其他引擎的使用者，對話方塊的其他部分不會有任何改變。
- 無法使用的引擎會保留在清單中，並顯示原因（「找不到」、「需要較新的版本」）；你無法選取它。在瀏覽器中，僅能在 Studio 中執行的引擎會顯示「儲存檔案」：{{ui:Render a picture…}} 接著會將場景及其設定儲存為檔案，你可以帶到該程式中。
- 所選的引擎會與檔案的算圖設定一併儲存；對於沒有自己選擇的檔案，你最後選取的引擎即為起始引擎。
- 來自其他程式的圖片會在對話方塊與算圖佇列中，說明是哪個程式繪製的及其版本。[算圖](topic:render)頁面的承諾僅涵蓋**我們自己的**引擎：其他程式會以自己的方式處理光線、色調與取樣，因此同一場景的兩張圖片在鏡頭、太陽、燈光與曝光上相似，但並非逐像素相同。

## 每個引擎所取得的內容

場景會以**封裝**形式交給其他程式：模型為 USD 檔（與[另存為 USD](topic:usd) 寫入的檔案相同），以及一個設定檔，其中包含 USD 匯入器無法可靠處理的內容：精確的材質數值、開啟中燈光的功率與光形、太陽、天空、曝光，以及對話方塊所呈現的鏡頭。內容不會上傳到任何地方。

## 算圖佇列

其他程式的圖片或動畫可以像我們自己的一樣在[算圖佇列](topic:render#the-render-queue)中等待；其工作會記住它所對應的引擎。動畫會一次交給該程式處理。
