在原本建模的地方繼續建模，再於此處使用成果：用來算圖、打光，或圍繞它安排場景。在另一個程式中的每項變更，都會更新 ModelCraft 中的一個群組。

:::note
此連結需要同一台電腦上的 **CadCraft Studio**。瀏覽器分頁無法建立連線。資料不會經過網際網路：指令稿會透過此電腦的本機位址與 Studio 通訊，並使用權杖。
:::

:::warning
此連結已透過指令稿的檔案寫入器與另一程式的替代元件測試，尚未在 Rhino 或 Grasshopper 本身中測試。若該處失敗，請回報其顯示的訊息。
:::

## 設定

1. 在 Studio 中開啟 ModelCraft。在{{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}}中，勾選 **讓 AI 助理與指令稿使用 ModelCraft**，然後按 **編輯**。
2. 在 Studio 中選擇{{ui:連接助理}}。畫面會顯示位址與權杖，需貼到下方。
3. 下載指令稿：[cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)。

## 從 Rhino 使用

1. 在 Rhino 的指令稿編輯器中執行 `cadcraft_link.py`（Rhino 8 使用 Python 3）。
2. 第一次執行時，貼上位址與權杖。兩者會保存在使用者資料夾中的 `.cadcraft-link.json`，絕不會存入模型。Studio 每次啟動都會產生新的權杖，因此指令稿屆時會再次詢問。

整個模型會以一個群組匯入，群組名稱為文件名稱，例如「chair (linked)」。之後，每項變更會在停頓片刻後匯入，且只會傳送有變動的物件。再次執行指令稿即可停止。

## 從 Grasshopper 使用

先在 Rhino 中執行一次指令稿，以儲存位址與權杖。

1. 新增 Script 元件（Python 3），並將整個 `cadcraft_link.py` 貼入其中。
2. 為其設定以下輸入：`G`（幾何，需使用清單存取）、`N`（名稱，可選填）、`On`（布林切換開關），以及 `Target`（可選填：`model` 或 `part`，適用於兩個應用程式都開啟時）。
3. 將 `On` 設為 true。

每次求解都會傳送 `G`，並取代該元件上次傳送的內容，因此拖曳滑桿時會更新此處的群組。其輸出 `a` 會說明發生的結果。每個元件各有自己的群組。

## 群組的用途

- **移動、加標籤、圍繞它建模。**群組的位置與其標籤會在每次更新後保留，旁邊的所有物件也會保留。
- **不要在群組內編輯。**每次更新都會取代群組內的內容，這些物件由另一個程式擁有。
- **復原。**間隔兩秒內的更新會共用一個復原步驟，因此{{key:Mod+Z}}可取消整段拖曳。下一次更新會讓模型回到相符的狀態。
- **儲存。**儲存的檔案會保留連結。重新開啟後再次執行指令稿，同一個群組會更新。

## 會匯入的內容

網格、多重曲面、曲面與擠出，會以螢幕上所見的網格匯入；SubD 以其網格匯入；曲線以邊匯入；區塊則在其所在位置以獨立物件匯入（不是元件）；圖層會成為標籤，色彩與單位也會一併匯入。這些內容在此處的呈現方式，請見[匯入 .3dm 模型](topic:import-3dm-files)。

以下內容不會匯入，另一個程式中會顯示其數量：點、文字、標註、燈光及類似項目。

**僅單向。**此處的變更不會回傳到另一個程式。

## 發生問題時

- **「沒有 ModelCraft 或 PartCraft 視窗允許此操作」：**執行設定的第 1 步。
- **「Studio 拒絕了權杖」：**Studio 已重新啟動。複製新的權杖後再次執行指令稿。若使用 Grasshopper，請先在 Rhino 中執行。
- **「無法連線至 CadCraft Studio」：**Studio 未在執行，或位址已變更。
