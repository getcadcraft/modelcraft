{{ui:Render a picture…}} 中的圖片由**我們自己的引擎**繪製：快速與路徑追蹤器，可在瀏覽器與 CadCraft Studio 中使用。只有當**算圖引擎外掛**提供時，其他程式才能繪製圖片：請參閱[以外掛新增算圖引擎](topic:render-engine-addons)。若要將場景帶到其他程式並在那裡繼續工作，請使用[在其他程式中開啟場景](topic:render-open-in)或[將場景傳送至遊戲引擎](topic:render-unreal)。

## 以外掛的引擎繪製圖片

1. 在 設定 › 外掛 中開啟該外掛。其引擎會出現在 {{ui:Render a picture…}} 的引擎清單中。
2. 選擇它。其自己的設定會顯示在引擎清單下方。
3. 點擊 {{ui:Render}}。在 Studio 中，外掛第一次執行程式時，Studio 會在其自己的對話方塊中詢問你。繪製期間會顯示進度；{{ui:Stop}} 可結束繪製。圖片會出現，並標示繪製它的引擎。

以 JavaScript 撰寫的引擎也能在瀏覽器中執行。在此電腦上執行程式的引擎只能在 Studio 中執行；在瀏覽器中則顯示為可儲存的檔案。

## 攜帶的內容

引擎會取得一個**封裝**：模型為 USD 檔（若引擎要求，也包含 glTF 檔），以及一個設定檔，內含精確的材質數值、太陽與天空、每一盞開啟中的燈及其功率與光形、攝影機與曝光。每個程式都以自己的方式處理光線、色調與取樣，因此圖片在鏡頭、太陽、燈光與曝光上相似，但並非逐像素相同。

## CadCraft 絕不執行的程式

CadCraft 絕不會啟動採用 GNU GPL 授權的程式，也絕不會將其列為引擎或「在…中開啟…」的目標。Blender 即是其中之一，因此它不會出現在引擎清單中。由 {{ui:Render a picture…}} 儲存的 USD 或 glTF 檔案，仍可像在任何能讀取這些檔案的程式中一樣，在 Blender 中開啟。

:::note
全景與立體攝影機，以及天空圖片（改用天空的顏色），不會攜帶到其他程式中。在其他程式中所做的任何變更，都不會回傳到模型。
:::
