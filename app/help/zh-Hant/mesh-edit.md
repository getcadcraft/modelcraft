**網格**工作區會逐點編輯[網格](topic:meshes)：其頂點、邊與面。推拉幾何則保留在**模型**工作區中。

## 開啟

- 在工具列左側的{{ui:Workspace}}清單中選擇{{ui:Mesh}}。所選網格會開啟以供編輯；若所選的是群組或元件，會先將其轉換為網格（一個復原步驟）。
- 或按兩下網格；若使用建模快速鍵，則選取網格後按{{key:Tab}}。
- 未選取任何項目時，面板會提供可新增的網格：平面、格線、立方體、圓形、圓柱、圓錐、球體、二十面體球與環面。新增的網格會放在視圖正在看的位置，並開啟以供編輯。

{{ui:Back to Model}}（或使用清單；建模快速鍵為{{key:Tab}}，推拉快速鍵且未選取任何項目時為{{key:Esc}}）會返回模型並保持選取網格。網格工作區開啟時，模型其餘部分會淡化，且模型的繪圖工具會收起。

## 選取

| 操作 | 作用 |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | 選取頂點、邊或面 |
| 按一下 | 選取一個；{{key:Shift}}+按一下可新增或移除 |
| 拖曳方框 | 選取框內且可見的項目；{{key:Shift}}新增，{{key:Ctrl}}移除 |
| {{key:Alt}}+按一下邊，或按兩下邊 | 其邊迴圈（面模式下為面迴圈；開放邊則為整個邊界） |
| {{key:Ctrl}}+{{key:Alt}}+按一下邊 | 其邊環 |
| 連按三下 | 與其相連的所有項目 |

{{ui:Select}}群組還包含{{ui:All}}、{{ui:Linked}}、{{ui:Loop}}、{{ui:Ring}}、{{ui:More}}與{{ui:Less}}。

## 移動、旋轉、縮放

{{ui:Move}}、{{ui:Rotate}}與{{ui:Scale}}會從指標位置開始：移動指標，然後按一下或按{{key:Enter}}放下所選項目，或按{{key:Esc}}取消。{{key:X}}、{{key:Y}}或{{key:Z}}（或方向鍵）可鎖定一個軸。若需精確數值，可輸入距離、角度或比例 — [計算](topic:value-box#calculations)同樣可用。

**比例編輯**（{{ui:Proportional}}，或面板中的選項）：靠近所選項目的頂點會隨移動而跟隨，距離越遠跟隨越少，範圍為所設定的距離，衰減方式可選。開啟{{ui:僅沿網格}}可沿邊量測，而非直線量測。

{{ui:Slide}}會沿其旁邊的邊，移動所選的邊迴圈。

## 變更形狀

| 工具 | 作用 |
|---|---|
| {{ui:Extrude}} | 沿法線方向拉出所選的面，並建立新的側面（或由開放的邊界邊建立面）。輸入距離 |
| {{ui:Inset}} | 所選面輪廓內側的帶狀區域；若要分別處理每個面，再次按{{key:I}} |
| {{ui:Bevel}} | 以指定寬度切割所選的邊（或按{{key:Ctrl}}+{{key:Shift}}+{{key:B}}切割頂點）；使用滾輪或加減鍵可增加分段，形成圓角邊 |
| {{ui:Loop cut}} | 指向一條邊：在四邊形面的環上建立新的迴圈；滾輪設定數量；按一下即可切割 |
| {{ui:Knife}} | 在邊或角落上按一下指定點；按{{key:Enter}}會依所見，沿直線切過其間的面 |
| {{ui:Bisect}} | 在螢幕上畫一條線：所選的面（或全部）會沿此線切割 |
| {{ui:Spin}} | 以階段方式繞藍色軸旋轉所選的面或開放邊（滾輪設定階數）；旋轉一整圈即會封閉 |
| {{ui:Subdivide}} | 將所選的邊一分為二；整個面會變成格狀 |
| {{ui:Merge}} | 所選頂點會合併為一點，位於其中心 |
| {{ui:Dissolve}} | 移除所選項目但保留表面：面會相連 |
| {{ui:Fill}} | 跨越所選開放邊界（或兩條開放邊之間）的面 |
| {{ui:Grid fill}} | 以四邊形格網填滿邊數為偶數的開放邊界 |
| {{ui:Bridge}} | 以面連接兩個所選的開放邊迴圈 |
| {{ui:Crease}} | 網格以細分曲面平滑時，所選邊保持銳利的程度：遠離中心拖曳、使用滾輪（每階 0.1），或輸入 0 至 1。面板會顯示所選邊的摺痕值，也可輸入數值。摺痕邊會以洋紅色繪製 |
| {{ui:Flip}}、{{ui:Smooth}}、{{ui:Delete}} | 翻轉面；使頂點朝相鄰頂點平滑；依選取模式刪除 |

每項操作都是一個復原步驟。貼圖座標、色彩與權重會延續到新的面與頂點。

## 重新網格化

{{ui:Remesh}}會以大小相同的均勻三角形重新建立整個網格，按下時會要求其大小（數值越小越精細，但速度越慢）。它會封閉孔洞、合併彼此重疊的部分，並平均化經雕刻拉伸的網格。銳利的邊會變得稍微圓滑。UV、上色與摺痕會重新開始。為一個復原步驟。

## 重新拓撲

若要在細緻的網格（雕刻或掃描）上建立新的、較乾淨的網格，請在面板中的{{ui:Retopology}} › **建立於**下選擇細緻的網格，然後：

- **將移動的頂點貼附至其上：**移動的頂點與擠出的邊，會落在其表面上。
- **將所選頂點放到其上**會立即將所選頂點移到其上（一個復原步驟）。
- **將此網格的邊顯示在前方**會將正在建立的網格繪製於表面之上，方便查看。

## 調整上一個操作

在執行{{ui:Inset}}、{{ui:Bevel}}、{{ui:Loop cut}}、{{ui:Subdivide}}、{{ui:Smooth}}、{{ui:Grid fill}}或{{ui:Spin}}之後，面板會顯示其設定（寬度、分段、形狀、切割數等）。變更其中一項後，操作會從起始位置重新執行，且仍為一個復原步驟。
