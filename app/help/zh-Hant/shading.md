在**著色**工作區中建立的材質屬於該檔案。它是一個小型節點圖：由**節點**製作貼圖、圖片與數值，並連結到**材質輸出**，其輸入決定表面的外觀——基底色、粗糙度、金屬度、法線、不透明度、自發光，以及OpenPBR模型的其餘部分。你可以像使用任何程式庫材質一樣為面上色，每項變更都會立即顯示在視圖中。

## 開啟

在工作區清單中選擇{{ui:著色}}。3D視圖保留螢幕上方，**節點編輯器**佔據下方。右側面板列出該檔案自有的材質。

- {{ui:新增材質}}會建立一個灰色材質，只包含材質輸出。
- **建立程式庫材質的可編輯副本**會將磚塊、木材、瓷磚等材質轉為可更改的節點圖：其貼圖透過程式庫貼圖節點引入，其凹凸透過凹凸節點引入。
- {{ui:用它繪製}}會為選取的面或群組上色，或為上色工具挑選材質。上色工具的材質清單也會在**此檔案中**列出該檔案自有的材質。
- {{ui:建立副本}}與{{ui:刪除}}作用於你正在編輯的材質。刪除無法復原：以它上色的面會顯示預設顏色，直到你重新上色為止。

## 程式庫材質

面板中的**材質庫（Library）**列出程式庫的材質，每個都附有由CadCraft路徑追蹤器算圖的預覽。它們是以CC0釋出的貼圖集，並標示其製作者。

- 按一下某個材質即可將它帶入檔案（其圖片會一併帶入），若已選取面或群組，也會為它們上色。
- 將材質拖曳到視圖中的面或群組上，即可只為該處上色。
- 它會成為檔案中的一項材質：可像其他材質一樣更改其節點。其標示來源會顯示在面板中，並保留在檔案內。

## 匯入貼圖集

**匯入貼圖集**下的{{ui:圖片或 zip…}}或{{ui:資料夾…}}會從一組貼圖建立材質。貼圖會依檔名中的字詞判定：color、albedo、diffuse或basecolor（顏色）；roughness（或gloss，會轉換為粗糙度）；metalness或metallic（金屬度）；normal（OpenGL或DirectX，由名稱中的`gl`／`dx`判定）；height或displacement（高度或置換）；ambient occlusion（環境遮蔽）；opacity（不透明度）；emission（自發光）。打包的貼圖（ARM、ORM）會被略過。貼圖磚起始為1 × 1 m：請在材質輸出上設定其實際尺寸。高度貼圖會接到置換，其比例為0——提高比例才能用於網格。

## MaterialX

MaterialX是其他3D與算圖程式用來傳遞材質的開放格式。

- {{ui:匯出為 MaterialX…}}會儲存你正在編輯的材質：其數值，以及每張貼圖（以PNG圖片形式，與`.mtlx`檔並存，包在zip中）。請選擇它寫入的著色器：**OpenPBR Surface**（MaterialX 1.39，與ModelCraft使用的模型相同）或**Standard Surface**（MaterialX 1.38，目前有較多程式可讀取）。貼圖依公尺為單位的UV座標放置；方塊與三平面投影會寫為UV。
- {{ui:匯入 MaterialX…}}（或{{ui:從資料夾…}}）會讀取具有OpenPBR、Standard Surface、UsdPreviewSurface或glTF PBR著色器的`.mtlx`檔。也請一併提供圖片，或包含所有內容的zip：圖片依其路徑、名稱，或以另一種圖片類型的名稱找到（例如，檔名為`.exr`的圖片可由旁邊的`.jpg`代替）。貼圖、法線貼圖、算術運算、混合與置換會以節點形式匯入；其他項目則保留其數值，狀態列會說明哪些項目被略過。

## 貼花

貼花是鋪在表面上的一張圖片——例如標誌、招牌、標籤或污漬——並擁有自己的材質。

- 設定**新貼花的寬度**，然後使用{{ui:放置貼花…}}（或工具列上的{{ui:貼花}}），選擇PNG、JPEG或WebP圖片，並按一下面。圖片會投影到該處的表面上並保持比例；PNG的透明部分仍保持透明。
- 它屬於你按一下的群組或元件，並隨之移動。它會覆蓋其框內朝向相同方向的面，並止於其所在表面的邊緣。
- 每個貼花都有自己的材質，在檔案的清單中命名為**Decal: <picture>**：可像其他材質一樣編輯（粗糙度、凹凸、發光）。貼花旁的{{ui:材質}}會開啟它。
- 每個貼花旁邊有：寬度（高度依圖片比例）、{{ui:旋轉}}（轉四分之一圈）與{{ui:刪除}}。貼花與檔案的材質一同保存，且不在復原範圍內。
- 它們會顯示在著色視圖、快速算圖與高品質圖片中。

## 在貼圖上繪製

{{ui:繪製紋理}}（或**在貼圖上繪製**下的{{ui:上色}}）會將指標變成圓形筆刷。在披有此檔案某個材質的面上拖曳：筆刷會繪製基底色後方的圖片。

- 在網格上，會沿網格的UV繪製（請先在UV工作區展開）；在其他面上，則會橫跨該面繪製，因此繪製內容會隨材質的貼圖磚重複。
- 基底色為單一顏色的材質，第一次繪製時會取得一張該顏色的新512 × 512圖片。基底色來自其他節點的材質，則需要一個連結到基底色的圖片節點。
- 在面板中設定筆刷顏色、大小（以圖片像素計）、強度與硬度。{{ui:復原筆劃}}或Ctrl+Z（繪製時）可收回一筆，最多可還原20筆。
- 繪製的圖片會儲存在檔案中。程式庫材質無法繪製：請先建立可編輯的副本。

## 烘焙貼圖

**烘焙貼圖**會將形狀與場景對表面的影響寫入沿網格UV的圖片。

- 選取具有UV的網格（請先在UV工作區展開），勾選要的貼圖，然後按{{ui:烘焙}}：
  - **環境遮蔽**——每個點的開闊程度：角落、折痕與其他物件下方的位置會變暗。模型中顯示的所有東西都會使其變暗，範圍至遮蔽距離為止。
  - **曲率**——外側邊緣發亮，內側角落變暗，平坦與微曲的部分為中灰，邊寬依你設定的值而定。
  - **高細節物件的法線**——同時選取一個細節版本：其表面細節會寫成簡化物件的法線貼圖（烘焙到三角形較少的物件上）。搜尋距離是兩個表面可相距的最遠距離。
  - **光照**——模型所在位置與日期（樣式）的太陽及其陰影，加上天空，寫成光照貼圖。
- 圖片會加入檔案，並出現在圖片節點中。若你正在編輯的材質有**髒污與邊緣磨損**節點，它會立即讀取新的遮蔽與曲率。
- 每個紋素的光線越多，遮蔽與光照越平滑，但耗時越長。烘焙會在背景中使用電腦的處理器核心執行；{{ui:停止烘焙}}可將其停止。

## 建立節點圖

1. {{ui:加入節點…}}（或在節點編輯器中按{{key:Shift+A}}）會在編輯器中央加入一個節點。
2. 從輸出點（節點右側）拖曳到輸入點（節點左側）即可連結。對同一輸入再次連結會取代第一個連結；拖曳已連結的輸入即可取消連結。
3. 未連結的輸入會顯示其數值：輸入數字或選擇顏色。設定位於每個節點的底部。

拖曳節點標題即可移動它，拖曳空白處可平移，並以滾輪縮放。{{key:Delete}}會移除選取的節點或連結，{{key:Mod+Z}}復原，{{key:Mod+D}}建立副本，{{key:F}}顯示所有節點。每項變更都是節點編輯器的一個復原步驟。模型本身的復原不會改變材質。

| 節點 | 產生的內容 |
|---|---|
| 紋理座標 | 點在貼圖磚上的位置：重複、偏移、旋轉四分之一圈。 |
| 數值、顏色 | 一個數字、一種顏色。 |
| 圖片 | 檔案中的一張圖片（隨匯入模型而來的圖片，或以{{ui:加入圖片…}}加入的圖片）。照片請選擇**顏色**，粗糙度或法線貼圖請選擇**資料**。 |
| 程式庫貼圖 | 程式庫材質的貼圖、粗糙度與高度。 |
| 棋盤、雜訊 | 方格；平滑的分形雜訊，可設定其細節、粗糙度與種子。 |
| Voronoi單元、波紋、漸層 | 單元（到最近點的距離、單元之間的邊緣，每個單元一種顏色）；橫向、縱向或對角的條紋，可為正弦、鋸齒或三角形，並以雜訊彎曲；線性、二次、放射與球面漸層。 |
| 磚塊、瓷磚 | 有錯位偏移的磚列，或瓷磚格網：顏色、灰漿或填縫材料、以公尺為單位的間隙與倒角、凹凸高度、每片的隨機數。 |
| 木材、大理石 | 沿紋理的年輪與細纖維；受亂流彎曲的紋路。 |
| 髒污與邊緣磨損 | 依網格的曲率與遮蔽圖片，磨損凸出的邊緣並弄髒凹陷處（[烘焙貼圖](topic:shading#bake-textures)會產生它們；或於網格的UV配置中設定其兩項圖片設定：以UV座標放置材質）。沒有它們則不會改變任何東西。 |
| 混合顏色、色彩漸層、色相/飽和度/明度、亮度與對比、反相、Gamma、分離與合併RGB | 顏色處理。 |
| 數學、範圍對應 | 數字的算術（加、乘、次方、平滑階梯等）。 |
| 凹凸、法線貼圖 | 由高度產生的法線（凹凸），或由法線貼圖圖片產生的法線（法線貼圖：選擇綠色通道的方向）。 |

## 材質輸出

其設定說明貼圖如何鋪在表面上：

- **貼圖磚寬度**與**貼圖磚高度**：一個貼圖磚涵蓋多少公尺。節點圖產生的所有內容都會在貼圖磚內無縫重複。
- **放置方式**：**UV座標**沿面跟隨（推拉的面：沿每個面；網格：其UV，一個UV單位等於一個貼圖磚），**方塊**從三個軸中最近的一軸投影，**三平面**在傾斜的表面上混合三個投影（**混合銳利度**：數值越高，混合越硬）。
- **法線強度**會縮放法線輸入。**置換比例**設定置換輸入使網格頂點移動的距離。
- {{ui:更多輸入}}會顯示其餘的OpenPBR輸入：塗層、絨毛、次表面、薄膜、穿透，以及它們的顏色。

## 在高品質圖片中

路徑追蹤器會從節點圖讀取基底色、粗糙度、金屬度、不透明度、法線與自發光，並隨表面變化。你連結的任何其他輸入（例如變化的塗層）都會以其平均值使用；面板會說明哪些項目如此。不透明度貼圖的鏤空會顯示其形狀，其陰影則均勻透光。發光的貼圖會照亮它所朝向的物件，但不會被當作光源取樣。

**置換**只會移動網格的頂點，因此請加入細分修飾器以獲得細節（[修飾器](topic:modifiers)）。推拉的面會保持其形狀，並由法線取得凹凸。

:::tip
在具有WebGPU的電腦上，節點圖會在顯示卡上計算；沒有WebGPU時則在處理器上計算。結果相同。
:::
