貼圖是平面的圖片，網格則不是平面。它的 **UV** 記錄每個面的每個角落在圖片上的位置。UV 工作區負責產生這些座標：沿著 **接縫** 將網格剖開，把各部分攤平（**展開**），再將它們放入正方形中（**排列**）。

## 開啟

選取網格，然後在{{ui:工作區}}清單中選擇 {{ui:UV}}。群組或元件會先轉換為網格，與網格工作區的做法相同。3D 視圖會移至左半部；右側的 **UV 編輯器** 會顯示網格的面在貼圖正方形上展開的結果。選取方式與網格工作區相同，且在其中一個視圖中選取的內容，會同時在另一個視圖中被選取。

## 標記接縫

接縫是網格可以被剖開的位置；兩個視圖中都會以紅色顯示。

- 選取邊（{{ui:邊}}，或 {{key:2}}），然後按下 {{ui:標記接縫}}（{{key:Ctrl+E}}）。{{ui:清除接縫}}（{{key:Ctrl+Shift+E}}）會將其移除。
- {{ui:銳角處接縫}} 會標記每一條銳利的邊，以及面與面夾角超過 60° 的每一條邊：方盒會被分成六個側面。
- {{ui:依UV產生接縫}} 會在 UV 已經斷開的位置標記接縫，例如投影之後。

封閉的部分需要接縫才能攤平：球體至少需要一道切割，管狀物則需要沿其長度切割一道。

## 展開

選取要攤平的面（若要處理整個網格，則不選取任何面），然後按下 {{ui:展開}}（{{key:U}}）。接縫之間的每個部分都會被攤平，並盡可能保持其角度正確（角度基準攤平），接著再將各部分排入正方形中。{{ui:保角}} 則改用最小平方保角映射進行展開：速度較快，但在曲率較大的部分會稍微不夠精確。可以由一張平面板材製成的形狀（例如圓柱側面只切一刀）展開後完全沒有拉伸。

## 投影

對於簡單的形狀，投影通常就已足夠：

| 投影 | 功能 |
| --- | --- |
| {{ui:方盒}} | 每個面投影到其朝向最多的方盒側面 |
| {{ui:圓柱}} | 繞藍色軸投影：橫向為圓周角度，縱向為高度 |
| {{ui:球面}} | 由中心投影：橫向為圓周角度，縱向為緯度 |
| {{ui:依視圖}} | 依目前 3D 視圖中所見的面投影 |

跨越圓柱或球面接合處的面會保持為一個整體，因此其 UV 可能會稍微超出正方形的右邊緣；貼圖在該處會重複。

## 排列

- {{ui:排列}} 會以相同的紋素大小，將各部分（島狀區塊）放入正方形中，並旋轉每個部分以占用最少空間。面板會設定它們之間保留的間距。
- {{ui:旋轉90°}} 與 {{ui:鏡射}} 會旋轉或鏡射所選面的 UV。
- 在 UV 編輯器中，拖曳所選面即可移動所選範圍的 UV；或將指標移至編輯器上，按下 {{key:R}} 或 {{key:S}}，再移動即可旋轉或縮放（點一下即保留，{{key:Esc}} 則取消）。{{key:G}} 可不拖曳直接移動。按兩下某個面（或按 {{key:L}}）即可選取其整個島狀區塊。滾輪用於縮放；以中鍵或右鍵拖曳可平移；{{key:F}} 會讓正方形再次符合視窗。

每個變更都是一個復原步驟。

## 檢查

- {{ui:棋盤格}} 會以其 UV 在網格上顯示帶標籤的棋盤格：方格均勻且呈正方形，表示貼圖分布均勻；標籤則顯示貼圖的方向。
- {{ui:拉伸}} 依各面的 UV 拉伸程度為其上色：藍色表示無拉伸，經綠色，至紅色表示拉伸嚴重。面板可選擇要以 **角度彎曲** 或 **尺寸變化** 來衡量，並顯示平均值。
