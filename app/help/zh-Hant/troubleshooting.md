## 3D 視圖是空白的

**症狀：**畫面中央保持空白，或只顯示背景色，點選工具也沒有反應。

**原因：**ModelCraft 使用 WebGL 2（瀏覽器的 3D 圖形功能）繪圖。當瀏覽器過舊、硬體加速被關閉，或圖形驅動程式被封鎖時，就會缺少 WebGL 2。

**修正方法：**

:::chromium
1. 開啟瀏覽器的設定，搜尋「圖形加速」。
2. 開啟「在可用時使用圖形加速」，然後重新啟動瀏覽器。
3. 若已開啟，請在網址列輸入`chrome://gpu`（Edge 則為`edge://gpu`），並在列表中找到「WebGL2」。若顯示為已停用，請更新圖形驅動程式。
:::

:::firefox
1. 開啟**設定**，然後是**一般**，並捲動至「效能」。
2. 取消勾選「使用建議的效能設定」，然後勾選「可用時使用硬體加速」。重新啟動 Firefox。
3. 若仍然失敗，請在網址列輸入`about:support`，並在「圖形」區段中查看 WebGL 2。
:::

:::safari
更新 macOS 和 Safari。較新版本的 Safari 一律會開啟 WebGL 2。若你曾在**Safari**、**設定**、**進階**（或**功能旗標**）中變更過實驗性功能，請將其重設。
:::

在公司電腦、遠端桌面或虛擬機器上，3D 圖形可能因政策而被封鎖。請嘗試其他電腦。參見[瀏覽器與電腦](common:browsers)。

## 按鍵無反應，或輸入到文字框中

**原因：**鍵盤焦點位於面板欄位中：{{ui:樣式}}中的{{ui:面}}清單、太陽設定、{{ui:實體資訊}}中的{{ui:名稱}}欄位，或單位選擇器。字母和方向鍵會因此輸入到該欄位中。

**修正方法：**在 3D 視圖中按一下，然後再按一次按鍵。對話方塊開啟時，按鍵同樣不會有反應。

## 輸入數字沒有反應

- **尚無方向。**輸入的長度會沿著第一次按一下後指標所指的方向前進。請將指標稍微移向所需方向，然後再輸入。
- **時機不對。**大多數工具需在第一次按一下後才接受輸入的值：先按一下第一個角點、面或要移動起點的點。{{ui:圓}}和{{ui:多邊形}}會在第一次按一下前接受邊數。
- **「請輸入長度，例如3m、10'6"或4m,3m。」**ModelCraft無法讀取。請檢查是否使用了小數逗號（`2,5`）：請改用小數點。

## 在觸控螢幕上形狀從錯誤的位置開始

**症狀：**以手指操作時，第一個矩形正常，但下一個矩形、圓或直線會從你上一次觸控結束的位置開始，而非你觸控的位置。

**原因：**此版本的錯誤：在觸控螢幕上，工具會記住上一次手勢的最後一個鎖點。

**修正方法：**每次繪製新形狀前，請再輕觸一次工具列上的工具按鈕。這會重新啟動工具，第一個點就會落在你觸控的位置。

## 編輯一個群組時，另一個也跟著變更

**症狀：**你用{{ui:移動}}加{{key:Ctrl}}複製了一個群組，打開其中一個副本並進行編輯，另一個副本也跟著變了。{{ui:大綱}}中兩者都顯示相同的名稱。

**原因：**在此版本中，複製群組會建立同一群組的第二個放置，如同元件一樣。ModelCraft的{{ui:獨立化}}按鈕只會出現在元件上。

**修正方法：**選取要變更的副本，在{{ui:實體資訊}}中按一下{{ui:建立元件}}，然後按一下{{ui:獨立化}}。該副本即會擁有自己的內容。或者將它{{ui:分解}}。

## 推拉的結果與預期不同

- **「推拉作用於面。請按一下面。」**你按到的是邊線或空白處。請將指標移動至面反白後再按一下。
- **面位於群組內。**請先按兩下群組以開啟它。
- **視窗沒有切穿牆面。**矩形必須畫在牆的面上，而非其前方，且牆必須有背面。參見[在牆上切出開口](topic:openings#if-it-did-not-cut-through)。
- **兩個方塊重疊但未合併。**在此版本中，互相推入的實體不會彼此切割或結合。

## 線條或形狀未形成面

只有當邊線封閉成一個平面迴圈時，面才會填滿。請確認最後一點有鎖定到第一點（「端點」），並確認所有邊線位於同一平面上。略微偏離平面的迴圈會保持為線條。請在角點上鎖點，重新繪製其中一條邊。

## 無法選取或刪除面

- 使用{{ui:選取}}時，若按一下靠近邊線處，會選到邊線。請按在面的中央附近。
- {{ui:橡皮擦}}不會選取面。請選取面並按{{key:Delete}}，或刪除其中一條邊線。
- 若面屬於群組或元件，按一下會選取整個物件。請按兩下以開啟。

## 「請先選取要移動的項目，或按一下該項目。」

{{ui:移動}}、{{ui:旋轉}}和{{ui:縮放}}需要有可作用的對象：請先選取它，或在項目本身上（而非空白處或輔助線）按一下以啟動工具。

## 「請先選取一些幾何圖形（拖曳框選，或按三下以選取所有相連的項目）。」

{{key:G}}和{{key:Shift+G}}需要先有選取的項目。輔助線無法群組。

## 方向鍵會環繞而非鎖定

鎖定只會在繪圖或編輯工具的第一次按一下之後生效。{{ui:推拉}}沒有鎖定功能，而在{{ui:旋轉}}中，方向鍵不會改變旋轉角度。其他時候，方向鍵會環繞視圖。

## 全螢幕中按 Esc

在全螢幕中，瀏覽器可能會以第一次{{key:Esc}}離開全螢幕。請再按一次{{key:Esc}}以取消工具。

## 沒有中鍵

按{{key:O}}切換至{{ui:環繞}}後拖曳，或使用方向鍵。參見[環繞、平移與縮放](topic:orbit-pan-zoom#without-a-middle-button)。

## 匯入

| 訊息 | 處理方式 |
|---|---|
| 「ModelCraft可匯入SketchUp (.skp)、Collada (.dae)、OBJ、glTF (.glb/.gltf)、FBX、PLY、STL、Alembic (.abc)、DWG和DXF。……不屬於這些格式。」 | 請從其他程式將模型匯出為以上其中一種格式 |
| 「此檔案超過 300 MB。」 | 在其他程式中簡化或分割模型 |
| 「……大到無法在此建模（超過 200 萬個頂點）。」 | 同上 |
| 「此.gltf檔案需要「……」……」 | 將`.gltf`連同其`.bin`和貼圖檔一起放入，或開啟`.glb`版本 |
| 「此glTF檔案需要……擴充功能，而ModelCraft尚不支援讀取。」 | 從其他程式重新匯出，不使用該擴充功能（例如 KTX2 貼圖） |
| OBJ匯入後沒有顏色或貼圖 | 將`.obj`連同其`.mtl`和圖片一起放入 |
| 「此Alembic檔案使用舊的HDF5格式……」 | 從其他程式另存為 Ogawa Alembic 檔案 |
| FBX匯入後沒有貼圖 | 將`.fbx`連同其貼圖圖片一起放入，或在匯出時嵌入媒體 |
| 「此FBX檔案為版本……，ModelCraft不支援讀取」 | 重新匯出為 FBX 2011 或更新版本 |
| STL或PLY匯入後大了或小了 1,000 倍 | STL以毫米讀取，PLY以公尺讀取：請縮放它（參見[旋轉與縮放](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)） |
| 「這不是Collada (.dae)檔案……」或「……不是格式正確的XML……」 | 檔案已損壞或不是 Collada。請重新匯出 |
| 「此Collada檔案沒有ModelCraft可匯入的幾何。」 | 它只包含攝影機、燈光或指向其他檔案的參照 |
| 「這是二進位DXF。請將其另存為ASCII DXF後再試一次。」 | 請從 CAD 程式重新另存為 ASCII |
| 「這不是DWG圖形……」 | 檔案不是 DWG，或已損壞 |
| 「無法讀取此圖形（……）。它可能已損壞，或以讀取器無法處理的 DWG 版本儲存……」 | 括號內為原因。請從 CAD 程式另存為 DXF，或另存為 AutoCAD 2000至2018的 DWG |
| 「此圖形距離其原點超過10,000 km……」 | 請在 CAD 程式中將圖形移近0,0 |

### 匯入的尺寸錯誤或橫躺

- **OBJ：**OBJ 沒有單位；ModelCraft以公尺讀取。毫米模型會被匯入成大 1000 倍：請以`0.001`[縮放](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)它；英吋模型則以`0.0254`縮放。
- **OBJ橫躺：**ModelCraft預期 OBJ 檔案為 Y 軸向上。Z 軸向上寫出的檔案會橫躺匯入。請沿紅色軸旋轉 90°：在朝向紅色軸的面上按一下{{ui:旋轉}}的中心，或在其原始程式中開啟檔案，並以 Y 軸向上匯出。
- **DWG或DXF：**你在「圖形單位」對話方塊中選錯了單位。請復原後重新匯入。

## 我遺失了工作

ModelCraft不會自動儲存到檔案。當你關閉或重新載入有未儲存變更的分頁時，瀏覽器會先詢問（「要離開此網站嗎？」或「要重新載入此網站嗎？」）；請選擇留下並儲存。{{ui:新增}}和{{ui:開啟}}也會詢問（「尚未儲存的變更」）。若瀏覽器或電腦當機，請在同一瀏覽器中重新開啟ModelCraft：它會提供未儲存的工作（「復原尚未儲存的內容？」；參見[復原尚未儲存的內容](common:recover)）。請經常使用{{key:Mod+S}}儲存。

## 我的下載資料夾充滿副本

每次儲存都會成為一次新的下載，名稱為`Untitled (1).modelcraft`、`Untitled (2).modelcraft`，依此類推。請刪除舊檔，或將瀏覽器設定為每次儲存時詢問儲存位置，並自行覆寫舊檔。參見[開啟、儲存、匯入與匯出](topic:files#save-a-model)。

## 運作變慢

- 復原的每一步都會保留一份模型副本（[網格](topic:meshes)只保留變更的部分），因此在非常大的推拉幾何匯入中，每次編輯都會花更長時間。請分解或刪除不需要的項目、儲存後重新開啟：重新開啟也會清除復原歷程。
- 日照陰影最耗費效能。建模時請取消勾選{{ui:日照陰影}}。

## 沒有陰影

{{ui:日照陰影}}未開啟，或你所選時間的太陽已落下（「此時太陽位於地平線下。」），或樣式為{{ui:線框}}（線框不繪製陰影）。

## 「此瀏覽器不允許全螢幕。」

部分瀏覽器和部分嵌入式檢視不允許全螢幕。請改用瀏覽器本身的全螢幕功能（{{pick:mac=Control-Command-F|windows linux=F11}}）。

## 沒有連線時 ModelCraft 無法開啟

ModelCraft只有在該瀏覽器中已儲存供離線使用後，才能離線開啟：應用程式列上的按鈕必須顯示{{ui:可離線使用}}。請在連線時開啟，然後按一下{{ui:儲存供離線使用}}。若按鈕顯示{{ui:無法儲存}}，請在較佳的連線下再按一次。{{ui:無法離線使用}}表示此視窗（私密視窗或受管理的電腦）無法保留副本。參見[離線工作](common:offline)。
