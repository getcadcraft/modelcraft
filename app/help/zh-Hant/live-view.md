{{ui:Export}} › {{ui:Live view}}會在應用程式上方開啟一個面板，以即時算圖的外觀顯示模型：依模型所在位置與日期的天空與太陽、太陽產生的陰影、為表面設定的外觀與材質、燈，以及從牆面與地板反彈的光線。它會跟隨你的操作：旋轉視圖時它也會旋轉，變更模型時會在稍後顯示變更。不會上傳任何內容。

## 開啟

1. 選擇{{ui:Export}} › {{ui:Live view}}。面板會在右下角開啟。
2. 拖曳其標題列可移動面板，拉動其角落可放大。
3. {{ui:New window}}會將面板移到獨立的視窗，方便用於第二個螢幕。{{ui:Export}} › {{ui:Live view in a new window}}會直接在新視窗中開啟。若瀏覽器封鎖彈出式視窗，則會以面板開啟。
4. {{ui:Close}}會將其關閉。

## 控制項

| 控制項 | 作用 |
|---|---|
| {{ui:Follow the view}} | 開啟時，即時檢視會朝向 ModelCraft 視圖的方向。漫遊時會自動關閉 |
| {{ui:Walk}} | 在模型中漫遊（見下文） |
| {{ui:Gravity}} | 漫遊時：站在地板上並爬樓梯。關閉時：飛行 |
| {{ui:Time}} | 一天中的時段，從 05:00 到 21:00。拖曳時太陽會移動 |
| {{ui:Month}} | 月份（以該月 21 日為準），可查看冬季與夏季的太陽 |
| {{ui:Quality}} | {{ui:For this computer}}（依[此電腦](topic:your-machine)的等級），或{{ui:Low}}、{{ui:Medium}}或{{ui:High}} |

底部的一行會顯示繪製視圖的方式（WebGPU 或 WebGL 2）、品質，以及反彈光。

## 在模型中漫遊

1. 將主視圖轉到想站立的位置，然後選擇{{ui:Walk}}。站立點位於視圖眼點下方的地板上，身高 1.6 m。
2. 在即時檢視中按一下，然後使用{{key:W}} {{key:A}} {{key:S}} {{key:D}}或方向鍵。按住{{key:Shift}}可奔跑。拖曳可環顧四周。
3. 高度不超過 40 cm 的台階可以爬上（樓梯）；更高的則視為牆。遇到牆時會停止，並沿牆面滑動。
4. 關閉{{ui:Gravity}}時可飛行：{{key:E}}上升，{{key:Q}}下降。
5. {{key:Esc}}可停止漫遊。

## 散佈植物、岩石與人物

即時檢視工具列中的{{ui:Scatter}}會在畫面旁開啟散佈面板。散佈集會將配景程式庫中的項目（樹木、灌木、草、花、岩石、人物、汽車）散佈到模型的部分區域。這些項目只在即時檢視中繪製：它們不是模型中的幾何，主視圖也不會顯示。

1. **填入表面：**在 ModelCraft 中選取表面（或群組，例如地形），然後選擇{{ui:Fill selection}}。散佈集會覆蓋這些表面。
2. **上色：**選擇{{ui:Paint}}，然後在即時檢視上拖曳。選取表面時，顏色只會落在這些表面上；未選取任何項目時，會落在筆刷下方的所有物件上，包括地面。{{ui:Brush size}}設定筆刷大小；{{ui:Eraser}}會清除已上色的區域。
3. 勾選要散佈的項目。每個項目旁的數字是其權重：3 與 1 表示第一種每出現三個，第二種就出現一個。

| 控制項 | 作用 |
|---|---|
| {{ui:Per m²}} | 每平方公尺上的項目數量 |
| {{ui:Keep away (m)}} | 與其他物件的距離不小於此值，且不會放在屋頂或桌子下方。0 表示關閉 |
| {{ui:Turn (°)}} | 每個項目繞垂直軸隨機旋轉的角度 |
| {{ui:Steepest (°)}} | 表面坡度超過此值的地方不放置項目 |
| {{ui:Size}} | 最小與最大尺寸，為項目本身尺寸的倍數 |
| {{ui:Height from, to (m)}} | 僅限於這些高度之間（留空 = 任意高度） |
| {{ui:Lean with the surface}} | 0 讓項目保持直立；1 讓項目與坡面垂直 |
| {{ui:Seed}}、{{ui:Shuffle}} | 相同的種子值一律產生相同的散佈；{{ui:Shuffle}}會產生另一組 |

散佈集會儲存在 .modelcraft 檔案中，變更時會跟隨其所覆蓋的表面。即時檢視最多會繪製多少項目，取決於[此電腦](topic:your-machine)的等級：{{ui:Processor only}}為20 000個，{{ui:Graphics card, basic}}為100 000個，{{ui:Graphics card, high}}為一百萬個。面板會顯示已放置的數量與密度要求的數量：達到上限時，或因物件排除而無法放置時，放置的數量會較少。靠近攝影機的項目會以實際外形繪製；較遠的項目則以其顏色的簡單形狀繪製。

:::note
散佈的項目會出現在即時檢視中（以及其漫遊、全景與獨立檢視器）。算出圖片目前尚未繪製這些項目。
:::

## 共用：全景、導覽、檢視器與影片

即時檢視工具列中的{{ui:Share}}會從即時檢視產生檔案。所有內容都在此電腦上產生；不會上傳任何內容。

| 選項 | 取得的內容 |
|---|---|
| {{ui:360° panorama}} | 從視圖所在位置（或漫遊位置）產生的 360° 圖片，為等距長方形 PNG，全景檢視器與多數照片網站都能開啟 |
| {{ui:Add this spot to the tour}}，接著{{ui:Save the tour}} | 一個網頁，每個位置都有全景，並有箭頭指向每個位置可看到的其他位置（中間有牆時會隱藏箭頭） |
| {{ui:Save a viewer}} | 一個網頁，以此即時外觀呈現模型：可旋轉、漫遊，並跳至已儲存的場景。可在支援 WebGPU 或 WebGL 2 的瀏覽器中離線開啟，可從資料夾、USB 隨身碟或電子郵件開啟，無需安裝，也無需帳戶，且不會從網際網路載入任何內容 |
| {{ui:Video of the path}} | 時間軸上的攝影機路徑（或依序排列的已儲存場景）會以此即時外觀製作成影片，尺寸與即時檢視相同：瀏覽器可產生時為 WebM 或 MP4，否則為 ZIP 內編號的圖片 |

全景的尺寸取決於品質：在{{ui:Low}}、{{ui:Medium}}與{{ui:High}}下，寬度分別為1024、2048或4096像素。檢視器檔案約為 5 MB，另加模型的大小。

:::note
導覽與檢視器用於展示，而非編輯：儲存時會保留模型當時的狀態。
:::

## 反彈光

從受陽光照射的牆面反彈到地板上的光線，以及房間較暗的內部，是由製作[算出的圖片](topic:render)所用的同一路徑追蹤器計算。它會在模型中的各點算出小型全景，並在每個處理器核心的背景中執行。運作期間，底部一行會顯示{{ui:反彈光：40 %}}；完成後，視圖即會納入這些光線。變更後會重新開始。

:::note
這是即時檢視的近似結果，並非算出的圖片：各點之間的細節會採用鄰近各點的反彈光。成品圖片請使用[算出圖片](topic:render)。
:::

## 亮度與色彩

即時檢視使用與[算出圖片](topic:render)相同的亮度、白平衡、對比與視圖轉換（ACES、AgX、電影感或標準）：在該處設定後，即時檢視便會跟隨。

:::note
各瀏覽器有所不同。若瀏覽器支援 WebGPU（Windows、macOS 與 ChromeOS 上的 Chrome 與 Edge，以及 Safari 26），即時檢視會使用 WebGPU；其他情況（Linux 上的多數瀏覽器、較舊的 Apple 系統）則使用 WebGL 2，外觀相同。
:::
