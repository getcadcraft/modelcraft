{{ui:選取}}（{{key:Space}}）是ModelCraft一開始使用的工具，按{{key:Esc}}會回到它。被選取的東西會變成藍色，右側的{{ui:實體資訊}}會說明它們是什麼。

## 按一下

| 操作 | 選取範圍 |
|---|---|
| 按一下面或邊 | 該面或該邊 |
| 按一下群組或元件 | 整個群組或元件 |
| 連按兩下面 | 該面與它的邊 |
| 連按兩下邊 | 該邊與兩側的面 |
| 連按兩下群組或元件 | 開啟以供編輯（見[群組與元件](topic:groups-components)） |
| 連按三下面或邊 | 與它相連的所有東西：整個物件 |
| 按一下空白處 | 沒有任何東西（清除選取） |
| 在編輯群組時連按兩下空白處 | 關閉群組 |

邊比面容易點到：當指標位於邊的幾個像素範圍內時，按一下會選取邊。

## 拖曳方框

- **由左至右**會畫出實線方框：即**視窗**選取。只有完全位於框內的東西會被選取。
- **由右至左**會畫出虛線方框：即**交叉**選取。方框碰到的東西都會被選取；當方框完全位於某個面之內時，該面即會被選取。

群組或元件視為一個整體：視窗必須完整包住它，交叉選取只需碰到即可。

## 加入與移除

在按一下或拖曳時按住按鍵：

| 按鍵 | 效果 |
|---|---|
| {{key:Shift}} | 切換：加入未被選取的東西，移除已被選取的東西 |
| {{key:Mod}} | 加入 |
| {{key:Shift}}與{{key:Mod}}一起 | 移除 |

若要選取模型中的所有東西（或正在編輯的群組中的所有東西），請按{{key:Mod+A}}。

## 清除選取

按{{key:Esc}}（且工具為{{ui:選取}}），或按一下空白處。

## 刪除選取的物件

按{{key:Delete}}或{{key:Backspace}}。選取中的面、邊、群組與輔助線會在一個步驟中全部移除；按{{key:Mod+Z}}即可將它們復原。

刪除邊時，會移除需要該邊的面，除非該邊只分隔同一平面上的兩個面：此時這兩個面會合併為一個。刪除面時會保留它的邊。見[刪除與清理](topic:erase)。

## 在群組內選取

按一下群組會選取整個群組。若要選取其中的面，請連按兩下群組以開啟它，然後再按一下。群組開啟時，按一下只會作用於其內部的東西，其他東西會淡化。在沒有選取任何東西時按{{key:Esc}}，或連按兩下空白處，即可關閉群組。

左側的{{ui:大綱}}可依名稱選取群組與元件，當它們被其他物件遮住時特別有用。
