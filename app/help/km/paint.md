ពណ៌ជួយឲ្យអ្នកបែងចែកផ្នែកនានានៃម៉ូដែល ហើយ**សម្ភារៈ** (ឥដ្ឋ ផ្ទាំងជញ្ជាំង ក្បឿងដំបូល ឈើ ថ្ម ក្បឿង បេតុង ស្ដាកូ ស្មៅ កញ្ចក់ លោហៈ) ធ្វើឲ្យវាមើលទៅដូចជាអ្វីដែលវាត្រូវបានសាងសង់ពី។ ទាំងពីរលាបតាមរបៀបដូចគ្នា។

## ជ្រើសរើសពណ៌

ផ្នែក {{ui:Colors}} នៅខាងស្ដាំបង្ហាញជួរពណ៌រឹង {{ui:Default}} (ដែលមានបន្ទាត់ឆ្លងកាត់៖ គ្មានពណ៌) និងប្រអប់ {{ui:+}} សម្រាប់ពណ៌ផ្សេងទៀតណាមួយ។ ចុចមួយដើម្បីធ្វើឲ្យវាជាពណ៌បច្ចុប្បន្ន។ ឧបករណ៍លាបចាប់ផ្ដើមជាមួយវា។

## លាប

1. ចុច {{key:B}} ({{ui:Paint}}) ឬ នៅពេលមិនបានជ្រើសរើសអ្វីសោះ ចុចពណ៌មួយ។ (នៅពេលមានអ្វីមួយត្រូវបានជ្រើសរើស ការចុចពណ៌នឹងលាបការជ្រើសរើសភ្លាមៗ។)
2. ចុចផ្ទៃមួយដើម្បីលាបវា។
3. ចុចក្រុម ឬសមាសភាគមួយដើម្បីលាបច្បាប់ចម្លងនោះ៖ ផ្ទៃរបស់វាដែលមិនមានពណ៌ផ្ទាល់ខ្លួននឹងទទួលពណ៌នេះ។ ផ្ទៃដែលអ្នកលាបនៅខាងក្នុងវានៅតែរក្សាពណ៌របស់វា។

ដើម្បីលាបវត្ថុជាច្រើនក្នុងពេលតែមួយ សូមជ្រើសរើសវាជាមុនសិន ហើយបន្ទាប់មកចុចពណ៌មួយ ឬចុចវត្ថុណាមួយនៃវាជាមួយ {{ui:Paint}}។ វាជាជំហានមិនធ្វើវិញតែមួយ។

| សង្កត់ | ហើយចុចលើផ្ទៃ | អ្វីដែលត្រូវបានលាប |
|---|---|---|
| — | | ផ្ទៃនោះ |
| {{key:Ctrl}} | | ផ្ទៃទាំងអស់ដែលភ្ជាប់ទៅវា ហើយមានពណ៌ដូចគ្នា |
| {{key:Shift}} | | ផ្ទៃទាំងអស់នៃពណ៌នោះ ក្នុងក្រុមដែលអ្នកកំពុងធ្វើការ |
| {{key:Alt}} | | គ្មានអ្វីទេ៖ អ្នកយកពណ៌នោះមកវិញជំនួសវិញ |

ដើម្បីយកផ្ទៃមួយទៅជាគ្មានពណ៌ សូមជ្រើសរើស {{ui:Default}} ហើយចុចវា។

## លាបជាមួយសម្ភារៈ

ផ្នែក {{ui:Materials}} នៅក្រោម {{ui:Colors}} បញ្ជីបណ្ណាល័យសម្ភារៈតាមប្រភេទ៖ ឥដ្ឋ និងប្លុក ផ្ទាំងជញ្ជាំង ក្បឿងដំបូល ឈើ ថ្ម ក្បឿង បេតុង ស្ដាកូ ដី កញ្ចក់ និងលោហៈ។ ដាក់កណ្ដុរលើគំរូមួយដើម្បីមើលឈ្មោះរបស់វា។ ចុចមួយ បន្ទាប់មកលាបវាដូចជាពណ៌ដែរ៖ {{key:B}} ចុចផ្ទៃ ក្រុម ឬសមាសភាគ; ឬជ្រើសរើសជាមុន ហើយចុចសម្ភារៈ។

- នៅរចនាប័ទ្ម **Shaded** ផ្ទៃបង្ហាញទម្រង់របស់សម្ភារៈ។ ការបន្ទាត់លាក់ ក្របខ័ណ្ឌ និង X-ray បង្ហាញពណ៌របស់វា។
- ទម្រង់ដាក់ **ដេកដោយផ្ដេកតាមផ្ទៃនីមួយៗ** និង**ឡើងលើ**៖ ជួរឥដ្ឋនៅតែដេកដោយផ្ដេកលើជញ្ជាំងគ្រប់ទាំងអស់ ក្បឿងរត់ចុះតាមជម្រាលដំបូល ក្ដារលើកម្រាលដើរតាមអ័ក្សក្រហម។ ទម្រង់មានទំហំពិតរបស់វា (ឥដ្ឋមានប្រវែងប្រមាណ 215 mm) ដូច្នេះវាមើលទៅត្រឹមត្រូវនៅគ្រប់ចម្ងាយ។
- នៅក្នុង[រូបភាពរេនឌ័រ](topic:render) សម្ភារៈរក្សាទម្រង់ ភាពរលោង និងសម្រាប់កញ្ចក់ និងលោហៈ ភាពភ្លឺរបស់វា។
- ការចុច {{key:Alt}} ជាមួយ {{ui:Paint}} ក៏យកសម្ភារៈនៃផ្ទៃមួយដែរ។

ទម្រង់ត្រូវបានគូរដោយ ModelCraft ផ្ទាល់ ដូច្នេះវាដំណើរការក្រៅបណ្ដាញ ហើយអាចប្រើបានដោយឥតគិតថ្លៃសម្រាប់អ្វីក៏ដោយ (CC0)។

## សមាសភាគ និងពណ៌

ពណ៌ដែលលាបលើផ្ទៃ**នៅខាងក្នុង**សមាសភាគ នឹងបង្ហាញលើច្បាប់ចម្លងទាំងអស់ ព្រោះច្បាប់ចម្លងចែករំលែកនិយមន័យតែមួយ។ ពណ៌ដែលលាបលើ**ច្បាប់ចម្លង**ពីខាងក្រៅ (នៅពេលសមាសភាគត្រូវបានបិទ) ជារបស់ច្បាប់ចម្លងនោះតែមួយគត់ ដូច្នេះច្បាប់ចម្លងពីរនៃសមាសភាគតែមួយអាចមានពណ៌ខុសគ្នា។ {{ui:Entity info}} បង្ហាញពណ៌នៃផ្ទៃ ក្រុម ឬសមាសភាគដែលបានជ្រើសរើស។

## ពណ៌នៅក្នុងឯកសារ

- ឯកសារ ModelCraft រក្សាទុកពណ៌ និងសម្ភារៈទាំងអស់។
- ទម្រង់ផ្សេងទៀតទទួលបាន**ពណ៌របស់សម្ភារៈ** (រូបរបស់វានៅពីចម្ងាយ) ជំនួសឲ្យទម្រង់៖ glTF, Collada, OBJ, DWG និង DXF និងការពិនិត្យសម្រាប់បោះពុម្ព 3D។ នៅ glTF, Collada និង OBJ សម្ភារៈរក្សាឈ្មោះរបស់វា ដូចជា `Material_brick-red`។
- **glTF (.glb)** និង **Collada (.dae)**៖ ពណ៌នីមួយៗក្លាយជាសម្ភារៈ។ សមាសភាគដែលបង្ហាញជាពណ៌ផ្សេងៗ ត្រូវបានសរសេរម្ដងសម្រាប់ពណ៌នីមួយៗ។ glTF ក៏សរសេរទម្រង់ដែលបាននាំចូលជាទម្រង់ផងដែរ។
- **OBJ**៖ ការនាំចេញទាញយកឯកសារពីរ គឺ `.obj` និងឯកសារសម្ភារៈ `.mtl` ដែលមានពណ៌។ រក្សាពួកវានៅថតតែមួយ។ ជាមួយទម្រង់ដែលបាននាំចូល `.obj` `.mtl` និងរូបភាពនឹងមកជា `.zip` តែមួយ។
- **DWG** រក្សាពណ៌ពិតប្រាកដ; **DXF** ប្រើពណ៌ CAD ស្តង់ដារ 255 ដែលនៅជិតបំផុត។
- **STL** និង **PLY** មានពណ៌៖ STL តាមបែបបទ VisCAM / SolidView (កម្មវិធីដែលមិនអានវាទេនឹងមិនអើពើវា) PLY ជាពណ៌នៅលើចំណុចនីមួយៗ។ សូមមើល [ទម្រង់ឯកសារលម្អិត](topic:formats)។
