កម្មវិធីបន្ថែម (ការកំណត់ › កម្មវិធីបន្ថែម) អាចបន្ថែមម៉ាស៊ីនមួយទៅក្នុងបញ្ជី​ម៉ាស៊ីន នៃ {{ui:រេនឌ័ររូបភាព…}}។ អត្ថបទពេញលេញសម្រាប់អ្នកនិពន្ធកម្មវិធីបន្ថែមគឺជាផ្នែកទី 16 នៃលក្ខណៈបច្ចេកទេសកម្មវិធីបន្ថែម; សរុបមក៖

- កម្មវិធីបន្ថែមចុះឈ្មោះម៉ាស៊ីនមួយដោយមានលេខសម្គាល់ដែលចាប់ផ្តើមដោយឈ្មោះរបស់វាផ្ទាល់ ឈ្មោះ ការកំណត់ជាជម្រើស និង **ទាំងកម្មវិធី** ដែលត្រូវដំណើរការ **ឬ** មុខងារក្នុង JavaScript ដែលគូររូបភាព។
- ម៉ាស៊ីនដែលដំណើរការកម្មវិធីត្រូវការការអនុញ្ញាត **`engine.run`** ដែលបង្ហាញមុនការដំឡើង និងក្នុងការកំណត់។ វាដំណើរការតែនៅក្នុង Studio; នៅក្នុងកម្មវិធីរុករក វាបង្ហាញជាឯកសារមួយដែលត្រូវរក្សាទុក។
- កម្មវិធីបន្ថែមដាក់ឈ្មោះកម្មវិធី (ឈ្មោះឯកសារធម្មតា៖ មិនដែលជា shell) script ដែលស្ថិតនៅ **ខាងក្នុងកម្មវិធីបន្ថែមដែលបានចុះហត្ថលេខា** និងអាគុយម៉ង់ដែលបង្កើតពីតួនាទីទុក និងពាក្យធម្មតា។ Studio រកកម្មវិធី ឬសួរអ្នកឲ្យចង្អុលទៅវាម្តង។
- លើកដំបូងដែលកម្មវិធីបន្ថែមដំណើរការកម្មវិធីមួយ **Studio សួរអ្នកនៅក្នុងប្រអប់ផ្ទាល់របស់វា**៖ កម្មវិធីបន្ថែមណា កម្មវិធីណា និងថា script អាចធ្វើអ្វីក៏បាន ដែលកម្មវិធីអាចធ្វើបាន។ អនុញ្ញាតតែកម្មវិធីបន្ថែមដែលអ្នកទុកចិត្តប៉ុណ្ណោះ។ ចម្លើយរបស់អ្នកត្រូវបានចងចាំសម្រាប់កម្មវិធីបន្ថែម និងកម្មវិធីនោះ។
- កញ្ចប់ (ឈុតឆាកជា USD និងឯកសារការកំណត់ ជាមួយឯកសារ glTF នៅពេលកម្មវិធីបន្ថែមស្នើ) និង script របស់កម្មវិធីបន្ថែមត្រូវដាក់ក្នុងថតបណ្តោះអាសន្នថ្មី កម្មវិធីដំណើរការនៅទីនោះ ហើយរូបភាពត្រឡប់មកវិញដោយមានសញ្ញាឈ្មោះម៉ាស៊ីនរបស់កម្មវិធីបន្ថែម។
