នៅក្នុង CadCraft Studio បញ្ជី Engine អាចផ្ទុក **តំណ** ទៅកាន់គម្រោង Unreal Engine ។ ទិសដៅតែមួយគត់៖ ពី CadCraft ទៅ Unreal ។

## ផ្ញើឈុតទិដ្ឋភាព

1. ជ្រើសធាតុ Unreal នៅក្នុងបញ្ជី Engine ។ លើកដំបូង Studio សួរឲ្យអ្នកជ្រើសថតគម្រោងរបស់អ្នក (ថតដែលមានឯកសារ `.uproject`) ; វាចងចាំថតនោះ ។
2. ចុច {{ui:ផ្ញើ}} ។ Studio សរសេរ `CadCraft/<file name>/` នៅក្នុងគម្រោង ៖ ឈុតទិដ្ឋភាពជាឯកសារ USD, ឯកសារការកំណត់, ទម្រង់ពន្លឺ និងឯកសារស្រទាប់តូចពីរ ។
3. ប្ដូរម៉ូដែល រក្សាទុក ហើយផ្ញើម្ដងទៀត ។ មានតែឈុតទិដ្ឋភាព និងឯកសារការកំណត់ប៉ុណ្ណោះដែលត្រូវជំនួស ។

## ការកែរបស់អ្នកមានសុវត្ថិភាព

ឆាក USD ដែល Unreal បើកគឺជាស្រទាប់ root តូចមួយដែលបង្កើតតែម្ដង ជាមួយស្រទាប់ពីរនៅក្រោម ៖ **របស់អ្នក** នៅខាងលើ (`<name>.user.usda`, ទទេនៅដំបូង, CadCraft មិនដែលសរសេរជាន់) និងឈុតទិដ្ឋភាពរបស់ CadCraft នៅខាងក្រោម ។ ការកែដែលអ្នករក្សាទុកទៅក្នុងស្រទាប់របស់អ្នកនៅតែមាន នៅពេលផ្ញើឈុតទិដ្ឋភាពម្ដងទៀត ។ ពន្លឺ និងតួអង្គផ្សេងទៀតដែលអ្នកដាក់ក្នុងកម្រិត Unreal នៅក្រៅឆាក ហើយក៏មិនត្រូវបានប៉ះពាល់ដែរ ។

## ដោយគ្មាន Studio

នៅក្នុងកម្មវិធីរុករក ឬនៅលើកុំព្យូទ័រដែល Studio រក Unreal មិនឃើញ ជ្រើស **ថតគម្រោង Unreal (.zip)** នៅក្នុងបញ្ជី Engine ហើយចុច {{ui:បង្ហាញ}} ។ វារក្សាទុកថតដូចគ្នាជា zip ៖ ស្រាយ (unzip) ចូលថត `CadCraft` របស់គម្រោងអ្នក ។ បន្សល់ **រួមបញ្ចូលឯកសារឆាក** ទុកនៅលើកដំបូង ; បិទវាសម្រាប់ការរក្សាទុកពេលក្រោយ ដូច្នេះ zip មានតែឈុតទិដ្ឋភាព និងឯកសារការកំណត់ ហើយស្រទាប់របស់អ្នកមិនដែលត្រូវជំនួសឡើយ ។
