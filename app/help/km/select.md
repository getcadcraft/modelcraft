{{ui:Select}} ({{key:Space}}) គឺជាឧបករណ៍ដែល ModelCraft ចាប់ផ្តើមដោយ ហើយជាឧបករណ៍ដែល {{key:Esc}} នាំអ្នកត្រឡប់ទៅវិញ។ វត្ថុដែលបានជ្រើសរើសនឹងប្រែទៅជាពណ៌ខៀវ ហើយ {{ui:Entity info}} នៅខាងស្តាំប្រាប់ថាវត្ថុទាំងនោះជាអ្វី។

## ចុច

| ធ្វើដូចនេះ | ជ្រើសរើស |
|---|---|
| ចុចផ្ទៃ ឬគែម | ផ្ទៃ ឬគែមនោះ |
| ចុចក្រុម ឬសមាសធាតុ | ក្រុម ឬសមាសធាតុទាំងមូល |
| ចុចទ្វេដងលើផ្ទៃ | ផ្ទៃ និងគែមរបស់វា |
| ចុចទ្វេដងលើគែម | គែមនោះ និងផ្ទៃនៅសងខាង |
| ចុចទ្វេដងលើក្រុម ឬសមាសធាតុ | បើកវាដើម្បីកែ (សូមមើល [ក្រុម និងសមាសធាតុ](topic:groups-components)) |
| ចុចបីដងលើផ្ទៃ ឬគែម | អ្វីៗទាំងអស់ដែលភ្ជាប់នឹងវា៖ វត្ថុទាំងមូល |
| ចុចកន្លែងទំនេរ | គ្មានអ្វីទេ (លុបការជ្រើសរើស) |
| ចុចទ្វេដងលើកន្លែងទំនេរ ខណៈកំពុងកែក្រុម | បិទក្រុម |

គែមងាយនឹងចុចជាងផ្ទៃ៖ នៅពេលទ្រនិចនៅក្បែរគែមក្នុងចម្ងាយប៉ុន្មានភីកសែល ការចុចនឹងយកគែម។

## អូសប្រអប់

- **ពីឆ្វេងទៅស្តាំ** គូសប្រអប់ពេញ៖ ការជ្រើសរើស **បង្អួច**។ មានតែអ្វីៗដែលនៅក្នុងប្រអប់ទាំងស្រុងប៉ុណ្ណោះដែលត្រូវបានជ្រើសរើស។
- **ពីស្តាំទៅឆ្វេង** គូសប្រអប់ដាច់ៗ៖ ការជ្រើសរើស **ឆ្លងកាត់**។ អ្វីក៏ដោយដែលប្រអប់ប៉ះត្រូវបានជ្រើសរើស ហើយផ្ទៃត្រូវបានជ្រើសរើសនៅពេលប្រអប់ស្ថិតនៅក្នុងផ្ទៃទាំងស្រុង។

ក្រុម ឬសមាសធាតុត្រូវបានរាប់ជាវត្ថុមួយ៖ បង្អួចត្រូវតែផ្ទុកវាទាំងមូល ឯការឆ្លងកាត់គ្រាន់តែត្រូវប៉ះវា។

## បន្ថែម និងដក

សង្កត់គ្រាប់ចុចមួយ ខណៈពេលចុច ឬអូស៖

| គ្រាប់ចុច | ផលប៉ះពាល់ |
|---|---|
| {{key:Shift}} | បិទ/បើក៖ បន្ថែមអ្វីដែលមិនត្រូវបានជ្រើសរើស ដកអ្វីដែលត្រូវបានជ្រើសរើស |
| {{key:Mod}} | បន្ថែម |
| {{key:Shift}} និង {{key:Mod}} រួមគ្នា | ដកចេញ |

ដើម្បីជ្រើសរើសអ្វីៗទាំងអស់នៅក្នុងម៉ូដែល (ឬអ្វីៗទាំងអស់នៅក្នុងក្រុមដែលអ្នកកំពុងកែ) សូមចុច {{key:Mod+A}}។

## លុបការជ្រើសរើស

ចុច {{key:Esc}} (នៅពេល {{ui:Select}} ជាឧបករណ៍) ឬចុចកន្លែងទំនេរ។

## លុបអ្វីដែលបានជ្រើសរើស

ចុច {{key:Delete}} ឬ {{key:Backspace}}។ ផ្ទៃ គែម ក្រុម និងបន្ទាត់ណែនាំ ដែលមាននៅក្នុងការជ្រើសរើសនឹងត្រូវលុបក្នុងជំហានតែមួយ; {{key:Mod+Z}} នាំវាត្រឡប់មកវិញ។

ការលុបគែមនឹងលុបផ្ទៃដែលត្រូវការវា លុះត្រាតែគែមនោះគ្រាន់តែបំបែកផ្ទៃពីរក្នុងប្លង់តែមួយ៖ ពេលនោះផ្ទៃទាំងពីរនឹងបញ្ចូលគ្នាទៅជាមួយ។ ការលុបផ្ទៃនឹងទុកគែមរបស់វា។ សូមមើល [លុប និងសម្អាត](topic:erase)។

## ជ្រើសរើសនៅក្នុងក្រុម

ការចុចក្រុមនឹងជ្រើសរើសក្រុមទាំងមូល។ ដើម្បីជ្រើសរើសផ្ទៃនៅក្នុងក្រុម សូមចុចទ្វេដងលើក្រុមដើម្បីបើក ហើយចុច។ ខណៈពេលក្រុមកំពុងបើក ការចុចអាចទៅដល់តែអ្វីដែលនៅខាងក្នុងប៉ុណ្ណោះ; អ្វីផ្សេងទៀតនឹងព្រាល។ ចុច {{key:Esc}} ពេលគ្មានអ្វីត្រូវបានជ្រើសរើស ឬចុចទ្វេដងលើកន្លែងទំនេរ ដើម្បីបិទវា។

{{ui:Outliner}} នៅខាងឆ្វេងជ្រើសរើសក្រុម និងសមាសធាតុតាមឈ្មោះ ដែលជួយនៅពេលវាត្រូវបានបាំងពីក្រោយវត្ថុផ្សេងទៀត។
