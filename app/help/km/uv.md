លំនាំ (texture) គឺជារូបភាពរាបស្មើ ហើយម៉ែសមិនរាបស្មើទេ។ **UV** របស់វាកំណត់ថាជ្រុងនីមួយៗនៃផ្ទៃនីមួយៗស្ថិតនៅកន្លែងណានៅលើរូបភាព។ តំបន់ការងារ UV បង្កើតវា៖ អ្នកកាត់ម៉ែសចេញតាម **ថ្នេរ** ដាក់ចំណែកឱ្យរាបស្មើ (**ពន្លាត**) ហើយដាក់ពួកវាចូលក្នុងការ៉េ (**ដាក់**)។

## បើកវា

ជ្រើសរើសម៉ែស ហើយជ្រើសរើស {{ui:UV}} នៅក្នុងបញ្ជីតំបន់ការងារ។ ក្រុម ឬសមាសភាគក្លាយជាម៉ែសជាមុនសិន ដូចក្នុងតំបន់ការងារម៉ែស។ ទិដ្ឋភាព 3D ផ្លាស់ទៅពាក់កណ្ដាលខាងឆ្វេង; **កម្មវិធីកែសម្រួល UV** នៅខាងស្ដាំបង្ហាញផ្ទៃម៉ែសដែលបានដាក់នៅលើការ៉េលំនាំ។ ការជ្រើសរើសដំណើរការដូចក្នុងតំបន់ការងារម៉ែស ហើយអ្វីដែលអ្នកជ្រើសក្នុងទិដ្ឋភាពមួយ ត្រូវបានជ្រើសក្នុងទិដ្ឋភាពម្ខាងទៀតដែរ។

## សម្គាល់ថ្នេរ

ថ្នេរគឺជាកន្លែងដែលម៉ែសអាចត្រូវបានកាត់បើក; ពួកវាបង្ហាញជាពណ៌ក្រហមនៅក្នុងទិដ្ឋភាពទាំងពីរ។

- ជ្រើសរើសគែម ({{ui:គែម}} ឬ {{key:2}}) ហើយចុច {{ui:សម្គាល់ថ្នេរ}} ({{key:Ctrl+E}})។ {{ui:សម្អាតថ្នេរ}} ({{key:Ctrl+Shift+E}}) យកវាចេញ។
- {{ui:ថ្នេរនៅមុំស្រួច}} សម្គាល់គែមមុតគ្រប់ទាំងអស់ និងគែមគ្រប់ទាំងអស់ដែលផ្ទៃជួបគ្នាលើសពី 60°៖ ប្រអប់មួយបែកចេញជាចំហៀងទាំងប្រាំមួយ។
- {{ui:ថ្នេរពី UV}} សម្គាល់ថ្នេរនៅកន្លែងដែល UV បែករួចហើយ ឧទាហរណ៍ បន្ទាប់ពីការព្រាង។

ផ្នែកបិទត្រូវការថ្នេរដើម្បីរាបស្មើ៖ បាល់ត្រូវការការកាត់យ៉ាងតិចមួយ បំពង់ត្រូវការការកាត់តាមប្រវែងរបស់វា។

## ពន្លាត

ជ្រើសរើសផ្ទៃដែលត្រូវដាក់ (ឬគ្មាន សម្រាប់ម៉ែសទាំងមូល) ហើយចុច {{ui:ពន្លាត}} ({{key:U}})។ ផ្នែកនីមួយៗរវាងថ្នេរត្រូវបានធ្វើឱ្យរាបស្មើ ដោយរក្សាមុំរបស់វាឱ្យត្រឹមត្រូវតាមដែលអាច (ការធ្វើរាបស្មើផ្អែកលើមុំ) បន្ទាប់មកផ្នែកទាំងនោះត្រូវបានដាក់ចូលក្នុងការ៉េ។ {{ui:កុងហ្វម័រ}} ពន្លាតដោយប្រើផែនទីកុងហ្វម័រការេតិចបំផុតវិញ៖ លឿនជាង ប៉ុន្តែមិនសូវត្រឹមត្រូវលើផ្នែកកោងខ្លាំង។ រូបរាងដែលអាចធ្វើចេញពីសន្លឹករាបស្មើ ដូចជាផ្នែកចំហៀងស៊ីឡាំងដែលកាត់ម្ដង ពន្លាតដោយគ្មានការលាតសន្ធឹងទាល់តែសោះ។

## ការព្រាង

សម្រាប់រូបរាងសាមញ្ញ ការព្រាងតែមួយជាញឹកញាប់គ្រប់គ្រាន់៖

| ការព្រាង | អ្វីដែលវាធ្វើ |
| --- | --- |
| {{ui:ប្រអប់}} | ផ្ទៃនីមួយៗទៅជ្រុងប្រអប់ដែលវាប្រឈមមុខច្រើនបំផុត |
| {{ui:ស៊ីឡាំង}} | ជុំវិញអ័ក្សពណ៌ខៀវ៖ ផ្ដេកជាមុំជុំវិញ ឡើងលើជាកម្ពស់ |
| {{ui:ស្វ៊ែរ}} | ពីចំណុចកណ្ដាល៖ ផ្ដេកជាមុំជុំវិញ ឡើងលើជារយៈទទឹង |
| {{ui:ពីទិដ្ឋភាព}} | ដូចដែលផ្ទៃត្រូវបានមើលក្នុងទិដ្ឋភាព 3D ឥឡូវនេះ |

ផ្ទៃដែលឆ្លងកាត់ការភ្ជាប់នៃស៊ីឡាំង ឬស្វ៊ែរ ត្រូវបានរក្សាទុកជាផ្នែកតែមួយ ដូច្នេះ UV របស់វាអាចលើសបន្តិចពីគែមស្ដាំនៃការ៉េ; លំនាំនឹងធ្វើម្ដងទៀតនៅទីនោះ។

## ចាត់ចែង

- {{ui:ដាក់ឱ្យជាប់គ្នា}} ដាក់ផ្នែក (កោះ) ចូលក្នុងការ៉េនៅទំហំ texel តែមួយ ហើយបង្វិលនីមួយៗដើម្បីយកកន្លែងតិចបំផុត។ បន្ទះកំណត់ចន្លោះដែលនៅសល់រវាងពួកវា។
- {{ui:បង្វិល 90°}} និង {{ui:ឆ្លុះ}} បង្វិល ឬឆ្លុះ UV នៃផ្ទៃដែលបានជ្រើសរើស។
- នៅក្នុងកម្មវិធីកែសម្រួល UV អូសផ្ទៃដែលបានជ្រើសរើស ដើម្បីផ្លាស់ទី UV នៃការជ្រើសរើស ឬចង្អុលទៅកម្មវិធីកែសម្រួល ហើយចុច {{key:R}} ឬ {{key:S}} បន្ទាប់មកផ្លាស់ទីដើម្បីបង្វិល ឬធ្វើមាត្រដ្ឋាន (ការចុចមួយដងរក្សាវា; {{key:Esc}} បោះបង់)។ {{key:G}} ផ្លាស់ទីដោយមិនចាំបាច់អូស។ ចុចផ្ទៃទ្វេដង (ឬ {{key:L}}) ដើម្បីជ្រើសរើសកោះទាំងមូលរបស់វា។ កង់កណ្ដុរធ្វើការពង្រីក; អូសដោយប៊ូតុងកណ្ដាល ឬស្ដាំដើម្បី{{ui:អូសទិដ្ឋភាព}}; {{key:F}} ដាក់ការ៉េឡើងវិញ។

រាល់ការផ្លាស់ប្ដូរគឺជាជំហានមិនធ្វើវិញមួយ។

## ពិនិត្យពួកវា

- {{ui:ក្រឡាត្រួត}} បង្ហាញក្រឡាត្រួតដែលមានស្លាកលើម៉ែសក្នុង UV របស់វា៖ ក្រឡាស្មើ និងការ៉េ មានន័យថាលំនាំដាក់ស្មើ; ស្លាកបង្ហាញទិសដៅដែលវារត់។
- {{ui:លាតសន្ធឹង}} ផ្ដល់ពណ៌ដល់ផ្ទៃនីមួយៗតាមកម្រិតដែល UV របស់វាលាតសន្ធឹង៖ ខៀវមិនមាន ឆ្លងកាត់បៃតង ទៅក្រហមច្រើន។ បន្ទះនេះជ្រើសរើសថាតើវាវាស់ **មុំដែលបត់** ឬ **ទំហំដែលផ្លាស់ប្ដូរ** ហើយបង្ហាញមធ្យម។
