**វត្ថុខ្សែកោង** គឺជាខ្សែកោងដែលបង្កើតរូបរាង៖ បំពង់តាមវា (bevel) ខ្សែក្រវ៉ាត់ (extrude) ស្នែងដែលរួញ (taper) ឬ — នៅពេលវារាបស្មើ និងបិទ — ចានពេញ ឬអក្សរ។ រូបរាងតាមខ្សែកោង៖ ផ្លាស់ទីចំណុចមួយ ហើយបំពង់ផ្លាស់ទីជាមួយវា។ នៅពេលរូបរាងត្រឹមត្រូវ ប្ដូរវាទៅជាម៉ែស។

## បន្ថែមខ្សែកោង

ជ្រើស{{ui:ខ្សែកោង}}នៅក្នុងបញ្ជីផ្ទាំងការងារ ហើយចុច{{ui:បន្ថែម}}៖

| ប្រភេទ | វាជាអ្វី |
| --- | --- |
| ខ្សែកោង Bézier, រង្វង់ Bézier | ឆ្លងកាត់ចំណុចរបស់វា; ចំណុចនីមួយៗមានដៃចាប់ពីរដែលកំណត់ទិសដៅខ្សែកោង |
| ខ្សែកោង NURBS, រង្វង់ NURBS, Path | រលូន គូសឆ្ពោះទៅចំណុចរបស់វា (ចាប់ផ្ដើម និងបញ្ចប់នៅចំណុចចុងរបស់វា); ចំណុចនីមួយៗមានទម្ងន់ |
| អត្ថបទ | អត្ថបទរបស់អ្នកជាបន្ទាត់អក្សររាបស្មើ និងបំពេញ |

ខ្សែកោងថ្មីទទួលបានបំពង់ស្តើង ដើម្បីឲ្យអាចមើលឃើញ និងជ្រើសបាន; កំណត់ជម្រៅ bevel របស់វាទៅ 0 សម្រាប់ខ្សែកោងទទេ។

អ្នកក៏អាចចាប់ផ្ដើមពីអ្វីដែលបានគូសបានដែរ៖ ជ្រើសធ្នូ រង្វង់ ពហុកោណ ឬខ្សែកោងដែលបានគូសនៅក្នុងផ្ទាំងការងារម៉ូដែល ហើយចុច{{ui:បង្កើតវត្ថុខ្សែកោង}}នៅក្នុង{{ui:ព័ត៌មានវត្ថុ}}។ បន្ទាត់ដែលបានគូសនៅតែនៅ។

## កែចំណុច

ចុចពីរដងលើវត្ថុខ្សែកោង (ឬជ្រើសវា ហើយជ្រើស{{ui:ខ្សែកោង}}) ដើម្បីកែវា។

- ចុចចំណុច ឬដៃចាប់ (Shift បន្ថែម ឬយកចេញ); អូសវាដើម្បីផ្លាស់ទីវា។ អូសលើកន្លែងទទេដើម្បីជ្រើសដោយប្រអប់។
- {{ui:ពន្យារ}} ({{key:E}}, ឬ {{key:Ctrl}}+ចុច) បន្ថែមចំណុចបន្ទាប់ពីចុងដែលបានជ្រើស, នៅទស្សន៍ទ្រនិច។
- {{ui:បែងចែក}} ({{key:W}}) ដាក់ចំណុចរវាងគូអ្នកជិតខាងដែលបានជ្រើសនីមួយៗ; Bézier រក្សារូបរាងរបស់វា។
- {{ui:ផ្លាស់ទី}}, {{ui:បង្វិល}}, {{ui:មាត្រដ្ឋាន}} ផ្លាស់ទីចំណុចដែលបានជ្រើសជាមួយទស្សន៍ទ្រនិច (គន្លឹះម៉ូដេលើ {{key:G}} {{key:R}} {{key:S}}, គន្លឹះរុញ/ទាញ {{key:M}} {{key:Q}} {{key:S}}); ចុចដើម្បីរក្សា {{key:Esc}} ដើម្បីបោះបង់។
- {{ui:បិទ}} ({{key:C}}) បិទខ្សែកោងបន្ទាត់ដែលបើក ឬបើកខ្សែកោងដែលបិទ; {{ui:បញ្ច្រាស}} ({{key:Shift+R}}) ដំណើរវាក្នុងទិសផ្សេង។
- ដៃចាប់ Bézier៖ {{ui:ធ្វើឲ្យរលោង}} ({{key:V}}) ដាក់ពួកវាសម្រាប់ខ្សែកោងរលូន, {{ui:ជ្រុង}} ({{key:Shift+V}}) ចង្អុលពួកវាទៅអ្នកជិតខាង, {{ui:សេរី}} ({{key:Alt+V}}) ទុកពួកវានៅកន្លែងដែលអ្នកដាក់។ អូសដៃចាប់ធ្វើឲ្យវាសេរី។
- {{ui:Bézier}}, {{ui:NURBS}} និង {{ui:ប៉ូលី}} ប្ដូរប្រភេទនៃ spline ដែលបានជ្រើស ដោយរក្សាចំណុចរបស់វា។

ការផ្លាស់ប្ដូរនីមួយៗគឺជាជំហានមួយនៃការមិនធ្វើវិញ។

## រូបរាង

ការកំណត់នៅក្នុងផ្ទាំង (និងនៅក្នុង{{ui:ព័ត៌មានវត្ថុ}}នៅក្នុងផ្ទាំងការងារម៉ូដែល)៖

- **រូបរាង**៖ ខ្សែកោង 3D ទៅគ្រប់ទិស; ខ្សែកោងរាបស្មើនៅក្នុងយន្តហោះរបស់វា ហើយអាចបំពេញបាន។
- **បំពេញ spline បិទ** (រាបស្មើ)៖ គែមក្លាយជាចាន; គែមនៅខាងក្នុងគែមផ្សេងគឺជារន្ធ ដូច្នេះអក្សររក្សារន្ធរបស់វា។
- **ពន្លាចេញ**៖ ពាក់កណ្ដាលទទឹងនៃខ្សែក្រវ៉ាត់ (ខ្សែកោងបើក ឬ 3D) ឬពាក់កណ្ដាលកម្រាស់នៃចាន (បំពេញ)។
- **ជម្រៅ bevel** និង**ភាពមូល**៖ បំពង់មូលតាមខ្សែកោង (ជាមួយ extrude: ខ្សែក្រវ៉ាត់មូល); នៅលើរូបរាងដែលបំពេញ គែមមូល។
- **បិទចុង**៖ ដំបូលនៅលើបំពង់បើក។
- **រួញតាមវា**៖ មាត្រដ្ឋានស្មើគ្នាតាមនីមួយៗ spline ឧទាហរណ៍ `1, 0.2` សម្រាប់ស្នែង, `0, 1, 0` សម្រាប់ទំពែក។
- **ភាពរលូន** និងសម្រាប់ NURBS **លំដាប់**៖ របៀបដែលវាត្រូវបានគូរយ៉ាងល្អិតល្អន់ និងរលូនប៉ុនណា (2 ត្រង់ … 6 រលូនបំផុត)។
- ជាមួយចំណុចដែលបានជ្រើស៖ **កាំ** (កម្រាស់បំពង់នៅទីនោះ គុណនឹង bevel), **ទ្រេត** (បង្វិលខ្សែក្រវ៉ាត់ជុំវិញខ្សែកោង) និងសម្រាប់ NURBS **ទម្ងន់**។

ម៉ូឌីហ្វាយដំណើរការនៅលើវត្ថុខ្សែកោងដូចនៅលើម៉ែស៖ Array តាមវា, Mirror, ផ្ទៃ Subdivision។ មើល[ម៉ូឌីហ្វាយនៅលើម៉ែស](topic:modifiers)។

## ប្ដូរវាទៅជាម៉ែស

{{ui:ទៅជាម៉ែស}} (នៅក្នុងផ្ទាំងការងារខ្សែកោង ឬនៅក្នុង{{ui:ព័ត៌មានវត្ថុ}} {{ui:ខ្សែកោងទៅជាម៉ែស}}) ធ្វើឲ្យវត្ថុខ្សែកោងក្លាយជាម៉ែសដែលវាបង្ហាញឥឡូវនេះ; ម៉ូឌីហ្វាយរបស់វានៅតែនៅខាងលើ។ បន្ទាប់មកកែវានៅក្នុងផ្ទាំងការងារម៉ែស។ ការមិនធ្វើវិញត្រឡប់វាទៅវិញ។
