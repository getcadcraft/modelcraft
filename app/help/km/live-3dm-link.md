បន្តធ្វើម៉ូដែលនៅកន្លែងដែលអ្នកធ្វើម៉ូដែល ហើយប្រើលទ្ធផលនៅទីនេះ៖ ដើម្បីរេនឌ័រ បំភ្លឺ ឬរៀបចំឈុតឆាកជុំវិញវា។ ការផ្លាស់ប្ដូរនីមួយៗក្នុងកម្មវិធីផ្សេង ធ្វើបច្ចុប្បន្នភាពក្រុមមួយក្នុង ModelCraft។

:::note
ការភ្ជាប់ត្រូវការ **CadCraft Studio** នៅលើកុំព្យូទ័រតែមួយ។ ផ្ទាំងកម្មវិធីរុករកមិនអាចយកការភ្ជាប់បានទេ។ គ្មានអ្វីឆ្លងកាត់អ៊ីនធឺណិតទេ៖ ស្គ្រីបនិយាយទៅកាន់ Studio តាមអាសយដ្ឋានរបស់កុំព្យូទ័រនេះផ្ទាល់ ជាមួយ token។
:::

:::warning
ការភ្ជាប់នេះត្រូវបានសាកល្បងជាមួយឧបករណ៍សរសេរឯកសាររបស់ស្គ្រីប និងកម្មវិធីជំនួស មិនទាន់នៅក្នុង Rhino ឬ Grasshopper ខ្លួនឯងនៅឡើយទេ។ បើមានអ្វីបរាជ័យនៅទីនោះ សូមប្រាប់យើងថាវាបាននិយាយអ្វី។
:::

## រៀបចំ

1. នៅ Studio បើក ModelCraft។ នៅ {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}} ធីក **អនុញ្ញាតឲ្យជំនួយការ AI និងស្គ្រីបប្រើ ModelCraft** បន្ទាប់មក **កែសម្រួល**។
2. នៅ Studio ជ្រើស {{ui:Connect an assistant}}។ វាបង្ហាញអាសយដ្ឋាន និង token ដែលអ្នកនឹងបិទភ្ជាប់ខាងក្រោម។
3. ទាញយកស្គ្រីប៖ [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)។

## ពី Rhino

1. រន់ `cadcraft_link.py` នៅក្នុងកម្មវិធីសរសេរស្គ្រីបរបស់ Rhino (Python 3 ក្នុង Rhino 8)។
2. លើកដំបូង បិទភ្ជាប់អាសយដ្ឋាន និង token។ វាត្រូវបានរក្សាទុកក្នុង `.cadcraft-link.json` នៅថតគេហដ្ឋានរបស់អ្នក មិនដែលនៅក្នុងម៉ូដែលទេ។ Studio បង្កើត token ថ្មីរាល់ពេលចាប់ផ្ដើម ដូច្នេះស្គ្រីបនឹងសួរម្ដងទៀតនៅពេលនោះ។

ម៉ូដែលទាំងមូលនឹងចូលមកជាក្រុមមួយដែលឈ្មោះតាមឯកសារ ឧទាហរណ៍ "chair (linked)"។ បន្ទាប់ពីនោះ ការផ្លាស់ប្ដូរនីមួយៗចូលមកនៅពេលអ្នកឈប់មួយស្របក់ ហើយមានតែវត្ថុដែលបានផ្លាស់ប្ដូរប៉ុណ្ណោះដែលត្រូវបានផ្ញើ។ រន់ស្គ្រីបម្ដងទៀតដើម្បីបញ្ឈប់។

## ពី Grasshopper

រន់ស្គ្រីបមួយដងក្នុង Rhino មុន ដើម្បីឲ្យអាសយដ្ឋាន និង token ត្រូវបានរក្សាទុក។

1. បន្ថែមសមាសធាតុ Script (Python 3) ហើយបិទភ្ជាប់ `cadcraft_link.py` ទាំងមូលចូលទៅក្នុងវា។
2. ផ្ដល់ធាតុបញ្ចូលទាំងនេះ៖ `G` (ធរណីមាត្រ ជាមួយការចូលប្រើបញ្ជី), `N` (ឈ្មោះ ជាជម្រើស), `On` (ប៊ូតុងបិទបើក boolean), និង `Target` (ជាជម្រើស៖ `model` ឬ `part` បើកម្មវិធីទាំងពីរ)។
3. បើក `On` ទៅ true។

ការគណនានីមួយៗផ្ញើ `G` ហើយជំនួសអ្វីដែលសមាសធាតុបានផ្ញើលើកមុន ដូច្នេះការអូស slider នឹងធ្វើបច្ចុប្បន្នភាពក្រុមនៅទីនេះ។ លទ្ធផល `a` របស់វាប្រាប់ថាមានអ្វីកើតឡើង។ សមាសធាតុនីមួយៗមានក្រុមរបស់ខ្លួន។

## អ្វីដែលអ្នកអាចធ្វើជាមួយក្រុម

- **ផ្លាស់ទី ដាក់ស្លាក ហើយសាងសង់ជុំវិញវា។** ទីតាំងក្រុម និងស្លាករបស់វានៅរក្សាដដែលគ្រប់ការធ្វើបច្ចុប្បន្នភាពទាំងអស់ ហើយអ្វីៗនៅក្បែរវាក៏ដូច្នេះដែរ។
- **កុំកែក្នុងក្រុម។** ការធ្វើបច្ចុប្បន្នភាពនីមួយៗជំនួសអ្វីដែលនៅក្នុងក្រុម។ កម្មវិធីផ្សេងជាម្ចាស់វត្ថុទាំងនោះ។
- **Undo។** ការធ្វើបច្ចុប្បន្នភាពដែលនៅជិតគ្នាក្នុងរយៈពេល 2 វិនាទី ចែករំលែកជំហាន undo តែមួយ ដូច្នេះ {{key:Mod+Z}} ដកការអូសទាំងមូលវិញ។ ការធ្វើបច្ចុប្បន្នភាពបន្ទាប់នឹងនាំម៉ូដែលត្រឡប់ទៅផ្គូផ្គងវិញ។
- **រក្សាទុក។** ឯកសារដែលបានរក្សាទុកនៅរក្សាការភ្ជាប់។ រន់ស្គ្រីបម្ដងទៀតបន្ទាប់ពីបើកឯកសារ ហើយក្រុមដដែលនឹងធ្វើបច្ចុប្បន្នភាព។

## អ្វីដែលចូលមក

ម៉ែស ប៉ូលីសឺហ្វេស ផ្ទៃ និងការទាញចេញ ជាម៉ែសដែលអ្នកឃើញនៅលើអេក្រង់ SubD ជាម៉ែសរបស់វា ខ្សែកោងជាគែម ប្លុកជាវត្ថុដាច់ដោយឡែកនៅកន្លែងដែលវាស្ថិត (មិនមែនជាសមាសធាតុ) ស្រទាប់ជាស្លាក ពណ៌ និងឯកតា។ សូមមើល [នាំចូលម៉ូដែល .3dm](topic:import-3dm-files) សម្រាប់របៀបដែលវាបង្ហាញនៅទីនេះ។

ត្រូវបានលុបចេញ ព្រមទាំងចំនួននៅក្នុងកម្មវិធីផ្សេង៖ ចំណុច អត្ថបទ វិមាត្រ ពន្លឺ និងរបស់ស្រដៀងគ្នា។

**មានទិសដៅតែមួយ។** ការផ្លាស់ប្ដូរនៅទីនេះមិនត្រឡប់ទៅកម្មវិធីផ្សេងទេ។

## បើមានអ្វីខុស

- **"No ModelCraft or PartCraft window allows it":** បង្អួច ModelCraft ឬ PartCraft មិនអនុញ្ញាតឲ្យធ្វើបានទេ៖ ធ្វើជំហានទី 1 នៃការរៀបចំ។
- **"Studio refused the token":** Studio បានចាប់ផ្ដើមឡើងវិញ។ ចម្លង token ថ្មី ហើយរន់ស្គ្រីបម្ដងទៀត។ សម្រាប់ Grasshopper រន់វានៅក្នុង Rhino មុនសិន។
- **"Cannot reach CadCraft Studio":** Studio មិនដំណើរការ ឬអាសយដ្ឋានបានផ្លាស់ប្ដូរ។
