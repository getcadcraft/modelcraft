Þetta eru ýta/toga-lyklarnir, þeir sem ModelCraft byrjar með. Fyrir hinn stílinn, sjá [Modeler-lykla](topic:keyboard#modeler-keys) hér að neðan og [Stillingar ModelCraft](topic:settings).

Flýtileiðir virka þegar þrívíddarsýnin eða hnappur á tækjastiku er virkur. Ef þú varst nýbúinn að skrifa í reit í spjaldi eða breyta lista í {{ui:Stíll}}, smelltu fyrst í þrívíddarsýnina, annars fara lyklarnir í þann reit. Sjá [Lyklar, mýs og snertiborð](common:keys) fyrir hvernig lyklar eru skrifaðir á hverri tölvu.

## Esc

{{key:Esc}} fer eitt þrep til baka í hvert skipti sem þú ýtir á hann:

1. Hættir við það sem verkfærið er mitt í (lína sem er verið að teikna, ýta/toga, færsla). Allt fer til baka.
2. Skiptir yfir í {{ui:Velja}}.
3. Hreinsar valið.
4. Lokar hópnum sem þú ert að breyta.

Það stöðvar líka senur frá því að spilast. Í gildisreitnum hreinsar {{key:Esc}} það sem þú skrifaðir og fer aftur í sýnina.

## Meðan verkfæri er í gangi

| Takki | Gerir |
|---|---|
| Tölustafur, eða einn af `. , - ' " [ < * /` | Byrjar að skrifa í gildisreitinn |
| {{key:Enter}} | Beitir því sem þú skrifaðir í gildisreitinn |
| {{key:Right}} | Læsir við rauða ásinn (ýttu aftur til að opna) |
| {{key:Left}} | Læsir við græna ásinn |
| {{key:Up}} | Læsir við bláa ásinn |
| {{key:Down}} | Læsir samsíða síðasta jaðri sem þú sveimaðir yfir áður en fyrsti smellur var gerður |
| Haltu {{key:Shift}} | Heldur þeirri stefnu sem þú ert smelltur að, meðan haldið er |
| {{key:Ctrl}}, {{key:Mod}} eða {{key:Alt}} ({{ui:Færa}}) | Skiptir á milli færslu og afritunar |

Læsingar með örvatökkum virka í {{ui:Lína}}, {{ui:Rétthyrningur}}, {{ui:Hringur}}, {{ui:Marghyrningur}}, {{ui:Færa}}, {{ui:Mælikvarði}} og {{ui:Málband}} (þegar mælt er frá punkti), eftir fyrsta smell. {{ui:Ýta/toga}} færist alltaf eftir stefnu flatarins og hefur engar læsingar. Í {{ui:Snúa}} sýna örvatakkarnir skilaboðin „Læst“ eftir fyrsta smell en breyta ekki snúningnum.

## Mús

| Aðgerð | Gerir |
|---|---|
| Smellur | Notar núverandi verkfæri |
| Ýta, draga, sleppa | Eins og tveir smellir (fyrir teikniverkfæri); reitaval (fyrir {{ui:Velja}}); eyðir á leiðinni (fyrir {{ui:Strokleður}}) |
| Tvísmellur | {{ui:Velja}}: flötur með jöðrum sínum, jaðar með flötum sínum, opnar hóp; autt rými lokar hópnum. {{ui:Ýta/toga}}: endurtekur síðustu fjarlægð |
| Þrísmellur | {{ui:Velja}}: allt tengt |
| {{key:Shift}} + smellur | {{ui:Velja}}: skiptir inn og út úr valinu |
| {{key:Mod}} + smellur | {{ui:Velja}}: bætir við valið |
| {{key:Shift}} + {{key:Mod}} + smellur | {{ui:Velja}}: fjarlægir úr valinu |
| Draga með miðhnappi | {{ui:Snúast}}, með hvaða verkfæri sem er |
| {{key:Shift}} + draga með miðhnappi | {{ui:Hliðra}}, með hvaða verkfæri sem er |
| Draga með hægri hnappi | {{ui:Hliðra}}, með hvaða verkfæri sem er |
| Hjól | {{ui:Aðdráttur}} að bendlinum |

Það er enginn hægrismellisvalmynd.

## Snertiskjár

| Bending | Gerir |
|---|---|
| Létt snerting | Smellur með núverandi verkfæri |
| Tvöföld létt snerting | Tvísmellur |
| Ýta, draga, lyfta | Eins og ýta, draga, sleppa með mús |
| Tveir fingur: klípa | Aðdráttur |
| Tveir fingur: færa saman | Hliðra ({{ui:Stillingar}} › {{ui:ModelCraft}} › Snertiskjár getur gert það að {{ui:Snúast}}) |
| Þrír fingur: færa saman | {{ui:Snúast}} (Hliðra þegar tveir fingur snúast) |
| Halda einum fingri kyrrum | Klárar verkfærið, eins og Enter; þegar ekkert er í gangi, dragðu þá til að snúast |
| Annar fingur meðan einn fingur gerir aðgerð | Hættir við þá aðgerð |
| {{ui:Snúast}} verkfærið, síðan draga einn fingur | {{ui:Snúast}} |

Til að skrifa gildi á snertiskjá, pikkaðu á gildisreitinn neðst, skrifaðu, og ýttu á Enter (eða Go) takkann á lyklaborðinu.

## Hvar Færa er

Færa er í {{ui:Færa}} verkfærinu, takki {{key:M}}: veldu það sem á að færa, smelltu á grunnpunkt, og síðan annan punkt eða skrifaðu fjarlægð. Sjá [Færa, afrita og búa til raðir](topic:move-copy).
