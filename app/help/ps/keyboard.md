دا د فشار-کشول کیلي دي، هغه چې ModelCraft پکې پیل کوي. د بل سټایل لپاره، لاندې [Modeler کیلي](topic:keyboard#modeler-keys) او [د ModelCraft امستنې](topic:settings) وګورئ.

شارټکټونه هغه وخت کار کوي کله چې د 3D لید یا د وسیلې تڼۍ فوکس ولري. که تازه په پینل ساحه کې ولیکئ یا په {{ui:Style}} کې لیست بدل کړئ، د 3D لید ته کلیک وکړئ، که نه کیلي هغې ساحې ته ځي. د کمپیوټرونو کې د کیلیو لیکلو لپاره [کیلي، موږک او ټریک پیډ](common:keys) وګورئ.

## Esc

{{key:Esc}} هر ځل کېکاږل یوه کچه شاته ځي:

1. هغه لغوه کوي چې وسیله یې په منځ کې ده (کرښه چې کښل کېږي، فشارول/کشول، لېږدول). هرڅه بېرته ځي.
2. {{ui:Select}} ته بدلېږي.
3. ټاکنه پاکوي.
4. هغه ډله تړي چې سمون یې کوئ.

همدارنګه صحنې لوبېدل بندوي. په د ارزښت بکس کې، {{key:Esc}} هغه څه پاکوي چې ولیکل شول او لید ته بېرته ځي.

## کله چې وسیله کار کوي

| کیلي | کار |
|---|---|
| یو عدد، یا یو له `. , - ' " [ < * /` څخه | د ارزښت بکس کې لیکل پیلوي |
| {{key:Enter}} | د ارزښت بکس کې ولیکل شوی پلي کوي |
| {{key:Right}} | سور محور ته قفل (بیا کېکاږئ څو خلاص شي) |
| {{key:Left}} | شنه محور ته قفل |
| {{key:Up}} | نیلي محور ته قفل |
| {{key:Down}} | د لومړي کلیک دمخه وروستۍ هغه څنډې ته موازي قفل |
| {{key:Shift}} نیول | هغه سمت ساتي چې ورسره نښلي یاست، تر هغه وخته چې ساتئ |
| {{key:Ctrl}}، {{key:Mod}} یا {{key:Alt}} (Move) | د لېږدولو او کاپي کولو ترمنځ بدلوي |

د تیر-کیلي قفلونه په {{ui:Line}}، {{ui:Rectangle}}، {{ui:Circle}}، {{ui:Polygon}}، {{ui:Move}}، {{ui:Scale}} او {{ui:Tape}} کې کار کوي (کله چې له یو ټکي اندازه کوئ) تر لومړي کلیک وروسته. {{ui:Push/pull}} تل د مخ سمت ته حرکت کوي او قفل نلري. په {{ui:Rotate}} کې تیر کیلي لومړي کلیک وروسته "قفل شوی" پیغام ښيي، مګر ګرځېدل نه بدلوي.

## نور وخت کې تیر کیلي

کله چې هېڅ وسیله په کار کې نه وي، تیر کیلي کیمره حرکت کوي:

| کیلي | کار |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | ګرځېدل |
| {{key:Shift}} سره تیر | لید خوځول |

## موږک

| عمل | کار |
|---|---|
| کلیک | اوسنۍ وسیله کاروي |
| فشار، کش، خوشي کول | د دوو کلیکونو په څېر (د کښلو وسیلو لپاره)؛ د کړکۍ ټاکنه ({{ui:Select}} لپاره)؛ د تګ پر مهال ړنګوي ({{ui:Eraser}} لپاره) |
| دوه ځلې کلیک | {{ui:Select}}: مخ له څنډو سره، څنډه له مخونو سره، ډله پرانیزي؛ تش ځای ډله تړي. {{ui:Push/pull}}: وروستی واټن بیا کوي |
| درې ځلې کلیک | {{ui:Select}}: هرڅه وصل شوي |
| {{key:Shift}} + کلیک | {{ui:Select}}: ټاکنې ته ننوتل/وتل |
| {{key:Mod}} + کلیک | {{ui:Select}}: ټاکنې ته اضافه کول |
| {{key:Shift}} + {{key:Mod}} + کلیک | {{ui:Select}}: له ټاکنې لرې کول |
| منځنۍ تڼۍ کش | ګرځېدل، د هرې وسیلې سره |
| {{key:Shift}} + منځنۍ تڼۍ کش | لید خوځول، د هرې وسیلې سره |
| ښۍ تڼۍ کش | لید خوځول، د هرې وسیلې سره |

د ښي کلیک مینو نشته.

## ټریک پیډ

څه چې دوه ګوتو سوایپ کوي د {{ui:Settings}} › {{ui:ModelCraft}} › سکرول پورې اړه لري:

| اشاره | ټریک پیډ (یا حل شوی) | د موږک چرخ |
|---|---|---|
| دوه ګوتو سوایپ | ګرځېدل | زوم د اشاره ګر په لور |
| {{key:Shift}} + دوه ګوتو سوایپ | لید خوځول | زوم |
| ټکل | زوم د اشاره ګر په لور | زوم د اشاره ګر په لور |
| دوه ګوتې فشار او کش (ثانوي کلیک نیول) | لید خوځول | لید خوځول |

وګورئ [لید ګرځول، خوځول او زوم](topic:orbit-pan-zoom#on-a-trackpad) او [د ModelCraft امستنې](topic:settings#scrolling-mouse-wheel-or-trackpad).

کاپي، سرېښول، بېرته کول، خوندي کول او پرانیستل هغه کیلي ساتي چې پورته لیست شوي دي. ټایپ شوي ارزښتونه، د ارزښت بکس او {{ui:Push/pull}} په دواړو سټایلونو کې یو شان کار کوي.

| اشاره | کار |
|---|---|
| ټیپ | د اوسنۍ وسیلې کلیک |
| دوه ځلې ټیپ | دوه ځلې کلیک |
| فشار، کش، پورته کول | د موږک سره د فشار، کش او خوشي کولو په څېر |
| دوې ګوتې: چوټل | زوم |
| دوې ګوتې: یوځای خوځېدل | لید خوځول ({{ui:Settings}} › {{ui:ModelCraft}} › لمس پرده کولی شي یې ګرځول وګرځوي) |

د ټایپ کولو لپاره په لمس پرده، د ارزښت بکس ټیپ کړئ، ټایپ کړئ، او د کیبورډ {{key:Enter}} (یا Go) کیلي وکېښئ.

## د Move چیرې ده

Move د {{ui:Move}} وسیله کې دی، کیلي {{key:M}}: هغه څه وټاکئ چې لېږدول غواړئ، د بنسټ ټکی کلیک کړئ، بیا دویم ټکی یا واټن ولیکئ. وګورئ [لېږدول، کاپي او سرې جوړول](topic:move-copy).
