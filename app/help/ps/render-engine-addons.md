یوه ضمیمه ({{ui:امستنې}} › {{ui:ضمیمې}}) کولی شي یو انجن د {{ui:انځور رنډر کول…}} د انجن لیست ته اضافه کړي. بشپړ متن د ضمیمو لیکوالانو لپاره د ضمیمې مشخصاتو د 16 برخې کې دی؛ په لنډ ډول:

- ضمیمه یو انجن ثبتوي چې ID یې د خپل ځان څخه پیلېږي، یو نوم، اختیاري امستنې او **یا** یو پروګرام چې چلېږي **یا** یو فنکشن په JavaScript کې چې انځور ډیزاینوي.
- یو انجن چې پروګرام چلوي د **`engine.run`** اجازې ته اړتیا لري، کومه چې له نصب مخکې او امستنو کې ښودل کېږي. دا یوازې په Studio کې چلېږي؛ په براوزر کې دا د ساتلو لپاره د فایل په ډول ښکاري.
- ضمیمه پروګرام نوموي (ساده فایل نوم: هېڅکله شیل نه)، یو سکریپټ چې **په لاسلیک شوې ضمیمه کې دی**، او دلیلونه چې له ځای نیونکو او ساده کلمو جوړ دي. Studio پروګرام پیدا کوي یا یو ځل له تاسو وپوښتي چې ورته اشاره وکړئ.
- لومړی ځل چې ضمیمه پروګرام چلوي، **Studio په خپل ډیالوګ کې له تاسو پوښتنه کوي**: کومه ضمیمه، کوم پروګرام، او دا چې سکریپټ کولی شي هر هغه څه وکړي چې پروګرام یې کولی شي. یوازې هغه ضمیمه اجازه ورکړئ چې ورباندې باور لرئ. ستاسو ځواب د هغې ضمیمې او پروګرام لپاره ساتل کېږي.
- بسته (صحنه د USD په توګه او یوه امستنې فایل، د glTF فایل سره کله چې ضمیمه یې وغواړي) او د ضمیمې سکریپټ په یوه نوي موقتي فولډر کې ځي، پروګرام هلته چلېږي، او انځور د ضمیمې د انجن نوم سره نښه شوی بېرته راځي.

:::note
ضمیمې یوازې د ضمیمې API 1.4 څخه رنډر انجنونه اضافه کولی شي. یو کار شوی مثال د یوه خلاص سرچینې د کمانډ لاین رنډرر لپاره په خپل ریپوزیټري کې دی؛ دا تر اوسه په دې رنډرر کې نه دی چلېدلی.
:::
