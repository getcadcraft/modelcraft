په CadCraft Studio کې د انجن لیست کولای شي د Unreal Engine پروژې ته یوه **اړیکه** وساتي. یوازې یو لوری: له CadCraft څخه Unreal ته.

## صحنه لېږل

1. د انجن لیست کې د Unreal ننوتنه وټاکئ. لومړی ځل، Studio له تاسو وغواړي چې د خپلې پروژې فولډر وټاکئ (هغه چې `.uproject` فایل لري)؛ دا یې په یاد ساتي.
2. {{ui:لېږل}} کلیک وکړئ. Studio په پروژه کې `CadCraft/<file name>/` لیکي: صحنه د USD فایل په توګه، د امستنو فایل، د رڼا پروفایلونه او دوه کوچني لایې فایلونه.
3. ماډل بدل کړئ، خوندي یې کړئ او بیا یې ولېږئ. یوازې صحنه او د امستنو فایل بدلېږي.

## ستاسو خپل بدلونونه خوندي دي

سټېج چې Unreal یې پرانيزي یو کوچنی ریښتنی لایه ده چې یو ځل جوړېږي، او د هغې لاندې دوه لایې دي: **ستاسو** پورته (`<name>.user.usda`، لومړی خالي، هېڅکله د CadCraft لخوا نه بیا لیکل کېږي) او د CadCraft صحنه لاندې. هغه بدلونونه چې په خپله لایه کې یې خوندي کوئ، کله چې صحنه بیا ولېږل شي هم پاتې کېږي. هغه څراغونه او نور اکټرونه چې په Unreal کچه کې ږدئ د سټېج بهر دي او هغه هم نه اغېزمنېږي.

## د Studio پرته

په براوزر کې، یا په کمپیوټر کې چې Studio Unreal نه مومي، د انجن لیست کې **Unreal project folder (.zip)** وټاکئ او {{ui:رنډر}} کلیک وکړئ. دا همغه فولډر د zip په توګه خوندي کوي: یې خلاص کړئ او د پروژې `CadCraft` فولډر ته یې واچوئ. لومړی ځل **د سټېج فایلونه شامل کړئ** فعال پرېږدئ؛ د وروستیو خوندي کولو لپاره یې بند کړئ، نو zip یوازې صحنه او د امستنو فایل لري او ستاسو لایه هېڅکله نه بدلېږي.

:::note
هغه Unreal پلګ ان چې سټېج پرانيزي، لمر، څراغونه، کیمرې او روڼوالی پلي کوي، هر لېږل تعقیبوي او کیمره رنډروي، **لا خپور شوی نه دی** او په Unreal کې نه دی چلول شوی. تر هغې، {{ui:لېږل}} فایلونه پروژې ته اچوي او د Unreal خپل USD وسایل کولای شي یې پرانیزي. Windows لومړی سیستم دی؛ macOS وروسته راځي.
:::
