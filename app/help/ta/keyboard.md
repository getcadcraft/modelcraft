இவை தள்ளு-இழு விசைகள், ModelCraft தொடங்கும் விசைகள். மற்ற பாணிக்கு, கீழே [மாடலர் விசைகளையும்](topic:keyboard#modeler-keys) [ModelCraft அமைப்புகளையும்](topic:settings) பார்.

குறுக்குவழிகள் 3D காட்சி அல்லது கருவிப்பட்டைப் பொத்தான் கவனத்தில் இருக்கும்போது வேலை செய்யும். ஒரு பலகப் புலத்தில் நீ தட்டச்சு செய்திருந்தாலோ {{ui:Style}}-இல் ஒரு பட்டியலை மாற்றியிருந்தாலோ, முதலில் 3D காட்சியில் கிளிக் செய், இல்லையென்றால் உன் விசைகள் அந்தப் புலத்திற்குச் செல்லும். ஒவ்வொரு கணினியிலும் விசைகள் எப்படி எழுதப்படுகின்றன என்பதற்கு [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys) பார்.

## Esc

{{key:Esc}} ஒவ்வொரு முறை அழுத்தும்போதும் ஒரு நிலை பின்வாங்கும்:

1. கருவி நடுவில் இருப்பதை ரத்து செய் (வரையப்படும் கோடு, ஒரு தள்ளு/இழு, ஒரு நகர்த்து). எல்லாம் பழைய நிலைக்குத் திரும்பும்.
2. {{ui:Select}}-க்கு மாறும்.
3. தேர்வை நீக்கும்.
4. நீ திருத்தும் குழுவை மூடும்.

காட்சிகள் இயங்குவதையும் அது நிறுத்தும். மதிப்புப் பெட்டியில், {{key:Esc}} நீ தட்டச்சு செய்ததை அழித்து காட்சிக்குத் திரும்பும்.

## கருவி வேலை செய்யும்போது

| விசை | செய்கிறது |
|---|---|
| ஓர் இலக்கம், அல்லது `. , - ' " [ < * /` இவற்றில் ஒன்று | மதிப்புப் பெட்டியில் தட்டச்சு செய்யத் தொடங்கும் |
| {{key:Enter}} | மதிப்புப் பெட்டியில் நீ தட்டச்சு செய்ததைப் பயன்படுத்தும் |
| {{key:Right}} | சிவப்பு அச்சுக்குப் பூட்டும் (மீண்டும் அழுத்தி பூட்டை நீக்கு) |
| {{key:Left}} | பச்சை அச்சுக்குப் பூட்டும் |
| {{key:Up}} | நீல அச்சுக்குப் பூட்டும் |
| {{key:Down}} | முதல் கிளிக்கிற்கு முன் நீ சுட்டிக்காட்டிய கடைசி விளிம்புக்கு இணையாகப் பூட்டும் |
| {{key:Shift}} பிடித்திரு | நீ ஒட்டிக்கொண்டுள்ள திசையை, பிடித்திருக்கும் வரை வைத்திருக்கும் |
| {{key:Ctrl}}, {{key:Mod}} அல்லது {{key:Alt}} (நகர்த்து) | நகர்த்துவதற்கும் நகலெடுப்பதற்கும் இடையே மாறும் |

அம்பு விசைப் பூட்டுகள் {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} மற்றும் {{ui:Tape}}-இல் (ஒரு புள்ளியிலிருந்து அளக்கும்போது) முதல் கிளிக்கிற்குப் பிறகு வேலை செய்யும். {{ui:Push/pull}} எப்போதும் முகத்தின் திசையில் நகரும், அதற்குப் பூட்டுகள் இல்லை. {{ui:Rotate}}-இல் முதல் கிளிக்கிற்குப் பிறகு அம்பு விசைகள் "பூட்டப்பட்டது" செய்தியைக் காட்டும், ஆனால் திருப்பத்தை மாற்றாது.

## மற்ற நேரங்களில் அம்பு விசைகள்

எந்தக் கருவியும் நடுவில் இல்லாதபோது, அம்பு விசைகள் கேமராவை நகர்த்தும்:

| விசை | செய்கிறது |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | சுற்று |
| அம்புடன் {{key:Shift}} | நகர்த்து (பான்) |

## டிராக்பேட்

இரு-விரல் ஸ்வைப் என்ன செய்கிறது என்பது {{ui:Settings}} › {{ui:ModelCraft}} › உருட்டல்-ஐப் பொறுத்தது:

| இரு-விரல் ஸ்வைப் | சுற்று | சுட்டியை நோக்கிப் பெரிதாக்கு |
| {{key:Shift}} + இரு-விரல் ஸ்வைப் | நகர்த்து (பான்) | பெரிதாக்கு |

| {{key:Alt}} + இழுப்பு / {{key:Alt+Shift}} + இழுப்பு | சுற்று / நகர்த்து (பான்) (நடு பொத்தான் தேவையில்லை) |

நகலெடு, ஒட்டு, செயல்தவிர், சேமி மற்றும் திற ஆகியவை மேலே பட்டியலிடப்பட்ட விசைகளையே தக்கவைக்கும். தட்டச்சு செய்த மதிப்புகள், மதிப்புப் பெட்டி மற்றும் {{ui:Push/pull}} இரு பாணிகளிலும் ஒரே மாதிரி வேலை செய்யும்.

## தொடுதிரை

| சைகை | செய்கிறது |
|---|---|
| தட்டு | நடப்புக் கருவியுடன் ஒரு கிளிக் |
| இருமுறை தட்டு | ஓர் இருமுறை கிளிக் |
| அழுத்து, இழு, தூக்கு | சுட்டியுடன் அழுத்து, இழு, விடு போலவே |
| இரு விரல்கள்: கிள்ளு | பெரிதாக்கு |
| இரு விரல்கள்: ஒன்றாக நகர்த்து | நகர்த்து (பான்) (அமைப்புகள் › ModelCraft › தொடுதிரையில் சுற்றாக மாற்றலாம்) |
| மூன்று விரல்கள்: ஒன்றாக நகர்த்து | சுற்று (இரு விரல்கள் சுற்றும்போது நகர்த்து) |
| ஒரு விரலை அசையாமல் பிடித்திரு | Enter போல கருவியை முடிக்கும்; எதுவும் நடக்கவில்லை என்றால், பின்னர் சுற்ற இழு |
| ஒரு-விரல் செயலின்போது இரண்டாவது விரல் | அந்தச் செயலை ரத்து செய்யும் |
| {{ui:Orbit}} கருவி, பின்னர் ஒரு விரலை இழு | சுற்று |

தொடுதிரையில் ஒரு மதிப்பைத் தட்டச்சு செய்ய, கீழே உள்ள மதிப்புப் பெட்டியைத் தட்டு, தட்டச்சு செய், பின்னர் விசைப்பலகையின் {{key:Enter}} (அல்லது Go) விசையை அழுத்து.

## நகர்த்து எங்கே உள்ளது

நகர்த்து {{ui:Move}} கருவியில் உள்ளது, விசை {{key:M}}: நகர்த்த வேண்டியதைத் தேர்ந்தெடு, ஓர் அடிப்படைப் புள்ளியைக் கிளிக் செய், பின்னர் இரண்டாவது புள்ளி அல்லது ஒரு தூரத்தைத் தட்டச்சு செய். பார்க்க [நகர்த்து, நகலெடு மற்றும் அணிகளை உருவாக்கு](topic:move-copy).
