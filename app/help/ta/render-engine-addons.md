ஒரு துணை நிரல் ({{ui:அமைப்புகள்}} › {{ui:துணை நிரல்கள்}}) {{ui:படத்தை ரெண்டர் செய்…}} இன் இயந்திரப் பட்டியலில் ஓர் இயந்திரத்தைச் சேர்க்க முடியும். துணை நிரல் ஆசிரியர்களுக்கான முழு உரை துணை நிரல் விவரக்குறிப்பின் பிரிவு 16 இல் உள்ளது; சுருக்கமாக:

- துணை நிரல் ஓர் இயந்திரத்தைப் பதிவு செய்கிறது: தன் சொந்தப் பெயருடன் தொடங்கும் ஓர் அடையாளம், ஒரு பெயர், விருப்ப அமைப்புகள், மற்றும் **ஒரு நிரலை இயக்குவது அல்லது** JavaScript இல் படத்தை வரையும் ஒரு செயல்பாடு — **இரண்டில் ஒன்று**.
- ஒரு நிரலை இயக்கும் இயந்திரத்துக்கு **`engine.run`** அனுமதி தேவை; அது நிறுவுவதற்கு முன்பும் அமைப்புகளிலும் காட்டப்படும். அது Studio இல் மட்டுமே இயங்கும்; உலாவியில் அது சேமிக்க வேண்டிய கோப்பாகக் காட்டப்படும்.
- துணை நிரல் நிரலின் பெயரை (ஒரு எளிய கோப்புப் பெயர்: ஒருபோதும் ஷெல் அல்ல), **கையொப்பமிட்ட துணை நிரலுக்குள்** உள்ள ஒரு ஸ்கிரிப்டை, அதோடு இடத்துளைகளாலும் எளிய சொற்களாலும் ஆன வாதங்களைக் குறிப்பிடுகிறது. Studio நிரலைக் கண்டுபிடிக்கும் அல்லது ஒருமுறை அதைச் சுட்டிக்காட்டக் கேட்கும்.
- ஒரு துணை நிரல் முதல் முறை ஒரு நிரலை இயக்கும்போது, **Studio அதன் சொந்த உரையாடலில் கேட்கும்**: எந்தத் துணை நிரல், எந்த நிரல், மற்றும் ஒரு ஸ்கிரிப்ட் நிரல் செய்யக்கூடிய எதையும் செய்ய முடியும் என்பது. நம்பும் துணை நிரலுக்கு மட்டுமே அனுமதி கொடு. உங்கள் பதில் அந்தத் துணை நிரல் மற்றும் நிரலுக்காக நினைவில் வைக்கப்படும்.
- தொகுப்பு (USD ஆக காட்சி, ஓர் அமைப்புகள் கோப்பு, கேட்கும்போது glTF கோப்புடன்) மற்றும் துணை நிரலின் ஸ்கிரிப்ட் ஒரு புதிய தற்காலிகக் கோப்புறைக்குச் செல்லும், நிரல் அங்கே ஓடும், படம் துணை நிரலின் இயந்திரப் பெயருடன் குறிக்கப்பட்டுத் திரும்பும்.

:::note
துணை நிரல்கள் துணை நிரல் API 1.4 இலிருந்து மட்டுமே ரெண்டர் இயந்திரங்களைச் சேர்க்க முடியும். திறந்த மூல கட்டளை-வரி ரெண்டரருக்கான வேலை செய்யப்பட்ட எடுத்துக்காட்டு அதன் சொந்த களஞ்சியத்தில் உள்ளது; அது அந்த ரெண்டரரில் இன்னும் இயக்கப்படவில்லை.
:::
