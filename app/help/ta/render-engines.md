{{ui:படத்தை ரெண்டர் செய்…}} இல் பயன்முறைக்கு மேலே ஒரு **இயந்திரம்** தேர்வு உண்டு. எங்கள் சொந்த இரண்டு இயந்திரங்கள் எப்போதும் இருக்கும், அவை எல்லா இடங்களிலும் வேலை செய்யும்; துணை நிரல்கள் இன்னும் சேர்க்கலாம், மேலும் CadCraft Studio இல் பட்டியலில் காட்சியை எடுத்துக்கொள்ளும் நிரல்களும் இருக்கும்.

| இயந்திரம் | அது என்ன செய்கிறது | எங்கே |
|---|---|---|
| உள்ளமைந்த: Fast | விரைவான நிலைப்படம்: பகல் வெளிச்சம், மென்மையான நிழல்கள், கண்ணாடி மற்றும் உலோகத் தோற்றங்கள், நொடிகளில் | உலாவி மற்றும் Studio |
| உள்ளமைந்த: Path tracer | ஒளி மேற்பரப்புகளுக்கு இடையே குதிப்பது, உங்கள் வரைகலை அட்டை அல்லது செயலியில், ரெண்டர் வரிசை மற்றும் உங்கள் பிணையத்திலுள்ள மற்ற கணினிகள் | உலாவி மற்றும் Studio |
| ஒரு துணை நிரலின் இயந்திரம் | அது வரைந்து படத்தைத் திருப்பித் தரும்: [வேறு நிரலுடன் படத்தை வரை](topic:render-other-program) ஐப் பார் | உலாவி (JavaScript இல் எழுதப்பட்ட இயந்திரம்) அல்லது Studio (ஒரு நிரலை இயக்கும் இயந்திரம்) |
| காட்சியை எடுத்துக்கொள்ளும் ஒரு நிரல் | Studio காட்சியை அதன் கோப்புறையில் வைத்து ஒத்திசைவில் வைத்திருக்கும் | Studio |
| வேறு நிரலில் திற… | காட்சியைச் சேமித்து ஒரு நிரலில் திறக்கும்; எதுவும் திரும்ப வராது: [காட்சியை வேறு நிரலில் திற](topic:render-open-in) ஐப் பார் | இணையம் கோப்பைச் சேமிக்கிறது |

## தேர்வு எப்படி நடந்துகொள்கிறது

- Fast அல்லது Path tracer ஐத் தேர்ந்தெடுத்தால், அதனுடன் பயன்முறையும் மாறும், மற்றொரு வழியிலும். வேறு இயந்திரங்களைப் பயன்படுத்தாதவர்களுக்கு உரையாடலின் மற்ற எதுவும் மாறாது.
- கிடைக்காத இயந்திரம் காரணத்துடன் பட்டியலில் இருக்கும் ("காணப்படவில்லை", "புதிய பதிப்பு தேவை"); அதைத் தேர்ந்தெடுக்க முடியாது. உலாவியில் Studio இல் மட்டும் இயங்கும் இயந்திரம் "கோப்பைச் சேமிக்கும்" எனக் காட்டும்: {{ui:படத்தை ரெண்டர் செய்…}} அப்போது காட்சியையும் அதன் அமைப்புகளையும் அந்த நிரலுக்கு நீங்கள் எடுத்துச் செல்லும் கோப்பில் சேமிக்கும்.
- தேர்வு கோப்பின் ரெண்டர் அமைப்புகளுடன் சேமிக்கப்படும்; கடைசியாகத் தேர்ந்தெடுத்த இயந்திரம் சொந்தத் தேர்வு இல்லாத கோப்புகளுக்கான தொடக்க இயந்திரமாகும்.
- மற்றொரு நிரலின் படம் எந்த நிரல் அதை வரைந்தது, அதன் பதிப்பு என்ன என்று உரையாடலிலும் ரெண்டர் வரிசையிலும் சொல்லும். [ரெண்டர்](topic:render) பக்கத்தின் வாக்குறுதிகள் **எங்கள் சொந்த** இயந்திரங்களுக்கு மட்டுமே: மற்றொரு நிரல் ஒளியூட்டுகிறது, தொனியூட்டுகிறது, மாதிரி எடுக்கிறது தனது சொந்த வழியில், அதனால் ஒரு காட்சியின் இரண்டு படங்கள் கேமரா, சூரியன், விளக்குகள் மற்றும் வெளிப்பாட்டில் ஒத்திருக்கும், பிக்சல் பிக்சல் அல்ல.

## காட்சி ஒவ்வொரு இயந்திரத்துக்கும் என்ன கொடுக்கப்படுகிறது

காட்சி மற்றொரு நிரலுக்கு ஒரு **தொகுப்பாக** செல்கிறது: மாதிரி USD கோப்பாக ([USD ஆக சேமி](topic:usd) எழுதும் அதே கோப்பு), மற்றும் USD இறக்குமதியாளரை நம்ப முடியாதவற்றை வைத்திருக்கும் ஓர் அமைப்புகள் கோப்பு: சரியான பொருள் மதிப்புகள், ஆற்றலும் ஒளிச் சுயவிவரங்களும் கொண்ட இயங்கும் விளக்குகள், சூரியன், வானம், வெளிப்பாடு, மற்றும் உரையாடல் வரையும் விதத்தில் உள்ள கேமரா. எதுவும் எங்கும் பதிவேற்றப்படாது.

## ரெண்டர் வரிசை

மற்றொரு நிரலுக்கான ஒரு படம் அல்லது அனிமேஷன் நமது சொந்தத்தைப் போலவே [ரெண்டர் வரிசையில்](topic:render#the-render-queue) காத்திருக்கலாம்; அதன் வேலை அது எந்த இயந்திரத்துக்கானது என்பதை நினைவில் வைத்திருக்கும். ஓர் அனிமேஷன் ஒரே ஓட்டத்தில் நிரலுக்குச் செல்லும்.
