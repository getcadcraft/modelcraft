Қосымша (Баптаулар › Қосымшалар) {{ui:Суретті рендерлеу…}} Қозғалтқыш тізіміне қозғалтқыш қоса алады. Қосымша авторларына арналған толық мәтін қосымша спецификациясының 16-бөлімінде; қысқаша былай:

- Қосымша өз префиксінен басталатын идентификаторы бар, атауы, қосымша параметрлері және бағдарламаны іске қосатын **немесе** суретті салатын JavaScript функциясы бар қозғалтқышты тіркейді.
- Бағдарламаны іске қосатын қозғалтқыш **`engine.run`** рұқсатын қажет етеді, ол орнатудан бұрын және Баптауларда көрсетіледі. Ол тек Studio-да жұмыс істейді; браузерде ол сақтау үшін файл ретінде көрсетіледі.
- Қосымша бағдарламаның атауын (қарапайым файл атауы: ешқашан shell емес), **қол қойылған қосымшаның ішіндегі** скриптті және плейсхолдерлер мен қарапайым сөздерден тұратын аргументтерді көрсетеді. Studio бағдарламаны табады немесе бір рет оған көрсетуіңізді сұрайды.
- Қосымша бағдарламаны алғаш іске қосқанда, **Studio өз диалогында сұрайды**: қай қосымша, қай бағдарлама, және скрипт бағдарлама істей алатын кез келген нәрсені істей алатыны. Оған тек сенімді қосымша үшін рұқсат етіңіз. Жауабыңыз сол қосымша мен бағдарлама үшін есте сақталады.
- Пакет (USD ретіндегі сахна және параметрлер файлы, қосымша сұраған кезде glTF файлымен бірге) және қосымшаның скрипті жаңа уақытша қалтаға түседі, бағдарлама сол жерде жұмыс істейді, ал сурет қосымшаның қозғалтқыш атауымен белгіленіп қайтады.

:::note
Қосымшалар тек қосымша API 1.4 нұсқасынан бастап рендер қозғалтқыштарын қоса алады. Ашық бастапқы кодты пәрмен жолы рендерері үшін толық мысал оның өз репозиторийінде; ол әлі сол рендерерде іске қосылмаған.
:::
