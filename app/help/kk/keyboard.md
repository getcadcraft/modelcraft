Бұл ModelCraft-тың бастапқы итеру-тарту пернелері. Басқа стиль үшін [Modeler пернелерін](topic:keyboard#modeler-keys) төменнен және [ModelCraft баптауларын](topic:settings) қараңыз.

Жылдам пернелер 3D көрінісі немесе құралдар жолағының батырмасы фокуста болғанда жұмыс істейді. Егер панельдің өрісіне мәтін енгізсеңіз немесе {{ui:Style}} ішіндегі тізімді өзгертсеңіз, алдымен 3D көрінісін басыңыз, әйтпесе пернелер сол өріске кетеді. Пернелердің қалай жазылатынын әр компьютерде қараңыз: [Пернелер, тінтуірлер және сенсорлық тақталар](common:keys).

## Esc

{{key:Esc}} оны басқан сайын бір деңгей артқа қайтарады:

1. Құрал орындап жатқан нәрсені тоқтатады (сызылып жатқан сызық, итеру/тарту, жылжыту). Бәрі бастапқы күйіне оралады.
2. {{ui:Select}} құралына ауысады.
3. Таңдауды тазалайды.
4. Өңдеп жатқан топты жабады.

Ол сахналардың ойнауын да тоқтатады. Мән қорапшасында {{key:Esc}} теріліп жатқан мәнді тазалап, көріністе оралады.

## Құрал жұмыс істеп тұрғанда

| Пернесі | Не істейді |
|---|---|
| Цифр, немесе `. , - ' " [ < * /` белгілерінің бірі | Мән қорапшасына теруді бастайды |
| {{key:Enter}} | Мән қорапшасына терілгенді қолданады |
| {{key:Right}} | Қызыл оське бекітеді (қайта басу — босату) |
| {{key:Left}} | Жасыл оське бекітеді |
| {{key:Up}} | Көк оське бекітеді |
| {{key:Down}} | Бірінші басудан бұрын соңғы көрсеткен қырға параллель бекітеді |
| {{key:Shift}} басып тұру | Басып тұрғанда, ілінген бағытты ұстайды |
| {{key:Ctrl}}, {{key:Mod}} немесе {{key:Alt}} ({{ui:Move}}) | Жылжыту мен көшіру арасында ауысады |

Көрсеткі пернелерінің бекітулері {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} және {{ui:Tape}} (нүктеден өлшеу кезінде) құралдарында бірінші басудан кейін жұмыс істейді. {{ui:Push/pull}} әрқашан бет бағыты бойымен жылжиды және бекіткіштері жоқ. {{ui:Rotate}} құралында көрсеткі пернелері бірінші басудан кейін "Locked" хабарын көрсетеді, бірақ бұрылуды өзгертпейді.

## Басқа уақыттағы көрсеткі пернелері

Құрал ештеңе орындамаған кезде көрсеткі пернелері камераны жылжытады:

| Пернесі | Не істейді |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Айналдыру |
| {{key:Shift}} және көрсеткі | Көріністі жылжыту |

## Тінтуір

| Әрекет | Не істейді |
|---|---|
| Басу | Ағымдағы құралды қолданады |

| Екі рет басу | {{ui:Select}}: бетті оның қырларымен, қырды оның беттерімен, топты ашады; бос орында топты жабады. {{ui:Push/pull}}: соңғы қашықтықты қайталайды |
| Үш рет басу | {{ui:Select}}: байланысқанның бәрі |

| {{key:Mod}} + басу | {{ui:Select}}: таңдауға қосады |

| Орта түйменің сүйреуі | Кез келген құрал арқылы айналдыру |
| {{key:Shift}} + орта түйменің сүйреуі | Кез келген құрал арқылы көріністі жылжыту |
| Оң түйменің сүйреуі | Кез келген құрал арқылы көріністі жылжыту |

## Сенсорлық тақта

Екі саусақпен сырғыту не істейтіні {{ui:Settings}} › {{ui:ModelCraft}} › Scrolling параметріне байланысты:

| Қимыл | Сенсорлық тақта (немесе есептелген) | Тінтуір дөңгелегі |
|---|---|---|
| Екі саусақпен сырғыту | Айналу | Көрсеткіш жаққа масштабтау |
| {{key:Shift}} + екі саусақпен сырғыту | Көріністі жылжыту | Масштабтау |
| Қысу | Көрсеткіш жаққа масштабтау | Көрсеткіш жаққа масштабтау |
| Екі саусақпен басу және сүйреу (екінші реттік басу ұсталған) | Көріністі жылжыту | Көріністі жылжыту |

Қараңыз: [Айналу, жылжыту және масштабтау](topic:orbit-pan-zoom#on-a-trackpad) және [ModelCraft баптаулары](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Сенсорлық экран

| Қимыл | Не істейді |
|---|---|
| Түрту | Ағымдағы құралмен басу |
| Екі рет түрту | Екі рет басу |
| Басу, сүйреу, көтеру | Тінтуірмен басу, сүйреу, босатумен бірдей |
| Екі саусақ: қысу | Масштабтау |
| Екі саусақ: бірге жылжыту | Жылжыту (Settings › ModelCraft › Touch screen арқылы Айналу қылуға болады) |
| Үш саусақ: бірге жылжыту | Айналдыру (екі саусақ айналдырса — Жылжыту) |
| Бір саусақты тыныш ұстау | Құралды аяқтайды, Enter сияқты; ештеңе болмаса, содан кейін сүйрегенде айналдырады |
| Бір саусақты әрекет кезіндегі екінші саусақ | Сол әрекетті болдырмайды |
| {{ui:Orbit}} құралы, содан кейін бір саусақпен сүйреу | Айналдыру |

Сенсорлық экранда мән теру үшін, төмендегі мән қорапшасын түртіңіз, теріңіз және пернетақтаның Enter (немесе Go) батырмасын басыңыз.

## Жылжыту қайда

Жылжыту {{ui:Move}} құралында, {{key:M}} пернесінде: нәрсені таңдаңыз, базалық нүктені басыңыз, содан кейін екінші нүктені немесе қашықтықты теріңіз. Қараңыз: [Жылжыту, көшіру және массивтер жасау](topic:move-copy).
