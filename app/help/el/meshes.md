Το ModelCraft έχει δύο είδη γεωμετρίας. Η **γεωμετρία push/pull** είναι αυτό που σχεδιάζετε: επίπεδες έδρες που κολλούν μεταξύ τους, κόβουν η μία την άλλη και ενώνονται ξανά. Ένα **mesh** είναι το είδος αντικειμένου με το οποίο μοντελοποιούν τα εργαλεία 3D περιεχομένου: έδρες με οποιοδήποτε πλήθος γωνιών, με κάθε γωνία να μπορεί να φέρει τις δικές της συντεταγμένες υφής (UV), κανονικά και χρώματα, και κάθε κορυφή τιμές όπως τα βάρη. Ένα mesh τοποθετείται όπως μια ομάδα ή ένα στοιχείο, και βρίσκεται δίπλα στη γεωμετρία push/pull στο ίδιο μοντέλο.

## Μετατροπή ομάδας ή στοιχείου σε mesh

1. Επιλέξτε μια ομάδα ή ένα στοιχείο.
2. Στις {{ui:Πληροφορίες οντότητας}}, κάντε κλικ στο {{ui:Μετατροπή σε mesh}}.

Οι έδρες του γίνονται έδρες του mesh (μια έδρα με οπές εισάγεται ως τρίγωνα), οι σκληρές ακμές μένουν αιχμηρές, οι μαλακές ακμές σκιάζονται ομαλά, και η βαφή, τα υλικά και οι εισαγόμενες υφές μένουν στις έδρες τους. Οι ομάδες και τα στοιχεία που περιέχει ενώνονται σε ένα mesh. Οι ελεύθερες ακμές παραλείπονται: ένα mesh κρατά έδρες. Κάθε τοποθέτηση ενός στοιχείου δείχνει το mesh. Είναι ένα βήμα αναίρεσης.

## Τι δείχνουν οι Πληροφορίες οντότητας

Επιλέξτε ένα mesh για να δείτε τις έδρες, τις κορυφές και τις ακμές του, αν είναι κλειστό στερεό (και τον όγκο του), και το μέγεθός του όπως τοποθετήθηκε. Ένα mesh με ανοιχτές ακμές λέει πόσες είναι.

## Μετατροπή mesh πίσω σε γεωμετρία push/pull

Επιλέξτε το mesh και κάντε κλικ στο {{ui:Μετατροπή σε γεωμετρία}}. Οι επίπεδες έδρες επιστρέφουν όπως ήταν· μια έδρα της οποίας οι γωνίες δεν βρίσκονται σε ένα επίπεδο επιστρέφει ως τρίγωνα. Οι αιχμηρές ακμές είναι σκληρές, οι υπόλοιπες μαλακές. Η {{ui:Ανάλυση}} τοποθετεί απευθείας τις έδρες ενός mesh στην ομάδα που το περιβάλλει.

## Καλό είναι να γνωρίζετε

- Κάντε διπλό κλικ σε ένα mesh για να [επεξεργαστείτε τις κορυφές, τις ακμές και τις έδρες του](topic:mesh-edit) στον χώρο εργασίας Mesh. Μετατρέψτε το σε γεωμετρία για να το επεξεργαστείτε με push/pull· μετακινήστε, περιστρέψτε, κλιμακώστε, αντιγράψτε, βάψτε, αποκρύψτε και επισημάνετε το όπως κάθε ομάδα.
- Οι εξαγωγές, η εκτύπωση 3D, τα render και το VR βλέπουν ένα mesh ως τις έδρες του.
- Ένα αρχείο που περιέχει mesh αποθηκεύεται ως νεότερη έκδοση του αρχείου `.modelcraft`, οπότε το ModelCraft 0.6 και παλαιότερα δεν μπορούν να το ανοίξουν· τα αρχεία χωρίς mesh ανοίγουν σε αυτές όπως και πριν. Μετατρέψτε πρώτα τα mesh σε γεωμετρία για να μοιραστείτε ένα αρχείο με κάποιον που έχει παλαιότερη έκδοση.
- Η αναίρεση σε ένα mesh κρατά μόνο όσα άλλαξε κάθε βήμα, οπότε ακόμη και ένα πολύ μεγάλο mesh αναιρείται γρήγορα.
