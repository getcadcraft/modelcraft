Αυτά είναι τα πλήκτρα της ώθησης/έλξης, με τα οποία ξεκινά το ModelCraft. Για το άλλο στυλ, δείτε [Πλήκτρα Modeler](topic:keyboard#modeler-keys) παρακάτω και [Ρυθμίσεις ModelCraft](topic:settings).

Οι συντομεύσεις λειτουργούν όταν έχει εστίαση η 3D προβολή ή ένα κουμπί της γραμμής εργαλείων. Αν μόλις πληκτρολογήσατε σε πεδίο πάνελ ή αλλάξατε λίστα στο {{ui:Στυλ}}, κάντε κλικ πρώτα στην 3D προβολή, αλλιώς τα πλήκτρα πάνε σε εκείνο το πεδίο. Δείτε [Πλήκτρα, ποντίκια και trackpad](common:keys) για το πώς γράφονται τα πλήκτρα σε κάθε υπολογιστή.

## Esc

Το {{key:Esc}} κάνει ένα βήμα πίσω κάθε φορά που το πατάτε:

1. Ακυρώνει ό,τι κάνει το εργαλείο αυτή τη στιγμή (μια γραμμή που σχεδιάζεται, μια ώθηση/έλξη, μια μετακίνηση). Όλα επιστρέφουν πίσω.
2. Αλλάζει σε {{ui:Επιλογή}}.
3. Καθαρίζει την επιλογή.
4. Κλείνει την ομάδα που επεξεργάζεστε.

Σταματά επίσης τις σκηνές που παίζουν. Στο πλαίσιο τιμής, το {{key:Esc}} σβήνει ό,τι πληκτρολογήσατε και επιστρέφει στην προβολή.

## Όσο ένα εργαλείο λειτουργεί

| Πλήκτρο | Κάνει |
|---|---|
| Ένα ψηφίο, ή ένα από τα `. , - ' " [ < * /` | Αρχίζει πληκτρολόγηση στο πλαίσιο τιμής |
| {{key:Enter}} | Εφαρμόζει ό,τι πληκτρολογήσατε στο πλαίσιο τιμής |
| {{key:Right}} | Κλειδώνει στον κόκκινο άξονα (πατήστε ξανά για ξεκλείδωμα) |
| {{key:Left}} | Κλειδώνει στον πράσινο άξονα |
| {{key:Up}} | Κλειδώνει στον μπλε άξονα |
| {{key:Down}} | Κλειδώνει παράλληλα στην τελευταία ακμή από την οποία περάσατε πριν από το πρώτο κλικ |
| Κρατήστε πατημένο το {{key:Shift}} | Κρατά την κατεύθυνση στην οποία είστε κουμπωμένοι, όσο είναι πατημένο |
| {{key:Ctrl}}, {{key:Mod}} ή {{key:Alt}} (Μετακίνηση) | Εναλλάσσει μεταξύ μετακίνησης και αντιγραφής |

Τα κλειδώματα με πλήκτρα βέλους λειτουργούν στις {{ui:Γραμμή}}, {{ui:Ορθογώνιο}}, {{ui:Κύκλος}}, {{ui:Πολύγωνο}}, {{ui:Μετακίνηση}}, {{ui:Κλιμάκωση}} και {{ui:Μετροταινία}} (όταν μετράτε από σημείο), μετά το πρώτο κλικ. Η {{ui:Ώθηση/έλξη}} κινείται πάντα στην κατεύθυνση της έδρας και δεν έχει κλειδώματα. Στην {{ui:Περιστροφή}} τα πλήκτρα βέλους δείχνουν μήνυμα «Κλειδωμένο» μετά το πρώτο κλικ, αλλά δεν αλλάζουν τη στροφή.

## Πλήκτρα βέλους σε άλλες στιγμές

Όταν κανένα εργαλείο δεν βρίσκεται στη μέση μιας ενέργειας, τα πλήκτρα βέλους μετακινούν την κάμερα:

| Πλήκτρο | Κάνει |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Τροχιά |
| {{key:Shift}} με βέλος | Μετατόπιση |

## Ποντίκι

| Ενέργεια | Κάνει |
|---|---|
| Κλικ | Χρησιμοποιεί το τρέχον εργαλείο |
| Πατήστε, σύρετε, αφήστε | Το ίδιο με δύο κλικ (για εργαλεία σχεδίασης)· επιλογή με πλαίσιο (για την {{ui:Επιλογή}})· διαγράφει στον δρόμο του (για τη {{ui:Γόμα}}) |
| Διπλό κλικ | {{ui:Επιλογή}}: έδρα με τις ακμές της, ακμή με τις έδρες της, ανοίγει ομάδα· ο κενός χώρος κλείνει την ομάδα. {{ui:Ώθηση/έλξη}}: επαναλαμβάνει την τελευταία απόσταση |
| Τριπλό κλικ | {{ui:Επιλογή}}: ό,τι είναι συνδεδεμένο |
| {{key:Shift}} + κλικ | {{ui:Επιλογή}}: εναλλαγή μέσα και έξω από την επιλογή |
| {{key:Mod}} + κλικ | {{ui:Επιλογή}}: προσθήκη στην επιλογή |
| {{key:Shift}} + {{key:Mod}} + κλικ | {{ui:Επιλογή}}: αφαίρεση από την επιλογή |
| Σύρση με το μεσαίο κουμπί | Τροχιά, με οποιοδήποτε εργαλείο |
| {{key:Shift}} + σύρση με το μεσαίο κουμπί | Μετατόπιση, με οποιοδήποτε εργαλείο |
| Σύρση με το δεξί κουμπί | Μετατόπιση, με οποιοδήποτε εργαλείο |
| Τροχός | Ζουμ προς τον δείκτη |

Δεν υπάρχει μενού με δεξί κλικ.

## Trackpad

Το τι κάνει ένα σάρωμα με δύο δάχτυλα εξαρτάται από το {{ui:Ρυθμίσεις}} › {{ui:ModelCraft}} › Κύλιση:

| Χειρονομία | Trackpad (ή συμπέρασμα) | Τροχός ποντικιού |
|---|---|---|
| Σάρωμα με δύο δάχτυλα | Τροχιά | Ζουμ προς τον δείκτη |
| {{key:Shift}} + σάρωμα με δύο δάχτυλα | Μετατόπιση | Ζουμ |
| Τσίμπημα (pinch) | Ζουμ προς τον δείκτη | Ζουμ προς τον δείκτη |
| Πάτημα και σύρση με δύο δάχτυλα (κρατημένο δευτερεύον κλικ) | Μετατόπιση | Μετατόπιση |

Δείτε [Τροχιά, μετατόπιση και ζουμ](topic:orbit-pan-zoom#on-a-trackpad) και [Ρυθμίσεις ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Πλήκτρα Modeler

Με το {{ui:Ρυθμίσεις}} › {{ui:ModelCraft}} › Έλεγχοι ρυθμισμένο σε στυλ Modeler:

| Πλήκτρο | Κάνει |
|---|---|
| {{key:W}} ή {{key:Space}} | {{ui:Επιλογή}} |
| {{key:L}} / {{key:B}} / {{key:C}} / {{key:N}} | {{ui:Γραμμή}} / {{ui:Ορθογώνιο}} / {{ui:Κύκλος}} / {{ui:Πολύγωνο}} |
| {{key:E}} | {{ui:Ώθηση/έλξη}} (εξώθηση) |
| {{key:T}} | Μέτρηση με τη {{ui:Μετροταινία}} |
| {{key:D}} | {{ui:Διάσταση}} |
| {{key:G}} | Μετακίνηση της επιλογής αμέσως, από τον δείκτη |
| {{key:R}} | Περιστροφή της επιλογής γύρω από το μέσο της (μπλε άξονας) |
| {{key:S}} | Κλιμάκωση της επιλογής γύρω από το μέσο της |
| {{key:X}} / {{key:Y}} / {{key:Z}} ενώ μετακινείτε ή περιστρέφετε | Κλειδώνει τον κόκκινο / πράσινο / μπλε άξονα (ξανά για ξεκλείδωμα) |
| Κλικ ή {{key:Enter}} | Αφήστε το στη θέση του |
| {{key:Esc}} ή δεξί κλικ | Επαναφέρετε το στην αρχική του θέση |
| {{key:Shift+D}} | Δημιουργία διπλότυπου και μετακίνηση του αντιγράφου |
| {{key:X}} ή {{key:Delete}} | Διαγραφή της επιλογής |
| {{key:A}} / {{key:Alt+A}} | Επιλογή όλων / αποεπιλογή όλων |
| {{key:Tab}} | Άνοιγμα της επιλεγμένης ομάδας ή στοιχείου· ξανά για κλείσιμο |
| {{key:Mod+G}} / {{key:Mod+Shift+G}} | Δημιουργία ομάδας / δημιουργία στοιχείου |
| Numpad {{key:1}} / {{key:3}} / {{key:7}} | Όψη από μπροστά / δεξιά / πάνω ({{key:Mod}} για πίσω / αριστερά / κάτω) |
| Numpad {{key:5}} | Προοπτική ενεργή ή ανενεργή |
| Numpad {{key:.}} | Ζουμ στην επιλογή |
| {{key:Home}} ή {{key:Shift+C}} | Ζουμ στα όρια |
| {{key:Shift+Tab}} | Snap ενεργό ή ανενεργό |
| Σύρση με το μεσαίο κουμπί / με {{key:Shift}} / με {{key:Mod}} | Τροχιά / μετατόπιση / ζουμ |

Η αντιγραφή, η επικόλληση, η αναίρεση, η αποθήκευση και το άνοιγμα κρατούν τα πλήκτρα που αναφέρονται παραπάνω. Οι πληκτρολογημένες τιμές, το πλαίσιο τιμής και η {{ui:Ώθηση/έλξη}} λειτουργούν το ίδιο και στα δύο στυλ.

## Οθόνη αφής

| Χειρονομία | Κάνει |
|---|---|
| Πάτημα | Ένα κλικ με το τρέχον εργαλείο |
| Διπλό πάτημα | Ένα διπλό κλικ |
| Πάτημα, σύρση, άρση | Το ίδιο με πάτημα, σύρση, αφήσιμο με ποντίκι |
| Δύο δάχτυλα: τσίμπημα | Ζουμ |
| Δύο δάχτυλα: κίνηση μαζί | Μετατόπιση (Ρυθμίσεις › ModelCraft › Οθόνη αφής μπορεί να την κάνει Τροχιά) |
| Τρία δάχτυλα: κίνηση μαζί | Τροχιά (Μετατόπιση όταν τα δύο δάχτυλα κάνουν τροχιά) |
| Ένα δάχτυλο ακίνητο για λίγο | Τελειώνει το εργαλείο, όπως το Enter· χωρίς τίποτα σε εξέλιξη, μετά σύρετε για τροχιά |
| Δεύτερο δάχτυλο κατά τη διάρκεια ενέργειας με ένα δάχτυλο | Ακυρώνει αυτή την ενέργεια |
| Εργαλείο {{ui:Τροχιά (Orbit)}}, μετά σύρση με ένα δάχτυλο | Τροχιά |

Για να πληκτρολογήσετε τιμή σε οθόνη αφής, πατήστε στο πλαίσιο τιμής κάτω, πληκτρολογήστε, και πατήστε το πλήκτρο Enter (ή Go) του πληκτρολογίου.

## Πού βρίσκεται η Μετακίνηση

Η {{ui:Μετακίνηση}} βρίσκεται στο εργαλείο {{ui:Μετακίνηση}}, με πλήκτρο {{key:M}}: επιλέξτε τι θα μετακινηθεί, κάντε κλικ σε ένα σημείο βάσης, και μετά σε ένα δεύτερο σημείο ή πληκτρολογήστε μια απόσταση. Δείτε [Μετακίνηση, αντιγραφή και δημιουργία παράταξης](topic:move-copy).
