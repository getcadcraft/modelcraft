Ова се клучевите за турни/повлечи, оние со кои ModelCraft почнува. За другиот стил, види [Modeler keys](topic:keyboard#modeler-keys) подолу и [Поставки на ModelCraft](topic:settings).

Кратенките работат кога 3D прегледот или копчето на алатка има фокус. Ако штотуку напишеше во поле на панел или промени листа во {{ui:Style}}, прво кликни во 3D прегледот, инаку клучевите одат во тоа поле. Види [Клучеви, глувчиња и тачпеди](common:keys) за тоа како се пишуваат клучевите на секој компјутер.

## Esc

{{key:Esc}} се враќа по едно ниво секој пат кога ќе го притиснеш:

1. Ја откажува работата што алатката ја прави (линија што се црта, турни/повлечи, поместување). Сè се враќа.
2. Преминува на {{ui:Select}}.
3. Го брише изборот.
4. Ја затвора групата што ја уредуваш.

Исто така ги запира сцените. Во кутијата со вредност, {{key:Esc}} ја брише внесената вредност и враќа на прегледот.

## Додека алатка работи

| Клуч | Прави |
|---|---|
| Цифра, или еден од знаците `. , - ' " [ < * /` | Почнува внесување во кутијата со вредност |
| {{key:Enter}} | Го применува внесеното во кутијата со вредност |
| {{key:Right}} | Заклучува на црвената оска (притисни повторно за отклучување) |
| {{key:Left}} | Заклучува на зелената оска |
| {{key:Up}} | Заклучува на сината оска |
| {{key:Down}} | Заклучува паралелно со последниот раб над кој поминал пред првиот клик |
| Држи {{key:Shift}} | Ја држи насоката на која си прилепен, додека е притиснат |
| {{key:Ctrl}}, {{key:Mod}} или {{key:Alt}} (Move) | Префрла помеѓу поместување и копирање |

Заклучувањата со стрелки работат во {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} и {{ui:Tape}} (кога мериш од точка), по првиот клик. {{ui:Push/pull}} секогаш се движи по насоката на лицето и нема заклучувања. Во {{ui:Rotate}}, стрелките по првиот клик покажуваат порака „Заклучено“, но не го менуваат вртењето.

## Глушец

| Постапка | Прави |
|---|---|
| Клик | Ја користи тековната алатка |
| Притисни, влечи, пушти | Исто како два клика (за алатки за цртање); избор со прозорец (за {{ui:Select}}); брише по патот (за {{ui:Eraser}}) |
| Двоен клик | {{ui:Select}}: лице со неговите рабови, раб со неговите лица, отвора група; празен простор ја затвора групата. {{ui:Push/pull}}: ја повторува последната дистанца |
| Тројен клик | {{ui:Select}}: сè поврзано |
| {{key:Shift}} + клик | {{ui:Select}}: вклучи или исклучи од изборот |
| {{key:Mod}} + клик | {{ui:Select}}: додај во изборот |
| {{key:Shift}} + {{key:Mod}} + клик | {{ui:Select}}: отстрани од изборот |
| Влечење со средното копче | Орбита, со која било алатка |
| {{key:Shift}} + влечење со средното копче | Помести поглед, со која било алатка |
| Влечење со десното копче | Помести поглед, со која било алатка |
| Тркало | Зумирај кон покажувачот |

Нема контекстно мени со десен клик.

| Гест | Тачпед (или пресметано) | Тркало на глушецот |
|---|---|---|
| Двопристо лизгање | Орбита | Зумирај кон покажувачот |
| {{key:Shift}} + двопристо лизгање | Помести поглед | Зумирај |
| Штипкање | Зумирај кон покажувачот | Зумирај кон покажувачот |
| Двопристо притиснување и влечење (држено секундарно копче) | Помести поглед | Помести поглед |

Види [Орбита, поместување и зумирање](topic:orbit-pan-zoom#on-a-trackpad) и [Поставки на ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Допирен екран

| Гест | Прави |
|---|---|
| Допир | Клик со тековната алатка |
| Двоен допир | Двоен клик |
| Притисни, влечи, дигни | Исто како притисни, влечи, пушти со глушец |
| Два прста: штипкање | Зумирај |
| Два прста: движење заедно | Помести поглед (Поставки › ModelCraft › Допирен екран може да го направи Орбита) |
| Три прсти: движење заедно | Орбита (Помести поглед кога два прсти вртат орбита) |
| Држи еден прст мирен | Ја завршува алатката, како Enter; кога ништо не се случува, влечи за орбита |
| Втор прст за време на едно-прстна работа | Ја откажува таа работа |
| Алатка {{ui:Orbit}}, па влечи еден прст | Орбита |

За да внесеш вредност на допирен екран, допри ја кутијата со вредност долу, напиши и притисни Enter (или Go) на тастатурата.
