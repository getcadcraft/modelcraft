Моделдөөнү аны жасаган жеринде улантыңыз, ал эми натыйжаны бул жерде колдонуңуз: рендерлөө, жарыктандыруу же анын айланасына сахна түзүү үчүн. Башка программадагы ар бир өзгөртүү ModelCraft ичиндеги бир топту жаңыртат.

:::note
Шилтеме бир эле компьютерде **CadCraft Studio** талап кылат. Браузердин өтмөгү байланышты кабыл ала албайт. Интернет аркылуу эч нерсе өтпөйт: скрипт Studio менен ушул компьютердин өз дареги боюнча, токен менен сүйлөшөт.
:::

:::warning
Бул шилтеме скрипттин файл жазгычы жана башка программанын ордун басуучу менен текшерилди, Rhino же Grasshopper ичинде али сыналган жок. Ал жерде бир нерсе ишке ашпаса, анда кандай билдирүү чыкканын бизге айтыңыз.
:::

## Орнотуу

1. Studio'до ModelCraft ачыңыз. {{ui:Жөндөөлөр}} › {{ui:ModelCraft}} › {{ui:Ассистенттер}} бөлүмүндө **AI жардамчыларга жана скрипттерге ModelCraft колдонууга уруксат берүү** белгисин коюп, андан кийин **Түзөтүү** баскычын басыңыз.
2. Studio'до {{ui:Ассистентти туташтыруу}} тандаңыз. Ал төмөндө чаптаган даректи жана токенди көрсөтөт.
3. Скриптти жүктөп алыңыз: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino'дон

1. `cadcraft_link.py` скриптин Rhino скрипт редакторунда иштетиңиз (Rhino 8'де Python 3).
2. Биринчи жолу даректи жана токенди чаптаңыз. Алар үй папкаңыздагы `.cadcraft-link.json` файлында сакталат, моделде эч качан эмес. Studio ар бир ишке киргенде жаңы токен жаратат, ошондо скрипт кайра сурайт.

Бүтүн модель документтин атындагы бир топ катары келет, мисалы « chair (linked) ». Андан кийин ар бир өзгөртүү бир аз токтогондо келет, жана өзгөргөн объекттер гана жөнөтүлөт. Токтотуу үчүн скриптти кайра иштетиңиз.

## Grasshopper'дон

Адегенде скриптти Rhino'до бир жолу иштетиңиз, дарек жана токен сакталсын.

1. Python 3 Script компонентин кошуңуз жана `cadcraft_link.py` скриптин толугу менен ага чаптаңыз.
2. Ага мындай киргизүүлөрдү бериңиз: `G` (геометрия, тизме кирүүсү менен), `N` (ат, милдеттүү эмес), `On` (булеан которгуч), жана `Target` (милдеттүү эмес: `model` же `part`, эгер эки колдонмо тең ачык болсо).
3. `On` маанисин true кылыңыз.

Ар бир эсептөө `G` жөнөтөт жана компонент акыркы жолу жөнөткөндү алмаштырат, ошондуктан сүргүчтү сүйрөгөндө бул жердеги топ жаңырат. Анын `a` чыгышы эмне болгонун көрсөтөт. Ар бир компонентте өз тобу бар.

## Топ менен эмне кылууга болот

- **Жылдырыңыз, белгилеңиз, айланасына куруңуз.** Топту жана анын белгисин кайда койгонуңуз ар бир жаңыртууда сакталат, ошондой эле анын жанындагы бардыгы да.
- **Ичин түзөтпөңүз.** Ар бир жаңыртуу топтун ичиндегини алмаштырат. Ал объекттер башка программага таандык.
- **Артка кайтаруу.** Бири-биринен эки секунд ичинде болгон жаңыртуулар бир артка кайтаруу кадамын бөлүшөт, ошондуктан {{key:Mod+Z}} бүтүн сүйрөөнү артка кайтарат. Кийинки жаңыртуу модельди дал келтирет.
- **Сактоо.** Сакталган файл шилтемени сактайт. Файлды кайра ачкандан кийин скриптти кайра иштетиңиз, ошол эле топ жаңырат.

## Эмне келет

Мештер, полибеттер, беттер жана сунулмалар экранда көрүнгөн меш катары, SubD өзүнүн меши катары, ийри сызыктар кырлар катары, блоктор турган жеринде өз алдынча объекттер катары (компоненттер катары эмес), катмарлар белгилер катары, түстөр жана бирдиктер. Алар бул жерде кандай көрүнөөрү үчүн [.3dm моделин киргизүү](topic:import-3dm-files) бөлүмүн караңыз.

Чыгарылып калат, башка программадагы саны менен: чекиттер, текст, өлчөмдөр, жарыктар жана ушул сыяктуулар.

**Бир багытта гана.** Бул жердеги өзгөртүүлөр башка программага кайтпайт.

## Ката болгондо

- « ModelCraft же PartCraft терезеси мүмкүнчүлүк бербейт »: орнотуунун 1-кадамын аткарыңыз.
- « Studio токенди кабыл алган жок »: Studio кайра ишке кирди. Жаңы токенди көчүрүп, скриптти кайра иштетиңиз. Grasshopper үчүн адегенде Rhino'до иштетиңиз.
- « CadCraft Studio'га жетүү мүмкүн эмес »: Studio иштебей жатат, же дарек өзгөрдү.
