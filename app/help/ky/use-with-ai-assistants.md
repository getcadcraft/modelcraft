## Эмне үйрөнөсүз

AI жардамчысын (же сиз жазган скриптти) ModelCraft менен кантип иштетүүнү жана ал эмнелерге кол тийгизе аларын кантип чечүүнү.

ModelCraft'та **өзүнүн AI'ы жок** жана эч нерсени эч жерге жөнөтпөйт. Жардамчыны өзүңүз алып келесиз: Model Context Protocol (MCP) тилин сүйлөгөн каалаган программа. ModelCraft ага куралдарды гана берет, ал эми кайсыларын берерин сиз тандайсыз.

## Жандыруу

1. Ачыңыз {{ui:Жөндөөлөр}} (башкы тилкедеги тиштүү дөңгөлөк сүрөтчөсү же {{key:Mod+,}}) жана {{ui:ModelCraft}} өтмөгүнө өтүңүз.
2. {{ui:Ассистенттер}} астында **AI жардамчыларына жана скрипттерге ModelCraft'ты колдонууга уруксат берүү** белгисин коюңуз. Сиз муну кылмайынча ал өчүк турат.
3. Эмнени кылууга болоорун тандаңыз: **Окуу** баштапкыда белгиленген; **Өзгөртүү**, **Сактоо** же **Экспорттоо** керек болгондо гана белгилеңиз.

Сиз белгилебеген уруксаттарга таандык куралдар жардамчыга сунушталбайт. Ал мындайларды сураса да, ModelCraft аларды четке кагып, иш-аракеттер журналына жазат. Өчүргүч өчүрүлгөндө бардык туташуулар бир заматта үзүлөт; {{ui:ModelCraft жөндөөлөрүн калыбына келтирүү}} аны да өчүрөт.

## Жардамчыңызды туташтыруу

Жардамчылар сиздин компьютериңиздеги **CadCraft Studio** аркылуу туташат: Studio ушул компьютер гана жете ала турган кичине серверди иштетет, ал ар бир ишке киргенде өзү түзгөн токен менен корголот. Studio'до {{ui:Ассистентти туташтыруу}} тандап, даректи жана токенди жардамчыңызга көчүрүңүз (Studio туура орнотууларды так көрсөтөт). Токенди эч кимге бербеңиз.

:::note
Браузердеги өтмө жардамчы үчүн туташуу ача албайт: браузердеги колдонмолордо өчүргүчтүн эч кандай таасири жок, сиз вашем компьютериндеги CadCraft Studio колдонмоюнча.
:::

## Башкаруу сизде бойдон калат

- **Ар бир өзгөртүү артка кайтаруунун бир кадамы**, жана ал жардамчынын аты менен белгиленет (мисалы, «Assistant: box»). {{key:Mod+Z}} жардамчынын акыркы өзгөртүүсүн толугу менен артка кайтарат.
- **Туташкан жардамчыны билип турасыз.** Башкы тилкедеги баскыч туташкан учурда жардамчынын атын көрсөтөт; аны басып, эмне кыла аларын көрүңүз же **Ажыратуу** кылыңыз.
- **Иш-аракеттер.** {{ui:Жөндөөлөр}} › {{ui:ModelCraft}} › {{ui:Ассистенттер}} › {{ui:Иш-аракеттер}} ар бир чакырууну тизмелейт: качан, кайсы курал, аткарылдыбы же четке кагылдыбы. {{ui:Журналды сактоо}} анын көчүрмөсүн сактайт.

## Жардамчы эмнени сурай алат

| Курал | Уруксат | Эмне кылат |
|---|---|---|
| `app_info`, `model_describe` | Окуу | Модельдин бирдиги, өлчөмү, ар бир топ жана компонент жайгашкан жери, жабык катуу дене экендиги жана анын көлөмү |
| `view_screenshot` | Окуу | 3D көрүнүштүн көрүнүп турган сүрөтү |
| `box_add`, `cylinder_add` | Өзгөртүү | Куб же цилиндр жаңы топ катары, сиз же ал берген жерде жана өлчөмдө («3m», «10'» же модель бирдигиндеги сан) |
| `instance_move`, `instances_erase` | Өзгөртүү | Топторду же компоненттерди жылдырат же өчүрөт |
| `faces_list`, `materials_list` | Окуу | Топтун же байланбаган геометриянын беттери (ар бирине багыты, аянты жана борбору); ал боёй ала турган материалдар жана түстөр |
| `push_pull` | Өзгөртүү | Бетти {{ui:Түртүү/тартуу}} сыяктуу түрөт же тартат |
| `paint` | Өзгөртүү | Беттерди же бүт топту түс же материал менен боёйт |
| `group_make` | Өзгөртүү | Байланбаган беттерден жана топтордон топ же компонент жасайт |
| `scene_add`, `scene_show` | Өзгөртүү | Көрүнүштү сахна катары сактайт; сакталган сахнага өтөт |
| `mesh_add` | Өзгөртүү | Баштоо үчүн меш объект (куб, сфера, цилиндр ж.б.), {{ui:Mesh}} жумуш мейкиндиги кошкондой |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | Окуу / Өзгөртүү | Мештин модификаторлор катмары: зеркало, массив, субдивизия, фаска жана калгандары; эч нерсе түбөлүккө колдонулбайт |
| `usd_export` | Экспорттоо | Модель OpenUSD катары (`.usda`, `.usdc` же `.usdz`), модельди USD катары сактаган сыяктуу ([USD](topic:usd)); Studio'до уруксат берилген папкага, болбосо жүктөө катары |
| `render_still` | Экспорттоо | Көрүнүштүн же сакталган сахнанын рендерленген сүрөтү, {{ui:Render}} диалогундагы {{ui:Render}} баскычы жасагандай, Рендер жөндөөлөрүңүз менен, эгер ал башкаларын сурабаса (сахна пресети: тышкы, ички, кесим, түнкү же автоматтык; тез же жогорку сапат, өлчөм, үлгүлөр, асман); жардамчы карай ала турган PNG же Studio'до уруксат берилген папкадагы PNG, EXR же рендер файлы ([Сүрөттү рендерлөө](topic:render)) |
| `render_queue` | Экспорттоо | Рендер диалогунун {{ui:Render queue}} кезегине жогорку сапаттагы сүрөттөрдү кошот (көрүнүш же сакталган сахналар) жана кезекти иштетет; даяр сүрөттөр уруксат берилген папкага барат же сиз үчүн кезекте калат. WebGPU керек |
| `link_push` | Өзгөртүү | Башка программадан шилтелген модельди жаңыртат (караңыз: [.3dm моделин тирүү кармоо](topic:live-3dm-link)) |
| `link_status` | Окуу | Шилтелген модель дагы бар-жогун жана акыркы жолу качан жаңыргандыгын айтат |
| `undo` | Өзгөртүү | Өзүнүн кадамдарын артка кайтарат |

Жардамчы түзгөн катуу денелер топтор катары келет, ошондуктан сиз чийген нерселер менен эч качан кошулушпайт. Моделди сактоочу курал жок: сактоо сизде калат, ал эми экспорттоо же рендерлөө **Экспорттоо** белгиленишин талап кылат. Рендер моделди өзгөртпөйт; сакталган сахнаны рендерлөө көрүнүштү ага жылдырат, {{ui:Сахналар}} сыяктуу.

## Эгер бир нерсе иштебесе

- **Жардамчы ModelCraft куралдарын көрбөйт:** ушул терезедеги өчүргүч күйгүзүлгөнүн жана терезе Studio'до ачык экенин текшериңиз.
- **«needs the edit permission»:** {{ui:Ассистенттер}} астында **Өзгөртүү** белгилеңиз, андан кийин кайра сураңыз.
- **«401» же «token» каталары:** токен өзгөрдү (Studio кайра иштеди же {{ui:Жаңы токен}}). Жаңы токенди жардамчынын жөндөөлөрүнө көчүрүңүз.
