{{ui:Экспорттоо}} › {{ui:Тирүү көрүнүш}} моделдин үстүндө панель ачат, ал моделди чыныгы убакыттагы көрүнүштө көрсөтөт: модель жайгашкан жер жана дата боюнча асман менен күн, күндүн көлөкөлөрү, беттерге берилген көрүнүштөр жана материалдар, чырактар, жана дубалдардан жана полдордон чагылган жарык. Сиз эмне кыласыз, ошону ээрчийт: көрүнүштү бурсаңыз ал да бурулат, моделди өзгөртсөңүз бир аздан кийин өзгөрүүнү көрсөтөт. Эч нерсе жүктөлүп салынбайт.

## Ачуу

1. {{ui:Экспорттоо}} › {{ui:Тирүү көрүнүш}} тандаңыз. Панель оң төмөнкү бурчта ачылат.
2. Аны жылдыруу үчүн анын аталыш тилкесин сүйрөңүз, чоңойтуу үчүн бурчун тартыңыз.
3. {{ui:Жаңы терезе}} аны өз алдынча терезеге, экинчи экран үчүн, которот. {{ui:Экспорттоо}} › {{ui:Тирүү көрүнүш жаңы терезеде}} аны дароо ошол жерде ачат. Эгер браузер калкыма терезелерди бөгөттөсө, ал панель катары ачылат.
4. {{ui:Жабуу}} аны жабат.

## Моделдин ичинен басып жүрүү

1. Негизги көрүнүштү каалаган жерге бурап, {{ui:Басып жүрүү}} тандаңыз. Сиз көрүнүштүн көз чекитинин астындагы полдо, 1,6 м бийиктикте турасыз.
2. Тирүү көрүнүштү басып, {{key:W}} {{key:A}} {{key:S}} {{key:D}} же жебе баскычтарын колдонуңуз. Жүгүрүү үчүн {{key:Shift}} кармаңыз. Тегеректеп карап сүйрөңүз.
3. 40 см ге чейинки кадамдар көтөрүлөт (тепкичтер); андан бийиктер дубал. Дубалдар сизди токтотот, сиз алардын боюнча сыдырыласыз.
4. {{ui:Тартылуу күчү}} өчүк болсо учасыз: {{key:E}} жогору, {{key:Q}} ылдый.
5. {{key:Esc}} басып жүрүүнү токтотот.

## Өсүмдүктөрдү, таштарды жана адамдарды чачуу

Тирүү көрүнүштүн тилкесиндеги {{ui:Чачуу}} чачуу панелин сүрөттүн жанында ачат. Чачуу топтому көркөмдөөчү элементтердин китепканасынан (дарактар, бадалдар, чөп, гүлдөр, таштар, адамдар, унаалар) нерселерди модельдин бир бөлүгүнө чачат. Нерселер гана тирүү көрүнүштө чийилет: алар модельдин геометриясы эмес, негизги көрүнүш аларды көрсөтпөйт.

1. **Беттерди толтуруңуз:** ModelCraft'та беттерди (же топту, мисалы рельефти) тандаңыз, андан кийин {{ui:Тандалганды толтуруу}} басыңыз. Топтом аларды каптайт.
2. **Боёо:** {{ui:Боёо}} тандаңыз, андан кийин тирүү көрүнүштүн үстүнөн сүйрөңүз. Беттер тандалганда боёк ошолорго гана түшөт; эч нерсе тандалбаганда, щётканын астындагы бардык нерсеге, жерди кошкондо, түшөт. {{ui:Кисть өлчөмү}} щётканы коет; {{ui:Очургуч}} боёлгон тактарды алып салат.
3. Чачуу үчүн керектүүлөрдү белгилеңиз. Ар бирин жанындагы сан анын салмагы: 3 жана 1 дегенде, биринчисинен үч, экинчисинен бир даана болот.

| Элемент | Эмне кылат |
|---|---|
| {{ui:1 m²ге}} | Ар бир квадрат метрге канча нерсе |
| {{ui:Четтетүү (m)}} | Башка объекттерден бул аралыктан жакын эмес, чатырдын же столдун астына эч нерсе коелбойт. 0 аны өчүрөт |
| {{ui:Буруу (°)}} | Ар бир нерсе тик огу боюнча кокусунан канчага бурулат |
| {{ui:Эң тик (°)}} | Бет ушундан тик болгон жерлерге нерсе коелбойт |
| {{ui:Өлчөм}} | Эң кичине жана эң чоң өлчөм, нерсенин өз өлчөмүнүн коэффициенти катары |
| {{ui:Бийиктиги, дан-ага (m)}} | Ушул бийиктиктердин ортосунда гана (бош = каалаган) |
| {{ui:Бет менен кыйшаюу}} | 0 нерсени тик кармайт; 1 нерсени жантайган бетке тик бурчтук менен коёт |
| {{ui:Баштапкы маани}}, {{ui:Аралаштыруу}} | Бирдей баштапкы маани ар дайым бирдей чачууну берет; Аралаштыруу башкасын тандайт |

Топтомдор `.modelcraft` файлында сакталат жана аларды өзгөрткөндө каптаган беттерди ээрчийт. Тирүү көрүнүш канча нерсе чийе аларын [сиздин машинаңыздын](topic:your-machine) деңгээли чектейт: {{ui:Процессор гана}} үчүн 20 000, {{ui:Видеокарта, негизги}} үчүн 100 000, {{ui:Видеокарта, жогорку}} үчүн миллион. Панель канча нерсе коюлганын, тыгыздык канча талап кылганын көрсөтөт: бюджет жетсе же объекттер аларды четтетсе, азыраак коюлат. Камерага жакын нерселер өз формасында, алыстагылар жөнөкөй формалар түсү менен чийилет.

:::note
Чачылган нерселер тирүү көрүнүштө (анын басып жүрүүсүндө, панорамаларда жана автономдуу көрүүчүдө). {{ui:Сүрөттү рендерлөө…}} аларды азырынча чийбейт.
:::

## Бөлүшүү: панорамалар, турлар, көрүүчү, видео

{{ui:Бөлүшүү}} тирүү көрүнүштүн тилкесинде тирүү көрүнүштөн файлдарды жасайт. Баары ушул компьютерде жасалат; эч нерсе жүктөлбөйт.

| Тандоо | Эмне аласыз |
|---|---|
| {{ui:360° панорама}} | Көрүнүш турган жерден (же сиз басып жүргөн жерден) 360° сүрөт, equirectangular PNG катары, аны панорама көрүүчүлөр жана көпчүлүк фото сайттар ачат |
| {{ui:Бул чекитти турга кошуу}}, андан кийин {{ui:Турду сактоо}} | Ар бир чекиттеги панорамасы бар бир веб-барак жана ар бир чекит көрө ала турган чекиттерге жебелер (ортодогу дубал жебени жашырат) |
| {{ui:Көрүүчүнү сактоо}} | Модель ушул чыныгы убакыттагы көрүнүш менен бир веб-барак: бурасыз, басып өтөсүз, сакталган сахналарга өтөсүз. WebGPU же WebGL 2 бар браузерде оффлайн ачылат, папкадан, USB флешкадан же электрондук каттан, орнотуусуз жана аккаунтсыз, жана интернеттен эч нерсе жүктөбөйт |
| {{ui:Жолдун видеосу}} | Таймлайндагы камеранын жолу (же сакталган сахналар иретинде) ушул чыныгы убакыттагы көрүнүш менен видео катары, тирүү көрүнүштүн өлчөмүндө: браузер жасай ала турган WebM же MP4, болбосо ZIP ичинде номерленген сүрөттөр |

Панорама туурасы сапатка жараша: {{ui:Төмөн}}, {{ui:Орточо}} жана {{ui:Жогорку}} учурда 1024, 2048 же 4096 пиксель. Көрүүчү файлы болжол менен 5 MB плюс модель.

:::note
Тур жана көрүүчү көрсөтүү үчүн жасалат, түзөтүү үчүн эмес: аларды сактаганда модель ошондой бойдон калат.
:::

## Чагылган жарык

Күн менен жарыкталган дубалдан полго чагылган жарык жана бөлмөнүн караңгы ички бети [сүрөттөрдү рендерлөө](topic:render) жасаган ошол эле жол тректөөчү менен эсептелет: ал модель аркылуу чекиттерде кичинекей панорама рендерлейт, процессордун ар бир ядросунда фонда. Иштеп жатканда төмөнкү сап {{ui:Чагылган жарык: 40 %}} деп жазат; даяр болгондо көрүнүш аны кабыл алат. Өзгөртүүдөн кийин ал кайра башталат.

:::note
Бул тирүү көрүнүш үчүн болжолдоо, рендерленген сүрөт эмес: чекиттердин ортосундагы майда деталдар жакын чекиттердин чагылган жарыгын алат. Даяр сүрөт үчүн [Сүрөттү рендерлөө](topic:render) колдонуңуз.
:::

## Жарыктуулук жана түстөр

Тирүү көрүнүш [Сүрөттү рендерлөө](topic:render) менен бирдей жарыктуулукту, ак балансты, контрастты жана көрүнүш түрлөндүрүүсүн (ACES, AgX, filmic же standard) колдонот: аларды ошол жерде коюңуз, тирүү көрүнүш ээрчийт.

:::note
Браузерлер ар башка. WebGPU'су бар браузерлерде (Windows, macOS жана ChromeOS'та Chrome жана Edge, Safari 26) тирүү көрүнүш аны колдонот; башка жерлерде (Linux'тагы көпчүлүк браузерлер, эски Apple системалары) ал WebGL 2'ни колдонот жана окшош көрүнөт.
:::
