Кошумча (Жөндөөлөр › Кошумчалар) {{ui:Сүрөттү рендерлөө…}} диалогунун **Механизм** тизмесине механизм кошо алат. Кошумча авторлоруна толук текст спецификациянын 16-бөлүмүндө; кыскача:

- Кошумча өз префикси менен башталган id, аты, милдеттүү эмес жөндөөлөр жана **же** иштетүүчү программа, **же** сүрөттү тарта турган JavaScript функциясы менен механизм катталат.
- Программаны иштеткен механизм **`engine.run`** уруксатын талап кылат, ал орнотуудан мурун жана Жөндөөлөрдө көрсөтүлөт. Ал Studio'до гана иштейт; браузерде сактала турган файл катары көрүнөт.
- Кошумча программанын атын (жөнөкөй файл аты, эч качан shell эмес), **кошумчанын ичинде кол коюлган** скриптти жана плейсхолдерлерден жана жөнөкөй сөздөрдөн турган аргументтерди жазат. Studio программаны табат же сизден бир жолу көрсөтүүнү сурайт.
- Кошумча программаны биринчи жолу иштеткенде, **Studio өз диалогунда сурайт**: кайсы кошумча, кайсы программа жана скрипт программа кыла ала турган нерсенин баарын кыла алат. Аны ишенимдүү кошумчага гана уруксат бериңиз. Жообуңуз ошол кошумча жана программа үчүн эсте калат.
- Пакет (сахна USD катары жана жөндөөлөр файлы, кошумча сураса glTF файлы менен) жана кошумчанын скрипти жаңы убактылуу папкага түшөт, программа ошол жерде иштейт, ал эми сүрөт кошумчанын механизм аты менен белгиленип кайтат.

:::note
Кошумчалар рендер механизмдерин 1.4 кошумча API'сынан баштап гана кошо алат. Ачык булактуу буйрук катарындагы рендерлөөчү үчүн иштелген мисал өз репозиторийинде; ал ошол рендерлөөчүдө али иштетилген эмес.
:::
