Бул түртүү/тартуу клавиштери, ModelCraft баштаган нерселер. Башка стиль үчүн төмөндөгү [Modeler keys](topic:keyboard#modeler-keys) жана [ModelCraft жөндөөлөрү](topic:settings) караңыз.

Кыска жолдор манипуляторду же куралдар тилкесинин баскычын басканда иштейт. Панелдеги талаага текст терип же {{ui:Стиль}} ичиндеги тизмени өзгөрткөн болсоңуз, адегенде үч өлчөмдүү көрүнүштү чыкылдатыңыз, антпесе клавишалар ошол талаага барат. Клавишалар кайсы компьютерде кантип жазылаарын [Клавиштер, чычкандар жана трекпадтар](common:keys) бөлүмүнөн караңыз.

## Esc

{{key:Esc}} ар бир басканда бир деңгээлден артка чегинет:

1. Курал жасап жаткан нерсени токтотот (сызылып жаткан сызык, түртүү/тартуу, жылдыруу). Баары баштапкы абалына кайтат.
2. {{ui:Тандоо}} куралына өтөт.
3. Тандоону тазалайт.
4. Түзөтүп жаткан топту жабат.

Ошондой эле сахналардын ойнотулушун токтотот. Маани кутусунда {{key:Esc}} терген нерсени тазалап, көрүнүшкө кайтарат.

## Курал иштеп жатканда

| Баскыч | Кылат |
|---|---|
| Сан же `. , - ' " [ < * /` белгилеринин бири | Маани кутусунда терүүнү баштайт |
| {{key:Enter}} | Маани кутусуна терген маанини колдонот |
| {{key:Right}} | Кызыл окко бекитет (ачуу үчүн кайра басыңыз) |
| {{key:Left}} | Жашыл окко бекитет |
| {{key:Up}} | Көк окко бекитет |
| {{key:Down}} | Биринчи чыкылдатуудан мурун сиз үстүнөн өткөн акыркы кырга параллель бекитет |
| {{key:Shift}} кармоо | Кармап турганыңызда туураланган багытты кармап турат |
| {{key:Ctrl}}, {{key:Mod}} же {{key:Alt}} (Жылдыруу) | Жылдыруу менен көчүрүүнүн ортосунда которот |

Жебе баскычынын бекитүүлөрү {{ui:Сызык}}, {{ui:Тик бурчтук}}, {{ui:Айлана}}, {{ui:Көп бурчтук}}, {{ui:Жылдыруу}}, {{ui:Масштаб}} жана {{ui:Лента}} куралдарында (чекиттен өлчөгөндө) биринчи чыкылдатуудан кийин иштейт. {{ui:Түртүү/тартуу}} ар дайым беттин багыты боюнча жылат, бекитүүлөрү жок. {{ui:Буруу}} куралында жебе баскычтары биринчи чыкылдатуудан кийин "Бекитилди" деген билдирүү көрсөтөт, бирок бурулушту өзгөртпөйт.

## Чычкан

| Аракет | Кылат |
|---|---|
| Чыкылдатуу | Учурдагы куралды колдонот |

## Трекпад

Эки манжа менен сыпыруу эмне кылаары {{ui:Жөндөөлөр}} › {{ui:ModelCraft}} › Скроллинг бөлүмүнө жараша болот:

| Жаңсоо | Трекпад (же ойлонуп чыгарылган) | Чычкан дөңгөлөгү |
|---|---|---|
| Эки манжа менен сыпыруу | Айлантуу | Көрсөткүчкө карай чоңойтуу |
| {{key:Shift}} + эки манжа менен сыпыруу | Жылдыруу | Чоңойтуу |
| Чымчып тартуу | Көрсөткүчкө карай чоңойтуу | Көрсөткүчкө карай чоңойтуу |
| Эки манжаны басып сүйрөө (экинчи чыкылдатуу кармалган) | Жылдыруу | Жылдыруу |

Караңыз: [Айлантуу, жылдыруу жана чоңойтуу](topic:orbit-pan-zoom#on-a-trackpad) жана [ModelCraft жөндөөлөрү](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Сенсордук экран

| Жаңсоо | Кылат |
|---|---|
| Таптоо | Учурдагы курал менен чыкылдатуу |
| Эки жолу таптоо | Эки жолу чыкылдатуу |
| Басуу, сүйрөө, көтөрүү | Чычкан менен басуу, сүйрөө, коё берүү сыяктуу |
| Эки манжа: чымчып тартуу | Чоңойтуу |
| Эки манжа: кошо жылдыруу | Жылдыруу ({{ui:Жөндөөлөр}} › {{ui:ModelCraft}} › Сенсордук экран аны Айлантуу кыла алат) |
| Үч манжа: кошо жылдыруу | Айлантуу (эки манжа менен айлантканда — Жылдыруу) |
| Бир манжа бир аз токтоп турса | Куралды бүтүрөт, Enter сыяктуу; эч нерсе болбосо, айлантуу үчүн сүйрөңүз |
| Бир манжанын аракетинде экинчи манжа | Ошол аракетти токтотот |
| {{ui:Айлантуу}} куралы, андан кийин бир манжаны сүйрөңүз | Айлантуу |

Сенсордук экранда маанини терүү үчүн, төмөндөгү маани кутусун таптаңыз, териңиз жана клавиатуранын Enter (же Go) баскычын басыңыз.

## Жылдыруу кайда жайгашкан

{{ui:Жылдыруу}} куралында, {{key:M}} клавишасында: эмнени жылдыруу керектигин тандаңыз, базалык чекитти чыкылдатыңыз, андан кийин экинчи чекитти же аралыкты териңиз. Караңыз: [Жылдыруу, көчүрүү жана массивдерди түзүү](topic:move-copy).
