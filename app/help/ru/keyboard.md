Это клавиши «толкай-тяни», с которых начинает ModelCraft. Для другого стиля см. [Клавиши Modeler](topic:keyboard#modeler-keys) ниже и [Настройки ModelCraft](topic:settings).

Сочетания работают, когда в фокусе 3D-вид или кнопка панели инструментов. Если вы только что печатали в поле панели или меняли список в {{ui:Style}}, сначала щелкните в 3D-виде, иначе клавиши попадут в это поле. См. [Клавиши, мыши и трекпады](common:keys), как записываются клавиши на каждом компьютере.

## Esc

{{key:Esc}} отменяет по одному уровню при каждом нажатии:

1. Отменяет то, что инструмент делает прямо сейчас (линию в процессе рисования, тягание, перемещение). Всё возвращается назад.
2. Переключается на {{ui:Select}}.
3. Снимает выделение.
4. Закрывает группу, которую вы редактируете.

Также останавливает проигрывание сцен. В поле значения {{key:Esc}} очищает введённое и возвращает к виду.

## Пока инструмент работает

| Клавиша | Делает |
|---|---|
| Цифра или один из `. , - ' " [ < * /` | Начинает ввод в поле значения |
| {{key:Enter}} | Применяет введённое в поле значения |
| {{key:Right}} | Фиксирует по красной оси (нажмите снова, чтобы снять) |
| {{key:Left}} | Фиксирует по зеленой оси |
| {{key:Up}} | Фиксирует по синей оси |
| {{key:Down}} | Фиксирует параллельно последнему ребру, над которым вы водили курсор до первого щелчка |
| Удерживать {{key:Shift}} | Удерживает направление, к которому вы привязаны, пока клавиша нажата |
| {{key:Ctrl}}, {{key:Mod}} или {{key:Alt}} (в {{ui:Move}}) | Переключает между перемещением и копированием |

Фиксация стрелками работает в {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} и {{ui:Tape}} (при измерении от точки), после первого щелчка. {{ui:Push/pull}} всегда движется по направлению грани и фиксаций не имеет. В {{ui:Rotate}} стрелки после первого щелчка показывают сообщение «Зафиксировано», но не меняют поворот.

## Стрелки в другое время

Когда никакой инструмент не в процессе работы, клавиши-стрелки двигают камеру:

| Клавиша | Делает |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Вращение |
| {{key:Shift}} со стрелкой | Панорама |

## Мышь

| Действие | Делает |
|---|---|
| Щелчок | Использует текущий инструмент |
| Нажатие, перетаскивание, отпускание | То же, что два щелчка (для инструментов рисования); рамка выбора (для {{ui:Select}}); стирание по пути (для {{ui:Eraser}}) |
| Двойной щелчок | {{ui:Select}}: грань с её рёбрами, ребро с его гранями, открывает группу; пустое место закрывает группу. {{ui:Push/pull}}: повторяет последнее расстояние |
| Тройной щелчок | {{ui:Select}}: всё связанное |
| {{key:Shift}} + щелчок | {{ui:Select}}: включает и исключает из выбора |
| {{key:Mod}} + щелчок | {{ui:Select}}: добавляет к выбору |
| {{key:Shift}} + {{key:Mod}} + щелчок | {{ui:Select}}: убирает из выбора |
| Перетаскивание средней кнопкой | Вращение, с любым инструментом |
| {{key:Shift}} + перетаскивание средней кнопкой | Панорама, с любым инструментом |
| Перетаскивание правой кнопкой | Панорама, с любым инструментом |
| Колесо | Масштаб к курсору |

Контекстного меню по правой кнопке нет.

## Трекпад

Что делает двухпальцевое смахивание, зависит от {{ui:Settings}} › {{ui:ModelCraft}} › Прокрутка:

| Жест | Трекпад (или определено) | Колесо мыши |
|---|---|---|
| Двухпальцевое смахивание | Вращение | Масштаб к курсору |
| {{key:Shift}} + двухпальцевое смахивание | Панорама | Масштаб |
| Щипок | Масштаб к курсору | Масштаб к курсору |
| Нажатие двумя пальцами и перетаскивание (удержанный вторичный щелчок) | Панорама | Панорама |

См. [Вращение, панорама и масштаб](topic:orbit-pan-zoom#on-a-trackpad) и [Настройки ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

При {{ui:Settings}} › {{ui:ModelCraft}} › Управление, выставленном в стиль Modeler:

| Клавиша | Делает |
|---|---|
| {{key:W}} или {{key:Space}} | {{ui:Select}} |
| {{key:L}} / {{key:B}} / {{key:C}} / {{key:N}} | {{ui:Line}} / {{ui:Rectangle}} / {{ui:Circle}} / {{ui:Polygon}} |
| {{key:E}} | {{ui:Push/pull}} (выдавливание) |
| {{key:T}} | {{ui:Tape}} измерение |
| {{key:D}} | {{ui:Dimension}} |
| {{key:G}} | Сразу переместить выбранное от курсора |
| {{key:R}} | Повернуть выбранное вокруг его середины (синяя ось) |
| {{key:S}} | Масштабировать выбранное вокруг его середины |
| {{key:X}} / {{key:Y}} / {{key:Z}} при перемещении или повороте | Фиксирует красную / зеленую / синюю ось (повторно — снять фиксацию) |
| Щелчок или {{key:Enter}} | Поставить на место |
| {{key:Esc}} или щелчок правой кнопкой | Вернуть на место |
| {{key:Shift+D}} | Дублировать и переместить копию |
| {{key:X}} или {{key:Delete}} | Удалить выбранное |
| {{key:A}} / {{key:Alt+A}} | Выбрать всё / снять выбор |
| {{key:Tab}} | Открыть выбранную группу или компонент; ещё раз — закрыть |
| {{key:Mod+G}} / {{key:Mod+Shift+G}} | Создать группу / создать компонент |
| Numpad {{key:1}} / {{key:3}} / {{key:7}} | Вид спереди / справа / сверху ({{key:Mod}} — сзади / слева / снизу) |
| Numpad {{key:5}} | Перспектива вкл. или выкл. |
| Numpad {{key:.}} | Масштаб к выбранному |
| {{key:Home}} или {{key:Shift+C}} | Показать границы |
| {{key:Shift+Tab}} | Привязка вкл. или выкл. |
| Перетаскивание средней кнопкой / с {{key:Shift}} / с {{key:Mod}} | Вращение / панорама / масштаб |
| {{key:Alt}} + перетаскивание / {{key:Alt+Shift}} + перетаскивание | Вращение / панорама (без средней кнопки) |

Копирование, вставка, отмена, сохранение и открытие сохраняют клавиши, перечисленные выше. Вводимые значения, поле значения и {{ui:Push/pull}} работают одинаково в обоих стилях.

## Сенсорный экран

| Жест | Делает |
|---|---|
| Касание | Щелчок текущим инструментом |
| Двойное касание | Двойной щелчок |
| Нажатие, перетаскивание, отпускание | То же, что нажатие, перетаскивание и отпускание мышью |
| Два пальца: сведение или разведение | Масштаб |
| Два пальца: движение вместе | Панорама (в Настройки › ModelCraft › Сенсорный экран можно сделать вращение) |
| Три пальца: движение вместе | Вращение (панорама, когда два пальца вращают) |
| Удержание одного пальца неподвижно | Завершает инструмент, как {{key:Enter}}; если ничего не происходит, затем перетащите для вращения |
| Второй палец во время действия одним пальцем | Отменяет это действие |
| Инструмент {{ui:Orbit}}, затем перетаскивание одним пальцем | Вращение |

Чтобы ввести значение на сенсорном экране, коснитесь поля значения внизу, введите его и нажмите на клавиатуре {{key:Enter}} (или Go).

## Где находится инструмент перемещения

Перемещение находится в инструменте {{ui:Move}}, клавиша {{key:M}}: выберите, что переместить, щелкните базовую точку, затем вторую точку или введите расстояние. См. [Перемещение, копирование и массивы](topic:move-copy).
