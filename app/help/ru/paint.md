Цвета помогают отличать части модели друг от друга, а **материалы** (кирпич, сайдинг, кровля, дерево, камень, плитка, бетон, штукатурка, трава, стекло, металл) делают модель похожей на то, из чего она построена. Оба наносятся одинаково.

## Выбор цвета

Раздел {{ui:Colors}} справа показывает ряд сплошных цветов, {{ui:Default}} (перечеркнутый линией: без цвета) и образец {{ui:+}} для любого другого цвета. Щелкните по нему, чтобы сделать его текущим. Инструмент {{ui:Paint}} начинает работу с ним.

## Краска

1. Нажмите {{key:B}} ({{ui:Paint}}) или, если ничего не выбрано, щелкните цвет. (Если что-то выбрано, щелчок по цвету сразу красит выделение.)
2. Щелкните грань, чтобы закрасить ее.
3. Щелкните группу или компонент, чтобы покрасить эту копию: их грани, которые не имеют собственного цвета, получают этот цвет. Грани, которые вы красили внутри нее, сохраняют свой цвет.

Чтобы покрасить несколько объектов сразу, сначала выделите их, затем щелкните цвет, или щелкайте любой из них с {{ui:Paint}}. Это один шаг отмены.

| Удерживать | Щелчок по грани | Что закрасится |
|---|---|---|
| — | | Эта грань |
| {{key:Ctrl}} | | Каждая грань, соединенная с ней, с таким же цветом |
| {{key:Shift}} | | Каждая грань такого цвета в группе, в которой вы работаете |
| {{key:Alt}} | | Ничего: вместо этого вы берете этот цвет |

Чтобы вернуть грань без цвета, выберите {{ui:Default}} и щелкните ее.

## Окраска материалом

Раздел {{ui:Materials}} под {{ui:Colors}} показывает библиотеку материалов по видам: кирпич и блоки, сайдинг, кровля, дерево, камень, плитка, бетон, штукатурка, грунт, стекло и металл. Наведите указатель на образец, чтобы увидеть его название. Щелкните по нему, затем красьте так же, как цветом: {{key:B}}, щелчки по граням, группам или компонентам; либо сначала выделите объекты и затем щелкните материал.

- В стиле **Тонированный** грани показывают текстуру материала. Скрытые линии, каркас и рентген показывают его цвет.
- Текстуры идут **по горизонтали вдоль каждой грани и вверх по ней**: ряды кирпича остаются горизонтальными на каждой стене, черепица идет вниз по скату кровли, доски на полу следуют красной оси. Они в реальном размере (кирпич около 215 mm в длину), поэтому выглядят правильно на любом расстоянии.
- В [визуализированном изображении](topic:render) материалы сохраняют текстуру, шероховатость, а для стекла и металла — блеск.
- {{key:Alt}}-щелчок с {{ui:Paint}} тоже берет материал грани.

Текстуры нарисованы самим ModelCraft, поэтому они работают офлайн и свободны для любого использования (CC0).

## Компоненты и цвета

Цвет, нанесенный на грань **внутри** компонента, отображается на каждой копии, потому что копии используют одно определение. Цвет, нанесенный на **копию** снаружи (при закрытом компоненте), относится только к этой копии, поэтому две копии одного компонента могут иметь разные цвета. {{ui:Entity info}} показывает цвет выбранной грани, группы или компонента.

## Цвета в файлах

- Файл ModelCraft сохраняет все цвета и все материалы.
- Другие форматы получают **цвет материала** (его вид издалека) вместо текстуры: glTF, Collada, OBJ, DWG и DXF, а также проверка для 3D-печати. В glTF, Collada и OBJ материал сохраняет свое имя, например `Material_brick-red`.
- **glTF (.glb)** и **Collada (.dae)**: каждый цвет становится материалом. Компонент, показанный в разных цветах, записывается по одному разу на каждый цвет. glTF также записывает импортированные текстуры как текстуры.
- **OBJ**: экспорт скачивает два файла, `.obj` и файл материалов `.mtl` с цветами. Держите их в одной папке. С импортированными текстурами `.obj`, `.mtl` и изображения приходят одним архивом `.zip`.
- **DWG** сохраняет точные цвета; **DXF** использует ближайший из 255 стандартных цветов CAD.
- **STL** и **PLY** содержат цвета: STL — по соглашению VisCAM / SolidView (программы, которые его не читают, его игнорируют), PLY — как цвет каждой точки. См. [Форматы файлов подробно](topic:formats).

:::tip
Чтобы смоделировать экран, покрасьте раму в угольный цвет, а стекло в синий — после того как сделаете [подобие](topic:draw-faces) передней грани.
:::
