Рабочая область **«Сетка»** правит [сетку](topic:meshes) точка за точкой: ее вершины, ребра и грани. Геометрия «Тянуть/толкать» остается в рабочей области **«Модель»**.

## Открытие

- Выберите {{ui:Сетка}} в списке {{ui:Рабочая область}} слева на панели инструментов. Выбранная сетка открывается для правки; выбранная группа или компонент сначала превращаются в сетку (один шаг отмены).
- Или дважды щелкните сетку, а при клавишах «Моделлер» выберите ее и нажмите {{key:Tab}}.
- Когда ничего не выбрано, панель предлагает сетки для добавления: плоскость, сетка, куб, окружность, цилиндр, конус, сфера, ico-сфера и тор. Новая сетка появляется там, куда смотрит вид, и открывается для правки.

{{ui:К модели}} (или список, {{key:Tab}} при клавишах «Моделлер», {{key:Esc}} при пустом выборе при клавишах «Тянуть/толкать») возвращает в «Модель» с выбранной сеткой. Пока открыта рабочая область «Сетка», остальная модель затенена, а инструменты рисования «Модели» убраны.

## Выбор

| Действие | Результат |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | Выбрать вершины, ребра или грани |
| Щелчок | Выбрать один объект; {{key:Shift}}+щелчок добавляет или убирает |
| Протащить рамку | Выбрать то, что внутри и видно; {{key:Shift}} добавляет, {{key:Ctrl}} убирает |
| {{key:Alt}}+щелчок по ребру или двойной щелчок по нему | Петля ребер (петля граней в режиме граней; весь контур на открытом ребре) |
| {{key:Ctrl}}+{{key:Alt}}+щелчок по ребру | Кольцо ребер |
| Тройной щелчок | Всё, соединенное с ним |

В группе {{ui:Выбор}} также есть {{ui:Все}}, {{ui:Связанные}}, {{ui:Петля}}, {{ui:Кольцо}}, {{ui:Ещё}} и {{ui:Меньше}}.

## Перемещение, поворот, масштаб

{{ui:Переместить}}, {{ui:Повернуть}} и {{ui:Масштабировать}} начинаются от указателя: двигайте его, затем щелкните или нажмите {{key:Enter}}, чтобы зафиксировать выбор, либо {{key:Esc}}, чтобы отменить. {{key:X}}, {{key:Y}} или {{key:Z}} (или клавиши-стрелки) блокируют ось. Введите расстояние, угол или коэффициент для точного значения — работают и [вычисления](topic:value-box#calculations).

**Пропорциональная правка** ({{ui:Пропорционально}} или на панели): вершины рядом с выбором следуют за перемещением, тем меньше, чем дальше они находятся, до заданного радиуса, с выбранным спадом. Включите {{ui:Только по сетке}}, чтобы измерять по ребрам, а не по прямой.

{{ui:Скольжение}} перемещает выбранную петлю ребер вдоль соседних ребер.

## Изменение формы

| Инструмент | Что делает |
|---|---|
| {{ui:Выдавить}} | Вытягивает выбранные грани по их нормали, с новыми боковыми гранями (или создает грани из открытых граничных ребер). Введите расстояние |
| {{ui:Врезать}} | Полоса внутри контура выбранных граней; нажмите {{key:I}} снова для каждой грани отдельно |
| {{ui:Скос}} | Срезает выбранные ребра (или, {{key:Ctrl}}+{{key:Shift}}+{{key:B}}, вершины) на заданную ширину; колесико или клавиши плюс и минус добавляют сегменты для скругленного ребра |
| {{ui:Разрез петлей}} | Укажите ребро: новые петли поперек кольца четырехугольных граней; колесико задает их число; щелчок — разрез |
| {{ui:Нож}} | Щелкайте точки на ребрах или углах; {{key:Enter}} режет прямо через грани между ними, как вы их видите |
| {{ui:Рассечь}} | Проведите линию на экране: выбранные грани (или все) разрезаются по ней |
| {{ui:Вращать}} | Вращает выбранные грани или открытые ребра вокруг синей оси с шагом (колесико задает их); полный оборот замыкает |
| {{ui:Разделить}} | Делит выбранные ребра пополам; целые грани становятся сеткой |
| {{ui:Слить}} | Выбранные вершины становятся одной, в их центре |
| {{ui:Растворить}} | Убирает выбор, но сохраняет поверхность: грани объединяются |
| {{ui:Заполнить}} | Грань поперек выбранного открытого контура (или между двумя открытыми ребрами) |
| {{ui:Заполнить сеткой}} | Заполняет открытый контур с четным числом ребер сеткой из четырехугольников |
| {{ui:Мост}} | Соединяет две выбранные открытые петли ребер гранями |
| {{ui:Складка}} | Насколько резкими остаются выбранные ребра при сглаживании сетки поверхностью подразделения: тяните от центра, используйте колесико (шаг 0.1) или введите значение от 0 до 1. Панель показывает складку выбранных ребер и принимает введенное значение. Ребра со складкой выделяются пурпурным цветом |
| {{ui:Отражение}}, {{ui:Сгладить}}, {{ui:Удалить}} | Переворачивают грани; сглаживают вершины к соседним; удаляют по режиму выбора |

Каждое действие — один шаг отмены. Текстурные координаты, цвета и веса переходят на новые грани и вершины.

## Перестроить сетку

{{ui:Перестроить сетку}} заново строит всю сетку из ровных треугольников одного размера, который задается при нажатии (чем меньше, тем точнее и медленнее). Она закрывает отверстия, объединяет перекрывающиеся части и выравнивает сетку, растянутую скульптингом. Острые ребра становятся очень слегка скругленными. UV, краска и складки начинаются заново. Один шаг отмены.

## Ретопология

Чтобы построить новую, более чистую сетку поверх детальной (скульптуры, скана), выберите детальную в {{ui:Ретопология}} › **Построить на** на панели, затем:

- **Привязывать перемещаемые точки к ней:** точки, которые вы двигаете, и ребра, которые вы выдавливаете, ложатся на ее поверхность.
- **Поставить выбранные точки на нее** сразу переносит выбранные точки на ее поверхность (один шаг отмены).
- **Показывать ребра этой сетки на переднем плане** рисует строящуюся сетку поверх поверхности, чтобы вы ее видели.

## Изменение последней операции

После {{ui:Врезать}}, {{ui:Скос}}, {{ui:Разрез петлей}}, {{ui:Разделить}}, {{ui:Сгладить}}, {{ui:Заполнить сеткой}} или {{ui:Вращать}} панель показывает ее настройки (ширина, сегменты, профиль, разрезы и т. д.). Измените одну из них, и операция выполнится заново с того места, где началась, по-прежнему одним шагом отмены.
