Дополнение (Настройки › Дополнения) может добавить движок в список **Движок** в {{ui:Рендер рисунка…}}. Полный текст для авторов дополнений — раздел 16 спецификации дополнений; коротко:

- Дополнение регистрирует движок с идентификатором, который начинается с его собственного, названием, необязательными настройками и **либо** программой для запуска, **либо** функцией на JavaScript, которая рисует изображение.
- Движку, который запускает программу, нужно разрешение **`engine.run`**, которое показывается до установки и в Настройках. Он работает только в Studio; в браузере он показывается как файл для сохранения.
- Дополнение называет программу (простое имя файла, никогда не оболочку), скрипт, который находится **внутри подписанного дополнения**, и аргументы из заполнителей и простых слов. Studio находит программу или один раз просит указать её.
- При первом запуске программы дополнением **Studio спрашивает в собственном диалоге**: какое дополнение, какая программа и что скрипт может делать всё, что может программа. Разрешайте только дополнения, которым доверяете. Ваш ответ запоминается для этого дополнения и программы.
- Пакет (сцена в USD и файл настроек, с файлом glTF, если дополнение его запрашивает) и скрипт дополнения помещаются во временную папку, программа запускается там, и изображение возвращается с пометкой названия движка дополнения.

:::note
Дополнения могут добавлять движки рендеринга только начиная с API дополнений 1.4. Пример работы для рендерера командной строки с открытым кодом находится в его собственном репозитории; в этом рендерере его еще не запускали.
:::
