Bunlar ModelCraft-ın başladığı, itələ-çək klavişləridir. Digər üslub üçün aşağıda [Modeler klavişləri](topic:keyboard#modeler-keys) və [ModelCraft parametrləri](topic:settings) bölməsinə baxın.

Qısayollar 3D görünüş və ya alətlər panelinin düyməsi fokusda olduqda işləyir. Əgər panel sahəsinə yazmısınızsa və ya {{ui:Üslub}}-da siyahını dəyişmisinizsə, əvvəlcə 3D görünüşə klikləyin, əks halda klavişləriniz həmin sahəyə gedir. Klavişlərin hər kompüterdə necə yazıldığı üçün [Klavişlər, siçanlar və trackpadlər](common:keys) bölməsinə baxın.

## Esc

{{key:Esc}} hər basışda bir səviyyə geri qayıdır:

1. Alətin ortasında olanı ləğv edir (çəkilən xətt, itələ/çək, köçürmə). Hər şey geri qayıdır.
2. {{ui:Seç}} alətinə keçir.
3. Seçimi təmizləyir.
4. Redaktə etdiyiniz qrupu bağlayır.

Həmçinin səhnələrin oynanmasını dayandırır. Dəyər qutusunda {{key:Esc}} yazdığınızı təmizləyir və görünüşə qayıdır.

## Alət işləyərkən

| Klavişi | Nə edir |
|---|---|
| Rəqəm, və ya `. , - ' " [ < * /` simvollarından biri | Dəyər qutusuna yazmağa başlayır |
| {{key:Enter}} | Dəyər qutusuna yazdığınızı tətbiq edir |
| {{key:Right}} | Qırmızı oxa kilidlənir (kilidi açmaq üçün yenidən basın) |
| {{key:Left}} | Yaşıl oxa kilidlənir |
| {{key:Up}} | Göy oxa kilidlənir |
| {{key:Down}} | İlk klikdən əvvəl göstərdiyiniz son kənara paralel kilidlənir |
| {{key:Shift}} basılı saxlanılır | Basılı saxladığınız müddətdə tutulduğunuz istiqaməti saxlayır |
| {{key:Ctrl}}, {{key:Mod}} və ya {{key:Alt}} ({{ui:Köçür}}) | Köçürmə və kopyalama arasında keçir |

Ox klavişi kilidləri ilk klikdən sonra {{ui:Xətt}}, {{ui:Düzbucaqlı}}, {{ui:Çevrə}}, {{ui:Çoxbucaqlı}}, {{ui:Köçür}}, {{ui:Miqyas}} və {{ui:Ölçü lenti}} alətlərində işləyir (nöqtədən ölçəndə). {{ui:İtələ/çək}} həmişə üzün istiqaməti ilə hərəkət edir və kilidləri yoxdur. {{ui:Fırlat}}-da ox klavişləri ilk klikdən sonra "Kilidlənib" mesajı göstərir, lakin dönməni dəyişmir.

## Trackpad

İki barmaqla sürüşdürmənin nə etdiyi {{ui:Parametrlər}} › {{ui:ModelCraft}} › Sürüşdürmə-dən asılıdır:

| Jest | Trackpad (və ya təfsilatlı) | Siçan təkəri |
|---|---|---|
| İki barmaqla sürüşdürmə | Orbit | Göstəriciyə doğru yaxınlaşdırır |
| {{key:Shift}} + iki barmaqla sürüşdürmə | Sürüşdürür | Yaxınlaşdırır |
| Sıxma | Göstəriciyə doğru yaxınlaşdırır | Göstəriciyə doğru yaxınlaşdırır |
| İki barmaqla basma və sürükləmə (ikinci dərəcəli klik basılı) | Sürüşdürür | Sürüşdürür |

Baxın: [Orbit, sürüşdürmə və yaxınlaşdırma](topic:orbit-pan-zoom#on-a-trackpad) və [ModelCraft parametrləri](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Toxunma ekranı

| Jest | Nə edir |
|---|---|
| Toxunma | Cari alətlə klik |
| İki dəfə toxunma | İki dəfə klik |
| Basma, sürükləmə, qaldırma | Siçanla basma, sürükləmə, buraxma ilə eynidir |
| İki barmaq: sıxma | Yaxınlaşdırır |
| İki barmaq: birlikdə hərəkət | Sürüşdürür ({{ui:Parametrlər}} › {{ui:ModelCraft}} › Toxunma ekranı Orbit edə bilər) |
| Üç barmaq: birlikdə hərəkət | Orbit (iki barmaq Orbit edəndə isə Sürüşdür) |
| Bir barmağı sakit saxlamaq | Alətin işini bitirir, Enter kimi; heç nə getmirsə, sonra sürükləyərək Orbit edir |
| Bir barmaqla əməl zamanı ikinci barmaq | Həmin əməli ləğv edir |
| {{ui:Orbit}} aləti, sonra bir barmağı sürüklə | Orbit |

Toxunma ekranında dəyər yazmaq üçün aşağıdakı dəyər qutusuna toxunun, yazın və klaviaturanın Enter (və ya Go) düyməsinə basın.

## Köçürmənin yeri

Köçürmə {{ui:Köçür}} alətindədir, klavişi {{key:M}}: nəyi köçürəcəyinizi seçin, baza nöqtəsinə klikləyin, sonra ikinci nöqtəyə klikləyin və ya məsafə yazın. Bax: [Köçürün, kopyalayın və massivlər yaradın](topic:move-copy).
