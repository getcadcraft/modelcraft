插件（设置 › 插件）可以在{{ui:渲染图片…}}的引擎列表中添加一个引擎。面向插件作者的完整说明见插件规范第 16 节；简要如下：

- 插件注册一个引擎，包括以插件自身前缀开头的 ID、名称、可选设置，以及**要运行的程序**或**绘制图片的JavaScript函数**，二者**选其一**。
- 运行程序的引擎需要 **`engine.run`** 权限，该权限会在安装前和设置中显示。它仅在 Studio 中运行；在浏览器中则显示为一个待保存的文件。
- 插件需指定程序（仅为普通文件名，绝不能是 shell），以及**位于已签名插件内部**的脚本，还有由占位符和普通词组成的参数。Studio 会查找该程序，或要求一次性指定其位置。
- 插件首次运行程序时，**Studio 会在其自身的对话框中询问**：是哪个插件、哪个程序，以及脚本可以执行该程序能执行的任何操作。仅允许可信的插件运行。所作的选择会记录在该插件和该程序上。
- 包（以USD格式保存的场景和一个设置文件，若插件要求，还包括glTF文件）以及插件的脚本会放入一个新的临时文件夹，程序在该文件夹中运行，生成的图片返回时会标注插件的引擎名称。

:::note
插件只能从插件 API 1.4 版起添加渲染引擎。一个开源命令行渲染器的完整示例位于其独立仓库中；该示例尚未在该渲染器中实际运行过。
:::
