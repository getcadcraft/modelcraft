{{ui:选择}} ({{key:Space}}) 是 ModelCraft 启动时的默认工具，按 {{key:Esc}} 即可回到该工具。选中的对象会变为蓝色，右侧的 {{ui:实体信息}} 会说明它们是什么。

## 单击

| 操作 | 选中 |
|---|---|
| 单击一个面或一条边 | 该面或该条边 |
| 单击一个组或组件 | 整个组或组件 |
| 双击一个面 | 该面及其边 |
| 双击一条边 | 该边及其两侧的面 |
| 双击一个组或组件 | 打开它进行编辑（参见 [组和组件](topic:groups-components)） |
| 三击一个面或一条边 | 与之相连的全部内容：整个对象 |
| 单击空白处 | 无（清除选择） |
| 编辑组时双击空白处 | 关闭该组 |

边比面更容易点中：指针距离边缘几个像素以内时，单击会选中该边。

## 拖动选框

- **从左到右**拖动会画出实线框：即**窗口**选择。只选中完全位于框内的对象。
- **从右到左**拖动会画出虚线框：即**交叉**选择。框所接触的任何对象都会被选中；当框完全位于某个面之内时，该面也会被选中。

组或组件算作一个整体：窗口选择必须完全包住它，交叉选择只需接触到它即可。

## 增加和移除

在单击或拖动时按住某个键：

| 按键 | 效果 |
|---|---|
| {{key:Shift}} | 切换：加入未选中的对象，移除已选中的对象 |
| {{key:Mod}} | 加入 |
| {{key:Shift}} 和 {{key:Mod}} 同时按下 | 移除 |

要选中模型中的全部对象（或正在编辑的组中的全部对象），按 {{key:Mod+A}}。

## 清除选择

按 {{key:Esc}}（当前工具为 {{ui:选择}}），或单击空白处。

## 删除所选对象

按 {{key:Delete}} 或 {{key:Backspace}}。所选的面、边、组和辅助线会一步全部删除；按 {{key:Mod+Z}} 可将其恢复。

删除一条边会移除需要它的面，除非这条边只分隔同一平面内的两个面：此时这两个面会合并为一个。删除一个面则保留其边。参见 [删除与清理](topic:erase)。

## 在组内选择

单击组会选中整个组。要选中组内的某个面，双击该组将其打开，然后单击。组打开时，单击只会作用于组内的对象；其他对象会变淡。在未选中任何对象时按 {{key:Esc}}，或双击空白处，即可关闭该组。

左侧的 {{ui:大纲}} 可按名称选择组和组件，当它们被其他对象遮挡时很有用。
