雕刻工作区使用笔刷塑造网格，如同雕土：在表面上拖动，表面会随之隆起、下陷、平滑，或在圆形笔刷下跟随指针移动；笔刷中心作用最强，边缘则逐渐衰减至零。

## 开始

选择网格，然后在工作区列表中选择{{ui:雕刻}}。组或组件会先转换为网格，与网格工作区中一样。笔刷作用于网格的顶点，因此顶点越多，形状越精细：请先对其{{ui:细分}}（网格工作区中的{{ui:细分}}，或你应用的细分曲面修改器），或开启{{ui:细节}}。

## 笔刷

| 笔刷 | 快捷键 | 作用 |
| --- | --- | --- |
| {{ui:绘制}} | {{key:D}} | 抬高笔刷下方的表面 |
| {{ui:黏土}} | {{key:C}} | 逐层堆积，先填充凹陷处 |
| {{ui:平滑}} | {{key:S}} | 抹平凸起；按住{{key:Shift}}可用任意笔刷进行平滑 |
| {{ui:抓取}} | {{key:G}} | 使表面随指针一起拖动 |
| {{ui:膨胀}} | {{key:I}} | 沿表面自身的方向向外鼓起 |
| {{ui:折痕}} | {{key:Shift+C}} | 刻出锐利的凹槽 |
| {{ui:捏合}} | {{key:P}} | 将表面拉向笔刷中心 |
| {{ui:压平}} | {{key:T}} | 将表面压向其平均平面 |
| {{ui:蒙版}} | {{key:M}} | 绘制蒙版，保护表面不受其他笔刷影响 |

在绘制时按住{{key:Ctrl}}，可以反向操作（降低而非抬高、凸脊而非凹槽、移除蒙版），或开启{{ui:去除}}。

## 大小与强度

笔刷大小以屏幕上的像素为单位，因此无论你放大还是缩小，手感都相同：{{key:[}}和{{key:]}}可缩小和放大笔刷，{{key:Shift+[}}和{{key:Shift+]}}用于更改其强度。面板会显示这两项。

使用数位板上的手写笔时，用力按下会使笔刷变大、变强；面板中这两项可以分别关闭。

## 镜像、蒙版与细节

- {{ui:沿 X 镜像}}（{{key:X}}）会沿红轴同时雕刻两侧，适用于面部和人物。
- 雕刻时蒙版会显示得更暗。{{ui:清除蒙版}}（{{key:Alt+M}}）可将其取消，{{ui:反转蒙版}}（{{key:Ctrl+I}}）会使原先未受保护的区域被保护、受保护的区域变为未受保护。蒙版随网格一起保存。
- {{ui:细节}}会在你雕刻的地方添加三角面：长于面板中所设大小（屏幕像素）的边会在笔刷下被分割。它需要三角形网格，若不是，会先询问是否转换。

每次笔画为一个撤销步骤。

:::note
细节只会添加三角面，不会移除已变得极小的三角面。网格工作区中的重新网格化会使整个网格重新均匀分布。
:::
