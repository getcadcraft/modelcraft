ModelCraft 目前是早期版本。本页列出了它尚未支持的功能，以便你不必四处寻找，并给出目前完成相应工作的最接近方法。

## 绘图工具

| 尚未支持 | 目前的替代方法 |
|---|---|
| 徒手绘制 | 用{{ui:Curve}}依次点击各点 |
| 绘制后更改圆弧或圆的分段数 | 删除后重新绘制，并在输入 `24s` 之后绘制 |
| 为[3D 文字](topic:text3d)选择字体，或在放置后编辑其文字 | 删除后重新添加文字 |
| 通过在角度标注中输入数值来修改角度，或通过圆的标注修改圆柱体尺寸 | 用 {{ui:Rotate}} 旋转边；用 {{ui:Scale}} 缩放圆柱体 |
| 导出的模型文件中的标注 | 标注会显示在视图的图像、打印件和 PDF 中；模型文件只包含几何信息 |
| 修剪、拆分和外壳 | 对封闭的组使用[并集、差集和交集](topic:solids)，或使用[面相交](topic:intersect)并删除不需要的部分 |
| 用方向键选择旋转轴 | 在朝向轴应指向的方向的面上点击 {{ui:Rotate}} 的中心 |
| 同时对多个推断进行锁定 | 用方向键锁定一个方向，然后捕捉到一个点 |
| 沿斜面或从不在角点上的标注端点调整大小 | 将标注放在两个角点上、沿边，或沿红、绿、蓝方向 |

## 动画

| 尚未支持 | 目前的替代方法 |
|---|---|
| 为面、边、太阳的时间、样式或隐藏内容设置动画 | 将运动部分设为组或组件；若需要另一时间的效果，请单独渲染视频 |
| 沿绘制路径移动或朝向移动对象的摄像机 | 沿路径设置更多摄像机关键帧（[动画](topic:animation)） |
| 视频中的声音，以及不使用 WebGPU 时的高质量（路径追踪）视频 | 在视频编辑器中添加声音；无 WebGPU 时，使用快速渲染器渲染视频（[渲染视频](topic:animation#render-the-video)） |
| 渲染视频中的动画灯光（亮度、扩散、颜色），在视频中未使用摄像机关键帧而直接动画的镜头角度，材质或渲染设置的动画 | 灯光可在视图中动画显示；如需缩放效果的视频，请同时为摄像机设置关键帧；不同灯光设置请分别渲染视频（[为任意属性设置动画](topic:animate)） |
| 在镜像一侧的权重或骨骼，可见的骨骼包络，逐点着色显示权重（当前按面显示），绘制权重时查看姿态网格 | 两侧都绘制，或先制作一半并在添加骨架之前使用镜像修改器；在“绘制权重”和“姿态”之间切换以进行检查 |
| 从 glTF、FBX 或 USD 文件读取骨骼作为骨架，并将骨架写入这些文件 | 带蒙皮的模型以文件中的权重按静止状态导入；按文件中的关节顺序添加骨骼，然后点击 {{ui:Use the file's weights}}（[动画](topic:animate)） |
| 通过在视图中拖动来移动 IK 目标或极点，选择约束自身的空间（局部或世界），拉伸 IK 链，沿曲线的 IK | 输入目标点，或瞄准一个对象并移动该对象；让链条保持其长度 |
| 布料、流体、软体、刚体之间的关节和铰链，与对象精确形状的碰撞（仅可用长方体和球体包围），播放时的实时模拟，初始速度或旋转（物体从静止开始） | 烘焙刚体并播放关键帧；用关键帧制作铰链；将不规则形状拆分为长方体（组） |
| 将动画导出为 glTF 或其他模型文件 | 渲染视频；`.modelcraft` 文件以及 ModelCraft 保存的 [USD 文件](topic:usd)仅供 ModelCraft 使用 |
| 在 VR 中为问题输入注释或标题，语音备注，在 VR 中手动移动剖切平面 | 在 VR 中放置问题，然后在 BCF 程序中添加文字；进入 VR 前在视图中设置剖切平面：参见[在 VR 头显中审阅模型](topic:vr-review) |
| 在 VR 中看到桌边的人（仅显示 VR 中的人），录制 VR 漫游 | 请他们以 VR 方式加入，或为漫游制作[动画](topic:animation) |

## 网格

| 尚未支持 | 目前的替代方法 |
|---|---|
| 按层级进行雕刻（多分辨率），以及“细节”去除已变得极小的三角形 | 对细分后的网格进行[雕刻](topic:sculpt)；用 {{ui:Remesh}} 使其重新均匀 |
| 重新网格化为沿形状分布的四边形面 | 用 {{ui:Remesh}}（均匀三角形），然后用[重拓扑](topic:mesh-edit#retopology)重建 |
| 为修改器在顶点上绘制权重（置换、平滑和收缩包裹作用于整个网格） | 应用修改器，然后雕刻或编辑需要的部分 |
| 复制和粘贴顶点、边或面，在面内部结束的刀切，没有面的线边 | 在模型中复制网格；从边到边进行刀切；用[挤出](topic:mesh-edit#change-the-shape)将开放边转为面 |

## 组织与查看

| 尚未支持 | 目前的替代方法 |
|---|---|
| 将 DWG 和 DXF 场地平面的图层作为标签 | 场地平面作为一个组导入：将其分解，并将需要标记的部分成组 |
| 同时进行多个剖切、剖切框，或将剖面轮廓导出为图纸 | 每次只能使用一个[剖切平面](topic:sections)；将视图导出为图像 |
| 将柔和边显示为虚线，或在拖动滑块时进行柔化 | 在实体信息中使用[按角度柔化](topic:soften)，并撤销以尝试其他角度 |
| 可搜索的在线模型库，或可选择选项（颜色、样式）的组件 | [入门库](topic:starter)；导入 Collada、OBJ 或 glTF 模型；将副本[拉伸](topic:stretch)到所需尺寸 |
| 从植物库放置植物 | 在实时视图中[散布](topic:live-view#scatter-plants-rocks-and-people)植物，或放置入门库中的树 |
| 组的独立副本 | 将其设为组件，然后点击 {{ui:Make unique}}（参见[故障排除](topic:troubleshooting#editing-one-group-changed-another)） |

## 渲染

| 尚未支持 | 目前的替代方法 |
|---|---|
| 视图中的渲染（{{ui:Render}} 工作区）、渲染队列，以及不使用 WebGPU 时的摄像机、天空图片、雾和灯光混合选项 | {{ui:Render a picture…}}中的“高质量”模式使用 WebGL 路径追踪器，但不包含这些选项（[渲染图片](topic:render#high-quality)） |
| 没有渲染引擎附加组件时由其他程序绘制渲染图片（CadCraft 从不运行遵循 GNU GPL 许可的程序）；通过其他程序使用全景或立体摄像机和天空图片；Unreal Engine 插件（文件已写出，但打开它们的插件未发布） | 我们自己的快速和路径追踪引擎；附加组件的引擎（[用其他程序绘制图片](topic:render-other-program)）；可从“引擎”列表中选择 USD、glTF 或 Unreal 文件夹文件，带到任何程序中使用 |
| {{ui:Render a picture…}} 中的散布植物和岩石 | 它们会显示在[实时视图](topic:live-view)、其全景、查看器和视频中 |

## 材质与颜色

| 尚未支持 | 目前的替代方法 |
|---|---|
| 高质量图片中，除基础颜色、粗糙度、金属度、不透明度、法线和自发光之外的输入在表面上变化（它们使用平均值） | [用节点制作材质](topic:shading)：仍可连接它们，视图会显示变化效果 |
| 推拉面上的置换 | 将对象转换为网格后进行置换 |
| 从应用程序将自己的材质分享到库，以及导入的纹理集中的打包（ARM/ORM）或 EXR 贴图 | 将其保存在文件中；将单独的贴图以 PNG 或 JPEG 格式导入 |
| 文件中的材质在实时团队协作会话中（它们只保留在制作它们的计算机上） | 保存文件并分享 |
| 贴花绕曲面弯曲，贴花的撤销，或在接缝处同时绘制多个面的纹理 | 在每个部件上放置较小的贴花；接缝的每一侧分别绘制 |
| 烘焙到推拉面，将多个对象烘焙到同一张图片中，手工塑造的笼，或来自灯光的烘焙光照 | 转换为网格后展开；分别烘焙每个对象；提高搜索距离；渲染图片以获得灯光效果 |
| 绘制粗糙度、金属度或高度，使用图片绘制（图章），以及大于 512 × 512 的纹理绘制 | 在此绘制基础颜色；在图片编辑器中制作其他贴图，并将其作为纹理集导入 |
| Collada、STL、PLY、3MF、IFC、DWG 和 DXF 导出中的纹理，以及导出模型中文件自身材质的节点图 | 这些格式会获得各材质的颜色；glTF 和 OBJ 会保留导入的纹理；将材质单独导出为 [MaterialX](topic:shading#materialx)；[USD](topic:usd) 为 ModelCraft 保留整个模型 |
| Collada 文件中的纹理 | 导入时会统计并忽略；`.skp` 和 `.glb` 文件中的纹理可以导入 |

## 文件

| 尚未支持 | 目前的替代方法 |
|---|---|
| 保存 SketchUp 文件，以及其中的文字和标注 | [导入](topic:import-sketchup-files)会保留面、颜色和纹理；导出 Collada（`.dae`）可返回 SketchUp |
| DWG 和 DXF 导出中的标注和参考线 | 导出后在 CAD 程序中添加 |
| DWG 和 DXF 中的点、表格和多重引线 | 导入时会统计并忽略；文字以单线字体导入，而非图纸使用的字体 |
| DWG 和 DXF 中的曲面、网格、表格和多重引线；三维实体在扫掠、放样或其他自由曲面上的面 | 同样会统计并忽略（三维实体本身可以导入）。请在 CAD 程序中将这些部分导出为 OBJ 或 Collada 后导入 |
| IFC 类型、属性或材质 | IFC 导出包含[楼层](topic:formats#ifc-ifc)和通用构件；其余内容请在 BIM 程序中添加 |
| 将模型直接发送到 BimCraft | 导出 {{ui:IFC for BimCraft (.ifc)}} 并在 BimCraft 中打开 |
| glTF 和 STL 中的散线 | 线稿请使用 OBJ 或 Collada |
| glTF 和 FBX 中除基础颜色以外的材质（金属、粗糙度、法线贴图、玻璃、清漆、光泽……） | 这些会被读取并列出；ModelCraft 保留基础颜色或纹理。请在[着色工作区](topic:shading)中重建外观 |
| glTF 骨骼、动画和变形目标 | 带蒙皮的模型以静止姿态导入；请在[时间线](topic:animation)中制作动画 |
| STEP 文件中的颜色和装配体零件名称 | 零件以网格导入，尺寸真实；导入后[上色](topic:paint)并命名 |
| `.3dm` 文件中的 SubD 对象、文字、标注和灯光 | 参见[排除的内容](topic:import-3dm-files#what-is-left-out-and-said)；在生成该文件的程序中将 SubD 转换为网格 |
| glTF 中的 KTX2 纹理和材质变体 | 使用 PNG 或 JPEG 纹理导出；将使用默认变体 |
| 写入 glTF 实例化（EXT_mesh_gpu_instancing） | 组件只写入一次并多次放置，所有查看器均可读取 |
| Alembic 动画（缓存的每个采样）、Alembic 点和曲线，以及写入 Alembic | 导入第一个采样；请在[时间线](topic:animation)中制作动画；可写入 glTF、USD 或 OBJ |
| OBJ 材质中的凹凸和法线贴图 | 仅导入颜色图片（`map_Kd`） |
| FBX 骨骼和动画、FBX 导出、FBX 6 文件 | 带蒙皮的模型以静止状态导入；导出为 glTF；旧文件请保存为 FBX 2011 或更高版本 |
| Collada 蒙皮、变形、摄像机、灯光、朝向和倾斜变换、外部引用 | 导入时忽略，并在消息中统计 |
| 备份文件 | {{ui:Save as}}（{{key:Mod+Shift+S}}）会保存另一份副本。崩溃后，ModelCraft 会提供未保存的工作内容（“恢复未保存的内容？”） |
| 云端保存和计算机之间的同步 | 目前尚不可用。请将文件保存到计算机，并在需要时复制到其他位置 |

## 三维打印

| 尚未支持 | 目前的替代方法 |
|---|---|
| 真正的切片器支撑（接口、底筏、精确的支撑图案） | [支撑预览](topic:print-tools#supports-preview)显示位置和大致用量；切片器的预览显示实际支撑 |
| 解开穿过自身的部件，或三个及以上面相交的边 | [修复](topic:print-tools#repair)会列出这些问题及其位置；使用[面相交](topic:intersect)并删除内部部分 |
| 填充图案，以及空心内部的晶格 | [抽空](topic:print-tools#hollow)会将其留空；切片器会为实心部件添加填充 |
| 比喷嘴能打印的更小的细节（墙体除外） | [壁厚](topic:print-tools#wall-thickness)用于查找薄壁；切片器的层预览会显示其余内容 |

## 性能

撤销会为每一步保存一份模型副本（[网格](topic:meshes)只保存已更改的部分），因此大量导入推拉几何体会使每次编辑都变慢。请保持导入内容精简，并保存后重新打开以清除历史记录。

## 应用与平台

- **桌面端：**ModelCraft 可在 Mac、Windows 和 Linux 的浏览器中运行，也可在 CadCraft Studio 中运行。CadCraft Studio 是一个桌面应用，一次安装即可包含全部八个应用。在 Android 上，CadCraft Studio 可通过 getcadcraft.com/download 下载的 APK 安装。目前尚无 iPad 或 iPhone 版本。
- **触控：**手指操作参见[环绕、平移与缩放](topic:orbit-pan-zoom)。手写笔压力用于设置[雕刻](topic:sculpt)中的画笔；在其他地方不使用压力和笔的倾斜。
- **布局：**ModelCraft [每页打印一个视图](topic:export-model#print-the-view-or-save-it-as-a-pdf)；没有包含多个视图或标题栏的图纸布局。如需按比例出图，请导出为便于 CadCraft 使用的 DWG/DXF。
