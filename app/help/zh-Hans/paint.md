颜色有助于区分模型的各个部分，**材质**（砖、墙板、屋面、木材、石材、瓷砖、混凝土、灰泥、草地、玻璃、金属）则让模型看起来像它所用的建材。两者的上色方式相同。

## 选择颜色

右侧的{{ui:颜色}}区域显示一排纯色、{{ui:默认}}（带斜线的那个：无颜色）以及用于其他颜色的{{ui:+}}色块。点击其中一个即可将其设为当前颜色。{{ui:材质}}工具会以此颜色开始。

## 上色

1. 按{{key:B}}（{{ui:材质}}），或在未选择任何对象时点击一种颜色。（已选择对象时，点击颜色会立即为所选对象上色。）
2. 点击一个面为其上色。
3. 点击一个组或组件，为该副本上色：其中没有自身颜色的面采用此颜色。在其内部上过色的面保留各自的颜色。

要同时为多个对象上色，先选择它们，再点击一种颜色；或用{{ui:材质}}点击其中任意一个。这算作一个撤销步骤。

| 按住 | 然后点击一个面 | 上色范围 |
|---|---|---|
| — | | 该面 |
| {{key:Ctrl}} | | 与其相连且颜色相同的所有面 |
| {{key:Shift}} | | 当前编辑的组中所有该颜色的面 |
| {{key:Alt}} | | 无：改为吸取该颜色 |

要将某个面恢复为无颜色，选择{{ui:默认}}后点击该面。

## 使用材质上色

{{ui:颜色}}下方的{{ui:材料}}区域按类别列出材质库：砖块与砌块、墙板、屋面、木材、石材、瓷砖、混凝土、灰泥、地面、玻璃和金属。将鼠标悬停在色块上可查看其名称。点击一个材质，然后像使用颜色一样为其上色：按{{key:B}}，点击面、组或组件；或先选择对象再点击该材质。

- 在**着色**样式下，面显示材质的纹理。隐藏线、线框和X射线样式显示其颜色。
- 纹理沿每个面的**水平方向**和**竖直方向**排布：砖层在每面墙上都保持水平，瓦片沿屋面坡度向下排列，地板上的木板沿红轴方向铺设。纹理为实际尺寸（一块砖约长 215 mm），因此在任何距离下看起来都正确。
- 在[渲染图](topic:render)中，材质保留其纹理和粗糙度；对于玻璃和金属，还保留其光泽。
- 使用{{ui:材质}}时按{{key:Alt}}点击，同样可以吸取面的材质。

这些纹理由ModelCraft自行绘制，因此可离线使用，且可免费用于任何用途（CC0）。

## 组件与颜色

在组件**内部**的面上涂的颜色会显示在每个副本上，因为所有副本共享同一个定义。从外部对**副本**（组件未打开时）上色，则该颜色仅属于该副本，因此同一组件的两个副本可以具有不同颜色。{{ui:实体信息}}显示所选面、组或组件的颜色。

## 文件中的颜色

- ModelCraft文件保留每种颜色和每种材质。
- 其他格式会用**材质颜色**（远看时的外观）代替纹理：glTF、Collada、OBJ、DWG和DXF，以及三维打印检查。在glTF、Collada和OBJ中，材质保留其名称，例如`Material_brick-red`。
- **glTF（.glb）**和**Collada（.dae）**：每种颜色都成为一种材质。以不同颜色显示的组件，每种颜色写入一次。glTF还会将导入的纹理写为纹理。
- **OBJ**：导出时会下载两个文件：`.obj`以及包含颜色的`.mtl`材质文件。请将它们保存在同一文件夹中。若含导入的纹理，`.obj`、`.mtl`和图片会打包为一个`.zip`。
- **DWG**保留准确颜色；**DXF**使用255种标准CAD颜色中最接近的一种。
- **STL**和**PLY**携带颜色：STL采用VisCAM / SolidView约定（不读取该约定的程序会忽略它），PLY则为每个点存储一种颜色。参见[文件格式详情](topic:formats)。

:::tip
要为屏幕建模，在对[偏移](topic:draw-faces)正面后，将边框涂成炭灰色，玻璃涂成蓝色。
:::
