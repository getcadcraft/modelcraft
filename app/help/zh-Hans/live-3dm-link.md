在你建模的地方继续建模，并在此处使用结果：渲染、布光，或围绕它布置场景。另一个程序中的每次修改都会更新 ModelCraft 中的一个群组。

:::note
链接需要在同一台计算机上运行 **CadCraft Studio**。浏览器标签页无法建立此连接。数据不会通过互联网传输：脚本使用本机地址和令牌与 Studio 通信。
:::

:::warning
此链接已使用脚本的文件写入器和另一程序的替代品进行测试，尚未在 Rhino 或 Grasshopper 本身中测试。如果在那里出现故障，请告知显示的提示内容。
:::

## 设置

1. 在 Studio 中打开 ModelCraft。在{{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}}中，勾选**允许 AI 助手和脚本使用 ModelCraft**，然后点击**编辑**。
2. 在 Studio 中选择{{ui:连接助手}}。它会显示地址和令牌，供下方粘贴使用。
3. 下载脚本：[cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)。

## 从 Rhino 中使用

1. 在 Rhino 的脚本编辑器中运行 `cadcraft_link.py`（Rhino 8 中为 Python 3）。
2. 首次运行时，粘贴地址和令牌。它们保存在主文件夹中的 `.cadcraft-link.json` 文件中，不会保存在模型里。Studio 每次启动都会生成新令牌，因此脚本届时会再次询问。

整个模型会作为一个以文档命名的群组导入，例如“chair (linked)”。之后，每次修改会在稍作停顿后同步过来，且只发送已更改的对象。再次运行脚本即可停止。

## 从 Grasshopper 中使用

请先在 Rhino 中运行一次脚本，以保存地址和令牌。

1. 添加一个脚本组件（Python 3），并将整个 `cadcraft_link.py` 粘贴到其中。
2. 为其设置以下输入：`G`（几何体，启用列表访问）、`N`（名称，可选）、`On`（布尔开关）和 `Target`（可选：`model` 或 `part`，适用于两个应用都已打开的情况）。
3. 将 `On` 设为 true。

每次求解都会发送 `G`，并替换该组件上次发送的内容，因此拖动滑块会更新此处的群组。其输出 `a` 会显示发生了什么。每个组件都有自己的群组。

## 群组可进行的操作

- **移动、标记、围绕其构建。** 群组及其标记的位置在每次更新后都会保持不变，其旁边的所有内容也一样。
- **不要编辑其内部。** 每次更新都会替换群组内的内容。这些对象归另一个程序所有。
- **撤销。** 间隔两秒以内的更新共用一个撤销步骤，因此{{key:Mod+Z}}可撤销整个拖动操作。下一次更新会使模型恢复一致。
- **保存。** 保存的文件会保留链接。重新打开后再次运行脚本，同一群组即可更新。

## 导入的内容

网格、多重曲面、曲面和挤出体会以屏幕上所见的网格形式导入；SubD 以其网格形式导入；曲线以边的形式导入；块按其所在位置作为独立对象导入（不作为组件）；图层导入为标记，颜色和单位也会一并导入。关于这些内容在此处的显示方式，请参阅[导入 .3dm 模型](topic:import-3dm-files)。

以下内容不会导入，其数量会在另一个程序中显示：点、文字、标注、灯光等。

**仅单向。** 此处的修改不会回传到另一个程序。

## 出现问题时

- **“没有 ModelCraft 或 PartCraft 窗口允许此操作”：** 执行设置的第 1 步。
- **“Studio 拒绝了令牌”：** Studio 已重新启动。复制新令牌并再次运行脚本。对于 Grasshopper，请先在 Rhino 中运行脚本。
- **“无法连接到 CadCraft Studio”：** Studio 未运行，或地址已更改。
