## 3D视图为空白

**症状：**屏幕中央保持空白，或只显示背景色，单击工具也没有反应。

**原因：**ModelCraft使用WebGL 2（浏览器的3D图形技术）绘制。当浏览器过旧、关闭了硬件加速，或图形驱动程序被阻止时，它就会缺失。

**解决办法：**

:::chromium
1. 打开浏览器设置，搜索“图形加速”。
2. 开启“可用时使用图形加速功能”，然后重新启动浏览器。
3. 如果已经开启，请在地址栏中输入`chrome://gpu`（Edge中为`edge://gpu`），在列表中查找“WebGL2”。如果显示为已禁用，请更新图形驱动程序。
:::

:::firefox
1. 打开**设置**，然后打开**常规**，向下滚动到“性能”。
2. 取消勾选“使用推荐的性能设置”，然后勾选“可用时使用硬件加速”。重新启动Firefox。
3. 如果仍然失败，请在地址栏中输入`about:support`，然后在“图形”部分查看WebGL 2。
:::

:::safari
更新macOS和Safari。较新版本的Safari始终开启WebGL 2。如果曾在**Safari** › **设置** › **高级**（或**功能标志**）中更改过实验性功能，请将其重置。
:::

在工作电脑、远程桌面或虚拟机上，3D图形可能被策略禁止。请尝试其他电脑。参见[浏览器和电脑](common:browsers)。

## 按键无效，或输入到输入框中

**原因：**键盘焦点位于面板的输入项中：{{ui:样式}}中的{{ui:面}}列表、太阳设置、{{ui:实体信息}}中的{{ui:名称}}字段，或单位选择器。此时字母键和方向键会进入该字段。

**解决办法：**在3D视图中单击，然后再按一次该键。对话框打开时，按键也无效。

## 输入数字无效

- **尚无方向。**输入的长度沿指针相对于第一次单击的方向。先将指针向所需方向稍微移动，再输入。
- **时机不对。**大多数工具只有在第一次单击之后才接受输入的值：先单击起始角点、面或要移动起点的点。{{ui:圆}}和{{ui:多边形}}在第一次单击前接受边数。
- **“Type a length such as 3m, 10'6" or 4m,3m.”** ModelCraft无法识别。请检查是否使用了小数逗号（`2,5`）：请改用句点。

## 触摸屏上图形起点错误

**症状：**用手指操作时，第一个矩形正常，但下一个矩形、圆或直线从上一次触摸结束的位置开始，而不是从你触摸的位置开始。

**原因：**此版本中的一个缺陷：在触摸屏上，工具会记住上一次手势的最后一个捕捉点。

**解决办法：**在绘制每个新图形之前，再次点按工具栏中的该工具按钮。这会重新启动工具，第一个点即落在触摸的位置。

## 编辑一个群组时另一个也发生了变化

**症状：**用{{ui:移动}}和{{key:Ctrl}}复制了一个群组，打开其中一个副本并进行编辑，另一个副本也随之改变了。{{ui:大纲}}中两者都显示为相同名称。

**原因：**在此版本中，复制群组会生成同一群组的第二个放置，与组件相同。ModelCraft的{{ui:设为唯一}}按钮仅对组件提供。

**解决办法：**选择要修改的副本，在{{ui:实体信息}}中单击{{ui:创建组件}}，然后单击{{ui:设为唯一}}。该副本现在拥有自己的内容。或者对其执行{{ui:分解}}。

## 推/拉没有达到预期效果

- **“Push/pull works on a face. Click a face.”** 你单击的是边或空白处。将指针悬停，直到面高亮显示，然后单击。
- **面位于群组内。**先双击群组将其打开。
- **窗洞没有切穿墙体。**矩形必须绘制在墙面上，而不是墙前方，并且墙体必须有背面。参见[在墙上开洞](topic:openings#if-it-did-not-cut-through)。
- **两个方块重叠却没有合并。**在此版本中，相互推入的实体不会相互切割或合并。

## 线或形状没有形成面

只有当边闭合成一个平面环时，面才会填充。请检查最后一个点是否捕捉到了第一个点（“端点”），以及所有边是否位于同一平面内。稍微偏离平面的环会保留为线。请在角点处捕捉，重新绘制其中一条边。

## 无法选择或擦除面

- 使用{{ui:选择}}时，单击靠近边缘会选中边。请单击靠近面中心的位置。
- {{ui:橡皮擦}}不会选中面。请选中面并按{{key:Delete}}，或擦除其中一条边。
- 如果面属于群组或组件，单击会选中整个对象。双击将其打开。

## “请先选择要移动的内容，或单击该内容。”

{{ui:移动}}、{{ui:旋转}}和{{ui:缩放}}需要作用对象：先选中它，或直接单击对象本身开始工具（不要单击空白处或辅助线）。

## “请先选择一些几何体（拖出选框，或三击以选择所有相连的内容）。”

{{key:G}}和{{key:Shift+G}}需要先有选择。辅助线不能成组。

## 方向键执行环绕而不是锁定

锁定仅在绘图或编辑工具的第一次单击之后才有效。{{ui:推/拉}}没有锁定功能；在{{ui:旋转}}中，锁定不会改变旋转角度。其他时候，方向键会环绕视图。

## 全屏时的Esc

全屏时，浏览器可能会用第一次{{key:Esc}}退出全屏。再次按{{key:Esc}}即可取消工具。

## 没有中键

按{{key:O}}启用{{ui:环绕}}并拖动，或使用方向键。参见[环绕、平移和缩放](topic:orbit-pan-zoom#without-a-middle-button)。

## 导入

| 消息 | 处理方法 |
|---|---|
| “ModelCraft可导入SketchUp (.skp)、Collada (.dae)、OBJ、glTF (.glb/.gltf)、FBX、PLY、STL、Alembic (.abc)、DWG和DXF。…不属于以上任何格式。” | 请在其他程序中将模型导出为以上格式之一 |
| “此文件超过300 MB。” | 在其他程序中简化或拆分模型 |
| “…对于此处的建模来说过大（超过200万个顶点）。” | 同上 |
| “此.gltf文件需要“…”…” | 将`.gltf`与其`.bin`和纹理文件一起拖入，或打开`.glb`版本 |
| “此glTF文件需要…扩展，ModelCraft尚不支持读取。” | 在其他程序中重新导出，不使用该扩展（例如KTX2纹理） |
| OBJ导入时没有颜色或纹理 | 将`.obj`与其`.mtl`和图片一起拖入 |
| “此Alembic文件使用旧版HDF5布局…” | 在其他程序中将其另存为Ogawa Alembic文件 |
| FBX导入时没有纹理 | 将`.fbx`与其纹理图片一起拖入，或在导出时嵌入媒体 |
| “此FBX文件为版本…，ModelCraft无法读取” | 重新导出为FBX 2011或更高版本 |
| STL或PLY导入后大了或小了1,000倍 | STL按毫米读取，PLY按米读取：请缩放它（参见[旋转和缩放](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)） |
| “这不是Collada (.dae)文件…”或“…不是格式良好的XML…” | 文件已损坏或不是Collada格式。请重新导出 |
| “此Collada文件中没有ModelCraft可导入的几何体。” | 它只包含相机、灯光或对其他文件的引用 |
| “这是二进制DXF。请将其保存为ASCII DXF，然后重试。” | 在CAD程序中重新将其保存为ASCII格式 |
| “这不是DWG图形…” | 文件不是DWG格式，或已损坏 |
| “无法读取此图形（…）。它可能已损坏，或保存为读取器不支持的DWG版本…” | 括号中给出了原因。请在CAD程序中将其保存为DXF，或保存为AutoCAD 2000至2018版本的DWG |
| “此图形距其原点超过10,000 km…” | 在CAD程序中将图形移到0,0附近 |

### 导入的尺寸错误或侧躺

- **OBJ：**OBJ没有单位；ModelCraft按米读取。毫米模型会导入为放大1000倍：请用`0.001`[缩放](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)；英寸模型则用`0.0254`。
- **OBJ侧躺：**ModelCraft期望OBJ文件的Y轴向上。以Z轴向上写入的文件会侧躺导入。请绕红色轴旋转90°：单击朝向红色方向的面以设置{{ui:旋转}}中心，或在其程序中打开文件并以Y轴向上导出。
- **DWG或DXF：**在“图形单位”对话框中选择的单位有误。撤销后重新导入。

## 打开文件

| 消息 | 处理方法 |
|---|---|
| “此文件不是ModelCraft模型（不是JSON）。” | 导入其他格式请使用{{ui:导入}} |
| “这不是我们能打开的ModelCraft文件：…” | 文件已损坏，或被手动修改过 |
| “此模型由更新版本的ModelCraft保存…” | 请在更新版本中打开它 |
| “此文件超过200 MB。” | 该模型对于此处打开来说过大 |

## 丢失了工作内容

ModelCraft不会自行保存到文件。关闭或刷新包含未保存更改的标签页时，浏览器会先询问（“离开网站？”或“重新加载网站？”）；请选择留在页面并保存。新建和打开也会询问（“未保存的更改”）。如果浏览器或电脑崩溃，请在同一浏览器中重新打开ModelCraft：它会提供恢复未保存的内容（“恢复未保存的内容？”；参见[恢复未保存的内容](common:recover)）。请经常使用{{key:Mod+S}}保存。

## 下载文件夹中充满了副本

每次保存都会生成一个新下载，名称为`Untitled (1).modelcraft`、`Untitled (2).modelcraft`，依此类推。删除旧文件，或将浏览器设置为每次保存时询问保存位置，并手动覆盖旧文件。参见[打开、保存、导入和导出](topic:files#save-a-model)。

## 运行变慢

- 撤销的每一步都会保存一份模型副本（[网格](topic:meshes)只保存变化的部分），因此在非常大的推/拉几何体导入中，每次编辑都会更慢。分解或擦除不需要的内容，保存，然后重新打开：重新打开也会清除撤销历史。
- 日照阴影的开销最大。建模时请取消勾选{{ui:日照阴影}}。

## 没有阴影

{{ui:日照阴影}}未启用、所选时间太阳在地平线以下（“此时太阳在地平线以下。”），或样式为{{ui:线框}}（不绘制阴影）。

## “此浏览器不允许全屏。”

某些浏览器和嵌入式视图会拒绝全屏。请改用浏览器自身的全屏功能（{{pick:mac=Control-Command-F|windows linux=F11}}）。

## 无网络连接时ModelCraft无法打开

只有在该浏览器中保存过离线使用版本后，ModelCraft才能离线打开：应用栏的按钮必须显示{{ui:离线可用}}。请在联网时打开它，然后单击{{ui:保存以供离线使用}}。如果按钮显示{{ui:无法保存}}，请在网络更好时再次单击。{{ui:无法离线使用}}表示此窗口（隐私窗口或受管理的电脑）无法保存副本。参见[离线工作](common:offline)。
