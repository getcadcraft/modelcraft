[时间轴](topic:animation)可以移动相机以及整个组和组件。**动画**工作空间能设置的关键帧不止这些，时间轴还增加了两个视图，用于调整和复用你设置的关键帧。

## 打开

在工具栏的工作空间列表中选择{{ui:动画}}。时间轴会在视图下方打开，工具栏显示动画组（{{ui:关键帧}}、{{ui:播放}}、{{ui:时间轴}}），右侧面板列出播放头处可以设置关键帧的内容。

## 为属性设置关键帧

面板在播放头处列出：

- **所选对象**：其{{ui:放置}}、{{ui:旋转（°）}}和{{ui:尺寸}}，各三个数值。输入数字并按Enter键：它会在播放头处设置关键帧，对象随之移动到该处。行旁边的菱形会按当前值设置关键帧；实心菱形表示播放头处已有关键帧。
- **灯光**：每个灯光的{{ui:亮度（lm）}}、{{ui:扩散角（°）}}（聚光灯）和{{ui:颜色}}。
- **相机**：{{ui:镜头视角（°）}}，用于在相机移动时缩放。

{{ui:设置变换关键帧}}（或{{key:I}}）会同时为每个所选组或组件设置位置、旋转和尺寸的关键帧；{{ui:相机关键帧}}（或{{key:K}}）为相机设置关键帧。打开{{ui:自动关键帧}}后，已用此方式设置位置、旋转和尺寸关键帧的组，每次移动时都会获得新的关键帧。

旋转由三个角度组成，依次绕 X、Y、Z 轴。设置关键帧的旋转超过 180° 时，会沿同一方向继续（190° 仍为 190°，而非 −170°），因此车轮可以转动多圈。

:::tip
用{{ui:所选对象关键帧}}在时间轴上设置了关键帧的组，拥有整体放置的关键帧。其行上的曲线按钮会将它们转换为位置、旋转和尺寸曲线（每个关键帧处的放置相同），以便你在{{ui:曲线}}中调整它们。
:::

## 形态键（变形）

**形态键**是同一网格（[网格](topic:meshes)）的另一种形状：脸上的笑容、门的凸起、弯曲的叶片。其滑块从网格的原始形状（0）混合到该形状（1）；多个形态键会叠加。

1. 在动画工作空间中选择一个网格：面板会显示其{{ui:形态键}}。
2. 单击{{ui:添加形态键}}。ModelCraft 会切换到[网格工作空间](topic:mesh-edit)，并编辑新的形态键：移动点、拉伸、雕刻，将网格改为你想要的形状。
3. 返回{{ui:动画}}并单击{{ui:完成}}。网格恢复原样，形态键保留你的更改。

然后拖动该形态键的滑块（或输入数值）来混合它。菱形会在播放头处为数值设置关键帧，因此形态键可以随时间渐增和渐隐；一旦它有了轨道，新的数值会在播放头处设置关键帧。铅笔图标再次编辑形态键的形状（直到单击{{ui:完成}}前，网格都会完整显示该形状；{{ui:取消}}会保持形态键原样），眼睛图标关闭该形态键，垃圾桶图标将其删除。

编辑形态键时添加的顶点属于网格本身：它会保留在你放置的位置，在每个形状中都是如此。

:::note
形态键先于网格的[修改器](topic:modifiers)移动网格：细分修改器会平滑混合后的形状。渲染的图片和视频会在每一帧显示形态键。
:::

## 骨架：使网格弯曲的骨骼

**骨架**是位于[网格](topic:meshes)内部的一组骨骼。摆动骨骼后，网格随之移动，每个点的移动幅度由其**权重**决定。

1. 在动画工作空间中选择网格，然后单击面板中的{{ui:添加骨架}}（或{{ui:绑定}}组中的{{ui:添加骨骼}}）：第一根骨骼从网格底部沿中间向上延伸。
2. 选中一根骨骼后，{{ui:添加子骨骼}}会从其末端添加下一根骨骼。在面板中设置任一骨骼的{{ui:头}}、{{ui:末端}}、{{ui:翻滚（°）}}以及它{{ui:挂靠于}}的对象；挂靠于另一根骨骼的骨骼会随之移动。对于仅用于控制其他骨骼的骨骼，请取消勾选{{ui:带动网格}}。
3. 单击{{ui:自动权重}}：每根骨骼会抓取离它最近的点，其影响会在网格上平滑扩散，因此两根骨骼之间的点会共享它们的影响。{{ui:仅最近的骨骼}}是一种更快、分界更硬的分配方式。

**摆姿势**：使用{{ui:姿势}}（{{key:P}}）：单击骨骼以选中它，拖动可绕视图轴旋转，按住{{key:Shift}}拖动可移动它。也可以在{{ui:姿势}}下输入其{{ui:放置}}、{{ui:旋转（°）}}和{{ui:尺寸}}；旋转以骨骼自身的轴为准，从其静止状态开始计算。菱形以及{{ui:为整个姿势设置关键帧}}会在播放头处为姿势设置关键帧；一旦骨骼有了关键帧，摆动它时就会在该处设置关键帧。{{ui:重置此骨骼}}和{{ui:重置姿势}}会让骨骼回到静止状态。

**绘制权重**（{{key:W}}）针对所选骨骼：网格以静止状态显示，每个面按该骨骼对它的影响程度着色，红色为全部影响，蓝色为无影响。绘制可增加影响（按住{{key:Mod}}则减少，按住{{key:Shift}}则平滑）；{{ui:大小（px）}}和{{ui:强度}}设置笔刷。勾选{{ui:使每个点的权重之和保持为 1}}时，给一根骨骼增加权重会从其他骨骼中等量扣除。每一笔都是模型撤销的一步。

{{ui:皮肤}}决定骨骼之间的点如何移动：{{ui:线性（快）}}会混合骨骼的移动，并使弯曲的关节略微收紧；{{ui:双四元数（在关节处保持体积）}}则让点绕关节旋转，因此肘部或膝盖保持其厚度（此时骨骼的{{ui:尺寸}}不会拉伸蒙皮）。

:::note
形态键先作用，然后是骨架，最后是[修改器](topic:modifiers)。视图、图片和视频都会显示摆姿后的网格；网格的权重随网格一起保存，骨骼及其姿势随动画一起保存。
:::

## 反向运动学（IK）和约束

**约束**会在对象的关键帧之后，按照某条规则移动骨骼或对象。选择对象（或骨架中的骨骼），然后在{{ui:…的约束}}下添加约束；多个约束会按列出的顺序运行（箭头可更改顺序），每个约束都有{{ui:影响程度}}（0 到 1，可像其他属性一样用菱形设置关键帧）以及开关。

| 约束 | 适用于 | 作用 |
|---|---|---|
| {{ui:伸展（IK）}} | 骨骼 | 该骨骼及其挂靠的骨骼（{{ui:链中的骨骼数}}）弯曲，使其末端抵达目标。使用两根骨骼并设置{{ui:极点（弯曲指向它）}}时，肘部或膝盖会指向极点；较长的链会平滑弯曲。超出范围时，链会直接指向目标。 |
| {{ui:注视}} | 两者 | 旋转，使{{ui:指向的轴}}朝向目标，同时尽量让{{ui:保持朝上的轴}}接近向上。 |
| {{ui:复制变换}} | 两者 | 采用目标的位置、旋转或尺寸（即勾选的项目）。 |
| {{ui:限制}} | 两者 | 在每个轴上，将其自身的位置、旋转（度数）或尺寸保持在{{ui:最小}}与{{ui:最大}}之间；留空某对数值则该轴不受限制。 |
| {{ui:子级于}} | 两者 | 跟随目标移动，如同挂靠于它一样，以选择目标时两者的位置为基准。 |
| {{ui:跟随路径}} | 对象 | 位于[曲线对象](topic:curves)上的{{ui:沿曲线位置}}处（0 为起点，1 为终点；为其设置关键帧即可沿路径移动），并在勾选{{ui:沿曲线转向}}时沿曲线方向朝向。 |

目标可以是当前打开的组中的另一个对象、同一骨架中的一根骨骼，或你输入的{{ui:一个点}}（对象的点使用模型坐标，骨骼的点使用其网格的坐标）。对于 IK 腿部，请将目标放在脚应处的位置并为目标设置关键帧，或为{{ui:影响程度}}设置关键帧，使腿部在关键帧动画与 IK 之间切换控制。

:::tip
注视沿路径跟随运动的对象的对象，会看到它位于路径上的位置：ModelCraft 会先计算所有目标，与对象的顺序无关。
:::

## 物理：下落、堆叠与碰撞

让对象下落并相互碰撞，然后将结果保留为关键帧。

1. 选择一个组、组件或网格，并在{{ui:物理}}下设置其{{ui:刚体}}：{{ui:下落并碰撞}}（会移动）或{{ui:保持不动，起阻挡作用}}（如桌子、墙、斜坡）。为下落的对象设置{{ui:形状}}，即{{ui:长方体（其边界）}}或{{ui:球体（其边界的外接球）}}，以及其{{ui:质量（kg）}}、{{ui:摩擦}}和{{ui:弹性}}（0 为沉闷的撞击，1 则反弹至同样的高度）。
2. 在{{ui:整个模型}}下设置{{ui:从（s）}}和{{ui:到（s）}}、{{ui:重力（m/s²，向下）}}，以及是否有{{ui:可落在其上的地面}}（及其高度）。
3. 单击{{ui:烘焙物理}}（在面板或{{ui:物理}}组中）。每个下落对象会在两个时间之间的每一帧获得位置、旋转和尺寸的关键帧；像播放其他动画一样播放即可。

重新烘焙会替换这些关键帧；{{ui:移除烘焙的关键帧}}会将其删除。对象从静止状态开始，位置由其关键帧、曲线和约束在{{ui:从（s）}}处决定（此前的关键帧运动不会延续到下落中）。增加{{ui:每帧步数}}可使高堆叠更稳定；状态栏会在结束时提示仍在运动的对象。

:::note
形状是围绕每个对象边界的长方体和球体；长方体通过其角、棱中点和面中点接触，因此长方体会按预期堆叠和翻倒。布料、流体、对象之间的关节以及精确形状尚未实现。
:::

## 驱动器

**驱动器**根据其他内容设定形态键，而不是手动设置：打开某个键的驱动器（计算器按钮），编写一个**表达式**，并为其中的每个名称指定其读取的内容（{{ui:读取}}）：以秒为单位的时间、帧、对象的位置、旋转或尺寸（沿 X、Y 或 Z）、灯光的亮度，或另一个形态键。例如，若 `v` 读取门绕 Z 轴的旋转，则 `clamp(v / 90, 0, 1)` 会随门的打开而打开某个形态。

表达式可以使用数字、名称、`+ - * / % ^` 和括号，以及函数 `sin cos tan asin acos atan atan2 abs sqrt exp log floor ceil round sign pow min max clamp lerp smoothstep rad deg`，并可使用 `pi` 和 `e`。错误会被指出，且不做任何更改。被驱动的关键帧的滑块会显示驱动器的数值；在删除驱动器之前，驱动器优先于该关键帧的轨道。

## 选择和更改关键帧（关键帧视图）

{{ui:关键帧}}为每个轨道显示一行：相机、每个运动的组，以及每个属性（例如“灯光 2 · 亮度（lm）”；属性关键帧为圆形）。

- 单击关键帧以选中它；按住{{key:Shift}}单击或{{key:Mod}}单击可在选择中添加或删除关键帧。在各行上按住{{key:Shift}}拖动可绘制一个框，框住其中的所有关键帧。
- 拖动所选关键帧即可一起移动；{{key:Left}} / {{key:Right}}可将其移动一帧（按住{{key:Shift}}则为十帧）。
- {{key:Mod+C}}复制所选关键帧，{{key:Mod+V}}从播放头处将其粘贴到相同的轨道上（其他 ModelCraft 标签页也可以粘贴）。
- {{ui:拉伸}}会以播放头为中心，按其旁边的数字拉开所选关键帧（2 表示间距加倍；0.5 则使其靠拢）。
- 缓动列表设置每个所选关键帧之后的运动方式。

## 调整曲线（曲线视图）

{{ui:曲线}}是每个数值随时间变化的图表：时间沿横轴，数值沿纵轴。在左侧列表中勾选要显示的曲线（X、Y、Z 分别为红、绿、蓝）。

- 单击关键帧（一个方块）以选中它，按住{{key:Shift}}单击可选择更多，或拖动框选。拖动所选关键帧可更改其时间和数值；选中多个时，拖动会沿时间方向一起移动。
- 选中的关键帧会显示其两个**控制柄**。拖动其中一个可调整该侧的曲线。{{ui:控制柄}}决定其行为：{{ui:自动}}（穿过周围关键帧的平滑曲线）、{{ui:指向下一个关键帧}}、{{ui:对齐}}（两个控制柄保持在一条直线上，因此曲线没有转角）或{{ui:自由}}。
- {{ui:来自所选关键帧}}设置每个所选关键帧如何运动到下一个：{{ui:曲线（控制柄）}}、{{ui:平滑}}、{{ui:匀速}}、{{ui:缓入缓出}}或{{ui:保持}}。
- {{ui:之前}}和{{ui:之后}}设置曲线在其关键帧之外的行为：{{ui:保持}}（停留在第一个或最后一个数值）、{{ui:重复}}、{{ui:往返}}，或{{ui:重复并延续}}（每次重复都从上一次结束的位置开始：车轮会持续滚动，行走的人会持续行走）。
- 滚轮可缩放（按住{{key:Mod}}：仅缩放数值；按住{{key:Shift}}：仅缩放时间）；用中键拖动或按住{{key:Alt}}拖动可平移；{{ui:显示全部}}或{{key:Home}}会适配所有显示的曲线。在空白处单击可将播放头移到该处。{{key:Delete}}删除所选关键帧。

曲线的控制柄在时间上不会相互交叉，因此曲线永远不会倒退。

## 复用动画（片段视图）

**片段**在时间轴上播放已保存的动画（**动作**）。片段按顺序混合，较低的行覆盖较高的行；时间轴自身的轨道位于所有片段之上。

1. 像平常一样为组和灯光设置关键帧，然后在{{ui:片段}}中单击{{ui:创建片段}}并为动作命名。这些轨道会成为动作，片段会在它们原来的位置播放它（相机仍留在时间轴上）。
2. 要再次使用，请选择该动作并单击{{ui:添加片段}}：新片段会从播放头处开始。
3. 沿其行拖动片段即可移动它；单击它可设置{{ui:开始（s）}}、{{ui:速度}}（2 表示两倍快）、{{ui:重复次数}}、{{ui:影响程度}}（0 到 1）、{{ui:混合}}（{{ui:替换}}，或{{ui:叠加}}于其之前的片段之上）、{{ui:片段之外}}（无内容、保持其结束状态，或保持两端）以及{{ui:静音}}。箭头可更改顺序；垃圾桶可删除它（不再被任何片段使用的动作也会一并删除）。

片段的{{ui:影响程度}}低于 100% 时，它会与其下方的内容混合：即其之前的片段，或没有动画时的灯光或放置状态。

## 各项内容在何处播放

| 内容 | 在视图中 | 在渲染的视频中 |
|---|---|---|
| 相机关键帧，带相机关键帧时的镜头视角 | 是 | 是 |
| 放置、旋转和尺寸（关键帧、曲线、片段） | 是 | 是 |
| 灯光亮度、扩散角和颜色 | 是 | 尚未支持：视频在开始时使用灯光的当前状态（参见[尚未实现的功能](topic:not-built-yet)） |
| 没有相机关键帧时的镜头视角 | 是 | 尚未支持：也请为相机设置关键帧 |
| 形态键和驱动器 | 是 | 是 |
| 骨架（摆姿后的网格） | 是 | 是 |
| 反向运动学和约束 | 是 | 是 |
| 烘焙的物理（关键帧） | 是 | 是 |

所有内容都与动画的其余部分一起保存在 `.modelcraft` 文件中，时间轴的{{ui:撤销}}和{{ui:重做}}可撤销其中任何操作。
