数值框位于底部状态栏中，其标签随工具变化。工作时它会实时显示当前尺寸；你随时可以输入精确的尺寸。

## 如何输入

1. 先单击开始该操作（第一个角点、面、要移动的起点）。
2. 直接输入。无需点击数值框：数字或以下字符之一`. , - ' " [ < * /`会将输入发送到数值框中。
3. 按{{key:Enter}}。

在数值框中按{{key:Esc}}可清除内容并返回视图。在触摸屏上，点击数值框即可调出键盘。

如果ModelCraft无法识别你输入的内容，状态栏会显示"请输入长度，例如3m、10'6"或4m,3m。"。如果工具无法使用该输入，会显示"操作失败：……"，并附上原因。

## 长度

| 输入 | 含义 |
|---|---|
| `3m` `320cm` `3200mm` | 米、厘米、毫米 |
| `10'` `10ft` `10 feet` | 英尺 |
| `6"` `6in` `6 inches` | 英寸 |
| `10'6"` `10' 6"` `10'-6 1/2"` | 英尺和英寸，带分数 |
| `6 1/2"` `6-1/2"` `3/4"` | 带分数的英寸 |
| `1.5ft` `.5m` | 带单位的小数 |
| `120` | 裸数字，以模型单位计 |

**裸数字使用模型的单位**，即右下角选择器中显示的单位：在英尺和英寸模型中为英寸（因此`120`即10英尺），在毫米模型中为毫米，依此类推。输入单位时始终以该单位为准，与模型单位无关。弯引号和撇号（’ ” ′ ″）同样按英尺和英寸解析。

:::warning
小数必须使用**小数点**：`2.5m`。逗号用于分隔两个值，因此`2,5`表示2和5（两个值），无论语言设置如何。
:::

## 计算

任何长度都可以是一个计算式：使用`+`加、`-`减、`*`乘、`/`除，并可使用括号。无需计算器。

| 输入 | 含义 |
|---|---|
| `2.5/3` | 2.5的三分之一（以模型单位计） |
| `12'6"+3/4"` | 12' 6 3/4" |
| `(24'-0")/3` | 8' |
| `2*450mm` | 900 mm |
| `4+7/16` | 在英尺和英寸模型中为4 7/16" |
| `3m-25cm` | 2.75 m |

裸数字为长度时以模型单位计（在米制模型中，`2.5/3`为0.833 m）；当它与一个长度相乘或相除时则视为普通系数（`2*450mm`）。角度和系数同样可以计算：`90/2`即45°。两个长度相乘得到的是面积而非长度，因此`2m*3m`会被拒绝。

如果ModelCraft无法计算，状态栏会说明错误所在的位置，例如"除数为零（第4个字符）。"。括号也会启动数值框，因此可以以`(`开头。

以下输入保留其自身含义：复制后的`/3`、`3x`和`*3`，表示边数的`24s`，以及选中边线时的`/3`（它会[等分该边线](topic:divide)）。

## 点和偏移

对于{{ui:直线}}和{{ui:移动}}，在第一次单击之后：

- `[x,y,z]`会移动到模型中的该精确点（若你正在组内编辑，则以该组自身的坐标轴为准）。示例：`[0,0,3m]`表示位于原点正上方3 m处。
- `<dx,dy,dz>`表示从第一个点沿红、绿、蓝轴方向偏移的距离。示例：`<0,0,10'>`表示竖直向上10英尺。

三个值可各自带不同的单位：`<12',0,6">`。

## 移动后的复制

紧接着使用{{ui:移动}}进行复制后，可输入：

| 输入 | 生成 |
|---|---|
| `3x`或`*3` | 以相同间距连续生成3个副本 |
| `/3` | 从原件到第一个副本之间均匀分布3个副本 |

最多500个副本。参见[移动、复制和创建阵列](topic:move-copy#a-row-of-copies)。

## 长度需要方向

单个输入的长度会沿第一次单击后指针所指的方向生效。如果在单击后、尚未移动指针时直接输入，则还没有方向，什么也不会发生。请先将指针稍微移向目标方向，再输入。

## 模型单位

在右下角的选择器中更改单位：{{ui:ft和in}}、in、ft、yd、mi、mil、µm、mm、cm、m或km，前提是它们已在{{ui:设置}} › {{ui:常规}} › {{ui:单位}}中启用（模型自身的单位始终可用）。以任何单位标记输入的长度都会按该单位解析。参见[单位、输入值和单位列表](common:unit-lists)。更改单位只影响长度的显示方式和裸数字的解析；模型的实际尺寸保持不变。单位会保存在文件中。

尺寸的显示方式：

| 单位 | 长度 | 面积 | 体积 |
|---|---|---|---|
| ft和in | `10' 6 1/2"`（精确到1/16"） | 平方英尺 | 立方英尺 |
| in | `126 1/2"` | 平方英寸 | 立方英寸 |
| m | `3.2 m` | m² | m³ |
| cm | `320 cm` | cm² | cm³ |
| mm | `3200 mm` | 0.01 m²及以上为m²，否则为mm² | 0.01 m³及以上为m³，否则为mm³ |

新模型在浏览器语言设置为美国地区（以及利比里亚和缅甸）时以英尺和英寸开始，其他地区则以毫米开始。在{{ui:设置}} › {{ui:常规}} › {{ui:单位}}中加星标的单位会代替上述默认值使用（前提是ModelCraft支持该单位）。也可以在{{ui:新建}}后更改选择器。
