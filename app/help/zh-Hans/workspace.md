自上而下依次为：应用栏、工具栏、三列（左侧面板、三维视图、右侧面板）和状态栏。

## 应用栏

最顶部的细栏属于每一个CadCraft应用。它包含应用名称和版本、{{ui:关于ModelCraft}}、屏幕模式按钮以及{{ui:图纸}} / {{ui:模型}}切换。

- {{ui:图纸}}是浅色主题，{{ui:模型}}是深色主题。三维视图会相应改变颜色；你的模型不会改变。
- 屏幕模式按钮（起初显示{{ui:全屏}}）和{{key:Ctrl+Shift+F}}依次切换三种模式：普通、全屏，以及隐藏各栏的全屏。隐藏各栏后，将指针指向屏幕顶端（或点按那里）即可调回。{{key:Esc}}退出全屏。

:::note
{{key:Ctrl+Shift+F}}在所有计算机上都使用Control键，Mac也一样。在iPhone上，浏览器没有全屏，该按钮只负责隐藏和显示各栏。
:::

## 工具栏

工具栏分为带标签的若干组。将指针悬停在按钮上可以看到它的名称和快捷键。

在它的左侧，{{ui:工作空间}}列表用于切换工具栏和右侧面板的用途：{{ui:模型}}（推/拉建模，即下文的导览）、{{ui:网格}}（[编辑网格](topic:mesh-edit)）、{{ui:曲线}}（[曲线对象](topic:curves)）、{{ui:UV}}（[布置UV](topic:uv)）、{{ui:雕刻}}（[雕刻](topic:sculpt)）、{{ui:着色}}（[用节点制作的材质](topic:shading)）、{{ui:动画}}（[制作动画](topic:animate)）和{{ui:渲染}}（[在视图中渲染](topic:render#render-in-the-view)）。

| 组 | 按钮 |
|---|---|
| 文件 | {{ui:新建}}、{{ui:打开}}、{{ui:保存}}、{{ui:导入}}、{{ui:导出}}（格式菜单） |
| 绘制 | {{ui:直线}}（{{key:L}}）、{{ui:矩形}}（{{key:R}}）、{{ui:圆}}（{{key:C}}）、{{ui:多边形}}（{{key:N}}） |
| 修改 | {{ui:选择}}（{{key:Space}}）、{{ui:推/拉}}（{{key:P}}）、{{ui:移动}}（{{key:M}}）、{{ui:旋转}}（{{key:Q}}）、{{ui:缩放}}（{{key:S}}）、{{ui:橡皮擦}}（{{key:E}}）、{{ui:卷尺}}（{{key:T}}） |
| 组织 | {{ui:组件}}（{{key:G}}）、{{ui:群组}}（{{key:Shift+G}}）、{{ui:分解}} |
| 编辑 | {{ui:撤销}}（{{key:Mod+Z}}）、{{ui:重做}}（{{key:Mod+Y}}）、{{ui:复制}}（{{key:Mod+C}}）、{{ui:粘贴}}（{{key:Mod+V}}）、{{ui:更多}}（菜单：剪切、复制、粘贴、原位粘贴{{key:Mod+Shift+V}}、创建副本{{key:Mod+D}}、删除、全选、取消选择，以及按键样式） |
| 相机 | {{ui:环绕}}（{{key:O}}）、{{ui:平移}}（{{key:H}}）、{{ui:缩放}}（{{key:Z}}）、{{ui:范围}}（{{key:Shift+Z}}）、{{ui:视图}}（菜单） |

这里显示的是推拉式的按键；如果在[ModelCraft设置](topic:settings)中选择了建模器样式，工具提示会改为显示建模器样式的按键。正在使用的工具呈按下状态。在窄屏幕上，工具栏可横向滚动。

{{ui:视图}}菜单包含{{ui:等轴测}}、{{ui:顶}}、{{ui:前}}、{{ui:右}}、{{ui:后}}、{{ui:左}}和{{ui:底}}（均适合模型显示），以及{{ui:透视}}，用于在透视投影和平行投影之间切换。

## 三维视图

屏幕中间部分。红、绿、蓝三条线是坐标轴：红轴和绿轴位于地面上，蓝轴朝上，**北方是绿轴方向**。它们的交点是原点。

- 刚开始时，一张标题为“开始建模”的卡片列出最先用到的几个按键。选择绘图工具或在视图中点击后它会消失。
- 工具工作时，视图会显示**推断标记**：指针捕捉位置上的彩色小图形（端点处为绿色圆圈，中点处为青色圆圈，边上为红色方块，面上为蓝色菱形）。参见[推断和捕捉](topic:inference)。
- 被选中的对象变成蓝色。从背面看到的面是蓝灰色。
- 打开一个群组进行编辑时，它外部的一切都会淡出，坐标轴会移到该群组自己的坐标轴上。
- 当模型有场景时，视图顶部会出现一排场景选项卡。
- 将文件拖放到视图的任意位置即可打开或导入。

## 左侧面板

**{{ui:大纲}}**列出模型中的群组和组件，层级与它们在模型中的嵌套一致。被多次使用的组件会显示使用次数，例如“Window (4)”。

- 点击名称可选择它。双击可打开它进行编辑。
- **按名称查找**（有两个或更多群组时显示）只保留名称匹配的行，以及它们所在的群组。{{key:Esc}}清除。
- 行末的**眼睛**图标可隐藏或显示该群组或组件（与{{ui:编辑}} › {{ui:更多}} › {{ui:隐藏}}效果相同）。标记图标表示它被其[标记](topic:tags)隐藏。
- **原地重命名：**点击一行，按{{key:F2}}，输入名称，再按{{key:Enter}}（{{key:Esc}}保留旧名称）。
- **拖动一行**：拖到另一个群组行的中间，即可把它移入该群组；拖到某行的上边缘或下边缘，即可把它放在该行之前或之后；拖到{{ui:大纲}}标题上，即可把它移到最上层。它在模型中的位置保持不变，并保留其颜色、标记和名称。群组不能放入它自己内部。每次移动是一步撤销。参见[在大纲中重新排列](topic:groups-components#rearrange-in-the-outliner)。
- 在群组内部编辑时，会显示“正在编辑：模型 › …”这样一行，并出现{{ui:关闭群组}}按钮。它会一次关闭所有已打开的层级。

**{{ui:组件}}**列出每个组件定义以及已放置的副本数（“3×”），还有一个{{ui:放置}}按钮，可在你点击的位置再添加一个副本。

## 右侧面板

**{{ui:实体信息}}**描述所选对象。它的标题会随所选内容而变化：

| 标题 | 显示内容 | 按钮 |
|---|---|---|
| 模型（未选择任何内容） | 面、边、群组、组件及其放置数量、辅助线、整体尺寸 | {{ui:删除所有辅助线}}（有辅助线时） |
| 面 | 面积、孔的数量 | {{ui:反转面}} |
| 边 | 长度 | 无 |
| 群组或组件 | 名称（输入即可重命名）、放置次数、是否为封闭实体、体积、尺寸 | {{ui:编辑}}、{{ui:分解}}、{{ui:设为唯一}}（放置多次的组件）、{{ui:创建组件}}（群组） |
| 辅助点或辅助线 | 无 | {{ui:删除}} |
| 多个对象 | 面、边、群组和辅助线的数量，面的总面积 | {{ui:创建组件（G）}}、{{ui:创建群组（Shift+G）}} |

**{{ui:样式}}**设置模型的绘制方式：{{ui:面}}（{{ui:着色}}、{{ui:消隐线}}、{{ui:线框}}、{{ui:X射线}}）、{{ui:显示边线}}，以及带有太阳日期、时间和位置的{{ui:日照阴影}}。参见[样式和日照阴影](topic:styles-shadows)。

**{{ui:场景}}**用于保存视图：{{ui:添加场景}}、场景列表，以及{{ui:上一个}}、{{ui:播放}}和{{ui:下一个}}。参见[将视图保存为场景](topic:scenes)。

## 状态栏

沿底部自左向右依次为：

1. **提示**：工具接下来需要什么，或指针正在捕捉什么（“端点”、“在红轴上”）。
2. **消息**：刚刚发生了什么（“已撤销推/拉。”、“已导入site.dxf：地面上有1697条边线，位于一个群组中。”）或某项操作为何没有成功。
3. **数值框**：标签随工具而变（{{ui:长度}}、{{ui:尺寸}}、{{ui:半径}}、{{ui:边数}}、{{ui:距离}}、{{ui:角度}}、{{ui:缩放}}、{{ui:偏移}}）。它在你操作时显示实时大小，并接受你的输入。参见[在数值框中输入精确尺寸](topic:value-box)。
4. **按键样式**：{{ui:按键：推拉式}}或{{ui:按键：建模器式}}会同时切换键盘快捷键和鼠标按键（与[ModelCraft设置](topic:settings)中相同）。
5. **{{ui:捕捉}}和{{ui:碰撞}}**：捕捉点、边和轴，以及实体在接触处停止。划掉表示关闭。点击可切换。参见[ModelCraft设置](topic:settings)。
6. **单位选择器**：长度所用的显示单位。参见[入门](topic:getting-started#check-the-units-first)。

## 在窄屏幕上

宽度低于约760像素时（手机或窄窗口），三维视图占满屏幕。工具栏变为可横向滚动的一行，面板从屏幕底部的栏中以面板页的形式打开。
