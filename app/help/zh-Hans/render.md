{{ui:渲染图片…}}会为当前视图制作一张类似日光照片的图片，而不是线稿：包括天空、根据模型所在位置和日期确定的太阳、柔和阴影、来自整个天空的光线（会使角落和缝隙变暗），以及可以呈现玻璃、金属或光泽漆效果的颜色。模型本身不会被改动。

## 渲染视图

1. 按照你想要的图片效果设置视图：环绕、缩放、选择一个[场景](topic:scenes)，隐藏不应显示的内容。图片使用视图自身的摄像机。
2. 在{{ui:文件}}组中点击{{ui:导出}}，然后点击{{ui:渲染图片…}}。
3. 如果按下的{{ui:场景}}不是你想要的（参见[场景预设](topic:render#scene-presets-a-good-picture-in-one-click)），请选择一个，选择{{ui:尺寸}}，然后点击{{ui:渲染}}。

   图片会随渲染逐步显现，每一遍都会更平滑。{{ui:停止}}（或{{key:Esc}}）会提前结束渲染，并保留当前已完成的图片。

4. 点击{{ui:保存}}以下载图片（除非{{ui:另存为}}另有设置，否则为 PNG）。

:::tip
先用{{ui:草稿}}和{{ui:视图尺寸}}检查摄像机和效果，然后以更大尺寸渲染{{ui:良好}}或{{ui:最佳}}作为最终图片。
:::

## 场景预设：一键得到好图片

对话框顶部有四个{{ui:场景}}按钮。每个按钮会一次性设置天空、亮度、地面、边线、质量和太阳，因此在制作第一张图片之前无需学习任何内容。点击其中一个，然后点击{{ui:渲染}}。

| 场景 | 设置内容 | 用途 |
|---|---|---|
| {{ui:室外}} | 晴朗天空、模型自带的太阳、开启地面 | 从外部看建筑 |
| {{ui:室内}} | 阴天天空（光线均匀，没有强烈的太阳光斑），亮度提高半档 | 从房间内部看 |
| {{ui:剖面视图}} | 白色影棚，无地面，快速渲染中显示边线 | 被剖切面切开的模型 |
| {{ui:夜间}} | 太阳落下（按场地所在半球取冬至午夜），亮度提高一档 | 由灯具照明的模型。没有灯具时画面会很暗 |

- {{ui:根据此视图选择}}会为你自动选择：剖切开启时选{{ui:剖面视图}}，摄像机位于模型内部时选{{ui:室内}}，否则选{{ui:室外}}。第一次打开对话框时，它会自动以这种方式开始。
- 下方的所有设置都可以修改。一旦你修改了某个场景所设定的值，就不再有按钮处于按下状态，按钮下方的提示行会说明这些设置是你自定义的。再次点击该场景即可恢复其数值。
- 场景不会改变引擎、模式、尺寸、材料、摄像机或灯具。

:::note
场景在 ModelCraft 和 BimCraft 中给出的数值相同。最终图片的效果取决于你的模型和显卡。
:::

## 设置

| 设置 | 作用 |
|---|---|
| {{ui:尺寸}} | 视图的尺寸、视图尺寸的两倍、全高清、4K 或正方形。固定尺寸保持视图的摄像机，并在两侧显示或多或少的内容 |
| {{ui:模式}} | {{ui:快速}}，或{{ui:高质量（路径追踪）}}（见下文）及其{{ui:时间限制}} |
| {{ui:质量}} | 参与平均的遍数（高质量模式下为采样数）：{{ui:草稿}} 16，{{ui:良好}} 64，{{ui:最佳}} 256。遍数越多，阴影和边缘越平滑，耗时也越长 |
| {{ui:天空}} | {{ui:晴空}}、{{ui:阴天}}（柔和光线，阴影较淡）、{{ui:黄昏}}（低而暖的光线）或{{ui:白色影棚}}（纯白背景） |
| {{ui:太阳}} | 太阳的日期、时间和位置来自{{ui:样式}}›太阳。勾选{{ui:为此图片使用另一个日期和时间}}，可在不更改模型样式的情况下尝试其他时间 |
| {{ui:亮度}} | 以档（stop）为单位调亮或调暗 |
| {{ui:模型下方的地面}} | 承接阴影并淡入地平线的地面。对于悬浮的模型请关闭 |
| {{ui:绘制边线}} | 在图片上以细线绘制模型边线，形成线稿效果 |

当所选时间太阳位于地平线以下时即为夜晚：天空变暗，模型由其[灯具](topic:lights)照亮。对话框会对此作出提示。

设置会保存在 `.modelcraft` 文件中，因此同一模型的下一张图片会从你上次停下的地方开始。

## 让颜色呈现玻璃或金属效果

在{{ui:材料}}下，屏幕上的每种颜色都有一种效果：{{ui:哑光}}、{{ui:缎面}}、{{ui:高光}}、{{ui:金属}}、{{ui:抛光金属}}、{{ui:玻璃}}或{{ui:磨砂玻璃}}。{{ui:未上色的面}}是指没有自身颜色的面。

要让窗户呈现玻璃效果，请先用一种颜色[上色](topic:paint)窗格，然后将该颜色设为{{ui:玻璃}}。玻璃会透出天空以及其后的物体，并带有其颜色的色调，同时反射天空。

:::note
在{{ui:快速}}模式下，玻璃和金属只反射天空，而不反射模型的其他部分，光线也不会在玻璃中折射。下面的{{ui:高质量（路径追踪）}}模式可以同时实现这两点。
:::

## 高质量

选择{{ui:模式}}›{{ui:高质量（路径追踪）}}，可得到一张像相机所见那样追踪光线的图片：

- 光线会在表面之间反射，因此透过窗户或由灯具照亮的房间会四周都被照亮，颜色也会溢到相邻表面上；
- 玻璃是真正的玻璃：光线会穿过它，并且它会反射模型；
- 金属和抛光表面会反射模型的其他部分；
- 灯板会以面光源的方式发光，并产生柔和阴影。

这比{{ui:快速}}慢得多：每一遍都会为每个像素重新追踪光线。图片一开始会有颗粒感，随着采样累加而逐渐清晰，因此请先用较小尺寸（{{ui:视图尺寸}}、{{ui:草稿}}），并设置{{ui:时间限制}}：时间用完时，会保留当前的图片。{{ui:停止}}同样会保留图片。第一遍会等待浏览器准备路径追踪器。

如果浏览器支持 WebGPU，路径追踪器就是 CadCraft 自己的程序，并在显卡上运行；图片下方的提示行会显示“在显卡上进行路径追踪（WebGPU）”。点击{{ui:停止}}或达到时间限制后，{{ui:继续}}会从同一张图片继续，直到完成所有采样；更改设置或再次按下{{ui:渲染}}则会重新开始。没有 WebGPU 时，图片会改用 WebGL 进行路径追踪（提示行会说明这一点），并且不提供{{ui:继续}}。

:::linux
Linux 上的 Firefox 以及大多数 Chrome 配置尚不支持 WebGPU，因此那里的高质量模式使用 WebGL。
:::

在此模式下不绘制边线，库纹理只显示颜色和粗糙度，不显示凹凸（[用节点制作的材料](topic:shading#in-high-quality-pictures)会显示其法线和凹凸），并且剖切会在图片开始前应用于模型。

{{ui:降噪（清除采样后残留的颗粒）}}默认开启：图片完成或停止后，残留的颗粒会由为此开发的神经网络清除（Intel Open Image Denoise 发布的网络，在你自己的电脑上运行：优先在显卡上运行，否则在处理器上运行）。采样较少的图片也能得到干净的结果；{{ui:显示}}›{{ui:降噪前的图像}}可显示降噪前的渲染效果。

## 在视图中渲染

{{ui:渲染}}工作区会直接在视图中运行路径追踪器：环绕视图、编辑模型或更改灯具，它都会立即重新开始。{{ui:区域}}：拖出一个矩形，只渲染该区域；{{ui:整个视图}}则恢复。{{ui:对焦}}：点击应当清晰的位置，景深会在该处对焦。{{ui:细节}}设置视图中参与渲染的像素比例（越少越快）。{{ui:暂停}}可停止并继续。此功能需要 WebGPU：没有它时，工作区会提示，但{{ui:导出}}›{{ui:渲染图片…}}仍可使用。

## 显卡上的天空和灯光配置文件

借助 WebGPU，高质量模式还提供两种天空：

- {{ui:物理天空}}根据太阳高度计算日光：头顶为深蓝色，地平线附近为浅色带，太阳越低颜色越暖、亮度越暗。{{ui:雾霾}}可从非常晴朗的一天（2）调整到雾霾较重的一天（10）。
- {{ui:天空图片（HDRI）}}使用真实场所的全景图片为模型照明。{{ui:选择图片…}}会选取一个等距圆柱投影的 `.hdr` 或 `.exr` 文件；{{ui:旋转}}可使其绕模型转动，{{ui:图片亮度}}则用于调亮或调暗。该图片本身包含太阳，因此不会再添加模型的太阳。该图片仅在页面打开期间保留：重新打开后，需要再次选择。

{{ui:灯}}列表中的每盏灯都可以使用制造商的灯光配置文件：{{ui:IES 配光文件…}}会读取 IES（LM-63）文件，灯具随后会按该灯具的方式投射光线（例如窄光束射灯、墙面洗墙灯）。所有同名灯具都会使用它，并且每盏灯仍保留自己的亮度。点击配置文件的名称即可停止使用。

透明玻璃窗有助于天空的光线进入房间，因此在天空下的室内图片会更快成形。

{{ui:快速}}模式和 WebGL 路径追踪器会将{{ui:物理天空}}和{{ui:天空图片（HDRI）}}显示为晴空，并忽略灯光配置文件。

## 摄像机

{{ui:相机}}会像摄影一样设置图片：

- {{ui:曝光}}：保持{{ui:亮度滑块}}不变，或选择{{ui:相机设置}}，像使用相机一样设置{{ui:光圈（f 值）}}、{{ui:快门速度}}和{{ui:ISO}}；旁边的 EV 即为常用的曝光值。f/16、1/100 秒、ISO 100 相当于晴天；较暗的场景需要更大的光圈、更慢的快门或更高的 ISO。此功能在所有模式下都可用。
- {{ui:景深}}会模糊比{{ui:对焦距离（m）}}更近或更远的部分，效果与使用该 f 值镜头相同（留空则对焦于视图中央的物体）；{{ui:光圈形状}}会让焦外高光呈圆形或多叶片形状。
- {{ui:两点透视（竖直线保持竖直）}}会像建筑移轴镜头一样校平摄像机并平移画面，因此在仰视或俯视建筑时，墙面不会倾斜。
- {{ui:白平衡}}设置哪种光色被视为白色：较低的值（例如 3000 K）用于偏暖的灯光，较高的值用于阴影和阴天。
- {{ui:投影}}：{{ui:360° 全景}}会为全景查看器生成一张 2:1 的图片，包含摄像机周围的所有内容；{{ui:360° 立体全景}}会上下堆叠左眼和右眼全景，用于头显；{{ui:立方体贴图（6 面）}}会以 3 × 2 网格生成六张正方形视图。宽度来自{{ui:尺寸}}。

投影、景深、两点透视和白平衡需要显卡上的路径追踪器（WebGPU），因此它们仅在{{ui:高质量}}中显示。

## 完成图片

{{ui:图片}}会像照片一样为高质量图片调色，每个控件都会立即改变最终图片，无需重新渲染：

- {{ui:观感（视图变换）}}：{{ui:ACES 电影感}}（与之前相同）、{{ui:AgX}}（更柔和，在极亮的光线下保留颜色）、{{ui:电影感}}（温和的胶片曲线）或{{ui:标准}}（平直，过亮的光线会被剪切为白色）。
- {{ui:对比度}}和{{ui:高光压缩}}（找回非常明亮部分的细节）。
- {{ui:泛光}}（亮光周围的柔和光晕）、{{ui:眩光}}及其{{ui:眩光条纹}}（从最亮点发出的星形光线）和{{ui:暗角}}（更暗的角落）。
- {{ui:颜色表（.cube）…}}会从 `.cube` 文件应用颜色分级，并可调整{{ui:颜色表强度}}；与天空图片一样，它仅在页面打开期间保留。

## 保存图片

{{ui:另存为}}位于{{ui:保存}}旁边，用于选择文件格式：{{ui:PNG}}、{{ui:JPEG}}或{{ui:WebP}}适用于分享（JPEG 和 WebP 仅在浏览器能够写入时可用）。在显卡上完成高质量渲染后，还可以选择：

- {{ui:PNG，16 位}}：经过调色的图片，明暗之间的过渡更细腻，适用于打印或进一步编辑。
- {{ui:EXR，所有图层（32 位浮点）}}：按渲染时的原样（线性光，无调色）保存图片，每个渲染元素和灯光组各为一个图层，适用于合成软件。
- {{ui:渲染文件（.ccrender，之后可重新调色）}}：包含对话框重新混合和调色所需的全部内容。{{ui:打开渲染文件…}}可将其恢复，并保留其混合和调色设置，无需重新渲染。

## 渲染后混合灯光

在按下{{ui:渲染}}之前，请开启{{ui:光线混合（渲染后可更改每盏灯的颜色和亮度）}}。图片完成（或停止）后，{{ui:混合图像}}会按组列出其中的灯光：天空、太阳，以及按名称划分的灯具（同名的每盏灯属于同一组）。关闭某个组、为其设置颜色，或调亮或调暗，图片会立即改变，无需重新渲染。{{ui:保存混合}}会以名称保存混合设置，便于以后再次选择；{{ui:按渲染结果}}则恢复为生成时的图片。{{ui:保存}}会保存混合后的图片。

{{ui:渲染元素（反照率、法线、深度、漫反射、镜面反射、透射、自发光、ID）}}同样会保留图片的各个部分。{{ui:显示}}会将视图切换为其中之一：表面颜色（反照率）、法线、深度、漫反射、镜面反射和透射光（各自的直接光和间接光）、发光部分和天空，以及为制作蒙版而按对象或按材料分配的颜色。

这两项功能都会在显卡上保留额外的图层。在较大尺寸下，显卡的显存可能不足；对话框会给出提示，此时使用较小尺寸即可。

## 渲染队列

完成高质量设置后，{{ui:渲染队列}}下的{{ui:将此图像加入队列}}会按当前设置保留该图片；视频对话框中的{{ui:将此动画加入队列}}则对整个动画执行同样的操作，即逐帧路径追踪。{{ui:开始队列}}会在这台电脑上依次渲染它们，每张完成的图片旁的{{ui:保存}}会将其下载。关闭页面时队列会保留：重新打开同一模型，它会从停止的地方继续。队列需要 WebGPU。

## 雾、烟、噪点和焦散

这些功能位于{{ui:雾、烟和噪点}}中，在显卡上的{{ui:高质量}}模式下可用；其他引擎不包含这些功能。

- {{ui:雾和霾}}会在一定高度内用雾气填充空气，雾气会被太阳、天空和灯具照亮。{{ui:可见距离（米）}}设置雾的浓度（约 100 m 为轻霾，20 m 为浓雾），{{ui:雾的高度（离地面，米）}}设置雾的顶部位置，{{ui:光束}}设置雾气向光源方向发亮的程度。阳光会从雾的顶部穿出，因此阳光透过窗户或建筑之间时，你会看到光束。
- {{ui:烟或云}}会添加一个由灯光照亮的烟或云体积。{{ui:类型}}可选择{{ui:云线}}、{{ui:烟柱}}或{{ui:来自体积文件（.ccvol）}}，后者是 CadCraft 自有的网格格式。{{ui:细节}}和{{ui:变化}}会改变已生成的云或烟柱；{{ui:最长边的尺寸（米，0 = 模型的尺寸）}}、{{ui:X 方向移动（m）}}、{{ui:Y 方向移动（m）}}、{{ui:Z 方向移动（m）}}以及{{ui:旋转}}用于放置它（初始位于模型中央）；{{ui:厚度}}使其更浓，{{ui:前向发光}}使其更多地朝向光源发亮，{{ui:颜色}}为其着色。体积文件与天空图片一样，仅在页面打开期间保留。
- {{ui:在画面已干净的地方提前停止（自适应采样）}}不再为已稳定的像素提供采样，因此画面的其余部分会更快完成。{{ui:可接受的噪点}}表示像素停止时仍残留的颗粒程度。图片下方的提示行会显示像素平均获得的采样数。
- {{ui:焦散（光线经玻璃折射或经镜面反射）}}会追踪来自灯具和太阳的光线，因此玻璃球下的亮斑或镜子在墙上反射的光斑会清晰呈现，而不是带有颗粒感。当雾、烟、{{ui:渲染后混合灯光}}或渲染元素开启时，焦散会关闭；它专为图片设计，不适用于 360° 图片、动画或渲染工作区。

## 需要多长时间

图片在你自己的电脑上由显卡生成；不会上传任何内容。耗时取决于显卡。时间会随遍数和像素数增加：{{ui:最佳}}的遍数是{{ui:草稿}}的 16 倍，4K 图片的像素数约为全高清的四倍。没有显卡的电脑仍然可以渲染，只是速度较慢。

:::note
如果对话框提示浏览器无法渲染图片，说明浏览器不支持 WebGL 2。请更新浏览器，或在其设置中开启硬件加速。
:::
