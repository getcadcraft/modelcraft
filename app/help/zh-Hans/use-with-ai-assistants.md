## 你将学到什么

如何让AI助手（或你编写的脚本）与ModelCraft协作，以及如何决定它可以操作哪些内容。

ModelCraft**本身不含AI**，也不会向任何地方发送内容。助手需要你自行提供：任何支持模型上下文协议（MCP）的程序均可。ModelCraft只为它提供工具，由你选择开放哪些工具。

## 开启

1. 打开{{ui:设置}}（应用栏中的齿轮图标，或{{key:Mod+,}}），进入{{ui:ModelCraft}}选项卡。
2. 在{{ui:助手}}下勾选**允许AI助手和脚本使用ModelCraft**。未勾选时此功能关闭。
3. 选择它可以执行的操作：**读取**默认已勾选；只有在需要时才勾选**编辑**、**保存**或**导出**。

未勾选权限对应的工具不会提供给助手；即使助手仍然请求这些工具，ModelCraft也会拒绝，并将该请求记入活动日志。关闭此开关会立即断开所有连接；{{ui:重置ModelCraft设置}}也会将其关闭。

## 连接助手

助手通过你电脑上的**CadCraft Studio**连接：Studio会运行一个仅本机可以访问的小型服务器，并通过每次启动时生成的令牌进行保护。在Studio中选择{{ui:连接助手}}，然后将地址和令牌复制到你的助手中（Studio会显示需要粘贴的具体设置）。切勿泄露令牌。

:::note
浏览器标签页无法为助手建立连接：在浏览器版应用中，该开关在你使用电脑上的CadCraft Studio之前不会生效。
:::

## 由你掌控

- **每次更改都是一个撤销步骤**，并以助手的名称命名（例如"助手：box"）。{{key:Mod+Z}}会一次性撤销助手的最后一次更改。
- **你总能知道是否已连接。** 连接期间，应用栏中的按钮会显示助手名称；点击它可查看其权限，或**断开连接**。
- **活动。** {{ui:设置}} › {{ui:ModelCraft}} › {{ui:助手}} › {{ui:活动}} 列出每一次调用：时间、调用的工具，以及是否已完成或被拒绝。{{ui:保存日志}}会保存一份副本。

## 助手可请求的内容

| 工具 | 权限 | 功能 |
|---|---|---|
| `app_info`, `model_describe` | 读取 | 模型的单位、尺寸，以及每个组和组件的位置、是否为封闭实体及其体积 |
| `view_screenshot` | 读取 | 三维视图当前显示的画面 |
| `box_add`, `cylinder_add` | 编辑 | 新建一个长方体或圆柱体组，位置和尺寸由你或助手给出（可用"3m"、"10'"或模型单位下的数字） |
| `instance_move`, `instances_erase` | 编辑 | 移动或删除组和组件 |
| `faces_list`, `materials_list` | 读取 | 组或散乱几何体的面（每个面的方向、面积和中心）；可用于上色的材质和颜色 |
| `push_pull` | 编辑 | 像{{ui:推/拉}}那样推或拉一个面 |
| `paint` | 编辑 | 用颜色或材质为面或整个组上色 |
| `group_make` | 编辑 | 将散乱的面和组创建为一个组或组件 |
| `scene_add`, `scene_show` | 编辑 | 将视图保存为场景；切换到已保存的场景 |
| `mesh_add` | 编辑 | 添加一个网格对象作为起点（立方体、球体、圆柱体等），与网格工作空间的添加方式相同 |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | 读取 / 编辑 | 网格的修改器堆栈：镜像、阵列、细分、倒角等；不会永久应用任何修改器 |
| `usd_export` | 导出 | 将模型导出为OpenUSD（.usda、.usdc或.usdz），与将模型保存为USD的方式相同（[USD](topic:usd)）；导出到你在Studio中允许的文件夹，否则为下载 |
| `render_still` | 导出 | 渲染视图或已保存场景的图片，与{{ui:渲染}}对话框中{{ui:渲染}}按钮的效果相同，使用你的渲染设置，除非它请求其他设置（场景预设：外部、内部、剖面、夜景或自动；快速或高质量、尺寸、采样数、天空）；输出为助手可查看的PNG，或保存到你在Studio中允许的文件夹中的PNG、EXR或渲染文件（[渲染图片](topic:render)） |
| `render_queue` | 导出 | 将高质量图片添加到{{ui:渲染}}对话框的队列中（当前视图或已保存场景）并运行队列；完成的图片会保存到你允许的文件夹，或保留在{{ui:渲染}}对话框的{{ui:渲染队列}}中。需要WebGPU |
| `link_push` | 编辑 | 更新从其他程序链接的模型（参见[保持.3dm模型实时更新](topic:live-3dm-link)） |
| `link_status` | 读取 | 说明链接的模型是否仍然存在，以及上次更新时间 |
| `undo` | 编辑 | 撤销其自身的步骤 |

助手创建的实体以组的形式出现，因此不会与你绘制的内容合并。没有任何工具可以保存模型：保存仍由你操作；导出或渲染则需要勾选**导出**。渲染不会改变模型；渲染已保存的场景会将视图切换到该场景，与{{ui:场景}}的效果相同。

## 如果出现问题

- **助手看不到ModelCraft工具：** 检查此窗口中的开关是否已打开，以及该窗口是否已在Studio中打开。
- **"needs the edit permission"（需要编辑权限）：** 在{{ui:助手}}下勾选**编辑**，然后再次请求。
- **"401"或"token"错误：** 令牌已更改（Studio已重启，或点击了{{ui:新令牌}}）。请将新令牌复制到助手的设置中。
