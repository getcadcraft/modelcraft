**网格**工作空间逐点编辑[网格](topic:meshes)：其顶点、边和面。推/拉几何体保留在**模型**工作空间中。

## 打开方式

- 在工具栏左侧的{{ui:Workspace}}列表中选择{{ui:Mesh}}。所选网格会打开以进行编辑；若所选为群组或组件，则会先将其转换为网格（一步撤销）。
- 或双击网格，或在建模器按键下选择网格后按{{key:Tab}}。
- 未选择任何对象时，面板会提供可添加的网格：平面、格网、立方体、圆、圆柱体、圆锥体、球体、二十面体球体和环面。新网格会放置在视图所朝的位置，并打开以进行编辑。

{{ui:Back to Model}}（或在列表中选择，建模器按键下按{{key:Tab}}，推拉按键下在未选择任何对象时按{{key:Esc}}）可返回模型，并保持所选网格处于选中状态。打开网格工作空间时，模型的其余部分会变淡，模型的绘图工具会被收起。

## 选择

| 操作 | 作用 |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | 选择顶点、边或面 |
| 单击 | 选择一个；{{key:Shift}}加单击可添加或移除 |
| 框选 | 选择框内且可见的对象；{{key:Shift}}添加，{{key:Ctrl}}移除 |
| {{key:Alt}}加单击边，或双击边 | 其边循环（面模式下为面循环；位于开放边上时为整个边界） |
| {{key:Ctrl}}+{{key:Alt}}加单击边 | 其边环 |
| 三击 | 与其相连的全部内容 |

{{ui:Select}}组还包含{{ui:All}}、{{ui:Linked}}、{{ui:Loop}}、{{ui:Ring}}、{{ui:More}}和{{ui:Less}}。

## 移动、旋转、缩放

{{ui:Move}}、{{ui:Rotate}}和{{ui:Scale}}从指针位置开始：移动指针，然后点击或按{{key:Enter}}放下所选内容，或按{{key:Esc}}取消。{{key:X}}、{{key:Y}}或{{key:Z}}（或方向键）可锁定一个轴。输入距离、角度或比例可获得精确结果，[计算](topic:value-box#calculations)同样适用。

**比例编辑**（{{ui:Proportional}}，或面板中的选项）：靠近所选内容的顶点会随移动而跟随，距离越远跟随越少，直至你设定的范围，衰减方式由你选择。开启{{ui:仅沿网格}}可沿边测量距离，而非直线测量。

{{ui:Slide}}可沿相邻边移动所选边循环。

## 修改形状

| 工具 | 作用 |
|---|---|
| {{ui:Extrude}} | 沿法线方向拉出所选面，并生成新的侧面（或由开放的边界边生成面）。输入距离 |
| {{ui:Inset}} | 在所选面轮廓内形成一圈带状区域；再次按{{key:I}}可分别处理每个面 |
| {{ui:Bevel}} | 以指定宽度切割所选边（或按{{key:Ctrl}}+{{key:Shift}}+{{key:B}}切割顶点）；滚轮或加减键可增加分段，以形成圆角边 |
| {{ui:Loop cut}} | 指向一条边：在四边形面环上生成新的循环；滚轮设置数量；点击即可切割 |
| {{ui:Knife}} | 在边或角上点击多个点；按{{key:Enter}}可沿这些点之间的面直线切割（按视图所见） |
| {{ui:Bisect}} | 在屏幕上绘制一条线：所选面（或全部面）将沿该线切割 |
| {{ui:Spin}} | 沿蓝色轴分步旋转所选面或开放边（滚轮设置步数）；旋转一整圈后会闭合 |
| {{ui:Subdivide}} | 将所选边一分为二；整个面会变为格网 |
| {{ui:Merge}} | 所选顶点合并为一个，位于其中心 |
| {{ui:Dissolve}} | 移除所选内容但保留表面：面会相连 |
| {{ui:Fill}} | 在所选开放边界上（或两条开放边之间）生成一个面 |
| {{ui:Grid fill}} | 用四边形格网填充边数为偶数的开放边界 |
| {{ui:Bridge}} | 用面连接两个所选的开放边循环 |
| {{ui:Crease}} | 网格经细分曲面平滑后，所选边保持锐利的程度：远离中心移动、使用滚轮（步长为 0.1）或输入 0至1 的值。面板会显示所选边的折痕值，也可输入数值。折痕边以洋红色绘制 |
| {{ui:Flip}}、{{ui:Smooth}}、{{ui:Delete}} | 翻转面；使顶点向相邻顶点平滑；按选择模式删除 |

每项操作均为一步撤销。纹理坐标、颜色和权重会延续到新面和新顶点上。

## 重新网格化

{{ui:Remesh}}会以一种尺寸的均匀三角形重新生成整个网格，尺寸在按下时设定（越小越精细，但速度越慢）。它会闭合孔洞，连接相互重叠的部分，并均匀化因雕刻而拉伸的网格。锐利的边会变得略微圆滑。UV、绘制和折痕会重新开始。一步撤销。

## 重拓扑

要在精细网格（例如雕刻或扫描模型）上构建新的、更简洁的网格，请在面板中的{{ui:Retopology}} › **构建于**下选择精细网格，然后：

- **将移动的点贴合到其上：**被移动的点和被挤出的边会落在其表面上。
- **将所选点放到其上**会立即将所选点移动到其表面上（一步撤销）。
- **将此网格的边显示在前面**会在表面上方绘制正在构建的网格，以便查看。

## 调整上一次操作

执行{{ui:Inset}}、{{ui:Bevel}}、{{ui:Loop cut}}、{{ui:Subdivide}}、{{ui:Smooth}}、{{ui:Grid fill}}或{{ui:Spin}}后，面板会显示其设置（宽度、分段、轮廓、切割数……）。更改任一设置后，操作会从起点重新执行，仍为一步撤销。
