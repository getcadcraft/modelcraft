ModelCraft读写计算机上的文件。不会上传任何内容：打开的文件在浏览器内读取，保存的文件则作为下载提供。参见[文件的存放位置](common:your-files)。

## 格式概览

| 格式 | 打开 | 导入 | 导出 | 用途 |
|---|---|---|---|---|
| ModelCraft（`.modelcraft`） | 是 | 否 | {{ui:保存}} | 工作文件，保留所有内容。 |
| USD（`.usd`、`.usda`、`.usdc`、`.usdz`） | 是 | 是 | {{ui:另存为}}、{{ui:导出}} | 渲染和场景组装程序。ModelCraft自身的USD保留所有内容。参见[保存、打开和导出USD](topic:usd)。 |
| SketchUp（`.skp`） | 否 | 是 | 否 | 导入SketchUp中的模型。保留组、组件、颜色、面上的纹理、标记和柔化边。参见[导入SKP模型](topic:import-sketchup-files)。 |
| Collada（`.dae`） | 否 | 是 | 是 | 与其他三维建模软件交换模型。保留组、组件和颜色。 |
| OBJ（`.obj`） | 否 | 是 | 是 | 渲染和可视化程序。 |
| glTF（`.glb`、`.gltf`） | 否 | 是 | 仅`.glb` | 网页查看器、游戏引擎、AR。 |
| STL（`.stl`） | 否 | 是 | 是 | 三维打印（单位为毫米）。 |
| PLY（`.ply`） | 否 | 是 | 是 | 带颜色的网格：扫描数据、彩色打印。 |
| FBX（`.fbx`） | 否 | 是 | 否 | 动画和游戏程序中的模型（FBX 2011及更新版本）。 |
| Alembic（`.abc`） | 否 | 是 | 否 | 几何缓存，取第一个采样。 |
| STEP（`.step`、`.stp`） | 否 | 是 | 否 | 来自零件建模软件和供应商的零件，以闭合网格的形式按真实尺寸导入。参见[文件格式](topic:formats)。 |
| `.3dm` | 否 | 是 | 否 | NURBS模型：多重曲面、网格、曲线、块和图层，以网格、棱边、组件和标记的形式导入。参见[导入.3dm模型](topic:import-3dm-files)。 |
| 3MF（`.3mf`） | 否 | 否 | 是 | 三维打印，带颜色（单位为毫米）。来自{{ui:检查是否适合三维打印（STL或3MF）…}}：参见[准备用于三维打印的模型](topic:print-3d)。 |
| IFC（`.ifc`） | 否 | 否 | 是 | BIM程序和BimCraft。 |
| DWG（`.dwg`） | 否 | 是 | 是 | 用作建模底图的总平面图或平面图；将模型发送到CAD程序。 |

[文件格式详情](topic:formats)准确列出每种格式保留和不保留的内容。

## ModelCraft文件

`.modelcraft`文件保存整个模型：几何体、组、组件、辅助线、场景、单位，以及保存时使用的相机和样式。它不保存撤销历史。

### 打开模型

1. 在{{ui:文件}}组中点击{{ui:打开}}，或按{{key:Mod+O}}。
2. 若屏幕上的模型有未保存的更改，ModelCraft会询问：“此模型有未保存的更改。是否先保存副本？”请选择{{ui:保存副本}}、{{ui:放弃更改}}或{{ui:取消}}。
3. 选择`.modelcraft`文件。

模型以保存时的单位打开，并使用保存时的相机视角。也可以将`.modelcraft`文件拖放到三维视图上，或在起始卡片的最近文件列表中点击一个文件（适用于能够重新打开文件的浏览器，以及桌面应用）。

:::desktop
在桌面应用中，双击`.modelcraft`文件即可在ModelCraft中打开它；对Collada、OBJ、glTF、DWG或DXF文件使用**打开方式**同样可以打开（文件会被导入到新模型中）。
:::

### 保存模型

点击{{ui:保存}}或按{{key:Mod+S}}。浏览器会下载`<name>.modelcraft`，其中名称为所打开的文件名；新模型则为“未命名”。

:::desktop
在桌面应用中，{{ui:保存}}会原位写入所打开的文件。新模型则会询问保存位置。
:::

- {{ui:另存为}}（{{key:Mod+Shift+S}}）将副本保存为`.modelcraft`文件或[USD](topic:usd)；浏览器支持时，会询问名称和位置。否则请重命名已下载的文件：打开重命名后的文件后，下一次保存将使用新名称。
- 每次保存都会产生一次新的下载。根据浏览器的设置，文件会直接保存到下载文件夹，或询问保存位置。若该名称的文件已存在，大多数浏览器会添加编号，例如`Untitled (1).modelcraft`。

:::chromium
若要每次都选择文件夹，请打开浏览器设置，搜索“下载”，然后开启“下载前询问每个文件的保存位置”。
:::

:::firefox
若要每次都选择文件夹，请打开**设置**，然后打开**常规**，在“下载”下选择“始终询问保存文件的位置”。
:::

:::safari
若要更改下载位置，请打开**Safari**，然后打开**设置**，再打开**通用**，并设置“文件下载位置”。
:::

### 新建模型

点击{{ui:新建}}。若有未保存的更改，ModelCraft会先询问。新模型从空白开始，使用当前区域设置的单位（美国为英尺和英寸，其他地区为毫米），且没有场景。

### 保存前浏览器关闭的情况

ModelCraft会在每次更改后几秒钟，在浏览器中保留一份未保存内容的副本。该副本在后台写入，因此即使是大型模型，保存副本时也不会造成卡顿。若在保存前关闭了标签页或浏览器，下次打开ModelCraft时，它会询问“恢复未保存的内容？”。恢复后将打开未保存为文件时的模型状态：保存即可将其留存。参见[恢复未保存的内容](common:recover)。

### 从CadCraft中：在ModelCraft中打开

在CadCraft制图应用中，依次点击**视图**、**{{ui:更多}}**、**在ModelCraft中打开**，即可在新标签页中将当前图形以DWG格式交给ModelCraft。其导入方式与导入DWG相同：地面上的线条位于一个组中，可直接在其上建模。不会上传任何内容；文件仅经过浏览器自身的存储。

## 导入

导入会将文件添加到当前打开的模型中，而不会替换该模型。

1. 在{{ui:文件}}组中点击{{ui:导入}}，或将文件拖放到三维视图上。
2. 选择SketchUp、Collada、OBJ、glTF、FBX、PLY、STL、Alembic、STEP、`.3dm`、USD、DWG或DXF文件。

   文件以**一个组**的形式导入，并处于选中状态，视图会缩放以显示该文件。状态栏会显示已导入的内容，并列出无法导入的项目，例如“未导入：2个纹理”。

3. 若要直接编辑其几何体，双击该组进入组内编辑，或点击{{ui:分解}}。

注意事项：

- **尺寸与朝上方向：**Collada文件会说明其单位以及哪个轴朝上，ModelCraft会对其进行转换。glTF始终以米为单位。OBJ文件不包含单位：ModelCraft将其按米读取，且Y轴朝上。若OBJ导入后大1000倍或小1000倍，请使用[缩放](topic:rotate-scale)，系数如`0.001`或`1000`。
- **DWG和DXF**以地面上的线条（棱边）形式导入，而不是面。若图形未说明其单位，标题为“图形单位”的对话框会询问一个图形单位等于多少。参见[在总平面图上建模](topic:site-plan)。
- **限制：**超过300 MB的文件无法导入，超过200 MB的文件无法打开。顶点或面超过200万个的文件因过大而被拒绝。超过64 MB的OBJ会在读取前被拒绝。文本文件（Collada、OBJ、ASCII STL、USD文本）每次读取一段，约4 MB，因此没有任何一段文本包含整个文件；在我们的测试中，一个16 MB的OBJ在打开时约占用0.5 GB内存。

## 导出

1. 在{{ui:文件}}组中点击{{ui:导出}}。
2. 选择格式：{{ui:glTF二进制（.glb）}}、{{ui:Collada（.dae）}}、{{ui:OBJ（.obj）}}、{{ui:用于打印的STL（.stl，毫米）}}、{{ui:带颜色的PLY（.ply）}}、{{ui:USD（.usda、.usdc、.usdz）…}}、{{ui:供BimCraft使用的IFC（.ifc）}}、{{ui:供CAD使用的DWG（.dwg，2004）}}或{{ui:供CAD使用的DXF（.dxf，R12）}}。

浏览器会下载该文件，文件名与模型名相同。导出的是整个模型，而非仅所选部分。glTF、Collada和OBJ文件在后台写入，因此导出大型模型时ModelCraft仍可继续工作；文件准备好后下载才会开始。空模型无法导出：“模型为空：请先绘制内容。”参见[为其他程序导出模型](topic:export-model)。

## 在线与离线

ModelCraft中的所有功能都在计算机上运行，因此应用加载完成后，建模、打开、保存、导入和导出均可在无网络连接时使用。

若要在完全没有网络连接的情况下打开ModelCraft，请在联网时将其保存以供离线使用：

1. 点击顶部应用栏中的{{ui:保存以供离线使用}}。
2. 保存时，按钮会显示进度（“正在保存40/212”）。ModelCraft会保存其自身的文件（包括其DWG读取器）、本帮助文档以及三维库，因此可能需要一些时间。
3. 当按钮显示{{ui:离线可用}}时，ModelCraft即可在无网络连接的情况下从同一地址打开，并且DWG导入也可离线使用。

之后点击{{ui:离线可用}}，可选择{{ui:重新保存（获取最新版本）}}或{{ui:移除离线副本}}。若按钮显示{{ui:无法保存}}，说明部分文件未能下载：请检查网络连接，然后点击它重试。{{ui:无法离线使用}}表示此浏览器窗口无法保存副本（隐私窗口和部分受管理的计算机）。参见[离线使用](common:offline)。

云存储尚不可用。每个模型都保存在保存时指定的位置。

:::offline
当前处于离线状态，仍可继续建模和保存。除非应用栏显示{{ui:离线可用}}，否则请在恢复联网后再刷新此标签页。
:::

## 桌面应用

:::desktop
正在CadCraft Studio（包含全部八个应用的桌面应用）中使用ModelCraft。文件在所选位置打开和保存。
:::

:::web
ModelCraft可在Mac、Windows和Linux的浏览器中运行，也可在CadCraft Studio中运行。CadCraft Studio是包含全部八个应用的桌面应用，安装一次即可获得全部应用，下载地址为getcadcraft.com/download。
:::
