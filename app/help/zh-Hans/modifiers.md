**修改器**会改变网格的显示效果，而不会改变网格本身。例如，将零件的一半镜像，然后只建模那一半；用细分曲面将方块变圆，同时仍可继续编辑该方块。修改器位于**堆栈**中，按从上到下的顺序依次作用。所看到、导出、打印和渲染的内容，是网格加上所有已开启的修改器后的结果。

## 添加修改器

1. 选择一个网格。在模型工作空间中，其**修改器**部分位于{{ui:Entity info}}中；在网格工作空间中，则位于右侧面板中。
2. 从{{ui:Add a modifier…}}中选择一个修改器。它会被添加到堆栈底部。
3. 在其名称下方更改设置。长度与数值框使用相同的值，因此 `600mm`、`2'6"` 和 `(6m)/4` 均可使用。

每次更改都是一步撤销：{{key:Mod+Z}}可撤销该更改。

## 每个修改器上的按钮

- 复选框用于开启或关闭该修改器。
- 屏幕按钮用于在视图中显示或隐藏它（它仍保留在堆栈中）。
- 相机按钮用于在渲染图片和视频中显示或隐藏它，因此修改器可仅用于渲染（或仅用于视图）。
- 箭头用于将其在堆栈中上移或下移。顺序很重要：先镜像再细分，接缝会平滑；先细分再镜像，则不会。
- {{ui:Apply}}会将形状并入网格：其上方的修改器及该修改器本身会作用于网格本身，并从堆栈中移除。这是一步撤销。
- 叉号用于移除它。

## 修改器列表

| 修改器 | 作用 |
| --- | --- |
| 缩放 | 以对象原点为中心缩放，红、绿、蓝三个方向可分别设置倍数。同样适用于群组或组件。 |
| 镜像 | 沿红、绿或蓝轴穿过网格原点添加镜像副本，并在两半相接处连接。 |
| 阵列 | 沿直线（步长为其自身尺寸乘以所输入数值，再加上固定步长）、绕轴或沿模型中的曲线复制。群组或组件只能使用直线阵列。 |
| 细分曲面 | 通过 Catmull-Clark 细分使网格平滑。锐利的边保持折痕。渲染可使用比视图更多的细分级别。 |
| 倒角 | 将所有比所给角度更尖锐的边变为圆角。 |
| 加厚 | 为曲面赋予厚度并封闭边缘。 |
| 布尔 | 与模型中的另一对象进行切除、合并或保留重叠部分。两者均需为闭合实体。 |
| 置换 | 通过平滑噪声使表面向内或向外移动。相同的种子每次都会产生相同的凸起。 |
| 焊接 | 将距离小于指定值的顶点连接起来。 |
| 抽取 | 保留一部分三角面，并移除对形状影响最小的三角面。 |
| 平滑 | 使顶点向相邻顶点松弛。 |
| 晶格 | 使用笼来弯曲网格：移动笼的点，网格会随之变化。 |
| 曲线变形 | 沿模型中的曲线弯曲网格，可沿红、绿或蓝轴方向。 |
| 收缩包裹 | 将每个顶点移动到另一对象上最近的点。 |

## 群组或组件上的修改器

群组或组件同样可以保存一套“配方”，因此灯罩可以是一个**缩放**加上该灯罩的一个**阵列**，修改其中一个数值即可改变整盏灯。

1. 选择一个群组或组件。在{{ui:Entity info}}中，其**修改器**部分会列出堆栈（初始为空）。
2. 从{{ui:Add a modifier…}}中选择{{ui:Scale}}或{{ui:Array}}。该群组会变为一个组件，即**由堆栈放置的原件**。原件会被保留：编辑它时，所有副本会立即随之变化。
3. 缩放需要分别输入红、绿、蓝三个方向的倍数（`1, 1, 2`会使高度加倍）。阵列需要输入副本数量、以当前结果尺寸的占比表示的步长，以及以长度表示的额外步长。

堆栈从上到下依次作用于原件自身的坐标轴，并以其原点为中心，因此顺序很重要：若先将 3 个副本以 3 m 间距阵列，再对红色方向使用缩放 2，则副本间距变为 6 m；若先缩放再阵列，则副本间距保持为 3 m。复选框、箭头和叉号的作用与网格相同；而单个修改器上的视图和相机按钮以及应用功能不适用，因为群组上的堆栈是一个整体。

- {{ui:Edit source}}会就地打开原件。修改会显示在所有副本中；关闭后将返回原来的位置。
- {{ui:Bake modifiers}}会将结果转为普通的边和面，并移除堆栈，为一步撤销。相互重叠的副本仍保持为独立的几何体：烘焙不是并集运算。
- 组件的副本共享同一配方；{{ui:Make unique}}会将其分离（原件仍保持共享）。
- 堆栈会保存在文件中，并随复制、粘贴和撤销一同传递；清除未使用项会保留原件。不支持修改器的程序仍会显示副本。
- 在烘焙之前，结果无法进入编辑、分解、调整尺寸或拉伸：下次修改时它将被重新构建。每个操作都会对此作出提示。
- 限制为 32 个修改器和 1,000 个副本。用于拉伸的组件（Stretch）与堆栈暂时无法共享同一定义。

## 细分曲面

细分会通过 Catmull-Clark 方法使网格平滑：每个面都会变为四边形面，每增加一级，面数就增加为四倍。一个方块经过两到三级细分后，即可看起来已是圆润的形状，而你仍可继续编辑该方块。

- **视图中的级别**用于设置平滑程度。
- **渲染中的级别**用于设置渲染图片和视频的平滑程度；渲染可使用比视图更多的级别。
- **在真实平滑曲面上渲染**会将渲染网格的点放置到各级别所趋向的极限曲面上，因此即使只有两级，渲染效果也与更多级别一样平滑。
- **折痕**使边保持锐利：在网格工作空间中选择边，然后使用{{ui:Crease}}（1 保持锐利，0.5 略微圆滑，0 为平滑）。请参阅[编辑网格](topic:mesh-edit)。
- **在大型网格上降低视图级别：**当所请求的级别会产生超出本机视图能良好处理的面数时，视图会显示较低的级别，并说明具体级别。{{ui:Apply}}始终使用所有级别。可绘制的面数由{{ui:Settings}} › 渲染 › 你的计算机中所设定的计算机等级决定。
- 开放边界会保留其角点，并保持在其边所在的直线上。

## 用晶格笼弯曲

1. 添加{{ui:Lattice}}修改器，然后按{{ui:Add a lattice cage round the mesh}}。网格周围会出现一个由 3 × 3 × 3 个点组成的笼，以线框形式绘制。
2. 在网格工作空间中打开笼（双击它），并移动其点。网格会平滑地随之变化。

:::tip
笼与其他网格一样，是一个网格：完成后可使用其标记将其隐藏。
:::

## 大型网格

小型堆栈会立即计算完成。大型堆栈会在计算机的每个核心上于后台计算：在新结果准备好之前，视图会继续显示上一次的结果。布尔运算首次使用时会加载实体建模器；视图会为此短暂提示。

## 修改器尚未支持的功能

- 置换、平滑和收缩包裹所使用的逐顶点权重（即在网格上绘制的衰减）。
- 对于推/拉几何体（群组和组件），除缩放和直线阵列外的修改器：请先将其转换为网格（{{ui:Convert to mesh}}）。群组上的镜像、环形或曲线阵列、弯曲和锥化功能将在以后提供。
