在 **着色** 工作区中创建的材质属于该文件。它是一个小型图：由生成纹理、图像和数值的**节点**组成，并连接到**材质输出**，其输入决定表面的外观：基础颜色、粗糙度、金属度、法线、不透明度、自发光，以及 OpenPBR 模型的其余属性。你可以像使用任何库材质一样用它绘制面，每次更改都会立即在视图中显示。

## 打开它

在工作区列表中选择 {{ui:着色}}。3D 视图保留屏幕顶部，**节点编辑器**占据底部。右侧面板列出该文件自有的材质。

- {{ui:新建材质}} 创建一个只含材质输出的灰色材质。
- **将库材质转为可编辑副本**：可将砖、木材、瓷砖等材质转换为可修改的图；其纹理通过库纹理节点引入，其凹凸通过凹凸节点引入。
- {{ui:用它绘制}} 会绘制所选面或组，或为绘制工具选取材质。绘制工具的材质列表中，该文件自有的材质会列在 **本文件中** 之下。
- {{ui:创建副本}} 和 {{ui:删除}} 作用于你正在编辑的材质。删除无法撤销：使用它绘制的面会显示默认颜色，直到你重新绘制它们。

## 库中的材质

面板中的 **材质库（Library）** 列出库中的材质，每个都带有由 CadCraft 路径追踪器渲染的预览。它们是以 CC0 发布的纹理集，并注明了制作者。

- 单击某个材质即可将其引入文件（其图像一并引入），若已选中面或组，则直接用它绘制。
- 将其拖动到视图中的某个面或某个组上，即可仅绘制该处。
- 它会成为文件中的一个材质：可像其他材质一样修改其节点。其署名会显示在面板中，并保留在文件内。

## 导入贴图集

在 **导入贴图集** 下的 {{ui:图像或 zip…}} 或 {{ui:文件夹…}} 可根据一组贴图创建材质。贴图依据文件名中的关键词识别：颜色、albedo、diffuse 或 basecolor；粗糙度（或 gloss，转换为粗糙度）；metalness 或 metallic；法线（OpenGL 或 DirectX，依据名称中的 `gl` / `dx`）；高度或置换；环境光遮蔽；不透明度；自发光。打包贴图（ARM、ORM）会被忽略。贴图平铺的初始尺寸为 1 × 1 m：请在材质输出上设置其实际尺寸。高度贴图连接到置换，其缩放为 0——若要在网格上使用，请提高缩放值。

## MaterialX

MaterialX 是其他 3D 和渲染程序用于交换材质的开放格式。

- {{ui:导出为 MaterialX…}} 保存你正在编辑的材质：其数值，以及每个纹理（以 PNG 图像形式，与 `.mtlx` 文件放在一起，打包为 zip）。可选择其着色器格式：**OpenPBR Surface**（MaterialX 1.39，与 ModelCraft 使用的模型相同）或 **Standard Surface**（MaterialX 1.38，目前更多程序可读取）。纹理按米为单位的 UV 坐标放置；盒式映射和三平面映射会以 UV 形式写入。
- {{ui:导入 MaterialX…}}（或 {{ui:从文件夹…}}）可读取使用 OpenPBR、Standard Surface、UsdPreviewSurface 或 glTF PBR 着色器的 `.mtlx` 文件。也请同时提供图像，或提供包含全部内容的 zip：图像通过其路径、名称，或其名称加上另一种图像类型来查找（文件名为 `.exr` 的图像可以是旁边的 `.jpg`）。纹理、法线贴图、算术、混合和置换会作为节点引入；其他内容保留其数值，状态栏会说明哪些内容被省略。

## 贴花

贴花是铺在表面上的图像——如标志、标牌、标签或污渍——拥有自己的材质。

- 设置 **新贴花宽度**，然后点击 {{ui:放置贴花…}}（或工具栏上的 {{ui:贴花}}），选择 PNG、JPEG 或 WebP 图像，并点击一个面。图像会投影到该处的表面上，并保持其比例；PNG 的透明部分保持透明。
- 贴花属于你点击的组或组件，并随之移动。它覆盖其框内朝向相同的面，并止于所贴附表面的边缘。
- 每个贴花都有自己的材质，名为 **贴花：<picture>**，列在文件的列表中：可像其他材质一样编辑（粗糙度、凹凸、发光）。贴花旁的 {{ui:材质}} 会打开它。
- 每个贴花旁边有：其宽度（高度随图像比例调整）、{{ui:旋转}}（转动四分之一圈）和 {{ui:删除}}。贴花与文件的材质一同保存，且不在撤销范围内。
- 它们会显示在着色视图、快速渲染和高质量图片中。

## 在贴图上绘制

{{ui:材质}}（或 **在贴图上绘制** 下的 {{ui:材质}}）会将指针变为圆形笔刷。在带有本文件某个材质的面上拖动：笔刷会绘制其基础颜色背后的图像。

- 在网格上，它沿网格的 UV 绘制（请先在 UV 工作区中展开网格）；在其他面上，它会横跨该面绘制，因此绘制图案会随材质的平铺重复。
- 基础颜色为纯色的材质，在首次绘制时会获得一张新的 512 × 512 该颜色图像。基础颜色来自其他节点的材质，需要将图像节点连接到基础颜色。
- 在面板中设置笔刷颜色、大小（以图像像素计）、强度和硬度。{{ui:撤销笔画}} 或 Ctrl+Z（绘制时）可撤销一笔，最多可撤销最近的 20 笔。
- 绘制的图像会保存在文件中。库材质无法绘制：请先创建可编辑副本。

## 烘焙贴图

**烘焙贴图**会将形状和场景给予表面的效果，沿网格的 UV 写入图像。

- 选择一个具有 UV 的网格（请先在 UV 工作区中展开），勾选所需贴图，然后按 {{ui:烘焙}}：
  - **环境光遮蔽**——每个点的开阔程度：角落、褶皱和处于其他物体下方的位置会变暗。模型中显示的一切都会对其产生遮挡，直至遮蔽距离。
  - **曲率**——外侧边缘明亮，内侧角落暗，平坦和缓曲部分为中灰色，边缘宽度由你设定。
  - **来自高细节对象的法线**——还需选择一个细节更丰富的副本：其表面细节会写成较简单对象的法线贴图（烘焙到三角形较少的对象上）。搜索距离指两个表面之间允许的最大间距。
  - **光照**——模型所在位置和日期（样式）的太阳及其阴影，加上天空，作为光照贴图。
- 图像会加入文件，并出现在图像节点中。如果你正在编辑的材质含有 **污垢与边缘磨损** 节点，它会立即读取新的遮蔽和曲率。
- 每个纹素的光线越多，遮蔽和光照越平滑，但耗时越长。烘焙在计算机处理器核心上后台运行；{{ui:停止烘焙}} 可将其停止。

## 构建节点图

1. {{ui:添加节点…}}（或在节点编辑器中按 {{key:Shift+A}}）会在编辑器中央添加一个节点。
2. 从输出点（节点右侧）拖动到输入点（节点左侧）即可连接。同一输入再次连接会替换第一个连接；拖离已连接的输入即可断开。
3. 未连接的输入会显示其数值：输入数字或选取颜色。设置位于每个节点的底部。

拖动节点标题可移动节点，拖动空白处可平移，滚动滚轮可缩放。{{key:Delete}} 删除所选节点或连线，{{key:Mod+Z}} 撤销，{{key:Mod+D}} 复制，{{key:F}} 显示所有节点。每次更改都是节点编辑器的一步撤销。模型自身的撤销不会改变材质。

| 节点 | 生成的内容 |
|---|---|
| 纹理坐标 | 点在平铺中的位置：重复、偏移，或旋转四分之一圈。 |
| 数值、颜色 | 一个数字，一种颜色。 |
| 图像 | 文件中的图像（随导入模型而来的图像，或通过 {{ui:添加图像…}} 添加的图像）。照片选择 **颜色**，粗糙度或法线贴图选择 **数据**。 |
| 库纹理 | 库材质的纹理、粗糙度和高度。 |
| 棋盘格、噪声 | 方格；带有细节、粗糙度和种子的平滑分形噪声。 |
| 沃罗诺伊单元、波纹、渐变 | 单元（到最近点的距离、单元之间的边缘，每个单元一种颜色）；横向、纵向或对角的条纹，可为正弦、锯齿或三角形，并由噪声扭曲；线性、二次、径向和球面渐变。 |
| 砖块、瓷砖 | 带有错缝的砖行，或瓷砖网格：颜色、砂浆或填缝剂、以米计的缝隙和倒角、用于凹凸的高度，以及每块的随机数。 |
| 木材、大理石 | 沿纹理的年轮，带细纤维；由湍流扭曲的纹路。 |
| 污垢与边缘磨损 | 根据网格的曲率和遮蔽图像，磨损凸边并弄脏凹处（由[烘焙贴图](topic:shading#bake-textures)生成；或在网格的 UV 布局中设置其两个图像选项：按 UV 坐标放置材质）。若没有这些图像，它不会产生任何变化。 |
| 混合颜色、颜色渐变、色相/饱和度/明度、亮度和对比度、反相、伽马、分离和合并 RGB | 颜色处理。 |
| 数学、映射范围 | 对数值进行运算（加、乘、幂、平滑阶跃等）。 |
| 凹凸、法线贴图 | 由高度生成法线（凹凸），或由法线贴图图像生成（法线贴图：选择绿色通道的方向）。 |

## 材质输出

其设置决定纹理如何铺在表面上：

- **平铺宽度**和**平铺高度**：一个纹理平铺覆盖多少米。图生成的所有内容都会在平铺内无缝重复。
- **放置方式**：**UV 坐标**沿面铺设（推/拉的面：沿每个面；网格：使用其 UV，一个 UV 单位 = 一个平铺）；**盒式**从三个轴中最近的一个投影；**三平面**在倾斜的表面上混合三个投影（**混合锐度**：越高，混合越生硬）。
- **法线强度**用于缩放法线输入。**置换缩放**设定置换输入使网格顶点移动的距离。
- {{ui:更多输入}} 显示其余的 OpenPBR 输入：涂层、绒毛、次表面、薄膜、透射及其颜色。

## 在高质量图片中

路径追踪器会按图中的基础颜色、粗糙度、金属度、不透明度、法线和自发光在表面上的变化进行读取。你连接的其他输入（例如会变化的涂层）则采用其平均值；面板会说明哪些输入如此处理。来自不透明度贴图的镂空会显示其形状，其阴影均匀透光。发光纹理会照亮它所朝向的物体，但不会被当作灯光采样。

**置换**只移动网格的顶点，因此请添加细分修改器以获得细节（参见 [修改器](topic:modifiers)）。推/拉的面保持其形状，并从法线获得凹凸效果。

:::tip
在支持 WebGPU 的计算机上，图由显卡计算；否则由处理器计算。结果相同。
:::
