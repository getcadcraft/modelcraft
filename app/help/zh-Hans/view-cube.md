视图立方体位于三维视图的右上角。它随视图一起转动，因此始终显示你正在观察的方向：{{ui:顶}}朝上，{{ui:前}}朝南（你面向北，沿绿色轴观看），{{ui:右}}朝东（红色轴）。在你将指针指向它之前，它保持半透明。

## 从一个面、棱边或顶点观察

1. 将指针指向立方体。指针下的部分会高亮显示：面的中心、棱边（会同时高亮与之相邻的两个面）或顶点（高亮三个面）。
2. 单击它。视图会转动到从该处观察，并保持相同的中心和缩放比例。

共有26个可单击的位置：6个面（{{ui:顶}}、{{ui:底}}、{{ui:前}}、{{ui:后}}、{{ui:左}}、{{ui:右}}）、12条棱边和8个顶点。顶点会给出经典的三分之四视图；棱边则位于两个面之间。

单击{{ui:前}}与工具栏中的{{ui:视图}}、{{ui:前}}相同，但不会执行适合窗口的缩放。{{ui:视图}}仍会缩放到整个模型。

## 拖动立方体旋转

拖动立方体即可转动视图，与直接在视图中环绕旋转相同。拖动永远不会被当作单击，因此你可以在立方体的任意位置拖动。

## 指南针环

立方体下方的环标有N、E、S和W。

- **拖动环**可使模型绕竖直轴转动，如同放在转盘上。环会跟随指针移动。
- **单击一个字母**可从该侧方向观察，同时保持你向下观察的倾斜程度。在正上方的视图中，你单击的字母会转到屏幕底部。

## 正对视图：箭头

当你正对某个面观察时，立方体周围会出现小箭头：

- 四个**三角形**会将该侧的面转到正前方：立方体上方的三角形表示原先位于顶部的面，依此类推。
- 右上角的两个**弧形箭头**可将画面顺时针或逆时针旋转四分之一圈，而不改变你所观察的面。使用它们可以转动平面图，使长墙横向显示在屏幕上。

## 初始视图

立方体左上角的房子按钮会返回三分之四视角的{{ui:等轴测}}视图，并适合窗口显示整个模型。当立方体获得键盘焦点时，{{key:Home}}也能达到相同效果。

## 使用键盘

按{{key:Tab}}切换到立方体，然后：

| 按键 | 功能 |
|---|---|
| {{key:left}} / {{key:right}} | 以八分之一圈为步长，在立方体周围选择一个侧面、棱边或顶点（屏幕阅读器会读出所选项） |
| {{key:up}} / {{key:down}} | 选择更高或更低的一个，直至{{ui:顶}}或{{ui:底}} |
| {{key:Enter}}或{{key:Space}} | 从所选位置观察 |
| {{key:Shift+left}} / {{key:Shift+right}} | 绕竖直轴将视图转动四分之一圈 |
| {{key:Home}} | 初始视图 |
| {{key:Esc}} | 离开立方体 |

在立方体上按下的按键仅作用于立方体：它们不会启动ModelCraft工具。

## 坐标轴图标或不显示

打开{{ui:设置}}（{{key:Mod+,}}），进入{{ui:ModelCraft}}选项卡，将**角落指示器**设为{{ui:视图立方体}}（默认）、{{ui:坐标轴图标}}（左下角的小型X、Y、Z标记：X为红色，Y为绿色，Z为蓝色）或{{ui:无}}。此浏览器会记住该选择。参见[ModelCraft设置](topic:settings#corner-indicator)。

:::note
ModelCraft没有翻滚功能：除了正上方和正下方的视图外，屏幕上的"上"始终是模型中的上方。立方体和弧形箭头可以转动平面视图；但它们无法将侧视图翻转到边缘朝上。
:::
