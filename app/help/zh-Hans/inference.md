绘图或编辑工具工作时，ModelCraft 会查看指针下方的内容，并捕捉到附近最有用的对象。标记显示其找到的内容，左下角的提示则会将其命名。

## 标记与提示

| 提示 | 标记 | 捕捉到 |
|---|---|---|
| 端点 | 绿色圆圈 | 边的端点 |
| 中点 | 青色圆圈 | 边的中点 |
| 面中心 | 蓝色圆圈 | 指针下方面的中心 |
| 辅助点 | 灰色 | 卷尺留下的辅助点 |
| 原点 | 赭色 | 红、绿、蓝轴的交汇处 |
| 位于红轴上 / 位于绿轴上 / 位于蓝轴上 | 该颜色的线 | 从起点沿该方向引出的线 |
| 平行于边 / 垂直于边 | 洋红色线 | 从起点出发、与所记忆的边平行或垂直的线（见下文） |
| 已锁定 | 洋红色线 | 使用方向键或 Shift 锁定的方向 |
| 位于边上 | 红色方块 | 沿边的任意位置 |
| 位于辅助线上 | 灰色 | 沿辅助线的任意位置 |
| 位于面上 | 蓝色菱形 | 面上的任意位置 |
| 位于平面上 | 无 | 指针位于空白处时，起始所在的平面 |
| 位于地面上 | 无 | 地面（红绿平面），当其他位置均无对象时 |

当从起点出发的轴线与边或辅助线相交时，ModelCraft 会捕捉到交点，提示会同时注明两者，例如“位于红轴上，位于边上”。

## 捕捉的优先级

1. **点**（约 12 像素范围内）：先为端点，其次为辅助点、中点、指针下方面的中心以及原点。
2. **方向**（从起点出发）：红、绿、蓝轴，以及与所记忆的边平行或垂直的方向。
3. **位于边上**或**位于辅助线上**。
4. **位于面上。**
5. **绘图平面**或地面。

位于面后方的隐藏内容永远不会被捕捉。通过环绕视图使所需的点可见。

## 从一点开始在面上绘图

从拐角、中点、边或面中心开始的{{ui:矩形}}、{{ui:圆}}或{{ui:多边形}}，会绘制在**指针下方面所在的平面内**，并切割该面。边属于两个面，因此由指针所在的一侧决定：若要在长盒子的端面上绘图，请从其某条边的中点开始，并将指针置于端面内侧。

## 平行与垂直

ModelCraft 会记住**首次点击之前指针最后经过的边**。从拐角或边上开始也视为经过该边。工具开始工作后，悬停经过的其他边不会替换它。

要绘制与现有边平行的直线：

1. 按{{key:L}}，并悬停在要对齐的边上。
2. 移动到起点，尽量避免途中穿过其他边，然后点击。
3. 沿与该边平行的方向移动。直线变为洋红色，提示显示“平行于边”。垂直的操作方式相同，但限定在所绘制的平面内。

若记住的边有误，请按{{key:Esc}}，悬停在正确的边上，然后重新开始。

## 锁定方向

在工具的首次点击之后，可以将下一个点保持在一条直线上：

| 按键 | 锁定到 |
|---|---|
| {{key:Right}} | 红轴 |
| {{key:Left}} | 绿轴 |
| {{key:Up}} | 蓝轴（竖直向上） |
| {{key:Down}} | 与所记忆的边平行（见上文） |

再次按下相同的方向键即可解除锁定。状态栏显示“已锁定到红轴。再次按下相同方向键即可解除锁定。”

锁定后，该点会沿直线滑动，朝向指针所在的位置，并且仍会与所悬停的点对齐：悬停在另一个盒子的拐角上，即可沿红轴绘制恰好到达该拐角的直线。

**{{key:Shift}}** 会锁定当前所捕捉的任何方向（某条轴，或平行方向），只要按住即有效。松开即可解除锁定。

锁定功能可用于{{ui:直线}}、{{ui:矩形}}、{{ui:圆}}、{{ui:多边形}}、{{ui:移动}}、{{ui:缩放}}和{{ui:卷尺}}。在首次点击之前，方向键则改为环绕视图。

## 在群组内部

在群组或组件内部编辑时，坐标轴即为该群组自身的坐标轴（它们会随群组移动，若群组被旋转，坐标轴也随之转动）。捕捉仍可找到群组外部的点和边，因此可与模型的其余部分对齐。
