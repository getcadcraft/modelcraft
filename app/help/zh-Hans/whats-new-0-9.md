以下是 ModelCraft 0.9 相比 0.8.1 的变化。ModelCraft 现在可以连接打印机和工厂车间：你可以把模型放到打印平台上直接发送，无需导出；可以为耗材或树脂切片；还能规划物料搬运线。这是 CadCraft Studio 0.9 及其八个应用的一部分；下面的大多数新功能都是插件。

## 新增

### 3D 打印

- **打印阶段。**在工具栏中点击{{ui:打印阶段}}。将库项目添加到打印机平台上，排列它们，查看切片后的各层，然后按{{ui:发送到3D打印机}}，无需导出 STL 文件。它属于 3D 打印插件，该插件默认开启，可像其他插件一样移除。参见[将模型放到打印平台上并发送到打印机](topic:print-stage)。
- **自有耗材切片器。**{{ui:CadCraft 基础版（内置，最快）}}是卡片**切片器**列表中的切片器：包括墙体、表层、填充、支撑和裙边，在后台工作线程中运行，页面仍可正常使用。{{ui:预览层}}配合**层**滑块可在发送前查看各层。Ender-3 和 Prusa MK4 等打印机配置文件各自带有起始 G-code。
- **发送。**可通过 USB（电脑上的 Chrome 或 Edge，且需保持页面打开），或发送到网络中的 Klipper（Moonraker）、OctoPrint 或 PrusaLink。未经点击，不会进行任何连接或发送，发送前会先询问。
- **其他切片器。**Kiri:Moto、PrusaSlicer 和 OrcaSlicer 各自是独立插件，默认关闭；可从卡片或从{{ui:设置}} › {{ui:插件}}中添加。PrusaSlicer 和 OrcaSlicer 使用 CadCraft Studio 中已安装的副本。Bambu Lab 打印机插件使用 OrcaSlicer 及其 P2S 预设进行切片，并需要在电脑上使用 Studio。
- **树脂打印。**树脂插件（默认关闭）为打印机屏幕生成层图片，支持中空和通气孔、底筏和支撑、层预览，以及时间、树脂用量和成本。文件格式插件可写入 Elegoo GOO、SL1、Chitubox（CBDDLP 以及 CTB 2 至 5）和 Anycubic（PWMX 和 PWS）。树脂曝光测试可生成由五种曝光时间组成的阶梯。参见[为树脂打印机切片](topic:resin-printing)。
- **未变化。**{{ui:导出}} › {{ui:检查是否适合三维打印（STL或3MF）…}}、打印工具以及为打印拆分的工作方式与 0.8 相同。参见[为三维打印准备模型](topic:print-3d)。

### 物料流、数字孪生和工厂车间

这三项都是插件，在{{ui:设置}} › {{ui:插件}}中开启前默认关闭，开启后各自有独立的帮助。

- **物料流。**名为“物料流”的面板会在三维视图中布置传送带、工位、缓冲区和 AGV 路径，运行可指定随机种子的仿真，可回放，并显示产量、交付周期和排队情况，结果可保存为 CSV。订单可来自 CSV 文件。机器人单元可检查和导出。PLC 连接提供软模式，以及基于 Modbus TCP 的真实模式，后者仅在 CadCraft Studio 中可用。
- **数字孪生。**读取物料流布局并在其上运行软 PLC，可强制设定故障，进行库存测试、布局比较和物料清单。
- **工厂车间。**将工位转换为设备和单元，可实时读取或从模拟器读取数据，并保留作业队列和简单的 OEE。它仅读取：本版本无法写入设备或 PLC。

### 曲面、模型和图形

- **NURBS 上的圆角、加厚和布尔运算。**{{ui:曲面}}面板包含{{ui:面之间的圆角}}、{{ui:多条边圆角}}、{{ui:加厚为实体}}以及并集、差集和交集，每项都带有测得的偏差。参见[自由曲面（NURBS）](topic:nurbs-surfaces)。
- **将曲面拟合到扫描数据。**选择扫描网格，在**扫描**组中使用{{ui:将曲面拟合到扫描数据}}，再使用{{ui:将曲面缝合为实体}}。这只是初步拟合，并非完整的逆向工程软件包。
- **来自 .3dm 建模软件的实时链接。**单向，来自 Rhino 8 或 Grasshopper，并且需要与 CadCraft Studio 位于同一台电脑上。参见[保持 .3dm 模型实时同步](topic:live-3dm-link)。
- **在现场查看模型。**{{ui:视图}}菜单中的{{ui:在现场查看（AR，手机）}}可在装有 Chrome 的 Android 手机上使用。参见[使用 Android 手机在现场查看模型（AR）](topic:ar-on-site)。
- **圆弧方法。**{{ui:圆弧方法}}下拉列表提供十种画圆弧的方式，包括{{ui:三点}}和{{ui:起点、圆心、端点}}。
- **更多单位。**在输入带单位的数值时，可识别重量（kg、lb、t、ton）和温度（摄氏度 C、华氏度 F、开尔文 K 和兰氏度 R）。

## 所有应用通用

- **工具提示。**按钮上的悬停文字和被截断的标签使用 Bootstrap 工具提示。
- **可关闭的起始提示。**空白绘图区域中的提示卡片带有一个小的关闭按钮 ×。关闭后将保持关闭，命令面板可以再次显示它。
- **可滚动的选项卡栏。**面板中放不下的选项卡栏会滚动显示，而不会被截断。
- **标签页标题。**打开文档时，浏览器标签页以文档名称开头，然后是 ModelCraft 和 CadCraft。未保存时，圆点会排在最前面。
- **布局。**{{ui:设置}} › {{ui:常规}} › 布局中以下拉列表保存各个布局，可选择仅为当前应用使用某个布局，还有一个重置布局的按钮。
- **语言。**设置中的语言列表与本版本包含的语言文件一致。英语以外的语言均为机器草稿。
- **实时协作与库。**Live TeamWork 显示实时光标和名称，库集合为每个应用提供默认集合。

## 已修复

- 动画播放时，{{ui:播放}}会变为{{ui:暂停}}；时间轴打开时，{{key:Space}}可播放和暂停。
- 当显卡无法启动路径追踪器时，静态渲染会回退到 WebGL。实时渲染视图可能仍会显示错误；该驱动程序未在使用它的 Windows 电脑上验证过。
- 物料流真实模式在因 PLC 异常应答而中断连接后，可以重新连接。

## 诚实的限制

- 尚未在真实打印机上打印过任何东西：耗材、树脂以及通过 Bambu Connect 的打印均未测试。树脂文件仅由 CadCraft 自带的读取器回读验证。
- 数字孪生和工厂车间仅在模拟器和已知答案上测试，未接入真实 PLC、生产线或通信协议。它们是检查辅助工具，不是安全验证。物理仿真仅覆盖箱体，最多支持八个载荷。
- Rhino 与 Grasshopper 的链接从未在真实程序中运行过。
- 英语以外的语言均为机器草稿。

## 早期版本：0.8 和 0.8.1

以下是 ModelCraft 0.8（2026-11-01）和 0.8.1（2026-11-02）相比 0.7 的变化。{{ui:渲染图片…}}对话框现在可以将场景发送到其他程序，曲面面板可制作平滑的自由曲面，已连接的助手可以用一句话设置整个场景。

### 新增

**渲染**

- **引擎选项。**{{ui:渲染图片…}}在模式上方有一个**引擎**列表。我们自有的两个引擎“快速”和“路径追踪器”为默认选项，并可在各处使用。其他选项会将场景保存为一个包（模型为 USD 文件，另加一个设置文件，记录精确的材质数值、已开启的灯光、太阳、天空、曝光和相机），以便带到其他程序中。由其他程序绘制的图片会注明是哪个程序及哪个版本生成的。参见[选择由哪个程序绘制图片](topic:render-engines)。
- **用其他程序打开。**引擎列表可在浏览器和 CadCraft Studio 中将场景保存为 USD 文件、glTF 文件（`.glb`）或 Unreal 项目文件夹（`.zip`）。在 Studio 中，它还可以启动 usdview 或电脑上为该文件设置的程序。参见[在其他程序中打开场景](topic:render-open-in)。
- **从 Studio 发送到游戏引擎。**Studio 将场景写入 Unreal Engine 项目，并在每次发送时保持同步，且仅单向。你自己的编辑保存在 CadCraft 从不写入的层中。参见[将场景发送到游戏引擎](topic:render-unreal)。
- **插件提供的引擎。**插件可以向列表中添加引擎。用 JavaScript 编写的引擎可在浏览器和 Studio 中绘图；运行外部程序的引擎需要在 Studio 中确认同意。参见[用其他程序绘制图片](topic:render-other-program)和[用插件添加渲染引擎](topic:render-engine-addons)。
- **描述场景。**在已连接的助手中输入“黄昏，小雨，秋天的树，广场上的人”，ModelCraft 会一步完成设置：太阳移动到对应的日期和时间，使阴影随之变化，天空随之改变，出现湿润的表面，树木和人会作为真实对象放置，并带有可隐藏、移动或删除的标记。时段、日期或季节，以及天气（晴朗、阴天、雾、小雨、雨、暴风雨）也可单独使用，之后的请求会修改同一场景。显卡绘制的高质量图片中会显示雾；其他引擎显示天空、光照和湿润的表面。雨不会绘制为落下的线条。

**材质**

- **从一张照片生成材质。**向 ModelCraft 提供一张表面照片（墙面、地板、石材），它会生成可平铺的材质：照片上的光照被均匀化，边缘被处理成可无缝衔接，颜色贴图、粗糙度贴图和法线贴图均从图片中推算出来。这只是对你自己照片的常规图像处理，未使用训练模型。粗糙度为估算值。平整、正方形、正对拍摄的照片可得到最佳平铺效果；砖块等强图案的接缝处可能出现柔和的重影，因为接缝经过了融合。

**曲面**

- **自由曲面。**{{ui:曲面}}面板可制作 NURBS 曲线和未修剪曲面：通过点的曲线、放样、直纹面、拉伸、旋转、沿一条或两条导轨的扫描、由曲线网络生成的曲面、由四条边生成的补片、匹配与混合。每条共享边都会在精确曲面上以 G0、G1 或 G2 进行测量（间隙、角度、曲率跳变）；超出所设标准的边会出现在问题面板中，并附带**匹配**修复选项。斑马纹和曲率颜色均根据精确曲面绘制。STEP 和 IGES 文件可导出和导入。参见[自由曲面（NURBS）](topic:nurbs-surfaces)。

**场地与房间**

- **草图照片落到地面。**{{ui:文件}} › {{ui:导入草图照片…}}可将手绘草图的手机照片转换为地面上的边线，比例按你设定的值：形成一个组，并为每种笔色添加一个标记。纸张在电脑上被识别并拉直，任何内容都不会发送到其他地方。参见[在总平面图上建模](topic:site-plan)。
- **布置房间。**选择地板，然后使用{{ui:组织}} › {{ui:布置房间…}}。卧室、客厅、餐厅、厨房、浴室或办公家具会按规则放置：靠墙摆放，并避开门窗，所有家具位于一个组中，可一步移除。这是供你检查的默认布局，而非设计方案。参见[入门库](topic:starter)。

**3D 打印**

- **倾斜切割。**为打印拆分可将切口倾斜最多 60 度，使各部件有更大的粘接面积。连接件与切口保持垂直。参见[为打印拆分模型](topic:print-split)。
- **问题面板中的打印检查。**3D 打印检查的结果会显示在问题面板中，并在模型上标出，修复可直接从那里进行。参见[支撑、壁厚、中空化与修复](topic:print-tools)。

**所有应用通用**

- **语言。**帮助和应用提供 54 种语言。其中十种为新增：立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语。在母语者审校之前，英语以外的语言均为机器草稿，帮助主题可能仍为英文。
- **输入设备。**触控板、手写笔、3D 鼠标、游戏手柄和 MIDI 控制器均可操作应用，可对所有应用或仅对某一个应用生效。
- **工具栏行数。**{{ui:设置}} › {{ui:常规}} › 工具栏行数可设置为换行（与之前相同）、2 行或 1 行。放不下的工具栏会横向滚动，而不会占用绘图区域的空间。换行仍为默认设置。
- **属性网格。**ModelCraft 的灯具字段使用共享网格：可折叠的类别、标签列和数值列，以及紧凑密度。输入的算式（如 `2*450`）仍可正常使用。
- **问题。**问题面板（应用栏中的警告按钮）由所有应用共享。在 ModelCraft 中，它包含打印检查和曲面连续性警告。
- **实时协作。**Live TeamWork 会话会显示每位成员所在的位置。参见[使用 Live TeamWork 共同建模](topic:work-live)。
- **插件。**插件可如上所述添加渲染引擎。
- **连接 AI。**八个应用的工具契约和检查均已通过，共计 454 个工具。Studio 内一键连接、面向浏览器助手的托管连接器、在 Studio 内使用自有密钥以及已发布的软件包尚未提供。应用本身不包含任何 AI。参见[在 AI 助手中使用 ModelCraft](topic:use-with-ai-assistants)。

### 0.8.1 中的修复

- **DWG 类别部分。**DWG 文件的类别部分曾被读取为错误的类型，可能导致导入时文件损坏。现在已正确读取，ModelCraft 以及其他读取 DWG 的应用均已修正。
- **竖屏平板。**多余的网格高度将分配给画布，布局在宽度为 760 像素或更小时启用。ModelCraft 的样式表也包含此更改。
- **Studio 中的语言。**CadCraft Studio 及打包版本可在运行时切换语言；此前仅支持英语。尚未在所有平台上测试：如果语言未能切换，请告知我们。

### 本版本尚未提供

- **未进行代码签名。**Windows 可能显示 SmartScreen：请选择{{ui:更多信息}}，然后选择{{ui:仍要运行}}。在 Mac 上，右键单击并选择{{ui:打开}}。商店版本暂缓发布，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- 在没有渲染引擎插件的情况下由其他程序绘制图片、全景或立体相机，以及通过其他程序生成天空图片，还有打开 Unreal 舞台的插件，目前尚未提供。文件已写入；插件尚未发布，也未在 Unreal 中运行过。
- 自由曲面：G3 和 A 级曲面尚未测量，也未作声明；修剪和实体将在之后提供。
- 其他程序生成的图片在像素层面与我们的图片并不相同：只有相机、太阳、灯光和曝光是一致的。
- 针对 Studio 语言切换的 0.8.1 修复尚未在所有平台上测试。

其他内容见[尚未实现](topic:not-built-yet)。上一版本请参见[0.7 版新增功能](topic:whats-new-0-7)。
