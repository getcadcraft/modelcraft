以下是推/拉式按键，即 ModelCraft 默认使用的按键。关于另一种键位方案，请参见下文的[Modeler 键位](topic:keyboard#modeler-keys)以及[ModelCraft 设置](topic:settings)。

当 3D 视图或工具栏按钮获得焦点时，快捷键方可生效。若刚在面板输入框中输入内容，或更改了{{ui:样式}}中的列表，请先点击 3D 视图，否则按键会被输入到该输入框中。关于各类电脑上按键的书写方式，请参见[键盘、鼠标和触控板](common:keys)。

## Esc

每按一次{{key:Esc}}，便退出一层：

1. 取消工具正在进行的操作（正在绘制的直线、推/拉或移动）。所有内容均恢复原样。
2. 切换到{{ui:选择}}。
3. 清除选择。
4. 关闭正在编辑的群组。

它还会停止场景播放。在数值框中，{{key:Esc}}会清除已输入的内容并返回视图。

## 工具工作时

| 按键 | 作用 |
|---|---|
| 数字，或以下符号之一：`. , - ' " [ < * /` | 开始在数值框中输入 |
| {{key:Enter}} | 应用数值框中输入的内容 |
| {{key:Right}} | 锁定到红轴（再次按下可解除锁定） |
| {{key:Left}} | 锁定到绿轴 |
| {{key:Up}} | 锁定到蓝轴 |
| {{key:Down}} | 锁定到首次点击前最后悬停经过的边的平行方向 |
| 按住{{key:Shift}} | 按住期间保持所捕捉的方向 |
| {{key:Ctrl}}、{{key:Mod}} 或 {{key:Alt}}（移动时） | 在移动与复制之间切换 |

方向键锁定可用于{{ui:直线}}、{{ui:矩形}}、{{ui:圆}}、{{ui:多边形}}、{{ui:移动}}、{{ui:缩放}}和{{ui:卷尺}}（从某点开始测量时），须在首次点击之后。{{ui:推/拉}}始终沿面的方向移动，没有锁定功能。在{{ui:旋转}}中，首次点击之后方向键会显示“已锁定”消息，但不会改变旋转方向。

## 其他时候的方向键

当没有工具正在进行操作时，方向键用于移动视角：

| 按键 | 作用 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 环绕 |
| {{key:Shift}}加方向键 | 平移 |

## 鼠标

| 操作 | 作用 |
|---|---|
| 点击 | 使用当前工具 |
| 按下、拖动、释放 | 与两次点击相同（用于绘图工具）；框选（用于{{ui:选择}}）；沿途擦除（用于{{ui:橡皮擦}}） |
| 双击 | {{ui:选择}}：选中面及其边、选中边及其面，或打开群组；点击空白处则关闭群组。{{ui:推/拉}}：重复上一次的距离 |
| 三击 | {{ui:选择}}：选中全部相连的内容 |
| {{key:Shift}} + 点击 | {{ui:选择}}：切换选中状态 |
| {{key:Mod}} + 点击 | {{ui:选择}}：加入选择 |
| {{key:Shift}} + {{key:Mod}} + 点击 | {{ui:选择}}：从选择中移除 |
| 中键拖动 | 环绕，适用于任何工具 |
| {{key:Shift}} + 中键拖动 | 平移，适用于任何工具 |
| 右键拖动 | 平移，适用于任何工具 |
| 滚轮 | 朝指针方向缩放 |

没有右键菜单。

## 触控板

双指滑动的作用取决于{{ui:设置}} › {{ui:ModelCraft}} › 滚动：

| 手势 | 触控板（或推算） | 鼠标滚轮 |
|---|---|---|
| 双指滑动 | 环绕 | 朝指针方向缩放 |
| {{key:Shift}} + 双指滑动 | 平移 | 缩放 |
| 捏合 | 朝指针方向缩放 | 朝指针方向缩放 |
| 双指按下并拖动（按住次要点击） | 平移 | 平移 |

参见[环绕、平移和缩放](topic:orbit-pan-zoom#on-a-trackpad)以及[ModelCraft 设置](topic:settings#scrolling-mouse-wheel-or-trackpad)。

## 触摸屏

| 手势 | 作用 |
|---|---|
| 轻点 | 使用当前工具进行一次点击 |
| 双击 | 一次双击 |
| 按下、拖动、抬起 | 与鼠标的按下、拖动、释放相同 |
| 双指：捏合 | 缩放 |
| 双指：一起移动 | 平移（设置 › ModelCraft › 触摸屏 可将其改为环绕） |
| 三指：一起移动 | 环绕（双指环绕时则为平移） |
| 保持单指不动 | 结束工具，效果同{{key:Enter}}；若此时没有任何操作，则拖动即可环绕 |
| 单指操作期间加入第二根手指 | 取消该单指操作 |
| {{ui:环绕}}工具，然后单指拖动 | 环绕 |

在触摸屏上输入数值时，请点击底部的数值框，输入后按键盘上的 Enter（或“前往”）键。

## 移动的位置

移动功能位于{{ui:移动}}工具中，按键为{{key:M}}：选择要移动的内容，点击基点，然后点击第二个点或输入距离。参见[移动、复制和创建阵列](topic:move-copy)。
