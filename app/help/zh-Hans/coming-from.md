如果你用过 SketchUp，ModelCraft 会让你感到熟悉：同样的面与推/拉理念、同样的工具字母、无需点击即可输入的数值框、使用红、绿、蓝坐标轴的推断、组、组件、大纲、实体信息和场景。本页列出了可以直接对应的内容，更重要的是，列出了不能对应的内容。

## 可以沿用的习惯

| 你习惯的操作 | 在 ModelCraft 中 |
|---|---|
| 按 Space 选择，L 画直线，R 画矩形，C 画圆 | 相同：{{key:Space}}、{{key:L}}、{{key:R}}、{{key:C}} |
| 按 P 推/拉，M 移动，Q 旋转，S 缩放，E 橡皮擦，T 卷尺 | 相同：{{key:P}}、{{key:M}}、{{key:Q}}、{{key:S}}、{{key:E}}、{{key:T}} |
| 按 O 环绕，H 平移，Z 缩放，Shift+Z 范围缩放 | 相同：{{key:O}}、{{key:H}}、{{key:Z}}、{{key:Shift+Z}} |
| 按 G 创建组件 | 相同：{{key:G}}。{{key:Shift+G}} 创建组 |
| 不点击测量框即可直接输入 | 相同，输入到底部的数值框中。按 {{key:Enter}} |
| 输入 `4m,3m` 绘制矩形，输入 `12s` 设置边长 | 相同 |
| 移动复制后输入 `3x` 或 `/3` | 相同；`*3` 也可以 |
| 输入 `[x,y,z]` 或 `<dx,dy,dz>` 指定点或偏移 | 相同 |
| 在英寸建筑模型中直接输入数字即得到英寸 | 相同 |
| 中键拖动环绕，Shift 加中键拖动平移，滚轮在光标处缩放 | 相同 |
| 用推/拉工具双击以重复距离 | 相同 |
| 方向键锁定红、绿、蓝以及平行 | 相同：{{key:Right}} 红，{{key:Left}} 绿，{{key:Up}} 蓝，{{key:Down}} 平行 |
| 按住 Shift 锁定推断 | 相同 |
| 移动时按 Ctrl（Mac 上为 Option）复制 | {{key:Ctrl}}、{{key:Mod}} 或 {{key:Alt}}，任何电脑上均可 |

| 用标注工具标注长度 | {{key:D}}，并且更多：在标注中输入新长度，模型会随之调整大小。参见[标注与调整大小](topic:dimensions) |

| 双击组以编辑；按 Esc 关闭 | 相同 |
| 在面上画线以拆分；删除共面之间的边以合并 | 相同 |

| 背面以蓝灰色显示；反转面 | 颜色相同；{{ui:反转面}}位于{{ui:实体信息}}中 |
| 场景以标签页形式位于视图上方，使用 Page Up 与 Page Down | 相同，并在{{ui:场景}}面板中使用{{ui:播放}} |

## 不同之处，容易让人出错

### 保存即下载

没有会覆盖你所打开文件的保存，没有带名称的“另存为”对话框，没有自动保存，也没有备份文件。{{ui:保存}}（{{key:Mod+S}}）每次都会下载一个新的 `.modelcraft` 文件，通常保存到你的下载文件夹。请经常保存，并自行重命名或移动文件。参见[打开、保存、导入和导出](topic:files)。

### 可以导入 .skp 文件，但不能保存

{{ui:导入}}会使用 ModelCraft 自己的读取器在页面中读取 SketchUp 文件：组、组件、颜色、面上的纹理、标记和柔化边都会一并导入。参见[文件格式详解](topic:formats#skp-files)。ModelCraft 无法保存 `.skp`：若要返回，请从 ModelCraft 导出 Collada，并在 SketchUp 中导入。

### 没有右键菜单

右键拖动为平移；单击右键没有任何作用。你在右键菜单中可能找到的命令，位于{{ui:实体信息}}（{{ui:反转面}}、{{ui:编辑}}、{{ui:分解}}、{{ui:设为唯一}}、{{ui:创建组件}}）以及工具栏的{{ui:组织}}组中。

### 单位位于状态栏

没有“模型信息”或模板选择。单位选择器位于右下角。新模型会根据你浏览器的语言设置开始：美国使用英尺和英寸，其他地区使用毫米。小数始终使用句点：`2.5m`，而不是 `2,5m`，因为逗号始终用于分隔数值。

### 材质有自己的材料

{{ui:材质}}（{{key:B}}）涂抹纯色以及{{ui:材料}}部分中的材料：砖、墙板、屋面、木材、石材等，均由 ModelCraft 绘制。你目前还无法加载自己的图像作为材料；随导入文件而来的纹理会被保留。参见[使用颜色和材料上色](topic:paint)。

### 缩放是均匀的，没有夹点

缩放不会显示带夹点的框。单击保持不动的点（参考点），然后输入新尺寸或输入的比例因子。它始终在所有方向上均匀缩放。若要沿某一方向拉伸，请使用推/拉或移动面，或在{{ui:实体信息}}中重新输入组的宽度、深度或高度，或[用标注调整大小](topic:dimensions)。

### 旋转根据你单击的位置选择平面

没有会随方向键悬停而贴附到面上、用于选择平面的量角器。在某个面的中心单击，可以在该面的平面内旋转；在地面上单击，则绕竖直方向旋转。第一次单击之前，方向键会环绕视图。

### 推断来自你经过的点

ModelCraft 会从**你的起点**沿坐标轴方向捕捉，并捕捉光标下的点、边和面。它不会沿你仅仅悬停经过的点追踪方向（SketchUp 的虚线“从点”推断）。要对齐远处的角点，请用方向键锁定该轴，并将光标悬停在该角点上：锁定的点会滑动到与其对齐。或放置一条[参考线](topic:guides-measure)。

### 平行使用你在开始前经过的边

平行和垂直推断使用指针在**第一次单击之前**经过的最后一条边，而不是你在绘制时悬停的边。参见[推断与捕捉](topic:inference#parallel-and-perpendicular)。

### 组的副本是链接的

用{{ui:移动}}复制组会生成同一组的第二个放置位置，因此编辑其中一个会同时改变两者，与组件一样。SketchUp 的组则是彼此独立的。参见[故障排除](topic:troubleshooting#editing-one-group-changed-another)。

### 空格不平移

{{key:Space}}选择{{ui:选择}}，与 SketchUp 相同。在其他一些网页应用中，按住空格会平移；此处不会。请改为右键拖动平移。

### 双指滚动缩放

在触控板上，请在{{ui:设置}} › {{ui:ModelCraft}} › 滚动中设置为触控板：双指环绕，{{key:Shift}}加双指平移，捏合缩放。参见[环绕、平移和缩放](topic:orbit-pan-zoom#on-a-trackpad)。

如果你的操作习惯来自 Blender 而非 SketchUp，请选择{{ui:建模器式}}菜单样式：{{key:G}}、{{key:R}} 和 {{key:S}} 会同时作用于所选内容，{{key:E}} 挤出（推/拉），{{key:Shift+D}} 复制，顶部的菜单栏（文件、编辑、视图、选择、添加、对象、网格）会替代工具栏。如果来自 SketchUp，则可使用{{ui:推拉式}}样式，它会在同样的工具字母上提供类似的菜单栏。参见[菜单、键盘和鼠标](topic:menus-keys-and-mouse)。

### 相互压入的实体不会切割

推/拉会穿透同一对象中其后的面进行切割，但两个相互压入的独立实体不会相交。没有“相交面”和“实体工具”。

### 缺失的功能

徒手绘制、修剪、拆分和外部抽壳、你自己的图像材料、插件，以及用于布局的工具，在此版本中均不可用。[尚未实现的功能](topic:not-built-yet)列出了替代方案。

## 浏览器保留的快捷键

ModelCraft 在浏览器中运行，因此有几个快捷键属于浏览器而非应用本身。{{key:Mod+N}} 会打开浏览器窗口（请改用{{ui:新建}}），{{key:Mod+W}} 会关闭标签页。如果有未保存的更改，浏览器会在关闭前询问。参见[按键、鼠标和触控板](common:keys#shortcuts-the-browser-keeps)。
