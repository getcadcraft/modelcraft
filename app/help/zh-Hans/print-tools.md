用于让模型适合3D打印机的四个工具。打开{{ui:导出}} › {{ui:检查是否适合三维打印（STL或3MF）…}}；对话框中的**打印工具**一行包含{{ui:支撑预览}}、{{ui:壁厚}}、{{ui:抽空}}和{{ui:修复}}。每个工具都会以卡片形式显示在视图上方；{{ui:关闭}}（叉号）会收起该卡片及其标记。同一时间只显示一张卡片。

每个工具都只处理可打印的内容：即所选内容；若未选择任何内容，则为当前显示的全部内容。{{ui:抽空}}和{{ui:修复}}需要选中一个组、组件或网格，因为它们会修改该对象。

## 支撑预览

与竖直方向的夹角超过**悬垂角度**的面以红色着色，并从这些面向下（橙色）绘制简单支撑，直至打印床或模型位于其下方的部分。

- **悬垂角度**：45° 是大多数打印机无需支撑即可应对的角度。若打印机桥接性能较好，请调高此值。
- **柱状**：在每个悬垂下方每隔 3 mm 设置一根直柱。估算时将其按 15% 的支撑图案计算。
- **树状**：邻近的点在其中点下方汇合为一根主干；任何分支的倾斜都不超过 45°。树状支撑通常用料较少，与打印床的接触点也更少。

卡片会显示需要支撑的表面积、支撑点的数量以及它们大致的用料。立于模型上（而非打印床上）的支撑也会被计入：它们会在模型上留下痕迹。若在{{ui:设置}}中选择了打印床，则会在模型下方绘制打印床。

:::note
这只是预览，不是切片软件：实际支撑由切片软件决定。对于非常大的悬垂，支撑点会分布得更宽，以保证预览速度；卡片会予以说明。
:::

## 壁厚

每个面都沿实体直接测量至另一侧。厚度低于**允许的最小壁厚**的壁以红色显示；低于其 1.5 倍的壁以橙色显示：它们可以打印，但可能偏弱。

薄弱区域按从薄到厚的顺序列出，并显示每处的厚度和大小。点击{{ui:显示}}会将相机转向该区域。

打印机无法打印比喷嘴宽度约两倍更薄的壁：对于常见的 0.4 mm 喷嘴，为 0.8 mm（初始值）。树脂打印机的能力更弱；请查阅打印机的说明书。

对于非常大的模型，只有部分面发射射线，其余面采用相邻面的厚度；卡片会说明实际测量了多少个面。

## 抽空

抽空会保留外部不变并去除内部，留下指定厚度的壁。树脂打印用料更少，对成型板的拉力也更小；耗材打印比填充方式用料更少。

1. 选择组、组件或网格，然后打开{{ui:抽空}}。
2. 设置**壁厚**（初始值为 2 mm）以及**排液孔**的宽度。
3. 对于树脂打印，点击{{ui:放置排液孔}}，然后在模型外表面点击其位置：应靠低处、靠近成型板，以便液态树脂流出。根据需要放置任意数量；每个都会显示为蓝色圆圈，并列在{{ui:移除}}下。
4. {{ui:预览}}会显示抽空会去除多少材料。
5. {{ui:抽空}}会执行更改：一步完成，{{key:Mod+Z}}可撤销。

结果是一个通过3D打印检查的封闭实体：ModelCraft会先进行检查，若无法通过则不做任何更改。若模型厚度不足两个壁厚，则保持实心。结果为一个组，其平面由单个面构成，因此仍可用{{ui:推/拉}}继续建模；在精细网格上抽空的曲面零件通常面数过多，因此会改为网格，状态栏会说明是哪种情况。

:::tip
对于大多数形状，内部即为外部向内精确偏移一个壁厚。若拐角或薄部使其无法实现，ModelCraft会改为在精细网格上按壁厚距离跟随外部；卡片随后会说明其精确程度（误差在毫米的几分之一以内）。
:::

## 修复

{{ui:修复}}会以打印机切片软件的方式检查所选零件，安全地修复能修复的问题，并列出每一项修复：

| 可修复内容 | 含义 |
|---|---|
| 无面积的三角形 | 删除 |
| 重复绘制的三角形 | 保留一份；与自身背靠背的面（无厚度）会被删除 |
| 小于 0.5 mm 的游离碎片 | 删除 |
| 朝向错误的三角形 | 转向，以与相邻三角形一致 |
| 孔洞，无论是否平坦 | 以从每个孔洞中心引出的一组新三角形封闭 |
| 内外翻转的部件 | 翻转为朝外（嵌套于另一部件内的空心则保持不变：它本就应当朝内） |

{{ui:修复安全的问题}}会一步完成所有修复，{{key:Mod+Z}}可撤销，状态栏会列出每一项修复。修复后的零件会成为一个组，其平面由单个面构成。若仍无法封闭（**留待处理**下仍有内容），或其面数过多而无法作为组，则会改为网格：其面保持为三角形，平面看起来仍是平的。状态栏会说明是哪种情况。{{ui:合并重叠部分}}的工作方式相同。

无法安全修复的内容会列在**留待处理**下，并在视图中以紫色标记，可用{{ui:显示}}查看：

- **三个或更多面相交的边**：确定哪个面属于该处，并删除其余面。
- **部件穿过自身**：移动或重新绘制该部分。参见[相交面](topic:intersect)。
- **孔洞过大或过于复杂而无法封闭**：跨越孔洞绘制面。
- **相互重叠的独立部件**：切片软件无论如何都会将其合并。{{ui:合并重叠部分}}会使其成为一个封闭实体（它会在相接处重建面，因此它是单独的按钮，不会自动执行）。

对于推/拉组，也可以在{{ui:实体信息}} › {{ui:显示问题}} / {{ui:修复}}中逐个修复，这样会保留所绘制的面。参见[实体工具](topic:solids)。
