你可以随时移动摄像机，即使正在绘制线条或推拉面：工具会在原处等待。

## 使用三键鼠标

| 目的 | 操作 |
|---|---|
| 环绕 | 按住中键（按下滚轮）拖动 |
| 平移 | 按住右键拖动，或按住 {{key:Shift}} 并用中键拖动。拖动过程中按下或松开 {{key:Shift}} 可在环绕与平移之间切换 |
| 缩放 | 转动滚轮。它会朝向指针下的面缩放，或朝向视图中心深度处指针下的点缩放 |
| 查看整个模型 | {{key:Shift+Z}} 或 {{ui:Extents}} |

环绕会围绕指针下的模型部分旋转视图，因此该点在所有内容围绕它旋转时保持不动。在空白区域上方，它围绕视图中心旋转。平移会保持你抓取的点位于指针下。

要始终围绕视图中心环绕，或调整环绕与平移的速度，请打开 {{ui:Settings}}（{{key:Mod+,}}），进入 {{ui:ModelCraft}} 选项卡中的**环绕和平移**。速度设置同时适用于鼠标、触控板、触摸和方向键。

不拖动的右键单击不起作用；ModelCraft 没有右键菜单。

## 没有中键时

使用工具栏中的摄像机工具，或键盘：

1. 按 {{key:O}}（或点击 {{ui:Orbit}}），然后用左键拖动以环绕。拖动时按住 {{key:Shift}} 可平移。
2. 按 {{key:H}}（或点击 {{ui:Pan}}）并拖动以平移。
3. 按 {{key:Z}}（或点击 {{ui:Zoom}}）并向上拖动以放大，向下拖动以缩小。
4. 按 {{key:Space}} 返回 {{ui:Select}}，或按下你接下来需要的工具的按键。

摄像机工具会替换你正在使用的工具。若要在操作中途环顾四周而不丢失当前操作，请改用键盘：

- 方向键用于环绕。
- {{key:Shift}} 加方向键用于平移。

当绘图工具处于操作中途（第一次点击之后），方向键会锁定方向而不是环绕。参见[推断与捕捉](topic:inference#lock-a-direction)。

## 在触控板上

最简单的方法：打开 {{ui:Settings}}（{{key:Mod+,}}），进入 {{ui:ModelCraft}} 选项卡，将滚动设置为**触控板**（或保持“自动判断”）。然后双指滑动即可环绕，按住 {{key:Shift}} 并滑动即可平移，捏合即可缩放，无需摄像机按钮。参见[ModelCraft 设置](topic:settings#scrolling-mouse-wheel-or-trackpad)。

将滚动设置为**鼠标滚轮**时：

:::mac
- **缩放：**双指滚动或捏合。两者都朝向指针缩放。
- **平移：**用双指按下（辅助点按），并在拖动时保持手指按下。如果双指点按无效，请在**系统设置**中打开“辅助点按”，路径为**触控板**。
- **环绕：**按 {{key:O}} 并用一根手指拖动，或使用方向键。
- 按住 {{key:Ctrl}} 点击时，在 ModelCraft 中可能不会被视为右键单击，具体取决于浏览器：它可能会作为按住 {{key:Ctrl}} 的点击。平移请使用双指按下。
:::

:::windows linux
- **缩放：**双指滚动。如果触控板驱动以按住 {{key:Ctrl}} 的滚动方式发送捏合，则捏合也可以缩放。
- **平移：**用右键拖动（在许多触控板上，按下右下角并拖动），或按 {{key:H}} 并拖动。
- **环绕：**按 {{key:O}} 并拖动，或使用方向键。
:::

使用鼠标滚轮时，双指滚动会缩放，不会平移。这与许多网页的操作相反，也是大多数三维建模软件中鼠标滚轮的行为。

:::tip
{{key:Space}} 在 ModelCraft 中会选择 {{ui:Select}} 工具。按住 {{key:Space}} 并拖动不会平移，这与某些其他应用不同。
:::

## 在触摸屏上

:::touch
- **一根手指**使用当前工具：**点按**即为点击，**按住并拖动**即为绘制或拖动。
- 绘图工具的手指按下时，其上方会显示**放大镜**，显示手指下的内容，因此你可以在抬起之前看到它将捕捉到的端点、中点或边。
- **保持不动**半秒即可完成工具正在执行的操作，相当于 {{key:Enter}}：完成一条曲线或一串线段。若没有任何操作，保持不动后用同一根手指拖动即可**环绕**，直到抬起手指。
- **双指一起拖动**即为**平移**；**捏合**即为缩放。两者可在一个手势中同时进行。
- **三指一起拖动**即为**环绕**。
- 若要交换它们（双指环绕，三指平移），请打开 {{ui:Settings}}，进入 {{ui:ModelCraft}} 选项卡中的触摸屏设置。
- 放下第二根手指会**取消**第一根手指开始的操作（例如绘制到一半的矩形，或进行中的推拉）。抬起手指后重新开始。
- 视图底部的小栏有**完成**（{{key:Enter}}）、**取消**（{{key:Esc}}）和**撤销**，适用于没有键盘的情况。
- 捕捉和拾取的范围比鼠标稍大，按钮也更大，方便手指点击。
:::

:::mouse
在触摸屏上，一根手指使用当前工具（点按即为点击，保持不动即可完成，或保持不动后拖动以环绕），两指平移并捏合缩放，三指环绕，并且会出现一个小栏，提供完成、取消和撤销。
:::

## 标准视图

1. 点击工具栏右端的 {{ui:Views}}。
2. 选择 {{ui:Iso}}、{{ui:Top}}、{{ui:Front}}、{{ui:Right}}、{{ui:Back}}、{{ui:Left}} 或 {{ui:Bottom}}。

视图会转到该方向，并适合整个模型。{{ui:Front}} 朝向北方，沿绿色轴；{{ui:Top}} 垂直向下看，北方朝上。

位于视图右上角的视图立方体可以一键完成相同操作，并提供边和角、用于旋转模型的指南针环以及主页按钮。参见[视图立方体](topic:view-cube)。

## 透视与平行投影

选择 {{ui:Views}}，然后选择 {{ui:Perspective}}。打勾表示透视已开启。关闭时，视图为平行（正交）投影：模型中平行的线在屏幕上保持平行，这对于从 {{ui:Front}} 或 {{ui:Right}} 查看立面图很有用。状态栏会显示“透视。”或“平行投影。”

每个场景会记住其是否处于透视状态。参见[将视图保存为场景](topic:scenes)。
