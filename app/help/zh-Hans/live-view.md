{{ui:Export}} › {{ui:Live view}}会在应用上方打开一个面板，以实时效果显示模型：根据模型的位置和日期显示天空与太阳、太阳阴影、你为表面设置的外观和材质、灯光，以及墙面和地面反射的光线。面板会跟随你的操作：转动视图时它也会转动，修改模型时稍后会显示变化。不会上传任何内容。

## 打开

1. 选择{{ui:Export}} › {{ui:Live view}}。面板会在右下角打开。
2. 拖动其标题栏可移动面板，拖动其角落可放大面板。
3. {{ui:New window}}会将其移至独立窗口，便于在第二个屏幕上使用。{{ui:Export}} › {{ui:Live view in a new window}}会直接在新窗口中打开。如果浏览器阻止弹出窗口，则会以面板形式打开。
4. {{ui:Close}}可关闭它。

## 控件

| 控件 | 作用 |
|---|---|
| {{ui:Follow the view}} | 开启时，实时视图朝向 ModelCraft 视图的方向。漫游时会将其关闭 |
| {{ui:Walk}} | 在模型中漫游（见下文） |
| {{ui:Gravity}} | 漫游时：站在地板上并爬楼梯。关闭时：飞行 |
| {{ui:Time}} | 一天中的小时，从 05:00至21:00。拖动时太阳会移动 |
| {{ui:Month}} | 月份（取该月的 21 日），便于查看冬季和夏季的太阳 |
| {{ui:Quality}} | {{ui:For this computer}}（取决于[你的计算机](topic:your-machine)），或{{ui:Low}}、{{ui:Medium}}或{{ui:High}} |

底部的一行会显示用于绘制视图的技术（WebGPU 或 WebGL 2）、质量和间接光。

## 在模型中漫游

1. 将主视图转到你想站立的位置，然后选择{{ui:Walk}}。你会站在视图视点下方的地面上，身高 1.6 m。
2. 点击实时视图，然后使用{{key:W}} {{key:A}} {{key:S}} {{key:D}}或方向键。按住{{key:Shift}}可奔跑。拖动可环顾四周。
3. 高度不超过 40 cm 的台阶可以爬上（楼梯）；更高的则视为墙。墙会阻挡移动，并沿墙滑动。
4. 关闭{{ui:Gravity}}时可飞行：{{key:E}}向上，{{key:Q}}向下。
5. {{key:Esc}}可停止漫游。

## 散布植物、岩石和人物

实时视图工具栏中的{{ui:Scatter}}会在画面旁打开散布面板。散布集会将配景库中的项目（树木、灌木、草、花、岩石、人物、汽车）铺设在模型的部分区域上。这些项目仅在实时视图中绘制：它们不是模型中的几何体，主视图也不会显示它们。

1. **填充表面：**在 ModelCraft 中选择表面（或群组，例如地形），然后选择{{ui:Fill selection}}。该集合会覆盖这些表面。
2. **绘制：**选择{{ui:Paint}}，然后在实时视图上拖动。选中表面时，绘制只作用于这些表面；未选中任何内容时，绘制会作用于画笔下方的任何物体，包括地面。{{ui:Brush size}}用于设置画笔大小；{{ui:Eraser}}可擦除已绘制的区域。
3. 勾选要散布的项目。每个项目旁边的数字是其权重：3 和 1 表示每放置一个第二种项目，就放置三个第一种项目。

| 控件 | 作用 |
|---|---|
| {{ui:Per m²}} | 每平方米上的项目数量 |
| {{ui:Keep away (m)}} | 项目与其他对象的距离不会小于此值，且不会放在屋顶或桌子下方。0 表示关闭 |
| {{ui:Turn (°)}} | 每个项目绕竖直方向随机旋转的角度 |
| {{ui:Steepest (°)}} | 表面坡度超过此值时不放置项目 |
| {{ui:Size}} | 最小和最大尺寸，以项目自身尺寸的倍数表示 |
| {{ui:Height from, to (m)}} | 仅在这些高度之间放置（留空 = 任意高度） |
| {{ui:Lean with the surface}} | 0 使项目保持直立；1 使其垂直于斜面 |
| {{ui:Seed}}、{{ui:Shuffle}} | 相同的种子总会得到相同的散布结果；{{ui:Shuffle}}会选择另一个种子 |

散布集保存在 .modelcraft 文件中，修改时会随其覆盖的表面一起变化。实时视图最多绘制多少个项目，由[你的计算机](topic:your-machine)的级别决定：{{ui:Processor only}}为 20 000 个，{{ui:Graphics card, basic}}为 100 000 个，{{ui:Graphics card, high}}为一百万个。面板会显示已放置数量与密度要求数量的对比：达到预算上限时，或因对象排斥而无法放置时，放置的数量会减少。靠近相机的项目会以其真实形状绘制；较远的项目则以其颜色的简单形状绘制。

:::note
散布的项目会显示在实时视图（及其漫游、全景和独立查看器）中。{{ui:渲染图片}}目前尚不绘制这些项目。
:::

## 分享：全景、导览、查看器、视频

实时视图工具栏中的{{ui:Share}}会从实时视图生成文件。所有内容均在本机生成；不会上传任何内容。

| 选项 | 所得效果 |
|---|---|
| {{ui:360° panorama}} | 从视图所在位置（或漫游位置）生成的 360° 图片，为等距柱状投影 PNG 格式，全景查看器和大多数图片网站均可打开 |
| {{ui:Add this spot to the tour}}，然后{{ui:Save the tour}} | 一个网页，每个位置都有全景，并带有指向其他可见位置的箭头（中间有墙时会隐藏箭头） |
| {{ui:Save a viewer}} | 一个网页，以此实时效果显示模型：可转动、可漫游，并可跳转到其保存的场景。在支持 WebGPU 或 WebGL 2 的浏览器中可离线打开，可从文件夹、U 盘或电子邮件中打开，无需安装，也无需账户，且不会从互联网加载任何内容 |
| {{ui:Video of the path}} | 时间线的相机路径（或按顺序排列的已保存场景）以此实时效果生成视频，尺寸与实时视图相同：浏览器可生成时为 WebM 或 MP4，否则为 ZIP 压缩包中的编号图片 |

全景图的尺寸取决于质量：在{{ui:Low}}、{{ui:Medium}}和{{ui:High}}下，宽度分别为 1024、2048 或 4096 像素。查看器文件约为 5 MB，另加模型的大小。

:::note
导览和查看器用于展示，而非编辑：保存时会保持模型的当前状态。
:::

## 间接光

从受阳光照射的墙面反射到地面的光线，以及房间较暗的内部，均由生成[渲染图片](topic:render)的同一路径追踪器计算：它会在模型中的若干点上渲染小型全景图，并在每个处理器核心上于后台运行。计算期间，底部一行会显示{{ui:间接光：40 %}}；计算完成后，视图会采用这些结果。每次修改后都会重新开始计算。

:::note
这是实时视图中的近似计算，而非渲染图片：各计算点之间的细小细节会采用附近计算点的间接光。如需成品图片，请使用[渲染图片](topic:render)。
:::

## 亮度和颜色

实时视图使用与[渲染图片](topic:render)相同的亮度、白平衡、对比度和视图变换（ACES、AgX、Filmic 或标准）：在那里设置后，实时视图会随之变化。

:::note
不同浏览器的支持情况有所不同。若浏览器支持 WebGPU（Windows、macOS 和 ChromeOS 上的 Chrome 和 Edge，Safari 26），实时视图会使用 WebGPU；其他情况（Linux 上的大多数浏览器、较旧的 Apple 系统）则使用 WebGL 2，效果相同。
:::
