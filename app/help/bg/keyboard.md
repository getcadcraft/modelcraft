Това са клавишите за избутване и издърпване, с които ModelCraft започва по подразбиране. За другия стил вижте [Клавиши на Modeler](topic:keyboard#modeler-keys) по-долу и [Настройки на ModelCraft](topic:settings).

Пряките пътища работят, когато 3D изгледът или бутон от лентата има фокус. Ако току-що сте написали нещо в поле на панел или сте променили списък в {{ui:Style}}, първо щракнете в 3D изгледа, иначе клавишите ви ще отидат в това поле. Вижте [Клавиши, мишки и тъчпадове](common:keys) за това как се записват клавишите на всеки компютър.

## Esc

{{key:Esc}} връща с по една стъпка назад при всяко натискане:

1. Отменя това, което инструментът върши в момента (начертана линия, избутване или издърпване, преместване). Всичко се връща.
2. Превключва към {{ui:Select}}.
3. Изчиства избора.
4. Затваря групата, която редактирате.

Той също спира изпълнението на сцени. В полето за стойност {{key:Esc}} изчиства въведеното и връща към изгледа.

## Докато инструмент работи

| Клавиш | Действие |
|---|---|
| Цифра или един от `. , - ' " [ < * /` | Започва писане в полето за стойност |
| {{key:Enter}} | Прилага въведеното в полето за стойност |
| {{key:Right}} | Заключва към червената ос (натиснете отново, за да отключите) |
| {{key:Left}} | Заключва към зелената ос |
| {{key:Up}} | Заключва към синята ос |
| {{key:Down}} | Заключва успоредно на последния ръб, над който сте минали преди първото щракване |
| Задръжте {{key:Shift}} | Задържа посоката, към която сте прихванати, докато е натиснат |
| {{key:Ctrl}}, {{key:Mod}} или {{key:Alt}} (при {{ui:Move}}) | Превключва между преместване и копиране |

Заключванията със стрелки работят в {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} и {{ui:Tape}} (при измерване от точка), след първото щракване. {{ui:Push/pull}} винаги се движи по посоката на стената и няма заключвания. В {{ui:Rotate}} стрелковите клавиши показват съобщение „Заключено“ след първото щракване, но не променят завъртането.

## Стрелковите клавиши в други случаи

Когато никой инструмент не е по средата на нещо, стрелковите клавиши движат камерата:

| Клавиш | Действие |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Орбита |
| {{key:Shift}} със стрелка | Панорамиране |

## Мишка

| Действие | Какво прави |
|---|---|
| Щракване | Използва текущия инструмент |
| Натискане, плъзгане, отпускане | Същото като две щраквания (за инструменти за рисуване); избор с рамка (за {{ui:Select}}); изтрива по пътя (за {{ui:Eraser}}) |
| Двукратно щракване | {{ui:Select}}: стена с нейните ръбове, ръб с неговите стени, отваря група; празното пространство затваря групата. {{ui:Push/pull}}: повтаря последното разстояние |
| Тройно щракване | {{ui:Select}}: всичко свързано |
| {{key:Shift}} + щракване | {{ui:Select}}: включва и изключва от избора |
| {{key:Mod}} + щракване | {{ui:Select}}: добавя към избора |
| {{key:Shift}} + {{key:Mod}} + щракване | {{ui:Select}}: премахва от избора |
| Плъзгане със среден бутон | Орбита, с всеки инструмент |
| {{key:Shift}} + плъзгане със среден бутон | Панорамиране, с всеки инструмент |
| Плъзгане с десен бутон | Панорамиране, с всеки инструмент |
| Колелце | Мащабиране към курсора |

Няма меню с десен бутон.

## Тъчпад

Какво прави плъзгане с два пръста зависи от {{ui:Settings}} › {{ui:ModelCraft}} › Превъртане:

| Жест | Тъчпад (или изчислено) | Колелце на мишката |
|---|---|---|
| Плъзгане с два пръста | Орбита | Мащабиране към курсора |
| {{key:Shift}} + плъзгане с два пръста | Панорамиране | Мащабиране |
| Събиране или разтваряне на пръсти | Мащабиране към курсора | Мащабиране към курсора |
| Натискане с два пръста и плъзгане (задържан вторичен бутон) | Панорамиране | Панорамиране |

Вижте [Орбита, панорамиране и мащабиране](topic:orbit-pan-zoom#on-a-trackpad) и [Настройки на ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

|---|---|
| {{key:W}} или {{key:Space}} | {{ui:Select}} |
| {{key:L}} / {{key:B}} / {{key:C}} / {{key:N}} | {{ui:Line}} / {{ui:Rectangle}} / {{ui:Circle}} / {{ui:Polygon}} |
| {{key:E}} | {{ui:Push/pull}} (издърпване) |
| {{key:T}} | {{ui:Tape}} |
| {{key:D}} | {{ui:Dimension}} |
| {{key:G}} | Премества избраното веднага, от курсора |
| {{key:R}} | Завърта избраното около средата му (синята ос) |
| {{key:S}} | Мащабира избраното около средата му |
| {{key:X}} / {{key:Y}} / {{key:Z}} при преместване или завъртане | Заключва червената / зелената / синята ос (още веднъж – за отключване) |
| Щракване или {{key:Enter}} | Поставя го |
| {{key:Esc}} или десен бутон | Връща го обратно |
| {{key:Shift+D}} | Дублира и премества копието |
| {{key:X}} или {{key:Delete}} | Изтрива избраното |
| {{key:A}} / {{key:Alt+A}} | Избира всичко / нищо |

| {{key:Mod+G}} / {{key:Mod+Shift+G}} | Създаване на група / създаване на компонент |
| Numpad {{key:1}} / {{key:3}} / {{key:7}} | Изглед отпред / отдясно / отгоре ({{key:Mod}} за отзад / отляво / отдолу) |
| Numpad {{key:5}} | Перспектива включена или изключена |

| {{key:Shift+Tab}} | Прихващането включено или изключено |
| Плъзгане със среден бутон / с {{key:Shift}} / с {{key:Mod}} | Орбита / панорамиране / мащабиране |

Копиране, поставяне, отмяна, запазване и отваряне запазват клавишите, изброени по-горе. Въведените стойности, полето за стойност и {{ui:Push/pull}} работят еднакво в двата стила.

## Сензорен екран

| Жест | Действие |
|---|---|
| Докосване | Щракване с текущия инструмент |
| Двукратно докосване | Двукратно щракване |
| Натискане, плъзгане, отделяне | Същото като натискане, плъзгане и отпускане с мишка |
| Два пръста: събиране | Мащабиране |
| Два пръста: движение заедно | Панорамиране (Настройки › ModelCraft › Сензорен екран може да го направи Орбита) |
| Три пръста: движение заедно | Орбита (Панорамиране, когато два пръста завъртат) |
| Задържане на един пръст неподвижно | Завършва инструмента, като Enter; когато нищо не се случва, после плъзнете за орбита |
| Втори пръст по време на действие с един пръст | Отменя това действие |
| Инструментът {{ui:Orbit}}, после плъзгане с един пръст | Орбита |

За да въведете стойност на сензорен екран, докоснете полето за стойност долу, напишете и натиснете клавиша Enter (или Go) на клавиатурата.

## Къде се намира инструментът за преместване

{{ui:Move}} е инструментът {{key:M}}: изберете какво да преместите, щракнете базова точка, после втора точка или въведете разстояние. Вижте [Преместване, копиране и създаване на масиви](topic:move-copy).
