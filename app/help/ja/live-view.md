{{ui:書き出し}} › {{ui:ライブビュー}} を選ぶと、アプリの上にパネルが開き、リアルタイム表示でモデルが表示されます。モデルの場所と日付に基づく空と太陽、太陽の影、面に設定した見た目と素材、ライト、壁や床から反射した光が表示されます。操作に追従します。ビューを回転すると表示も回転し、モデルを変更すると少し遅れて変更が表示されます。何もアップロードされません。

## 開く

1. {{ui:書き出し}} › {{ui:ライブビュー}} を選びます。パネルが右下隅に開きます。
2. タイトルバーをドラッグして移動し、角を引っ張って大きくします。
3. {{ui:新しいウィンドウ}} を選ぶと、パネルが独立したウィンドウになり、2 つ目の画面に表示できます。{{ui:書き出し}} › {{ui:新しいウィンドウでライブビュー}} を選ぶと、すぐにそのウィンドウで開きます。ブラウザーがポップアップウィンドウをブロックしている場合は、パネルとして開きます。
4. {{ui:閉じる}} をクリックすると閉じます。

## 操作

| 操作 | 働き |
|---|---|
| {{ui:ビューに追従}} | オンにすると、ライブビューは ModelCraft のビューが向いている方向を表示します。ウォークすると、オフになります |
| {{ui:ウォーク}} | モデル内を歩きます（下記） |
| {{ui:重力}} | ウォーク中は、床に立ち、階段を上ります。オフにすると飛行します |
| {{ui:時刻}} | 時刻を 05:00 から 21:00 の間で設定します。ドラッグすると太陽が動きます |
| {{ui:月}} | 月を設定します（その月の 21 日）。冬と夏の太陽を確認できます |
| {{ui:品質}} | {{ui:このコンピューターに合わせる}}（[お使いのマシン](topic:your-machine)の性能に応じた設定）、または {{ui:低}}、{{ui:中}}、{{ui:高}} |

一番下の行には、ビューを描画するもの（WebGPU または WebGL 2）、品質、間接光が表示されます。

## モデル内を歩く

1. メインビューで立ちたい位置に向け、{{ui:ウォーク}} を選びます。ビューの視点の真下の床に立ち、身長は 1.6 m になります。
2. ライブビューをクリックしてから、{{key:W}} {{key:A}} {{key:S}} {{key:D}} または矢印キーを使います。{{key:Shift}} を押しながらだと走ります。ドラッグして周囲を見回します。
3. 40 cm までの段は上れます（階段）。それより高いものは壁です。壁では止まり、壁に沿って移動します。
4. {{ui:重力}} がオフの場合は飛行します。{{key:E}} で上昇、{{key:Q}} で下降します。
5. {{key:Esc}} でウォークを停止します。

## 植物、岩、人を散布

{{ui:散布}} は、ライブビューのバーにあり、横に散布パネルを開きます。散布セットは、添景ライブラリ（木、低木、草、花、岩、人、車）の項目を、モデルの一部に広げます。項目はライブビューでのみ描かれ、モデルのジオメトリにはならず、メインビューにも表示されません。

1. **面を埋める:** ModelCraft で面（または地形などのグループ）を選び、{{ui:選択範囲を埋める}} を選びます。セットがそれらを覆います。
2. **塗る:** {{ui:ペイント}} を選び、ライブビュー上でドラッグします。面を選択している場合は、その面にだけ塗られます。何も選択していない場合は、ブラシの下にある、地面を含むすべてのものに塗られます。{{ui:ブラシサイズ}} でブラシの大きさを設定し、{{ui:消しゴム}} で塗った点を消します。
3. 散布する項目にチェックを付けます。各項目の横の数字は重みです。3 と 1 なら、2 つ目の項目 1 個につき、1 つ目の項目を 3 個配置します。

| 操作 | 働き |
|---|---|
| {{ui:Per m²}} | 1 m² あたりに配置する項目の数 |
| {{ui:離す距離(m)}} | ほかのオブジェクトからこの距離より近くには配置しません。屋根やテーブルの下にも配置しません。0 にするとオフになります |
| {{ui:回転(°)}} | 各項目を鉛直軸のまわりにランダムに回転させる角度 |
| {{ui:最大傾斜(°)}} | 面がこれより急な場所には配置しません |
| {{ui:サイズ}} | 項目自身のサイズに対する倍率で、最小と最大のサイズを指定します |
| {{ui:高さの範囲(m)}} | これらの高さの間にのみ配置します（空欄は任意の高さ） |
| {{ui:面に合わせて傾ける}} | 0 では項目は垂直に立ちます。1 では斜面に対して直角に立てます |
| {{ui:シード}}、{{ui:シャッフル}} | 同じシードなら、いつも同じ散布になります。シャッフルで別の配置を選びます |

セットは .modelcraft ファイルに保存され、覆っている面を変更すると一緒に追従します。ライブビューが一度に描画する項目の最大数は、[お使いのマシン](topic:your-machine)のレベルで決まります: {{ui:プロセッサーのみ}} では 20 000、{{ui:グラフィックカード、基本}} では 100 000、{{ui:グラフィックカード、高}} では 100 万です。パネルには、密度が要求する数に対して、実際に配置された数が表示されます。上限に達した場合や、ほかのオブジェクトによって配置が妨げられた場合は、配置数が少なくなります。カメラに近い項目はそのままの形で描かれ、遠い項目は色付きの簡単な形で描かれます。

:::note
散布された項目は、ライブビュー（およびそのウォーク、パノラマ、スタンドアロンビューアー）に表示されます。画像をレンダリングではまだ描画されません。
:::

## 共有: パノラマ、ツアー、ビューアー、動画

{{ui:共有}} は、ライブビューのバーにあり、ライブビューからファイルを作成します。すべて、このコンピューター上で作成されます。何もアップロードされません。

| 選択 | 得られるもの |
|---|---|
| {{ui:360° パノラマ}} | ビューの位置（またはウォーク中の位置）からの 360° 画像。正距円筒図法の PNG で、パノラマビューアーやほとんどの写真サイトで開けます |
| {{ui:この地点をツアーに追加}}、次に {{ui:ツアーを保存}} | 各地点にパノラマがあり、そこから見える地点への矢印が付いた 1 つのウェブページ（間に壁があると矢印は隠れます） |
| {{ui:ビューアーを保存}} | このリアルタイム表示でモデルを表示する 1 つのウェブページ。回転、ウォーク、保存済みのシーンへのジャンプができます。WebGPU または WebGL 2 を備えたブラウザーで、フォルダー、USB メモリー、メールから、インストールもアカウントも不要でオフラインで開けます。インターネットから何も読み込みません |
| {{ui:経路の動画}} | タイムラインのカメラ経路（または保存済みのシーンを順番に）を、このリアルタイム表示で、ライブビューと同じサイズの動画にします。ブラウザーが作成できる場合は WebM または MP4、できない場合は連番の画像を ZIP にまとめます |

パノラマのサイズは品質に従い、{{ui:低}}、{{ui:中}}、{{ui:高}} のそれぞれで、幅 1024、2048、4096 ピクセルです。ビューアーファイルは、約 5 MB にモデルの容量を加えたものです。

:::note
ツアーとビューアーは、表示用に作られており、編集はできません。保存時点のモデルがそのまま保持されます。
:::

## 間接光

日当たりのよい壁から床に反射する光や、部屋の奥の暗い部分の光は、[レンダリングした画像](topic:render)と同じパストレーサーで計算されます。モデル内の点で小さなパノラマを描画し、すべてのプロセッサーコアでバックグラウンドで処理します。処理中は一番下の行に {{ui:間接光: 40 %}} と表示され、準備ができるとビューがその光を取り込みます。変更するたびに計算は最初からやり直されます。

:::note
これはライブビュー用の近似であり、レンダリングした画像ではありません。点と点の間の細かいディテールは、近くの点の間接光を受け取ります。完成した画像には、[画像をレンダリング](topic:render)を使ってください。
:::

## 明るさと色

ライブビューは、[画像をレンダリング](topic:render)と同じ明るさ、ホワイトバランス、コントラスト、表示変換（ACES、AgX、フィルミック、標準）を使用します。そちらで設定すると、ライブビューも追従します。

:::note
ブラウザーによって異なります。WebGPU に対応しているブラウザー（Windows、macOS、ChromeOS の ChromeとEdge、Safari 26）では、ライブビューは WebGPU を使用します。それ以外（Linux の多くのブラウザー、古い Apple システム）では WebGL 2 を使用し、見た目は同じです。
:::
