**モディファイア**は、メッシュ自体は変えずに、メッシュの表示を変えます。部品の半分だけをミラーして、その半分だけをモデリングできます。ボックスをサブディビジョンサーフェスで丸くして、ボックスの編集を続けられます。モディファイアは**スタック**に入り、上から下へ順番に働きます。見える、書き出す、印刷する、レンダリングするものは、オンになっているすべてのモディファイアが適用されたメッシュです。

## モディファイアを追加

1. メッシュを選択します。モデルワークスペースでは、その **モディファイア** セクションは {{ui:エンティティ情報}} にあります。メッシュワークスペースでは、右側のパネルにあります。
2. {{ui:モディファイアを追加…}} から 1 つ選びます。スタックの一番下に追加されます。
3. 名前の下で設定を変更します。長さには、値の入力欄と同じ値を使えます。そのため `600mm`、`2'6"`、`(6m)/4` のいずれも使えます。

すべての変更は元に戻す 1 回分です。{{key:Mod+Z}} で取り消せます。

## 各モディファイアのボタン

- チェックボックスで、オン・オフを切り替えます。
- 画面のボタンで、ビューでの表示・非表示を切り替えます（スタックには残ります）。
- カメラのボタンで、レンダリングした画像と動画での表示・非表示を切り替えます。そのため、モディファイアをレンダリング専用（またはビュー専用）にできます。
- 矢印でスタック内の位置を上下に動かします。順序は重要です。ミラーの後にサブディビジョンを行うと滑らかな継ぎ目になりますが、サブディビジョンの後にミラーを行うとそうはなりません。
- {{ui:適用}} は、形状をメッシュの一部にします。その上にあるモディファイアとこのモディファイアは、メッシュ自体に対して実行され、スタックから外れます。元に戻す 1 回分です。
- ×印で削除します。

## モディファイアの種類

| モディファイア | 働き |
| --- | --- |
| 尺度変更 | オブジェクトの原点を基準に、赤、緑、青のそれぞれの倍率で拡大・縮小します。グループやコンポーネントにも使えます。 |
| ミラー | メッシュの原点を通る赤、緑、青の軸で、ミラーコピーを追加し、両者が接する箇所でつなぎます。 |
| 配列 | 直線上（自身のサイズに指定した数を掛けた間隔と、固定の間隔）、軸の周り、またはモデル内の曲線に沿って、コピーを作成します。グループやコンポーネントは直線配列になります。 |
| サブディビジョンサーフェス | Catmull-Clark の細分化でメッシュを平滑化します。シャープなエッジはクリースとして保たれます。レンダリングでは、ビューよりも多くのレベルを使えます。 |
| ベベル | 指定した角度より鋭いすべてのエッジを丸くします。 |
| ソリッド化 | サーフェスに厚みを与え、縁を閉じます。 |
| ブーリアン | モデル内の別のオブジェクトと重なる部分を、切り取り、結合、または残します。どちらも閉じたソリッドである必要があります。 |
| 変位 | 滑らかなノイズで、サーフェスを内側または外側に動かします。同じシードなら、毎回同じでこぼこになります。 |
| ウェルド | 指定した距離より近い頂点を結合します。 |
| デシメート | 形状を最も変えない三角形から取り除き、一定の割合の三角形を残します。 |
| スムーズ | 頂点を隣接する頂点へ向けて緩和します。 |
| ラティス | ケージでメッシュを曲げます。ケージの点を動かすと、メッシュがそれに追従します。 |
| カーブ変形 | モデル内の曲線に沿って、赤、緑、青のいずれかの方向にメッシュを曲げます。 |
| シュリンクラップ | 各頂点を、別のオブジェクトの最も近い点へ移動させます。 |

## グループまたはコンポーネントの場合

グループやコンポーネントも、レシピを持つことができます。たとえば、ランプのシェードを、1 つのシェードの**尺度変更**と**配列**にできます。数値を変えると、ランプも変わります。

1. グループまたはコンポーネントを選択します。{{ui:エンティティ情報}} の **モディファイア** セクションに、スタックが表示されます（最初は空です）。
2. {{ui:モディファイアを追加…}} から {{ui:尺度変更}} または {{ui:配列}} を選びます。グループは、**元のもの（スタックで配置）**であるコンポーネントになります。元のものは残ります。編集すると、すべてのコピーがすぐに追従します。
3. 尺度変更では、赤、緑、青の倍率を指定します（`1, 1, 2` で高さが 2 倍になります）。配列では、コピーの数、結果の現在のサイズに対する割合の間隔、長さによる追加の間隔を指定します。

スタックは、元のものの軸を基準に、原点を中心に上から下へ働くため、順序が重要です。3 m 間隔で 3 つのコピーを配列してから、赤方向に 2 倍の尺度変更を行うと、コピーの間隔は 6 m になります。先に尺度変更を行ってから配列すると、間隔は 3 m のままです。チェックボックス、矢印、×印はメッシュと同じように働きます。ビューとカメラのボタン、および 1 つのモディファイアに対する適用は働きません。グループ上のスタックは 1 つのまとまりだからです。

- {{ui:ソースを編集}} は、元のものをその場で開きます。変更はすべてのコピーに表示されます。閉じると、元の位置に戻ります。
- {{ui:モディファイアーをベイク}} は、結果を単純なエッジと面にし、スタックを取り除きます。元に戻す 1 回分です。重なっているコピーは、別々のジオメトリのままです。ベイクは結合ではありません。
- コンポーネントのコピーは、同じレシピを共有します。{{ui:ユニークにする}} で、レシピを分けられます（元のものは共有されたままです）。
- スタックはファイルに保存され、コピーと貼り付け、および元に戻す操作でも引き継がれます。未使用項目を消去しても、元のものは残ります。モディファイアを扱えないプログラムでも、コピーは表示されます。
- ベイクするまで、結果はグループの中に入る、分解する、サイズ変更する、伸ばすといった操作ができません。次の変更で再構築されてしまうためです。各操作にその旨が表示されます。
- 上限は、モディファイア 32 個、コピー 1,000 個です。伸縮（ストレッチ）用に作られたコンポーネントとスタックは、まだ同じ定義を共有できません。

## サブディビジョンサーフェス

サブディビジョンは、Catmull-Clark によってメッシュを滑らかにします。すべての面が四角形の面に分割され、レベルごとに面数は 4 倍になります。2〜3 レベルのボックスで、すでに丸みのある形に見え、ボックスの編集を続けられます。

- **ビューのレベル**は、滑らかさを設定します。
- **レンダリングのレベル**は、レンダリングした画像と動画の滑らかさを設定します。レンダリングでは、ビューよりも多くのレベルを使えます。
- **レンダリングは真の滑らかなサーフェスで行う**は、レンダリングするメッシュの点を、レベルが近づく極限サーフェス上に配置します。そのため、2 レベルでも多くのレベルと同じくらい滑らかにレンダリングされます。
- **クリース**はエッジをシャープに保ちます。メッシュワークスペースでエッジを選択し、{{ui:クリース}} を使用します（1 はシャープなまま、0.5 は少し丸く、0 は滑らか）。[メッシュを編集](topic:mesh-edit)を参照してください。
- **大きなメッシュでビューのレベルを下げる**: 要求したレベルが、このコンピューターのビューで十分に扱えるよりも多くの面を作る場合、ビューはより低いレベルを表示し、その旨を示します。{{ui:適用}} は常にすべてのレベルを使います。面の上限は、{{ui:設定}} › レンダリング › お使いのマシン で、お使いのマシンの区分によって決まります。
- 開いた境界は、角を保ち、エッジの線上にとどまります。

## ラティスケージで曲げる

1. {{ui:ラティス}} モディファイアを追加し、{{ui:メッシュの周りにラティスケージを追加}} を押します。メッシュの周りに 3 × 3 × 3 の点のケージが表示され、ワイヤーで描かれます。
2. メッシュワークスペースでケージを開き（ダブルクリック）、その点を動かします。メッシュが滑らかに追従します。

:::tip
ケージも通常のメッシュなので、作業が終わったら、そのタグで非表示にしてください。
:::

## 大きなメッシュ

小さなスタックはすぐに計算されます。大きなものは、コンピューターのすべてのコアでバックグラウンドで計算されます。新しい結果ができるまで、ビューには前回の結果が表示され続けます。ブーリアンは、初めて使うときにソリッドモデラーを読み込みます。その間、ビューにその旨が一時的に表示されます。

## モディファイアでまだできないこと

- 頂点ごとのウェイト（メッシュに塗ったフォールオフ）は、変位、スムーズ、シュリンクラップではまだ使えません。
- プッシュ/プルのジオメトリ（グループとコンポーネント）では、尺度変更と直線配列以外のモディファイアは、先にメッシュに変換してください（{{ui:メッシュに変換}}）。グループでのミラー、放射状または曲線の配列、曲げ、テーパーは、今後対応します。
