これらは、ModelCraftの初期設定であるプッシュ/プルのキーです。もう1つの方式については、下の[モデラー方式のキー](topic:keyboard#modeler-keys)と[ModelCraftの設定](topic:settings)を参照してください。

ショートカットは、3Dビューまたはツールバーボタンにフォーカスがあるときに機能します。パネルの欄に入力した直後、または{{ui:スタイル}}のリストを変更した直後は、先に3Dビューをクリックしてください。そうしないと、キーがその欄に送られてしまいます。各コンピューターでのキーの表記方法については、[キー、マウス、トラックパッド](common:keys)を参照してください。

## Esc

{{key:Esc}}を押すたびに、1段階ずつ戻ります:

1. ツールの途中の操作（描画中の線、プッシュ/プル、移動）を取り消します。すべて元に戻ります。
2. {{ui:選択}}に切り替えます。
3. 選択を解除します。
4. 編集中のグループを閉じます。

また、再生中のシーンを停止します。値ボックスでは、{{key:Esc}}で入力した内容を消去し、ビューに戻ります。

## ツールの動作中

| キー | 機能 |
|---|---|
| 数字、または `. , - ' " [ < * /` のいずれか | 値ボックスへの入力を開始 |
| {{key:Enter}} | 値ボックスに入力した内容を適用 |
| {{key:Right}} | 赤軸にロック（もう一度押すとロック解除） |
| {{key:Left}} | 緑軸にロック（もう一度押すとロック解除） |
| {{key:Up}} | 青軸にロック（もう一度押すとロック解除） |
| {{key:Down}} | 最初のクリック前にホバーした最後のエッジに平行にロック |
| {{key:Shift}}を押し続ける | 押している間、スナップしている方向を保持 |
| {{key:Ctrl}}、{{key:Mod}}、または{{key:Alt}}（移動） | 移動とコピーを切り替え |

矢印キーによるロックは、{{ui:ライン}}、{{ui:長方形}}、{{ui:円}}、{{ui:多角形}}、{{ui:移動}}、{{ui:尺度変更}}、{{ui:メジャー}}（点から計測するとき）で、最初のクリック後に機能します。{{ui:プッシュ/プル}}は常に面の方向に沿って移動し、ロックはありません。{{ui:回転}}では、最初のクリック後に矢印キーを押すと「ロック済み」のメッセージが表示されますが、回転量は変わりません。

## ほかの場合の矢印キー

ツールが操作中でない場合、矢印キーはカメラを動かします:

| キー | 機能 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | オービット |
| 矢印と{{key:Shift}} | パン |

## マウス

| 操作 | 機能 |
|---|---|
| クリック | 現在のツールを使用 |
| 押す、ドラッグ、離す | 2回のクリックと同じ（描画ツールの場合）。窓選択（{{ui:選択}}の場合）。通過した部分を削除（{{ui:消しゴム}}の場合） |
| ダブルクリック | {{ui:選択}}: 面とそのエッジ、エッジとその面を選択し、グループを開きます。何もない場所ではグループを閉じます。{{ui:プッシュ/プル}}: 直前の距離を繰り返します |
| トリプルクリック | {{ui:選択}}: つながっているものすべて |
| {{key:Shift}} + クリック | {{ui:選択}}: 選択に追加、または選択から除外を切り替えます |
| {{key:Mod}} + クリック | {{ui:選択}}: 選択に追加 |
| {{key:Shift}} + {{key:Mod}} + クリック | {{ui:選択}}: 選択から除外 |
| 中ボタンのドラッグ | 任意のツールでオービット |
| {{key:Shift}} + 中ボタンのドラッグ | 任意のツールでパン |
| 右ボタンのドラッグ | 任意のツールでパン |
| ホイール | ポインターの方向にズーム |

右クリックメニューはありません。

## トラックパッド

2本指スワイプの動作は、{{ui:設定}} › {{ui:ModelCraft}} › スクロールの設定によって異なります:

| ジェスチャー | トラックパッド（または推定） | マウスホイール |
|---|---|---|
| 2本指スワイプ | オービット | ポインターの方向にズーム |
| {{key:Shift}} + 2本指スワイプ | パン | ズーム |
| ピンチ | ポインターの方向にズーム | ポインターの方向にズーム |
| 2本指で押してドラッグ（副クリックを押したまま） | パン | パン |

[オービット、パン、ズーム](topic:orbit-pan-zoom#on-a-trackpad)と[ModelCraftの設定](topic:settings#scrolling-mouse-wheel-or-trackpad)を参照してください。

| {{key:T}} | {{ui:メジャー}}（計測） |
| {{key:D}} | {{ui:寸法}} |
| {{key:G}} | 選択を、ポインターから直ちに移動 |
| {{key:R}} | 選択を、その中央（青軸）を中心に回転 |
| {{key:S}} | 選択を、その中央を中心に尺度変更 |
| 移動または回転中の{{key:X}} / {{key:Y}} / {{key:Z}} | 赤 / 緑 / 青の軸にロック（もう一度押すとロック解除） |
| クリックまたは{{key:Enter}} | 配置する |
| {{key:Esc}}または右クリック | 元の位置に戻す |
| {{key:Shift+D}} | 複製して、コピーを移動 |
| {{key:X}}または{{key:Delete}} | 選択を削除 |

| テンキーの{{key:1}} / {{key:3}} / {{key:7}} | 正面 / 右 / 上のビュー（{{key:Mod}}を押すと背面 / 左 / 下） |

## タッチスクリーン

| ジェスチャー | 機能 |
|---|---|
| タップ | 現在のツールでクリック |
| ダブルタップ | ダブルクリック |
| 押す、ドラッグ、指を離す | マウスでの押す、ドラッグ、離すと同じ |
| 2本指: ピンチ | ズーム |
| 2本指: 一緒に動かす | パン（設定 › ModelCraft › タッチスクリーンで、オービットに変更可能） |
| 3本指: 一緒に動かす | オービット（2本指がオービットの場合は、パン） |
| 1本指を静止させて保持 | Enterと同様にツールを完了します。何も動作していない場合は、ドラッグしてオービットします |
| 1本指の操作中に2本目の指 | その操作を取り消します |
| {{ui:オービット}}ツールで、1本指をドラッグ | オービット |

タッチスクリーンで値を入力するには、下部の値ボックスをタップし、入力して、キーボードの Enter（または Go）キーを押します。

## 移動の場所

移動は{{ui:移動}}ツール（キー{{key:M}}）にあります。移動するものを選び、基点をクリックしてから、2点目をクリックするか、距離を入力します。[移動、コピー、配列の作成](topic:move-copy)を参照してください。
