SketchUpでモデリングしてきた場合、ModelCraftは使い慣れた感覚になるでしょう。面とプッシュ/プルの考え方、同じツールキー、クリックせずに入力できる値ボックス、赤、緑、青の軸による推定、グループ、コンポーネント、アウトライナー、エンティティ情報、シーンが同じです。このページでは、そのまま対応するものと、より重要な、対応しないものを示します。

## 引き継がれる習慣

| 慣れている操作 | ModelCraftでは |
|---|---|
| Spaceで選択、Lで線、Rで長方形、Cで円 | 同じです: {{key:Space}}、{{key:L}}、{{key:R}}、{{key:C}} |
| Pでプッシュ/プル、Mで移動、Qで回転、Sで拡大縮小、Eで消しゴム、Tで巻尺 | 同じです: {{key:P}}、{{key:M}}、{{key:Q}}、{{key:S}}、{{key:E}}、{{key:T}} |
| Oで軌道、Hでパン、Zでズーム、Shift+Zで範囲ズーム | 同じです: {{key:O}}、{{key:H}}、{{key:Z}}、{{key:Shift+Z}} |
| Gでコンポーネントを作成 | 同じです: {{key:G}}。{{key:Shift+G}}でグループを作成 |
| クリックせずに計測ボックスへ入力 | 同じです。下部の値ボックスに入力し、{{key:Enter}}を押します |
| 長方形に`4m,3m`、辺に`12s`と入力 | 同じです |
| 移動コピーの後に`3x`または`/3`と入力 | 同じです。`*3`も使えます |
| 点やオフセットに`[x,y,z]`または`<dx,dy,dz>`と入力 | 同じです |
| インチのモデルで数値だけを入力してインチを得る | 同じです |
| 中ボタンのドラッグで軌道、Shift+中ボタンのドラッグでパン、ホイールでカーソル位置にズーム | 同じです |
| プッシュ/プルでダブルクリックして距離を繰り返す | 同じです |
| 矢印キーで赤、緑、青、平行をロック | 同じです: {{key:Right}}で赤、{{key:Left}}で緑、{{key:Up}}で青、{{key:Down}}で平行 |
| Shiftを押して推定をロック | 同じです |
| 移動しながらコピーするCtrl(Macでは Option) | {{key:Ctrl}}、{{key:Mod}}、または{{key:Alt}}で、どのコンピューターでも同じです |
| Shiftで切り替え、Ctrlで追加、Shift+Ctrlで選択から削除 | 同じキーです。Macでは、Ctrlと書かれている箇所で{{key:Mod}}を使います |
| 左から右へのウィンドウ選択、右から左への交差選択 | 同じです |

## 戸惑いやすい違い

### 保存はダウンロードです

開いたファイルを上書きする保存はなく、名前を指定する名前を付けて保存ダイアログもなく、自動保存もバックアップファイルもありません。{{ui:保存}}({{key:Mod+S}})は毎回、新しい`.modelcraft`ファイルをダウンロードします。通常はダウンロードフォルダーに保存されます。こまめに保存し、ファイルの名前変更や移動は自分で行ってください。[ファイルの開く、保存、読み込み、書き出し](topic:files)を参照してください。

### .skpファイルは読み込めますが、保存はできません

{{ui:読み込み}}は、ModelCraft独自のリーダーを使って、ページ内でSketchUpファイルを読み込みます。グループ、コンポーネント、色、面のテクスチャ、タグ、ソフトエッジが読み込まれます。[詳しいファイル形式](topic:formats#skp-files)を参照してください。ModelCraftでは`.skp`を保存できません。元に戻すには、ModelCraftからColladaを書き出し、SketchUpで読み込んでください。

### 右クリックメニューはありません

右ドラッグでパンします。右クリックは何もしません。コンテキストメニューにあるはずのコマンドは、{{ui:エンティティ情報}}({{ui:面を反転}}、{{ui:編集}}、{{ui:分解}}、{{ui:ユニークにする}}、{{ui:コンポーネントを作成}})と、ツールバーの{{ui:整理}}グループにあります。

### 単位はステータスバーにあります

モデル情報やテンプレートの選択はありません。単位のピッカーは右下にあります。新しいモデルは、ブラウザーの言語設定に応じて、米国ではフィートとインチ、その他の地域ではミリメートルで始まります。小数点には必ずピリオドを使います: `2.5m`。`2,5m`は使えません。カンマは常に値の区切りに使われるためです。

### 塗りには専用のマテリアルがあります

{{ui:ペイント}}({{key:B}})は、単色と、{{ui:マテリアル}}セクションのマテリアル(レンガ、サイディング、屋根材、木材、石材など)を塗ります。ModelCraftが描画します。自分の画像をマテリアルとして読み込むことは、まだできません。読み込んだファイルに含まれるテクスチャは残ります。[色とマテリアルで塗る](topic:paint)を参照してください。

### 拡大縮小は均一で、グリップはありません

{{ui:尺度変更}}では、グリップ付きのボックスは表示されません。そのまま残す点(基準点)をクリックし、次に新しいサイズまたは入力した倍率を指定します。拡大縮小は常に、すべての方向に均等に行われます。1方向だけ引き伸ばすには、プッシュ/プルするか、面を移動するか、{{ui:エンティティ情報}}でグループの幅、奥行き、高さを入力し直すか、[寸法でサイズ変更](topic:dimensions)します。

### 回転は、クリックした位置から平面を決めます

{{ui:回転}}では、矢印キーで平面を選ぶ間に面へ吸着する分度器はありません。面の中心をクリックすると、その面の平面内で回転します。地面をクリックすると、垂直方向の軸を中心に回転します。矢印キーは、最初のクリックの前にビューを軌道移動します。

### 通過した点からの推定

ModelCraftは、**開始点**から軸方向にスナップし、ポインターの下にある点、辺、面にもスナップします。単にホバーしただけの点からの方向は追跡しません(点線で示される「点からの」推定)。遠くの角に揃えるには、矢印キーで軸をロックし、その角にホバーします。すると、ロックされた点がその角に揃うように移動します。または[ガイド](topic:guides-measure)を配置します。

### 平行は、開始前に通過した辺を使います

平行と垂直の推定は、**最初のクリックの前**にポインターが最後に横切った辺を使います。作図中にホバーした辺は使いません。[推定とスナップ](topic:inference#parallel-and-perpendicular)を参照してください。

### グループのコピーはリンクされます

{{ui:移動}}でグループをコピーすると、同じグループの2つ目の配置が作られるため、コンポーネントと同様に、一方を編集すると両方が変わります。SketchUpではグループは独立しています。[トラブルシューティング](topic:troubleshooting#editing-one-group-changed-another)を参照してください。

### Spaceではパンしません

{{key:Space}}は、SketchUpと同じく{{ui:選択}}を選びます。他の一部のWebアプリではSpaceを押しながらパンしますが、ここでは行いません。代わりに右ドラッグでパンします。

### 2本指スクロールはズームします

トラックパッドでは、{{ui:設定}} › ModelCraft › スクロールを トラックパッド に設定します。2本指で軌道移動し、{{key:Shift}}と2本指でパンし、ピンチでズームします。[軌道、パン、ズーム](topic:orbit-pan-zoom#on-a-trackpad)を参照してください。

Blenderのキーに慣れている場合は、{{ui:モデラー}}のメニュースタイルを選べます。{{key:G}}、{{key:R}}、{{key:S}}は選択範囲に対して一度に作用し、{{key:E}}は押し出し(プッシュ/プル)を行い、{{key:Shift+D}}は複製します。ヘッダーのメニューバー(ファイル、編集、ビュー、選択、追加、オブジェクト、メッシュ)が、ツールバーの代わりになります。SketchUpから移行する場合は、{{ui:プッシュ/プル}}スタイルで、同じツールキーに対応する専用のメニューバーが表示されます。[メニュー、キー、マウス](topic:menus-keys-and-mouse)を参照してください。

### 押し込まれたソリッドは切り抜きません

プッシュ/プルは、同じオブジェクト内で、その後ろの面を貫通して切り抜きます。しかし、互いに押し込まれた2つの別々のソリッドは交差しません。面の交差やソリッドツールはありません。

### 不足しているもの

フリーハンド、トリム、分割、外側シェル、独自の画像マテリアル、拡張機能、シート用のレイアウトツールは、このビルドにはありません。代わりにすべきことは、[まだ作成されていないもの](topic:not-built-yet)に記載されています。

## ブラウザーが保持するショートカット

ModelCraftはブラウザーで動作するため、一部のショートカットはアプリではなくブラウザーのものです。{{key:Mod+N}}は新しいブラウザーウィンドウを開き({{ui:新規}}を使ってください)、{{key:Mod+W}}はタブを閉じます。保存していない変更がある場合、ブラウザーは閉じる前に確認します。[キー、マウス、トラックパッド](common:keys#shortcuts-the-browser-keeps)を参照してください。
