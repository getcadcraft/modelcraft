{{ui:選択}}（{{key:Space}}）は、ModelCraftが最初に使うツールで、{{key:Esc}}を押すといつでもこのツールに戻ります。選択されたものは青色に変わり、右側の{{ui:エンティティ情報}}に、その内容が表示されます。

## クリック

| 操作 | 選択されるもの |
|---|---|
| 面またはエッジをクリック | その面またはエッジ |
| グループまたはコンポーネントをクリック | グループまたはコンポーネント全体 |
| 面をダブルクリック | その面とそのエッジ |
| エッジをダブルクリック | そのエッジと、その両側の面 |
| グループまたはコンポーネントをダブルクリック | 編集のために開きます（[グループとコンポーネント](topic:groups-components)を参照） |
| 面またはエッジをトリプルクリック | それに接続されているすべて: オブジェクト全体 |
| 何もない空間をクリック | 何も選択されません（選択を解除） |
| グループの編集中に何もない空間をダブルクリック | グループを閉じます |

エッジは面よりも選択しやすくなっています。ポインターがエッジから数ピクセル以内にあると、クリックしたときにエッジが選択されます。

## 枠をドラッグ

- **左から右**へドラッグすると、実線の枠が表示され、**窓選択**になります。枠内に完全に含まれるものだけが選択されます。
- **右から左**へドラッグすると、破線の枠が表示され、**交差選択**になります。枠に触れたものはすべて選択され、面は枠がその面の内側に完全に収まったときに選択されます。

グループまたはコンポーネントは1つのものとして扱われます。窓選択では全体が枠内に収まる必要があり、交差選択では枠に触れるだけで選択されます。

## 追加と解除

クリックまたはドラッグするときに、キーを押したままにします:

| キー | 動作 |
|---|---|
| {{key:Shift}} | 切り替え: 未選択のものを追加し、選択済みのものを解除します |
| {{key:Mod}} | 追加します |
| {{key:Shift}}と{{key:Mod}}を同時に | 解除します |

モデル内のすべて（編集中のグループ内のすべて）を選択するには、{{key:Mod+A}}を押します。

## 選択の解除

{{key:Esc}}を押す（ツールが{{ui:選択}}のとき）か、何もない空間をクリックします。

## 選択したものを削除

{{key:Delete}}または{{key:Backspace}}を押します。選択されている面、エッジ、グループ、ガイドは1回の操作で削除されます。{{key:Mod+Z}}で元に戻せます。

エッジを削除すると、そのエッジを必要とする面も削除されます。ただし、そのエッジが同一平面上の2つの面を分けていただけの場合は、2つの面が1つにつながります。面を削除した場合は、エッジは残ります。[消去とクリーンアップ](topic:erase)を参照してください。

## グループ内の選択

グループをクリックすると、グループ全体が選択されます。グループ内の面を選択するには、グループをダブルクリックして開き、その後クリックします。グループを開いている間は、クリックはグループ内のものだけに有効になり、それ以外は薄く表示されます。何も選択されていない状態で{{key:Esc}}を押すか、何もない空間をダブルクリックすると閉じます。

左側の{{ui:アウトライナー}}は、名前でグループとコンポーネントを選択します。他のものの後ろに隠れている場合に便利です。
