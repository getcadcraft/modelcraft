## 学べること

AIアシスタント(または自分で書いたスクリプト)にModelCraftを操作させる方法と、そのアシスタントに何を触らせるかを決める方法を説明します。

ModelCraftは**独自のAIを持たず**、どこにも何も送信しません。アシスタントは自分で用意します。Model Context Protocol (MCP)に対応したプログラムであれば何でも使えます。ModelCraftはそのアシスタントにツールを提供するだけで、どのツールを使わせるかはあなたが選びます。

## 有効にする

1. {{ui:設定}}(アプリバーの歯車、または {{key:Mod+,}})を開き、{{ui:ModelCraft}}タブに移動します。
2. {{ui:アシスタント}}の下で、**AIアシスタントとスクリプトにModelCraftの使用を許可**にチェックを入れます。これをオンにするまではオフのままです。
3. 許可する操作を選びます。**読み取り**は最初からオンになっています。**編集**、**保存**、**書き出し**は必要なときだけチェックしてください。

許可でチェックしていないツールはアシスタントに提示されません。それでも要求された場合、ModelCraftはそれを拒否し、アクティビティログに記録します。スイッチをオフにすると、すべての接続が直ちに終了します。{{ui:ModelCraftの設定をリセット}}でもオフになります。

## アシスタントを接続する

アシスタントは、お使いのコンピューター上の**CadCraft Studio**を通じて接続します。Studioは、このコンピューターからしかアクセスできない小さなサーバーを起動します。このサーバーは、Studioの起動のたびに作られるトークンで保護されます。Studioで{{ui:アシスタントを接続}}を選び、アドレスとトークンをアシスタントにコピーします(貼り付ける正確な設定はStudioに表示されます)。トークンは決して共有しないでください。

:::note
ブラウザーのタブではアシスタント用の接続を開けません。ブラウザー版のアプリでは、お使いのコンピューターのCadCraft Studioを使うまでスイッチは効果がありません。
:::

## 主導権はあなたにあります

- **すべての変更は元に戻す1回分になります。** アシスタントの名前付きで表示されます(例: 「Assistant: box」)。{{key:Mod+Z}}でアシスタントの直前の変更を一括で取り消します。
- **接続されているかがわかります。** アプリバーのボタンは、接続中のアシスタントの名前を表示します。クリックすると、そのアシスタントに許可されている操作を確認したり、**切断**したりできます。
- **アクティビティ。** {{ui:設定}} › {{ui:ModelCraft}} › {{ui:アシスタント}} › {{ui:アクティビティ}}に、すべての呼び出しが一覧表示されます(いつ、どのツール、完了したか拒否されたか)。{{ui:ログを保存}}で控えを保存できます。

## アシスタントが要求できる操作

| ツール | 許可 | 内容 |
|---|---|---|
| `app_info`, `model_describe` | 読み取り | モデルの単位、サイズ、すべてのグループとコンポーネントとその位置、閉じたソリッドかどうか、体積 |
| `view_screenshot` | 読み取り | 表示されている3Dビューの画像 |
| `box_add`, `cylinder_add` | 編集 | ボックスまたは円柱を、あなたまたはアシスタントが指定した位置とサイズで新しいグループとして追加(「3m」「10'」またはモデルの単位の数値) |
| `instance_move`, `instances_erase` | 編集 | グループとコンポーネントを移動または削除 |
| `faces_list`, `materials_list` | 読み取り | グループまたは独立したジオメトリの面(それぞれの向き、面積、中心)。塗ることができるマテリアルと色 |
| `push_pull` | 編集 | {{ui:プッシュ/プル}}と同じように面を押し出す、または引き込む |
| `paint` | 編集 | 面、またはグループ全体を色またはマテリアルで塗る |
| `group_make` | 編集 | 独立した面とグループから、グループまたはコンポーネントを作成 |
| `scene_add`, `scene_show` | 編集 | 表示をシーンとして保存。保存済みのシーンに移動 |
| `mesh_add` | 編集 | 開始点となるメッシュオブジェクト(立方体、球、円柱 …)。メッシュワークスペースで追加されるのと同じ |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | 読み取り / 編集 | メッシュのモディファイアスタック: ミラー、配列、サブディビジョン、ベベルなど。どれも確定的には適用されません |
| `usd_export` | 書き出し | モデルをOpenUSD(.usda、.usdc、.usdz)として。USDとして保存するのと同じ形式([USD](topic:usd))。Studioで許可したフォルダーに、なければダウンロードとして |
| `render_still` | 書き出し | ビューまたは保存済みシーンのレンダリング画像。{{ui:画像をレンダリング…}}ダイアログの{{ui:レンダリング}}ボタンと同じ。他の指定がない限り、レンダリング設定を使用(シーンのプリセット: 外観、内観、断面、夜、自動。高速または高品質、サイズ、サンプル数、空)。アシスタントが確認できるPNG、またはStudioで許可したフォルダーのPNG、EXR、レンダーファイル([画像をレンダリング](topic:render)) |
| `render_queue` | 書き出し | 高品質の画像を{{ui:レンダーキュー}}(ビューまたは保存済みシーン)に追加し、キューを実行。完成した画像は許可したフォルダーに保存されるか、ダイアログの{{ui:レンダーキュー}}に残ります。WebGPUが必要 |
| `link_push` | 編集 | 別のプログラムからリンクされたモデルを更新([.3dmモデルをライブで維持](topic:live-3dm-link)を参照) |
| `link_status` | 読み取り | リンクされたモデルがまだあるか、最後にいつ更新されたかを表示 |
| `undo` | 編集 | アシスタント自身の操作を取り消す |

アシスタントが作成したソリッドはグループとして追加されるため、あなたが描いたものと結合されることはありません。モデルを保存するツールはありません。保存はあなたが行います。書き出しやレンダリングには**書き出し**のチェックが必要です。レンダリングはモデルを変更しません。保存済みのシーンをレンダリングすると、{{ui:シーン}}と同じようにビューがそのシーンに移動します。

## 問題が起きたとき

- **アシスタントにModelCraftのツールが表示されない:** このウィンドウでスイッチがオンになっていること、およびこのウィンドウがStudioで開かれていることを確認してください。
- **「編集の許可が必要です」:** {{ui:アシスタント}}の下で**編集**にチェックを入れてから、もう一度依頼してください。
- **「401」または「token」のエラー:** トークンが変わりました(Studioの再起動、または{{ui:新しいトークン}})。新しいトークンをアシスタントの設定にコピーしてください。
