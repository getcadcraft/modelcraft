ModelCraft は初期段階のビルドです。このページでは、まだ対応していない機能と、今日その作業を行うための最も近い方法を示します。探さずに済むようにまとめています。

## 作図ツール

| まだ未対応 | 今日の代替手順 |
|---|---|
| フリーハンド描画 | {{ui:曲線}} で点をクリックします |
| 描画後の円弧または円の分割数の変更 | 削除し、`24s` と入力してから描き直します |
| [3D テキスト](topic:text3d) の書体の選択、または配置後の文字の編集 | 削除し、テキストを追加し直します |
| 角度寸法への入力による角度の変更、または円の寸法からの円柱のサイズ変更 | {{ui:回転}} で辺を回転します。{{ui:尺度変更}} で円柱を拡大縮小します |
| 書き出したモデルファイル内の寸法 | 寸法は、ビューの画像、印刷物、PDF に表示されます。モデルファイルにはジオメトリのみが含まれます |
| トリム、分割、外側シェル | [ユニオン、カット、交差](topic:solids)で閉じたグループを作成するか、[面を交差](topic:intersect)してから不要なものを削除します |
| 矢印キーによる回転軸の選択 | 軸が向くべき方向を向いた面上で、{{ui:回転}} の中心をクリックします |
| 一度に複数の推論でのロック | 矢印キーで一方向をロックし、その後で点にスナップします |
| 斜面に沿ったサイズ変更、または角ではない寸法の端からのサイズ変更 | 寸法を 2 つの角、辺、または赤・緑・青の軸に沿って配置します |

## パフォーマンス

元に戻す操作は、各ステップのモデルのコピーを保持します（[メッシュ](topic:meshes)は変更された部分のみを保持します）。そのため、プッシュ/プルのジオメトリを大量に読み込むと、すべての編集が遅くなります。読み込むものは軽くし、保存して開き直すと履歴が消去されます。

## アプリとプラットフォーム

- **デスクトップ:** ModelCraft は Mac、Windows、Linux のブラウザーで動作し、また、8 つのアプリをすべて 1 つのインストールに含むデスクトップアプリ CadCraft Studio でも動作します。Android では、CadCraft Studio を getcadcraft.com/download の APK からインストールします。iPad および iPhone 向けのビルドはまだありません。
- **タッチ:** 指のジェスチャーについては[オービット、パン、ズーム](topic:orbit-pan-zoom)を参照してください。ペンの筆圧は[スカルプト](topic:sculpt)でブラシを設定します。それ以外では、筆圧とペンの傾きは使用されません。
- **シート:** ModelCraft は[1 ページに 1 つのビューを印刷](topic:export-model#print-the-view-or-save-it-as-a-pdf)します。複数のビューや表題欄を持つシートレイアウトはありません。縮尺どおりの図面には、CadCraft と互換性のある DWG/DXF に書き出します。
