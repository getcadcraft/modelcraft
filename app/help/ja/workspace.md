上から下へ。アプリバー、ツールバー、3つの列 (左のパネル、3Dビュー、右のパネル)、ステータスバーの順です。

## アプリバー

最上部の細いバーは、CadCraftのすべてのアプリに共通です。アプリ名とバージョン、{{ui:ModelCraftについて}}、画面モードのボタン、{{ui:ペーパー}} / {{ui:モデル}}の切り替えがあります。

- {{ui:ペーパー}}は明るいテーマ、{{ui:モデル}}は暗いテーマです。3Dビューの色もそれに合わせて変わりますが、モデルは変わりません。
- 画面モードのボタン (最初は{{ui:全画面表示}}と表示) と{{key:Ctrl+Shift+F}}で、通常、全画面表示、バーを隠した全画面表示の3つのモードを順に切り替えます。バーを隠しているときは、画面の上端にポインターを合わせる (またはタップする) と、バーが戻ります。{{key:Esc}}キーで全画面表示を終了します。

:::note
{{key:Ctrl+Shift+F}}は、Macを含むすべてのコンピューターでControlキーを使います。ブラウザーに全画面表示がないiPhoneでは、ボタンはバーの表示と非表示を切り替えるだけです。
:::

## ツールバー

ツールバーは、ラベル付きのグループに分かれています。ボタンにポインターを合わせると、名前とキーが表示されます。

左端の{{ui:ワークスペース}}リストは、ツールバーと右パネルの用途を切り替えます。{{ui:モデル}} (プッシュ/プル式モデリング。以下で説明します)、{{ui:メッシュ}} ([メッシュを編集する](topic:mesh-edit))、{{ui:曲線}} ([曲線オブジェクト](topic:curves))、{{ui:UV}} ([UVを配置する](topic:uv))、{{ui:スカルプト}} ([スカルプトする](topic:sculpt))、{{ui:シェーディング}} ([ノードで作るマテリアル](topic:shading))、{{ui:アニメーション}} ([アニメーションを付ける](topic:animate))、{{ui:レンダリング}} ([ビューでレンダリングする](topic:render#render-in-the-view)) です。

| グループ | ボタン |
|---|---|
| ファイル | {{ui:新規}}、{{ui:開く}}、{{ui:保存}}、{{ui:読み込み}}、{{ui:書き出し}} (フォーマットのメニュー) |
| 作図 | {{ui:ライン}} ({{key:L}})、{{ui:長方形}} ({{key:R}})、{{ui:円}} ({{key:C}})、{{ui:多角形}} ({{key:N}}) |
| 修正 | {{ui:選択}} ({{key:Space}})、{{ui:プッシュ/プル}} ({{key:P}})、{{ui:移動}} ({{key:M}})、{{ui:回転}} ({{key:Q}})、{{ui:尺度変更}} ({{key:S}})、{{ui:消しゴム}} ({{key:E}})、{{ui:メジャー}} ({{key:T}}) |
| 整理 | {{ui:コンポーネント}} ({{key:G}})、{{ui:グループ}} ({{key:Shift+G}})、{{ui:分解}} |
| 編集 | {{ui:元に戻す}} ({{key:Mod+Z}})、{{ui:やり直し}} ({{key:Mod+Y}})、{{ui:コピー}} ({{key:Mod+C}})、{{ui:貼り付け}} ({{key:Mod+V}})、{{ui:その他}} (メニュー: 切り取り、コピー、貼り付け、同じ位置に貼り付け {{key:Mod+Shift+V}}、複製 {{key:Mod+D}}、削除、すべて選択、選択解除、キースタイル) |
| カメラ | {{ui:オービット}} ({{key:O}})、{{ui:パン}} ({{key:H}})、{{ui:ズーム}} ({{key:Z}})、{{ui:範囲}} ({{key:Shift+Z}})、{{ui:ビュー}} (メニュー) |

表示されるキーはプッシュ/プル式のものです。[ModelCraftの設定](topic:settings)でモデラー式を選ぶと、ツールチップにはそちらのキーが表示されます。使用中のツールは押された状態で表示されます。画面幅が狭いと、ツールバーは横にスクロールします。

{{ui:ビュー}}メニューには、モデルに合わせて表示される{{ui:等角}}、{{ui:上}}、{{ui:前}}、{{ui:右}}、{{ui:後}}、{{ui:左}}、{{ui:下}}と、透視投影と平行投影を切り替える{{ui:パースペクティブ}}があります。

## 3Dビュー

画面の中央です。赤、緑、青の線は軸です。赤と緑は地面の上にあり、青は上を向き、**北は緑の軸**です。それらが交わる点が原点です。

- 開始時には、「モデリングを始める」というカードに、最初に使うキーが数個並びます。作図ツールを選ぶか、ビューをクリックすると消えます。
- ツールの動作中、ビューには**推定マーカー**が表示されます。ポインターがスナップする位置に出る小さな色付きの図形です (端点は緑の円、中点はシアンの円、エッジ上は赤い四角、面上は青いひし形)。[推定とスナップ](topic:inference)を参照してください。
- 選択したものは青くなります。裏側から見た面は青みがかった灰色です。
- グループを開いて編集すると、その外側のものは薄くなり、軸はグループ自身の軸に移ります。
- モデルにシーンがあると、ビューの上部にシーンのタブが並びます。
- ファイルをビューのどこにでもドロップすると、開くか読み込みます。

## 左のパネル

**{{ui:アウトライナー}}**には、モデル内のグループとコンポーネントが、モデルでの入れ子の構造のまま一覧されます。複数回使われているコンポーネントには、「Window (4)」のように個数が表示されます。

- 名前をクリックすると選択され、ダブルクリックすると編集のために開きます。
- **名前で検索** (グループが2つ以上になると表示) は、名前が一致する行と、それを含むグループだけを表示します。{{key:Esc}}キーで解除します。
- 行の端の**目**のアイコンは、そのグループまたはコンポーネントを非表示/表示にします ({{ui:編集}} › {{ui:その他}} › {{ui:非表示}}と同じです)。タグのアイコンは、[タグ](topic:tags)によって非表示になっていることを示します。
- **その場で名前を変更:** 行をクリックして{{key:F2}}キーを押し、入力して{{key:Enter}}キーを押します ({{key:Esc}}キーなら元の名前のままです)。
- **行をドラッグ**して、別のグループの行の中央にドロップするとそのグループの内側に移動し、行の上端または下端にドロップするとその行の直前または直後に移動し、{{ui:アウトライナー}}の見出しにドロップすると最上位に移動します。モデル内の位置は変わらず、色、タグ、名前も維持されます。グループを自分自身の内側に入れることはできません。各移動は、元に戻す操作の1ステップです。[アウトライナーで並べ替える](topic:groups-components#rearrange-in-the-outliner)を参照してください。
- グループの内側を編集している間は、「編集中: モデル › …」という行が表示され、{{ui:グループを閉じる}}ボタンが現れます。開いているすべての階層が一度に閉じます。

**{{ui:コンポーネント}}**には、すべてのコンポーネント定義が、配置されているコピーの数 (「3×」) と、クリックした位置に別のコピーを追加する{{ui:配置}}ボタンとともに一覧されます。

## 右のパネル

**{{ui:エンティティ情報}}**には、選択したものの内容が表示されます。見出しは、何が選択されているかに応じて変わります。

| 見出し | 表示内容 | ボタン |
|---|---|---|
| モデル (何も選択していない) | 面、エッジ、グループ、コンポーネントと配置数、ガイド、全体のサイズ | {{ui:すべてのガイドを削除}} (ガイドがある場合) |
| 面 | 面積、穴の数 | {{ui:面を反転}} |
| エッジ | 長さ | なし |
| グループまたはコンポーネント | 名前 (入力して変更)、配置数、閉じたソリッドかどうか、体積、サイズ | {{ui:編集}}、{{ui:分解}}、{{ui:ユニークにする}} (複数回配置されたコンポーネント)、{{ui:コンポーネントを作成}} (グループ) |
| ガイド点またはガイド線 | なし | {{ui:削除}} |
| 複数のもの | 面、エッジ、グループ、ガイドの数、面の合計面積 | {{ui:コンポーネントを作成(G)}}、{{ui:グループを作成(Shift+G)}} |

**{{ui:スタイル}}**は、モデルの描画方法を設定します。{{ui:面}} ({{ui:シェード}}、{{ui:隠線}}、{{ui:ワイヤーフレーム}}、{{ui:X線}})、{{ui:エッジを表示}}、そして太陽の日付、時刻、場所を指定する{{ui:太陽の影}}です。[スタイルと太陽の影](topic:styles-shadows)を参照してください。

**{{ui:シーン}}**は、ビューを保存します。{{ui:シーンを追加}}、シーンの一覧、{{ui:前へ}}、{{ui:再生}}、{{ui:次へ}}があります。[ビューをシーンとして保存する](topic:scenes)を参照してください。

## ステータスバー

下端に、左から右へ次のものが並びます。

1. **ヒント:** ツールが次に求めているもの、またはポインターがスナップしているもの (「端点」「赤軸上」)。
2. **メッセージ:** いま起きたこと (「プッシュ/プルを元に戻しました。」「site.dxfを読み込みました: 地面に1697本のエッジ、グループ内。」)、または何かができなかった理由。
3. **値ボックス:** ラベルはツールに応じて変わります ({{ui:長さ}}、{{ui:寸法}}、{{ui:半径}}、{{ui:辺の数}}、{{ui:距離}}、{{ui:角度}}、{{ui:倍率}}、{{ui:オフセット}})。作業中はそのときのサイズが表示され、入力した値を受け取ります。[値ボックスに正確なサイズを入力する](topic:value-box)を参照してください。
4. **キースタイル:** {{ui:キー: プッシュ/プル式}}または{{ui:キー: モデラー式}}で、キーボードショートカットとマウスボタンがまとめて切り替わります ([ModelCraftの設定](topic:settings)と同じです)。
5. **{{ui:スナップ}}と{{ui:衝突}}:** 点、エッジ、軸へのスナップと、ソリッドが接したところで止まる動作です。取り消し線が付いているとオフです。クリックで切り替えます。[ModelCraftの設定](topic:settings)を参照してください。
6. **単位の選択:** 長さを表示する単位。[はじめよう](topic:getting-started#check-the-units-first)を参照してください。

## 画面幅が狭い場合

幅がおよそ760ピクセルを下回る場合 (スマートフォン、または狭いウィンドウ) は、3Dビューが画面を占めます。ツールバーは1行で横にスクロールし、パネルは画面下部のバーからシートとして開きます。
