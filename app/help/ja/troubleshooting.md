## 3Dビューが空白になる

**症状:** 画面の中央が空のまま、または背景色だけが表示され、ツールをクリックしても何も起こりません。

**原因:** ModelCraft は WebGL 2（ブラウザーの3Dグラフィックス）で描画します。ブラウザーが古い場合、ハードウェアアクセラレーションがオフの場合、またはグラフィックスドライバーがブロックされている場合は、WebGL 2 が利用できません。

**対処法:**

:::chromium
1. ブラウザーの設定を開き、「グラフィックス アクセラレーション」を検索します。
2. 「ハードウェア アクセラレーションを使用可能な場合は使用する」をオンにし、ブラウザーを再起動します。
3. すでにオンの場合は、アドレスバーに `chrome://gpu` と入力します（Edge の場合は `edge://gpu`）。一覧で「WebGL2」を探します。無効と表示されている場合は、グラフィックスドライバーを更新してください。
:::

:::firefox
1. **設定** を開き、**全般** を選択して、「パフォーマンス」までスクロールします。
2. 「推奨のパフォーマンス設定を使用する」のチェックを外し、「利用可能な場合はハードウェア アクセラレーションを使用する」にチェックを入れます。Firefox を再起動します。
3. それでも失敗する場合は、アドレスバーに `about:support` と入力し、「グラフィックス」セクションで WebGL 2 を確認します。
:::

:::safari
macOS と Safari を更新してください。最近の Safari では、WebGL 2 が常に有効になっています。**Safari** の **設定** で、**詳細**（または**機能フラグ**）から実験的な機能を変更した場合は、それらをリセットしてください。
:::

業務用のコンピューター、リモートデスクトップ、仮想マシンでは、ポリシーによって3Dグラフィックスがブロックされている場合があります。別のコンピューターで試してください。[ブラウザーとコンピューター](common:browsers)を参照してください。

## キーが効かない、またはボックスに入力される

**原因:** キーボードのフォーカスがパネルの入力欄にあります。{{ui:スタイル}} の {{ui:面}} 一覧、太陽の設定、{{ui:エンティティ情報}} の {{ui:名前}} 欄、または単位の選択欄です。その場合、文字キーと矢印キーはその欄に入力されます。

**対処法:** 3Dビューをクリックしてから、もう一度キーを押してください。ダイアログが開いている間も、キーは動作しません。

## 数字を入力しても何も起こらない

- **まだ方向がありません。** 入力した長さは、1回目のクリックからポインターが指す方向に伸びます。目的の方向へ少しポインターを動かしてから入力してください。
- **タイミングが違います。** ほとんどのツールは、最初のクリックの後にだけ値を受け付けます。最初の角、面、または移動元の点をクリックしてください。{{ui:円}} と {{ui:多角形}} は、1回目のクリックの前に辺の数を受け付けます。
- **「3m、10'6"、4m,3m のような長さを入力してください。」** ModelCraft がこれを読み取れませんでした。小数点としてカンマ（`2,5`）を使っていないか確認してください。ピリオドを使用してください。

## タッチ画面で図形の開始位置がずれる

**症状:** 指で操作すると、最初の長方形は正しく描けますが、次の長方形、円、ラインは、タッチした位置ではなく前回のタッチが終わった位置から始まります。

**原因:** このビルドのバグです。タッチ画面では、ツールが前回の操作での最後のスナップ点を記憶してしまいます。

**対処法:** 図形を描くたびに、ツールバーでツールのボタンを再度タップしてください。これによりツールが新たに開始され、1点目はタッチした位置になります。

## 1つのグループを編集すると別のグループも変わる

**症状:** {{ui:移動}} と {{key:Ctrl}} を使ってグループをコピーし、1つのコピーを開いて編集すると、もう1つのコピーも変わりました。{{ui:アウトライナー}} には、両方が同じ名前で表示されます。

**原因:** このビルドでは、グループをコピーすると、コンポーネントの場合と同様に、同じグループの2つ目の配置が作られます。ModelCraft の {{ui:ユニークにする}} ボタンは、コンポーネントに対してのみ表示されます。

**対処法:** 変更したいコピーを選択し、{{ui:エンティティ情報}} の {{ui:コンポーネントを作成}} をクリックしてから、{{ui:ユニークにする}} をクリックします。これでそのコピーは独自の内容を持ちます。または、{{ui:分解}} してください。

## プッシュ/プルが期待どおりに動作しない

- **「プッシュ/プルは面に対して動作します。面をクリックしてください。」** エッジや何もない場所をクリックしています。面がハイライトされるまでポインターを合わせてから、クリックしてください。
- **面がグループの内側にあります。** 先にグループをダブルクリックして開いてください。
- **窓が壁を貫通しませんでした。** 長方形は、壁の前ではなく壁の面上に描く必要があり、壁には裏面がある必要があります。[壁に開口部を切り抜く](topic:openings#if-it-did-not-cut-through)を参照してください。
- **2つの直方体が重なっても結合されません。** このビルドでは、互いに押し込んだソリッドは、互いに切り取ったり結合したりしません。

## ラインや図形で面が作られない

エッジが平面のループを閉じた場合にだけ面が作られます。最後の点が最初の点にスナップしている（「端点」）こと、およびすべてのエッジが1つの平面上にあることを確認してください。わずかに平面からずれたループは、線のままになります。その1つのエッジを、角にスナップさせながら描き直してください。

## 面を選択または消去できない

- {{ui:選択}} を使うと、エッジの近くをクリックした場合はエッジが選択されます。面の中央寄りをクリックしてください。
- {{ui:消しゴム}} では面を選択できません。面を選択して {{key:Delete}} を押すか、そのエッジの1つを消去してください。
- グループまたはコンポーネントに含まれている場合は、クリックするとその全体が選択されます。ダブルクリックして開いてください。

## 「移動するものを選択するか、そのものをクリックしてください。」

{{ui:移動}}、{{ui:回転}}、{{ui:尺度変更}} には、操作対象が必要です。先に選択するか、ツールを使い始める際にそのもの自体をクリックしてください（何もない場所やガイドをクリックしないでください）。

## 「先にジオメトリを選択してください（窓選択でドラッグするか、トリプルクリックで接続されたものすべてを選択します）。」

{{key:G}} と {{key:Shift+G}} には選択が必要です。ガイドはグループにできません。

## 矢印キーがロックではなくオービットする

ロックは、作図ツールや編集ツールの1回目のクリックの後にだけ動作します。{{ui:プッシュ/プル}} にはロックがなく、{{ui:回転}} ではロックは回転の向きを変更しません。それ以外の場合、矢印キーはビューをオービットさせます。

## 全画面表示での Esc

全画面表示では、ブラウザーが最初の {{key:Esc}} で全画面表示を終了することがあります。ツールをキャンセルするには、もう一度 {{key:Esc}} を押してください。

## 中ボタンがない

{{key:O}} を押して {{ui:オービット}} を使いドラッグするか、矢印キーを使用してください。[オービット、パン、ズーム](topic:orbit-pan-zoom#without-a-middle-button)を参照してください。

## インポート

| メッセージ | 対処法 |
|---|---|
| 「ModelCraft は SketchUp（.skp）、Collada（.dae）、OBJ、glTF（.glb/.gltf）、FBX、PLY、STL、Alembic（.abc）、DWG、DXF をインポートします。…はこのいずれでもありません。」 | 他のプログラムから、これらの形式のいずれかでモデルを書き出してください |
| 「このファイルは 300 MB を超えています。」 | 他のプログラムでモデルを簡略化するか、分割してください |
| 「…ここでモデル化するには大きすぎます（頂点数が 2 million を超えています）。」 | 同じ |
| 「この .gltf ファイルには "…" が必要です…」 | `.gltf` を、その `.bin` ファイルおよびテクスチャーファイルと一緒にドロップするか、`.glb` 版を開いてください |
| 「この glTF ファイルには、ModelCraft がまだ読み取れない … 拡張機能が必要です。」 | 他のプログラムから、その拡張機能を使わずに再度書き出してください（例: KTX2 テクスチャー） |
| OBJ が色やテクスチャーなしでインポートされる | `.obj` を、その `.mtl` と画像と一緒にドロップしてください |
| 「この Alembic ファイルは古い HDF5 レイアウトを使用しています…」 | 他のプログラムから、Ogawa Alembic ファイルとして保存し直してください |
| FBX がテクスチャーなしでインポートされる | `.fbx` を、そのテクスチャー画像と一緒にドロップするか、書き出し時にメディアを埋め込んでください |
| 「この FBX ファイルはバージョン …で、ModelCraft では読み取れません」 | FBX 2011 以降として再度書き出してください |
| STL または PLY が 1,000 倍大きすぎる、または小さすぎる状態でインポートされる | STL はミリメートル、PLY はメートルとして読み取られます。サイズを変更してください（[回転と尺度変更](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)を参照） |
| 「これは Collada（.dae）ファイルではありません…」または「…整形式の XML ではありません…」 | ファイルが破損しているか、Collada ではありません。再度書き出してください |
| 「この Collada ファイルには、ModelCraft がインポートできるジオメトリがありません。」 | カメラ、ライト、または他のファイルへの参照のみが含まれています |
| 「これはバイナリ DXF です。ASCII DXF として保存し、もう一度お試しください。」 | CAD プログラムから ASCII 形式で保存し直してください |
| 「これは DWG 図面ではありません…」 | ファイルが DWG ではないか、破損しています |
| 「この図面を読み取れませんでした（…）。破損しているか、読み取り機能が対応していない DWG バージョンで保存されている可能性があります…」 | 括弧内に理由が示されています。CAD プログラムから、DXF として、または AutoCAD 2000 から 2018 の DWG として保存してください |
| 「この図面は原点から 10,000 km 以上離れています…」 | CAD プログラムで、図面を 0,0 の近くに移動してください |

### インポートされたものがサイズ違い、または横倒しになっている

- **OBJ:** OBJ には単位がありません。ModelCraft はメートルとして読み取ります。ミリメートルのモデルは 1000 倍大きくインポートされます。[尺度変更](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)で `0.001` 倍してください。インチのモデルの場合は `0.0254` 倍してください。
- **OBJ が横倒し:** ModelCraft は Y 軸が上の OBJ ファイルを想定しています。Z 軸が上で書き出されたファイルは横倒しでインポートされます。赤の軸を中心に 90° 回転させてください。赤の方向を向いている面上で {{ui:回転}} の中心をクリックするか、ファイルを元のプログラムで開き、Y 軸が上の状態で書き出してください。
- **DWG または DXF:** 「図面の単位」ダイアログで間違った単位を選択しました。元に戻して、もう一度インポートしてください。

## ファイルを開く

| メッセージ | 対処法 |
|---|---|
| 「これは ModelCraft モデルではありません（JSON ではありません）。」 | 他の形式には {{ui:読み込み}} を使用してください |
| 「ModelCraft で開けるファイルではありません: …」 | ファイルが破損しているか、手作業で変更されています |
| 「このモデルは新しい ModelCraft で保存されています…」 | 新しいバージョンで開いてください |
| 「このファイルは 200 MB を超えています。」 | モデルが大きすぎるため、ここでは開けません |

## 作業が失われた

ModelCraft はファイルへ自動では保存しません。保存されていない変更がある状態でタブを閉じるか再読み込みすると、ブラウザーが最初に確認します（「サイトから移動しますか？」または「サイトを再読み込みしますか？」）。そのままとどまって保存してください。「新規」と「開く」でも確認されます（「保存されていない変更」）。ブラウザーまたはコンピューターがクラッシュした場合は、同じブラウザーで ModelCraft を再度開いてください。保存されていない作業が戻されます（「作業内容を復元しますか？」。[作業内容を復元](common:recover)を参照）。{{key:Mod+S}} で頻繁に保存してください。

## ダウンロードフォルダーにコピーがたまる

保存のたびに新しいダウンロードになり、名前は `Untitled (1).modelcraft`、`Untitled (2).modelcraft` のように付けられます。古いファイルを削除するか、ブラウザーで各ファイルの保存場所を尋ねるように設定して、古いファイルを自分で上書きしてください。[開く、保存、インポート、書き出し](topic:files#save-a-model)を参照してください。

## 動作が遅くなる

- 元に戻す操作の各ステップは、モデルのコピーを保持します（[メッシュ](topic:meshes)は変更された部分だけを保持します）。そのため、プッシュ/プルで作成した非常に大きなジオメトリをインポートした場合、編集ごとに時間がかかります。不要なものは分解するか消去し、保存してから開き直してください。開き直すと、元に戻す操作の履歴も消去されます。
- 太陽の影が最も負荷がかかります。モデリング中は {{ui:太陽の影}} のチェックを外してください。

## 影が表示されない

{{ui:太陽の影}} がオフになっているか、選択した時刻に太陽が沈んでいるか（「この時刻には太陽が沈んでいます。」）、またはスタイルが影を描かない {{ui:ワイヤーフレーム}} になっています。

## 「このブラウザーでは全画面表示が許可されていません。」

一部のブラウザーや埋め込みビューでは全画面表示が拒否されます。代わりにブラウザー自体の全画面表示を使用してください（{{pick:mac=Control-Command-F|windows linux=F11}}）。

## 接続なしでは ModelCraft が開かない

ModelCraft は、そのブラウザーでオフライン用に保存された後にだけ、オフラインで開けます。アプリバーのボタンに {{ui:オフライン対応済み}} と表示されている必要があります。オンラインのときに開き、{{ui:オフライン用に保存}} をクリックしてください。ボタンに {{ui:保存できませんでした}} と表示される場合は、より良い接続でもう一度クリックしてください。{{ui:オフライン利用不可}} と表示される場合は、このウィンドウ（プライベートウィンドウや管理されたコンピューター）ではコピーを保持できません。[オフラインでの作業](common:offline)を参照してください。
