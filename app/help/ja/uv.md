テクスチャーは平らな画像ですが、メッシュは平らではありません。その**UV**が、面の各角の位置を画像上で指定します。UVワークスペースでは、**シーム**に沿ってメッシュを切り開き、ピースを平らにし(**展開**)、正方形に収めます(**パッキング**)。

## 開く

メッシュを選択し、ワークスペース一覧で{{ui:UV}}を選びます。グループまたはコンポーネントは、メッシュワークスペースと同様に、先にメッシュに変換されます。3Dビューは左半分に移動し、右側の**UVエディター**にメッシュの面がテクスチャーの正方形上に配置されて表示されます。選択はメッシュワークスペースと同じように機能し、一方のビューで選択したものは、もう一方でも選択されます。

## シームを設定

シームは、メッシュを切り開いてよい場所です。両方のビューで赤く表示されます。

- エッジを選択({{ui:エッジ}}、または{{key:2}})し、{{ui:シームを設定}}({{key:Ctrl+E}})を押します。{{ui:シームを消去}}({{key:Ctrl+Shift+E}})で取り除きます。
- {{ui:鋭角部分にシーム}}は、すべての鋭角のエッジと、面が60°を超える角度で交わるすべてのエッジにシームを設定します。ボックスは6つの面に分かれます。
- {{ui:UVからシームを作成}}は、投影の後などで UV がすでに切れている場所にシームを設定します。

閉じた形状を平らにするには、シームが必要です。球には少なくとも1か所、チューブには長さに沿った切れ目が1本必要です。

## 展開

展開する面を選択し(何も選択しなければメッシュ全体)、{{ui:展開}}({{key:U}})を押します。シームで区切られた各ピースが、角度をできるだけ正確に保ったまま平らに広げられ(角度ベースの平坦化)、その後ピースが正方形に配置されます。{{ui:等角}}は、代わりに最小二乗法の等角写像で展開します。速いですが、強く曲がったピースでは少し正確性が下がります。一度切られた円柱の側面のように、平らなシートから作れる形状は、まったく伸びずに展開されます。

## 投影

単純な形状では、投影で十分な場合が多いです。

| 投影 | 内容 |
| --- | --- |
| {{ui:ボックス}} | 各面を、最も正面を向いている箱の側面に投影 |
| {{ui:円柱}} | 青い軸の周りに投影。横方向は周囲の角度、縦方向は高さ |
| {{ui:球}} | 中心から投影。横方向は周囲の角度、縦方向は緯度 |
| {{ui:ビューから}} | 現在の3Dビューに見えているとおりに面を投影 |

円柱または球の継ぎ目をまたぐ面は1つのピースに保たれるため、その UV は正方形の右端をわずかに超えることがあります。テクスチャーはそこで繰り返されます。

## 配置

- {{ui:パッキング}}は、ピース(アイランド)を1テクセルサイズで正方形に収め、それぞれ最も少ないスペースで収まるよう回転させます。パネルでピース間の余白を設定します。
- {{ui:90°回転}}と{{ui:鏡像}}は、選択した面の UV を回転または鏡像にします。
- UVエディターで、選択した面をドラッグすると選択の UV が移動します。またはエディター上にポインターを置き、{{key:R}}または{{key:S}}を押してから移動すると、UV が回転または拡大縮小されます(クリックで確定、{{key:Esc}}でキャンセル)。{{key:G}}はドラッグせずに移動します。面をダブルクリック(または{{key:L}})すると、そのアイランド全体を選択します。ホイールでズーム、中ボタンまたは右ボタンのドラッグでパン、{{key:F}}で正方形を再び全体表示します。

すべての変更は元に戻す1回分になります。

## 確認する

- {{ui:チェッカー}}は、UV上でラベル付きのチェッカーをメッシュに表示します。正方形が均一なら、テクスチャーが均等に貼られていることを示します。ラベルは、テクスチャーの向きを示します。
- {{ui:ストレッチ}}は、UVによってどれだけ伸びるかに応じて各面を色分けします。青は伸びなし、緑を経て、赤は大きく伸びていることを示します。パネルで、**角度の曲がり**と**サイズの変化**のどちらを測るかを選べ、平均値が表示されます。
