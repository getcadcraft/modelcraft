{{ui:Settings}}({{key:Mod+,}})を開き、このアプリのタブのまま {{ui:Rendering}} までスクロールします。{{ui:Your machine}} には、このブラウザーがレンダリングにアプリで使用することを許可している項目が一覧表示されます。この一覧の内容がお使いのコンピューターの外に送信されることはありません。

| 行 | 意味 |
|---|---|
| {{ui:Graphics}} | ブラウザーが報告するグラフィックカードです。「WebGPU」は、レンダリング作業のすべてを行えることを示します。「WebGL 2 only」は、ライブビューと {{ui:Render a picture…}} がこれを使用することを示します（WebGL のパストレーサーにより高品質）。一方、WebGPU を必要とするビュー内のレンダリングとレンダリングキューは提供されません。ソフトウェアによる代替の場合は、すべての処理がプロセッサーで実行されることを示します |
| {{ui:Processor}} | ブラウザーが報告するプロセッサーのコア数です |
| {{ui:Memory}} | ブラウザーが報告する場合の、コンピューターのメモリ量の目安です。報告しないブラウザーもあります |
| {{ui:Shared memory}} | ページがワーカー間でメモリを共有してよいかどうかです。オンの場合、すべてのコアが1つのシーンのコピーに対して作業できます。オフの場合、各コアがそれぞれ独自のコピーを必要とするため、大きなシーンは同時に使えるコア数が少なくなります |
| {{ui:Fast processor code}} | ブラウザーが高速なWebAssemblyコードを実行するかどうかです。これがオフの場合、低速な代替コードが使用されます |
| {{ui:Level}} | {{ui:Graphics card, high}}、{{ui:Graphics card, basic}}、{{ui:Processor only}} のいずれかで、その理由が下に表示されます |

## レベル

レベルは、[ライブビュー](topic:live-view) の開始位置（{{ui:For this computer}}）、描画する散在アイテムの数、およびビューに表示できる [サブディビジョンサーフェス](topic:modifiers#subdivision-surface) の面の数を決めます。これにより、内蔵グラフィックスチップのみのノートパソコンや、グラフィックカードがないノートパソコンでも応答性が保たれます。内蔵グラフィックスチップまたはスマートフォン用のグラフィックスチップの場合、またはメモリが4 GB以下の場合は、{{ui:Graphics card, high}} が割り当てられることはありません。

:::note
ブラウザーによって異なります。同じコンピューターでも、あるブラウザーではWebGPU、別のブラウザーでは「WebGL 2 only」と表示されることがあります。Linuxでは、ほとんどのブラウザーにまだWebGPUがありません。
:::
