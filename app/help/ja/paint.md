色を使うと、モデルの各部分を見分けやすくなります。また、**材料**(レンガ、サイディング、屋根材、木材、石、タイル、コンクリート、スタッコ、草、ガラス、金属)を使うと、モデルが実際の素材で作られているように見えます。どちらも同じ方法でペイントします。

## 色を選ぶ

右側の{{ui:カラー}}セクションには、単色の列、{{ui:既定}}(線が引かれたもの: 色なし)、その他の色用の{{ui:+}}の見本が表示されます。いずれかをクリックすると、現在の色になります。ペイントツールは、この色から始まります。

## ペイントする

1. {{key:B}}({{ui:ペイント}})を押すか、何も選択していない状態で色をクリックします。(何かを選択している状態で色をクリックすると、選択部分がすぐにペイントされます。)
2. 面をクリックしてペイントします。
3. グループまたはコンポーネントをクリックすると、そのコピーをペイントします。独自の色を持たない面はこの色になります。その内部でペイントした面は、そのままの色を保ちます。

複数のものをまとめてペイントするには、先に選択してから色をクリックするか、{{ui:ペイント}}を使ってそのうちのいずれかをクリックします。これは1回の元に戻す操作になります。

| 押すキー | 面をクリック | ペイントされるもの |
|---|---|---|
| — | | その面 |
| {{key:Ctrl}} | | 同じ色で、つながっているすべての面 |
| {{key:Shift}} | | 作業中のグループ内にある、その色のすべての面 |
| {{key:Alt}} | | 何もペイントされません。代わりにその色を取得します |

面を色なしに戻すには、{{ui:既定}}を選んでその面をクリックします。

## 材料でペイントする

{{ui:カラー}}の下にある{{ui:マテリアル}}セクションには、材料ライブラリが種類別に表示されます。種類は、レンガとブロック、サイディング、屋根材、木材、石、タイル、コンクリート、スタッコ、地面、ガラス、金属です。見本にカーソルを合わせると名前が表示されます。いずれかをクリックし、色の場合と同じように、{{key:B}}を押して面、グループ、コンポーネントをクリックしてペイントします。または、先に選択してから材料をクリックします。

- **陰影付き**スタイルでは、面に材料のテクスチャが表示されます。隠線、ワイヤーフレーム、X線では、材料の色が表示されます。
- テクスチャは、**各面に沿って水平**に、そして**面を上る方向**に配置されます。レンガの目地はどの壁でも水平に保たれ、シングルは屋根の勾配に沿って下に並び、床の板は赤軸に沿います。テクスチャは実寸で表示されます(レンガは長さ約215 mm)。そのため、どの距離からでも正しく見えます。
- [レンダリング画像](topic:render)では、材料はテクスチャ、粗さ、そしてガラスと金属の場合は光沢を保持します。
- {{ui:ペイント}}を使って{{key:Alt}}キーを押しながらクリックすると、面の材料も取得されます。

テクスチャはModelCraft自身が描画するため、オフラインでも動作し、どのような用途でも自由に使えます(CC0)。

## コンポーネントと色

コンポーネントの**内部**の面にペイントした色は、すべてのコピーに表示されます。コピーは1つの定義を共有しているためです。コンポーネントを閉じた状態で、外部から**コピー**にペイントした色は、そのコピーだけのものになります。そのため、1つのコンポーネントの2つのコピーが異なる色を持つこともあります。{{ui:エンティティ情報}}には、選択した面、グループ、コンポーネントの色が表示されます。

## ファイル内の色

- ModelCraftファイルには、すべての色とすべての材料が保持されます。
- 他の形式では、テクスチャの代わりに**材料の色**(遠くから見たときの見た目)が使われます。対象は、glTF、Collada、OBJ、DWG、DXF、および3Dプリント向けチェックです。glTF、Collada、OBJでは、材料は`Material_brick-red`のように名前を保持します。
- **glTF (.glb)**と**Collada (.dae)**: 色ごとに材料になります。異なる色で表示されたコンポーネントは、色ごとに1回ずつ書き出されます。glTFでは、読み込まれたテクスチャもテクスチャとして書き出されます。
- **OBJ**: 書き出しでは、2つのファイル、`.obj`と色を含む`.mtl`材料ファイルがダウンロードされます。同じフォルダーに保存してください。読み込んだテクスチャがある場合、`.obj`、`.mtl`、画像は1つの`.zip`としてまとめられます。
- **DWG**は正確な色を保持します。**DXF**は、標準のCAD色255色のうち最も近い色を使います。
- **STL**と**PLY**は色を持ちます。STLはVisCAM / SolidViewの規則で(読み込めないプログラムでは無視されます)、PLYは各点の色として保持されます。[ファイル形式の詳細](topic:formats)を参照してください。

:::tip
画面をモデル化するには、正面の面を[オフセット](topic:draw-faces)した後、フレームをチャコールグレー、ガラスを青でペイントします。
:::
