**シェーディング**ワークスペースで作成したマテリアルは、ファイルに属します。これは小さなグラフで、テクスチャー、画像、数値を作る**ノード**を**マテリアル出力**につなげたものです。マテリアル出力の入力は、サーフェスの見た目を決めます（ベースカラー、ラフネス、メタルネス、法線、不透明度、エミッション、およびOpenPBRモデルのその他の項目）。他のライブラリマテリアルと同様に面に塗ることができ、変更はすべてビューにすぐ反映されます。

## 作業を始める

ワークスペースの一覧で{{ui:シェーディング}}を選択します。3Dビューは画面の上部を保持し、**ノードエディター**が下部を占めます。右側のパネルには、ファイル独自のマテリアルが一覧表示されます。

- {{ui:新規マテリアル}}を押すと、マテリアル出力のみを持つグレーのマテリアルを作成します。
- **マテリアルライブラリのマテリアルを編集可能なコピーにする**と、レンガ、木材、タイルなどを変更可能なグラフに変換します。そのテクスチャーはライブラリテクスチャーノードを通り、そのバンプはバンプノードを通ります。
- {{ui:これでペイント}}は、選択した面またはグループに塗るか、ペイントツールのマテリアルを選びます。ペイントツールのマテリアルには、**このファイル内**の、ファイル独自のマテリアルも一覧表示されます。
- {{ui:複製}}と{{ui:削除}}は、編集中のマテリアルに対して動作します。削除は元に戻せません。削除したマテリアルで塗られた面は、再度塗るまでデフォルトの色で表示されます。

## ライブラリのマテリアル

パネルの**マテリアルライブラリ（Library）**には、ライブラリのマテリアルが一覧表示されます。それぞれのマテリアルには、CadCraftのパストレーサーでレンダリングされたプレビューが付いています。これらはCC0で公開されたテクスチャーセットで、作成した人のクレジットが付いています。

- 1つクリックするとファイルに読み込まれ（画像も一緒に読み込まれます）、面またはグループが選択されていれば、それらに塗ります。
- 1つをビュー内の面またはグループにドラッグすると、その面またはグループだけに塗ります。
- ファイルのマテリアルの1つになり、他のマテリアルと同様にノードを変更できます。そのクレジットはパネルに表示され、ファイル内に保持されます。

## テクスチャーセットのインポート

**テクスチャーセットのインポート**の下にある{{ui:画像またはzip…}}または{{ui:フォルダーから…}}を使うと、マップのセットからマテリアルを作成します。マップは、ファイル名に含まれる語で見分けられます。カラー、アルベド、ディフューズ、basecolor（ベースカラー）、ラフネス（またはグロス。ラフネスに変換されます）、メタルネスまたはメタリック、法線（OpenGLまたはDirectX。名前内の`gl` / `dx`による）、高さまたはディスプレイスメント、アンビエントオクルージョン、不透明度、エミッションです。パックされたマップ（ARM、ORM）は除外されます。タイルは1 × 1 mから始まります。実際のサイズはマテリアル出力で設定します。高さはスケールを0にした状態でディスプレイスメントに入ります。メッシュに使うには、スケールを上げてください。

## MaterialX

MaterialXは、他の3D・レンダリングプログラムがマテリアルを受け渡すために使うオープンな形式です。

- {{ui:MaterialXとして書き出し…}}は、編集中のマテリアルを保存します。その値と、各テクスチャーをPNG画像として`.mtlx`ファイルと並べて（zip内に）保存します。書き出すシェーダーを選択します: **OpenPBR Surface**（MaterialX 1.39。ModelCraftが使うものと同じモデル）または**Standard Surface**（MaterialX 1.38。現在より多くのプログラムで読み込めるもの）。テクスチャーはメートル単位のUV座標で配置されます。ボックスとトリプラナーの配置は、UVとして書き出されます。
- {{ui:MaterialXを読み込み…}}（または{{ui:フォルダーから…}}）は、OpenPBR、Standard Surface、UsdPreviewSurface、glTF PBRのシェーダーを使う`.mtlx`ファイルを読み込みます。画像も一緒に指定するか、すべてをまとめたzipを指定してください。画像は、そのパス、名前、または別の画像形式の同名ファイルで見つかります（`.exr`と指定されたファイルは、その横にある`.jpg`として見つかる場合があります）。テクスチャー、法線マップ、演算、ミックス、ディスプレイスメントはノードとして読み込まれます。それ以外は値を保持し、どの項目が除外されたかはステータスバーに表示されます。

## デカール

デカールは、サーフェスに重ねて配置される画像です。ロゴ、看板、ラベル、汚れなど、独自のマテリアルを持ちます。

- **新しいデカールの幅**を設定してから、{{ui:デカールを配置…}}（またはツールバーの{{ui:デカール}}）を押し、PNG、JPEG、またはWebPの画像を選んで面をクリックします。画像は、その位置のサーフェスに投影され、縦横比を保ちます。PNGの透明な部分は透けて見えます。
- デカールは、クリックしたグループまたはコンポーネントに属し、それと一緒に移動します。その枠内にある、同じ向きの面に配置され、配置先の端で止まります。
- 各デカールには専用のマテリアルが作成され、ファイルの一覧に**デカール: <画像>**という名前で表示されます。他のマテリアルと同様に編集できます（ラフネス、バンプ、グロー）。デカールの横にある{{ui:マテリアル}}で開きます。
- 各デカールの横には、幅（高さは画像に合わせて変わります）、{{ui:回転}}（四分の一回転）、{{ui:削除}}があります。デカールはファイルのマテリアルと一緒に保持され、元に戻す操作の対象外です。
- デカールは、シェーディングビュー、高速レンダリング、高品質画像に表示されます。

## テクスチャーに塗る

{{ui:テクスチャペイント}}（または**テクスチャーに塗る**の下の{{ui:ペイント}}）を使うと、ポインターが丸いブラシに変わります。このファイルのマテリアルが適用されている面をドラッグすると、ブラシがベースカラーの背後にある画像に塗ります。

- メッシュでは、メッシュのUVに沿って塗ります（先にUVワークスペースでUVを展開してください）。それ以外の面では、面全体に塗るため、マテリアルのタイルごとに塗りが繰り返されます。
- ベースカラーが単色のマテリアルは、初めて塗るときに、その色の512 × 512の新しい画像が作成されます。ベースカラーが他のノードから得られるマテリアルには、ベースカラーに接続した画像ノードが必要です。
- パネルでブラシの色、サイズ（画像のピクセル単位）、強さ、硬さを設定します。{{ui:ストロークを元に戻す}}またはCtrl+Z（塗っている間）で、直前の20回までのストロークを取り消せます。
- 塗った画像はファイルに保存されます。ライブラリのマテリアルには塗れません。先に編集可能なコピーを作成してください。

## テクスチャーをベイクする

**テクスチャーのベイク**は、形状とシーンがサーフェスに与える情報を、メッシュのUVに沿って画像として書き出します。

- UVを持つメッシュを選択し（UVワークスペースで展開します）、マップにチェックを入れて{{ui:ベイク}}を押します:
  - **アンビエントオクルージョン**: 各点がどれだけ開けているかを示します。角、折り目、他のものの下にある場所は暗くなります。モデルに表示されているすべてのものが、オクルージョン距離までの範囲でこれに影を落とします。
  - **曲率**: 外側のエッジに沿って明るく、内側の角では暗くなり、平らで緩やかに曲がった部分は中間のグレーになります。設定したエッジの幅が対象になります。
  - **高ディテールのオブジェクトからの法線**: 詳細なコピーも選択します。その表面のディテールが、よりシンプルなオブジェクトの法線マップとして書き出されます（三角形の数が少ないオブジェクトにベイクされます）。検索距離は、2つの面がどれだけ離れていてよいかを示します。
  - **ライティング**: モデルの場所と日付（スタイル）による太陽とその影、および空を、ライトマップとして書き出します。
- 画像はファイルに追加され、画像ノードに表示されます。編集中のマテリアルに**汚れとエッジの摩耗**ノードがある場合は、新しいオクルージョンと曲率をすぐに読み込みます。
- テクセルあたりのレイを増やすと、オクルージョンとライティングが滑らかになりますが、時間がかかります。ベイクはバックグラウンドでコンピューターのプロセッサーコアを使って実行され、{{ui:ベイクを停止}}で停止します。

## グラフを作成する

1. {{ui:ノードを追加…}}（ノードエディターでは{{key:Shift+A}}）を押すと、エディターの中央にノードが追加されます。
2. 出力の点（ノードの右側）から入力の点（ノードの左側）にドラッグして接続します。入力に2つ目の接続をすると、最初の接続が置き換えられます。接続されている入力をドラッグして離すと、接続が解除されます。
3. 接続されていない入力は値を表示します。数値を入力するか、色を選択します。設定は各ノードの下部にあります。

ノードのタイトルをドラッグするとノードを移動し、何もない空間をドラッグするとパンし、ホイールでズームします。{{key:Delete}}で選択したノードまたは接続を削除し、{{key:Mod+Z}}で元に戻し、{{key:Mod+D}}で複製し、{{key:F}}ですべてのノードを表示します。変更はそれぞれ、ノードエディターの1回の元に戻す操作になります。モデル自体の元に戻す操作では、マテリアルは変わりません。

| ノード | 作成されるもの |
|---|---|
| テクスチャー座標 | タイル上の点の位置です。繰り返し、オフセット、四分の一回転ができます。 |
| 値、カラー | 数値、色。 |
| 画像 | ファイルの画像です（読み込んだモデルに含まれていたもの、または{{ui:画像を追加…}}で追加したもの）。写真には**カラー**、ラフネスや法線マップには**データ**を選択します。 |
| ライブラリテクスチャー | ライブラリマテリアルのテクスチャー、ラフネス、高さ。 |
| チェッカー、ノイズ | 正方形。細部、ラフネス、シードを持つ、滑らかなフラクタルノイズ。 |
| ボロノイセル、波、グラデーション | セル（最も近い点までの距離、セル間の境界、セルごとの色）。横、縦、または斜めの帯で、サイン波、のこぎり波、三角波の形を持ち、ノイズで曲げられたもの。線形、二次、放射状、球状のグラデーション。 |
| レンガ、タイル | ずらして積んだレンガの列、またはタイルの格子: 色、モルタルまたは目地、隙間と面取り（メートル単位）、バンプの高さ、ピースごとの乱数。 |
| 木材、大理石 | 木目に沿った年輪と細かい繊維。乱流で曲げられた筋。 |
| 汚れとエッジの摩耗 | メッシュの曲率とオクルージョンの画像から、凸のエッジを摩耗させ、くぼみを汚します（[テクスチャーのベイク](topic:shading#bake-textures)で作成するか、メッシュのUVレイアウトでその2つの画像設定を行います。マテリアルをUV座標で配置します）。これらがない場合は、何も変わりません。 |
| カラーのミックス、カラーランプ、色相/彩度/明度、明るさとコントラスト、反転、ガンマ、RGBの分離と結合 | 色の処理。 |
| 計算、マップ範囲 | 数値の計算（加算、乗算、べき乗、スムーズステップなど）。 |
| バンプ、法線マップ | 高さから作る法線（バンプ）、または法線マップの画像から作る法線（法線マップ: 緑チャンネルの向きを選択します）。 |

## マテリアル出力

その設定は、テクスチャーがサーフェスにどのように配置されるかを決めます:

- **タイルの幅**と**タイルの高さ**: テクスチャーの1タイルが覆う範囲をメートル単位で指定します。グラフが作成するものはすべて、継ぎ目なしでタイル全体に繰り返されます。
- **配置方法**: **UV座標**は面に沿って配置されます（プッシュ/プルの面は各面に沿って、メッシュはそのUVに沿って。UV単位1 = 1タイル）。**ボックス**は3つの軸のうち最も近いものから投影します。**トリプラナー**は、傾いたサーフェスで3つの投影をブレンドします（**ブレンドのシャープさ**: 値が大きいほど境界がくっきりします）。
- **法線の強さ**は法線の入力を拡大縮小します。**ディスプレイスメントのスケール**は、ディスプレイスメントの入力がメッシュの頂点をどれだけ動かすかを設定します。
- {{ui:入力を増やす}}では、OpenPBRの残りの入力を表示します: コート、ファズ、サブサーフェス、薄膜、透過、およびそれらの色。

## 高品質画像での表示

パストレーサーは、サーフェス全体で変化するベースカラー、ラフネス、メタルネス、不透明度、法線、エミッションをグラフから読み取ります。接続した他の入力（例えば、場所によって変わるコート）は、その平均値が使われます。どの入力かはパネルに表示されます。不透明度のテクスチャーによる切り抜きは、その形を表示し、その影は均一に透けます。発光するテクスチャーは、向いている方向を照らしますが、ランプとしてはサンプリングされません。

**ディスプレイスメント**はメッシュの頂点のみを動かします。そのため、詳細にするには細分化モディファイアーを追加してください（[モディファイアー](topic:modifiers)）。プッシュ/プルの面は形状を保ち、法線からバンプを得ます。

:::tip
WebGPUに対応したコンピューターでは、グラフはグラフィックカードで計算されます。対応していない場合は、プロセッサーで計算されます。結果は同じです。
:::
