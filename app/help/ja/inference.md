描画または編集ツールの動作中、ModelCraftはポインターの下にあるものを確認し、近くで最も有用なものにスナップします。マーカーは見つけたものを示し、左下のヒントがその名前を表示します。

## マーカーとヒント

| ヒント | マーカー | スナップ先 |
|---|---|---|
| エンドポイント | 緑の円 | エッジの端点 |
| 中点 | シアンの円 | エッジの中央 |
| 面の中心 | 青の円 | ポインターの下にある面の中央 |
| ガイド点 | グレー | メジャーで残したガイド点 |
| 原点 | オーカー | 赤、緑、青の軸が交わる位置 |
| 赤軸上 / 緑軸上 / 青軸上 | その色の線 | 開始点からその方向に沿った線 |
| エッジに平行 / エッジに垂直 | マゼンタの線 | 開始点から、記憶されたエッジに平行または垂直な線（下記を参照） |
| ロック | マゼンタの線 | 矢印キーまたは{{key:Shift}}でロックした方向 |
| エッジ上 | 赤い正方形 | エッジ上の任意の位置 |
| ガイド線上 | グレー | ガイド線上の任意の位置 |
| 面上 | 青のひし形 | 面上の任意の位置 |
| 平面上 | なし | ポインターが何もない空間にあるとき、開始した平面 |
| 地面上 | なし | 地面（赤と緑の平面）。ほかに何もない場合 |

開始点からの軸線がエッジまたはガイドと交差すると、ModelCraftは交点にスナップし、ヒントには両方の名前が表示されます。例: 「赤軸上、エッジ上」

## どのスナップが優先されるか

1. **点**（約12ピクセル以内）: エンドポイントが最優先され、次にガイド点、中点、ポインターの下にある面の中心、原点の順です。
2. **方向**（開始点から）: 赤、緑、青の軸、および記憶されたエッジに平行または垂直な方向。
3. **エッジ上**またはガイド線上。
4. **面上。**
5. **作図平面**、または地面。

面の背後に隠れているものにはスナップしません。目的の点が見えるように、{{ui:オービット}}で視点を回転させてください。

## 点から面上に描画する

{{ui:長方形}}、{{ui:円}}、{{ui:多角形}}を、角、中点、エッジ、または面の中心から開始すると、**ポインターの下にある面の平面内**に描画され、その面を切り抜きます。エッジは2つの面に属するため、ポインターがあるエッジの側によって決まります。長い箱の端面に描画するには、エッジの中点から開始し、ポインターを端面の内側に置きます。

## 平行と垂直

ModelCraftは、**最初のクリック前に、ポインターが最後に通過したエッジ**を記憶します。角またはエッジから開始すると、そのエッジを通過したものとみなされます。ツールが動作し始めると、ほかにホバーしたエッジは、それを置き換えません。

既存のエッジに平行な線を描くには:

1. {{key:L}}を押し、合わせたいエッジの上にポインターを置きます。
2. 開始点に移動し、可能であれば途中で他のエッジを横切らないようにして、クリックします。
3. そのエッジに平行な方向に移動します。線がマゼンタに変わり、ヒントに「エッジに平行」と表示されます。垂直も同様に、描画している平面内で機能します。

誤ったエッジが記憶された場合は、{{key:Esc}}を押し、正しいエッジの上にポインターを置いて、やり直してください。

## 方向をロックする

ツールの最初のクリック後、次の点を1本の線上に保つことができます:

| キー | ロック先 |
|---|---|
| {{key:Right}} | 赤軸 |
| {{key:Left}} | 緑軸 |
| {{key:Up}} | 青軸（真上） |
| {{key:Down}} | 記憶されたエッジに平行（上記を参照） |

同じ矢印キーをもう一度押すとロックを解除します。ステータスバーに「赤軸にロックしました。同じ矢印キーを押すとロックを解除します。」と表示されます。

ロック中は、点はポインターの位置に向かって線に沿ってスライドし、ホバーした点にも揃います。別の箱の角にホバーすると、その角までちょうどの距離で赤軸に沿った線を描けます。

**{{key:Shift}}**を押すと、現在スナップしている方向（軸、または平行）をロックします。押している間ロックされます。離すとロックが解除されます。

ロックは、{{ui:ライン}}、{{ui:長方形}}、{{ui:円}}、{{ui:多角形}}、{{ui:移動}}、{{ui:尺度変更}}、{{ui:メジャー}}で機能します。最初のクリック前は、代わりに矢印キーで視点をオービットします。

## グループの内部

グループまたはコンポーネントの内部を編集中は、軸はグループ自身の軸になります（グループと一緒に移動し、回転されている場合は一緒に回転します）。スナップは、グループの外側の点やエッジも引き続き検出するため、モデルのほかの部分に合わせて配置できます。
