**メッシュ**ワークスペースでは、[メッシュ](topic:meshes)を頂点、エッジ、面の単位で編集します。プッシュ/プルのジオメトリは **モデル**ワークスペースに残ります。

## 開く

- ツールバー左側の {{ui:ワークスペース}} リストで {{ui:メッシュ}} を選びます。選択中のメッシュが編集用に開きます。選択中のグループまたはコンポーネントは、先にメッシュに変換されます（元に戻す 1 回分）。
- または、メッシュをダブルクリックします。モデラーのキーを使っている場合は、メッシュを選択して {{key:Tab}} を押します。
- 何も選択していない場合、パネルには追加できるメッシュが表示されます: 平面、グリッド、立方体、円、円柱、円錐、球、アイコスフィア、トーラス。新しいメッシュはビューが向いている場所に配置され、編集用に開きます。

{{ui:モデルに戻る}}（またはリスト。モデラーのキーでは {{key:Tab}}、プッシュ/プルのキーでは何も選択していない状態で {{key:Esc}}）を選ぶと、選択したメッシュを残したままモデルに戻ります。メッシュワークスペースを開いている間、モデルの残りの部分は薄く表示され、モデルの作図ツールは使えなくなります。

## 選択

| 操作 | 対象 |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | 頂点、エッジ、面を選択 |
| クリック | 1 つを選択。{{key:Shift}}+クリックで追加または削除 |
| ボックスをドラッグ | 内側にあり、見えているものを選択。{{key:Shift}} で追加、{{key:Ctrl}} で削除 |
| {{key:Alt}}+クリック（エッジ）、またはダブルクリック | そのエッジループ（面モードでは面ループ、開いたエッジでは境界全体） |
| {{key:Ctrl}}+{{key:Alt}}+クリック（エッジ） | そのエッジリング |
| トリプルクリック | それにつながるすべて |

{{ui:選択}} グループには、{{ui:すべて}}、{{ui:連結}}、{{ui:ループ}}、{{ui:リング}}、{{ui:その他}}、{{ui:縮小}} もあります。

## 移動、回転、尺度変更

{{ui:移動}}、{{ui:回転}}、{{ui:尺度変更}} はポインターから始まります。動かしてから、クリックするか {{key:Enter}} を押して選択を配置するか、{{key:Esc}} でキャンセルします。{{key:X}}、{{key:Y}}、{{key:Z}}（または矢印キー）で軸を固定します。距離、角度、倍率を入力すると正確に指定できます。[計算](topic:value-box#calculations)も使えます。

**プロポーショナル編集**（{{ui:プロポーショナル}}、またはパネル）: 選択の近くにある頂点は、移動に追従します。離れるほど追従の度合いは弱くなり、設定した範囲まで、選んだ減衰に従います。{{ui:メッシュに沿ってのみ}} をオンにすると、直線ではなくエッジに沿って距離を測ります。

{{ui:スライド}} は、選択したエッジループを、隣接するエッジに沿って移動します。

## 形状を変更

| ツール | 働き |
|---|---|
| {{ui:押し出し}} | 選択した面を法線方向に引き出し、新しい側面を作ります（または、開いた境界エッジから面を作ります）。距離を入力します |
| {{ui:インセット}} | 選択した面の輪郭の内側に帯を作ります。面ごとに個別に行うには、{{key:I}} を再度押します |
| {{ui:ベベル}} | 選択したエッジ（または、{{key:Ctrl}}+{{key:Shift}}+{{key:B}} で頂点）を、指定した幅で切り落とします。ホイールまたはプラス・マイナスキーでセグメントを追加し、丸みのあるエッジにします |
| {{ui:ループカット}} | エッジを指し示すと、4 辺の面のリングを横切る新しいループが表示されます。ホイールで本数を設定し、クリックして切断します |
| {{ui:ナイフ}} | エッジや角の上で点をクリックします。{{key:Enter}} で、その間の面を、見えているとおりにまっすぐ切断します |
| {{ui:二分割}} | 画面上に線を描きます。選択した面（または全体）がその線に沿って切断されます |
| {{ui:スピン}} | 選択した面または開いたエッジを、青い軸のまわりに段階的に回転させます（段数はホイールで設定）。1 回転すると閉じます |
| {{ui:細分化}} | 選択したエッジを 2 つに分割します。面全体はグリッドになります |
| {{ui:マージ}} | 選択した頂点を 1 つにまとめ、その中心に配置します |
| {{ui:溶解}} | 選択を取り除きますが、サーフェスは残します。面がつながります |
| {{ui:塗りつぶし}} | 選択した開いた境界（または 2 つの開いたエッジの間）に面を作ります |
| {{ui:グリッド塗りつぶし}} | 偶数本のエッジからなる開いた境界を、四角形のグリッドで埋めます |
| {{ui:ブリッジ}} | 選択した 2 つの開いたエッジループを、面でつなぎます |
| {{ui:クリース}} | メッシュがサブディビジョンサーフェスで平滑化されたとき、選択したエッジがどの程度シャープに残るかを設定します。中心から離す、ホイールを使う（0.1 刻み）、または 0 から 1 の値を入力します。パネルには選択したエッジのクリースが表示され、入力した値も受け付けます。クリースされたエッジはマゼンタで表示されます |
| {{ui:反転}}、{{ui:スムーズ}}、{{ui:削除}} | 面を裏返します。頂点を隣接する頂点の方向へ平滑化します。選択モードに従って削除します |

いずれも、元に戻す 1 回分になります。テクスチャー座標、色、ウェイトは、新しい面と頂点に引き継がれます。

## リメッシュ

{{ui:リメッシュ}} は、メッシュ全体を同じ大きさの均等な三角形で作り直します。大きさは押したときに指定します（小さいほど細かく、処理は遅くなります）。穴を埋め、重なる部分をつなぎ、スカルプトによって伸びたメッシュを均します。鋭いエッジはわずかに丸くなります。UV、ペイント、クリースは作り直されます。元に戻す 1 回分です。

## リトポロジー

詳細なメッシュ（スカルプト、スキャン）の上に、よりきれいな新しいメッシュを作るには、パネルの {{ui:リトポロジー}} › **作成元** で詳細なメッシュを選択してから、次を行います。

- **移動した点をスナップ:** 移動する点と、押し出すエッジが、そのサーフェス上に配置されます。
- **選択した点をサーフェスに乗せる** で、選択した点をすぐにサーフェス上に移動します（元に戻す 1 回分）。
- **このメッシュのエッジを前面に表示** で、作成中のメッシュを表面の上に描画し、確認できるようにします。

## 直前の操作を調整

{{ui:インセット}}、{{ui:ベベル}}、{{ui:ループカット}}、{{ui:細分化}}、{{ui:スムーズ}}、{{ui:グリッド塗りつぶし}}、または {{ui:スピン}} の後は、パネルにその設定（幅、セグメント、プロファイル、切断数など）が表示されます。値を変更すると、操作は開始点からやり直され、元に戻す 1 回分のままです。
