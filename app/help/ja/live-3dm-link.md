別のプログラムでモデリングを続け、その結果をここで使います。レンダリング、ライティング、シーンのレイアウトに使えます。もう一方のプログラムで変更するたびに、ModelCraft 内の 1 つのグループが更新されます。

:::note
この接続には、同じコンピューター上の **CadCraft Studio** が必要です。ブラウザータブでは接続できません。インターネットを経由する通信はありません。スクリプトはこのコンピューター自身のアドレスで Studio と通信し、トークンを使います。
:::

:::warning
このリンクは、スクリプトのファイル書き出し機能と、もう一方のプログラムの代わりになるものを使って検証されています。Rhino や Grasshopper 自体ではまだ検証されていません。そこで問題が発生した場合は、表示されたメッセージをお知らせください。
:::

## 設定

1. Studio で ModelCraft を開きます。{{ui:設定}} › {{ui:ModelCraft}} › {{ui:アシスタント}} で、**AIアシスタントとスクリプトに ModelCraft の使用を許可する** にチェックを付けてから、**編集** をクリックします。
2. Studio で {{ui:アシスタントに接続}} を選びます。アドレスと、次に貼り付けるトークンが表示されます。
3. スクリプトをダウンロードします: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)。

## Rhinoから

1. Rhino のスクリプトエディターで `cadcraft_link.py` を実行します（Rhino 8 では Python 3）。
2. 初回は、アドレスとトークンを貼り付けます。これらはホームフォルダーの `.cadcraft-link.json` に保存され、モデル内には保存されません。Studio は起動するたびに新しいトークンを作るため、その場合はスクリプトが再度入力を求めます。

モデル全体が、ドキュメント名にちなんだ 1 つのグループとして取り込まれます（例: "chair (linked)"）。その後、変更は少し待つと取り込まれ、変更されたオブジェクトだけが送られます。停止するには、スクリプトをもう一度実行します。

## Grasshopperから

最初に Rhino でスクリプトを 1 回実行し、アドレスとトークンを保存しておきます。

1. Script コンポーネント（Python 3）を追加し、`cadcraft_link.py` の全文を貼り付けます。
2. 次の入力を設定します: `G`（ジオメトリ、リストアクセス付き）、`N`（名前、省略可）、`On`（ブール値のトグル）、`Target`（省略可: `model` または `part`、両方のアプリが開いている場合）。
3. `On` を true にします。

再計算のたびに `G` が送られ、前回送ったものと置き換わるため、ここにあるグループもスライダーをドラッグすると更新されます。出力 `a` には、何が起きたかが表示されます。コンポーネントごとに、それぞれ独自のグループを持ちます。

## グループでできること

- **移動、タグ付け、周囲への配置。** グループの位置とタグは、すべての更新で維持されます。隣接するものも同様です。
- **グループ内を編集しない。** 更新のたびに、グループ内の内容は置き換えられます。これらのオブジェクトは、もう一方のプログラムが管理します。
- **元に戻す。** 2 秒以内の更新は、1 つの元に戻す操作にまとめられるため、{{key:Mod+Z}} でドラッグ全体を取り消せます。次の更新で、モデルは再び一致する状態に戻ります。
- **保存。** 保存したファイルにはリンクが残ります。ファイルを開き直したあとにスクリプトを再度実行すると、同じグループが更新されます。

## 取り込まれるもの

メッシュ、ポリサーフェス、サーフェス、押し出しは、画面に表示されているメッシュとして取り込まれます。SubD はそのメッシュとして、曲線はエッジとして、ブロックは配置された場所にそのまま個別のオブジェクトとして（コンポーネントではなく）、レイヤーはタグとして、色と単位も取り込まれます。取り込まれ方は [.3dmモデルを読み込む](topic:import-3dm-files) を参照してください。

除外されるもの（件数は、もう一方のプログラムに表示されます）: 点、文字、寸法、ライトなど。

**一方向のみ。** ここでの変更は、もう一方のプログラムには戻りません。

## 問題が発生した場合

- **「ModelCraftまたはPartCraftのウィンドウで許可されていません」:** 設定の手順 1 を実行してください。
- **「Studioがトークンを拒否しました」:** Studio が再起動されています。新しいトークンをコピーして、スクリプトをもう一度実行してください。Grasshopper の場合は、先に Rhino で実行してください。
- **「CadCraft Studioに接続できません」:** Studio が実行されていないか、アドレスが変わっています。
