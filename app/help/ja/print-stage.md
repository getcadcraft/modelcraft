{{ui:Print stage}} は、プリンターのベッド上にモデルを配置し、スライスして、プリンターに送信します。先にファイルを書き出す必要はありません。3D Print アドオンに含まれ、既定でオンになっています。

:::note
この機能で実機のプリンターに印刷した実績はまだありません。スライサーは新しいものです。初回の印刷では最初のレイヤーを見守り、送信する前にレイヤープレビューを使ってください。
:::

## 作業内容

モデルをベッドに配置し、収まるかを確認して、スライスされたレイヤーを見て、プリンターに送るか G-code を保存します。

## 手順

1. ツールバーの {{ui:Print stage}} をクリックします。ビューの上にカードが開き、ベッドは破線の輪郭で示されます。
2. **ライブラリから追加**の下の検索欄に名前を入力し、{{ui:Search}} を押して、結果の {{ui:Add}} を押します。項目は原寸でベッドに配置されるか、収まるように縮小されます。ビューに見えている、既に描画またはインポート済みのものも、ベッドに含まれます。
3. **ベッド上**の下で、各項目のサイズを確認します。**ベッドの外**と表示された項目は移動が必要です。通常のツールを使って、ビュー内で項目を移動、回転、拡大縮小します。
4. {{ui:Arrange on the bed}} を押すと項目をベッド上に並べ、{{ui:Fit all on the bed}} を押すと、すべてがベッドに収まるまで縮小されます。
5. **プリンター**の下で、**ベッド**のサイズ、またはプリンターのプロファイルのいずれかを選びます。
6. **印刷設定**の下で、**材料**、**品質**、**インフィル %** を選びます。形状で必要な場合は、**オーバーハングの下にサポートを追加**にチェックを入れます。
7. {{ui:Preview layers}} を押し、**レイヤー**スライダーを動かして、スライスされたレイヤーを確認します。その後にステージや設定を変えた場合は、{{ui:Preview layers}} をもう一度押してください。
8. **接続**の下で、{{ui:USB cable}}、{{ui:Klipper (Moonraker)}}、{{ui:OctoPrint}}、または {{ui:PrusaLink}} を選びます。USB の場合は {{ui:Connect}} を押します。ネットワークプリンターの場合は、その**アドレス**を入力し(求められた場合は **API キー**も入力し)、{{ui:Test the connection}} を押します。
9. {{ui:Send to 3D printer}} を押します。カードは、ベッドが空いていること、正しい材料がセットされていることを確認し、時間、材料、温度を表示します。内容を確認して送信します。

プリンターの起動中であることを示すメッセージが表示されます。{{ui:Stop the print}} を押すと、ヒーター、ファン、モーターが止まります。ファイルだけが必要な場合は、{{ui:Save the G-code instead}} を押してください。

## 注意

- USB は、コンピューター上の Chrome または Edge で使用できます。印刷が終わるまでページを開いたままにしてください。閉じると、データの送信が止まります。
- ネットワークプリンターでは、このサイトのアクセスを許可する必要があります(Moonraker では `cors_domains` に追加し、OctoPrint では CORS をオンにして API キーをコピーします)。ブラウザーから、ネットワーク上の機器へのアクセス許可を求められる場合があります。
- 接続や送信は、ご自身がクリックするまで行われません。
- スライサーの一覧は**スライサー**の下にあります。{{ui:CadCraft basic (同梱、最速)}} は組み込みです。Kiri:Moto、PrusaSlicer、OrcaSlicer、Bambu Lab P2S は、それぞれ独自のアドオンで、カードまたは {{ui:Settings}} › {{ui:Add-ons}} でオンに切り替えます。PrusaSlicer と OrcaSlicer は、お使いのコンピューターにあるコピーを使い、コンピューター上の CadCraft Studio から動作します。
- 閉じたソリッドではないピースは除外され、カードには、それが形状全体のどれだけに当たるかが表示されます。
- レジン式プリンターについては、[レジン式プリンターでのスライス](topic:resin-printing) を参照してください。先にモデルを確認または修復する場合は、[サポート、壁の厚さ、中空化、修復](topic:print-tools) を参照してください。
