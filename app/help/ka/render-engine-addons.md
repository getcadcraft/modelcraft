დამატებას (პარამეტრები › დამატებები) შეუძლია ძრავა დაამატოს {{ui:Render a picture…}}-ის ძრავების სიაში. დამატების ავტორებისთვის სრული ტექსტი არის დამატების სპეციფიკაციის მე-16 ნაწილი; მოკლედ:

- დამატება არეგისტრირებს ძრავას ID-ით, რომელიც მის საკუთარ პრეფიქსს იწყებს, სახელით, არასავალდებულო პარამეტრებით და **ან** პროგრამით გასაშვებად, **ან** JavaScript-ში ფუნქციით, რომელიც სურათს ხატავს.
- პროგრამის გამშვებ ძრავას სჭირდება **`engine.run`** უფლება, რომელიც ჩანს დაყენებამდე და პარამეტრებში. ის მხოლოდ Studio-ში მუშაობს; ბრაუზერში ის ჩანს, როგორც ფაილი შესანახად.
- დამატება ასახელებს პროგრამას (უბრალო ფაილის სახელი: არასოდეს shell), სკრიპტს, რომელიც **ხელმოწერილ დამატებაშია**, და არგუმენტებს, რომლებიც ადგილმნიშვნელებისა და უბრალო სიტყვებისგან შედგება. Studio პროგრამას პოულობს ან ერთხელ გთხოვთ მიუთითოთ მისკენ.
- პირველად, როცა დამატება პროგრამას გაუშვებს, **Studio თქვენ ეკითხება თავის დიალოგში**: რომელი დამატება, რომელი პროგრამა და რომ სკრიპტს შეუძლია ყველაფერი, რაც თავად პროგრამას შეუძლია. დაუშვით მხოლოდ იმ დამატებისთვის, რომელსაც ენდობით. თქვენი პასუხი ამ დამატებისა და პროგრამისთვის დაიმახსოვრება.
- პაკეტი (სცენა USD-ად და პარამეტრების ფაილი, glTF ფაილით, თუ დამატება მას ითხოვს) და დამატების სკრიპტი ახალ დროებით საქაღალდეში ხვდება, პროგრამა იქ მუშაობს, და სურათი უბრუნდება დამატების ძრავის სახელით მონიშნული.

:::note
დამატებებს მხოლოდ დამატების API 1.4-დან შეუძლიათ რენდერის ძრავების დამატება. სამუშაო მაგალითი ღია კოდის ბრძანების ხაზის რენდერერისთვის თავის საცავშია; ის ამ რენდერერში ჯერ არ გაშვებულა.
:::
