ხელსაწყოს მუშაობისას, რომელიც ხატავს ან არედაქტირებს, ModelCraft უყურებს, რა არის მაჩვენებლის ქვეშ, და მიემაგრება ყველაზე სასარგებლოს მის მახლობლად. მარკერი აჩვენებს, რა იპოვა, ხოლო ქვედა მარცხენა კუთხეში მდებარე წვერი მის სახელს წერს.

## მარკერები და წვეროები

| წვერი | მარკერი | მიემაგრება |
|---|---|---|
| ბოლო წერტილი | მწვანე წრე | წიბოს ბოლო |
| შუა წერტილი | ცისფერი წრე | წიბოს შუა |
| წახნაგის ცენტრი | ლურჯი წრე | მაჩვენებლის ქვეშ მყოფი წახნაგის შუა |
| მოსახაზე წერტილი | ნაცრისფერი | წერტილი, რომელიც საზომმა ლენტმა დატოვა |
| სათავე | ოხრისფერი | სადაც წითელი, მწვანე და ლურჯი ღერძები იკვეთება |
| წითელ ღერძზე / მწვანე ღერძზე / ლურჯ ღერძზე | იმ ფერის ხაზი | ხაზი თქვენი საწყისი წერტილიდან იმ მიმართულებით |
| პარალელურად წიბოსთან / მართობულად წიბოსთან | იისფერი ხაზი | ხაზი თქვენი საწყისი წერტილიდან, წიბოს პარალელურად ან მართობულად (იხ. ქვემოთ) |
| ჩაკეტილია | იისფერი ხაზი | მიმართულება, რომელიც ჩაკეტეთ ისრის კლავიშით ან {{key:Shift}}-ით |
| წიბოზე | წითელი კვადრატი | წიბოს ნებისმიერ წერტილზე |
| მოსახაზეზე | ნაცრისფერი | მოსახაზე ხაზის ნებისმიერ წერტილზე |
| წახნაგზე | ლურჯი რომბი | წახნაგის ნებისმიერ წერტილზე |
| სიბრტყეზე | არ არის | სიბრტყე, რომელზეც დაიწყეთ, როცა მაჩვენებელი ცარიელ სივრცეზეა |
| მიწაზე | არ არის | მიწა (წითელ-მწვანე სიბრტყე), როცა სხვა არაფერია |

როცა ღერძის ხაზი თქვენი საწყისი წერტილიდან წიბოს ან მოსახაზეს კვეთს, ModelCraft მიემაგრება გადაკვეთას და წვეროში ორივე სახელი ჩანს, მაგალითად "წითელ ღერძზე, წიბოზე".

## რომელი მიმაგრება იმარჯვებს

1. **წერტილები** დაახლოებით 12 პიქსელში: ჯერ ბოლო წერტილები, შემდეგ მოსახაზე წერტილები, შუა წერტილები, მაჩვენებლის ქვეშ მყოფი წახნაგის ცენტრი და სათავე.
2. **მიმართულებები** საწყისი წერტილიდან: წითელი, მწვანე და ლურჯი ღერძები, და პარალელური ან მართობული დამახსოვრებული წიბოსთან.
3. **წიბოზე** ან მოსახაზე ხაზზე.
4. **წახნაგზე.**
5. **სახატავი სიბრტყე** ან მიწა.

წახნაგის უკან დამალული ობიექტები არასდროს მიემაგრება. დატრიალეთ ხედი, რომ დაინახოთ წერტილი, რომელიც გინდათ.

## წახნაგზე ხატვა წერტილიდან

{{ui:Rectangle}}, {{ui:Circle}} ან {{ui:Polygon}}, რომელიც დაიწყო კუთხიდან, შუა წერტილიდან, წიბოდან ან წახნაგის ცენტრიდან, იხატება **იმ წახნაგის სიბრტყეში, რომელიც მაჩვენებლის ქვეშაა**, და ჭრის ამ წახნაგს. წიბო ორ წახნაგს ეკუთვნის, ამიტომ წიბოს ის მხარე წყვეტს, სადაც მაჩვენებელია: გრძელი ყუთის ბოლოზე სახატავად დაიწყეთ ერთ-ერთი წიბოს შუა წერტილიდან, მაჩვენებელი ბოლო წახნაგის შიდა მხარეს.

## პარალელური და მართობული

ModelCraft იმახსოვრებს **ბოლო წიბოს, რომელზეც მაჩვენებელი გაიარა თქვენს პირველ დაწკაპუნებამდე**. კუთხეზე ან წიბოზე დაწყება ითვლება იმ წიბოზე გავლად. ხელსაწყოს მუშაობის დაწყების შემდეგ სხვა წიბოები, რომლებზეც მაჩვენებლით გადის, ამას არ ცვლის.

არსებული წიბოს პარალელური ხაზის დასახატავად:

1. დააჭირეთ {{key:L}}-ს და გადაატარეთ მაჩვენებელი წიბოზე, რომლის შესაბამისადაც გინდათ.
2. გადაიტანეთ საწყის წერტილამდე, თუ შეიძლება, სხვა წიბოების გადაკვეთის გარეშე, და დააწკაპუნეთ.
3. გადაიტანეთ იმ წიბოს პარალელურ მიმართულებით. ხაზი იისფერი ხდება და წვეროში წერია "პარალელურად წიბოსთან". მართობული ანალოგიურად მუშაობს, იმ სიბრტყეში, რომელზეც ხატავთ.

თუ არასწორი წიბო დამახსოვრდა, დააჭირეთ {{key:Esc}}-ს, გადაატარეთ მაჩვენებელი სწორ წიბოზე და დაიწყეთ თავიდან.

## მიმართულების ჩაკეტვა

ხელსაწყოს პირველი დაწკაპუნების შემდეგ შემდეგი წერტილი შეგიძლიათ ერთ ხაზზე დატოვოთ:

| კლავიში | ჩაკეტავს |
|---|---|
| {{key:Right}} | წითელ ღერძს |
| {{key:Left}} | მწვანე ღერძს |
| {{key:Up}} | ლურჯ ღერძს (პირდაპირ ზემოთ) |
| {{key:Down}} | დამახსოვრებული წიბოს პარალელურად |

ხელახლა დააჭირეთ იმავე ისარს, რომ გახსნათ. სტატუსის ზოლში წერია: "ჩაკეტილია წითელ ღერძზე. ხელახლა დააჭირეთ იმავე ისარს, რომ გახსნათ."

ჩაკეტვისას წერტილი ხაზის გასწვრივ სრიალებს იქით, სადაც მაჩვენებელია, და მაინც ემთხვევა წერტილებს, რომლებზეც გადაატარებთ: გადაატარეთ მეორე ყუთის კუთხეზე, რომ წითლის გასწვრივ ზუსტად იმდენი სიგრძის ხაზი დახაზოთ, რამდენადაც ეს კუთხე არის.

**{{key:Shift}}** ჩაკეტავს იმ მიმართულებას, რომელზეც ახლა ხართ მიმაგრებული (ღერძი ან პარალელური), სანამ ის დაჭერილი გაქვთ. გაუშვით და ის გაიხსნება.

ჩაკეტვა მუშაობს {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} და {{ui:Tape}} ხელსაწყოებში. პირველ დაწკაპუნებამდე ისრის კლავიშები ხედს ატრიალებს.

## ჯგუფის შიგნით

ჯგუფის ან კომპონენტის შიგნით რედაქტირებისას ღერძები ამ ჯგუფის საკუთარი ღერძებია (ისინი მასთან ერთად გადაადგილდება და ტრიალებს, თუ ის შემობრუნებული იყო). მიმაგრება მაინც პოულობს წერტილებსა და წიბოებს ჯგუფის გარეთ, ასე რომ შეგიძლიათ დანარჩენ მოდელთან გასწორება.
