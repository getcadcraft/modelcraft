ტექსტურა ბრტყელი სურათია; ბადე კი ბრტყელი არ არის. მისი **UV**-ები განსაზღვრავენ, სად ზის ყოველი წახნაგის ყოველი კუთხე ამ სურათზე. UV სამუშაო სივრცე ქმნის მათ: თქვენ ბადეს **ნაკერებზე** ჭრით, ბრტყლად აწყობთ ნაწილებს (**გაშლა**) და ათავსებთ კვადრატში (**შეფუთვა**).

## გახსნა

მონიშნეთ ბადე და სამუშაო სივრცის სიიდან აირჩიეთ {{ui:UV}}. ჯგუფი ან კომპონენტი ჯერ ბადედ იქცევა, ისევე როგორც ბადის სამუშაო სივრცეში. 3D ხედი მარცხენა ნახევარში გადადის; **UV რედაქტორი** მარჯვნივ აჩვენებს ბადის წახნაგებს, განლაგებულს ტექსტურის კვადრატზე. მონიშვნა ისე მუშაობს, როგორც ბადის სამუშაო სივრცეში, და ერთ ხედში მონიშნული მეორეშიც მონიშნულია.

## ნაკერების დადება

ნაკერები ის ადგილებია, სადაც ბადე შეიძლება გაიჭრას; ორივე ხედში წითლად ჩანს.

- მონიშნეთ წიბოები ({{ui:წიბო}}, ან {{key:2}}) და დააჭირეთ {{ui:ნაკერის დადება}}-ს ({{key:Ctrl+E}}). {{ui:ნაკერის მოხსნა}} ({{key:Ctrl+Shift+E}}) მათ აშორებს.
- {{ui:ნაკერები მკვეთრზე}} ნაკერს დებს ყველა მკვეთრ წიბოზე და ყველა წიბოზე, სადაც წახნაგები 60°-ზე მეტი კუთხით ერთვებიან: ყუთი იშლება თავის ექვს მხარედ.
- {{ui:ნაკერები UV-დან}} ნიშნავს ნაკერებს იმ ადგილებში, სადაც UV-ები უკვე წყდება, მაგალითად პროექციის შემდეგ.

დახურულ ნაწილს ბრტყლად გასაშლელად ნაკერები სჭირდება: სფეროს სულ ცოტა ერთი გაჭრა სჭირდება, მილს კი — გაჭრა მის სიგრძეზე.

## გაშლა

მონიშნეთ წახნაგები, რომლებიც უნდა განლაგდეს (ან არცერთი, მთელი ბადისთვის), და დააჭირეთ {{ui:გაშლა}}-ს ({{key:U}}). ყოველი ნაწილი ნაკერებს შორის ბრტყლად იშლება და თავის კუთხეებს რაც შეიძლება ზუსტად ინარჩუნებს (კუთხეებზე დაფუძნებული გაბრტყელება); შემდეგ ნაწილები კვადრატში იფუთება. {{ui:კონფორმული}} იგივეს აკეთებს უმცირეს კვადრატთა კონფორმული ასახვებით: უფრო სწრაფად, მაგრამ ძლიერად მრუდ ნაწილებზე ოდნავ ნაკლებად ზუსტად. ფორმა, რომლის დამზადებაც შეიძლება ბრტყელი ფურცლიდან, მაგალითად ცილინდრის გვერდი, ერთხელ გაჭრილი, იშლება სრულიად დეფორმაციის გარეშე.

## პროექცია

მარტივი ფორმებისთვის ხშირად საკმარისია პროექცია:

| პროექცია | რას აკეთებს |
| --- | --- |
| {{ui:ყუთი}} | ყოველი წახნაგი ყუთის იმ მხარეს, რომელსაც ყველაზე მეტად უყურებს |
| {{ui:ცილინდრი}} | ლურჯი ღერძის გარშემო: განივად კუთხე გარშემო, ზევით სიმაღლე |
| {{ui:სფერო}} | ცენტრიდან: განივად კუთხე გარშემო, ზევით განედი |
| {{ui:ხედიდან}} | როგორც წახნაგები ახლა ჩანს 3D ხედში |

წახნაგი, რომელიც ცილინდრის ან სფეროს შეერთებას კვეთს, ერთ ნაწილად რჩება, ამიტომ მისი UV-ები კვადრატის მარჯვენა კიდეს შეიძლება ოდნავ გადასცდეს; ტექსტურები იქ მეორდება.

## განლაგება

- {{ui:შეფუთვა}} ნაწილებს (კუნძულებს) კვადრატში ათავსებს ერთი ტექსელის ზომით, და თითოეულს ისე ატრიალებს, რომ ყველაზე ნაკლები ადგილი დაიკავოს. პანელი განსაზღვრავს მათ შორის დარჩენილ სივრცეს.
- {{ui:90° შებრუნება}} და {{ui:სარკე}} მონიშნული წახნაგების UV-ებს ატრიალებს ან ასარკისებს.
- UV რედაქტორში გადაათრიეთ მონიშნული წახნაგი, რომ მოძრაობდეს მონიშვნის UV-ები, ან მიუთითეთ რედაქტორზე და დააჭირეთ {{key:R}} ან {{key:S}}, შემდეგ გადაადგილეთ, რომ შეატრიალოთ ან მასშტაბი შეცვალოთ (დაწკაპუნება ინარჩუნებს, {{key:Esc}} აუქმებს). {{key:G}} გადააადგილებს გადათრევის გარეშე. ორმაგი დაწკაპუნება წახნაგზე (ან {{key:L}}) მონიშნავს მთლიან მის კუნძულს. ბორბალი ახდენს მასშტაბირებას; შუა ან მარჯვენა ღილაკით გადათრევა ხედს გადააადგილებს; {{key:F}} კვადრატს ისევ მთლიანად ჩაატევებს.

თითოეული ცვლილება ერთი დაბრუნების ბიჯია.

## შემოწმება

- {{ui:შაშხი}} ბადეზე აჩვენებს ნიშნებიან შაშხს მის UV-ებში: ერთგვაროვანი, კვადრატული უჯრები ნიშნავს, რომ ტექსტურა თანაბრად ზის; ნიშნები გვიჩვენებს, რა მიმართულებით მიდის ის.
- {{ui:გაჭიმვა}} ყოველ წახნაგს ფერით აღნიშნავს იმის მიხედვით, რამდენად აჭიმავს მას UV-ები: ლურჯი — არაფერი, მწვანეზე გავლით, წითელი — ძლიერად. პანელი ირჩევს, ზომავს თუ არა ეს **მოხრილ კუთხეებს** ან **შეცვლილ ზომას**, და აჩვენებს საშუალო მნიშვნელობას.
