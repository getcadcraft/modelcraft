{{ui:Export}} › {{ui:Live view}} ເປີດແຜງເທິງແອັບ ທີ່ສະແດງໂມເດວໃນແບບເຣຍທາມ: ທ້ອງຟ້າ ແລະ ດວງອາທິດຕາມສະຖານທີ່ ແລະ ວັນທີຂອງໂມເດວ, ເງາຂອງດວງອາທິດ, ລັກສະນະ ແລະ ວັດສະດຸທີ່ທ່ານໃຫ້ແກ່ໜ້າ, ໂຄມໄຟ, ແລະ ແສງທີ່ສະທ້ອນຈາກຝາ ແລະ ພື້ນ. ມັນຕິດຕາມສິ່ງທີ່ທ່ານເຮັດ: ເມື່ອທ່ານໝຸນມຸມມອງ ມັນກໍໝຸນຕາມ, ເມື່ອທ່ານປ່ຽນໂມເດວ ມັນສະແດງການປ່ຽນແປງໃນບໍ່ດົນ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ.

## ເປີດມັນ

1. ເລືອກ {{ui:Export}} › {{ui:Live view}}. ແຜງຈະເປີດຢູ່ມຸມລຸ່ມຂວາ.
2. ລາກແຖບຫົວເລື່ອງເພື່ອຍ້າຍມັນ, ດຶງມຸມຂອງມັນເພື່ອໃຫ້ໃຫຍ່ຂຶ້ນ.
3. {{ui:New window}} ຍ້າຍມັນໄປເປັນໜ້າຕ່າງຂອງມັນເອງ, ສຳລັບໜ້າຈໍທີສອງ. {{ui:Export}} › {{ui:Live view in a new window}} ເປີດມັນຢູ່ທີ່ນັ້ນທັນທີ. ຖ້າບຣາວເຊີຂອງທ່ານບລັອກໜ້າຕ່າງ pop-up, ມັນຈະເປີດເປັນແຜງ.
4. {{ui:Close}} ປິດມັນ.

## ຍ່າງຜ່ານໂມເດວ

1. ໝຸນມຸມມອງຫຼັກໄປບ່ອນທີ່ທ່ານຢາກຢືນ ແລະ ເລືອກ {{ui:Walk}}. ທ່ານຢືນເທິງພື້ນລຸ່ມຈຸດຕາຂອງມຸມມອງ, ສູງ 1.6 m.
2. ກົດມຸມມອງສົດ, ແລ້ວໃຊ້ {{key:W}} {{key:A}} {{key:S}} {{key:D}} ຫຼື ປຸ່ມລູກສອນ. ຖື {{key:Shift}} ເພື່ອແລ່ນ. ລາກເພື່ອເບິ່ງອ້ອມ.
3. ຂັ້ນບັນໄດສູງເຖິງ 40 cm ຈະຖືກປີນ (ບັນໄດ); ອັນໃດສູງກວ່ານັ້ນຄືກຳແພງ. ກຳແພງຈະຢຸດທ່ານ ແລະ ທ່ານຈະເລື່ອນໄປຕາມມັນ.
4. ເມື່ອ {{ui:Gravity}} ປິດ ທ່ານຈະບິນ: {{key:E}} ຂຶ້ນ, {{key:Q}} ລົງ.
5. {{key:Esc}} ຢຸດການຍ່າງ.

## ກະຈາຍພືດ, ຫີນ ແລະ ຄົນ

{{ui:Scatter}} ໃນແຖບຂອງມຸມມອງສົດ ເປີດແຜງ scatter ຂ້າງຮູບ. ຊຸດ scatter ກະຈາຍລາຍການຈາກຫໍສະໝຸດ entourage (ຕົ້ນໄມ້, ພຸ່ມໄມ້, ຫຍ້າ, ດອກໄມ້, ຫີນ, ຄົນ, ລົດ) ໄປທົ່ວສ່ວນໜຶ່ງຂອງໂມເດວ. ລາຍການຖືກວາດໃນມຸມມອງສົດເທົ່ານັ້ນ: ມັນບໍ່ແມ່ນເລຂາຄະນິດໃນໂມເດວ, ແລະ ມຸມມອງຫຼັກບໍ່ສະແດງມັນ.

1. **ເຕີມໃສ່ໜ້າ:** ເລືອກໜ້າ (ຫຼື ກຸ່ມ, ເຊັ່ນ ພູມສັນຖານ) ໃນ ModelCraft, ແລ້ວເລືອກ {{ui:Fill selection}}. ຊຸດນັ້ນຈະປົກຄຸມມັນ.
2. **ທາສີ:** ເລືອກ {{ui:Paint}}, ແລ້ວລາກທັບມຸມມອງສົດ. ເມື່ອເລືອກໜ້າ ການທາສີຈະລົງພຽງໜ້າເຫຼົ່ານັ້ນ; ເມື່ອບໍ່ໄດ້ເລືອກຫຍັງ ມັນຈະລົງທຸກສິ່ງທີ່ຢູ່ໃຕ້ແປງ, ລວມທັງພື້ນດ້ວຍ. {{ui:Brush size}} ກຳນົດແປງ; {{ui:Eraser}} ເອົາຈຸດທີ່ທາອອກ.
3. ໝາຍສິ່ງທີ່ຈະກະຈາຍ. ຕົວເລກຂ້າງແຕ່ລະອັນຄືນ້ຳໜັກຂອງມັນ: 3 ແລະ 1 ໝາຍຄວາມວ່າອັນທຳອິດສາມອັນຕໍ່ອັນທີສອງໜຶ່ງອັນ.

ຊຸດຖືກບັນທຶກໃນໄຟລ໌ .modelcraft ແລະ ຕິດຕາມໜ້າທີ່ພວກມັນປົກຄຸມເມື່ອທ່ານປ່ຽນແປງ. ຈຳນວນລາຍການສູງສຸດທີ່ມຸມມອງສົດວາດ ຖືກຕັ້ງໂດຍລະດັບຂອງ [ເຄື່ອງຂອງທ່ານ](topic:your-machine): 20 000 ສຳລັບ {{ui:Processor only}}, 100 000 ສຳລັບ {{ui:Graphics card, basic}}, ໜຶ່ງລ້ານສຳລັບ {{ui:Graphics card, high}}. ແຜງບອກວ່າວາງໄດ້ເທົ່າໃດ ຈາກຈຳນວນທີ່ຄວາມໜາແໜ້ນຕ້ອງການ: ວາງໄດ້ໜ້ອຍລົງເມື່ອຮອດງົບ, ຫຼື ບ່ອນທີ່ວັດຖຸອື່ນກີດກັນພວກມັນ. ລາຍການທີ່ໃກ້ກ້ອງຖືກວາດເປັນຕົວຂອງມັນເອງ; ລາຍການທີ່ໄກຖືກວາດເປັນຮູບຮ່າງງ່າຍໆດ້ວຍສີຂອງມັນ.

:::note
ລາຍການທີ່ກະຈາຍຢູ່ໃນມຸມມອງສົດ (ແລະ ການຍ່າງ, panorama ແລະ ຕົວສະແດງແບບ standalone ຂອງມັນ). ເຣັນເດີຮູບພາບຍັງບໍ່ວາດມັນ.
:::

## ແສງສະທ້ອນ

ແສງທີ່ສະທ້ອນຈາກຝາທີ່ມີແດດລົງໄປພື້ນ, ແລະ ດ້ານມືດຂອງຫ້ອງ, ຖືກຄິດໄລ່ດ້ວຍເສັ້ນທາງດຽວກັນກັບ [ຮູບທີ່ເຣັນເດີແລ້ວ](topic:render): ມັນເຣັນເດີ panorama ນ້ອຍໆຢູ່ຈຸດຕ່າງໆໃນໂມເດວ, ໃນພື້ນຫຼັງໃນທຸກແກນຂອງໂປຣເຊດເຊີ. ໃນຂະນະທີ່ມັນເຮັດວຽກ ແຖວລຸ່ມສຸດເວົ້າວ່າ {{ui:ແສງສະທ້ອນ: 40 %}}; ເມື່ອມັນພ້ອມແລ້ວ ມຸມມອງຈະຮັບເອົາມັນ. ຫຼັງຈາກການປ່ຽນແປງ ມັນຈະເລີ່ມໃໝ່.

:::note
ນີ້ແມ່ນການປະມານສຳລັບມຸມມອງສົດ, ບໍ່ແມ່ນຮູບທີ່ເຣັນເດີແລ້ວ: ລາຍລະອຽດນ້ອຍລະຫວ່າງຈຸດຈະໄດ້ແສງສະທ້ອນຂອງຈຸດທີ່ໃກ້ຄຽງ. ສຳລັບຮູບທີ່ສຳເລັດແລ້ວ ໃຫ້ໃຊ້ [ເຣັນເດີຮູບພາບ](topic:render).
:::

## ຄວາມສະຫວ່າງ ແລະ ສີ

ມຸມມອງສົດໃຊ້ຄວາມສະຫວ່າງ, ສົມດຸນສີຂາວ, ຄອນທຣາສ ແລະ view transform (ACES, AgX, filmic ຫຼື standard) ດຽວກັນກັບ [ເຣັນເດີຮູບພາບ](topic:render): ຕັ້ງມັນທີ່ນັ້ນ ແລະ ມຸມມອງສົດຈະປະຕິບັດຕາມ.

:::note
ບຣາວເຊີແຕກຕ່າງກັນ. ບ່ອນທີ່ບຣາວເຊີມີ WebGPU (Chrome ແລະ Edge ໃນ Windows, macOS ແລະ ChromeOS, Safari 26) ມຸມມອງສົດໃຊ້ມັນ; ບ່ອນອື່ນ (ບຣາວເຊີສ່ວນໃຫຍ່ໃນ Linux, ລະບົບ Apple ເກົ່າ) ມັນໃຊ້ WebGL 2 ແລະ ເບິ່ງຄືກັນ.
:::
