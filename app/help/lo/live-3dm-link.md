ສືບຕໍ່ໂມເດວຢູ່ບ່ອນທີ່ທ່ານໂມເດວ, ແລ້ວໃຊ້ຜົນລັບຢູ່ບ່ອນນີ້: ເພື່ອເຣັນເດີ, ໃຫ້ແສງ, ຫຼື ຈັດວາງສາກອ້ອມມັນ. ທຸກການປ່ຽນແປງໃນອີກໂປຣແກຣມຈະອັບເດດໜຶ່ງກຸ່ມໃນ ModelCraft.

:::note
ການເຊື່ອມຕໍ່ຕ້ອງການ **CadCraft Studio** ຢູ່ຄອມພິວເຕີດຽວກັນ. ແທັບບຣາວເຊີບໍ່ສາມາດເຮັດການເຊື່ອມຕໍ່ໄດ້. ບໍ່ມີຫຍັງຖືກສົ່ງຜ່ານອິນເຕີເນັດ: ສະຄຣິບຕິດຕໍ່ກັບ Studio ທີ່ທີ່ຢູ່ຂອງຄອມພິວເຕີນີ້ເອງ, ດ້ວຍໂທເຄັນ.
:::

:::warning
ການເຊື່ອມຕໍ່ນີ້ໄດ້ທົດສອບກັບໂປຣແກຣມຂຽນໄຟລ໌ຂອງສະຄຣິບ ແລະ ຕົວແທນແທນອີກໂປຣແກຣມ, ຍັງບໍ່ໄດ້ທົດສອບພາຍໃນ Rhino ຫຼື Grasshopper ເອງ. ຖ້າມີຫຍັງຜິດພາດຢູ່ບ່ອນນັ້ນ ກະລຸນາບອກພວກເຮົາວ່າມັນບອກຫຍັງ.
:::

## ຕັ້ງຄ່າ

1. ໃນ Studio ໃຫ້ເປີດ ModelCraft. ໃນ {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}}, ໃຫ້ໝາຍ **ໃຫ້ຜູ້ຊ່ວຍ AI ແລະ ສະຄຣິບໃຊ້ ModelCraft**, ແລ້ວ **ແກ້ໄຂ**.
2. ໃນ Studio ໃຫ້ເລືອກ **ເຊື່ອມຕໍ່ຜູ້ຊ່ວຍ**. ມັນຈະສະແດງທີ່ຢູ່ ແລະ ໂທເຄັນທີ່ທ່ານຈະວາງຂ້າງລຸ່ມ.
3. ດາວໂຫຼດສະຄຣິບ: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## ຈາກ Rhino

1. ແລ່ນ `cadcraft_link.py` ໃນ script editor ຂອງ Rhino (Python 3 ໃນ Rhino 8).
2. ເທື່ອທຳອິດ ໃຫ້ວາງທີ່ຢູ່ ແລະ ໂທເຄັນ. ມັນຖືກເກັບໄວ້ໃນ `.cadcraft-link.json` ໃນໂຟນເດີບ້ານຂອງທ່ານ, ບໍ່ເຄີຍຢູ່ໃນໂມເດວ. Studio ສ້າງໂທເຄັນໃໝ່ທຸກຄັ້ງທີ່ມັນເລີ່ມ, ສະນັ້ນສະຄຣິບຈະຖາມອີກຕອນນັ້ນ.

ທັງໂມເດວມາເປັນກຸ່ມດຽວ ທີ່ຕັ້ງຊື່ຕາມເອກະສານ, ຕົວຢ່າງ "chair (linked)". ຫຼັງຈາກນັ້ນ, ແຕ່ລະການປ່ຽນແປງຈະມາເມື່ອທ່ານຢຸດຊົ່ວຄາວ, ແລະ ສະເພາະວັດຖຸທີ່ປ່ຽນເທົ່ານັ້ນທີ່ຖືກສົ່ງ. ແລ່ນສະຄຣິບອີກຄັ້ງເພື່ອຢຸດ.

## ຈາກ Grasshopper

ແລ່ນສະຄຣິບໜຶ່ງຄັ້ງໃນ Rhino ກ່ອນ, ເພື່ອໃຫ້ທີ່ຢູ່ ແລະ ໂທເຄັນຖືກບັນທຶກໄວ້.

1. ເພີ່ມ Script component (Python 3) ແລະ ວາງ `cadcraft_link.py` ທັງໝົດໃສ່ມັນ.
2. ໃຫ້ມັນມີອິນພຸດເຫຼົ່ານີ້: `G` (ເລຂາຄະນິດ, ມີ list access), `N` (ຊື່, ບໍ່ບັງຄັບ), `On` (ສະວິດ boolean), ແລະ `Target` (ບໍ່ບັງຄັບ: `model` ຫຼື `part`, ຖ້າທັງສອງແອັບເປີດຢູ່).
3. ຕັ້ງ `On` ເປັນ true.

ທຸກການ solve ຈະສົ່ງ `G` ແລະ ແທນທີ່ສິ່ງທີ່ມັນສົ່ງຄັ້ງກ່ອນ, ດັ່ງນັ້ນການລາກ slider ຈະອັບເດດກຸ່ມຢູ່ບ່ອນນີ້. ຜົນອອກ `a` ບອກວ່າເກີດຫຍັງຂຶ້ນ. ແຕ່ລະ component ມີກຸ່ມຂອງຕົນເອງ.

## ສິ່ງທີ່ເຮັດໄດ້ກັບກຸ່ມ

- **ຍ້າຍ, ໃສ່ປ້າຍ, ສ້າງອ້ອມມັນ.** ບ່ອນທີ່ທ່ານວາງກຸ່ມ ແລະ ປ້າຍຂອງມັນຈະຄົງຢູ່ທຸກການອັບເດດ, ແລະ ສິ່ງທີ່ຢູ່ຂ້າງມັນກໍຄືກັນ.
- **ຢ່າແກ້ໄຂພາຍໃນມັນ.** ທຸກການອັບເດດຈະແທນທີ່ສິ່ງທີ່ຢູ່ໃນກຸ່ມ. ໂປຣແກຣມອື່ນເປັນເຈົ້າຂອງວັດຖຸເຫຼົ່ານັ້ນ.
- **ຍ້ອນກັບ.** ການອັບເດດທີ່ຫ່າງກັນບໍ່ເກີນສອງວິນາທີຈະໃຊ້ຂັ້ນຕອນຍ້ອນກັບຮ່ວມກັນ, ສະນັ້ນ {{key:Mod+Z}} ຈະຍ້ອນກັບການລາກທັງໝົດ. ການອັບເດດຕໍ່ໄປຈະນຳໂມເດວກັບມາໃຫ້ກົງກັນ.
- **ບັນທຶກ.** ໄຟລ໌ທີ່ບັນທຶກຈະເກັບການເຊື່ອມຕໍ່ໄວ້. ແລ່ນສະຄຣິບອີກຄັ້ງຫຼັງຈາກເປີດໃໝ່, ແລະ ກຸ່ມດຽວກັນຈະອັບເດດ.

## ສິ່ງທີ່ຖືກສົ່ງມາ

Meshes, polysurfaces, surfaces ແລະ extrusions ເປັນເມຊ໌ຕາມທີ່ທ່ານເຫັນໃນໜ້າຈໍ, SubD ເປັນເມຊ໌ຂອງມັນ, curves ເປັນຂອບ, blocks ເປັນວັດຖຸແຍກກັນຕາມບ່ອນທີ່ມັນຢູ່ (ບໍ່ແມ່ນ components), layers ເປັນປ້າຍ, ແລະ ສີ, ແລະ ໜ່ວຍ. ເບິ່ງ [ນຳເຂົ້າໄຟລ໌ .3dm](topic:import-3dm-files) ເພື່ອເບິ່ງວ່າສິ່ງເຫຼົ່ານີ້ປາກົດບ່ອນນີ້ແນວໃດ.

ຖືກຍົກເວັ້ນ, ມີຈຳນວນໃນໂປຣແກຣມອື່ນ: ຈຸດ, ຂໍ້ຄວາມ, ຂະໜາດ, ໄຟ ແລະ ອື່ນໆ.

**ທາງດຽວເທົ່ານັ້ນ.** ການປ່ຽນແປງບ່ອນນີ້ຈະບໍ່ກັບໄປໂປຣແກຣມອື່ນ.

## ຖ້າມີຫຍັງຜິດພາດ

- **"ບໍ່ມີໜ້າຕ່າງ ModelCraft ຫຼື PartCraft ທີ່ອະນຸຍາດ":** ໃຫ້ເຮັດຂັ້ນຕອນທີ 1 ຂອງການຕັ້ງຄ່າ.
- **"Studio ປະຕິເສດໂທເຄັນ":** Studio ໄດ້ເລີ່ມໃໝ່. ສຳເນົາໂທເຄັນໃໝ່ ແລະ ແລ່ນສະຄຣິບອີກຄັ້ງ. ສຳລັບ Grasshopper, ໃຫ້ແລ່ນໃນ Rhino ກ່ອນ.
- **"ເຊື່ອມຕໍ່ CadCraft Studio ບໍ່ໄດ້":** Studio ບໍ່ໄດ້ເຮັດວຽກຢູ່, ຫຼື ທີ່ຢູ່ໄດ້ປ່ຽນແລ້ວ.
