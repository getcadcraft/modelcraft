{{ui:Select}} ({{key:Space}}) ແມ່ນເຄື່ອງມືທີ່ ModelCraft ເລີ່ມຕົ້ນດ້ວຍ, ແລະ ເປັນອັນທີ່ {{key:Esc}} ພາທ່ານກັບມາ. ສິ່ງທີ່ຖືກເລືອກຈະປ່ຽນເປັນສີຟ້າ, ແລະ {{ui:Entity info}} ທາງຂວາຈະບອກວ່າມັນແມ່ນຫຍັງ.

## ຄລິກ

| ເຮັດແບບນີ້ | ເລືອກ |
|---|---|
| ຄລິກໜ້າ ຫຼື ຂອບ | ໜ້າ ຫຼື ຂອບນັ້ນ |
| ຄລິກກຸ່ມ ຫຼື ອົງປະກອບ | ທັງກຸ່ມ ຫຼື ອົງປະກອບ |
| ຄລິກສອງຄັ້ງທີ່ໜ້າ | ໜ້ານັ້ນ ແລະ ຂອບຂອງມັນ |
| ຄລິກສອງຄັ້ງທີ່ຂອບ | ຂອບນັ້ນ ແລະ ໜ້າທັງສອງດ້ານ |
| ຄລິກສອງຄັ້ງທີ່ກຸ່ມ ຫຼື ອົງປະກອບ | ເປີດມັນເພື່ອແກ້ໄຂ (ເບິ່ງ [ກຸ່ມ ແລະ ອົງປະກອບ](topic:groups-components)) |
| ຄລິກສາມຄັ້ງທີ່ໜ້າ ຫຼື ຂອບ | ທຸກຢ່າງທີ່ເຊື່ອມກັບມັນ: ວັດຖຸທັງໝົດ |
| ຄລິກພື້ນທີ່ຫວ່າງ | ບໍ່ມີຫຍັງ (ລຶບການເລືອກ) |
| ຄລິກສອງຄັ້ງທີ່ພື້ນທີ່ຫວ່າງ ໃນຂະນະແກ້ໄຂກຸ່ມ | ປິດກຸ່ມ |

ຂອບຄລິກໂດນງ່າຍກວ່າໜ້າ: ເມື່ອຕົວຊີ້ຢູ່ໃນລະຍະບໍ່ຫຼາຍ pixel ຈາກຂອບ, ການຄລິກຈະເລືອກເອົາຂອບ.

## ລາກກ່ອງ

- **ຈາກຊ້າຍໄປຂວາ** ແຕ້ມກ່ອງທຶບ: ການເລືອກແບບ **window**. ມີແຕ່ສິ່ງທີ່ຢູ່ພາຍໃນກ່ອງທັງໝົດເທົ່ານັ້ນຈຶ່ງຖືກເລືອກ.
- **ຈາກຂວາໄປຊ້າຍ** ແຕ້ມກ່ອງເສັ້ນປະ: ການເລືອກແບບ **crossing**. ທຸກສິ່ງທີ່ກ່ອງສຳຜັດຈະຖືກເລືອກ, ແລະ ໜ້າຈະຖືກເລືອກເມື່ອກ່ອງຢູ່ພາຍໃນໜ້ານັ້ນທັງໝົດ.

ກຸ່ມ ຫຼື ອົງປະກອບນັບເປັນສິ່ງດຽວ: window ຕ້ອງບັນຈຸມັນທັງໝົດ, ສ່ວນ crossing ພຽງແຕ່ຕ້ອງສຳຜັດກັບມັນ.

## ເພີ່ມ ແລະ ລຶບ

ກົດປຸ່ມຄ້າງໄວ້ໃນຂະນະທີ່ຄລິກ ຫຼື ລາກ:

| ປຸ່ມ | ຜົນ |
|---|---|
| {{key:Shift}} | ສະຫຼັບ: ເພີ່ມສິ່ງທີ່ບໍ່ໄດ້ເລືອກ, ລຶບສິ່ງທີ່ເລືອກຢູ່ |
| {{key:Mod}} | ເພີ່ມ |
| {{key:Shift}} ແລະ {{key:Mod}} ພ້ອມກັນ | ລຶບ |

ເພື່ອເລືອກທຸກຢ່າງໃນແບບ (ຫຼື ທຸກຢ່າງໃນກຸ່ມທີ່ທ່ານກຳລັງແກ້ໄຂ), ກົດ {{key:Mod+A}}.

## ລຶບການເລືອກ

ກົດ {{key:Esc}} (ເມື່ອ {{ui:Select}} ເປັນເຄື່ອງມື), ຫຼື ຄລິກພື້ນທີ່ຫວ່າງ.

## ລຶບສິ່ງທີ່ຖືກເລືອກ

ກົດ {{key:Delete}} ຫຼື {{key:Backspace}}. ໜ້າ, ຂອບ, ກຸ່ມ ແລະ ເສັ້ນນຳທາງໃນການເລືອກຈະຖືກລຶບໃນຂັ້ນຕອນດຽວ; {{key:Mod+Z}} ຈະເອົາມັນກັບມາ.

ການລຶບຂອບຈະລຶບໜ້າທີ່ຕ້ອງການມັນ, ເວັ້ນເສຍແຕ່ວ່າຂອບນັ້ນພຽງແຕ່ແຍກສອງໜ້າທີ່ຢູ່ໃນລະນາບດຽວກັນ: ໃນກໍລະນີນັ້ນ ສອງໜ້າຈະລວມເປັນໜຶ່ງ. ການລຶບໜ້າຈະເຫຼືອຂອບຂອງມັນໄວ້. ເບິ່ງ [ລຶບ ແລະ ເຮັດຄວາມສະອາດ](topic:erase).

## ເລືອກພາຍໃນກຸ່ມ

ການຄລິກກຸ່ມຈະເລືອກທັງກຸ່ມ. ເພື່ອເລືອກໜ້າທີ່ຢູ່ພາຍໃນ, ໃຫ້ຄລິກສອງຄັ້ງທີ່ກຸ່ມເພື່ອເປີດມັນ, ແລ້ວຈຶ່ງຄລິກ. ໃນຂະນະທີ່ກຸ່ມເປີດຢູ່, ການຄລິກຈະເຖິງແຕ່ສິ່ງທີ່ຢູ່ພາຍໃນເທົ່ານັ້ນ; ສິ່ງອື່ນຈະຈາງລົງ. ກົດ {{key:Esc}} ໂດຍບໍ່ມີສິ່ງໃດຖືກເລືອກ, ຫຼື ຄລິກສອງຄັ້ງທີ່ພື້ນທີ່ຫວ່າງ, ເພື່ອປິດມັນ.

{{ui:Outliner}} ທາງຊ້າຍເລືອກກຸ່ມ ແລະ ອົງປະກອບດ້ວຍຊື່, ເຊິ່ງເປັນປະໂຫຍດເມື່ອພວກມັນຖືກເຊື່ອງຢູ່ຫຼັງສິ່ງອື່ນ.
