{{ui:Render a picture…}} ມີຕົວເລືອກ **Engine** ຢູ່ເໜືອ Mode. ເອນຈິນຂອງພວກເຮົາສອງຢ່າງມີຢູ່ສະເໝີ ແລະ ໃຊ້ໄດ້ທຸກບ່ອນ; ສ່ວນເສີມສາມາດເພີ່ມເຂົ້າໄດ້ຫຼາຍກວ່ານັ້ນ, ແລະ ໃນ CadCraft Studio ລາຍການຍັງມີໂປຣແກຣມທີ່ຮັບເອົາສາກໄປເຮັດວຽກຕໍ່ນຳອີກ.

| Engine | ມັນເຮັດຫຍັງ | ຢູ່ໃສ |
|---|---|---|
| Built-in: Fast | ພາບນິ່ງທີ່ໄວ: ແສງກາງເວັນ, ເງົາອ່ອນ, ລັກສະນະແກ້ວ ແລະ ໂລຫະ, ໃນບໍ່ກີ່ວິນາທີ | ເບລາເຊີ ແລະ Studio |
| Built-in: Path tracer | ແສງທີ່ສະທ້ອນລະຫວ່າງພື້ນຜິວ, ໃນການ໌ດກຣາບິກ ຫຼື ໂປຣເຊດເຊີຂອງທ່ານ, ຄິວການເຣັນເດີ ແລະ ຄອມພິວເຕີເຄື່ອງອື່ນໃນເຄືອຂ່າຍຂອງທ່ານ | ເບລາເຊີ ແລະ Studio |
| ເອນຈິນຂອງສ່ວນເສີມ | ມັນແຕ້ມ ແລະ ສົ່ງຮູບກັບຄືນ: ເບິ່ງ [Draw the picture with another program](topic:render-other-program) | ເບລາເຊີ (ເອນຈິນທີ່ຂຽນດ້ວຍ JavaScript) ຫຼື Studio (ເອນຈິນທີ່ເປີດໂປຣແກຣມ) |
| ໂປຣແກຣມທີ່ຮັບເອົາສາກໄປ | Studio ໃສ່ສາກໃນໂຟນເດີຂອງມັນ ແລະ ຮັກສາໃຫ້ກົງກັນ | Studio |
| Open in … | ບັນທຶກສາກ ແລະ ເປີດມັນໃນໂປຣແກຣມ; ບໍ່ມີຫຍັງກັບຄືນມາ: ເບິ່ງ [Open the scene in another program](topic:render-open-in) | ເວັບບັນທຶກໄຟລ໌ |

## ການເລືອກເຮັດວຽກແນວໃດ

- ການເລືອກ Fast ຫຼື Path tracer ຈະປ່ຽນ Mode ໄປພ້ອມກັນ, ແລະ ກັບກັນ. ສິ່ງອື່ນໃນກ່ອງໂຕ້ຕອບຈະບໍ່ປ່ຽນສຳລັບຜູ້ທີ່ບໍ່ເຄີຍໃຊ້ເອນຈິນອື່ນ.
- ເອນຈິນທີ່ບໍ່ພ້ອມໃຊ້ຈະຍັງຢູ່ໃນລາຍການພ້ອມເຫດຜົນ ("not found", "needs a newer version"); ທ່ານບໍ່ສາມາດເລືອກມັນໄດ້. ໃນເບລາເຊີ ເອນຈິນທີ່ເຮັດວຽກພຽງໃນ Studio ຈະສະແດງ "saves a file": {{ui:Render a picture…}} ຈະບັນທຶກສາກ ແລະ ການຕັ້ງຄ່າຂອງມັນເປັນໄຟລ໌ທີ່ທ່ານນຳໄປໃຫ້ໂປຣແກຣມນັ້ນ.
- ການເລືອກຈະຖືກບັນທຶກພ້ອມການຕັ້ງຄ່າການເຣັນເດີຂອງໄຟລ໌, ແລະ ເອນຈິນທີ່ທ່ານເລືອກຄັ້ງສຸດທ້າຍຈະເປັນເອນຈິນເລີ່ມຕົ້ນສຳລັບໄຟລ໌ທີ່ບໍ່ມີການເລືອກຂອງຕົນເອງ.
- ຮູບຈາກໂປຣແກຣມອື່ນຈະບອກວ່າໂປຣແກຣມໃດແຕ້ມມັນ ແລະ ເວີຊັນຂອງມັນ, ທັງໃນກ່ອງໂຕ້ຕອບ ແລະ ໃນຄິວການເຣັນເດີ. ຄຳໝັ້ນສັນຍາຂອງໜ້າ [Render](topic:render) ຄອບຄຸມພຽງ**ເອນຈິນຂອງພວກເຮົາເອງ**: ໂປຣແກຣມອື່ນໃຫ້ແສງ, ປັບໂທນ ແລະ ເກັບຕົວຢ່າງໃນແບບຂອງມັນເອງ, ສະນັ້ນສອງຮູບຂອງສາກດຽວກັນຈະຄ້າຍກັນໃນມຸມກ້ອງ, ດວງຕາເວັນ, ໂຄມໄຟ ແລະ ການເປີດຮັບແສງ, ແຕ່ບໍ່ຄືກັນທຸກພິກເຊນ.

## ສິ່ງທີ່ທຸກເອນຈິນໄດ້ຮັບ

ສາກຖືກສົ່ງໄປຍັງໂປຣແກຣມອື່ນເປັນ **ແພັກເກັດ**: ໂມເດວເປັນໄຟລ໌ USD (ໄຟລ໌ດຽວກັບທີ່ [Save as USD](topic:usd) ຂຽນ), ແລະ ໄຟລ໌ການຕັ້ງຄ່າທີ່ເກັບສິ່ງທີ່ເຄື່ອງນຳເຂົ້າ USD ບໍ່ສາມາດໄວ້ວາງໃຈໄດ້: ຄ່າວັດສະດຸທີ່ແນ່ນອນ, ໂຄມໄຟທີ່ເປີດພ້ອມພະລັງ ແລະ ໂປຣໄຟລ໌ແສງ, ດວງຕາເວັນ, ທ້ອງຟ້າ, ການເປີດຮັບແສງ ແລະ ກ້ອງຕາມທີ່ກ່ອງໂຕ້ຕອບຈະແຕ້ມ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດໄປທີ່ໃດເລີຍ.

## ຄິວການເຣັນເດີ

ຮູບ ຫຼື ອະນິເມຊັນສຳລັບໂປຣແກຣມອື່ນສາມາດລໍຖ້າຢູ່ໃນ [the render queue](topic:render#the-render-queue) ເໝືອນກັບຂອງພວກເຮົາເອງ; ວຽກຂອງມັນຈະຈື່ໄວ້ວ່າມັນເປັນສຳລັບເອນຈິນໃດ. ອະນິເມຊັນຈະຖືກສົ່ງໄປໂປຣແກຣມໃນການເຮັດວຽກຄັ້ງດຽວ.
