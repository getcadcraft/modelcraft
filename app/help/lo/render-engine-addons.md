ສ່ວນເສີມ (Settings › Add-ons) ສາມາດເພີ່ມເອນຈິນເຂົ້າໃນລາຍການ Engine ຂອງ {{ui:Render a picture…}} ໄດ້. ເນື້ອຫາເຕັມສຳລັບຜູ້ຂຽນສ່ວນເສີມແມ່ນພາກທີ 16 ຂອງສະເປັກສ່ວນເສີມ; ໂດຍຫຍໍ້ແລ້ວ:

- ສ່ວນເສີມລົງທະບຽນເອນຈິນດ້ວຍ id ທີ່ເລີ່ມດ້ວຍຊື່ຂອງມັນເອງ, ຊື່, ການຕັ້ງຄ່າຕາມຕ້ອງການ, ແລະ **ຢ່າງໃດຢ່າງໜຶ່ງ** ໂປຣແກຣມທີ່ຈະເປີດ **ຫຼື** ຟັງຊັນໃນ JavaScript ທີ່ແຕ້ມຮູບ.
- ເອນຈິນທີ່ເປີດໂປຣແກຣມຕ້ອງການສິດ **`engine.run`**, ທີ່ສະແດງກ່ອນການຕິດຕັ້ງ ແລະ ໃນ Settings. ມັນເຮັດວຽກພຽງໃນ Studio; ໃນເບລາເຊີມັນສະແດງເປັນໄຟລ໌ໃຫ້ບັນທຶກ.
- ສ່ວນເສີມລະບຸໂປຣແກຣມ (ຊື່ໄຟລ໌ທຳມະດາ: ບໍ່ແມ່ນ shell), ສະຄຣິບທີ່ **ຢູ່ພາຍໃນສ່ວນເສີມທີ່ລົງນາມແລ້ວ**, ແລະ ອາກິວເມັນທີ່ປະກອບດ້ວຍຕົວຍຶດຕຳແໜ່ງ ແລະ ຄຳທຳມະດາ. Studio ຈະຊອກຫາໂປຣແກຣມ ຫຼື ຖາມໃຫ້ທ່ານຊີ້ມັນຄັ້ງດຽວ.
- ໃນຄັ້ງທຳອິດທີ່ສ່ວນເສີມເປີດໂປຣແກຣມ, **Studio ຈະຖາມທ່ານໃນກ່ອງໂຕ້ຕອບຂອງມັນເອງ**: ສ່ວນເສີມໃດ, ໂປຣແກຣມໃດ, ແລະ ສະຄຣິບສາມາດເຮັດສິ່ງໃດກໍໄດ້ທີ່ໂປຣແກຣມເຮັດໄດ້. ອະນຸຍາດພຽງສຳລັບສ່ວນເສີມທີ່ທ່ານໄວ້ວາງໃຈ. ຄຳຕອບຂອງທ່ານຈະຖືກຈື່ໄວ້ສຳລັບສ່ວນເສີມ ແລະ ໂປຣແກຣມນັ້ນ.
- ແພັກເກັດ (ສາກເປັນ USD ແລະ ໄຟລ໌ການຕັ້ງຄ່າ, ພ້ອມໄຟລ໌ glTF ເມື່ອສ່ວນເສີມຂໍ) ແລະ ສະຄຣິບຂອງສ່ວນເສີມຈະຖືກໃສ່ໃນໂຟນເດີຊົ່ວຄາວໃໝ່, ໂປຣແກຣມຈະເຮັດວຽກຢູ່ບ່ອນນັ້ນ, ແລະ ຮູບຈະກັບມາພ້ອມໝາຍຊື່ເອນຈິນຂອງສ່ວນເສີມ.

:::note
ສ່ວນເສີມສາມາດເພີ່ມເອນຈິນເຣັນເດີໄດ້ພຽງຈາກ add-on API 1.4. ຕົວຢ່າງການເຮັດວຽກສຳລັບເຄື່ອງເຣັນເດີແບບບັນທັດຄຳສັ່ງໂອເພນຊອດ ຢູ່ໃນບ່ອນເກັບຂອງມັນເອງ; ມັນຍັງບໍ່ເຄີຍຖືກເຮັດວຽກໃນເຄື່ອງເຣັນເດີນັ້ນ.
:::
