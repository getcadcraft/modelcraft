ເທັກເຈີເປັນຮູບພາບຮາບ; ເມຊ໌ບໍ່ຮາບ. **UV** ຂອງມັນບອກວ່າແຕ່ລະມຸມຂອງແຕ່ລະໜ້າຢູ່ຕຳແໜ່ງໃດໃນຮູບພາບ. ພື້ນທີ່ເຮັດວຽກ UV ສ້າງມັນຂຶ້ນມາ: ທ່ານຕັດເມຊ໌ອອກຕາມ **ຮອຍຕໍ່**, ວາງສ່ວນຕ່າງໆໃຫ້ຮາບ (**Unwrap**), ແລ້ວຈັດໃສ່ໃນສີ່ຫຼ່ຽມຈັດຕຸລັດ (**ຈັດເຂົ້າກັນ**).

## ເປີດມັນ

ເລືອກເມຊ໌ ແລ້ວເລືອກ {{ui:UV}} ໃນລາຍການ {{ui:ພື້ນທີ່ເຮັດວຽກ}}. ກຸ່ມ ຫຼືຄອມໂພເນັນຈະກາຍເປັນເມຊ໌ກ່ອນ, ຄືກັບໃນພື້ນທີ່ເຮັດວຽກ {{ui:ເມຊ໌}}. ມຸມມອງ 3D ຈະຍ້າຍໄປເບື້ອງຊ້າຍເຄິ່ງໜຶ່ງ; ຕົວແກ້ໄຂ **UV** ທາງຂວາຈະສະແດງໜ້າຂອງເມຊ໌ທີ່ຈັດວາງເທິງສີ່ຫຼ່ຽມເທັກເຈີ. ການເລືອກເຮັດວຽກຄືກັບໃນພື້ນທີ່ເຮັດວຽກ {{ui:ເມຊ໌}}, ແລະສິ່ງທີ່ທ່ານເລືອກໃນມຸມມອງໜຶ່ງຈະຖືກເລືອກໃນອີກມຸມມອງໜຶ່ງເຊັ່ນກັນ.

## ໝາຍຮອຍຕໍ່

ຮອຍຕໍ່ແມ່ນບ່ອນທີ່ເມຊ໌ອາດຖືກຕັດອອກ; ມັນສະແດງເປັນສີແດງໃນທັງສອງມຸມມອງ.

- ເລືອກຂອບ ({{ui:ຂອບ}}, ຫຼື {{key:2}}) ແລ້ວກົດ {{ui:ໝາຍຮອຍຕໍ່}} ({{key:Ctrl+E}}). {{ui:ລຶບຮອຍຕໍ່}} ({{key:Ctrl+Shift+E}}) ຈະເອົາມັນອອກ.
- {{ui:ຮອຍຕໍ່ຢູ່ມຸມແຫຼມ}} ໝາຍທຸກຂອບແຫຼມ ແລະທຸກຂອບທີ່ໜ້າມາພົບກັນທີ່ມຸມເກີນ 60°: ກ່ອງຈະແບ່ງອອກເປັນ 6 ດ້ານ.
- {{ui:ຮອຍຕໍ່ຈາກ UV}} ໝາຍຮອຍຕໍ່ຕຳແໜ່ງທີ່ UV ແຕກຢູ່ແລ້ວ, ຕົວຢ່າງ ຫຼັງຈາກການສາຍພາບ.

ສ່ວນທີ່ປິດຕ້ອງມີຮອຍຕໍ່ເພື່ອໃຫ້ຮາບ: ລູກບານຕ້ອງມີຢ່າງໜ້ອຍໜຶ່ງຮອຍຕັດ, ທໍ່ຕ້ອງມີຮອຍຕັດຕາມຄວາມຍາວ.

## Unwrap

ເລືອກໜ້າທີ່ຈະຈັດວາງ (ຫຼືບໍ່ເລືອກເລີຍ ສຳລັບທັງເມຊ໌) ແລ້ວກົດ {{ui:Unwrap}} ({{key:U}}). ແຕ່ລະສ່ວນລະຫວ່າງຮອຍຕໍ່ຈະຖືກເຮັດໃຫ້ຮາບ ໂດຍຮັກສາມຸມຂອງມັນໃຫ້ຖືກຕ້ອງເທົ່າທີ່ເປັນໄປໄດ້ (ການເຮັດໃຫ້ຮາບຕາມມຸມ), ຈາກນັ້ນສ່ວນຕ່າງໆຈະຖືກຈັດເຂົ້າໃນສີ່ຫຼ່ຽມ. {{ui:Conformal}} ຈະ unwrap ດ້ວຍການ map ແບບ conformal ດ້ວຍກຳລັງສອງນ້ອຍທີ່ສຸດ (least-squares) ແທນ: ໄວກວ່າ, ແຕ່ຖືກຕ້ອງໜ້ອຍກວ່າເລັກນ້ອຍໃນສ່ວນທີ່ໂຄ້ງຫຼາຍ. ຮູບຮ່າງທີ່ສາມາດເຮັດຈາກແຜ່ນຮາບ, ເຊັ່ນດ້ານຂ້າງຂອງຊິລິນເດີທີ່ຕັດໜຶ່ງຄັ້ງ, ຈະ unwrap ໂດຍບໍ່ມີການຍືດເລີຍ.

## ການສາຍພາບ

ສຳລັບຮູບຮ່າງງ່າຍໆ ການສາຍພາບມັກພຽງພໍ:

| ການສາຍພາບ | ມັນເຮັດຫຍັງ |
| --- | --- |
| {{ui:ກ່ອງ}} | ແຕ່ລະໜ້າໄປຍັງດ້ານຂອງກ່ອງທີ່ໜ້ານັ້ນຫັນໄປຫາຫຼາຍທີ່ສຸດ |
| {{ui:ຊິລິນເດີ}} | ວົນຮອບແກນສີຟ້າ: ແນວນອນແມ່ນມຸມຮອບ, ແນວຕັ້ງແມ່ນຄວາມສູງ |
| {{ui:ທົງກົມ}} | ຈາກຈຸດກາງ: ແນວນອນແມ່ນມຸມຮອບ, ແນວຕັ້ງແມ່ນລະດັບເສັ້ນຂະໜານ |
| {{ui:ຈາກມຸມມອງ}} | ຕາມທີ່ໜ້າຖືກເບິ່ງເຫັນໃນມຸມມອງ 3D ໃນຕອນນີ້ |

ໜ້າທີ່ຂ້າມຈຸດຕໍ່ຂອງຊິລິນເດີ ຫຼືທົງກົມຈະຖືກເກັບໄວ້ເປັນສ່ວນດຽວ, ດັ່ງນັ້ນ UV ຂອງມັນອາດຍາວເກີນຂອບຂວາຂອງສີ່ຫຼ່ຽມເລັກນ້ອຍ; ເທັກເຈີຈະຊ້ຳຊ້ອນຢູ່ບ່ອນນັ້ນ.

## ຈັດວາງ

- {{ui:ຈັດເຂົ້າກັນ}} ຈັດສ່ວນຕ່າງໆ (ເກາະ) ເຂົ້າໃນສີ່ຫຼ່ຽມທີ່ຂະໜາດ texel ດຽວກັນ, ແຕ່ລະອັນຖືກໝຸນເພື່ອໃຊ້ພື້ນທີ່ໜ້ອຍທີ່ສຸດ. ແຜງຕັ້ງຄ່າຊ່ອງຫວ່າງທີ່ເຫຼືອລະຫວ່າງພວກມັນ.
- {{ui:ໝຸນ 90°}} ແລະ {{ui:ສະທ້ອນ}} ໝຸນ ຫຼືສະທ້ອນ UV ຂອງໜ້າທີ່ເລືອກ.
- ໃນຕົວແກ້ໄຂ UV, ລາກໜ້າທີ່ເລືອກເພື່ອຍ້າຍ UV ຂອງການເລືອກ, ຫຼືຊີ້ໃສ່ຕົວແກ້ໄຂ ແລ້ວກົດ {{key:R}} ຫຼື {{key:S}} ແລ້ວຍ້າຍເພື່ອໝຸນ ຫຼືປັບຂະໜາດ (ການຄລິກໜຶ່ງຄັ້ງຈະຮັກສາມັນໄວ້, {{key:Esc}} ຍົກເລີກ). {{key:G}} ຍ້າຍໂດຍບໍ່ຕ້ອງລາກ. ຄລິກສອງຄັ້ງໃສ່ໜ້າ (ຫຼື {{key:L}}) ເພື່ອເລືອກເກາະທັງໝົດ. ລໍ້ເລື່ອນຈະຊູມ; ລາກດ້ວຍປຸ່ມກາງ ຫຼືປຸ່ມຂວາເພື່ອເລື່ອນ; {{key:F}} ຈະປັບສີ່ຫຼ່ຽມໃຫ້ພໍດີອີກຄັ້ງ.

ທຸກການປ່ຽນແປງເປັນຂັ້ນຕອນຍ້ອນກັບໜຶ່ງຂັ້ນ.

## ກວດສອບ

- {{ui:ຕາຕະລາງ}} ສະແດງຕາຕະລາງທີ່ມີປ້າຍກຳກັບເທິງເມຊ໌ໃນ UV ຂອງມັນ: ຕາຕະລາງສີ່ຫຼ່ຽມທີ່ສະໝໍ່າສະເໝີໝາຍຄວາມວ່າເທັກເຈີວາງຢ່າງສະໝໍ່າສະເໝີ; ປ້າຍກຳກັບສະແດງວ່າມັນໄປທິດທາງໃດ.
- {{ui:ຍືດ}} ໃສ່ສີໃຫ້ແຕ່ລະໜ້າຕາມຈຳນວນທີ່ UV ຂອງມັນຍືດມັນ: ສີຟ້າຄືບໍ່ຍືດ, ຜ່ານສີຂຽວ, ຈົນຮອດສີແດງຄືຍືດຫຼາຍ. ແຜງຈະເລືອກວ່າຈະວັດ **ມຸມທີ່ງໍ** ຫຼື **ຂະໜາດທີ່ປ່ຽນ** ແລະສະແດງຄ່າສະເລ່ຍ.
