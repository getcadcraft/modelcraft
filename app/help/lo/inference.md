ໃນຂະນະທີ່ເຄື່ອງມືແຕ້ມ ຫຼື ແກ້ໄຂກຳລັງເຮັດວຽກ, ModelCraft ຈະເບິ່ງສິ່ງທີ່ຢູ່ໃຕ້ຕົວຊີ້ ແລະ ດູດເກາະເຂົ້າກັບສິ່ງທີ່ມີປະໂຫຍດທີ່ສຸດທີ່ຢູ່ໃກ້ຄຽງ. ເຄື່ອງໝາຍຈະສະແດງສິ່ງທີ່ພົບ ແລະ ປາຍທີ່ມຸມລຸ່ມຊ້າຍຈະບອກຊື່ຂອງມັນ.

## ເຄື່ອງໝາຍ ແລະ ຄຳບອກ

| ຄຳບອກ | ເຄື່ອງໝາຍ | ດູດເກາະເຂົ້າກັບ |
|---|---|---|
| Endpoint | ວົງມົນສີຂຽວ | ປາຍຂອງຂອບ |
| Midpoint | ວົງມົນສີຟ້າອ່ອນ | ກາງຂອງຂອບ |
| Center of face | ວົງມົນສີຟ້າ | ກາງຂອງໜ້າທີ່ຢູ່ໃຕ້ຕົວຊີ້ |
| Guide point | ສີເທົາ | ຈຸດນຳທາງທີ່ສາຍວັດຊ້າຍໄວ້ |
| Origin | ສີ ochre | ບ່ອນທີ່ແກນແດງ, ຂຽວ ແລະ ຟ້າມາພົບກັນ |
| On red axis / On green axis / On blue axis | ເສັ້ນສີນັ້ນ | ເສັ້ນຈາກຈຸດເລີ່ມຕົ້ນຂອງທ່ານໄປຕາມທິດທາງນັ້ນ |
| Parallel to edge / Perpendicular to edge | ເສັ້ນສີບົວ | ເສັ້ນຈາກຈຸດເລີ່ມຕົ້ນຂອງທ່ານ ຂະໜານ ຫຼື ຕັ້ງສາກກັບຂອບທີ່ຈຳໄວ້ (ເບິ່ງດ້ານລຸ່ມ) |
| Locked | ເສັ້ນສີບົວ | ທິດທາງທີ່ທ່ານລັອກດ້ວຍປຸ່ມລູກສອນ ຫຼື {{key:Shift}} |
| On edge | ສີ່ຫຼ່ຽມສີແດງ | ບ່ອນໃດກໍໄດ້ຕາມຂອບ |
| On guide | ສີເທົາ | ບ່ອນໃດກໍໄດ້ຕາມເສັ້ນນຳທາງ |
| On face | ເພັດສີຟ້າ | ບ່ອນໃດກໍໄດ້ເທິງໜ້າ |
| On plane | ບໍ່ມີ | ຣະນາບທີ່ທ່ານເລີ່ມ, ເມື່ອຕົວຊີ້ຢູ່ເທິງບ່ອນຫວ່າງ |
| On the ground | ບໍ່ມີ | ພື້ນ (ຣະນາບສີແດງ-ຂຽວ), ເມື່ອບໍ່ມີຫຍັງອື່ນຢູ່ນັ້ນ |

ເມື່ອເສັ້ນແກນຈາກຈຸດເລີ່ມຕົ້ນຂອງທ່ານຕັດຂອບ ຫຼື ເສັ້ນນຳທາງ, ModelCraft ຈະດູດເກາະເຂົ້າກັບຈຸດຕັດ ແລະ ຄຳບອກຈະບອກທັງສອງ, ເຊັ່ນ "On red axis, on edge".

## ການດູດເກາະໃດຊະນະ

1. **ຈຸດ** ພາຍໃນປະມານ 12 ພິກເຊວ: ປາຍຂອງຂອບກ່ອນ, ຈາກນັ້ນຈຸດນຳທາງ, ຈຸດກາງ, ກາງຂອງໜ້າທີ່ຢູ່ໃຕ້ຕົວຊີ້ ແລະ ຈຸດກຳເນີດ.
2. **ທິດທາງ** ຈາກຈຸດເລີ່ມຕົ້ນ: ແກນແດງ, ຂຽວ ແລະ ຟ້າ, ແລະ ຂະໜານ ຫຼື ຕັ້ງສາກກັບຂອບທີ່ຈຳໄວ້.
3. **ຢູ່ຂອບ** ຫຼື ເສັ້ນນຳທາງ.
4. **ຢູ່ໜ້າ.**
5. **ຣະນາບແຕ້ມ**, ຫຼື ພື້ນ.

ສິ່ງທີ່ຖືກຊ່ອນຢູ່ຫຼັງໜ້າຈະບໍ່ດູດເກາະເລີຍ. ໃຫ້ໝຸນມຸມມອງເພື່ອໃຫ້ເຫັນຈຸດທີ່ທ່ານຕ້ອງການ.

## ແຕ້ມເທິງໜ້າຈາກຈຸດ

{{ui:ສີ່ແຈສາກ}}, {{ui:ວົງມົນ}} ຫຼື {{ui:ຫຼາຍແຈ}} ທີ່ເລີ່ມຈາກມຸມ, ຈຸດກາງ, ຂອບ ຫຼື ກາງຂອງໜ້າ ຈະຖືກແຕ້ມ **ໃນຣະນາບຂອງໜ້າທີ່ຢູ່ໃຕ້ຕົວຊີ້**, ແລະ ຕັດໜ້ານັ້ນ. ຂອບໜຶ່ງເປັນຂອງສອງໜ້າ, ດັ່ງນັ້ນດ້ານຂອງຂອບທີ່ຕົວຊີ້ຢູ່ຈະເປັນຕົວຕັດສິນ: ເພື່ອແຕ້ມທີ່ປາຍຂອງກ່ອງຍາວ, ເລີ່ມຈາກກາງຂອງຂອບໜຶ່ງ ໂດຍໃຫ້ຕົວຊີ້ຢູ່ພາຍໃນໜ້າປາຍພໍດີ.

## ຂະໜານ ແລະ ຕັ້ງສາກ

ModelCraft ຈື່**ຂອບສຸດທ້າຍທີ່ຕົວຊີ້ຜ່ານກ່ອນການຄລິກທຳອິດຂອງທ່ານ**. ການເລີ່ມຈາກມຸມ ຫຼື ຈາກຂອບ ຖືວ່າຜ່ານຂອບນັ້ນ. ເມື່ອເຄື່ອງມືເຮັດວຽກແລ້ວ, ຂອບອື່ນທີ່ທ່ານຊີ້ຈະບໍ່ປ່ຽນມັນ.

ເພື່ອແຕ້ມເສັ້ນຂະໜານກັບຂອບທີ່ມີຢູ່:

1. ກົດ {{key:L}} ແລ້ວຊີ້ຂອບທີ່ທ່ານຕ້ອງການໃຫ້ກົງກັນ.
2. ເລື່ອນໄປຫາຈຸດເລີ່ມຕົ້ນ, ໂດຍບໍ່ຂ້າມຂອບອື່ນຖ້າເປັນໄປໄດ້, ແລ້ວຄລິກ.
3. ເລື່ອນໄປໃນທິດທາງຂະໜານກັບຂອບນັ້ນ. ເສັ້ນຈະປ່ຽນເປັນສີບົວ ແລະ ປາຍຈະຂຽນວ່າ "Parallel to edge". ຕັ້ງສາກກໍເຮັດໃນລັກສະນະດຽວກັນ, ພາຍໃນຣະນາບທີ່ທ່ານກຳລັງແຕ້ມ.

ຖ້າຂອບທີ່ຈຳໄວ້ບໍ່ຖືກ, ກົດ {{key:Esc}}, ຊີ້ຂອບທີ່ຖືກຕ້ອງ, ແລ້ວເລີ່ມໃໝ່.

## ລັອກທິດທາງ

ຫຼັງຈາກການຄລິກທຳອິດຂອງເຄື່ອງມື, ທ່ານສາມາດຮັກສາຈຸດຕໍ່ໄປໃຫ້ຢູ່ເສັ້ນດຽວໄດ້:

| ປຸ່ມ | ລັອກໃສ່ |
|---|---|
| {{key:Right}} | ແກນແດງ |
| {{key:Left}} | ແກນຂຽວ |
| {{key:Up}} | ແກນຟ້າ (ຊີ້ຂຶ້ນ) |
| {{key:Down}} | ຂະໜານກັບຂອບທີ່ຈຳໄວ້ (ເບິ່ງດ້ານເທິງ) |

ກົດລູກສອນດຽວກັນອີກເທື່ອເພື່ອປົດລັອກ. ແຖບສະຖານະຈະຂຽນວ່າ "Locked to the red axis. Press the same arrow to unlock."

ໃນຂະນະທີ່ລັອກຢູ່, ຈຸດຈະເລື່ອນຕາມເສັ້ນໄປຫາບ່ອນທີ່ຕົວຊີ້ຢູ່, ແລະ ຍັງຕົງກັບຈຸດທີ່ທ່ານຊີ້ຢູ່: ຊີ້ມຸມຂອງກ່ອງອື່ນເພື່ອແຕ້ມເສັ້ນຕາມແກນແດງໄປໄກເທົ່າກັບມຸມນັ້ນພໍດີ.

**{{key:Shift}}** ລັອກທິດທາງໃດກໍຕາມທີ່ທ່ານດູດເກາະຢູ່ໃນຕອນນີ້ (ແກນ ຫຼື ຂະໜານ), ຕາບໃດທີ່ທ່ານຍັງຖືມັນຢູ່. ປ່ອຍມືເພື່ອປົດລັອກ.

ການລັອກເຮັດວຽກໃນ {{ui:ເສັ້ນ}}, {{ui:ສີ່ແຈສາກ}}, {{ui:ວົງມົນ}}, {{ui:ຫຼາຍແຈ}}, {{ui:ຍ້າຍ}}, {{ui:ປັບຂະໜາດ}} ແລະ {{ui:ສາຍວັດ}}. ກ່ອນການຄລິກທຳອິດ, ປຸ່ມລູກສອນຈະໝຸນມຸມມອງແທນ.

## ພາຍໃນກຸ່ມ

ໃນຂະນະທີ່ທ່ານແກ້ໄຂພາຍໃນກຸ່ມ ຫຼື ອົງປະກອບ, ແກນແມ່ນແກນຂອງກຸ່ມເອງ (ພວກມັນເຄື່ອນຍ້າຍໄປກັບມັນ, ແລະ ໝຸນໄປກັບມັນຖ້າມັນຖືກໝຸນ). ການດູດເກາະຍັງຊອກຫາຈຸດ ແລະ ຂອບທີ່ຢູ່ນອກກຸ່ມ, ດັ່ງນັ້ນທ່ານສາມາດຈັດແນວສິ່ງຕ່າງໆກັບສ່ວນທີ່ເຫຼືອຂອງໂມເດວໄດ້.
