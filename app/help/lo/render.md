{{ui:ເຣັນເດີຮູບພາບ…}} ສ້າງຮູບຂອງມຸມມອງທີ່ເບິ່ງຄືແສງກາງເວັນແທນທີ່ຈະເປັນຮູບແຕ້ມ: ມີທ້ອງຟ້າ, ດວງອາທິດຕາມສະຖານທີ່ ແລະ ວັນທີຂອງໂມເດວ, ເງົາອ່ອນ, ແສງຈາກທັງທ້ອງຟ້າທີ່ເຮັດໃຫ້ມຸມ ແລະ ຊ່ອງຫວ່າງມືດລົງ, ແລະ ສີທີ່ອາດເບິ່ງຄືແກ້ວ, ໂລຫະ ຫຼື ສີເງົາ. ໂມເດວບໍ່ຖືກປ່ຽນແປງ.

## ເຣັນເດີມຸມມອງ

1. ຕັ້ງມຸມມອງຕາມທີ່ທ່ານຕ້ອງການ: ໝຸນ, ຊູມ, ເລືອກ [ສາກ](topic:scenes), ເຊື່ອງສິ່ງທີ່ບໍ່ຄວນສະແດງ. ຮູບຈະໃຊ້ກ້ອງຂອງມຸມມອງນັ້ນເອງ.
2. ກົດ {{ui:ສົ່ງອອກ}} ໃນກຸ່ມ {{ui:ໄຟລ໌}}, ແລ້ວກົດ {{ui:ເຣັນເດີຮູບພາບ…}}.
3. ເລືອກ {{ui:ສາກ}} ຖ້າສາກທີ່ກົດຢູ່ບໍ່ແມ່ນສິ່ງທີ່ທ່ານຕ້ອງການ (ເບິ່ງ [ການຕັ້ງຄ່າສາກລ່ວງໜ້າ](topic:render#scene-presets-a-good-picture-in-one-click)), ເລືອກ {{ui:ຂະໜາດ}}, ແລ້ວກົດ {{ui:ເຣັນເດີ}}.

   ຮູບຈະຄ່ອຍໆປາກົດຂຶ້ນ ແລະ ລຽບຂຶ້ນໃນແຕ່ລະຮອບ. {{ui:ຢຸດ}} (ຫຼື {{key:Esc}}) ຈະຢຸດກ່ອນເວລາ ແລະ ເກັບຮູບທີ່ໄດ້ມາແລ້ວ.

4. ກົດ {{ui:ບັນທຶກ}} ເພື່ອດາວໂຫຼດ (ເປັນ PNG ຖ້າ {{ui:ບັນທຶກເປັນ}} ບໍ່ໄດ້ກຳນົດເປັນຢ່າງອື່ນ).

:::tip
ເລີ່ມດ້ວຍ {{ui:ສະບັບຮ່າງ}} ທີ່ {{ui:ຂະໜາດມຸມມອງ}} ເພື່ອກວດກ້ອງ ແລະ ລັກສະນະ, ແລ້ວເຣັນເດີ {{ui:ດີ}} ຫຼື {{ui:ດີທີ່ສຸດ}} ທີ່ຂະໜາດໃຫຍ່ກວ່າສຳລັບຮູບສຸດທ້າຍ.
:::

## ຊຸດສາກ: ຮູບທີ່ດີດ້ວຍການຄລິກດຽວ

ດ້ານເທິງຂອງກ່ອງໂຕ້ຕອບມີປຸ່ມ {{ui:ສາກ}} ສີ່ປຸ່ມ. ແຕ່ລະປຸ່ມຕັ້ງທ້ອງຟ້າ, ຄວາມສະຫວ່າງ, ພື້ນດິນ, ເສັ້ນຂອບ, ຄຸນນະພາບ ແລະ ດວງອາທິດໃນຄລິກດຽວ, ດັ່ງນັ້ນບໍ່ຕ້ອງຮຽນຮູ້ຫຍັງກ່ອນຮູບທຳອິດ. ຄລິກປຸ່ມໜຶ່ງ ແລ້ວກົດ {{ui:ເຣັນເດີ}}.

| ສາກ | ສິ່ງທີ່ມັນຕັ້ງ | ໃຊ້ສຳລັບ |
|---|---|---|
| {{ui:ພາຍນອກ}} | ທ້ອງຟ້າໃສ, ດວງອາທິດຂອງໂມເດວເອງ, ເປີດພື້ນດິນ | ຕຶກຈາກພາຍນອກ |
| {{ui:ພາຍໃນ}} | ທ້ອງຟ້າມີເມກປົກຄຸມ (ແສງສະໝໍ່າສະເໝີ, ບໍ່ມີແສງແດດແຂງ), ສະຫວ່າງກວ່າເຄິ່ງຂັ້ນ | ມຸມມອງຈາກພາຍໃນຫ້ອງ |
| {{ui:ມຸມມອງໜ້າຕັດ}} | ສະຕູດິໂອສີຂາວ, ບໍ່ມີພື້ນດິນ, ເສັ້ນຂອບໃນເຣັນເດີໄວ | ໂມເດວທີ່ຖືກຕັດດ້ວຍໜ້າຕັດ |
| {{ui:ກາງຄືນ}} | ດວງອາທິດຕົກ (ເວລາທ່ຽງຄືນໃນລະດູໜາວ ສຳລັບເຄິ່ງໂລກຂອງສະຖານທີ່), ສະຫວ່າງກວ່າໜຶ່ງຂັ້ນ | ໂຄມໄຟທີ່ສ່ອງໂມເດວ. ຖ້າບໍ່ມີໂຄມໄຟ ຮູບຈະມືດ |

- {{ui:ເລືອກຕາມມຸມມອງນີ້}} ເລືອກໃຫ້ທ່ານ: {{ui:ມຸມມອງໜ້າຕັດ}} ເມື່ອເປີດການຕັດໜ້າຕັດ, {{ui:ພາຍໃນ}} ເມື່ອກ້ອງຢູ່ໃນໂມເດວ, ນອກຈາກນັ້ນໃຊ້ {{ui:ພາຍນອກ}}. ຄັ້ງທຳອິດທີ່ເປີດກ່ອງໂຕ້ຕອບ ມັນຈະເລີ່ມແບບນີ້ເອງ.
- ທຸກການຕັ້ງຄ່າຢູ່ດ້ານລຸ່ມ ແລະ ສາມາດປ່ຽນໄດ້. ເມື່ອທ່ານປ່ຽນໜຶ່ງຄ່າທີ່ສາກຕັ້ງ, ບໍ່ມີປຸ່ມໃດກົດຄ້າງຢູ່ແລ້ວ ແລະ ແຖວລຸ່ມປຸ່ມຈະບອກວ່າການຕັ້ງຄ່າເປັນຂອງທ່ານເອງ. ກົດສາກອີກຄັ້ງເພື່ອໃຫ້ຄ່າຂອງມັນກັບຄືນ.
- ສາກບໍ່ແຕະຕ້ອງເອນຈິນ, ໂໝດ, ຂະໜາດ, ວັດສະດຸ, ກ້ອງ ຫຼື ໂຄມໄຟ.

:::note
ສາກໃຫ້ຄ່າດຽວກັນໃນ ModelCraft ແລະ BimCraft. ຮູບສຸດທ້າຍຈະເບິ່ງແນວໃດ ຂຶ້ນກັບໂມເດວ ແລະ ກາດກຣາຟິກຂອງທ່ານ.
:::

ເມື່ອດວງອາທິດຢູ່ລຸ່ມຂອບຟ້າໃນເວລາທີ່ເລືອກ ມັນຄືກາງຄືນ: ທ້ອງຟ້າມືດລົງ ແລະ [ໂຄມໄຟ](topic:lights) ຂອງໂມເດວຈະສ່ອງມັນ. ກ່ອງໂຕ້ຕອບຈະບອກແບບນັ້ນ.

ການຕັ້ງຄ່າຈະຖືກບັນທຶກໄວ້ໃນໄຟລ໌ `.modelcraft`, ດັ່ງນັ້ນຮູບຕໍ່ໄປຂອງໂມເດວດຽວກັນຈະເລີ່ມຈາກບ່ອນທີ່ທ່ານຢຸດໄວ້.

## ເຮັດໃຫ້ສີເບິ່ງຄືແກ້ວ ຫຼື ໂລຫະ

ພາຍໃຕ້ {{ui:ວັດສະດຸ}}, ທຸກສີທີ່ເຫັນຢູ່ໜ້າຈໍມີລັກສະນະໜຶ່ງ: {{ui:ດ້ານ}}, {{ui:ກຶ່ງເງົາ}}, {{ui:ເງົາ}}, {{ui:ໂລຫະ}}, {{ui:ໂລຫະຂັດເງົາ}}, {{ui:ແກ້ວ}} ຫຼື {{ui:ແກ້ວດ້ານ}}. {{ui:ໜ້າທີ່ບໍ່ໄດ້ທາສີ}} ແມ່ນໜ້າທີ່ບໍ່ມີສີຂອງຕົນເອງ.

ເພື່ອເຮັດໃຫ້ໜ້າຕ່າງເປັນແກ້ວ, [ທາສີ](topic:paint) ບານໜ້າຕ່າງດ້ວຍສີດຽວ, ແລ້ວຕັ້ງສີນັ້ນເປັນ {{ui:ແກ້ວ}}. ແກ້ວຈະໃຫ້ທ້ອງຟ້າ ແລະ ສິ່ງທີ່ຢູ່ຫຼັງມັນສະແດງຜ່ານ, ມີສີຕາມສີຂອງມັນ, ແລະ ສະທ້ອນທ້ອງຟ້າ.

:::note
ໃນໂໝດ {{ui:ໄວ}}, ແກ້ວ ແລະ ໂລຫະສະທ້ອນທ້ອງຟ້າ ບໍ່ແມ່ນສ່ວນອື່ນຂອງໂມເດວ, ແລະ ແສງບໍ່ງໍຜ່ານແກ້ວ. ໂໝດ {{ui:ຄຸນນະພາບສູງ (path traced)}} ຂ້າງລຸ່ມເຮັດທັງສອງຢ່າງ.
:::

## ຄຸນນະພາບສູງ

ເລືອກ {{ui:ໂໝດ}} › {{ui:ຄຸນນະພາບສູງ (path traced)}} ເພື່ອໃຫ້ໄດ້ຮູບທີ່ຕິດຕາມແສງໃນແບບທີ່ກ້ອງເຫັນ:

- ແສງສະທ້ອນລະຫວ່າງພື້ນຜິວ, ດັ່ງນັ້ນຫ້ອງທີ່ມີແສງຜ່ານໜ້າຕ່າງ ຫຼື ຈາກໂຄມໄຟ ຈະສະຫວ່າງທົ່ວທັງຮອບ ແລະ ສີຈະໄຫຼໄປຫາເພື່ອນບ້ານ;
- ແກ້ວເປັນແກ້ວແທ້: ແສງງໍຜ່ານມັນ ແລະ ມັນສະທ້ອນໂມເດວ;
- ໂລຫະ ແລະ ພື້ນຜິວຂັດເງົາສະທ້ອນສ່ວນອື່ນຂອງໂມເດວ;
- ແຜງແສງສ່ອງເປັນແຜງ ພ້ອມເງົາອ່ອນ.

ມັນຊ້າກວ່າ {{ui:ໄວ}} ຫຼາຍ: ແຕ່ລະຮອບຕິດຕາມແສງຂອງທຸກ pixel ໃໝ່. ຮູບເລີ່ມຕົ້ນເປັນເມັດ ແລະ ຈະຊັດຂຶ້ນເມື່ອຕົວຢ່າງສະສົມ, ດັ່ງນັ້ນໃຫ້ເລີ່ມນ້ອຍ ({{ui:ຂະໜາດມຸມມອງ}}, {{ui:ສະບັບຮ່າງ}}) ແລະ ເລືອກ {{ui:ເວລາຈຳກັດ}}: ເມື່ອໝົດເວລາ ຮູບທີ່ມີຢູ່ຈະຖືກເກັບໄວ້. {{ui:ຢຸດ}} ກໍ່ເກັບມັນໄວ້ເຊັ່ນກັນ. ຮອບທຳອິດລໍຖ້າໃນຂະນະທີ່ບຣາວເຊີກຽມ path tracer.

ບ່ອນທີ່ບຣາວເຊີມີ WebGPU, path tracer ແມ່ນຂອງ CadCraft ເອງ ແລະ ເຮັດວຽກໃນກາດກຣາຟິກ; ແຖວລຸ່ມຮູບຈະບອກ {{ui:ປະມວນຜົນ path tracing ໃນກາດກຣາຟິກ (WebGPU)}}. ຫຼັງຈາກ {{ui:ຢຸດ}} ຫຼື ໝົດເວລາຈຳກັດ, {{ui:ສືບຕໍ່}} ຈະດຳເນີນຕໍ່ດ້ວຍຮູບດຽວກັນຈົນຄົບຕົວຢ່າງ; ການປ່ຽນການຕັ້ງຄ່າ ຫຼື ກົດ {{ui:ເຣັນເດີ}} ອີກຄັ້ງຈະເລີ່ມໃໝ່. ບໍ່ມີ WebGPU, ຮູບຈະຖືກ path traced ດ້ວຍ WebGL ແທນ (ແຖວຈະບອກແບບນັ້ນ) ແລະ {{ui:ສືບຕໍ່}} ຈະບໍ່ສະເໜີໃຫ້.

:::linux
Firefox ແລະ ການຕັ້ງຄ່າ Chrome ສ່ວນໃຫຍ່ເທິງ Linux ຍັງບໍ່ມີ WebGPU, ດັ່ງນັ້ນຄຸນນະພາບສູງໃຊ້ WebGL ຢູ່ບ່ອນນັ້ນ.
:::

ໃນໂໝດນີ້ ຂອບບໍ່ຖືກແຕ້ມ, ພື້ນຜິວຈາກຄັງແສດງສີ ແລະ ຄວາມຫຍາບ ແຕ່ບໍ່ແສດງຮອຍນູນ ([ວັດສະດຸທີ່ສ້າງດ້ວຍ node](topic:shading#in-high-quality-pictures) ຈະແສດງເສັ້ນປົກກະຕິ ແລະ ຮອຍນູນ), ແລະ ການຕັດໜ້າຕັດຈະເຮັດໃນໂມເດວກ່ອນຮູບເລີ່ມ.

{{ui:ລຶບສຽງລົບກວນ (ລຶບເມັດທີ່ເຫຼືອຫຼັງຕົວຢ່າງ)}} ເປີດຢູ່ແລ້ວຕາມຄ່າເລີ່ມຕົ້ນ: ເມື່ອຮູບສຳເລັດ ຫຼື ຖືກຢຸດ, ເມັດທີ່ເຫຼືອຈະຖືກລຶບອອກໂດຍ neural network ທີ່ສ້າງໄວ້ສຳລັບເລື່ອງນີ້ (Intel Open Image Denoise ທີ່ເຜີຍແຜ່, ເຮັດວຽກໃນຄອມພິວເຕີຂອງທ່ານເອງ: ໃນກາດກຣາຟິກ, ຖ້າບໍ່ມີກໍ່ໃນໂປຣເຊດເຊີ). ຮູບທີ່ມີຕົວຢ່າງໜ້ອຍຈະອອກມາສະອາດ; {{ui:ສະແດງ}} › {{ui:ຮູບພາບກ່ອນລົບສຽງລົບກວນ}} ຈະສະແດງມັນຕາມທີ່ເຣັນເດີໄດ້ມາ.

## ເຣັນເດີໃນມຸມມອງ

ພື້ນທີ່ເຮັດວຽກ {{ui:ເຣັນເດີ}} ຈະຮັນ path tracer ໃນມຸມມອງເອງ: ໝຸນ, ແກ້ໄຂໂມເດວ ຫຼື ປ່ຽນໂຄມໄຟ ແລ້ວມັນຈະເລີ່ມໃໝ່ທັນທີ. {{ui:ເຂດ}}: ລາກສີ່ຫຼ່ຽມ ແລະ ມີແຕ່ມັນທີ່ຖືກເຣັນເດີ; {{ui:ທັງມຸມມອງ}} ຈະກັບຄືນ. {{ui:ໂຟກັສ}}: ຄລິກສິ່ງທີ່ຄວນຊັດ, ແລະ ຄວາມຊັດຂອງພາບຈະໂຟກັສບ່ອນນັ້ນ. {{ui:ລາຍລະອຽດ}} ກຳນົດວ່າຈະເຣັນເດີ pixel ຂອງມຸມມອງຈັກເທື່ອ (ໜ້ອຍກວ່າຈະໄວກວ່າ). {{ui:ຢຸດຊົ່ວຄາວ}} ຢຸດ ແລະ ດຳເນີນຕໍ່. ມັນຕ້ອງການ WebGPU: ຖ້າບໍ່ມີ, ພື້ນທີ່ເຮັດວຽກຈະບອກແບບນັ້ນ ແລະ {{ui:ສົ່ງອອກ}} › {{ui:ເຣັນເດີຮູບພາບ…}} ຍັງໃຊ້ໄດ້.

## ທ້ອງຟ້າ ແລະ ໂປຣໄຟລ໌ແສງໃນກາດກຣາຟິກ

ດ້ວຍ WebGPU, ຄຸນນະພາບສູງມີທ້ອງຟ້າເພີ່ມອີກສອງແບບ:

- {{ui:ທ້ອງຟ້າແບບຟິສິກ}} ຄິດໄລ່ແສງກາງເວັນຈາກຄວາມສູງຂອງດວງອາທິດ: ທ້ອງຟ້າສີຟ້າເຂັ້ມເທິງຫົວ, ແຖບສີອ່ອນຢູ່ຂອບຟ້າ, ແລະ ດວງອາທິດທີ່ອົບອຸ່ນຂຶ້ນ ແລະ ມືດລົງເມື່ອຕ່ຳລົງ. {{ui:ຄວາມໝອກ}} ຈາກວັນທີ່ໃສຫຼາຍ (2) ໄປຫາວັນທີ່ມີໝອກ (10).
- {{ui:ຮູບທ້ອງຟ້າ (HDRI)}} ສ່ອງໂມເດວດ້ວຍຮູບພາບ panorama ຂອງສະຖານທີ່ຈິງ. {{ui:ເລືອກຮູບ…}} ຈະເອົາໄຟລ໌ `.hdr` ຫຼື `.exr` ແບບ equirectangular; {{ui:ໝຸນ}} ຈະໝຸນມັນອ້ອມໂມເດວ ແລະ {{ui:ຄວາມສະຫວ່າງຮູບ}} ຈະເຮັດໃຫ້ມັນສະຫວ່າງ ຫຼື ມືດລົງ. ຮູບນັ້ນມີດວງອາທິດຂອງມັນເອງ, ດັ່ງນັ້ນດວງອາທິດຂອງໂມເດວຈະບໍ່ຖືກເພີ່ມ. ມັນຖືກເກັບໄວ້ພຽງແຕ່ໃນຂະນະທີ່ໜ້າເວັບເປີດຢູ່: ເມື່ອເປີດໃໝ່ ໃຫ້ເລືອກມັນອີກຄັ້ງ.

ແຕ່ລະໂຄມໄຟໃນລາຍການ {{ui:ໂຄມໄຟ}} ສາມາດໃຊ້ໂປຣໄຟລ໌ແສງຂອງຜູ້ຜະລິດໄດ້: {{ui:ໂປຣໄຟລ໌ IES…}} ອ່ານໄຟລ໌ IES (LM-63) ແລະ ໂຄມໄຟນັ້ນຈະສ່ອງແສງຕາມແບບຂອງອຸປະກອນນັ້ນ (ເປັນ downlight ແຄບ, ຫຼື ໂຄມສ່ອງຝາ). ທຸກໂຄມທີ່ມີຊື່ນັ້ນຈະໃຊ້ມັນ, ແລະ ໂຄມແຕ່ລະອັນຈະເກັບຄວາມສະຫວ່າງຂອງຕົນເອງໄວ້. ຄລິກຊື່ໂປຣໄຟລ໌ເພື່ອຢຸດການໃຊ້ມັນ.

ໜ້າຕ່າງແກ້ວໃສຊ່ວຍໃຫ້ແສງຈາກທ້ອງຟ້າເຂົ້າໄປໃນຫ້ອງໄດ້, ດັ່ງນັ້ນຮູບພາຍໃນພາຍໃຕ້ທ້ອງຟ້າຈະສຳເລັດໄວຂຶ້ນ.

ໂໝດ {{ui:ໄວ}} ແລະ WebGL path tracer ສະແດງ {{ui:ທ້ອງຟ້າແບບຟິສິກ}} ແລະ {{ui:ຮູບທ້ອງຟ້າ (HDRI)}} ເປັນທ້ອງຟ້າໃສ ແລະ ບໍ່ສົນໃຈໂປຣໄຟລ໌ແສງ.

## ກ້ອງ

{{ui:ກ້ອງ}} ຈັດຮູບໃຫ້ຄືຮູບຖ່າຍ:

- {{ui:ການເປີດຮັບແສງ}}: ຮັກສາ {{ui:ແຖບປັບຄວາມສະຫວ່າງ}}, ຫຼື ເລືອກ {{ui:ການຕັ້ງຄ່າກ້ອງ}} ແລ້ວຕັ້ງ {{ui:ຮູຮັບແສງ (f-stop)}}, {{ui:ຄວາມໄວຊັດເຕີ}} ແລະ {{ui:ISO}} ເໝືອນກ້ອງຖ່າຍຮູບ; EV ຂ້າງພວກມັນແມ່ນຄ່າການເປີດຮັບແສງທົ່ວໄປ. f/16 ທີ່ 1/100 s ແລະ ISO 100 ກົງກັບວັນແດດອອກ; ສາກທີ່ມືດກວ່າຕ້ອງການຮູທີ່ກວ້າງກວ່າ, ຊັດເຕີທີ່ຊ້າກວ່າ ຫຼື ISO ທີ່ສູງກວ່າ. ອັນນີ້ໃຊ້ໄດ້ໃນທຸກໂໝດ.
- {{ui:ຄວາມຊັດຂອງພາບ (Depth of field)}} ເຮັດໃຫ້ສິ່ງທີ່ໃກ້ ຫຼື ໄກກວ່າ {{ui:ໄລຍະໂຟກັດ (m)}} ເບລີ່ອອກ ຄືກັບເລນທີ່ມີ f-stop ນັ້ນ (ປ່ອຍໃຫ້ວ່າງເພື່ອໂຟກັສໃສ່ສິ່ງທີ່ຢູ່ກາງມຸມມອງ); {{ui:ຮູບຮ່າງຮູຮັບແສງ}} ເຮັດໃຫ້ແສງຈ້າທີ່ບໍ່ຊັດເປັນຮູບວົງມົນ ຫຼື ຮູບໃບມີດ.
- {{ui:ທັດສະນະສອງຈຸດ (ເສັ້ນຕັ້ງຄົງຕັ້ງ)}} ປັບລະດັບກ້ອງ ແລະ ເລື່ອນຮູບ, ຄືກັບເລນ tilt-shift ທາງສະຖາປັດຕະຍະກຳ, ດັ່ງນັ້ນຝາຈະບໍ່ຫຼຽງເມື່ອທ່ານເບິ່ງຂຶ້ນ ຫຼື ລົງໃສ່ຕຶກ.
- {{ui:ສົມດຸນສີຂາວ}} ກຳນົດວ່າສີແສງໃດປາກົດເປັນສີຂາວ: ຕ່ຳກວ່າ (ເຊັ່ນ 3000 K) ສຳລັບແສງໂຄມອົບອຸ່ນ, ສູງກວ່າສຳລັບເງົາ ແລະ ວັນມີເມກ.
- {{ui:ການສະແດງພາບ}}: {{ui:ພາໂນຣາມາ 360°}} ເຮັດຮູບ 2:1 ຂອງທຸກສິ່ງອ້ອມກ້ອງສຳລັບໂປຣແກຣມເບິ່ງ panorama; {{ui:ພາໂນຣາມາສະເຕຣິໂອ 360°}} ຊ້ອນພາໂນຣາມາຕາຊ້າຍ ແລະ ຕາຂວາສຳລັບຫູຟັງ VR; {{ui:ແຜນທີ່ລູກບາດ (6 ດ້ານ)}} ເຮັດມຸມມອງຈັດຕຸລັດ 6 ອັນໃນຕາຕະລາງ 3 × 2. ຄວາມກວ້າງມາຈາກ {{ui:ຂະໜາດ}}.

ການສະແດງພາບ, ຄວາມຊັດຂອງພາບ, ທັດສະນະສອງຈຸດ ແລະ ສົມດຸນສີຂາວຕ້ອງການ path tracer ໃນກາດກຣາຟິກ (WebGPU), ດັ່ງນັ້ນພວກມັນຈະສະແດງພຽງແຕ່ໃນ {{ui:ຄຸນນະພາບສູງ}}.

## ສຳເລັດຮູບ

{{ui:ຮູບພາບ}} ປັບສີຂອງຮູບຄຸນນະພາບສູງຄືກັບຮູບຖ່າຍ, ແລະ ທຸກການຄວບຄຸມປ່ຽນຮູບສຸດທ້າຍທັນທີ, ໂດຍບໍ່ຕ້ອງເຣັນເດີໃໝ່:

- {{ui:ໂທນສີ (view transform)}}: {{ui:ACES filmic}} (ຮູບເໝືອນເດີມ), {{ui:AgX}} (ນຸ່ມກວ່າ, ຮັກສາສີໃນແສງທີ່ສະຫວ່າງຫຼາຍ), {{ui:Filmic}} (ເສັ້ນໂຄ້ງຟິມທີ່ອ່ອນໂຍນ) ຫຼື {{ui:ມາດຕະຖານ}} (ເຮັບ, ແສງສະຫວ່າງຈັດຈະຕັດເປັນສີຂາວ).
- {{ui:ຄອນທຣາສ໌}} ແລະ {{ui:ການບີບອັດຈຸດສະຫວ່າງ}} (ເອົາລາຍລະອຽດກັບຄືນໃນສ່ວນທີ່ສະຫວ່າງຫຼາຍ).
- {{ui:Bloom}} (ແສງເຮືອງນຸ່ມອ້ອມແສງສະຫວ່າງ), {{ui:ແສງຈ້າ}} ພ້ອມ {{ui:ເສັ້ນແສງຈ້າ}} (ເສັ້ນແສງຮູບດາວຈາກຈຸດທີ່ສະຫວ່າງທີ່ສຸດ) ແລະ {{ui:ຂອບມືດ}} (ມຸມທີ່ມືດກວ່າ).
- {{ui:ຕາຕະລາງສີ (.cube)…}} ໃຊ້ການປັບສີຈາກໄຟລ໌ `.cube`, ພ້ອມ {{ui:ຄວາມເຂັ້ມຂອງຕາຕະລາງສີ}}; ເຊັ່ນດຽວກັບຮູບທ້ອງຟ້າ ມັນຖືກເກັບໄວ້ພຽງແຕ່ໃນຂະນະທີ່ໜ້າເວັບເປີດຢູ່.

## ບັນທຶກຮູບ

{{ui:ບັນທຶກເປັນ}} ຢູ່ຂ້າງ {{ui:ບັນທຶກ}} ເລືອກໄຟລ໌: {{ui:PNG}}, {{ui:JPEG}} ຫຼື {{ui:WebP}} ສຳລັບແບ່ງປັນ (JPEG ແລະ WebP ພຽງແຕ່ຢູ່ບ່ອນທີ່ບຣາວເຊີສາມາດຂຽນມັນໄດ້), ແລະ ຫຼັງຈາກເຣັນເດີຄຸນນະພາບສູງໃນກາດກຣາຟິກ ຍັງມີ:

- {{ui:PNG, 16 ບິດ}}: ຮູບທີ່ປັບສີແລ້ວ ພ້ອມຂັ້ນຄວາມເຂັ້ມທີ່ລະອຽດກວ່າ, ສຳລັບການພິມ ຫຼື ແກ້ໄຂຕໍ່.
- {{ui:EXR, ທຸກເລເຢີ (32-bit float)}}: ຮູບຕາມທີ່ເຣັນເດີໄດ້ມາ (ແສງເສັ້ນຊື່, ບໍ່ມີການປັບສີ) ພ້ອມທຸກອົງປະກອບການເຣັນເດີ ແລະ ກຸ່ມແສງເປັນເລເຢີຂອງຕົນເອງ, ສຳລັບໂປຣແກຣມ compositing.
- {{ui:ໄຟລ໌ເຣັນເດີ (.ccrender, ເພື່ອປັບສີພາຍຫຼັງ)}}: ທຸກຢ່າງທີ່ກ່ອງໂຕ້ຕອບຕ້ອງການເພື່ອປະສົມ ແລະ ປັບສີຮູບອີກຄັ້ງ. {{ui:ເປີດໄຟລ໌ເຣັນເດີ…}} ຈະນຳມັນກັບມາ, ພ້ອມການປະສົມ ແລະ ການປັບສີ, ໂດຍບໍ່ຕ້ອງເຣັນເດີ.

## ປະສົມແສງຫຼັງເຣັນເດີ

ເປີດ {{ui:ປະສົມແສງ (ປ່ຽນສີ ແລະ ຄວາມສະຫວ່າງຂອງແຕ່ລະໄຟຫຼັງເຣັນເດີ)}} ກ່ອນກົດ {{ui:ເຣັນເດີ}}. ເມື່ອຮູບສຳເລັດ (ຫຼື ຖືກຢຸດ), {{ui:ປະສົມຮູບພາບ}} ຈະລາຍການແສງຂອງມັນເປັນກຸ່ມ: ທ້ອງຟ້າ, ດວງອາທິດ, ແລະ ໂຄມໄຟຕາມຊື່ (ທຸກໂຄມທີ່ມີຊື່ດຽວກັນເປັນໜຶ່ງກຸ່ມ). ປິດກຸ່ມ, ໃຫ້ມັນສີ, ຫຼື ເຮັດໃຫ້ສະຫວ່າງ ຫຼື ມືດລົງ, ແລ້ວຮູບຈະປ່ຽນທັນທີ, ໂດຍບໍ່ຕ້ອງເຣັນເດີໃໝ່. {{ui:ບັນທຶກການປະສົມ}} ເກັບການປະສົມໄວ້ດ້ວຍຊື່ເພື່ອເລືອກໃໝ່ພາຍຫຼັງ; {{ui:ຕາມທີ່ເຣັນເດີ}} ຈະກັບໄປຫາຮູບຕາມທີ່ຖືກສ້າງ. {{ui:ບັນທຶກ}} ຈະບັນທຶກຮູບທີ່ປະສົມແລ້ວ.

{{ui:ອົງປະກອບການເຣັນເດີ (albedo, normals, depth, diffuse, specular, transmission, emission, IDs)}} ຍັງເກັບສ່ວນຕ່າງໆຂອງຮູບໄວ້. {{ui:ສະແດງ}} ຈະປ່ຽນມຸມມອງເປັນໜຶ່ງໃນນັ້ນ: ສີພື້ນຜິວ (albedo), ເສັ້ນປົກກະຕິ (normals), ຄວາມເລິກ (depth), ແສງ diffuse, specular ແລະ transmitted (ທັງໂດຍກົງ ແລະ ທາງອ້ອມ), ສິ່ງທີ່ເຮືອງແສງ ແລະ ທ້ອງຟ້າ, ແລະ ສີຕໍ່ວັດຖຸ ຫຼື ຕໍ່ວັດສະດຸສຳລັບການສ້າງ mask.

ທັງສອງຢ່າງເກັບເລເຢີເພີ່ມເຕີມໄວ້ໃນກາດກຣາຟິກ. ທີ່ຂະໜາດໃຫຍ່ ກາດກຣາຟິກອາດບໍ່ມີບ່ອນພໍ; ກ່ອງໂຕ້ຕອບຈະບອກແບບນັ້ນ ແລະ ຂະໜາດທີ່ນ້ອຍກວ່າຈະໃຊ້ໄດ້.

## ຄິວເຣັນເດີ

ຫຼັງຈາກຕັ້ງຄ່າຄຸນນະພາບສູງແລ້ວ, {{ui:ເພີ່ມຮູບພາບນີ້ເຂົ້າຄິວ}} ພາຍໃຕ້ {{ui:ຄິວເຣັນເດີ}} ຈະເກັບຮູບໄວ້ຕາມທີ່ຕັ້ງຢູ່ຕອນນີ້; ກ່ອງໂຕ້ຕອບວິດີໂອ {{ui:ເພີ່ມອະນິເມຊັນນີ້ເຂົ້າຄິວ}} ເຮັດແບບດຽວກັນສຳລັບອະນິເມຊັນທັງໝົດ, ໂດຍ path traced ທີລະເຟຣມ. {{ui:ເລີ່ມຄິວ}} ຈະເຣັນເດີພວກມັນທີລະອັນໃນຄອມພິວເຕີນີ້, ແລະ {{ui:ບັນທຶກ}} ຂ້າງແຕ່ລະອັນທີ່ສຳເລັດຈະດາວໂຫຼດມັນ. ການປິດໜ້າເວັບຈະເກັບຄິວໄວ້: ເປີດໂມເດວດຽວກັນ ແລ້ວມັນຈະດຳເນີນຕໍ່ຈາກບ່ອນທີ່ຢຸດ. ຄິວຕ້ອງການ WebGPU.

## ໝອກ, ຄວັນ, ສຽງລົບກວນ ແລະ ແສງສະທ້ອນ

ສິ່ງເຫຼົ່ານີ້ຢູ່ໃນ {{ui:ໝອກ, ຄວັນ ແລະ ສຽງລົບກວນ}} ແລະ ເຮັດວຽກໃນ {{ui:ຄຸນນະພາບສູງ}} ໃນກາດກຣາຟິກ; engine ອື່ນຈະບໍ່ມີສ່ວນນີ້.

- {{ui:ໝອກ ແລະ ຄວາມມົວ}} ເຕີມອາກາດເຖິງຄວາມສູງໜຶ່ງດ້ວຍໝອກທີ່ດວງອາທິດ, ທ້ອງຟ້າ ແລະ ໂຄມໄຟສ່ອງ. {{ui:ເບິ່ງເຫັນໄດ້ໄກປານໃດ, ເປັນແມັດ}} ກຳນົດຄວາມໜາ (ປະມານ 100 m ແມ່ນໝອກບາງໆ, 20 m ແມ່ນໝອກໜາ), {{ui:ຄວາມສູງຂອງໝອກເໜືອພື້ນດິນ, ເປັນແມັດ}} ແມ່ນບ່ອນທີ່ມັນສິ້ນສຸດ, ແລະ {{ui:ລຳແສງ}} ແມ່ນໝອກເຮືອງແສງໄປຫາແສງຫຼາຍປານໃດ. ແສງຕາເວັນອອກຈາກໝອກທີ່ດ້ານເທິງ, ດັ່ງນັ້ນບ່ອນທີ່ແສງແດດຜ່ານໜ້າຕ່າງ ຫຼື ລະຫວ່າງຕຶກ ທ່ານຈະເຫັນມັນເປັນລຳແສງ.
- {{ui:ຄວັນ ຫຼື ເມກ}} ເພີ່ມປະລິມາດຂອງຄວັນ ຫຼື ເມກໜຶ່ງອັນ ທີ່ສ່ອງດ້ວຍແສງຄືກັບໝອກ. {{ui:ປະເພດ}} ແມ່ນ {{ui:ເມກ}}, {{ui:ຄໍລຳຄວັນ}} ຫຼື {{ui:ຈາກໄຟລ໌ປະລິມາດ (.ccvol)}}, ເປັນຮູບແບບຕາຕະລາງຂອງ CadCraft ເອງ. {{ui:ລາຍລະອຽດ}} ແລະ {{ui:ຄວາມແຕກຕ່າງ}} ປ່ຽນເມກ ຫຼື ຄໍລຳທີ່ສ້າງແລ້ວ, {{ui:ຂະໜາດຂອງດ້ານທີ່ຍາວທີ່ສຸດ, ເປັນແມັດ (0 = ຂະໜາດຂອງໂມເດວ)}}, {{ui:ຍ້າຍ X (m)}}, {{ui:ຍ້າຍ Y (m)}}, {{ui:ຍ້າຍ Z (m)}} ແລະ {{ui:ໝຸນ}} ຈັດວາງມັນ (ມັນເລີ່ມຕົ້ນຢູ່ກາງໂມເດວ), {{ui:ຄວາມໜາ}} ເຮັດໃຫ້ໜາແໜ້ນຂຶ້ນ, {{ui:ແສງເຮືອງໄປໜ້າ}} ເຮັດໃຫ້ສະຫວ່າງຂຶ້ນໄປຫາແສງ, ແລະ {{ui:ສີ}} ໃຫ້ສີມັນ. ໄຟລ໌ປະລິມາດຈະຖືກເກັບໄວ້ພຽງແຕ່ໃນຂະນະທີ່ໜ້າເວັບເປີດຢູ່, ເໝືອນຮູບທ້ອງຟ້າ.
- {{ui:ຢຸດກ່ອນເວລາບ່ອນທີ່ຮູບພາບສະອາດແລ້ວ (adaptive sampling)}} ຈະບໍ່ໃຫ້ຕົວຢ່າງເພີ່ມແກ່ pixel ທີ່ນິ່ງແລ້ວ, ດັ່ງນັ້ນສ່ວນທີ່ເຫຼືອຂອງຮູບຈະສຳເລັດໄວຂຶ້ນ. {{ui:ສຽງລົບກວນທີ່ຍອມຮັບ}} ແມ່ນເມັດທີ່ເຫຼືອເມື່ອ pixel ໜຶ່ງຢຸດ. ແຖວລຸ່ມຮູບຈະບອກວ່າ pixel ໄດ້ຕົວຢ່າງເລ່ຍເທົ່າໃດ.
- {{ui:Caustics (ແສງທີ່ຖືກງໍໂດຍແກ້ວ ຫຼື ສະທ້ອນໂດຍກະຈົກ)}} ຕິດຕາມແສງຈາກໂຄມໄຟ ແລະ ດວງອາທິດ, ດັ່ງນັ້ນຈຸດສະຫວ່າງໃຕ້ລູກແກ້ວ ຫຼື ແສງກະຈົກເທິງຝາຈະອອກມາສະອາດແທນທີ່ຈະເປັນເມັດ. ມັນປິດຢູ່ໃນຂະນະທີ່ໝອກ, ຄວັນ, {{ui:ປະສົມແສງ}} ຫຼື ອົງປະກອບການເຣັນເດີເປີດຢູ່, ແລະ ມັນຖືກເຮັດສຳລັບຮູບ, ບໍ່ແມ່ນສຳລັບຮູບ 360°, ອະນິເມຊັນ ຫຼື ພື້ນທີ່ເຮັດວຽກ Render.

## ໃຊ້ເວລາດົນປານໃດ

ຮູບຖືກສ້າງຢູ່ໃນຄອມພິວເຕີຂອງທ່ານເອງ ໂດຍກາດກຣາຟິກ; ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ. ໃຊ້ເວລາດົນປານໃດຂຶ້ນກັບກາດນັ້ນ. ເວລາເພີ່ມຕາມຈຳນວນຮອບ ແລະ pixel: {{ui:ດີທີ່ສຸດ}} ມີຮອບ 16 ເທົ່າຂອງ {{ui:ສະບັບຮ່າງ}}, ແລະ ຮູບ 4K ມີ pixel ປະມານສີ່ເທົ່າຂອງ Full HD. ຄອມພິວເຕີທີ່ບໍ່ມີກາດກຣາຟິກຍັງເຣັນເດີໄດ້, ແຕ່ຊ້າກວ່າ.

:::note
ຖ້າກ່ອງໂຕ້ຕອບບອກວ່າບຣາວເຊີບໍ່ສາມາດເຣັນເດີຮູບໄດ້, ບຣາວເຊີບໍ່ມີ WebGL 2. ໃຫ້ອັບເດດມັນ, ຫຼື ເປີດ hardware acceleration ໃນການຕັ້ງຄ່າຂອງມັນ.
:::
