ວັດສະດຸທີ່ສ້າງໃນພື້ນທີ່ເຮັດວຽກ **Shading** ເປັນຂອງໄຟລ໌ນັ້ນ. ມັນເປັນກຣາຟນ້ອຍໆ: **ໂນດ** ທີ່ສ້າງເທັກເຈີ, ຮູບພາບ ແລະ ຕົວເລກ, ເຊື່ອມເຂົ້າກັບ **Material output**, ເຊິ່ງ input ຂອງມັນແມ່ນລັກສະນະຂອງໜ້າ — ສີພື້ນຖານ, ຄວາມຫຍາບ, ຄວາມເປັນໂລຫະ, normal, ຄວາມໂປ່ງໃສ, ການແຜ່ແສງ ແລະ ອື່ນໆຂອງແບບ OpenPBR. ທ່ານທາສີໜ້າດ້ວຍມັນຄືກັບວັດສະດຸຄັງໃດໆ, ແລະ ທຸກການປ່ຽນແປງຈະສະແດງໃນມຸມມອງທັນທີ.

## ເປີດມັນ

ເລືອກ {{ui:Shading}} ໃນລາຍການ Workspace. ມຸມມອງ 3D ຈະຢູ່ເທິງສຸດຂອງໜ້າຈໍ ແລະ **node editor** ຈະຢູ່ດ້ານລຸ່ມ. ແຜງທາງຂວາຈະລາຍການວັດສະດຸຂອງໄຟລ໌.

- {{ui:New material}} ສ້າງວັດສະດຸສີເທົາໜຶ່ງອັນ ທີ່ມີພຽງ Material output ເທົ່ານັ້ນ.
- **ສ້າງສຳເນົາທີ່ແກ້ໄຂໄດ້ຂອງວັດສະດຸຄັງ** ປ່ຽນອິດ, ໄມ້, ກະເບື້ອງ ແລະ ອື່ນໆໃຫ້ເປັນກຣາຟທີ່ທ່ານແກ້ໄຂໄດ້: ເທັກເຈີຂອງມັນຜ່ານໂນດເທັກເຈີຈາກຄັງ, ແລະ ຮອຍນູນຂອງມັນຜ່ານໂນດ Bump.
- {{ui:Paint with it}} ທາສີໜ້າ ຫຼື ກຸ່ມທີ່ເລືອກ, ຫຼື ເລືອກວັດສະດຸສຳລັບເຄື່ອງມືທາສີ. ວັດສະດຸຂອງເຄື່ອງມືທາສີຍັງລາຍການວັດສະດຸຂອງໄຟລ໌ໃຕ້ **ໃນໄຟລ໌ນີ້**.
- {{ui:Duplicate}} ແລະ {{ui:Delete}} ເຮັດວຽກກັບວັດສະດຸທີ່ທ່ານກຳລັງແກ້ໄຂ. ການລຶບບໍ່ສາມາດຍ້ອນກັບໄດ້: ໜ້າທີ່ທາດ້ວຍມັນຈະສະແດງສີເລີ່ມຕົ້ນ ຈົນກວ່າທ່ານຈະທາມັນໃໝ່.

## ວັດສະດຸຈາກຄັງ

**ຄັງວັດສະດຸ (Library)** ໃນແຜງ ລາຍການວັດສະດຸຂອງຄັງ, ແຕ່ລະອັນມີຕົວຢ່າງທີ່ເຣັນເດີໂດຍ path tracer ຂອງ CadCraft. ພວກມັນເປັນຊຸດເທັກເຈີທີ່ເຜີຍແຜ່ພາຍໃຕ້ CC0, ໃຫ້ເຄຣດິດແກ່ຜູ້ສ້າງ.

- ຄລິກໜຶ່ງອັນເພື່ອນຳເຂົ້າໄຟລ໌ (ຮູບພາບຂອງມັນມາພ້ອມ) ແລະ, ເມື່ອໜ້າ ຫຼື ກຸ່ມຖືກເລືອກ, ທາສີໃສ່ພວກມັນ.
- ລາກໜຶ່ງອັນໄປວາງເທິງໜ້າ ຫຼື ກຸ່ມໃນມຸມມອງເພື່ອທາສີສະເພາະຈຸດນັ້ນ.
- ມັນກາຍເປັນໜຶ່ງໃນວັດສະດຸຂອງໄຟລ໌: ປ່ຽນໂນດຂອງມັນຄືກັບອັນອື່ນ. ເຄຣດິດຂອງມັນສະແດງໃນແຜງ ແລະ ຢູ່ໃນໄຟລ໌.

## ນຳເຂົ້າຊຸດເທັກເຈີ

**ຮູບພາບ ຫຼື zip…** ຫຼື **ໂຟນເດີ…** ພາຍໃຕ້ **ນຳເຂົ້າຊຸດເທັກເຈີ** ສ້າງວັດສະດຸຈາກຊຸດແຜນທີ່. ແຜນທີ່ຖືກຊອກຫາຈາກຄຳໃນຊື່ໄຟລ໌ຂອງມັນ: color, albedo, diffuse ຫຼື basecolor; roughness (ຫຼື gloss, ແປງເປັນ roughness); metalness ຫຼື metallic; normal (OpenGL ຫຼື DirectX, ຈາກ `gl` / `dx` ໃນຊື່); height ຫຼື displacement; ambient occlusion; opacity; emission. ແຜນທີ່ທີ່ແພັກຮວມກັນ (ARM, ORM) ຈະຖືກຂ້າມ. ກະເບື້ອງເລີ່ມຕົ້ນທີ່ 1 × 1 m: ຕັ້ງຂະໜາດຈິງຂອງມັນໃນ Material output. Height ຈະໄປເປັນ displacement ທີ່ຂະໜາດ 0 — ເພີ່ມຂະໜາດເພື່ອໃຊ້ມັນກັບ mesh.

## MaterialX

MaterialX ແມ່ນຮູບແບບເປີດທີ່ໂປຣແກຣມ 3D ແລະ ການເຣັນເດີອື່ນໆໃຊ້ເພື່ອສົ່ງວັດສະດຸຕໍ່ກັນ.

- {{ui:Export as MaterialX…}} ບັນທຶກວັດສະດຸທີ່ທ່ານກຳລັງແກ້ໄຂ: ຄ່າຂອງມັນ, ແລະ ທຸກເທັກເຈີເປັນຮູບ PNG ຢູ່ຂ້າງໄຟລ໌ `.mtlx` (ໃນ zip). ເລືອກ shader ທີ່ມັນຖືກຂຽນ: **OpenPBR Surface** (MaterialX 1.39, ແບບດຽວກັນກັບທີ່ ModelCraft ໃຊ້) ຫຼື **Standard Surface** (MaterialX 1.38, ທີ່ໂປຣແກຣມຫຼາຍອັນອ່ານໃນປັດຈຸບັນ). ເທັກເຈີຖືກວາງດ້ວຍພິກັດ UV ໃນໜ່ວຍເມັດ; ການວາງແບບ box ແລະ triplanar ຈະຖືກຂຽນເປັນ UV.
- {{ui:Import MaterialX…}} (ຫຼື {{ui:From a folder…}}) ອ່ານໄຟລ໌ `.mtlx` ທີ່ມີ shader OpenPBR, Standard Surface, UsdPreviewSurface ຫຼື glTF PBR. ໃຫ້ຮູບພາບນຳມານຳນຳ, ຫຼື zip ທີ່ມີທຸກຢ່າງ: ຮູບພາບຖືກພົບດ້ວຍເສັ້ນທາງ, ຊື່ຂອງມັນ, ຫຼື ຊື່ດ້ວຍປະເພດຮູບອື່ນ (ໄຟລ໌ `.exr` ອາດມາເປັນ `.jpg` ຢູ່ຂ້າງມັນ). ເທັກເຈີ, normal map, arithmetic, mix ແລະ displacement ຈະເຂົ້າມາເປັນໂນດ; ສິ່ງອື່ນຈະຮັກສາຄ່າຂອງມັນ, ແລະ ແຖບສະຖານະຈະບອກວ່າມີຫຍັງຖືກຕັດອອກ.

## Decal

Decal ແມ່ນຮູບທີ່ວາງເທິງໜ້າ — ໂລໂກ້, ປ້າຍ, ປ້າຍຊື່, ຮອຍເປື້ອນ — ພ້ອມວັດສະດຸຂອງມັນເອງ.

- ຕັ້ງ **ຄວາມກວ້າງຂອງ decal ໃໝ່**, ແລ້ວ {{ui:Place a decal…}} (ຫຼື {{ui:Decal}} ໃນແຖບເຄື່ອງມື), ເລືອກຮູບ PNG, JPEG ຫຼື WebP ແລ້ວຄລິກໜ້າໜຶ່ງ. ຮູບຈະຖືກຄາດໃສ່ໜ້າທີ່ຢູ່ບ່ອນນັ້ນ, ຮັກສາສັດສ່ວນຂອງມັນ; ສ່ວນທີ່ໂປ່ງໃສຂອງ PNG ຈະຍັງໂປ່ງໃສ.
- ມັນເປັນຂອງກຸ່ມ ຫຼື ອົງປະກອບທີ່ທ່ານຄລິກ ແລະ ເຄື່ອນໄປພ້ອມມັນ. ມັນຄອບຄຸມໜ້າທີ່ຢູ່ໃນກ່ອງຂອງມັນ ທີ່ຫັນໄປທາງດຽວກັນ, ແລະ ຢຸດຢູ່ຂອບຂອງສິ່ງທີ່ມັນວາງຢູ່.
- ແຕ່ລະ decal ມີວັດສະດຸຂອງຕົນເອງ, ຊື່ **Decal: <ຮູບພາບ>**, ໃນລາຍການຂອງໄຟລ໌: ແກ້ໄຂມັນຄືກັບອັນອື່ນ (roughness, bump, glow). {{ui:Material}} ຂ້າງ decal ຈະເປີດມັນ.
- ຂ້າງແຕ່ລະ decal: ຄວາມກວ້າງຂອງມັນ (ຄວາມສູງຕາມຮູບ), {{ui:Turn}} (ໝຸນໜຶ່ງສ່ວນສີ່), ແລະ {{ui:Delete}}. Decal ຖືກເກັບໄວ້ກັບວັດສະດຸຂອງໄຟລ໌, ນອກ Undo.
- ພວກມັນສະແດງໃນມຸມມອງແບບ shaded, ໃນການເຣັນເດີໄວ ແລະ ໃນຮູບຄຸນນະພາບສູງ.

## ທາສີເທິງເທັກເຈີ

{{ui:Paint texture}} (ຫຼື {{ui:Paint}} ພາຍໃຕ້ **ທາສີເທິງເທັກເຈີ**) ປ່ຽນຕົວຊີ້ເປັນແປງກົມ. ລາກເທິງໜ້າທີ່ໃສ່ວັດສະດຸໜຶ່ງຂອງໄຟລ໌ນີ້: ແປງຈະທາຮູບທີ່ຢູ່ເບື້ອງຫຼັງສີພື້ນຖານຂອງມັນ.

- ເທິງ mesh ມັນທາຕາມ UV ຂອງ mesh (ເປີດອອກດ້ວຍ UV workspace ກ່ອນ); ໃນໜ້າອື່ນມັນທາຂ້າມໜ້າ, ດັ່ງນັ້ນການທາສີຈະຊ້ຳຕາມກະເບື້ອງຂອງວັດສະດຸ.
- ວັດສະດຸທີ່ສີພື້ນຖານເປັນສີດຽວ ຈະໄດ້ຮູບໃໝ່ 512 × 512 pixel ຂອງສີນັ້ນຄັ້ງທຳອິດທີ່ທ່ານທາ. ວັດສະດຸທີ່ສີພື້ນຖານມາຈາກໂນດອື່ນຕ້ອງການໂນດ Picture ທີ່ເຊື່ອມກັບ Base color.
- ຕັ້ງສີແປງ, ຂະໜາດ (ເປັນ pixel ຂອງຮູບ), ຄວາມແຮງ ແລະ ຄວາມແຂງໃນແຜງ. {{ui:Undo stroke}} ຫຼື Ctrl+Z (ໃນຂະນະທາສີ) ຈະເອົາການແຕ້ມກັບຄືນ, ເຖິງ 20 ຄັ້ງຫຼ້າສຸດ.
- ຮູບທີ່ທາແລ້ວຖືກບັນທຶກໄວ້ໃນໄຟລ໌. ວັດສະດຸຄັງບໍ່ສາມາດທາສີໄດ້: ສ້າງສຳເນົາທີ່ແກ້ໄຂໄດ້ກ່ອນ.

## ອົບເທັກເຈີ

**ອົບເທັກເຈີ** ຂຽນສິ່ງທີ່ຮູບຮ່າງ ແລະ ແບບໃຫ້ແກ່ໜ້າ ເປັນຮູບຕາມ UV ຂອງ mesh.

- ເລືອກ mesh ທີ່ມີ UV (ເປີດອອກດ້ວຍ UV workspace), ຕິກແຜນທີ່, ແລ້ວກົດ {{ui:Bake}}:
  - **Ambient occlusion** — ແຕ່ລະຈຸດເປີດຫຼາຍປານໃດ: ມຸມ, ຮອຍພັບ ແລະ ບ່ອນທີ່ຢູ່ໃຕ້ສິ່ງອື່ນຈະມືດກວ່າ. ທຸກສິ່ງທີ່ສະແດງໃນແບບເຮັດໃຫ້ມັນມີເງົາ, ຈົນເຖິງໄລຍະ occlusion ທີ່ທ່ານຕັ້ງ.
  - **Curvature** — ສະຫວ່າງຕາມຂອບນອກ, ມືດໃນມຸມພາຍໃນ, ສີເທົາກາງໃນສ່ວນແບນ ແລະ ໂຄ້ງເບົາໆ, ຕາມຄວາມກວ້າງຂອບທີ່ທ່ານຕັ້ງ.
  - **Normal ຈາກວັດຖຸລະອຽດສູງ** — ເລືອກສຳເນົາທີ່ລະອຽດກວ່າດ້ວຍ: ລາຍລະອຽດຂອງພື້ນຜິວຂອງມັນຖືກຂຽນເປັນ normal map ໃຫ້ອັນທີ່ງ່າຍກວ່າ (ວັດຖຸທີ່ມີສາມຫຼ່ຽມໜ້ອຍກວ່າແມ່ນຖືກອົບໃສ່). ໄລຍະການຄົ້ນຫາແມ່ນໄລຍະຫ່າງທີ່ພື້ນຜິວທັງສອງສາມາດຢູ່ຫ່າງກັນໄດ້.
  - **ແສງ** — ດວງອາທິດຂອງສະຖານທີ່ ແລະ ວັນທີຂອງແບບ (Style) ພ້ອມເງົາຂອງມັນ, ແລະ ທ້ອງຟ້າ, ເປັນ light map.
- ຮູບເຫຼົ່ານັ້ນເຂົ້າໄປໃນໄຟລ໌ ແລະ ປາກົດໃນໂນດ Picture. ຖ້າວັດສະດຸທີ່ທ່ານກຳລັງແກ້ໄຂມີໂນດ **Dirt and edge wear**, ມັນຈະອ່ານຮູບ occlusion ແລະ curvature ໃໝ່ທັນທີ.
- ຈຳນວນ ray ຕໍ່ texel ຫຼາຍກວ່າ ຈະເຮັດໃຫ້ occlusion ແລະ ແສງລຽບກວ່າ ແຕ່ໃຊ້ເວລາດົນກວ່າ. ການອົບເຮັດວຽກໃນ core ຂອງໂປຣເຊດເຊີຄອມພິວເຕີໃນພື້ນຫຼັງ; {{ui:Stop baking}} ຢຸດມັນ.

2. ລາກຈາກຈຸດ output (ດ້ານຂວາຂອງໂນດ) ໄປຫາຈຸດ input (ດ້ານຊ້າຍຂອງໂນດ) ເພື່ອເຊື່ອມ. ການເຊື່ອມທີ່ສອງເຂົ້າ input ຈະແທນທີ່ອັນທຳອິດ; ລາກ input ທີ່ເຊື່ອມແລ້ວອອກເພື່ອຍົກເລີກການເຊື່ອມ.

## Material output

ການຕັ້ງຄ່າຂອງມັນບອກວ່າເທັກເຈີວາງຢູ່ເທິງໜ້າແນວໃດ:

- **ຄວາມກວ້າງຂອງກະເບື້ອງ** ແລະ **ຄວາມສູງຂອງກະເບື້ອງ**: ກະເບື້ອງໜຶ່ງຂອງເທັກເຈີຄອບຄຸມຈັກເມັດ. ທຸກສິ່ງທີ່ກຣາຟສ້າງຈະຊ້ຳຕາມກະເບື້ອງໂດຍບໍ່ມີຮອຍຕໍ່.
- **ວາງດ້ວຍ**: **ພິກັດ UV** ເຮັດຕາມໜ້າ (ໜ້າທີ່ດັນ/ດຶງ: ຕາມແຕ່ລະໜ້າ; mesh: UV ຂອງມັນ, ໜຶ່ງໜ່ວຍ UV = ໜຶ່ງກະເບື້ອງ), **Box** ຄາດຈາກແກນທັງສາມທີ່ໃກ້ທີ່ສຸດ, **Triplanar** ປະສົມການຄາດທັງສາມ ເທິງພື້ນຜິວທີ່ອຽງ (**ຄວາມຄົມຂອງການປະສົມ**: ສູງກວ່າ ການປະສົມຈະແຂງກວ່າ).
- **ຄວາມແຮງ normal** ປັບ input ຂອງ normal. **ຂະໜາດ displacement** ກຳນົດວ່າ input displacement ຍ້າຍຈຸດຂອງ mesh ໄປໄກເທົ່າໃດ.
- {{ui:More inputs}} ສະແດງ input OpenPBR ທີ່ເຫຼືອ: coat, fuzz, subsurface, thin film, transmission ແລະ ສີຂອງພວກມັນ.

## ໃນຮູບຄຸນນະພາບສູງ

Path tracer ອ່ານສີພື້ນຖານ, roughness, metalness, opacity, normal ແລະ emission ຈາກກຣາຟ ຕາມການປ່ຽນແປງເທິງພື້ນຜິວ. input ອື່ນໃດທີ່ທ່ານເຊື່ອມ (ເຊັ່ນ coat ທີ່ປ່ຽນແປງ) ຈະໃຊ້ຄ່າສະເລ່ຍ; panel ບອກວ່າອັນໃດ. Cut-out ຈາກເທັກເຈີ opacity ຈະສະແດງຮູບຮ່າງຂອງມັນ, ແລະ ເງົາຂອງມັນຈະໂປ່ງເທົ່າທຽມກັນ. ເທັກເຈີທີ່ເຮືອງແສງຈະສ່ອງສິ່ງທີ່ມັນຫັນໄປຫາ, ໂດຍບໍ່ຖືກຖືວ່າເປັນໄຟ.

**Displacement** ຍ້າຍຈຸດຂອງ mesh ເທົ່ານັ້ນ, ສະນັ້ນໃຫ້ເພີ່ມ Subdivision modifier ເພື່ອລາຍລະອຽດ ([Modifiers](topic:modifiers)). ໜ້າທີ່ດັນ/ດຶງຈະຮັກສາຮູບຮ່າງຂອງມັນ ແລະ ໄດ້ຮອຍນູນຈາກ normal.
