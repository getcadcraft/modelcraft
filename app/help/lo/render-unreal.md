ໃນ CadCraft Studio ລາຍການເອນຈິນສາມາດເກັບ **ການເຊື່ອມຕໍ່** ໄປຫາໂປຣເຈັກ Unreal Engine ໄດ້. ມີທິດທາງດຽວເທົ່ານັ້ນ: ຈາກ CadCraft ໄປຫາ Unreal.

## ສົ່ງສາກ

1. ເລືອກ Unreal ໃນລາຍການເອນຈິນ. ຄັ້ງທຳອິດ Studio ຈະຖາມໃຫ້ເລືອກໂຟນເດີຂອງໂປຣເຈັກ (ໂຟນເດີທີ່ມີໄຟລ໌ `.uproject`); ມັນຈະຈື່ໄວ້.
2. ກົດ {{ui:ສົ່ງ}}. Studio ຂຽນ `CadCraft/<file name>/` ໄວ້ໃນໂປຣເຈັກ: ສາກເປັນໄຟລ໌ USD, ໄຟລ໌ການຕັ້ງຄ່າ, ໂປຣໄຟລ໌ແສງ ແລະ ໄຟລ໌ເລເຢີນ້ອຍສອງໄຟລ໌.
3. ປ່ຽນໂມເດວ, ບັນທຶກ ແລ້ວສົ່ງອີກຄັ້ງ. ມີແຕ່ສາກ ແລະ ໄຟລ໌ການຕັ້ງຄ່າເທົ່ານັ້ນທີ່ຖືກແທນທີ່.

## ການແກ້ໄຂຂອງທ່ານປອດໄພ

ສະເຕຈທີ່ Unreal ເປີດແມ່ນເລເຢີຮາກຂະໜາດນ້ອຍທີ່ສ້າງຄັ້ງດຽວ ມີສອງເລເຢີຢູ່ລຸ່ມ: **ຂອງທ່ານ** ຢູ່ດ້ານເທິງ (`<name>.user.usda`, ວ່າງເປົ່າໃນຕອນຕົ້ນ, CadCraft ບໍ່ເຄີຍຂຽນທັບ) ແລະ ສາກຂອງ CadCraft ຢູ່ດ້ານລຸ່ມ. ການແກ້ໄຂທີ່ທ່ານບັນທຶກໄວ້ໃນເລເຢີຂອງທ່ານຈະຄົງຢູ່ເມື່ອສົ່ງສາກອີກ. ແສງ ແລະ ແອັກເຕີອື່ນທີ່ທ່ານວາງໄວ້ໃນລະດັບ Unreal ຢູ່ນອກສະເຕຈ ແລະ ກໍ່ບໍ່ຖືກແຕະຕ້ອງເຊັ່ນກັນ.

## ໂດຍບໍ່ໃຊ້ Studio

ໃນບຣາວເຊີ ຫຼື ໃນຄອມພິວເຕີທີ່ Studio ບໍ່ພົບ Unreal, ເລືອກ **ໂຟນເດີໂປຣເຈັກ Unreal (.zip)** ໃນລາຍການເອນຈິນ ແລ້ວກົດ {{ui:ເຣັນເດີ}}. ມັນຈະບັນທຶກໂຟນເດີດຽວກັນເປັນ zip: ແຕກ zip ລົງໃນໂຟນເດີ `CadCraft` ຂອງໂປຣເຈັກ. ຄັ້ງທຳອິດໃຫ້ເປີດ **ລວມໄຟລ໌ສະເຕຈ** ໄວ້; ສຳລັບການບັນທຶກຄັ້ງຕໍ່ໄປໃຫ້ປິດມັນ, ເພື່ອໃຫ້ zip ມີແຕ່ສາກ ແລະ ໄຟລ໌ການຕັ້ງຄ່າ ແລະ ເລເຢີຂອງທ່ານຈະບໍ່ຖືກແທນທີ່.

:::note
ປລັກອິນ Unreal ທີ່ເປີດສະເຕຈ, ນຳໃຊ້ດວງອາທິດ, ໂຄມໄຟ, ກ້ອງ ແລະ ການເປີດຮັບແສງ, ຕິດຕາມການສົ່ງແຕ່ລະຄັ້ງ ແລະ ເຣັນເດີກ້ອງ **ຍັງບໍ່ໄດ້ເຜີຍແຜ່**, ແລະ ຍັງບໍ່ໄດ້ຖືກທົດລອງໃນ Unreal. ຈົນກວ່າຈະເປັນແບບນັ້ນ, ການສົ່ງຈະວາງໄຟລ໌ໄວ້ໃນໂປຣເຈັກ ແລະ ເຄື່ອງມື USD ຂອງ Unreal ເອງສາມາດເປີດມັນໄດ້. Windows ເປັນລະບົບທຳອິດ; macOS ຈະຕາມມາ.
