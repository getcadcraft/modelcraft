아래는 ModelCraft가 기본으로 사용하는 밀기/당기기 키입니다. 다른 방식은 아래의 [모델러 키](topic:keyboard#modeler-keys)와 [ModelCraft 설정](topic:settings)을 참고하십시오.

단축키는 3D 뷰나 도구 모음 버튼에 포커스가 있을 때 작동합니다. 패널 입력란에 입력했거나 {{ui:Style}}의 목록을 바꾼 뒤에는 먼저 3D 뷰를 클릭하십시오. 그렇지 않으면 키가 그 입력란으로 들어갑니다. 각 컴퓨터에서 키를 쓰는 방법은 [키, 마우스, 트랙패드](common:keys)를 참고하십시오.

## Esc

{{key:Esc}} 키를 누를 때마다 한 단계씩 물러납니다:

1. 도구가 진행 중이던 것을 취소합니다(그리는 선, 밀기/당기기, 이동). 모든 것이 원래대로 돌아갑니다.
2. {{ui:Select}} 도구로 바꿉니다.
3. 선택을 해제합니다.
4. 편집 중인 그룹을 닫습니다.

{{key:Esc}} 키는 장면 재생도 멈춥니다. 값 상자에서는 입력한 내용을 지우고 뷰로 돌아갑니다.

## 도구 작동 중

| 키 | 기능 |
|---|---|
| 숫자, 또는 `. , - ' " [ < * /` 중 하나 | 값 상자에 입력 시작 |
| {{key:Enter}} | 값 상자에 입력한 내용 적용 |
| {{key:Right}} | 빨강 축으로 잠금(다시 누르면 해제) |
| {{key:Left}} | 초록 축으로 잠금 |
| {{key:Up}} | 파랑 축으로 잠금 |
| {{key:Down}} | 첫 클릭 전에 마지막으로 가리킨 모서리에 평행하게 잠금 |
| {{key:Shift}} 키 누르고 있기 | 누르는 동안 스냅된 방향을 유지 |
| {{key:Ctrl}}, {{key:Mod}} 또는 {{key:Alt}} 키(이동 시) | 이동과 복사 전환 |

화살표 키 잠금은 첫 클릭 후 {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}}, {{ui:Tape}}(점에서 측정할 때)에서 작동합니다. {{ui:Push/pull}} 도구는 항상 면의 방향을 따라 움직이며 잠금이 없습니다. {{ui:Rotate}}에서는 첫 클릭 후 화살표 키가 "잠김" 메시지를 표시하지만 회전 각도는 바꾸지 않습니다.

## 다른 때의 화살표 키

도구가 작업 중이 아닐 때 화살표 키는 카메라를 움직입니다.

| 키 | 기능 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 궤도 회전 |
| {{key:Shift}} 키와 화살표 | 초점 이동 |

## 마우스

| 동작 | 기능 |
|---|---|
| 클릭 | 현재 도구 사용 |
| 누르기, 끌기, 놓기 | 두 번 클릭과 같음(그리기 도구); 상자 선택({{ui:Select}}); 지나간 곳을 지움({{ui:Eraser}}) |
| 더블 클릭 | {{ui:Select}}: 면은 그 모서리와, 모서리는 그 면과 함께 선택하며, 그룹을 엽니다. 빈 공간에서는 그룹을 닫습니다. {{ui:Push/pull}}: 마지막 거리를 반복 |
| 세 번 클릭 | {{ui:Select}}: 연결된 모든 것 |
| {{key:Shift}} + 클릭 | {{ui:Select}}: 선택에 넣거나 뺌 |
| {{key:Mod}} + 클릭 | {{ui:Select}}: 선택에 추가 |
| {{key:Shift}} + {{key:Mod}} + 클릭 | {{ui:Select}}: 선택에서 제거 |
| 가운데 버튼 끌기 | 어느 도구에서든 궤도 회전 |
| {{key:Shift}} + 가운데 버튼 끌기 | 어느 도구에서든 초점 이동 |
| 오른쪽 버튼 끌기 | 어느 도구에서든 초점 이동 |
| 휠 | 포인터 쪽으로 줌 |

오른쪽 클릭 메뉴는 없습니다.

## 트랙패드

두 손가락 스와이프의 동작은 {{ui:Settings}} › {{ui:ModelCraft}} › Scrolling 설정에 따라 달라집니다.

| 제스처 | 트랙패드(또는 계산) | 마우스 휠 |
|---|---|---|
| 두 손가락 스와이프 | 궤도 회전 | 포인터 쪽으로 줌 |
| {{key:Shift}} + 두 손가락 스와이프 | 초점 이동 | 줌 |
| 핀치 | 포인터 쪽으로 줌 | 포인터 쪽으로 줌 |
| 두 손가락 누르고 끌기(보조 클릭 누른 채) | 초점 이동 | 초점 이동 |

[궤도 회전, 초점 이동, 줌](topic:orbit-pan-zoom#on-a-trackpad) 및 [ModelCraft 설정](topic:settings#scrolling-mouse-wheel-or-trackpad)을 참고하십시오.

## 모델러 키

{{ui:Settings}} › {{ui:ModelCraft}} › Controls를 모델러 스타일로 설정하면:

| 키 | 기능 |
|---|---|
| {{key:W}} 또는 {{key:Space}} | {{ui:Select}} |
| {{key:L}} / {{key:B}} / {{key:C}} / {{key:N}} | {{ui:Line}} / {{ui:Rectangle}} / {{ui:Circle}} / {{ui:Polygon}} |
| {{key:E}} | {{ui:Push/pull}}(돌출) |
| {{key:T}} | {{ui:Tape}} 측정 |
| {{key:D}} | {{ui:Dimension}} |
| {{key:G}} | 포인터에서 선택 항목을 바로 이동 |
| {{key:R}} | 선택 항목을 중간(파랑 축)을 기준으로 회전 |
| {{key:S}} | 선택 항목을 중간을 기준으로 축척 |
| 이동 또는 회전 중 {{key:X}} / {{key:Y}} / {{key:Z}} | 빨강 / 초록 / 파랑 축 잠금(다시 누르면 해제) |
| 클릭 또는 {{key:Enter}} | 내려놓기 |
| {{key:Esc}} 또는 오른쪽 클릭 | 원래 자리로 되돌리기 |
| {{key:Shift+D}} | 복제하고 복사본 이동 |
| {{key:X}} 또는 {{key:Delete}} | 선택 항목 지우기 |
| {{key:A}} / {{key:Alt+A}} | 모두 선택 / 아무것도 선택하지 않기 |
| {{key:Tab}} | 선택한 그룹 또는 구성요소 열기. 다시 누르면 닫기 |
| {{key:Mod+G}} / {{key:Mod+Shift+G}} | 그룹 만들기 / 구성요소 만들기 |
| 숫자패드 {{key:1}} / {{key:3}} / {{key:7}} | 정면 / 오른쪽 / 위 보기({{key:Mod}} 키와 함께: 뒤 / 왼쪽 / 아래) |
| 숫자패드 {{key:5}} | 원근 켜기 또는 끄기 |
| 숫자패드 {{key:.}} | 선택 항목으로 확대 |
| {{key:Home}} 또는 {{key:Shift+C}} | 범위 확대 |
| {{key:Shift+Tab}} | 스냅 켜기 또는 끄기 |
| 가운데 버튼 끌기 / {{key:Shift}} 키와 함께 / {{key:Mod}} 키와 함께 | 궤도 회전 / 초점 이동 / 줌 |
| {{key:Alt}} + 끌기 / {{key:Alt+Shift}} + 끌기 | 궤도 회전 / 초점 이동(가운데 버튼 불필요) |

복사, 붙여넣기, 실행 취소, 저장, 열기는 위에 나열된 키를 그대로 유지합니다. 입력한 값, 값 상자, {{ui:Push/pull}} 도구는 두 방식에서 똑같이 작동합니다.

## 터치 화면

| 제스처 | 기능 |
|---|---|
| 탭 | 현재 도구로 클릭 |
| 두 번 탭 | 더블 클릭 |
| 누르기, 끌기, 떼기 | 마우스의 누르기, 끌기, 놓기와 같음 |
| 두 손가락: 핀치 | 줌 |
| 두 손가락: 함께 움직이기 | 초점 이동({{ui:Settings}} › {{ui:ModelCraft}} › 터치 화면에서 궤도 회전으로 바꿀 수 있음) |
| 세 손가락: 함께 움직이기 | 궤도 회전(두 손가락이 궤도 회전 중이면 초점 이동) |
| 한 손가락을 가만히 대고 있기 | Enter 키처럼 도구 동작을 마칩니다. 진행 중인 동작이 없으면 끌어서 궤도 회전 |
| 한 손가락 동작 중 두 번째 손가락 | 그 동작 취소 |
| {{ui:Orbit}} 도구 선택 후 한 손가락 끌기 | 궤도 회전 |

터치 화면에서 값을 입력하려면 아래의 값 상자를 탭하고 입력한 다음, 키보드의 Enter(또는 Go) 키를 누르십시오.

## 이동 명령 위치

이동은 {{ui:Move}} 도구({{key:M}} 키)에 있습니다. 이동할 대상을 고르고, 기준점을 클릭한 뒤, 두 번째 점을 클릭하거나 거리를 입력합니다. [이동, 복사 및 배열 만들기](topic:move-copy)를 참고하십시오.
