텍스처는 평평한 그림이지만 메시는 평평하지 않습니다. **UV**는 각 면의 각 모서리가 그림의 어디에 놓이는지를 정합니다. UV 작업 공간에서 이를 만듭니다. **솔기**를 따라 메시를 잘라 조각을 펼친 다음(**펼치기**), 조각들을 정사각형 안에 맞춥니다(**패킹**).

## 열기

메시를 선택하고 작업 공간 목록에서 {{ui:UV}}를 고르십시오. 그룹이나 구성요소는 먼저 메시 작업 공간에서와 같이 메시로 바뀝니다. 3D 뷰는 왼쪽 절반으로 이동하며, 오른쪽의 **UV 편집기**에는 텍스처 정사각형에 펼쳐진 메시의 면이 표시됩니다. 선택은 메시 작업 공간에서와 같이 동작하며, 한쪽 뷰에서 선택한 것은 다른 쪽에서도 선택됩니다.

## 솔기 표시

솔기는 메시를 잘라 펼칠 수 있는 위치입니다. 솔기는 두 뷰 모두에서 빨간색으로 표시됩니다.

- 모서리를 선택한 다음({{ui:모서리}} 또는 {{key:2}}) {{ui:솔기 표시}}({{key:Ctrl+E}})를 누르십시오. {{ui:솔기 지우기}}({{key:Ctrl+Shift+E}})를 누르면 솔기가 해제됩니다.
- {{ui:날카로운 곳에 솔기}}는 모든 날카로운 모서리와 면이 60°를 넘게 만나는 모든 모서리에 솔기를 표시합니다. 상자는 여섯 면으로 나뉩니다.
- {{ui:UV에서 솔기 만들기}}는 UV가 이미 끊어진 곳(예: 투영 후)에 솔기를 표시합니다.

닫힌 조각을 평평하게 펴려면 솔기가 필요합니다. 공은 최소 한 번 잘라야 하고, 관은 길이 방향으로 한 번 잘라야 합니다.

## 펼치기

펼칠 면을 선택하고(전체 메시라면 아무것도 선택하지 않고), {{ui:펼치기}}({{key:U}})를 누르십시오. 솔기 사이의 각 조각은 가능한 한 각도를 정확하게 유지하면서 평평하게 펴지고(각도 기반 평탄화), 그다음 조각들이 정사각형 안에 패킹됩니다. {{ui:등각}}은 대신 최소 제곱 등각 사상으로 펼칩니다. 더 빠르지만, 심하게 휜 조각에서는 조금 덜 정확합니다. 평평한 시트로 만들 수 있는 형상, 예를 들어 한 번 잘라 펼친 원기둥의 옆면은 전혀 늘어나지 않은 채 펼쳐집니다.

## 투영

단순한 형상에는 투영만으로 충분한 경우가 많습니다.

| 투영 | 하는 일 |
| --- | --- |
| {{ui:상자}} | 각 면을 그 면이 가장 많이 향한 상자의 옆면에 투영합니다 |
| {{ui:원기둥}} | 파란 축을 기준으로 둥글게: 가로는 둘레 각도, 세로는 높이입니다 |
| {{ui:구}} | 중심에서: 가로는 둘레 각도, 세로는 위도입니다 |
| {{ui:뷰에서}} | 지금 3D 뷰에 보이는 대로 면을 투영합니다 |

원기둥이나 구의 이음매를 가로지르는 면은 한 조각으로 유지되므로, 그 UV는 정사각형의 오른쪽 가장자리를 조금 넘을 수 있습니다. 그 부분에서는 텍스처가 반복됩니다.

## 배치

- {{ui:패킹}}은 조각(아일랜드)들을 하나의 텍셀 크기로 정사각형 안에 맞추며, 각 조각은 가장 적은 공간을 차지하도록 회전됩니다. 패널에서 조각 사이의 간격을 정합니다.
- {{ui:90° 회전}}과 {{ui:대칭}}은 선택한 면의 UV를 회전하거나 대칭시킵니다.
- UV 편집기에서 선택한 면을 끌면 선택 영역의 UV가 이동합니다. 또는 편집기 위에 포인터를 놓고 {{key:R}} 또는 {{key:S}}를 누른 다음 움직이면 회전하거나 축척을 바꿉니다(클릭하면 그대로 유지되고, {{key:Esc}}는 취소합니다). {{key:G}}는 끌지 않고 이동합니다. 면을 두 번 클릭하거나({{key:L}}) 누르면 전체 아일랜드가 선택됩니다. 휠로 확대/축소하고, 가운데 또는 오른쪽 버튼으로 끌면 화면을 이동하며, {{key:F}}는 정사각형을 다시 화면에 맞춥니다.

모든 변경은 실행 취소 한 단계입니다.

## 확인하기

- {{ui:체커}}는 UV에서 메시 위에 라벨이 붙은 체커를 보여 줍니다. 고르고 정사각형인 체커는 텍스처가 고르게 놓여 있다는 뜻이며, 라벨은 텍스처가 어느 방향으로 흐르는지 보여 줍니다.
- {{ui:신축}}은 각 면이 UV 때문에 얼마나 늘어났는지에 따라 색을 입힙니다. 파란색은 늘어나지 않음, 초록색을 거쳐 빨간색은 많이 늘어남을 뜻합니다. 패널에서 **각도 꺾임**과 **크기 변화** 중 무엇으로 측정할지 고를 수 있으며, 평균값을 표시합니다.
