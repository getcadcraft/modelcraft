내보내기는 모델의 복사본을 다른 형식으로 만듭니다. `.modelcraft` 파일도 함께 보관하십시오. 이 파일만 모든 것을 유지하며, ModelCraft가 직접 여는 유일한 파일입니다.

## 내보내기

1. 먼저 저장합니다({{key:Mod+S}}). 작업 파일을 안전하게 보관하기 위해서입니다.
2. {{ui:파일}} 그룹에서 {{ui:내보내기}}를 클릭합니다.
3. 형식을 고릅니다. 브라우저가 모델과 같은 이름으로 파일을 다운로드합니다.

모델 전체가 내보내집니다. 한 부분만 내보내려면 저장하고, 나머지를 지운 다음 내보내고, 실행 취소하거나 다시 엽니다.

## 형식 고르기

| 하고 싶은 일 | 선택 | 참고 |
|---|---|---|
| 다른 3D 모델러에서 열기 | {{ui:Collada (.dae)}} | 그룹, 중첩 그룹, 구성요소(복사하지 않고 공유), 이름과 색을 유지합니다. Z 위 방향, 미터. |
| 렌더링하거나 시각화 프로그램에서 사용 | {{ui:OBJ (.obj)}} 또는 {{ui:glTF 바이너리 (.glb)}} | OBJ는 가장 널리 읽히는 형식입니다. 그룹 배치마다 별도의 객체로 씁니다. 하지만 색과 공유 구성요소는 없습니다. glTF는 구성요소와 색을 유지합니다. |
| 웹, 게임 엔진, AR에 올리기 | {{ui:glTF 바이너리 (.glb)}} | 모든 것이 담긴 파일 하나. |
| 3D 프린팅 | {{ui:3D 프린팅 검사 (STL 또는 3MF)…}} | 모델이 닫혀 있고 면 방향이 올바른지 검사한 뒤, 밀리미터 단위로 STL 또는 3MF를 씁니다. 참고: [3D 프린팅용 모델 준비](topic:print-3d). {{ui:3D 프린팅용 STL (.stl, 밀리미터)}}는 검사 없이 모델 전체를 씁니다. |
| BimCraft 또는 다른 BIM 프로그램에서 열기 | {{ui:BimCraft용 IFC (.ifc)}} | 최상위 그룹이나 구성요소마다 건물 요소 하나가 됩니다. |

상태 표시줄에 각 내보내기가 확인됩니다. 예: "House.stl 내보냄 (밀리미터)." 또는 "House.dae 내보냄 (Collada 1.4.1, Z 위 방향, 미터; 구성요소는 공유 상태 유지)."

## 내보내기 전에

- **객체를 그룹으로 묶으십시오.** Collada, glTF, IFC는 그룹과 구성요소를 별도의 객체로 유지합니다. 그룹에 속하지 않은 형상은 하나의 덩어리로 나가며, IFC에서는 "분리된 형상"이라는 이름의 요소 하나가 됩니다.
- **이름을 지정하십시오.** 그룹과 구성요소 이름은 Collada와 IFC에 들어갑니다. 그래서 "North wall"이라는 벽은 그대로 "North wall"로 전달됩니다.
- **면 방향을 확인하십시오.** 바깥쪽에서 청회색으로 보이는 면은 내보내기에서 안쪽을 향하게 됩니다. {{ui:면 뒤집기}}로 고칩니다([지우기 및 정리](topic:erase#a-face-facing-the-wrong-way) 참고).
- **인쇄하려면** 각 부품을 닫힌 솔리드로 만드십시오. 그룹마다 선택하고 {{ui:객체 정보}}에 "솔리드: 예"라고 표시되는지 확인합니다. 그다음 모델을 인쇄 크기로 축척하거나, 프린터 소프트웨어에서 축척합니다.

## BimCraft로 모델 보내기

1. 각 건물 부분을 그룹이나 구성요소로 만들고 이름을 지정합니다.
2. {{ui:내보내기}}를 고른 다음 {{ui:BimCraft용 IFC (.ifc)}}를 고릅니다.
3. 다운로드한 `.ifc` 파일을 BimCraft에서 엽니다.

개념 매스라면 대신 {{ui:내보내기}} › {{ui:BimCraft 매스 내보내기…}}를 사용합니다. 각 그룹이 층수, 바닥 면적, 부피를 가진 매스 옵션으로 전달됩니다. [매스를 BimCraft로 보내기](topic:massing-to-bimcraft)를 참고하십시오.

일반 IFC 내보내기는 두 앱 사이에 직접 연결을 만들지 않습니다. IFC에는 층이 하나만 있으며, 모든 요소는 유형이나 속성이 없는 일반 건물 요소 프록시입니다. 형상과 이름만 담깁니다. 닫힌 그룹은 솔리드 형상이 되고, 열린 그룹은 면이 됩니다.

## 선만 있는 경우

어떤 면에도 속하지 않는 모서리(보조선과 같은 선, 가져온 대지 평면도)는 OBJ와 Collada에 선으로 들어갑니다. glTF와 STL에는 이를 담을 곳이 없어 제외됩니다. 보조선과 장면은 어떤 형식으로도 내보내지 않습니다.

## 뷰를 이미지로 저장

{{ui:내보내기}} › {{ui:뷰 이미지 (.png)}}는 3D 뷰에 보이는 그대로, 화면 크기로 저장합니다. {{ui:두 배 크기의 이미지 (.png)}}는 가로와 세로를 두 배로 저장합니다(인쇄나 선명한 슬라이드용). 치수와 표시는 늘리지 않고 그 크기에 맞게 다시 그립니다.

하늘, 태양, 부드러운 그림자, 유리처럼 자연광에 가까운 그림이 필요하면 대신 {{ui:내보내기}} › {{ui:그림 렌더링…}}를 사용합니다. 참고: [그림 렌더링](topic:render).

깔끔한 그림을 얻으려면 먼저 [프레젠테이션 보기](topic:styles-shadows#presentation-view)({{key:Shift+P}})를 켭니다. 축, 보조선, 단면 윤곽과 선택 상태는 제외됩니다. 카메라, 스타일, 그림자를 원하는 대로 설정하거나 [장면](topic:scenes)으로 이동하십시오. 장면의 움직이는 영상을 저장하려면 {{ui:장면}} 패널의 {{ui:애니메이션 내보내기}} 명령을 사용합니다.

## 뷰 인쇄 또는 PDF로 저장

- {{ui:내보내기}} › {{ui:뷰 PDF (.pdf)}}는 한 페이지짜리 PDF를 저장합니다. 화면 크기의 두 배로 뷰를 담고 치수를 포함하며, A4 용지(모델이 피트와 인치 단위이면 Letter)에 가로 방향으로 배치됩니다. 아래에는 파일 이름, 날짜, 단위를 표시하는 줄이 붙습니다.
- {{ui:내보내기}} › {{ui:뷰 인쇄…}} 명령은 같은 페이지를 브라우저의 인쇄 대화상자에 띄웁니다. 프린터를 고르거나 "PDF로 저장"을 선택합니다.

페이지에는 뷰가 있는 그대로 표시됩니다. 원근 뷰에는 축척이 없습니다. 축척에 맞는 도면을 원하면 {{ui:원근}}을 끄고 {{ui:위}} 또는 {{ui:앞}}에서 봅니다. 그리고 중요한 크기에 [치수](topic:dimensions)를 추가합니다. [프레젠테이션 보기](topic:styles-shadows#presentation-view)는 축, 보조선, 선택 상태를 제외하며, 치수는 남습니다.
