ModelCraft는 초기 설계 단계를 위한 3D 모델러입니다: 매싱 스터디, 실 배치, 빠른 건물 형태 검토와 그 그림자. 평면 도형을 그리고, 위로 당겨 솔리드로 만들고, 그 면 위에 다시 그리면서 계속 작업합니다. 웹 브라우저에서 실행되며 모델은 사용자 컴퓨터에 남습니다.

SketchUp을 사용해 보셨다면 아는 내용 대부분이 그대로 적용됩니다: 같은 도구 문자, 밀기/당기기, 정확한 크기를 위한 값 입력란, 그룹과 구성요소. [다른 모델러에서 오신 분께](topic:coming-from)에 차이점이 정리되어 있습니다.

## ModelCraft 열기

1. 최신 버전의 Chrome, Edge, Firefox, Safari에서 ModelCraft를 엽니다. [브라우저와 컴퓨터](common:browsers)를 참조하십시오.
2. 3D 뷰가 나타날 때까지 기다립니다: 가운데에 밝은(또는 어두운) 영역과 "모델링 시작" 카드가 보입니다.

화면에는 위쪽에 도구 모음, 왼쪽에 {{ui:개요}} 및 {{ui:구성요소}}, 가운데에 3D 뷰, 오른쪽에 {{ui:객체 정보}}, {{ui:스타일}}, {{ui:장면}}, 아래쪽에 값 입력란과 단위가 있는 상태 표시줄이 있습니다. 각 부분은 [ModelCraft 화면](topic:workspace)에서 설명합니다.

:::note
ModelCraft는 브라우저의 3D 그리기 기능인 WebGL이 필요합니다. 화면 가운데가 비어 있고 도구가 반응하지 않으면 [문제 해결](topic:troubleshooting#the-3d-view-is-blank)을 참조하십시오.
:::

## 먼저 단위 확인

오른쪽 아래 모서리를 보십시오. 단위 선택기에 길이를 측정하는 단위가 표시됩니다.

- 새 모델은 브라우저가 미국(및 라이베리아, 미얀마)으로 설정된 경우 **피트와 인치**로, 그 밖의 지역에서는 **밀리미터**로 시작합니다.
- 바꾸려면 선택기에서 다른 단위를 고릅니다: {{ui:피트와 인치}}, {{ui:in}}, {{ui:m}}, {{ui:cm}}, {{ui:mm}} 중 하나입니다. 모델 자체의 크기는 변하지 않으며, 길이가 표시되는 방식과 단위 없는 숫자를 읽는 방식만 바뀝니다.

단위 없이 입력한 숫자는 모델의 단위를 사용합니다. 피트와 인치 모델에서 단위 없는 숫자는 **인치**이므로 `120`은 10피트입니다.

## ModelCraft의 안내로 첫 모델 만들기

3D가 처음이십니까? {{ui:모델링 시작}} 카드에서 {{ui:안내에 따라 첫 모델 만들기}} 버튼을 클릭합니다({{ui:뷰}} 메뉴에도 있습니다). 작은 카드가 평면 사각형에서 3D 프린터에 보낼 수 있는 모델까지 네 단계를 안내합니다.

1. 바닥에 사각형을 그립니다.
2. 위로 당겨 상자로 만듭니다.
3. 상자를 하나의 객체(그룹)로 만듭니다.
4. 3D 프린팅 검사를 하고 3MF 또는 STL 파일을 다운로드합니다.

카드는 버튼이 아니라 모델을 지켜봅니다. 어떤 방법으로 했든 단계가 끝나면 다음으로 넘어가고, 실행 취소하면 한 단계 되돌아갑니다. {{ui:도구 고르기}} 버튼은 도구를 대신 골라 줍니다. 언제든지 {{ui:×}} 버튼으로 닫을 수 있습니다.

## 첫 번째 상자 그리기

1. {{key:R}} 키를 눌러 {{ui:사각형}} 도구를 선택하거나, 도구 모음의 {{ui:그리기}} 그룹에서 {{ui:사각형}} 버튼을 클릭합니다.
2. 뷰 가운데 근처의 바닥을 한 번 클릭합니다. 첫 번째 모서리입니다.
3. 포인터를 멀리 움직입니다. 사각형이 따라오고, 아래쪽 값 입력란({{ui:치수}} 라벨)에 크기가 표시됩니다.
4. 크기를 입력하고 {{key:Enter}} 키를 누릅니다: 예를 들어 `4m,3m`, 피트와 인치로는 `16',12'`입니다. 값 입력란을 먼저 클릭할 필요는 없습니다. 숫자를 입력하면 자동으로 그곳에 들어갑니다.

   바닥에 평면 사각형이 생깁니다. 이것이 **면**입니다: 가장자리로 둘러싸인 표면입니다.

5. {{key:P}} 키를 눌러 {{ui:밀기/당기기}} 도구를 선택합니다.
6. 사각형을 클릭하고 포인터를 위로 움직인 다음 다시 클릭합니다. 또는 사각형을 클릭하고 `3m`이나 `10'` 같은 높이를 입력한 다음 {{key:Enter}} 키를 누릅니다.

   사각형이 윗면, 아랫면, 옆면 네 개를 가진 상자가 됩니다.

7. {{key:Space}} 키를 눌러 {{ui:선택}} 도구로 돌아간 다음 상자의 윗면을 클릭합니다. 오른쪽의 {{ui:객체 정보}}에 그 면적이 표시됩니다.

:::tip
두 번 클릭하는 대신 끌어도 됩니다: 첫 번째 모서리에서 누르고, 끌고, 두 번째 모서리에서 놓습니다. 모든 그리기 도구에서 두 방법 모두 사용할 수 있습니다.
:::

## 둘러보기

- **궤도 회전:** 마우스 가운데 버튼(휠)으로 끌거나, {{key:O}} 키를 누르고 왼쪽 버튼으로 끕니다.
- **초점 이동:** 오른쪽 버튼으로 끌거나, {{key:Shift}} 키를 누른 채 가운데 버튼으로 끕니다.
- **줌:** 휠을 돌립니다. 포인터 아래의 대상 쪽으로 줌이 됩니다.
- **전체 보기:** {{key:Shift+Z}} 키를 누르거나 {{ui:범위}} 버튼을 클릭합니다.

트랙패드나 터치 화면에서는 제스처가 다릅니다. [궤도 회전, 초점 이동, 줌](topic:orbit-pan-zoom)을 참조하십시오.

## 실행 취소

{{key:Mod+Z}} 키로 실행 취소, {{key:Mod+Y}} 키로 다시 실행하거나 도구 모음의 {{ui:실행 취소}} 및 {{ui:다시 실행}} 버튼을 사용합니다. ModelCraft는 모델이 열려 있는 동안 최근 200단계를 기억합니다. 기록은 파일에 저장되지 않습니다.

## 모델 저장

1. {{ui:파일}} 그룹의 {{ui:저장}} 버튼을 클릭하거나 {{key:Mod+S}} 키를 누릅니다.
2. 브라우저가 모델 이름의 파일을 다운로드합니다. 예: `제목 없음.modelcraft`. 상태 표시줄에 저장된 위치가 표시됩니다: "제목 없음.modelcraft 파일을 다운로드 폴더에 저장했습니다."

**저장은 다운로드입니다.** 저장할 때마다 다운로드 폴더에 새 사본이 만들어지며, 열었던 파일을 덮어쓰지 않습니다. 프로젝트 폴더를 깔끔하게 유지하려면 파일을 직접 옮기거나 이름을 바꾸십시오. 이유와 다른 방법은 [열기, 저장, 가져오기, 내보내기](topic:files)에서 설명합니다.

:::warning
ModelCraft는 자동으로 저장하지 않습니다. 저장되지 않은 변경 사항이 있는 상태에서 탭을 닫으면 브라우저가 먼저 묻습니다("사이트에서 나가시겠습니까?"). 머무르기를 선택한 다음 저장하십시오.
:::

## 도움말 보기

{{key:F1}} 키를 누르거나 앱 바의 {{ui:도움말}} 버튼을 클릭하면 모델 옆에 이 도움말이 열립니다. 연결 없이도 작동합니다. 닫으려면 {{key:F1}} 키를 다시 누르거나 도움말 안에서 {{key:Esc}} 키를 누르십시오. [이 도움말 사용하기](common:help)를 참조하십시오.
