ModelCraft는 컴퓨터의 파일을 읽고 씁니다. 업로드되는 것은 없습니다. 연 파일은 브라우저 안에서 읽히고, 저장한 파일은 다운로드됩니다. [파일이 저장되는 위치](common:your-files)를 참조하십시오.

## 형식 한눈에 보기

| 형식 | 열기 | 가져오기 | 내보내기 | 용도 |
|---|---|---|---|---|
| ModelCraft (`.modelcraft`) | 예 | 아니요 | {{ui:저장}} | 작업 파일입니다. 모든 내용을 보관합니다. |
| USD (`.usd`, `.usda`, `.usdc`, `.usdz`) | 예 | 예 | {{ui:다른 이름으로 저장}}, {{ui:내보내기}} | 렌더링 및 장면 조립 프로그램용. ModelCraft의 USD는 모든 내용을 보관합니다. [USD 저장, 열기 및 내보내기](topic:usd)를 참조하십시오. |
| SketchUp (`.skp`) | 아니요 | 예 | 아니요 | SketchUp 모델을 가져올 때 사용합니다. 그룹, 구성요소, 색, 면의 텍스처, 태그, 부드러운 모서리를 유지합니다. [SKP 모델 가져오기](topic:import-sketchup-files)를 참조하십시오. |
| Collada (`.dae`) | 아니요 | 예 | 예 | 다른 3D 모델링 프로그램과 모델을 주고받을 때 사용합니다. 그룹, 구성요소, 색을 유지합니다. |
| OBJ (`.obj`) | 아니요 | 예 | 예 | 렌더링 및 시각화 프로그램용. |
| glTF (`.glb`, `.gltf`) | 아니요 | 예 | `.glb`만 | 웹 뷰어, 게임 엔진, AR용. |

| FBX (`.fbx`) | 아니요 | 예 | 아니요 | 애니메이션 및 게임 프로그램의 모델 (FBX 2011 이상). |

| `.3dm` | 아니요 | 예 | 아니요 | NURBS 모델: 폴리서피스, 메시, 곡선, 블록, 도면층을 메시, 모서리, 구성요소, 태그로. [.3dm 모델 가져오기](topic:import-3dm-files)를 참조하십시오. |

| IFC (`.ifc`) | 아니요 | 아니요 | 예 | BIM 프로그램 및 BimCraft용. |
| DWG (`.dwg`) | 아니요 | 예 | 예 | 모델링의 바탕이 되는 배치도나 평면도, 그리고 CAD 프로그램으로 모델을 보낼 때. |

[파일 형식 상세](topic:formats)에는 각 형식이 유지하는 항목과 제외하는 항목이 정확히 나와 있습니다.

## ModelCraft 파일

`.modelcraft` 파일은 모델 전체를 보관합니다: 지오메트리, 그룹, 구성요소, 가이드, 장면, 단위, 그리고 저장할 때 사용하던 카메라와 스타일. 실행 취소 기록은 보관하지 않습니다.

### 모델 열기

1. {{ui:파일}} 그룹의 {{ui:열기}} 버튼을 클릭하거나 {{key:Mod+O}} 키를 누릅니다.
2. 화면의 모델에 저장되지 않은 변경 사항이 있으면 ModelCraft가 묻습니다: "이 모델에는 저장되지 않은 변경 사항이 있습니다. 먼저 사본을 저장하시겠습니까?" {{ui:사본 저장}}, {{ui:변경 사항 버리기}} 또는 {{ui:취소}} 중 하나를 선택합니다.
3. `.modelcraft` 파일을 선택합니다.

모델은 저장할 때의 단위와 카메라 상태로 열립니다. `.modelcraft` 파일을 3D 뷰에 끌어다 놓거나, 시작 카드의 최근 파일 목록에서 클릭해 열 수도 있습니다(파일을 다시 열 수 있는 브라우저와 데스크톱 앱에서 가능합니다).

:::desktop
데스크톱 앱에서는 `.modelcraft` 파일을 두 번 클릭하면 ModelCraft에서 열립니다. Collada, OBJ, glTF, DWG 또는 DXF 파일에서 **다음으로 열기**를 선택해도 같습니다(이 경우 파일은 새 모델로 가져옵니다).
:::

### 모델 저장

{{ui:저장}} 버튼을 클릭하거나 {{key:Mod+S}} 키를 누릅니다. 브라우저는 `<name>.modelcraft` 파일을 다운로드합니다. 여기서 이름은 연 파일의 이름이며, 새 모델이면 "제목 없음"입니다.

:::desktop
데스크톱 앱에서 {{ui:저장}}은 연 파일을 그 자리에 씁니다. 새 모델이면 저장 위치를 묻습니다.
:::

- {{ui:다른 이름으로 저장}} ({{key:Mod+Shift+S}})은 사본을 `.modelcraft` 파일 또는 [USD](topic:usd)로 저장합니다. 브라우저가 지원하면 이름과 위치를 묻습니다. 그렇지 않으면 다운로드된 파일의 이름을 바꾸십시오. 이름을 바꾼 파일을 연 뒤 다음 저장부터 새 이름을 사용합니다.
- 저장할 때마다 새로 다운로드됩니다. 브라우저 설정에 따라 다운로드 폴더에 바로 저장되거나 저장 위치를 물어봅니다. 같은 이름의 파일이 이미 있으면 대부분의 브라우저는 `Untitled (1).modelcraft`처럼 번호를 붙입니다.

:::chromium
다운로드할 때마다 폴더를 선택하려면 브라우저 설정을 열고 "다운로드"를 검색한 뒤 "다운로드 전에 각 파일의 저장 위치 묻기"를 켜십시오.
:::

:::firefox
다운로드할 때마다 폴더를 선택하려면 **설정**, **일반**을 차례로 열고 "다운로드"에서 "파일을 저장할 위치를 항상 묻기"를 선택하십시오.
:::

:::safari
다운로드 위치를 바꾸려면 **Safari**, **설정**, **일반**을 차례로 열고 "파일 다운로드 위치"를 설정하십시오.
:::

### 새 모델 시작

{{ui:새로 만들기}} 버튼을 클릭합니다. 저장되지 않은 변경 사항이 있으면 ModelCraft가 먼저 묻습니다. 새 모델은 비어 있는 상태로 시작하며, 지역의 단위(미국에서는 피트와 인치, 그 밖의 지역에서는 밀리미터)를 사용하고 장면은 없습니다.

### 저장하기 전에 브라우저가 닫히면

ModelCraft는 변경 후 몇 초 뒤에 저장되지 않은 작업의 사본을 브라우저에 보관합니다. 사본은 백그라운드에서 기록되므로 큰 모델도 작업을 방해하지 않습니다. 저장하기 전에 탭이나 브라우저가 닫히면, 다음에 ModelCraft를 열 때 "작업 복구?"라고 묻습니다. 복구하면 모델이 열렸던 그대로 열리지만, 아직 파일로 저장되지 않은 상태입니다. 유지하려면 저장하십시오. [작업 복구](common:recover)를 참조하십시오.

### CadCraft에서: ModelCraft에서 열기

CadCraft 도면 프로그램에서 **보기**, **더보기**, **ModelCraft에서 열기**를 차례로 선택하면, 열려 있는 도면이 새 탭의 ModelCraft로 DWG 파일로 넘어갑니다. 가져온 DWG 파일과 같은 방식으로 들어옵니다: 지면의 선이 그룹 안에 놓여 모델링할 준비가 된 상태입니다. 업로드되는 것은 없으며, 파일은 브라우저 자체의 저장 공간을 거칩니다.

## 가져오기

가져오기는 열려 있는 모델에 파일을 추가합니다. 모델을 대체하지 않습니다.

1. {{ui:파일}} 그룹의 {{ui:가져오기}} 버튼을 클릭하거나 파일을 3D 뷰에 끌어다 놓습니다.
2. SketchUp, Collada, OBJ, glTF, FBX, PLY, STL, Alembic, STEP, `.3dm`, USD, DWG 또는 DXF 파일을 선택합니다.

   파일은 **하나의 그룹**으로 들어와 선택된 상태가 되며, 뷰가 확대되어 그룹을 보여줍니다. 상태 표시줄에 가져온 내용이 표시되고, "가져오지 않음: 텍스처 2개"처럼 가져오지 못한 항목도 나열됩니다.

3. 지오메트리를 직접 다루려면 그룹을 두 번 클릭해 그룹 안에서 편집하거나 {{ui:분해}}를 클릭하십시오.

알아두실 점:

- **크기와 위쪽 방향:** Collada 파일은 단위와 위쪽 축을 밝히며, ModelCraft가 이를 변환합니다. glTF는 항상 미터 단위입니다. OBJ 파일에는 단위 정보가 없으므로 ModelCraft는 미터 단위이며 Y축이 위쪽인 것으로 읽습니다. OBJ가 1000배 크거나 작게 들어오면 `0.001` 또는 `1000` 같은 배율로 [축척](topic:rotate-scale)을 사용하십시오.
- **DWG와 DXF**는 면이 아니라 지면의 선(모서리)으로 들어옵니다. 도면에 단위가 없으면 "도면 단위"라는 대화상자가 도면 단위 하나가 무엇인지 묻습니다. [배치도에서 모델링하기](topic:site-plan)를 참조하십시오.
- **제한:** 가져오기는 300 MB를 넘는 파일을, 열기는 200 MB를 넘는 파일을 거부합니다. 정점이나 면이 200만 개를 넘는 파일은 너무 크다는 이유로 거부됩니다. 64 MB를 넘는 OBJ는 읽기 전에 거부됩니다. 텍스트 파일(Collada, OBJ, ASCII STL, USD 텍스트)은 약 4 MB씩 나누어 읽으므로 텍스트 한 블록에 파일 전체가 담기지 않습니다. 테스트에서 16 MB OBJ를 열 때 약 0.5 GB의 메모리를 사용했습니다.

## 내보내기

1. {{ui:파일}} 그룹의 {{ui:내보내기}} 버튼을 클릭합니다.
2. 형식을 선택합니다: {{ui:glTF 바이너리 (.glb)}}, {{ui:Collada (.dae)}}, {{ui:OBJ (.obj)}}, {{ui:3D 프린팅용 STL (.stl, 밀리미터)}}, {{ui:색 포함 PLY (.ply)}}, {{ui:USD(.usda, .usdc, .usdz)…}}, {{ui:BimCraft용 IFC (.ifc)}}, {{ui:CAD용 DWG (.dwg, 2004)}} 또는 {{ui:CAD용 DXF (.dxf, R12)}}.

브라우저가 파일을 다운로드하며, 파일 이름은 모델 이름과 같습니다. 선택 영역이 아니라 모델 전체를 내보냅니다. glTF, Collada, OBJ 파일은 백그라운드에서 기록되므로 큰 모델을 내보내는 동안에도 ModelCraft는 계속 작동하며, 파일이 준비되면 다운로드가 시작됩니다. 빈 모델은 내보내지 않으며, "모델이 비어 있습니다. 먼저 무언가를 그리십시오." 메시지가 표시됩니다. [다른 프로그램용 모델 내보내기](topic:export-model)를 참조하십시오.

## 온라인과 오프라인

ModelCraft의 모든 기능은 컴퓨터에서 실행됩니다. 따라서 앱을 불러온 뒤에는 연결이 없어도 모델링, 열기, 저장, 가져오기, 내보내기가 모두 작동합니다.

연결이 전혀 없는 상태에서도 ModelCraft를 열려면, 온라인일 때 오프라인 사용을 위해 저장하십시오:

1. 상단 앱 바의 {{ui:오프라인용 저장}} 버튼을 클릭합니다.
2. 저장하는 동안 버튼에 진행 상황이 표시됩니다("저장 중 40/212"). ModelCraft는 자체 파일(DWG 읽기 기능 포함), 이 도움말, 3D 라이브러리를 저장하므로 시간이 걸릴 수 있습니다.
3. 버튼에 {{ui:오프라인 사용 준비됨}}이 표시되면 ModelCraft는 연결 없이 같은 주소에서 열립니다. DWG 가져오기도 오프라인에서 작동합니다.

나중에 {{ui:오프라인 사용 준비됨}} 버튼을 클릭하여 {{ui:다시 저장 (최신 버전 받기)}} 또는 {{ui:오프라인 사본 제거}}를 선택합니다. 버튼에 {{ui:저장하지 못했습니다}}가 표시되면 일부 파일이 다운로드되지 않은 것입니다. 연결을 확인하고 버튼을 클릭해 다시 시도하십시오. {{ui:오프라인 사용 불가}}는 이 브라우저 창에 사본을 보관할 수 없다는 뜻입니다(비공개 창과 일부 관리되는 컴퓨터). [오프라인 작업](common:offline)을 참조하십시오.

클라우드 저장은 아직 제공되지 않습니다. 모든 모델은 저장한 위치에 있습니다.

:::offline
현재 오프라인입니다. 모델링과 저장은 계속할 수 있습니다. 앱 바에 {{ui:오프라인 사용 준비됨}}이 표시되지 않으면, 다시 온라인이 될 때까지 이 탭을 새로 고치지 마십시오.
:::

## 데스크톱 앱

:::desktop
여덟 개 앱이 모두 포함된 데스크톱 앱인 CadCraft Studio에서 ModelCraft를 사용하고 있습니다. 파일은 선택한 위치에서 열리고 저장됩니다.
:::

:::web
ModelCraft는 Mac, Windows, Linux의 브라우저에서 실행되며, 여덟 개 앱이 하나의 설치 파일에 모두 들어 있는 CadCraft Studio 데스크톱 앱에서도 실행됩니다. getcadcraft.com/download에서 받을 수 있습니다.
:::
