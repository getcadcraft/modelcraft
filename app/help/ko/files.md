ModelCraft는 사용자 컴퓨터의 파일을 읽고 씁니다. 업로드되는 것은 없습니다. 연 파일은 브라우저 안에서 읽히고, 저장한 파일은 다운로드로 처리됩니다. [내 파일이 가는 곳](common:your-files)을 참조하십시오.

## 형식 한눈에 보기

| 형식 | 열기 | 가져오기 | 내보내기 | 용도 |
|---|---|---|---|---|
| ModelCraft (`.modelcraft`) | 예 | 아니요 | {{ui:저장}} | 작업 파일. 모든 내용을 보존합니다. |
| USD (`.usd`, `.usda`, `.usdc`, `.usdz`) | 예 | 예 | {{ui:다른 이름으로 저장}}, {{ui:내보내기}} | 렌더링 및 장면 조립 프로그램. ModelCraft 자체 USD는 모든 내용을 보존합니다. [USD 저장, 열기, 내보내기](topic:usd)를 참조하십시오. |
| SketchUp (`.skp`) | 아니요 | 예 | 아니요 | SketchUp 모델 가져오기. 그룹, 구성요소, 색상, 면의 텍스처, 태그, 부드러운 모서리를 보존합니다. [SKP 모델 가져오기](topic:import-sketchup-files)를 참조하십시오. |
| Collada (`.dae`) | 아니요 | 예 | 예 | 다른 3D 모델러와 모델 교환. 그룹, 구성요소, 색상을 보존합니다. |
| OBJ (`.obj`) | 아니요 | 예 | 예 | 렌더링 및 시각화 프로그램. |
| glTF (`.glb`, `.gltf`) | 아니요 | 예 | `.glb`만 | 웹 뷰어, 게임 엔진, AR. |
| STL (`.stl`) | 아니요 | 예 | 예 | 3D 프린팅(밀리미터 단위). |
| PLY (`.ply`) | 아니요 | 예 | 예 | 색이 있는 메시: 스캔, 컬러 프린팅. |
| FBX (`.fbx`) | 아니요 | 예 | 아니요 | 애니메이션 및 게임 프로그램의 모델(FBX 2011 이상). |
| Alembic (`.abc`) | 아니요 | 예 | 아니요 | 지오메트리 캐시, 첫 번째 샘플 기준. |
| STEP (`.step`, `.stp`) | 아니요 | 예 | 아니요 | 파트 모델러와 공급업체의 파트. 실제 크기의 닫힌 메시로 가져옵니다. [파일 형식](topic:formats)을 참조하십시오. |
| `.3dm` | 아니요 | 예 | 아니요 | NURBS 모델: 폴리서피스, 메시, 곡선, 블록, 레이어를 메시, 모서리, 구성요소, 태그로 가져옵니다. [.3dm 모델 가져오기](topic:import-3dm-files)를 참조하십시오. |
| 3MF (`.3mf`) | 아니요 | 아니요 | 예 | 색이 있는 3D 프린팅(밀리미터 단위). {{ui:3D 프린팅 검사 (STL 또는 3MF)…}}에서 만듭니다. [3D 프린팅용 모델 준비](topic:print-3d)를 참조하십시오. |
| IFC (`.ifc`) | 아니요 | 아니요 | 예 | BIM 프로그램 및 BimCraft. |
| DWG (`.dwg`) | 아니요 | 예 | 예 | 모델링의 바탕이 되는 대지 평면도 또는 건물 평면도. 모델을 CAD 프로그램으로 보낼 때도 사용합니다. |
| DXF (`.dxf`) | 아니요 | 예 | 예 | 위와 같으며, 모든 CAD 프로그램용입니다. |

[파일 형식 상세](topic:formats)에서 각 형식이 무엇을 보존하고 무엇을 빼는지 정확히 확인할 수 있습니다.

## ModelCraft 파일

`.modelcraft` 파일은 모델 전체를 보존합니다: 지오메트리, 그룹, 구성요소, 안내선, 장면, 단위, 저장 당시의 카메라와 스타일. 실행 취소 기록은 보존하지 않습니다.

### 모델 열기

1. {{ui:파일}} 그룹의 {{ui:열기}} 버튼을 클릭하거나 {{key:Mod+O}} 키를 누릅니다.
2. 화면의 모델에 저장되지 않은 변경 사항이 있으면 ModelCraft가 묻습니다: "이 모델에는 저장되지 않은 변경 사항이 있습니다. 먼저 사본을 저장하시겠습니까?" {{ui:사본 저장}}, {{ui:변경 사항 버리기}}, {{ui:취소}} 중에서 선택합니다.
3. `.modelcraft` 파일을 선택합니다.

모델은 저장된 단위와 저장된 카메라 그대로 열립니다. `.modelcraft` 파일을 3D 뷰에 끌어다 놓거나, 시작 카드의 최근 파일 목록에서 클릭해도 됩니다(파일을 다시 열 수 있는 브라우저와 데스크톱 앱에서 가능).

:::desktop
데스크톱 앱에서는 `.modelcraft` 파일을 더블 클릭하면 ModelCraft에서 열리며, Collada, OBJ, glTF, DWG, DXF 파일의 **연결 프로그램**으로 ModelCraft를 선택해도 열립니다(새 모델로 가져옴).
:::

### 모델 저장

{{ui:저장}} 버튼을 클릭하거나 {{key:Mod+S}} 키를 누릅니다. 브라우저가 `<name>.modelcraft` 파일을 다운로드합니다. 이름은 열었던 파일의 이름이며, 새 모델은 "제목 없음"입니다.

:::desktop
데스크톱 앱에서는 {{ui:저장}} 버튼은 열었던 파일에 바로 덮어씁니다. 새 모델은 저장 위치를 묻습니다.
:::

- {{ui:다른 이름으로 저장}}({{key:Mod+Shift+S}})는 사본을 `.modelcraft` 파일 또는 [USD](topic:usd)로 저장합니다. 브라우저가 지원하면 이름과 위치를 묻습니다. 지원하지 않으면 다운로드된 파일의 이름을 직접 바꾸십시오. 이름을 바꾼 파일을 연 뒤의 다음 저장부터는 새 이름이 사용됩니다.
- 저장할 때마다 새 다운로드가 생성됩니다. 브라우저 설정에 따라 바로 다운로드 폴더로 가거나 저장 위치를 묻습니다. 같은 이름의 파일이 이미 있으면 대부분의 브라우저가 `제목 없음 (1).modelcraft`처럼 번호를 붙입니다.

:::chromium
매번 폴더를 선택하려면 브라우저 설정을 열고 "다운로드"를 검색한 다음 "다운로드 전에 각 파일의 저장 위치 확인"을 켭니다.
:::

:::firefox
매번 폴더를 선택하려면 **설정**, **일반**을 차례로 열고 "다운로드"에서 "항상 파일을 저장할 위치 선택"을 고릅니다.
:::

:::safari
다운로드 위치를 바꾸려면 **Safari**, **설정**, **일반**을 차례로 열고 "파일 다운로드 위치"를 지정합니다.
:::

### 새 모델 시작

{{ui:새로 만들기}} 버튼을 클릭합니다. 저장되지 않은 변경 사항이 있으면 ModelCraft가 먼저 묻습니다. 새 모델은 비어 있는 상태로 시작하며, 사용자 지역의 단위(미국은 피트와 인치, 그 밖의 지역은 밀리미터)를 쓰고 장면은 없습니다.

### 저장하기 전에 브라우저가 닫힌 경우

ModelCraft는 변경할 때마다 몇 초 뒤에 저장되지 않은 작업의 사본을 브라우저에 보관합니다. 저장하기 전에 탭이나 브라우저가 닫히면 다음에 ModelCraft를 열 때 "작업을 복구할까요?"라고 묻습니다. 복구하면 모델이 이전 상태로 열리지만 아직 파일로 저장된 것은 아니므로, 보관하려면 저장하십시오. [작업 복구](common:recover)를 참조하십시오.

### CadCraft에서: Open in ModelCraft

CadCraft 도면 앱에서 **View**, **More**, **Open in ModelCraft**를 차례로 선택하면 열려 있는 도면이 DWG로 새 탭의 ModelCraft에 전달됩니다. 가져온 DWG와 똑같이 도착합니다: 바닥 위의 선이 그룹 안에 들어 있어 바로 모델링할 수 있습니다. 업로드되는 것은 없으며, 파일은 브라우저 자체 저장소를 거쳐 전달됩니다.

## 가져오기

가져오기는 열려 있는 모델에 파일을 추가하며, 모델을 대체하지 않습니다.

1. {{ui:파일}} 그룹의 {{ui:가져오기}} 버튼을 클릭하거나 파일을 3D 뷰에 끌어다 놓습니다.
2. SketchUp, Collada, OBJ, glTF, FBX, PLY, STL, Alembic, STEP, `.3dm`, USD, DWG, DXF 파일 중 하나를 선택합니다.

   파일은 선택된 상태의 **그룹 하나**로 들어오고 뷰가 그에 맞게 확대됩니다. 상태 표시줄에 가져온 내용이 표시되며, 가져오지 못한 항목이 있으면 "가져오지 않음: 텍스처 2개"처럼 함께 나열됩니다.

3. 지오메트리를 직접 편집하려면 그룹을 더블 클릭해 안에서 편집하거나 {{ui:분해}} 버튼을 클릭합니다.

알아 둘 점:

- **크기와 위쪽 방향:** Collada 파일에는 단위와 위쪽 축이 기록되어 있어 ModelCraft가 변환합니다. glTF는 항상 미터 단위입니다. OBJ 파일에는 단위가 없으므로 ModelCraft는 미터 단위, Y축이 위쪽인 것으로 읽습니다. OBJ가 1000배 크거나 작게 들어오면 `0.001` 또는 `1000` 같은 배율로 [축척](topic:rotate-scale)을 사용하십시오.
- **DWG와 DXF**는 면이 아니라 바닥 위의 선(모서리)으로 들어옵니다. 도면에 단위가 기록되어 있지 않으면 "도면 단위" 대화상자가 도면 단위 하나의 크기를 묻습니다. [대지 평면도 위에서 모델링](topic:site-plan)을 참조하십시오.
- **제한:** 300 MB를 넘는 파일은 가져오기가, 200 MB를 넘는 파일은 열기가 거부됩니다. 꼭짓점 또는 면이 200만 개를 넘는 파일은 너무 크다는 이유로 거부됩니다.

## 내보내기

1. {{ui:파일}} 그룹의 {{ui:내보내기}} 버튼을 클릭합니다.
2. 형식을 선택합니다: {{ui:glTF 바이너리 (.glb)}}, {{ui:Collada (.dae)}}, {{ui:OBJ (.obj)}}, {{ui:3D 프린팅용 STL (.stl, 밀리미터)}}, {{ui:색 포함 PLY (.ply)}}, {{ui:USD(.usda, .usdc, .usdz)…}}, {{ui:BimCraft용 IFC (.ifc)}}, {{ui:CAD용 DWG (.dwg, 2004)}}, {{ui:CAD용 DXF (.dxf, R12)}} 중 하나입니다.

브라우저가 모델 이름의 파일을 다운로드합니다. 선택 항목만이 아니라 모델 전체가 내보내집니다. 빈 모델은 내보내지지 않습니다: "모델이 비어 있습니다. 먼저 그리십시오." [다른 프로그램용으로 모델 내보내기](topic:export-model)를 참조하십시오.

## 온라인과 오프라인

ModelCraft의 모든 작업은 사용자 컴퓨터에서 실행되므로, 앱을 불러온 뒤에는 모델링, 열기, 저장, 가져오기, 내보내기 모두 연결 없이 작동합니다.

연결이 전혀 없는 상태에서 ModelCraft를 열려면 온라인일 때 오프라인용으로 저장해 두십시오.

1. 위쪽 앱 바의 {{ui:오프라인용 저장}} 버튼을 클릭합니다.
2. 저장하는 동안 버튼에 진행 상황이 표시됩니다("212 중 40 저장 중"). ModelCraft는 자체 파일(DWG 리더 포함), 이 도움말, 3D 라이브러리를 저장하므로 시간이 걸릴 수 있습니다.
3. 버튼에 {{ui:오프라인 사용 준비됨}} 문구가 표시되면 같은 주소에서 연결 없이 ModelCraft가 열리고 DWG 가져오기도 오프라인에서 작동합니다.

나중에 {{ui:오프라인 사용 준비됨}} 버튼을 클릭하면 {{ui:다시 저장 (최신 버전 받기)}} 또는 {{ui:오프라인 사본 제거}} 항목을 선택할 수 있습니다. 버튼에 {{ui:저장하지 못했습니다}} 문구가 표시되면 일부 파일이 다운로드되지 않은 것이므로 연결을 확인하고 버튼을 클릭해 다시 시도하십시오. {{ui:오프라인 사용 불가}} 표시는 이 브라우저 창이 사본을 보관할 수 없다는 뜻입니다(시크릿 창 및 일부 관리되는 컴퓨터). [오프라인 작업](common:offline)을 참조하십시오.

클라우드 저장은 아직 제공되지 않습니다. 모든 모델은 사용자가 저장한 곳에 있습니다.

:::offline
오프라인 상태입니다. 모델링과 저장은 계속할 수 있습니다. 앱 바에 {{ui:오프라인 사용 준비됨}} 문구가 표시되어 있지 않다면 다시 온라인이 될 때까지 이 탭을 새로 고치지 마십시오.
:::

## 데스크톱 앱

:::desktop
CadCraft Studio에서 ModelCraft를 사용하고 있습니다. CadCraft Studio는 여덟 개 앱이 모두 들어 있는 데스크톱 앱입니다. 파일은 사용자가 선택한 위치에서 열리고 저장됩니다.
:::

:::web
ModelCraft는 Mac, Windows, Linux의 브라우저에서 실행되며, getcadcraft.com/download에서 받을 수 있는 CadCraft Studio(여덟 개 앱이 한 번에 설치되는 데스크톱 앱)에서도 실행됩니다.
:::
