{{ui:Export}} › {{ui:Live view}} 명령을 선택하면 앱 위에 패널이 열리며, 모델을 실시간 화면으로 보여 줍니다. 모델의 위치와 날짜에 맞는 하늘과 태양, 태양이 만드는 그림자, 면에 설정한 재질과 모양, 램프, 벽과 바닥에서 반사된 빛이 표시됩니다. 보기를 돌리면 함께 돌고, 모델을 바꾸면 잠시 후 변경 사항이 나타납니다. 아무것도 업로드되지 않습니다.

## 열기

1. {{ui:Export}} › {{ui:Live view}} 명령을 선택하십시오. 패널이 오른쪽 아래 모서리에 열립니다.
2. 제목 표시줄을 끌어서 이동하고, 모서리를 당겨서 크기를 키우십시오.
3. {{ui:New window}}: 패널이 보조 화면에 띄울 수 있도록 별도 창으로 이동합니다. {{ui:Export}} › {{ui:Live view in a new window}} 명령은 패널을 바로 그 창에서 엽니다. 브라우저가 팝업 창을 차단하면 패널로 열립니다.
4. {{ui:Close}}: 패널을 닫습니다.

## 컨트롤

| 컨트롤 | 기능 |
|---|---|
| {{ui:Follow the view}} | 켜짐: Live 보기가 ModelCraft 보기가 바라보는 방향을 따릅니다. 걸으면 꺼집니다 |
| {{ui:Walk}} | 모델 안을 걷습니다(아래 참조) |
| {{ui:Gravity}} | 걷는 동안: 바닥에 서고 계단을 오릅니다. 꺼짐: 날아다닙니다 |
| {{ui:Time}} | 하루 중 시간, 05:00부터 21:00까지. 끌면 태양이 움직입니다 |
| {{ui:Month}} | 월(그 달의 21일). 겨울과 여름의 태양을 볼 수 있습니다 |
| {{ui:Quality}} | {{ui:For this computer}}([내 컴퓨터](topic:your-machine)에 맞는 설정), 또는 {{ui:Low}}, {{ui:Medium}}, {{ui:High}} |

화면 하단의 줄은 보기를 그리는 방식(WebGPU 또는 WebGL 2), 품질, 간접광을 표시합니다.

## 모델 안 걷기

1. 기본 보기를 원하는 위치로 돌리고 {{ui:Walk}}를 선택하십시오. 보기의 눈 위치 아래 바닥에 서게 되며, 키는 1.6 m입니다.
2. Live 보기를 클릭한 다음 {{key:W}} 키, {{key:A}} 키, {{key:S}} 키, {{key:D}} 키 또는 방향키를 사용하십시오. {{key:Shift}} 키를 누르고 있으면 달립니다. 드래그하면 주변을 둘러볼 수 있습니다.
3. 40 cm 이하의 턱은 올라갑니다(계단). 그보다 높은 것은 벽입니다. 벽에 막히면 벽을 따라 미끄러집니다.
4. {{ui:Gravity}}가 꺼져 있으면 날아다닙니다. {{key:E}} 키는 위로, {{key:Q}} 키는 아래로 이동합니다.
5. {{key:Esc}} 키를 누르면 걷기를 멈춥니다.

## 식물, 바위, 사람 흩뿌리기

Live 보기 막대의 {{ui:Scatter}}는 그림 옆에 흩뿌리기 패널을 엽니다. 흩뿌리기 세트는 엔투라지 라이브러리(나무, 관목, 잔디, 꽃, 바위, 사람, 자동차)의 항목을 모델의 일부에 퍼뜨립니다. 항목은 Live 보기에서만 그려집니다. 모델의 지오메트리가 아니며 기본 보기에는 표시되지 않습니다.

1. **면 채우기:** ModelCraft에서 면(또는 지형 같은 그룹)을 선택한 다음 {{ui:Fill selection}} 명령을 선택하십시오. 세트가 선택한 면을 덮습니다.
2. **칠하기:** {{ui:Paint}} 도구를 선택하고 Live 보기 위에서 드래그하십시오. 면을 선택했으면 칠은 그 면에만 적용되고, 선택이 없으면 브러시 아래의 모든 것(지면 포함)에 적용됩니다. {{ui:Brush size}}: 브러시 크기를 정합니다. {{ui:Eraser}}: 칠한 지점을 지웁니다.
3. 흩뿌릴 항목을 선택하십시오. 각 항목 옆의 숫자는 가중치입니다. 3과 1을 설정하면 첫 번째 항목 3개마다 두 번째 항목이 1개씩 생깁니다.

| 컨트롤 | 기능 |
|---|---|
| {{ui:Per m²}} | 제곱미터당 항목 수 |
| {{ui:Keep away (m)}} | 다른 객체와 이보다 가까이 두지 않으며, 지붕이나 테이블 아래에도 두지 않습니다. 0이면 끕니다 |
| {{ui:Turn (°)}} | 각 항목을 수직축을 중심으로 무작위로 돌리는 정도 |
| {{ui:Steepest (°)}} | 표면이 이보다 가파르면 항목을 두지 않습니다 |
| {{ui:Size}} | 항목 자체 크기에 곱하는 배율로, 가장 작은 크기와 가장 큰 크기 |
| {{ui:Height from, to (m)}} | 이 높이 사이에서만 배치합니다(비워 두면 모든 높이) |
| {{ui:Lean with the surface}} | 0이면 항목을 똑바로 세우고, 1이면 경사면에 수직으로 세웁니다 |
| {{ui:Seed}}, {{ui:Shuffle}} | 같은 시드는 항상 같은 흩뿌리기를 만듭니다. {{ui:Shuffle}}: 다른 배치를 고릅니다 |

세트는 .modelcraft 파일에 저장되며, 덮고 있는 면을 바꾸면 함께 따라갑니다. Live 보기가 최대로 그리는 항목 수는 [내 컴퓨터](topic:your-machine)의 수준에 따라 정해집니다. {{ui:Processor only}}: 20 000개, {{ui:Graphics card, basic}}: 100 000개, {{ui:Graphics card, high}}: 100만 개입니다. 패널에는 밀도가 요구하는 개수 중 실제로 배치된 개수가 표시됩니다. 예산에 도달하거나 다른 객체가 제외하는 곳에서는 적게 배치됩니다. 카메라에 가까운 항목은 원래 모양으로, 먼 항목은 같은 색의 단순한 형태로 그려집니다.

:::note
흩뿌린 항목은 Live 보기(및 그 안의 걷기, 파노라마, 독립 뷰어)에 표시됩니다. 그림 렌더링에는 아직 표시되지 않습니다.
:::

## 공유: 파노라마, 투어, 뷰어, 동영상

Live 보기 막대의 {{ui:Share}}는 Live 보기로 파일을 만듭니다. 모든 것은 이 컴퓨터에서 만들어지며, 아무것도 업로드되지 않습니다.

| 선택 | 결과 |
|---|---|
| {{ui:360° panorama}} | 보기가 있는 위치(또는 걷고 있는 위치)에서 찍은 360° 그림입니다. 파노라마 뷰어와 대부분의 사진 사이트에서 열 수 있는 등장방형 PNG입니다 |
| {{ui:Add this spot to the tour}} 다음 {{ui:Save the tour}} | 각 지점의 파노라마와, 각 지점에서 볼 수 있는 지점으로 가는 화살표가 있는 웹 페이지 하나입니다(사이에 벽이 있으면 화살표가 숨겨집니다) |
| {{ui:Save a viewer}} | 이 실시간 화면의 모델이 담긴 웹 페이지 하나입니다. 돌려 보고, 걸어 다니고, 저장한 장면으로 이동할 수 있습니다. WebGPU나 WebGL 2를 지원하는 브라우저에서 폴더, USB 드라이브, 이메일을 통해 오프라인으로 열립니다. 설치나 계정이 필요 없고, 인터넷에서 아무것도 불러오지 않습니다 |
| {{ui:Video of the path}} | 타임라인의 카메라 경로(또는 저장된 장면을 순서대로)를 Live 보기 크기의 이 실시간 화면 동영상으로 만듭니다. 브라우저가 만들 수 있으면 WebM 또는 MP4, 그렇지 않으면 번호가 매겨진 그림을 담은 ZIP입니다 |

파노라마의 크기는 품질에 따라 정해집니다. {{ui:Low}}, {{ui:Medium}}, {{ui:High}}에서 가로 폭은 각각 1024, 2048, 4096 픽셀입니다. 뷰어 파일은 모델 크기에 더해 약 5 MB입니다.

:::note
투어와 뷰어는 보여 주기 위한 것이며 편집용이 아닙니다. 저장할 때의 모델 상태를 그대로 유지합니다.
:::

## 간접광

벽에서 햇빛이 반사되어 바닥으로 들어오는 빛과 방 안쪽의 어두운 부분은 [렌더링된 그림](topic:render)과 같은 경로 추적기로 계산됩니다. 모델 곳곳의 지점에서 작은 파노라마를 계산하며, 모든 프로세서 코어에서 배경으로 작업합니다. 작업하는 동안 하단 줄에 {{ui:간접광: 40 %}}가 표시되고, 준비되면 보기에 반영됩니다. 변경하면 다시 시작합니다.

:::note
이것은 Live 보기를 위한 근사치이며 완성된 그림이 아닙니다. 지점 사이의 작은 세부 사항은 가까운 지점의 간접광을 받습니다. 완성된 그림은 [그림 렌더링](topic:render)을 사용하십시오.
:::

## 밝기와 색

Live 보기는 [그림 렌더링](topic:render)과 같은 밝기, 화이트 밸런스, 대비, 보기 변환(ACES, AgX, filmic, standard 중 하나)을 사용합니다. 그곳에서 설정하면 Live 보기도 따라갑니다.

:::note
브라우저마다 다릅니다. WebGPU를 지원하는 브라우저(Windows, macOS, ChromeOS의 Chrome 및 Edge, Safari 26)에서는 Live 보기가 WebGPU를 사용합니다. 그 밖의 환경(Linux의 대부분의 브라우저, 구형 Apple 시스템)에서는 WebGL 2를 사용하며 결과는 같습니다.
:::
