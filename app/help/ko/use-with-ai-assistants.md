## 학습 내용

AI 어시스턴트(또는 직접 작성한 스크립트)가 ModelCraft와 함께 작업하도록 하는 방법과, 어시스턴트가 무엇을 건드릴 수 있는지 정하는 방법을 설명합니다.

ModelCraft에는 **고유한 AI가 없으며** 어디로도 아무것도 보내지 않습니다. 어시스턴트는 여러분이 준비하십시오. 모델 컨텍스트 프로토콜(MCP)를 사용하는 프로그램이면 무엇이든 됩니다. ModelCraft는 도구만 제공하며, 어떤 도구를 쓸지는 여러분이 고릅니다.

## 켜기

1. {{ui:설정}}을 여십시오(앱 막대의 톱니바퀴 또는 {{key:Mod+,}}). 그런 다음 {{ui:ModelCraft}} 탭으로 이동하십시오.
2. {{ui:어시스턴트}} 아래에서 **AI 어시스턴트와 스크립트의 ModelCraft 사용 허용**을 선택하십시오. 이 설정을 켜기 전까지는 꺼져 있습니다.
3. 허용할 작업을 고르십시오. **읽기**는 처음부터 선택되어 있습니다. **편집**, **저장** 또는 **내보내기**는 필요할 때만 선택하십시오.

선택하지 않은 권한 밖의 도구는 어시스턴트에 제공되지 않습니다. 그래도 어시스턴트가 그런 도구를 요청하면 ModelCraft는 거부하고 활동 기록에 남깁니다. 이 스위치를 끄면 모든 연결이 즉시 끊어지며, {{ui:ModelCraft 설정 초기화}}를 실행해도 꺼집니다.

## 어시스턴트 연결

어시스턴트는 이 컴퓨터의 **CadCraft Studio**를 통해 연결됩니다. Studio는 이 컴퓨터에서만 접근할 수 있는 작은 서버를 실행하며, 시작할 때마다 새로 만드는 토큰으로 보호됩니다. Studio에서 {{ui:어시스턴트 연결}}을 선택하고 주소와 토큰을 어시스턴트에 복사하십시오(붙여넣을 정확한 설정은 Studio가 보여 줍니다). 토큰을 절대 공유하지 마십시오.

:::note
브라우저 탭은 어시스턴트를 위한 연결을 열 수 없습니다. 브라우저 앱에서는 이 컴퓨터의 CadCraft Studio를 사용하기 전까지 스위치가 아무 효과도 없습니다.
:::

## 직접 제어하기

- **모든 변경은 실행 취소 한 단계**이며, 어시스턴트가 붙인 이름으로 표시됩니다(예: "어시스턴트: box"). {{key:Mod+Z}}를 누르면 어시스턴트의 마지막 변경을 한꺼번에 되돌립니다.
- **연결 여부를 알 수 있습니다.** 연결되어 있는 동안 앱 막대의 버튼에 어시스턴트의 이름이 표시됩니다. 버튼을 누르면 어시스턴트가 할 수 있는 작업을 보거나 **연결 해제**를 실행할 수 있습니다.
- **활동.** {{ui:설정}} › {{ui:ModelCraft}} › {{ui:어시스턴트}} › {{ui:활동}}에는 모든 호출이 나열됩니다. 언제, 어떤 도구를, 완료되었는지 거부되었는지 나옵니다. {{ui:기록 저장}}을 누르면 사본을 보관합니다.

## 어시스턴트가 요청할 수 있는 작업

| 도구 | 권한 | 하는 일 |
|---|---|---|
| `app_info`, `model_describe` | 읽기 | 모델의 단위, 크기, 모든 그룹과 구성요소의 위치, 닫힌 솔리드인지 여부와 부피 |
| `view_screenshot` | 읽기 | 화면에 보이는 대로의 3D 뷰 그림 |
| `box_add`, `cylinder_add` | 편집 | 여러분이나 어시스턴트가 정한 위치와 크기로 새 그룹을 만드는 상자 또는 원기둥("3m", "10'" 또는 모델 단위의 숫자) |
| `instance_move`, `instances_erase` | 편집 | 그룹과 구성요소를 이동하거나 지웁니다 |
| `faces_list`, `materials_list` | 읽기 | 그룹 또는 자유 형상의 면(각 면의 방향, 면적, 중심), 칠할 수 있는 재료와 색 |
| `push_pull` | 편집 | {{ui:밀기/당기기}}와 같이 면을 밀거나 당깁니다 |
| `paint` | 편집 | 면이나 그룹 전체를 색 또는 재료로 칠합니다 |
| `group_make` | 편집 | 자유 면과 그룹으로 그룹 또는 구성요소를 만듭니다 |
| `scene_add`, `scene_show` | 편집 | 뷰를 장면으로 저장하고, 저장된 장면으로 이동합니다 |
| `mesh_add` | 편집 | 메시 작업 공간에서 추가하는 것과 같이, 시작점으로 쓸 메시 객체(큐브, 구, 원기둥 등)를 추가합니다 |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | 읽기 / 편집 | 메시의 모디파이어 스택: 대칭, 배열, 세분할, 베벨 등. 어느 것도 영구히 적용되지 않습니다 |
| `usd_export` | 내보내기 | 모델을 OpenUSD(.usda, .usdc 또는 .usdz)로 내보냅니다. 모델을 USD로 저장하는 것과 같습니다([USD](topic:usd)). Studio에서 허용한 폴더에 저장하며, 그렇지 않으면 다운로드됩니다 |
| `render_still` | 내보내기 | 뷰 또는 저장된 장면의 렌더링 그림을 만듭니다. {{ui:렌더링}} 대화상자의 {{ui:렌더링}} 버튼과 같은 방식이며, 다른 설정을 요청하지 않는 한 여러분의 렌더링 설정을 따릅니다(장면 프리셋: 외부, 내부, 단면, 야간 또는 자동, 빠름 또는 고품질, 크기, 샘플, 하늘). 어시스턴트가 볼 수 있는 PNG로 주거나, Studio에서 허용한 폴더에 PNG, EXR 또는 렌더 파일로 저장합니다([그림 렌더링](topic:render)) |
| `render_queue` | 내보내기 | 고품질 그림을 {{ui:렌더링}} 대화상자의 대기열에 추가하고(뷰 또는 저장된 장면) 대기열을 실행합니다. 완성된 그림은 허용한 폴더로 가거나, 여러분을 위해 대화상자의 {{ui:렌더 대기열}}에 남습니다. WebGPU가 필요합니다 |
| `link_push` | 편집 | 다른 프로그램에서 연결된 모델을 업데이트합니다([.3dm 모델을 실시간으로 유지하기](topic:live-3dm-link) 참조) |
| `link_status` | 읽기 | 연결된 모델이 아직 있는지, 마지막으로 언제 업데이트되었는지 알려 줍니다 |
| `undo` | 편집 | 어시스턴트 자신의 단계를 되돌립니다 |

어시스턴트가 만든 솔리드는 그룹으로 들어오므로 여러분이 그린 것과 절대 합쳐지지 않습니다. 모델을 저장하는 도구는 없습니다. 저장은 여러분이 직접 하며, 내보내기나 렌더링에는 **내보내기**가 선택되어 있어야 합니다. 렌더링은 모델을 바꾸지 않습니다. 저장된 장면을 렌더링하면 {{ui:장면}}을 사용할 때와 같이 뷰가 그 장면으로 이동합니다.

## 문제가 생기면

- **어시스턴트에 ModelCraft 도구가 보이지 않습니다:** 이 창에서 스위치가 켜져 있는지, 그리고 Studio에서 이 창이 열려 있는지 확인하십시오.
- **"편집 권한이 필요합니다":** {{ui:어시스턴트}} 아래에서 **편집**을 선택한 다음 다시 요청하십시오.
- **"401" 또는 "토큰" 오류:** 토큰이 바뀌었습니다(Studio를 다시 시작했거나 {{ui:새 토큰}}을 실행한 경우). 새 토큰을 어시스턴트 설정에 복사하십시오.
