## 3D 화면이 비어 있음

**증상:** 화면 가운데가 비어 있거나 배경색만 보이며, 도구를 클릭해도 아무 일도 일어나지 않습니다.

**원인:** 그리기에는 브라우저의 3D 그래픽인 WebGL 2가 필요합니다. 브라우저가 오래되었거나, 하드웨어 가속이 꺼져 있거나, 그래픽 드라이버가 차단된 경우 이 기능이 없습니다.

**해결 방법:**

:::chromium
1. 브라우저 설정을 열고 "그래픽 가속"을 검색합니다.
2. ‘사용 가능한 경우 그래픽 가속 사용’ 옵션을 켜고 브라우저를 다시 실행합니다.
3. 이미 켜져 있다면 주소 표시줄에 `chrome://gpu`를 입력합니다(Edge에서는 `edge://gpu`). 목록에서 "WebGL2"를 찾습니다. 비활성화되어 있으면 그래픽 드라이버를 업데이트합니다.
:::

:::firefox
1. **설정**을 열고 **일반**을 선택한 다음, "성능" 항목까지 스크롤합니다.
2. ‘권장 성능 설정 사용’ 옵션을 해제하고, ‘사용 가능한 경우 하드웨어 가속 사용’ 옵션을 켭니다. Firefox를 다시 시작합니다.
3. 그래도 실패하면 주소 표시줄에 `about:support`를 입력하고 "그래픽" 항목에서 WebGL 2를 확인합니다.
:::

:::safari
macOS와 Safari를 업데이트하십시오. 최신 버전의 Safari는 항상 WebGL 2가 켜져 있습니다. **Safari** › **설정** › **고급**(또는 **기능 플래그**)에서 실험 기능을 바꾸었다면 재설정하십시오.
:::

회사 컴퓨터, 원격 데스크톱 또는 가상 머신에서는 정책에 따라 3D 그래픽이 차단될 수 있습니다. 다른 컴퓨터에서 시도하십시오. [브라우저와 컴퓨터](common:browsers)를 참조하십시오.

## 키가 작동하지 않거나 상자에 입력됨

**원인:** 키보드 포커스가 패널 입력란에 있습니다. 예: {{ui:Style}}의 {{ui:Faces}} 목록, 태양 설정, {{ui:Entity info}}의 {{ui:Name}} 입력란, 단위 선택기. 그러면 글자 키와 화살표 키가 그 입력란으로 들어갑니다.

**해결 방법:** 3D 화면을 클릭한 다음 키를 다시 누르십시오. 대화상자가 열려 있는 동안에도 키는 작동하지 않습니다.

## 숫자를 입력해도 아무 일도 일어나지 않음

- **아직 방향이 없음.** 입력한 길이는 첫 클릭부터 포인터가 가리키는 방향으로 적용됩니다. 원하는 방향으로 포인터를 조금 움직인 다음 입력하십시오.
- **잘못된 시점.** 대부분의 도구는 첫 클릭 후에만 입력 값을 받습니다. 먼저 첫 번째 모서리, 면 또는 이동 기준점을 클릭하십시오. {{ui:Circle}} 및 {{ui:Polygon}} 도구는 첫 클릭 전에 변의 수를 입력받습니다.
- **"3m, 10'6" 또는 4m,3m처럼 길이를 입력하십시오."** 이 값을 읽을 수 없습니다. 소수점 쉼표(`2,5`)가 있는지 확인하고, 마침표를 사용하십시오.

## 터치 화면에서 도형이 잘못된 위치에서 시작됨

**증상:** 손가락으로 그릴 때 첫 사각형은 괜찮지만, 다음 사각형, 원 또는 선은 터치한 위치가 아니라 이전 터치가 끝난 위치에서 시작됩니다.

**원인:** 이 빌드의 버그입니다. 터치 화면에서 도구가 이전 제스처의 마지막 스냅 점을 기억합니다.

**해결 방법:** 새 도형을 그리기 전에 도구 모음에서 해당 도구 버튼을 다시 탭하십시오. 그러면 도구가 새로 시작되고, 첫 점은 터치한 위치에 놓입니다.

## 한 그룹을 편집했는데 다른 그룹도 바뀜

**증상:** {{ui:Move}} 도구와 {{key:Ctrl}} 키로 그룹을 복사했고, 복사본 하나를 열어 편집했더니 다른 복사본도 바뀌었습니다. {{ui:Outliner}}에는 두 항목이 같은 이름으로 표시됩니다.

**원인:** 이 빌드에서는 그룹을 복사하면 구성요소의 경우와 같이 같은 그룹의 두 번째 배치가 만들어집니다. ModelCraft의 {{ui:Make unique}} 버튼은 구성요소에만 제공됩니다.

**해결 방법:** 바꾸려는 복사본을 선택하고, {{ui:Entity info}}에서 {{ui:Make component}}를 클릭한 다음 {{ui:Make unique}}를 클릭하십시오. 그러면 그 복사본은 자체 내용을 갖게 됩니다. 또는 {{ui:Explode}}하십시오.

## 밀기/당기기가 예상과 다르게 작동함

- **"밀기/당기기는 면에서 작동합니다. 면을 클릭하십시오."** 모서리나 빈 공간을 클릭했습니다. 면이 강조될 때까지 포인터를 가져간 다음 클릭하십시오.
- **면이 그룹 안에 있습니다.** 먼저 그룹을 더블 클릭하여 엽니다.
- **창이 벽을 관통하지 않았습니다.** 사각형은 벽 앞이 아니라 벽면 위에 그려야 하며, 벽에는 뒷면이 있어야 합니다. [벽에 개구부 내기](topic:openings#if-it-did-not-cut-through)를 참조하십시오.
- **두 상자가 겹치지만 합쳐지지 않습니다.** 이 빌드에서는 서로 밀어 넣은 솔리드끼리 서로를 자르거나 결합하지 않습니다.

## 선이나 도형이 면을 만들지 않음

면은 모서리가 평평한 고리를 닫을 때만 채워집니다. 마지막 점이 첫 점에 스냅되었는지("끝점") 그리고 모든 모서리가 한 평면에 있는지 확인하십시오. 평면에서 약간 벗어난 고리는 선으로 남습니다. 모서리 중 하나를 다시 그리되, 모서리 점에 스냅하십시오.

## 면을 선택하거나 지울 수 없음

- {{ui:Select}} 도구를 사용해 모서리 근처를 클릭하면 모서리가 선택됩니다. 면의 가운데에 더 가깝게 클릭하십시오.
- {{ui:Eraser}}는 면을 선택하지 않습니다. 면을 선택하고 {{key:Delete}} 키를 누르거나, 면의 모서리 중 하나를 지우십시오.
- 면이 그룹이나 구성요소에 속해 있으면 클릭하면 전체가 선택됩니다. 더블 클릭하여 엽니다.

## "먼저 이동할 것을 선택하거나 그것을 클릭하십시오."

{{ui:Move}}, {{ui:Rotate}}, {{ui:Scale}} 도구는 작업할 대상이 필요합니다. 먼저 선택하거나, 빈 공간이나 가이드가 아닌 대상 자체를 클릭하여 도구를 시작하십시오.

## "먼저 형상을 선택하십시오(창을 드래그하거나 세 번 클릭하여 연결된 모든 항목을 선택)."

{{key:G}} 및 {{key:Shift+G}} 키는 선택 항목이 필요합니다. 가이드는 그룹으로 묶을 수 없습니다.

## 화살표 키가 고정 대신 회전함

잠금은 그리기 또는 편집 도구의 첫 클릭 후에만 작동합니다. {{ui:Push/pull}}에는 잠금이 없으며, {{ui:Rotate}}에서는 잠금이 회전 각도를 바꾸지 않습니다. 그 밖의 경우 화살표 키는 화면을 회전합니다.

## 전체 화면에서 Esc

전체 화면에서는 브라우저가 처음 누른 {{key:Esc}} 키로 전체 화면을 빠져나갈 수 있습니다. 도구를 취소하려면 {{key:Esc}} 키를 다시 누르십시오.

## 가운데 버튼이 없음

{{ui:Orbit}}을 위해 {{key:O}} 키를 누른 채 드래그하거나 화살표 키를 사용하십시오. [회전, 초점 이동, 줌](topic:orbit-pan-zoom#without-a-middle-button)을 참조하십시오.

### 가져온 모델의 크기가 잘못되었거나 옆으로 누워 있음

- **OBJ:** OBJ에는 단위가 없으며, ModelCraft에서는 미터 단위로 읽습니다. 밀리미터 모델은 1,000배 크게 가져와집니다. `0.001` 배율을 적용하십시오([축척 조정](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size) 참조). 인치 모델은 `0.0254` 배율을 적용하십시오.
- **OBJ가 옆으로 누움:** ModelCraft에서는 Y축이 위인 OBJ 파일을 기대합니다. Z축이 위인 파일은 누워서 가져와집니다. 빨강 축을 기준으로 90° 회전하십시오. 빨강 축 방향을 향하는 면에서 {{ui:Rotate}} 중심을 클릭하거나, 파일을 원래 프로그램에서 열어 Y축 위로 내보내십시오.
- **DWG 또는 DXF:** "도면 단위" 대화상자에서 잘못된 단위를 선택했습니다. 실행 취소한 뒤 다시 가져오십시오.

## 파일 열기

| 메시지 | 해결 방법 |
|---|---|
| "이 파일은 ModelCraft 모델이 아닙니다(JSON이 아님)." | 다른 형식은 {{ui:Import}}를 사용하십시오. |
| "이 파일은 열 수 있는 ModelCraft 파일이 아닙니다: …" | 파일이 손상되었거나 수동으로 변경되었습니다. |
| "이 모델은 최신 ModelCraft 버전에서 저장되었습니다…" | 최신 버전에서 여십시오. |
| "이 파일은 200 MB를 넘습니다." | 이 도구에서 열기에는 모델이 너무 큽니다. |

## 작업을 잃어버림

ModelCraft에서는 스스로 파일에 저장하지 않습니다. 저장되지 않은 변경 사항이 있는 탭을 닫거나 새로 고칠 때 브라우저가 먼저 묻습니다("이 사이트를 떠나시겠습니까?" 또는 "사이트를 다시 로드하시겠습니까?"). 머물러서 저장하는 것을 선택하십시오. 새로 만들기와 열기도 물어봅니다("저장되지 않은 변경 사항"). 브라우저나 컴퓨터가 충돌하면 같은 브라우저에서 ModelCraft 앱을 다시 여십시오. 저장되지 않은 작업을 되돌려 줍니다("작업을 복구하시겠습니까?"; [작업 복구](common:recover) 참조). {{key:Mod+S}} 키를 눌러 자주 저장하십시오.

## 다운로드 폴더에 사본이 계속 쌓임

저장할 때마다 새 다운로드가 되며, 이름은 `Untitled (1).modelcraft`, `Untitled (2).modelcraft`처럼 붙습니다. 이전 파일을 삭제하거나, 브라우저가 각 파일을 어디에 저장할지 묻도록 설정하고 이전 파일은 직접 덮어쓰십시오. [열기, 저장, 가져오기, 내보내기](topic:files#save-a-model)를 참조하십시오.

## 느려짐

- 실행 취소의 각 단계는 모델의 사본을 보관합니다([메시](topic:meshes)는 바뀐 부분만 보관합니다). 그래서 밀기/당기기 형상을 매우 크게 가져온 경우 편집마다 시간이 더 걸립니다. 필요 없는 것은 분해하거나 지우고, 저장한 다음 다시 여십시오. 다시 열면 실행 취소 기록도 지워집니다.
- 태양 그림자가 가장 많은 비용을 씁니다. 모델링하는 동안 {{ui:Sun shadows}} 선택을 해제하십시오.

## 그림자가 없음

{{ui:Sun shadows}}가 꺼져 있거나, 선택한 시간에 태양이 졌거나("이 시간에는 태양이 졌습니다."), 스타일이 그림자를 그리지 않는 {{ui:Wireframe}}입니다.

## "이 브라우저에서는 전체 화면을 허용하지 않았습니다."

일부 브라우저와 내장 보기에서는 전체 화면을 거부합니다. 대신 브라우저 자체의 전체 화면 기능을 사용하십시오({{pick:mac=Control-Command-F|windows linux=F11}}).

## 연결 없이는 ModelCraft를 열 수 없음

ModelCraft에서는 해당 브라우저에서 오프라인용으로 저장한 뒤에만 오프라인으로 열 수 있습니다. 앱 막대의 버튼에 {{ui:Offline ready}} 상태로 표시되어야 합니다. 온라인 상태에서 열고 {{ui:Save for offline}}을 클릭하십시오. 버튼에 {{ui:Could not save}}가 표시되면 더 좋은 연결에서 다시 클릭하십시오. {{ui:Offline not available}}는 이 창(비공개 창이나 관리되는 컴퓨터)이 사본을 보관할 수 없다는 뜻입니다. [오프라인 작업](common:offline)을 참조하십시오.
