SketchUp에 익숙하다면 ModelCraft도 친숙하게 느껴질 것입니다. 면과 밀기/당기기라는 같은 개념, 같은 도구 문자, 클릭하지 않고 입력하는 값 상자, 빨강, 녹색, 파랑 축을 이용한 추론, 그룹, 구성요소, 아웃라이너, 객체 정보, 장면이 모두 있습니다. 이 페이지는 직접 대응하는 것과, 더 중요하게는 대응하지 않는 것을 보여 줍니다.

## 그대로 이어지는 습관

| 익숙한 방식 | ModelCraft에서 |
|---|---|
| {{key:Space}} 선택, {{key:L}} 선, {{key:R}} 사각형, {{key:C}} 원 | 같음: {{key:Space}}, {{key:L}}, {{key:R}}, {{key:C}} |
| {{key:P}} 밀기/당기기, {{key:M}} 이동, {{key:Q}} 회전, {{key:S}} 축척, {{key:E}} 지우개, {{key:T}} 줄자 | 같음: {{key:P}}, {{key:M}}, {{key:Q}}, {{key:S}}, {{key:E}}, {{key:T}} |
| {{key:O}} 궤도 회전, {{key:H}} 초점 이동, {{key:Z}} 줌, {{key:Shift+Z}} 범위 줌 | 같음: {{key:O}}, {{key:H}}, {{key:Z}}, {{key:Shift+Z}} |
| {{key:G}}로 구성요소 만들기 | 같음: {{key:G}}. {{key:Shift+G}}는 그룹을 만듭니다 |
| 측정 상자를 클릭하지 않고 입력 | 같음. 아래의 값 상자에 입력하고 {{key:Enter}}를 누릅니다 |
| 사각형은 `4m,3m`, 변은 `12s`로 입력 | 같음 |
| 이동 복사 뒤에 `3x` 또는 `/3` 입력 | 같음. `*3`도 동작합니다 |
| 점이나 오프셋에 `[x,y,z]` 또는 `<dx,dy,dz>` 입력 | 같음 |
| 인치 모델에서 숫자만 입력하면 인치 | 같음 |
| 가운데 버튼 드래그로 궤도 회전, Shift+가운데 버튼 드래그로 초점 이동, 휠로 커서 위치에서 줌 | 같음 |
| 밀기/당기기에서 두 번 클릭하면 거리 반복 | 같음 |
| 화살표 키로 빨강, 녹색, 파랑 고정, 평행 | 같음: {{key:Right}} 빨강, {{key:Left}} 녹색, {{key:Up}} 파랑, {{key:Down}} 평행 |
| Shift를 누르고 있으면 추론 고정 | 같음 |
| Ctrl(Mac에서는 Option)으로 이동하며 복사 | {{key:Ctrl}}, {{key:Mod}} 또는 {{key:Alt}}, 어떤 컴퓨터에서든 |
| Shift로 전환, Ctrl로 추가, Shift+Ctrl로 선택에서 제거 | 같은 키. Mac에서는 Ctrl이라고 된 곳에 {{key:Mod}}를 사용합니다 |
| 왼쪽에서 오른쪽은 윈도우, 오른쪽에서 왼쪽은 걸침 | 같음 |
| 길이를 표시하는 치수 도구 | {{key:D}}, 그리고 더: 치수에 새 길이를 입력하면 모델이 그 크기에 맞게 바뀝니다. [치수와 크기 변경](topic:dimensions) 참조 |
| 면을 두 번 클릭하면 면과 모서리, 세 번 클릭하면 연결된 전부 | 같음 |
| 그룹을 두 번 클릭해 편집, Esc로 닫기 | 같음 |
| 면을 가로지르는 선으로 면 나누기, 같은 평면의 면 사이 모서리를 지워 합치기 | 같음 |
| 창 사각형을 벽을 통과하게 밀어 벽 자르기 | 같음 |
| 뒷면은 청회색, 면 뒤집기 | 같은 색. {{ui:객체 정보}}의 {{ui:면 뒤집기}} |
| 뷰 위의 탭으로 장면, Page Up과 Page Down | 같음. {{ui:장면}} 패널의 {{ui:재생}} |
| 날짜, 시간, 위도, 경도에 따른 그림자, 북쪽은 녹색 | 같음. {{ui:스타일}} 패널에서 |

## 사람들이 헷갈리는 차이점

### 저장은 다운로드입니다

열었던 파일을 덮어쓰는 저장, 이름을 정하는 다른 이름으로 저장 대화상자, 자동 저장, 백업 파일은 모두 없습니다. {{ui:저장}}은 {{key:Mod+S}}를 누를 때마다 새 `.modelcraft` 파일을 다운로드합니다. 보통 다운로드 폴더에 저장됩니다. 자주 저장하고, 파일 이름은 직접 바꾸거나 옮기세요. [파일 열기, 저장, 가져오기와 내보내기](topic:files) 참조.

### .skp 파일은 가져오지만 저장하지 않습니다

{{ui:가져오기}}는 SketchUp 파일을 ModelCraft 자체 읽기 기능으로 브라우저 안에서 읽습니다. 그룹, 구성요소, 색, 면의 질감, 태그, 부드러운 모서리가 넘어옵니다. 자세히는 [파일 형식 상세](topic:formats#skp-files)를 보세요. ModelCraft는 `.skp`로 저장할 수 없습니다. 되돌아가려면 ModelCraft에서 Collada로 내보낸 뒤 SketchUp에서 가져오세요.

### 우클릭 메뉴가 없습니다

오른쪽 버튼 드래그는 초점을 이동하고, 오른쪽 클릭은 아무 일도 하지 않습니다. 컨텍스트 메뉴에서 찾을 명령은 {{ui:객체 정보}}({{ui:면 뒤집기}}, {{ui:편집}}, {{ui:분해}}, {{ui:고유하게 만들기}}, {{ui:구성요소 만들기}})와 도구 모음의 {{ui:정리}} 그룹에 있습니다.

### 단위는 상태 표시줄에 있습니다

모델 정보나 템플릿 선택은 없습니다. 단위 선택기는 오른쪽 아래에 있습니다. 새 모델은 브라우저 언어 설정에 따라 미국에서는 피트·인치, 그 밖에서는 밀리미터로 시작합니다. 소수점은 항상 마침표로 씁니다: `2.5m`이며 `2,5m`는 안 됩니다. 쉼표는 항상 값을 나누는 데 쓰이기 때문입니다.

### 페인트에는 자체 재질이 있습니다

{{ui:페인트}}({{key:B}})는 단색과 {{ui:재질}} 섹션의 재질을 칠합니다: 벽돌, 사이딩, 지붕재, 목재, 석재 등이며 ModelCraft가 직접 그립니다. 아직 자신의 이미지를 재질로 불러올 수는 없습니다. 가져온 파일에 들어 있던 질감은 유지됩니다. [색과 재질로 칠하기](topic:paint) 참조.

### 축척은 균일하며 그립이 없습니다

축척은 그립이 있는 상자를 보여 주지 않습니다. 그대로 두는 점(기준점)을 클릭한 다음 새 크기나 입력한 배율을 지정합니다. 항상 모든 방향에서 고르게 축척됩니다. 한 방향으로 늘리려면 밀기/당기기나 면 이동을 하거나, {{ui:객체 정보}}에서 그룹의 너비, 깊이, 높이를 다시 입력하거나, [치수로 크기 바꾸기](topic:dimensions)를 하세요.

### 회전은 클릭한 곳에서 평면을 고릅니다

화살표 키로 평면을 고르려고 면 위에 올려놓을 때 면에 붙는 각도기는 없습니다. 면 위에서 중심을 클릭하면 그 면의 평면 안에서 돌고, 지면을 클릭하면 수직축을 중심으로 돕니다. 화살표 키는 첫 클릭 전에 뷰를 궤도 회전합니다.

### 지나간 점에서 추론

ModelCraft는 **시작점**에서 축 방향으로 스냅하고, 포인터 아래의 점, 모서리, 면에도 스냅합니다. 그저 지나친 점에서 방향을 추적하지는 않습니다(점선 기준점 추론). 먼 모서리와 정렬하려면 화살표 키로 축을 고정하고 그 모서리 위에 포인터를 올리세요. 잠긴 점이 그 점에 맞춰 미끄러집니다. 또는 [안내선](topic:guides-measure)을 놓으세요.

### 평행은 시작 전에 지나친 모서리를 사용합니다

평행과 수직 추론은 **첫 클릭 전에** 포인터가 마지막으로 지나간 모서리를 사용하며, 그리는 중에 지나친 모서리는 사용하지 않습니다. [추론과 스냅](topic:inference#parallel-and-perpendicular) 참조.

### 그룹의 복사본은 연결됩니다

{{ui:이동}}으로 그룹을 복사하면 같은 그룹의 두 번째 배치가 만들어지므로, 하나를 편집하면 둘 다 바뀝니다. 구성요소와 같습니다. SketchUp에서는 그룹이 독립적입니다. [문제 해결](topic:troubleshooting#editing-one-group-changed-another) 참조.

### 스페이스는 초점을 이동하지 않습니다

{{key:Space}}는 SketchUp에서처럼 {{ui:선택}}을 고릅니다. 다른 웹 앱에서는 스페이스를 누른 채 초점을 이동하기도 하지만, 여기서는 그렇지 않습니다. 대신 오른쪽 버튼 드래그로 초점을 이동하세요.

### 두 손가락 스크롤은 줌입니다

트랙패드에서 {{ui:설정}} › {{ui:ModelCraft}} › 스크롤을 트랙패드로 설정하세요. 두 손가락은 궤도 회전, {{key:Shift}} 키를 누른 채 두 손가락은 초점 이동, 핀치는 줌입니다. [궤도 회전, 초점 이동, 줌](topic:orbit-pan-zoom#on-a-trackpad) 참조.

Blender 키에 익숙하다면 {{ui:모델러}} 메뉴 스타일을 고르세요. {{key:G}}, {{key:R}}, {{key:S}}는 선택 전체에 한꺼번에 작용하고, {{key:E}}는 돌출(밀기/당기기)을 하며, {{key:Shift+D}}는 복제합니다. 도구 모음 대신 상단 메뉴 막대(파일, 편집, 보기, 선택, 추가, 객체, 메시)가 나타납니다. SketchUp에서 왔다면 {{ui:밀기/당기기}} 스타일이 같은 도구 문자 위에 자신만의 메뉴 막대를 보여 줍니다. [메뉴, 키와 마우스](topic:menus-keys-and-mouse) 참조.

### 서로 밀어 넣은 솔리드는 잘리지 않습니다

밀기/당기기는 같은 객체 안에서 뒤의 면을 뚫고 지나가지만, 서로 밀어 넣은 두 개의 분리된 솔리드는 교차하지 않습니다. 면 교차와 솔리드 도구는 없습니다.

### 빠진 기능

프리핸드, 자르기, 나누기, 외부 쉘, 자신의 이미지 재질, 확장 기능, 시트용 배치 도구는 이 빌드에 없습니다. [아직 만들지 않은 기능](topic:not-built-yet)에서 대신 할 일을 알 수 있습니다.

## 브라우저가 차지하는 단축키

ModelCraft는 브라우저에서 실행되므로 몇몇 단축키는 앱이 아니라 브라우저의 것입니다. {{key:Mod+N}}은 브라우저 창을 열며({{ui:새로 만들기}}를 사용하세요), {{key:Mod+W}}는 탭을 닫습니다. 저장되지 않은 변경 사항이 있으면 브라우저가 닫기 전에 묻습니다. [키, 마우스와 트랙패드](common:keys#shortcuts-the-browser-keeps) 참조.
