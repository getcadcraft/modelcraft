## 앱 바

맨 위의 얇은 막대는 모든 CadCraft 앱에 공통입니다. 앱 이름과 버전, {{ui:ModelCraft 정보}}, 화면 모드 버튼, {{ui:종이}} / {{ui:모델}} 스위치가 있습니다.

- {{ui:종이}}: 밝은 테마, {{ui:모델}}: 어두운 테마입니다. 3D 뷰의 색이 그에 맞게 바뀌며, 모델은 변하지 않습니다.
- 화면 모드 버튼(처음에는 {{ui:전체 화면}} 문구로 표시됨) 및 {{key:Ctrl+Shift+F}} 키는 세 가지 모드를 순서대로 전환합니다: 일반, 전체 화면, 막대를 숨긴 전체 화면. 막대가 숨겨져 있을 때는 화면 위쪽 가장자리에 포인터를 대거나 그곳을 탭하면 다시 나타납니다. {{key:Esc}} 키를 누르면 전체 화면이 해제됩니다.

:::note
{{key:Ctrl+Shift+F}} 키는 Mac을 포함한 모든 컴퓨터에서 Control 키를 사용합니다. 브라우저에 전체 화면이 없는 iPhone에서는 버튼이 막대를 숨기고 표시하는 기능만 합니다.
:::

## 도구 모음

도구 모음은 이름이 붙은 그룹으로 나뉩니다. 버튼에 포인터를 올리면 이름과 키가 표시됩니다.

왼쪽 끝의 {{ui:작업 공간}} 목록은 도구 모음과 오른쪽 패널의 용도를 전환합니다: {{ui:모델}}(밀기/당기기 모델링, 아래 둘러보기), {{ui:메시}}([메시 편집](topic:mesh-edit)), {{ui:곡선}}([곡선 객체](topic:curves)), {{ui:UV}}([UV 배치](topic:uv)), {{ui:지형 조각}}([조각](topic:sculpt)), {{ui:셰이딩}}([노드로 만드는 재질](topic:shading)), {{ui:애니메이션}}([애니메이션](topic:animate)), {{ui:렌더}}([뷰에서 렌더](topic:render#render-in-the-view))입니다.

| 그룹 | 버튼 |
|---|---|
| 파일 | {{ui:새로 만들기}}, {{ui:열기}}, {{ui:저장}}, {{ui:가져오기}}, {{ui:내보내기}} (형식 메뉴) |
| 그리기 | {{ui:선}} ({{key:L}}), {{ui:사각형}} ({{key:R}}), {{ui:원}} ({{key:C}}), {{ui:폴리곤}} ({{key:N}}) |
| 수정 | {{ui:선택}} ({{key:Space}}), {{ui:밀기/당기기}} ({{key:P}}), {{ui:이동}} ({{key:M}}), {{ui:회전}} ({{key:Q}}), {{ui:축척}} ({{key:S}}), {{ui:지우개}} ({{key:E}}), {{ui:줄자}} ({{key:T}}) |
| 정리 | {{ui:구성요소}} ({{key:G}}), {{ui:그룹}} ({{key:Shift+G}}), {{ui:분해}} |
| 편집 | {{ui:실행 취소}} ({{key:Mod+Z}}), {{ui:다시 실행}} ({{key:Mod+Y}}), {{ui:복사}} ({{key:Mod+C}}), {{ui:붙여넣기}} ({{key:Mod+V}}), {{ui:더보기}} (메뉴: 잘라내기, 복사, 붙여넣기, 제자리에 붙여넣기 {{key:Mod+Shift+V}}, 복제 {{key:Mod+D}}, 삭제, 모두 선택, 선택 해제, 키 스타일) |
| 카메라 | {{ui:궤도 회전}} ({{key:O}}), {{ui:초점 이동}} ({{key:H}}), {{ui:줌}} ({{key:Z}}), {{ui:범위}} ({{key:Shift+Z}}), {{ui:뷰}} (메뉴) |

표시된 키는 밀기/당기기 스타일의 키이며, [ModelCraft 설정](topic:settings)에서 모델러 스타일을 고르면 툴팁에 그 키가 표시됩니다. 사용 중인 도구는 눌린 상태로 표시됩니다. 화면이 좁으면 도구 모음이 옆으로 스크롤됩니다.

{{ui:뷰}} 메뉴에는 모델에 맞춰 보여 주는 {{ui:등각}}, {{ui:위}}, {{ui:앞}}, {{ui:오른쪽}}, {{ui:뒤}}, {{ui:왼쪽}}, {{ui:아래}} 항목이 있으며, 원근 투영과 평행 투영을 전환하는 {{ui:원근}}도 있습니다.

## 3D 뷰

화면 가운데입니다. 빨강, 초록, 파랑 선이 축입니다: 빨강과 초록은 바닥에 놓이고, 파랑은 위를 향하며, **북쪽은 초록 축**입니다. 세 축이 만나는 곳이 원점입니다.

- 시작하면 "모델링 시작" 카드에 처음 쓸 키 몇 개가 나열됩니다. 그리기 도구를 고르거나 뷰를 클릭하면 사라집니다.
- 도구가 작동하는 동안 뷰에는 **추정 표식**이 나타납니다. 포인터가 스냅되는 곳에 표시되는 작은 색 도형입니다(끝점의 초록 원, 중간점의 청록 원, 모서리 위의 빨간 사각형, 면 위의 파란 마름모). [추정과 스냅](topic:inference)을 참조하십시오.
- 선택된 대상은 파랗게 바뀝니다. 뒤에서 본 면은 청회색입니다.
- 그룹을 열어 편집하면 그 바깥은 모두 흐려지고, 축은 그룹 자체의 축으로 옮겨 갑니다.
- 모델에 장면이 있으면 뷰 위쪽에 장면 탭 줄이 나타납니다.
- 파일을 뷰 아무 곳에나 끌어다 놓으면 열거나 가져옵니다.

## 왼쪽 패널

**{{ui:개요}}** 패널은 모델에 들어 있는 그룹과 구성요소를 모델에서 중첩된 방식 그대로 나열합니다. 두 번 이상 사용된 구성요소는 "창 (4)"처럼 사용 횟수가 표시됩니다.

- 이름을 클릭하면 선택됩니다. 더블 클릭하면 편집을 위해 엽니다.
- **이름으로 찾기**(그룹이 둘 이상이 되면 표시됨)는 이름이 일치하는 행과 그것이 속한 그룹만 남깁니다. {{key:Esc}} 키로 해제합니다.
- 행 끝의 **눈** 아이콘은 그 그룹 또는 구성요소를 숨기거나 표시합니다({{ui:편집}} › {{ui:더보기}} › {{ui:숨기기}} 명령과 같은 동작). 태그 아이콘은 [태그](topic:tags)에 의해 숨겨졌다는 뜻입니다.
- **제자리에서 이름 바꾸기:** 행을 클릭하고 {{key:F2}} 키를 누른 다음 입력하고 {{key:Enter}} 키를 누릅니다({{key:Esc}} 키는 이전 이름을 유지함).
- **행 끌기:** 다른 그룹 행의 가운데로 끌면 그 그룹 안으로 이동하고, 행의 위쪽 또는 아래쪽 가장자리로 끌면 그 행의 바로 앞 또는 뒤에 놓이며, {{ui:개요}} 제목으로 끌면 최상위로 이동합니다. 모델 안의 위치는 그대로 유지되고 색, 태그, 이름도 유지됩니다. 그룹은 자기 자신 안으로 들어갈 수 없습니다. 각 이동은 실행 취소 한 단계입니다. [개요에서 재배열](topic:groups-components#rearrange-in-the-outliner)을 참조하십시오.
- 그룹 안에서 편집하는 동안 "편집 중: 모델 › …" 줄이 표시되고 {{ui:그룹 닫기}} 버튼이 나타납니다. 이 버튼은 열려 있는 모든 단계를 한꺼번에 닫습니다.

**{{ui:구성요소}}** 패널은 모든 구성요소 정의를 배치된 사본 수("3×")와 함께 나열하며, {{ui:배치}} 버튼은 클릭한 위치에 사본을 하나 더 추가합니다.

## 오른쪽 패널

**{{ui:객체 정보}}** 패널은 선택한 대상을 설명합니다. 제목이 대상에 따라 바뀝니다.

| 제목 | 표시 내용 | 버튼 |
|---|---|---|
| 모델(선택 항목 없음) | 면, 모서리, 그룹, 구성요소와 배치된 수, 안내선, 전체 크기 | {{ui:안내선 모두 삭제}} (안내선이 있을 때) |
| 면 | 면적, 구멍 수 | {{ui:면 뒤집기}} |
| 모서리 | 길이 | 없음 |
| 그룹 또는 구성요소 | 이름(입력해서 바꿈), 배치된 횟수, 닫힌 솔리드인지 여부, 부피, 크기 | {{ui:편집}}, {{ui:분해}}, {{ui:고유하게 만들기}} (두 번 이상 배치된 구성요소), {{ui:구성요소 만들기}} (그룹) |
| 안내점 또는 안내선 | 없음 | {{ui:삭제}} |
| 여러 대상 | 면, 모서리, 그룹, 안내선의 수와 면의 총면적 | {{ui:구성요소 만들기 (G)}}, {{ui:그룹 만들기 (Shift+G)}} |

**{{ui:스타일}}** 패널은 모델이 그려지는 방식을 정합니다: {{ui:면}} ({{ui:음영}}, {{ui:은선}}, {{ui:와이어프레임}}, {{ui:엑스레이}}), {{ui:모서리 표시}}, 그리고 태양의 날짜, 시간, 장소를 지정하는 {{ui:태양 그림자}} 설정이 있습니다. [스타일과 태양 그림자](topic:styles-shadows)를 참조하십시오.

**{{ui:장면}}** 패널은 뷰를 저장합니다: {{ui:장면 추가}}, 장면 목록, {{ui:이전}}, {{ui:재생}}, {{ui:다음}}. [뷰를 장면으로 저장](topic:scenes)을 참조하십시오.

## 상태 표시줄

아래쪽에 왼쪽부터 오른쪽으로 다음이 있습니다.

1. **팁**: 도구가 다음에 필요로 하는 것, 또는 포인터가 스냅되는 대상("끝점", "빨강 축 위").
2. **메시지**: 방금 일어난 일("밀기/당기기를 실행 취소했습니다.", "site.dxf 가져옴: 그룹 안, 지면의 모서리 1697개.") 또는 작업이 되지 않은 이유.
3. **값 입력란**: 라벨이 도구에 따라 바뀝니다({{ui:길이}}, {{ui:치수}}, {{ui:반지름}}, {{ui:변}}, {{ui:거리}}, {{ui:각도}}, {{ui:축척}}, {{ui:간격 띄우기}}). 작업 중에는 실시간 크기를 표시하고 입력한 값을 받습니다. [값 입력란에 정확한 크기 입력](topic:value-box)을 참조하십시오.
4. **키 스타일**: {{ui:키: 밀기/당기기}} 또는 {{ui:키: 모델러}} 버튼은 키보드 단축키와 마우스 버튼을 한꺼번에 전환합니다([ModelCraft 설정](topic:settings)과 동일함).
5. **{{ui:스냅}} 및 {{ui:충돌}}**: 점, 모서리, 축에 스냅, 그리고 솔리드가 닿는 곳에서 멈추기. 취소선 = 꺼짐. 클릭하면 전환됩니다. [ModelCraft 설정](topic:settings)을 참조하십시오.
6. **단위 선택기**: 길이가 표시되는 단위. [시작하기](topic:getting-started#check-the-units-first)를 참조하십시오.

## 좁은 화면에서

너비가 약 760픽셀 미만이면(휴대폰 또는 좁은 창) 3D 뷰가 화면을 차지합니다. 도구 모음은 옆으로 스크롤되는 한 줄이 되고, 패널은 화면 아래쪽 막대에서 시트로 열립니다.
