**메시** 작업 공간에서는 [메시](topic:meshes)를 꼭짓점, 모서리, 면 단위로 편집합니다. 밀기/당기기 지오메트리는 **모델** 작업 공간에서 편집합니다.

## 열기

- {{ui:Workspace}} 목록(도구 모음 왼쪽)에서 {{ui:Mesh}}를 선택하십시오. 선택한 메시가 편집을 위해 열립니다. 선택한 그룹이나 구성 요소는 먼저 메시로 바뀝니다(실행 취소 한 단계).
- 메시를 두 번 클릭하거나, 모델러 키를 쓰는 경우 메시를 선택한 다음 {{key:Tab}} 키를 누르십시오.
- 선택이 없으면 패널에 추가할 메시가 나타납니다: 평면, 격자, 정육면체, 원, 원기둥, 원뿔, 구, 아이코 구, 토러스. 새 메시는 보고 있는 곳에 놓이며 편집을 위해 열립니다.

{{ui:Back to Model}} 명령(또는 목록, 모델러 키에서는 {{key:Tab}} 키, 밀기/당기기 키에서 선택이 없을 때는 {{key:Esc}} 키)을 쓰면 선택된 메시와 함께 모델로 돌아갑니다. 메시 작업 공간이 열려 있는 동안 나머지 모델은 흐리게 표시되고, 모델의 그리기 도구는 치워집니다.

## 선택

| 작업 | 대상 |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | 꼭짓점, 모서리 또는 면을 선택 |
| 클릭 | 하나를 선택. {{key:Shift}}+클릭은 추가하거나 제거 |
| 상자 드래그 | 안에 있고 보이는 것을 선택. {{key:Shift}}는 추가, {{key:Ctrl}}은 제거 |
| {{key:Alt}}+모서리 클릭, 또는 모서리 두 번 클릭 | 그 모서리의 루프(면 모드에서는 면 루프, 열린 가장자리에서는 테두리 전체) |
| {{key:Ctrl}}+{{key:Alt}}+모서리 클릭 | 그 모서리의 링 |
| 세 번 클릭 | 그와 연결된 모든 것 |

{{ui:Select}} 그룹에는 {{ui:All}}, {{ui:Linked}}, {{ui:Loop}}, {{ui:Ring}}, {{ui:More}}, {{ui:Less}}도 있습니다.

## 이동, 회전, 축척

{{ui:Move}}, {{ui:Rotate}}, {{ui:Scale}} 명령은 포인터에서 시작합니다. 이동한 다음 클릭하거나 {{key:Enter}} 키를 눌러 선택을 놓고, {{key:Esc}} 키를 누르면 취소합니다. {{key:X}}, {{key:Y}}, {{key:Z}} 키(또는 방향키)는 축을 고정합니다. 정확한 값을 원하면 거리, 각도 또는 배율을 입력하십시오. [계산](topic:value-box#calculations)도 사용할 수 있습니다.

**비례 편집**({{ui:Proportional}}, 또는 패널): 선택 근처의 꼭짓점은 이동을 따라 움직이며, 멀수록 덜 움직입니다. 설정한 범위까지, 선택한 감쇠 방식에 따릅니다. {{ui:Only along the mesh}} 옵션을 켜면 직선이 아니라 모서리를 따라 거리를 잽니다.

{{ui:Slide}} 명령은 선택한 모서리 루프를 옆의 모서리를 따라 이동합니다.

## 모양 바꾸기

| 도구 | 기능 |
|---|---|
| {{ui:Extrude}} | 선택한 면을 법선 방향으로 당겨 내고 새 측면을 만듭니다(또는 열린 테두리 모서리로 면을 만듭니다). 거리를 입력하십시오 |
| {{ui:Inset}} | 선택한 면 외곽선 안쪽의 띠를 만듭니다. 면마다 따로 하려면 {{key:I}} 키를 다시 누르십시오 |
| {{ui:Bevel}} | 선택한 모서리(또는 {{key:Ctrl}}+{{key:Shift}}+{{key:B}}로 꼭짓점)를 지정한 폭으로 자릅니다. 휠이나 + 및 - 키로 둥근 모서리의 분할 수를 추가하십시오 |
| {{ui:Loop cut}} | 모서리를 가리키면 네 변 면의 링을 가로지르는 새 루프가 생깁니다. 휠로 개수를 정하고 클릭하여 자르십시오 |
| {{ui:Knife}} | 모서리나 꼭짓점에서 점을 클릭하십시오. {{key:Enter}} 키는 그 사이의 면들을 화면에서 보이는 그대로 직선으로 자릅니다 |
| {{ui:Bisect}} | 화면에 선을 그리면, 선택한 면(또는 전체)이 그 선을 따라 잘립니다 |
| {{ui:Spin}} | 선택한 면이나 열린 모서리를 파란 축을 중심으로 단계별로 돌립니다(휠로 단계 설정). 한 바퀴를 돌면 닫힙니다 |
| {{ui:Subdivide}} | 선택한 모서리를 둘로 나눕니다. 면 전체는 격자가 됩니다 |
| {{ui:Merge}} | 선택한 꼭짓점들을 중심에서 하나로 합칩니다 |
| {{ui:Dissolve}} | 선택을 빼내지만 표면은 유지합니다. 면들이 합쳐집니다 |
| {{ui:Fill}} | 선택한 열린 테두리(또는 두 열린 모서리 사이)에 면을 채웁니다 |
| {{ui:Grid fill}} | 짝수 개의 모서리로 된 열린 테두리를 사각형 격자로 채웁니다 |
| {{ui:Bridge}} | 선택한 두 열린 모서리 루프를 면으로 잇습니다 |
| {{ui:Crease}} | 메시가 세분화 곡면으로 매끄러워질 때 선택한 모서리가 얼마나 날카롭게 남는지 정합니다. 중심에서 멀리 밀거나, 휠(0.1 단위)을 쓰거나, 0~1 값을 입력하십시오. 패널은 선택한 모서리의 주름 값을 보여 주며 입력도 받습니다. 주름 모서리는 자홍색으로 그려집니다 |
| {{ui:Flip}}, {{ui:Smooth}}, {{ui:Delete}} | 면을 뒤집고, 꼭짓점을 이웃 쪽으로 매끄럽게 하고, 선택 모드에 따라 삭제합니다 |

각 작업은 실행 취소 한 단계입니다. 텍스처 좌표, 색상, 가중치는 새 면과 꼭짓점으로 따라갑니다.

## 리메시

{{ui:Remesh}}는 전체 메시를 같은 크기의 고른 삼각형으로 다시 만듭니다. 누를 때 요청한 크기로 생성되며, 작을수록 세밀하지만 느립니다. 구멍을 막고, 겹치는 조각을 잇고, 스컬프트로 늘어난 메시를 고릅니다. 날카로운 모서리는 아주 약간 둥글어집니다. UV, 칠, 주름은 새로 시작합니다. 실행 취소 한 단계입니다.

## 리토폴로지

세밀한 메시(스컬프트나 스캔) 위에 더 깔끔한 새 메시를 만들려면, 패널의 {{ui:Retopology}} › **기반**에서 세밀한 메시를 고른 다음 다음 기능을 사용하십시오.

- **이동한 점을 표면에 붙이기:** 이동하는 점과 압출하는 모서리가 그 표면에 놓입니다.
- **선택한 점을 표면에 놓기:** 선택한 점을 지금 표면 위로 옮깁니다(실행 취소 한 단계).
- **이 메시의 모서리를 앞에 표시:** 만들고 있는 메시를 표면 위에 그려 보이게 합니다.

## 마지막 작업 조정

{{ui:Inset}}, {{ui:Bevel}}, {{ui:Loop cut}}, {{ui:Subdivide}}, {{ui:Smooth}}, {{ui:Grid fill}} 또는 {{ui:Spin}} 다음에는 패널에 설정(폭, 분할 수, 프로파일, 자르기 수 등)이 표시됩니다. 설정을 바꾸면 작업을 처음부터 다시 수행하며, 여전히 실행 취소 한 단계입니다.
