{{ui:Select}} ({{key:Space}})은 ModelCraft가 처음 여는 도구이며, {{key:Esc}}를 누르면 다시 이 도구로 돌아옵니다. 선택된 항목은 파란색으로 바뀌고, 오른쪽의 {{ui:Entity info}}에 항목의 종류가 표시됩니다.

## 클릭

| 동작 | 선택 항목 |
|---|---|
| 면 또는 모서리를 클릭 | 해당 면 또는 모서리 |
| 그룹 또는 구성요소를 클릭 | 그룹 또는 구성요소 전체 |
| 면을 더블 클릭 | 면과 그 모서리 |
| 모서리를 더블 클릭 | 모서리와 양쪽에 있는 면 |
| 그룹 또는 구성요소를 더블 클릭 | 편집을 위해 엽니다 (참조: [그룹과 구성요소](topic:groups-components)) |
| 면 또는 모서리를 세 번 클릭 | 그것에 연결된 모든 항목: 객체 전체 |
| 빈 공간을 클릭 | 없음 (선택 해제) |
| 그룹을 편집하는 동안 빈 공간을 더블 클릭 | 그룹을 닫습니다 |

모서리는 면보다 클릭하기 쉽습니다. 포인터가 모서리에서 몇 픽셀 이내에 있으면 클릭이 모서리를 선택합니다.

## 상자 끌기

- **왼쪽에서 오른쪽**으로 끌면 실선 상자가 그려지며 **윈도우** 선택이 됩니다. 상자 안에 완전히 들어간 항목만 선택됩니다.
- **오른쪽에서 왼쪽**으로 끌면 점선 상자가 그려지며 **걸침** 선택이 됩니다. 상자가 닿은 모든 항목이 선택되며, 상자가 면 안에 완전히 들어가 있으면 그 면이 선택됩니다.

그룹이나 구성요소는 하나의 항목으로 취급됩니다. 윈도우는 전체를 포함해야 하고, 걸침은 닿기만 하면 됩니다.

## 추가와 제거

클릭하거나 끌 때 키를 누릅니다:

| 키 | 효과 |
|---|---|
| {{key:Shift}} | 전환: 선택되지 않은 항목은 추가하고, 선택된 항목은 제거합니다 |
| {{key:Mod}} | 추가합니다 |
| {{key:Shift}} + {{key:Mod}} 함께 | 제거합니다 |

모델의 모든 항목(또는 편집 중인 그룹의 모든 항목)을 선택하려면 {{key:Mod+A}} 키를 누릅니다.

## 선택 해제

{{ui:Select}} 도구 상태에서 {{key:Esc}} 키를 누르거나 빈 공간을 클릭합니다.

## 선택한 항목 삭제

{{key:Delete}} 키 또는 {{key:Backspace}} 키를 누릅니다. 선택한 면, 모서리, 그룹, 안내선은 한 번에 제거되며, {{key:Mod+Z}} 키로 되돌릴 수 있습니다.

모서리를 삭제하면 그 모서리가 필요한 면도 함께 제거됩니다. 다만 모서리가 같은 평면에 있는 두 면만 나누고 있었다면 두 면이 하나로 합쳐집니다. 면을 삭제하면 모서리는 남습니다. [지우기와 정리](topic:erase)를 참조하십시오.

## 그룹 안에서 선택

그룹을 클릭하면 그룹 전체가 선택됩니다. 그 안의 면을 선택하려면 그룹을 더블 클릭해 열고 클릭하십시오. 그룹이 열려 있는 동안에는 클릭이 그 안의 항목에만 닿고, 나머지는 흐리게 표시됩니다. 아무것도 선택하지 않은 상태에서 {{key:Esc}} 키를 누르거나 빈 공간을 더블 클릭하면 그룹이 닫힙니다.

왼쪽의 {{ui:Outliner}}에서는 이름으로 그룹과 구성요소를 선택할 수 있습니다. 다른 항목 뒤에 가려져 있을 때 유용합니다.
