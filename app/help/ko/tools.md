상태 표시줄의 팁에는 현재 도구가 다음에 원하는 것이 항상 표시됩니다. {{key:Esc}} 키는 도구가 진행 중인 작업을 취소합니다.

## 그리기 도구

| 도구 | 키 | 클릭 | 값 상자에 입력 |
|---|---|---|---|
| {{ui:Line}} | {{key:L}} | 시작점, 그다음 각 점. 면이 닫히거나 {{key:Esc}} 키를 누르면 멈춤 | 포인터 방향 길이. 점은 `[x,y,z]`, 간격은 `<dx,dy,dz>` ({{ui:Length}}) |
| {{ui:Rectangle}} | {{key:R}} | 첫 번째 모서리(지면 또는 면), 반대쪽 모서리 | 너비와 깊이: `4m,3m` ({{ui:Dimensions}}) |
| {{ui:Circle}} | {{key:C}} | 중심(지면 또는 면), 가장자리의 한 점 | 첫 클릭 전: 변의 수, `24s` 또는 `24` ({{ui:Sides}}). 이후: 반지름 ({{ui:Radius}}) |
| {{ui:Polygon}} | {{key:N}} | 중심, 모서리 | 원과 같음. 기본값은 변 6개입니다 |
| {{ui:Arc}} | {{key:A}} | 시작점, 끝점, 그다음 굽힘 | 시작 후 현의 길이 ({{ui:Length}}), 끝 후 굽힘 ({{ui:Bulge}}), 세그먼트는 `12s` |
| {{ui:Protractor}} | — | 중심, 0° 점, 그다음 각도 | 도 단위 각도 ({{ui:Angle}}) |
| {{ui:Follow me}} | — | 경로를 선택한 다음 면을 클릭(또는 면을 클릭한 다음 경로의 모서리를 클릭) | — |
| {{ui:Paint}} | {{key:B}} | 면, 그룹 또는 구성요소 | — ({{key:Ctrl}} 연결된 면, {{key:Shift}} 같은 색 전체, {{key:Alt}} 색 추출) |
| {{ui:Offset}} | {{key:F}} | 면(또는 먼저 면이나 모서리를 선택), 그다음 방향과 거리 | 거리 ({{ui:Distance}}). 면 안쪽으로 가면 안쪽 방향 |
| {{ui:Curve}} | — | 곡선이 지나는 점들. {{key:Enter}} 키 또는 더블 클릭으로 완료 | 포인터 방향 길이. 다음 점은 `[x,y,z]` 또는 `<dx,dy,dz>` |
| {{ui:Arc center}} | — | 중심, 시작점, 그다음 끝점 | 중심 다음 반지름, 시작 다음 도 단위 각도, 세그먼트는 `12s` |

## 편집 도구

| 도구 | 키 | 클릭 | 값 상자에 입력 |
|---|---|---|---|
| {{ui:Select}} | {{key:Space}} | 클릭, 더블 클릭, 세 번 클릭, 상자 드래그. [항목 선택](topic:select) 참조 | 치수나 모서리를 하나 선택한 상태에서 새 길이를 입력하면 모델 크기가 조정됨 |
| {{ui:Push/pull}} | {{key:P}} | 면, 그다음 거리. 면을 더블 클릭하면 마지막 거리를 반복 | 거리. 음수면 반대 방향 ({{ui:Distance}}) |
| {{ui:Move}} | {{key:M}} | 한 점에서 다른 점으로. {{key:Ctrl}} 또는 {{key:Alt}} 키를 누른 채 복사 | 포인터 방향 거리, `<dx,dy,dz>` 또는 `[x,y,z]` ({{ui:Distance}}). 복사 후: `3x` 또는 `/3` |
| {{ui:Rotate}} | {{key:Q}} | 중심(면에서 누르면 그 평면 안에서 회전), 시작 방향, 끝 방향 | 도 단위 각도 ({{ui:Angle}}) |
| {{ui:Scale}} | {{key:S}} | 고정점, 기준점, 새 크기 | 배율: `2`, `0.5` ({{ui:Scale}}) |
| {{ui:Eraser}} | {{key:E}} | 모서리, 그룹, 가이드, 치수 위를 클릭하거나 드래그 | 없음 |
| {{ui:Tape}} | {{key:T}} | 모서리에서: 평행 가이드 선. 점에서: 측정하고 가이드 점을 남김 | 간격 ({{ui:Offset}}) 또는 거리 ({{ui:Length}}) |
| {{ui:Dimension}} | {{key:D}} | 두 모서리(또는 모서리 하나), 그다음 치수선 위치. [치수와 크기 조정](topic:dimensions) 참조 | 간격 ({{ui:Offset}}). 직후에는 새 길이를 입력하면 모델 크기가 조정됨 |

{{ui:Move}}, {{ui:Rotate}}, {{ui:Scale}} 도구는 선택 항목에 작동합니다. 선택된 것이 없으면 먼저 클릭한 대상을 사용합니다(면을 클릭하면 그 모서리도 함께 가져옵니다).

## 카메라 도구

| 도구 | 키 | 드래그 기능 |
|---|---|---|
| {{ui:Orbit}} | {{key:O}} | 포인터 아래 모델 부분을 중심으로 회전({{key:Shift}} 키를 누르면 초점 이동) |
| {{ui:Pan}} | {{key:H}} | 화면 이동 |
| {{ui:Zoom}} | {{key:Z}} | 줌: 위로 드래그하면 확대, 아래로 드래그하면 축소 |
| {{ui:Extents}} | {{key:Shift+Z}} | (도구가 아니라 버튼) 모델 전체에 맞춤 |

마우스로는 이것들을 거의 쓸 필요가 없습니다. 가운데 버튼 드래그로 회전, 오른쪽 버튼 드래그로 초점 이동, 휠로 줌을 어떤 도구에서든 사용할 수 있습니다. [회전, 초점 이동, 줌](topic:orbit-pan-zoom) 참조.

## 정리

| 버튼 | 키 | 기능 |
|---|---|---|
| {{ui:Component}} | {{key:G}} | 선택 항목을 구성요소로 만듭니다 |
| {{ui:Group}} | {{key:Shift+G}} | 선택 항목을 그룹으로 만듭니다 |
| {{ui:Explode}} | 없음 | 선택한 그룹과 구성요소를 다시 개별 형상으로 되돌립니다 |

## 구성요소 배치

도구 모음에는 없습니다. {{ui:Components}} 패널에서 구성요소 옆의 {{ui:Place}} 버튼을 클릭하십시오. 구성요소의 원점이 놓일 위치를 한 번 클릭하면, 그 뒤에는 {{ui:Select}} 도구가 다시 활성화됩니다.
