모델링은 원래 쓰던 프로그램에서 계속하고, 그 결과는 여기에서 사용하십시오. 렌더링하거나, 조명을 설정하거나, 장면을 구성할 때 쓸 수 있습니다. 다른 프로그램에서 바꿀 때마다 ModelCraft의 그룹 하나가 업데이트됩니다.

:::note
이 연결에는 같은 컴퓨터의 **CadCraft Studio**가 필요합니다. 브라우저 탭으로는 연결할 수 없습니다. 인터넷으로는 아무것도 전송되지 않습니다. 스크립트는 이 컴퓨터의 고유 주소로 토큰과 함께 Studio와 통신합니다.
:::

:::warning
이 연결은 스크립트의 파일 작성기와, 다른 프로그램을 대신하는 모의 프로그램으로 테스트되었습니다. Rhino나 Grasshopper 안에서는 아직 테스트되지 않았습니다. 그곳에서 문제가 생기면 표시된 메시지를 알려 주십시오.
:::

## 설정하기

1. Studio에서 ModelCraft를 여십시오. {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}}에서 **AI 어시스턴트와 스크립트가 ModelCraft를 사용하도록 허용**을 선택한 뒤 **편집**을 누르십시오.
2. Studio에서 {{ui:Connect an assistant}} 명령을 선택하십시오. 아래에 붙여넣을 주소와 토큰이 표시됩니다.
3. 스크립트를 내려받으십시오: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino에서

1. Rhino의 스크립트 편집기에서 `cadcraft_link.py`를 실행하십시오(Rhino 8의 Python 3).
2. 처음 실행할 때 주소와 토큰을 붙여넣으십시오. 이 값은 홈 폴더의 `.cadcraft-link.json`에 저장되며, 모델 안에는 저장되지 않습니다. Studio는 시작할 때마다 새 토큰을 만들므로, 그때마다 스크립트가 다시 묻습니다.

전체 모델이 문서 이름을 딴 하나의 그룹으로 가져와집니다. 예: "chair (linked)". 그 뒤에는 다른 프로그램에서 변경하고 잠시 멈출 때마다 변경 사항이 가져와지며, 바뀐 객체만 전송됩니다. 연결을 멈추려면 스크립트를 다시 실행하십시오.

## Grasshopper에서

연결 주소와 토큰이 저장되도록 먼저 Rhino에서 스크립트를 한 번 실행하십시오.

1. Script 구성 요소(Python 3)를 추가하고 `cadcraft_link.py` 전체를 붙여넣으십시오.
2. 다음 입력을 지정하십시오: `G`(지오메트리, 목록 액세스), `N`(이름, 선택 사항), `On`(부울 토글), `Target`(선택 사항: 두 앱이 모두 열려 있을 때 `model` 또는 `part`).
3. `On`을 true로 설정하십시오.

Grasshopper가 계산할 때마다 `G`를 보내고 이전에 보낸 내용을 대체하므로, 슬라이더를 끌면 여기의 그룹도 업데이트됩니다. 출력 `a`에는 어떤 일이 있었는지 표시됩니다. 구성 요소마다 자체 그룹이 있습니다.

## 그룹으로 할 수 있는 일

- **이동하고, 태그를 붙이고, 주변에 구성하십시오.** 그룹의 위치와 태그는 업데이트 후에도 유지되며, 그룹 옆에 있는 것도 그대로 유지됩니다.
- **그룹 안을 편집하지 마십시오.** 업데이트할 때마다 그룹 안의 내용이 교체됩니다. 그 객체들은 다른 프로그램이 관리합니다.
- **실행 취소.** 2초 이내의 업데이트는 실행 취소 한 단계로 묶이므로, {{key:Mod+Z}} 키를 누르면 한 번의 드래그 전체가 되돌아갑니다. 다음 업데이트가 모델을 다시 맞춥니다.
- **저장.** 저장한 파일에도 연결이 유지됩니다. 파일을 다시 연 뒤 스크립트를 다시 실행하면 같은 그룹이 업데이트됩니다.

## 가져오는 항목

메시, 폴리서피스, 서피스, 익스트루전은 화면에 보이는 메시로, SubD는 해당 메시로, 곡선은 모서리로, 블록은 구성 요소가 아니라 있는 위치의 별도 객체로 가져옵니다. 레이어는 태그로, 색상과 단위도 함께 가져옵니다. 이 항목들이 여기에서 어떻게 보이는지는 [.3dm 모델 가져오기](topic:import-3dm-files)를 참조하십시오.

가져오지 않는 항목은 다른 프로그램에 개수와 함께 표시됩니다: 점, 텍스트, 치수, 조명 등.

**한 방향만 지원합니다.** ModelCraft에서 한 변경 사항은 다른 프로그램으로 되돌아가지 않습니다.

## 문제가 생겼을 때

- **"ModelCraft 또는 PartCraft 창이 이를 허용하지 않습니다":** 설정의 1단계를 수행하십시오.
- **"Studio가 토큰을 거부했습니다":** Studio가 다시 시작되었습니다. 새 토큰을 복사하고 스크립트를 다시 실행하십시오. Grasshopper의 경우 먼저 Rhino에서 실행하십시오.
- **"CadCraft Studio에 연결할 수 없습니다":** Studio가 실행 중이 아니거나 주소가 바뀌었습니다.
