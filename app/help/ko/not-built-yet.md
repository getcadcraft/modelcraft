ModelCraft는 초기 빌드입니다. 이 페이지는 아직 하지 않는 기능을 나열하여 찾아 헤매지 않도록 하고, 오늘 작업을 마칠 수 있는 가장 가까운 방법을 알려 줍니다.

## 그리기 도구

| 아직 아님 | 대신, 오늘은 |
|---|---|
| 자유형 그리기 | {{ui:Curve}} 도구로 점을 클릭하십시오. |
| 그린 뒤 호나 원의 분할 수 바꾸기 | `24s` 입력 후 지우고 다시 그리십시오. |
| [3D 텍스트](topic:text3d)의 글꼴 선택, 또는 배치한 뒤 문구 편집 | 삭제한 다음 텍스트를 다시 추가하십시오. |
| 각도 치수에 입력하여 각도 바꾸기, 또는 원의 치수로 원통 크기 바꾸기 | {{ui:Rotate}} 도구로 모서리를 회전하고, {{ui:Scale}} 도구로 원통의 크기를 조정하십시오. |
| 내보낸 모델 파일의 치수 | 치수는 보기의 이미지, 인쇄물, PDF에 나타납니다. 모델 파일에는 형상만 들어 있습니다. |
| 자르기, 분할, 외곽 쉘 | 닫힌 그룹에 [합집합, 차집합, 교집합](topic:solids)을 사용하거나, [면 교차](topic:intersect)한 뒤 필요 없는 부분을 지우십시오. |
| 화살표 키로 회전 축 선택 | 축이 향해야 할 방향을 향하는 면에서 {{ui:Rotate}} 중심을 클릭하십시오. |
| 한 번에 둘 이상의 추론에 잠금 | 화살표 키로 한 방향을 잠근 다음 점에 스냅하십시오. |
| 경사를 따라 크기 조정, 또는 모서리가 아닌 치수 끝에서 크기 조정 | 치수를 두 모서리에, 모서리를 따라, 또는 빨강, 초록, 파랑 방향을 따라 놓으십시오. |

## 애니메이션

| 아직 아님 | 대신, 오늘은 |
|---|---|
| 면, 모서리, 태양의 시간대, 스타일 또는 숨긴 항목 애니메이션 | 움직이는 부분을 그룹이나 구성요소로 만드십시오. 다른 시간대는 별도의 동영상으로 렌더링하십시오. |
| 그려진 경로를 따라가거나 움직이는 객체를 바라보는 카메라 | 중간에 카메라 키를 더 설정하십시오([애니메이션](topic:animation)). |
| 동영상의 소리, 그리고 WebGPU 없이 고품질(경로 추적) 동영상 | 동영상 편집기에서 소리를 추가하십시오. WebGPU가 없으면 빠른 렌더러로 동영상을 렌더링하십시오([동영상 렌더링](topic:animation#render-the-video)). |
| 렌더링된 동영상의 애니메이션 램프(밝기, 퍼짐, 색상), 카메라 키 없이 동영상의 렌즈 각도 애니메이션, 재질 또는 렌더 설정의 애니메이션 | 램프는 보기에서 애니메이션됩니다. 동영상에서 줌하려면 카메라도 키로 설정하십시오. 램프 설정이 다르면 별도의 동영상을 렌더링하십시오([모든 속성 애니메이션](topic:animate)). |
| 한쪽에서 다른 쪽으로 가중치나 뼈 대칭, 보이는 뼈 외피, 점별로 음영 처리된 가중치 표시(면별로 표시됨), 가중치를 칠하는 동안 포즈된 메시 보기 | 양쪽을 칠하거나, 한쪽 절반을 만든 뒤 아마추어를 추가하기 전에 대칭 모디파이어를 사용하십시오. 확인하려면 가중치 칠하기와 포즈 사이를 전환하십시오. |
| glTF, FBX 또는 USD 파일에서 아마추어로 읽은 뼈, 그리고 그 파일에 쓰인 아마추어 | 스킨 모델은 파일의 가중치를 가지고 휴지 상태로 들어옵니다. 파일의 관절 순서대로 뼈를 추가한 다음 {{ui:Use the file's weights}} 명령을 사용하십시오([애니메이션](topic:animate)). |
| 보기에서 끌어서 IK 대상이나 극점 이동, 제약 자체의 공간(로컬 또는 월드) 선택, IK 체인 늘이기, 곡선을 따른 IK | 대상의 점을 입력하거나, 객체를 겨냥해 그 객체를 이동하십시오. 체인은 원래 길이를 유지하십시오. |
| 천, 유체, 연체, 강체 사이의 관절과 힌지, 객체의 정확한 형상과의 충돌(상자와 구만 둘러쌀 수 있음), 재생 중 실시간 시뮬레이션, 시작 속도 또는 회전(물체는 정지 상태에서 시작) | 강체를 굽고 키를 재생하십시오. 키로 힌지를 만드십시오. 이상한 형상은 상자(그룹)로 나누십시오. |
| glTF 또는 다른 모델 파일로 애니메이션 내보내기 | 동영상을 렌더링하십시오. `.modelcraft` 파일과 ModelCraft가 저장한 [USD 파일](topic:usd)은 ModelCraft용으로 유지됩니다. |
| VR에서 이슈에 댓글이나 제목 입력, 음성 메모, VR에서 단면 평면을 손으로 이동 | VR에서 이슈를 배치한 다음, BCF 프로그램에서 문구를 추가하십시오. VR에 들어가기 전에 보기에서 단면 평면을 설정하십시오. [VR 헤드셋으로 모델 검토](topic:vr-review)를 참고하십시오. |
| VR에서 책상에 앉은 사람 보기(VR에 있는 사람만 표시됨), VR 걷기 녹화 | 그들이 VR에 참여하도록 요청하거나, 걷기를 [애니메이션](topic:animation)으로 만드십시오. |

## 메시

| 아직 아님 | 대신, 오늘은 |
|---|---|
| 단계별 조각하기(멀티해상도), 그리고 아주 작아진 삼각형을 줄이는 디테일 | 세분화된 메시를 [조각](topic:sculpt)하십시오. 다시 고르게 하려면 {{ui:Remesh}}를 사용하십시오. |
| 형상을 따르는 사각형 면으로의 리메시 | {{ui:Remesh}}(고른 삼각형)를 한 다음, [리토폴로지](topic:mesh-edit#retopology)로 다시 만드십시오. |
| 모디파이어용으로 꼭짓점에 칠한 가중치(Displace, Smooth, Shrinkwrap은 전체 메시에 작동) | 모디파이어를 적용한 다음, 필요한 부분을 조각하거나 편집하십시오. |
| 꼭짓점, 모서리, 면의 복사와 붙여넣기, 면 안에서 끝나는 칼 자르기, 면이 없는 와이어 모서리 | 모델 탭에서 메시를 복제하고, 모서리에서 모서리까지 칼 도구로 자르십시오. [돌출](topic:mesh-edit#change-the-shape)로 열린 모서리를 면으로 만드십시오. |

## 정리와 보기

| 아직 아님 | 대신, 오늘은 |
|---|---|
| DWG와 DXF 배치도의 도면층을 태그로 | 배치도는 그룹 하나로 들어옵니다. 분해한 다음, 태그하려는 부품을 그룹으로 묶으십시오. |
| 한 번에 여러 단면 자르기, 단면 상자, 또는 단면의 윤곽선을 도면으로 내보내기 | 한 번에 하나의 [단면 평면](topic:sections)만 자릅니다. 보기를 이미지로 내보내십시오. |
| 부드러운 모서리를 점선으로 표시, 또는 슬라이더를 끄는 동안 부드럽게 하기 | 객체 정보의 [각도로 부드럽게](topic:soften)를 사용하고, 다른 각도를 시도하려면 실행 취소하십시오. |
| 검색할 수 있는 온라인 모델 라이브러리, 또는 (색상, 스타일)을 고를 수 있는 구성요소 | [시작 라이브러리](topic:starter)를 사용하고, Collada, OBJ 또는 glTF 모델을 가져오십시오. 복사본을 [늘려](topic:stretch) 크기를 맞추십시오. |
| 식물 라이브러리에서 식물 배치 | 실시간 보기에서 [흩뿌리기](topic:live-view#scatter-plants-rocks-and-people)로 식물을 뿌리거나, 시작 라이브러리의 나무를 배치하십시오. |
| 그룹의 독립된 복사본 | 구성요소로 만든 다음 {{ui:Make unique}}를 사용하십시오([문제 해결](topic:troubleshooting#editing-one-group-changed-another)을 참고하십시오). |

## 렌더링

| 아직 아님 | 대신, 오늘은 |
|---|---|
| WebGPU가 없으면 보기에서의 렌더링({{ui:Render}} 작업 공간), 렌더 대기열, 카메라, 하늘 사진, 안개, 빛 혼합 옵션 | {{ui:High quality}}의 {{ui:Render a picture…}} 명령은 그곳에서 WebGL 경로 추적기를 사용하며, 그 옵션들은 없습니다([그림 렌더링](topic:render#high-quality)). |
| 렌더 엔진 애드온 없이 다른 프로그램이 렌더 그림을 그리는 것(CadCraft는 GNU GPL 라이선스의 프로그램을 실행하지 않습니다), 다른 프로그램을 통한 파노라마 또는 스테레오 카메라와 하늘 그림, Unreal Engine 플러그인(파일은 쓰이지만 열어 주는 플러그인은 배포되지 않음) | 자체 Fast 및 Path 트레이서 엔진, 애드온의 엔진([다른 프로그램으로 그림 그리기](topic:render-other-program)), 또는 엔진 목록의 USD, glTF, Unreal 폴더 파일을 가져가 어느 프로그램에서든 사용하십시오. |
| {{ui:Render a picture…}}에 흩뿌린 식물과 바위 | 이들은 [실시간 보기](topic:live-view), 파노라마, 뷰어, 동영상에 나타납니다. |

## 재질과 색

| 아직 아님 | 대신, 오늘은 |
|---|---|
| 고품질 그림에서 기본 색, 거칠기, 금속성, 불투명도, 노멀, 발광 이외의 입력이 표면 전체에서 변하는 것(평균값을 사용) | [노드로 재질 만들기](topic:shading)를 사용하십시오. 어쨌든 연결하면 보기에서 변화가 나타납니다. |
| 밀기/당기기 면의 변위 | 변위를 위해 객체를 메시로 변환하십시오. |
| 앱에서 자신의 재질을 라이브러리에 공유, 그리고 가져온 텍스처 세트의 패킹된(ARM/ORM) 또는 EXR 맵 | 파일에 보관하십시오. 별도의 맵은 PNG 또는 JPEG로 가져오십시오. |
| Live 공동 편집 세션의 파일 재질(재질은 만든 컴퓨터에 남음) | 파일을 저장하고 공유하십시오. |
| 곡면을 감싸며 휘는 데칼, 실행 취소의 데칼, 또는 이음매를 가로질러 여러 면의 질감을 한 번에 칠하기 | 각 부분에 더 작은 데칼을 배치하십시오. 이음매의 양쪽은 각각 따로 칠하십시오. |
| 밀기/당기기 면에 굽기, 여러 객체를 하나의 그림에 굽기, 손으로 모양을 만드는 케이지, 또는 램프의 구운 조명 | 메시로 변환하고 UV를 펼치십시오. 객체마다 굽고, 검색 거리를 늘리고, 램프 빛은 그림을 렌더링하여 처리하십시오. |
| 거칠기, 금속성 또는 높이 칠하기, 그림(스탬프)으로 칠하기, 512 × 512보다 큰 텍스처 칠하기 | 여기서는 기본 색을 칠하십시오. 다른 맵은 그림 편집기에서 만들고 텍스처 세트로 가져오십시오. |
| Collada, STL, PLY, 3MF, IFC, DWG, DXF 내보내기의 질감, 그리고 내보낸 모델의 파일 고유 재질의 노드 그래프 | 이 형식들은 각 재질의 색을 받으며, glTF와 OBJ는 가져온 질감을 담습니다. 재질 하나만 [MaterialX](topic:shading#materialx)로 따로 내보내십시오. [USD](topic:usd)는 ModelCraft용으로 모델 전체를 유지합니다. |
| Collada 파일의 질감 | 가져올 때 세어지고 제외됩니다. `.skp` 및 `.glb` 파일의 질감은 들어옵니다. |

## 파일

| 아직 아님 | 대신, 오늘은 |
|---|---|
| SketchUp 파일 저장, 그리고 그 안의 텍스트와 치수 | [가져오기](topic:import-sketchup-files)는 면, 색, 질감을 유지합니다. SketchUp으로 되돌리려면 Collada(`.dae`)로 내보내십시오. |
| DWG 및 DXF 내보내기의 치수와 안내선 | 내보낸 뒤 CAD 프로그램에서 추가하십시오. |
| DWG와 DXF의 점, 표, 다중 지시선 | 세어지고 제외됩니다. 문자는 도면의 글꼴이 아니라 단일 선 글자로 들어옵니다. |
| DWG와 DXF의 곡면, 메시, 표, 다중 지시선, 스윕, 로프트 또는 다른 자유형 곡면 위의 3D 솔리드 면 | 이것들도 세어지고 제외됩니다(3D 솔리드 자체는 들어옵니다). 그 부분을 CAD 프로그램에서 OBJ 또는 Collada로 내보내고, 그것을 가져오십시오. |
| IFC 유형, 속성 또는 재질 | IFC 내보내기에는 [층](topic:formats#ifc-ifc)과 일반 요소가 들어 있습니다. 나머지는 BIM 프로그램에서 추가하십시오. |
| 모델을 BimCraft로 바로 보내기 | {{ui:IFC for BimCraft (.ifc)}} 형식으로 내보내고 BimCraft에서 여십시오. |
| glTF 및 STL의 낱개 모서리 | 선 작업에는 OBJ 또는 Collada를 사용하십시오. |
| 기본 색을 넘는 glTF 및 FBX 재질(금속, 거칠기, 노멀 맵, 유리, 클리어 코트, 광택 등) | 읽혀서 목록에 나타납니다. ModelCraft는 기본 색이나 질감을 유지합니다. [음영 작업 공간](topic:shading)에서 외관을 다시 만드십시오. |
| glTF 뼈, 애니메이션, 모프 타깃 | 스킨 모델은 쉬는 자세 그대로 들어옵니다. [타임라인](topic:animation)에서 애니메이션하십시오. |
| STEP 파일의 색과 어셈블리의 부품 이름 | 부품은 실제 크기의 메시로 들어옵니다. 가져온 뒤 [칠하고](topic:paint) 이름을 붙이십시오. |
| `.3dm` 파일의 SubD 객체, 텍스트, 치수, 조명 | [제외되는 항목](topic:import-3dm-files#what-is-left-out-and-said)을 참고하십시오. SubD는 파일을 만든 프로그램에서 메시로 바꾸십시오. |
| glTF의 KTX2 질감과 재질 변형 | PNG 또는 JPEG 질감으로 내보내십시오. 기본 변형이 사용됩니다. |
| glTF 인스턴싱(EXT_mesh_gpu_instancing) 쓰기 | 구성요소는 한 번 쓰이고 여러 번 배치되며, 모든 뷰어가 이를 읽습니다. |
| Alembic 애니메이션(캐시의 모든 샘플), Alembic 점과 곡선, Alembic 쓰기 | 첫 샘플이 들어옵니다. [타임라인](topic:animation)에서 애니메이션하고, glTF, USD 또는 OBJ로 쓰십시오. |
| OBJ 재질의 범프 맵과 노멀 맵 | 색 그림(`map_Kd`)만 들어옵니다. |
| FBX 뼈와 애니메이션, FBX 내보내기, FBX 6 파일 | 스킨 모델은 휴지 상태로 들어옵니다. glTF로 내보내십시오. 오래된 파일은 FBX 2011 이상으로 저장하십시오. |
| Collada 스킨, 모프, 카메라, 조명, look-at 및 기울임 변환, 외부 참조 | 가져올 때 제외되며, 메시지에 개수가 표시됩니다. |
| 백업 파일 | {{ui:Save as}}({{key:Mod+Shift+S}}) 명령은 다른 복사본을 저장합니다. 충돌 후에는 ModelCraft가 저장되지 않은 작업을 돌려주겠다고 제안합니다("작업 복구?"). |
| 컴퓨터 간 클라우드 저장과 동기화 | 아직 사용할 수 없습니다. 파일을 컴퓨터에 저장하고, 필요한 곳에 복사하십시오. |

## 3D 프린팅

| 아직 아님 | 대신, 오늘은 |
|---|---|
| 실제 슬라이서 서포트(인터페이스, 라프트, 정확한 서포트 패턴) | [서포트 미리 보기](topic:print-tools#supports-preview)는 위치와 대략의 양을 보여 줍니다. 실제 서포트는 슬라이서의 미리 보기에서 보입니다. |
| 스스로 관통하는 부품, 또는 세 개 이상의 면이 만나는 모서리의 정리 | [복구](topic:print-tools#repair)는 위치와 함께 나열합니다. [면 교차](topic:intersect)를 사용하고 안쪽을 지우십시오. |
| 채움 패턴과 빈 속 안의 격자 | [속 비우기](topic:print-tools#hollow)는 비워 둡니다. 채움은 슬라이서가 꽉 찬 부품에 추가합니다. |
| 노즐에 비해 너무 작은 세부 사항(벽 제외) | [벽 두께](topic:print-tools#wall-thickness)는 얇은 벽을 찾습니다. 나머지는 슬라이서의 레이어 미리 보기가 보여 줍니다. |

## 성능

실행 취소는 단계마다 모델의 복사본을 보관합니다([메시](topic:meshes)는 바뀐 부분만 보관합니다). 그래서 밀기/당기기 형상을 아주 크게 가져오면 모든 편집이 느려집니다. 가져오기는 가볍게 유지하고, 저장한 뒤 다시 열어 기록을 지우십시오.

## 앱과 플랫폼

- **데스크톱:** ModelCraft는 Mac, Windows, Linux의 브라우저에서 실행되며, 여덟 개 앱을 한 번에 설치하는 데스크톱 앱 CadCraft Studio에서도 실행됩니다. Android에서는 getcadcraft.com/download의 APK로 CadCraft Studio를 설치합니다. iPad나 iPhone 빌드는 아직 없습니다.
- **터치:** 손가락 제스처는 [궤도 회전, 초점 이동, 줌](topic:orbit-pan-zoom)을 참고하십시오. 펜의 압력은 [조각](topic:sculpt)에서 브러시를 설정하며, 그 밖에서는 압력과 펜 기울기를 사용하지 않습니다.
- **시트:** ModelCraft는 [페이지마다 뷰 하나를 인쇄](topic:export-model#print-the-view-or-save-it-as-a-pdf)합니다. 여러 뷰나 표제란이 있는 시트 배치는 없습니다. 축척 도면은 CadCraft와 호환되는 DWG/DXF로 내보내십시오.
