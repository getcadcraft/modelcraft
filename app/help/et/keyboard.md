Need on lükka/tõmba klahvid, millega ModelCraft algab. Teise stiili kohta vt [Modeleerija klahvid](topic:keyboard#modeler-keys) allpool ja [ModelCraft sätted](topic:settings).

Kiirklahvid töötavad, kui 3D-vaade või tööriistariba nupp on fookuses. Kui just kirjutasid paneeli väljale või muutsid nimekirja jaotises {{ui:Stiil}}, klõpsa kõigepealt 3D-vaates, muidu lähevad sinu klahvid sellele väljale. Vt [Klahvid, hiired ja puuteplaadid](common:keys), kuidas klahve igal arvutil kirjutatakse.

## Esc

{{key:Esc}} viib ühe taseme tagasi iga vajutusega:

1. Tühistab selle, mida tööriist parasjagu teeb (joone joonistamine, lükkamine/tõmbamine, teisaldamine). Kõik läheb tagasi.
2. Lülitub valikule {{ui:Vali}}.
3. Tühistab valiku.
4. Sulgeb grupi, mida redigeerid.

See peatab ka stseenide mängimise. Väärtuste kastis tühistab {{key:Esc}} sisestatu ja naaseb vaatesse.

## Tööriista töötamise ajal

| Klahv | Teeb |
|---|---|
| Number või üks märkidest `. , - ' " [ < * /` | Alustab sisestamist väärtuste kasti |
| {{key:Enter}} | Rakendab väärtuste kasti sisestatu |
| {{key:Right}} | Lukustab punasele teljele (uuesti vajutades lukustus eemaldub) |
| {{key:Left}} | Lukustab rohelisele teljele |
| {{key:Up}} | Lukustab sinisele teljele |
| {{key:Down}} | Lukustab paralleelselt viimase servaga, mille kohal liikusid enne esimest klõpsu |
| Hoia all {{key:Shift}} | Hoiab suuna, millega haakud, kuni hoiad |
| {{key:Ctrl}}, {{key:Mod}} või {{key:Alt}} (Teisalda) | Vahetab teisaldamise ja kopeerimise vahel |

Nooleklahvide lukustused töötavad tööriistades {{ui:Joon}}, {{ui:Ristkülik}}, {{ui:Ring}}, {{ui:Hulknurk}}, {{ui:Teisalda}}, {{ui:Mõõtkava}} ja {{ui:Mõõdulint}} (kui mõõdad punktist), pärast esimest klõpsu. {{ui:Lükka/tõmba}} liigub alati tahu suunas ega paku lukustusi. Tööriistas {{ui:Pööra}} näitavad nooleklahvid pärast esimest klõpsu teadet „Lukustatud“, kuid pööret ei muuda.

## Nooleklahvid muul ajal

Kui ükski tööriist parasjagu midagi ei tee, liigutavad nooleklahvid kaamerat:

| Klahv | Teeb |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Orbiit |
| {{key:Shift}} koos noolega | Nihuta vaadet |

## Hiir

| Toiming | Teeb |
|---|---|
| Klõps | Kasutab praegust tööriista |
| Vajuta, lohista, lase lahti | Sama mis kaks klõpsu (joonistamise tööriistadele); kastivalik (tööriistale {{ui:Vali}}); kustutab teel (tööriistale {{ui:Kustutaja}}) |
| Topeltklõps | {{ui:Vali}}: tahk koos servadega, serv koos tahkudega, avab grupi; tühi ruum sulgeb grupi. {{ui:Lükka/tõmba}}: kordab viimast kaugust |
| Kolmikklõps | {{ui:Vali}}: kõik ühendatud |
| {{key:Shift}} + klõps | {{ui:Vali}}: lülita valikusse ja sealt välja |
| {{key:Mod}} + klõps | {{ui:Vali}}: lisa valikusse |
| {{key:Shift}} + {{key:Mod}} + klõps | {{ui:Vali}}: eemalda valikust |
| Keskmise nupuga lohistamine | Orbiit, mis tahes tööriistaga |
| {{key:Shift}} + keskmise nupuga lohistamine | Nihuta vaadet, mis tahes tööriistaga |
| Parema nupuga lohistamine | Nihuta vaadet, mis tahes tööriistaga |
| Hiireratas | Suumi kursori poole |

Parempoolse klõpsu menüüd ei ole.

## Puuteplaat

Mida teeb kahe sõrmega pühkimine, sõltub jaotisest {{ui:Sätted}} › {{ui:ModelCraft}} › Kerimine:

| Žest | Puuteplaat (või arvutatud) | Hiireratas |
|---|---|---|
| Kahe sõrmega pühkimine | Orbiit | Suumi kursori poole |
| {{key:Shift}} + kahe sõrmega pühkimine | Nihuta vaadet | Suumi |
| Näpistamine | Suumi kursori poole | Suumi kursori poole |
| Kahe sõrmega vajutus ja lohistamine (hoitud teisene klõps) | Nihuta vaadet | Nihuta vaadet |

Vt [Orbiit, vaate nihutamine ja suumimine](topic:orbit-pan-zoom#on-a-trackpad) ja [ModelCraft sätted](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Puuteekraan

| Žest | Teeb |
|---|---|
| Koputus | Klõps praeguse tööriistaga |
| Topeltkoputus | Topeltklõps |
| Vajuta, lohista, tõsta | Sama mis hiirega vajutus, lohistamine ja vabastamine |
| Kaks sõrme: näpistamine | Suumi |
| Kaks sõrme: liiguvad koos | Nihuta vaadet ({{ui:Sätted}} › {{ui:ModelCraft}} › Puuteekraan võib selle muuta orbiidiks) |
| Kolm sõrme: liiguvad koos | Orbiit (kui kaks sõrme orbiidivad, siis nihuta vaadet) |
| Hoia üks sõrm paigal | Lõpetab tööriista nagu {{key:Enter}}; kui midagi ei toimu, siis lohista orbiidi jaoks |
| Teine sõrm ühe sõrme toimingu ajal | Tühistab selle toimingu |
| {{ui:Orbiit}}-tööriist, seejärel lohista ühe sõrmega | Orbiit |

Väärtuse sisestamiseks puuteekraanil koputa alumist väärtuste kasti, kirjuta ja vajuta klaviatuuri klahvi {{key:Enter}} (või Go).

## Kus asub Teisalda

Teisalda asub tööriistas {{ui:Teisalda}}, klahv {{key:M}}: vali, mida liigutada, klõpsa lähtepunkt ja seejärel teine punkt või sisesta kaugus. Vt [Teisalda, kopeeri ja tee massiive](topic:move-copy).
