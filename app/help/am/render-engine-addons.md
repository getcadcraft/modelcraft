ተጨማሪ (ቅንብሮች › ተጨማሪዎች) ወደ {{ui:ምስል ሬንደር አድርግ…}} የሞተር ዝርዝር አንድ ሞተር ማከል ይችላል። ለተጨማሪ ጸሐፊዎች ሙሉ ጽሑፉ በተጨማሪ ዝርዝር መግለጫው ክፍል 16 ነው፤ በአጭሩ፦

- ተጨማሪው ሞተር ይመዘግባል፦ የራሱን በሚጀምር መለያ (id)፣ ስም፣ አማራጭ ቅንብሮች፣ እና **ወይ** ሊሄድ የሚገባ ፕሮግራም **ወይም** ምስሉን የሚስል በJavaScript የተጻፈ ተግባር።
- ፕሮግራም የሚያስኬድ ሞተር **`engine.run`** ፈቃድ ያስፈልገዋል፣ ይህም ከመጫኑ በፊት እና በቅንብሮች ውስጥ ይታያል። በStudio ብቻ ይሰራል፤ በአሳሹ ውስጥ እንደ የሚቀመጥ ፋይል ይታያል።
- ተጨማሪው ፕሮግራሙን ይሰይማል (ተራ የፋይል ስም፤ በፍጹም ሼል አይደለም)፣ በ**በተፈረመው ተጨማሪ ውስጥ ያለ** ስክሪፕት፣ እና ከቦታ ያዥ እና ከተራ ቃላት የተሰሩ መለኪያዎች። Studio ፕሮግራሙን ያገኛል ወይም አንድ ጊዜ እንዲጠቁሙት ይጠይቅዎታል።
- ተጨማሪ ፕሮግራም ለመጀመሪያ ጊዜ ሲያስኬድ፣ **Studio በራሱ ንግግር ይጠይቅዎታል**፦ የትኛው ተጨማሪ፣ የትኛው ፕሮግራም፣ እና ስክሪፕት ፕሮግራሙ የሚችለውን ሁሉ ማድረግ እንደሚችል። የሚያምኑትን ተጨማሪ ብቻ ይፍቀዱ። መልስዎ ለዚያ ተጨማሪና ፕሮግራም ይታወሳል።
- ፓኬጁ (ትዕይንቱ እንደ USD እና የቅንብሮች ፋይል፣ ተጨማሪው ሲጠይቅ የglTF ፋይል ጋር) እና የተጨማሪው ስክሪፕት አዲስ ጊዜያዊ አቃፊ ውስጥ ይገባሉ፣ ፕሮግራሙ እዚያ ይሰራል፣ እና ምስሉ በተጨማሪው የሞተር ስም ምልክት ተደርጎ ይመለሳል።

:::note
ተጨማሪዎች የሬንደር ሞተሮችን ማከል የሚችሉት ከተጨማሪ API 1.4 ጀምሮ ብቻ ነው። ለክፍት ምንጭ የትእዛዝ-መስመር ሬንደረር የተሰራ ምሳሌ የራሱ ማከማቻ ውስጥ አለ፤ በዚያ ሬንደረር ገና አልተሞከረም።
:::
