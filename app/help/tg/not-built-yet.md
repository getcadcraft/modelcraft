ModelCraft нусхаи аввалин аст. Ин саҳифа мефаҳмонад, ки он ҳоло чиро иҷро намекунад, то ки шумо дар ҷустуҷӯи он набошед, ва наздиктарин роҳи иҷро кардани кор имрӯз.

## Абзорҳои нақшакашӣ

| Ҳанӯз нест | Ба ҷои ин, имрӯз |
|---|---|
| Нақшакашии озод | Нуқтаҳоро бо {{ui:Хами}} пахш кунед |
| Тағйир додани шумораи сегментҳои камон ё давра пас аз кашидан | Онро нест кунед ва пас аз навиштани `24s` аз нав кашед |
| Интихоби шрифт барои [матни 3D](topic:text3d), ё таҳрири калимаҳои он пас аз ҷойгир кардан | Онро нест кунед ва матнро аз нав илова кунед |
| Тағйир додани кунҷ бо навиштан ба андозаи кунҷ, ё андозаи силиндр аз андозаи давраи он | Канорҳоро бо {{ui:Гардонидан}} гардонед; силиндрро бо {{ui:Миқёс}} калон ё хурд кунед |
| Андозаҳо дар файлҳои моделии содиршуда | Андозаҳо дар тасвирҳо, чопҳо ва PDF-и намуд нишон дода мешаванд; файлҳои модел танҳо геометрияро нигоҳ медоранд |
| Буридан, Ҷудо кардан ва Қабати берунӣ | Гурӯҳҳои бастаи [Муттаҳид кардан, Тарҳ кардан ва Умумӣ кардан](topic:solids) ё [рӯҳоро умумӣ кардан](topic:intersect) ва он чиро, ки лозим нест, нест кунед |
| Интихоби меҳвари гардиш бо тирҳои клавиатура | Тугмаи маркази {{ui:Гардонидан}}-ро дар рӯе пахш кунед, ки самти меҳвар бояд нишон диҳад |
| Қуфл дар бештар аз як ишорат дар як вақт | Як самтро бо тири клавиатура қуфл кунед, сипас ба нуқта часпед |
| Андоза кардан дар муқобили нишеб, ё аз охири андозае, ки дар кунҷ нест | Андозаро дар ду кунҷ, дар канор ё дар самти сурх, сабз ё кабуд ҷойгир кунед |

## Аниматсия

| Ҳанӯз нест | Ба ҷои ин, имрӯз |
|---|---|
| Аниматсияи рӯҳо, каноронҳо, вақти рӯз бо офтоб, услуб ё он чи пинҳон аст | Қисми ҳаракаткунандаро гурӯҳ ё компонент созед; барои вақти дигари рӯз видеои алоҳида рендер кунед |
| Камере, ки роҳи кашидашударо пайравӣ мекунад ё ба ашёи ҳаракаткунанда нигоҳ мекунад | Дар роҳ калидҳои бештари камера гузоред ([Аниматсия](topic:animation)) |
| Садо дар видеоҳо ва видеоҳои сифати баланд (бо роҳи ҷилодиҳӣ) бе WebGPU | Садоро дар муҳаррири видео илова кунед; бе WebGPU видеоро бо рендерери тез рендер кунед ([Рендери видео](topic:animation#render-the-video)) |
| Чароғҳои аниматсияшуда (равшанӣ, паҳнӣ, ранг) дар видеои рендершуда, кунҷи линзаи аниматсияшуда бе калидҳои камера дар видео, аниматсияи мавод ё танзимоти рендер | Чароғҳо дар намуд аниматсия мешаванд; барои видео камераро низ калид кунед барои калонкунӣ; барои танзимоти гуногуни чароғ видеоҳои алоҳида рендер кунед ([Ҳар хосиятро аниматсия кунед](topic:animate)) |
| Оина кардани вазнҳо ё устухонҳо аз як тараф ба тарафи дигар, конвертҳои устухонро дидан, нишон додани вазнҳо нуқта ба нуқта бо соя (онҳо ба ҳар рӯ нишон медиҳанд), дидани меши позадор ҳангоми рангкунии вазнҳо | Ҳарду тарафро ранг кунед ё як нимро созед ва модификатори Mirror-ро пеш аз илова кардани армотура истифода баред; барои санҷиш байни Ранги вазнҳо ва Поза гузаред |
| Устухонҳо аз файлҳои glTF, FBX ё USD ҳамчун армотура хонда мешаванд, ва армотураҳо ба ин файлҳо навишта мешаванд | Моделҳои пӯстдор бо вазнҳои файл дар ҳолати истироҳат меоянд; устухонҳоро бо тартиби пайвасти файл илова кунед, сипас {{ui:Вазнҳои файлро истифода бурдан}} ([Аниматсия](topic:animate)) |
| Кашидани ҳадафи IK ё қутб бо кашидан дар намуд, интихоби фазои хосаи маҳдудият (маҳаллӣ ё ҷаҳонӣ), кашидани занҷирҳои IK, IK дар хами | Нуқтаи ҳадафро нависед ё ба ашёе нишона гиред ва онро кӯчонед; занҷирҳоро ба дарозиҳои худ нигоҳ доред |
| Матоъ, моеъҳо, ҷисмҳои нарм, бандҳо ва лӯлаҳо байни ҷисмҳои сахт, бархӯрдан бо шакли дақиқи ашё (фақат қуттӣ ва тӯп дар атрофаш), симулятсияи зинда ҳангоми бозӣ, сураъти ибтидоӣ ё чархиши ибтидоӣ (ҷисмҳо дар истироҳат шурӯъ мекунанд) | Ҷисмҳои сахтро бо калидҳо пухта бозӣ кунед; лӯлаеро аз калидҳо созед; шакли ғайриоддиро ба қуттиҳо (гурӯҳҳо) ҷудо кунед |
| Содироти аниматсия ба файлҳои glTF ё дигар файлҳои модел | Видео рендер кунед; файли `.modelcraft` ва [файли USD](topic:usd)-е, ки ModelCraft захира кардааст, барои ModelCraft мемонанд |
| Навиштани матн ё сарлавҳа дар масъалаи VR, ёддоштҳои овозӣ, кашидани ҳавопаи бурриш бо даст дар VR | Масъаларо дар VR ҷойгир кунед, сипас матнашро дар барномаи BCF илова кунед; пеш аз ворид шудан ҳавопаи бурриши дар намуд танзим кунед: нигаред ба [Баррасии модел бо гарнитураи VR](topic:vr-review) |
| Дидани одамон дар мизи корӣ дар VR (фақат одамони дар VR буда нишон дода мешаванд), сабти гашти VR | Аз онҳо хоҳиш кунед, ки дар VR ҳамроҳ шаванд, ё [аниматсия](topic:animation)-и гашт созед |

|---|---|
| Ҳайкалтарошӣ бо сатҳҳо (мултирезолюшн) ва Тафсил, ки секунҷаҳои хурдшударо мегирад | [Ҳайкалтарошӣ](topic:sculpt)-и меши зершуда; барои ҳамвор кардани он боз {{ui:Азнавсозии меш}} |

| Нусхабардорӣ ва гузоштани нуқтаҳо, каноронҳо ё рӯҳо, буридани корд, ки дар дохили рӯ тамом мешавад, канорҳои сим бе рӯ | Меши дар Model дубликат кунед; бо корд аз канор то канор бурrед; [Экструзияи](topic:mesh-edit#change-the-shape) канорҳои кушодаро ба рӯҳо табдил диҳед |

## Иҷро

Undo барои ҳар қадам нусхаи модел нигоҳ медорад ([меш](topic:meshes) танҳо тағйирёфтаро нигоҳ медорад), бинобар ин воридоти хеле калони геометрияи push/pull ҳар таҳриррро суст мекунад. Воридотро сабук нигоҳ доред ва барои тоза кардани таърих захира кунед ва боз кушоед.

## Барномаҳо ва платформаҳо

- **Мизи корӣ:** ModelCraft дар браузер дар Mac, Windows ва Linux кор мекунад, ва дар CadCraft Studio, барномаи мизи корӣ бо ҳар ҳашт барнома дар як насб. Дар Android, CadCraft Studio аз APK-и худ дар getcadcraft.com/download насб мешавад. Ҳоло барои iPad ё iPhone нусха нест.
- **Ламс:** барои имову ҳаракатҳои ангушт [Гардиш, ҷойивазкунӣ ва калонкунӣ](topic:orbit-pan-zoom)-ро бинед. Фишори қалам [Ҳайкалтарошӣ](topic:sculpt)-ро танзим мекунад; дар ҷои дигар фишор ва каҷии қалам истифода намешаванд.
- **Варақҳо:** ModelCraft [ҳар намудро дар як саҳифа чоп мекунад](topic:export-model#print-the-view-or-save-it-as-a-pdf); варақҳои чандинамуда ё блоки унвон нест. Барои нақшаҳо бо миқёс ба DWG/DXF-и ба CadCraft мувофиқ содир кунед.
