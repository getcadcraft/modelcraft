Дар CadCraft Studio рӯйхати муҳаррик метавонад **пайванд**ро ба лоиҳаи Unreal Engine нигоҳ дорад. Танҳо як роҳ: аз CadCraft ба Unreal.

## Фиристодани манзара

1. Дар рӯйхати муҳаррик Unreal-ро интихоб кунед. Бори аввал Studio аз шумо ҷузвдони лоиҳаи худро мепурсад (он ки файли `.uproject` дорад); онро ба ёд мегирад.
2. {{ui:Фиристодан}}-ро пахш кунед. Studio дар дохили лоиҳа `CadCraft/<file name>/`-ро менависад: манзара ҳамчун файли USD, файли танзимот, профилҳои чароғ ва ду файли хурди қабат.
3. Моделро иваз кунед, захира кунед ва дубора фиристед. Танҳо манзара ва файли танзимот иваз мешаванд.

## Таҳрирҳои шумо бехатар ҳастанд

Сахнае (stage), ки Unreal мекушояд, решаи хурди қабатест, ки як бор сохта мешавад, бо ду қабат дар поёнаш: **шумо** дар боло (`<name>.user.usda`, дар аввал холӣ, ҳеҷ гоҳ аз ҷониби CadCraft навишта намешавад) ва манзараи CadCraft дар поён. Таҳрирҳое, ки дар қабати худ захира мекунед, ҳангоми дубора фиристодани манзара бомонда мемонанд. Чароғҳо ва дигар актёрҳое, ки дар сатҳи Unreal ҷойгир мекунед, берун аз сахна мебошанд ва онҳо низ дахл намеёбанд.

## Бе Studio

Дар браузер ё дар компютере, ки Studio Unreal-ро пайдо намекунад, **Ҷузвдони лоиҳаи Unreal (.zip)**-ро дар рӯйхати муҳаррик интихоб кунед ва {{ui:Рендер}}-ро пахш кунед. Он ҳамон ҷузвдонро ҳамчун zip захира мекунад: онро ба ҷузвдони `CadCraft`-и лоиҳаи худ экстракт кунед. Бори аввал **Дохил кардани файлҳои сахна**-ро фаъол гузоред; барои захираҳои баъдӣ онро хомӯш кунед, то zip танҳо манзара ва файли танзимотро дошта бошад ва қабати шумо ҳеҷ гоҳ иваз нашавад.

:::note
Плагини Unreal, ки сахнаро мекушояд, рӯшноӣ, офтоб, камераҳо ва экспозицияро татбиқ мекунад, ҳар фиристодани навро пайгирӣ мекунад ва камераро рендер мекунад, **ҳанӯз нашр нашудааст** ва дар Unreal иҷро нашудааст. То он вақт {{ui:Фиристодан}} файлҳоро ба лоиҳа мегузорад ва абзорҳои USD-и худи Unreal метавонанд онҳоро кушоянд. Windows системаи аввал аст; macOS баъдан меояд.
:::
