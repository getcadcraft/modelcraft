## Чӣ меомӯзед

Чӣ гуна ёвари AI (ё скрипте, ки шумо навиштаед) бо ModelCraft кор кунад ва чиро ӯ дар модел дастрас дошта метавонад, шумо муайян мекунед.

ModelCraft **худи AI надорад** ва ҳеҷ чизро ба ҷои дигар намефиристад. Шумо ёварро меоред: ҳар барномае, ки Model Context Protocol (MCP)-ро мефаҳмад. ModelCraft ба он абзорҳо медиҳад, ва шумо интихоб мекунед, ки кадомашон.

## Фаъол кардан

1. {{ui:Settings}}-ро кушоед (зоҳи дар панели барнома, ё {{key:Mod+,}}) ва ба варақаи {{ui:ModelCraft}} гузаред.
2. Дар зери {{ui:Assistants}} қайд кунед: **Иҷозат ба ёварҳои AI ва скриптҳо барои истифодаи ModelCraft**. То он ки қайд накунед, калид хомӯш аст.
3. Интихоб кунед, ки чӣ карда метавонад: **Хондан** ба таври пешфарз қайд шудааст; **Таҳрир**, **Захира** ё **Содирот**-ро танҳо вақте қайд кунед, ки лозиманд.

Абзорҳое, ки берун аз иҷозатҳои қайднамудаи шумо ҳастанд, ба ёвар пешниҳод намешаванд, ва агар ӯ ба яке аз онҳо талаб кунад ҳам, ModelCraft рад мекунад ва онро дар журнали фаъолият менависад. Хомӯш кардани калид ҳамаи пайвастҳоро якбора қатъ мекунад; {{ui:Reset ModelCraft settings}} низ онро хомӯш мекунад.

## Ёварро пайваст кунед

Ёварҳо тавассути **CadCraft Studio** дар компютери шумо пайваст мешаванд: Studio сервери хурде иҷро мекунад, ки танҳо ин компютер ба он дастрас аст ва бо токене, ки ҳар бор ҳангоми оғоз месозад, муҳофизат шудааст. Дар Studio {{ui:Connect an assistant}}-ро интихоб кунед ва суроға ва токенро ба ёвари худ нусхабардорӣ кунед (Studio танзимоти дақиқи гузоштаниро нишон медиҳад). Токенро ҳеҷ гоҳ паҳн накунед.

:::note
Варақаи браузер барои ёвар пайваст шуда наметавонад: дар барномаҳои браузер калид то истифодаи CadCraft Studio дар компютери шумо таъсир намекунад.
:::

## Шумо назоратро нигоҳ медоред

- **Ҳар тағйирот як қадами баргардондан аст**, ки бо номи ёвар (масалан «Assistant: box») ишора шудааст. {{key:Mod+Z}} тағйироти охирини ёварро якҷоя бармегардонад.
- **Шумо медонед, ки кай пайваст аст.** Тугма дар панели барнома ҳангоми пайваст будан номи ёварро нишон медиҳад; онро пахш кунед, то бубинед чӣ карда метавонад, ё барои **Қатъ кардани пайванд**.
- **Фаъолият.** {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}} › {{ui:Activity}} ҳар даъватро нишон медиҳад: кай, кадом абзор, иҷро шуд ё рад. {{ui:Save the log}} нусхаи онро нигоҳ медорад.

## Ёвар чиро талаб карда метавонад

| Абзор | Иҷозат | Чӣ мекунад |
|---|---|---|
| `app_info`, `model_describe` | Хондан | Воҳиди модел, андоза, ҳар гурӯҳ ва ҷузъ бо ҷойгиршавиашон, ҷисми пӯшида будан ё не ва ҳаҷмаш |
| `view_screenshot` | Хондан | Тасвири намуди 3D ҳамон тавре ки намоиш дода мешавад |
| `box_add`, `cylinder_add` | Таҳрир | Қуттӣ ё силиндр ҳамчун гурӯҳи нав, дар ҷой ва андозае, ки шумо ё ӯ медиҳед («3m», «10'» ё рақам дар воҳиди модел) |
| `instance_move`, `instances_erase` | Таҳрир | Гурӯҳҳо ва ҷузъҳоро мекӯчонад ё нест мекунад |
| `faces_list`, `materials_list` | Хондан | Рӯйҳои гурӯҳ ё геометрияи озод (самт, масоҳат ва маркази ҳар кадом); маводҳо ва ранге, ки бо онҳо рангкорӣ мешавад |
| `push_pull` | Таҳрир | Рӯйро фишор медиҳад ё мекашад, мисли {{ui:Push/pull}} |
| `paint` | Таҳрир | Рӯйҳо ё гурӯҳи пурраро бо ранг ё масолеҳ рангкорӣ мекунад |
| `group_make` | Таҳрир | Аз рӯйҳо ва гурӯҳҳои озод гурӯҳ ё ҷузъ месозад |
| `scene_add`, `scene_show` | Таҳрир | Намудро ҳамчун манзара захира мекунад; ба манзараи захирашуда меравад |
| `mesh_add` | Таҳрир | Объекти меш барои оғоз (куб, сфера, силиндр …), мисли фазои Меш илова мекунад |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | Хондан / Таҳрир | Стеки модификаторҳои меш: оина, массив, субдивизия, фаска ва ғайра; ҳеҷ чиз ба таври доимӣ татбиқ намешавад |
| `usd_export` | Содирот | Моделро ҳамчун OpenUSD (.usda, .usdc ё .usdz) мисли захиркунии модел ҳамчун USD менависад ([USD](topic:usd)); ба ҷузвдоне, ки дар Studio иҷозат додаед, вагарна зеркашӣ |
| `render_still` | Содирот | Аксҳои рендеркардаи намуд ё манзараи захирашуда, мисли тугмаи {{ui:Render}}-и диалоги {{ui:Render}}, бо танзимоти рендери шумо, магар ин ки ӯ дигарашро талаб кунад (пешниҳоди манзара: беруна, дарунӣ, бурриш, шабона ё худкор; зуд ё сифати баланд, андоза, намуна, осмон); PNG, ки ӯ дида метавонад, ё PNG, EXR ё файли рендер дар ҷузвдоне, ки дар Studio иҷозат додаед ([Расмро рендер кардан](topic:render)) |
| `render_queue` | Содирот | Аксҳои сифати баландро ба навбати диалоги Рендер илова мекунад (намуд ё манзараҳои захирашуда) ва навбатро иҷро мекунад; аксҳои анҷомёфта ба ҷузвдоне, ки иҷозат додаед, мераванд ё барои шумо дар {{ui:Render queue}}-и диалоги Рендер мемонанд. Лозим аст WebGPU |
| `link_push` | Таҳрир | Моделеро, ки аз барномаи дигар пайваст шудааст, навсозӣ мекунад (ниг. [Моделии .3dm-ро зинда нигоҳ доред](topic:live-3dm-link)) |
| `link_status` | Хондан | Мегӯяд, ки модели пайвастшуда ҳанӯз ҳаст ё не ва охирин бор кай навсозӣ шудааст |
| `undo` | Таҳрир | Қадамҳои худашро бармегардонад |

Ҷисмҳое, ки ёвар месозад, ҳамчун гурӯҳ меоянд, пас ҳеҷ гоҳ бо он чи шумо кашидаед якҷоя намешаванд. Абзоре нест, ки модел захира кунад: захира кардан бо шумост, ва содирот ё рендер **Содирот**-ро қайд кардан талаб мекунад. Рендер ҳеҷ чизро дар модел тағйир намедиҳад; рендери манзараи захирашуда намудро ба он мегузаронад, мисли {{ui:Scenes}} мекунад.

## Агар чизе кор накунад

- **Ёвар абзорҳои ModelCraft-ро намебинад:** санҷед, ки калид дар ин тиреза фаъол аст ва тиреза дар Studio кушода аст.
- **«needs the edit permission»:** **Таҳрир**-ро дар зери {{ui:Assistants}} қайд кунед, сипас дубора пурсед.
- **Хатогиҳои «401» ё «token»:** токен иваз шудааст (Studio аз нав оғоз шуд ё {{ui:New token}}). Токени навро ба танзимоти ёвар нусхабардорӣ кунед.
