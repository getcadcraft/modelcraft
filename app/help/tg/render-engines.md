{{ui:Расмро рендер кардан…}} дорои интихоби **Механизм** дар боло Режим аст. Ду механизми худамон ҳамеша ҳастанд ва ҳамаҷо кор мекунанд; иловаҳо метавонанд бештар илова кунанд, ва дар CadCraft Studio рӯйхат инчунин барномаҳоеро дорад, ки саҳнаро ба дасти худ мегиранд.

| Механизм | Чӣ кор мекунад | Дар куҷо |
|---|---|---|
| Дохилӣ: Тез | Тасвири зуд: рӯшноии рӯз, сояҳои нарм, намуди шиша ва металл, дар чанд сония | Браузер ва Studio |
| Дохилӣ: Path tracer | Рӯшноӣ байни сатҳҳо акс мезанад, бо кортҳои графикӣ ё протсессор, навбати рендер ва компютерҳои дигар дар шабакаи шумо | Браузер ва Studio |
| Механизми илова | Тасвирро мекашад ва бармегардонад: нигаред ба [Тасвирро бо барномаи дигар кашидан](topic:render-other-program) | Браузер (механизми дар JavaScript навишташуда) ё Studio (механизме, ки барномаро иҷро мекунад) |
| Барномае, ки саҳнаро мегирад | Studio саҳнаро ба ҷузвдонаш мегузорад ва онро ҳамоҳанг нигоҳ медорад | Studio |
| Кушодан дар … | Саҳнаро захира мекунад ва онро дар барнома мекушояд; ҳеҷ чиз бармегардад: нигаред ба [Кушодани саҳна дар барномаи дигар](topic:render-open-in) | Веб файлро захира мекунад |

## Интихоб чӣ гуна рафтор мекунад

- Интихоби Тез ё Path tracer Режимро бо он иваз мекунад ва баръакс. Дигар ҳеҷ чиз дар диалог барои онҳое, ки ҳеҷ гоҳ механизми дигарро истифода намебаранд, иваз намешавад.
- Механизме, ки дастрас нест, бо сабаб дар рӯйхат мемонад ("ёфт нашуд", "версияи навтар лозим аст"); онро интихоб кардан мумкин нест. Дар браузер механизме, ки танҳо дар Studio кор мекунад, "файлро захира мекунад" нишон медиҳад: {{ui:Расмро рендер кардан…}} он гоҳ саҳна ва танзимоти онро ба файле захира мекунад, ки ба он барнома мебаред.
- Интихоб бо танзимоти рендери файл захира мешавад, ва механизме, ки охирин интихоб кардед, механизми оғозии файлҳоест, ки интихоби худро надоранд.
- Тасвир аз барномаи дигар мегӯяд, ки кадом барнома онро кашидааст ва версияи он, дар диалог ва дар навбати рендер. Ваъдаҳои саҳифаи [Рендер](topic:render) танҳо механизмҳои **худамонро** фаро мегиранд: барномаи дигар рӯшноӣ, рангҳо ва семплҳоро ба роҳи худаш мекунад, пас ду тасвири як саҳна дар камера, офтоб, чароғҳо ва экспозиция монанданд, на пиксел ба пиксел.

## Ҳар механизм чӣ мегирад

Саҳна ба барномаи дигар ҳамчун **баста** меравад: модел ҳамчун файли USD (ҳамон файле, ки [Захира ҳамчун USD](topic:usd) менависад), ва файли танзимот, ки чизеро дар бар мегирад, ки ба воридкунандаи USD ишонидан мумкин нест: арзишҳои дақиқи мавод, чароғҳое, ки равшананд, бо қуввати худ ва профили рӯшноии худ, офтоб, осмон, экспозиция ва камера тавре ки диалог мекашид. Ҳеҷ чиз ба ҷое боргузорӣ намешавад.

## Навбати рендер

Тасвир ё анимация барои барномаи дигар метавонад мисли худамон дар [навбати рендер](topic:render#the-render-queue) интизор шавад; корашон ба ёд дорад, ки барои кадом механизм аст. Анимация як маротиба ба барнома меравад.
