Инҳо тугмаҳои push-pull ҳастанд, ки ModelCraft бо онҳо оғоз мешавад. Барои услуби дигар, нигаред ба [тугмаҳои Modeler](topic:keyboard#modeler-keys) дар поён ва [Танзимоти ModelCraft](topic:settings).

Миёнбурҳо вақте кор мекунанд, ки намоиши 3D ё тугмаи абзор фокус дошта бошад. Агар шумо ҳоло дар майдони панел матн нависед ё рӯйхатро дар {{ui:Style}} иваз кардед, аввал дар намоиши 3D пахш кунед, вагарна тугмаҳоятон ба он майдон мераванд. Нигаред ба [Тугмаҳо, мушҳо ва тачпадҳо](common:keys), то бифаҳмед, ки тугмаҳо дар ҳар компютер чӣ гуна навишта мешаванд.

## Esc

{{key:Esc}} ҳар бор як сатҳ аз нав бармегардад:

1. Чизеро, ки абзор дар миёнаи он аст, бекор мекунад (хатеро, ки кашида мешавад, push/pull, ҳаракат). Ҳама чиз ба ҷои худ бармегардад.
2. Ба {{ui:Select}} мегузарад.
3. Интихобро тоза мекунад.
4. Гурӯҳеро, ки таҳрир мекунед, мепӯшад.

Ҳамчунин, он намоиши манзараҳоро қатъ мекунад. Дар қуттии арзиш, {{key:Esc}} чизеро, ки навиштаед, тоза мекунад ва ба намоиш бармегардад.

## Вақте ки абзор кор мекунад

| Тугма | Кор мекунад |
|---|---|
| Рақам ё яке аз `. , - ' " [ < * /` | Навиштан дар қуттии арзиш оғоз мекунад |
| {{key:Enter}} | Он чиро, ки дар қуттии арзиш навиштаед, татбиқ мекунад |
| {{key:Right}} | Ба меҳвари сурх қуфл мекунад (барои кушодан боз пахш кунед) |
| {{key:Left}} | Ба меҳвари сабз қуфл мекунад |
| {{key:Up}} | Ба меҳвари кабуд қуфл мекунад |
| {{key:Down}} | Параллел ба канори охирини пеш аз пахши аввал қуфл мекунад |
| {{key:Shift}} нигоҳ доред | Самти часпидаатонро нигоҳ медорад, то вақте ки нигоҳ доред |
| {{key:Ctrl}}, {{key:Mod}} ё {{key:Alt}} (Move) | Байни ҳаракат ва нусхабардорӣ гузаришро анҷом медиҳад |

Қуфлҳои тирҳои стрелка дар {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} ва {{ui:Tape}} (ҳангоми ченкунӣ аз нуқта) пас аз пахши аввал кор мекунанд. {{ui:Push/pull}} ҳамеша дар самти рӯй ҳаракат мекунад ва қуфл надорад. Дар {{ui:Rotate}} тирҳои стрелка пас аз пахши аввал паёми «Қуфлшуда» мебароранд, вале гардишро тағйир намедиҳанд.

## Тирҳои стрелка дар вақтҳои дигар

Вақте ки абзор дар миёни коре нест, тирҳои стрелка камераро ҳаракат медиҳанд:

| Тугма | Кор мекунад |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Гардиш |
| {{key:Shift}} бо тир | Ҷойивазкунӣ |

## Муш

| Амал | Кор мекунад |
|---|---|
| Пахш | Абзори ҷориро истифода мебарад |
| Пахш, кашидан, раҳо кардан | Мисли ду пахш (барои абзорҳои кашидан); интихоби қуттӣ (барои {{ui:Select}}); нест кардан дар роҳ (барои {{ui:Eraser}}) |
| Пахши дукарата | {{ui:Select}}: рӯй бо канораҳояш, канор бо рӯяҳояш, гурӯҳро мекушояд; ҷои холӣ гурӯҳро мепӯшад. {{ui:Push/pull}}: масофаи охиринро такрор мекунад |
| Пахши сеқата | {{ui:Select}}: ҳама пайваста |
| {{key:Shift}} + пахш | {{ui:Select}}: ба интихоб ворид ва аз он баромадан |
| {{key:Mod}} + пахш | {{ui:Select}}: ба интихоб илова кардан |
| {{key:Shift}} + {{key:Mod}} + пахш | {{ui:Select}}: аз интихоб баровардан |
| Кашидани тугмаи миёна | Гардиш, бо ҳар абзор |
| {{key:Shift}} + кашидани тугмаи миёна | Ҷойивазкунӣ, бо ҳар абзор |
| Кашидани тугмаи рост | Ҷойивазкунӣ, бо ҳар абзор |
| Чарх | Калонкунӣ ба сӯи нишоннамо |

Меню бо пахши рост вуҷуд надорад.

## Тачпад

Ҷунбиши ду ангушт чӣ кор мекунад, аз {{ui:Settings}} › {{ui:ModelCraft}} › Ғелондан вобаста аст:

| Ишора | Тачпад (ё ҳисобшуда) | Чархи муш |
|---|---|---|
| Ҷунбиши ду ангушт | Гардиш | Калонкунӣ ба сӯи нишоннамо |
| {{key:Shift}} + ҷунбиши ду ангушт | Ҷойивазкунӣ | Калонкунӣ |
| Фишурдан | Калонкунӣ ба сӯи нишоннамо | Калонкунӣ ба сӯи нишоннамо |
| Пахш ва кашидан бо ду ангушт (пахши дуюм нигоҳ дошта) | Ҷойивазкунӣ | Ҷойивазкунӣ |

Нигаред ба [Гардиш, ҷойивазкунӣ ва калонкунӣ](topic:orbit-pan-zoom#on-a-trackpad) ва [Танзимоти ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Экрани сенсорӣ

| Ишора | Кор мекунад |
|---|---|
| Пахши сабук | Пахш бо абзори ҷорӣ |
| Пахши дукарата | Пахши дукарата |
| Фишурдан, кашидан, бардоштан | Мисли фишурдан, кашидан, раҳо кардан бо муш |

| Се ангушт: якҷоя ҳаракат | Гардиш (Ҷойивазкунӣ, вақте ки ду ангушт гардиш мекунанд) |
| Як ангуштро бе ҳаракат нигоҳ доред | Абзорро тамом мекунад, мисли {{key:Enter}}; агар чизе набошад, сипас кашед, то гардиш |

| Абзори {{ui:Orbit}}, сипас як ангуштро кашед | Гардиш |

Барои навиштани қимат дар экрани сенсорӣ, қуттии арзиши поёнро пахш кунед, нависед ва тугмаи Enter (ё Go) дар клавиатура пахш кунед.

## Ҷойи Move

Move дар абзори {{ui:Move}} ҷойгир аст, тугмаи {{key:M}}: чизеро, ки ҳаракат медиҳед, интихоб кунед, нуқтаи асосиро пахш кунед, сипас нуқтаи дуюмро ё масофаро нависед. Нигаред ба [Кӯчонидан, нусха бардоштан ва массив сохтан](topic:move-copy).
