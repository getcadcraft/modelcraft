ModelCraft เป็นบิลด์ระยะแรก หน้านี้แสดงรายการสิ่งที่ยังไม่ทำ เพื่อให้คุณไม่ต้องไปหาเอง พร้อมวิธีที่ใกล้เคียงที่สุดในการทำงานให้สำเร็จในตอนนี้

## เครื่องมือวาด

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| การวาดแบบอิสระ | คลิกจุดด้วย {{ui:Curve}} |
| การเปลี่ยนจำนวนส่วนของส่วนโค้งหรือวงกลมหลังจากวาดแล้ว | ลบแล้ววาดใหม่หลังพิมพ์ `24s` |
| การเลือกรูปแบบตัวอักษรสำหรับ[ข้อความ 3 มิติ](topic:text3d) หรือการแก้ไขคำหลังจากวางแล้ว | ลบแล้วเพิ่มข้อความใหม่ |
| การเปลี่ยนมุมโดยพิมพ์ลงในไดเมนชันมุม หรือการเปลี่ยนขนาดทรงกระบอกจากไดเมนชันของวงกลม | หมุนขอบด้วย {{ui:Rotate}} แล้วสเกลทรงกระบอกด้วย {{ui:Scale}} |
| ไดเมนชันในไฟล์โมเดลที่ส่งออก | ไดเมนชันจะแสดงในภาพ ภาพพิมพ์ และ PDF ของมุมมอง ส่วนไฟล์โมเดลเก็บเฉพาะรูปทรง |
| ตัดแต่ง แยก และเชลล์นอก | กลุ่มปิดด้วย [รวม หักออก และตัดกัน](topic:solids) หรือ[ตัดกันของหน้า](topic:intersect) แล้วลบส่วนที่ไม่ต้องการ |
| การเลือกแกนหมุนด้วยปุ่มลูกศร | คลิกจุดศูนย์กลางของ {{ui:Rotate}} บนหน้าที่หันไปทางที่แกนควรชี้ |
| การล็อกมากกว่าหนึ่งการอนุมานในเวลาเดียวกัน | ล็อกทิศทางหนึ่งด้วยปุ่มลูกศร แล้วสแนปไปยังจุด |
| การปรับขนาดตามแนวเฉียง หรือจากปลายไดเมนชันที่ไม่อยู่บนมุม | วางไดเมนชันบนสองมุม ตามขอบ หรือตามสีแดง เขียว หรือน้ำเงิน |

## แอนิเมชัน

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| การทำแอนิเมชันหน้า ขอบ เวลาของดวงอาทิตย์ สไตล์ หรือสิ่งที่ซ่อนอยู่ | ทำให้ส่วนที่เคลื่อนไหวเป็นกลุ่มหรือส่วนประกอบ และเรนเดอร์วิดีโอแยกสำหรับเวลาของวันอื่น |
| กล้องที่ตามเส้นทางที่วาดหรือมองไปยังวัตถุที่เคลื่อนที่ | ตั้งคีย์กล้องเพิ่มระหว่างทาง ([แอนิเมต](topic:animation)) |
| เสียงในวิดีโอ และวิดีโอคุณภาพสูง (ไทรซิงแบบเส้นทาง) โดยไม่มี WebGPU | เพิ่มเสียงในโปรแกรมตัดต่อวิดีโอ ถ้าไม่มี WebGPU ให้เรนเดอร์วิดีโอด้วยตัวเรนเดอร์เร็ว ([เรนเดอร์วิดีโอ](topic:animation#render-the-video)) |
| โคมไฟแอนิเมต (ความสว่าง การกระจาย สี) ในวิดีโอที่เรนเดอร์ มุมเลนส์ที่แอนิเมตโดยไม่มีคีย์กล้องในวิดีโอ หรือการแอนิเมตวัสดุหรือการตั้งค่าการเรนเดอร์ | โคมไฟแอนิเมตในมุมมอง และสำหรับวิดีโอ ให้ตั้งคีย์กล้องด้วยสำหรับการซูม และเรนเดอร์วิดีโอแยกสำหรับการตั้งค่าโคมไฟที่ต่างกัน ([แอนิเมตทุกคุณสมบัติ](topic:animate)) |
| การถ่ายโอนน้ำหนักหรือกระดูกจากด้านหนึ่งไปอีกด้าน ซองกระดูกที่มองเห็นได้ การแสดงน้ำหนักแบบแรเงาทีละจุด (แสดงเป็นรายหน้า) หรือการดูเมชที่อยู่ในท่าขณะทาน้ำหนัก | ทาทั้งสองด้าน หรือทำครึ่งหนึ่งแล้วใช้ตัวปรับแบบกระจก (Mirror modifier) ก่อนเพิ่มโครงกระดูก สลับระหว่าง Paint weights และ Pose เพื่อตรวจสอบ |
| กระดูกที่อ่านจากไฟล์ glTF, FBX หรือ USD เป็นโครงกระดูก และโครงกระดูกที่เขียนลงไฟล์เหล่านั้น | โมเดลที่มีโครงกระดูกจะนำเข้าในท่าพักพร้อมน้ำหนักของไฟล์ เพิ่มกระดูกตามลำดับข้อต่อของไฟล์ แล้วกด {{ui:Use the file's weights}} ([แอนิเมต](topic:animate)) |
| การลาก IK target หรือ pole ในมุมมอง พื้นที่ของข้อจำกัด (local หรือ world) ให้เลือก การยืดโซ่ IK หรือ IK ตามเส้นโค้ง | พิมพ์จุดของ target หรือเล็งไปที่วัตถุแล้วเคลื่อนวัตถุนั้น และคงโซ่ไว้ตามความยาวของมัน |
| ผ้า ของเหลว วัตถุนิ่ม ข้อต่อและบานพับระหว่างวัตถุแข็ง การชนกับรูปร่างที่แม่นตรงของวัตถุ (มีเพียงกล่องและลูกบอลที่ล้อมรอบ) การจำลองสดขณะเล่น ความเร็วหรือการหมุนเริ่มต้น (วัตถุเริ่มอยู่นิ่ง) | อบวัตถุแข็งและเล่นคีย์ สร้างบานพับจากคีย์ แยกรูปร่างแปลกเป็นกล่อง (กลุ่ม) |
| ส่งออกแอนิเมชันเป็น glTF หรือไฟล์โมเดลอื่น | เรนเดอร์วิดีโอ ไฟล์ `.modelcraft` และ[ไฟล์ USD](topic:usd) ที่ ModelCraft บันทึกไว้ จะใช้เฉพาะกับ ModelCraft |
| พิมพ์ความเห็นหรือชื่อเรื่องในประเด็นใน VR บันทึกเสียง หรือย้ายระนาบตัดด้วยมือใน VR | วางประเด็นใน VR แล้วเพิ่มข้อความในโปรแกรม BCF ตั้งระนาบตัดในมุมมองก่อนเข้า VR: ดู [ตรวจทานโมเดลในหมวก VR](topic:vr-review) |
| การเห็นคนนั่งโต๊ะใน VR (เห็นเฉพาะคนที่อยู่ใน VR) การบันทึกการเดินใน VR | ขอให้พวกเขาเข้าร่วมใน VR หรือทำ[แอนิเมชัน](topic:animation)ของการเดิน |

## เมช

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| การปั้นตามระดับ (multiresolution) และรายละเอียดที่ลบสามเหลี่ยมที่เล็กมาก | [ปั้น](topic:sculpt)เมชที่แบ่งย่อยแล้ว และ {{ui:Remesh}} เพื่อทำให้สม่ำเสมออีกครั้ง |
| รีเมชเป็นหน้าสี่เหลี่ยมที่ตามรูปร่าง | {{ui:Remesh}} (สามเหลี่ยมสม่ำเสมอ) แล้วสร้างใหม่ด้วย [รีโทโพโลยี](topic:mesh-edit#retopology) |
| น้ำหนักที่ทาบนจุดยอดสำหรับตัวปรับ (Displace, Smooth และ Shrinkwrap ทำงานกับทั้งเมช) | ใช้ตัวปรับ แล้วปั้นหรือแก้ไขส่วนที่ต้องการ |
| การคัดลอกและวางจุดยอด ขอบ หรือหน้า การตัดด้วยมีดที่จบภายในหน้า หรือขอบลวดที่ไม่มีหน้า | ทำสำเนาเมชใน Model มีดตัดจากขอบถึงขอบ และ[ดัน](topic:mesh-edit#change-the-shape)ขอบเปิดให้เป็นหน้า |

## การจัดระเบียบและการดู

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| เลเยอร์ของแผนผังที่ตั้งของ DWG และ DXF เป็นแท็ก | แผนผังที่ตั้งจะนำเข้าเป็นกลุ่มเดียว: ให้ explode แล้วจัดกลุ่มชิ้นส่วนที่ต้องการติดแท็ก |
| การตัดหลายรอบพร้อมกัน กล่องตัด หรือการส่งออกเส้นรอบนอกของการตัดเป็นแบบ | [ระนาบตัด](topic:sections)ตัดได้ทีละหนึ่งครั้ง ส่งออกมุมมองเป็นภาพ |
| การแสดงขอบนุ่มเป็นเส้นประ หรือการทำให้นุ่มขณะลากแถบเลื่อน | [ทำให้นุ่มตามมุม](topic:soften)ใน Entity info และเลิกทำเพื่อลองมุมอื่น |
| คลังโมเดลออนไลน์สำหรับค้นหา หรือส่วนประกอบที่มีตัวเลือก (สี สไตล์) | [คลังเริ่มต้น](topic:starter) นำเข้าโมเดล Collada, OBJ หรือ glTF และ[ยืด](topic:stretch)สำเนาให้ได้ขนาด |
| การวางพืชจากคลังพืช | [กระจาย](topic:live-view#scatter-plants-rocks-and-people)พืชในมุมมองสด หรือวางต้นไม้จากคลังเริ่มต้น |
| สำเนาอิสระของกลุ่ม | ทำให้เป็นส่วนประกอบ แล้ว {{ui:Make unique}} (ดู [การแก้ปัญหา](topic:troubleshooting#editing-one-group-changed-another)) |

## การเรนเดอร์

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| การเรนเดอร์ในมุมมอง (พื้นที่ทำงาน {{ui:Render}}) คิวการเรนเดอร์ และตัวเลือกกล้อง รูปพื้นหลังท้องฟ้า หมอก และการผสมแสงโดยไม่มี WebGPU | {{ui:Render a picture…}} ใน {{ui:High quality}} ใช้ตัวติดตามเส้นทางแบบ WebGL ที่นั่น โดยไม่มีตัวเลือกเหล่านั้น ([เรนเดอร์ภาพ](topic:render#high-quality)) |
| โปรแกรมอื่นวาดภาพจาก Render โดยไม่มีส่วนเสริมเอนจินการเรนเดอร์ (CadCraft ไม่เคยรันโปรแกรมภายใต้ GNU GPL) กล้องพาโนรามาหรือสเตอริโอ และรูปท้องฟ้าผ่านโปรแกรมอื่น ปลั๊กอิน Unreal Engine (ไฟล์ถูกเขียน แต่ปลั๊กอินที่เปิดไฟล์ยังไม่ได้ปล่อย) | เอนจิน Fast และ Path tracer ของเราเอง หรือเอนจินของส่วนเสริม ([วาดภาพด้วยโปรแกรมอื่น](topic:render-other-program)) หรือโฟลเดอร์ไฟล์ USD, glTF หรือ Unreal จากรายการ Engine เพื่อนำไปใช้กับโปรแกรมใดก็ได้ |
| ต้นไม้และหินที่กระจายใน {{ui:Render a picture…}} | แสดงใน[มุมมองสด](topic:live-view) พาโนรามา ตัวดู และวิดีโอของมัน |

## วัสดุและสี

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| อินพุตอื่นนอกจากสีฐาน ความหยาบ โลหะ ความทึบ นอร์มอล และการเปล่งแสงที่เปลี่ยนไปทั่วพื้นผิวในภาพคุณภาพสูง (ใช้ค่าเฉลี่ยแทน) | [สร้างวัสดุด้วยโหนด](topic:shading): เชื่อมต่อได้เลย มุมมองจะแสดงการเปลี่ยนแปลง |
| การแทนที่ (displacement) บนหน้าที่ดันหรือดึง | แปลงวัตถุเป็นเมชเพื่อใช้การแทนที่ |
| การแชร์วัสดุของคุณเองไปยังไลบรารีจากแอป และแผนที่แบบบรรจุ (ARM/ORM) หรือ EXR ในชุดเท็กซ์เจอร์ที่นำเข้า | เก็บไว้ในไฟล์ นำเข้าแผนที่แยกเป็น PNG หรือ JPEG |
| วัสดุของไฟล์ในเซสชัน Live TeamWork (อยู่บนคอมพิวเตอร์ที่สร้างขึ้น) | บันทึกไฟล์และแชร์ |
| ดีคอลที่โค้งตามพื้นผิวโค้ง ดีคอลในการเลิกทำ หรือการทาเท็กซ์เจอร์หลายหน้าพร้อมกันข้ามรอยต่อ | วางดีคอลที่เล็กกว่าบนแต่ละชิ้น ทาแต่ละด้านของรอยต่อแยกกัน |
| การอบบนหน้าที่ดันหรือดึง การอบหลายวัตถุเป็นภาพเดียว กรงที่คุณปั้นด้วยมือ หรือแสงที่อบจากโคมไฟ | แปลงเป็นเมชแล้วคลายรูป อบแต่ละวัตถุ เพิ่มระยะค้นหา หรือเรนเดอร์ภาพสำหรับแสงโคมไฟ |
| การทาความหยาบ โลหะ หรือความสูง การทาด้วยรูปภาพ (สแตมป์) และการทาเท็กซ์เจอร์ที่ใหญ่กว่า 512 × 512 | ทาสีฐานที่นี่ สร้างแผนที่อื่นในโปรแกรมแก้ภาพ แล้วนำเข้าเป็นชุดเท็กซ์เจอร์ |
| เท็กซ์เจอร์ในการส่งออก Collada, STL, PLY, 3MF, IFC, DWG และ DXF และกราฟโหนดของวัสดุของไฟล์ในโมเดลที่ส่งออก | รูปแบบเหล่านั้นได้สีของแต่ละวัสดุ glTF และ OBJ เก็บเท็กซ์เจอร์ที่นำเข้า ส่งออกวัสดุเดี่ยวเป็น [MaterialX](topic:shading#materialx) และ[USD](topic:usd) เก็บทั้งโมเดลไว้สำหรับ ModelCraft |
| เท็กซ์เจอร์ในไฟล์ Collada | นับและละไว้ตอนนำเข้า เท็กซ์เจอร์ในไฟล์ `.skp` และ `.glb` จะนำเข้ามาได้ |

## ไฟล์

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| การบันทึกไฟล์ SketchUp และข้อความกับไดเมนชันจากไฟล์นั้น | [นำเข้า](topic:import-sketchup-files)เก็บหน้า สี และเท็กซ์เจอร์ไว้ ส่งออก Collada (`.dae`) เพื่อกลับไป SketchUp |
| ไดเมนชันและไกด์ในการส่งออก DWG และ DXF | เพิ่มในโปรแกรม CAD หลังการส่งออก |
| จุด ตาราง และ multileader จาก DWG และ DXF | นับและละไว้ ข้อความนำเข้าเป็นตัวอักษรเส้นเดียว ไม่ใช่ฟอนต์ของแบบ |
| พื้นผิว เมช ตาราง และ multileader จาก DWG และ DXF หน้าของโซลิด 3 มิติบนพื้นผิวที่กวาด ลอฟต์ หรือพื้นผิวอิสระอื่น | นับและละไว้เช่นกัน (โซลิด 3 มิติเองจะนำเข้ามา) ส่งออกชิ้นเหล่านั้นจากโปรแกรม CAD เป็น OBJ หรือ Collada แล้วนำเข้า |
| ประเภท คุณสมบัติ หรือวัสดุของ IFC | การส่งออก IFC มี[ชั้น](topic:formats#ifc-ifc)และองค์ประกอบทั่วไป เพิ่มส่วนที่เหลือในโปรแกรม BIM |
| การส่งโมเดลไปยัง BimCraft โดยตรง | ส่งออก {{ui:IFC for BimCraft (.ifc)}} แล้วเปิดใน BimCraft |
| ขอบที่หลวมใน glTF และ STL | ใช้ OBJ หรือ Collada สำหรับงานเส้น |
| วัสดุ glTF และ FBX นอกเหนือจากสีฐาน (โลหะ ความหยาบ แผนที่นอร์มอล กระจก เคลือบใส ขนแกะ…) | อ่านและแสดงรายการไว้ ModelCraft เก็บสีฐานหรือเท็กซ์เจอร์ สร้างลักษณะใหม่ใน[พื้นที่ทำงานการเชดดิ้ง](topic:shading) |
| กระดูก แอนิเมชัน และ morph target ของ glTF | โมเดลที่มีโครงกระดูกจะนำเข้าในท่าพัก แอนิเมตในหน่วย[ไทม์ไลน์](topic:animation) |
| สีและชื่อชิ้นส่วนของแอสเซมบลีจากไฟล์ STEP | ชิ้นส่วนนำเข้าเป็นเมชที่ขนาดจริง [ทาสี](topic:paint)และตั้งชื่อหลังนำเข้า |
| วัตถุ SubD ข้อความ ไดเมนชัน และแสงจากไฟล์ `.3dm` | ดู[สิ่งที่ถูกละไว้](topic:import-3dm-files#what-is-left-out-and-said) แปลง SubD เป็นเมชในโปรแกรมที่สร้างไฟล์ |
| เท็กซ์เจอร์ KTX2 และ material variant ใน glTF | ส่งออกด้วยเท็กซ์เจอร์ PNG หรือ JPEG จะใช้ variant เริ่มต้น |
| การเขียน glTF instancing (EXT_mesh_gpu_instancing) | ส่วนประกอบจะเขียนครั้งเดียวและวางหลายครั้ง ซึ่งทุกตัวดูอ่านได้ |
| แอนิเมชัน Alembic (ทุกตัวอย่างของแคช) จุดและเส้นโค้ง Alembic หรือการเขียน Alembic | ตัวอย่างแรกจะนำเข้า แอนิเมตในหน่วย[ไทม์ไลน์](topic:animation) เขียนเป็น glTF, USD หรือ OBJ |
| แผนที่ bump และ normal ในวัสดุ OBJ | เฉพาะภาพสี (`map_Kd`) ที่นำเข้า |
| กระดูกและแอนิเมชัน FBX การส่งออก FBX ไฟล์ FBX 6 | โมเดลที่มีโครงกระดูกนำเข้าในท่าพัก ส่งออกเป็น glTF บันทึกไฟล์เก่าเป็น FBX 2011 หรือใหม่กว่า |
| skin, morph, กล้อง, แสง, การหมุนแบบ look-at และ skew ของ Collada และการอ้างอิงภายนอก | ละไว้ตอนนำเข้าและนับในข้อความ |
| ไฟล์สำรอง | {{ui:Save as}} ({{key:Mod+Shift+S}}) บันทึกสำเนาอีกชุด หลังจากขัดข้อง ModelCraft จะเสนองานที่ยังไม่ได้บันทึกคืนให้ ("กู้คืนงานของคุณ?") |
| การบันทึกบนคลาวด์และการซิงก์ระหว่างคอมพิวเตอร์ | ยังไม่พร้อมใช้งาน บันทึกไฟล์ไว้ในคอมพิวเตอร์ แล้วคัดลอกไปยังที่ที่ต้องการ |

## การพิมพ์ 3 มิติ

| ยังไม่มี | ทำแทนได้ในตอนนี้ |
|---|---|
| ซัพพอร์ตของโปรแกรมสไลซ์จริง (อินเทอร์เฟซ แพ เช่นรูปแบบซัพพอร์ตที่แน่นอน) | [ตัวอย่างซัพพอร์ต](topic:print-tools#supports-preview) แสดงตำแหน่งและปริมาณโดยประมาณ ตัวอย่างในโปรแกรมสไลซ์ของคุณแสดงของจริง |
| การแก้ชิ้นส่วนที่ทะลุตัวเอง หรือขอบที่พบกันของสามหน้าขึ้นไป | [ซ่อมแซม](topic:print-tools#repair) แสดงรายการพร้อมตำแหน่ง ใช้[ตัดกันของหน้า](topic:intersect) และลบส่วนที่อยู่ข้างใน |
| รูปแบบอินฟิลและโครงตาข่ายภายในส่วนกลวง | [ทำให้กลวง](topic:print-tools#hollow) ทิ้งไว้ว่าง โปรแกรมสไลซ์ของคุณจะเพิ่มอินฟิลให้ชิ้นส่วนทึบ |
| รายละเอียดที่เล็กเกินหัวฉีดของคุณ (นอกเหนือจากผนัง) | [ความหนาผนัง](topic:print-tools#wall-thickness) หาผนังบาง ตัวอย่างชั้นของโปรแกรมสไลซ์จะแสดงส่วนที่เหลือ |

## ประสิทธิภาพ

การเลิกทำเก็บสำเนาของโมเดลไว้ทุกขั้น ([เมช](topic:meshes) เก็บเฉพาะส่วนที่เปลี่ยน) ดังนั้นการนำเข้าขนาดใหญ่ของรูปทรงที่ดันหรือดึงจะทำให้ทุกการแก้ไขช้าลง ควรนำเข้าให้กระชับ และบันทึกแล้วเปิดใหม่เพื่อล้างประวัติ

## แอปและแพลตฟอร์ม

- **เดสก์ท็อป:** ModelCraft ทำงานในเบราว์เซอร์บน Mac, Windows และ Linux และใน CadCraft Studio ซึ่งเป็นแอปเดสก์ท็อปที่มีแอปทั้งแปดในการติดตั้งเดียว บน Android ติดตั้ง CadCraft Studio จาก APK ที่ getcadcraft.com/download ยังไม่มีบิลด์สำหรับ iPad หรือ iPhone
- **สัมผัส:** ดู [หมุนมุมมอง แพน และซูม](topic:orbit-pan-zoom) สำหรับท่าทางนิ้ว แรงกดของปากกาจะกำหนดแปรงใน [ปั้น](topic:sculpt) ส่วนที่อื่นไม่ใช้แรงกดและการเอียงปากกา
- **แผ่นงาน:** ModelCraft [พิมพ์หนึ่งมุมมองต่อหน้า](topic:export-model#print-the-view-or-save-it-as-a-pdf) ไม่มีเลย์เอาต์แผ่นงานที่มีหลายมุมมองหรือตารางชื่อเรื่อง ส่งออกเป็น DWG/DXF ที่ CadCraft ใช้ได้สำหรับแบบที่มีสเกล
