**ตัวปรับแต่ง** เปลี่ยนสิ่งที่เมชแสดงโดยไม่เปลี่ยนตัวเมชเอง สะท้อนครึ่งหนึ่งของชิ้นส่วนและสร้างเฉพาะครึ่งนั้น หรือทำกล่องให้มนด้วยพื้นผิวแบ่งย่อยและยังแก้ไขกล่องได้ต่อ ตัวปรับแต่งอยู่ใน**สแต็ก** และทำงานตามลำดับจากบนลงล่าง สิ่งที่เห็น ส่งออก พิมพ์ และเรนเดอร์ คือเมชที่มีตัวปรับแต่งทุกตัวที่เปิดอยู่

## เพิ่มตัวปรับแต่ง

1. เลือกเมช ในพื้นที่ทำงานโมเดล ส่วน **ตัวปรับแต่ง** อยู่ใน {{ui:ข้อมูลองค์ประกอบ}}; ในพื้นที่ทำงานเมชจะอยู่ในพาเนลด้านขวา
2. เลือกหนึ่งตัวจาก {{ui:เพิ่มตัวปรับแต่ง…}} มันจะไปอยู่ล่างสุดของสแต็ก
3. ปรับการตั้งค่าใต้ชื่อ ความยาวใช้ค่าเดียวกับกล่องค่า ดังนั้น `600mm`, `2'6"` และ `(6m)/4` ใช้ได้ทั้งหมด

การเปลี่ยนแปลงแต่ละครั้งเป็นหนึ่งขั้นเลิกทำ: {{key:Mod+Z}} เลิกทำได้

## ปุ่มในตัวปรับแต่งแต่ละตัว

- ช่องทำเครื่องหมายเปิดหรือปิดตัวปรับแต่ง
- ปุ่มหน้าจอจะแสดงหรือซ่อนในมุมมอง (ตัวปรับแต่งยังคงอยู่ในสแต็ก)
- ปุ่มกล้องจะแสดงหรือซ่อนในภาพเรนเดอร์และวิดีโอ ทำให้ตัวปรับแต่งใช้เฉพาะตอนเรนเดอร์ได้ (หรือเฉพาะมุมมอง)
- ลูกศรเลื่อนตัวปรับแต่งขึ้นหรือลงในสแต็ก ลำดับสำคัญ: สะท้อนแล้วแบ่งย่อยจะได้รอยต่อที่เรียบ แบ่งย่อยแล้วสะท้อนจะไม่ได้
- {{ui:นำไปใช้}} ทำให้รูปร่างเป็นส่วนหนึ่งของเมช: ตัวปรับแต่งที่อยู่ด้านบนและตัวนี้จะถูกทำกับเมชจริงและออกจากสแต็ก เป็นหนึ่งขั้นเลิกทำ
- กากบาทจะลบตัวปรับแต่งนั้นออก

## ตัวปรับแต่ง

| ตัวปรับแต่ง | ทำอะไร |
|---|---|
| มาตราส่วน | ปรับขนาดรอบจุดกำเนิดของวัตถุ ด้วยตัวคูณสำหรับแดง เขียว และน้ำเงิน ใช้กับกลุ่มหรือคอมโพเนนต์ได้ด้วย |
| สะท้อน | เพิ่มสำเนาที่สะท้อนข้ามแดง เขียว หรือน้ำเงิน ผ่านจุดกำเนิดของเมช และเชื่อมครึ่งทั้งสองตรงที่มาบรรจบ |
| อาร์เรย์ | คัดลอกเป็นเส้นตรง (ขั้นละขนาดของมันคูณจำนวนที่ให้ บวกขั้นคงที่) เป็นวงรอบแกน หรือตามเส้นโค้งในโมเดล กลุ่มหรือคอมโพเนนต์ใช้เส้นตรงได้ |
| พื้นผิวแบ่งย่อย | ทำให้เมชเรียบด้วยการแบ่งย่อยแบบ Catmull-Clark ขอบคมยังคงเป็นรอยพับ การเรนเดอร์ใช้ระดับได้มากกว่ามุมมอง |
| ลบมุม | ทำให้ขอบทุกเส้นที่คมกว่ามุมที่กำหนดโค้งมน |
| ทำให้เป็นของแข็ง | ทำให้พื้นผิวมีความหนา และปิดขอบ |
| บูลีน | ตัด รวม หรือเก็บส่วนที่ซ้อนทับกับวัตถุอื่นในโมเดล ทั้งสองต้องเป็นโซลิดปิด |
| เลื่อนพื้นผิว | เลื่อนพื้นผิวเข้าหรือออกด้วยนอยส์เรียบ ค่า seed เดียวกันให้ปุ่มนูนเดิมทุกครั้ง |
| เชื่อม | รวมจุดยอดที่อยู่ใกล้กว่าระยะที่กำหนด |
| ลดความละเอียด | เก็บสัดส่วนของสามเหลี่ยมไว้ โดยตัดตัวที่เปลี่ยนรูปทรงน้อยที่สุดออก |
| ทำให้เรียบ | ผ่อนจุดยอดเข้าหาเพื่อนบ้าน |
| แลตทิซ | ดัดเมชด้วยกรง: เลื่อนจุดของกรงแล้วเมชจะตาม |
| ดัดตามเส้นโค้ง | ดัดเมชตามเส้นโค้งในโมเดล ตามแดง เขียว หรือน้ำเงิน |
| หดให้พอดี | เลื่อนทุกจุดยอดไปยังจุดที่ใกล้ที่สุดของวัตถุอีกชิ้น |

## บนกลุ่มหรือคอมโพเนนต์

กลุ่มหรือคอมโพเนนต์ก็เก็บสูตรไว้ได้เช่นกัน ดังนั้นร่มโคมไฟอาจเป็น **มาตราส่วน** และ **อาร์เรย์** ของร่มหนึ่งใบ และการเปลี่ยนตัวเลขจะเปลี่ยนโคมไฟ

1. เลือกกลุ่มหรือคอมโพเนนต์ ใน {{ui:ข้อมูลองค์ประกอบ}} ส่วน **ตัวปรับแต่ง** จะแสดงสแต็ก (ว่างตอนแรก)
2. เลือก {{ui:มาตราส่วน}} หรือ {{ui:อาร์เรย์}} จาก {{ui:เพิ่มตัวปรับแต่ง…}} กลุ่มจะกลายเป็นคอมโพเนนต์ที่เป็น**ต้นฉบับ วางด้วยสแต็ก** ต้นฉบับยังคงอยู่: แก้ไขมัน และทุกสำเนาจะตามทันที
3. มาตราส่วนรับตัวคูณสำหรับแดง เขียว และน้ำเงิน (`1, 1, 2` ทำให้สูงเป็นสองเท่า) อาร์เรย์รับจำนวนสำเนา ขั้นเป็นสัดส่วนของขนาดผลลัพธ์ ณ ตอนนั้น และขั้นเพิ่มเติมเป็นความยาว

สแต็กทำงานจากบนลงล่าง บนแกนของต้นฉบับเองรอบจุดกำเนิด ลำดับจึงสำคัญ: อาร์เรย์สามสำเนาห่างกัน 3 m แล้วมาตราส่วน 2 บนแดง จะทำให้สำเนาห่างกัน 6 m; มาตราส่วนก่อนแล้วอาร์เรย์ จะคงระยะห่าง 3 m ช่องทำเครื่องหมาย ลูกศร และกากบาททำงานเหมือนบนเมช ส่วนปุ่มหน้าจอ ปุ่มกล้อง และปุ่ม{{ui:นำไปใช้}}บนตัวปรับแต่งทีละตัว ไม่ทำงาน เพราะสแต็กบนกลุ่มเป็นสิ่งเดียว

- {{ui:แก้ไขต้นฉบับ}} เปิดต้นฉบับในที่เดิม การเปลี่ยนแปลงจะเห็นในทุกสำเนา เมื่อปิดจะกลับไปยังจุดที่อยู่
- {{ui:อบตัวปรับแต่ง}} ทำให้ผลลัพธ์เป็นขอบและหน้าธรรมดา และนำสแต็กออก เป็นหนึ่งขั้นเลิกทำ สำเนาที่ซ้อนกันจะยังคงเป็นรูปทรงแยกกัน: การอบไม่ใช่การรวม
- สำเนาของคอมโพเนนต์ใช้สูตรร่วมกัน {{ui:ทำให้เป็นของตัวเอง}} แยกสูตรออก (ต้นฉบับยังคงใช้ร่วม)
- สแต็กถูกบันทึกในไฟล์ และติดตามไปพร้อมการคัดลอกและวาง และการเลิกทำ การล้างรายการที่ไม่ได้ใช้ยังคงต้นฉบับไว้ โปรแกรมที่ไม่รู้จักตัวปรับแต่งยังคงแสดงสำเนาได้
- ก่อนการอบ ผลลัพธ์จะเข้าไปแก้ไข ถอดประกอบ ปรับขนาด หรือยืดไม่ได้: มันจะถูกสร้างใหม่ในการเปลี่ยนแปลงครั้งถัดไป แต่ละอย่างจะแจ้งไว้
- ขีดจำกัดคือ 32 ตัวปรับแต่ง และ 1,000 สำเนา คอมโพเนนต์ที่สร้างให้ยืด (Stretch) และสแต็กยังไม่สามารถใช้นิยามร่วมกันได้

## พื้นผิวแบ่งย่อย

การแบ่งย่อยทำให้เมชเรียบด้วย Catmull-Clark: ทุกหน้ากลายเป็นหน้าสี่เหลี่ยม และแต่ละระดับทำให้มากขึ้นสี่เท่า กล่องที่มีสองหรือสามระดับจะดูเป็นรูปทรงมน และยังแก้ไขกล่องได้ต่อ

- **ระดับในมุมมอง** กำหนดความเรียบ
- **ระดับในภาพเรนเดอร์** กำหนดความเรียบของภาพเรนเดอร์และวิดีโอ การเรนเดอร์ใช้ระดับได้มากกว่ามุมมอง
- **การเรนเดอร์บนพื้นผิวเรียบจริง** ทำให้จุดของเมชที่เรนเดอร์อยู่บนพื้นผิวลิมิตที่ระดับมุ่งไป ดังนั้นแม้สองระดับก็เรนเดอร์เรียบเท่าหลายระดับ
- **รอยพับ** ทำให้ขอบคม: ในพื้นที่ทำงานเมช เลือกขอบแล้วใช้ {{ui:รอยพับ}} (1 คม, 0.5 โค้งเล็กน้อย, 0 เรียบ) ดู [แก้ไขเมช](topic:mesh-edit)
- **ลดระดับมุมมองของเมชขนาดใหญ่:** เมื่อระดับที่ขอจะให้หน้ามากกว่าที่เครื่องนี้จัดการได้ดี มุมมองจะแสดงระดับที่ต่ำกว่าและบอกว่าเป็นระดับใด {{ui:นำไปใช้}} ใช้ทุกระดับเสมอ จำนวนหน้าที่กำหนดโดยคลาสของ[เครื่องนี้](topic:your-machine)ในการตั้งค่า › การเรนเดอร์ › เครื่องนี้
- ขอบเปิดยังคงมุมของมันไว้และอยู่บนเส้นของขอบ

## ดัดด้วยกรงแลตทิซ

1. เพิ่มตัวปรับแต่ง {{ui:แลตทิซ}} แล้วกด {{ui:เพิ่มกรงแลตทิซรอบเมช}} กรง 3 × 3 × 3 จุดจะปรากฏรอบเมช วาดเป็นเส้น
2. เปิดกรงในพื้นที่ทำงานเมช (ดับเบิลคลิก) แล้วย้ายจุดของมัน เมชจะตามอย่างราบรื่น

:::tip
กรงเป็นเมชเหมือนอื่น ๆ ให้ซ่อนด้วยแท็กเมื่อทำเสร็จ
:::

## เมชขนาดใหญ่

สแต็กเล็กคำนวณทันที สแต็กใหญ่จะคำนวณเบื้องหลังบนทุกคอร์ของคอมพิวเตอร์: มุมมองจะยังแสดงผลลัพธ์ก่อนหน้าจนกว่าผลใหม่จะพร้อม บูลีนจะโหลดตัวสร้างโซลิดในครั้งแรก มุมมองจะแจ้งเรื่องนี้ชั่วครู่

## สิ่งที่ตัวปรับแต่งยังทำไม่ได้

- น้ำหนักต่อจุดยอด (การลดทอนที่ทาบนเมช) สำหรับ เลื่อนพื้นผิว, ทำให้เรียบ และหดให้พอดี
- ตัวปรับแต่งอื่นนอกจากมาตราส่วนและอาร์เรย์เชิงเส้นบนรูปทรงดัน-ดึง (กลุ่มและคอมโพเนนต์): แปลงเป็นเมชก่อน ({{ui:แปลงเป็นเมช}}) สะท้อน อาร์เรย์แบบวงหรือโค้ง ดัด และเรียว บนกลุ่มจะมาทีหลัง
