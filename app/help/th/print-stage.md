{{ui:ขั้นตอนการพิมพ์}} จะจัดวางงานบนแท่นพิมพ์ของเครื่องพิมพ์ สไลซ์ และส่งไปยังเครื่องพิมพ์ คุณไม่ต้องส่งออกไฟล์ก่อน ฟีเจอร์นี้เป็นของส่วนเสริม 3D Print ซึ่งเปิดอยู่โดยค่าเริ่มต้น

:::note
ยังไม่เคยพิมพ์งานบนเครื่องพิมพ์จริงด้วยฟีเจอร์นี้ ตัวสไลเซอร์เป็นของใหม่: ให้ดูเลเยอร์แรกๆ ของงานพิมพ์แรก และใช้ตัวอย่างเลเยอร์ก่อนส่ง
:::

## สิ่งที่จะทำ

วางโมเดลบนแท่นพิมพ์ ตรวจว่าพอดีหรือไม่ ดูเลเยอร์ที่สไลซ์แล้ว แล้วส่งไปยังเครื่องพิมพ์หรือบันทึก G-code

## ขั้นตอน

1. คลิก {{ui:ขั้นตอนการพิมพ์}} บนแถบเครื่องมือ การ์ดจะเปิดซ้อนบนมุมมอง และเส้นประจะแสดงแท่นพิมพ์
2. ภายใต้ **เพิ่มจากคลังไลบรารี** พิมพ์ชื่อในช่องค้นหา กด {{ui:ค้นหา}} แล้วกด {{ui:เพิ่ม}} ที่ผลลัพธ์ รายการจะไปอยู่บนแท่นพิมพ์ในขนาดเต็ม หรือย่อลงให้พอดี สิ่งที่วาดหรือนำเข้าไว้แล้วและมองเห็นได้ในมุมมอง ก็จะอยู่บนแท่นพิมพ์ด้วยเช่นกัน
3. ภายใต้ **อยู่บนแท่นพิมพ์** ตรวจขนาดของแต่ละรายการ รายการที่มี **อยู่นอกแท่นพิมพ์** ต้องย้าย ย้าย หมุน และปรับขนาดสิ่งต่างๆ ในมุมมองด้วยเครื่องมือปกติ
4. กด {{ui:จัดเรียงบนแท่นพิมพ์}} เพื่อกระจายรายการออก หรือ {{ui:พอดีทั้งหมดบนแท่นพิมพ์}} เพื่อย่อให้พอดี
5. ภายใต้ **เครื่องพิมพ์ของคุณ** เลือกขนาด **แท่นพิมพ์** หรือหนึ่งในโปรไฟล์เครื่องพิมพ์
6. ภายใต้ **การตั้งค่าการพิมพ์** เลือก **วัสดุ** **คุณภาพ** และ **อินฟิล %** และทำเครื่องหมาย **เพิ่มซัพพอร์ตใต้ส่วนที่ยื่นออก** หากรูปทรงต้องการ
7. กด {{ui:ตัวอย่างเลเยอร์}} และเลื่อนตัวเลื่อน **เลเยอร์** เพื่อดูเลเยอร์ที่สไลซ์แล้ว หากเปลี่ยนขั้นตอนหรือการตั้งค่าภายหลัง ให้กด {{ui:ตัวอย่างเลเยอร์}} อีกครั้ง
8. ภายใต้ **การเชื่อมต่อ** เลือก {{ui:สาย USB}}, {{ui:Klipper (Moonraker)}}, {{ui:OctoPrint}} หรือ {{ui:PrusaLink}} สำหรับ USB กด {{ui:เชื่อมต่อ}} สำหรับเครื่องพิมพ์ผ่านเครือข่าย ให้พิมพ์ **ที่อยู่** (และ **API key** หากถาม) แล้วกด {{ui:ทดสอบการเชื่อมต่อ}}
9. กด {{ui:ส่งไปยังเครื่องพิมพ์ 3D}} การ์ดจะถามว่าแท่นพิมพ์ว่างและโหลดวัสดุที่ถูกต้องแล้วหรือไม่ และจะแสดงเวลา วัสดุ และอุณหภูมิ ยืนยันเพื่อส่ง

จะมีข้อความแจ้งว่าเครื่องพิมพ์กำลังเริ่มทำงาน {{ui:หยุดการพิมพ์}} จะปิดฮีตเตอร์ พัดลม และมอเตอร์ หากต้องการเพียงไฟล์ ให้กด {{ui:บันทึก G-code แทน}}

## หมายเหตุ

- USB ต้องใช้ Chrome หรือ Edge บนคอมพิวเตอร์ และหน้าเว็บต้องเปิดอยู่จนกว่าการพิมพ์จะจบ การปิดหน้าจะหยุดการส่งข้อมูล
- เครื่องพิมพ์ผ่านเครือข่ายต้องอนุญาตเว็บไซต์นี้ (ใน Moonraker ให้เพิ่มลงใน `cors_domains`; ใน OctoPrint ให้เปิด CORS และคัดลอก API key) เบราว์เซอร์ของคุณอาจถามเพื่อเข้าถึงอุปกรณ์ในเครือข่ายของคุณ
- จะไม่มีการเชื่อมต่อหรือส่งใดๆ หากไม่ได้คลิกก่อน
- รายการสไลเซอร์อยู่ภายใต้ **สไลเซอร์** {{ui:CadCraft basic (รวมมาให้ เร็วที่สุด)}} มีอยู่ในตัวแล้ว Kiri:Moto, PrusaSlicer, OrcaSlicer และ Bambu Lab P2S เป็นส่วนเสริมของตัวเอง ที่คุณเปิดได้จากการ์ดหรือภายใต้ {{ui:การตั้งค่า}} › {{ui:ส่วนเสริม}} PrusaSlicer และ OrcaSlicer ใช้สำเนาของคุณเอง และทำงานจาก CadCraft Studio บนคอมพิวเตอร์
- ชิ้นที่ไม่ใช่ของแข็งปิดจะถูกละไว้ และการ์ดจะบอกว่ารูปทรงส่วนนั้นมีมากเพียงใด
- สำหรับเครื่องพิมพ์เรซิน ดู [สไลซ์สำหรับเครื่องพิมพ์เรซิน](topic:resin-printing) หากต้องการตรวจหรือซ่อมแซมโมเดลก่อน ดู [ซัพพอร์ต ความหนาผนัง การทำให้กลวง และการซ่อมแซม](topic:print-tools)
