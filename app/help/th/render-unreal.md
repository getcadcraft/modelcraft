ใน CadCraft Studio รายการ{{ui:เอนจิน}}สามารถเก็บ**ลิงก์**ไปยังโปรเจกต์ Unreal Engine ได้ ทางเดียวเท่านั้น คือจาก CadCraft ไปยัง Unreal

## ส่งฉาก

1. เลือกรายการ Unreal ในรายการ{{ui:เอนจิน}} ครั้งแรก Studio จะขอให้คุณเลือกโฟลเดอร์ของโปรเจกต์ (โฟลเดอร์ที่มีไฟล์ `.uproject`) และจะจำไว้
2. คลิก {{ui:ส่ง}} Studio จะเขียน `CadCraft/<file name>/` ภายในโปรเจกต์ ได้แก่ ฉากเป็นไฟล์ USD ไฟล์การตั้งค่า โปรไฟล์ไฟ และไฟล์เลเยอร์ขนาดเล็กสองไฟล์
3. เปลี่ยนโมเดล บันทึก แล้วส่งอีกครั้ง มีเพียงฉากและไฟล์การตั้งค่าเท่านั้นที่ถูกแทนที่

## การแก้ไขของคุณปลอดภัย

สเตจที่ Unreal เปิดคือเลเยอร์รากขนาดเล็กที่สร้างครั้งเดียว มีเลเยอร์สองชั้นอยู่ข้างใต้ ชั้นบนคือ**ของคุณ** (`<name>.user.usda` ว่างตั้งแต่แรก และ CadCraft ไม่เขียนทับเลย) และฉากของ CadCraft อยู่ด้านล่าง การแก้ไขที่คุณบันทึกลงเลเยอร์ของคุณจะคงอยู่เมื่อส่งฉากอีกครั้ง ไฟและแอคเตอร์อื่นที่คุณวางในเลเวลของ Unreal อยู่นอกสเตจ และก็ไม่ถูกแตะต้องเช่นกัน

## โดยไม่ใช้ Studio

ในเบราว์เซอร์ หรือบนคอมพิวเตอร์ที่ Studio หา Unreal ไม่พบ ให้เลือก **โฟลเดอร์โปรเจกต์ Unreal (.zip)** ในรายการ{{ui:เอนจิน}} แล้วคลิก {{ui:เรนเดอร์}} ระบบจะบันทึกโฟลเดอร์เดียวกันเป็นไฟล์ zip ให้แตกไฟล์ลงในโฟลเดอร์ `CadCraft` ของโปรเจกต์ ครั้งแรกให้เปิด **รวมไฟล์สเตจ** ไว้ ส่วนการบันทึกครั้งต่อไปให้ปิดออก เพื่อให้ไฟล์ zip มีเพียงฉากและไฟล์การตั้งค่า และเลเยอร์ของคุณจะไม่ถูกแทนที่

:::note
ส่วนเสริม Unreal ที่เปิดสเตจ ใช้ดวงอาทิตย์ โคมไฟ กล้อง และการรับแสง ติดตามการส่งแต่ละครั้ง และเรนเดอร์จากกล้อง **ยังไม่ได้เผยแพร่** และยังไม่เคยรันใน Unreal จนกว่าจะเผยแพร่ ระหว่างนี้ ส่ง จะวางไฟล์ไว้ในโปรเจกต์ และเครื่องมือ USD ของ Unreal เองสามารถเปิดไฟล์เหล่านั้นได้ ระบบ Windows มาก่อน ตามด้วย macOS
:::
