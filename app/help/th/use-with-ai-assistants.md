## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียนเอง) ทำงานร่วมกับ ModelCraft และวิธีตัดสินใจว่าผู้ช่วยจะแตะต้องอะไรได้บ้าง

ModelCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใดเลย คุณนำผู้ช่วยมาเอง: โปรแกรมใดก็ได้ที่รองรับ Model Context Protocol (MCP) ModelCraft เพียงให้เครื่องมือแก่ผู้ช่วย และคุณเป็นผู้เลือกว่าจะให้เครื่องมือใดบ้าง

## เปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนเฟืองในแถบแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:ModelCraft}}
2. ภายใต้ {{ui:ผู้ช่วย}} ทำเครื่องหมาย **ให้ผู้ช่วย AI และสคริปต์ใช้ ModelCraft** สวิตช์นี้ปิดอยู่จนกว่าคุณจะเปิด
3. เลือกสิ่งที่ผู้ช่วยทำได้: **อ่าน** ถูกทำเครื่องหมายไว้เป็นค่าเริ่มต้น ให้ทำเครื่องหมาย **แก้ไข** **บันทึก** หรือ **ส่งออก** เฉพาะเมื่อคุณต้องการ

เครื่องมือที่อยู่นอกสิทธิ์ที่คุณทำเครื่องหมายจะไม่ถูกเสนอให้ผู้ช่วย และหากผู้ช่วยขอใช้เครื่องมือนั้นอยู่ดี ModelCraft จะปฏิเสธและบันทึกไว้ในบันทึกกิจกรรม การปิดสวิตช์จะยกเลิกการเชื่อมต่อทั้งหมดในทันที และ{{ui:รีเซ็ตการตั้งค่า ModelCraft}} ก็ปิดสวิตช์นี้ด้วย

## เชื่อมต่อผู้ช่วยของคุณ

ผู้ช่วยจะเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ: Studio รันเซิร์ฟเวอร์ขนาดเล็กที่มีเพียงคอมพิวเตอร์เครื่องนี้เข้าถึงได้ และป้องกันด้วยโทเคนที่สร้างใหม่ทุกครั้งที่เริ่มทำงาน ใน Studio เลือก {{ui:เชื่อมต่อผู้ช่วย}} แล้วคัดลอกที่อยู่และโทเคนไปใส่ในผู้ช่วยของคุณ (Studio จะแสดงการตั้งค่าที่ต้องวางให้เห็น) ห้ามแชร์โทเคนเด็ดขาด

:::note
เบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้: ในแอปบนเบราว์เซอร์ สวิตช์จะไม่มีผลจนกว่าคุณจะใช้ CadCraft Studio บนคอมพิวเตอร์ของคุณ
:::

## คุณยังคงควบคุมอยู่

- **ทุกการเปลี่ยนแปลงคือหนึ่งขั้นของการเลิกทำ** มีป้ายชื่อตามชื่อที่ผู้ช่วยตั้งให้ (เช่น "ผู้ช่วย: กล่อง") {{key:Mod+Z}} จะเลิกทำการเปลี่ยนแปลงล่าสุดของผู้ช่วยทั้งชุด
- **คุณรู้ได้เมื่อมีการเชื่อมต่อ** ปุ่มในแถบแอปจะแสดงชื่อผู้ช่วยขณะที่เชื่อมต่ออยู่ คลิกเพื่อดูว่าผู้ช่วยทำอะไรได้ หรือเพื่อ **ตัดการเชื่อมต่อ**
- **กิจกรรม** {{ui:การตั้งค่า}} › {{ui:ModelCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงทุกการเรียกใช้: เมื่อใด เครื่องมือใด สำเร็จหรือถูกปฏิเสธ {{ui:บันทึกบันทึกกิจกรรม}} จะเก็บสำเนาไว้

## ผู้ช่วยขออะไรได้บ้าง

| เครื่องมือ | สิทธิ์ | สิ่งที่ทำ |
|---|---|---|
| `app_info`, `model_describe` | อ่าน | หน่วย ขนาด และทุกกลุ่มและองค์ประกอบของโมเดลพร้อมตำแหน่ง ว่าเป็นโซลิดปิดหรือไม่ และปริมาตร |
| `view_screenshot` | อ่าน | ภาพของมุมมอง 3D ตามที่แสดงอยู่ |
| `box_add`, `cylinder_add` | แก้ไข | กล่องหรือทรงกระบอกเป็นกลุ่มใหม่ ที่ตำแหน่งและขนาดที่คุณหรือผู้ช่วยระบุ ("3m", "10'" หรือตัวเลขในหน่วยของโมเดล) |
| `instance_move`, `instances_erase` | แก้ไข | ย้ายหรือลบกลุ่มและองค์ประกอบ |
| `faces_list`, `materials_list` | อ่าน | หน้าของกลุ่มหรือของรูปทรงอิสระ (ทิศทาง พื้นที่ และจุดศูนย์กลางของแต่ละหน้า) วัสดุและสีที่ใช้ทาได้ |
| `push_pull` | แก้ไข | ดันหรือดึงหน้า เหมือนที่ {{ui:ดัน/ดึง}} ทำ |
| `paint` | แก้ไข | ทาหน้าหรือทั้งกลุ่มด้วยสีหรือวัสดุ |
| `group_make` | แก้ไข | สร้างกลุ่มหรือองค์ประกอบจากหน้าและกลุ่มที่เป็นรูปทรงอิสระ |
| `scene_add`, `scene_show` | แก้ไข | บันทึกมุมมองเป็นฉาก; ไปยังฉากที่บันทึกไว้ |
| `mesh_add` | แก้ไข | วัตถุเมชเพื่อเริ่มต้น (ลูกบาศก์ ทรงกลม ทรงกระบอก ...) ตามที่พื้นที่ทำงานเมชเพิ่ม |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | อ่าน / แก้ไข | สแต็กตัวปรับแต่งของเมช: สะท้อน อาร์เรย์ การแบ่งย่อย เบเวล และอื่น ๆ ไม่มีการนำไปใช้อย่างถาวร |
| `usd_export` | ส่งออก | โมเดลเป็น OpenUSD (.usda, .usdc หรือ .usdz) เหมือนที่การบันทึกโมเดลเป็น USD เขียน ([USD](topic:usd)) ไปยังโฟลเดอร์ที่คุณอนุญาตใน Studio มิฉะนั้นจะดาวน์โหลด |
| `render_still` | ส่งออก | ภาพเรนเดอร์ของมุมมองหรือของฉากที่บันทึกไว้ เหมือนปุ่ม {{ui:เรนเดอร์}} ในกล่องโต้ตอบ {{ui:เรนเดอร์}} โดยใช้การตั้งค่าการเรนเดอร์ของคุณ เว้นแต่ผู้ช่วยจะขอค่าอื่น (พรีเซ็ตฉาก: ภายนอก ภายใน ภาคตัด กลางคืน หรืออัตโนมัติ; เร็วหรือคุณภาพสูง ขนาด จำนวนตัวอย่าง ท้องฟ้า) เป็นไฟล์ PNG ที่ผู้ช่วยดูได้ หรือเป็นไฟล์ PNG, EXR หรือไฟล์เรนเดอร์ในโฟลเดอร์ที่คุณอนุญาตใน Studio ([เรนเดอร์ภาพ](topic:render)) |
| `render_queue` | ส่งออก | เพิ่มภาพคุณภาพสูงลงในคิวของกล่องโต้ตอบ {{ui:เรนเดอร์}} (มุมมอง หรือฉากที่บันทึกไว้) แล้วรันคิว ภาพที่เสร็จจะไปยังโฟลเดอร์ที่คุณอนุญาต หรือคงอยู่ใน {{ui:คิวการเรนเดอร์}} ของกล่องโต้ตอบไว้ให้คุณ ต้องใช้ WebGPU |
| `link_push` | แก้ไข | อัปเดตโมเดลที่เชื่อมโยงมาจากโปรแกรมอื่น (ดู [ทำให้โมเดล .3dm อัปเดตสด](topic:live-3dm-link)) |
| `link_status` | อ่าน | บอกว่าโมเดลที่เชื่อมโยงยังอยู่หรือไม่ และอัปเดตล่าสุดเมื่อใด |
| `undo` | แก้ไข | เลิกทำขั้นตอนของตัวเอง |

โซลิดที่ผู้ช่วยสร้างจะเข้ามาเป็นกลุ่ม จึงไม่มีวันรวมกับสิ่งที่คุณวาด ไม่มีเครื่องมือใดบันทึกโมเดลได้: การบันทึกเป็นหน้าที่ของคุณ และการส่งออกหรือการเรนเดอร์ต้องทำเครื่องหมาย **ส่งออก** ไว้ การเรนเดอร์ไม่เปลี่ยนแปลงอะไรในโมเดล การเรนเดอร์ฉากที่บันทึกไว้จะย้ายมุมมองไปยังฉากนั้น เหมือนที่ {{ui:ฉาก}} ทำ

## หากมีบางอย่างไม่ทำงาน

- **ผู้ช่วยไม่เห็นเครื่องมือของ ModelCraft:** ตรวจสอบว่าสวิตช์เปิดอยู่ในหน้าต่างนี้ และหน้าต่างเปิดอยู่ใน Studio
- **"needs the edit permission":** ทำเครื่องหมาย **แก้ไข** ภายใต้ {{ui:ผู้ช่วย}} แล้วถามอีกครั้ง
- **ข้อผิดพลาด "401" หรือ "token":** โทเคนเปลี่ยนไปแล้ว (Studio เริ่มใหม่ หรือ {{ui:โทเคนใหม่}}) คัดลอกโทเคนใหม่ไปใส่ในการตั้งค่าของผู้ช่วย
