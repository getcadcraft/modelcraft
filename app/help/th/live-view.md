{{ui:Export}} › {{ui:Live view}} เปิดพาเนลเหนือแอปที่แสดงโมเดลในลักษณะเรียลไทม์: ท้องฟ้าและดวงอาทิตย์ตามตำแหน่งและวันที่ของโมเดล เงาจากดวงอาทิตย์ ลักษณะและวัสดุที่กำหนดให้กับหน้า โคมไฟ และแสงที่สะท้อนจากผนังและพื้น มันทำตามสิ่งที่ทำ: หมุนมุมมองแล้วมันก็หมุนตาม เปลี่ยนโมเดลแล้วจะแสดงการเปลี่ยนแปลงในอีกสักครู่ ไม่มีการอัปโหลดข้อมูลใด ๆ

## เปิดมุมมอง

1. เลือก {{ui:Export}} › {{ui:Live view}} พาเนลจะเปิดที่มุมล่างขวา
2. ลากแถบชื่อเพื่อย้าย ดึงมุมเพื่อขยาย
3. {{ui:New window}} ย้ายไปเป็นหน้าต่างของตัวเอง สำหรับจอที่สอง {{ui:Export}} › {{ui:Live view in a new window}} จะเปิดในหน้าต่างใหม่ทันที หากเบราว์เซอร์บล็อกหน้าต่างป๊อปอัป มุมมองจะเปิดเป็นพาเนลแทน
4. {{ui:Close}} ปิดมุมมอง

## การควบคุม

| การควบคุม | ทำอะไร |
|---|---|
| {{ui:Follow the view}} | เปิด: มุมมองแบบ live มองไปทางเดียวกับมุมมองของ ModelCraft การเดินจะปิดตัวนี้ |
| {{ui:Walk}} | เดินผ่านโมเดล (ด้านล่าง) |

| {{ui:Time}} | ชั่วโมงของวัน ตั้งแต่ 05:00 ถึง 21:00 ดวงอาทิตย์เคลื่อนที่ขณะลาก |
| {{ui:Month}} | เดือน (วันที่ 21 ของเดือนนั้น) เพื่อดูดวงอาทิตย์ในฤดูหนาวและฤดูร้อน |

บรรทัดด้านล่างแสดงตัวที่วาดมุมมอง (WebGPU หรือ WebGL 2) ระดับคุณภาพ และแสงสะท้อน

## เดินผ่านโมเดล

1. หมุนมุมมองหลักไปยังจุดที่ต้องการยืน แล้วเลือก {{ui:Walk}} การยืนจะอยู่บนพื้นต่ำกว่าจุดมองของมุมมอง สูง 1.6 m
2. คลิกมุมมองแบบ live แล้วใช้ {{key:W}} {{key:A}} {{key:S}} {{key:D}} หรือปุ่มลูกศร กด {{key:Shift}} เพื่อวิ่ง ลากเพื่อมองรอบตัว
3. ขั้นบันไดสูงไม่เกิน 40 cm จะปีนได้ (บันได) ส่วนที่สูงกว่านั้นเป็นผนัง ผนังจะหยุดการเดินและเลื่อนไปตามผนัง
4. เมื่อปิด {{ui:Gravity}} จะบิน: {{key:E}} ขึ้น {{key:Q}} ลง
5. {{key:Esc}} หยุดการเดิน

## โปรยพืช หิน และผู้คน

{{ui:Scatter}} ในแถบของมุมมองแบบ live จะเปิดพาเนลการโปรยข้างภาพ ชุดการโปรยจะกระจายรายการจากไลบรารี entourage (ต้นไม้ พุ่มไม้ หญ้า ดอกไม้ หิน ผู้คน รถยนต์) ลงบนบางส่วนของโมเดล รายการเหล่านี้วาดเฉพาะในมุมมองแบบ live: มันไม่ใช่รูปทรงในโมเดล และมุมมองหลักจะไม่แสดงมัน

1. **เติมหน้า:** เลือกหน้า (หรือกลุ่ม เช่นภูมิประเทศ) ใน ModelCraft แล้วเลือก {{ui:Fill selection}} ชุดนั้นจะครอบคลุมหน้าเหล่านั้น
2. **ทาสี:** เลือก {{ui:Paint}} แล้วลากบนมุมมองแบบ live หากเลือกหน้าไว้ การทาสีจะลงเฉพาะหน้าที่เลือก หากไม่ได้เลือกอะไร จะลงบนทุกอย่างที่อยู่ใต้แปรง รวมถึงพื้นดิน {{ui:Brush size}} กำหนดขนาดแปรง {{ui:Eraser}} ลบจุดที่ทาสีออก
3. ทำเครื่องหมายรายการที่จะโปรย ตัวเลขข้างแต่ละรายการคือน้ำหนัก: 3 และ 1 หมายถึงรายการแรกสามชิ้นต่อรายการที่สองหนึ่งชิ้น

| การควบคุม | ทำอะไร |
|---|---|
| {{ui:Per m²}} | จำนวนรายการต่อ m² |
| {{ui:Keep away (m)}} | ไม่วางรายการใกล้วัตถุอื่นกว่าค่านี้ และไม่วางใต้หลังคาหรือโต๊ะ 0 คือปิด |
| {{ui:Turn (°)}} | รายการแต่ละชิ้นหมุนแบบสุ่มรอบแกนตั้งมากเพียงใด |
| {{ui:Steepest (°)}} | ไม่วางรายการในที่ที่พื้นผิวชันกว่านี้ |
| {{ui:Size}} | ขนาดเล็กที่สุดและใหญ่ที่สุด เป็นตัวคูณของขนาดรายการนั้นเอง |
| {{ui:Height from, to (m)}} | วางเฉพาะระหว่างความสูงเหล่านี้ (ว่าง = ทุกความสูง) |
| {{ui:Lean with the surface}} | 0 ให้รายการตั้งตรง; 1 ให้ตั้งฉากกับความลาด |
| {{ui:Seed}}, {{ui:Shuffle}} | ค่าเริ่มต้นสุ่มเดิมจะได้การโปรยเดิมเสมอ; {{ui:Shuffle}} เลือกชุดอื่น |

ชุดการโปรยจะถูกบันทึกในไฟล์ `.modelcraft` และตามหน้าที่ครอบคลุมไว้เมื่อมีการเปลี่ยนแปลง จำนวนรายการสูงสุดที่มุมมองแบบ live วาดขึ้นอยู่กับระดับของ[เครื่องนี้](topic:your-machine): 20 000 สำหรับ {{ui:Processor only}}, 100 000 สำหรับ {{ui:Graphics card, basic}}, หนึ่งล้านสำหรับ {{ui:Graphics card, high}} พาเนลจะแสดงจำนวนที่วางได้เทียบกับจำนวนที่ความหนาแน่นต้องการ จะวางได้น้อยลงเมื่อถึงงบประมาณ หรือเมื่อวัตถุกันไม่ให้วาง รายการที่อยู่ใกล้กล้องจะวาดเป็นรูปจริง ส่วนรายการที่อยู่ไกลจะวาดเป็นรูปทรงง่าย ๆ ตามสีของมัน

:::note
รายการที่โปรยอยู่ในมุมมองแบบ live (และการเดินชม พาโนรามา และตัวดูแบบสแตนด์อโลน) การเรนเดอร์ภาพยังไม่วาดรายการเหล่านี้
:::

## แชร์: พาโนรามา ทัวร์ ตัวดู วิดีโอ

{{ui:Share}} ในแถบของมุมมองแบบ live สร้างไฟล์จากมุมมองแบบ live ทุกอย่างถูกสร้างบนคอมพิวเตอร์เครื่องนี้ ไม่มีการอัปโหลด

| ตัวเลือก | สิ่งที่ได้ |
|---|---|
| {{ui:360° panorama}} | ภาพ 360° จากตำแหน่งที่มุมมองยืนอยู่ (หรือตำแหน่งที่กำลังเดิน) เป็น PNG แบบ equirectangular ที่ตัวดูพาโนรามาและเว็บไซต์ภาพส่วนใหญ่เปิดได้ |
| {{ui:Add this spot to the tour}}, then {{ui:Save the tour}} | หน้าเว็บหนึ่งหน้าที่มีพาโนรามาในแต่ละจุด และลูกศรไปยังจุดที่แต่ละจุดมองเห็นได้ (ผนังที่อยู่ระหว่างจะซ่อนลูกศร) |
| {{ui:Save a viewer}} | หน้าเว็บหนึ่งหน้าที่มีโมเดลในลักษณะเรียลไทม์นี้: หมุนดู เดินผ่าน และกระโดดไปยังฉากที่บันทึกไว้ เปิดแบบออฟไลน์ในเบราว์เซอร์ที่รองรับ WebGPU หรือ WebGL 2 จากโฟลเดอร์ แฟลชไดรฟ์ USB หรืออีเมลได้ ไม่ต้องติดตั้งและไม่ต้องมีบัญชี และไม่โหลดอะไรจากอินเทอร์เน็ต |
| {{ui:Video of the path}} | เส้นทางกล้องของไทม์ไลน์ (หรือฉากที่บันทึกไว้เรียงตามลำดับ) เป็นวิดีโอในลักษณะเรียลไทม์นี้ ที่ขนาดเท่ามุมมองแบบ live: WebM หรือ MP4 ตามที่เบราว์เซอร์สร้างได้ ไม่เช่นนั้นเป็นภาพลำดับในไฟล์ ZIP |

ขนาดของพาโนรามาขึ้นอยู่กับคุณภาพ: กว้าง 1024, 2048 หรือ 4096 พิกเซล สำหรับระดับ ต่ำ ปานกลาง และ สูง ไฟล์ตัวดูมีขนาดประมาณ 5 MB บวกกับโมเดล

:::note
ทัวร์และตัวดูถูกทำขึ้นเพื่อการแสดงผล ไม่ใช่เพื่อการแก้ไข เมื่อบันทึก พวกมันจะเก็บโมเดลไว้ตามที่เป็นอยู่
:::

## แสงสะท้อน

แสงที่สะท้อนจากผนังที่โดนแดดลงสู่พื้น และส่วนที่มืดกว่าภายในห้อง คำนวณด้วยตัวติดตามเส้นทาง (path tracer) ตัวเดียวกับที่สร้าง[ภาพเรนเดอร์](topic:render) มันเรนเดอร์พาโนรามาขนาดเล็กที่จุดต่าง ๆ ในโมเดล ทำงานเบื้องหลังบนทุกคอร์ของโปรเซสเซอร์ ขณะทำงาน บรรทัดล่างจะแสดง {{ui:แสงสะท้อน: 40 %}} เมื่อพร้อมแล้ว มุมมองจะนำไปใช้ หลังการเปลี่ยนแปลงจะเริ่มใหม่

:::note
นี่คือการประมาณค่าสำหรับมุมมองแบบ live ไม่ใช่ภาพเรนเดอร์: รายละเอียดเล็ก ๆ ระหว่างจุดจะได้รับแสงสะท้อนจากจุดที่อยู่ใกล้ ๆ สำหรับภาพสำเร็จรูป ให้ใช้[เรนเดอร์ภาพ](topic:render)
:::

## ความสว่างและสี

มุมมองแบบ live ใช้ความสว่าง สมดุลสีขาว คอนทราสต์ และการแปลงมุมมองแบบเดียวกัน (ACES, AgX, filmic หรือ standard) กับ[เรนเดอร์ภาพ](topic:render) ตั้งค่าที่นั่น แล้วมุมมองแบบ live จะตาม

:::note
เบราว์เซอร์แต่ละตัวต่างกัน ที่ใดที่เบราว์เซอร์มี WebGPU (Chrome และ Edge บน Windows, macOS และ ChromeOS, Safari 26) มุมมองแบบ live จะใช้ WebGPU ที่อื่น (เบราว์เซอร์ส่วนใหญ่บน Linux และระบบ Apple รุ่นเก่า) จะใช้ WebGL 2 และให้ผลลัพธ์เหมือนกัน
:::
