ขณะที่เครื่องมือวาดหรือแก้ไขทำงาน ModelCraft จะดูสิ่งที่อยู่ใต้ตัวชี้ และสแนปไปยังสิ่งที่มีประโยชน์ที่สุดในบริเวณใกล้เคียง เครื่องหมายจะแสดงสิ่งที่พบ และปลายตัวชี้ที่มุมล่างซ้ายจะระบุชื่อ

## เครื่องหมายและปลายตัวชี้

| ปลายตัวชี้ | เครื่องหมาย | สแนปไปยัง |
|---|---|---|
| ปลาย | วงกลมสีเขียว | ปลายของขอบ |
| จุดกึ่งกลาง | วงกลมสีฟ้า | กลางของขอบ |
| จุดศูนย์กลางของหน้า | วงกลมสีน้ำเงิน | กลางของหน้าใต้ตัวชี้ |
| จุดไกด์ | สีเทา | จุดไกด์ที่เครื่องมือวัดระยะทิ้งไว้ |
| จุดกำเนิด | สีโอเคอร์ | จุดที่แกนสีแดง เขียว และน้ำเงินมาบรรจบกัน |
| บนแกนสีแดง / บนแกนสีเขียว / บนแกนสีน้ำเงิน | เส้นในสีนั้น | เส้นจากจุดเริ่มไปตามทิศทางนั้น |
| ขนานกับขอบ / ตั้งฉากกับขอบ | เส้นสีม่วงแดง | เส้นจากจุดเริ่มที่ขนานหรือตั้งฉากกับขอบที่จำไว้ (ดูด้านล่าง) |
| ล็อก | เส้นสีม่วงแดง | ทิศทางที่ล็อกด้วยปุ่มลูกศรหรือ {{key:Shift}} |
| บนขอบ | สี่เหลี่ยมสีแดง | ตำแหน่งใดก็ได้บนขอบ |
| บนไกด์ | สีเทา | ตำแหน่งใดก็ได้บนเส้นไกด์ |
| บนหน้า | ข้าวหลามตัดสีน้ำเงิน | ตำแหน่งใดก็ได้บนหน้า |
| บนระนาบ | ไม่มี | ระนาบที่เริ่มต้น เมื่อตัวชี้อยู่เหนือพื้นที่ว่าง |
| บนพื้น | ไม่มี | พื้น (ระนาบสีแดง-เขียว) เมื่อไม่มีอย่างอื่นอยู่ตรงนั้น |

เมื่อเส้นแกนจากจุดเริ่มตัดกับขอบหรือไกด์ ModelCraft จะสแนปไปยังจุดตัดนั้น และปลายตัวชี้จะระบุทั้งสองอย่าง เช่น "บนแกนสีแดง, บนขอบ"

## สแนปใดชนะ

1. **จุด** ภายในประมาณ 12 พิกเซล: ปลายก่อน จากนั้นจุดไกด์ จุดกึ่งกลาง จุดศูนย์กลางของหน้าใต้ตัวชี้ และจุดกำเนิด
2. **ทิศทาง** จากจุดเริ่ม: แกนสีแดง เขียว และน้ำเงิน และขนานหรือตั้งฉากกับขอบที่จำไว้
3. **บนขอบ** หรือบนเส้นไกด์
4. **บนหน้า**
5. **ระนาบวาด** หรือพื้น

สิ่งที่ซ่อนอยู่หลังหน้าจะไม่สแนปเลย หมุนมุมมองเพื่อให้เห็นจุดที่ต้องการ

## วาดบนหน้าจากจุด

{{ui:Rectangle}}, {{ui:Circle}} หรือ {{ui:Polygon}} ที่เริ่มจากมุม จุดกึ่งกลาง ขอบ หรือจุดศูนย์กลางของหน้า จะถูกวาด**บนระนาบของหน้าใต้ตัวชี้** และตัดหน้านั้น ขอบหนึ่งเส้นเป็นของสองหน้า ดังนั้นด้านของขอบที่ตัวชี้อยู่จะเป็นตัวกำหนด: หากต้องการวาดบนปลายของกล่องยาว ให้เริ่มจากจุดกึ่งกลางของขอบหนึ่งของกล่อง โดยให้ตัวชี้อยู่ด้านในของหน้าปลาย

## ขนานและตั้งฉาก

ModelCraft จะจำ**ขอบสุดท้ายที่ตัวชี้ผ่านก่อนการคลิกครั้งแรก** การเริ่มที่มุมหรือบนขอบนับว่าผ่านขอบนั้น เมื่อเครื่องมือทำงานแล้ว ขอบอื่นที่ชี้ผ่านจะไม่มาแทนที่

หากต้องการวาดเส้นขนานกับขอบที่มีอยู่:

1. กด {{key:L}} แล้วชี้ไปที่ขอบที่ต้องการให้ตรงกัน
2. เลื่อนไปยังจุดเริ่ม โดยไม่ข้ามขอบอื่นระหว่างทางหากทำได้ แล้วคลิก
3. เลื่อนในทิศทางขนานกับขอบนั้น เส้นจะเปลี่ยนเป็นสีม่วงแดงและปลายตัวชี้จะแสดง "ขนานกับขอบ" การตั้งฉากทำงานในลักษณะเดียวกัน ภายในระนาบที่กำลังวาด

หากจำขอบผิด ให้กด {{key:Esc}} ชี้ไปที่ขอบที่ถูกต้อง แล้วเริ่มใหม่

## ล็อกทิศทาง

หลังจากคลิกครั้งแรกของเครื่องมือ สามารถให้จุดถัดไปอยู่บนเส้นเดียวได้:

| ปุ่ม | ล็อกไปยัง |
|---|---|
| {{key:Right}} | แกนสีแดง |
| {{key:Left}} | แกนสีเขียว |
| {{key:Up}} | แกนสีน้ำเงิน (ตั้งตรงขึ้น) |
| {{key:Down}} | ขนานกับขอบที่จำไว้ (ดูด้านบน) |

กดลูกศรเดิมอีกครั้งเพื่อปลดล็อก แถบสถานะแสดง "ล็อกไปยังแกนสีแดง กดลูกศรเดิมเพื่อปลดล็อก"

ขณะล็อก จุดจะเลื่อนไปตามเส้นไปยังตำแหน่งที่ตัวชี้อยู่ และยังคงเรียงตรงกับจุดที่ชี้ผ่าน: ชี้ที่มุมของกล่องอีกอันเพื่อวาดเส้นตามแนวแดงให้ยาวเท่ากับระยะถึงมุมนั้นพอดี

**{{key:Shift}}** ล็อกทิศทางที่สแนปอยู่ในขณะนั้น (แกน หรือขนาน) ตราบเท่าที่กดค้างไว้ ปล่อยเพื่อปลดล็อก

การล็อกใช้ได้ใน {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} และ {{ui:Tape}} ก่อนการคลิกครั้งแรก ปุ่มลูกศรจะหมุนมุมมองแทน

## ภายในกลุ่ม

ขณะแก้ไขภายในกลุ่มหรือชิ้นส่วน แกนจะเป็นแกนของกลุ่มเอง (เคลื่อนที่ไปพร้อมกลุ่ม และหมุนตามหากกลุ่มถูกหมุน) การสแนปยังพบจุดและขอบภายนอกกลุ่ม จึงจัดแนวสิ่งต่าง ๆ ให้ตรงกับส่วนอื่นของโมเดลได้
