นี่คือปุ่มแบบดัน/ดึง ซึ่งเป็นปุ่มที่ ModelCraft เริ่มต้นด้วย สำหรับอีกรูปแบบ ดู[ปุ่มแบบ Modeler](topic:keyboard#modeler-keys) ด้านล่าง และ[การตั้งค่า ModelCraft](topic:settings)

ปุ่มลัดทำงานเมื่อมุมมอง 3D หรือปุ่มบนแถบเครื่องมือมีโฟกัส หากเพิ่งพิมพ์ในช่องของพาเนลหรือเปลี่ยนรายการใน {{ui:Style}} ให้คลิกที่มุมมอง 3D ก่อน มิฉะนั้นปุ่มจะไปที่ช่องนั้น ดู[ปุ่ม เมาส์ และแทร็กแพด](common:keys) เพื่อดูวิธีเขียนปุ่มในคอมพิวเตอร์แต่ละเครื่อง

## Esc

{{key:Esc}} จะถอยหนึ่งระดับทุกครั้งที่กด:

1. ยกเลิกสิ่งที่เครื่องมือกำลังทำค้างอยู่ (เส้นที่กำลังวาด การดัน/ดึง หรือการย้าย) ทุกอย่างจะกลับคืน
2. สลับไปที่ {{ui:Select}}
3. ล้างการเลือก
4. ปิดกลุ่มที่กำลังแก้ไข

นอกจากนี้ยังหยุดการเล่นฉาก ในกล่องค่า {{key:Esc}} จะล้างสิ่งที่พิมพ์และกลับไปที่มุมมอง

## ขณะที่เครื่องมือทำงาน

| ปุ่ม | ทำหน้าที่ |
|---|---|
| ตัวเลข หรือหนึ่งใน `. , - ' " [ < * /` | เริ่มพิมพ์ในกล่องค่า |
| {{key:Enter}} | ใช้ค่าที่พิมพ์ในกล่องค่า |
| {{key:Right}} | ล็อกไปยังแกนสีแดง (กดอีกครั้งเพื่อปลดล็อก) |
| {{key:Left}} | ล็อกไปยังแกนสีเขียว (กดอีกครั้งเพื่อปลดล็อก) |
| {{key:Up}} | ล็อกไปยังแกนสีน้ำเงิน (กดอีกครั้งเพื่อปลดล็อก) |
| {{key:Down}} | ล็อกขนานกับขอบสุดท้ายที่ชี้ผ่านก่อนการคลิกครั้งแรก |
| กดค้าง {{key:Shift}} | ยึดทิศทางที่สแนปอยู่ ขณะกดค้าง |
| {{key:Ctrl}}, {{key:Mod}} หรือ {{key:Alt}} (Move) | สลับระหว่างการย้ายกับการคัดลอก |

การล็อกด้วยปุ่มลูกศรใช้ได้ใน {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} และ {{ui:Tape}} (เมื่อวัดจากจุด) หลังการคลิกครั้งแรก {{ui:Push/pull}} จะเคลื่อนที่ตามทิศทางของหน้าเสมอและไม่มีการล็อก ใน {{ui:Rotate}} ปุ่มลูกศรจะแสดงข้อความ "ล็อก" หลังการคลิกครั้งแรก แต่จะไม่เปลี่ยนการหมุน

## ปุ่มลูกศรในเวลาอื่น

เมื่อไม่มีเครื่องมือกำลังทำงานค้างอยู่ ปุ่มลูกศรจะเคลื่อนกล้อง:

| ปุ่ม | ทำหน้าที่ |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | หมุนมุมมอง |
| {{key:Shift}} กับปุ่มลูกศร | แพน |

## เมาส์

| การกระทำ | ทำหน้าที่ |
|---|---|
| คลิก | ใช้เครื่องมือปัจจุบัน |
| กด ลาก ปล่อย | เหมือนคลิกสองครั้ง (สำหรับเครื่องมือวาด) การเลือกด้วยกรอบ (สำหรับ {{ui:Select}}) ลบไปตามทาง (สำหรับ {{ui:Eraser}}) |
| ดับเบิลคลิก | {{ui:Select}}: หน้าพร้อมขอบ ขอบพร้อมหน้า หรือเปิดกลุ่ม พื้นที่ว่างจะปิดกลุ่ม {{ui:Push/pull}}: ทำซ้ำระยะล่าสุด |
| คลิกสามครั้ง | {{ui:Select}}: ทุกอย่างที่เชื่อมต่อกัน |
| {{key:Shift}} + คลิก | {{ui:Select}}: สลับเข้าออกจากการเลือก |
| {{key:Mod}} + คลิก | {{ui:Select}}: เพิ่มเข้าในการเลือก |
| {{key:Shift}} + {{key:Mod}} + คลิก | {{ui:Select}}: นำออกจากการเลือก |
| ลากปุ่มกลาง | หมุนมุมมอง ด้วยเครื่องมือใดก็ได้ |
| {{key:Shift}} + ลากปุ่มกลาง | แพน ด้วยเครื่องมือใดก็ได้ |
| ลากปุ่มขวา | แพน ด้วยเครื่องมือใดก็ได้ |
| ล้อเลื่อน | ซูมไปยังตัวชี้ |

ไม่มีเมนูคลิกขวา

## แทร็กแพด

การปัดสองนิ้วทำอะไรขึ้นอยู่กับ {{ui:Settings}} › {{ui:ModelCraft}} › การเลื่อน:

| ท่าทาง | แทร็กแพด (หรือที่คำนวณได้) | ล้อเลื่อนเมาส์ |
|---|---|---|
| ปัดสองนิ้ว | หมุนมุมมอง | ซูมไปยังตัวชี้ |
| {{key:Shift}} + ปัดสองนิ้ว | แพน | ซูม |
| บีบนิ้ว | ซูมไปยังตัวชี้ | ซูมไปยังตัวชี้ |
| กดและลากสองนิ้ว (ค้างการคลิกรอง) | แพน | แพน |

ดู[หมุนมุมมอง แพน และซูม](topic:orbit-pan-zoom#on-a-trackpad) และ[การตั้งค่า ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad)

## หน้าจอสัมผัส

| ท่าทาง | ทำหน้าที่ |
|---|---|
| แตะ | คลิกด้วยเครื่องมือปัจจุบัน |
| แตะสองครั้ง | ดับเบิลคลิก |
| กด ลาก ยก | เหมือนกด ลาก ปล่อยด้วยเมาส์ |
| สองนิ้ว: บีบ | ซูม |
| สองนิ้ว: เลื่อนพร้อมกัน | แพน ({{ui:Settings}} › {{ui:ModelCraft}} › หน้าจอสัมผัส สามารถตั้งให้เป็นการหมุนมุมมองได้) |
| สามนิ้ว: เลื่อนพร้อมกัน | หมุนมุมมอง (แพนเมื่อสองนิ้วหมุนมุมมอง) |
| กดนิ้วเดียวค้างไว้ | จบเครื่องมือ เหมือน {{key:Enter}} เมื่อไม่มีอะไรทำงาน แล้วลากเพื่อหมุนมุมมอง |
| นิ้วที่สองระหว่างการกระทำด้วยนิ้วเดียว | ยกเลิกการกระทำนั้น |
| เครื่องมือ {{ui:Orbit}} แล้วลากนิ้วเดียว | หมุนมุมมอง |

หากต้องการพิมพ์ค่าบนหน้าจอสัมผัส ให้แตะกล่องค่าที่ด้านล่าง พิมพ์ แล้วกดปุ่ม Enter (หรือ Go) ของคีย์บอร์ด

## ที่อยู่ของการย้าย

การย้ายอยู่ในเครื่องมือ {{ui:Move}} ปุ่ม {{key:M}}: เลือกสิ่งที่จะย้าย คลิกจุดฐาน แล้วคลิกจุดที่สอง หรือพิมพ์ระยะ ดู[ย้าย คัดลอก และสร้างอาร์เรย์](topic:move-copy)
