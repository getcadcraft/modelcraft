**พื้นที่ทำงานเมช** แก้ไข[เมช](topic:meshes) ทีละจุด ได้แก่ จุดยอด ขอบ และหน้า รูปทรงดัน-ดึงยังอยู่ในพื้นที่ทำงานโมเดล

## เปิด

- เลือก {{ui:Mesh}} ในรายการ {{ui:Workspace}} ทางซ้ายของแถบเครื่องมือ เมชที่เลือกจะเปิดเพื่อแก้ไข; กลุ่มหรือคอมโพเนนต์ที่เลือกจะถูกแปลงเป็นเมชก่อน (หนึ่งขั้นเลิกทำ)
- หรือดับเบิลคลิกเมช หรือเมื่อใช้คีย์โมเดลเลอร์ ให้เลือกเมชแล้วกด {{key:Tab}}
- เมื่อไม่ได้เลือกอะไร พาเนลจะเสนอเมชให้เพิ่ม: ระนาบ ตาราง ลูกบาศก์ วงกลม ทรงกระบอก กรวย ทรงกลม ไอโคสเฟียร์ และทอรัส เมชใหม่จะวางตรงจุดที่มุมมองมอง และเปิดเพื่อแก้ไข

{{ui:กลับไปที่โมเดล}} (หรือจากรายการ, {{key:Tab}} เมื่อใช้คีย์โมเดลเลอร์, {{key:Esc}} เมื่อไม่ได้เลือกอะไรและใช้คีย์ดัน-ดึง) จะกลับไปที่โมเดลพร้อมเมชที่เลือก ขณะที่พื้นที่ทำงานเมชเปิดอยู่ ส่วนอื่นของโมเดลจะจางลง และเครื่องมือวาดของโมเดลจะถูกเก็บไป

## เลือก

| ทำ | เพื่อ |
|---|---|
| {{key:1}} {{key:2}} {{key:3}} | เลือกจุดยอด ขอบ หรือหน้า |
| คลิก | เลือกหนึ่งรายการ; {{key:Shift}}+คลิก เพิ่มหรือนำออก |
| ลากกรอบ | เลือกสิ่งที่อยู่ในกรอบและมองเห็นได้; {{key:Shift}} เพิ่ม, {{key:Ctrl}} นำออก |
| {{key:Alt}}+คลิกขอบ หรือดับเบิลคลิก | ลูปขอบของมัน (ลูปหน้าในโหมดหน้า; ขอบทั้งหมดของขอบเปิด) |
| {{key:Ctrl}}+{{key:Alt}}+คลิกขอบ | วงแหวนขอบของมัน |
| คลิกสามครั้ง | ทุกอย่างที่เชื่อมกับมัน |

กลุ่ม {{ui:Select}} ยังมี {{ui:ทั้งหมด}}, {{ui:ที่เชื่อมโยง}}, {{ui:ลูป}}, {{ui:วงแหวน}}, {{ui:เพิ่มเติม}} และ {{ui:น้อยลง}}

## ย้าย หมุน สเกล

{{ui:ย้าย}}, {{ui:หมุน}} และ {{ui:มาตราส่วน}} เริ่มจากตัวชี้: เคลื่อนที่ จากนั้นคลิกหรือกด {{key:Enter}} เพื่อวางตัวเลือก หรือ {{key:Esc}} เพื่อยกเลิก {{key:X}}, {{key:Y}} หรือ {{key:Z}} (หรือปุ่มลูกศร) ล็อกแกน พิมพ์ระยะ มุม หรือตัวคูณเพื่อให้ได้ค่าที่แน่นอน [การคำนวณ](topic:value-box#calculations) ใช้ได้ด้วย

**การแก้ไขตามสัดส่วน** ({{ui:สัดส่วน}} หรือในพาเนล): จุดยอดที่อยู่ใกล้ตัวเลือกจะตามการย้าย โดยลดลงเมื่อไกลขึ้น จนถึงระยะที่ตั้งไว้ ด้วยการลดลงที่เลือก เปิด {{ui:ตามแนวเมชเท่านั้น}} เพื่อวัดตามขอบแทนการวัดเป็นเส้นตรง

{{ui:เลื่อน}} เลื่อนลูปขอบที่เลือกไปตามขอบที่อยู่ข้างๆ

## เปลี่ยนรูปร่าง

| เครื่องมือ | ทำอะไร |
|---|---|
| {{ui:Extrude}} | ดึงหน้าที่เลือกออกตามเส้นตั้งฉาก พร้อมหน้าด้านข้างใหม่ (หรือสร้างหน้าจากขอบเปิด) พิมพ์ระยะ |
| {{ui:Inset}} | แถบภายในขอบของหน้าที่เลือก; กด {{key:I}} อีกครั้งสำหรับแต่ละหน้าแยกกัน |
| {{ui:Bevel}} | ตัดขอบที่เลือก (หรือ {{key:Ctrl}}+{{key:Shift}}+{{key:B}} คือจุดยอด) ด้วยความกว้างที่กำหนด ล้อหรือปุ่มบวกและลบจะเพิ่มส่วนเพื่อให้ขอบโค้ง |
| {{ui:Loop cut}} | ชี้ไปที่ขอบ: ลูปใหม่ข้ามวงแหวนของหน้าสี่เหลี่ยม; ล้อกำหนดจำนวนครั้ง คลิกเพื่อตัด |
| {{ui:Knife}} | คลิกจุดบนขอบหรือมุม; {{key:Enter}} ตัดตรงข้ามหน้าระหว่างจุดเหล่านั้น ตามที่เห็น |
| {{ui:Bisect}} | วาดเส้นบนหน้าจอ: หน้าที่เลือก (หรือทั้งหมด) จะถูกตัดตามเส้นนั้น |
| {{ui:Spin}} | หมุนหน้าที่เลือกหรือขอบเปิดรอบแกนสีน้ำเงินเป็นขั้น (ล้อกำหนดขั้น); หมุนครบรอบจะปิด |
| {{ui:Subdivide}} | ตัดขอบที่เลือกเป็นสองส่วน; หน้าทั้งหน้าจะกลายเป็นตาราง |
| {{ui:Merge}} | จุดยอดที่เลือกรวมเป็นหนึ่ง ณ จุดศูนย์กลาง |
| {{ui:Dissolve}} | นำตัวเลือกออกแต่คงพื้นผิวไว้: หน้าเชื่อมต่อกัน |
| {{ui:Fill}} | หน้าข้ามขอบเปิดที่เลือก (หรือระหว่างขอบเปิดสองขอบ) |
| {{ui:Grid fill}} | เติมขอบเปิดที่มีจำนวนขอบเป็นเลขคู่ด้วยตารางของ quad |
| {{ui:Bridge}} | เชื่อมลูปขอบเปิดสองลูปที่เลือกด้วยหน้า |
| {{ui:Crease}} | ขอบที่เลือกจะคมแค่ไหนเมื่อเมชถูกทำให้เรียบด้วยพื้นผิวแบ่งย่อย: เลื่อนออกจากศูนย์กลาง ใช้ล้อ (ขั้นละ 0.1) หรือพิมพ์ค่า 0 ถึง 1 พาเนลแสดงค่ารอยพับของขอบที่เลือกและรับค่าที่พิมพ์ด้วย ขอบรอยพับจะวาดเป็นสีม่วงแดง |
| {{ui:Flip}}, {{ui:Smooth}}, {{ui:Delete}} | พลิกหน้า; ทำให้จุดยอดเรียบเข้าหาเพื่อนบ้าน; ลบตามโหมดการเลือก |

แต่ละอย่างเป็นหนึ่งขั้นเลิกทำ พิกัดพื้นผิว สี และน้ำหนักจะตามไปยังหน้าและจุดยอดใหม่

## สร้างเมชใหม่

{{ui:Remesh}} สร้างเมชทั้งหมดใหม่เป็นสามเหลี่ยมขนาดเท่ากัน ตามขนาดที่กำหนดเมื่อกดปุ่ม (ยิ่งเล็กยิ่งละเอียดและช้า) มันปิดรู รวมชิ้นส่วนที่ทับกัน และปรับเมชที่ถูกยืดจากการปั้นให้เรียบ ขอบคมจะโค้งเล็กน้อย UV สี และรอยพับจะเริ่มใหม่ เป็นหนึ่งขั้นเลิกทำ

## การจัดโครงข่ายใหม่

เพื่อสร้างเมชใหม่ที่สะอาดกว่าทับเมชที่มีรายละเอียด (การปั้นหรือการสแกน) ให้เลือกเมชที่มีรายละเอียดภายใต้ {{ui:การจัดโครงข่ายใหม่ (retopology)}} › **สร้างบน** ในพาเนล จากนั้น:

- **ยึดจุดที่ย้ายบนพื้นผิว:** จุดที่ย้ายและขอบที่เอ็กซ์ทรูดจะไปอยู่บนพื้นผิวของเมชนั้น
- **วางจุดที่เลือกบนพื้นผิวนั้น** ย้ายจุดที่เลือกไปยังพื้นผิวทันที (หนึ่งขั้นเลิกทำ)
- **แสดงขอบของเมชนี้ไว้ด้านหน้า** วาดเมชที่กำลังสร้างทับพื้นผิว เพื่อให้เห็นได้

## ปรับการดำเนินการล่าสุด

หลังจาก {{ui:ออฟเซ็ตเข้า}}, {{ui:ลบมุม}}, {{ui:ตัดลูป}}, {{ui:แบ่งย่อย}}, {{ui:ทำให้เรียบ}}, {{ui:เติมตาราง}} หรือ {{ui:หมุนเวียน}} พาเนลจะแสดงการตั้งค่า (ความกว้าง ส่วน โปรไฟล์ การตัด ...) เมื่อเปลี่ยนค่าใดค่าหนึ่ง การดำเนินการจะทำใหม่จากจุดเริ่มต้น และยังเป็นหนึ่งขั้นเลิกทำ
