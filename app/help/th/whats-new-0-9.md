นี่คือสิ่งที่เปลี่ยนแปลงใน ModelCraft 0.9 เมื่อเทียบกับ 0.8.1 ตอนนี้ ModelCraft เชื่อมต่อถึงเครื่องพิมพ์และพื้นโรงงานแล้ว คุณสามารถวางสิ่งของบนแท่นพิมพ์และส่งโดยไม่ต้องส่งออก สไลซ์สำหรับเส้นฟิลาเมนต์หรือเรซิน และวางผังสายการขนถ่ายวัสดุ นี่คือ CadCraft Studio 0.9 และแอปทั้งแปดของมัน ส่วนเสริมส่วนใหญ่ของฟีเจอร์ใหม่ด้านล่างเป็นส่วนเสริม

## ใหม่

### การพิมพ์ 3 มิติ

- **ขั้นตอนการพิมพ์** คลิก {{ui:ขั้นตอนการพิมพ์}} บนแถบเครื่องมือ เพิ่มรายการในไลบรารีลงบนแท่นพิมพ์ของเครื่องพิมพ์ จัดเรียง ดูชั้นที่สไลซ์แล้ว และกด {{ui:ส่งไปเครื่องพิมพ์ 3 มิติ}} โดยไม่ต้องส่งออก STL ฟีเจอร์นี้เป็นของส่วนเสริม 3D Print ซึ่งเปิดไว้เป็นค่าเริ่มต้น และนำออกได้เหมือนส่วนเสริมอื่น ๆ ดู [วางสิ่งของบนแท่นพิมพ์และส่งไปยังเครื่องพิมพ์](topic:print-stage)
- **ตัวสไลเซอร์เส้นฟิลาเมนต์ของเราเอง** {{ui:CadCraft basic (รวมอยู่แล้ว เร็วที่สุด)}} คือสไลเซอร์ในรายการ **สไลเซอร์** ของการ์ด: ผนัง ผิว การเติม โครงรองรับ และขอบรอบชิ้นงาน ทำงานบนตัวประมวลผลเบื้องหลัง เพื่อให้หน้าเว็บยังใช้งานได้ {{ui:ดูตัวอย่างชั้น}} พร้อมแถบ **ชั้น** แสดงชั้นก่อนส่ง โปรไฟล์เครื่องพิมพ์ เช่นรูปแบบ Ender-3 และ Prusa MK4 มี G-code เริ่มต้นของตัวเอง
- **การส่ง** ผ่าน USB (Chrome หรือ Edge บนคอมพิวเตอร์ โดยหน้าเว็บต้องเปิดค้างไว้) หรือไปยัง Klipper (Moonraker), OctoPrint หรือ PrusaLink บนเครือข่ายของคุณ จะไม่มีการเชื่อมต่อหรือส่งใด ๆ หากไม่มีการคลิก และการส่งจะถามยืนยันก่อนเสมอ
- **สไลเซอร์อื่น** Kiri:Moto, PrusaSlicer และ OrcaSlicer เป็นส่วนเสริมของตัวเอง ปิดอยู่เป็นค่าเริ่มต้น เพิ่มได้จากการ์ดหรือจาก {{ui:การตั้งค่า}} › {{ui:ส่วนเสริม}} PrusaSlicer และ OrcaSlicer ใช้สำเนาที่คุณติดตั้งไว้เองจาก CadCraft Studio ส่วนเสริมเครื่องพิมพ์ Bambu Lab สไลซ์ด้วย OrcaSlicer ของคุณและโปรไฟล์ P2S ของมัน และต้องใช้ Studio บนคอมพิวเตอร์
- **การพิมพ์เรซิน** ส่วนเสริมเรซิน (ปิดเป็นค่าเริ่มต้น) สร้างภาพชั้นสำหรับหน้าจอของเครื่องพิมพ์ พร้อมการทำให้กลวงและรูระบาย ราฟต์และโครงรองรับ การดูตัวอย่างชั้น และเวลา เรซิน และต้นทุน ส่วนเสริมรูปแบบไฟล์เขียนไฟล์ Elegoo GOO, SL1, Chitubox (CBDDLP และ CTB 2 ถึง 5) และ Anycubic (PWMX และ PWS) การทดสอบการรับแสงของเรซินสร้างบันไดการรับแสงห้าค่า ดู [สไลซ์สำหรับเครื่องพิมพ์เรซิน](topic:resin-printing)
- **ไม่เปลี่ยนแปลง** {{ui:ส่งออก}} › {{ui:ตรวจสอบการพิมพ์ 3 มิติ (STL หรือ 3MF)…}} เครื่องมือการพิมพ์ และการแบ่งเพื่อพิมพ์ ทำงานเหมือนเดิมใน 0.8 ดู [เตรียมโมเดลสำหรับการพิมพ์ 3 มิติ](topic:print-3d)

### การไหลของวัสดุ ดิจิทัลทวิน และพื้นโรงงาน

ทั้งสามเป็นส่วนเสริมที่ปิดอยู่จนกว่าคุณจะเปิดใน {{ui:การตั้งค่า}} › {{ui:ส่วนเสริม}} และแต่ละส่วนมีวิธีใช้ของตัวเองเมื่อเปิดแล้ว

- **การไหลของวัสดุ** พาเนลชื่อการไหลของวัสดุวางสายพาน สถานี บัฟเฟอร์ และเส้นทาง AGV ในมุมมอง 3 มิติ รันการจำลองแบบกำหนดค่าเริ่มต้น เล่นย้อนกลับ และแสดงปริมาณงาน เวลารอ และคิว ผลลัพธ์บันทึกเป็น CSV คำสั่งซื้อนำเข้าจากไฟล์ CSV ได้ เซลล์หุ่นยนต์ตรวจสอบและส่งออกได้ การเชื่อมต่อ PLC มีโหมดจำลองและโหมดจริงผ่าน Modbus TCP ซึ่งใช้ได้เฉพาะใน CadCraft Studio
- **ดิจิทัลทวิน** อ่านเลย์เอาต์การไหลของวัสดุและรัน PLC จำลองบนเลย์เอาต์นั้น พร้อมข้อผิดพลาดที่คุณบังคับได้ การทดสอบสต็อก การเปรียบเทียบเลย์เอาต์ และรายการวัสดุ
- **พื้นโรงงาน** เปลี่ยนสถานีให้เป็นเครื่องจักรและเซลล์ อ่านค่าแบบสดหรือจากตัวจำลอง และเก็บคิวงานกับ OEE แบบง่าย ใช้อ่านค่าเท่านั้น บิลด์นี้ไม่สามารถเขียนไปยังเครื่องจักรหรือ PLC ได้

### พื้นผิว โมเดล และการเขียนแบบ

- **ฟิลเลต การทำให้หนา และบูลีนบน NURBS** พาเนล {{ui:พื้นผิว}} มี {{ui:ฟิลเลตระหว่างหน้า}} {{ui:ทำมนหลายขอบ}} {{ui:ทำให้หนาเป็นโซลิด}} และ Union, Subtract และ Intersect ซึ่งแต่ละอย่างมีค่าการเบี่ยงเบนที่วัดได้ ดู [พื้นผิวอิสระ (NURBS)](topic:nurbs-surfaces)
- **พอดีพื้นผิวกับการสแกน** เลือกเมชที่สแกนแล้วใช้ {{ui:ทำให้พื้นผิวพอดีกับการสแกน}} ในกลุ่ม **สแกน** จากนั้น {{ui:เย็บพื้นผิวเป็นโซลิด}} นี่เป็นการพอดีเบื้องต้น ไม่ใช่ชุดเครื่องมือวิศวกรรมย้อนกลับแบบเต็ม
- **การเชื่อมแบบสดจากตัวสร้างโมเดล .3dm** ทางเดียว จาก Rhino 8 หรือ Grasshopper และต้องใช้ CadCraft Studio บนคอมพิวเตอร์เดียวกัน ดู [ทำให้โมเดล .3dm สดอยู่เสมอ](topic:live-3dm-link)
- **ดูโมเดลที่หน้างาน** {{ui:ดูที่หน้างาน (AR, โทรศัพท์)}} ในเมนู {{ui:มุมมอง}} ใช้ได้กับโทรศัพท์ Android ที่มี Chrome ดู [ดูโมเดลที่หน้างานด้วยโทรศัพท์ Android (AR)](topic:ar-on-site)
- **วิธีสร้างส่วนโค้ง** รายการแบบเลื่อนลง {{ui:วิธีสร้างส่วนโค้ง}} มีวิธีวาดส่วนโค้งสิบวิธี รวมถึง {{ui:3 จุด}} และ {{ui:จุดเริ่มต้น, จุดศูนย์กลาง, จุดปลาย}}
- **หน่วยเพิ่มเติม** น้ำหนัก (kg, lb, t, ton) และอุณหภูมิ (องศา C, F, K และ R) เข้าใจได้ในจุดที่คุณพิมพ์ค่าพร้อมหน่วย

## ในทุกแอป

- **ทูลทิป** ข้อความที่แสดงเมื่อชี้เมาส์บนปุ่ม และป้ายที่ถูกตัด เป็นทูลทิปของ Bootstrap
- **เคล็ดลับเริ่มต้นที่ปิดได้** การ์ดเคล็ดลับบนพื้นที่วาดว่างมีปุ่มปิดขนาดเล็กรูปกากบาท มันจะปิดค้างไว้ และ command palette สามารถแสดงให้เห็นอีกครั้งได้
- **แถบแท็บที่เลื่อนได้** แถบแท็บของพาเนลที่ไม่พอดีจะเลื่อนแทนการถูกตัด
- **ชื่อแท็บ** เมื่อมีเอกสารเปิดอยู่ แท็บเบราว์เซอร์จะขึ้นต้นด้วยชื่อเอกสาร ตามด้วย ModelCraft และ CadCraft จุดจะขึ้นนำหน้าเมื่อยังไม่ได้บันทึก
- **เลย์เอาต์** {{ui:การตั้งค่า}} › {{ui:ทั่วไป}} › เลย์เอาต์ เก็บเลย์เอาต์ไว้ในรายการแบบเลื่อนลง พร้อมตัวเลือกให้ใช้เลย์เอาต์เฉพาะแอปนี้ และปุ่มรีเซ็ตเลย์เอาต์
- **ภาษา** รายการภาษาในการตั้งค่าจะตามไฟล์ภาษาที่บิลด์มี ภาษาอื่นที่ไม่ใช่อังกฤษเป็นฉบับแปลด้วยเครื่อง
- **Live และไลบรารี** Live TeamWork แสดงเคอร์เซอร์และชื่อแบบสด และคอลเลกชันไลบรารีให้แต่ละแอปมีคอลเลกชันเริ่มต้นของตัวเอง

## แก้ไขแล้ว

- {{ui:เล่น}} เปลี่ยนเป็น {{ui:หยุดชั่วคราว}} ขณะแอนิเมชันกำลังเล่น และ {{key:Space}} เล่นและหยุดชั่วคราวเมื่อไทม์ไลน์เปิดอยู่
- ภาพเรนเดอร์นิ่งจะถอยกลับไปใช้ WebGL เมื่อการ์ดจอไม่สามารถเริ่ม path tracer ได้ มุมมองเรนเดอร์สดอาจยังแสดงข้อผิดพลาด และยังไม่ได้ตรวจสอบบนเครื่อง Windows ที่ใช้ไดรเวอร์นั้น
- โหมดจริงของการไหลของวัสดุเชื่อมต่อใหม่ได้หลังการเชื่อมต่อสิ้นสุดลงจากคำตอบข้อยกเว้นของ PLC

## ข้อจำกัดที่ควรทราบ

- ยังไม่มีชิ้นงานใดถูกพิมพ์บนเครื่องพิมพ์จริง ไม่ว่าจะเป็นฟิลาเมนต์ เรซิน หรือผ่าน Bambu Connect ไฟล์เรซินถูกอ่านกลับด้วยตัวอ่านของ CadCraft เองเท่านั้น
- ดิจิทัลทวินและพื้นโรงงานได้รับการทดสอบกับตัวจำลองและคำตอบที่ทราบแล้วเท่านั้น ไม่มี PLC, สายการผลิต หรือโปรโตคอลจริง ทั้งสองเป็นเครื่องมือช่วยตรวจสอบ ไม่ใช่การรับรองความปลอดภัย ฟิสิกส์ครอบคลุมเฉพาะกล่องเท่านั้น สูงสุดแปดโหลด
- การเชื่อมต่อ Rhino และ Grasshopper ไม่เคยทำงานในโปรแกรมจริง
- ภาษาอื่นที่ไม่ใช่อังกฤษเป็นฉบับแปลด้วยเครื่อง

## ก่อนหน้า: 0.8 และ 0.8.1

นี่คือสิ่งที่เปลี่ยนแปลงใน ModelCraft 0.8 (2026-11-01) และ 0.8.1 (2026-11-02) เมื่อเทียบกับ 0.7 กล่องโต้ตอบ {{ui:เรนเดอร์ภาพ…}} ตอนนี้ส่งฉากไปยังโปรแกรมอื่นได้ พาเนลพื้นผิวสร้างพื้นผิวอิสระที่เรียบ และผู้ช่วย AI ที่คุณเชื่อมต่อสามารถตั้งค่าฉากทั้งฉากจากประโยคเดียว

### ใหม่

**การเรนเดอร์**

- **ตัวเลือกเอนจิน** {{ui:เรนเดอร์ภาพ…}} มีรายการ **เอนจิน** อยู่เหนือ Mode เอนจินของเราเองสองตัว คือ Fast และ Path tracer เป็นค่าเริ่มต้นและใช้ได้ทุกที่ รายการอื่นจะบันทึกฉากเป็นแพ็กเกจ (โมเดลเป็นไฟล์ USD พร้อมไฟล์การตั้งค่าที่มีค่าวัสดุที่แน่นอน โคมไฟที่เปิดอยู่ ดวงอาทิตย์ ท้องฟ้า การรับแสง และกล้อง) เพื่อนำไปใช้กับโปรแกรมอื่น ภาพที่วาดโดยโปรแกรมอื่นจะระบุว่าโปรแกรมและเวอร์ชันใดเป็นผู้สร้าง ดู [เลือกโปรแกรมที่วาดภาพ](topic:render-engines)
- **เปิดในโปรแกรมอื่น** รายการเอนจินบันทึกฉากเป็นไฟล์ USD ไฟล์ glTF (`.glb`) หรือโฟลเดอร์โปรเจกต์ Unreal (`.zip`) ได้ ทั้งในเบราว์เซอร์และใน CadCraft Studio ใน Studio ยังเริ่ม usdview หรือโปรแกรมของคอมพิวเตอร์สำหรับไฟล์นั้นได้ด้วย ดู [เปิดฉากในโปรแกรมอื่น](topic:render-open-in)
- **ส่งไปยังเอนจินเกม จาก Studio** Studio เขียนฉากลงในโปรเจกต์ Unreal Engine และรักษาให้ตรงกันทุกครั้งที่ส่ง เป็นทางเดียวเท่านั้น การแก้ไขของคุณอยู่ในเลเยอร์ที่ CadCraft ไม่เคยเขียนทับ ดู [ส่งฉากไปยังเอนจินเกม](topic:render-unreal)
- **เอนจินจากส่วนเสริม** ส่วนเสริมเพิ่มเอนจินลงในรายการได้ เอนจินที่เขียนด้วย JavaScript วาดในเบราว์เซอร์และใน Studio เอนจินที่รันโปรแกรมต้องได้รับการยืนยันจากคุณใน Studio ดู [วาดภาพด้วยโปรแกรมอื่น](topic:render-other-program) และ [เพิ่มเอนจินเรนเดอร์ด้วยส่วนเสริม](topic:render-engine-addons)
- **บอกฉาก** บอกผู้ช่วยที่เชื่อมต่อไว้ว่า "พลบค่ำ ฝนปรอย ต้นไม้ฤดูใบไม้ร่วง มีคนอยู่บนลานพลาซ่า" แล้ว ModelCraft จะตั้งค่าให้ในขั้นตอนเดียว ดวงอาทิตย์เลื่อนไปตามวันที่และเวลาเพื่อให้เงาตามไป ท้องฟ้าเปลี่ยน พื้นผิวเปียกปรากฏ และต้นไม้กับคนถูกวางเป็นวัตถุจริงบนแท็กที่คุณซ่อน ย้าย หรือลบได้ เวลาของวัน วันที่หรือฤดูกาล และสภาพอากาศ (ปลอดโปร่ง มีเมฆครึ้ม หมอก ฝนปรอย ฝน พายุ) ก็ใช้ได้เองเช่นกัน และคำขอภายหลังจะเปลี่ยนฉากเดิม หมอกแสดงในภาพคุณภาพสูงบนการ์ดจอ เอนจินอื่นจะแสดงท้องฟ้า แสง และพื้นผิวเปียก ฝนไม่ได้วาดเป็นเส้นตกลงมา

**วัสดุ**

- **วัสดุจากภาพเดียว** ให้ ModelCraft ภาพถ่ายของพื้นผิว (ผนัง พื้น หิน) แล้วจะสร้างวัสดุแบบกระเบื้องซ้ำ แสงทั่วภาพถูกทำให้เรียบ ขอบถูกทำให้ต่อกัน และแผนที่สี แผนที่ความหยาบ และแผนที่ปกติถูกคำนวณจากภาพ เป็นการประมวลผลภาพธรรมดาบนภาพของคุณเอง ไม่มีโมเดลที่ฝึกไว้ ความหยาบเป็นค่าประมาณ ภาพถ่ายตรง เรียบ เป็นสี่เหลี่ยม ให้กระเบื้องที่ดีที่สุด ส่วนลวดลายที่เข้มอย่างอิฐอาจมีเงาจางตรงจุดต่อ

**พื้นผิว**

- **พื้นผิวอิสระ** พาเนล {{ui:พื้นผิว}} สร้างเส้นโค้ง NURBS และพื้นผิวที่ไม่ได้ตัด: เส้นโค้งผ่านจุด ลอฟต์ ruled ดึงออก หมุนรอบแกน สวีปตามรางหนึ่งหรือสองราง พื้นผิวจากเครือข่ายเส้นโค้ง แพตช์จากสี่ขอบ การจับคู่ และการผสม ทุกขอบร่วมถูกวัดเป็น G0, G1 หรือ G2 (ช่องว่าง มุม การเปลี่ยนความโค้ง) บนพื้นผิวที่แน่นอน ขอบที่แย่กว่าที่คุณขอจะแสดงในพาเนลปัญหาพร้อมการแก้ไข **จับคู่** ลายซีบราและสีความโค้งถูกวาดจากพื้นผิวที่แน่นอน ไฟล์ STEP และ IGES ส่งออกและนำเข้าได้ ดู [พื้นผิวอิสระ (NURBS)](topic:nurbs-surfaces)

**ไซต์และห้อง**

- **ภาพร่างเป็นพื้นดิน** {{ui:ไฟล์}} › {{ui:นำเข้าภาพถ่ายสเกตช์…}} แปลงภาพถ่ายโทรศัพท์ของภาพร่างด้วยมือให้เป็นเส้นขอบบนพื้นดินในมาตราส่วนที่คุณระบุ เป็นหนึ่งกลุ่ม พร้อมแท็กสำหรับสีปากกาแต่ละสี กระดาษถูกค้นหาและทำให้ตรงบนคอมพิวเตอร์ของคุณ และไม่มีการส่งไปที่ใด ดู [สร้างโมเดลบนผังไซต์](topic:site-plan)
- **จัดเฟอร์นิเจอร์ในห้อง** เลือกพื้นแล้วใช้ {{ui:จัดระเบียบ}} › {{ui:จัดเฟอร์นิเจอร์ในห้อง…}} เฟอร์นิเจอร์ห้องนอน ห้องนั่งเล่น ห้องอาหาร ห้องครัว ห้องน้ำ หรือห้องทำงานจะถูกวางตามกฎ ชิดผนังและไม่ทับประตูหรือหน้าต่าง ในกลุ่มเดียวที่คุณนำออกได้ในขั้นตอนเดียว เป็นเลย์เอาต์เริ่มต้นให้คุณตรวจทาน ไม่ใช่การออกแบบ ดู [ไลบรารีเริ่มต้น](topic:starter)

**การพิมพ์ 3 มิติ**

- **การตัดเอียง** การแบ่งเพื่อพิมพ์สามารถทำให้รอยตัดเอียงได้สูงสุด 60 องศา ซึ่งให้ชิ้นส่วนมีพื้นที่ติดกาวมากขึ้น ตัวเชื่อมตั้งฉากกับรอยตัด ดู [แบ่งโมเดลเพื่อพิมพ์](topic:print-split)
- **การตรวจการพิมพ์ในปัญหา** ผลการตรวจการพิมพ์ 3 มิติแสดงในพาเนลปัญหาพร้อมเครื่องหมายบนโมเดล และ Repair แก้ไขจากตรงนั้นได้ ดู [โครงรองรับ ความหนาผนัง การทำให้กลวง และการซ่อมแซม](topic:print-tools)

**ในทุกแอป**

- **ภาษา** วิธีใช้และแอปมีให้ 54 ภาษา สิบภาษาเป็นภาษาใหม่: ลิทัวเนีย ลัตเวีย บอสเนีย มาราฐี เตลูกู แอลเบเนีย แอฟริกานส์ ฟิลิปิโน สวาฮีลี และอุซเบก ภาษาอื่นที่ไม่ใช่อังกฤษเป็นฉบับแปลด้วยเครื่องจนกว่าผู้พูดภาษานั้นจะตรวจทาน และหัวข้อวิธีใช้บางส่วนอาจยังเป็นภาษาอังกฤษ
- **อุปกรณ์ป้อนข้อมูล** แทร็กแพด ปากกา เมาส์ 3 มิติ ตัวควบคุมเกม และการควบคุม MIDI สามารถควบคุมแอปได้ ทั้งหมดหรือเฉพาะแอปเดียว
- **แถวแถบเครื่องมือ** {{ui:การตั้งค่า}} › {{ui:ทั่วไป}} › แถวแถบเครื่องมือ ตั้งค่า Wrap (เหมือนเดิม) 2 แถว หรือ 1 แถว แถบที่ไม่พอดีจะเลื่อนในแนวนอนแทนการกินพื้นที่ของภาพวาด Wrap ยังเป็นค่าเริ่มต้น
- **กริดคุณสมบัติ** ช่องของโคมไฟใน ModelCraft ใช้กริดร่วม: หมวดที่พับได้ คอลัมน์ป้ายและค่า และความหนาแน่น Compact การคำนวณที่พิมพ์ เช่น `2*450` ยังทำงานได้
- **ปัญหา** พาเนลปัญหา (ปุ่มเตือนในแถบแอป) ใช้ร่วมกันทุกแอป ใน ModelCraft มีการตรวจการพิมพ์และคำเตือนความต่อเนื่องของพื้นผิว
- **Live** เซสชัน Live TeamWork แสดงว่าใครอยู่ที่ใด ดู [สร้างแบบร่วมกันด้วย Live TeamWork](topic:work-live)
- **ส่วนเสริม** ส่วนเสริมเพิ่มเอนจินเรนเดอร์ได้ ตามที่กล่าวไว้ข้างต้น
- **เชื่อมต่อ AI ของคุณ** สัญญาเครื่องมือและการตรวจสอบของแอปทั้งแปดผ่านแล้ว รวมเครื่องมือทั้งหมด 454 รายการ การเชื่อมต่อคลิกเดียวภายใน Studio ตัวเชื่อมต่อแบบโฮสต์สำหรับผู้ช่วยในเบราว์เซอร์ คีย์ของคุณเองภายใน Studio และแพ็กเกจที่เผยแพร่ยังไม่ได้รับการรับประกัน แอปไม่มี AI ของตัวเอง ดู [ใช้ ModelCraft กับผู้ช่วย AI](topic:use-with-ai-assistants)

### แก้ไขแล้วใน 0.8.1

- **ส่วนคลาสของ DWG** ส่วนคลาสของไฟล์ DWG ถูกอ่านเป็นชนิดผิด ซึ่งอาจทำให้ไฟล์เสียเมื่อนำเข้า ตอนนี้อ่านถูกต้องแล้วใน ModelCraft และแอปอื่นที่อ่าน DWG
- **แท็บเล็ตแนวตั้ง** พื้นที่กริดที่เหลือจะให้กับแคนวาส และเลย์เอาต์แผ่นงานเริ่มที่ 760 พิกเซลกว้างหรือน้อยกว่า สไตล์ชีตของ ModelCraft ก็มีการเปลี่ยนแปลงนี้ด้วย
- **ภาษาใน Studio** CadCraft Studio และรุ่นที่บรรจุไว้สามารถเปลี่ยนภาษาขณะกำลังทำงานได้ ก่อนหน้านี้มีเพียงภาษาอังกฤษ ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม โปรดแจ้งเราหากภาษาไม่เปลี่ยน

### ยังไม่มีในเวอร์ชันนี้

- **ยังไม่มีการลงลายมือชื่อโค้ด** Windows อาจแสดง SmartScreen ให้เลือก {{ui:ข้อมูลเพิ่มเติม}} แล้วเลือก {{ui:เรียกใช้ต่อไป}} บน Mac ให้คลิกขวาแล้วเลือก {{ui:เปิด}} บิลด์สำหรับร้านค้าถูกระงับ และบิลด์ iPad และ iPhone ไม่ได้สร้างใหม่สำหรับ 0.8.1
- โปรแกรมอื่นที่วาดภาพโดยไม่มีส่วนเสริมเอนจินเรนเดอร์ กล้องพาโนรามาหรือสเตอริโอ และภาพท้องฟ้าผ่านโปรแกรมอื่น รวมทั้งปลั๊กอินที่เปิดฉาก Unreal ยังไม่มี ไฟล์ถูกเขียนแล้ว แต่ปลั๊กอินยังไม่ถูกเผยแพร่และยังไม่เคยรันใน Unreal
- พื้นผิวอิสระ: G3 และ class A ยังไม่ถูกวัดหรืออ้างถึง และการตัดและโซลิดจะมาในภายหลัง
- ภาพจากโปรแกรมอื่นไม่เหมือนกันทุกพิกเซลกับของเรา: เฉพาะกล้อง ดวงอาทิตย์ โคมไฟ และการรับแสงที่ตรงกัน
- การแก้ไขการเปลี่ยนภาษาใน Studio ใน 0.8.1 ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม
