ถ้าคุณเคยทำโมเดลใน SketchUp ModelCraft จะคุ้นเคย: แนวคิดเดียวกันเรื่องหน้าและการดัน/ดึง ตัวอักษรเครื่องมือเดียวกัน กล่องค่าที่คุณพิมพ์ลงไปได้โดยไม่ต้องคลิก การอนุมานด้วยแกนสีแดง เขียว และน้ำเงิน กลุ่ม องค์ประกอบ Outliner, Entity Info และฉาก หน้านี้จะแสดงสิ่งที่แมปโดยตรง และที่สำคัญกว่าคือสิ่งที่ไม่แมป

## นิสัยที่ยังใช้ได้

| สิ่งที่คุณคุ้นเคย | ใน ModelCraft |
|---|---|
| กด Space เพื่อเลือก, L เส้น, R สี่เหลี่ยมผืนผ้า, C วงกลม | เหมือนกัน: {{key:Space}}, {{key:L}}, {{key:R}}, {{key:C}} |
| กด P ดัน/ดึง, M ย้าย, Q หมุน, S สเกล, E ยางลบ, T เครื่องมือวัด | เหมือนกัน: {{key:P}}, {{key:M}}, {{key:Q}}, {{key:S}}, {{key:E}}, {{key:T}} |
| กด O โคจร, H แพน, Z ซูม, Shift+Z ซูมขอบเขต | เหมือนกัน: {{key:O}}, {{key:H}}, {{key:Z}}, {{key:Shift+Z}} |
| กด G เพื่อสร้างองค์ประกอบ | เหมือนกัน: {{key:G}} {{key:Shift+G}} สร้างกลุ่ม |
| พิมพ์ในกล่องการวัดโดยไม่ต้องคลิก | เหมือนกัน ในกล่องค่าด้านล่าง กด {{key:Enter}} |
| พิมพ์ `4m,3m` สำหรับสี่เหลี่ยมผืนผ้า `12s` สำหรับด้าน | เหมือนกัน |
| พิมพ์ `3x` หรือ `/3` หลังการคัดลอกด้วยการย้าย | เหมือนกัน `*3` ก็ใช้ได้ |
| พิมพ์ `[x,y,z]` หรือ `<dx,dy,dz>` สำหรับจุดหรือออฟเซ็ต | เหมือนกัน |
| พิมพ์ตัวเลขเปล่าในโมเดลหน่วยนิ้วแบบสถาปัตย์แล้วได้นิ้ว | เหมือนกัน |
| ลากกลางเพื่อโคจร Shift+ลากกลางเพื่อแพน ล้อเพื่อซูมที่เคอร์เซอร์ | เหมือนกัน |
| ดับเบิลคลิกด้วยดัน/ดึงเพื่อทำซ้ำระยะ | เหมือนกัน |
| ปุ่มลูกศรเพื่อล็อกแดง เขียว น้ำเงิน และขนาน | เหมือนกัน: {{key:Right}} แดง {{key:Left}} เขียว {{key:Up}} น้ำเงิน {{key:Down}} ขนาน |
| กด Shift ค้างเพื่อล็อกการอนุมาน | เหมือนกัน |
| Ctrl (Option บน Mac) เพื่อคัดลอกขณะย้าย | {{key:Ctrl}}, {{key:Mod}} หรือ {{key:Alt}} ได้ทุกคอมพิวเตอร์ |
| Shift เพื่อสลับ Ctrl เพื่อเพิ่ม Shift+Ctrl เพื่อนำออกจากการเลือก | ปุ่มเดียวกัน บน Mac ใช้ {{key:Mod}} แทนที่ที่เขียนว่า Ctrl |
| กรอบซ้ายไปขวา กรอบข้ามขวาไปซ้าย | เหมือนกัน |
| เครื่องมือไดเมนชันเพื่อระบุความยาว | {{key:D}} และอื่นๆ: พิมพ์ความยาวใหม่ลงในไดเมนชัน แล้วโมเดลจะปรับขนาดตาม ดู [ไดเมนชันและการปรับขนาด](topic:dimensions) |
| ดับเบิลคลิกหน้าเพื่อหน้าพร้อมขอบ ทริปเปิลคลิกเพื่อทั้งหมดที่เชื่อมต่อ | เหมือนกัน |
| ดับเบิลคลิกกลุ่มเพื่อแก้ไข Esc เพื่อปิด | เหมือนกัน |
| ลากเส้นข้ามหน้าเพื่อแบ่ง ลบขอบระหว่างหน้าที่อยู่ในระนาบเดียวกันเพื่อรวม | เหมือนกัน |
| ดันสี่เหลี่ยมหน้าต่างผ่านผนังเพื่อตัด | เหมือนกัน |
| หน้าด้านหลังเป็นสีน้ำเงินเทา และ Reverse Faces | สีเดียวกัน; {{ui:Reverse face}} ใน {{ui:Entity info}} |
| ฉากเป็นแท็บเหนือมุมมอง Page Up และ Page Down | เหมือนกัน โดยมี {{ui:Play}} ในพาเนล {{ui:Scenes}} |
| เงาจากวันที่ เวลา ละติจูดและลองจิจูด โดยทิศเหนือเป็นสีเขียว | เหมือนกัน ในพาเนล {{ui:Style}} |

## ความแตกต่างที่ทำให้หลายคนสะดุด

### การบันทึกคือการดาวน์โหลด

ไม่มีการบันทึกที่เขียนทับไฟล์ที่คุณเปิด ไม่มีกล่องโต้ตอบบันทึกเป็นพร้อมชื่อ ไม่มีการบันทึกอัตโนมัติ และไม่มีไฟล์สำรอง {{ui:Save}} ({{key:Mod+S}}) จะดาวน์โหลดไฟล์ `.modelcraft` ใหม่ทุกครั้ง โดยปกติไปยังโฟลเดอร์ดาวน์โหลดของคุณ บันทึกบ่อยๆ และเปลี่ยนชื่อหรือย้ายไฟล์ด้วยตัวคุณเอง ดู [เปิด บันทึก นำเข้า และส่งออก](topic:files)

### นำเข้าไฟล์ .skp ได้ แต่บันทึกเป็น .skp ไม่ได้

{{ui:Import}} อ่านไฟล์ SketchUp ด้วยตัวอ่านของ ModelCraft เองในหน้าเว็บ กลุ่ม องค์ประกอบ สี พื้นผิวบนหน้า แท็ก และขอบนุ่มจะถูกนำเข้ามาด้วย ดู [รูปแบบไฟล์โดยละเอียด](topic:formats#skp-files) ModelCraft ไม่สามารถบันทึก `.skp` ได้ หากต้องการกลับไป ให้ส่งออก Collada จาก ModelCraft แล้วนำเข้าใน SketchUp

### ไม่มีเมนูคลิกขวา

การลากขวาใช้แพน การคลิกขวาไม่ทำอะไร คำสั่งที่คุณจะพบในเมนูบริบทอยู่ใน {{ui:Entity info}} ({{ui:Reverse face}}, {{ui:Edit}}, {{ui:Explode}}, {{ui:Make unique}}, {{ui:Make component}}) และในกลุ่ม {{ui:Organize}} ของแถบเครื่องมือ

### หน่วยอยู่ในแถบสถานะ

ไม่มี Model Info หรือการเลือกเทมเพลต ตัวเลือกหน่วยอยู่ที่มุมล่างขวา โมเดลใหม่จะเริ่มเป็นฟุตและนิ้วในสหรัฐฯ และมิลลิเมตรในที่อื่น ตามการตั้งค่าภาษาของเบราว์เซอร์ ทศนิยมจะใช้จุดเสมอ: `2.5m` ไม่ใช่ `2,5m` เพราะเครื่องหมายจุลภาคใช้คั่นค่าเสมอ

### สีที่ทาเป็นวัสดุของตัวเอง

{{ui:Paint}} ({{key:B}}) ทาสีทึบและวัสดุในส่วน {{ui:Materials}}: อิฐ ไซดิง หลังคา ไม้ หิน และอื่นๆ ที่ ModelCraft วาดขึ้น ยังไม่สามารถโหลดรูปภาพของคุณเองเป็นวัสดุได้ แต่พื้นผิวที่มาพร้อมไฟล์ที่นำเข้าจะถูกเก็บไว้ ดู [ทาสีด้วยสีและวัสดุ](topic:paint)

### สเกลสม่ำเสมอ ไม่มีกริป

สเกลไม่แสดงกล่องพร้อมกริป คลิกจุดที่ต้องอยู่กับที่ เป็นจุดอ้างอิง แล้วคลิกขนาดใหม่หรือพิมพ์ตัวคูณ จะสเกลเท่ากันในทุกทิศทางเสมอ หากต้องการยืดไปทางเดียว ให้ดัน/ดึง หรือย้ายหน้า หรือพิมพ์ความกว้าง ความลึก หรือความสูงของกลุ่มใหม่ใน {{ui:Entity info}} หรือ[ปรับขนาดด้วยไดเมนชัน](topic:dimensions)

### การหมุนเลือกระนาบจากจุดที่คุณคลิก

ไม่มีโปรแกรมวัดมุมที่ติดกับหน้าขณะที่คุณชี้ด้วยปุ่มลูกศรเพื่อเลือกระนาบ คลิกจุดศูนย์กลางบนหน้าเพื่อหมุนในระนาบของหน้านั้น หรือคลิกบนพื้นเพื่อหมุนรอบแนวตั้ง ปุ่มลูกศรจะโคจรมุมมองก่อนการคลิกครั้งแรก

### การอนุมานจากจุดที่คุณผ่าน

ModelCraft สแนปไปยังทิศทางของแกนจาก**จุดเริ่มต้นของคุณ** และไปยังจุด ขอบ และหน้าที่อยู่ใต้เคอร์เซอร์ มันไม่ติดตามทิศทางจากจุดที่คุณเพียงชี้ผ่าน (การอนุมาน "จากจุด" แบบจุดประ) หากต้องการให้ตรงกับมุมที่ไกล ให้ล็อกแกนด้วยปุ่มลูกศรแล้วชี้ไปที่มุมนั้น จุดที่ล็อกจะเลื่อนมาอยู่ตรงแนวกับมัน หรือวาง[เส้นนำทาง](topic:guides-measure)

### ขนานใช้ขอบที่คุณผ่านก่อนเริ่ม

การอนุมานแบบขนานและตั้งฉากใช้ขอบล่าสุดที่เคอร์เซอร์ข้ามผ่าน**ก่อนการคลิกครั้งแรก** ไม่ใช่ขอบที่คุณชี้ขณะวาด ดู [การอนุมานและการสแนป](topic:inference#parallel-and-perpendicular)

### สำเนาของกลุ่มเชื่อมโยงกัน

การคัดลอกกลุ่มด้วย {{ui:Move}} จะสร้างตำแหน่งที่สองของกลุ่มเดียวกัน การแก้ไขอันหนึ่งจะเปลี่ยนทั้งสองอัน เหมือนกับองค์ประกอบ SketchUp ทำให้กลุ่มเป็นอิสระ ดู [การแก้ไขปัญหา](topic:troubleshooting#editing-one-group-changed-another)

### Space ไม่ใช้แพน

{{key:Space}} เลือก {{ui:Select}} เหมือนใน SketchUp ในเว็บแอปอื่นบางตัว การกด Space ค้างจะแพน แต่ที่นี่ไม่ใช่ ให้ลากขวาเพื่อแพนแทน

### การเลื่อนสองนิ้วใช้ซูม

บนแทร็กแพด ตั้ง {{ui:Settings}} › {{ui:ModelCraft}} › Scrolling เป็น Trackpad: สองนิ้วโคจร {{key:Shift}} และสองนิ้วแพน การบีบซูม ดู [โคจร แพน และซูม](topic:orbit-pan-zoom#on-a-trackpad)

หากมือคุณคุ้นกับปุ่มของ Blender มากกว่า SketchUp ให้เลือกสไตล์เมนู {{ui:Modeler}}: {{key:G}}, {{key:R}} และ {{key:S}} จะทำกับการเลือกทั้งหมดพร้อมกัน {{key:E}} ดันออก (ดัน/ดึง) {{key:Shift+D}} ทำสำเนา และแถบเมนูด้านบน (File, Edit, View, Select, Add, Object, Mesh) จะแทนที่แถบเครื่องมือ มาจาก SketchUp ใช้สไตล์ {{ui:Push-pull}} จะได้แถบเมนูของมันเองเหนือตัวอักษรเครื่องมือเดียวกัน ดู [เมนู ปุ่ม และเมาส์](topic:menus-keys-and-mouse)

### ทึบที่ดันเข้าหากันไม่ตัดกัน

การดัน/ดึงจะตัดผ่านหน้าที่อยู่ด้านหลังในวัตถุเดียวกัน แต่วัตถุทึบสองชิ้นที่แยกกันและดันเข้าหากันจะไม่ตัดกัน ไม่มี Intersect Faces และไม่มี Solid Tools

### สิ่งที่ยังไม่มี

การวาดอิสระ Trim, Split และ Outer Shell วัสดุจากรูปภาพของคุณเอง ส่วนขยาย และเครื่องมือเลย์เอาต์สำหรับแผ่นงาน ยังไม่มีในบิลด์นี้ [ยังไม่ได้สร้าง](topic:not-built-yet) จะแสดงสิ่งที่ต้องทำแทน

## ปุ่มลัดที่เบราว์เซอร์ใช้

ModelCraft ทำงานในเบราว์เซอร์ ดังนั้นปุ่มลัดบางอย่างเป็นของเบราว์เซอร์ ไม่ใช่ของแอป {{key:Mod+N}} จะเปิดหน้าต่างเบราว์เซอร์ (ให้ใช้ {{ui:New}}) และ {{key:Mod+W}} จะปิดแท็บ หากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เบราว์เซอร์จะถามก่อนปิด ดู [ปุ่มคีย์ เมาส์ และแทร็กแพด](common:keys#shortcuts-the-browser-keeps)
