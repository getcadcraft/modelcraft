สีช่วยให้คุณแยกชิ้นส่วนของโมเดลออกจากกันได้ และ**วัสดุ** (อิฐ ไซดิง มุงหลังคา ไม้ หิน กระเบื้อง คอนกรีต ปูนฉาบ หญ้า กระจก โลหะ) ทำให้โมเดลดูเหมือนสิ่งที่สร้างขึ้นจากวัสดุนั้น ทั้งสองอย่างทาในลักษณะเดียวกัน

## เลือกสี

ส่วน {{ui:Colors}} ทางขวาแสดงแถวของสีทึบ {{ui:Default}} (ช่องที่มีเส้นขีดทับ คือไม่มีสี) และช่องสี {{ui:+}} สำหรับสีอื่น คลิกหนึ่งสีเพื่อให้เป็นสีปัจจุบัน เครื่องมือทาสีจะเริ่มด้วยสีนั้น

## ทาสี

1. กด {{key:B}} ({{ui:Paint}}) หรือหากไม่มีอะไรถูกเลือก ให้คลิกสี (หากมีที่เลือกอยู่ การคลิกสีจะทาที่เลือกทันที)
2. คลิกหน้าเพื่อทา
3. คลิกกลุ่มหรือส่วนประกอบเพื่อทาสำเนานั้น หน้าของมันที่ไม่มีสีเป็นของตัวเองจะได้สีนี้ หน้าที่คุณทาไว้ข้างในจะคงสีของมันไว้

หากต้องการทาหลายสิ่งพร้อมกัน ให้เลือกก่อนแล้วคลิกสี หรือคลิกอันใดอันหนึ่งด้วย {{ui:Paint}} การทำนี้นับเป็นการเลิกทำหนึ่งขั้น

| กด | แล้วคลิกหน้า | สิ่งที่ถูกทา |
|---|---|---|
| — | | หน้านั้น |
| {{key:Ctrl}} | | ทุกหน้าที่เชื่อมกับหน้านั้นและมีสีเดียวกัน |
| {{key:Shift}} | | ทุกหน้าที่มีสีนั้นในกลุ่มที่คุณกำลังทำงานอยู่ |
| {{key:Alt}} | | ไม่มีอะไร: คุณจะหยิบสีนั้นขึ้นมาแทน |

หากต้องการเอาสีออกจากหน้าให้กลับไม่มีสี ให้เลือก {{ui:Default}} แล้วคลิกหน้านั้น

## ทาด้วยวัสดุ

ส่วน {{ui:Materials}} ซึ่งอยู่ใต้ {{ui:Colors}} แสดงไลบรารีวัสดุตามประเภท ได้แก่ อิฐและบล็อก ไซดิง มุงหลังคา ไม้ หิน กระเบื้อง คอนกรีต ปูนฉาบ พื้นดิน กระจก และโลหะ วางเมาส์บนช่องสีเพื่อดูชื่อ คลิกหนึ่งวัสดุ แล้วทาด้วยวิธีเดียวกับการทาสี: กด {{key:B}} คลิกหน้า กลุ่ม หรือส่วนประกอบ หรือเลือกก่อนแล้วคลิกวัสดุ

- ในสไตล์ **แรเงา** หน้าจะแสดงเท็กซ์เจอร์ของวัสดุ ส่วนเส้นซ่อน โครงลวด และเอกซ์เรย์จะแสดงสีของวัสดุ
- เท็กซ์เจอร์วางแนว **ราบตามแต่ละหน้า** และ **ขึ้นตามหน้า**: แนวอิฐคงระดับบนทุกผนัง ชิงเกิลไล่ลงตามความลาดของหลังคา แผ่นไม้บนพื้นตามแกนแดง เท็กซ์เจอร์มีขนาดจริง (อิฐยาวประมาณ 215 mm) จึงดูถูกต้องในทุกระยะ
- ในภาพที่[เรนเดอร์แล้ว](topic:render) วัสดุจะคงเท็กซ์เจอร์ ความหยาบ และสำหรับกระจกและโลหะคือความวาวไว้
- คลิกด้วย {{key:Alt}} พร้อม {{ui:Paint}} จะหยิบวัสดุของหน้านั้นด้วยเช่นกัน

เท็กซ์เจอร์เหล่านี้ ModelCraft วาดขึ้นเอง จึงใช้งานออฟไลน์ได้ และใช้ได้อย่างอิสระกับทุกอย่าง (CC0)

## ส่วนประกอบและสี

สีที่ทาบนหน้า**ภายใน**ส่วนประกอบจะแสดงในทุกสำเนา เพราะสำเนาทั้งหมดใช้นิยามเดียวกัน ส่วนสีที่ทาบน**สำเนา**จากภายนอก (เมื่อส่วนประกอบปิดอยู่) จะเป็นของสำเนานั้นเท่านั้น ดังนั้นสำเนาสองชุดของส่วนประกอบเดียวกันจึงมีสีต่างกันได้ {{ui:Entity info}} แสดงสีของหน้า กลุ่ม หรือส่วนประกอบที่เลือก

## สีในไฟล์

- ไฟล์ ModelCraft เก็บทุกสีและทุกวัสดุไว้
- รูปแบบอื่นจะได้**สีของวัสดุ** (ลักษณะจากระยะไกล) แทนเท็กซ์เจอร์: glTF Collada OBJ DWG และ DXF และการตรวจสอบการพิมพ์ 3D ใน glTF Collada และ OBJ วัสดุจะคงชื่อไว้ เช่น `Material_brick-red`
- **glTF (.glb)** และ **Collada (.dae)**: แต่ละสีจะกลายเป็นวัสดุหนึ่งอัน ส่วนประกอบที่แสดงด้วยหลายสีจะถูกเขียนหนึ่งครั้งต่อหนึ่งสี glTF เขียนเท็กซ์เจอร์ที่นำเข้ามาเป็นเท็กซ์เจอร์ด้วย
- **OBJ**: การส่งออกจะดาวน์โหลดสองไฟล์ คือ `.obj` และไฟล์วัสดุ `.mtl` ที่มีสี เก็บทั้งสองไว้ในโฟลเดอร์เดียวกัน หากมีเท็กซ์เจอร์ที่นำเข้า `.obj` `.mtl` และภาพจะมาเป็นไฟล์ `.zip` ไฟล์เดียว
- **DWG** เก็บสีเดิมไว้ทุกประการ ส่วน **DXF** ใช้สีที่ใกล้ที่สุดจากสีมาตรฐาน CAD 255 สี
- **STL** และ **PLY** มีสี: STL ตามแบบของ VisCAM / SolidView (โปรแกรมที่ไม่อ่านจะละเว้น) และ PLY เป็นสีที่แต่ละจุด ดู [รูปแบบไฟล์โดยละเอียด](topic:formats)

:::tip

:::
