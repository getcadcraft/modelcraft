{{ui:เรนเดอร์ภาพ…}} มีตัวเลือก**เอนจิน** อยู่เหนือ Mode เอนจินสองตัวของเรามีอยู่เสมอและใช้ได้ทุกที่ ส่วนเสริมสามารถเพิ่มได้อีก และใน CadCraft Studio รายการยังมีโปรแกรมที่รับช่วงฉากไปดำเนินการต่อด้วย

| เอนจิน | ทำอะไร | ใช้ได้ที่ |
|---|---|---|
| ในตัว: Fast | ภาพนิ่งที่รวดเร็ว: แสงกลางวัน เงานุ่ม ลักษณะกระจกและโลหะ ภายในไม่กี่วินาที | เบราว์เซอร์และ Studio |
| ในตัว: Path tracer | แสงสะท้อนระหว่างพื้นผิวบนการ์ดกราฟิกหรือโปรเซสเซอร์ของคุณ คิวการเรนเดอร์ และคอมพิวเตอร์เครื่องอื่นในเครือข่าย | เบราว์เซอร์และ Studio |
| เอนจินของส่วนเสริม | วาดภาพและส่งกลับมา: ดู [วาดภาพด้วยโปรแกรมอื่น](topic:render-other-program) | เบราว์เซอร์ (เอนจินที่เขียนด้วย JavaScript) หรือ Studio (เอนจินที่รันโปรแกรม) |
| โปรแกรมที่รับฉากไป | Studio ใส่ฉากลงในโฟลเดอร์และรักษาให้ตรงกัน | Studio |
| เปิดใน … | บันทึกฉากและเปิดในโปรแกรม ไม่มีอะไรส่งกลับมา: ดู [เปิดฉากในโปรแกรมอื่น](topic:render-open-in) | เว็บจะบันทึกไฟล์ |

## วิธีที่ตัวเลือกทำงาน

- การเลือก Fast หรือ Path tracer จะเปลี่ยน Mode ตามไปด้วย และในทางกลับกัน ไม่มีอะไรอื่นในกล่องโต้ตอบเปลี่ยนไปสำหรับผู้ที่ไม่เคยใช้เอนจินอื่น
- เอนจินที่ไม่พร้อมใช้งานจะยังคงอยู่ในรายการพร้อมเหตุผล ("ไม่พบ", "ต้องการเวอร์ชันใหม่กว่า") และเลือกไม่ได้ ในเบราว์เซอร์ เอนจินที่ทำงานได้เฉพาะใน Studio จะแสดงว่า "บันทึกไฟล์" {{ui:เรนเดอร์ภาพ…}} จะบันทึกฉากและการตั้งค่าเป็นไฟล์ที่นำไปเปิดในโปรแกรมนั้น
- ตัวเลือกจะถูกบันทึกพร้อมการตั้งค่าการเรนเดอร์ของไฟล์ และเอนจินที่เลือกล่าสุดจะเป็นเอนจินเริ่มต้นสำหรับไฟล์ที่ไม่มีตัวเลือกของตัวเอง
- ภาพจากโปรแกรมอื่นจะแสดงว่าโปรแกรมใดเป็นผู้วาดและเวอร์ชันของโปรแกรม ทั้งในกล่องโต้ตอบและในคิวการเรนเดอร์ คำสัญญาของหน้า [เรนเดอร์](topic:render) ครอบคลุมเฉพาะ**เอนจินของเรา** เท่านั้น: โปรแกรมอื่นจัดแสง ปรับโทน และสุ่มตัวอย่างในแบบของตัวเอง ดังนั้นสองภาพของฉากเดียวกันจะคล้ายกันในเรื่องกล้อง ดวงอาทิตย์ หลอดไฟ และการรับแสง แต่จะไม่เหมือนกันทุกพิกเซล

## สิ่งที่ทุกเอนจินได้รับ

ฉากจะถูกส่งไปยังโปรแกรมอื่นเป็น **แพ็กเกจ**: โมเดลเป็นไฟล์ USD (ไฟล์เดียวกับที่ [บันทึกเป็น USD](topic:usd) เขียน) และไฟล์การตั้งค่าที่เก็บสิ่งที่ตัวนำเข้า USD ไม่ควรเชื่อถือ ได้แก่ ค่าวัสดุที่แน่นอน หลอดไฟที่เปิดอยู่พร้อมกำลังและรูปแบบแสง ดวงอาทิตย์ ท้องฟ้า การรับแสง และกล้องตามที่กล่องโต้ตอบจะวาด ไม่มีการอัปโหลดข้อมูลไปที่ใดเลย

## คิวการเรนเดอร์

ภาพหรือแอนิเมชันสำหรับโปรแกรมอื่นสามารถรอใน[คิวการเรนเดอร์](topic:render#the-render-queue) เหมือนของเรา งานของมันจะจำไว้ว่าเป็นของเอนจินใด แอนิเมชันจะถูกส่งไปยังโปรแกรมในการทำงานครั้งเดียว
