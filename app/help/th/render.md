{{ui:เรนเดอร์ภาพ…}} สร้างภาพของมุมมองที่ดูเหมือนแสงกลางวันมากกว่าภาพร่าง ได้แก่ ท้องฟ้า ดวงอาทิตย์ตามตำแหน่งและวันที่ของโมเดล เงานุ่ม แสงจากท้องฟ้าทั้งผืนที่ทำให้มุมและซอกมืดลง และสีที่ดูเหมือนกระจก โลหะ หรือสีเงา โมเดลจะไม่ถูกเปลี่ยนแปลง

## เรนเดอร์มุมมอง

1. จัดมุมมองตามที่ต้องการสำหรับภาพ ได้แก่ หมุนมุมมอง ซูม เลือก[ฉาก](topic:scenes) และซ่อนสิ่งที่ไม่ควรแสดง ภาพจะใช้กล้องของมุมมองนั้น
2. คลิก {{ui:ส่งออก}} ในกลุ่ม {{ui:ไฟล์}} แล้วคลิก {{ui:เรนเดอร์ภาพ…}}
3. เลือก{{ui:ฉาก}}หากฉากที่กดอยู่ไม่ใช่ที่ต้องการ (ดู[พรีเซ็ตฉาก](topic:render#scene-presets-a-good-picture-in-one-click)) จากนั้นเลือก{{ui:ขนาด}} แล้วคลิก{{ui:เรนเดอร์}}

   ภาพจะค่อย ๆ ปรากฏขึ้นระหว่างเรนเดอร์ และเรียบขึ้นในแต่ละรอบ {{ui:หยุด}} (หรือ {{key:Esc}}) จะหยุดก่อนกำหนดและเก็บภาพที่ได้จนถึงตอนนั้นไว้

4. คลิก {{ui:บันทึก}} เพื่อดาวน์โหลด (เป็น PNG เว้นแต่ {{ui:บันทึกเป็น}} จะระบุเป็นอย่างอื่น)

:::tip
เริ่มด้วย{{ui:ร่าง}}ที่{{ui:ขนาดของมุมมอง}} เพื่อตรวจกล้องและลุค แล้วจึงเรนเดอร์{{ui:ดี}}หรือ{{ui:ดีที่สุด}}ที่ขนาดใหญ่ขึ้นสำหรับภาพสุดท้าย
:::

## พรีเซ็ตฉาก: ภาพที่ดีในคลิกเดียว

ด้านบนของกล่องโต้ตอบมีปุ่ม{{ui:ฉาก}}สี่ปุ่ม แต่ละปุ่มตั้งค่าท้องฟ้า ความสว่าง พื้น เส้นขอบ คุณภาพ และดวงอาทิตย์ ด้วยการคลิกครั้งเดียว จึงไม่ต้องเรียนรู้อะไรก่อนได้ภาพแรก คลิกหนึ่งปุ่ม แล้วคลิก {{ui:เรนเดอร์}}

| ฉาก | สิ่งที่ตั้งค่า | ใช้สำหรับ |
|---|---|---|
| {{ui:ภายนอก}} | ท้องฟ้าโปร่ง ดวงอาทิตย์ของโมเดลเอง เปิดพื้น | อาคารจากภายนอก |
| {{ui:ภายใน}} | ท้องฟ้าครึ้ม (แสงนุ่ม ไม่มีจุดแดดแข็ง) สว่างขึ้นครึ่งสต็อป | มุมมองจากภายในห้อง |
| {{ui:มุมมองภาพตัด}} | สตูดิโอสีขาว ไม่มีพื้น เส้นขอบในการเรนเดอร์เร็ว | โมเดลที่ถูกตัดด้วยระนาบตัด |
| {{ui:กลางคืน}} | ดวงอาทิตย์ลับขอบฟ้า (เที่ยงคืนในฤดูหนาวสำหรับซีกโลกของสถานที่) สว่างขึ้นหนึ่งสต็อป | โคมไฟที่ส่องโมเดล หากไม่มีโคมไฟ ภาพจะมืด |

- {{ui:เลือกตามมุมมองนี้}} เลือกให้คุณ: {{ui:มุมมองภาพตัด}} เมื่อเปิดการตัดด้วยระนาบตัด, {{ui:ภายใน}} เมื่อกล้องอยู่ภายในโมเดล มิฉะนั้นใช้ {{ui:ภายนอก}} ครั้งแรกที่เปิดกล่องโต้ตอบ ระบบจะเริ่มด้วยวิธีนี้โดยอัตโนมัติ
- การตั้งค่าทั้งหมดอยู่ด้านล่างและแก้ไขได้ เมื่อคุณเปลี่ยนค่าใดค่าหนึ่ง ฉากนั้นจะไม่ถูกเลือกอีก ไม่มีปุ่มใดถูกกด และบรรทัดใต้ปุ่มจะบอกว่าการตั้งค่าเป็นของคุณเอง คลิกฉากนั้นอีกครั้งเพื่อคืนค่าเดิม
- ฉากไม่เปลี่ยนเอนจิน โหมด ขนาด วัสดุ กล้อง หรือโคมไฟ

:::note
ฉากให้ค่าเดียวกันใน ModelCraft และ BimCraft ลักษณะของภาพที่เสร็จขึ้นอยู่กับโมเดลและการ์ดจอของคุณ
:::

## การตั้งค่า

| การตั้งค่า | หน้าที่ |
|---|---|
| {{ui:ขนาด}} | ขนาดของมุมมอง ขนาดสองเท่าของมุมมอง Full HD, 4K หรือสี่เหลี่ยมจัตุรัส ขนาดคงที่จะคงกล้องของมุมมองไว้ และแสดงภาพด้านข้างมากขึ้นหรือน้อยลง |
| {{ui:โหมด}} | {{ui:เร็ว}} หรือ {{ui:คุณภาพสูง (path traced)}} (ด้านล่าง) พร้อม{{ui:ขีดจำกัดเวลา}} |
| {{ui:คุณภาพ}} | จำนวนรอบ (หรือในคุณภาพสูงคือจำนวนตัวอย่าง) ที่นำมาเฉลี่ย: {{ui:ร่าง}} 16, {{ui:ดี}} 64, {{ui:ดีที่สุด}} 256 รอบยิ่งมากเงาและขอบยิ่งเรียบ แต่ใช้เวลานานขึ้น |

| {{ui:ดวงอาทิตย์}} | ดวงอาทิตย์มาจากวันที่ เวลา และสถานที่ใน{{ui:สไตล์}} › ดวงอาทิตย์ ทำเครื่องหมาย {{ui:ใช้วันและเวลาอื่นสำหรับภาพนี้}} เพื่อลองเวลาอื่นโดยไม่เปลี่ยนสไตล์ของโมเดล |
| {{ui:ความสว่าง}} | สว่างขึ้นหรือมืดลง เป็นขั้น (สต็อป) |
| {{ui:พื้นดินใต้โมเดล}} | พื้นที่รับเงาและจางหายไปที่ขอบฟ้า ปิดไว้สำหรับโมเดลที่ลอยอยู่ |
| {{ui:วาดขอบ}} | วาดเส้นขอบของโมเดลบาง ๆ ทับภาพ ให้ลักษณะเหมือนภาพร่าง |

เมื่อดวงอาทิตย์อยู่ใต้ขอบฟ้าในเวลาที่เลือก จะเป็นกลางคืน ท้องฟ้าจะมืดลง และ[โคมไฟ](topic:lights)ของโมเดลจะส่องสว่างโมเดล กล่องโต้ตอบจะแจ้งไว้

การตั้งค่าจะถูกบันทึกในไฟล์ `.modelcraft` ดังนั้นภาพถัดไปของโมเดลเดียวกันจะเริ่มจากจุดที่คุณค้างไว้

## ทำให้สีดูเหมือนกระจกหรือโลหะ

ภายใต้ {{ui:วัสดุ}} สีทุกสีบนหน้าจอมีลุคหนึ่ง ได้แก่ {{ui:ด้าน}}, {{ui:ซาติน}}, {{ui:เงา}}, {{ui:โลหะ}}, {{ui:โลหะขัดเงา}}, {{ui:กระจก}} หรือ {{ui:กระจกฝ้า}} {{ui:หน้าที่ไม่ได้ทาสี}} คือหน้าที่ไม่มีสีของตัวเอง

หากต้องการให้หน้าต่างเป็นกระจก ให้[ทาสี](topic:paint)บานหน้าต่างด้วยสีเดียว แล้วตั้งสีนั้นเป็น{{ui:กระจก}} กระจกจะให้ท้องฟ้าและสิ่งที่อยู่ด้านหลังส่องผ่าน ได้สีตามสีของมัน และสะท้อนท้องฟ้า

:::note
ในโหมด{{ui:เร็ว}} กระจกและโลหะจะสะท้อนท้องฟ้า ไม่ใช่ส่วนอื่นของโมเดล และแสงจะไม่หักเหผ่านกระจก โหมด{{ui:คุณภาพสูง (path traced)}} ด้านล่างทำได้ทั้งสองอย่าง
:::

## คุณภาพสูง

เลือก{{ui:โหมด}} › {{ui:คุณภาพสูง (path traced)}} สำหรับภาพที่ติดตามแสงในแบบที่กล้องมองเห็น:

- แสงสะท้อนระหว่างพื้นผิว ห้องที่ได้รับแสงผ่านหน้าต่างหรือจากโคมไฟจะสว่างทั่วทั้งห้อง และสีจะซึมไปยังด้านข้าง
- กระจกเป็นกระจกจริง แสงหักเหผ่านมัน และมันสะท้อนโมเดล
- โลหะและพื้นผิวขัดเงาสะท้อนส่วนอื่นของโมเดล
- แผงไฟส่องสว่างเป็นแผง พร้อมเงานุ่ม

โหมดนี้ช้ากว่า{{ui:เร็ว}}มาก: แต่ละรอบจะติดตามแสงของทุกพิกเซลใหม่ ภาพจะเริ่มเป็นเม็ดและชัดขึ้นเมื่อตัวอย่างสะสม ดังนั้นให้เริ่มด้วยขนาดเล็ก ({{ui:ขนาดของมุมมอง}}, {{ui:ร่าง}}) และเลือก{{ui:ขีดจำกัดเวลา}}: เมื่อหมดเวลา ภาพที่ได้ถึงตอนนั้นจะถูกเก็บไว้ {{ui:หยุด}} ก็เก็บภาพไว้เช่นกัน รอบแรกจะรอขณะที่เบราว์เซอร์เตรียม path tracer

เมื่อเบราว์เซอร์มี WebGPU path tracer ของ CadCraft เองจะทำงานบนการ์ดจอ และบรรทัดใต้ภาพจะแสดง{{ui:ติดตามเส้นทางแสงบนการ์ดจอ (WebGPU)}} หลังจาก{{ui:หยุด}}หรือหมดเวลา{{ui:ทำต่อ}}จะดำเนินภาพเดิมต่อจนได้ตัวอย่างครบ การเปลี่ยนค่าหรือกด{{ui:เรนเดอร์}}อีกครั้งจะเริ่มใหม่ตั้งแต่ต้น หากไม่มี WebGPU ภาพจะถูกติดตามเส้นทางแสงด้วย WebGL แทน (บรรทัดจะแจ้งไว้) และจะไม่มี{{ui:ทำต่อ}}

:::linux
Firefox และ Chrome ส่วนใหญ่บน Linux ยังไม่มี WebGPU ดังนั้นคุณภาพสูงจะใช้ WebGL ในที่นั้น
:::

ในโหมดนี้จะไม่วาดขอบ เท็กซ์เจอร์จากไลบรารีจะแสดงสีและความหยาบแต่ไม่แสดงความนูน ([วัสดุที่สร้างด้วยโหนด](topic:shading#in-high-quality-pictures) จะแสดงเวกเตอร์ปกติและความนูนของมัน) และการตัดด้วยระนาบตัดจะทำบนโมเดลก่อนที่ภาพจะเริ่ม

{{ui:ลดนอยส์ (ลบเม็ดที่เหลือจากตัวอย่าง)}}เปิดไว้เป็นค่าเริ่มต้น: เมื่อภาพเสร็จหรือถูกหยุด เม็ดที่เหลือจะถูกลบโดยโครงข่ายประสาทที่สร้างมาเพื่องานนี้ (โครงข่ายที่เผยแพร่โดย Intel Open Image Denoise ทำงานบนคอมพิวเตอร์ของคุณเอง: บนการ์ดจอ หรือหากไม่มีก็บนโปรเซสเซอร์) ภาพที่มีตัวอย่างน้อยจะออกมาสะอาด และ{{ui:แสดง}} › {{ui:ภาพก่อนลดนอยส์}} จะแสดงภาพตามที่เรนเดอร์

## เรนเดอร์ในมุมมอง

พื้นที่ทำงาน{{ui:เรนเดอร์}}รัน path tracer ในมุมมองเอง: หมุนมุมมอง แก้ไขโมเดล หรือเปลี่ยนโคมไฟ และมันจะเริ่มใหม่ทันที {{ui:พื้นที่}}: ลากสี่เหลี่ยม และมีเพียงส่วนนั้นที่จะถูกเรนเดอร์ {{ui:ทั้งมุมมอง}} จะกลับไปเหมือนเดิม {{ui:โฟกัส}}: คลิกจุดที่ต้องการให้คมชัด ความชัดลึกจะโฟกัสตรงนั้น {{ui:รายละเอียด}} กำหนดจำนวนพิกเซลของมุมมองที่จะถูกเรนเดอร์ (น้อยกว่าจะเร็วกว่า) {{ui:หยุดชั่วคราว}} หยุดและไปต่อได้ ต้องใช้ WebGPU หากไม่มี พื้นที่ทำงานจะแจ้งไว้ และ{{ui:ส่งออก}} › {{ui:เรนเดอร์ภาพ…}} ยังใช้ได้

## ท้องฟ้าและโปรไฟล์แสงบนการ์ดจอ

ด้วย WebGPU คุณภาพสูงมีท้องฟ้าเพิ่มอีกสองแบบ:

- {{ui:ท้องฟ้าจริง}} คำนวณแสงกลางวันจากความสูงของดวงอาทิตย์: ฟ้าสีน้ำเงินเข้มเหนือศีรษะ แถบสีซีดที่ขอบฟ้า และดวงอาทิตย์ที่อุ่นขึ้นและหรี่ลงเมื่อต่ำลง {{ui:ความขุ่นของบรรยากาศ}} ไล่จากวันที่ใสมาก (2) ไปจนถึงวันที่ขุ่น (10)
- {{ui:ภาพท้องฟ้า (HDRI)}} ส่องแสงให้โมเดลด้วยภาพพาโนรามาของสถานที่จริง {{ui:เลือกภาพ…}} รับไฟล์ `.hdr` หรือ `.exr` แบบ equirectangular; {{ui:หมุน}} หมุนภาพรอบโมเดล และ{{ui:ความสว่างของภาพ}}ทำให้สว่างหรือมืดลง ภาพมีดวงอาทิตย์ของตัวเอง ดังนั้นดวงอาทิตย์ของโมเดลจะไม่ถูกเพิ่มเข้าไป ภาพจะถูกเก็บไว้เฉพาะขณะที่หน้าเว็บเปิดอยู่ หลังจากเปิดใหม่ให้เลือกอีกครั้ง

แต่ละโคมไฟในรายการ{{ui:โคมไฟ}}สามารถใช้โปรไฟล์แสงของผู้ผลิตได้: {{ui:โปรไฟล์ IES…}} อ่านไฟล์ IES (LM-63) และโคมไฟจะส่งแสงตามแบบของโคมนั้น (เช่น ดาวน์ไลต์แคบ หรือโคมส่องผนัง) โคมไฟทุกดวงที่มีชื่อนั้นจะใช้โปรไฟล์นี้ และโคมไฟยังคงความสว่างของตัวเอง คลิกชื่อโปรไฟล์เพื่อหยุดใช้

หน้าต่างกระจกใสช่วยให้แสงจากท้องฟ้าเข้ามาในห้องได้ ดังนั้นภาพในร่มภายใต้ท้องฟ้าจะชัดเร็วขึ้น

โหมด{{ui:เร็ว}}และ path tracer แบบ WebGL จะแสดง{{ui:ท้องฟ้าจริง}}และ{{ui:ภาพท้องฟ้า (HDRI)}}เป็นท้องฟ้าโปร่ง และจะไม่สนใจโปรไฟล์แสง

## กล้อง

{{ui:กล้อง}}ตั้งค่าภาพเหมือนภาพถ่าย:

- {{ui:การรับแสง}}: ใช้{{ui:แถบเลื่อนความสว่าง}}ไว้ หรือเลือก{{ui:การตั้งค่ากล้อง}} แล้วตั้ง{{ui:รูรับแสง (f-stop)}}, {{ui:ความเร็วชัตเตอร์}} และ{{ui:ISO}} เหมือนกล้องจริง ค่า EV ข้างกันคือค่าการรับแสงตามปกติ f/16 ที่ 1/100 s และ ISO 100 ตรงกับวันที่มีแดด ฉากที่มืดกว่าต้องการรูรับแสงกว้างขึ้น ชัตเตอร์ช้าลง หรือ ISO สูงขึ้น ใช้ได้ในทุกโหมด
- {{ui:ความชัดลึก}} ทำให้สิ่งที่อยู่ใกล้หรือไกลกว่า{{ui:ระยะโฟกัส (m)}}เบาลง เหมือนเลนส์ที่มี f-stop นั้น (เว้นว่างไว้เพื่อโฟกัสสิ่งที่อยู่กลางมุมมอง); {{ui:รูปร่างรูรับแสง}} ทำให้แสงเบลอให้เป็นวงกลมหรือเป็นใบมีด
- {{ui:ทัศนมิติสองจุด (เส้นแนวตั้งคงเป็นแนวตั้ง)}} ปรับระดับกล้องและเลื่อนภาพ เหมือนเลนส์ tilt-shift ทางสถาปัตยกรรม ดังนั้นผนังจะไม่เอียงเมื่อคุณมองขึ้นหรือลงไปที่อาคาร
- {{ui:สมดุลแสงขาว}} กำหนดว่าสีแสงใดจะแสดงเป็นสีขาว ค่าต่ำ (เช่น 3000 K) สำหรับแสงโคมไฟที่อุ่น ค่าสูงสำหรับร่มเงาและวันที่ฟ้าครึ้ม
- {{ui:การฉาย}}: {{ui:พาโนรามา 360°}} สร้างภาพ 2:1 ของทุกอย่างรอบกล้อง สำหรับโปรแกรมดูพาโนรามา; {{ui:พาโนรามาสเตอริโอ 360°}} เรียงพาโนรามาตาซ้ายและตาขวาสำหรับหมวกหูฟัง; {{ui:แผนที่ลูกบาศก์ (6 ด้าน)}} สร้างมุมมองจัตุรัสหกมุมในตาราง 3 × 2 ความกว้างมาจาก{{ui:ขนาด}}

การฉาย ความชัดลึก ทัศนมิติสองจุด และสมดุลแสงขาวต้องใช้ path tracer บนการ์ดจอ (WebGPU) จึงจะแสดงเฉพาะใน{{ui:คุณภาพสูง}}

## ปรับแต่งภาพสุดท้าย

{{ui:ภาพ}}ปรับแต่งภาพคุณภาพสูงเหมือนภาพถ่าย และทุกตัวควบคุมเปลี่ยนภาพสำเร็จรูปทันที โดยไม่ต้องเรนเดอร์ใหม่:

- {{ui:ลุค (การแปลงมุมมอง)}}: {{ui:ACES filmic}} (ภาพเหมือนเดิม), {{ui:AgX}} (นุ่มกว่า รักษาสีในแสงที่สว่างมาก), {{ui:Filmic}} (เส้นโค้งฟิล์มที่นุ่มนวล) หรือ{{ui:มาตรฐาน}} (ธรรมดา แสงที่สว่างมากจะถูกตัดเป็นขาว)
- {{ui:คอนทราสต์}} และ{{ui:การบีบอัดไฮไลต์}} (ทำให้รายละเอียดกลับมาในส่วนที่สว่างมาก)
- {{ui:บลูม}} (แสงเรืองนุ่มรอบแสงสว่าง), {{ui:แสงจ้า}} พร้อม{{ui:เส้นแสงจ้า}} (รังสีรูปดาวจากจุดที่สว่างที่สุด) และ{{ui:วิกเนต}} (มุมที่มืดลง)
- {{ui:ตารางสี (.cube)…}} ใช้การปรับสีจากไฟล์ `.cube` พร้อม{{ui:ความเข้มของตารางสี}} เช่นเดียวกับภาพท้องฟ้า จะถูกเก็บไว้เฉพาะขณะที่หน้าเว็บเปิดอยู่

## บันทึกภาพ

{{ui:บันทึกเป็น}} ข้าง{{ui:บันทึก}}เลือกไฟล์: {{ui:PNG}}, {{ui:JPEG}} หรือ {{ui:WebP}} สำหรับการแชร์ (JPEG และ WebP เฉพาะเมื่อเบราว์เซอร์เขียนได้) และหลังการเรนเดอร์คุณภาพสูงบนการ์ดจอ ยังมี:

- {{ui:PNG 16 บิต}}: ภาพที่ปรับแต่งแล้ว พร้อมขั้นความเข้มที่ละเอียดกว่า สำหรับการพิมพ์หรือแก้ไขต่อ
- {{ui:EXR ทุกเลเยอร์ (ทศนิยม 32 บิต)}}: ภาพตามที่เรนเดอร์ (แสงเชิงเส้น ไม่มีการปรับ) โดยแต่ละองค์ประกอบการเรนเดอร์และกลุ่มแสงเป็นเลเยอร์ของตัวเอง สำหรับโปรแกรมคอมโพสิต
- {{ui:ไฟล์เรนเดอร์ (.ccrender ไว้ปรับสีอีกครั้งภายหลัง)}}: ทุกอย่างที่กล่องโต้ตอบต้องใช้เพื่อผสมและปรับสีภาพอีกครั้ง {{ui:เปิดไฟล์เรนเดอร์…}} จะนำกลับมาพร้อมการผสมและการปรับสี โดยไม่ต้องเรนเดอร์

## ผสมแสงหลังเรนเดอร์

เปิด{{ui:การผสมแสง (เปลี่ยนสีและความสว่างของแต่ละดวงหลังเรนเดอร์)}}ก่อนกด{{ui:เรนเดอร์}} เมื่อภาพเสร็จ (หรือถูกหยุด) {{ui:ผสมภาพ}} จะแสดงแสงของภาพเป็นกลุ่ม: ท้องฟ้า ดวงอาทิตย์ และโคมไฟตามชื่อ (โคมไฟที่มีชื่อเดียวกันเป็นหนึ่งกลุ่ม) ปิดกลุ่มหนึ่ง ให้สี หรือทำให้สว่างหรือมืดลง ภาพจะเปลี่ยนทันที โดยไม่ต้องเรนเดอร์ใหม่ {{ui:บันทึกการผสม}} เก็บการผสมไว้ภายใต้ชื่อเพื่อเลือกใหม่ภายหลัง {{ui:ตามที่เรนเดอร์}} จะกลับไปยังภาพตามที่สร้างขึ้น {{ui:บันทึก}} บันทึกภาพที่ผสมแล้ว

{{ui:องค์ประกอบการเรนเดอร์ (albedo, normals, depth, diffuse, specular, transmission, emission, IDs)}}เก็บส่วนต่าง ๆ ของภาพไว้ด้วย {{ui:แสดง}} สลับมุมมองไปยังส่วนหนึ่ง: สีพื้นผิว (albedo) เวกเตอร์ปกติ ความลึก แสง diffuse, specular และแสงที่ส่งผ่าน (ทั้งแบบตรงและอ้อม) สิ่งที่เรืองแสงและท้องฟ้า และสีต่อวัตถุหรือต่อวัสดุสำหรับทำมาสก์

ทั้งสองแบบเก็บเลเยอร์เพิ่มไว้บนการ์ดจอ ที่ขนาดใหญ่การ์ดจออาจไม่มีที่พอ กล่องโต้ตอบจะแจ้งไว้ และขนาดที่เล็กลงจะใช้ได้

## คิวการเรนเดอร์

หลังการตั้งค่าคุณภาพสูง{{ui:เพิ่มภาพนี้เข้าคิว}}ภายใต้{{ui:คิวการเรนเดอร์}}จะเก็บภาพตามที่ตั้งไว้ตอนนี้ ส่วน{{ui:เพิ่มแอนิเมชันนี้เข้าคิว}}ของกล่องโต้ตอบวิดีโอจะทำเช่นเดียวกันสำหรับแอนิเมชันทั้งชิ้น โดยติดตามเส้นทางแสงทีละเฟรม {{ui:เริ่มคิว}} จะเรนเดอร์ทีละรายการบนคอมพิวเตอร์เครื่องนี้ และ{{ui:บันทึก}}ข้างแต่ละรายการที่เสร็จจะดาวน์โหลดมัน การปิดหน้าเว็บจะคงคิวไว้: เปิดโมเดลเดิมอีกครั้งแล้วคิวจะทำต่อจากจุดที่หยุด คิวต้องใช้ WebGPU

## หมอก ควัน นอยส์ และคอสติก

ทั้งหมดนี้อยู่ใน{{ui:หมอก ควัน และนอยส์}} และทำงานใน{{ui:คุณภาพสูง}}บนการ์ดจอ เอนจินอื่นจะไม่รวมไว้

- {{ui:หมอกและหมอกควัน}}เติมอากาศจนถึงความสูงหนึ่งด้วยหมอกที่ดวงอาทิตย์ ท้องฟ้า และโคมไฟส่องสว่าง{{ui:มองเห็นได้ไกลแค่ไหน หน่วยเป็นเมตร}}กำหนดความหนา (ประมาณ 100 m คือหมอกบาง 20 m คือหมอกหนา) {{ui:ความสูงของหมอกเหนือพื้น หน่วยเป็นเมตร}}คือจุดสิ้นสุด และ{{ui:ลำแสง}}คือหมอกเรืองมากเพียงใดเข้าหาแสง แสงแดดจะออกจากหมอกที่ด้านบนสุด ดังนั้นตรงที่แดดลอดผ่านหน้าต่างหรือระหว่างตึก คุณจะเห็นเป็นลำแสง
- {{ui:ควันหรือเมฆ}}เพิ่มปริมาตรเดียวของควันหรือเมฆที่ส่องสว่างเหมือนหมอก{{ui:ชนิด}}คือ{{ui:เมฆ}}, {{ui:เสาควัน}} หรือ{{ui:จากไฟล์ปริมาตร (.ccvol)}} ซึ่งเป็นรูปแบบกริดของ CadCraft เอง{{ui:รายละเอียด}}และ{{ui:ความแตกต่าง}}เปลี่ยนเมฆหรือเสาที่สร้างแล้ว{{ui:ขนาดของด้านที่ยาวที่สุด หน่วยเป็นเมตร (0 = ขนาดของโมเดล)}}, {{ui:เลื่อน X (m)}}, {{ui:เลื่อน Y (m)}}, {{ui:เลื่อน Z (m)}} และ{{ui:หมุน}}กำหนดตำแหน่ง (เริ่มจากกึ่งกลางของโมเดล) {{ui:ความหนา}}ทำให้หนาแน่นขึ้น {{ui:เรืองไปข้างหน้า}}ทำให้สว่างขึ้นเข้าหาแสง และ{{ui:สี}}ใส่สี ไฟล์ปริมาตรจะถูกเก็บไว้เฉพาะขณะที่หน้าเว็บเปิดอยู่ เหมือนภาพท้องฟ้า
- {{ui:หยุดเร็วขึ้นตรงที่ภาพสะอาดแล้ว (adaptive sampling)}}จะไม่ให้ตัวอย่างเพิ่มกับพิกเซลที่นิ่งแล้ว ดังนั้นส่วนที่เหลือของภาพจะเสร็จเร็วขึ้น{{ui:นอยส์ที่ยอมรับได้}}คือเม็ดที่ยังเหลือเมื่อพิกเซลหยุด บรรทัดใต้ภาพจะบอกจำนวนตัวอย่างเฉลี่ยที่พิกเซลได้รับ
- {{ui:คอสติก (แสงที่หักเหผ่านแก้วหรือสะท้อนจากกระจกเงา)}}ติดตามแสงจากโคมไฟและดวงอาทิตย์ ดังนั้นจุดสว่างใต้ลูกแก้วหรือแสงจากกระจกเงาบนผนังจะออกมาสะอาดแทนที่จะเป็นเม็ด จะปิดอยู่ขณะที่หมอก ควัน{{ui:ผสมแสงหลังเรนเดอร์}}หรือองค์ประกอบการเรนเดอร์เปิดอยู่ และทำขึ้นสำหรับภาพ ไม่ใช่สำหรับภาพ 360° แอนิเมชัน หรือพื้นที่ทำงาน{{ui:เรนเดอร์}}

## ใช้เวลานานแค่ไหน

ภาพถูกสร้างบนคอมพิวเตอร์ของคุณเอง โดยการ์ดจอของคุณ ไม่มีการอัปโหลดอะไรทั้งสิ้น ใช้เวลานานแค่ไหนขึ้นอยู่กับการ์ดนั้น เวลาจะเพิ่มตามจำนวนรอบและจำนวนพิกเซล: {{ui:ดีที่สุด}} มีจำนวนรอบ 16 เท่าของ{{ui:ร่าง}} และภาพ 4K มีพิกเซลประมาณสี่เท่าของ Full HD คอมพิวเตอร์ที่ไม่มีการ์ดจอยังเรนเดอร์ได้ แต่ช้ากว่า

:::note
หากกล่องโต้ตอบแจ้งว่าเบราว์เซอร์ไม่สามารถเรนเดอร์ภาพได้ แปลว่าเบราว์เซอร์ไม่มี WebGL 2 ให้อัปเดตเบราว์เซอร์ หรือเปิดการเร่งความเร็วด้วยฮาร์ดแวร์ในการตั้งค่าของเบราว์เซอร์
