ภาพใน {{ui:เรนเดอร์ภาพ…}} วาดโดย**เอนจินของเรา**: Fast และ Path tracer ทั้งในเบราว์เซอร์และใน CadCraft Studio โปรแกรมอื่นจะวาดได้ก็ต่อเมื่อ**ส่วนเสริมเอนจินการเรนเดอร์**นำมาใช้: ดู [เพิ่มเอนจินการเรนเดอร์ด้วยส่วนเสริม](topic:render-engine-addons) หากต้องการนำฉากไปยังโปรแกรมอื่นและทำงานต่อในนั้น ให้ใช้ [เปิดฉากในโปรแกรมอื่น](topic:render-open-in) หรือ [ส่งฉากไปยังเอนจินเกม](topic:render-unreal)

## วาดภาพด้วยเอนจินของส่วนเสริม

1. เปิดส่วนเสริมในการตั้งค่า › ส่วนเสริม เอนจินของมันจะปรากฏในรายการ**เอนจิน**ของ {{ui:เรนเดอร์ภาพ…}}
2. เลือกเอนจินนั้น การตั้งค่าของมันจะแสดงอยู่ใต้รายการเอนจิน
3. คลิก {{ui:เรนเดอร์}} ใน Studio ครั้งแรกที่ส่วนเสริมรันโปรแกรม Studio จะถามในกล่องโต้ตอบของตัวเอง ความคืบหน้าจะแสดงขณะที่กำลังวาด {{ui:หยุด}} จะยุติการทำงาน ภาพจะปรากฏโดยมีป้ายระบุว่าเป็นเอนจินที่วาดมัน

เอนจินที่เขียนด้วย JavaScript ก็ทำงานในเบราว์เซอร์ได้ด้วย เอนจินที่รันโปรแกรมบนคอมพิวเตอร์เครื่องนี้จะทำงานได้เฉพาะใน Studio ในเบราว์เซอร์จะแสดงเป็นไฟล์ให้บันทึก

## สิ่งที่ถูกส่งต่อ

เอนจินจะได้รับ**แพ็กเกจ**: โมเดลเป็นไฟล์ USD (และไฟล์ glTF เมื่อมันขอ) และไฟล์การตั้งค่าที่มีค่าวัสดุที่แน่นอน ดวงอาทิตย์และท้องฟ้า หลอดไฟทุกดวงที่เปิดอยู่พร้อมกำลังและรูปแบบแสง กล้อง และการรับแสง โปรแกรมแต่ละตัวจัดแสง ปรับโทน และสุ่มตัวอย่างในแบบของตัวเอง ดังนั้นภาพจะคล้ายกันในเรื่องกล้อง ดวงอาทิตย์ หลอดไฟ และการรับแสง แต่จะไม่เหมือนกันทุกพิกเซล

## โปรแกรมที่ CadCraft จะไม่รัน

CadCraft จะไม่เริ่มโปรแกรมที่อยู่ภายใต้ลิขสิทธิ์ GNU GPL และจะไม่แสดงเป็นเอนจินหรือเป้าหมาย Open in เลย Blender เป็นหนึ่งในนั้น ดังนั้นจึงไม่อยู่ในรายการ**เอนจิน** ไฟล์ USD หรือ glTF ที่บันทึกจาก {{ui:เรนเดอร์ภาพ…}} ยังเปิดในโปรแกรมนั้นได้ เหมือนโปรแกรมอื่นที่อ่านไฟล์เหล่านั้นได้

:::note
พื้นหลังแบบพาโนรามาและกล้องสเตอริโอ รวมถึงภาพท้องฟ้า (จะใช้เฉพาะสีของท้องฟ้า) จะไม่ถูกส่งต่อไปยังโปรแกรมอื่น และสิ่งที่ทำในโปรแกรมอื่นจะไม่ส่งกลับมายังโมเดล
:::
