ส่วนเสริม (การตั้งค่า › ส่วนเสริม) สามารถเพิ่มเอนจินลงในรายการ**เอนจิน**ของ {{ui:เรนเดอร์ภาพ…}} ได้ ข้อความฉบับเต็มสำหรับผู้เขียนส่วนเสริมอยู่ในส่วนที่ 16 ของข้อกำหนดส่วนเสริม โดยสรุปได้ดังนี้:

- ส่วนเสริมจะลงทะเบียนเอนจินด้วย id ที่ขึ้นต้นด้วยของตัวเอง ชื่อ การตั้งค่าที่เลือกได้ และ**อย่างใดอย่างหนึ่ง**: โปรแกรมที่จะรัน **หรือ** ฟังก์ชันใน JavaScript ที่วาดภาพ
- เอนจินที่รันโปรแกรมต้องใช้สิทธิ์ **`engine.run`** ซึ่งจะแสดงก่อนติดตั้งและในการตั้งค่า มันจะรันเฉพาะใน Studio ส่วนในเบราว์เซอร์จะแสดงเป็นไฟล์ให้บันทึก
- ส่วนเสริมระบุชื่อโปรแกรม (ชื่อไฟล์ธรรมดา ไม่ใช่เชลล์) สคริปต์ที่**อยู่ภายในส่วนเสริมที่ลงลายมือชื่อ** และอาร์กิวเมนต์ที่ประกอบจากตัวยึดตำแหน่งและคำธรรมดา Studio จะหาโปรแกรมนั้น หรือขอให้คุณชี้ไปยังโปรแกรมหนึ่งครั้ง
- ครั้งแรกที่ส่วนเสริมรันโปรแกรม **Studio จะถามในกล่องโต้ตอบของตัวเอง**: ส่วนเสริมใด โปรแกรมใด และว่าสคริปต์สามารถทำอะไรก็ได้ที่โปรแกรมทำได้ อนุญาตเฉพาะส่วนเสริมที่คุณเชื่อถือเท่านั้น คำตอบจะถูกจำไว้สำหรับส่วนเสริมและโปรแกรมนั้น
- แพ็กเกจ (ฉากเป็น USD และไฟล์การตั้งค่า พร้อมไฟล์ glTF เมื่อส่วนเสริมขอ) และสคริปต์ของส่วนเสริมจะถูกนำไปไว้ในโฟลเดอร์ชั่วคราวใหม่ โปรแกรมจะรันที่นั่น และภาพจะถูกส่งกลับมาพร้อมชื่อเอนจินของส่วนเสริมกำกับ

:::note
ส่วนเสริมจะเพิ่มเอนจินการเรนเดอร์ได้เฉพาะใน API ของส่วนเสริม 1.4 ขึ้นไป ตัวอย่างการทำงานสำหรับตัวเรนเดอร์บรรทัดคำสั่งโอเพนซอร์สอยู่ในที่เก็บของมันเอง ซึ่งยังไม่ได้รันกับตัวเรนเดอร์นั้น
:::
