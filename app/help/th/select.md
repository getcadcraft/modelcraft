{{ui:เลือก}} ({{key:Space}}) คือเครื่องมือที่ ModelCraft เริ่มต้นด้วย และเป็นเครื่องมือที่ {{key:Esc}} จะพากลับมา สิ่งที่เลือกจะเป็นสีน้ำเงิน และ {{ui:ข้อมูลองค์ประกอบ}} ทางขวาจะบอกว่าเป็นอะไร

## คลิก

| ทำอย่างนี้ | เลือก |
|---|---|
| คลิกหน้าหรือขอบ | หน้าหรือขอบนั้น |
| คลิกกลุ่มหรือชิ้นส่วน | ทั้งกลุ่มหรือชิ้นส่วน |
| ดับเบิลคลิกหน้า | หน้านั้นและขอบของหน้า |
| ดับเบิลคลิกขอบ | ขอบนั้นและหน้าทั้งสองด้านของขอบ |
| ดับเบิลคลิกกลุ่มหรือชิ้นส่วน | เปิดเพื่อแก้ไข (ดู [กลุ่มและชิ้นส่วน](topic:groups-components)) |
| ทริปเปิลคลิกหน้าหรือขอบ | ทุกอย่างที่เชื่อมต่อกับหน้าหรือขอบนั้น คือทั้งวัตถุ |
| คลิกพื้นที่ว่าง | ไม่มีอะไร (ล้างการเลือก) |
| ดับเบิลคลิกพื้นที่ว่างขณะแก้ไขกลุ่ม | ปิดกลุ่ม |

ขอบคลิกได้ง่ายกว่าหน้า: เมื่อตัวชี้อยู่ห่างจากขอบไม่กี่พิกเซล การคลิกจะเลือกขอบ

## ลากกรอบ

- **จากซ้ายไปขวา** วาดกรอบทึบ คือการเลือกแบบ **หน้าต่าง** เลือกเฉพาะสิ่งที่อยู่ในกรอบทั้งหมด
- **จากขวาไปซ้าย** วาดกรอบประ คือการเลือกแบบ **ข้าม** สิ่งที่กรอบแตะจะถูกเลือก และหน้าจะถูกเลือกเมื่อกรอบอยู่ภายในหน้าทั้งหมด

กลุ่มหรือชิ้นส่วนนับเป็นสิ่งเดียว: หน้าต่างต้องบรรจุทั้งหมด ส่วนการข้ามเพียงแตะก็พอ

## เพิ่มและนำออก

กดปุ่มค้างไว้ขณะคลิกหรือลาก:

| ปุ่ม | ผล |
|---|---|
| {{key:Shift}} | สลับ: เพิ่มสิ่งที่ยังไม่ได้เลือก และนำออกสิ่งที่เลือกอยู่ |
| {{key:Mod}} | เพิ่ม |
| {{key:Shift}} และ {{key:Mod}} พร้อมกัน | นำออก |

เพื่อเลือกทุกอย่างในโมเดล (หรือทุกอย่างในกลุ่มที่กำลังแก้ไข) กด {{key:Mod+A}}

## ยกเลิกการเลือก

กด {{key:Esc}} (เมื่อ {{ui:เลือก}} เป็นเครื่องมือ) หรือคลิกพื้นที่ว่าง

## ลบสิ่งที่เลือก

กด {{key:Delete}} หรือ {{key:Backspace}} หน้า ขอบ กลุ่ม และเส้นนำทางที่เลือกจะถูกลบในขั้นตอนเดียว; {{key:Mod+Z}} จะคืนค่าให้

การลบขอบจะลบหน้าที่ต้องใช้ขอบนั้น เว้นแต่ขอบนั้นแยกหน้าสองหน้าที่อยู่บนระนาบเดียวกันเท่านั้น: หน้าทั้งสองจะรวมเป็นหนึ่ง การลบหน้าจะคงขอบของหน้าไว้ ดู [ลบและทำความสะอาด](topic:erase)

## เลือกภายในกลุ่ม

การคลิกกลุ่มจะเลือกทั้งกลุ่ม หากต้องการเลือกหน้าภายในกลุ่ม ให้ดับเบิลคลิกกลุ่มเพื่อเปิด แล้วคลิก ขณะที่กลุ่มเปิดอยู่ การคลิกจะเข้าถึงเฉพาะสิ่งที่อยู่ในกลุ่มเท่านั้น สิ่งอื่นจะจางลง กด {{key:Esc}} เมื่อไม่มีอะไรถูกเลือก หรือดับเบิลคลิกพื้นที่ว่างเพื่อปิดกลุ่ม

{{ui:ตัวจัดการโครงสร้าง}} ทางซ้ายเลือกกลุ่มและชิ้นส่วนตามชื่อ ซึ่งช่วยเมื่อถูกซ่อนอยู่หลังสิ่งอื่น
