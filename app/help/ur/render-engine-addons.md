ایک ایڈ آن (ترتیبات › ایڈ آنز) {{ui:Render a picture…}} کی Engine فہرست میں ایک انجن شامل کر سکتا ہے۔ ایڈ آن لکھنے والوں کے لیے مکمل متن ایڈ آن اسپیسفیکیشن کے سیکشن 16 میں ہے؛ مختصر یہ ہے:

- ایڈ آن ایک انجن ایسے id کے ساتھ رجسٹر کرتا ہے جو اس کے اپنے id سے شروع ہو، ایک نام، اختیاری ترتیبات، اور **یا** ایک پروگرام جو چلایا جائے **یا** ایک JavaScript فنکشن جو تصویر بناتا ہے۔
- وہ انجن جو پروگرام چلاتا ہے اسے **`engine.run`** کی اجازت چاہیے، جو انسٹال سے پہلے اور ترتیبات میں دکھائی جاتی ہے۔ یہ صرف Studio میں چلتا ہے؛ براؤزر میں یہ ایک فائل کے طور پر دکھائی دیتا ہے جسے محفوظ کرنا ہے۔
- ایڈ آن پروگرام کا نام لیتا ہے (سادہ فائل نام، کبھی شیل نہیں)، ایک اسکرپٹ جو **دستخط شدہ ایڈ آن کے اندر** ہو، اور دلائل جو پلیس ہولڈرز اور سادہ الفاظ سے بنیں۔ Studio پروگرام ڈھونڈتا ہے یا ایک بار آپ سے اس کی جگہ پوچھتا ہے۔
- جب کوئی ایڈ آن پہلی بار پروگرام چلاتا ہے تو **Studio اپنے ڈائیلاگ میں آپ سے پوچھتا ہے**: کون سا ایڈ آن، کون سا پروگرام، اور یہ کہ اسکرپٹ وہ سب کچھ کر سکتا ہے جو پروگرام کر سکتا ہے۔ اسے صرف اس ایڈ آن کے لیے اجازت دیں جس پر آپ بھروسا کرتے ہوں۔ آپ کا جواب اس ایڈ آن اور پروگرام کے لیے یاد رکھا جاتا ہے۔
- پیکج (منظر USD کی شکل میں اور ایک ترتیبات فائل، ایڈ آن کے مانگنے پر glTF فائل کے ساتھ) اور ایڈ آن کا اسکرپٹ ایک نئے عارضی فولڈر میں جاتے ہیں، پروگرام وہیں چلتا ہے، اور تصویر واپس آتی ہے جس پر ایڈ آن کے انجن کا نام لکھا ہوتا ہے۔

:::note
ایڈ آن صرف API ورژن 1.4 سے رینڈر انجن شامل کر سکتے ہیں۔ ایک کھلے ذریعے کے کمانڈ لائن رینڈرر کے لیے ایک عملی مثال اپنے ریپوزیٹری میں ہے؛ وہ اس رینڈرر میں ابھی نہیں چلائی گئی۔
:::
