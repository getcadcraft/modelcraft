Kuwani waa furayaasha riix-jiid, kuwa ModelCraft ku bilaabo. Nooca kale, eeg [Furayaasha Modeler](topic:keyboard#modeler-keys) hoose iyo [Dejinta ModelCraft](topic:settings).

Gaabintu waxay shaqeysaa marka muuqaalka 3D ama badhanka qalabka uu xoogga ku leeyahay. Haddii aad hadda ku qortay goob panel ama aad beddelday liiska {{ui:Style}}, guji muuqaalka 3D marka hore, si furayaasha uusan u tagin goobtaas. Eeg [Furayaasha, jiirarka iyo trackpad-yada](common:keys) si aad u aragto sida furayaasha loo qoro kombiyuutar kasta.

## Esc

{{key:Esc}} wuxuu ka baxaa hal heer mar kasta oo aad riixdo:

1. Joojinta wixii qalabku ku jiro (xariiq la rinjiyeynayo, riix/jiid, guuri). Wax kasta waa dib loo celiyaa.
2. Wuxuu u beddelaa {{ui:Select}}.
3. Wuxuu nadiifiyaa doorashada.
4. Wuxuu xirayaa kooxda aad tafatirayso.

Wuxuu sidoo kale joojiyaa aragtiyada la ciyaarayo. Sanduuqa qiimaha gudihiisa, {{key:Esc}} wuxuu nadiifiyaa wixii aad qortay, kadibna wuxuu kuu celinayaa aragtida.

## Inta qalabku shaqeynayo

| Furay | Wuxuu sameeyaa |
|---|---|
| Tiro, ama mid ka mid ah `. , - ' " [ < * /` | Wuxuu bilaabaa qorista sanduuqa qiimaha |
| {{key:Enter}} | Wuxuu dabaqaa wixii aad qortay sanduuqa qiimaha |
| {{key:Right}} | Wuxuu xidhaa dhuumaha casaan (mar kale riix si aad u furto) |
| {{key:Left}} | Wuxuu xidhaa dhuumaha cagaaran |
| {{key:Up}} | Wuxuu xidhaa dhuumaha buluug |
| {{key:Down}} | Wuxuu xidhaa la mid geesha ugu dambaysay ee aad hoos u marisay guji koowaad ka hor |
| Hay {{key:Shift}} | Wuxuu hayaa jihada aad ku dhejisan tahay, inta aad haysato |
| {{key:Ctrl}}, {{key:Mod}} ama {{key:Alt}} (Move) | Wuxuu u beddelaa dhaqdhaqaaq iyo nuqul |

Furayaasha fallaadha ee xidhashada waxay shaqeeyaan {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} iyo {{ui:Tape}} (marka qiyaas laga bilaabo barta), guji koowaad ka dib. {{ui:Push/pull}} mar walba wuxuu u dhaqaaqaa jihada wajiga, mana laha xidhasho. {{ui:Rotate}} furayaasha fallaadhu waxay muujiyaan fariin "Locked" guji koowaad ka dib, laakiin ma beddelaan wareejinta.

## Furayaasha fallaadha waqtiyada kale

Marka qalab aan waxba ku jirin, furayaasha fallaadhu waxay dhaqdhaqaaqaan kamarada:

| Furay | Wuxuu sameeyaa |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Wareeg |
| {{key:Shift}} oo fallaad | Muuqaalka guuri |

## Jiirka

| Ficil | Wuxuu sameeyaa |
|---|---|
| Guji | Wuxuu isticmaalaa qalabka hadda jira |
| Riix, jiid, sii dayn | Isku mid sida labo guji (qalabyada rinjiyeynta); jiid doorasho (for {{ui:Select}}); tirtir inta lagu jiro (for {{ui:Eraser}}) |
| Laba jeer gucsi | {{ui:Select}}: wajiga iyo geesihiisa, geeska iyo wajiyadiisa, kooxda furta; meel bannaan ayaa kooxda xirta. {{ui:Push/pull}}: ku celi masaafadii ugu dambaysay |
| Saddex jeer gucsi | {{ui:Select}}: wax kasta oo isku xidhan |
| {{key:Shift}} + guji | {{ui:Select}}: u dhex geli ama ka bax doorashada |
| {{key:Mod}} + guji | {{ui:Select}}: ku dar doorashada |
| {{key:Shift}} + {{key:Mod}} + guji | {{ui:Select}}: ka saar doorashada |
| Jiid badhanka dhexe | Wareeg, qalab kasta |
| {{key:Shift}} + jiid badhanka dhexe | Muuqaalka guuri, qalab kasta |
| Jiid badhanka midig | Muuqaalka guuri, qalab kasta |
| Wheel | Weynee mawshaarka ku dhow |

Ma jiro menu-ga badhanka midig.

## Trackpad

Waxa laba farood oo jiidan sameeyaa waxay ku xidhan tahay {{ui:Settings}} › {{ui:ModelCraft}} › Dhaqdhaqaaqa:

| Gesture | Trackpad (ama la xisaabiyay) | Mouse wheel |
|---|---|---|
| Laba farood oo jiid | Wareeg | Weynee mawshaarka ku dhow |
| {{key:Shift}} + laba farood oo jiid | Muuqaalka guuri | Weynee |
| Pinch | Weynee mawshaarka ku dhow | Weynee mawshaarka ku dhow |
| Laba farood oo riix oo jiid (badhanka labaad la hayo) | Muuqaalka guuri | Muuqaalka guuri |

Eeg [Wareeg, muuqaalka guuri iyo weynee](topic:orbit-pan-zoom#on-a-trackpad) iyo [Dejinta ModelCraft](topic:settings#scrolling-mouse-wheel-or-trackpad).

## Shaashad taabasho

| Gesture | Wuxuu sameeyaa |
|---|---|
| Taabo | Guji oo qalabka hadda jira |
| Laba jeer taabo | Laba jeer gucsi |
| Riix, jiid, sii dayn | Isku mid sida riix, jiid, sii dayn ee jiirka |
| Laba farood: fur-xidh | Weynee |
| Laba farood: wada dhaqdhaqaaq | Muuqaalka guuri (Settings › ModelCraft › Touch screen ayaa ka dhigi karta Wareeg) |
| Saddex farood: wada dhaqdhaqaaq | Wareeg (Muuqaalka guuri marka laba farood wareegayaan) |
| Hal farood oo aan dhaqdhaqaaqin | Wuxuu dhammeeyaa qalabka, sida Enter; marka waxba socon, kadibna jiid si aad u wareegto |
| Farood labaad inta lagu jiro ficil hal farood | Ficilkaas wuu joojiyaa |
| Qalabka {{ui:Orbit}}, kadibna jiid hal farood | Wareeg |

Si aad qiimo u qorto shaashad taabasho, taabo sanduuqa qiimaha ee hoose, qor, kadibna riix Enter (ama Go) ee kiboodhka.

## Meesha ay Move ku jirto

Move waxay ku jirtaa qalabka {{ui:Move}}, furayaha {{key:M}}: dooro waxa la guurinayo, guji barta saldhigga, kadibna barta labaad ama qor masaafada. Eeg [Guuri, koobiyee iyo samee array-yada](topic:move-copy).
