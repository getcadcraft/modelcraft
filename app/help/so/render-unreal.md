Studio CadCraft waxa liiska **Engine** ku jiri kara **xidhiidh** la mashruuca Unreal Engine. Hal jihood oo keliya: CadCraft ilaa Unreal.

## Dir muuqaalka

1. Dooro Unreal liiska Engine. Markii ugu horreysay, Studio wuxuu kaa weydiinayaa inaad dooratid fooldhaga mashruucaaga (kan ku jira faylka `.uproject`); wuu xasuustaa.
2. Guji {{ui:Dir}}. Studio wuxuu qori doonaa `CadCraft/<magaca faylka>/` gudaha mashruuca: muuqaalka oo ah fayl USD, faylka dejinta, profiilada nalalka, iyo laba fayl lakab oo yaryar.
3. Beddel moodeelka, kaydi, kadibna mar kale dir. Muuqaalka iyo faylka dejinta oo keliya ayaa la beddelaa.

## Tafatirkaagu waa ammaan

Marxalada Unreal furto waa lakab xidid yar oo la sameeyay mar keliya, hoostiisana laba lakab ayaa ku jira: **kaaga** oo sare yaal (`<magac>.user.usda`, markii hore madhan, CadCraft weligeed ma qorto) iyo muuqaalka CadCraft ee hoose. Tafatirka aad ku kaydiso lakabkaaga wuu sii jiri doonaa marka muuqaalka mar kale la diro. Nalalka iyo actor-yada kale ee aad ku dhejiso heerka Unreal waxay ka baxsan yihiin marxalada, sidaas darteedna mana taabtaan.

## Studio la'aanteed

Browser-ka, ama kombiyuutarka aan Studio ka helin Unreal, dooro **Unreal project folder (.zip)** liiska Engine oo guji {{ui:Soo saar}}. Waxay kaydinaysaa isla fooldhaga zip ahaan: fur zip-ka oo ku dhig fooldhaga `CadCraft` ee mashruucaaga. Markii ugu horreysay ka tag **Include the stage files** (Ku dar faylalka marxalada); kaydinta dambe demi, si zip-ku u hayo muuqaalka iyo faylka dejinta oo keliya, lakabkaagana aan mar walba la bedelin.

:::note
Plug-ka Unreal ee furaya marxalada, codsada qorraxda, nalalka, kaamerooyinka iyo iftiinka, raacaya dir kasta oo kaamerad rendaraya, **weli lama sii deynin** oo weli Unreal lama shaqeynin. Ilaa taas, Dir waxa faylalka geliya mashruuca, qalabka USD ee Unreal ayaa furi kara. Windows ayaa nidaamka ugu horreeya; macOS ayaa raacaysa.
:::
