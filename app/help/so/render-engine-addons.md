Kordhin (Dejinta › {{ui:Kordhinno}}) wuxuu ku dari karaa matoor liiska Matoorka ee {{ui:Rendar sawir…}}. Qoraalka oo dhan ee horumariyeyaasha kordhinta waa qaybta 16 ee qorshaha kordhinta; si kooban:

- Kordhinta wuxuu diiwaangeliyaa matoor leh aqoonsi uu ku bilaabmo magiciisa, magac, dejinno ikhtiyaari ah, iyo **midkood** barnaamij la socodsiiyo **ama** function JavaScript ah oo sawirka sameeya.
- Matoorka barnaamij socodsiiya wuxuu u baahan yahay ogolaanshaha **`engine.run`**, oo la muujiyaa ka hor rakibidda iyo Dejinta. Wuxuu ku shaqeeyaa Studio oo keliya; browser-ka wuxuu muujiyaa sida fayl loo keydiyo.
- Kordhinta wuxuu magacaabaa barnaamijka (magac fayl oo fudud oo keliya: marna shell), script ah oo **ku jirta kordhinta la saxiixay**, iyo arguments oo ka kooban placeholders iyo eray fudud. Studio wuxuu helaa barnaamijka ama wuxuu kuu weydiinayaa inaad hal mar u tilmaamto.
- Markii ugu horreysay ee kordhin barnaamij socodsiiyo, **Studio wuxuu kuu weydiinayaa sanduuqiisa**: kordhinta noocee, barnaamijka noocee, iyo in script-ku wax kasta samayn karo oo barnaamijku samayn karo. Kaliya u oggolow kordhin aad aaminsan tahay. Jawaabtaadu waxa loo xasuusanayaa kordhinta iyo barnaamijka.
- Pakajka (muuqaalka sida USD iyo fayl dejin, iyo fayl glTF marka kordhinta weydiiso) iyo script-ka kordhinta waxay galaan folder cusub oo ku meel gaar ah; barnaamijku wuxuu ku shaqeeyaa folderkaas, sawirkuna wuu soo noqdaa isagoo calaamadeysan magaca matoorka kordhinta.

:::note
Kordhinno kaliya ayaa ku dari kara matoorrada rendarka API 1.4 iyo wixii ka dambeeya. Tusaale shaqeynaya oo rendar command-line ah oo open-source ah wuxuu ku jiraa kaydkiisa u gaar ah; weli lama socodsiin rendar-kaas.
:::
