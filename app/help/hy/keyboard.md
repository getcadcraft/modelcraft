Սրանք մղել-քաշելու ստեղներն են, որոնցից ModelCraft-ն է սկսում։ Մյուս ոճի համար տես [Modeler ստեղներ](topic:keyboard#modeler-keys) ստորև և [ModelCraft կարգավորումներ](topic:settings)։

Դյուրանցումները աշխատում են, երբ 3D տեսքը կամ գործիքագոտու կոճակն է ընտրված։ Եթե նոր եք մուտքագրել վահանակի դաշտում կամ փոխել ցանկը {{ui:Ոճ}}-ում, նախ սեղմեք 3D տեսքի վրա, այլապես ձեր ստեղները կգնան այդ դաշտ։ Տես [Ստեղներ, մկնիկներ և թրեքփադներ](common:keys), թե ինչպես է յուրաքանչյուր համակարգչում գրվում ստեղների անունը։

## Esc

{{key:Esc}}-ը ամեն անգամ սեղմելիս հետ է գնում մեկ մակարդակ.

1. Չեղարկում է այն, ինչ գործիքը անում է (գծվող գիծը, մղել-քաշելը, տեղափոխումը)։ Ամեն ինչ վերադառնում է։
2. Անցնում է {{ui:Ընտրել}}-ին։
3. Մաքրում է ընտրությունը։
4. Փակում է խումբը, որ խմբագրում եք։

Այն նաև դադարեցնում է սցենաների նվագարկումը։ Արժեքի վանդակում {{key:Esc}}-ը ջնջում է այն, ինչ մուտքագրել եք, և վերադառնում է տեսքին։

## Մինչ գործիքն աշխատում է

| Ստեղն | Ինչ է անում |
|---|---|
| Թիվ, կամ `. , - ' " [ < * /`-ից մեկը | Սկսում է մուտքագրումը արժեքի վանդակում |
| {{key:Enter}} | Կիրառում է արժեքի վանդակում մուտքագրածը |
| {{key:Right}} | Կողպում է կարմիր առանցքին (նորից սեղմեք՝ ապակողպելու համար) |
| {{key:Left}} | Կողպում է կանաչ առանցքին |
| {{key:Up}} | Կողպում է կապույտ առանցքին |
| {{key:Down}} | Կողպում է զուգահեռ՝ վերջին եզրին, որի վրայով շարժվել եք առաջին սեղմումից առաջ |
| Պահել {{key:Shift}} | Պահում է ուղղությունը, որին կպչած եք, քանի դեռ պահում եք |
| {{key:Ctrl}}, {{key:Mod}} կամ {{key:Alt}} ({{ui:Տեղափոխել}}-ում) | Փոխում է տեղափոխման և պատճենման միջև |

Սլաքի ստեղների կողպումները աշխատում են {{ui:Գիծ}}, {{ui:Ուղղանկյուն}}, {{ui:Շրջան}}, {{ui:Բազմանկյուն}}, {{ui:Տեղափոխել}}, {{ui:Մասշտաբ}} և {{ui:Չափանալար}} (երբ չափում եք կետից) գործիքներում՝ առաջին սեղմումից հետո։ {{ui:Մղել/քաշել}}-ը միշտ շարժվում է երեսի ուղղությամբ և կողպումներ չունի։ {{ui:Պտտել}}-ում սլաքի ստեղները առաջին սեղմումից հետո ցույց են տալիս «Կողպված» հաղորդագրություն, բայց չեն փոխում պտույտը։

## Սլաքի ստեղները այլ պահերին

Երբ ոչ մի գործիք մեջտեղում չէ, սլաքի ստեղները տեղաշարժում են տեսախցիկը.

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Պտույտ |
| {{key:Shift}} սլաքով | Տեղաշարժ |

Պատճենելը, տեղադրելը, հետարկելը, պահելն ու բացելը պահում են վերևում թվարկված ստեղները։ Մուտքագրված արժեքները, արժեքի վանդակը և {{ui:Մղել/քաշել}}-ը աշխատում են նույնը երկու ոճում։

## Հպման էկրան

| Ժեստ | Ինչ է անում |
|---|---|
| Հպում | Մեկ սեղմում ընթացիկ գործիքով |
| Կրկնակի հպում | Կրկնակի սեղմում |
| Սեղմել, քաշել, բարձրացնել | Նույնն է, ինչ սեղմել, քաշել, թողնել մկնիկով |
| Երկու մատ՝ մերձեցում | Մասշտաբ |
| Երկու մատ՝ միասին շարժում | Տեղաշարժ ({{ui:Կարգավորումներ}} › {{ui:ModelCraft}} › Հպման էկրան-ը կարող է դարձնել Պտույտ) |
| Երեք մատ՝ միասին շարժում | Պտույտ (տեղաշարժ, երբ երկու մատը պտտում է) |
| Մեկ մատը անշարժ պահել | Ավարտում է գործիքը, ինչպես {{key:Enter}}-ը. եթե ոչինչ չի ընթանում, ապա քաշեք՝ պտտելու համար |
| Երկրորդ մատ մեկ մատի գործողության ընթացքում | Չեղարկում է այդ գործողությունը |
| {{ui:Պտույտ}} գործիք, ապա մեկ մատի քաշում | Պտույտ |

Արժեք մուտքագրելու համար հպման էկրանին հպեք ներքևի արժեքի վանդակին, մուտքագրեք և սեղմեք ստեղնաշարի {{key:Enter}} (կամ Go) ստեղնը։

## Որտեղ է Տեղափոխել-ը

Տեղափոխելը գտնվում է {{ui:Տեղափոխել}} գործիքում, ստեղնը՝ {{key:M}}. ընտրեք, թե ինչ տեղափոխել, սեղմեք բազային կետ, ապա երկրորդ կետ կամ մուտքագրեք հեռավորություն։ Տես [Տեղափոխել, պատճենել և ստեղծել զանգվածներ](topic:move-copy)։
