ModelCraft-ը վաղ տարբերակ է։ Այս էջը թվարկում է այն, ինչ դեռ չի անում, որպեսզի դուք դա չփնտրեք, և այսօր աշխատանքը կատարելու մոտակա եղանակը։

## Գծագրման գործիքներ

| Դեռ ոչ | Փոխարենը, այսօր |
|---|---|
| Ազատ գծագրություն | Կետերը սեղմեք {{ui:Կոր}}-ով |
| Աղեղի կամ շրջանի հատվածների թիվը փոխել դրա գծագրումից հետո | Ջնջեք և նորից գծեք՝ `24s` գրելուց հետո |
| Ընտրել տառատեսակ [3D տեքստի](topic:text3d) համար կամ փոխել դրա բառերը տեղադրելուց հետո | Ջնջեք և նորից ավելացրեք տեքստը |
| Փոխել անկյունը՝ անկյունային չափի մեջ թիվ գրելով, կամ գլանի չափը՝ դրա շրջանի չափից | {{ui:Պտտել}}-ով պտտեք եզրերը․ {{ui:Մասշտաբ}}-ով մասշտաբավորեք գլանը |
| Չափեր արտահանված մոդելի ֆայլերում | Չափերը երևում են տեսքի պատկերներում, տպագրություններում և PDF-ներում․ մոդելի ֆայլերը պարունակում են միայն գեոմետրիա |
| {{ui:Կտրել}}, {{ui:Բաժանել}} և արտաքին պատյան | [Միավորել, Հանել և Հատել](topic:solids) փակ խմբերը, կամ [հատել նիստերը](topic:intersect) և ջնջել ավելորդը |
| Պտտման առանցքի ընտրությունը սլաքի ստեղներով | Սեղմեք {{ui:Պտտել}}-ի կենտրոնը այնպիսի նիստի վրա, որը նայում է առանցքի ուղղությամբ |
| Կողպումներ մեկից ավելի ուղղորդման միաժամանակ | Կողպեք մեկ ուղղություն սլաքի ստեղնով, ապա հենվեք կետի վրա |
| Չափափոխում թեք ուղղությամբ կամ չափի այնպիսի ծայրից, որը գտնվում է անկյունում չէ | Տեղադրեք չափը երկու անկյունների վրա, եզրի երկայնքով կամ կարմիր, կանաչ կամ կապույտ ուղղությամբ |

## Անիմացիա

| Դեռ ոչ | Փոխարենը, այսօր |
|---|---|
| Նիստերի, եզրերի, արևի օրվա ժամի, ոճի կամ թաքցված բաների անիմացիա | Շարժվող մասը դարձրեք խումբ կամ բաղադրիչ․ այլ օրվա ժամի համար առանձին տեսանյութ ռենդերեք |
| Տեսախցիկ, որը հետևում է գծված ուղուն կամ նայում շարժվող օբյեկտին | Ավելի շատ տեսախցիկի կադրեր դրեք ճանապարհին ([Անիմացնել](topic:animation)) |
| Ձայն տեսանյութերում և բարձր որակի (ճառագայթային հետագծմամբ) տեսանյութեր առանց WebGPU-ի | Ձայնը ավելացրեք տեսանյութերի խմբագրիչում․ առանց WebGPU-ի ռենդերեք տեսանյութը արագ ռենդերիչով ([Ռենդերել տեսանյութը](topic:animation#render-the-video)) |
| Անիմացված լամպեր (պայծառություն, տարածում, գույն) ռենդերված տեսանյութում, ոսպնյակի անկյունն անիմացված առանց տեսախցիկի կադրերի, նյութերի կամ ռենդերի կարգավորումների անիմացիա | Լամպերը անիմացվում են տեսքում․ տեսանյութի համար նաև տեսախցիկը կադրավորեք զումի համար․ տարբեր լամպի կարգավորումների համար ռենդերեք առանձին տեսանյութեր ([Անիմացնել ցանկացած հատկություն](topic:animate)) |
| Կշիռների կամ ոսկորների արտացոլում մի կողմից մյուսը, տեսանելի ոսկորների պատյաններ, կշիռների ցուցադրում կետ առ կետ ստվերավորմամբ (ցուցադրվում են ըստ նիստի), դիրքավորված ցանցը տեսնելը կշիռներ նկարելիս | Նկարեք երկու կողմերը, կամ պատրաստեք մեկ կեսը և օգտագործեք Mirror մոդիֆիկատոր՝ մինչև կմախք ավելացնելը․ ստուգելու համար անցեք Նկարել կշիռները և Դիրք ռեժիմների միջև |
| Ոսկորներ, որոնք կարդացվում են glTF, FBX կամ USD ֆայլերից որպես կմախք, և կմախքներ, որոնք գրվում են այդ ֆայլերում | Ոսկորներով մոդելները բեռնվում են հանգստի վիճակում՝ ֆայլի կշիռներով․ ավելացրեք ոսկորները ֆայլի հոդերի հերթականությամբ, ապա՝ {{ui:Օգտագործել ֆայլի կշիռները}} ([Անիմացնել](topic:animate)) |
| IK նպատակակետի կամ բևեռի տեղափոխումը տեսքում քաշելով, սահմանափակման սեփական տարածությունը (տեղական կամ համաշխարհային) ընտրելը, IK շղթաների ձգումը, IK կորի երկայնքով | Գրեք նպատակակետի կետը, կամ նշեք օբյեկտի վրա և տեղափոխեք այն․ պահեք շղթաները իրենց երկարություններում |
| Կտոր, հեղուկներ, փափուկ մարմիններ, հոդեր և առանցքներ կոշտ մարմինների միջև, բախում օբյեկտի ճշգրիտ ձևի հետ (միայն տուփերն ու գնդերը են շրջապատում), կենդանի սիմուլյացիա նվագելու ընթացքում, սկզբնական արագություն կամ պտույտ (մարմինները սկսում են հանգստի վիճակում) | Կոշտ մարմինները ամրացրեք և նվագեք կադրերը․ հոդը կառուցեք կադրերով․ անսովոր ձևը բաժանեք տուփերի (խմբերի) |
| Անիմացիան արտահանել glTF կամ այլ մոդելի ֆայլերի մեջ | Ռենդերեք տեսանյութ․ `.modelcraft` ֆայլը և ModelCraft-ի պահած [USD ֆայլը](topic:usd) պահեք ModelCraft-ի համար |
| VR-ում խնդրի վրա մեկնաբանություն կամ վերնագիր գրել, ձայնային նշումներ, հատվածի հարթությունը ձեռքով տեղափոխել VR-ում | Տեղադրեք խնդիրը VR-ում, ապա դրա բառերը ավելացրեք BCF ծրագրում․ մտնելուց առաջ տեսքում դրեք հատվածի հարթություն․ տես [Վերանայել մոդելը VR ականոցով](topic:vr-review) |
| Մարդկանց տեսնել VR-ում սեղանի մոտ (ցուցադրվում են միայն VR-ում գտնվող մարդիկ), VR-ում քայլքի ձայնագրում | Խնդրեք նրանց միանալ VR-ին, կամ պատրաստեք քայլքի [անիմացիա](topic:animation) |

## Ցանցեր (Meshes)

| Դեռ ոչ | Փոխարենը, այսօր |
|---|---|
| Քանդակում մակարդակներով (multiresolution), և Detail-ը, որը հեռացնում է դարձած փոքր եռանկյունները | [Քանդակել](topic:sculpt) ենթաբաժանված ցանցը․ {{ui:Նորից ցանցավորել}}՝ նորից հավասարեցնելու համար |
| Ցանցավորում չորսանկյուն նիստերի, որոնք հետևում են ձևին | {{ui:Նորից ցանցավորել}} (հավասար եռանկյուններ), ապա վերակառուցեք [Ռետոպոլոգիայով](topic:mesh-edit#retopology) |
| Գագաթների վրա նկարված կշիռներ մոդիֆիկատորների համար (Displace, Smooth և Shrinkwrap-ը աշխատում են ամբողջ ցանցի վրա) | Կիրառեք մոդիֆիկատորը, ապա քանդակեք կամ խմբագրեք այն մասերը, որոնց պետք է դա |
| Գագաթների, եզրերի կամ նիստերի պատճենում և տեղադրում, կտրում դանակով, որը ավարտվում է նիստի ներսում, ծայրերով եզրեր առանց նիստի | Կրկնօրինակեք ցանցը Model-ում; կտրեք դանակով եզրից եզր; [Ձգեք](topic:mesh-edit#change-the-shape) բաց եզրերը նիստերի |

## Կազմակերպում և դիտում

| Դեռ ոչ | Փոխարենը, այսօր |
|---|---|
| DWG և DXF տեղադրման պլանների շերտերը որպես պիտակներ | Տեղադրման պլանը բեռնվում է որպես մեկ խումբ․ քանդեք այն և խմբավորեք այն մասերը, որոնք ուզում եք պիտակավորել |
| Մի քանի հատվածային կտրվածքներ միաժամանակ, հատվածի արկղ, կամ հատվածի ուրվագիծը որպես գծագիր արտահանված | Մեկ [հատվածի հարթություն](topic:sections) է կտրում միաժամանակ․ տեսքը արտահանեք որպես պատկեր |
| Փափուկ եզրերի ցուցադրում կետագծերով, կամ փափկեցում երբ քաշում եք սահնակը | [Փափկեցնել անկյունով](topic:soften) Օբյեկտի տվյալներում, և հետարկեք՝ այլ անկյուն փորձելու համար |
| Մոդելների առցանց գրադարան որոնման համար, կամ բաղադրիչներ՝ ընտրովի տարբերակներով (գույն, ոճ) | [Սկզբնական գրադարան](topic:starter)․ ներմուծեք Collada, OBJ կամ glTF մոդելներ․ [ձգեք](topic:stretch) պատճենը չափի համար |
| Բույսերի տեղադրում բույսերի գրադարանից | [Տեղադրեք](topic:live-view#scatter-plants-rocks-and-people) բույսերը կենդանի տեսքում, կամ տեղադրեք ծառ սկզբնական գրադարանից |
| Խմբի անկախ պատճեններ | Դարձրեք այն բաղադրիչ, ապա {{ui:Դարձնել եզակի}} (տես [Խնդիրների լուծում](topic:troubleshooting#editing-one-group-changed-another)) |

## Կատարողականություն

Հետարկումը պահում է մոդելի պատճենը յուրաքանչյուր քայլի համար ([ցանցը](topic:meshes) պահում է միայն փոխվածը), ուստի շատ մեծ ներմուծումները դարձնում են յուրաքանչյուր խմբագրումը ավելի դանդաղ։ Պահեք ներմուծումները թեթև, և պահեք ու նորից բացեք՝ պատմությունը մաքրելու համար։

## Հավելվածներ և հարթակներ

- **Աշխատասեղան՝** ModelCraft-ը աշխատում է դիտարկիչում Mac, Windows և Linux-ում, և CadCraft Studio-ում՝ աշխատասեղանի հավելվածում, որը բոլոր ութ հավելվածները պարունակում է մեկ տեղադրմամբ։ Android-ում CadCraft Studio-ն տեղադրվում է իր APK-ից՝ getcadcraft.com/download-ից։ iPad կամ iPhone տարբերակ դեռ չկա։
- **Շոշափելի էկրան՝** տես [Պտտել, տեղաշարժել և մասշտաբավորել](topic:orbit-pan-zoom) մատների ժեստերի համար։ Գրչի ճնշումը սահմանում է խոզանակը [Քանդակում](topic:sculpt)-ում․ մնացած տեղերում ճնշումը և գրչի թեքությունը չեն օգտագործվում։
- **Թերթեր՝** ModelCraft-ը [տպում է մեկ տեսք մեկ էջում](topic:export-model#print-the-view-or-save-it-as-a-pdf)․ չկան թերթի դասավորություններ մի քանի տեսքերով և վերնագրի բլոկով։ Գծագրերը մասշտաբով արտահանեք CadCraft-ին հարմար DWG/DXF։
