ModelCraft нь эртний хувилбар юм. Энэ хуудас юу хийдэггүйг жагсаана, ингэснээр та үүнийг эрэх хэрэггүй, мөн одоо ажлаа хийх хамгийн ойрын арга замыг харуулна.

## Зурах хэрэгслүүд

| Одоогоор байхгүй | Оронд нь, одоо |
|---|---|
| Чөлөөт зураг | {{ui:Curve}} хэрэгслээр цэгүүдийг дарна уу |
| Зурсны дараа нумын эсвэл тойргийн сегментийн тоог өөрчлөх | Устгаад, `24s` бичсэний дараа дахин зурна уу |
| [3D текст](topic:text3d)-ийн фонт сонгох, эсвэл байрлуулсны дараа үгийг нь засах | Устгаад текстийг дахин нэмнэ үү |
| Өнцгийн хэмжээсэд тоо бичих замаар өнцгийг өөрчлөх, эсвэл цилиндрийн хэмжээг тойргийн хэмжээсээс өөрчлөх | Ирмэгүүдийг {{ui:Rotate}}-ээр эргүүлэх; цилиндрийг {{ui:Scale}}-ээр масштабын | 
| Экспортолсон загварын файлд хэмжээсүүд | Хэмжээсүүд харагдацын зураг, хэвлэлт ба PDF-д гарна; загварын файлд зөвхөн геометр байна |
| {{ui:Trim}}, Split ба Гадна бүрхүүл | [Union, Subtract ба Intersect](topic:solids) хаалттай бүлгүүд, эсвэл [гадаргуу огтлолцуулах](topic:intersect) ба хэрэггүй зүйлээ устгана |
| Сумтай товчоор эргүүлэх тэнхлэг сонгох | Тэнхлэг заах чиглэлтэй гадаргуу дээр {{ui:Rotate}} төвийг дарна уу |
| Нэг зэрэг хоёроос дээш чиглэлийг түгжих | Нэг чиглэлийг сумтай товчоор түгжээд, дараа нь цэг дээр барина уу |
| Налуу дагуу, эсвэл булан дээр биш хэмжээсийн үзүүрээс хэмжээг өөрчлөх | Хэмжээсээ хоёр булан дээр, ирмэгийн дагуу, эсвэл улаан, ногоон, цэнхэр тэнхлэгийн дагуу байрлуулна уу |

## Анимейшн

| Одоогоор байхгүй | Оронд нь, одоо |
|---|---|
| Гадаргуу, ирмэг, нарны өдрийн цаг, загвар эсвэл нуусан зүйлийг анимейшнд оруулах | Хөдөлгөөнт хэсгийг бүлэг эсвэл компонент болгоно; өөр өдрийн цагт зориулж тусдаа видео рендерлэнэ |
| Зурсан замыг дагадаг эсвэл хөдөлгөөнт объектыг харж буй камер | Замын дагуу камерын түлхүүрүүдийг илүү тавина уу ([Анимейшн](topic:animation)) |
| Видео дахь дуу, мөн WebGPU-гүй өндөр чанарын (path-traced) видео | Дууг видео засварлагчид нэмнэ; WebGPU-гүй үед видеог хурдан рендерээр рендерлэнэ ([Видео рендерлэх](topic:animation#render-the-video)) |
| Рендерлэсэн видео дахь анимейшн гэрэл (гэрэлтэлт, тархалт, өнгө), камерийн түлхүүргүйгээр видеонд линзний өнцгийг анимейшнд оруулах, материал эсвэл рендерийн тохиргоог анимейшнд оруулах | Гэрэл нь харагдацдаа хөдөлнө; видео дээр томруулахын тулд камерын түлхүүрийг бас тавина уу; өөр гэрлийн тохиргоонд зориулж тусдаа видео рендерлэнэ үү ([Аливаа шинж чанарыг анимейшнд оруулах](topic:animate)) |
| Жингийг эсвэл яснуудыг нэг талаас нөгөөд толиорлох, харагдах яс бүрхүүлүүд, жинг цэг тус бүрээр сүүдэрлэх (тэд гадаргуу тус бүрээр харуулдаг), жин будах үед хэлбэр тогтсон mesh-ийг харах | Хоёр талыг будна уу, эсвэл нэг талыг хийгээд армэтур нэмэхээс өмнө Mirror модификатор ашиглана уу; шалгахдаа Жин будах ба Pose-ийн хооронд шилжинэ үү |
| glTF, FBX эсвэл USD файлаас яс уншиж армэтур болгох, мөн тэдгээр файлд армэтур бичих | Яс бүхий загварууд файлын жингээр амарч орно; яснуудыг файлын үе мөрийн дарааллаар нэмээд, дараа нь {{ui:Use the file's weights}} ([Анимейшн](topic:animate)) |
| IK зорилтыг эсвэл туйлыг харагдацад чирж зөөх, constraint-ийн өөрийн орон зай (local эсвэл world) сонгох, IK гинжийг сунгах, муруйн дагуух IK | Зорилтын цэгийг бичнэ үү, эсвэл объект руу чиглээд тэрийг зөөнө үү; гинжийг урттайгаа байлгана уу |
| Даавуу, шингэн, зөөлөн биет, хатуу биетүүдийн хооронд үе эсвэл салаа, объектын яг хэлбэртэй мөргөлдөөн (зөвхөн хайрцаг ба бөмбөлөг л тойрсон байдаг), тоглуулахад бодит цагийн симуляци, эхлэх хурд эсвэл эргэлт (биетүүд тайван эхэлнэ) | Хатуу биетийг шарж түлхүүрүүдийг тоглуулна; үеийг түлхүүрээр бүтээнэ; хачин хэлбэрийг хайрцаг (бүлэг) болгон хуваана |
| Анимейшнийг glTF эсвэл бусад загварын файлд экспортлох | Видео рендерлэнэ; `.modelcraft` файл болон ModelCraft-ийн хадгалсан [USD файл](topic:usd) нь ModelCraft-д зориулагдсан |
| VR дээр асуудалд гарчиг эсвэл тайлбар бичих, дуут тэмдэглэл, VR дотор хэсгийн хавтгайг гараар зөөх | Асуудлыг VR дотор байрлуулаад, үгийг нь BCF программд нэмнэ; VR-д орохоосоо өмнө харагдацад хэсгийн хавтгайг тохируулна уу: см. [VR шилэнд загварыг шалгах](topic:vr-review) |
| VR дэх ширээний хүмүүсийг харах (зөвхөн VR дахь хүмүүс харагдана), VR алхалтыг бичих | Тэдэнд VR-д нэгдэхийг хүснэ үү, эсвэл алхалтын [анимейшн](topic:animation) хийнэ үү |

## Mesh

| Одоогоор байхгүй | Оронд нь, одоо |
|---|---|
| Түвшнээр мүүсэх (multiresolution), мөн жижиг болсон гурвалжнуудыг Detail-ээр устгах | Дэд хуваасан mesh-ийг [Скульптинг](topic:sculpt) хийгээд, дахин тэгшлэхийн тулд {{ui:Remesh}} |
| Хэлбэрийг дагасан дөрвөн талт гадаргуу болгон remesh хийх | {{ui:Remesh}} (жигд гурвалжнууд), дараа нь [Retopology](topic:mesh-edit#retopology) ашиглан дахин бүтээнэ |
| Модификаторуудад зориулсан оройн жин будах (Displace, Smooth, Shrinkwrap бүх mesh дээр ажиллана) | Модификаторыг хэрэглээд, дараа нь хэрэгтэй хэсгүүдийг скульптинг хийх эсвэл засна уу |
| Оройн, ирмэгийн, гадаргуугийн хуулах, буулгах, гадаргуугийн дотор дуусах хайчилбар, гадаргуугүй утас шиг ирмэгүүд | Mesh-ийг Model дотор хуулбарлана; ирмэгээс ирмэг хүртэл хайчилна; нээлттэй ирмэгүүдийг [Extrude](topic:mesh-edit#change-the-shape) ашиглан гадаргуу болгоно |

## Зохион байгуулалт ба харах

| Одоогоор байхгүй | Оронд нь, одоо |
|---|---|
| DWG ба DXF сайтын төлөвлөгөөний давхаргууд tag болгох | Сайтын төлөвлөгөө нэг бүлэг болж орно: үүнийг задалж, tag хийх хэсгүүдээ бүлэглэнэ үү |
| Хэд хэдэн хэсгийн огтлол зэрэг, хэсгийн хайрцаг, эсвэл хэсгийн гадна зургийг зураг болгон экспортлох | Нэг [хэсгийн хавтгай](topic:sections) нэг удаад огтолно; харагдацыг зураг болгон экспортлоно |
| Зөөлөн ирмэгүүдийг тасархай харуулах, эсвэл слайдер чирэхэд зөөлрүүлэх | Объектын мэдээлэлд [өнцгөөр зөөлрүүлэх](topic:soften), дараа нь өөр өнцөг туршихын тулд буцаана уу |
| Хайх онлайн загварын сан, эсвэл өнгө, хэв маягаар сонгож болох компонентууд | [Эхлэх сан](topic:starter); Collada, OBJ, glTF загварыг импортлох; хуулбарыг хэмжээнд нь [сунгах](topic:stretch) |
| Ургамлын санаас ургамал байрлуулах | Амьд харагдацад [ургамал, хад, хүмүүсийг тараах](topic:live-view#scatter-plants-rocks-and-people), эсвэл эхлэх сангаас модыг байрлуулна |
| Бүлгийн бие даасан хуулбарууд | Компонент болгоод, дараа нь {{ui:Make unique}} (см. [Асуудал шийдэх](topic:troubleshooting#editing-one-group-changed-another)) |

## Гүйцэтгэл

Undo алхам бүрт загварын хуулбарыг хадгалдаг ([mesh](topic:meshes) зөвхөн өөрчлөгдсөн хэсгийг хадгална), тиймээс түлхэх/татах геометрийн маш том импорт засвар бүрийг удаашруулна. Импортыг хөнгөн байлгаж, түүхийг цэвэрлэхийн тулд хадгалаад дахин нээнэ үү.

## Апп ба платформ

- **Desktop:** ModelCraft нь Mac, Windows, Linux дээр хөтөч дотор ажиллана, мөн нэг суулгалтад найман аппыг агуулсан CadCraft Studio desktop апп дээр. Android дээр CadCraft Studio-г getcadcraft.com/download дахь APK-аас суулгана. iPad эсвэл iPhone-ийн хувилбар одоогоор байхгүй.
- **Мэдрэгч:** хурууны аваалтуудын талаар [Эргүүлэх, шилжүүлэх ба томруулах](topic:orbit-pan-zoom)-ийг харна уу. Үзэгний даралт [Скульптинг](topic:sculpt) дээрх сойзыг тохируулна; бусад газар даралт ба үзэгний налалтыг ашиглахгүй.
- **Хуудас:** ModelCraft [хуудас тус бүрт нэг харагдац хэвлэнэ](topic:export-model#print-the-view-or-save-it-as-a-pdf); хэд хэдэн харагдац ба гарчгийн блоктой хуудасны зохион байгуулалт байхгүй. Масштабтай зурагт зориулж CadCraft-д тохирсон DWG/DXF руу экспортлоно уу.
