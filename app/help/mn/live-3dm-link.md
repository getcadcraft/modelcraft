Загвараа өөрийнхөө програмд үргэлжлүүлэн загварчилж, үр дүнг энд ашиглана: рендерлэх, гэрэлтүүлэх, эсвэл түүний эргэн тойронд сцен зохион байгуулах. Нөгөө програм дахь өөрчлөлт бүр ModelCraft дотор нэг бүлгийг шинэчилнэ.

:::note
Холболтод ижил компьютер дээр **CadCraft Studio** хэрэгтэй. Хөтчийн таб холболтыг авч чадахгүй. Интернэтээр юу ч дамжихгүй: скрипт нь Studio-той энэ компьютерийн өөрийн хаягаар, токен ашиглан харилцана.
:::

:::warning
Энэ холболтыг скриптийн файл бичигч болон нөгөө програмын орлуулагчтай туршсан, харин Rhino эсвэл Grasshopper-ийн дотор бүрэн туршаагүй байна. Тэнд ямар нэг зүйл амжилтгүй болбол юу гэж гарснаа бидэнд мэдэгдэнэ үү.
:::

## Тохируулах

1. Studio-д ModelCraft-ыг нээнэ. {{ui:Тохиргоо}} › {{ui:ModelCraft}} › {{ui:Туслахууд}} хэсэгт **AI туслахууд болон скриптүүдэд ModelCraft-ыг ашиглуулах**-ыг тэмдэглээд, дараа нь **Засварлах**-ыг дарна.
2. Studio-д {{ui:Туслахтай холбох}}-ыг сонгоно. Энд доор наах хаяг болон токен харагдана.
3. Скриптээ татаж авна: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino-оос

1. Rhino-ийн скрипт редактор дээр `cadcraft_link.py`-г ажиллуулна (Rhino 8-д Python 3).
2. Анх удаа хаяг болон токеныг наана. Тэдгээр нь таны нүүр хавтасны `.cadcraft-link.json` дотор хадгалагдана, загвар дотор хэзээ ч хадгалагдахгүй. Studio эхлэх бүрт шинэ токен үүсгэдэг тул скрипт дахин асууна.

Бүх загвар нэг бүлэг болж ирнэ; бүлэг нь баримт бичгийнхээ нэрээр нэрлэгдэнэ, жишээ нь "chair (linked)". Үүний дараа өөрчлөлт бүр бага зэрэг зогсоход ирэх бөгөөд зөвхөн өөрчлөгдсөн объектууд илгээгдэнэ. Зогсоохын тулд скриптийг дахин ажиллуулна.

## Grasshopper-оос

Эхлээд Rhino-д скриптийг нэг удаа ажиллуулна, ингэснээр хаяг болон токен хадгалагдана.

1. Python 3 Script компонент нэмээд, `cadcraft_link.py`-ийн бүхэлд нь наана.
2. Түүнд эдгээр оролтыг өгнө: `G` (геометр, жагсаалтын хандалттай), `N` (нэр, сонголтоор), `On` (логик унтраалга), `Target` (сонголтоор: `model` эсвэл `part`, хоёр аппликейшн нээлттэй үед).
3. `On`-ийг true болгоно.

Бодолт бүр `G`-г илгээж, компонентийн өмнө илгээснийг солино; ингэснээр слайдерыг чирэхэд энд байгаа бүлэг шинэчлэгдэнэ. Гаралт `a` нь юу болсныг харуулна. Компонент бүр өөрийн бүлэгтэй.

## Бүлгээрээ юу хийж болох вэ

- **Зөөх, тэмдэглэх, эргэн тойронд нь барих.** Бүлгийн байрлал ба түүний тэмдэг шинэчлэлт бүрт хэвээр үлдэж, түүний хажууд байгаа бүх зүйл мөн адил.
- **Доторх зүйлийг засахгүй.** Шинэчлэлт бүр бүлгийн доторх зүйлийг солино. Тэдгээр объектыг нөгөө програм эзэмшдэг.
- **Буцаах.** Хоорондоо хоёр секундээс бага зайтай шинэчлэлтүүд нэг буцаах алхам хуваана, тиймээс {{key:Mod+Z}} бүтэн чирэлтийг буцаана. Дараагийн шинэчлэлт загварыг таарахаар дахин авчирна.
- **Хадгалах.** Хадгалсан файл холболтыг хадгална. Дахин нээсний дараа скриптийг ажиллуулахад ижил бүлэг шинэчлэгдэнэ.

## Юу орж ирэх вэ

Мэш, полигадаргуу, гадаргуу ба түлхэлтийг дэлгэц дээр харагдах мэш хэлбэрээр; SubD-ийг өөрийн мэшээр; муруйг ирмэгээр; блокуудыг байгаа газраа тусдаа объектоор (бүрдэл биш); давхаргуудыг тэмдэг болгон, өнгө ба нэгжүүдийг. Эдгээр энд хэрхэн харагдахыг [.3dm загвар импортлох](topic:import-3dm-files)-аас үзнэ үү.

Орхигдох зүйлс, нөгөө програм дахь тоотой: цэг, текст, хэмжээс, гэрэл болон бусад.

**Нэг чиглэлд л.** Энд хийсэн өөрчлөлт нөгөө програм руу буцаж очихгүй.

## Хэрэв алдаа гарвал

- **«Ямар ч ModelCraft эсвэл PartCraft цонх зөвшөөрөхгүй»:** тохируулгын 1-р алхамыг хийнэ үү.
- **«Studio токеныг татгалзлаа»:** Studio дахин эхэлсэн. Шинэ токеныг хуулаад скриптийг дахин ажиллуулна уу. Grasshopper-ийн хувьд эхлээд Rhino-д ажиллуулна.
- **«CadCraft Studio-д хүрч чадахгүй байна»:** Studio ажиллахгүй байна, эсвэл хаяг өөрчлөгдсөн байна.
