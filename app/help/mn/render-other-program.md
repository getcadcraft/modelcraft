{{ui:Зураг рендерлэх…}}-ийн зургийг **манай хөдөлгүүрүүд** зурдаг: Хурдан ба Path tracer, браузер ба CadCraft Studio дээр. Өөр програм зөвхөн **рендер хөдөлгүүрийн нэмэлт** авчирсан үед л зурж чадна: [Нэмэлтээр рендер хөдөлгүүр нэмэх](topic:render-engine-addons)-ыг үзнэ үү. Үзэгдлийг өөр програмд авч явж, тэнд ажиллаж үргэлжлүүлэхийн тулд [Үзэгдлийг өөр програмд нээх](topic:render-open-in) эсвэл [Үзэгдлийг тоглоомын хөдөлгүүрт илгээх](topic:render-unreal)-ийг ашигла.

## Нэмэлтийн хөдөлгүүрээр зураг зурах

1. Тохиргоо › Нэмэлтээс нэмэлтийг асаа. Түүний хөдөлгүүр {{ui:Зураг рендерлэх…}}-ийн Хөдөлгүүр жагсаалтад гарна.
2. Түүнийг сонго. Түүний өөрийн тохиргоо Хөдөлгүүр жагсаалтын доор харагдана.
3. {{ui:Рендер}} дар. CadCraft Studio-д нэмэлт програм анх ажиллахад Studio өөрийн харилцах цонхоороо асууна. Зурах явцад явц харагдана; {{ui:Зогсоох}} үүнийг дуусгана. Зураг тэр хөдөлгүүрийн нэрээр тэмдэглэгдэн гарна.

JavaScript-ээр бичсэн хөдөлгүүр браузерт ч ажиллана. Энэ компьютер дээр програм ажиллуулдаг хөдөлгүүр зөвхөн Studio дээр ажиллана; браузерт хадгалах файл гэж харагдана.

## Юу дамжигдах вэ

Хөдөлгүүр **багц** авна: загвар USD файл хэлбэрээр (мөн шаардвал glTF файл), мөн тохиргооны файл: материалын яг утгууд, нар ба тэнгэр, асаалттай гэрэл бүр чадал ба гэрлийн профайлтайгаа, камер ба экспозиц. Програм бүр өөрийнхөөрөө гэрэлтүүлж, өнгө тохируулж, дээжлэнэ тул зургууд камер, нар, гэрэл, экспозицид төстэй, харин пикселээр яг адил биш байна.

## CadCraft-ын хэзээ ч ажиллуулдаггүй програмууд

CadCraft GNU GPL лицензтэй програмыг хэзээ ч эхлүүлдэггүй, хэзээ ч хөдөлгүүр эсвэл Өөр програмд нээх зорилт гэж жагсаадаггүй. Blender бол тэдний нэг тул Хөдөлгүүр жагсаалтад байхгүй. {{ui:Зураг рендерлэх…}}-ээс хадгалсан USD эсвэл glTF файл нь үүнийг уншдаг бусад програм шиг нээгдэнэ.

:::note
Панорама ба стерео камер, тэнгэрийн зураг (тэнгэрийн өнгө ашиглагдана) өөр програмд дамжихгүй. Өөр програмд хийсэн юу ч загварт буцаж ирэхгүй.
:::
