## ModelCraft файл

`.modelcraft` файл нь бүх загварыг хадгална: геометр, бүлэг, компонент, удирдамж, үзэгдэл, нэгжүүд, мөн хадгалах үед та ашиглаж байсан камер ба хэв маяг. Буцаах түүхийг хадгалахгүй.

### Загвар нээх

1. {{ui:Файл}} бүлгийн {{ui:Нээх}} дээр дарна, эсвэл {{key:Mod+O}} дарна.
2. Дэлгэц дээрх загварт хадгалаагүй өөрчлөлт байвал ModelCraft асууна: «Энэ загварт хадгалаагүй өөрчлөлт байна. Эхлээд хуулбарыг хадгалах уу?» Сонгоно: {{ui:Хуулбарыг хадгалах}}, {{ui:Өөрчлөлтийг хасах}} эсвэл {{ui:Цуцлах}}.
3. `.modelcraft` файлыг сонгоно.

Загвар хадгалсан нэгжээрээ, хадгалсан камертайгаа нээгдэнэ. Мөн `.modelcraft` файлыг 3D харагдац дээр буулгаж болно, эсвэл эхлэх картын сүүлийн файлуудын жагсаалтаас дарж болно (файлыг дахин нээж чадах хөтчүүд, ширээний програм).

:::desktop
Ширээний програмд `.modelcraft` файл дээр хоёр удаа дарахад ModelCraft-д нээгдэнэ. Мөн Collada, OBJ, glTF, DWG эсвэл DXF файл дээр **Open with** гэснээр адил нээгдэнэ (шинэ загварт импортлогдоно).
:::

### Загвар хадгалах

{{ui:Хадгалах}} дээр дарна, эсвэл {{key:Mod+S}} дарна. Хөтөч `<name>.modelcraft` файлыг татаж авна; нэр нь таны нээсэн файлын нэр, эсвэл шинэ загварын хувьд "Untitled".

:::desktop
Ширээний програмд {{ui:Хадгалах}} нь таны нээсэн файлд шууд бичнэ. Шинэ загвар хаана хадгалахыг асууна.
:::

- {{ui:Хадгалах хэлбэр}} ({{key:Mod+Shift+S}}) нь хуулбарыг `.modelcraft` файл эсвэл [USD](topic:usd) хэлбэрээр хадгална; хөтөч боломжтой бол нэр ба байршлыг асуудаг. Үгүй бол татсан файлаа нэрийг нь солино: нэрийг солисон файлаа нээгээд дараагийн хадгалалт шинэ нэрийг ашиглана.
- Хадгалах бүр шинэ татаж авалт юм. Хөтчийн тохиргооноос хамаарч шууд татаж авах хавтас руу очих эсвэл хаана хадгалахыг асуух болно. Ижил нэртэй файл аль хэдийн байвал ихэнх хөтөч `Untitled (1).modelcraft` гэх мэт дугаар нэмнэ.

:::chromium
Хавтсыг бүр сонгохын тулд хөтчийн тохиргоог нээгээд "downloads" гэж хайж, "Ask where to save each file before downloading" гэснийг асаана.
:::

:::firefox
Хавтсыг бүр сонгохын тулд **Settings**, дараа нь **General** нээгээд "Downloads" доорх "Always ask you where to save files" гэснийг сонгоно.
:::

:::safari
Татаж авалт хаашаа очихыг өөрчлөхийн тулд **Safari**, дараа нь **Settings**, дараа нь **General** нээгээд "File download location" тохируулна.
:::

### Шинэ загвар эхлүүлэх

{{ui:Шинэ}} дээр дарна. Хадгалаагүй өөрчлөлт байвал ModelCraft эхлээд асууна. Шинэ загвар хоосон, таны бүсийн нэгжээр эхэлнэ (АНУ-д фут ба инч, бусад газар миллиметрээр), үзэгдэлгүйгээр.

### Хөтөч хадгалахаас өмнө хаагдвал

ModelCraft өөрчлөлт бүрийн дараа хэдхэн секундын дотор хадгалаагүй ажлын хуулбарыг таны хөтөчид хадгална. Хэрэв та хадгалахаас өмнө таб эсвэл хөтөч хаагдвал, ModelCraft-ийг дараагийн удаа нээхэд «Ажлаа сэргээх үү?» гэж асууна. Сэргээвэл загвар өмнөх байдлаараа нээгдэнэ, гэхдээ файлд хадгалагдаагүй байна: хадгалснаар хадгална. Үзэх: [Ажлаа сэргээх](common:recover).

### CadCraft-аас: ModelCraft-д нээх

CadCraft зургийн програмд **Харагдац**, дараа нь **Нэмэлт**, дараа нь **ModelCraft-д нээх** гэснээр нээлттэй зургаа шинэ табд ModelCraft рүү DWG хэлбэрээр шилжүүлнэ. Импортлогдсон DWG шиг ирнэ: газар дээрх шугамууд, бүлэгт, загварчлахад бэлэн. Юу ч байршуулагдахгүй; файл таны хөтчийн өөрийн санах ойгоор дамжина.

## Импорт

Импортлох нь файлыг одоо нээлттэй загвартаа нэмнэ; түүнийг орлуулахгүй.

1. {{ui:Файл}} бүлгийн {{ui:Импорт}} дээр дарна, эсвэл файлыг 3D харагдац дээр буулгана.
2. SketchUp, Collada, OBJ, glTF, FBX, PLY, STL, Alembic, STEP, `.3dm`, USD, DWG эсвэл DXF файл сонгоно.

   Файл **нэг бүлэг** болж ирнэ, сонгогдсон, харагдац нь түүнийг харуулахаар томрно. Статус мөр юу ирснийг хэлж, импортлож чадаагүй зүйлсийг жагсаана, жишээ нь: «Импортлогдсонгүй: 2 текстур».

3. Геометрт нь шууд ажиллахын тулд бүлэг дээр хоёр удаа дараад доторх нь засварлах, эсвэл {{ui:Задлах}} дарна.

Мэдэх зүйлс:

- **Хэмжээ ба дээш чиглэл:** Collada файлууд өөрийн нэгж болон аль тэнхлэг дээш байхаа хэлдэг бөгөөд ModelCraft хөрвүүлдэг. glTF үргэлж метрээр байдаг. OBJ файлд нэгж байхгүй: ModelCraft-ийн уншихад метр, Y дээш гэж үзнэ. Хэрэв OBJ 1000 дахин том эсвэл жижиг орж ирвэл `0.001` эсвэл `1000` гэх мэт коэффициентээр [Масштаб](topic:rotate-scale) ашиглана.
- **DWG ба DXF** нь гадаргуу биш, газар дээрх шугам (ирмэг)-ээр орж ирнэ. Зураг өөрийн нэгжээ хэлээгүй бол «Зургийн нэгжүүд» гэсэн цонх нэг зургийн нэгж гэж юу болохыг асууна. Үзэх: [Талбайн план дээр загварчлах](topic:site-plan).
- **Хязгаар:** 300 MB-аас их файлыг импортлохоос, 200 MB-аас их файлыг нээхээс татгалзана. 2 сая-аас олон оройтой эсвэл гадаргуутай файлыг хэт том гэж үзэн татгалзана.

## Экспорт

1. {{ui:Файл}} бүлгийн {{ui:Экспорт}} дээр дарна.
2. Формат сонгоно: {{ui:glTF binary (.glb)}}, {{ui:Collada (.dae)}}, {{ui:OBJ (.obj)}}, {{ui:Хэвлэхэд зориулсан STL (.stl, миллиметрээр)}}, {{ui:Өнгөтэй PLY (.ply)}}, {{ui:USD (.usda, .usdc, .usdz)…}}, {{ui:BimCraft-д зориулсан IFC (.ifc)}}, {{ui:CAD-д зориулсан DWG (.dwg, 2004)}} эсвэл {{ui:CAD-д зориулсан DXF (.dxf, R12)}}.

Хөтөч файлыг загварын нэртэйгээр татаж авна. Бүх загвар экспортлогдоно, зөвхөн сонголт биш. Хоосон загвар экспортлогдохгүй: «Загвар хоосон байна: эхлээд ямар нэг зүйл зурна уу.» Үзэх: [Загварыг бусад програмд экспортлох](topic:export-model).

## Онлайн ба офлайн

ModelCraft-ийн бүх зүйл таны компьютер дээр ажилладаг тул аппыг ачаалсны дараа загварчлах, нээх, хадгалах, импортлох, экспортлох бүх зүйл холболтгүйгээр ажиллана.

ModelCraft-ийг огт холболтгүйгээр нээхийн тулд онлайн байхдаа офлайн хэрэглээнд хадгал:

1. Дээд талын аппын мөрөнд байгаа {{ui:Офлайнд хадгалах}} дээр дарна.
2. Хадгалах явцад товч тоолно («Хадгалж байна: 40 / 212»). ModelCraft өөрийн файлуудаа (түүний дотор DWG уншигчийг), энэ тусламжийг, мөн 3D номын санг хадгалдаг тул хэсэг хугацаа шаардаж болно.
3. Товч {{ui:Офлайнд бэлэн}} гэж харуулах үед ModelCraft ижил хаягаас холболтгүйгээр нээгдэнэ, мөн DWG импорт офлайнд ажиллана.

Дараа нь {{ui:Офлайнд бэлэн}} дээр дарж {{ui:Дахин хадгалах (хамгийн шинэ хувилбарыг авах)}} эсвэл {{ui:Офлайн хуулбарыг устгах}}-ыг сонгоно. Хэрэв товч {{ui:Хадгалж чадсангүй}} гэж харуулбал зарим файл татагдаагүй: холболтоо шалгаад, дахин оролдохын тулд дарна уу. {{ui:Офлайн боломжгүй}} гэдэг нь энэ хөтчийн цонх хуулбар хадгалж чадахгүй гэсэн үг (хувийн цонх болон зарим удирдлагатай компьютер). Үзэх: [Офлайнаар ажиллах](common:offline).

Үүлэн хадгалалт одоогоор боломжгүй. Загвар бүр таны хадгалсан газарт байрлана.

:::offline
Та офлайн байна. Загварчлах, хадгалах үргэлжлүүлж болно. Аппын мөрөнд {{ui:Офлайнд бэлэн}} харагдахгүй бол онлайн болтол энэ табыг дахин ачаалахгүй байгаарай.
:::
