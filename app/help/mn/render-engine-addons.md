Нэмэлт (Тохиргоо › {{ui:Нэмэлт}}) нь {{ui:Зураг рендерлэх…}}-ийн Хөдөлгүүр жагсаалтад хөдөлгүүр нэмж чадна. Нэмэлт зохиогчдод зориулсан бүрэн текст нь нэмэлтийн тодорхойлолтын 16-р хэсэгт байгаа; товчхондоо:

- Нэмэлт өөрийн дугаараар эхэлсэн id-тай хөдөлгүүр бүртгэнэ: нэр, нэмэлт тохиргоо, мөн **аль нэг нь** ажиллуулах програм **эсвэл** зургийг зурах JavaScript функц.
- Програм ажиллуулдаг хөдөлгүүрт **`engine.run`** зөвшөөрөл хэрэгтэй; энэ нь суулгахаас өмнө болон Тохиргоонд харагдана. Зөвхөн Studio дээр ажиллана; браузерт хадгалах файл гэж харагдана.
- Нэмэлт програмын нэрийг (зөвхөн энгийн файлын нэр, хэзээ ч shell биш), **гарын үсэгтэй нэмэлтийн дотор** байрлах скрипт, мөн орлуулагч ба энгийн үгнүүдээс бүрсэн аргументуудыг зааж өгнө. Studio програмыг олох эсвэл нэг удаа заахыг танаас хүснэ.
- Нэмэлт програмыг анх ажиллуулахад **Studio өөрийн харилцах цонхоороо асууна**: аль нэмэлт, аль програм, мөн скрипт програмын хийж чадах бүхнийг хийж чадна гэдгийг. Зөвхөн итгэдэг нэмэлтэд зөвшөөрөөрэй. Таны хариулт тэр нэмэлт ба програмд хадгалагдана.
- Багц (USD хэлбэрийн үзэгдэл ба тохиргооны файл, нэмэлт хүсвэл glTF файлтай хамт) ба нэмэлтийн скрипт шинэ түр хавтсанд орно, програм тэнд ажиллана, зураг нэмэлтийн хөдөлгүүрийн нэрээр тэмдэглэгдэн буцаж ирнэ.

:::note
Нэмэлтүүд зөвхөн нэмэлтийн API 1.4-өөс хойш рендер хөдөлгүүр нэмж чадна. Нээлттэй эхийн командын мөрийн рендерийн жишээ тусдаа репозиторт байгаа; тэр рендерт хараахан ажиллаагүй байна.
:::
