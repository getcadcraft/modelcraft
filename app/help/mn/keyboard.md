Эдгээр нь ModelCraft-ийн анхдагч, түлхэх/татах товчлуурууд. Нөгөө хэв маягийн тухай доорх [Modeler товчлуурууд](topic:keyboard#modeler-keys) болон [ModelCraft-ийн тохиргоо](topic:settings) харна уу.

Товчлолууд 3D харагдац эсвэл хэрэгслийн мөрийн товчлуур фокустай үед ажиллана. Хэрэв та самбарын талбарт бичсэн эсвэл {{ui:Хэв маяг}}-ын жагсаалтыг өөрчилсөн бол эхлээд 3D харагдац дээр дарна уу, эс тэгвээс товчлуурууд тэр талбарт очно. Компьютер бүр дээр товчлуурууд хэрхэн бичигддэгийг [Товчлуур, хулгана ба трекпад](common:keys) хэсгээс харна уу.

## Esc

{{key:Esc}} дарах бүрд нэг түвшин буцна:

1. Хэрэгсэл дунд байгаа зүйлээ цуцална (зурж буй шугам, түлхэх/татах, зөөх). Бүх зүйл буцна.
2. {{ui:Сонгох}} руу шилжинэ.
3. Сонголтыг арилгана.
4. Таны засч байгаа бүлгийг хаана.

Мөн сценууд тоглохыг зогсооно. Утгын хайрцагт {{key:Esc}} таны бичсэнийг арилгаж, харагдац руу буцна.

## Хэрэгсэл ажиллаж байхад

| Түлхүүр | Юу хийдэг |
|---|---|
| Цифр, эсвэл `. , - ' " [ < * /`-ын нэг | Утгын хайрцагт бичиж эхэлнэ |
| {{key:Enter}} | Утгын хайрцагт бичсэнийг хэрэглэнэ |
| {{key:Right}} | Улаан тэнхлэгт түгжинэ (дахин дарвал тайлагдана) |
| {{key:Left}} | Ногоон тэнхлэгт түгжинэ |
| {{key:Up}} | Цэнхэр тэнхлэгт түгжинэ |
| {{key:Down}} | Эхний дарахаас өмнө сүүлд заасан ирмэгтэй параллель түгжинэ |
| Барих {{key:Shift}} | Барьж байх хугацаанд таны наалдсан чиглэлийг барина |
| {{key:Ctrl}}, {{key:Mod}} эсвэл {{key:Alt}} (Зөөх) | Зөөх ба хуулах хооронд сольно |

Сумны товчлуурын түгжээ {{ui:Шугам}}, {{ui:Тэгш өнцөгт}}, {{ui:Тойрог}}, {{ui:Олон өнцөгт}}, {{ui:Зөөх}}, {{ui:Масштаб}} болон {{ui:Хэмжих хэрэгсэл}} (цэгээс хэмжих үед) дээр эхний дарсны дараа ажиллана. {{ui:Түлхэх/татах}} үргэлж гадаргуугийн чиглэлд хөдөлнө, түгжээгүй. {{ui:Эргүүлэх}}-д сумны товчлуурууд эхний дарсны дараа "Түгжээтэй" мессеж харуулна, гэхдээ эргэлтийг өөрчлөхгүй.

## Бусад үед сумны товчлуурууд

Хэрэгсэл дунд байхгүй үед сумны товчлуурууд камер хөдөлгөнө:

| Түлхүүр | Юу хийдэг |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Эргүүлэх (Orbit) |
| {{key:Shift}} + сум | Харагдац шилжүүлэх (Pan) |

## Хулгана

| Үйлдэл | Юу хийдэг |
|---|---|
| Дарах | Одоогийн хэрэгслийг ашиглана |
| Дарж, чирж, суллах | Хоёр дарсантай адил (зурах хэрэгслүүдэд); хайрцгаар сонгох ({{ui:Сонгох}}-д); замдаа устгана ({{ui:Устгагч}}-д) |
| Давхар дарах | {{ui:Сонгох}}: гадаргуу ирмэгүүдтэйгээ, ирмэг гадаргуутайгаа, бүлэг нээгдэнэ; хоосон зай нь бүлгийг хаана. {{ui:Түлхэх/татах}}: сүүлийн зайг давтана |
| Гурван удаа дарах | {{ui:Сонгох}}: холбогдсон бүх зүйл |

| {{key:Mod}} + дарах | {{ui:Сонгох}}: сонголтод нэмэх |
| {{key:Shift}} + {{key:Mod}} + дарах | {{ui:Сонгох}}: сонголтоос хасах |
| Дундах товчлуураар чирэх | Эргүүлэх, ямар ч хэрэгсэлтэй |

Баруун товчийн цэс байхгүй.

## Трекпад

Хоёр хурууны гүйлгэлт юу хийхийг {{ui:Тохиргоо}} › {{ui:ModelCraft}} › Гүйлгэлт (Scrolling) гэсэн тохиргоонд тулгуурлана:

| Үйлдэл | Трекпад (эсвэл тооцоолсон) | Хулганы дугуй |
|---|---|---|
| Хоёр хурууны гүйлгэлт | Эргүүлэх | Заагч руу томруулах |
| {{key:Shift}} + хоёр хурууны гүйлгэлт | Харагдац шилжүүлэх | Томруулах |
| Хурууг нийлүүлэх/тэлэх | Заагч руу томруулах | Заагч руу томруулах |
| Хоёр хурууны дарж чирэлт (хоёрдогч товчлуур дарагдсан) | Харагдац шилжүүлэх | Харагдац шилжүүлэх |

См. [Эргүүлэх, шилжүүлэх ба томруулах](topic:orbit-pan-zoom#on-a-trackpad) ба [ModelCraft-ийн тохиргоо](topic:settings#scrolling-mouse-wheel-or-trackpad).

| Түлхүүр | Юу хийдэг |
|---|---|
| {{key:W}} эсвэл {{key:Space}} | {{ui:Сонгох}} |
| {{key:L}} / {{key:B}} / {{key:C}} / {{key:N}} | {{ui:Шугам}} / {{ui:Тэгш өнцөгт}} / {{ui:Тойрог}} / {{ui:Олон өнцөгт}} |

## Мэдрэгчтэй дэлгэц

| Үйлдэл | Юу хийдэг |
|---|---|
| Товших | Одоогийн хэрэгслээр нэг дарсан |
| Давхар товших | Давхар дарсан |
| Дарах, чирэх, өргөх | Хулганын дарах, чирэх, суллахтай адил |
| Хоёр хуруу: нийлүүлэх/тэлэх | Томруулах |
| Хоёр хуруу: хамт хөдөлгөх | Харагдац шилжүүлэх ({{ui:Тохиргоо}} › {{ui:ModelCraft}} › Мэдрэгчтэй дэлгэц нь эргүүлэх болгож болно) |
| Гурван хуруу: хамт хөдөлгөх | Эргүүлэх (хоёр хуруу эргүүлж байвал харагдац шилжүүлэх) |
| Нэг хуруу хөдөлгөөнгүй барих | Enter шиг хэрэгслийг дуусгана; юу ч болоогүй бол чирж эргүүлнэ |
| Нэг хуруугаар үйлдэл хийж байхад хоёр дахь хуруу | Тэр үйлдлийг цуцална |
| {{ui:Эргүүлэх}} хэрэгсэл, дараа нь нэг хуруугаар чирэх | Эргүүлэх |

Мэдрэгчтэй дэлгэц дээр утга бичихийн тулд доод талд байгаа утгын хайрцгийг товших, бичих, гарны Enter (эсвэл Go) товчийг дарна.

## Move хаана байдаг вэ

Move нь {{ui:Зөөх}} хэрэгсэлд, товчлуур {{key:M}}: зөөх зүйлээ сонгоно, базын цэг дээр дарна, дараа нь хоёр дахь цэг эсвэл зайг бичнэ. См. [Зөөх, хуулах ба массив үүсгэх](topic:move-copy).
