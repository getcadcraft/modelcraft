{{ui:Khetha}} ({{key:Space}}) ngulo thuluzi ModelCraft aqala ngalo, futhi ngulo {{key:Esc}} akubuyisela kuwo. Izinto ezikhethiwe ziba bluu, futhi {{ui:Ulwazi lwento}} ngakwesokudla litshela ukuthi yini.

## Chofoza

| Yenza lokhu | Ikhetha |
|---|---|
| Chofoza ubuso noma umphetho | Lobo buso noma lo mphetho |
| Chofoza iqembu noma isakhi | Lonke iqembu noma isakhi |
| Chofoza kabili ubuso | Ubuso nemiphetho yalo |
| Chofoza kabili umphetho | Lo mphetho nobuso obuseceleni bawo |
| Chofoza kabili iqembu noma isakhi | Liyavula ukuze lihlelwe (bona [Amaqembu nezakhi](topic:groups-components)) |
| Chofoza kathathu ubuso noma umphetho | Konke okuxhumene nakho: lonke into |
| Chofoza indawo engenalutho | Akukho lutho (kususa ukukhetha) |
| Chofoza kabili indawo engenalutho uma uhlela iqembu | Ivala iqembu |

Imiphetho ilula ukuyithinta kunobuso: uma iphoyinti liseduze nomphetho ngamapikseli ambalwa, ukuchofoza kukhetha umphetho.

## Hudula ibhokisi

- **Kusuka kwesobunxele kuya kwesokudla** udweba ibhokisi eliqinile: ukukhetha **iwindi**. Kukhethwa kuphela izinto ezisebhokisini.
- **Kusuka kwesokudla kuya kwesobunxele** udweba ibhokisi elinamachashaza: ukukhetha **ukudlula**. Noma yini ethintwa yibhokisi iyakhethwa, futhi ubuso buyakhethwa uma ibhokisi lisebuso ngokuphelele.

Iqembu noma isakhi sibalwa njengento eyodwa: iwindi kumele libambe konke, kanti ukudlula kudinga ukuthinta kuphela.

## Engeza nokususa

Bamba ukhiye uma uchofoza noma uhudula:

| Ukhiye | Umphumela |
|---|---|
| {{key:Shift}} | Iyaguqula: yengeza okungakhethiwe, isuse okukhethiwe |
| {{key:Mod}} | Iyengeza |
| {{key:Shift}} kanye {{key:Mod}} ndawonye | Iyasusa |

Ukukhetha yonke into emodelini (noma yonke into eqenjini oliyahlela), cindezela {{key:Mod+A}}.

## Sula ukukhetha

Cindezela {{key:Esc}} (ngo-{{ui:Khetha}} njengethuluzi), noma chofoza indawo engenalutho.

## Susa okukhethiwe

Cindezela {{key:Delete}} noma {{key:Backspace}}. Ubuso, imiphetho, amaqembu nemihlahlandlela okukhethiwe kuyasuswa ngesinyathelo esisodwa; {{key:Mod+Z}} iyabuyisa.

Ukususa umphetho kususa ubuso obudinga wona, ngaphandle uma lowo mphetho wawuhlukanisa ubuso ababili ophaneni olufanayo: khona lobo buso ababili buba bubodwa. Ukususa ubuso kushiya imiphetho yalo. Bona [Ukusula nokuhlanza](topic:erase).

## Khetha ngaphakathi kweqembu

Ukuchofoza iqembu kukhetha lonke iqembu. Ukuze ukhethe ubuso ngaphakathi kwalo, chofoza kabili iqembu ukuze uvule, bese uchofoza. Lapho iqembu livulekile, ukuchofoza kufinyelela kuphela okungaphakathi kwalo; konke okunye kuyafiphala. Cindezela {{key:Esc}} kungakhethiwe lutho, noma chofoza kabili indawo engenalutho, ukuze uvale.

I-{{ui:Uhlu lwezinto}} ngakwesobunxele ikhetha amaqembu nezakhi ngegama, okusiza lapho zifihlwe ngemuva kwezinye izinto.
