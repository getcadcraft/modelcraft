## Ifayela le-ModelCraft

Ifayela le-`.modelcraft` ligcina imodeli yonke: ijiyometri, amaqembu, izakhi, imihlahlandlela, imiboniso, amayunithi, nekhamera nesitayela owawusebenzisa lapho olondoloza. Alighoshi umlando wokuhlehlisa.

### Vula imodeli

1. Chofoza {{ui:Vula}} eqenjini {{ui:Ifayela}}, noma cindezela {{key:Mod+O}}.
2. Uma imodeli esikrinini inezinguquko ezingalondolozwanga, i-ModelCraft iyabuza: "Le modeli inezinguquko ezingalondolozwanga. Londoloza ikhophi kuqala?" Khetha {{ui:Londoloza ikhophi}}, {{ui:Lahla izinguquko}} noma {{ui:Khansela}}.
3. Khetha ifayela le-`.modelcraft`.

Imodeli ivuleka ngamayunithi ayo alondolozwe ngawo, nekhamera eyayinayo. Ungaphinda uphonsele ifayela le-`.modelcraft` ebukeni le-3D, noma uchofoze elinye kuhlu lwamafayela akamuva ekhadini lokuqala (izisiphequluli ezingavula kabusha ifayela, nohlelo lwasedeskithophu).

:::desktop
Ohlelweni lwasedeskithophu, ukuchofoza kabili ifayela le-`.modelcraft` luyivula ku-ModelCraft, kanjalo **Vula nge-** kufayela le-Collada, OBJ, glTF, DWG noma DXF (lingeniswa ngaphakathi kwemodeli entsha).
:::

### Londoloza imodeli

Chofoza {{ui:Londoloza}} noma cindezela {{key:Mod+S}}. Isiphequluli silanda `<name>.modelcraft`, lapho igama liyigama lefayela owalivulayo, noma "Untitled" kumodeli entsha.

:::desktop
Ohlelweni lwasedeskithophu, {{ui:Londoloza}} ibhala ifayela owalivulayo endaweni yalo. Imodeli entsha ibuza ukuthi ilondolozwe kuphi.
:::

- {{ui:Londoloza njenge}} ({{key:Mod+Shift+S}}) ilondoloza ikhophi njengefayela le-`.modelcraft` noma njenge-[USD](topic:usd); lapho isiphequluli sikwazi, sicela igama nendawo. Uma kungenjalo, qamba kabusha ifayela elilandiwe: ukulondolozwa okulandelayo ngemva kokuvula ifayela eliqanjiwe kabusha kusebenzisa igama elisha.
- Ukulondoloza ngakunye kuyisilanda esisha. Kuncike ezilungiselelweni zesiphequluli, lisiya ngqo ezilandweni zakho noma libuze lapho okufanele lilondolozwe khona. Uma kunegama elifanayo lifayela lakho selikhona lapho, izisiphequluli eziningi zengeza inombolo, njengo `Untitled (1).modelcraft`.

:::chromium
Ukuze ukhethe ifolda njalo, vula izilungiselelo zesiphequluli, sesha "downloads", bese uvula "Ask where to save each file before downloading".
:::

:::firefox
Ukuze ukhethe ifolda njalo, vula **Settings**, bese **General**, bese ngaphansi kwe-"Downloads" khetha "Always ask you where to save files".
:::

:::safari
Ukuze ushintshe lapho izilandiwe zifika khona, vula **Safari**, bese **Settings**, bese **General**, bese usetha "File download location".
:::

### Qala imodeli entsha

Chofoza {{ui:Okusha}}. Uma kunezinguquko ezingalondolozwanga, i-ModelCraft iyabuza kuqala. Imodeli entsha iqala ingenalutho, ngeyunithi yendawo yakho (amafidi nezintshi e-United States, amamillimitha kwezinye izindawo), ingenamiboniso.

### Uma isiphequluli sivala ungakalondolozi

I-ModelCraft igcina ikhophi yomsebenzi ongalondolozwanga esiphequluleni ngemuva kwesekhondi ambalwa ngemva kwenguquko ngayinye. Uma ithebhu noma isiphequluli sivala ungakalondolozi, ngokuvula kwakho okulandelayo i-ModelCraft ibuza ukuthi "Buyisela umsebenzi wakho?". Ukubuyisela kuvula imodeli njengoba yayinjalo, ingakalondolozwa ifayela: yilondoloze ukuze uyigcine. Bona [Buyisela umsebenzi wakho](common:recover).

### Ku-CadCraft: Vula ku-ModelCraft

Ohlelweni lokudweba le-CadCraft, **Ukubuka**, bese **Okwengeziwe**, bese **Vula ku-ModelCraft** kunikeza idrowing evulekile ku-ModelCraft ethebhini elisha, njenge-DWG. Ifika njengoba i-DWG engeniswayo ifika: imigqa phansi, iqembu, ilungele ukumodela phezu kwayo. Akulayishwa lutho; ifayela lidlula kwisitoreji sesiphequluli sakho.

## Ngenisa

Ukungenisa kwengeza ifayela emodelini ovulile; akukhiphi okukhona.

1. Chofoza {{ui:Ngenisa}} eqenjini {{ui:Ifayela}}, noma uphonsele ifayela ebukeni le-3D.
2. Khetha ifayela le-SketchUp, Collada, OBJ, glTF, FBX, PLY, STL, Alembic, STEP, `.3dm`, USD, DWG noma DXF.

   Ifayela lifika njengo-**qembu elilodwa**, likhethiwe, nombono usondela ukuze ukubonise. Ibha yesimo itshela ukuthi kufike ni, futhi ibhale lokho okungangeniswanga, njengo "Akungeniswanga: izakhiwo zendawo ezi-2".

3. Ukuze usebenze ngejiyometri yalo ngqo, chofoza kabili iqembu ukuze uhlele ngaphakathi kwalo, noma chofoza {{ui:Chitha}}.

Okufanele uyazi:

- **Usayizi nokuthi yiphi indlela ephezulu:** amafayela e-Collada aveza iyunithi yawo nokuthi yiphi i-axis ephezulu, futhi i-ModelCraft iyawaguqula. I-glTF ihlala ingamamitha. Amafayela e-OBJ awanayo iyunithi: i-ModelCraft iwafunda njengamamitha, nge-Y iphezulu. Uma i-OBJ ifika ingu-1000 izikhathi inkulu noma incane kakhulu, sebenzisa [Shintsha usayizi](topic:rotate-scale) nge-factor njengo `0.001` noma `1000`.
- **DWG ne-DXF** zifika njengemigqa (imiphetho) phansi, hhayi njengobuso. Uma idrowing ingasho iyunithi yayo, ingxoxo ebizwa ngokuthi "Amayunithi edrowing" ibuza ukuthi iyunithi eyodwa yedrowing iyini. Bona [Yenza imodeli ngepulani yesayithi](topic:site-plan).
- **Imikhawulo:** amafayela angaphezu kuka-300 MB anqatshelwa ukungenisa, nangaphezu kuka-200 MB ukuvula. Amafayela anamaphoyinti noma ubuso obungaphezu kwezigidi ezi-2 anqatshelwa njengakhulu kakhulu.

## Khipha

1. Chofoza {{ui:Khipha}} eqenjini {{ui:Ifayela}}.
2. Khetha ifomethi: {{ui:glTF binary (.glb)}}, {{ui:Collada (.dae)}}, {{ui:OBJ (.obj)}}, {{ui:STL for printing (.stl, millimeters)}}, {{ui:PLY with colours (.ply)}}, {{ui:USD (.usda, .usdc, .usdz)…}}, {{ui:IFC for BimCraft (.ifc)}}, {{ui:DWG for CAD (.dwg, 2004)}} noma {{ui:DXF for CAD (.dxf, R12)}}.

Isiphequluli silanda ifayela, eligama njengemodeli. Imodeli yonke iyakhishwa, hhayi okukhethiwe kuphela. Imodeli engenalutho ayikhishwa: "Imodeli ayinalutho: qala udwebe okuthile kuqala." Bona [Khipha imodeli yezinye izinhlelo](topic:export-model).

## Ku-inthanethi nangaphandle kwe-inthanethi

Konke okusemodelini ku-ModelCraft kusebenza esikhompyutheni yakho, ngakho ukumodela, ukuvula, ukulondoloza, ukungenisa nokukhipha konke kusebenza ngaphandle kokuxhumana uma uhlelo selulayishiwe.

Ukuze uvule i-ModelCraft ngaphandle kokuxhumana noma yikuphi, yilondoloze ukuze isetshenziswe ngaphandle kwe-inthanethi ngenkathi uku-inthanethi:

1. Chofoza {{ui:Londoloza ngaphandle kwe-inthanethi}} ebhalweni lohlelo phezulu.
2. Inkinobho ibala ("Ilondoloza 40 kwezingu-212") ngenkathi ilondoloza. I-ModelCraft ilondoloza amafayela ayo (ahlanganisa nomfundi wayo we-DWG), lo usizo kanye nelabhulali ye-3D, ngakho kungathatha isikhathi.
3. Lapho inkinobho ifunda {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}, i-ModelCraft ivula ekeleni elifanayo ngaphandle kokuxhumana, nokungenisa i-DWG kusebenza ngaphandle kwe-inthanethi nakho.

Chofoza {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}} kamuva ukuze uthole {{ui:Londoloza futhi (thola inguqulo entsha kakhulu)}} noma {{ui:Susa ikopi engaphandle kwe-inthanethi}}. Uma inkinobho ifunda {{ui:Akukwazanga ukulondoloza}}, amanye amafayela awazange alandwe: hlola ukuxhumana bese uyichofoza ukuze uzame futhi. {{ui:Ayikho ingaphandle kwe-inthanethi}} isho ukuthi le windi yesiphequluli ayikwazi ukugcina ikhophi (amawindi angasese namanye amakhompyutha alawulwayo). Bona [Ukusebenza ngaphandle kwe-inthanethi](common:offline).

Ukugcinwa kwelifu akukatholakali okwamanje. Yonke imodeli ihlala lapho oyilondoloza khona.

:::offline
Awuxhunyiwe. Ungaqhubeka umodela futhi ulondoloze. Ngaphandle kokuthi ibha yohlelo ibonisa {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}, ungayi kabusha le thebhu uze uxhume futhi.
:::

## Uhlelo lwasedeskithophu

:::desktop
Usebenzisa i-ModelCraft ku-CadCraft Studio, uhlelo lwasedeskithophu olunazo zonke izinhlelo eziyisishiyagalombili. Amafayela avulwa futhi alondolozwe lapho okhetha khona.
:::

:::web
I-ModelCraft isebenza ngesiphequluli kuMac, Windows nase-Linux, nasku-CadCraft Studio, uhlelo lwasedeskithophu olunazo zonke izinhlelo eziyisishiyagalombili kufakwe kunye, kusuka ku-getcadcraft.com/download.
:::
