I-add-on (Izilungiselelo › Okwengeziwe) ingangeza injini ohlwini lwe-Injini lwe-{{ui:Renda isithombe…}}. Umbhalo ogcwele wabalobi be-add-on useqeqeshini 16 lencazelo ye-add-on; ngokufushane:

- I-add-on ibhalisa injini enesihlonzi esiqala ngesayo, igama, izilungiselelo ezikhethekayo, **noma** uhlelo oluzoqhuba **noma** umsebenzi ku-JavaScript odweba isithombe.
- Injini eqhuba uhlelo idinga imvume **`engine.run`**, ebonakala ngaphambi kokufakwa nasezilungiselelweni. Isebenza kuphela ku-Studio; kusiphequluli iboniswa njengefayela okufanele silondolozwe.
- I-add-on ichaza uhlelo (igama lefayela elilula: hhayi i-shell), umbhalo **osendaweni ye-add-on esayiniwe**, nezimpikiswano ezakhiwe ngezibambi nemagama alula. I-Studio iyathola uhlelo noma ikucela ukuthi ulikhombise kanye.
- Ngokuqala i-add-on iqhuba uhlelo, **i-Studio iyakubuza ngengxoxo yayo**: iyiphi i-add-on, yiluphi uhlelo, nokuthi umbhalo ungenza noma yini uhlelo olungayenza. Yivumele kuphela i-add-on oyithembayo. Impendulo yakho iyakhunjulwa ye-add-on nohlelo oluthile.
- Iphakheji (imbonakalo njenge-USD nefayela lezilungiselelo, nefayela le-glTF uma i-add-on ikucela lona) nombhalo we-add-on kuya kufolda lesikhashana elisha, uhlelo luqhuba lapho, isithombe sibuyela sibhalwe ngegama lenjini ye-add-on.

:::note
Ama-add-on angangeza izinjini zokurenda kuphela kusuka ku-add-on API 1.4. Isibonelo esisebenzayo somshicilelo we-command-line onomthombo ovulekile sisemthonjeni wawo; asikaqhutshwa kulowo renderer.
:::
