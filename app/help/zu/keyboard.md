Lezi yizinkinobho zokusunduza-hudula, eziqala ngazo i-ModelCraft. Ngesitayela esihlukile, bona [Izinkinobho zeModeler](topic:keyboard#modeler-keys) ngezansi nokuthi [Izilungiselelo ze-ModelCraft](topic:settings).

Izinkinobho zisebenza uma i-3D view noma inkinobho yebha yamathuluzi igxilile. Uma ubhale egunjini lephaneli noma ushintshe uhlu ku-{{ui:Style}}, chofoza ku-3D view kuqala, noma izinkinobho zizoya kulowo gunjana. Bona [Izinkinobho, izinkinobho zembewu nopendi](common:keys) ukuthi izinkinobho zibhalwa kanjani kwikhompyutha ngayinye.

## Esc

{{key:Esc}} ibuyela emuva inqubo eyodwa ngalo lonke ukucindezela:

1. Yenza ukuphela kwalokho ithuluzi eliphakathi kwakho (umugqa oqhubeka wedwetshwa, ukusunduza-hudula, ukuhambisa). Konke kuyabuya.
2. Kushintsha ube {{ui:Select}}.
3. Kususa ukukhethwa.
4. Kuvala iqembu oyihlelayo.

Iphinde iyeke izigcawu zingadlali. Kubhokisi lenani, {{key:Esc}} isula lokho okuthayiphile ibuyele kumbono.

## Ithuluzi lisasebenza

| Inkinobho | Yenza |
|---|---|
| Inombolo, noma eyodwa yezi `. , - ' " [ < * /` | Iqala ukuthayipha ebhokisini lenani |
| {{key:Enter}} | Isebenzisa okuthayiphile ebhokisini lenani |
| {{key:Right}} | Ikhiya ku-axis ebomvu (cindezela futhi ukuze uvule) |
| {{key:Left}} | Ikhiya ku-axis eluhlaza |
| {{key:Up}} | Ikhiya ku-axis ezolile |
| {{key:Down}} | Ikhiya ihambisana nomphetho wokugcina oshayelwe ngaphambi kokuchofoza kokuqala |
| Bamba {{key:Shift}} | Ibamba isiqondiso osinqunyiwe, kuze kubanjwe |
| {{key:Ctrl}}, {{key:Mod}} noma {{key:Alt}} (Move) | Iguqula phakathi kokuhambisa nokukopisha |

Izikhiye zomcibisholo zisebenza ku-{{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} kanye ne-{{ui:Tape}} (lapho ulinganisa kusuka kwiphoyinti), emva kokuchofoza kokuqala. {{ui:Push/pull}} ihamba njalo ngendlela yohlangothi futhi ayinazikhiye. Ku-{{ui:Rotate}} amakhiye omcibisholo akhombisa umlayezo wokuthi "Locked" emva kokuchofoza kokuqala kodwa awashintshi ukuphenduka.

## Amakhiye omcibisholo ngezikhathi ezinye

Lapho nengathi akukho thuluzi eliphakathi kokwenza into, amakhiye omcibisholo ahambisa ikhamera:

| Inkinobho | Yenza |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Zungeza (Orbit) |
| {{key:Shift}} nomcibisholo | Shelelisa (Pan) |

## Imbewu

| Isenzo | Yenza |
|---|---|
| Chofoza | Isebenzisa ithuluzi lamanje |
| Cindezela, hudula, khipha | Njengokuchofoza kabili (kumathuluzi okudweba); ukukhetha ibhokisi (kwe-{{ui:Select}}); isula endleleni (kwe-{{ui:Eraser}}) |
| Chofoza kabili | {{ui:Select}}: uhlangothi nemiphetho yalo, umphetho nezinhlangothi zawo, ivula iqembu; isikhala esingenalutho sivala iqembu |
| Chofoza kathathu | {{ui:Select}}: konke okuxhunyiwe |

| {{key:Mod}} + chofoza | {{ui:Select}}: engeza ekukhethweni |
| {{key:Shift}} + {{key:Mod}} + chofoza | {{ui:Select}}: susa ekukhethweni |
| Hudula inkinobho ephakathi | Zungeza (Orbit), nganoma yiliphi ithuluzi |
| {{key:Shift}} + hudula inkinobho ephakathi | Shelelisa (Pan), nganoma yiliphi ithuluzi |
| Hudula inkinobho yesokudla | Shelelisa (Pan), nganoma yiliphi ithuluzi |

## Isikrini sokuthinta

| Isenzo | Yenza |
|---|---|
| Thinta | Ukuchofoza nethuluzi lamanje |
| Thinta kabili | Ukuchofoza kabili |
| Cindezela, hudula, phakamisa | Njengokucindezela, ukudonsa, ukukhulula nge-mouse |
| Iminwe emibili: ukuhlanganisa | Sondeza |
| Iminwe emibili: nyakazisa ndawonye | Shelelisa (Pan) (Izilungiselelo › ModelCraft › Isikrini sokuthinta kungenza kube yi-Orbit) |
| Iminwe emithathu: nyakazisa ndawonye | Zungeza (Orbit) (Shelelisa uma iminwe emibili izungeza) |
| Mbamba umunwe owodwa ume ngcwaba | Iqeda ithuluzi, njenge-Enter; uma kungenzeki lutho, bese uyadonsa ukuze uzungeze |
| Umunwe wesibili phakathi kwesenzo somunwe owodwa | Ikhansela lesenzo |
| Ithuluzi le-{{ui:Orbit}}, bese udonsa umunwe owodwa | Zungeza (Orbit) |

Ukuze uthayiphe inani esikrinini sokuthinta, thinta ibhokisi lenani ngaphansi, thayipha, bese ucindezela inkinobho ye-Enter (noma i-Go) yekhibhodi.

## Lapho kuhlala khona i-Move

I-Move ihlala kuthuluzi le-{{ui:Move}}, inkinobho {{key:M}}: khetha okufanele kuhanjiswe, chofoza iphoyinti lesisekelo, bese uchofoza iphoyinti lesibili noma uthayipha ibanga. Bona [Hambisa, kopisha wenze ama-array](topic:move-copy).
