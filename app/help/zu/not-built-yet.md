I-ModelCraft iyibhilidi yokuqala. Leli khasi lidweba okungakenziwa okwamanje, ukuze ungazifunele, nendlela eseduze yokwenza umsebenzi namanje.

## Amathuluzi okudweba

| Akukakwenziwa | Esikhundleni salokho, namanje |
|---|---|
| Ukudweba ngesandla | Chofoza amaphoyinti nge-{{ui:Curve}} |
| Ukushintsha inani lezingxenye ze-arc noma isiyingi ngemva kokukudweba | Susa bese udweba kabusha ngemva kokuthayipha `24s` |
| Ukukhetha uhlobo lombhalo we-[3D text](topic:text3d), noma ukuhlela amagama alo ngemva kokuwubeka | Susa bese wengeza umbhalo kabusha |
| Ukushintsha i-engeli ngokuthayipha esilinganisweni se-engeli, noma usayizi wesilinda kusuka esilinganisweni sesiyingi saso | Jikisa imiphetho nge-{{ui:Rotate}}; shintsha usayizi wesilinda nge-{{ui:Scale}} |
| Izilinganiso ezifakweni zemodeli ezithunyelwayo | Izilinganiso ziyabonakala emifanekisweni, emaphrinteni nasemaPDF ombono; amafayela emodeli athwala ijiyomethri kuphela |
| Trim, Split ne-Outer shell | Amaqembu avaliwe e-[Union, Subtract and Intersect](topic:solids), noma [intersect faces](topic:intersect) bese ususa okungadingeki |
| Ukukhetha i-axis yokujikeleza ngokhiye bomcibisholo | Chofoza isikhungo se-{{ui:Rotate}} ebusweni elibheka ngendlela i-axis okumele ibheke ngayo |
| Ukukhiya ngaphezu kokukhomba kunye ngesikhathi | Khiya inqondo elilodwa ngokhiye bomcibisholo, bese ubamba iphoyinti |
| Ukushintsha usayizi ngokuthambeka, noma kusuka ekugcineni kwesilinganiso okungasikho ekhoneni | Beka isilinganiso kumakhona amabili, ngomphetho noma ngomugqa obomvu, oluhlaza noma oluzuri |

| Akukakwenziwa | Esikhundleni salokho, namanje |
|---|---|
| Ukunyakazisa izinhlangothi, imiphetho, isikhathi sosuku selanga, isitayela noma okufihliwe | Yenza ingxenye enyakazayo ibe iqembu noma ikhomponenti; yenza ividiyo ehlukile yesikhathi sosuku esihlukile |
| Ikhamera elandela umzila odwetshiwe, noma ebuka into enyakazayo | Beka okhiye bekhamera abaningi ndleleni ([Nyakazisa](topic:animation)) |
| Umsindo emavidiyweni, namavidiyo ekhwalithi ephezulu (ahlanganiswa ngomzila) ngaphandle kwe-WebGPU | Engeza umsindo kwi-video editor; ngaphandle kwe-WebGPU, yenza ividiyo nge-renderer esheshayo ([Yenza ividiyo](topic:animation#render-the-video)) |
| Amalambu anyakazayo (ukukhanya, ukusakazeka, umbala) evidiyweni eyenziwe, i-engeli yelensi enyakazisiwe ngaphandle kwokhiye bekhamera evidiyweni, ukunyakazisa izinto zokwakha noma izilungiselelo zokwenza | Amalambu anyakaza embonweni; ngevidiyo, khiya nekhamera ukuze usondele; yenza amavidiyo ahlukene ngezilungiselelo ezahlukene zelambu ([Nyakazisa noma yimuphi umbono](topic:animate)) |
| Ukucwilisa izisindo noma amathambo kusuka uhlangothi olulodwa kuya kolunye, amaenvelopu amathambo abonakalayo, ukubonisa izisindo ngamaphoyinti ngamaphoyinti, ukubona imodeli eyenziwe ngesikhathi sokupenda izisindo | Penda zombili izinhlangothi, noma yenza uhhafu bese usebenzisa i-Mirror modifier ngaphambi kokungeza i-armature; shintsha phakathi kwe-Penda izisindo ne-Ukuma ukuhlola |
| Amathambo afundwa kumafayela e-glTF, FBX noma USD njenge-armature, namathambo abhalwe kulawo mafayela | Imodeli enesikhumba ingena ime njengoba iphumule ngezisindo zefayela; engeza amathambo ngokulandelana kwamajoyinti efayela, bese {{ui:Use the file's weights}} ([Nyakazisa](topic:animate)) |
| Ukuhambisa injongo ye-IK noma i-pole ngokuyidonsa embonweni, isikhala somkhawulo (lokhu kwendawo noma komhlaba) okukhethwayo, ukwelula amaketanga e-IK, i-IK ngejika | Thayipha iphoyinti lenjongo, noma uqondise kwento bese uyihambisa; gcina amaketanga ezinhlobeni zawo |
| Indwangu, amanzi, izinto ezithambile, izixhumanisi namahinji phakathi kwezinto eziqinile, ukungqubuzana nesimo esiqondile sento (amabhokisi namabhola kuphela azungezile), isimulation ephilayo uma udlala, isivinini sokuqala noma ukujikeleza (izinto ziqala zimi) | Bhaka izinto eziqinile bese udlala okhiye; yakha ihinji ngokhiye; hlukanisa isimo esiyinkimbinkimbi sibe amabhokisi (amaqembu) |
| Ukuthumela ukunyakaza kumafayela e-glTF noma amanye amafayela emodeli | Yenza ividiyo; ifayela le-`.modelcraft`, nefayela le-[USD](topic:usd) elilondolozwe yi-ModelCraft, ligcine kwi-ModelCraft |
| Ukuthayipha ukuphawula noma isihloko sesimo ku-VR, amanothi ngezwi, ukuhambisa ipulani lesigaba ngesandla ku-VR | Beka isimo ku-VR, bese wengeza amagama aso ohlelweni lwe-BCF; setha ipulani lesigaba embonweni ngaphambi kokungena: bona [Buka imodeli nge-VR headset](topic:vr-review) |
| Ukubona abantu ezindaweni zabo ku-VR (abantu be-VR kuphela ndabawubonakalayo), ukurekhoda uhambo lwe-VR | Bacele bajoyine ku-VR, noma yenza [ukunyakazisa](topic:animation) kohambo |

## Ukusebenza

Ukuhlehlisa kugcina ikhophi yemodeli ngesinyathelo ngasinye ([i-mesh](topic:meshes) igcina kuphela okushintshiwe), ngakho ukungeniswa okukhulu kakhulu kwejiyomethri yokuhudula kwenza ukuhlela ngakunye kube kancane. Gcina ukungenisa kuncane, bese ulondoloza futhi uvule kabusha ukuze uhlanze umlando.

## Izinhlelo nezinkundla

- **Ideskithophu:** i-ModelCraft isebenza kusiphequluli se-Mac, Windows ne-Linux, nakwi-CadCraft Studio, uhlelo lwedeskithophu olunazo zonke izinhlelo eziyisishiyagalombili ekufakweni okukodwa. Ku-Android, i-CadCraft Studio ifakwa nge-APK yayo kuma-getcadcraft.com/download. Akukakho ukwakhiwa kwe-iPad noma i-iPhone.
- **Ukuthinta:** bona [Zungeza, shelelisa nesondeza](topic:orbit-pan-zoom) ngezenzo zeminwe. Ingcindezi yepeni isetha ibhulashi ku-[Bumba](topic:sculpt); kwezinye izindawo ingcindezi nokuthambekela kwepeni akusetshenziswa.
- **Amashidi:** i-ModelCraft [iprinta ukubuka okukodwa ngekhasi ngalinye](topic:export-model#print-the-view-or-save-it-as-a-pdf); akukho ukwakheka kwamashidi anemibono eminingi noma i-title block. Thumela ku-DWG/DXF ehambisana ne-CadCraft ukuze uthole imidwebo ngesilinganiso.
