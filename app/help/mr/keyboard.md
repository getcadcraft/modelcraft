या पुश-पुल की आहेत, ज्या ModelCraft सुरुवातीला वापरते. दुसऱ्या शैलीसाठी खाली [मॉडेलर की](topic:keyboard#modeler-keys) आणि [ModelCraft सेटिंग्ज](topic:settings) पहा.

शॉर्टकट 3D व्ह्यू किंवा टूलबार बटण फोकसमध्ये असताना काम करतात. तुम्ही नुकतेच पॅनल फील्डमध्ये टाइप केले असल्यास किंवा {{ui:Style}} मधील यादी बदलली असल्यास, आधी 3D व्ह्यूमध्ये क्लिक करा, नाहीतर तुमच्या की त्या फील्डकडे जातील. प्रत्येक संगणकावर की कशा लिहिल्या जातात यासाठी [की, माउस आणि ट्रॅकपॅड](common:keys) पहा.

## Esc

{{key:Esc}} प्रत्येक वेळी दाबल्यावर एक पातळी मागे जाते:

1. टूल ज्यात अडकलेले आहे ते रद्द करते (काढली जाणारी रेषा, पुश/पुल, हलवणे). सर्व काही मूळ जागी परत जाते.
2. {{ui:Select}} वर स्विच करते.
3. निवड साफ करते.
4. तुम्ही संपादन करत असलेला गट बंद करते.

ते सीन चालण्यापासूनही थांबवते. मूल्य बॉक्समध्ये, {{key:Esc}} तुम्ही टाइप केलेले साफ करते आणि व्ह्यूकडे परत येते.

## टूल चालू असताना

| की | काय करते |
|---|---|
| अंक, किंवा `. , - ' " [ < * /` पैकी एक | मूल्य बॉक्समध्ये टाइप सुरू करते |
| {{key:Enter}} | मूल्य बॉक्समध्ये टाइप केलेले लागू करते |
| {{key:Right}} | लाल अक्षावर लॉक करते (पुन्हा दाबल्यास अनलॉक) |
| {{key:Left}} | हिरव्या अक्षावर लॉक करते |
| {{key:Up}} | निळ्या अक्षावर लॉक करते |
| {{key:Down}} | पहिल्या क्लिकपूर्वी तुम्ही फिरवलेल्या शेवटच्या कडेला समांतर लॉक करते |
| {{key:Shift}} धरा | धरलेले असताना, तुम्ही स्नॅप झालेली दिशा धरून ठेवते |
| {{key:Ctrl}}, {{key:Mod}} किंवा {{key:Alt}} (हलवणे) | हलवणे आणि कॉपी करणे यामध्ये स्विच करते |

बाण-की लॉक {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} आणि {{ui:Tape}} मध्ये काम करतात (बिंदूपासून मोजताना), पहिल्या क्लिकनंतर. {{ui:Push/pull}} नेहमी फेसच्या दिशेने हलते आणि त्यात लॉक नसतात. {{ui:Rotate}} मध्ये पहिल्या क्लिकनंतर बाण की "Locked" संदेश दाखवतात पण वळण बदलत नाहीत.

## इतर वेळी बाण की

कोणतेही टूल काही करत नसताना, बाण की कॅमेरा हलवतात:

| की | काय करते |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | ऑर्बिट |
| बाणासोबत {{key:Shift}} | पॅन |

## माउस

| क्रिया | काय करते |
|---|---|
| क्लिक | सध्याचे टूल वापरते |
| दाबा, ड्रॅग, सोडा | दोन क्लिकसारखे (रेखाटन टूलसाठी); बॉक्स निवड ({{ui:Select}} साठी); वाटेत मिटवते ({{ui:Eraser}} साठी) |
| डबल-क्लिक | {{ui:Select}}: फेस त्याच्या कडांसह, कड त्याच्या फेससह, गट उघडते; रिकामी जागा गट बंद करते. {{ui:Push/pull}}: शेवटचे अंतर पुन्हा करते |
| ट्रिपल-क्लिक | {{ui:Select}}: जोडलेले सर्व काही |
| {{key:Shift}} + क्लिक | {{ui:Select}}: निवडीत आत/बाहेर टॉगल करते |
| {{key:Mod}} + क्लिक | {{ui:Select}}: निवडीत जोडते |
| {{key:Shift}} + {{key:Mod}} + क्लिक | {{ui:Select}}: निवडीतून काढते |
| मधले-बटण ड्रॅग | कोणत्याही टूलसोबत ऑर्बिट |

## ट्रॅकपॅड

दोन-बोटी स्वाइप काय करते ते {{ui:Settings}} › {{ui:ModelCraft}} › स्क्रोलिंग यावर अवलंबून असते:

| जेश्चर | ट्रॅकपॅड (किंवा ठरवलेला) | माउस व्हील |
|---|---|---|
| दोन-बोटी स्वाइप | ऑर्बिट | पॉइंटरच्या दिशेने झूम |
| {{key:Shift}} + दोन-बोटी स्वाइप | पॅन | झूम |
| पिंच | पॉइंटरच्या दिशेने झूम | पॉइंटरच्या दिशेने झूम |
| दोन-बोटी दाबून ड्रॅग (दुय्यम क्लिक धरलेले) | पॅन | पॅन |

पहा [ऑर्बिट, पॅन आणि झूम](topic:orbit-pan-zoom#on-a-trackpad) आणि [ModelCraft सेटिंग्ज](topic:settings#scrolling-mouse-wheel-or-trackpad).

## टचस्क्रीन

| जेश्चर | काय करते |
|---|---|
| टॅप | सध्याच्या टूलसह एक क्लिक |
| डबल-टॅप | डबल-क्लिक |
| दाबा, ड्रॅग, उचला | माउससह दाबणे, ड्रॅग, सोडणे यासारखे |
| दोन बोटे: पिंच | झूम |
| दोन बोटे: एकत्र हलवा | पॅन ({{ui:Settings}} › {{ui:ModelCraft}} › टचस्क्रीन त्याला ऑर्बिट करू शकते) |
| तीन बोटे: एकत्र हलवा | ऑर्बिट (दोन बोटे ऑर्बिट करत असताना पॅन) |
| एक बोट स्थिर धरा | Enter सारखे टूल पूर्ण करते; काहीही चालू नसल्यास, मग ऑर्बिटसाठी ड्रॅग करा |
| एका बोटाच्या क्रियेदरम्यान दुसरे बोट | ती क्रिया रद्द करते |
| {{ui:Orbit}} टूल, मग एक बोट ड्रॅग करा | ऑर्बिट |

टचस्क्रीनवर मूल्य टाइप करण्यासाठी, खालील मूल्य बॉक्सवर टॅप करा, टाइप करा, आणि कीबोर्डची {{key:Enter}} (किंवा Go) की दाबा.

## हलवा कुठे आहे

हलवा {{ui:Move}} टूलमध्ये आहे, की {{key:M}}: काय हलवायचे ते निवडा, आधार बिंदूवर क्लिक करा, मग दुसरा बिंदू किंवा अंतर टाइप करा. पहा [हलवा, कॉपी करा आणि अ‍ॅरे तयार करा](topic:move-copy).
