אלה מקשי דחיפה/משיכה, אלה שבהם ModelCraft מתחיל כברירת מחדל. לסגנון האחר, ראו [מקשי Modeler](topic:keyboard#modeler-keys) למטה ו[הגדרות ModelCraft](topic:settings).

קיצורים פועלים כשתצוגת התלת-מימד או לחצן בסרגל הכלים בפוקוס. אם הקלדתם זה עתה בשדה בחלונית או שיניתם רשימה ב{{ui:Style}}, לחצו קודם בתצוגת התלת-מימד, אחרת המקשים יגיעו לשדה ההוא. ראו [מקשים, עכברים ולוחות מגע](common:keys) לכתיבת המקשים בכל מחשב.

## Esc

{{key:Esc}} חוזר צעד אחד אחורה בכל לחיצה:

1. מבטל את מה שהכלי עושה באמצע (קו שמצוייר, דחיפה/משיכה, הזזה). הכול חוזר למקומו.
2. עובר לכלי {{ui:Select}}.
3. מנקה את הבחירה.
4. סוגר את הקבוצה שעורכים.

הוא גם עוצר הפעלה של סצנות. בתיבת הערך, {{key:Esc}} מנקה את מה שהקלדתם וחוזר לתצוגה.

## בזמן שכלי פועל

| מקש | פעולה |
|---|---|
| ספרה, או אחד מהתווים `. , - ' " [ < * /` | מתחיל הקלדה בתיבת הערך |
| {{key:Enter}} | מחיל את מה שהקלדתם בתיבת הערך |
| {{key:Right}} | נועל לציר האדום (לחצו שוב לשחרור) |
| {{key:Left}} | נועל לציר הירוק |
| {{key:Up}} | נועל לציר הכחול |
| {{key:Down}} | נועל מקביל לקצה האחרון שהעברתם מעליו לפני הלחיצה הראשונה |
| החזיקו {{key:Shift}} | שומר את הכיוון שאליו נצמדתם, כל עוד מחזיקים |
| {{key:Ctrl}}, {{key:Mod}} או {{key:Alt}} (הזזה) | מחליף בין הזזה להעתקה |

נעילות במקשי חצים פועלות בכלים {{ui:Line}}, {{ui:Rectangle}}, {{ui:Circle}}, {{ui:Polygon}}, {{ui:Move}}, {{ui:Scale}} ו{{ui:Tape}} (בזמן מדידה מנקודה), אחרי הלחיצה הראשונה. לכלי {{ui:Push/pull}} יש תמיד תנועה לאורך כיוון הפאה, ואין בו נעילות. בסיבוב, מקשי החצים מציגים הודעה "נעול" אחרי הלחיצה הראשונה, אבל אינם משנים את זווית הסיבוב.

## מקשי חצים בזמנים אחרים

כשאף כלי לא באמצע פעולה, מקשי החצים מזיזים את המצלמה:

| מקש | פעולה |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | {{ui:Orbit}} |
| {{key:Shift}} עם חץ | {{ui:Pan}} |

## עכבר

| פעולה | מבצע |
|---|---|
| לחיצה | משתמשת בכלי הנוכחי |
| לחיצה, גרירה, שחרור | זהה לשתי לחיצות (לכלי ציור); בחירה בתיבה (ל{{ui:Select}}); מוחק לאורך הדרך (ל{{ui:Eraser}}) |
| לחיצה כפולה | בבחירה: פאה עם הקצוות שלה, קצה עם הפאות שלו, פותחת קבוצה; מקום ריק סוגר את הקבוצה. בדחיפה/משיכה: חוזר על המרחק האחרון |
| לחיצה משולשת | בבחירה: הכול המחובר |
| {{key:Shift}} + לחיצה | בבחירה: מחליף בין הוספה להסרה מהבחירה |
| {{key:Mod}} + לחיצה | בבחירה: מוסיף לבחירה |
| {{key:Shift}} + {{key:Mod}} + לחיצה | בבחירה: מסיר מהבחירה |
| גרירה עם הכפתור האמצעי | {{ui:Orbit}}, בכל כלי |
| {{key:Shift}} + גרירה עם הכפתור האמצעי | {{ui:Pan}}, בכל כלי |
| גרירה עם הכפתור הימני | {{ui:Pan}}, בכל כלי |
| גלגלת | זום לעבר הסמן |

אין תפריט לחיצה ימנית.

## מסך מגע

| מחווה | פעולה |
|---|---|
| הקשה | לחיצה עם הכלי הנוכחי |
| הקשה כפולה | לחיצה כפולה |
| לחיצה, גרירה, הרמה | זהה ללחיצה, גרירה ושחרור בעכבר |
| שתי אצבעות: צביטה | זום |
| שתי אצבעות: תנועה משותפת | {{ui:Pan}} ({{ui:Settings}} › {{ui:ModelCraft}} › מסך מגע יכול להפוך אותה ל{{ui:Orbit}}) |
| שלוש אצבעות: תנועה משותפת | {{ui:Orbit}} ({{ui:Pan}} כששתי אצבעות מסובבות) |
| החזקת אצבע אחת ללא תנועה | מסיימת את הכלי, כמו {{key:Enter}}; כשאין פעולה, אחר כך גוררים למסלול |
| אצבע שנייה במהלך פעולת אצבע אחת | מבטלת את הפעולה ההיא |
| כלי {{ui:Orbit}}, ואז גרירה באצבע אחת | {{ui:Orbit}} |

כדי להקליד ערך במסך מגע, הקישו על תיבת הערך שבתחתית, הקלידו, ולחצו על מקש Enter (או Go) במקלדת.

## איפה נמצאת ההזזה

ההזזה נמצאת בכלי {{ui:Move}}, במקש {{key:M}}: בחרו מה להזיז, לחצו נקודת בסיס, ואז נקודה שנייה או הקלידו מרחק. ראו [הזזה, העתקה ויצירת מערכים](topic:move-copy).
