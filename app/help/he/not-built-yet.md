ModelCraft היא גרסה מוקדמת. העמוד הזה מפרט מה היא עדיין לא עושה, כדי שלא תחפשו את זה, ואת הדרך הקרובה ביותר לביצוע העבודה היום.

## כלי שרטוט

| עדיין לא | במקום זאת, היום |
|---|---|
| ציור חופשי | לחצו על הנקודות עם {{ui:Curve}} |
| שינוי מספר הקטעים של קשת או מעגל אחרי שרטוטם | מחקו וציירו שוב אחרי הקלדת `24s` |
| בחירת גופן ל[טקסט תלת-ממדי](topic:text3d), או עריכת המילים שלו אחרי הצבתו | מחקו והוסיפו את הטקסט מחדש |
| שינוי זווית על ידי הקלדה במידה זוויתית, או שינוי גודל גליל ממידת העיגול שלו | סובבו את הקצוות עם {{ui:Rotate}}; שנו את הגודל של הגליל עם {{ui:Scale}} |
| מידות בקבצי מודל מיוצאים | המידות מופיעות בתמונות, בהדפסות ובקבצי PDF של התצוגה; קבצי המודל שומרים רק גיאומטריה |
| חיתוך, פיצול ומעטפת חיצונית | קבוצות סגורות של [איחוד, חיסור וחיתוך](topic:solids), או [חיתוך פאות](topic:intersect) ומחיקת מה שאינכם צריכים |
| בחירת ציר הסיבוב עם מקשי החצים | לחצו על מרכז {{ui:Rotate}} בפאה שפונה לכיוון שאליו ציר הסיבוב צריך להצביע |
| נעילה על יותר מכיוון אחד בכל פעם | נעלו כיוון אחד עם מקש חץ, ואז נעצו לנקודה |
| שינוי גודל לאורך שיפוע, או מקצה מידה שאינו בפינה | הציבו את המידה על שתי פינות, לאורך קצה, או לאורך האדום, הירוק או הכחול |

## הנפשה

| עדיין לא | במקום זאת, היום |
|---|---|
| הנפשת פאות, קצוות, שעת היום של השמש, הסגנון או מה שמוסתר | הפכו את החלק הנע לקבוצה או לרכיב; רנדרו סרטון נפרד לשעת יום אחרת |
| מצלמה שעוקבת אחרי נתיב שצויר, או מביטה בעצם נע | הגדירו עוד מפתחות מצלמה לאורך הדרך ([הנפשה](topic:animation)) |
| צליל בסרטונים, וסרטונים באיכות גבוהה (path-traced) בלי WebGPU | הוסיפו צליל בעורך וידאו; בלי WebGPU, רנדרו את הסרטון עם הרנדרר המהיר ([רינדור הסרטון](topic:animation#render-the-video)) |
| מנורות מונפשות (בהירות, פיזור, צבע) בסרטון מרונדר, זווית עדשה מונפשת בלי מפתחות מצלמה בסרטון, הנפשת חומרים או הגדרות רינדור | מנורות מונפשות בתצוגה; לסרטון, הוסיפו גם מפתחות למצלמה לזום; רנדרו סרטונים נפרדים להגדרות מנורה שונות ([הנפשת כל מאפיין](topic:animate)) |
| שיקוף משקולות או עצמות מצד לצד, מעטפות עצמות גלויות, הצגת משקולות מוצללות נקודה אחר נקודה (הן מוצגות לפי פאה), וראיית הרשת במצב תנוחה בזמן צביעת משקולות | צבעו את שני הצדדים, או צרו צד אחד והשתמשו במשנה שיקוף (Mirror) לפני הוספת השלד; עברו בין צביעת משקולות ל-Pose לבדיקה |
| עצמות הנקראות מקבצי glTF, FBX או USD כשלד, ושלדים הנכתבים לקבצים אלה | מודלים עם עור מיובאים במנוחה עם המשקולות של הקובץ; הוסיפו את העצמות לפי סדר המפרקים של הקובץ, ואז {{ui:Use the file's weights}} ([הנפשה](topic:animate)) |
| הזזת יעד IK או קוטב בגרירה בתצוגה, מרחב אילוץ משלו (מקומי או עולמי) לבחירה, מתיחת שרשראות IK, IK לאורך עקומה | הקלידו את הנקודה של היעד, או כוונו לאובייקט והזיזו אותו; שמרו על השרשראות באורכיהן |
| בד, נוזלים, גופים רכים, מפרקים וצירים בין גופים נוקשים, התנגשות עם הצורה המדויקת של אובייקט (רק קופסאות וכדורים סביבו), סימולציה חיה בזמן ההפעלה, מהירות או סיבוב התחלתיים (הגופים מתחילים במנוחה) | אפו גופים נוקשים והפעילו את המפתחות; בנו ציר מפתחות; פצלו צורה לא רגילה לקופסאות (קבוצות) |
| ייצוא ההנפשה לקבצי glTF או למודלים אחרים | רנדרו סרטון; קובץ `.modelcraft` וקובץ [USD](topic:usd) ש-ModelCraft שמרה שומרים את ההנפשה עבור ModelCraft |
| הקלדת הערה או כותרת לבעיה ב-VR, הערות קוליות, הזזת מישור חתך ביד ב-VR | הציבו את הבעיה ב-VR, ואז הוסיפו את המילים בתוכנת BCF; קבעו מישור חתך בתצוגה לפני הכניסה: ראו [סקירת המודל בקסדת VR](topic:vr-review) |
| ראיית אנשים ליד השולחן ב-VR (רק אנשים ב-VR מוצגים), הקלטת סיור ב-VR | בקשו מהם להצטרף ב-VR, או צרו [הנפשה](topic:animation) של הסיור |

## רשתות

| עדיין לא | במקום זאת, היום |
|---|---|
| פיסול לפי רמות (multiresolution), וכלי Detail שמסיר משולשים שהפכו זעירים | [פיסול](topic:sculpt) של רשת מחולקת; {{ui:Remesh}} כדי ליישר אותה שוב |
| בנייה מחדש לפאות ארבע-צדדיות שעוקבות אחרי הצורה | {{ui:Remesh}} (משולשים אחידים), ואז בנו מחדש את הטופולוגיה עם [Retopology](topic:mesh-edit#retopology) |
| משקולות שנצבעו על קודקודים עבור משנים (Displace, Smooth ו-Shrinkwrap פועלים על כל הרשת) | החילו את המשנה, ואז פסלו או ערכו את החלקים שצריכים אותה |
| העתקה והדבקה של קודקודים, קצוות או פאות, חיתוך סכין שמסתיים בתוך פאה, קצוות חוטיים בלי פאה | שכפלו את הרשת ב{{ui:Model}}; חתכו בסכין מקצה לקצה; [הבלטה](topic:mesh-edit#change-the-shape) של קצוות פתוחים לפאות |

| עותקים עצמאיים של קבוצה | הפכו אותה לרכיב, ואז {{ui:Make unique}} (ראו [פתרון בעיות](topic:troubleshooting#editing-one-group-changed-another)) |

| פתירת חלק שחוצה את עצמו, או קצוות שבהם שלוש פאות או יותר נפגשות | [תיקון](topic:print-tools#repair) מפרט אותם עם מיקומם; השתמשו ב[חיתוך פאות](topic:intersect) ומחקו את מה שבפנים |
| דפוסי מילוי ורשת בתוך חלל | [חלול](topic:print-tools#hollow) משאיר אותו ריק; תוכנת החיתוך שלכם מוסיפה מילוי לחלק מלא |
| פרטים קטנים מדי לנחיר שלכם (למעט קירות) | [עובי קיר](topic:print-tools#wall-thickness) מוצא קירות דקים; תצוגת השכבות של תוכנת החיתוך מראה את השאר |

## ביצועים

ביטול שומר עותק של המודל לכל שלב ([רשת](topic:meshes) שומרת רק את מה שהשתנה), ולכן ייבוא גדול מאוד של גיאומטריית דחיפה/משיכה מאט כל עריכה. שמרו על ייבואים קלים, ושמרו ופתחו מחדש כדי לנקות את ההיסטוריה.

## יישומים ופלטפורמות

- **שולחן עבודה:** ModelCraft פועלת בדפדפן ב-Mac, Windows ו-Linux, וב-CadCraft Studio, יישום שולחן העבודה עם כל שמונת היישומים בהתקנה אחת. ב-Android, CadCraft Studio מותקן מקובץ ה-APK ב-getcadcraft.com/download. עדיין אין גרסה ל-iPad או ל-iPhone.
- **מגע:** ראו [מסלול, הזזה וזום](topic:orbit-pan-zoom) לתנועות אצבע. לחץ העט קובע את המברשת ב[פיסול](topic:sculpt); במקומות אחרים לא משתמשים בלחץ ובהטיה של העט.
- **גיליונות:** ModelCraft [מדפיסה תצוגה אחת בכל עמוד](topic:export-model#print-the-view-or-save-it-as-a-pdf); אין פריסות גיליון עם כמה תצוגות או טבלת כותרת. לשרטוטים בקנה מידה, ייצאו לקבצי DWG/DXF התואמים ל-CadCraft.
