## 3D view ဗလာ ဖြစ်နေသည်

**လက္ခဏာ:** မျက်နှာပြင်အလယ်တွင် ဗလာ ကျန်နေသည်၊ သို့မဟုတ် နောက်ခံအရောင်သာ ပြသသည်၊ ကိရိယာများကို နှိပ်လျှင် ဘာမျှ မဖြစ်ပါ။

**အကြောင်းရင်း:** ModelCraft က WebGL 2 ဖြင့် ဆွဲသည်၊ ဘရောက်ဆာ၏ 3D graphics ဖြစ်သည်။ ဘရောက်ဆာ အဟောင်းဖြစ်လျှင်၊ hardware acceleration ပိတ်ထားလျှင် သို့မဟုတ် graphics driver ပိတ်ဆို့ထားလျှင် ပျောက်နေသည်။

**ပြင်ဆင်နည်း:**

:::chromium
1. ဘရောက်ဆာ settings ကို ဖွင့်ပြီး "graphics acceleration" ကို ရှာပါ။
2. "Use graphics acceleration when available" ကို ဖွင့်ပြီး ဘရောက်ဆာကို ပြန်ဖွင့်ပါ။
3. ဖွင့်ပြီးသားဆိုလျှင် လိပ်စာဘားတွင် `chrome://gpu` ရိုက်ပါ (Edge တွင် `edge://gpu`) ပြီး စာရင်းတွင် "WebGL2" ကို ရှာပါ။ disabled ဟု ပြလျှင် graphics driver ကို အပ်ဒိတ်လုပ်ပါ။
:::

:::firefox
1. **Settings** ကို ဖွင့်ပြီး **General** သို့သွား၊ "Performance" သို့ scroll လုပ်ပါ။
2. "Use recommended performance settings" ကို ဖြုတ်ပြီး "Use hardware acceleration when available" ကို အမှန်ခြစ်ပါ။ Firefox ကို ပြန်စတင်ပါ။
3. ဆက်မရလျှင် လိပ်စာဘားတွင် `about:support` ရိုက်ပြီး "Graphics" ကဏ္ဍရှိ WebGL 2 ကို ကြည့်ပါ။
:::

:::safari
macOS နှင့် Safari ကို အပ်ဒိတ်လုပ်ပါ။ Safari ၏ နောက်ဆုံး ဗားရှင်းများတွင် WebGL 2 အမြဲဖွင့်ထားသည်။ **Safari** ၊ ထို့နောက် **Settings** ၊ ထို့နောက် **Advanced** (သို့မဟုတ် **Feature Flags**) အောက်တွင် experimental features များကို ပြောင်းထားလျှင် ပြန်သတ်မှတ်ပါ။
:::

အလုပ်ကွန်ပျူတာ၊ remote desktop သို့မဟုတ် virtual machine တွင် 3D graphics ကို မူဝါဒဖြင့် ပိတ်ထားနိုင်သည်။ ကွန်ပျူတာ အခြားတစ်လုံးဖြင့် စမ်းကြည့်ပါ။ See [ဘရောက်ဆာများနှင့် ကွန်ပျူတာများ](common:browsers)။

## ကီးများ ဘာမျှ မလုပ်၊ သို့မဟုတ် ဘောက်စ်ထဲ ရိုက်သည်

**အကြောင်းရင်း:** keyboard focus သည် panel field တစ်ခုတွင် ရှိနေသည်: {{ui:Style}} ရှိ {{ui:Faces}} စာရင်း၊ နေ ဆက်တင်တစ်ခု၊ {{ui:Entity info}} ရှိ {{ui:Name}} field သို့မဟုတ် units picker။ ထိုအခါ အက္ခရာများနှင့် arrow ကီးများ ထို field သို့ သွားသည်။

**ပြင်ဆင်နည်း:** 3D view ကို နှိပ်ပြီး ကီးကို ထပ်ဖိပါ။ dialog ဖွင့်နေချိန်တွင်လည်း ကီးများ အလုပ်မလုပ်ပါ။

## ဂဏန်း ရိုက်သော်လည်း ဘာမျှ မဖြစ်ပါ

- **ဦးတည်ချက် မရှိသေး။** ရိုက်ထားသော အလျားသည် ပထမ နှိပ်ချက်မှ pointer ညွှန်သည့် လမ်းကြောင်းအတိုင်း သွားသည်။ လိုချင်သော ဦးတည်ချက်ဆီ pointer ကို အနည်းငယ် ရွှေ့ပြီးမှ ရိုက်ပါ။
- **မှားသော အချိန်။** ကိရိယာအများစုက ပထမ နှိပ်ပြီးမှသာ တန်ဖိုးကို လက်ခံသည်: ပထမ ထောင့်၊ မျက်နှာပြင် သို့မဟုတ် ရွှေ့မည့် point ကို ဦးစွာ နှိပ်ပါ။ {{ui:Circle}} နှင့် {{ui:Polygon}} က ပထမ နှိပ်ခြင်းမတိုင်မီ ဘက်အရေအတွက် ယူသည်။
- **"Type a length such as 3m, 10'6" or 4m,3m."** ModelCraft က ဖတ်၍ မရပါ။ ဒဿမ ကော်မာ (`2,5`) ရှိမရှိ စစ်ပါ: ဒဿမ အစက် (period) ကို သုံးပါ။

## touch screen တွင် ပုံသဏ္ဍာန် မှားသော နေရာမှ စတင်သည်

**လက္ခဏာ:** လက်ညှိုးဖြင့် ပထမ စတုဂ္ဂံ မှန်သော်လည်း နောက် စတုဂ္ဂံ၊ စက်ဝိုင်း သို့မဟုတ် မျဉ်းသည် သင်ထိခဲ့သော နေရာမဟုတ်ဘဲ ယခင် touch ပြီးဆုံးရာမှ စတင်သည်။

**အကြောင်းရင်း:** ဤ build ရှိ bug ဖြစ်သည်: touch screen တွင် ကိရိယာက ယခင် gesture မှ နောက်ဆုံး snap point ကို မှတ်ထားသည်။

**ပြင်ဆင်နည်း:** ပုံသဏ္ဍာန်အသစ်တိုင်းမတိုင်မီ toolbar ရှိ ကိရိယာခလုတ်ကို ထပ်ထိပါ။ ၎င်းက ကိရိယာကို အစကနေ စတင်စေပြီး ပထမ point သည် သင်ထိသည့်နေရာသို့ ကျသည်။

## အုပ်စု တစ်ခု တည်းဖြတ်ရာ နောက်တစ်ခု ပြောင်းသွားသည်

**လက္ခဏာ:** {{ui:Move}} နှင့် {{key:Ctrl}} ဖြင့် အုပ်စုတစ်ခုကို ကူးပြီး ပုံတူတစ်ခုကို ဖွင့်ကာ ပြင်ဆင်သည်၊ နောက်တစ်ခုလည်း ပြောင်းသွားသည်။ {{ui:Outliner}} တွင် နှစ်ခုစလုံး အမည်တူ ပြသည်။

**အကြောင်းရင်း:** ဤ build တွင် အုပ်စု ကူးခြင်းက အစိတ်အပိုင်းကဲ့သို့ တူညီသော အုပ်စု၏ နောက်ထပ် placement တစ်ခု ပြုလုပ်သည်။ ModelCraft ၏ {{ui:Make unique}} ခလုတ်ကို အစိတ်အပိုင်းများအတွက်သာ ပေးသည်။

**ပြင်ဆင်နည်း:** ပြောင်းလိုသော ပုံတူကို ရွေးပါ၊ {{ui:Entity info}} ရှိ {{ui:Make component}} ကို နှိပ်ပြီး ထို့နောက် {{ui:Make unique}}။ ထိုပုံတူသည် ကိုယ်ပိုင် အကြောင်းအရာ ရရှိသည်။ သို့မဟုတ် {{ui:Explode}} လုပ်ပါ။

## Push/pull မျှော်လင့်သလို မလုပ်ပါ

- **"Push/pull works on a face. Click a face."** သင် edge သို့မဟုတ် အလွတ်နေရာကို နှိပ်ခဲ့သည်။ မျက်နှာပြင် မီးမလင်းမချင် ကြည့်ပြီး နှိပ်ပါ။
- **မျက်နှာပြင်က အုပ်စုတစ်ခုအတွင်း ရှိသည်။** ဦးစွာ ဖွင့်ရန် အုပ်စုကို နှစ်ကြိမ်နှိပ်ပါ။
- **ဝင်းဒိုးက နံရံကို မဖြတ်ခဲ့ပါ။** စတုဂ္ဂံကို နံရံ၏ မျက်နှာပြင်ပေါ် ဆွဲရမည်၊ ရှေ့မှာ မဟုတ်ဘဲ၊ နံရံတွင် နောက်မျက်နှာပြင် ရှိရမည်။ See [နံရံတစ်ခုတွင် အပေါက် ဖြတ်ခြင်း](topic:openings#if-it-did-not-cut-through)။
- **Solid နှစ်ခု ထပ်နေသော်လည်း မပေါင်းပါ။** တစ်ခုထဲသို့ တွန်းထားသော solid များသည် ဤ build တွင် တစ်ခုကို တစ်ခု မဖြတ်/မပေါင်းပါ။

## မျဉ်း သို့မဟုတ် ပုံသဏ္ဍာန်က မျက်နှာပြင် မဖြစ်ပါ

မျက်နှာပြင်သည် အစွန်းများက ပြားသော loop တစ်ခုကို ပိတ်မှသာ ဖြည့်သည်။ နောက်ဆုံး point သည် ပထမ point သို့ snap ("Endpoint") ဖြစ်မဖြစ်၊ အစွန်းအားလုံး ပြားတစ်ခုတွင် ရှိမရှိ စစ်ပါ။ အနည်းငယ် ပြားမှ ထွက်သော loop သည် မျဉ်းများအဖြစ် ကျန်နေသည်။ ၎င်း၏ အစွန်းတစ်ခုကို ထောင့်များသို့ snap လုပ်ပြီး ပြန်ဆွဲပါ။

## မျက်နှာပြင် ရွေး/ဖျက် မရပါ

- {{ui:Select}} ဖြင့် အစွန်းအနီး နှိပ်လျှင် အစွန်းကို ယူသည်။ မျက်နှာပြင်၏ အလယ်အနီးတွင် နှိပ်ပါ။
- {{ui:Eraser}} က မျက်နှာပြင်ကို မရွေးပါ။ မျက်နှာပြင်ကို ရွေးပြီး {{key:Delete}} ကို ဖိပါ၊ သို့မဟုတ် ၎င်း၏ အစွန်းတစ်ခုကို ဖျက်ပါ။
- အုပ်စု သို့မဟုတ် အစိတ်အပိုင်း၏ အစိတ်အပိုင်းဖြစ်လျှင် နှိပ်ချက်က အရာတစ်ခုလုံးကို ရွေးသည်။ ဖွင့်ရန် နှစ်ကြိမ်နှိပ်ပါ။

## "Select something to move first, or click on it."

{{ui:Move}}၊ {{ui:Rotate}} နှင့် {{ui:Scale}} သည် လုပ်ရန် အရာတစ်ခု လိုသည်: ဦးစွာ ရွေးပါ၊ သို့မဟုတ် အရာပေါ်တွင် တိုက်ရိုက် နှိပ်ပြီး ကိရိယာ စတင်ပါ (အလွတ်နေရာ သို့မဟုတ် guide ပေါ် မဟုတ်ဘဲ)။

## "Select some geometry first (drag a window, or triple-click to select everything connected)."

{{key:G}} နှင့် {{key:Shift+G}} သည် ရွေးချယ်မှု လိုသည်။ Guide များကို အုပ်စုဖွဲ့၍ မရပါ။

## Arrow ကီးများက lock အစား orbit လုပ်သည်

Lock များသည် ဆွဲခြင်း သို့မဟုတ် တည်းဖြတ်ခြင်း ကိရိယာ၏ ပထမ နှိပ်ချက်ပြီးမှသာ အလုပ်လုပ်သည်။ {{ui:Push/pull}} တွင် lock မရှိပါ၊ {{ui:Rotate}} တွင် ၎င်းတို့က လှည့်မှုကို မပြောင်းပါ။ အခြားအချိန်များတွင် arrow ကီးများက view ကို orbit လုပ်သည်။

## Full screen တွင် Esc

Full screen တွင် ဘရောက်ဆာက ပထမ {{key:Esc}} ကို full screen မှ ထွက်ရန် သုံးနိုင်သည်။ ကိရိယာကို ပယ်ဖျက်ရန် {{key:Esc}} ကို ထပ်ဖိပါ။

## အလယ်ခလုတ် မရှိ

{{ui:Orbit}} အတွက် {{key:O}} ကို ဖိပြီး ဆွဲပါ၊ သို့မဟုတ် arrow ကီးများ သုံးပါ။ See [Orbit, pan and zoom](topic:orbit-pan-zoom#without-a-middle-button)။

### သွင်းထားသော အရွယ်အစား မှား သို့မဟုတ် ဘေးတိုက် လဲနေသည်

- **OBJ:** OBJ တွင် ယူနစ် မပါ; ModelCraft က မီတာဖြင့် ဖတ်သည်။ မီလီမီတာ model သည် 1000 ဆ ကြီးလာသည်: `0.001` ဖြင့် [အတိုင်းအတာ ပြောင်း](topic:rotate-scale#fix-an-import-that-came-in-the-wrong-size)၊ လက်မ model အတွက် `0.0254`။
- **OBJ ဘေးတိုက်:** ModelCraft က Y အပေါ်ဖြင့် OBJ ဖိုင်များကို မျှော်သည်။ Z အပေါ်ဖြင့် ရေးထားသော ဖိုင်သည် လဲလျောင်းလာသည်။ red ဝင်ရိုးပေါ် 90° လှည့်ပါ: red ဘက်သို့ မျက်နှာမူသော မျက်နှာပြင်ပေါ် {{ui:Rotate}} ဗဟိုကို နှိပ်ပါ၊ သို့မဟုတ် program တွင် ဖွင့်ပြီး Y အပေါ်ဖြင့် export လုပ်ပါ။
- **DWG သို့မဟုတ် DXF:** "Drawing units" dialog တွင် မှားသော ယူနစ် ရွေးခဲ့သည်။ Undo လုပ်ပြီး ပြန်သွင်းပါ။

## အလုပ် ဆုံးရှုံးခဲ့သည်

ModelCraft သည် ဖိုင်သို့ သူ့ဘာသာ မသိမ်းပါ။ မသိမ်းရသေးသော ပြောင်းလဲမှုများရှိသော tab ကို ပိတ်ခြင်း သို့မဟုတ် ပြန်တင်ခြင်း ပြုသည့်အခါ ဘရောက်ဆာက ဦးစွာ မေးသည် ("Leave site?" သို့မဟုတ် "Reload site?")၊ ရပ်ပြီး သိမ်းရန် ရွေးပါ။ New နှင့် Open လည်း မေးသည် ("Unsaved changes")။ ဘရောက်ဆာ သို့မဟုတ် ကွန်ပျူတာ ပျက်ကျသွားလျှင် တူညီသော ဘရောက်ဆာတွင် ModelCraft ကို ပြန်ဖွင့်ပါ- မသိမ်းရသေးသော အလုပ်ကို ပြန်ပေးသည် ("Recover your work?"; see [အလုပ် ပြန်ရယူခြင်း](common:recover))။ {{key:Mod+S}} ဖြင့် မကြာခဏ သိမ်းပါ။

## ဒေါင်းလုဒ် ဖိုလ်ဒါ ကော်ပီ များ ပြည့်နေသည်

သိမ်းတိုင်း အသစ် download တစ်ခု ဖြစ်သည်၊ `Untitled (1).modelcraft`၊ `Untitled (2).modelcraft` စသည်ဖြင့် အမည်ပေးသည်။ အဟောင်းများကို ဖျက်ပါ၊ သို့မဟုတ် ဘရောက်ဆာကို ဖိုင်တစ်ခုစီ သိမ်းမည့်နေရာ မေးစေပြီး အဟောင်းကို ကိုယ်တိုင် အစားထိုးစေပါ။ See [ဖိုင်ဖွင့်၊ သိမ်း၊ သွင်းနှင့် ပို့ခြင်း](topic:files#save-a-model)။

## နှေးသွားသည်

- undo ၏ အဆင့်တိုင်းက မော်ဒယ်၏ မိတ္တူတစ်ခု ထားသည် ([mesh](topic:meshes) က ပြောင်းသည့်အရာသာ ထားသည်)၊ ထို့ကြောင့် push/pull ဂျီသြမေတြီ အလွန်ကြီးသော import တွင် တည်းဖြတ်တိုင်း ပိုကြာသည်။ မလိုသည်များကို Explode သို့မဟုတ် ဖျက်ပြီး သိမ်း၊ ပြန်ဖွင့်ပါ- ပြန်ဖွင့်ခြင်းက undo မှတ်တမ်းကိုလည်း ရှင်းသည်။
- နေရောင်အရိပ်များက အများဆုံး ကုန်ကျသည်။ ပုံဖော်နေစဉ် {{ui:Sun shadows}} ကို ဖြုတ်ပါ။

## အရိပ် မရှိ

{{ui:Sun shadows}} ပိတ်ထားသည်၊ သို့မဟုတ် သင်ရွေးသော အချိန်တွင် နေ ဝင်နေသည် ("The sun is down at this time.")၊ သို့မဟုတ် ပုံစံက {{ui:Wireframe}} ဖြစ်သည်၊ ၎င်းက အရိပ် မဆွဲပါ။

## "This browser did not allow full screen."

ဘရောက်ဆာအချို့နှင့် embedded view အချို့က full screen ကို ငြင်းသည်။ ဘရောက်ဆာ၏ ကိုယ်ပိုင် full screen ကို အစား သုံးပါ ({{pick:mac=Control-Command-F|windows linux=F11}})။

## ချိတ်ဆက်မှု မရှိဘဲ ModelCraft မဖွင့်ပါ

ModelCraft သည် ထိုဘရောက်ဆာတွင် offline အသုံးပြုရန် သိမ်းထားမှသာ offline ဖွင့်နိုင်သည်: app bar ရှိ ခလုတ်က {{ui:Offline ready}} ဟု ဖတ်ရမည်။ အင်တာနက်ရှိစဉ် ဖွင့်ပြီး {{ui:Save for offline}} ကို နှိပ်ပါ။ ခလုတ်က {{ui:Could not save}} ဖတ်လျှင် ပိုကောင်းသော ချိတ်ဆက်မှုဖြင့် နောက်တစ်ကြိမ် နှိပ်ပါ။ {{ui:Offline not available}} ဆိုလျှင် ဤ window (private window သို့မဟုတ် စီမံထားသော ကွန်ပျူတာ) က မိတ္တူ မထားနိုင်ပါ။ See [အော့ဖ်လိုင်း အလုပ်လုပ်ခြင်း](common:offline)။
