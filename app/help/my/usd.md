USD သည် 3D၊ rendering နှင့် archviz program များ မျှဝေသော scene format ဖြစ်သည်။ ModelCraft က ရေးပြီး ဖတ်သည်။ `.modelcraft` သည် {{ui:Save}} ရေးသော format ဖြစ်ဆဲဖြစ်သည်; USD သည် {{ui:Save as}} တွင် ရွေးချယ်မှု ဖြစ်သည်။

## USD အဖြစ် သိမ်းခြင်း

1. {{ui:File}} အုပ်စုရှိ {{ui:Save as}} ကို ရွေးပါ (သို့မဟုတ် {{key:Mod+Shift+S}} ကို ဖိပါ)။
2. format ရွေးပါ- {{ui:Text (.usda)}} (ဖတ်ရလွယ်၊ version control အတွက် ကောင်း)၊ {{ui:Binary (.usdc)}} (အသေးဆုံး နှင့် မြန်ဆုံး) သို့မဟုတ် {{ui:Package (.usdz)}} (texture များ အတွင်းပါဝင်သော ဖိုင်တစ်ခု)။
3. ဖိုင် download ဖြစ်သည် (desktop app တွင် ဘယ်နေရာ သွားမည်ကို ရွေးနိုင်သည်)။

အတူတူ ရွေးချယ်မှုများက {{ui:Export}} › {{ui:USD (.usda, .usdc, .usdz)…}} တွင်လည်း ရှိသည်။

## ဘာမျှ မဆုံးရှုံးပါ

ModelCraft သိမ်းထားသော USD ဖိုင်ကို ဖွင့်လျှင် မော်ဒယ်ကို အတိအကျ ပြန်ရသည်: အပေါက်များပါသော မျက်နှာပြင်များ၊ နူးညံ့သော နှင့် ဝှက်ထားသော အစွန်းများ၊ ကွေးမျဉ်းများ၊ အုပ်စုများနှင့် အစိတ်အပိုင်းများ၊ တဂ်များ၊ scene များ၊ dimension များ၊ guide များ၊ section plane များ၊ မီးများ၊ သွင်းထားသော texture များနှင့် မြင်ကွင်း။ အခြား program များက တူညီသော မော်ဒယ်ကို mesh များ၊ အုပ်စုများ၊ အစိတ်အပိုင်းများအတွက် prototype များ၊ material များ၊ မီးများနှင့် ကင်မရာများအဖြစ် မြင်သည်။

:::note
အခြား program က အုပ်စု သို့မဟုတ် အစိတ်အပိုင်း၏ ဂျီသြမေတြီကို ပြောင်းလျှင် ModelCraft က ထိုအပိုင်းကို ပြောင်းလဲမှု ထားသည့် mesh အဖြစ် ဖွင့်ပြီး ဘယ်နှစ်ပိုင်း ထိုသို့ ဖတ်သည်ကို ပြောသည်။ အခြား program တွင် ရွှေ့ထားသော သို့မဟုတ် ဖျက်ထားသော placement သည် ရွှေ့ထား/ဖျက်ထား ဆက်ရှိသည်။
:::

## တခြားသူ၏ USD ကို ဖွင့်ခြင်း သို့မဟုတ် သွင်းခြင်း

- `.usd`၊ `.usda`၊ `.usdc` သို့မဟုတ် `.usdz` ဖိုင်တစ်ခုကို {{ui:Open}} လုပ်ပြီး ထိုမှ မော်ဒယ် စတင်ပါ။
- တစ်ခုကို {{ui:Import}} လုပ်ပြီး ဖွင့်ထားသော မော်ဒယ်သို့ ထည့်ပါ။ ၎င်းရည်ညွှန်းသော ဖိုင်များ (အခြား layer များ၊ texture များ) ကို ၎င်းနှင့်အတူ ချပါ။

Mesh များသည် ၎င်းတို့၏ normal၊ UV coordinate နှင့် အရောင်များဖြင့် ဝင်လာသည်၊ မျှဝေသော ဂျီသြမေတြီများက အစိတ်အပိုင်းအဖြစ်၊ material များက ဆေးသုတ်အရောင်အဖြစ်၊ မီးများက မီးအဖြစ်၊ ကင်မရာများက scene အဖြစ် ဝင်လာသည်၊ ဖိုင်၏ ယူနစ်နှင့် up axis မည်သို့ပင် ဖြစ်စေ မီတာနှင့် Z အပေါ်ဖြင့်။

## မရသေးသော အရာများ

Animation၊ skeleton နှင့် MaterialX node graph များကို USD အဖြစ် ဖတ်ခြင်း သို့မဟုတ် ရေးခြင်း မလုပ်ရသေးပါ။ ModelCraft ၏ ကိုယ်ပိုင် animation နှင့် node material များကို ၎င်း သိမ်းထားသော USD ဖိုင်တွင် ထားသည်၊ ModelCraft က ပြန်ဖွင့်ရန်၊ သို့သော် အခြား program များက မမြင်ပါ။ ModelCraft မဖတ်နိုင်သော ဖိုင်မှ ရည်ညွှန်းသော layer များ (ဥပမာ MaterialX စာရွက်စာတမ်း) ကို မှတ်ချက်ဖြင့် ချန်ထားသည်။
