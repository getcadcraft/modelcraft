ModelCraft ၏ ကိရိယာများသည် မည်သို့ရောက်ရောက် တူညီသည်။ **မီနူးပုံစံ** သည် ၎င်းတို့ ဖန်သားပြင်ပေါ်တွင် ဘယ်နေရာ ရှိမည်၊ ထိုနေရာတွင် ဘယ်လို ခေါ်မည်နှင့် ဘယ် key က ၎င်းတို့ကို run မည်ကို ဆုံးဖြတ်သည်။ {{ui:Settings}} ({{key:Mod+,}}) › {{ui:ModelCraft}} › {{ui:Menus, keys and mouse}} တွင် ရွေးပါ၊ ပြောင်းလဲမှုက ချက်ချင်း ဖြစ်သည်၊ ဤ browser က မှတ်ထားသည်။

## ပုံစံများ

| ပုံစံ | သင်ရရှိမည့်အရာ |
|---|---|
| {{ui:ModelCraft}} | ModelCraft ၏ ကိုယ်ပိုင် toolbar (File၊ Draw၊ Modify၊ Organize၊ Edit၊ Camera) နှင့် အက္ခရာတစ်လုံးစီ key များ: {{key:L}} line၊ {{key:R}} rectangle၊ {{key:P}} push/pull၊ {{key:M}} move၊ {{key:Q}} rotate၊ {{key:S}} scale၊ {{key:E}} eraser၊ {{key:O}} orbit။ စတင်ပုံစံ |
| {{ui:Push-pull}} | မီနူးဘား (File၊ Edit၊ View၊ Camera၊ Draw၊ Tools၊ Window) နှင့် အဓိကကိရိယာများ တန်းတစ်တန်း၊ အက္ခရာတစ်လုံးစီ key များတူညီသည် |
| {{ui:Modeler}} | ခေါင်းစီးမီနူးဘား (File၊ Edit၊ View၊ Select၊ Add၊ Object၊ Mesh) နှင့် mesh modeler များ၏ key များ: {{key:W}} select၊ {{key:G}} grab၊ {{key:R}} rotate နှင့် {{key:S}} scale ကို ရွေးထားသည်များအပေါ် တစ်ပြိုင်တည်း ({{key:X}}၊ {{key:Y}} သို့မဟုတ် {{key:Z}} သည် ရွှေ့နေစဉ် axis တစ်ခုကို လော့ခ်ချသည်)၊ {{key:E}} push/pull၊ {{key:B}} rectangle၊ {{key:X}} delete၊ {{key:A}} select all၊ {{key:Alt+A}} none၊ {{key:Shift+D}} duplicate၊ {{key:Mod+G}} group၊ {{key:H}} hide။ အလယ်ခလုတ်က orbit လုပ်သည်၊ {{key:Shift}} နှင့် အလယ်ခလုတ်က pan၊ {{key:Mod}} နှင့် အလယ်ခလုတ်က zoom လုပ်သည်၊ ညာခလုတ်က ကိရိယာ လုပ်နေသည်ကို ပယ်ဖျက်သည် |
| {{ui:Beginner}} | {{ui:Make}} tab သည် ခလုတ်ကြီးအနည်းငယ် ပါသော ribbon- ချရန် ပုံသဏ္ဍာန်များ၊ အပေါက်များ၊ ရွှေ့ခြင်း၊ လှည့်ခြင်းနှင့် အရွယ်အစား၊ ညှိခြင်း၊ {{ui:Group}} (ပုံသဏ္ဍာန်များထဲသို့ ဖြတ်ထားသော အပေါက်များ) နှင့် 3D print စစ်ဆေးချက်။ အခြားကိရိယာများအားလုံးသည် {{ui:More tools}} tab တွင်။ ညာခလုတ်က orbit၊ အလယ်ခလုတ်က pan လုပ်သည်။ [Beginner ပုံစံ](topic:beginner) ကို ကြည့်ပါ |

{{ui:Keys}} (ဖန်သားပြင် ညာဘက်အောက်ထောင့်နှင့် {{ui:Edit}} › {{ui:More}} မှ) ဟူသော key ပုံစံသည် ဤရွေးချယ်မှုနှင့် တူညီသည်- ထို့နေရာတွင် modeler keys ကို ရွေးလျှင် {{ui:Modeler}} ပုံစံကို ရွေးသည်၊ push-pull keys ကို ရွေးလျှင် {{ui:ModelCraft}} ပုံစံသို့ ပြန်သွားသည်။ ဗားရှင်းဟောင်းတွင် modeler keys ကို ရွေးခဲ့လျှင် ModelCraft သည် တစ်ကြိမ်တည်း {{ui:Modeler}} ပုံစံဖြင့် ကိုယ်တိုင် ဖွင့်သည်။

:::tip
push-pull keys နှင့် ပတ်သက်သော key တစ်ခုသည် သင့်ပုံစံက အခြား command ကို ပေးထားလျှင် ဘာမျှ မလုပ်ပါ၊ အခြေအနေလိုင်းက command ၏ နေရာကို ပြသည် ("In Modeler, Push/pull is E")။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် မြားများက အမြဲ ၎င်းတို့၏ အဓိပ္ပာယ်ကို ထိန်းသည်၊ နံပါတ်များက အမြဲ value box သို့ သွားသည်၊ ကိရိယာတစ်ခုက တစ်ခုခုကို ရွှေ့နေစဉ် ၎င်း၏ ကိုယ်ပိုင် key များက အနိုင်ရသည်။
:::

## ကိုယ်ပိုင်ပြုလုပ်ရန်

1. သင်လိုချင်သည်နှင့် အနီးဆုံးပုံစံကို ရွေးပြီး {{ui:Customize…}} ကို နှိပ်ပါ။
2. {{ui:Keys and menus}} တွင် command တစ်ခုကို ရှာပါ (ရှာဖွေရေးဘောက်စ် ကူညီသည်)။ {{ui:Add a key}} ကို နှိပ်ပြီး key ကို နှိပ်ပါ။ key ကို ဖယ်ရန် နှိပ်ပါ။
3. မီနူးဘားဖြင့် {{ui:Where it sits}} သည် command ကို အခြားမီနူးသို့ ရွှေ့သည်၊ သို့မဟုတ် {{ui:Keys only}} သို့။
4. {{ui:Mouse}} တွင် ဘီးနှင့် ခလုတ်များက 3D view တွင် ဘာလုပ်မည်ကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး **Save** ကို နှိပ်ပါ။

built-in ပုံစံကို သိမ်းလျှင် သင့်ကိုယ်ပိုင် မိတ္တူ ("My Modeler") ဖြစ်လာသည်၊ built-in ကတော့ ပြောင်းလဲခြင်း မရှိပါ။ သင့်မိတ္တူသည် စတင်ခဲ့သော ပုံစံအတိုင်း key များကို ဖတ်သည်- {{ui:Modeler}} မှ ပြုလုပ်သည်က grab၊ rotate နှင့် scale key များကို တစ်ပြိုင်တည်း ဆက်လုပ်ပေးသည်။

## Mouse

- **Mouse ဘီး**: {{ui:Scroll up zooms in}} (စတင်ပုံစံ) သို့မဟုတ် {{ui:Scroll up zooms out}}၊ နှင့် မည်မျှမြန်သလဲ။ trackpad pinch သည် အမြဲ သင့်လက်ချောင်းရွေ့သည့် ဘက်သို့ zoom လုပ်သည်။
- **3D view ထဲ ဆွဲခြင်း**: {{ui:Each view's own}} သည် ModelCraft ၏ ခလုတ်များကို ထိန်းသည် (အလယ်ခလုတ်က orbit၊ ညာခလုတ် သို့မဟုတ် {{key:Shift}} နှင့် အလယ်ခလုတ်က pan)။ သို့မဟုတ် အလယ်နှင့် ညာခလုတ်များကို orbit၊ pan၊ zoom သို့မဟုတ် ဘာမျှမလုပ်ရန် သတ်မှတ်နိုင်သည်၊ {{key:Shift}} နှင့် ခလုတ်က orbit နှင့် pan ကို လဲလှယ်သည်။ ဘယ်ခလုတ်က အမြဲ အသုံးပြုနေသော ကိရိယာနှင့် ဆိုင်သည်။
- **Trackpad များ**: {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Scrolling}} က လက်ချောင်းနှစ်ချောင်းက orbit (trackpad) သို့မဟုတ် zoom (mouse) လုပ်မလားကို ဆုံးဖြတ်သည်။ [Orbit၊ pan နှင့် zoom](topic:orbit-pan-zoom) ကို ကြည့်ပါ။

## သင်နှင့်အတူ ယူသွားရန်

{{ui:Export}} သည် အသုံးပြုနေသော ပုံစံကို `.ccinput.json` ဖိုင်ငယ်တစ်ခုအဖြစ် သိမ်းသည်၊ {{ui:Import…}} သည် အခြားကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်ထံမှ တစ်ခုကို ထည့်သည်။ ထည့်သွင်းသော ဖိုင်သည် ModelCraft ၏ ကိုယ်ပိုင် command များကိုသာ ညွှန်ပြနိုင်သည်၊ အခြားအရာများကို ချန်ထားပြီး အခြေအနေလိုင်းတွင် ရေတွက်ပြသည်။ {{ui:Delete this style}} က သင့်ကိုယ်ပိုင်တစ်ခုကို ဖယ်ရှားသည်။

:::note
ဤဆက်တင်များသည် ဤ browser တွင် ကျန်ရှိသည်။ ပုံစံကဒ်များအောက်ရှိ {{ui:Use this style in every app}} သည် အက်ပ်အားလုံးကို ကိုက်ညီသော ပုံစံဖြင့် ဖွင့်စေသည်- {{ui:Push-pull}} သည် အခြားအက်ပ်များ၏ မီနူးဘားပုံစံများနှင့် တွဲသည်။ {{ui:Modeler}} တွင် အခြားအက်ပ်များမှာ တူညီသည် မရှိသဖြင့် ModelCraft ရွေးချယ်မှုအဖြစ် ဆက်ရှိနေသည်။
:::
