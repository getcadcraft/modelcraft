## သင် သိရှိရမည့်အရာများ

AI အကူအညီပေးသူ (သို့မဟုတ် သင်ရေးထားသော script) ကို ModelCraft နှင့် အလုပ်လုပ်စေခြင်းနှင့် ၎င်းထိခွင့်ရှိသည့်အရာများကို ဆုံးဖြတ်ခြင်း အကြောင်း ဖြစ်သည်။

ModelCraft တွင် **ကိုယ်ပိုင် AI မရှိပါ** ၊ မည်သည့်နေရာသို့မျှ ဘာမျှ မပို့ပါ။ အကူအညီပေးသူကို သင်ယူလာရမည်- Model Context Protocol (MCP) ကို နားလည်သော မည်သည့် program မဆို ဖြစ်နိုင်သည်။ ModelCraft က tools များကိုသာ ပေးသည်၊ မည်သည်ကို ရွေးမည်ကို သင် ဆုံးဖြတ်သည်။

## ဖွင့်ခြင်း

1. {{ui:Settings}} (app bar ရှိ gear သို့မဟုတ် {{key:Mod+,}}) ကို ဖွင့်ပြီး {{ui:ModelCraft}} tab သို့ သွားပါ။
2. {{ui:Assistants}} အောက်တွင် **AI အကူအညီပေးသူများနှင့် script များကို ModelCraft သုံးခွင့်ပေးရန်** ကို အမှန်ခြစ်ပါ။ သင်မလုပ်မချင်း ၎င်းသည် ပိတ်ထားသည်။
3. ၎င်းလုပ်ဆောင်နိုင်မည့်အရာကို ရွေးပါ- **ဖတ်ရန်** ကို အစမှာ အမှန်ခြစ်ထားပြီးဖြစ်သည်၊ **တည်းဖြတ်ရန်**၊ **သိမ်းရန်** သို့မဟုတ် **ပို့ရန်** ကို လိုအပ်မှသာ အမှန်ခြစ်ပါ။

သင် အမှန်ခြစ်ထားသော ခွင့်ပြုချက်များ အပြင်ရှိ tools များကို အကူအညီပေးသူသို့ မပေးပါ၊ တောင်းဆိုပါက ModelCraft က ပယ်ချပြီး activity မှတ်တမ်းတွင် ရေးထားမည်။ ဤခလုတ်ကို ပိတ်လိုက်ပါက ချိတ်ဆက်မှုအားလုံး တစ်ချိန်တည်း ပြတ်သွားမည်၊ {{ui:Reset ModelCraft settings}} ကလည်း ၎င်းကို ပိတ်ပေးသည်။

## အကူအညီပေးသူကို ချိတ်ဆက်ခြင်း

အကူအညီပေးသူများသည် သင့်ကွန်ပျူတာပေါ်ရှိ **CadCraft Studio** မှတစ်ဆင့် ချိတ်ဆက်သည်- Studio သည် ဤကွန်ပျူတာသာ ဝင်နိုင်သော server ငယ်တစ်ခုကို ဖွင့်ပြီး ၎င်း စတင်တိုင်းတွင် ပြုလုပ်သော token ဖြင့် ကာကွယ်ထားသည်။ Studio တွင် {{ui:Connect an assistant}} ကို ရွေးပြီး လိပ်စာနှင့် token ကို သင့်အကူအညီပေးသူထဲသို့ ကူးထည့်ပါ (ကူးထည့်ရန် တိကျသော ဆက်တင်များကို Studio က ပြသသည်)။ Token ကို ဘယ်တော့မျှ မမျှဝေပါနှင့်။

:::note
browser tab သည် အကူအညီပေးသူအတွက် ချိတ်ဆက်မှု ဖွင့်နိုင်ခြင်း မရှိပါ- browser apps များတွင် သင့်ကွန်ပျူတာပေါ်ရှိ CadCraft Studio ကို မသုံးမချင်း ခလုတ်သည် အကျိုးမရှိပါ။
:::

## သင်က ထိန်းချုပ်ထားဆဲ

- **ပြောင်းလဲမှု တစ်ခုစီသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်သည်**၊ အကူအညီပေးသူ၏ အမည်ဖြင့် အမှတ်အသားပြုထားသည် (ဥပမာ "Assistant: box")။ {{key:Mod+Z}} သည် အကူအညီပေးသူ၏ နောက်ဆုံးပြောင်းလဲမှုကို တစ်ခုလုံး ပြန်ဖျက်သည်။
- **ချိတ်ဆက်ထားသည်ကို သင် သိနိုင်သည်။** App bar ရှိ ခလုတ်တစ်ခုက ချိတ်ဆက်ထားစဉ် အကူအညီပေးသူ၏ အမည်ကို ပြသည်၊ ၎င်းကို နှိပ်လိုက်ပါက ၎င်း ဘာလုပ်ခွင့်ရှိသည်ကို ကြည့်နိုင်ပြီး **ဆက်သွယ်မှု ဖြတ်ရန်** ကိုလည်း ရွေးနိုင်သည်။
- **Activity။** {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}} › {{ui:Activity}} သည် ခေါ်ဆိုမှု တိုင်းကို စာရင်းပြုသည်- အချိန်၊ tool ဘယ်တစ်ခု၊ ပြီးခဲ့သည် သို့မဟုတ် ပယ်ချခံရသည်။ {{ui:Save the log}} က မိတ္တူတစ်ခု သိမ်းထားသည်။

## အကူအညီပေးသူ တောင်းဆိုနိုင်သည့်အရာများ

| Tool | ခွင့်ပြုချက် | ဘာလုပ်သလဲ |
|---|---|---|
| `app_info`, `model_describe` | ဖတ်ရန် | မော်ဒယ်၏ ယူနစ်၊ အရွယ်အစားနှင့် group နှင့် component တိုင်း၏ နေရာ၊ ပိတ်ထားသော solid ဟုတ်မဟုတ်နှင့် ၎င်း၏ ထုထည် |
| `view_screenshot` | ဖတ်ရန် | ပြထားသည့်အတိုင်း 3D မြင်ကွင်း၏ ပုံ |
| `box_add`, `cylinder_add` | တည်းဖြတ်ရန် | ဘောက်စ် သို့မဟုတ် ဆလင်ဒါတစ်ခုကို group အသစ်အဖြစ် သင် သို့မဟုတ် ၎င်း ပေးသော နေရာနှင့် အရွယ်အစားဖြင့် ("3m"၊ "10'" သို့မဟုတ် မော်ဒယ်ယူနစ်ဖြင့် ဂဏန်း) |
| `instance_move`, `instances_erase` | တည်းဖြတ်ရန် | group နှင့် component များကို ရွှေ့ခြင်း သို့မဟုတ် ဖျက်ခြင်း |
| `faces_list`, `materials_list` | ဖတ်ရန် | group တစ်ခု သို့မဟုတ် loose geometry ၏ မျက်နှာများ (တစ်ခုစီ၏ ဦးတည်ချက်၊ ဧရိယာနှင့် ဗဟို); ၎င်း ဆေးသုံးနိုင်သော ပစ္စည်းနှင့် အရောင်များ |
| `push_pull` | တည်းဖြတ်ရန် | {{ui:တွန်း/ဆွဲ}} လုပ်သကဲ့သို့ မျက်နှာတစ်ခုကို တွန်းခြင်း သို့မဟုတ် ဆွဲခြင်း |
| `paint` | တည်းဖြတ်ရန် | မျက်နှာများ သို့မဟုတ် group တစ်ခုလုံးကို အရောင် သို့မဟုတ် ပစ္စည်းဖြင့် ဆေးခြယ်ခြင်း |
| `group_make` | တည်းဖြတ်ရန် | loose မျက်နှာများနှင့် group များမှ group သို့မဟုတ် component ဖန်တီးခြင်း |
| `scene_add`, `scene_show` | တည်းဖြတ်ရန် | မြင်ကွင်းကို scene အဖြစ် သိမ်းခြင်း; သိမ်းထားသော scene သို့ သွားခြင်း |
| `mesh_add` | တည်းဖြတ်ရန် | Mesh workspace က ထည့်သကဲ့သို့ စတင်ရန် mesh object (cube, sphere, cylinder …) |
| `modifiers_list`, `modifier_add`, `modifier_set`, `modifier_remove` | ဖတ်ရန် / တည်းဖြတ်ရန် | mesh ၏ modifier stack: mirror၊ array၊ subdivision၊ bevel နှင့် အခြားများ; အပြီးတိုင် မည်သည်ကိုမျှ အသုံးမပြုပါ |
| `usd_export` | ပို့ရန် | မော်ဒယ်ကို OpenUSD (.usda၊ .usdc သို့မဟုတ် .usdz) အဖြစ်၊ မော်ဒယ်ကို USD အဖြစ် သိမ်းသည့်နည်းအတိုင်း ([USD](topic:usd)); Studio တွင် သင်ခွင့်ပြုထားသော ဖိုဒါသို့၊ မဟုတ်ပါက ဒေါင်းလုဒ် |
| `render_still` | ပို့ရန် | မြင်ကွင်း သို့မဟုတ် သိမ်းထားသော scene ၏ render ပုံ၊ {{ui:ပုံရိပ် ထုတ်ရန်…}} dialog ရှိ {{ui:ရေးဆွဲရန်}} ခလုတ်က ပြုလုပ်သည့်အတိုင်း၊ အခြားတောင်းဆိုခြင်းမရှိလျှင် သင်၏ Render ဆက်တင်များဖြင့် (scene preset: exterior၊ interior၊ section၊ night သို့မဟုတ် auto; fast သို့မဟုတ် high quality၊ size၊ samples၊ sky); ကြည့်နိုင်သော PNG၊ သို့မဟုတ် Studio တွင် သင်ခွင့်ပြုထားသော ဖိုဒါထဲရှိ PNG၊ EXR သို့မဟုတ် render ဖိုင် ([ပုံ render လုပ်ခြင်း](topic:render)) |
| `render_queue` | ပို့ရန် | Render dialog ၏ queue သို့ အရည်အသွေးမြင့် ပုံများ (မြင်ကွင်း သို့မဟုတ် သိမ်းထားသော scene များ) ထည့်ပြီး queue ကို run သည်; ပြီးသော ပုံများသည် သင်ခွင့်ပြုထားသော ဖိုဒါသို့ သွားသည်၊ သို့မဟုတ် Render dialog ရှိ {{ui:Render queue}} တွင် သင့်အတွက် ဆက်ရှိနေသည်။ WebGPU လိုအပ်သည် |
| `link_push` | တည်းဖြတ်ရန် | အခြား program မှ ချိတ်ထားသော မော်ဒယ်ကို အပ်ဒိတ်လုပ်သည် (ကြည့်ရန် [.3dm မော်ဒယ်ကို live ထားခြင်း](topic:live-3dm-link)) |
| `link_status` | ဖတ်ရန် | ချိတ်ထားသော မော်ဒယ် ရှိနေသေးခြင်း ရှိ/မရှိနှင့် နောက်ဆုံး အပ်ဒိတ်လုပ်ခဲ့သည့်အချိန်ကို ပြောသည် |
| `undo` | တည်းဖြတ်ရန် | ကိုယ်ပိုင် အဆင့်များကို ပြန်ဖျက်သည် |

အကူအညီပေးသူ ဖန်တီးသော solid များသည် group များအဖြစ် ဝင်လာသဖြင့် သင်ဆွဲထားသည်များနှင့် ဘယ်တော့မျှ ပေါင်းမသွားပါ။ မော်ဒယ်ကို သိမ်းနိုင်သော tool မရှိပါ- သိမ်းခြင်းသည် သင့်အတွက် ဖြစ်ပြီး၊ ပို့ခြင်း သို့မဟုတ် render လုပ်ခြင်းအတွက် **ပို့ရန်** ကို အမှန်ခြစ်ရန် လိုအပ်သည်။ Render သည် မော်ဒယ်ကို မပြောင်းလဲပါ၊ သိမ်းထားသော scene ကို render လုပ်ခြင်းသည် {{ui:Scenes}} လုပ်သကဲ့သို့ မြင်ကွင်းကို ထို scene သို့ ရွှေ့သည်။

## မအောင်မြင်ပါက

- **အကူအညီပေးသူက ModelCraft tools များကို မမြင်ပါ-** ဤဝင်းဒိုးတွင် ခလုတ် ဖွင့်ထားခြင်းနှင့် ဝင်းဒိုး Studio တွင် ဖွင့်ထားခြင်းကို စစ်ပါ။
- **"needs the edit permission":** {{ui:Assistants}} အောက်တွင် **တည်းဖြတ်ရန်** ကို အမှန်ခြစ်ပြီး ထပ်မေးပါ။
- **"401" သို့မဟုတ် "token" အမှားများ:** token ပြောင်းသွားသည် (Studio ပြန်စတင်ခြင်း၊ သို့မဟုတ် {{ui:New token}})။ အသစ်ကို အကူအညီပေးသူ ဆက်တင်များထဲသို့ ကူးထည့်ပါ။
