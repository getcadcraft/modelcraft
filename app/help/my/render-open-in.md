ဇာတ်ခင်းကို အခြားပရိုဂရမ်သို့ ယူသွားရန် {{ui:Render a picture…}} ၏ Engine စာရင်းမှ **Open in** အတန်းကို ရွေးပါ။ မော်ဒယ်သို့ ဘာမျှ ပြန်မလာပါ။

## မည်သည့်ပရိုဂရမ်အတွက်မဆို ဖိုင်

- **USD file** က ဇာတ်ခင်းကို `.usdc` (သို့မဟုတ် မော်ဒယ်တွင် ပုံများပါလျှင် `.usdz`) အဖြစ် သိမ်းသည်: [USD အဖြစ် သိမ်းခြင်းနှင့် တူညီသော ဖိုင်](topic:usd)၊ material များ၊ မီးချောင်းများနှင့် ကင်မရာများပါဝင်သည်။ Instancing နှင့် material တန်ဖိုးအတိအကျကို ထိန်းသည်။ Renderer အများစု၊ game engine များနှင့် viewer များက USD ကို ဖတ်သည်။
- **glTF file (.glb)** က material၊ texture နှင့် မီးချောင်းများပါဝင်သော ပေါ့ပါးသော glTF 2.0 ဖိုင်ကို သိမ်းသည်; ModelCraft ရေးသော ဖော်မတ်များအတွက် [အခြားပရိုဂရမ်များအတွက် မော်ဒယ် ထုတ်ခြင်း](topic:export-model) ကို ကြည့်ပါ။

- **Unreal project ဖိုလ်ဒါ (.zip)** က [game engine သို့ ဇာတ်ခင်း ပို့ခြင်း](topic:render-unreal) ရေးသော ဖိုလ်ဒါကို သိမ်းသည်၊ မည်သည့်ကွန်ပျူတာပေါ်ရှိ project အတွက်မဆို။

သုံးမျိုးလုံး browser နှင့် Studio နှစ်ခုစလုံးတွင် အလုပ်လုပ်သည်။

## Studio တွင်: ပရိုဂရမ်တစ်ခုတွင် ဖွင့်ခြင်း

Studio က ဤကွန်ပျူတာပေါ်တွင် ဇာတ်ခင်းကို ဖွင့်နိုင်သော ပရိုဂရမ်များကို ရှာတွေ့သည်: သင့် search path ပေါ်ရှိ usdview နှင့် ဖိုင်အမျိုးအစားအတွက် ကွန်ပျူတာ၏ ကိုယ်ပိုင်ပရိုဂရမ်။ တစ်ခုကို ရွေးပါ၊ ဖတ်နိုင်သည့်နေရာတွင် USD သို့မဟုတ် glTF ကို ရွေးပြီး {{ui:Render}} ကို နှိပ်ပါ။ Studio က package ကို **Documents** အောက်ရှိ ဖိုလ်ဒါအသစ်တစ်ခုထဲ ရေးသည် (`CadCraft hand-off`; ဘာမျှ အစားထိုးမခံရ၊ ပို့တိုင်း ၎င်း၏ကိုယ်ပိုင် ဖိုလ်ဒါ ရသည်) ထို့နောက် ပရိုဂရမ်ကို ထိုဖိုလ်ဒါပေါ်တွင် စတင်ပြီး ဖိုင်များ ရှိနေသည့်နေရာကို ပြောသည်။

| ပရိုဂရမ် | အကောင်းဆုံး ဖတ်သည် |
|---|---|
| usdview | USD |
| ကွန်ပျူတာ၏ ကိုယ်ပိုင်ပရိုဂရမ် | ကွန်ပျူတာတွင် ထိုဖိုင်အမျိုးအစားအတွက် ရှိသည်မှာ မည်သည်ကမဆို |

Studio က ဤသတ်မှတ်ထားသော စာရင်းမှ ပရိုဂရမ်များကိုသာ စတင်သည်; စာမျက်နှာက အမည်ဖြင့် တောင်းဆိုသည်ကို မည်သည့်အရာမှ run ခြင်း မလုပ်ပါ၊ GNU GPL လိုင်စင်အောက်ရှိ ပရိုဂရမ်ကို ဘယ်တော့မှ မစတင်ပါ ([အခြားပရိုဂရမ်ဖြင့် ပုံဆွဲခြင်း](topic:render-other-program#programs-cadcraft-never-runs) ကို ကြည့်ပါ)။ USD သို့မဟုတ် glTF ဖတ်နိုင်သည့် မည်သည့်ပရိုဂရမ်မဆို အထက်ရှိ **ဖိုင်တစ်ခုအတွက် မည်သည့်ပရိုဂရမ်မဆို** ကို ဖွင့်သည်။

:::note
Twinmotion, Enscape နှင့် အခြား visualization ပရိုဂရမ်များသည် စာရင်းတွင် မပါပါ: CadCraft ကို ၎င်းတို့နှင့် စမ်းသပ်ခြင်း မရှိသဖြင့် ၎င်းတို့အကြောင်း အာမခံချက် မပေးပါ။ ဤနေရာမှ glTF သို့မဟုတ် USD ဖိုင်သည် ဝင်ပေါက် ဖြစ်သည်။
:::
