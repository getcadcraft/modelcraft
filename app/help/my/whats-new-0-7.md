ဤသည်မှာ ModelCraft 0.7 တွင် 0.6 နှင့် နှိုင်းယှဉ်၍ ပြောင်းလဲသွားခဲ့သည်များ ဖြစ်သည်။ ModelCraft သည် ယခု push/pull ဂျီသြမေတြီအပြင် mesh များကိုလည်း မော်ဒယ်ပြုလုပ်ပြီး graphics card ပေါ်တွင် ရေးဆွဲပြီး အလုပ်အမျိုးအစားတိုင်းအတွက် အလုပ်နေရာ တစ်ခုစီ ရှိသည်: toolbar ၏ ဘယ်ဘက်ရှိ {{ui:အလုပ်နေရာ}} စာရင်းတွင် ရွေးပါ။

## အသစ်

### Mesh များ

- **Mesh များ။** group သို့မဟုတ် component ကို ရွေးပြီး {{ui:Entity info}} ရှိ {{ui:Convert to mesh}} ကို click လုပ်ပါ: ၎င်း mesh ဖြစ်သွားသည်၊ မည်သည့် corner အရေအတွက်ရှိသော မျက်နှာများဖြင့်၊ texture coordinates၊ normals၊ အရောင်များနှင့် weights ကို ထိန်းနိုင်သည်။ {{ui:Convert to geometry}} က ပြန်ပြောင်းသည်။ mesh တွင် ပြန်လှည့်ခြင်း (Undo) က အဆင့်တိုင်းက ပြောင်းလဲခဲ့သည်များကိုသာ ထိန်းသည်။ mesh ပါဝင်သော ဖိုင်ကို ဖွင့်ရန် ModelCraft 0.7 လိုအပ်သည်။ ကြည့်ရန် [Mesh များ](topic:meshes)။
- **Mesh အလုပ်နေရာ။** mesh ကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် {{ui:Mesh}} ကို {{ui:အလုပ်နေရာ}} စာရင်းတွင် ရွေးပါ၊ ၎င်း၏ vertices၊ edges နှင့် faces ကို တည်းဖြတ်ရန်: loops နှင့် rings၊ proportional editing၊ extrude၊ inset၊ bevel၊ loop cut၊ knife၊ bisect၊ spin၊ merge၊ dissolve၊ fill၊ grid fill၊ bridge နှင့် slide၊ နောက်ဆုံး လုပ်ဆောင်ချက်၏ ဆက်တင်များကို နောက်မှ panel တွင် ပြောင်းနိုင်သည်။ plane၊ cube၊ sphere၊ torus နှင့် အခြားများမှ စတင်ပါ။ Push/pull ခလုတ်များနှင့် modeler ခလုတ်များ နှစ်ခုစလုံး အလုပ်လုပ်သည်။ ကြည့်ရန် [Mesh အလုပ်နေရာတွင် mesh တည်းဖြတ်ခြင်း](topic:mesh-edit)။
- **Modifiers။** Mirror၊ array၊ subdivision surface၊ bevel၊ solidify၊ boolean၊ displace၊ weld၊ decimate၊ smooth၊ lattice၊ curve deform နှင့် shrinkwrap တို့သည် mesh ပြသပုံကို ပြောင်းသည်၊ မော်ဒယ်ကို မပြောင်းဘဲ။ စုပုံထားနိုင်ပြီး မြင်ကွင်းနှင့် render အတွက် တစ်ခုစီကို ဖွင့်/ပိတ် လုပ်နိုင်ပြီး၊ အပြီးတိုင် လိုချင်သောအခါ တစ်ခုကို {{ui:Apply}} လုပ်ပါ။ ကြည့်ရန် [mesh ပေါ်ရှိ Modifiers](topic:modifiers)။
- **Subdivision ဖြင့် creases။** Mesh အလုပ်နေရာရှိ {{ui:Crease}} က ရွေးထားသော edges များကို subdivision surface အောက်တွင် ထက်မြက်နေစေသည်။ Render များတွင် မြင်ကွင်းထက် အဆင့် ပိုသုံးနိုင်ပြီး ကြီးမားသော mesh တွင် မြင်ကွင်းက အနိမ့်အဆင့်ကို ပြပြီး ထိုသို့ ပြောသည်။ ကြည့်ရန် [Subdivision surface](topic:modifiers#subdivision-surface)။
- **Curve objects။** Bézier၊ NURBS နှင့် straight-segment curves တို့သည် ပိုက်၊ ခါး၊ taper သို့မဟုတ် ဖြည့်ထားသော ပြား ပြုလုပ်ပြီး curve အဖြစ် စာသားကိုလည်း ပြုလုပ်နိုင်သည်။ {{ui:Curve}} အလုပ်နေရာတွင် ၎င်းတို့၏ အမှတ်များကို တည်းဖြတ်ပါ; ပုံသဏ္ဍာန် မှန်ကန်သောအခါ {{ui:To mesh}}။ ကြည့်ရန် [Curve objects](topic:curves)။
- **UV အလုပ်နေရာ။** Seams အမှတ်အသားပြုပါ (သို့မဟုတ် ထက်သော အစွန်းများတွင် ModelCraft က အမှတ်အသားပြုခွင့်ပြုပါ)၊ {{ui:Unwrap}} နှင့် {{ui:Pack}}၊ သို့မဟုတ် ဘောက်စ်၊ ဆလင်ဒါ၊ စဖီယာ သို့မဟုတ် မြင်ကွင်းဖြင့် project လုပ်ပါ။ 3D မြင်ကွင်းဘေးရှိ UV editor က အပိုင်းများကို ရွှေ့၊ လှည့်နှင့် အတိုင်းအတာချနိုင်ပြီး checker နှင့် stretch အရောင်များက ရလဒ်ကို ပြသည်။ ကြည့်ရန် [mesh ၏ UV များကို စီစဉ်ခြင်း](topic:uv)။
- **ပုံသွင်းခြင်း။** {{ui:Sculpt}} အလုပ်နေရာတွင် draw၊ clay၊ smooth၊ grab၊ inflate၊ crease၊ pinch၊ flatten နှင့် mask brushes များ၊ X ဝင်ရိုးပတ်လည် mirroring နှင့် သင် ပုံသွင်းသည့်နေရာတွင် တြိဂံများထည့်သော {{ui:Detail}}။ ဘောပင်၏ ဖိအားက brush ၏ အရွယ်အစားနှင့် အား သတ်မှတ်သည်။ stroke တစ်ခုစီ တစ်ဆင့် undo ဖြစ်သည်။ ကြည့်ရန် [mesh ကို ပုံသွင်းခြင်း](topic:sculpt)။
- **Remesh နှင့် retopology။** {{ui:Remesh}} က mesh တစ်ခုလုံးကို တြိဂံညီညာစွာ ပြန်လုပ်ပြီး အပေါက်များပိတ်ကာ ထပ်နေသော အပိုင်းများ ပေါင်းသည်။ အသေးစိတ် mesh အပေါ် သန့်ရှင်းသော mesh တည်ဆောက်ရန် {{ui:Retopology}} အောက်တွင် ရွေးပါ: သင် ရွှေ့သော အမှတ်များသည် ၎င်း၏ မျက်နှာပြင်ပေါ် ကျသည်။ ကြည့်ရန် [Remesh](topic:mesh-edit#remesh)။

### ပုံဆွဲခြင်း

- **Edge သို့မဟုတ် curve ကို ခွဲခြင်း။** {{ui:Divide}} tool က edge တစ်လျှောက် ရွှေ့သည့်အခါ ဖြတ်မှတ်များကို မှတ်ပြီး click တစ်ချက် သို့မဟုတ် ရိုက်ထားသော ဂဏန်းဖြင့် ခွဲသည်; edge၊ arc သို့မဟုတ် circle ရွေးထားသောအခါ `/5` ကို ရိုက်ပါ; tablet များအတွက် {{ui:Entity info}} › {{ui:Divide…}} က ဂဏန်းကို မေးသည်။ arc သို့မဟုတ် circle ကို မှန်ကန်သော arc ပေါ်တွင် ညီညာသော ထောင့်များဖြင့် ခွဲသည်။ ကြည့်ရန် [edge သို့မဟုတ် curve ကို အညီအမျှ အပိုင်းများအဖြစ် ခွဲခြင်း](topic:divide)။
- **တန်ဖိုးအကွက်ရှိ တွက်ချက်မှုများ။** အရှည်အတွက် `2.5/3`၊ `12'6"+3/4"`၊ `(24'-0")/3` သို့မဟုတ် `2*450mm` ကို ရိုက်ပြီး ထောင့်အတွက် `90/2` ကို ရိုက်ပါ။ မလုပ်နိုင်သော တွက်ချက်မှုက ဘာမှားနေသည်နှင့် ဘယ်နေရာတွင်ဟု ပြောသည်။ ကြည့်ရန် [တွက်ချက်မှုများ](topic:value-box#calculations)။

### ရိုက်ယူခြင်း

- **Graphics card ပေါ် path tracing။** {{ui:ပုံရိပ် ထုတ်ရန်…}} › {{ui:အရည်အသွေးမြင့် (path traced)}} သည် browser တွင် WebGPU ရှိသည့်နေရာတွင် CadCraft ၏ ကိုယ်ပိုင် path tracer ကို graphics card ပေါ်တွင် run သည်; ပုံအောက်ရှိ စာကြောင်းက မည်သည့် engine က ပြုလုပ်သည်ကို ပြောသည်။ {{ui:Stop}} က ပုံကို ထိန်းထားပြီး {{ui:Resume}} က ထိုနေရာမှ ဆက်သည်။ WebGPU မရှိပါက ပုံသည် ယခင်အတိုင်း WebGL ဖြင့် path traced ဖြစ်သည်။ ကြည့်ရန် [အရည်အသွေးမြင့်](topic:render#high-quality)။
- **မြင်ကွင်းထဲတွင် ရေးဆွဲခြင်း။** {{ui:Render}} အလုပ်နေရာသည် မြင်ကွင်းကို ကိုယ်တိုင် path trace လုပ်ပြီး သင် orbit သို့မဟုတ် တည်းဖြတ်သည့်အခါ ပြန်စသည်: {{ui:Region}} ကို render လုပ်ပါ၊ {{ui:Focus}} ကို click လုပ်ပါ၊ {{ui:Detail}} ကို သတ်မှတ်ပါ။ WebGPU လိုအပ်သည်။ ကြည့်ရန် [မြင်ကွင်းထဲတွင် ရေးဆွဲခြင်း](topic:render#render-in-the-view)။
- **ပစ္စည်း၊ မီးနှင့် ကောင်းကင်များ။** အရည်အသွေးမြင့် ပုံများသည် မျက်နှာတိုင်းကို OpenPBR ပစ္စည်းပုံစံ (coats၊ fuzz၊ thin films၊ အရောင်ရှိ မှန်၊ glow) ဖြင့် အရိပ်ပေးသည်။ WebGPU ဖြင့် {{ui:Physical sky}} ကို {{ui:Haze}} နှင့်အတူ၊ {{ui:Sky picture (HDRI)}}၊ မီးများအတွက် ထုတ်လုပ်သူ၏ IES light profiles လည်း ရှိသည်။ ကြည့်ရန် [ကောင်းကင်များနှင့် light profiles](topic:render#skies-and-light-profiles-on-the-graphics-card)။
- **ဓာတ်ပုံကင်မရာကဲ့သို့။** f-stop၊ shutter နှင့် ISO မှ exposure ကို မုဒ်တိုင်းတွင်၊ WebGPU ဖြင့် depth of field၊ two-point perspective၊ white balance၊ 360° panorama (stereo ဖြင့်လည်း) နှင့် cube maps။ ကြည့်ရန် [ကင်မရာ](topic:render#the-camera)။
- **ရုပ်ပုံပြီးနောက် ပြီးမြောက်စေခြင်း။** အဆင့်သတ်မှတ်ခြင်း ({{ui:ACES filmic}}၊ {{ui:AgX}}၊ {{ui:Filmic}} သို့မဟုတ် {{ui:Standard}}၊ contrast၊ bloom၊ glare၊ vignette၊ `.cube` color table)၊ ကောင်းကင်၊ နေနှင့် မီးအုပ်စု တစ်ခုစီကို ရောနှောခြင်း၊ render elements တစ်ခုချင်းစီကို ကြည့်ခြင်း၊ ထပ်မံ render မလုပ်ဘဲ။ ကျန်သော grain ကို သင့်ကွန်ပျူတာပေါ်ရှိ denoiser က ရှင်းသည်။ ကြည့်ရန် [ပုံကို ပြီးမြောက်စေခြင်း](topic:render#finish-the-picture) နှင့် [render ပြီးနောက် မီးများကို ရောနှောခြင်း](topic:render#mix-the-lights-after-the-render)။
- **render သိမ်းနည်း ပိုများ။** 16-bit PNG၊ render element နှင့် light group အားလုံးပါသော multi-layer EXR၊ နှင့် ၎င်း၏ ရောနှောမှုနှင့် ဂရိတ်ဖြင့် ပြန်ဖွင့်နိုင်သော render ဖိုင် (`.ccrender`)။ ကြည့်ရန် [ပုံကို သိမ်းခြင်း](topic:render#save-the-picture)။
- **မှိုင်း၊ မီး ခိုး နှင့် caustics။** နေနှင့် မီးများက မီးထိုးထားသော မှိုင်းနှင့် haze၊ အလင်းတိုင်များပါဝင်; မီးခိုးကော်လံ သို့မဟုတ် တိမ်တစ်ခု; မှန်နှင့် မှန်ထောင့်များအောက်ရှိ caustics; ရှင်းနေသော pixels များ၌ ရပ်သော adaptive sampling။ graphics card ပေါ်တွင်သာ။ ကြည့်ရန် [မှိုင်း၊ မီးခိုး၊ noise နှင့် caustics](topic:render#fog-smoke-noise-and-caustics)။
- **Render queue နှင့် MP4။** အရည်အသွေးမြင့် ပုံများနှင့် အပြည့်အစုံ animations များကို {{ui:Render queue}} သို့ ထည့်ပါ; တစ်ခုပြီးတစ်ခု render လုပ်ပြီး စာမျက်နှာပိတ်သော်လည်း queue ကျန်ရှိသည်။ WebGPU လိုအပ်သည်။ browser ရေးနိုင်သည့်နေရာတွင် ဗီဒီယိုကို MP4 အဖြစ်လည်း သိမ်းနိုင်သည်။ ကြည့်ရန် [render queue](topic:render#the-render-queue) နှင့် [ဗီဒီယို render လုပ်ခြင်း](topic:animation#render-the-video)။

### Live view နှင့် တင်ပြချက်များ

- **Live view။** {{ui:Export}} › {{ui:Live view}} သည် မော်ဒယ်ကို မြင်ကွင်းဘေးတွင် real-time ပုံစံဖြင့် ပြသသည်၊ တည်းဖြတ်မှုတိုင်းနှင့် ကင်မရာကို လိုက်သည်: နေရိပ်များ၊ ပစ္စည်းများ၊ မီးများနှင့် နံရံများမှ ပြန်ထွက်သော အလင်း။ {{ui:Walk}} ဖြင့် ဖြတ်သွားပါ၊ {{ui:Time}} နှင့် {{ui:Month}} ကို ဆွဲ၍ နေကို ရွှေ့ပါ၊ သို့မဟုတ် {{ui:New window}} သို့ ရွှေ့ပါ။ browser တွင် WebGPU ရှိပါက ၎င်းကို အသုံးပြုသည်၊ မဟုတ်ပါက WebGL 2။ ကြည့်ရန် [live view](topic:live-view)။
- **Scatter။** ခုံ ကြိမ် ဖြန့်ကျဲ ... (ဖြန့်ကျဲခြင်း): မြက်၊ ပန်းများ၊ ကျောက်များ၊ သစ်ပင်များနှင့် လူများကို မျက်နှာများပေါ် သို့မဟုတ် brush ဖြင့် ဖြန့်ကျဲသည်၊ entourage အသစ် ခုနစ်ခုနှင့် စာကြည့်တိုက်၏ ကျန်များမှ; အစုံများကို ဖိုင်ထဲတွင် သိမ်းသည်။ ကြည့်ရန် [အပင်၊ ကျောက်နှင့် လူများကို ဖြန့်ကျဲခြင်း](topic:live-view#scatter-plants-rocks-and-people)။
- **မျှဝေခြင်း။** 360° panorama၊ လေးမြှား မြှားများကြား panorama tour၊ standalone viewer (အင်တာနက်မှ ဘာမျှ မဖွင့်ဘဲ offline ဖွင့်နိုင်သော web စာမျက်နှာတစ်ခု) နှင့် ကင်မရာလမ်းကြောင်း ဗီဒီယို၊ အားလုံး real-time ပုံစံဖြင့်။ ကြည့်ရန် [မျှဝေခြင်း](topic:live-view#share-panoramas-tours-a-viewer-a-video)။
- **Real-time ပုံစံဖြင့် VR။** {{ui:VR တွင် သုံးသပ်ရန်}} သည် မော်ဒယ်ကို ပစ္စည်း၊ ကောင်းကင်၊ နေရိပ်၊ မီးများ၊ ကျဲကျဲ ပြန့်သော ပစ္စည်းများနှင့် ပြန်ထွက်သော အလင်းဖြင့် ပြသသည်။ ကြည့်ရန် [မည်သို့ ပုံပေါ်သလဲ](topic:vr-review#what-it-looks-like)။

### ပစ္စည်းများ

- **Nodes ဖြင့် ပြုလုပ်ထားသော ပစ္စည်းများ။** {{ui:Shading}} အလုပ်နေရာသည် ဖိုင်၏ ကိုယ်ပိုင် ပစ္စည်းများကို node graphs အဖြစ် တည်ဆောက်သည်: ပုံများ၊ noise နှင့် checkers၊ Voronoi cells၊ လှိုင်းများ၊ အုတ်များ၊ ကြွေပြား၊ သစ်၊ စကျင်ကျောက်၊ gradients၊ ညစ်ပေရာနှင့် အစွန်း ပွန်းပဲ့မှု၊ အရောင်လုပ်ငန်း၊ သင်္ချာ၊ bump နှင့် normal maps၊ OpenPBR ပစ္စည်းအပြည့်အစုံအဖြစ်။ မြင်ကွင်းက ပြောင်းလဲမှုတိုင်းကို ချက်ချင်း ပြသည်။ ကြည့်ရန် [nodes ဖြင့် ပစ္စည်းများ ပြုလုပ်ခြင်း](topic:shading)။
- **ပစ္စည်း စာကြည့်တိုက်နှင့် သင့်ကိုယ်ပိုင် texture အစုံများ။** Shading panel သည် Library ၏ ပစ္စည်းများကို ဖော်ပြသည်: CC0 texture အစုံ ၁၆ ခု၊ တစ်ခုစီ credit ပါသည်။ တစ်ခုကို click လုပ်ပြီး သုံးပါ၊ သို့မဟုတ် မျက်နှာတစ်ခုပေါ် ဆွဲချပါ။ {{ui:Pictures or a zip…}} သို့မဟုတ် {{ui:A folder…}} က သင့် maps များမှ ပစ္စည်းတစ်ခု ပြုလုပ်သည်၊ ဖိုင်အမည်ဖြင့် ရှာသည်။ ကြည့်ရန် [စာကြည့်တိုက်မှ ပစ္စည်းများ](topic:shading#materials-from-the-library)။
- **MaterialX ဝင်နှင့် ထွက်။** ပစ္စည်းကို MaterialX (OpenPBR Surface သို့မဟုတ် Standard Surface၊ texture များကို PNG အဖြစ်) အဖြစ် export လုပ်ပြီး MaterialX ဖိုင်များကို ၎င်းတို့၏ ပုံများနှင့်အတူ import လုပ်ပါ။ ကြည့်ရန် [MaterialX](topic:shading#materialx)။
- **Decals နှင့် texture ဆေးခြယ်ခြင်း။** မျက်နှာတစ်ခုပေါ် ပုံကို ကိုယ်ပိုင် ပစ္စည်းဖြင့် decal အဖြစ် ထားပါ၊ နှင့် ပစ္စည်း၏ ပုံပေါ်တွင် စက်ဝိုင်း brush ဖြင့် ဆေးခြယ်ပါ။ ကြည့်ရန် [Decals](topic:shading#decals) နှင့် [texture ပေါ်တွင် ဆေးခြယ်ခြင်း](topic:shading#paint-on-the-texture)။
- **Texture baking။** ambient occlusion၊ curvature၊ ရောင်စဉ်နှင့် အသေးစိတ် object ၏ normals များကို mesh ၏ UV များအတိုင်း ပုံများအဖြစ် bake လုပ်ပါ၊ ကွန်ပျူတာ processor cores ပေါ်တွင်။ ကြည့်ရန် [texture bake လုပ်ခြင်း](topic:shading#bake-textures)။

### Animation

- **Animate အလုပ်နေရာ။** object ၏ နေရာ၊ လှည့်ပတ်မှုနှင့် အရွယ်အစား၊ မီးတစ်ခုစီ၏ အလင်းရောင်၊ ပျံ့နှံ့မှုနှင့် အရောင်၊ နှင့် lens angle ကို key လုပ်ပါ၊ panel ထဲတွင် တိုက်ရိုက်။ timeline တွင် {{ui:Curves}} view (Bézier handles၊ repeats) နှင့် {{ui:Clips}} view ရှိ၍ keys များကို actions အဖြစ် သိမ်းပြီး ပြန်ထည့်/ရောနှောနိုင်သည်; အတန်းများစွာပေါ်ရှိ keys များကို ရွှေ့၊ ဆန့်၊ ကူး၊ ကပ်နိုင်သည်။ ကြည့်ရန် [မည်သည့် property ကိုမဆို animate လုပ်ခြင်း](topic:animate)။
- **Shape keys နှင့် drivers။** mesh တစ်ခုတွင် ကိုယ်တိုင်၏ အခြားပုံသဏ္ဍာန်များ ရှိနိုင်ပြီး key လုပ်နိုင်သော slider များဖြင့် ရောနှောသည်၊ သို့မဟုတ် သေးငယ်သော expression ဖြင့် အခြားတန်ဖိုးများမှ သတ်မှတ်သည်။ ကြည့်ရန် [Shape keys](topic:animate#shape-keys-morphs) နှင့် [Drivers](topic:animate#drivers)။
- **Armatures။** mesh ထဲတွင် အရိုးများ ထည့်ပါ၊ {{ui:Automatic weights}} က အမှတ်များကို ၎င်းတို့အကြား မျှဝေစေခြင်း သို့မဟုတ် weights ကို ဆေးခြယ်ခြင်း၊ နှင့် အရိုးများကို pose နှင့် key လုပ်ပါ; linear သို့မဟုတ် dual quaternion skinning။ ကြည့်ရန် [Armatures](topic:animate#armatures-bones-that-bend-a-mesh)။
- **IK နှင့် constraints။** pole ပါသော Reach (IK)၊ look at၊ copy transforms၊ limits၊ child of နှင့် follow path၊ အရိုးနှင့် object များအတွက်။ ကြည့်ရန် [IK နှင့် constraints](topic:animate#ik-and-constraints)။
- **Physics။** groups နှင့် components များသည် boxes သို့မဟုတ် ball များအဖြစ် ကျ၊ ပုံ၊ တိုက်မိသည်၊ နှင့် {{ui:Bake physics}} က ရလဒ်ကို keys အဖြစ် ထိန်းထားသည်။ ကြည့်ရန် [Physics](topic:animate#physics-drop-stack-and-collide)။

- **FBX၊ PLY၊ STL နှင့် Alembic import များ။** FBX 2011 နှင့် အသစ်များ (mesh များ၊ UV sets၊ ပစ္စည်းများ၊ ထည့်ထားသော textures၊ မီးများ၊ ကင်မရာများ)၊ အရောင်များပါသော PLY နှင့် STL၊ နှင့် ပထမ sample တွင် Alembic caches။ OBJ သည် `.mtl` နှင့် ပုံများကို အတူချလျှင် ဝင်လာသည်။ ကြည့်ရန် [ဖိုင်ပုံစံများ အသေးစိတ်](topic:formats)။
- **ပိုများသော export များ။** အရောင်ပါသော PLY၊ ဆေးခြယ်ထားသော မျက်နှာများ၏ အရောင်ပါသော STL၊ နှင့် texture ပါသော OBJ ကို zip တစ်ခုအဖြစ်။ ကြည့်ရန် [ဖိုင်ပုံစံများ အသေးစိတ်](topic:formats)။
- **STEP ဖိုင်များ။** {{ui:Import}} က STEP (AP203၊ AP214၊ AP242) ပစ္စည်းများနှင့် assemblies များကို အတိအကျ အရွယ်အစားဖြင့် ပိတ်ထားသော mesh များအဖြစ် ဖတ်သည်၊ ပစ္စည်းတိုင်းကို ဖိုင်က ထားသည့်နေရာတွင်။ ကြည့်ရန် [STEP](topic:formats#step-step-stp)။
- **.3dm ဖိုင်များ။** {{ui:Import}} က `.3dm` မော်ဒယ်များကို ဖတ်သည်: meshes၊ polysurfaces နှင့် extrusions (ဖိုင်တွင် သိမ်းထားသော meshes မှ၊ မဟုတ်ပါက ModelCraft က tessellate လုပ်သည်)၊ curves များကို edges အဖြစ်၊ blocks များကို components အဖြစ်၊ layers များကို tags အဖြစ်။ ကြည့်ရန် [.3dm မော်ဒယ်ကို ယူခြင်း](topic:import-3dm-files)။
- **DWG နှင့် DXF မှ 3D solids။** ပုံဆွဲချက်တစ်ခုကို import လုပ်သောအခါ ၎င်း၏ 3D solids၊ regions နှင့် bodies များကိုလည်း ယူလာပြီး၊ တစ်ခုစီသည် ကိုယ်ပိုင် group ဖြစ်ကာ ပိတ်ထားသောများသည် solids ဖြစ်သည်။ ကြည့်ရန် [site plan ပေါ် မော်ဒယ်ပြုလုပ်ခြင်း](topic:site-plan#what-comes-in)။

### 3D printing

- **Print tools။** {{ui:Check for 3D printing (STL or 3MF)…}} › **Print tools** တွင် {{ui:Supports preview}} (overhangs၊ columns သို့မဟုတ် tree supports၊ ပစ္စည်းမည်မျှခန့်)၊ {{ui:Wall thickness}} (ပုံနှိပ်ရန် ပါးလွန်းသော နံရံများ၊ {{ui:Show}} ဖြင့် ဖော်ပြသည်)၊ {{ui:Hollow}} (သင်ပေးသော အထူရှိ နံရံများ၊ ရေထွက်အပေါက်များပါ) နှင့် {{ui:Repair}} (ပြင်ဆင်မှု တိုင်းကို ဖော်ပြသည်; ထပ်နေသော အစိတ်အပိုင်းများသည် သင်တောင်းသောအခါမှသာ ပေါင်းသည်) တို့ ရှိသည်။ Hollow နှင့် Repair သည် ပြားချပ်သော မျက်နှာများ တစ်ခုစီဖြစ်သော group ကို ပေးသည်၊ သို့မဟုတ် ရလဒ် မပိတ်ခဲ့လျှင် သို့မဟုတ် မျက်နှာများ များလွန်းလျှင် mesh ကို ပေးသည်; status line က ဘာဖြစ်သည်ကို ပြောသည်။ ကြည့်ရန် [Supports၊ နံရံထူ၊ hollowing နှင့် repair](topic:print-tools)။
- **Beginner style။** {{ui:ဆက်တင်များ}} › {{ui:ModelCraft}} › {{ui:Menus, keys and mouse}} › {{ui:စတင်သူ}}: ပုံသဏ္ဍာန်များနှင့် အပေါက်များ ချရန်၊ ရွှေ့ရန်၊ ချိန်ညှိရန်နှင့် {{ui:အုပ်စု}} ခလုတ်ကြီးများ၊ အပေါက်များ ဖြတ်နိုင်ရန်၊ ထို့နောက် ပုံနှိပ်ရန် မော်ဒယ်ကို စစ်ဆေးရန်။ ကြည့်ရန် [Beginner style](topic:beginner)။

## အက်ပ်အားလုံးတွင်

- **ယူနစ်များ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ယူနစ်များ}} တွင် အရှည်၊ ဧရိယာ၊ ထုထည်၊ ထောင့်နှင့် slope အတွက် စာရင်းတစ်ခုစီ ရှိပြီး ယူနစ် သတ်မှတ်ချက်များက ပေးသော တိကျသော အရွယ်အစားများဖြင့် (US survey foot သည် ကိုယ်ပိုင် ယူနစ်ဖြစ်သည်)။ သင်မသုံးသော ယူနစ်များကို ပိတ်ပါက ၎င်းတို့သည် ယူနစ်စာရင်းမှ ထွက်သွားသည်; ကြယ်အမှတ်ပြုပါက အသစ်လုပ်ငန်းများ ၎င်းဖြင့် စတင်သည်။ ဖိုင်တစ်ခုသည် ကိုယ်ပိုင် ယူနစ်ကို အမြဲ ထိန်းသည်။ ModelCraft တွင် တန်ဖိုးအကွက်ဘေးရှိ ယူနစ်စာရင်းသည် ခလုတ်များကို လိုက်သည် (မော်ဒယ်၏ ကိုယ်ပိုင် ယူနစ်သည် အမြဲ ရှိနေသည်)၊ ကြယ်သည် မော်ဒယ်အသစ်၏ ယူနစ်ကို သတ်မှတ်သည် (ModelCraft တွင် ထိုယူနစ် ရှိပါက)၊ ယူနစ်မှတ်ဖြင့် ရိုက်ထားသော အရှည်ကို ထိုယူနစ်ဖြင့် ဖတ်သည်။ ကြည့်ရန် [ယူနစ်များ၊ ရိုက်ထားသော တန်ဖိုးများနှင့် ယူနစ်စာရင်းများ](common:unit-lists)။
- **ပိုသိပ်သော အပြင်အဆင်နှင့် ပြေလျော့သော panels။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:Layout density}} › {{ui:Compact}} က ပိုမို ဖြည့်ထည့်သည် (touch screen နှင့် ဖုန်းများက ခလုတ်ကြီးများ ထားသည်)။ panel တစ်ခုစီတွင် ပါးလွှာသော title bar ရှိပြီး ဆွဲ၍ panel ကို dock သို့မဟုတ် float လုပ်နိုင်သည်၊ အခြား panel ၏ bar ပေါ် ချ၍ tabs အဖြစ် frame တစ်ခု မျှဝေနိုင်သည်၊ ထိပ်သို့ slide ရန် pin လုပ်နိုင်သည်၊ သို့မဟုတ် ဖျောက်ပြီး ထိပ်မှ ပြန်ခေါ်နိုင်သည်။ ကြည့်ရန် [panels များကို စီစဉ်ခြင်း](common:arrange-panels#make-the-layout-denser)။
- **Dialog များ ရွှေ့နိုင်ခြင်း။** dialog ကို title bar ဖြင့် ဆွဲ၍ ပုံဆွဲချက်မှ ဖယ်ပါ; နောက်ဆုံး ထားခဲ့ရာသို့ ပြန်ရောက်သည်။ title bar ကို နှစ်ချက်နှိပ်၍ ဗဟိုသို့ ပြန်ထားနိုင်သည်။ ကြည့်ရန် [dialog ကို ရွှေ့ခြင်း](common:arrange-panels#move-a-dialog)။
- **AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ။** သင့်ကိုယ်ပိုင် အကူအညီပေးသူအတွက် တောင်းဆိုချက် ဆယ်ခု (ပုံဆွဲချက် သန့်ရှင်းခြင်း၊ အစုံ ပုံဖော်ခြင်း၊ ပုံဆွဲချက်များ စစ်ဆေးခြင်း၊ မော်ဒယ်ကို မေးခွန်းမေးခြင်း၊ takeoff စုစုပေါင်းခြင်း၊ အစိတ်အပိုင်း variant စမ်းခြင်း…)၊ တစ်ခုစီတွင် ခေါ်သော tools နှင့် လိုအပ်သော ခွင့်ပြုချက်များ၊ တစ်ခုစီကို ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ပြန်ဖွင့်ပြသည်။ apps တွင် AI မပါပါ။ ကြည့်ရန် [AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ](common:assistants-recipes)။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ဘာသာစကား}} တွင် အသစ်ဖြစ်သည်။ ၎င်းနှင့် **Português (Brasil)**၊ **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် apps ၏ စကားလုံးအားလုံး ယခု ရှိသည်၊ ဇာတိစကားပြောသူက မပြန်လည်စစ်ဆေးရသေးသော မူကြမ်းများအဖြစ်။ Help topics များသည် အင်္ဂလိပ်ဖြင့်သာ ဖြစ်သည်။

## ဤဗားရှင်းတွင် မရှိသေးသော အရာများ

- **0.7 သည် code-signed မဟုတ်ပါ။** Signing နှင့် Microsoft Store package သည် 0.8 သို့ ရွှေ့သွားသည်၊ အကြောင်းမှာ certificate validation မရောက်သေးသောကြောင့်။ getcadcraft.com/download ရှိ ဖိုင်တိုင်းဘေးရှိ SHA-256 ကို စစ်ပါ။ Windows တွင် SmartScreen က installer ကို ရပ်စေပါက {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ပထမအကြိမ် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ CadCraft Studio သည် app store တွင် မရှိသေးပါ၊ iPad သို့မဟုတ် iPhone build လည်း မရှိသေးပါ။
- {{ui:Units}} တွင် angle နှင့် slope စာရင်းများကို သိမ်းထားသော်လည်း ၎င်းတို့ကို ဖတ်သော box မရှိသေးပါ။
- graphics card ပေါ်ရှိ ရေးဆွဲခြင်း (WebGPU) ကို ဤနေရာတွင် software stand-in ဖြင့်သာ စမ်းသပ်ခဲ့ပြီး အမှန်တကယ် graphics card များပေါ်တွင် မစမ်းသပ်ရသေးပါ၊ ထို့ကြောင့် ကွန်ပျူတာပေါ်တွင် ဘာမဆို သေးသေးလေး ပထမဆုံး render လုပ်ပါ။ live view အတွက်လည်း အတူတူ ဖြစ်ပြီး VR ကို headset emulator ဖြင့်သာ စမ်းသပ်ခဲ့သည်။

- {{ui:Render a picture…}} သည် ဖြန့်ကျဲထားသော အရာများကို မဆွဲရသေးပါ; live view၊ ၎င်း၏ panorama များ၊ viewer နှင့် ဗီဒီယိုများတွင် ပြသည်။
- မီးများသည် မြင်ကွင်းတွင် animate ဖြစ်သော်လည်း ရေးဆွဲထားသော ဗီဒီယိုက စတင်ချိန်ရှိ မီးများကို အသုံးပြုသည်။
- အရိုးများနှင့် animation များကို glTF၊ FBX သို့မဟုတ် USD ဖိုင်များမှ ဖတ်ခြင်း သို့မဟုတ် ရေးခြင်း မရှိသေးပါ (skinned မော်ဒယ်များသည် rest တွင် ဝင်လာပြီး weights ပါသည်)၊ နှင့် glTF နှင့် FBX ပစ္စည်းများ၏ base color သို့မဟုတ် texture ထက်ပိုသော အရာများကို မထိန်းသေးပါ။
- STEP အရောင်များနှင့် assembly ၏ အစိတ်အပိုင်းအမည်များကို မဖတ်ရသေးပါ။ `.3dm` import ကို format ၏ toolkit ဖြင့် ရေးထားသော ဖိုင်များဖြင့် စမ်းသပ်ခဲ့ပြီး မော်ဒယ်ထုတ်သော program မှ ဖိုင်များဖြင့် မစမ်းသပ်ရသေးပါ; SubD objects၊ text နှင့် dimensions ကို ချန်ထားသည်။
- CivilCraft မှ ပင်စာကြည့်တိုက်သည် ModelCraft တွင် ရှိသော်လည်း ၎င်းမှ အပင်များ ထည့်ခြင်းကို မတည်ဆောက်ရသေးပါ။
- push/pull မျက်နှာများပေါ် texture ဆေးခြယ်ခြင်းသည် ပစ္စည်း၏ tile ဖြင့် ထပ်တလဲလဲ ဖြစ်သည်; မျက်နှာတစ်ခုတည်းကို ဆေးရန် mesh သို့ ပြောင်းပြီး unwrap လုပ်ပါ။
