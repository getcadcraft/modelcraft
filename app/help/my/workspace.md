အပေါ်မှ အောက်သို့: app bar၊ toolbar၊ ကော်လံသုံးခု (ဘယ်ဘက် panel များ၊ 3D view၊ ညာဘက် panel များ) နှင့် status bar။

## App bar

အပေါ်ဆုံးရှိ ပါးလျသော bar သည် CadCraft app အားလုံးအတွက် ဖြစ်သည်။ app အမည်နှင့် ဗားရှင်း၊ {{ui:About ModelCraft}}၊ မျက်နှာပြင်မုဒ်ခလုတ်နှင့် {{ui:Paper}} / {{ui:Model}} ခလုတ်တို့ ပါဝင်သည်။

- {{ui:Paper}} သည် အလင်းအပေါ်ဖုံး ဖြစ်ပြီး {{ui:Model}} သည် အမှောင်ဖြစ်သည်။ 3D view သည် အရောင်များကို ကိုက်ညီအောင် ပြောင်းသည်; မော်ဒယ်ကိုယ်တိုင် မပြောင်းပါ။
- မျက်နှာပြင်မုဒ်ခလုတ် (စမှ {{ui:Full screen}} ဟု ဖတ်ရသည်) နှင့် {{key:Ctrl+Shift+F}} တို့သည် မုဒ်သုံးမျိုးကို လည်ပတ်သည်: ပုံမှန်၊ မျက်နှာပြင်အပြည့်၊ နှင့် bar များ ဖျောက်ထားသော မျက်နှာပြင်အပြည့်။ Bar များ ဖျောက်ထားချိန်တွင် မျက်နှာပြင်အပေါ်ဘက်အစွန်းကို ညွှန်ပြ (သို့မဟုတ် ထိ) လျှင် ပြန်ပေါ်လာမည်။ {{key:Esc}} သည် မျက်နှာပြင်အပြည့်မှ ထွက်စေသည်။

:::note
{{key:Ctrl+Shift+F}} သည် Mac အပါအဝင် ကွန်ပျူတာအားလုံးတွင် Control ခလုတ်ကို သုံးသည်။ iPhone တွင် ဘရောင်ဇာများ၌ မျက်နှာပြင်အပြည့်မရှိသောကြောင့် ခလုတ်သည် bar များကို ဖျောက်/ပြ သာ လုပ်သည်။
:::

## Toolbar

Toolbar ကို အမည်တပ်ထားသော အုပ်စုများအဖြစ် ခွဲထားသည်။ ခလုတ်ပေါ်တွင် ကာဆာထားလျှင် ၎င်း၏အမည်နှင့် ကီးကို မြင်ရမည်။

toolbar ၏ ဘယ်ဘက်ရှိ {{ui:Workspace}} စာရင်းက toolbar နှင့် ညာဘက် panel ဘာအတွက်လဲကို ပြောင်းသည်: {{ui:Model}} (တွန်း/ဆွဲ မော်ဒယ်ဆွဲခြင်း၊ အောက်ပါ လေ့လာခန်း)၊ {{ui:Mesh}} ([mesh ကို တည်းဖြတ်ခြင်း](topic:mesh-edit))၊ {{ui:Curve}} ([ကွေးမျဉ်း အရာဝတ္ထုများ](topic:curves))၊ {{ui:UV}} ([UV ကို ချထားခြင်း](topic:uv))၊ {{ui:Sculpt}} ([ပုံသွင်းခြင်း](topic:sculpt))၊ {{ui:Shading}} ([node ဖြင့် ပြုလုပ်ထားသော ပစ္စည်းများ](topic:shading))၊ {{ui:Animate}} ([လှုပ်ရှားမှု](topic:animate)) နှင့် {{ui:Render}} ([view တွင် ရေးဆွဲခြင်း](topic:render#render-in-the-view))။

| အုပ်စု | ခလုတ်များ |
|---|---|
| ဖိုင် | {{ui:New}}, {{ui:Open}}, {{ui:Save}}, {{ui:Import}}, {{ui:Export}} (ဖော်မတ်များ၏ မီနူး) |
| ဆွဲရန် | {{ui:Line}} ({{key:L}}), {{ui:Rectangle}} ({{key:R}}), {{ui:Circle}} ({{key:C}}), {{ui:Polygon}} ({{key:N}}) |
| ပြင်ဆင်ခြင်း | {{ui:Select}} ({{key:Space}}), {{ui:Push/pull}} ({{key:P}}), {{ui:Move}} ({{key:M}}), {{ui:Rotate}} ({{key:Q}}), {{ui:Scale}} ({{key:S}}), {{ui:Eraser}} ({{key:E}}), {{ui:Tape}} ({{key:T}}) |
| စီစဉ်ရန် | {{ui:Component}} ({{key:G}}), {{ui:Group}} ({{key:Shift+G}}), {{ui:Explode}} |
| တည်းဖြတ်ရန် | {{ui:Undo}} ({{key:Mod+Z}}), {{ui:Redo}} ({{key:Mod+Y}}), {{ui:Copy}} ({{key:Mod+C}}), {{ui:Paste}} ({{key:Mod+V}}), {{ui:More}} (မီနူး: ဖြတ်ရန်၊ ကူးရန်၊ ကူးထည့်ရန်၊ နေရာတွင်ကူးထည့်ရန် {{key:Mod+Shift+V}}၊ ပွားရန် {{key:Mod+D}}၊ ဖျက်ရန်၊ အားလုံးရွေးရန်၊ ဘာမျှမရွေးရန်၊ နှင့် ကီးပုံစံ) |
| ကင်မရာ | {{ui:Orbit}} ({{key:O}}), {{ui:Pan}} ({{key:H}}), {{ui:Zoom}} ({{key:Z}}), {{ui:Extents}} ({{key:Shift+Z}}), {{ui:Views}} (မီနူး) |

ပြထားသော ကီးများသည် push-pull ကီးများဖြစ်သည်; [ModelCraft ဆက်တင်များ](topic:settings) တွင် Modeler ပုံစံကို ရွေးထားလျှင် tooltip များက ထိုကီးများကို ပြမည်။ သုံးနေသော ကိရိယာကို နှိပ်ထားသည်ဟု ပြသည်။ မျက်နှာပြင်ကျဉ်းလျှင် toolbar သည် ဘေးသို့ scroll လုပ်သည်။

{{ui:Views}} မီနူးတွင် {{ui:Iso}}, {{ui:Top}}, {{ui:Front}}, {{ui:Right}}, {{ui:Back}}, {{ui:Left}} နှင့် {{ui:Bottom}} ရှိပြီး တစ်ခုစီကို မော်ဒယ်နှင့် ကိုက်ညီအောင် ညှိသည်၊ နှင့် {{ui:Perspective}} ရှိသည် ၎င်းသည် perspective နှင့် parallel projection ကြား ပြောင်းသည်။

## 3D view

မျက်နှာပြင်အလယ်ဗဟို။ အနီ၊ အစိမ်းနှင့် အပြာ မျဉ်းများသည် ဝင်ရိုးများဖြစ်သည်: အနီနှင့် အစိမ်းသည် မြေပြင်ပေါ်တွင် ရှိပြီး အပြာသည် အပေါ်သို့ ညွှန်သည်၊ နှင့် **မြောက်သည် အစိမ်းဝင်ရိုး ဖြစ်သည်**။ ၎င်းတို့ တွေ့ဆုံသော နေရာသည် origin ဖြစ်သည်။

- စတင်သောအခါ "မော်ဒယ်ဖန်တီးခြင်း စတင်ရန်" ခေါင်းစဉ်ရှိ card တစ်ခုက ကီးအနည်းငယ် ပြသည်။ ဆွဲရန်ကိရိယာ ရွေးသည့်အခါ သို့မဟုတ် view ကို နှိပ်သည့်အခါ ပျောက်သွားသည်။
- ကိရိယာ အလုပ်လုပ်နေစဉ် view တွင် **inference markers** ပြသည်: ကာဆာ snap ဖြစ်သော နေရာတွင် အရောင်ပါ ပုံသဏ္ဍာန်လေးများ (အဆုံးမှတ်တွင် အစိမ်း စက်ဝိုင်း၊ အလယ်မှတ်တွင် cyan၊ မျဉ်းပေါ်တွင် အနီ စတုရန်း၊ မျက်နှာပြင်ပေါ်တွင် အပြာ စိန်)။ [Inference နှင့် snapping](topic:inference) ကို ကြည့်ပါ။
- ရွေးထားသော အရာများ အပြာရောင်ဖြစ်သည်။ နောက်ဘက်မှ မြင်ရသော မျက်နှာပြင်သည် အပြာမီးခိုးရောင်ဖြစ်သည်။
- အုပ်စုတစ်ခုကို တည်းဖြတ်ရန် ဖွင့်လျှင် ထိုအုပ်စုအပြင်ရှိ အရာအားလုံး မှိန်သွားပြီး ဝင်ရိုးများက အုပ်စု၏ ကိုယ်ပိုင်ဝင်ရိုးများသို့ ရွေ့သည်။
- မော်ဒယ်တွင် ဇာတ်ခုံများရှိလျှင် view ၏ အပေါ်ဘက်တွင် ဇာတ်ခုံ tab အတန်းတစ်ခု ပေါ်လာသည်။
- ဖိုင်တစ်ခုကို view ၏ နေရာမည်သည့်နေရာတွင်မဆို ချလျှင် ဖွင့်ခြင်း သို့မဟုတ် သွင်းခြင်း ဖြစ်မည်။

## ဘယ်ဘက် panel များ

**{{ui:Outliner}}** သည် မော်ဒယ်ရှိ အုပ်စုများနှင့် အစိတ်အပိုင်းများကို မော်ဒယ်တွင် ဖွဲ့ထားသည့်အတိုင်း အဆင့်ဆင့် ပြသည်။ တစ်ကြိမ်ထက်ပို သုံးထားသော အစိတ်အပိုင်းသည် "ပြတင်းပေါက် (4)" ကဲ့သို့ အကြိမ်အရေအတွက် ပြသည်။

- အမည်ကို နှိပ်လျှင် ရွေးမည်။ နှစ်ကြိမ်နှိပ်လျှင် တည်းဖြတ်ရန် ဖွင့်မည်။
- **Find by name** (အုပ်စု နှစ်ခု သို့မဟုတ် ထို့ထက်ပိုရှိမှ ပေါ်သည်) သည် အမည်ကိုက်ညီသော အတန်းများနှင့် ၎င်းတို့ပါဝင်သော အုပ်စုများသာ ထားသည်။ {{key:Esc}} ဖြင့် ရှင်းသည်။
- အတန်း၏အဆုံးရှိ **မျက်လုံး** သည် ထိုအုပ်စု သို့မဟုတ် အစိတ်အပိုင်းကို ဖျောက်/ပြ လုပ်သည် (ဤအရာသည် {{ui:Edit}} › {{ui:More}} › {{ui:Hide}} နှင့် တူသည်)။ tag အိုင်ကွန်သည် [tag](topic:tags) ကြောင့် ဝှက်ထားသည်ဟု ဆိုလိုသည်။
- **နေရာတွင် အမည်ပြောင်းခြင်း:** အတန်းကို နှိပ်ပြီး {{key:F2}} ကို နှိပ်ကာ ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ ({{key:Esc}} က အဟောင်းအမည်ကို ထားသည်)။
- **အတန်းကို ဆွဲယူခြင်း:** အခြားအုပ်စု၏ အတန်း၏ အလယ်သို့ ချလျှင် ထိုအုပ်စုအတွင်း ရွှေ့မည်; အတန်း၏ အပေါ် သို့မဟုတ် အောက်အစွန်းသို့ ချလျှင် ထိုအတန်း၏ ရှေ့ သို့မဟုတ် နောက်တွင် ထားမည်; {{ui:Outliner}} ခေါင်းစဉ်သို့ ချလျှင် အပေါ်အဆင့်သို့ ရွှေ့မည်။ မော်ဒယ်အတွင်း နေရာ မပြောင်းပဲ အရောင်၊ tag နှင့် အမည်ကို ထိန်းထားသည်။ အုပ်စုတစ်ခုကို ကိုယ်တိုင်အတွင်း ထည့်၍ မရပါ။ ရွှေ့တိုင်း ပြန်ဖျက်ခြင်း အဆင့်တစ်ခု ဖြစ်သည်။ [Outliner တွင် ပြန်စီခြင်း](topic:groups-components#rearrange-in-the-outliner) ကို ကြည့်ပါ။
- အုပ်စုတစ်ခုအတွင်း တည်းဖြတ်နေစဉ် "တည်းဖြတ်နေသည်: Model › …" ဟု စာသား ပေါ်ပြီး {{ui:Close group}} ခလုတ် ပေါ်လာသည်။ ၎င်းသည် ဖွင့်ထားသော အဆင့်အားလုံးကို တစ်ပြိုင်နက် ပိတ်သည်။

**{{ui:Components}}** သည် အစိတ်အပိုင်းအမျိုးအစား အားလုံးနှင့် နေရာချထားထားသော မိတ္တူအရေအတွက် ("3×") နှင့် နှိပ်သည့်နေရာတွင် မိတ္တူတစ်ခု ထပ်ထည့်သော {{ui:Place}} ခလုတ်ကို ပြသည်။

## ညာဘက် panel များ

**{{ui:Entity info}}** သည် ရွေးထားသော အရာကို ဖော်ပြသည်။ ခေါင်းစဉ်သည် ၎င်းကဘာလဲဟု ပြောင်းသည်:

| ခေါင်းစဉ် | ပြသသည် | ခလုတ်များ |
|---|---|---|
| မော်ဒယ် (ဘာမျှမရွေးထား) | မျက်နှာပြင်၊ အစွန်း၊ အုပ်စု၊ အစိတ်အပိုင်း နှင့် နေရာချထားထားသော အရေအတွက်၊ guide များ၊ အရွယ်အစားစုစုပေါင်း | {{ui:Delete all guides}} (guide များ ရှိသည့်အခါ) |

## Status bar

အောက်ဘက်တွင် ဘယ်မှညာသို့:

1. **အကြံပြုချက်**: ကိရိယာက နောက်ဘာလိုသလဲ၊ သို့မဟုတ် ကာဆာ snap ဖြစ်နေသည် ("အဆုံးမှတ်", "အနီဝင်ရိုးပေါ်")။
2. **မက်ဆေ့ချ်များ**: ဘာဖြစ်ခဲ့သလဲ ("တွန်း/ဆွဲကို ပြန်ဖျက်ပြီး။", "site.dxf သွင်းပြီး: မြေပြင်ပေါ်ရှိ edge 1697 ခု၊ အုပ်စုတစ်ခုတွင်။") သို့မဟုတ် အရာတစ်ခု မအလုပ်လုပ်သည့် အကြောင်းရင်း။
3. **တန်ဖိုးအကွက်**: ၎င်း၏အညွှန်းသည် ကိရိယာနှင့်အတူ ပြောင်းသည် ({{ui:Length}}, {{ui:Dimensions}}, {{ui:Radius}}, {{ui:Sides}}, {{ui:Distance}}, {{ui:Angle}}, {{ui:Scale}}, {{ui:Offset}})။ အလုပ်လုပ်နေစဉ် တိုက်ရိုက် အရွယ်အစားကို ပြပြီး သင်ရိုက်သည်ကို လက်ခံသည်။ [တန်ဖိုးအကွက်တွင် တိကျသော အရွယ်အစားများ ရိုက်ခြင်း](topic:value-box) ကို ကြည့်ပါ။
4. **ကီးပုံစံ**: {{ui:Keys: Push-pull}} သို့မဟုတ် {{ui:Keys: Modeler}} သည် ကီးဘုတ်ဖြတ်လမ်းများနှင့် မောက်စ်ခလုတ်များကို တစ်ပြိုင်နက် ပြောင်းသည် ([ModelCraft ဆက်တင်များ](topic:settings) နှင့် တူသည်)။
5. **{{ui:Snap}} နှင့် {{ui:Collide}}**: အမှတ်၊ အစွန်းနှင့် ဝင်ရိုးများသို့ snap လုပ်ခြင်း၊ နှင့် solid များ ထိတွေ့သောနေရာတွင် ရပ်ခြင်း။ ဖြတ်ထားသည် = ပိတ်။ နှိပ်ပြီး ပြောင်းပါ။ [ModelCraft ဆက်တင်များ](topic:settings) ကို ကြည့်ပါ။
6. **ယူနစ်ရွေးချယ်ကိရိယာ**: အလျားများ ပြသသည့် ယူနစ်။ [ စတင်ခြင်း](topic:getting-started#check-the-units-first) ကို ကြည့်ပါ။

## ကျဉ်းသော မျက်နှာပြင်တွင်

ပစ်စဲလ် 760 ခန့်ထက် ကျဉ်းလျှင် (ဖုန်း သို့မဟုတ် ကျဉ်းသော ဝင်းဒိုး) 3D view သည် မျက်နှာပြင်ကို ထိန်းသည်။ toolbar သည် ဘေးသို့ scroll လုပ်သော အတန်းတစ်ခုဖြစ်ပြီး panel များသည် မျက်နှာပြင်အောက်ဘက် bar မှ စာမျက်နှာများအဖြစ် ဖွင့်သည်။
