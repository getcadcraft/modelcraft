**curve object** သည် ပုံသဏ္ဍာန်ဖန်တီးသော curve တစ်ခု ဖြစ်သည်- ၎င်းတစ်လျှောက် ပိုက် (bevel)၊ ဘောင် (extrude)၊ ကျဉ်းလာသော ဆင်းတစ်ခု (taper)၊ သို့မဟုတ် ပြားပြီး ပိတ်ထားလျှင် ဖြည့်ထားသော ပြား သို့မဟုတ် အက္ခရာများ ဖြစ်သည်။ ပုံသဏ္ဍာန်သည် curve ကို လိုက်သည်- point တစ်ခုကို ရွှေ့လျှင် ပိုက်လည်း ၎င်းနှင့်အတူ ရွှေ့သည်။ ပုံသဏ္ဍာန် မှန်ပြီးလျှင် mesh အဖြစ် ပြောင်းပါ။

## curve တစ်ခု ထည့်ခြင်း

Workspace စာရင်းမှ {{ui:Curve}} ကို ရွေးပြီး {{ui:Add}} ကို နှိပ်ပါ-

| အမျိုးအစား | ဘာလဲ |
| --- | --- |
| Bézier curve၊ Bézier circle | ၎င်း၏ points များကို ဖြတ်သွားသည်၊ point တစ်ခုစီတွင် curve ၏ ဦးတည်ချက်ကို သတ်မှတ်သော handles နှစ်ခု ရှိသည် |
| NURBS curve၊ NURBS circle၊ Path | ချောမွေ့သည်၊ point များဆီသို့ ဆွဲသည် (အဆုံး point များတွင် စတင်ပြီး အဆုံးသတ်သည်)၊ point တစ်ခုစီတွင် weight ရှိသည် |
| Text | သင်၏ စာသားကို ပြား၊ ဖြည့်ထားသော အက္ခရာ အပြင်ပိုင်းများအဖြစ် |

curve အသစ်တစ်ခုသည် မြင်ရပြီး ရွေးနိုင်ရန် ပါးလွှာသော ပိုက်ကို ရရှိသည်၊ curve အလွတ်အတွက် ၎င်း၏ bevel depth ကို 0 သို့ သတ်မှတ်ပါ။

ဆွဲထားသော အရာမှလည်း စတင်နိုင်သည်- Model workspace တွင် arc၊ circle၊ polygon သို့မဟုတ် ဆွဲထားသော curve ကို ရွေးပြီး Entity info ရှိ {{ui:Make a curve object}} ကို နှိပ်ပါ။ ဆွဲထားသော မျဉ်းများက ကျန်ရစ်သည်။

## point များ တည်းဖြတ်ခြင်း

curve object ကို နှစ်ကြိမ်နှိပ်ပါ (သို့မဟုတ် ရွေးပြီး {{ui:Curve}} ကို ရွေးပါ) ပြင်ဆင်ရန်။

- point သို့မဟုတ် handle ကို နှိပ်ပါ (Shift က ထည့် သို့မဟုတ် ဖယ်ပေးသည်); ရွှေ့ရန် ဆွဲပါ။ ဘောင်ဖြင့် ရွေးရန် အလွတ်နေရာပေါ်တွင် ဆွဲပါ။
- {{ui:Extend}} ({{key:E}}၊ သို့မဟုတ် {{key:Ctrl}}+နှိပ်) က ရွေးထားသော အဆုံးနောက်တွင် ကာဆာနေရာ၌ point တစ်ခု ထည့်သည်။
- {{ui:Subdivide}} ({{key:W}}) က ရွေးထားသော ပတ်ဝန်းကျင် အတွဲတစ်ခုစီကြား point တစ်ခု ထည့်သည်; Bézier သည် ၎င်း၏ပုံသဏ္ဍာန်ကို ထိန်းသည်။
- {{ui:Move}}၊ {{ui:Turn}}၊ {{ui:Scale}} က ရွေးထားသော points များကို ကာဆာဖြင့် ရွှေ့သည် (modeler keys {{key:G}} {{key:R}} {{key:S}}၊ push/pull keys {{key:M}} {{key:Q}} {{key:S}}); ထိန်းထားရန် နှိပ်ပါ၊ ပယ်ဖျက်ရန် {{key:Esc}}။
- {{ui:Close}} ({{key:C}}) က ဖွင့်ထားသော spline ကို ပိတ်ပြီး ပိတ်ထားသောတစ်ခုကို ဖွင့်သည်; {{ui:Reverse}} ({{key:Shift+R}}) က ၎င်းကို နောက်ပြန် လည်ပတ်စေသည်။
- Bézier handles: {{ui:Smooth}} ({{key:V}}) က ချောမွေ့သော curve အတွက် နေရာချသည်၊ {{ui:Corner}} ({{key:Shift+V}}) က ပတ်ဝန်းကျင်ဆီ ညွှန်သည်၊ {{ui:Free}} ({{key:Alt+V}}) က သင်ထားသည့်နေရာတွင် ထားသည်။ handle တစ်ခုကို ဆွဲလျှင် ၎င်းသည် free ဖြစ်သွားသည်။
- {{ui:Bézier}}၊ {{ui:NURBS}} နှင့် {{ui:Poly}} က ရွေးထားသော splines များ၏ အမျိုးအစားကို ပြောင်းသည်၊ points များကို ထိန်းသည်။

ပြောင်းလဲမှုတိုင်းသည် undo တစ်ဆင့် ဖြစ်သည်။

## ပုံသဏ္ဍာန်

ဆက်တင်များသည် panel တွင် (နှင့် Model workspace ရှိ Entity info တွင်) ရှိသည်-

- **Shape:** 3D curves များသည် မည်သည့်ဘက်သို့မဆို သွားသည်; ပြား curve သည် ၎င်း၏ကိုယ်ပိုင် လေယာဉ်တွင် ရှိနေပြီး ဖြည့်နိုင်သည်။
- **Fill closed splines** (ပြား): အပြင်ပိုင်းများသည် ပြား ဖြစ်လာသည်; အခြားတစ်ခု အတွင်းရှိ အပြင်ပိုင်းသည် အပေါက် ဖြစ်သည်၊ ထို့ကြောင့် အက္ခရာများ၏ အပေါက်များ ကျန်ရစ်သည်။
- **Extrude:** ဘောင်၏ အကျယ်ရဲ့ တစ်ဝက် (ပွင့်သော သို့မဟုတ် 3D curves)၊ သို့မဟုတ် ပြား၏ အထူရဲ့ တစ်ဝက် (ဖြည့်ထားလျှင်)။
- **Bevel depth** နှင့် **roundness:** curve တစ်လျှောက် စက်ဝိုင်း ပိုက် (extrude ဖြင့်: ဝိုင်းသော ဘောင်); ဖြည့်ထားသော ပုံသဏ္ဍာန်တွင် ဝိုင်းသော အစွန်း။
- **Close the ends:** ပွင့်သော ပိုက်ပေါ်ရှိ အဖုံးများ။
- **Taper along it:** spline တစ်ခုစီတစ်လျှောက် ညီညီ scale လုပ်သည်၊ ဥပမာ ဆင်းအတွက် `1, 0.2`၊ ကြိုးလုံးအတွက် `0, 1, 0`။
- **Smoothness** နှင့် NURBS အတွက် **order**: ဘယ်လောက် ပိုသေချာ ဆွဲသလဲ၊ နှင့် ဘယ်လောက် ချောမွေ့သလဲ (2 မျဉ်းဖြောင့်… 6 အချောမွေ့ဆုံး)။
- point များ ရွေးထားစဉ်: **radius** (ထိုနေရာရှိ ပိုက်အထူ၊ bevel နှင့် မြှောက်ထား)၊ **tilt** (ဘောင်ကို curve ပတ်လည် လှည့်သည်) နှင့် NURBS အတွက် **weight**။

Modifiers များသည် curve object ပေါ်တွင် mesh ပေါ်ကဲ့သို့ အလုပ်လုပ်သည်- curve တစ်လျှောက် Array၊ Mirror၊ Subdivision surface။ [Mesh ပေါ်ရှိ modifiers](topic:modifiers) ကို ကြည့်ပါ။

## mesh အဖြစ် ပြောင်းခြင်း

{{ui:To mesh}} (Curve workspace တွင် သို့မဟုတ် Entity info တွင်၊ {{ui:Curve to mesh}}) က curve object ကို ယခုပြနေသော mesh အဖြစ် ပြောင်းသည်; ၎င်း၏ modifiers များက အပေါ်တွင် ကျန်သည်။ ထို့နောက် Mesh workspace တွင် တည်းဖြတ်ပါ။ Undo က ပြန်ပြောင်းသည်။
