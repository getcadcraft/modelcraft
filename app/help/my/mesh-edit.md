**Mesh** workspace သည် [mesh](topic:meshes) ကို အမှတ်တစ်ခုချင်းစီဖြင့် တည်းဖြတ်သည်- vertex၊ edge နှင့် face များ။ push/pull geometry သည် **Model** workspace တွင် ကျန်ရှိသည်။

## ဖွင့်ရန်

- toolbar ၏ ဘယ်ဘက်ရှိ {{ui:Workspace}} စာရင်းမှ {{ui:Mesh}} ကို ရွေးပါ။ ရွေးထားသော mesh ကို တည်းဖြတ်ရန် ဖွင့်သည်၊ ရွေးထားသော group သို့မဟုတ် component ကို အရင် mesh အဖြစ် ပြောင်းသည် (undo အဆင့် တစ်ခု)။
- သို့မဟုတ် mesh ကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် modeler keys ဖြင့် ရွေးပြီး {{key:Tab}} ကို နှိပ်ပါ။
- ဘာမျှ မရွေးထားလျှင် ပြခန်းက ထည့်နိုင်သော mesh များကို ပေးသည်- plane၊ grid၊ cube၊ circle၊ cylinder၊ cone၊ sphere၊ ico sphere နှင့် torus။ အသစ်တစ်ခုသည် view ကြည့်နေသော နေရာသို့ သွားပြီး တည်းဖြတ်ရန် ဖွင့်သည်။

{{ui:Back to Model}} (သို့မဟုတ် စာရင်း၊ modeler keys ဖြင့် {{key:Tab}}၊ push/pull keys ဖြင့် ဘာမျှ မရွေးထားစဉ် {{key:Esc}}) က ရွေးထားသော mesh ဖြင့် Model သို့ ပြန်သွားသည်။ Mesh workspace ဖွင့်နေစဉ် မော်ဒယ်၏ အခြားအပိုင်းများ မှိန်သွားပြီး Model ၏ ဆွဲသည့် ကိရိယာများ သိမ်းထားသည်။

## ရွှေ့ခြင်း၊ လှည့်ခြင်း၊ အတိုင်းအတာ

{{ui:Move}}၊ {{ui:Rotate}} နှင့် {{ui:Scale}} သည် pointer မှ စတင်သည်- ရွှေ့ပြီး နှိပ်ခြင်း သို့မဟုတ် {{key:Enter}} ဖြင့် ရွေးထားသည်ကို ချထားပါ၊ သို့မဟုတ် {{key:Esc}} ဖြင့် ပယ်ဖျက်ပါ။ {{key:X}}၊ {{key:Y}} သို့မဟုတ် {{key:Z}} (သို့မဟုတ် မြားများ) က axis တစ်ခုကို လော့ခ်ချသည်။ အတိအကျ အတွက် အကွာအဝေး၊ ထောင့် သို့မဟုတ် factor ကို ရိုက်ပါ- [တွက်ချက်မှုများ](topic:value-box#calculations) လည်း အလုပ်လုပ်သည်။

**Proportional editing** ({{ui:Proportional}}၊ သို့မဟုတ် panel): ရွေးထားသည်နှင့် နီးသော vertex များသည် ရွှေ့ခြင်းကို လိုက်သည်၊ သင်သတ်မှတ်သော အကွာအဝေးအထိ၊ ဝေးလေ လျော့လေ၊ သင်ရွေးသော falloff ဖြင့်။ **Only along the mesh** ကို ဖွင့်လျှင် ဖြောင့်ဖြောင့် မဟုတ်ဘဲ edge များတစ်လျှောက် တိုင်းတာသည်။

{{ui:Slide}} က ရွေးထားသော edge loop ကို ၎င်းဘေးရှိ edge များတစ်လျှောက် ရွှေ့သည်။

## ပုံသဏ္ဍာန် ပြောင်းခြင်း

| ကိရိယာ | လုပ်ဆောင်ချက် |
|---|---|
| {{ui:Extrude}} | ရွေးထားသော face များကို ၎င်းတို့၏ normal အတိုင်း ဆွဲထုတ်ပြီး face ဘေးအသစ်များ ထည့်သည် (သို့မဟုတ် ဖွင့်ထားသော အပြင်ဘောင် edge များမှ face များ ပြုလုပ်သည်)။ အကွာအဝေးကို ရိုက်ပါ |
| {{ui:Inset}} | ရွေးထားသော face များ၏ အပြင်ဘောင်အတွင်း ဘောင်ကြိုး တစ်ခု; face တစ်ခုချင်းစီအတွက် {{key:I}} ကို ထပ်နှိပ်ပါ |
| {{ui:Bevel}} | ရွေးထားသော edge များ (သို့မဟုတ် {{key:Ctrl}}+{{key:Shift}}+{{key:B}} ဖြင့် vertex များ) ကို အကျယ်တစ်ခုဖြင့် ဖြတ်သည်; ဘီး သို့မဟုတ် plus နှင့် minus keys က အပေါင်းအစိတ်များ ထည့်ပြီး ခွေထားသော edge ပြုလုပ်သည် |
| {{ui:Loop cut}} | edge တစ်ခုကို ညွှန်ပါ- လေးဘက်ပါ face များ၏ ring ကို ဖြတ်သော loop အသစ်များ; ဘီးက အရေအတွက် သတ်မှတ်သည်; နှိပ်ခြင်းဖြင့် ဖြတ်သည် |
| {{ui:Knife}} | edge များ သို့မဟုတ် ထောင့်များပေါ် အမှတ်များ နှိပ်ပါ; {{key:Enter}} က ၎င်းတို့ကြား face များကို မြင်သည့်အတိုင်း ဖြောင့်ဖြောင့် ဖြတ်သည် |
| {{ui:Bisect}} | ဖန်သားပြင်ပေါ် မျဉ်းတစ်ကြောင်း ဆွဲပါ: ရွေးထားသော face များ (သို့မဟုတ် အားလုံး) ကို ထိုမျဉ်းအတိုင်း ဖြတ်သည် |
| {{ui:Spin}} | ရွေးထားသော face များ သို့မဟုတ် ဖွင့်ထားသော edge များကို အပြာ axis ပတ်လည် အဆင့်လိုက် လှည့်သည် (ဘီးက အဆင့်များ သတ်မှတ်သည်); လှည့်ပတ်တစ်ကြိမ်ပြည့်လျှင် ပိတ်သွားသည် |
| {{ui:Subdivide}} | ရွေးထားသော edge များကို နှစ်ပိုင်းခွဲသည်; face အပြည့်များ ကွက်ကွက်ဖြစ်လာသည် |
| {{ui:Merge}} | ရွေးထားသော vertex များ တစ်ခုဖြစ်သည်၊ ၎င်းတို့၏ ဗဟိုတွင် |
| {{ui:Dissolve}} | ရွေးထားသည်ကို ဖယ်သော်လည်း မျက်နှာပြင်ကို ထိန်းထားသည်: face များ ပေါင်းသည် |
| {{ui:Fill}} | ရွေးထားသော ဖွင့်ထားသည့် အပြင်ဘောင်တစ်ခု (သို့မဟုတ် ဖွင့်ထားသော edge နှစ်ခုကြား) တစ်လျှောက် face တစ်ခု |
| {{ui:Grid fill}} | edge အရေအတွက် ဂဏန်းစုံဖြင့် ဖွင့်ထားသော အပြင်ဘောင်ကို quad ကွက်ဖြင့် ဖြည့်သည် |
| {{ui:Bridge}} | ရွေးထားသော ဖွင့်ထားသော edge loop နှစ်ခုကို face များဖြင့် ချိတ်သည် |
| {{ui:Crease}} | Subdivision surface ဖြင့် mesh ကို ချောမွေ့စေသည့်အခါ ရွေးထားသော edge များ မည်မျှ ထက်မြက်နေမလဲ: ဗဟိုမှ ဝေးအောင် ရွှေ့ပါ၊ ဘီးကို သုံးပါ (0.1 အဆင့်များ) သို့မဟုတ် 0 မှ 1 အထိ ရိုက်ပါ။ panel က ရွေးထားသော edge များ၏ crease ကို ပြပြီး ရိုက်ထည့်သော တန်ဖိုးကိုလည်း လက်ခံသည်။ crease ရှိသော edge များကို magenta ဖြင့် ဆွဲသည် |
| {{ui:Flip}}၊ {{ui:Smooth}}၊ {{ui:Delete}} | face များကို လှန်သည်; vertex များကို ၎င်းတို့၏ အိမ်နီးချင်းများဆီ ချောမွေ့စေသည်; ရွေးချယ်မုဒ်အလိုက် ဖျက်သည် |

အရာတစ်ခုစီသည် undo အဆင့် တစ်ခု ဖြစ်သည်။ Texture coordinate၊ အရောင်နှင့် အလေးချိန်များသည် face နှင့် vertex အသစ်များသို့ လိုက်ပါသည်။

## Remesh

{{ui:Remesh}} က mesh တစ်ခုလုံးကို တြိဂံ တူညီအရွယ်အစားဖြင့် ပြန်ပြုလုပ်သည်၊ နှိပ်သောအခါ တောင်းဆိုသည် (သေးလေ ပိုနူးညံ့လေ၊ နှေးလေ)။ အပေါက်များကို ပိတ်ပြီး ထပ်နေသော အပိုင်းများကို ပေါင်းပြီး sculpting က ဆန့်ထားသော mesh ကို ညှိသည်။ ထက်မြက်သော edge များက အနည်းငယ် ဝိုင်းသွားသည်။ UV၊ သုတ်ချက်နှင့် crease များ အစမှ ပြန်စသည်။ undo အဆင့် တစ်ခု။

## Retopology

အသေးစိတ် mesh (sculpt၊ scan) အပေါ် သန့်ရှင်းသော mesh အသစ်တစ်ခု တည်ဆောက်ရန် panel ရှိ {{ui:Retopology}} › **Build on** အောက်တွင် အသေးစိတ် mesh ကို ရွေးပါ၊ ထို့နောက်-

- **ရွှေ့ထားသော အမှတ်များကို ၎င်းပေါ်သို့ ကပ်ရန်:** သင်ရွှေ့သော အမှတ်များနှင့် extrude လုပ်သော edge များသည် ၎င်း၏ မျက်နှာပြင်ပေါ် ဆင်းသည်။
- **ရွေးထားသော အမှတ်များကို ၎င်းပေါ် ထားရန်** သည် ရွေးထားသော အမှတ်များကို ယခု ၎င်းပေါ်သို့ ရွှေ့သည် (undo အဆင့် တစ်ခု)။
- **ဤ mesh ၏ edge များကို မျက်နှာမှောက်တွင် ပြရန်** သည် သင်တည်ဆောက်နေသော mesh ကို မျက်နှာပြင်အပေါ် ဆွဲပြ၍ မြင်နိုင်စေသည်။

## နောက်ဆုံး လုပ်ဆောင်ချက်ကို ညှိရန်

{{ui:Inset}}၊ {{ui:Bevel}}၊ {{ui:Loop cut}}၊ {{ui:Subdivide}}၊ {{ui:Smooth}}၊ {{ui:Grid fill}} သို့မဟုတ် {{ui:Spin}} ပြီးနောက် panel က ၎င်း၏ ဆက်တင်များ (အကျယ်၊ အပိုင်းများ၊ ပုံသဏ္ဍာန်၊ ဖြတ်မှုများ …) ကို ပြသည်။ တစ်ခုကို ပြောင်းလျှင် လုပ်ဆောင်ချက်ကို စတင်ရာမှ ပြန်လုပ်သည်၊ undo အဆင့် တစ်ခုအဖြစ် ဆက်ရှိသည်။
