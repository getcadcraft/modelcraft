ModelCraft 0.9 တွင် ပြောင်းလဲချက်များကို 0.8.1 နှင့် နှိုင်းယှဉ်ဖော်ပြထားပါသည်။ ModelCraft သည် ယခု ပရင့်ထုတ်စက်နှင့် စက်ရုံ ကြမ်းပြင်ထိ ရောက်ရှိပါပြီ။ ပို့ခြင်းမပြုဘဲ ပရင့်ခုံပေါ်တွင် အရာများ ထားပြီး ပို့နိုင်ပါသည်၊ filament သို့မဟုတ် resin အတွက် slice ပြုလုပ်နိုင်ပြီး ပစ္စည်းကိုင်တွယ်ရေး လိုင်းကို ဒီဇိုင်းဆွဲနိုင်ပါသည်။ ၎င်းသည် CadCraft Studio 0.9 နှင့် ၎င်း၏ app ရှစ်ခု ဖြစ်ပြီး အောက်ပါ အသစ်အများစုသည် ထပ်ဆောင်းများ ဖြစ်ပါသည်။

## အသစ်

### 3D ပရင့်ထုတ်ခြင်း

- **Print stage။** Toolbar ရှိ {{ui:Print stage}} ကို နှိပ်ပါ။ Library ပစ္စည်းများကို ပရင့်ခုံသို့ ထည့်ပါ၊ စီစဉ်ပါ၊ slice ပြုလုပ်ပြီးသော layer များကို ကြည့်ပါ၊ ပြီးလျှင် {{ui:Send to 3D printer}} ကို နှိပ်ပါ၊ STL ကို ပို့စရာမလိုပါ။ ၎င်းသည် 3D Print ထပ်ဆောင်းတွင် ပါဝင်ပြီး မူလအားဖြင့် ဖွင့်ထားပါသည်၊ အခြားထပ်ဆောင်းများကဲ့သို့ ဖယ်ရှားနိုင်ပါသည်။ [အရာများကို ပရင့်ခုံပေါ်တင်ပြီး printer သို့ ပို့ရန်](topic:print-stage) ကို ကြည့်ပါ။
- **ကိုယ်ပိုင် filament slicer။** {{ui:CadCraft basic (included, fastest)}} သည် ကဒ်ရှိ **Slicer** စာရင်းထဲမှ slicer ဖြစ်ပြီး နံရံများ၊ အပြင်အလွှာများ၊ infill၊ support များနှင့် skirt ပါဝင်ပါသည်၊ စာမျက်နှာ အသုံးပြုနိုင်စေရန် worker ပေါ်တွင် လုပ်ဆောင်ပါသည်။ ပို့မီ layer များကို {{ui:Preview layers}} နှင့် **Layer** slider ဖြင့် ကြည့်နိုင်ပါသည်။ Ender-3 နှင့် Prusa MK4 ပုံစံ printer profile များတွင် ၎င်းတို့ကိုယ်ပိုင် start G-code ပါဝင်ပါသည်။
- **ပို့ခြင်း။** USB ဖြင့် (ကွန်ပျူတာပေါ်ရှိ Chrome သို့ Edge၊ စာမျက်နှာ ဖွင့်ထားရန်လိုသည်) သို့မဟုတ် သင့်ကွန်ရက်ပေါ်ရှိ Klipper (Moonraker)၊ OctoPrint သို့မဟုတ် PrusaLink သို့။ နှိပ်ခြင်းမရှိဘဲ ဘာမျှ ချိတ်ဆက်ခြင်း သို့မဟုတ် ပို့ခြင်း မရှိပါ၊ ပို့ရာတွင် အရင်မေးပါသည်။
- **အခြား slicer များ။** Kiri:Moto၊ PrusaSlicer နှင့် OrcaSlicer တို့သည် သီးခြား ထပ်ဆောင်းများဖြစ်ပြီး မူလအားဖြင့် ပိတ်ထားပါသည်၊ ကဒ်မှ သို့မဟုတ် {{ui:Settings}} › {{ui:Add-ons}} မှ ထည့်နိုင်ပါသည်။ PrusaSlicer နှင့် OrcaSlicer သည် CadCraft Studio မှ သင် ထည့်ထားသော မိတ္တူကို အသုံးပြုပါသည်။ Bambu Lab printer ထပ်ဆောင်းသည် သင့် OrcaSlicer နှင့် ၎င်း၏ P2S preset များဖြင့် slice ပြုလုပ်ပြီး ကွန်ပျူတာပေါ်ရှိ Studio လိုအပ်ပါသည်။
- **Resin ပရင့်ထုတ်ခြင်း။** Resin ထပ်ဆောင်းများ (မူလအားဖြင့် ပိတ်ထား) သည် သင့် printer ၏ မျက်နှာပြင်အတွက် layer ပုံများ ထုတ်ပေးပြီး hollow ပြုလုပ်ခြင်းနှင့် လေထွက်အပေါက်များ၊ raft နှင့် support များ၊ layer ကြိုကြည့်ခြင်းနှင့် အချိန်၊ resin နှင့် ကုန်ကျစရိတ် ပါဝင်ပါသည်။ ဖိုင်ပုံစံ ထပ်ဆောင်းများက Elegoo GOO၊ SL1၊ Chitubox (CBDDLP နှင့် CTB 2 မှ 5) နှင့် Anycubic (PWMX နှင့် PWS) ကို ရေးပေးပါသည်။ Resin exposure test က exposure ငါးခုပါသော ladder တစ်ခု ထုတ်ပေးပါသည်။ [resin printer အတွက် slice ပြုလုပ်ရန်](topic:resin-printing) ကို ကြည့်ပါ။
- **မပြောင်းလဲသေးသည်များ။** {{ui:Export}} › {{ui:Check for 3D printing (STL or 3MF)…}}၊ ပရင့်ကိရိယာများနှင့် Split for printing တို့သည် 0.8 တွင်ကဲ့သို့ အလုပ်လုပ်ပါသည်။ [3D ပရင့်ထုတ်ရန် မော်ဒယ်ကို ပြင်ဆင်ခြင်း](topic:print-3d) ကို ကြည့်ပါ။

### Material flow၊ Digital twin နှင့် Factory floor

ဤသုံးခုသည် ထပ်ဆောင်းများဖြစ်ပြီး {{ui:Settings}} › {{ui:Add-ons}} တွင် ဖွင့်မချင်း ပိတ်ထားပါသည်၊ ဖွင့်ပြီးနောက် ၎င်းတို့၏ ကိုယ်ပိုင် အကူအညီ ရှိပါသည်။

- **Material flow။** Material flow အမည်ရှိ panel သည် 3D view တွင် conveyor၊ station၊ buffer နှင့် AGV လမ်းကြောင်းများကို ဖန်တီးပြီး seed ဖြင့် simulation လုပ်ကာ ပြန်ဖွင့်ပြပြီး throughput၊ lead time နှင့် queue များကို ပြသပါသည်။ ရလဒ်များကို CSV အဖြစ် သိမ်းပါသည်။ မှာယူမှုများကို CSV ဖိုင်မှ ယူနိုင်ပါသည်။ Robot cell များကို စစ်ဆေးပြီး ပို့နိုင်ပါသည်။ PLC ချိတ်ဆက်မှုတွင် Modbus TCP ဖြင့် soft mode နှင့် real mode ရှိပြီး real mode သည် CadCraft Studio တွင်သာ အလုပ်လုပ်ပါသည်။
- **Digital twin။** Material flow layout ကို ဖတ်ပြီး ၎င်းပေါ်တွင် soft PLC ကို လည်ပတ်စေပါသည်၊ အတင်းအဓမ္မ ချိုးဖောက်နိုင်သော fault များ၊ stock စမ်းသပ်ချက်များ၊ layout နှိုင်းယှဉ်ခြင်းနှင့် bill of materials ပါဝင်ပါသည်။
- **Factory floor။** Station များကို စက်များနှင့် cell များအဖြစ် ပြောင်းပြီး တိုက်ရိုက် သို့မဟုတ် simulator မှ ဖတ်ပါသည်၊ job queue နှင့် ရိုးရှင်းသော OEE ကို ထိန်းသိမ်းပါသည်။ ဖတ်ခြင်းသာ လုပ်ပါသည်၊ ဤတည်ဆောက်ချက်သည် စက် သို့မဟုတ် PLC သို့ ရေးနိုင်ခြင်း မရှိပါ။

### မျက်နှာပြင်များ၊ မော်ဒယ်များနှင့် ပုံဆွဲခြင်း

- **NURBS ပေါ်တွင် fillet၊ thickening နှင့် boolean။** {{ui:Surfaces}} panel တွင် {{ui:Fillet between faces}}၊ {{ui:Fillet several edges}}၊ {{ui:Thicken into a solid}} နှင့် Union၊ Subtract နှင့် Intersect တို့ ပါဝင်ပြီး တစ်ခုစီတွင် တိုင်းတာထားသော သွေဖည်မှု ပါဝင်ပါသည်။ [Freeform surfaces (NURBS)](topic:nurbs-surfaces) ကို ကြည့်ပါ။
- **Scan သို့ မျက်နှာပြင်များ ကိုက်ညီစေခြင်း။** Scan လုပ်ထားသော mesh ကို ရွေးပြီး **Scan** အုပ်စုတွင် {{ui:Fit surfaces to the scan}} ကို သုံးပါ၊ ထို့နောက် {{ui:Stitch the surfaces to a solid}} ကို သုံးပါ။ ၎င်းသည် ပထမ ကိုက်ညီမှုသာ ဖြစ်ပြီး reverse-engineering ပက်ကေ့ချ် အပြည့်အစုံ မဟုတ်ပါ။
- **.3dm modeller မှ တိုက်ရိုက် ချိတ်ဆက်မှု။** Rhino 8 သို့မဟုတ် Grasshopper မှ တစ်လမ်းသွား ဖြစ်ပြီး ကွန်ပျူတာတစ်လုံးတည်းတွင် CadCraft Studio လိုအပ်ပါသည်။ [.3dm မော်ဒယ်ကို တိုက်ရိုက် ထားရန်](topic:live-3dm-link) ကို ကြည့်ပါ။
- **မော်ဒယ်ကို နေရာတွင် ကြည့်ခြင်း။** {{ui:Views}} မီနူးရှိ {{ui:View on site (AR, phone)}} သည် Chrome ပါသော Android ဖုန်းတွင် အလုပ်လုပ်ပါသည်။ [Android ဖုန်းဖြင့် မော်ဒယ်ကို နေရာတွင် ကြည့်ခြင်း (AR)](topic:ar-on-site) ကို ကြည့်ပါ။
- **Arc နည်းလမ်းများ။** {{ui:Arc methods}} drop-down တွင် arc ဆွဲနည်း ဆယ်မျိုး ရှိပြီး {{ui:3-Point}} နှင့် {{ui:Start, Center, End}} တို့ ပါဝင်ပါသည်။
- **ယူနစ် ထပ်မံ။** တန်ချိန် (kg၊ lb၊ t၊ ton) နှင့် အပူချိန် (ဒီဂရီ C၊ F၊ K နှင့် R) ကို ယူနစ်ဖြင့် တန်ဖိုး ရိုက်သွင်းသည့်နေရာများတွင် နားလည်ပါသည်။

## app တိုင်းတွင်

- **Tooltip များ။** ခလုတ်များပေါ်ရှိ hover စာသားနှင့် ဖြတ်ထားသော label များသည် Bootstrap tooltip ဖြစ်ပါသည်။
- **ပိတ်နိုင်သော စတင် အကြံပြုချက်။** ဗလာ ပုံဆွဲနေရာပေါ်ရှိ အကြံပြုချက် ကဒ်တွင် အသေးစား ပိတ်ရန် x ရှိပါသည်။ ပိတ်ထားမည်ဖြစ်ပြီး command palette မှ ပြန်ပြနိုင်ပါသည်။
- **လှိမ့်နိုင်သော tab အတန်းများ။** ကိုက်ညီခြင်းမရှိသော panel tab အတန်းသည် ဖြတ်ခံရမည့်အစား လှိမ့်ပါသည်။
- **Tab ခေါင်းစဉ်များ။** စာရွက်စာတမ်း ဖွင့်ထားစဉ် browser tab သည် စာရွက်စာတမ်းအမည်ဖြင့် စတင်ပြီး ထို့နောက် ModelCraft နှင့် CadCraft ပါပါသည်။ သိမ်းမထားရသေးပါက အစက်ကို ရှေ့ဆုံးတွင် ပြပါသည်။
- **Layout။** {{ui:Settings}} › {{ui:General}} › Layout တွင် layout များကို drop-down ဖြင့် ထားပြီး ဤ app အတွက်သာ layout ကို သုံးရန် ရွေးချယ်စရာနှင့် layout ကို ပြန်သတ်မှတ်ရန် ခလုတ် ရှိပါသည်။
- **ဘာသာစကားများ။** Settings ရှိ ဘာသာစကားစာရင်းသည် build တွင်ပါသော ဘာသာစကားဖိုင်များကို လိုက်ပါသည်။ အင်္ဂလိပ်မှတစ်ပါး ဘာသာစကားများသည် စက်ဖြင့် ဆွဲထားသော မူကြမ်းများဖြစ်ပါသည်။
- **Live နှင့် Library။** Live TeamWork သည် တိုက်ရိုက် cursor နှင့် နာမည်များကို ပြပြီး Library collection များက app တစ်ခုစီကို မူလ collection ပေးပါသည်။

## ပြင်ဆင်ထားသည်များ

### အသစ်

**Rendering**

- **Engine ရွေးချယ်မှု။** {{ui:Render a picture…}} တွင် Mode အပေါ်၌ **Engine** စာရင်း ရှိပါသည်။ ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် engine နှစ်ခုဖြစ်သော Fast နှင့် Path tracer သည် မူလဖြစ်ပြီး နေရာတိုင်းတွင် အလုပ်လုပ်ပါသည်။ အခြား ရွေးချယ်စရာများသည် scene ကို package (မော်ဒယ်ကို USD ဖိုင်အဖြစ်၊ ပစ္စည်းတန်ဖိုးအတိအကျ၊ ဖွင့်ထားသော မီးများ၊ နေ၊ ကောင်းကင်၊ exposure နှင့် ကင်မရာ ပါဝင်သော settings ဖိုင်) အဖြစ် သိမ်းပြီး အခြားပရိုဂရမ်သို့ ယူသွားနိုင်ပါသည်။ အခြားပရိုဂရမ်ဖြင့် ဆွဲထားသော ပုံသည် မည်သည့် ပရိုဂရမ်နှင့် ဗားရှင်းက ဖန်တီးခဲ့သည်ကို ပြောပါသည်။ [ပုံကို မည်သည့်ပရိုဂရမ်က ဆွဲမည်ကို ရွေးချယ်ခြင်း](topic:render-engines) ကို ကြည့်ပါ။
- **အခြားပရိုဂရမ်တွင် ဖွင့်ခြင်း။** Engine စာရင်းက scene ကို USD ဖိုင်၊ glTF ဖိုင် (`.glb`) သို့မဟုတ် Unreal project folder (`.zip`) အဖြစ် browser နှင့် CadCraft Studio တွင် သိမ်းနိုင်ပါသည်။ Studio တွင် usdview သို့မဟုတ် ကွန်ပျူတာ၏ ကိုယ်ပိုင် ပရိုဂရမ်ကိုလည်း ဖိုင်အတွက် စတင်နိုင်ပါသည်။ [Scene ကို အခြားပရိုဂရမ်တွင် ဖွင့်ခြင်း](topic:render-open-in) ကို ကြည့်ပါ။
- **Studio မှ game engine သို့ ပို့ခြင်း။** Studio သည် scene ကို Unreal Engine project တွင် ရေးပြီး ပို့တိုင်း ကိုက်ညီအောင် ထိန်းသိမ်းပါသည်၊ တစ်လမ်းသွားသာ ဖြစ်ပါသည်။ သင့်ကိုယ်ပိုင် ပြင်ဆင်ချက်များသည် CadCraft ဘယ်တော့မှ မရေးသော layer တွင် ရှိပါသည်။ [Scene ကို game engine သို့ ပို့ခြင်း](topic:render-unreal) ကို ကြည့်ပါ။
- **ထပ်ဆောင်းမှ engine များ။** ထပ်ဆောင်းတစ်ခုက engine ကို စာရင်းထဲ ထည့်နိုင်ပါသည်။ JavaScript ဖြင့် ရေးထားသည်မှာ browser နှင့် Studio တွင် ဆွဲပြီး ပရိုဂရမ် တစ်ခုကို လည်ပတ်စေသည်မှာ Studio တွင် သင့်ခွင့်ပြုချက် လိုအပ်ပါသည်။ [အခြားပရိုဂရမ်ဖြင့် ပုံဆွဲခြင်း](topic:render-other-program) နှင့် [ထပ်ဆောင်းဖြင့် render engine ထည့်ခြင်း](topic:render-engine-addons) ကို ကြည့်ပါ။
- **Scene ကို ပြောခြင်း။** ချိတ်ဆက်ထားသော assistant ကို "dusk, light rain, autumn trees, people on the plaza" ဟု ပြောပါ၊ ModelCraft သည် အဆင့်တစ်ဆင့်တည်းဖြင့် တည်ဆောက်ပေးပါသည်: နေသည် ရက်စွဲနှင့် အချိန်သို့ ရွေ့ပြီး အရိပ်များ လိုက်ပါသည်၊ ကောင်းကင် ပြောင်းလဲပြီး စိုစွတ်သော မျက်နှာပြင်များ ပေါ်လာပါသည်၊ သစ်ပင်များနှင့် လူများကို ဖျောက်နိုင်၊ ရွှေ့နိုင်၊ ဖျက်နိုင်သော tag များပေါ်ရှိ အစစ်အမှန် အရာများအဖြစ် ထားပါသည်။ နေ့ရက်ချိန်၊ ရက်စွဲ သို့မဟုတ် ရာသီနှင့် ရာသီဥတု (ကြည်လင်၊ မိုးလေဝသ ဆိုင်း၊ မြူ၊ မိုးဖွဲ၊ မိုး၊ မုန်တိုင်း) တို့သည်လည်း သီးခြား အလုပ်လုပ်ပြီး နောက်ပိုင်း တောင်းဆိုချက်က scene တူတူကို ပြောင်းပါသည်။ မြူသည် ဂရပ်ဖစ်ကတ်ပေါ်ရှိ အရည်အသွေးမြင့် ပုံတွင် ပေါ်ပါသည်၊ အခြား engine များက ကောင်းကင်၊ အလင်းနှင့် စိုစွတ်သော မျက်နှာပြင်များကို ပြပါသည်။ မိုးဖွဲကို ကျဆင်းသော မျဉ်းများအဖြစ် မဆွဲပါ။

**ပစ္စည်းများ**

- **ဓာတ်ပုံတစ်ပုံမှ ပစ္စည်း။** မျက်နှာပြင် (နံရံ၊ ကြမ်းပြင်၊ ကျောက်) ၏ ဓာတ်ပုံကို ပေးလိုက်ပါက ၎င်းက tiling ပစ္စည်း ဖန်တီးပါသည်: ဓာတ်ပုံတစ်ခွင်ရှိ အလင်းကို ညီညွတ်စေပြီး ထောင့်များကို ဆက်စပ်အောင် လုပ်ပြီး အရောင်မြေပုံ၊ roughness မြေပုံနှင့် normal မြေပုံတို့ကို ပုံမှ တွက်ထုတ်ပါသည်။ ၎င်းသည် သင့်ကိုယ်ပိုင်ပုံအပေါ် ရိုးရိုး ပုံဖြတ်ပြုပြင်ခြင်းသာ ဖြစ်ပြီး သင်ကြားထားသော မော်ဒယ် မပါပါ။ Roughness သည် ခန့်မှန်းချက်ဖြစ်ပါသည်။ ရိုးရှင်းပြီး စတုရန်း၊ တည့်တည့်ရိုက်ထားသော ဓာတ်ပုံက tile အကောင်းဆုံး ပေးပါသည်; အုတ်ကဲ့သို့ ပြင်းထန်သော ပုံစံများတွင် ဆက်စပ်နေရာတွင် ဝါးနေသော ghost ပေါ်နိုင်ပါသည်။

**မျက်နှာပြင်များ**

- **Freeform မျက်နှာပြင်များ။** {{ui:Surfaces}} panel သည် NURBS curve များနှင့် untrimmed မျက်နှာပြင်များ ဖန်တီးပါသည်: အမှတ်များမှ ဖြတ်သော curve များ၊ loft၊ ruled၊ extrude၊ revolve၊ rail တစ်ခု သို့မဟုတ် နှစ်ခုတလျှောက် sweep များ၊ curve network မှ မျက်နှာပြင်များ၊ အစွန်းလေးခုမှ patch များ၊ match နှင့် blend တို့ ဖြစ်ပါသည်။ မျှဝေထားသော အစွန်းတိုင်းကို တိကျသော မျက်နှာပြင်များပေါ်တွင် G0၊ G1 သို့မဟုတ် G2 (ကွာဟချက်၊ ထောင့်၊ ကွေးညွှတ်မှု ခုန်ချက်) အဖြစ် တိုင်းတာပြီး သင်တောင်းဆိုထားသည်ထက် ဆိုးသော အစွန်းသည် **Match** ပြင်ဆင်ချက်ဖြင့် Problems panel တွင် ပေါ်ပါသည်။ Zebra ကြိုးများနှင့် ကွေးညွှတ်မှု အရောင်များကို တိကျသော မျက်နှာပြင်များမှ ဆွဲပါသည်။ STEP နှင့် IGES ဖိုင်များ ထွက်ပြီး ဝင်ပါသည်။ [Freeform surfaces (NURBS)](topic:nurbs-surfaces) ကို ကြည့်ပါ။

**နေရာနှင့် အခန်းများ**

- **လက်ရေးပုံကြမ်းကို မြေပေါ်သို့။** {{ui:File}} › {{ui:Import a sketch photo…}} သည် လက်ရေးပုံကြမ်း၏ ဖုန်းဓာတ်ပုံကို သင်ပြောသော စကေးဖြင့် မြေပေါ်ရှိ အစွန်းများအဖြစ် ပြောင်းပေးပါသည်: အုပ်စုတစ်ခုတည်းတွင် ဘောပင်အရောင်တစ်ခုစီအတွက် tag တစ်ခုစီ ပါဝင်ပါသည်။ စက္ကူကို ကွန်ပျူတာပေါ်တွင် ရှာပြီး ဖြောင့်ပေးပြီး ဘာမျှ ဘယ်သို့မျှ မပို့ပါ။ [Site plan ပေါ်တွင် မော်ဒယ်ထားခြင်း](topic:site-plan) ကို ကြည့်ပါ။
- **အခန်းကို ပရိဘောဂဖြင့် ပြင်ဆင်ခြင်း။** Floor ကို ရွေးပြီး {{ui:Organize}} › {{ui:Furnish a room…}} ကို သုံးပါ။ Bedroom၊ living room၊ dining room၊ kitchen၊ bathroom သို့မဟုတ် office ပရိဘောဂများကို နံရံများနှင့် ကပ်ပြီး တံခါးနှင့် ပြတင်းပေါက်များမှ ရှင်းလင်းစွာ စည်းမျဉ်းဖြင့် ထားပြီး အဆင့်တစ်ဆင့်တည်းဖြင့် ဖယ်နိုင်သော အုပ်စုတစ်ခုတွင် ထားပါသည်။ ၎င်းသည် သင် ပြန်စစ်ဆေးရန် မူလ အပြင်အဆင် ဖြစ်ပြီး ဒီဇိုင်း မဟုတ်ပါ။ [Starter library](topic:starter) ကို ကြည့်ပါ။

**3D ပရင့်ထုတ်ခြင်း**

- **စောင်းနေသော ဖြတ်ခြင်း။** Split for printing သည် ဖြတ်ရာများကို 60 ဒီဂရီအထိ စောင်းနိုင်ပြီး ပိုမို ကော်ပတ်နိုင်သော နေရာ ပေးပါသည်။ ချိတ်ဆက်ကိရိယာများသည် ဖြတ်ရာနှင့် ထောင့်မှန်ရပ်ပါသည်။ [ပရင့်ထုတ်ရန် မော်ဒယ်ကို ခွဲခြင်း](topic:print-split) ကို ကြည့်ပါ။
- **Problems ရှိ print စစ်ဆေးချက်။** 3D print စစ်ဆေးချက်၏ တွေ့ရှိချက်များကို Problems panel တွင် မော်ဒယ်ပေါ်ရှိ အမှတ်အသားများဖြင့် ပြပြီး Repair က ထိုနေရာမှ ပြင်ပေးပါသည်။ [Supports၊ wall thickness၊ hollowing နှင့် repair](topic:print-tools) ကို ကြည့်ပါ။

**app တိုင်းတွင်**

- **ဘာသာစကားများ။** အကူအညီနှင့် apps များသည် ဘာသာစကား 54 ခုဖြင့် ရရှိနိုင်ပါသည်။ ဆယ်ခုသည် အသစ်ဖြစ်သည်: Lithuanian၊ Latvian၊ Bosnian၊ Marathi၊ Telugu၊ Albanian၊ Afrikaans၊ Filipino၊ Swahili နှင့် Uzbek။ အင်္ဂလိပ်မှတစ်ပါး ဘာသာစကားများသည် ဒေသခံ စာတည်းသူက မစစ်ဆေးမချင်း စက်ဖြင့် ဆွဲထားသော မူကြမ်းများဖြစ်ပြီး အကူအညီ အပိုင်းများ အင်္ဂလိပ်ဖြင့် ကျန်နိုင်ပါသည်။
- **Input ကိရိယာများ။** Trackpad၊ ဘောပင်၊ 3D mouse၊ game controller နှင့် MIDI controls များဖြင့် apps များကို လည်ပတ်စေနိုင်ပါသည်၊ အားလုံး သို့မဟုတ် တစ်ခုအတွက်ပါ။
- **Toolbar အတန်းများ။** {{ui:Settings}} › {{ui:General}} › Toolbar rows တွင် Wrap (ယခင်အတိုင်း)၊ 2 rows သို့မဟုတ် 1 row ကို သတ်မှတ်ပါသည်။ မကိုက်ညီသော bar သည် ပုံဆွဲနေရာမှ နေရာမယူဘဲ ဘေးသို့ လှိမ့်ပါသည်။ Wrap သည် မူလအတိုင်း ဖြစ်နေဆဲပါ။
- **Property grid။** ModelCraft ၏ မီးအကွက်များသည် မျှဝေ grid ကို သုံးပါသည်: ခေါက်နိုင်သော အမျိုးအစားများ၊ label နှင့် တန်ဖိုး column များနှင့် Compact density။ `2*450` ကဲ့သို့ ရိုက်ထည့်သော ဂဏန်းတွက်ချက်မှုများ ဆက်လုပ်နေဆဲ ဖြစ်ပါသည်။
- **Problems။** Problems panel (app bar ရှိ သတိပေးခလုတ်) ကို apps အားလုံးက မျှဝေပါသည်။ ModelCraft တွင် print စစ်ဆေးချက်နှင့် မျက်နှာပြင် ဆက်တိုက်မှု သတိပေးချက်များ ပါဝင်ပါသည်။
- **Live။** Live TeamWork session တွင် မည်သူ ဘယ်မှာရှိသည်ကို ပြပါသည်။ [Live TeamWork ဖြင့် အတူ မော်ဒယ်လုပ်ခြင်း](topic:work-live) ကို ကြည့်ပါ။
- **ထပ်ဆောင်းများ။** ထပ်ဆောင်းများသည် အထက်ပါအတိုင်း render engine များ ထည့်နိုင်ပါသည်။
- **AI ချိတ်ဆက်ခြင်း။** Tool contract နှင့် apps ရှစ်ခု၏ စစ်ဆေးချက်များ အောင်မြင်ပြီး tool စုစုပေါင်း 454 ခု ရှိပါသည်။ Studio အတွင်း တစ်ချက်နှိပ် ချိတ်ဆက်မှု၊ browser assistant များအတွက် hosted connector၊ Studio အတွင်း သင့်ကိုယ်ပိုင် key နှင့် ထုတ်ပြန်ထားသော ပက်ကေ့ချ် တို့ကို မကတိပြုသေးပါ။ Apps တွင် ကိုယ်ပိုင် AI မပါပါ။ [ModelCraft ကို AI assistant များနှင့် သုံးခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

### 0.8.1 တွင် ပြင်ဆင်ထားသည်များ

- **DWG classes အပိုင်း။** DWG ဖိုင်၏ classes အပိုင်းကို မှားသော အမျိုးအစားအဖြစ် ဖတ်ခဲ့ပြီး import လုပ်စဉ် ဖိုင်ကို ပျက်စေနိုင်ပါသည်။ ယခု မှန်ကန်စွာ ဖတ်ပါသည်၊ ModelCraft နှင့် DWG ဖတ်သော အခြား apps များတွင်လည်း ဖြစ်ပါသည်။
- **Portrait မုဒ်ရှိ tablet များ။** ကျန်နေသော grid အမြင့်ကို canvas သို့ ပေးပြီး sheet layout သည် 760 pixel ကျယ်သော သို့မဟုတ် ထို့ထက်နည်းသည်မှ စတင်ပါသည်။ ModelCraft ၏ style sheet တွင်လည်း ပြောင်းလဲချက် ရှိပါသည်။
- **Studio ရှိ ဘာသာစကား။** CadCraft Studio နှင့် packed edition များသည် လည်ပတ်စဉ် ဘာသာစကား ပြောင်းနိုင်ပါပြီ၊ ယခင်က အင်္ဂလိပ်သာ ဖြစ်ပါသည်။ ၎င်းကို platform အားလုံးတွင် မစမ်းသပ်ရသေးပါ၊ ဘာသာစကား မပြောင်းပါက ကျွန်ုပ်တို့ကို အသိပေးပါ။

### ဤဗားရှင်းတွင် မရှိသေးသည်များ

- **Code-signed မဟုတ်ပါ။** Windows က SmartScreen ပြနိုင်ပါသည်: {{ui:More info}} ကို ရွေးပြီး ထို့နောက် {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store build များကို ဆိုင်းငံ့ထားပြီး iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- Render-engine ထပ်ဆောင်းမရှိဘဲ အခြားပရိုဂရမ်က ပုံဆွဲခြင်း၊ panorama သို့မဟုတ် stereo ကင်မရာများနှင့် အခြားပရိုဂရမ်မှတစ်ဆင့် ကောင်းကင်ပုံ၊ နှင့် Unreal stage ကို ဖွင့်သော plug-in တို့ ယခုမရှိသေးပါ။ ဖိုင်များကို ရေးထားပြီး plug-in ကို မထုတ်ဝေရသေးပါ၊ Unreal တွင်လည်း မလည်ပတ်ရသေးပါ။
- Freeform မျက်နှာပြင်များ: G3 နှင့် class A ကို တိုင်းတာခြင်း သို့မဟုတ် ကြေညာခြင်း မရှိသေးပါ၊ ဖြတ်တောက်ခြင်းနှင့် solid များ နောက်ပိုင်းတွင် ရောက်လာပါမည်။
