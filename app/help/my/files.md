ModelCraft သည် သင့်ကွန်ပျူတာပေါ်ရှိ ဖိုင်များကို ဖတ်ပြီး ရေးသည်။ ဘာမျှ အပ်လုဒ်မလုပ်ပါ: သင်ဖွင့်သော ဖိုင်ကို ဘရောင်ဇာအတွင်းတွင် ဖတ်ပြီး၊ သင်သိမ်းသော ဖိုင်သည် ဒေါင်းလုဒ်တစ်ခု ဖြစ်သည်။ [ဖိုင်များ သွားရောက်ရာနေရာ](common:your-files) ကို ကြည့်ပါ။

## ModelCraft ဖိုင်

`.modelcraft` ဖိုင်သည် မော်ဒယ်တစ်ခုလုံးကို သိမ်းသည်: ဂျီသြမေတြီ၊ အုပ်စုများ၊ အစိတ်အပိုင်းများ၊ guide များ၊ ဇာတ်ခုံများ၊ ယူနစ်များ၊ နှင့် သိမ်းချိန်ရှိ ကင်မရာနှင့် ပုံစံ။ ပြန်ဖျက်ရန် မှတ်တမ်းကို သိမ်းမထားပါ။

### မော်ဒယ်ဖွင့်ရန်

1. {{ui:File}} အုပ်စုရှိ {{ui:Open}} ကို နှိပ်ပါ၊ ဒါမှမဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ။
2. စခရင်ပေါ်ရှိ မော်ဒယ်တွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိလျှင် ModelCraft က မေးသည်: "ဤမော်ဒယ်တွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိသည်။ ပထမဆုံး မိတ္တူတစ်ခု သိမ်းမလား?" {{ui:Save a copy}}, {{ui:Discard changes}} သို့မဟုတ် {{ui:Cancel}} ကို ရွေးပါ။
3. `.modelcraft` ဖိုင်ကို ရွေးပါ။

မော်ဒယ်သည် သိမ်းချိန်ရှိ ယူနစ်များဖြင့်၊ သိမ်းချိန်ရှိ ကင်မရာဖြင့် ဖွင့်မည်။ `.modelcraft` ဖိုင်ကို 3D view ပေါ်သို့ ချထားနိုင်သည်၊ ဒါမှမဟုတ် start card ရှိ မကြာသေးမီဖိုင်စာရင်းမှ တစ်ခုကို နှိပ်နိုင်သည် (ဖိုင်ကို ပြန်ဖွင့်နိုင်သော ဘရောင်ဇာများနှင့် desktop app)။

:::desktop
Desktop app တွင် `.modelcraft` ဖိုင်ကို နှစ်ကြိမ်နှိပ်လျှင် ModelCraft တွင် ဖွင့်မည်ဖြစ်ပြီး၊ Collada, OBJ, glTF, DWG သို့မဟုတ် DXF ဖိုင်တစ်ခုပေါ်ရှိ **Open with** ကလည်း အလားတူ ဖွင့်မည် (မော်ဒယ်အသစ်တစ်ခုအဖြစ် သွင်းမည်)။
:::

### မော်ဒယ်သိမ်းရန်

{{ui:Save}} ကို နှိပ်ပါ၊ ဒါမှမဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။ ဘရောင်ဇာသည် `<name>.modelcraft` ကို ဒေါင်းလုဒ်ဆွဲမည်၊ ဤတွင် name သည် သင်ဖွင့်ထားသော ဖိုင်အမည် ဖြစ်သည်၊ မော်ဒယ်အသစ်ဖြစ်လျှင် "Untitled" ဖြစ်သည်။

:::desktop
Desktop app တွင် {{ui:Save}} သည် သင်ဖွင့်ထားသော ဖိုင်ထဲသို့ နေရာတွင်ပင် ရေးမည်။ မော်ဒယ်အသစ်ဆိုလျှင် မည်သည့်နေရာတွင် သိမ်းမည်ကို မေးမည်။
:::

- {{ui:Save as}} ({{key:Mod+Shift+S}}) သည် `.modelcraft` ဖိုင် သို့မဟုတ် [USD](topic:usd) အဖြစ် မိတ္တူတစ်ခု သိမ်းသည်; ဘရောင်ဇာက ခွင့်ပြုလျှင် အမည်နှင့် နေရာကို မေးမည်။ မဟုတ်ပါက ဒေါင်းလုဒ်ဆွဲထားသော ဖိုင်ကို အမည်ပြောင်းပါ: အမည်ပြောင်းထားသော ဖိုင်ကို ဖွင့်ပြီးနောက် သိမ်းသည့်အခါ အမည်အသစ်ကို သုံးမည်။
- သိမ်းတိုင်းသည် ဒေါင်းလုဒ်အသစ်တစ်ခု ဖြစ်သည်။ ဘရောင်ဇာ ဆက်တင်အလိုက် ဒေါင်းလုဒ်ဖိုင်တွဲသို့ တိုက်ရိုက်ရောက်မည်၊ ဒါမှမဟုတ် ဘယ်နေရာသို့ သိမ်းမည်ကို မေးမည်။ ထိုအမည်ဖြင့် ဖိုင်တစ်ခု ရှိပြီးသားဆိုလျှင် ဘရောင်ဇာအများစုက `Untitled (1).modelcraft` ကဲ့သို့ နံပါတ်ထည့်မည်။

:::chromium
ဖိုင်တွဲကို အမြဲရွေးချယ်ရန် ဘရောင်ဇာ ဆက်တင်များကို ဖွင့်ပြီး "downloads" ကို ရှာကာ "Ask where to save each file before downloading" ကို ဖွင့်ပါ။
:::

:::firefox
ဖိုင်တွဲကို အမြဲရွေးချယ်ရန် **Settings** ကို ဖွင့်ပြီး **General** ကို ရွေးကာ "Downloads" အောက်တွင် "Always ask you where to save files" ကို ရွေးပါ။
:::

:::safari
ဒေါင်းလုဒ်များ သွားမည့်နေရာကို ပြောင်းရန် **Safari** ကို ဖွင့်ပြီး **Settings**၊ ထို့နောက် **General** သို့ သွားကာ "File download location" ကို သတ်မှတ်ပါ။
:::

### မော်ဒယ်အသစ်စတင်ရန်

{{ui:New}} ကို နှိပ်ပါ။ မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိလျှင် ModelCraft က ဦးစွာ မေးမည်။ မော်ဒယ်အသစ်သည် ဗလာဖြင့် စတင်ပြီး၊ သင့်ဒေသ၏ ယူနစ် (အမေရိကန်တွင် feet နှင့် inches၊ အခြားနေရာများတွင် millimeters) ဖြင့် ဖြစ်မည်၊ ဇာတ်ခုံမရှိပါ။

### ဘရောင်ဇာ သိမ်းမီ ပိတ်သွားလျှင်

ပြောင်းလဲမှုတိုင်းပြီး ဆယ်စက္ကန့်အနည်းငယ်အကြာ ModelCraft သည် မသိမ်းရသေးသော အလုပ်၏ မိတ္တူကို ဘရောင်ဇာအတွင်း သိမ်းထားသည်။ သင်မသိမ်းမီ tab သို့မဟုတ် ဘရောင်ဇာ ပိတ်သွားလျှင် နောက်တစ်ကြိမ် ModelCraft ဖွင့်သည့်အခါ "သင့်အလုပ်ကို ပြန်ယူမလား?" ဟု မေးမည်။ ပြန်ယူခြင်းသည် မော်ဒယ်ကို မူလအတိုင်း ဖွင့်ပေးမည်၊ ဖိုင်အဖြစ် မသိမ်းရသေးပါ: သိမ်းရန် သိမ်းပါ။ [သင့်အလုပ်ကို ပြန်ယူခြင်း](common:recover) ကို ကြည့်ပါ။

### CadCraft မှ: ModelCraft တွင် ဖွင့်ရန်

CadCraft drafting app တွင် **View**၊ ထို့နောက် **More**၊ ထို့နောက် **Open in ModelCraft** က ဖွင့်ထားသော ပုံဆွဲချက်ကို DWG အဖြစ် tab အသစ်တစ်ခုတွင် ModelCraft သို့ ပေးပို့သည်။ သွင်းထားသော DWG နည်းတူ ရောက်လာမည်: ကြမ်းပြင်ပေါ်ရှိ မျဉ်းများ၊ အုပ်စုတစ်ခုတွင်၊ မော်ဒယ်ဆွဲရန် အဆင်သင့်။ ဘာမျှ အပ်လုဒ်မလုပ်ပါ; ဖိုင်သည် ဘရောင်ဇာ၏ ကိုယ်ပိုင် သိုလှောင်မှုကို ဖြတ်သွားသည်။

## သွင်းခြင်း

သွင်းခြင်းသည် ဖွင့်ထားသော မော်ဒယ်တွင် ဖိုင်တစ်ခုကို ထည့်သည်; ၎င်းကို အစားထိုးခြင်း မဟုတ်ပါ။

1. {{ui:File}} အုပ်စုရှိ {{ui:Import}} ကို နှိပ်ပါ၊ ဒါမှမဟုတ် ဖိုင်ကို 3D view ပေါ်သို့ ချပါ။
2. SketchUp, Collada, OBJ, glTF, FBX, PLY, STL, Alembic, STEP, `.3dm`, USD, DWG သို့မဟုတ် DXF ဖိုင်တစ်ခုကို ရွေးပါ။

   ဖိုင်သည် **အုပ်စုတစ်ခု** အဖြစ် ရောက်လာပြီး ရွေးထားမည်၊ view သည် ၎င်းကို ပြရန် ချဲ့ပေးမည်။ status bar တွင် ဘာ ရောက်လာသည်ကို ပြပြီး မသွင်းနိုင်သော အရာများကို စာရင်းပြသည်၊ ဥပမာ "Not imported: 2 texture"။

3. ဂျီသြမေတြီကို တိုက်ရိုက် ပြင်ချင်လျှင် အုပ်စုကို နှစ်ကြိမ်နှိပ်ပြီး အတွင်းသို့ ဝင်ပါ၊ ဒါမှမဟုတ် {{ui:Explode}} ကို နှိပ်ပါ။

အသိထားရန် အချို့:

- **အရွယ်အစားနှင့် အပေါ်ဘက် ဦးတည်ချက်:** Collada ဖိုင်များက ၎င်းတို့၏ ယူနစ်နှင့် မည်သည့် ဝင်ရိုးက အပေါ်ဘက်ဖြစ်သည်ကို ပြောပြပြီး ModelCraft က ပြောင်းပေးသည်။ glTF သည် အမြဲ meter ဖြင့် ဖြစ်သည်။ OBJ ဖိုင်များတွင် ယူနစ် မပါ: ModelCraft က meter အဖြစ် ဖတ်ပြီး Y အပေါ်ဘက်ဟု ယူသည်။ OBJ သည် 1000 ဆ ကြီးလွန်းခြင်း သို့မဟုတ် သေးလွန်းခြင်း ဝင်လာလျှင် `0.001` သို့မဟုတ် `1000` ကဲ့သို့ factor ဖြင့် [Scale](topic:rotate-scale) ကို သုံးပါ။
- **DWG နှင့် DXF** သည် မျက်နှာပြင်များအဖြစ်မဟုတ်ဘဲ ကြမ်းပြင်ပေါ်ရှိ မျဉ်းများ (edge များ) အဖြစ် ဝင်လာသည်။ ပုံဆွဲချက်က ၎င်း၏ ယူနစ်ကို မပြောလျှင် "Drawing units" ခေါင်းစဉ်ရှိ ဒိုင်ယာလော့ဂ်က ပုံဆွဲယူနစ်တစ်ခုသည် အဘယ်နည်းဟု မေးမည်။ [ဆိုဒ်အစီအစဉ်ပေါ်တွင် မော်ဒယ်ဆွဲခြင်း](topic:site-plan) ကို ကြည့်ပါ။
- **ကန့်သတ်ချက်များ:** 300 MB ကျော်သော ဖိုင်များကို သွင်းခွင့်မပြုပါ၊ ဖွင့်ရန် 200 MB ကျော်သော ဖိုင်များကို ခွင့်မပြုပါ။ vertex သို့မဟုတ် face 2 သန်းကျော်ရှိသော ဖိုင်များကို အရမ်းကြီးသည်ဟု ငြင်းပယ်မည်။

## ပို့ခြင်း

1. {{ui:File}} အုပ်စုရှိ {{ui:Export}} ကို နှိပ်ပါ။
2. ပုံစံတစ်ခု ရွေးပါ: {{ui:glTF binary (.glb)}}, {{ui:Collada (.dae)}}, {{ui:OBJ (.obj)}}, {{ui:STL for printing (.stl, millimeters)}}, {{ui:PLY with colours (.ply)}}, {{ui:USD (.usda, .usdc, .usdz)…}}, {{ui:IFC for BimCraft (.ifc)}}, {{ui:DWG for CAD (.dwg, 2004)}} သို့မဟုတ် {{ui:DXF for CAD (.dxf, R12)}}။

ဘရောင်ဇာက ဖိုင်ကို ဒေါင်းလုဒ်ဆွဲမည်၊ မော်ဒယ်အမည်နှင့် တူသောအမည်ဖြင့်။ ရွေးချယ်ထားသည်ကိုသာမက မော်ဒယ်တစ်ခုလုံးကို ပို့မည်။ မော်ဒယ်ဗလာဖြစ်လျှင် မပို့ပါ: "The model is empty: draw something first." ။ [မော်ဒယ်ကို အခြားပရိုဂရမ်များအတွက် ပို့ခြင်း](topic:export-model) ကို ကြည့်ပါ။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

ModelCraft ရှိ အရာအားလုံးသည် သင့်ကွန်ပျူတာပေါ်တွင် လည်ပတ်သည်၊ ထို့ကြောင့် အက်ပ်ကို တင်ပြီးသည်နှင့် မော်ဒယ်ဆွဲခြင်း၊ ဖွင့်ခြင်း၊ သိမ်းခြင်း၊ သွင်းခြင်းနှင့် ပို့ခြင်းအားလုံး ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်သည်။

ချိတ်ဆက်မှု လုံးဝမရှိဘဲ ModelCraft ကို ဖွင့်လိုလျှင် အွန်လိုင်းတွင်ရှိစဉ် အော့ဖ်လိုင်းအတွက် သိမ်းပါ:

1. အပေါ်ဘက် app bar ရှိ {{ui:Save for offline}} ကို နှိပ်ပါ။
2. သိမ်းနေစဉ် ခလုတ်က တိုးလာသော ရေတွက်မှုကို ပြသည် ("Saving 40 of 212")။ ModelCraft သည် ကိုယ်ပိုင်ဖိုင်များ (ထိုထဲတွင် DWG ဖတ်ကိရိယာ)၊ ဤအကူအညီစာမျက်နှာနှင့် 3D စာကြည့်တိုက်ကို သိမ်းသောကြောင့် အချိန်ယူနိုင်သည်။
3. ခလုတ်က {{ui:Offline ready}} ဟု ဖတ်ရသည့်အခါ ModelCraft သည် တူညီသော လိပ်စာမှ ချိတ်ဆက်မှုမရှိဘဲ ဖွင့်မည်၊ DWG သွင်းခြင်းလည်း အော့ဖ်လိုင်းတွင် အလုပ်လုပ်မည်။

နောက်ပိုင်း {{ui:Offline ready}} ကို နှိပ်ပြီး {{ui:Save again (get the newest version)}} သို့မဟုတ် {{ui:Remove the offline copy}} ကို ရွေးနိုင်သည်။ ခလုတ်က {{ui:Could not save}} ဟု ဖတ်လျှင် ဖိုင်အချို့ ဒေါင်းလုဒ်မဆွဲရသေးပါ: ချိတ်ဆက်မှုကို စစ်ပြီး ပြန်ကြိုးစားရန် နှိပ်ပါ။ {{ui:Offline not available}} ဆိုသည်မှာ ဤဘရောင်ဇာ ဝင်းဒိုးက မိတ္တူ မသိမ်းနိုင်ဟု ဆိုလိုသည် (private ဝင်းဒိုးများနှင့် အချို့ စီမံထားသော ကွန်ပျူတာများ)။ [အော့ဖ်လိုင်းတွင် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။

Cloud သိမ်းခြင်းသည် ယခုမရနိုင်သေးပါ။ မော်ဒယ်တိုင်းသည် သင်သိမ်းသည့်နေရာတွင်သာ ရှိသည်။

:::offline
သင် အော့ဖ်လိုင်းဖြစ်နေသည်။ မော်ဒယ်ဆွဲခြင်းနှင့် သိမ်းခြင်းကို ဆက်လုပ်နိုင်သည်။ app bar တွင် {{ui:Offline ready}} မပြသမှုကို ကွန်ရက်ပြန်ရသည်အထိ ဤ tab ကို ပြန်မခေါ်ပါနှင့်။
:::
