**timeline** သည် ကင်မရာနှင့် မည်သည့်အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်ကိုမဆို အချိန်အလိုက် ရွှေ့သည်။ **keys** (တစ်ခုခု အချိန်တစ်ခုတွင် ဘယ်နေရာရောက်သလဲ) ကို သတ်မှတ်သည်၊ ModelCraft က key မှ key သို့ ချောမွေ့စွာ ရွှေ့ပေးသည်။ view တွင် ဖွင့်ကြည့်ပြီး [rendered ပုံတစ်ပုံ](topic:render) နှင့် တူညီသော ကောင်းကင်၊ နေ၊ ပစ္စည်းနှင့် မီးချောင်းများဖြင့် ဗီဒီယိုအဖြစ် ရိုက်ယူနိုင်သည်။

## timeline ဖွင့်ရန်

views ကို {{ui:Camera}} အုပ်စုတွင် နှိပ်ပြီး ထို့နောက် {{ui:Animation timeline}} ကို နှိပ်ပါ။ timeline သည် view အောက်တွင် ဖွင့်သည်- ထိပ်ပိုင်းရှိ ထိန်းချုပ်မှုများ၊ ထို့နောက် **Camera** row နှင့် ရွှေ့သော အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်တိုင်းအတွက် row။ diamonds များသည် keys ဖြစ်သည်၊ အနီရောင် မျဉ်းသည် **playhead** ဖြစ်ပြီး view တွင် ပြနေသော အချိန်ကို ဖော်ပြသည်။

:::touch
ဖုန်းတွင် timeline သည် view အောက်တွင် လည်း ဖွင့်သည်။ ၎င်း၏ ထိန်းချုပ်မှုများသည် တန်းတစ်တန်းတည်း ဖြစ်သည်၊ ကျန်ကိုရောက်ရန် ဘေးသို့ ပွတ်ဆွဲပါ၊ timeline ကို ပိတ်သော ခလုတ်က အဆုံးတွင် ကျန်နေသည်။
:::

playhead ကို ရွှေ့ရန် slider ကို ဆွဲပါ (သို့မဟုတ် row တွင် နှိပ်ပါ)။ {{ui:Play}} သည် playhead မှ ဖွင့်ပြီး ဖွင့်နေစဉ် {{ui:Pause}} ဖြစ်သွားသည်၊ ရပ်ရန် ထပ်နှိပ်ပါ၊ ရပ်လိုက်သောနေရာတွင် ရပ်သည်။ timeline ဖွင့်ထားစဉ် {{key:Space}} သည် အလားတူလုပ်သည် (timeline ပိတ်ထားစဉ် Space သည် ရွေးချယ်ရန်အတွက် ဆက်ရှိသည်)။ {{ui:Previous key}} နှင့် {{ui:Next key}} က keys များကြား ခုန်သွားသည်။ ကိုယ်ပိုင် style ဖြင့် ဖွင့်/ရပ် ကို တခြား key တစ်ခုပေးနိုင်သည်- {{ui:Settings}}၊ ထို့နောက် menus၊ keys နှင့် mouse၊ *Play or pause the animation* command။

## ကင်မရာ ရွှေ့ခြင်း

1. ရိုက်ချက်စတင်မည့်နေရာ (0 s) သို့ playhead ကို ရွှေ့ပြီး view ကို စီစဉ်ကာ {{ui:Key camera}} ကို နှိပ်ပါ။
2. playhead ကို နောက်ကျရာသို့ ရွှေ့ပါ (ဥပမာ 4 s)၊ view ကို လည်ပတ်၊ ပန်၊ သို့မဟုတ် လျှောက်ပြီး နောက်နေရာသို့ ရောက်စေပြီး {{ui:Key camera}} ကို ထပ်နှိပ်ပါ။
3. လိုသလောက် keys ထည့်ပြီး {{ui:Play}}။

ကင်မရာသည် key တိုင်းကို ချောမွေ့စွာ ဖြတ်ကျော်ပြီး နားနေသောအနေအထားဖြင့် စတင်၍ အဆုံးသတ်သည်။

:::tip
[ဇာတ်ခင်းများ (scenes)](topic:scenes) ရှိပြီးလား။ {{ui:From scenes}} က ၎င်းတို့မှ ကင်မရာ လမ်းကြောင်းကို ဖန်တီးသည်- scene တစ်ခုစီတွင် ခဏရပ်ပြီး နောက် scene သို့ ရွှေ့သည်။ timeline တွင် keys လုံးဝ မရှိလျှင် {{ui:Render video…}} က ၎င်းကို အလိုအလျောက် လုပ်ပေးသည်၊ ထို့ကြောင့် scene နှစ်ခု သို့မဟုတ် ထို့ထက်ပိုလျှင် လမ်းလျှောက်ဗီဒီယိုအတွက် လုံလောက်သည်။
:::

## အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်ကို ရွှေ့ခြင်း

1. အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်ကို ရွေးပါ (အုပ်စုတစ်ခုလုံး နှင့် ကွန်ပိုနင့်များသာ ရွေ့သည်; [အုပ်စု ဖန်တီးပါ](topic:groups-components) ကို အရင်လုပ်ပါ)။
2. 0 s တွင် {{ui:Key selected}} ကို နှိပ်ပါ။
3. နောက်ကျရာသို့ playhead ကို ရွှေ့ပြီး အုပ်စုကို ဖြစ်သင့်သော နေရာသို့ [ရွှေ့၊ လှည့် သို့မဟုတ် ချဲ့](topic:move-copy) ပြီး {{ui:Key selected}} ကို ထပ်နှိပ်ပါ။

၎င်းသည် keys များကြား ဆွဲသွား၊ လှည့်၊ ကြီးလာသည်။ လှည့်မှုများသည် တိုသော လမ်းကြောင်းကို ယူသည်။

**Auto key** က အဆင့် 3 ၏ နှိပ်ခြင်းကို ချန်လှပ်စေသည်- {{ui:Auto key}} ဖွင့်ထားစဉ် သင်ရွှေ့၊ လှည့် သို့မဟုတ် ချဲ့သော ရွေးထားသည့် အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်သည် playhead မှာ key ကို အလိုအလျောက် ရရှိသည် (ပထမအကြိမ်တွင် ၎င်းရှိနေသော 0 s တွင် key တစ်ခုလည်း ရရှိသည်)။

:::note
key မရှိဘဲ animated အုပ်စုကို ရွှေ့ပါက playhead ရွေ့သည်အထိသာ ကျန်နေသည်- ဖွင့်ခြင်း သို့မဟုတ် scrub လုပ်သည့်အခါ ၎င်း၏ keys က သတ်မှတ်သော နေရာသို့ ပြန်ရောက်သွားသည်။ status bar က ထိုသို့ပြောသည်။ ထိန်းထားရန် {{ui:Key selected}} ကို နှိပ်ပါ။
:::

## Keys ပြောင်းခြင်း

- **key ရွေးရန်** ၎င်း၏ diamond ကို နှိပ်ပါ- playhead သည် ထိုနေရာသို့ သွားသည်။
- **key ရွှေ့ရန်** ၎င်း၏ diamond ကို row တစ်လျှောက် ဆွဲ၊ သို့မဟုတ် {{key:Left}} နှင့် {{key:Right}} (frame တစ်ခု၊ {{key:Shift}} ဖြင့် ဆယ်ခု) ဖြင့် ရွှေ့ပါ။
- **ဖျက်ရန်** {{ui:Delete key}} ဖြင့် (ရွေးထားသော key သို့မဟုတ် playhead မှာ key အားလုံး) သို့မဟုတ် ရွေးထားသော diamond ပေါ်ရှိ {{key:Delete}}။
- **နောက်သို့ ရွေ့ပုံ**၊ ရွေးထားသော key အတွက်- {{ui:Smooth}} (ပတ်လည် keys များကို ဖြတ်သော curve)၊ {{ui:Steady}} (တစ်သတ်မှတ်တည်း အရှိန်ဖြင့် မျဉ်းဖြောင့်)၊ {{ui:Slow in and out}} (ဤ key တွင် နားသည်) သို့မဟုတ် {{ui:Hold}} (နောက် key အထိ ထိုနေရာတွင် ရှိနေသည်)။
- **Length (s)** က animation ၏ ကြာချိန်ကို သတ်မှတ်သည်၊ အဆုံးထက်နောက်တွင် သတ်မှတ်သော key သည် ၎င်းကို ရှည်စေသည်။ တိုစေရန် အဆုံးအပြင်ဘက်ရှိ keys များကို အရင်ရွှေ့ သို့မဟုတ် ဖျက်ပါ။
- အုပ်စု row ပေါ်ရှိ **×** က ၎င်းကို animate လုပ်ခြင်းကို ရပ်စေသည်။

timeline တွင် ကိုယ်ပိုင် {{ui:Undo}} နှင့် {{ui:Redo}} ရှိသည်- model ၏ undo ({{key:Mod+Z}}) က model ကို ပြန်ပြောင်းသည်၊ keys များကို မဟုတ်ပါ။ animation ကို `.modelcraft` ဖိုင်တွင် သိမ်းသည်။ timeline ကို ပိတ်လိုက်လျှင် ရွေ့နေသော အုပ်စုများကို ၎င်းတို့၏ ပထမ ပုံသဏ္ဍာန်သို့ ပြန်ထားသည်။

## ဗီဒီယို ရိုက်ယူခြင်း

1. timeline ပေါ်ရှိ {{ui:Render video}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Export}} › {{ui:Render video…}})။
2. {{ui:Size}}၊ {{ui:Frame rate}}၊ {{ui:Quality of each frame}} နှင့် {{ui:File}} ကို ရွေးပါ။
3. {{ui:Render video}} ကို နှိပ်ပါ။ frame တစ်ခုစီကို ပြုလုပ်နေစဉ် ပြပြီး ကျန်ရှိချိန်ကိုပါ ပြသည်။
4. ပြီးသောအခါ {{ui:Save video}} ကို နှိပ်ပါ။

{{ui:Stop}} (သို့မဟုတ် {{key:Esc}}) က စောစောရပ်သည်၊ ထို့နောက် {{ui:Save video}} က ပြီးသား frames များကို ပိုတိုသော ဗီဒီယိုအဖြစ် သိမ်းသည်။

ကောင်းကင်၊ နေ၊ ပစ္စည်းများ၊ မီးချောင်းများနှင့် တောက်ပမှုများသည် {{ui:Render a picture…}} တွင် သတ်မှတ်ထားသည့်အတိုင်း ဖြစ်သည်- ၎င်းတို့ကို ထိုနေရာတွင် အရင်သတ်မှတ်ပြီး ပုံငြိမ်တစ်ပုံဖြင့် စစ်ဆေးပါ။ frame တစ်ခုစီကို ဤကွန်ပျူတာပေါ်တွင် ရိုက်ယူသည်၊ ဘာမျှ မတင်ပါ။

| သတ်မှတ်ချက် | ဘာလုပ်သလဲ |
|---|---|
| {{ui:Size}} | 480p၊ 720p HD၊ 1080p Full HD၊ သို့မဟုတ် view ၏ ကိုယ်ပိုင်ပုံသဏ္ဍာန် (အကျယ် 1920 pixels အထိ) |
| {{ui:Frame rate}} | စက္ကန့်လျှင် frames 24၊ 25၊ 30 သို့မဟုတ် 60။ frames နှစ်ဆဆိုလျှင် အချိန်နှစ်ဆ ကြာသည် |
| {{ui:Quality of each frame}} | {{ui:Quick}} (passes 4)၊ {{ui:Draft}} (16) သို့မဟုတ် {{ui:Good}} (64): passes ပိုများလျှင် အရိပ်နှင့် အစွန်းများ ပိုချောမွေ့သည် |
| {{ui:File}} | {{ui:WebM video}}၊ browser ရေးနိုင်သောနေရာတွင် {{ui:MP4 video (H.264)}}၊ သို့မဟုတ် ဗီဒီယို တည်းဖြတ်သူများအတွက် (နှင့် video encoder မရှိသော browsers များအတွက်) frame တစ်ခုစီအတွက် တစ်ပုံစီ {{ui:PNG pictures, one per frame (ZIP)}} |

:::tip
စက္ကန့် 10 ရှိ ဗီဒီယိုသည် စက္ကန့်လျှင် frames 30 ဖြင့် frames 301 ရှိသည်။ 480p တွင် {{ui:Quick}} ဖြင့် အရင်စမ်းပြီး လှုပ်ရှားမှုကို စစ်ဆေးကာ၊ ထို့နောက် ပိုကြီးသော အရွယ်အစားဖြင့် {{ui:Draft}} သို့မဟုတ် {{ui:Good}} ကို ရိုက်ပါ။
:::

WebM ကို browsers နှင့် VLC တွင် ဖွင့်နိုင်ပြီး ဗီဒီယို တည်းဖြတ်သူများက ပြောင်းလဲနိုင်သည်။ {{ui:MP4 video (H.264)}} ကို browser က ရေးနိုင်သည့်နေရာတွင် ပေးသည်။ {{ui:Render video}} က မြန်သော renderer ကို သုံးသည်၊ frame တစ်ခုစီကို path trace လုပ်လိုလျှင် တူညီသော dialog တွင် {{ui:Add this animation to the queue}} ကို ရွေးပါ- frames များကို [render queue](topic:render#the-render-queue) တွင် ရိုက်ပြီး WebGPU လိုအပ်သည်။

ဗီဒီယို ရိုက်ရန် browser က ဗီဒီယိုကို ကိုယ်တိုင် encode လုပ်နိုင်ရမည် (WebCodecs): မကြာသေးမီ Chrome၊ Edge၊ Firefox နှင့် Safari 17 တို့က လုပ်နိုင်သည်။ မဟုတ်ပါက {{ui:PNG pictures, one per frame (ZIP)}} ကို ရွေးပါ။
:::

## သိထားရမည့်အချက်များ

- အုပ်စု နှင့် ကွန်ပိုနင့်တစ်ခုလုံးသာ ရွေ့သည်။ မျက်နှာများ၊ အစွန်းများ၊ နေ၏အချိန်နှင့် style တို့သည် အချိန်အလိုက် မပြောင်းလဲသေးပါ။
- [Scenes](topic:scenes) အောက်ရှိ {{ui:Export animation}} သည် မျက်နှာပြင်ပေါ်ရှိအတိုင်း view ကို အချိန်နှင့်တပြေးညီ ဆက်လက် မှတ်သည်၊ {{ui:Render video}} က ကောင်းကင်၊ အရိပ်နှင့် ပစ္စည်းများဖြင့် frame တစ်ခုစီကို ရိုက်သည်။
