မော်ဒယ်ဖန်တီးသည့်နေရာတွင် ဆက်ဖန်တီးပြီး ရလဒ်ကို ဤနေရာတွင် အသုံးပြုပါ- ပုံထုတ်ရန်၊ အလင်းပေးရန် သို့မဟုတ် ၎င်းပတ်လည်တွင် ဇာတ်ခင်းကို စီစဉ်ရန်။ အခြားပရိုဂရမ်ရှိ ပြောင်းလဲမှုတိုင်းသည် ModelCraft ရှိ အုပ်စုတစ်ခုကို အပ်ဒိတ်လုပ်သည်။

:::note
ချိတ်ဆက်မှုအတွက် တူညီသော ကွန်ပျူတာပေါ်တွင် **CadCraft Studio** လိုသည်။ browser tab က ချိတ်ဆက်မှုကို မယူနိုင်ပါ။ အင်တာနက်ဖြင့် ဘာမှ မပို့ပါ- script သည် ဤကွန်ပျူတာ၏ ကိုယ်ပိုင်လိပ်စာဖြင့် token ဖြင့် Studio နှင့် ပြောဆိုသည်။
:::

:::warning
ဤချိတ်ဆက်မှုကို script ၏ ဖိုင်ရေးသားသူနှင့် အခြားပရိုဂရမ်အစား တစ်ခုဖြင့် စမ်းသပ်ပြီးပြီ၊ Rhino သို့မဟုတ် Grasshopper အတွင်း၌ ကိုယ်တိုင် မစမ်းသပ်ရသေးပါ။ ထိုနေရာတွင် မအောင်မြင်ပါက ၎င်းက ဘာပြောသည်ကို ကျွန်ုပ်တို့အား အကြောင်းကြားပေးပါ။
:::

## တပ်ဆင်ရန်

1. Studio တွင် ModelCraft ကို ဖွင့်ပါ။ {{ui:Settings}} › {{ui:ModelCraft}} › {{ui:Assistants}} တွင် **AI အကူအညီပေးသူများနှင့် script များက ModelCraft ကို သုံးခွင့်ပေးရန်** ကို အမှန်ခြစ်ပြီး **Edit** ကို နှိပ်ပါ။
2. Studio တွင် {{ui:Connect an assistant}} ကို ရွေးပါ။ အောက်တွင် ကူးထည့်မည့် လိပ်စာနှင့် token ကို ပြသည်။
3. script ကို ဒေါင်းလုဒ်ဆွဲပါ- [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)။

## Rhino မှ

1. Rhino ၏ script editor တွင် `cadcraft_link.py` ကို run ပါ (Rhino 8 တွင် Python 3)။
2. ပထမအကြိမ်တွင် လိပ်စာနှင့် token ကို ကူးထည့်ပါ။ ၎င်းတို့ကို သင့် home folder ရှိ `.cadcraft-link.json` တွင် သိမ်းထားပြီး မော်ဒယ်ထဲတွင် ဘယ်တော့မှ မထားပါ။ Studio သည် စတင်တိုင်း token အသစ် ပြုလုပ်သဖြင့် script က ထိုအချိန်တွင် ထပ်မေးသည်။

မော်ဒယ်တစ်ခုလုံးသည် စာရွက်စာတမ်းအမည်ဖြင့် အုပ်စုတစ်ခုအဖြစ် ရောက်လာသည်၊ ဥပမာ "chair (linked)"။ ထို့နောက် ပြောင်းလဲမှုတိုင်းသည် ခဏရပ်လိုက်သောအခါ ရောက်လာပြီး ပြောင်းလဲခဲ့သော object များသာ ပို့သည်။ ရပ်ရန် script ကို ပြန် run ပါ။

## Grasshopper မှ

လိပ်စာနှင့် token သိမ်းနိုင်ရန် script ကို Rhino တွင် အရင် တစ်ကြိမ် run ပါ။

1. Script component (Python 3) ထည့်ပြီး `cadcraft_link.py` တစ်ခုလုံးကို ထဲသို့ ကူးထည့်ပါ။
2. အောက်ပါ input များ ပေးပါ- `G` (geometry၊ list access ဖြင့်)၊ `N` (အမည်၊ ရွေးချယ်နိုင်)၊ `On` (boolean toggle)၊ နှင့် `Target` (ရွေးချယ်နိုင်: `model` သို့မဟုတ် `part`၊ app နှစ်ခုလုံး ဖွင့်ထားလျှင်)။
3. `On` ကို true ပြောင်းပါ။

solve တိုင်းသည် `G` ကို ပို့ပြီး component က နောက်ဆုံးပို့ထားသည်ကို အစားထိုးသည်၊ ထို့ကြောင့် slider ကို ဆွဲသည့်အခါ ဤနေရာရှိ အုပ်စုကို အပ်ဒိတ်လုပ်သည်။ ၎င်း၏ output `a` က ဖြစ်ခဲ့သည်ကို ပြောသည်။ component တစ်ခုစီတွင် ၎င်း၏ကိုယ်ပိုင် အုပ်စု ရှိသည်။

## အုပ်စုဖြင့် လုပ်နိုင်သည်များ

- **ရွှေ့ပါ၊ tag တပ်ပါ၊ ပတ်လည်တွင် တည်ဆောက်ပါ။** အုပ်စုနှင့် ၎င်း၏ tag ထားရှိသည့်နေရာသည် အပ်ဒိတ်တိုင်း၌ ကျန်ရှိပြီး ၎င်းဘေးရှိ အရာအားလုံးလည်း ထိုနည်းတူ ကျန်ရှိသည်။
- **အတွင်းမှ မတည်းဖြတ်ပါနှင့်။** အပ်ဒိတ်တိုင်းက အုပ်စုအတွင်းရှိ အရာကို အစားထိုးသည်။ ထို object များကို အခြားပရိုဂရမ်က ပိုင်ဆိုင်သည်။
- **Undo။** စက္ကန့် ၂ အတွင်း အပ်ဒိတ်များသည် undo အဆင့်တစ်ခုကို မျှဝေသဖြင့် {{key:Mod+Z}} က ဆွဲမှုတစ်ခုလုံးကို ပြန်ယူသည်။ နောက်အပ်ဒိတ်က မော်ဒယ်ကို ကိုက်ညီအောင် ပြန်ထားသည်။
- **သိမ်းခြင်း။** သိမ်းထားသောဖိုင်က ချိတ်ဆက်မှုကို ထိန်းထားသည်။ ပြန်ဖွင့်ပြီးနောက် script ကို ပြန် run ပါ၊ အုပ်စုတူ အပ်ဒိတ်လုပ်သည်။

## ရောက်လာသည်များ

Mesh များ၊ polysurface များ၊ surface များနှင့် extrusion များကို ဖန်သားပြင်တွင် မြင်ရသော mesh အဖြစ်၊ SubD ကို ၎င်း၏ mesh အဖြစ်၊ curve များကို edge များအဖြစ်၊ block များကို ၎င်းတို့ရှိနေသည့်နေရာတွင် သီးခြား object များအဖြစ် (component အဖြစ် မဟုတ်)၊ layer များကို tag များအဖြစ်၊ အရောင်နှင့် ယူနစ်များ ရောက်လာသည်။ ဤနေရာတွင် ၎င်းတို့ ပေါ်ပုံအတွက် [`.3dm` မော်ဒယ် သွင်းခြင်း](topic:import-3dm-files) ကို ကြည့်ပါ။

အခြားပရိုဂရမ်တွင် အရေအတွက်ဖြင့် ချန်ထားခဲ့သည်- point များ၊ စာသား၊ dimension များ၊ မီးများနှင့် ဆင်တူသည်များ။

**တစ်လမ်းသွားသာ။** ဤနေရာ၏ ပြောင်းလဲမှုများသည် အခြားပရိုဂရမ်သို့ ပြန်မသွားပါ။

## ပြဿနာရှိလျှင်

- **"ModelCraft သို့မဟုတ် PartCraft ဝင်းဒိုး မည်သည်ကိုမျှ ခွင့်မပြုပါ":** တပ်ဆင်ခြင်း အဆင့် ၁ ကို လုပ်ပါ။
- **"Studio က token ကို ငြင်းပယ်သည်":** Studio ပြန်စထားသည်။ token အသစ်ကို ကူးပြီး script ကို ပြန် run ပါ။ Grasshopper အတွက် Rhino တွင် အရင် run ပါ။
- **"CadCraft Studio သို့ ချိတ်ဆက်၍ မရပါ":** Studio မ run နေခြင်း သို့မဟုတ် လိပ်စာ ပြောင်းသွားခြင်း ဖြစ်သည်။
