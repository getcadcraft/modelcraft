CadCraft Studio တွင် Engine စာရင်းသည် Unreal Engine project တစ်ခုသို့ **ချိတ်ဆက်မှု** တစ်ခုကို ထားနိုင်သည်။ တစ်လမ်းတည်းသာ ရှိသည်- CadCraft မှ Unreal သို့သာ ဖြစ်သည်။

## ဇာတ်ခုံကို ပို့ရန်

1. Engine စာရင်းတွင် Unreal အတန်းကို ရွေးပါ။ ပထမအကြိမ်တွင် Studio က သင့် project ဖိုင်တွဲ (`.uproject` ဖိုင်ပါသော ဖိုင်တွဲ) ကို ရွေးရန် မေးမည်၊ ၎င်းက မှတ်ထားမည်။
2. {{ui:Send}} ကို နှိပ်ပါ။ Studio သည် project အတွင်း `CadCraft/<file name>/` ကို ရေးမည်- ဇာတ်ခုံကို USD ဖိုင်အဖြစ်၊ ဆက်တင်ဖိုင်၊ မီးပရိုဖိုင်များနှင့် layer ဖိုင်ငယ်နှစ်ခု။
3. မော်ဒယ်ကို ပြင်ပါ၊ သိမ်းပြီး ထပ်ပို့ပါ။ ဇာတ်ခုံနှင့် ဆက်တင်ဖိုင်ကိုသာ အစားထိုးမည်။

## သင့်ကိုယ်ပိုင် တည်းဖြတ်မှုများ လုံခြုံသည်

Unreal ဖွင့်သော stage သည် တစ်ကြိမ်တည်း ဖန်တီးထားသော အဓိက layer ငယ်တစ်ခုဖြစ်ပြီး အောက်တွင် layer နှစ်ခုရှိသည်- ထိပ်ပိုင်းတွင် **သင့်ကိုယ်ပိုင်** (`<name>.user.usda`၊ အစတွင် ဗလာဖြစ်ပြီး CadCraft က ဘယ်တော့မှ ပြန်မရေး) နှင့် အောက်ပိုင်းတွင် CadCraft ၏ ဇာတ်ခုံ။ သင့်ကိုယ်ပိုင် layer တွင် သိမ်းထားသော တည်းဖြတ်မှုများသည် ဇာတ်ခုံကို ထပ်ပို့သည့်အခါ ကျန်ရှိနေမည်။ Unreal level တွင် သင်ထားသော မီးများနှင့် အခြား actor များသည် stage အပြင်ဘက်တွင် ရှိပြီး ထိခိုက်မှုလည်း မရှိပါ။

## Studio မပါဘဲ

ဘရောက်ဇာတွင်၊ သို့မဟုတ် Studio က Unreal ကို မတွေ့သော ကွန်ပျူတာတွင် Engine စာရင်းမှ **Unreal project ဖိုင်တွဲ (.zip)** ကို ရွေးပြီး {{ui:Render}} ကို နှိပ်ပါ။ ၎င်းသည် တူညီသော ဖိုင်တွဲကို zip အဖြစ် သိမ်းပါသည်- project ၏ `CadCraft` ဖိုင်တွဲထဲသို့ unzip လုပ်ပါ။ ပထမအကြိမ်တွင် **stage ဖိုင်များ ပါဝင်ရန်** ကို ဖွင့်ထားပါ၊ နောက်ပိုင်း သိမ်းမည့်အခါတွင် ပိတ်ပါ၊ ထို့ကြောင့် zip တွင် ဇာတ်ခုံနှင့် ဆက်တင်ဖိုင်သာ ပါပြီး သင့် layer ကို ဘယ်တော့မှ အစားမထိုးပါ။

:::note
stage ကို ဖွင့်ပြီး နေ၊ မီး၊ ကင်မရာနှင့် exposure ကို အသုံးချကာ ပို့တိုင်းကို လိုက်ပြီး ကင်မရာတစ်ခုကို render လုပ်သော Unreal plug-in သည် **အသိပေးထုတ်ဝေထားခြင်း မရှိသေးပါ** ဖြစ်ပြီး Unreal တွင် မလည်ပတ်ရသေးပါ။ ထိုအချိန်အထိ Send သည် ဖိုင်များကို project ထဲသို့ ထည့်ပေးပြီး Unreal ၏ ကိုယ်ပိုင် USD ကိရိယာများဖြင့် ဖွင့်နိုင်ပါသည်။ Windows က ပထမဆုံး စနစ်ဖြစ်ပြီး macOS က နောက်မှ ရောက်မည်။
:::
