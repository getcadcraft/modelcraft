solid ကိရိယာများသည် **solid** များကို ပေါင်းသည်: ထိုအုပ်စုများနှင့် component များသည် ထုထည်ကို ပိတ်သော မျက်နှာများ ရှိပြီး အစွန်းတိုင်း မျက်နှာနှစ်ခုကို ချိတ်သည်။ {{ui:Entity info}} က {{ui:Solid}}: တစ်ခုအတွက် {{ui:Yes}} ဟု ပြပြီး ၎င်း၏ ထုထည်ကို ပြသည်။

ဤကိရိယာများသည် {{ui:Organize}} အုပ်စုရှိ {{ui:Solids}} menu တွင် ရှိသည်။

## အရာတစ်ခု solid မဟုတ်သောအခါ

group သို့မဟုတ် component ကို ရွေးပါ။ solid မဖြစ်လျှင် {{ui:Entity info}} က အကြောင်းပြသည်၊ ဥပမာ "Not a solid: 4 edges border a hole · 1 stray edge"။

| ပြဿနာ | အဓိပ္ပာယ် |
|---|---|
| အစွန်းများက အပေါက်ကို ထိသည် | မျက်နှာတစ်ခု ပျောက်နေသည် |
| အစွန်းများကို မျက်နှာ သုံးခု သို့မဟုတ် ထို့ထက်ပို ဝေမျှသည် | မျက်နှာတစ်ခုက အတွင်းကို ခွဲသည်၊ သို့မဟုတ် ပုံသဏ္ဍာန် နှစ်ခု အစွန်းတစ်လျှောက် ထိနေသည် |
| ပုံသဏ္ဍာန်အတွင်း မျက်နှာများ | ထုထည်အတွင်း ကျန်ခဲ့သော နံရံ |
| Stray အစွန်းများ | မျက်နှာ မသတ်မှတ်သော မျဉ်းများ |
| အတွင်းပြင်ဘက် လှန်နေသော မျက်နှာများ | ၎င်းတို့၏ ရှေ့မျက်နှာများ အတွင်းသို့ ဝင်နေသည်၊ ၎င်းတို့၏ နေ့နယ်မျက်နှာများနှင့် ဆန့်ကျင်ဘက် |

{{ui:Show problems}} သည် ထိုအစွန်းနှင့် မျက်နှာများကို ရွေးထားပြီး ဖွင့်ပေးသည်၊ ထို့ကြောင့် မြင်နိုင်သည်။ {{ui:Fix}} သည် ရိုးရှင်းသော ကိစ္စများကို Undo အဆင့်တစ်ခုဖြင့် ပြင်သည်: stray အစွန်းများနှင့် ပုံသဏ္ဍာန်အတွင်း မျက်နှာများကို ဖယ်သည်၊ မျက်နှာများကို မှန်ကန်စွာ အပြင်သို့ လှည့်သည်၊ ဘောင်ပြားချပ်နေသော အပေါက်များကို ပိတ်သည်။ အန္တရာယ်ကင်းစွာ မပြင်နိုင်သည်များ (ပြားချပ်မဟုတ်သော အပေါက်၊ မျက်နှာများစွာ ဝေမျှသော အစွန်း) ကို သင့်အတွက် ချန်ထားပြီး ဘာကျန်သေးသည်ကို ပြောသည်။

## ပေါင်းခြင်း (Union)

1. solid နှစ်ခု သို့မဟုတ် ထို့ထက်ပို ရွေးပါ (တစ်ခုကို နှိပ်ပြီး၊ အခြားများကို {{key:Ctrl}}+နှိပ်ပါ)။
2. {{ui:Solids}} › {{ui:Union}}။

ထိုအရာများသည် group တစ်ခုအတွင်း solid တစ်ခုဖြစ်လာသည်။ ထပ်နေသော နေရာများတွင် အတွင်းရှိ မျက်နှာများ ပျောက်သွားသည်။

## နုတ်ခြင်း (Subtract)

1. {{ui:Solids}} › {{ui:Subtract}}။
2. **ဖယ်ရန်** (cutter) solid ကို နှိပ်ပါ။
3. **ဖြတ်ရန်** solid ကို နှိပ်ပါ။

ဒုတိယ solid ၏ ကျန်သည်ကို ထားသည်; cutter ကို သုံးပြီးသွားသည်။ ဥပမာ၊ block တစ်ခုတွင် အပေါက်ဖောက်ရန် ၎င်းကို တိုးဖောက်ပြီး ဝင်သော တိုင်ကို ဆွဲပါ၊ တိုင်ကို group ပြုလုပ်ပြီး block မှ နုတ်ပါ။

## ဖြတ်ယူခြင်း (Intersect)

solid နှစ်ခု သို့မဟုတ် ထို့ထက်ပို ရွေးပြီး {{ui:Solids}} › {{ui:Intersect}}။ အားလုံး မျှသော အပိုင်းကိုသာ ထားသည်။

## သိထားရမည့်အရာများ

- ရလဒ်သည် group အသစ် ဖြစ်သည်။ ပထမ solid ၏ အမည်၊ အရောင်နှင့် tag ကို ထိန်းထားသည် (Subtract အတွက်: ဖြတ်လိုက်သော တစ်ခု)။ ၎င်း၏ မျက်နှာများပေါ် ဆေးထားသော အရောင်များကို မထိန်းပါ။
- ရလဒ်၏ ပြားချပ်သော ဘေးများသည် မျက်နှာတစ်ခုစီ ဖြစ်သည်။ ကွေးသော ဘေးများသည် ဆွဲထားသည့် ပြားချပ် facet များအဖြစ် ထွက်သည်။
- group သို့မဟုတ် component တစ်ခု solid မဟုတ်လျှင် ကိရိယာက မည်သည့်တစ်ခုဖြစ်သည်ကို ပြောပြပြီး ဘာမျှ မပြောင်းပါ။ ပျောက်နေသော မျက်နှာ သို့မဟုတ် အတွင်း stray မျက်နှာကို ရှာပါ။
- group ဖွင့်ထားစဉ် ကိရိယာများသည် ထို group ရှိ group နှင့် component များပေါ် အလုပ်လုပ်သည်။
- ကိရိယာတစ်ခုစီသည် Undo အဆင့်တစ်ခု ဖြစ်သည်။
- solid ကိရိယာကို ပထမဆုံး သုံးသောအခါ ၎င်း၏ engine (manifold-3d) ကို load လုပ်ပြီး အချိန်အနည်းငယ် ကြာနိုင်သည်။
