ModelCraft သည် 2D CAD ရေးဆွဲချက်၊ site plan သို့မဟုတ် floor plan ၏ မျဉ်းများကို သွင်းနိုင်ပြီး၊ ၎င်းတို့ကို မြေပြင်ပေါ် ခင်းကာ အပေါ်တွင် မော်ဒယ်ဆွဲနိုင်သည်။

## ရေးဆွဲချက်ကို သွင်းခြင်း

1. **File** အုပ်စုရှိ {{ui:Import}} ကို နှိပ်ပါ (သို့မဟုတ် 3D view ပေါ် ဖိုင်ကို ချပါ)။
2. `.dwg` သို့မဟုတ် `.dxf` ဖိုင် ရွေးပါ။

   DWG ကြီးသည် အချိန်ယူသည်: ရောက်သည်အထိ status bar က "Reading plan.dwg…" ဟု ပြသည်။

3. ရေးဆွဲချက်က ၎င်း၏ ယူနစ်ကို မပြောလျှင် "Drawing units" ခေါင်းစဉ်ရှိ dialog က "What is one drawing unit?" ဟု မေးသည်။ {{ui:Inches}}၊ {{ui:Feet}}၊ {{ui:Millimeters}} သို့မဟုတ် {{ui:Meters}} ကို ရွေးပါ။ အမေရိကန် site plan အများစုကို feet ဖြင့်၊ ဗိသုကာ plan များကို inches ဖြင့်၊ မက်ထရစ် plan များကို millimeters ဖြင့် ဆွဲသည်။

   ရေးဆွဲချက်သည် မြေပြင်ပေါ် edge များ၏ group တစ်ခုအဖြစ် ရောက်လာပြီး ရွေးထားသည်၊ view က ၎င်းဆီ zoom လုပ်သည်။ status bar က မျဉ်း မည်မျှ ရောက်လာသည်ကို ပြသည်၊ ဥပမာ "Imported site.dwg: 1697 edges on the ground, in a group. Explode it to draw on it directly."

## ဘာတွေ ရောက်လာသလဲ

- မျဉ်းများ၊ polyline များ (ကွေးများပါ)၊ စက်ဝိုင်းများနှင့် ဆွဲကွေးများ၊ နှင့် ၎င်းတို့အတွင်းရှိ အရာအားလုံးပါသော block များ၊ **model space** မှသာ။ ကွေးများသည် တိုတောင်းသော မျဉ်းအပိုင်းများ ဖြစ်လာသည်။
- မျဉ်းများ၊ polyline များ၊ ဆွဲကွေးများ၊ စက်ဝိုင်းများ၊ ellipse များနှင့် spline များသည် မြေပြင်ပေါ် ပြားချပ်စွာ ဆင်းသက်ပြီး edge များအဖြစ် ရောက်သည်။
- **Hatch** များသည် မြေပြင်ပေါ် မျက်နှာများ ဖြစ်လာပြီး ၎င်းတို့၏ ကျွန်းများက အပေါက်များ ဖြစ်သည်၊ ထို့ကြောင့် hatch ထားသော နေရာကို ချက်ချင်း push/pull လုပ်နိုင်သည်။
- **3D face** များနှင့် solid fill များသည် မျက်နှာများ ဖြစ်လာပြီး; 3D face များသည် ၎င်းတို့၏ အမြင့်ကို ထိန်းသည်။
- **စာသား** (တစ်ကြောင်းစာသား၊ အကြောင်းများစွာ စာသားနှင့် attribute တန်ဖိုးများ) ကို ရိုးရှင်းသော single-stroke စာလုံးပုံစံဖြင့် edge များအဖြစ် ဆွဲသည်၊ စာသား၏ ကိုယ်ပိုင် အမြင့်၊ ထောင့်နှင့် ညှိနှိုင်းမှုဖြင့်။ ၎င်း၏ font သည် ရေးဆွဲချက်၏ မဟုတ်သဖြင့် စကားလုံးများ အနည်းငယ် ရှည်သို့မဟုတ် တိုသွားနိုင်သည်။ လက်ရှိ စာလုံးပုံစံတွင် ပုံသဏ္ဍာန် မရှိသော စာလုံးများကို အသေးစား အကွက်များအဖြစ် ဆွဲပြီး ရေတွက်သည်။
- **Dimension** များကို ရေးဆွဲချက်က ပြသည့်အတိုင်း ဆွဲသည် (ဆွဲကြိုး၊ မြားဦးနှင့် စာသား၊ edge နှင့် မျက်နှာအဖြစ်)။
- **Dynamic block** များသည် ရေးဆွဲချက်က ပြသည့်အတိုင်း ရောက်သည်: ချထားသော block တစ်ခုစီ၏ သိမ်းဆည်းထားသော visibility state၊ ထို state ၏ မျဉ်းများသာ။ status bar က ၎င်းတို့ကို ပြထားသော state နှင့် ၎င်းတစ်ခုစီ၏ အခြား state များနှင့်အတူ ဖော်ပြသည်၊ ဥပမာ "Receptacle shown as Duplex ×38, GFI ×7 (states: Duplex, GFI)"။ ModelCraft က state များကို မပြောင်းပါ။
- **3D solid များ၊ region များနှင့် body များ** (ရေးဆွဲချက်၏ ACIS ဒေတာ) သည် ၎င်းတို့၏ ကိုယ်ပိုင် group များအဖြစ် ရောက်သည်: ပိတ်ထားသော solid တစ်ခုသည် solid အဖြစ်၊ region သို့မဟုတ် ဖွင့်ထားသော body သည် မျက်နှာများအဖြစ်။ ပြားချပ်သော မျက်နှာများသည် အပြည့်အစုံ ရောက်သည်; ကွေးသော မျက်နှာများ (ဘူး၊ ကွန်း၊ ဘောလုံး၊ တော်ရစ်၊ ရိုးရှင်းသော spline မျက်နှာများ) သည် ကြားတွင် နူးညံ့သော အစွန်းများရှိ သေးငယ်သော တြိဂံများအဖြစ် ရောက်ပြီး၊ solid ၏ ကိုယ်ပိုင် အစွန်းများသာ ပေါ်သည်။ အခြားအမျိုးအစား မျက်နှာပေါ်ရှိ မျက်နှာကို ချန်ထားပြီး "Not drawn yet (3D solids): …" ဟု စာရင်းပြုသည်။
- မသွင်းပါ: အမှတ်များ၊ ဇယားများ၊ multileader များ၊ ပုံများနှင့် အခြား object အမျိုးအစားများ။ status bar က "Not imported: 12 POINT." ကဲ့သို့ အမျိုးအစားဖြင့် စာရင်းပြုသည်။ layout (paper space) ပေါ်ရှိ အရာအားလုံးကိုလည်း စာရင်းမပြဘဲ ချန်ထားသည်။
- Layer များကို မထိန်းသိမ်းပါ: မျဉ်းအားလုံး တူညီစွာ ရောက်သည်။

ရေးဆွဲချက်သည် ၎င်း၏ origin မှ ဝေးနေလျှင် (ဥပမာ state plane coordinates)၊ ၎င်းသည် သွင်းနိုင်သော်လည်း ModelCraft ၏ origin မှ ဝေးသော နေရာတွင် ရောက်နိုင်သည်။ origin မှ 10,000 km ထက် ဝေးသော ရေးဆွဲချက်များကို ငြင်းသည်: CAD program တွင် ရေးဆွဲချက်ကို 0,0 နှင့် နီးအောင် အရင် ရွှေ့ပါ။

## မျဉ်းများကို မျက်နှာများအဖြစ် ခြေရာခံခြင်း

သွင်းထားသော မျဉ်းများသည် ကိုယ်ပိုင်အားဖြင့် မျက်နှာများအဖြစ် သေသပ်စွာ ပိတ်ခဲ့သည်မြင့်သည်။ အလုပ်လုပ်နည်း နှစ်မျိုး ရှိသည်-

**Plan ကို underlay အဖြစ် ထားပါ (အကြံပြုသည်)**

1. Plan ကို ကိုယ်ပိုင် group အဖြစ် ထားပါ။
2. {{ui:Rectangle}} နှင့် {{ui:Line}} ဖြင့် သင့်အဆောက်အဦကို အပေါ်တွင် ဆွဲပါ၊ plan ၏ ထောင့်များ ("Endpoint") နှင့် အစွန်းများ ("On edge") သို့ ကပ်ပါ။
3. သင့်မျက်နှာများကို push/pull လုပ်ပြီး အထက်သို့ မြှင့်ပါ။ Plan သည် အောက်တွင် မထိရောက်ဘဲ ကျန်ပြီး၊ နောက်တွင် group တစ်ခုလုံးကို တစ်ချက်နှိပ်ဖြင့် ဖျက်နိုင်သည်။

ကပ်ခြင်းသည် group များကြား အလုပ်လုပ်သည်: plan ကို မဖွင့်ဘဲ ၎င်း၏ ထောင့်များသို့ ကပ်နိုင်သည်။

**Plan ၏ ကိုယ်ပိုင် မျဉ်းများပေါ် ဆွဲခြင်း**

1. Plan group ကို ရွေးပြီး {{ui:Explode}} ကို နှိပ်ပါ။ ၎င်း၏ မျဉ်းများသည် တည်ရှိသော edge များ ဖြစ်လာသည်။
2. ပိတ်ထားသော ပုံသဏ္ဍာန်သည် မျက်နှာ ဖြစ်သင့်သော နေရာတွင် {{ui:Line}} ဖြင့် အစွန်းတစ်ခုပေါ် မျဉ်းတစ်ကြောင်း ထောင့်မှ ထောင့်သို့ ဆွဲပါ။ ပုံသဏ္ဍာန် ပိတ်ပြီး ပြားချပ်သောအခါ မျက်နှာသည် များသောအားဖြင့် ဖြည့်ဝင်သည်။ မဖြည့်လျှင် ပုံသဏ္ဍာန်တွင် ကွက်လပ် သို့မဟုတ် ထပ်နေမှုကို ရှာပြီး ထိုနေရာကို ဆွဲကျော်ပါ။
3. Push/pull လုပ်ပါ။

၎င်းသည် သန့်ရှင်းသော plan တွင် အကောင်းဆုံး အလုပ်လုပ်သည်။ ရှုပ်ထွေးသော survey တွင်မူ အပေါ်မှ ခြေရာခံခြင်း ပိုမြန်သည်။

## ပြဿနာများ

- "This is a binary DXF. Save it as ASCII DXF and try again." DXF ကို CAD program မှ ASCII (text) အဖြစ် ပြန်သိမ်းပါ။
- "…has no lines, arcs or circles in model space to bring in." ရေးဆွဲချက်သည် layout များပေါ်တွင်သာ ရှိနိုင်သည်၊ သို့မဟုတ် စာသားနှင့် hatch သာ ဖြစ်နိုင်သည်။
- "This drawing could not be read (…). It may be damaged, or saved in a DWG version the reader does not handle…" ကွင်းများက အကြောင်းပြသည်၊ ဥပမာ "DWG version AC1009 is not supported"။ CAD program မှ DXF အဖြစ်၊ သို့မဟုတ် AutoCAD 2000 မှ 2018 အထိ DWG အဖြစ် သိမ်းပါ။
- Plan ၏ အရွယ်အစား မှားနေသည်: ယူနစ် မှားရွေးထားသည်။ Undo ({{key:Mod+Z}}) လုပ်ပြီး ပြန်သွင်းပါ၊ သို့မဟုတ် group ကို မှန်ကန်သော factor ဖြင့် [scale](topic:rotate-scale) လုပ်ပါ (feet နှင့် inches အကြား 12၊ inches နှင့် millimeters အကြား 25.4)။

## လက်ဖြင့် ရေးထားသော sketch ဓာတ်ပုံမှ

**File › Import a sketch photo…** က စက္ကူပေါ် sketch ၏ ဓာတ်ပုံကို ယူသည် (JPEG၊ PNG သို့မဟုတ် TIFF၊ ဖုန်းမှ တိုက်ရိုက်ကလည်း ရသည်) ပြီး မြေပြင်ပေါ် အစွန်းအမျိုးအစား တူညီသည်ကို ပြုလုပ်သည်။ စက္ကူ အမျိုးအစားကို ပြောပါ (သို့မဟုတ် စာရွက်ကို ရှာခွင့်ပေးပါ၊ A4 ဟု ယူသည်) နှင့် sketch ၏ စကေး၊ ဥပမာ 1 : 100။ စက္ကူ၏ အစွန်းကို ရှာပြီး ဓာတ်ပုံကို ဖြောင့်ထားသည်၊ မင်ကို မျဉ်းနှင့် ဆွဲကွေးများအဖြစ် ခြေရာခံသည်၊ မင်အရောင်တစ်ခုစီ (အနက်၊ အနီ၊ အပြာ၊ အစိမ်း) သည် ကိုယ်ပိုင် tag (**Sketch black**၊ **Sketch red**၊ …) ပါသော group တစ်ခု ဖြစ်လာပြီး ဓာတ်ပုံ၏ အမည်ဖြင့် group တစ်ခုတည်းအတွင်း ရောက်သည်။ ၎င်းသည် Undo အဆင့်တစ်ခု ဖြစ်ပြီး အရာအားလုံးကို ဤကွန်ပျူတာပေါ်တွင်သာ လုပ်သည်- ဘယ်နေရာသို့မှ မပို့ပါ။

စက္ကူ အစွန်းကို မတွေ့နိုင်သောအခါ ဓာတ်ပုံ တစ်ခုလုံးကို စက္ကူအဖြစ် ယူပြီး status line က ထိုသို့ ပြောသည်: သိသော အရာတစ်ခုကို တိုင်းပြီး မှားနေလျှင် group ကို စကေးချပါ။ အပေါ်ကဖော်ပြထားသည့်အတိုင်း မျဉ်းများကို မျက်နှာများအဖြစ် ခြေရာခံပါ။
