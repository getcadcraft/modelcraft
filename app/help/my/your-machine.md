{{ui:ဆက်တင်များ}} ({{key:Mod+,}}) ကိုဖွင့်ပြီး ဤအက်ပ်၏ ကိုယ်ပိုင်တက်ဘ်တွင် ဆက်နေကာ {{ui:ရိုက်ယူခြင်း}} သို့ လှိမ့်ပါ။ {{ui:သင့်စက်}} တွင် ဤဘရောက်ဇာက ရိုက်ယူရန် အက်ပ်အား သုံးခွင့်ပြုသည့်အရာများ ပါဝင်သည်။ ထိုအချက်အလက်များသည် သင့်ကွန်ပျူတာမှ တစ်ခုမျှ ထွက်သွားခြင်း မရှိပါ။

| အတန်း | အဓိပ္ပာယ် |
|---|---|
| {{ui:ဂရပ်ဖစ်}} | ဘရောက်ဇာက အစီရင်ခံသော ဂရပ်ဖစ်ကတ်။ "WebGPU" ဆိုသည်မှာ ရိုက်ယူလုပ်ငန်းအားလုံးကို လုပ်နိုင်သည်ဟု ဆိုလိုသည်။ "WebGL 2 only" ဆိုသည်မှာ တိုက်ရိုက်ကြည့်ရှုမှုနှင့် {{ui:ပုံရိပ် ထုတ်ရန်…}} တို့က ၎င်းကို သုံးသည်ဟု ဆိုလိုသည် (WebGL path tracer ဖြင့် အရည်အသွေးမြင့်)၊ သို့သော် WebGPU လိုအပ်သော ကြည့်ရှုမှုတွင် ရိုက်ယူခြင်းနှင့် render queue ကို မပေးပါ။ ဆော့ဖ်ဝဲ အစားထိုး ဖြစ်လျှင် အားလုံးကို ပရိုဆက်ဆာဖြင့် လုပ်ဆောင်သည်ဟု ဆိုလိုသည် |
| {{ui:ပရိုဆက်ဆာ}} | ဘရောက်ဇာက အစီရင်ခံသော ပရိုဆက်ဆာ core အရေအတွက် |

| {{ui:မျှဝေထားသော memory}} | စာမျက်နှာက workers များကြား memory ကို မျှဝေခွင့်ရှိ/မရှိ။ ဖွင့်ထားလျှင် core တိုင်းသည် scene တစ်ခုတည်းပေါ်တွင် လုပ်ဆောင်နိုင်သည်။ ပိတ်ထားလျှင် core တစ်ခုစီသည် ကိုယ်ပိုင်မိတ္တူ လိုအပ်သဖြင့် scene ကြီးသည် တစ်ချိန်တည်းတွင် core လျော့နည်းသာ ဝင်နိုင်သည် |
| {{ui:မြန်ဆန်သော ပရိုဆက်ဆာကုဒ်}} | ဘရောက်ဇာက WebAssembly ကုဒ်ကို မြန်ဆန်စွာ run/မ run ဆိုသည်။ မရှိလျှင် နှေးသော အရန်ကို သုံးသည် |

## အဆင့်

အဆင့်သည် [တိုက်ရိုက်ကြည့်ရှုမှု](topic:live-view) စတင်သည့်နေရာ ({{ui:ဤကွန်ပျူတာအတွက်}})၊ ဆွဲသော ပစ္စည်းအရေအတွက်၊ နှင့် ကြည့်ရှုမှုတွင် [subdivision surface](topic:modifiers#subdivision-surface) ပြနိုင်သော မျက်နှာပြင် အရေအတွက်ကို သတ်မှတ်သည်။ ထို့ကြောင့် built-in ဂရပ်ဖစ်ချစ်ပ် သို့မဟုတ် ဂရပ်ဖစ်ကတ် မရှိသော laptop သည် တုံ့ပြန်မှု ကောင်းနေသည်။ built-in သို့မဟုတ် ဖုန်းဂရပ်ဖစ်ချစ်ပ်၊ သို့မဟုတ် 4 GB သို့မဟုတ် ထိုထက်နည်းသော memory ရှိသည့် စက်သည် {{ui:ဂရပ်ဖစ်ကတ်၊ မြင့်}} ကို ဘယ်တော့မှ မရရှိပါ။

:::note
ဘရောက်ဇာများ ကွဲပြားသည်။ ကွန်ပျူတာတစ်ခုတည်းက ဘရောက်ဇာတစ်ခုတွင် WebGPU ပြနိုင်ပြီး နောက်တစ်ခုတွင် "WebGL 2 only" ပြနိုင်သည်။ Linux တွင် ဘရောက်ဇာအများစုတွင် WebGPU မရှိသေးပါ။
:::
