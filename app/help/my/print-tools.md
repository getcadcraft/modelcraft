3D ပရင့်အတွက် မော်ဒယ်ကို ပြင်ဆင်ရန် ကိရိယာလေးမျိုး ရှိသည်။ {{ui:Export}} › {{ui:Check for 3D printing (STL or 3MF)…}} ကို ဖွင့်ပါ; dialog ရှိ **ပရင့် ကိရိယာများ** အတန်းတွင် {{ui:Supports preview}}, {{ui:Wall thickness}}, {{ui:Hollow}} နှင့် {{ui:Repair}} ရှိသည်။ ကိရိယာတစ်ခုချင်းစီသည် view အပေါ်တွင် card အဖြစ် ဖွင့်လာသည်; {{ui:Close}} (ပေါင်းလက်ကုန်း) က ၎င်းနှင့် ၎င်း၏ အမှတ်အသားများကို ဖယ်သည်။ တစ်ကြိမ်တွင် card တစ်ခုသာ ပြသည်။

ကိရိယာတစ်ခုချင်းစီသည် ပရင့်ထုတ်မည့်အရာပေါ်တွင် အလုပ်လုပ်သည်: ရွေးထားသည့်အရာ၊ သို့မဟုတ် ရွေးမထားပါက မြင်ရသည့် အရာအားလုံး။ {{ui:Hollow}} နှင့် {{ui:Repair}} တို့သည် ၎င်းတို့က ပြောင်းလဲသောကြောင့် အုပ်စု၊ component သို့မဟုတ် mesh တစ်ခုကို ရွေးထားရန် လိုအပ်သည်။

## Supports preview

အထက်သို့ဒေါင်ကျင်းမှ **overhang angle** ထက် ပိုထွက်နေသော မျက်နှာများကို အနီရောင်ဖြင့် အရိပ်ထည့်ပြီး ရိုးရှင်းသော supports များကို ၎င်းတို့ထံမှ (လိမ္မော်ရောင်) bed သို့မဟုတ် ၎င်းအောက်ရှိ မော်ဒယ်အပိုင်းသို့ ဆွဲချထားသည်။

- **Overhang angle**: 45° သည် ပရင့်ထုတ်စက် အများစုက support မလိုဘဲ လုပ်နိုင်သော အတိုင်းအတာဖြစ်သည်။ တံတားကောင်းကောင်းဆောက်နိုင်သော ပရင့်အတွက် ၎င်းကို မြှင့်ပါ။
- **Columns**: overhang တစ်ခုစီအောက်တွင် 3 mm တိုင်း တိုင်တစ်ခု။ ခန့်မှန်းချက်တွင် ၎င်းတို့ကို support pattern 15% အဖြစ် ရေတွက်သည်။
- **Tree**: နီးကပ်သော အမှတ်များသည် ၎င်းတို့၏ အလယ်အောက်ရှိ တုတ်တစ်ခုသို့ ပေါင်းသည်; ခက်ရိုးတစ်ခုမှ 45° ထက် မပိုစောင်းပါ။ Tree များသည် ပုံမှန်အားဖြင့် ပစ္စည်းနည်းနည်းသုံးပြီး bed ကို နေရာနည်းနည်းဖြင့် ထိသည်။

Card က မည်မျှ မျက်နှာဧရိယာ support လိုသည်၊ support အမှတ် မည်မျှရှိသည်၊ နှင့် ၎င်းတို့က ပစ္စည်းမည်မျှ ယူမည်ကို ခန့်မှန်းသည်။ မော်ဒယ်ပေါ်တွင် ရပ်နေသော supports (bed မဟုတ်ဘဲ) များကို ရေတွက်သည်: ၎င်းတို့သည် ထိုနေရာတွင် အမှတ်များ ကျန်ခဲ့စေသည်။ {{ui:Settings}} တွင် ပရင့် bed ကို ရွေးထားပါက bed ကို မော်ဒယ်အောက်တွင် ဆွဲပြသည်။

:::note
ဤသည်မှာ preview ဖြစ်ပြီး slicer မဟုတ်ပါ: အစစ်အမှန် supports ကို သင့် slicer က ဆုံးဖြတ်သည်။ အလွန်ကြီးသော overhang တစ်ခုတွင် support အမှတ်များကို ကျယ်ကျယ်ပြန့်ပြန့် ခွဲထားသဖြင့် preview မြန်ဆန်နေသည်; card က ထိုအကြောင်းကို ပြောသည်။
:::

## Wall thickness

မျက်နှာတစ်ခုစီကို solid ၏ တစ်ဖက်သို့ တိုက်ရိုက် ဖြတ်ပြီး တိုင်းတာသည်။ **thinnest wall to allow** အောက်ရှိ နံရံများကို အနီရောင်ဖြင့် ပြပြီး ထိုတန်ဖိုး၏ တစ်ဝက်ခွဲ တစ်ဆဲ့ဆတစ်ဆ အောက်ရှိ နံရံများကို လိမ္မော်ရောင်ဖြင့် ပြသည်: ၎င်းတို့ ပရင့်ထွက်နိုင်သော်လည်း အားနည်းနိုင်သည်။

ပါးသော နေရာများကို အပါးဆုံးက ပထမ၊ ဘယ်လောက်ပါးပြီး ဘယ်လောက်ကြီးသည်ကို ပြသထားသည်။ {{ui:Show}} က ကင်မရာကို ထိုနေရာသို့ လှည့်ပေးသည်။

ပရင့်ထုတ်စက်တစ်ခုက nozzle အချင်း နှစ်ဆခန့်ထက် ပါးသော နံရံကို မပြုလုပ်နိုင်ပါ: သာမန် 0.4 mm nozzle အတွက် 0.8 mm (စတင်တန်ဖိုး)။ Resin ပရင့်များက ပိုနည်းသည်; သင့်ပရင့်၏ လမ်းညွှန်ကို စစ်ပါ။

မော်ဒယ်အလွန်ကြီးပါက မျက်နှာအချို့သာ ray ကို ပစ်ပြီး ကျန်တာများက ၎င်းတို့၏ အိမ်နီးချင်းများ၏ ထူထဲမှုကို ယူသည်; card က မည်မျှ တိုင်းတာခဲ့သည်ကို ပြောသည်။

## Hollow

Hollowing သည် အပြင်ဘက်ကို မူလအတိုင်းထားပြီး အတွင်းပိုင်းကို ဖယ်ထုတ်ကာ သင်တောင်းသော အထူရှိသည့် နံရံများကို ချန်ထားသည်။ Resin ပရင့်များသည် resin ပိုနည်းသုံးပြီး build plate ကို ပိုနည်းဆွဲသည်; filament ပရင့်များသည် infill ထက် plastic ပိုနည်းသုံးသည်။

1. အုပ်စု၊ component သို့မဟုတ် mesh ကို ရွေးပြီး {{ui:Hollow}} ကို ဖွင့်ပါ။
2. **wall** (စတင်တန်ဖိုး 2 mm) နှင့် **drain holes** ၏ အကျယ်ကို သတ်မှတ်ပါ။
3. Resin ပရင့်အတွက် {{ui:Place a drain hole}} ကို နှိပ်ပြီး မော်ဒယ်၏ အပြင်ဘက်တွင် သွားရမည့်နေရာကို နှိပ်ပါ: အောက်ပိုင်း၊ build plate အနီး၊ အရည် resin ထွက်သွားစေရန်။ လိုသလောက် ထားပါ; တစ်ခုစီသည် အပြာရောင် အဝိုင်းအဖြစ် ပေါ်ပြီး {{ui:Remove}} ဖြင့် စာရင်းပြုသည်။
4. {{ui:Preview}} က hollowing က ဘယ်လောက်ဖယ်ထုတ်သည်ကို ပြသည်။
5. {{ui:Hollow it}} က ပြောင်းလဲမှုကို လုပ်သည်: {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သော အဆင့်တစ်ခုတည်း။

ရလဒ်သည် 3D-print စစ်ဆေးမှု လက်ခံမည့် ပိတ်ထားသော solid တစ်ခုဖြစ်သည်: ModelCraft က ပထမ စစ်ဆေးပြီး မအောင်ပါက ဘာမျှ မပြောင်းပါ။ မော်ဒယ်သည် နံရံနှစ်ခုထက် ပါးသည့်နေရာတွင် solid ဆက်နေသည်။ ရလဒ်သည် မျက်နှာပြားများ တစ်ခုစီ မျက်နှာတစ်ခုတည်းဖြစ်သော အုပ်စုတစ်ခု ဖြစ်သဖြင့် {{ui:Push/pull}} ဖြင့် ဆက်ပုံဖော်နိုင်သည်; fine grid တွင် ကွေးသော အပိုင်းကို hollow လုပ်ပါက မျက်နှာများ အလွန်များသဖြင့် mesh ဖြစ်သွားတတ်ပြီး status line က မည်သည့်ပုံစံဖြစ်သည်ကို ပြောသည်။

:::tip
အများစု ပုံသဏ္ဍာန်များအတွက် အတွင်းပိုင်းသည် အပြင်ဘက်ကို နံရံအတိုင်း အတိအကျ ဝင်ရွှေ့ထားခြင်းဖြစ်သည်။ ထောင့်များ သို့မဟုတ် ပါးသောအပိုင်းများက ထိုသို့ မဖြစ်နိုင်သောအခါ ModelCraft က fine grid ပေါ်တွင် အပြင်ဘက်ကို နံရံ၏ အကွာအဝေးဖြင့် လိုက်ပြီး card က ၎င်း၏ နီးကပ်မှု (မီလီမီတာ၏ အစိတ်အပိုင်းအတွင်း) ကို ပြသည်။
:::

## Repair

{{ui:Repair}} သည် ရွေးထားသော အပိုင်းကို ပရင့်ထုတ်စက်၏ slicer က ကြည့်သည့်နည်းဖြင့် ကြည့်ပြီး လုံခြုံစွာ ပြင်နိုင်သည်များကို ပြင်ကာ ပြင်ဆင်မှုတိုင်းကို စာရင်းပြုသည်:

| ပြင်သည် | ဆိုလိုချက် |
|---|---|
| ဧရိယာမရှိသော တြိဂံများ | ထုတ်ချန်သည် |
| နှစ်ကြိမ်ဆွဲထားသော တြိဂံ | မိတ္တူတစ်ခုကို ထားပြီး အထူမရှိဘဲ နောက်ကျောချင်းကပ်နေသော မျက်နှာကို ဖယ်သည် |
| 0.5 mm အောက် ကွဲထွက်နေသော အပိုင်းများ | ဖယ်ရှားသည် |
| မှားသော ဦးတည်ချက်ရှိ တြိဂံများ | အိမ်နီးချင်းများနှင့် ကိုက်ညီအောင် လှည့်သည် |
| အပေါက်များ၊ ပြားသည်ဖြစ်စေ မဟုတ်စေ | အပေါက်တစ်ခုစီ၏ အလယ်မှ တြိဂံအသစ်များ ပန်ကာပုံဖြင့် ပိတ်သည် |
| အပြင်ဘက်ပြန်ဖြစ်နေသော အပိုင်း | အပြင်ဘက်သို့ လှည့်သည် (အခြားအပိုင်းအတွင်းရှိ အတွင်းပိုင်းကို ထားခဲ့သည်: ၎င်းသည် အတွင်းသို့ မျက်နှာမူရန် ဖြစ်သည်) |

{{ui:Fix the safe ones}} က ၎င်းတို့အားလုံးကို {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သော အဆင့်တစ်ခုတည်းဖြင့် လုပ်ပြီး status line က ပြင်ဆင်မှုတိုင်းကို စာရင်းပြုသည်။ ပြင်ပြီးသော အပိုင်းသည် မျက်နှာပြားများ တစ်ခုစီ မျက်နှာတစ်ခုတည်းဖြစ်သော အုပ်စုတစ်ခု ဖြစ်လာသည်။ အကယ်၍ ၎င်းသည် ပိတ်မသွားသေးပါက (**Left for you** အောက်ရှိ တစ်ခုခု ကျန်နေသည်) သို့မဟုတ် အုပ်စုအတွက် မျက်နှာများ အလွန်များပါက mesh ဖြစ်သွားသည်: မျက်နှာများက တြိဂံအဖြစ်ကျန်ပြီး ပြားနေသော မျက်နှာများက ပြားနေဆဲ ပုံရသည်။ Status line က မည်သည့်ပုံစံဖြစ်သည်ကို ပြောသည်။ {{ui:Join overlapping parts}} လည်း အလားတူ အလုပ်လုပ်သည်။

လုံခြုံစွာ မပြင်နိုင်သောအရာများကို **Left for you** အောက်တွင် စာရင်းပြုပြီး view တွင် ခရမ်းရောင်ဖြင့် အမှတ်အသားပြုသည်၊ {{ui:Show}} နှင့်အတူ:

- **မျက်နှာသုံး ခု သို့မဟုတ် ပိုတွေ့ဆုံသော အစွန်းများ**: မျက်နှာဘယ်ဟာ ပိုင်သလဲ ဆုံးဖြတ်ပြီး အခြားများကို ဖျက်ပါ။
- **ကိုယ်တိုင် ဖြတ်ကျော်သွားသော အပိုင်း**: ထိုအပိုင်းကို ရွှေ့ပါ သို့မဟုတ် ပြန်ဆွဲပါ။ [မျက်နှာ ဖြတ်ကျော်ခြင်း](topic:intersect) ကို ကြည့်ပါ။
- **ပိတ်ရန် အလွန်ကြီးသော သို့မဟုတ် ရှုပ်ထွေးသော အပေါက်များ**: ၎င်းတို့ပေါ်မှာ မျက်နှာများ ဆွဲပါ။
- **ထပ်နေသော သီးခြားအပိုင်းများ**: slicer များက ၎င်းတို့ကို ဘယ်လိုဆိုစေ ပေါင်းပေးသည်။ {{ui:Join overlapping parts}} က ၎င်းတို့ကို ပိတ်ထားသော ခန္ဓာကိုယ်တစ်ခုဖြစ်အောင် လုပ်သည် (ထိတွေ့ရာ မျက်နှာများကို ပြန်တည်ဆောက်သဖြင့် ၎င်းသည် သီးခြား ခလုတ်ဖြစ်ပြီး အလိုအလျောက် တစ်ခါမှ မလုပ်ပါ)။

Push/pull အုပ်စုများအတွက် {{ui:Entity info}} › {{ui:Show problems}} / {{ui:Fix}} တွင် တစ်ခုချင်းစီ ပြင်နိုင်သည်၊ ၎င်းက သင်ဆွဲထားသော မျက်နှာများကို ထိန်းထားသည်။ [Solid ကိရိယာများ](topic:solids) ကို ကြည့်ပါ။
