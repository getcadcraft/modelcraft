ဆွဲသော သို့မဟုတ် တည်းဖြတ်သော ကိရိယာ အလုပ်လုပ်နေစဉ် ModelCraft သည် မျက်နှာပြင်အောက်ရှိအရာကို ကြည့်ပြီး အနီးဆုံး အသုံးဝင်ဆုံးအရာသို့ ကပ်သည်။ အမှတ်အသားက ၎င်းတွေ့သည်ကို ပြပြီး ဘယ်ဘက်အောက်ရှိ ထိပ်က အမည်ပေးသည်။

## အမှတ်အသားများနှင့် ထိပ်များ

| ထိပ် | အမှတ်အသား | ကပ်သည့်အရာ |
|---|---|---|
| Endpoint | အစိမ်း စက်ဝိုင်း | အနားတစ်ခု၏ အဆုံး |
| Midpoint | ပြာပြာ စက်ဝိုင်း | အနားတစ်ခု၏ အလယ် |
| Center of face | အပြာ စက်ဝိုင်း | ညွှန်ပြချက်အောက်ရှိ မျက်နှာ၏ အလယ် |
| Guide point | မီးခိုးရောင် | တိပ်အတိုင်းတာ ထားခဲ့သော လမ်းညွှန်အမှတ် |
| Origin | ရွှေဝါရောင် | အနီ၊ အစိမ်းနှင့် အပြာ ဝင်ရိုးများ တွေ့သည့်နေရာ |
| On red axis / On green axis / On blue axis | ထိုအရောင်ဖြင့် မျဉ်း | သင့်စတင်အမှတ်မှ ထိုဦးတည်ချက်အတိုင်း မျဉ်း |
| Parallel to edge / Perpendicular to edge | စူးရောင် မျဉ်း | သင့်စတင်အမှတ်မှ မှတ်ထားသော အနားနှင့် အပြိုင် သို့မဟုတ် ထောင့်မှန်သော မျဉ်း (အောက်တွင် ကြည့်ပါ) |
| Locked | စူးရောင် မျဉ်း | မြှားကီး သို့မဟုတ် {{key:Shift}} ဖြင့် သော့ခတ်ထားသော ဦးတည်ချက် |
| On edge | အနီ စတုရန်း | အနားတစ်လျှောက် မည်သည့်နေရာမဆို |
| On guide | မီးခိုးရောင် | လမ်းညွှန်မျဉ်းတစ်လျှောက် မည်သည့်နေရာမဆို |
| On face | အပြာ စိန်ပုံ | မျက်နှာပေါ် မည်သည့်နေရာမဆို |
| On plane | မရှိ | ညွှန်ပြချက် အလွတ်နေရာပေါ်တွင် ရှိသောအခါ သင် စတင်ခဲ့သော ပလိန်း |
| On the ground | မရှိ | ဘာမျှ မရှိသောအခါ မြေပြင် (အနီ-အစိမ်း ပလိန်း) |

သင့်စတင်အမှတ်မှ ဝင်ရိုးမျဉ်းသည် အနား သို့မဟုတ် လမ်းညွှန်ကို ဖြတ်သောအခါ ModelCraft သည် ဖြတ်သည့်နေရာသို့ ကပ်ပြီး ထိပ်က နှစ်ခုလုံးကို အမည်ပေးသည်၊ ဥပမာ "On red axis, on edge"။

## ဘယ် snap က အနိုင်ရသလဲ

1. ခန့်မှန်းခြေ 12 ပစ်ဆယ်အတွင်း **အမှတ်များ**: အဆုံးမှတ်များ ဦးစွာ၊ ထို့နောက် လမ်းညွှန်အမှတ်များ၊ အလယ်များ၊ ညွှန်ပြချက်အောက်ရှိ မျက်နှာ၏ အလယ်နှင့် မူလအမှတ်။
2. သင့်စတင်အမှတ်မှ **ဦးတည်ချက်များ**: အနီ၊ အစိမ်းနှင့် အပြာ ဝင်ရိုးများ၊ နှင့် မှတ်ထားသော အနားနှင့် အပြိုင် သို့မဟုတ် ထောင့်မှန်။
3. **အနားတစ်ခု** သို့မဟုတ် လမ်းညွှန်မျဉ်း။
4. **မျက်နှာတစ်ခု**။
5. **ဆွဲမည့် ပလိန်း** သို့မဟုတ် မြေပြင်။

မျက်နှာတစ်ခု နောက်ကွယ်ရှိ အရာများသည် ဘယ်တော့မှ မကပ်ပါ။ သင်လိုချင်သော အမှတ်ကို မြင်နိုင်ရန် လှည့်ကြည့်ပါ။

## မျက်နှာတစ်ခုပေါ် အမှတ်မှ ဆွဲခြင်း

ထောင့်၊ အလယ်မှတ်၊ အနား သို့မဟုတ် မျက်နှာ၏ အလယ်မှ စတင်သော {{ui:Rectangle}}၊ {{ui:Circle}} သို့မဟုတ် {{ui:Polygon}} ကို **ညွှန်ပြချက်အောက်ရှိ မျက်နှာ၏ ပလိန်းတွင်** ဆွဲပြီး ထိုမျက်နှာကို ဖြတ်သည်။ အနားတစ်ခုသည် မျက်နှာနှစ်ခုပိုင်သဖြင့် အနား၏ ညွှန်ပြချက်ရှိဘက်က ဆုံးဖြတ်သည်- ရှည်သော သေတ္တာ၏ အဆုံးပေါ် ဆွဲရန်၊ ထိုအနားတစ်ခု၏ အလယ်မှ စတင်ပြီး ညွှန်ပြချက်ကို အဆုံးမျက်နှာ၏ အတွင်းဘက်တွင် ထားပါ။

## ပြား နှင့် ထောင့်မှန်

ModelCraft သည် သင်၏ ပထမနှိပ်မှုမတိုင်မီ ညွှန်ပြချက် **နောက်ဆုံး ဖြတ်ခဲ့သော အနား** ကို မှတ်ထားသည်။ ထောင့် သို့မဟုတ် အနားပေါ်တွင် စတင်ခြင်းသည် ထိုအနားကို ဖြတ်ခဲ့သည်ဟု ရေတွက်သည်။ ကိရိယာ အလုပ်လုပ်ပြီးနောက် သင် ကျော်ဖြတ်သော အခြားအနားများသည် ၎င်းကို အစားထိုးမည် မဟုတ်ပါ။

ရှိပြီးသား အနားနှင့် အပြိုင် မျဉ်းတစ်ကြောင်း ဆွဲရန်:

1. {{key:L}} ကို နှိပ်ပြီး တူစေလိုသော အနားပေါ် ညွှန်ပြပါ။
2. စတင်အမှတ်သို့ ရွှေ့ပါ၊ နိုင်လျှင် တခြားအနားများကို မဖြတ်ဘဲ၊ ပြီးနှိပ်ပါ။
3. ထိုအနားနှင့် အပြိုင် ဦးတည်ချက်သို့ ရွှေ့ပါ။ မျဉ်းသည် စူးရောင် ဖြစ်ပြီး ထိပ်က "Parallel to edge" ဟု ပြောသည်။ ထောင့်မှန် (Perpendicular) ကလည်း အလားတူ အလုပ်လုပ်သည်၊ ဆွဲနေသော ပလိန်းအတွင်းတွင်။

မှားသော အနားကို မှတ်မိထားလျှင် {{key:Esc}} ကို နှိပ်ပြီး မှန်ကန်သော အနားပေါ် ညွှန်ပြကာ ထပ်စတင်ပါ။

## ဦးတည်ချက်ကို သော့ခတ်ရန်

ကိရိယာ၏ ပထမနှိပ်မှုပြီးနောက် နောက်အမှတ်ကို မျဉ်းတစ်ကြောင်းတည်း ထားနိုင်သည်:

| ကီး | သော့ခတ်သည့်အရာ |
|---|---|
| {{key:Right}} | အနီ ဝင်ရိုး |
| {{key:Left}} | အစိမ်း ဝင်ရိုး |
| {{key:Up}} | အပြာ ဝင်ရိုး (တိုက်ရိုက် အပေါ်သို့) |
| {{key:Down}} | မှတ်ထားသော အနားနှင့် အပြိုင် (အထက်တွင် ကြည့်ပါ) |

ဖြုတ်ရန် တူညီသော မြှားကို ထပ်နှိပ်ပါ။ အခြေအနေ ဘားက "Locked to the red axis. Press the same arrow to unlock." ဟု ပြသည်။

သော့ခတ်ထားစဉ် အမှတ်သည် ညွှန်ပြချက် ရှိရာဘက်သို့ မျဉ်းတစ်လျှောက် ရွေ့သည်၊ နှင့် ညွှန်ပြသော အမှတ်များနှင့် ဆက်တိုက် ညီညာနေဆဲ ဖြစ်သည်: အခြားသေတ္တာ၏ ထောင့်ပေါ် ညွှန်ပြပြီး ထိုထောင့်အထိ အနီဦးတည်ချက်အတိုင်း မျဉ်းဆွဲပါ။

**{{key:Shift}}** က သင်ယခု ကပ်နေသော ဦးတည်ချက် (ဝင်ရိုး သို့မဟုတ် အပြိုင်) ကို သင် ကိုင်ထားသမျှ ကာလ သော့ခတ်သည်။ လွှတ်လိုက်လျှင် ဖြုတ်သည်။

သော့ခတ်ခြင်းများသည် {{ui:Line}}၊ {{ui:Rectangle}}၊ {{ui:Circle}}၊ {{ui:Polygon}}၊ {{ui:Move}}၊ {{ui:Scale}} နှင့် {{ui:Tape}} တွင် အလုပ်လုပ်သည်။ ပထမနှိပ်မှု မတိုင်မီ မြှားကီးများက မြင်ကွင်းကို လှည့်သည်။

## အုပ်စုတစ်ခု အတွင်း

အုပ်စု သို့မဟုတ် အစိတ်အပိုင်း အတွင်း တည်းဖြတ်နေစဉ် ဝင်ရိုးများသည် အုပ်စု၏ ကိုယ်ပိုင် ဝင်ရိုးများ ဖြစ်သည် (၎င်းနှင့်အတူ ရွှေ့ပြီး လှည့်ထားလျှင် လှည့်သည်)။ Snap များသည် အုပ်စုပြင်ပရှိ အမှတ်များနှင့် အနားများကို ဆက်ရှာသည်၊ ထို့ကြောင့် မော်ဒယ်၏ အခြားအရာများနှင့် ညီညာအောင် ထားနိုင်သည်။
