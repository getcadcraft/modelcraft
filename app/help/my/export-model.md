ပို့ထုတ်ခြင်းသည် မော်ဒယ်ကို အခြားဖော်မတ်တစ်ခုအဖြစ် မိတ္တူပြုလုပ်သည်။ သင့် `.modelcraft` ဖိုင်ကိုလည်း ထိန်းသိမ်းထားပါ: ၎င်းသည် အရာအားလုံးကို ထိန်းထားသော တစ်ခုတည်းသော ဖိုင်ဖြစ်ပြီး ModelCraft က တိုက်ရိုက် ဖွင့်နိုင်သော တစ်ခုတည်းသော ဖိုင်ဖြစ်သည်။

## ပို့ထုတ်ရန်

1. ဦးစွာ သိမ်းပါ ({{key:Mod+S}})၊ သင့်အလုပ်ဖိုင် ဘေးကင်းစေရန်။
2. {{ui:File}} အုပ်စုရှိ {{ui:Export}} ကို နှိပ်ပါ။
3. ဖော်မတ်ကို ရွေးပါ။ browser က မော်ဒယ်နာမည်နှင့်တူသော အမည်ဖြင့် ဒေါင်းလုဒ်ဆွဲသည်။

မော်ဒယ်တစ်ခုလုံးကို ပို့ထုတ်သည်။ အပိုင်းတစ်ခုကိုသာ ပို့လိုပါက သိမ်းပါ၊ ကျန်သည်များကို ဖျက်ပါ၊ ပို့ပါ၊ ထို့နောက် ပြန်ဖျက်ပါ သို့မဟုတ် ပြန်ဖွင့်ပါ။

## ဘယ်ဖော်မတ်

| သင်လိုချင်သည် | ရွေးပါ | မှတ်ချက် |
|---|---|---|
| အခြား 3D modeler တွင် ဖွင့်ရန် | {{ui:Collada (.dae)}} | အုပ်စုများ၊ အုပ်စု အတွင်းအုပ်စုများ၊ အစိတ်အပိုင်းများ (မျှဝေထား၊ မိတ္တူမဟုတ်)၊ အမည်များနှင့် အရောင်များကို ထိန်းထားသည်။ Z အပေါ်၊ မီတာ။ |
| Render ပြုလုပ်ရန်၊ သို့မဟုတ် visualization ပရိုဂရမ်တွင် သုံးရန် | {{ui:OBJ (.obj)}} သို့မဟုတ် {{ui:glTF binary (.glb)}} | OBJ သည် အကျယ်ဆုံး ဖတ်သည်; အုပ်စုနေရာချထားမှု တစ်ခုစီကို object သီးခြား အဖြစ် ရေးသော်လည်း အရောင် နှင့် မျှဝေထားသော အစိတ်အပိုင်း မရှိပါ။ glTF က အစိတ်အပိုင်းနှင့် အရောင်များကို ထိန်းထားသည်။ |
| ဝဘ်တွင် တင်ရန်၊ game engine သို့မဟုတ် AR တွင် ထားရန် | {{ui:glTF binary (.glb)}} | အရာအားလုံးပါသော ဖိုင်တစ်ခုတည်း။ |
| 3D ဖြင့် ပရင့်ထုတ်ရန် | {{ui:Check for 3D printing (STL or 3MF)…}} | မော်ဒယ် ပိတ်ထားခြင်းနှင့် မှန်ကန်သော ဘက်သို့ လှည့်ခြင်းကို စစ်ဆေးပြီး၊ မီလီမီတာဖြင့် STL သို့မဟုတ် 3MF ရေးသည်။ [3D ပရင့်အတွက် မော်ဒယ် ပြင်ဆင်ခြင်း](topic:print-3d) ကို ကြည့်ပါ။ {{ui:STL for printing (.stl, millimeters)}} သည် စစ်ဆေးမှုမပါဘဲ မော်ဒယ်တစ်ခုလုံးကို ရေးသည်။ |
| BimCraft သို့မဟုတ် အခြား BIM ပရိုဂရမ်တွင် ဖွင့်ရန် | {{ui:IFC for BimCraft (.ifc)}} | အဆင့်မြင့်ဆုံး အုပ်စု သို့မဟုတ် အစိတ်အပိုင်းတိုင်းသည် အဆောက်အအုံ ဒြပ်စင် တစ်ခု ဖြစ်လာသည်။ |

အခြေအနေဘားက ပို့ထုတ်ချက်တိုင်းကို အတည်ပြုသည်၊ ဥပမာ "House.stl ကို ပို့ပြီးပြီ (မီလီမီတာ)။" သို့မဟုတ် "House.dae ကို ပို့ပြီးပြီ (Collada 1.4.1၊ Z အပေါ်၊ မီတာ၊ အစိတ်အပိုင်းများ မျှဝေထားဆဲ)။"

## ပို့ခြင်းမတိုင်မီ

- **သင့်အရာများကို အုပ်စုဖွဲ့ပါ။** Collada၊ glTF နှင့် IFC သည် အုပ်စုများနှင့် အစိတ်အပိုင်းများကို သီးခြား object များအဖြစ် ထိန်းထားသည်။ ကပ်လျက်မဟုတ်သော ဂျီသြမေတြီသည် ဘလော့ခ်တစ်ခုအဖြစ် ထွက်သည်; IFC တွင် "Loose geometry" ဟု အမည်ရှိသော ဒြပ်စင် တစ်ခု ဖြစ်လာသည်။
- **အမည်ပေးပါ။** အုပ်စုနှင့် အစိတ်အပိုင်း အမည်များသည် Collada နှင့် IFC ထဲ ဝင်သွားသည်၊ ထို့ကြောင့် "North wall" ဟု ခေါ်သော နံရံသည် "North wall" ဟုပင် ရောက်သည်။
- **မျက်နှာပြင် ဦးတည်ချက် စစ်ဆေးပါ။** အပြင်ဘက်တွင် မီးခိုးပြာ-အပြာရောင် ပြသော မျက်နှာပြင်များသည် ပို့ထုတ်ချိန်တွင် အတွင်းသို့ လှည့်နေမည်။ {{ui:Reverse face}} ဖြင့် ပြင်ပါ ([ဖျက်ရန်နှင့် သန့်ရှင်းရန်](topic:erase#a-face-facing-the-wrong-way) ကို ကြည့်ပါ)။
- **ပရင့်ထုတ်ရန်အတွက်** အပိုင်းများကို ပိတ်ထားသော solid များ ဖြစ်အောင် ပြုလုပ်ပါ: အုပ်စုတစ်ခုစီကို ရွေးပြီး {{ui:Entity info}} က "Solid: Yes" ဟု ပြသခြင်းကို စစ်ဆေးပါ။ ထို့နောက် မော်ဒယ်ကို ပရင့်ထုတ်မည့် အရွယ်အစားသို့ scale လုပ်ပါ၊ သို့မဟုတ် printer software တွင် scale လုပ်ပါ။

## BimCraft သို့ မော်ဒယ် ပို့ရန်

1. အဆောက်အအုံ အစိတ်အပိုင်းတိုင်းကို အုပ်စု သို့မဟုတ် အစိတ်အပိုင်း ဖြစ်အောင် လုပ်ပြီး အမည်ပေးပါ။
2. {{ui:Export}} ကို ရွေးပြီး၊ ထို့နောက် {{ui:IFC for BimCraft (.ifc)}} ကို ရွေးပါ။
3. ဒေါင်းလုဒ်ဆွဲထားသော `.ifc` ဖိုင်ကို BimCraft တွင် ဖွင့်ပါ။

အစီအစဉ်ကြမ်းအတွက် ၎င်းအစား {{ui:Export}} › {{ui:Massing to BimCraft…}} ကို သုံးပါ: အုပ်စုတစ်ခုစီသည် ထပ်များ၊ ထပ်ဧရိယာများနှင့် ထုထည်ပါသော massing ရွေးချယ်မှု တစ်ခုအဖြစ် ထွက်သည်။ [BimCraft သို့ massing ပို့ရန်](topic:massing-to-bimcraft) ကို ကြည့်ပါ။

ရိုးရိုး IFC ပို့ထုတ်ခြင်းတွင် ဆော့ဖ်ဝဲနှစ်ခုကြား တိုက်ရိုက်ချိတ်ဆက်မှု မရှိပါ။ IFC တွင် ထပ်တစ်ခုသာ ရှိပြီး၊ ဒြပ်စင်တိုင်းသည် အမျိုးအစား သို့မဟုတ် ဂုဏ်သတ္တိ မပါသော ယေဘုယျ building element proxy ဖြစ်သည်: ပုံသဏ္ဍာန်နှင့် အမည်သာ ပါသည်။ ပိတ်ထားသော အုပ်စုများသည် solid ပုံသဏ္ဍာန်များ ဖြစ်လာသည်; ဖွင့်ထားသောများသည် မျက်နှာပြင်များ ဖြစ်လာသည်။

## မျဉ်းများ မျက်နှာပြင်မရှိဘဲ

မည်သည့်မျက်နှာပြင်၏ အစိတ်အပိုင်းမဟုတ်သော အနားများ (လမ်းညွှန်ဟန် မျဉ်းများ၊ သွင်းထားသော site plan) သည် OBJ နှင့် Collada တွင် မျဉ်းအဖြစ် ထွက်သည်။ glTF နှင့် STL တွင် ထည့်ရန်နေရာ မရှိ၍ ချန်ထားသည်။ လမ်းညွှန်များနှင့် scene များကို မည်သည့်ဖော်မတ်သို့မျှ ပို့ထုတ်ခြင်း မရှိပါ။

## မြင်ကွင်းကို ပုံအဖြစ် သိမ်းရန်

{{ui:Export}} › {{ui:Image of the view (.png)}} သည် 3D မြင်ကွင်းက ပြသသည့်အတိုင်း၊ မျက်နှာပြင်ပေါ်ရှိ အရွယ်အစားဖြင့် သိမ်းသည်။ {{ui:Image at twice the size (.png)}} သည် နှစ်ဆ ကျယ်ပြီး နှစ်ဆ မြင့်သော ပုံကို သိမ်းသည် (ပရင့် သို့မဟုတ် ပြတ်သားသော slide အတွက်)၊ အရွယ်အစားများနှင့် အမှတ်အသားများကို ဆန့်ထုတ်မည့်အစား ထိုအရွယ်တွင် ပြန်ဆွဲသည်။

နေရောင်ခြည်ရှိသော ပုံ (ကောင်းကင်၊ နေ၊ နုသော အရိပ်၊ ဖန်သားပြင်) လိုပါက {{ui:Export}} › {{ui:Render a picture…}} ကို သုံးပါ: [ပုံ ထုတ်ရန်](topic:render) ကို ကြည့်ပါ။

သန့်ရှင်းသော ပုံအတွက် ပထမ [တင်ပြမှု မြင်ကွင်း](topic:styles-shadows#presentation-view) ({{key:Shift+P}}) ကို ဖွင့်ပါ: ဝင်ရိုးများ၊ လမ်းညွှန်များ၊ section အနားများနှင့် ရွေးထားမှုကို ဖယ်ထားသည်။ ကင်မရာ၊ style နှင့် အရိပ်များကို လိုချင်သည့်အတိုင်း သတ်မှတ်ပါ၊ သို့မဟုတ် [scene](topic:scenes) သို့ သွားပါ; scene များ၏ ရွေ့လျားသော ဇာတ်ကားကို သိမ်းလိုပါက {{ui:Scenes}} ပန်နယ်ရှိ {{ui:Export animation}} ကို သုံးပါ။

## မြင်ကွင်းကို ပရင့်ထုတ်ရန် သို့မဟုတ် PDF အဖြစ် သိမ်းရန်

- {{ui:Export}} › {{ui:PDF of the view (.pdf)}} သည် စာမျက်နှာတစ်ခုတည်း PDF ကို သိမ်းသည်: မြင်ကွင်းကို မျက်နှာပြင် အရွယ်အစား၏ နှစ်ဆဖြင့်၊ အတိုင်းအတာများပါသော၊ A4 စာမျက်နှာ (မော်ဒယ် ပေနှင့် လက်မဖြစ်လျှင် Letter)၊ ရှုထောင့်အလျား၊ အောက်တွင် ဖိုင်အမည်၊ ရက်စွဲနှင့် ယူနစ်ကို ပြသသည့် မျဉ်း။
- {{ui:Export}} › {{ui:Print the view…}} သည် တူညီသော စာမျက်နှာကို browser ၏ print dialog ရှေ့သို့ ထားသည်။ ပရင်တာ ရွေးပါ၊ သို့မဟုတ် "Save as PDF" ကို ရွေးပါ။

စာမျက်နှာသည် မြင်ကွင်းကို ရှိသည့်အတိုင်း ပြသသည်: perspective မြင်ကွင်းတွင် စကေးမရှိပါ။ စကေးဖြင့် ပုံဆွဲလိုပါက {{ui:Perspective}} ကို ပိတ်ပြီး {{ui:Top}} သို့မဟုတ် {{ui:Front}} မှ ကြည့်ပါ၊ ပြီးလျှင် အရေးကြီးသော အရွယ်အစားများအတွက် [အတိုင်းအတာများ](topic:dimensions) ထည့်ပါ။ [တင်ပြမှု မြင်ကွင်း](topic:styles-shadows#presentation-view) သည် ဝင်ရိုးများ၊ လမ်းညွှန်များနှင့် ရွေးထားမှုကို ဖယ်ထားသည်; အတိုင်းအတာများ ကျန်ရှိသည်။
