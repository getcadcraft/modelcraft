မျဉ်းဆွဲနေစဉ် သို့မဟုတ် မျက်နှာကို တွန်းနေစဉ်လည်း ကင်မရာကို အချိန်မရွေး ရွှေ့နိုင်သည်: ကိရိယာသည် ရပ်နေခဲ့သည့် နေရာတွင် စောင့်သည်။

## သုံးခလုတ် mouse ဖြင့်

| ပြုလုပ်လိုသည် | ဤသို့ လုပ်ပါ |
|---|---|
| Orbit | အလယ်ခလုတ်ဖြင့် ဆွဲပါ (wheel ကို နှိပ်ပါ) |
| Pan | ညာခလုတ်ဖြင့် ဆွဲပါ၊ သို့မဟုတ် {{key:Shift}} ကို ဖိပြီး အလယ်ခလုတ်ဖြင့် ဆွဲပါ။ ဆွဲနေစဉ် {{key:Shift}} ကို ဖိခြင်း သို့မဟုတ် လွှတ်ခြင်းသည် orbit နှင့် pan ကြား ပြောင်းသည် |
| Zoom | Wheel ကို လှည့်ပါ။ ညွှန်ပြကိရိယာအောက်ရှိ မျက်နှာဆီသို့ သို့မဟုတ် view ၏ အလယ်အနက်တွင် အောက်ရှိ အမှတ်ဆီသို့ ချဲ့သည် |
| Model တစ်ခုလုံး မြင်ရန် | {{key:Shift+Z}} သို့မဟုတ် {{ui:Extents}} |

Orbit သည် ညွှန်ပြကိရိယာအောက်ရှိ model ၏ အပိုင်းကို ပတ်လည်တွင် view ကို လှည့်သည်၊ ထိုအမှတ်သည် အားလုံးလှည့်နေစဉ်တွင် နေရာတူ ရှိနေသည်။ အလွတ်နေရာပေါ်တွင် view ၏ အလယ်ဗဟိုကို ပတ်လည် လှည့်သည်။ Pan သည် သင် ဆွဲယူထားသော အမှတ်ကို ညွှန်ပြကိရိယာအောက်တွင် ထားသည်။

Orbit ကို အမြဲ view ၏ အလယ်ဗဟိုဝန်းကျင်တွင် လှည့်စေလိုပါက သို့မဟုတ် orbit နှင့် pan ၏ အမြန်နှုန်းကို ပြင်လိုပါက {{ui:Settings}} ({{key:Mod+,}}) ကို ဖွင့်ပါ၊ {{ui:ModelCraft}} tab၊ **Orbit and pan**။ အမြန်နှုန်းများသည် mouse၊ trackpad၊ touch နှင့် မြား key များအတွက် အသုံးပြုသည်။

ဆွဲခြင်းမရှိဘဲ ညာခလုတ် နှိပ်ခြင်းသည် ဘာမျှ မလုပ်ပါ; ModelCraft တွင် right-click menu မရှိပါ။

## အလယ်ခလုတ် မရှိပါက

Toolbar ရှိ ကင်မရာကိရိယာများ သို့မဟုတ် keyboard ကို သုံးပါ:

1. {{key:O}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Orbit}} ကို နှိပ်ပါ) ပြီး ဘယ်ခလုတ်ဖြင့် ဆွဲ၍ လှည့်ပါ။ ဆွဲနေစဉ် {{key:Shift}} ကို ဖိ၍ pan လုပ်ပါ။
2. {{key:H}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Pan}} ကို နှိပ်ပါ) ပြီး ဆွဲ၍ pan လုပ်ပါ။
3. {{key:Z}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Zoom}} ကို နှိပ်ပါ) ပြီး အပေါ်သို့ ဆွဲလျှင် ချဲ့၊ အောက်သို့ ဆွဲလျှင် ချုံ့ပါ။
4. {{key:Space}} ကို နှိပ်ပါ ({{ui:Select}} သို့ ပြန်သွားရန်) သို့မဟုတ် နောက်တစ်ခု လိုချင်သော ကိရိယာ၏ key ကို နှိပ်ပါ။

ကင်မရာကိရိယာများသည် သင် အသုံးပြုနေသော ကိရိယာကို အစားထိုးသည်။ လုပ်ဆောင်ချက် အလယ်တွင် ကြည့်ရှုလိုပါက ကိရိယာမပျောက်စေဘဲ keyboard ကို သုံးပါ:

- မြား key များသည် orbit လုပ်သည်။
- {{key:Shift}} ကို မြား key များနှင့် ဖိခြင်းသည် pan လုပ်သည်။

ဆွဲကိရိယာတစ်ခု လုပ်ဆောင်ချက် အလယ်တွင် (ပထမ နှိပ်ပြီးနောက်) ဖြစ်နေလျှင် မြား key များသည် orbit မလုပ်ဘဲ ဦးတည်ချက်များကို လော့ခ်ချသည်။ [Inference နှင့် snapping](topic:inference#lock-a-direction) ကို ကြည့်ပါ။

## Trackpad ပေါ်တွင်

အလွယ်ဆုံး နည်း: {{ui:Settings}} ({{key:Mod+,}}) ကို ဖွင့်ပါ၊ {{ui:ModelCraft}} tab ၌ Scrolling ကို **Trackpad** သို့ သတ်မှတ်ပါ (သို့မဟုတ် "Work it out" ၌ ထားပါ)။ ထို့နောက် လက်ချောင်းနှစ်ချောင်းဖြင့် ပွတ်ဆွဲ၍ orbit၊ {{key:Shift}} ကို ဖိ၍ ပွတ်ဆွဲ၍ pan၊ နှင့် pinch ဖြင့် zoom လုပ်ပါ — ကင်မရာခလုတ် မလိုပါ။ [ModelCraft settings](topic:settings#scrolling-mouse-wheel-or-trackpad) ကို ကြည့်ပါ။

Scrolling ကို **Mouse wheel** သို့ သတ်မှတ်ထားလျှင်:

:::mac
- **Zoom:** လက်ချောင်းနှစ်ချောင်းဖြင့် scroll လုပ်ပါ၊ သို့မဟုတ် pinch။ နှစ်ခုစလုံးက ညွှန်ပြကိရိယာဆီသို့ ချဲ့သည်။
- **Pan:** လက်ချောင်းနှစ်ချောင်းဖြင့် နှိပ်ပါ (secondary click) နှင့် ဆွဲနေစဉ် လက်ချောင်းများကို ဆက်ဖိထားပါ။ လက်ချောင်းနှစ်ချောင်း နှိပ်ခြင်း မအလုပ်လုပ်ပါက **System Settings**၊ ထို့နောက် **Trackpad** တွင် "Secondary click" ကို ဖွင့်ပါ။
- **Orbit:** {{key:O}} ကို နှိပ်ပြီး လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ၊ သို့မဟုတ် မြား key များကို သုံးပါ။
- Browser ပေါ်မူတည်ပြီး ModelCraft တွင် {{key:Ctrl}} ကို ဖိ၍ နှိပ်ခြင်းသည် right-click ဟု မရေတွက်နိုင်ပါ: {{key:Ctrl}} ကို ဖိထားသော နှိပ်ခြင်းအဖြစ် လုပ်ဆောင်နိုင်သည်။ Pan အတွက် လက်ချောင်းနှစ်ချောင်း နှိပ်ခြင်းကို သုံးပါ။
:::

:::windows linux
- **Zoom:** လက်ချောင်းနှစ်ချောင်းဖြင့် scroll လုပ်ပါ။ Touchpad driver က {{key:Ctrl}} ဖြင့် scroll အဖြစ် ပို့သည့်နေရာတွင် pinch ကလည်း zoom လုပ်သည်။
- **Pan:** ညာခလုတ်ဖြင့် ဆွဲပါ (touchpad အများစုတွင် အောက်ညာထောင့်ကို နှိပ်ပြီး ဆွဲပါ)၊ သို့မဟုတ် {{key:H}} ကို နှိပ်ပြီး ဆွဲပါ။
- **Orbit:** {{key:O}} ကို နှိပ်ပြီး ဆွဲပါ၊ သို့မဟုတ် မြား key များကို သုံးပါ။
:::

Mouse wheel ဖြင့် ဆိုလျှင် လက်ချောင်းနှစ်ချောင်း scroll သည် zoom လုပ်သည်; pan မလုပ်ပါ။ ၎င်းသည် web စာမျက်နှာ အများစုနှင့် ဆန့်ကျင်ဘက် ဖြစ်သည်၊ ၎င်းသည် 3D modeler အများစုတွင် mouse wheel လုပ်ဆောင်ပုံ ဖြစ်သည်။

:::tip
{{key:Space}} သည် ModelCraft တွင် {{ui:Select}} ကိရိယာကို ရွေးသည်။ {{key:Space}} ကို ဖိထားပြီး ဆွဲခြင်းသည် အခြား app အချို့ကဲ့သို့ pan မလုပ်ပါ။
:::

## Touch screen ပေါ်တွင်

:::touch
- **လက်ချောင်းတစ်ချောင်း** သည် လက်ရှိကိရိယာကို သုံးသည်: **tap** ဖြင့် နှိပ်၊ **နှိပ်ပြီး ဆွဲ** ဖြင့် ဆွဲ သို့မဟုတ် ဆွဲချ။
- ဆွဲကိရိယာ၏ လက်ချောင်း ဆိတ်နေစဉ် အထက်တွင် **loupe** က လက်ချောင်းအောက်ရှိအရာကို ပြသည်၊ ထို့ကြောင့် မ ပြေးမီ endpoint၊ midpoint သို့မဟုတ် snap လုပ်မည့် အစွန်းကို မြင်နိုင်သည်။
- ဝက်ဘ်လက်ချောင်း ကိုင်ထားနေ စက္ကန့်ဝက်အကြာ **ငြိမ်ထားပါ** — {{key:Enter}} ကဲ့သို့ ကိရိယာ လုပ်ဆောင်နေသည်ကို ပြီးစေသည်: မျဉ်းကွေး သို့မဟုတ် မျဉ်းကွင်း။ ဘာမျှ မလုပ်နေသည်ဖြစ်စေ ငြိမ်ထားပြီး လက်ချောင်းတူကိုပင် ဆွဲလျှင် ထွက်သည်အထိ **orbit** လုပ်သည်။
- လက်ချောင်းနှစ်ချောင်း အတူတကွ ဆွဲလျှင် **pan**; **pinch** ဖြင့် zoom။ နှစ်ခုစလုံး တစ်ကြိမ်တည်း gesture တွင် အလုပ်လုပ်သည်။
- လက်ချောင်းသုံးချောင်း အတူတကွ ဆွဲလျှင် **orbit**။
- အပြန်အလှန် လဲရန် (လက်ချောင်းနှစ်ချောင်း orbit၊ သုံးချောင်း pan)၊ {{ui:Settings}}၊ {{ui:ModelCraft}} tab၊ Touch screen ကို ဖွင့်ပါ။
- ဒုတိယ လက်ချောင်းကို ချလျှင် ပထမ လက်ချောင်း စတင်ထားသည့်အရာကို **ပယ်ဖျက်သည်** (ဆွဲထားသော စတုဂံ၊ ဆွဲနေသော push/pull)။ လက်ချောင်းများကို ဖယ်ပြီး ပြန်စပါ။
- View ၏ အောက်ဘက်ရှိ အနည်းငယ်သော ဘားတွင် **Done** ({{key:Enter}})၊ **Cancel** ({{key:Esc}}) နှင့် **Undo** ရှိသည်၊ keyboard မရှိသော အခါအတွက် ဖြစ်သည်။
- Snapping နှင့် ရွေးချယ်ခြင်းသည် mouse ထက် အနည်းငယ် ပိုဝေးသို့ ရောက်သည်၊ ခလုတ်များ ပိုကြီးသည်၊ ထို့ကြောင့် လက်ချောင်းဖြင့် ထိနိုင်သည်။
:::

:::mouse
Touch screen ပေါ်တွင် လက်ချောင်းတစ်ချောင်းသည် လက်ရှိကိရိယာကို သုံးသည် (tap ဖြင့် နှိပ်၊ ငြိမ်ထား၍ ပြီးစေ၊ သို့မဟုတ် ငြိမ်ထား၍ ဆွဲ၍ orbit)၊ လက်ချောင်းနှစ်ချောင်းသည် pan နှင့် pinch ဖြင့် zoom၊ လက်ချောင်းသုံးချောင်းသည် orbit၊ နှင့် ဘားတစ်ခုက Done၊ Cancel နှင့် Undo ကို ပေးသည်။
:::

## စံ view များ

1. Toolbar ၏ ညာဘက်အဆုံးရှိ {{ui:Views}} ကို နှိပ်ပါ။
2. {{ui:Iso}}၊ {{ui:Top}}၊ {{ui:Front}}၊ {{ui:Right}}၊ {{ui:Back}}၊ {{ui:Left}} သို့မဟုတ် {{ui:Bottom}} ကို ရွေးပါ။

View သည် ထိုဦးတည်ချက်သို့ လှည့်ပြီး model တစ်ခုလုံးနှင့် ကိုက်ညီသည်။ {{ui:Front}} သည် မြောက်ဘက်ကို၊ green ဝင်ရိုးတစ်လျှောက် ကြည့်သည်; {{ui:Top}} သည် တည့်တည့် အောက်သို့ ကြည့်ပြီး မြောက်ဘက် အပေါ်ဖြစ်သည်။

View cube (view ၏ ညာဘက်အပေါ်ထောင့်) သည် တစ်ချက်နှိပ်ဖြင့် တူညီသည်၊ အစွန်းများ၊ ထောင့်များ၊ model ကို လှည့်ရန် compass ring နှင့် home ခလုတ် အပို ပါသည်။ [View cube](topic:view-cube) ကို ကြည့်ပါ။

## Perspective နှင့် parallel projection

{{ui:Views}} ကို ရွေးပြီး {{ui:Perspective}} ကို ရွေးပါ။ အမှန်ခြစ်ရှိလျှင် perspective ဖွင့်ထားသည်။ ပိတ်ထားလျှင် view သည် parallel (orthographic) projection ဖြစ်ပြီး model တွင် ညီသော မျဉ်းများသည် မျက်နှာပြင်တွင်လည်း ညီနေသည်၊ ၎င်းသည် {{ui:Front}} သို့မဟုတ် {{ui:Right}} မှ elevation များအတွက် လိုသည်။ Status bar က "Perspective." သို့မဟုတ် "Parallel projection." ဟု ပြသည်။

Scene တစ်ခုစီသည် perspective ဖြစ်ခဲ့သလား မှတ်မိသည်။ [View များကို scene အဖြစ် သိမ်းခြင်း](topic:scenes) ကို ကြည့်ပါ။
