add-on တစ်ခု (Settings › Add-ons) က {{ui:Render a picture…}} ၏ Engine စာရင်းသို့ engine တစ်ခု ထည့်နိုင်သည်။ add-on ရေးသားသူများအတွက် အပြည့်အစုံ စာသားသည် add-on specification ၏ အပိုင်း 16 ဖြစ်သည်; အတိုချုပ်မှာ-

- Add-on က id တစ်ခုဖြင့် engine ကို မှတ်ပုံတင်သည်။ id သည် ကိုယ်ပိုင် id ဖြင့် စတင်ရမည်၊ အမည်၊ ရွေးချယ်နိုင်သော ဆက်တင်များနှင့်အတူ **သို့မဟုတ်** ပရိုဂရမ်တစ်ခုကို run ရန် **သို့မဟုတ်** ပုံဆွဲရန် JavaScript function တစ်ခု။
- ပရိုဂရမ်ကို run သော engine သည် **`engine.run`** ခွင့်ပြုချက် လိုအပ်သည်၊ ၎င်းကို install မလုပ်မီနှင့် Settings တွင် ပြသည်။ ၎င်းသည် Studio တွင်သာ run သည်; browser တွင် သိမ်းရန် ဖိုင်အဖြစ် ပြသည်။
- Add-on က ပရိုဂရမ်ကို အမည် (ရိုးရိုး ဖိုင်အမည်တစ်ခု၊ shell ဘယ်တော့မှ မဟုတ်) ဖြင့် ဖော်ပြသည်၊ **signed add-on အတွင်း**ရှိ script တစ်ခု၊ နှင့် placeholder များနှင့် ရိုးရိုးစကားလုံးများဖြင့် ပြုလုပ်ထားသော argument များ။ Studio က ပရိုဂရမ်ကို ရှာတွေ့ သို့မဟုတ် တစ်ကြိမ် ညွှန်ပြရန် မေးသည်။
- Add-on တစ်ခုက ပရိုဂရမ်ကို ပထမဆုံး run သောအခါ **Studio က ၎င်း၏ကိုယ်ပိုင် dialog ဖြင့် မေးသည်**: ဘယ် add-on၊ ဘယ်ပရိုဂရမ်၊ နှင့် script က ပရိုဂရမ်ဖြင့် ဘာမဆို လုပ်နိုင်သည်ဆိုသည်။ ယုံကြည်သော add-on အတွက်သာ ခွင့်ပြုပါ။ သင့်အဖြေကို ထို add-on နှင့် ပရိုဂရမ်အတွက် မှတ်ထားသည်။
- Package (USD အဖြစ် ဇာတ်ခင်းနှင့် ဆက်တင်ဖိုင်၊ add-on က တောင်းဆိုသောအခါ glTF ဖိုင်ဖြင့်) နှင့် add-on ၏ script ကို ယာယီဖိုလ်ဒါအသစ်တစ်ခုထဲသို့ ထည့်ပြီး ပရိုဂရမ်ကို ထိုနေရာတွင် run သည်။ ပုံကို add-on ၏ engine အမည်ဖြင့် အမှတ်အသားပြုပြီး ပြန်ပေးသည်။

:::note
Add-on များသည် add-on API 1.4 မှစ၍သာ render engine များ ထည့်နိုင်သည်။ open-source command-line renderer အတွက် ဥပမာ လုပ်ငန်းစဉ်ကို ၎င်း၏ကိုယ်ပိုင် repository တွင် ရှိသော်လည်း ထို renderer တွင် မသုံးရသေးပါ။
:::
