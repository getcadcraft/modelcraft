Texture သည် ပြားချပ်သော ပုံတစ်ပုံ ဖြစ်သည်၊ mesh မှာ ပြားချပ်မနေပါ။ ၎င်း၏ **UV** များက face တစ်ခုစီ၏ corner တစ်ခုစီသည် ပုံပေါ်တွင် ဘယ်နေရာ ရောက်သည်ကို ပြောသည်။ UV workspace က ၎င်းတို့ကို ဖန်တီးသည်- mesh ကို **seam** များအတိုင်း ဖြတ်ဖွင့်၊ အပိုင်းများကို ပြားချပ်ခြင်း (**unwrap**)၊ ထို့နောက် စတုရန်းထဲသို့ ထည့်သွင်းခြင်း (**pack**)။

## ဖွင့်ခြင်း

mesh တစ်ခုကို ရွေးပြီး အလုပ်နေရာ စာရင်းတွင် {{ui:UV}} ကို ရွေးပါ။ Group သို့မဟုတ် component သည် ပထမဦးစွာ mesh ဖြစ်လာသည်၊ Mesh အလုပ်နေရာတွင်ကဲ့သို့ပင်။ 3D မြင်ကွင်းသည် ဘယ်ဘက်ခြမ်းသို့ ရွေ့သည်၊ ညာဘက်ရှိ **UV editor** က mesh ၏ မျက်နှာများကို texture စတုရန်းပေါ်တွင် ခင်းကျင်းပြသသည်။ ရွေးချယ်ခြင်းသည် Mesh အလုပ်နေရာနည်းတူ အလုပ်လုပ်ပြီး၊ မြင်ကွင်းတစ်ခုတွင် ရွေးထားသည်များ အခြားမြင်ကွင်းတွင်လည်း ရွေးထားသည်။

## Seam များ အမှတ်အသားပြုခြင်း

Seam များသည် mesh ကို ဖြတ်ဖွင့်နိုင်သည့် နေရာများ ဖြစ်သည်; မြင်ကွင်းနှစ်ခုလုံးတွင် အနီရောင်ဖြင့် ပြသည်။

- Edge များကို ရွေးပါ ({{ui:အစွန်း}}၊ သို့မဟုတ် {{key:2}}) ပြီး {{ui:ချုပ်ရိုး အမှတ်အသား}} ({{key:Ctrl+E}}) ကို နှိပ်ပါ။ {{ui:ချုပ်ရိုး ရှင်းရန်}} ({{key:Ctrl+Shift+E}}) က ၎င်းတို့ကို ဖယ်ရှားသည်။
- {{ui:ထက်သော အနားများတွင် ချုပ်ရိုး}} သည် ထက်သော edge အားလုံးနှင့် မျက်နှာများ 60° ထက်ပိုသော ထောင့်ဖြင့် တွေ့သည့် edge အားလုံးကို အမှတ်အသားပြုသည်: ဘောက်စ်တစ်ခုသည် ၎င်း၏ ဘက် ၆ ခုအဖြစ် ပြိုကွဲသွားသည်။
- {{ui:UV များမှ ချုပ်ရိုးများ}} သည် UV များ ပြိုကွဲနေပြီးသား seam များကို အမှတ်အသားပြုသည်၊ ဥပမာ projection ပြီးနောက်။

ပိတ်ထားသော အပိုင်းတစ်ခုသည် ပြားချပ်ဖြစ်ရန် seam များ လိုအပ်သည်- ဘောလုံးတွင် အနည်းဆုံး ဖြတ်တစ်ခု၊ ပိုက်တွင် အလျားလိုက် ဖြတ်တစ်ခု လိုအပ်သည်။

## Unwrap

ခင်းရန် မျက်နှာများကို ရွေးပါ (သို့မဟုတ် mesh တစ်ခုလုံးအတွက် မည်သည်ကိုမျှ မရွေးပါနှင့်) ပြီး {{ui:Unwrap}} ({{key:U}}) ကို နှိပ်ပါ။ Seam များကြား အပိုင်းတစ်ခုစီကို ၎င်း ထောင့်များကို ဖြစ်နိုင်သမျှ မှန်ကန်အောင် ထိန်းထားရင်း ပြားချပ်ပြီး (angle-based flattening)၊ ထို့နောက် အပိုင်းများကို စတုရန်းထဲသို့ pack လုပ်သည်။ {{ui:Conformal}} က အစား least-squares conformal maps ဖြင့် unwrap လုပ်သည်- ပိုမြန်သော်လည်း အကွေးများသော အပိုင်းများတွင် အနည်းငယ် တိကျမှု နည်းသည်။ ပြားသော စာရွက်မှ ဖန်တီးနိုင်သော ပုံသဏ္ဍာန်၊ ဥပမာ ဆလင်ဒါ၏ ဘေးတစ်ဖက်ကို တစ်ကြိမ်ဖြတ်ထားခြင်းသည် stretch လုံးဝ မရှိဘဲ unwrap ဖြစ်သည်။

## Projection

ရိုးရှင်းသော ပုံသဏ္ဍာန်များအတွက် projection သည် မကြာခဏ လုံလောက်သည်:

| Projection | ဘာလုပ်သလဲ |
| --- | --- |
| {{ui:ဘောက်စ်}} | မျက်နှာတစ်ခုစီကို ၎င်း အများဆုံး ဆိုင်းသော ဘောက်စ်ဘက်သို့ ပရိုဂျက်လုပ်သည် |
| {{ui:ဆလင်ဒါ}} | အပြာ ဝင်ရိုးပတ်လည်: ဘေးလိုက်သည် ပတ်လည် ထောင့်ဖြစ်၊ အပေါ်သည် အမြင့်ဖြစ်သည် |
| {{ui:စဖီယာ}} | ဗဟိုမှ: ဘေးလိုက်သည် ပတ်လည် ထောင့်ဖြစ်၊ အပေါ်သည် latitude ဖြစ်သည် |
| {{ui:မြင်ကွင်းမှ}} | 3D မြင်ကွင်းတွင် ယခု မြင်ရသည့်အတိုင်း မျက်နှာများ |

ဆလင်ဒါ သို့မဟုတ် စဖီယာ၏ ဆက်ဆုံရာကို ဖြတ်ကျော်သော မျက်နှာတစ်ခုကို အပိုင်းတစ်ခုတည်းအဖြစ် ထားသည်၊ ထို့ကြောင့် ၎င်း၏ UV များသည် စတုရန်း၏ ညာဘက်အစွန်းကို အနည်းငယ် ကျော်သွားနိုင်သည်; texture များသည် ထိုနေရာတွင် ထပ်ခါတလဲလဲ ဖြစ်သည်။

## စီစဉ်ခြင်း

- {{ui:Pack}} သည် အပိုင်းများ (islands) ကို texel အရွယ်အစား တစ်ခုတည်းဖြင့် စတုရန်းထဲသို့ ထည့်သည်၊ တစ်ခုစီကို နေရာအနည်းဆုံး ယူရန် လှည့်သည်။ Panel က ၎င်းတို့ကြား ကျန်နေသော နေရာကို သတ်မှတ်သည်။
- {{ui:90° လှည့်ရန်}} နှင့် {{ui:မှန်ပြောင်း}} က ရွေးထားသော မျက်နှာများ၏ UV များကို လှည့် သို့မဟုတ် မှန်ပြောင်းသည်။
- UV editor တွင် ရွေးထားသော မျက်နှာကို ဆွဲ၍ ရွေးထားသော UV များကို ရွှေ့ပါ၊ သို့မဟုတ် editor ဘက်သို့ ညွှန်ပြပြီး {{key:R}} သို့မဟုတ် {{key:S}} ကို နှိပ်ကာ ရွှေ့ပြီး လှည့်ရန် သို့မဟုတ် အတိုင်းအတာချရန် (click တစ်ချက်သည် ၎င်းကို ထားရှိသည်၊ {{key:Esc}} က ပယ်ဖျက်သည်)။ {{key:G}} က ဆွဲခြင်းမရှိဘဲ ရွှေ့သည်။ မျက်နှာကို နှစ်ချက်နှိပ်ပါ (သို့မဟုတ် {{key:L}}) ၎င်း၏ island တစ်ခုလုံးကို ရွေးရန်။ ဘီးက zoom လုပ်သည်; အလယ် သို့မဟုတ် ညာခလုတ်ဖြင့် ဆွဲ၍ pan လုပ်ပါ; {{key:F}} က စတုရန်းကို ပြန်ကိုက်ညီစေသည်။

ပြောင်းလဲမှု တိုင်းသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်သည်။

## စစ်ဆေးခြင်း

- {{ui:စစ်ဆေးသည့်ပုံစံ}} သည် UV များတွင် mesh ပေါ်ရှိ အမှတ်အသားပါ checker ကို ပြသည်: တူညီပြီး စတုရန်း checker များက texture ညီညာစွာ ခင်းနေကြောင်း ဖြစ်သည်; အမှတ်အသားများက ၎င်း ဘယ်ဘက်သို့ ပြေးသည်ကို ပြသည်။
- {{ui:ဆန့်ထုတ်မှု}} က မျက်နှာတစ်ခုစီကို ၎င်း၏ UV များက ဆန့်ထုတ်မှု မည်မျှ ရှိသည်ဖြင့် အရောင်ခွဲသည်: အပြာ ဘာမှမရှိ၊ အစိမ်းကို ဖြတ်ပြီး အနီသည် အများအပြား။ Panel က ၎င်း တိုင်းတာမည့် **ထောင့် ကွေးမှု** သို့မဟုတ် **အရွယ်အစား ပြောင်းလဲမှု** ကို ရွေးချယ်ပြီး ပျမ်းမျှကို ပြသည်။
