{{ui:Render a picture…}} ရှိ ပုံကို **ကိုယ်ပိုင် engine များ** က ဆွဲသည်: Fast နှင့် Path tracer၊ browser နှင့် CadCraft Studio နှစ်ခုစလုံးတွင်။ အခြားပရိုဂရမ်တစ်ခုက **render-engine add-on** မှတစ်ဆင့် ယူဆောင်လာမှသာ ပုံကို ဆွဲနိုင်သည်: [add-on ဖြင့် render engine ထည့်ခြင်း](topic:render-engine-addons) ကို ကြည့်ပါ။ ဇာတ်ခင်းကို အခြားပရိုဂရမ်သို့ ယူသွားပြီး ထိုနေရာတွင် ဆက်လုပ်ရန် [ဇာတ်ခင်းကို အခြားပရိုဂရမ်တွင် ဖွင့်ခြင်း](topic:render-open-in) သို့မဟုတ် [ဇာတ်ခင်းကို game engine သို့ ပို့ခြင်း](topic:render-unreal) ကို သုံးပါ။

## Add-on ၏ engine ဖြင့် ပုံဆွဲခြင်း

1. Settings › Add-ons တွင် add-on ကို ဖွင့်ပါ။ ၎င်း၏ engine သည် {{ui:Render a picture…}} ၏ Engine စာရင်းတွင် ပေါ်လာသည်။
2. ၎င်းကို ရွေးပါ။ ၎င်း၏ကိုယ်ပိုင် ဆက်တင်များသည် Engine စာရင်းအောက်တွင် ပေါ်သည်။
3. {{ui:Render}} ကို နှိပ်ပါ။ Studio တွင် add-on က ပရိုဂရမ်ကို ပထမဆုံး run သည့်အခါ Studio က ၎င်း၏ကိုယ်ပိုင် dialog ဖြင့် မေးသည်။ ဆွဲနေစဉ် တိုးတက်မှု ပြသည်; {{ui:Stop}} က ရပ်စေသည်။ ပုံသည် ၎င်းကို ဆွဲသော engine အမှတ်အသားဖြင့် ပေါ်လာသည်။

JavaScript ဖြင့် ရေးထားသော engine သည် browser တွင်လည်း run သည်။ ဤကွန်ပျူတာပေါ်တွင် ပရိုဂရမ် run သော engine သည် Studio တွင်သာ run သည်; browser တွင် သိမ်းရန် ဖိုင်အဖြစ် ပြသည်။

## ဘာတွေ လွှဲပြောင်းသလဲ

Engine သည် **package** ကို ရသည်: မော်ဒယ်ကို USD ဖိုင်အဖြစ် (နှင့် တောင်းဆိုပါက glTF ဖိုင်အဖြစ်) နှင့် တိကျသော material တန်ဖိုး၊ နေနှင့် ကောင်းကင်၊ အလုပ်လုပ်နေသော မီးချောင်းတိုင်းကို ပါဝါနှင့် light profile ဖြင့်၊ ကင်မရာနှင့် exposure ပါဝင်သော ဆက်တင်ဖိုင်။ ပရိုဂရမ်တိုင်းသည် အလင်း၊ အရောင်အသွေးနှင့် sampling ကို ကိုယ်ပိုင်နည်းဖြင့် လုပ်သည်၊ ထို့ကြောင့် ပုံများသည် ကင်မရာ၊ နေ၊ မီးချောင်းနှင့် exposure တွင် ဆင်တူသည်၊ pixel အတိအကျ မတူပါ။

## CadCraft မည်သည့်အခါမှ မ run သော ပရိုဂရမ်များ

CadCraft သည် GNU GPL လိုင်စင်အောက်ရှိ ပရိုဂရမ်ကို ဘယ်တော့မှ မစတင်ပါ၊ ၎င်းကို engine အဖြစ် သို့မဟုတ် Open in ပစ်မှတ်အဖြစ်လည်း ဘယ်တော့မှ မစာရင်းပြုပါ။ Blender သည် ထိုပရိုဂရမ်များထဲမှ တစ်ခုဖြစ်သဖြင့် Engine စာရင်းတွင် မပါပါ။ {{ui:Render a picture…}} မှ သိမ်းထားသော USD သို့မဟုတ် glTF ဖိုင်သည် ထိုဖိုင်များကို ဖတ်သည့် မည်သည့်ပရိုဂရမ်တွင်မဆို ဖွင့်နိုင်ဆဲ ဖြစ်သည်။

:::note
Panorama နှင့် stereo ကင်မရာများ နှင့် ကောင်းကင်ပုံ (ကောင်းကင်၏ အရောင်များကို အသုံးပြုသည်) သည် အခြားပရိုဂရမ်သို့ မလွှဲပြောင်းပါ။ အခြားပရိုဂရမ်တွင် လုပ်ထားသော အရာများသည် မော်ဒယ်သို့ ပြန်မလာပါ။
:::
