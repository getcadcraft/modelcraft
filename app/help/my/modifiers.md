**ပြင်ဆင်ကိရိယာ (modifier)** သည် mesh ကို မပြောင်းဘဲ ၎င်းပြသသည့်အရာကို ပြောင်းသည်။ အစိတ်အပိုင်းတစ်ဝက်ကို mirror လုပ်ပြီး ထိုတစ်ဝက်ကိုသာ မော်ဒယ်လုပ်ပါ၊ သို့မဟုတ် သေတ္တာကို subdivision surface ဖြင့် ဝိုင်းပြီး သေတ္တာကို ဆက်တည်းဖြတ်ပါ။ ပြင်ဆင်ကိရိယာများသည် **stack** (အစီအစဉ်) တွင် ထားပြီး အပေါ်မှ အောက်သို့ အစဉ်လိုက် အလုပ်လုပ်သည်။ သင်မြင်သည်၊ ထုတ်သည်၊ ပရင့်ထုတ်သည်နှင့် render လုပ်သည်မှာ ဖွင့်ထားသော ပြင်ဆင်ကိရိယာအားလုံးပါသော mesh ဖြစ်သည်။

## ပြင်ဆင်ကိရိယာ ထည့်ရန်

1. mesh ကို ရွေးပါ။ Model workspace တွင် ၎င်း၏ **Modifiers** အပိုင်းသည် {{ui:Entity info}} တွင် ရှိသည်; Mesh workspace တွင် ညာဘက် panel တွင် ရှိသည်။
2. {{ui:Add a modifier…}} မှ တစ်ခု ရွေးပါ။ stack ၏ အောက်ဆုံးသို့ ရောက်သည်။
3. အမည်အောက်ရှိ ဆက်တင်များကို ပြောင်းပါ။ အရှည်များသည် Value box ၏ တန်ဖိုးများနှင့် တူသည်၊ ထို့ကြောင့် `600mm`၊ `2'6"` နှင့် `(6m)/4` အားလုံး အလုပ်လုပ်သည်။

ပြောင်းလဲမှုတိုင်းသည် undo အဆင့် တစ်ခုဖြစ်သည်: {{key:Mod+Z}} က ပြန်ယူသည်။

## ပြင်ဆင်ကိရိယာတစ်ခုစီပေါ် ခလုတ်များ

- checkbox က ဖွင့်/ပိတ် ပြောင်းသည်။
- ဖန်သားပြင်ခလုတ်က view တွင် ပြသည်/ဖျောက်သည် (stack တွင် ကျန်ရှိသည်)။
- ကင်မရာခလုတ်က rendered ပုံများနှင့် ဗီဒီယိုများတွင် ပြသည်/ဖျောက်သည်၊ ထို့ကြောင့် ပြင်ဆင်ကိရိယာတစ်ခုသည် render အတွက်သာ (သို့မဟုတ် view အတွက်သာ) ဖြစ်နိုင်သည်။
- မြားများက stack ထဲ အပေါ် သို့မဟုတ် အောက် ရွှေ့သည်။ အစဉ်အတန်းက အရေးကြီးသည်- mirror ပြီးနောက် subdivide က ချောမွေ့သော အဆစ် ပေးသည်၊ subdivide ပြီးနောက် mirror က မပေးပါ။
- {{ui:Apply}} က ပုံသဏ္ဍာန်ကို mesh ၏ အစိတ်အပိုင်း ဖြစ်စေသည်: အပေါ်ရှိ ပြင်ဆင်ကိရိယာများနှင့် ဤတစ်ခုကို mesh ပေါ်တွင် တိုက်ရိုက် လုပ်ပြီး stack မှ ထွက်သည်။ undo အဆင့် တစ်ခု။
- ခြစ်ခြင်း (cross) က ဖယ်ရှားသည်။

## Group သို့မဟုတ် component ပေါ်တွင်

group သို့မဟုတ် component သည် ချက်ပြုတ်နည်းကိုလည်း ထိန်းနိုင်သည်၊ ထို့ကြောင့် မီးခွက်အရိပ်ကို **Scale** နှင့် ထိုအရိပ်တစ်ခု၏ **Array** အဖြစ် ထားနိုင်ပြီး နံပါတ်တစ်ခုပြောင်းလျှင် မီးခွက် ပြောင်းသည်။

1. group သို့မဟုတ် component ကို ရွေးပါ။ {{ui:Entity info}} တွင် ၎င်း၏ **Modifiers** အပိုင်းက stack ကို ဖော်ပြသည် (အစတွင် ဗလာ)။
2. {{ui:Add a modifier…}} မှ {{ui:Scale}} သို့မဟုတ် {{ui:Array}} ကို ရွေးပါ။ group သည် **မူရင်း၊ stack က နေရာချထားသော** component ဖြစ်လာသည်။ မူရင်းကို ထိန်းထားသည်- ၎င်းကို တည်းဖြတ်လျှင် မိတ္တူအားလုံး ချက်ချင်း လိုက်သည်။
3. Scale က အနီ၊ အစိမ်းနှင့် အပြာအတွက် factor ယူသည် (`1, 1, 2` က အမြင့်ကို နှစ်ဆ လုပ်သည်)။ Array က မိတ္တူအရေအတွက်၊ ရလဒ်၏ အရွယ်အစားအလိုက် အဆင့် (အစိတ်အပိုင်း) နှင့် အရှည်ဖြင့် အပို အဆင့် ယူသည်။

stack သည် မူရင်း၏ ကိုယ်ပိုင်ဝင်ရိုးပေါ်တွင် ၎င်း၏ origin ပတ်လည် အပေါ်မှ အောက်သို့ အလုပ်လုပ်သဖြင့် အစဉ်အတန်း အရေးကြီးသည်- မိတ္တူသုံးခု 3 m ခွာ Array ပြီးနောက် အနီပေါ် Scale 2 ကို လုပ်လျှင် မိတ္တူများ 6 m ခွာသွားသည်; Scale ကို အရင်လုပ်ပြီး Array ကို နောက်မှ လုပ်လျှင် 3 m ခွာသည်။ checkbox၊ မြားနှင့် ခြစ်ခြင်းတို့သည် mesh ပေါ်တွင်ကဲ့သို့ အလုပ်လုပ်သည်; view နှင့် ကင်မရာခလုတ်များနှင့် ပြင်ဆင်ကိရိယာတစ်ခုပေါ် Apply တို့သည် မလုပ်ပါ၊ အကြောင်းမှာ group ပေါ် stack သည် တစ်ခုတည်း ဖြစ်သည်။

- {{ui:Edit source}} က မူရင်းကို နေရာတွင် ဖွင့်သည်။ ပြောင်းလဲမှုများ မိတ္တူအားလုံးတွင် ပြသည်; ပိတ်လျှင် မူလနေရာသို့ ပြန်ရောက်သည်။
- {{ui:Bake modifiers}} က ရလဒ်ကို ရိုးရိုး edge များနှင့် face များ ဖြစ်စေပြီး stack ကို ဖယ်သည်၊ undo အဆင့် တစ်ခု။ ထပ်နေသော မိတ္တူများသည် သီးခြား geometry အဖြစ် ကျန်ရှိသည်: Bake သည် union မဟုတ်ပါ။
- component ၏ မိတ္တူများသည် ချက်ပြုတ်နည်းကို မျှဝေသည်; {{ui:Make unique}} က သီးခြားစေသည် (မူရင်းက မျှဝေနေဆဲ)။
- stack ကို ဖိုင်ထဲ သိမ်းပြီး ကူးထည့်ခြင်းနှင့် undo တို့က သယ်ဆောင်သည်၊ Purge unused က မူရင်းကို ထိန်းထားသည်။ ပြင်ဆင်ကိရိယာကို နားမလည်သော ပရိုဂရမ်များကလည်း မိတ္တူများကို ပြသည်။
- Bake မလုပ်မချင်း ရလဒ်ကို ဝင်ရောက်၊ ဖောက်ခွဲ၊ အရွယ်ပြင်၊ ဆန့်ခြင်း မလုပ်နိုင်ပါ- နောက်ပြောင်းလဲမှုတွင် ပြန်တည်ဆောက်မည်ဖြစ်သည်။ နှစ်ခုစလုံး ၎င်းကို ပြောသည်။
- ကန့်သတ်ချက်များမှာ ပြင်ဆင်ကိရိယာ 32 ခုနှင့် မိတ္တူ 1,000 ဖြစ်သည်။ ဆန့်ရန် ပြုလုပ်ထားသော component (Stretch) နှင့် stack သည် အဓိပ္ပာယ်ဖွင့်ဆိုချက် တစ်ခုတည်း မျှဝေနိုင်သေးခြင်း မရှိပါ။

## Subdivision surface

Subdivision သည် mesh ကို Catmull-Clark ဖြင့် ချောမွေ့စေသည်- face တိုင်း လေးဘက်ပါ face များ ဖြစ်လာပြီး အဆင့်တိုင်း လေးဆ ပိုများသည်။ သေတ္တာကို အဆင့် ၂ သို့မဟုတ် ၃ ဖြင့် ဝိုင်းသော ပုံသဏ္ဍာန်အဖြစ် ပြပြီး သေတ္တာကို ဆက်တည်းဖြတ်နိုင်သည်။

- **View ရှိ အဆင့်များ** က ၎င်း ချောမွေ့မှုကို သတ်မှတ်သည်။
- **Render များရှိ အဆင့်များ** က rendered ပုံနှင့် ဗီဒီယိုများ ချောမွေ့မှုကို သတ်မှတ်သည်; render များသည် view ထက် အဆင့်ပိုသုံးနိုင်သည်။
- **Render များသည် အမှန်ချောမွေ့သော မျက်နှာပြင်ပေါ်** က rendered mesh ၏ အမှတ်များကို အဆင့်များ ဦးတည်ရာ limit surface ပေါ် ထားသည်၊ ထို့ကြောင့် အဆင့်နှစ်ခုတည်းပင် အဆင့်များစွာလို ချောမွေ့စွာ render လုပ်သည်။
- **Crease** များက edge များ ထက်မြက်နေစေသည်: Mesh workspace တွင် edge များကို ရွေး၍ {{ui:Crease}} သုံးပါ (1 က ထက်မြက်နေ၊ 0.5 က နည်းနည်း ဝိုင်း၊ 0 က ချောမွေ့)။ [mesh တည်းဖြတ်ခြင်း](topic:mesh-edit) ကို ကြည့်ပါ။
- **ကြီးသော mesh ပေါ် view အဆင့်ကို လျှော့ပါ:** သင်တောင်းသော အဆင့်များက ဤကွန်ပျူတာ၏ view က ကောင်းစွာ ကိုင်တွယ်နိုင်သည်ထက် မျက်နှာများ ပိုပေးမည်ဆိုလျှင် view က အဆင့်နိမ့်ကို ပြပြီး ထိုအကြောင်းကို ပြောသည်။ {{ui:Apply}} က အဆင့်အားလုံးကို အမြဲသုံးသည်။ မျက်နှာအရေအတွက်ကို {{ui:Settings}} › Rendering › Your machine တွင် သင့်စက်အတန်းက သတ်မှတ်သည်။
- ဖွင့်ထားသော အနားများက ၎င်းတို့ထောင့်များကို ထိန်းပြီး ၎င်းတို့ edge ၏ မျဉ်းပေါ် ရှိနေသည်။

## Lattice cage ဖြင့် ကွေးခြင်း

1. {{ui:Lattice}} ပြင်ဆင်ကိရိယာကို ထည့်ပြီး {{ui:Add a lattice cage round the mesh}} ကို နှိပ်ပါ။ 3 × 3 × 3 အမှတ် cage တစ်ခုသည် mesh ပတ်လည် ဝိုင်ယာများအဖြစ် ပေါ်လာသည်။
2. Mesh workspace တွင် cage ကို ဖွင့်ပါ (နှစ်ချက်နှိပ်ပါ) ပြီး ၎င်း၏ အမှတ်များကို ရွှေ့ပါ။ mesh က ချောချောမွေ့မွေ့ လိုက်သည်။

:::tip
cage သည် အခြား mesh ကဲ့သို့ ဖြစ်သည်: ပြီးသောအခါ tag ဖြင့် ဖျောက်ပါ။
:::

## ကြီးသော mesh များ

ရိုးရိုး stack များကို ချက်ချင်း တွက်သည်။ ကြီးသောတစ်ခုကို သင့်ကွန်ပျူတာ၏ core တိုင်းပေါ်တွင် နောက်ကွယ်တွင် တွက်သည်: အသစ် ပြီးမချင်း view က နောက်ဆုံးရလဒ်ကို ဆက်ပြသည်။ Boolean များသည် ပထမအကြိမ် solid modeler ကို တင်သည်; view က ခဏ ပြောသည်။

## ပြင်ဆင်ကိရိယာများ မလုပ်နိုင်သေးသည်များ

- vertex တစ်ခုချင်းစီ အလေးချိန် (mesh ပေါ် ဆေးထားသော falloff) ကို Displace၊ Smooth နှင့် Shrinkwrap အတွက်။
- push/pull geometry ပေါ်တွင် Scale နှင့် မျဉ်းဖြောင့် Array အပြင် ပြင်ဆင်ကိရိယာများ (group နှင့် component များ)- အရင် mesh အဖြစ် ပြောင်းပါ ({{ui:Convert to mesh}})။ Mirror၊ ကွေးသော သို့မဟုတ် curve Array၊ Bend နှင့် Taper တို့ကို group များပေါ်တွင် နောက်ပိုင်း ရရှိမည်။
