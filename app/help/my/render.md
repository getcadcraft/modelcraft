{{ui:Render a picture…}} သည် မြင်ကွင်းကို ပုံဆွဲချက်ထက် နေ့ရောင်ခြည်အောက်က ပုံလို ဖန်တီးပေးသည်- ကောင်းကင်၊ မော်ဒယ်၏ နေရာနှင့် ရက်စွဲအရ နေ၊ ပျော့ပျောင်းသော အရိပ်များ၊ ကောင်းကင်တစ်ခုလုံးမှ အလင်းကြောင့် ထောင့်များနှင့် အပေါက်များကို မှောင်စေခြင်း၊ နှင့် မှန်၊ သတ္တု သို့မဟုတ် ပြောင်သော ဆေးအရောင်ကဲ့သို့ ပေါ်စေသော အရောင်များ။ မော်ဒယ်ကို မပြောင်းပါ။

## မြင်ကွင်းကို ရေးဆွဲရန်

1. ပုံအတွက် မြင်ကွင်းကို သင်ကြိုက်သလို ပြင်ပါ- orbit လုပ်ပါ၊ zoom လုပ်ပါ၊ [မြင်ကွင်း](topic:scenes) တစ်ခုကို ရွေးပါ၊ မပြသင့်သည်များကို ဖျောက်ပါ။ ပုံသည် မြင်ကွင်း၏ ကိုယ်ပိုင် ကင်မရာကို သုံးသည်။
2. {{ui:File}} အုပ်စုတွင် {{ui:Export}} ကို နှိပ်ပြီး {{ui:Render a picture…}} ကို နှိပ်ပါ။
3. နှိပ်ထားသည်မှာ သင်မလိုချင်ပါက {{ui:Scene}} ကို ရွေးပါ ([မြင်ကွင်း ကြိုတင်သတ်မှတ်ချက်များ](topic:render#scene-presets-a-good-picture-in-one-click) ကို ကြည့်ပါ)၊ {{ui:Size}} ကို ရွေးပြီး {{ui:Render}} ကို နှိပ်ပါ။

   ပုံသည် ရေးဆွဲစဉ် ဖြည့်လာပြီး pass တိုင်းတွင် ပို၍ ချောမွေ့လာသည်။ {{ui:Stop}} (သို့မဟုတ် {{key:Esc}}) သည် အစောပိုင်း ရပ်စေပြီး ထိအချိန်အထိ ပုံကို ဆက်ထားသည်။

4. ဒေါင်းလုဒ်ဆွဲရန် {{ui:Save}} ကို နှိပ်ပါ (PNG ဖြစ်သည်၊ {{ui:Save as}} က အခြားပြောပါက မတူပါ)။

:::tip
မြင်ကွင်း၏ အရွယ်အစားဖြင့် {{ui:Draft}} ကို စတင်၍ ကင်မရာနှင့် ပုံစံကို စစ်ပါ၊ ထို့နောက် နောက်ဆုံးပုံအတွက် ပိုကြီးသော အရွယ်အစားဖြင့် {{ui:Good}} သို့မဟုတ် {{ui:Best}} ဖြင့် ရေးဆွဲပါ။
:::

## ဇာတ်ခုံ ကြိုတင်သတ်မှတ်ချက်များ- တစ်ချက်နှိပ်ဖြင့် ကောင်းသော ပုံ

ဒိုင်ယာလော့ခ်၏ အပေါ်ဘက်တွင် {{ui:Scene}} ခလုတ် လေးခု ရှိသည်။ တစ်ခုစီက ကောင်းကင်၊ ထိန်းညှိမှု၊ မြေပြင်၊ အနားမျဉ်းများ၊ အရည်အသွေးနှင့် နေကို တစ်ချက်နှိပ်ဖြင့် သတ်မှတ်ပေးသဖြင့် ပထမပုံမတိုင်မီ သင်ယူစရာ မလိုပါ။ တစ်ခုကို နှိပ်ပြီး {{ui:Render}} ကို နှိပ်ပါ။

| Scene | ၎င်းက သတ်မှတ်သည့်အရာ | အသုံးပြုရန် |
|---|---|---|
| {{ui:Exterior}} | ကြည်လင်သော ကောင်းကင်၊ မော်ဒယ်၏ ကိုယ်ပိုင်နေ၊ မြေပြင် ဖွင့်ထား | အပြင်ဘက်မှ အဆောက်အအုံ |
| {{ui:Interior}} | တိမ်အုပ်ကောင်းကင် (တူညီသော အလင်း၊ ပြင်းထန်သော နေစက္ကန့်မရှိ)၊ ခဲဝက် ပိုလင်းသည် | အခန်းအတွင်းမှ မြင်ကွင်း |
| {{ui:Section view}} | အဖြူရောင် studio၊ မြေပြင်မရှိ၊ အနားမျဉ်းများကို မြန်ဆန်သော render တွင် | section ဖြတ်ထားသော မော်ဒယ် |
| {{ui:Night}} | နေကို ညဘက်သို့ ချထားခြင်း (ကမ္ဘာ၏ ဝက်အခြမ်းအတွက် ဆောင်းလယ်ညသန်း)၊ တစ်ခဲ ပိုလင်းသည် | မော်ဒယ်ကို မီးထိုးထားခြင်း။ မီးမရှိပါက ပုံသည် မှောင်သည် |

- {{ui:Pick for this view}} က သင့်အတွက် ရွေးပေးသည်- section ဖြတ်ချက် ဖွင့်ထားလျှင် {{ui:Section view}}၊ ကင်မရာသည် မော်ဒယ်အတွင်း ရှိလျှင် {{ui:Interior}}၊ မဟုတ်လျှင် {{ui:Exterior}}။ ဒိုင်ယာလော့ခ်ကို ပထမဆုံး ဖွင့်သည့်အခါ ဤနည်းဖြင့် အလိုအလျောက် စတင်သည်။
- ဆက်တင်အားလုံးသည် အောက်တွင် ရှိနေပြီး ပြောင်းလဲနိုင်သည်။ ဆက်တင်တစ်ခုကို ပြောင်းလိုက်သည်နှင့် ဇာတ်ခုံက သတ်မှတ်ထားသည်ကို ရပ်ပြီး ခလုတ်တွင် မည်သည့်အရာမှ နှိပ်ထားခြင်း မရှိတော့ပါ၊ ခလုတ်အောက်ရှိ လိုင်းက ဆက်တင်များသည် သင့်ကိုယ်ပိုင်ဖြစ်ကြောင်း ပြောသည်။ တန်ဖိုးများကို ပြန်ထားရန် ဇာတ်ခုံကို ထပ်နှိပ်ပါ။
- ဇာတ်ခုံသည် engine၊ mode၊ အရွယ်အစား၊ ပစ္စည်းများ၊ ကင်မရာ သို့မဟုတ် မီးများကို မထိပါ။

:::note
ဇာတ်ခုံများသည် ModelCraft နှင့် BimCraft တွင် တူညီသော တန်ဖိုးများ ပေးသည်။ ပြီးသော ပုံ၏ ပုံစံသည် သင့်မော်ဒယ်နှင့် သင့်ဂရပ်ဖစ်ကတ်ပေါ် မူတည်သည်။
:::

ဆက်တင်များကို `.modelcraft` ဖိုင်တွင် သိမ်းသဖြင့် ထိုမော်ဒယ်၏ နောက်ပုံသည် ရပ်ခဲ့သည့်နေရာမှ စတင်သည်။

## အရောင်များကို မှန် သို့မဟုတ် သတ္တုအဖြစ် ပေါ်စေရန်

{{ui:Materials}} အောက်တွင် မျက်နှာပြင်ရှိ အရောင်တိုင်းတွင် အသွင်တစ်ခုရှိသည်- {{ui:Matte}}၊ {{ui:Satin}}၊ {{ui:Glossy}}၊ {{ui:Metal}}၊ {{ui:Polished metal}}၊ {{ui:Glass}} သို့မဟုတ် {{ui:Frosted glass}}။ {{ui:Unpainted faces}} ဆိုသည်မှာ ကိုယ်ပိုင်အရောင်မရှိသော မျက်နှာများ ဖြစ်သည်။

ပြတင်းပေါက်များကို မှန်ဖြစ်စေရန် ပြတင်းပြင်များကို အရောင်တစ်ခုဖြင့် [ဆေးသုတ်](topic:paint) ပြီးနောက် ထိုအရောင်ကို {{ui:Glass}} သို့ သတ်မှတ်ပါ။ မှန်သည် ကောင်းကင်နှင့် နောက်ကွယ်ရှိအရာကို ဖြတ်ပေးပြီး ၎င်း၏အရောင်ဖြင့် အရောင်တင်ကာ ကောင်းကင်ကို ပြန်ထင်ပြသည်။

:::note
{{ui:Fast}} mode တွင် မှန်နှင့် သတ္တုသည် ကောင်းကင်ကိုသာ ပြန်ထင်ပြပြီး မော်ဒယ်၏ အခြားအရာများကို မပြန်ပါ၊ အလင်းလည်း မှန်ကို မဖြတ်ပါ။ အောက်ပါ {{ui:High quality (path traced)}} mode က နှစ်ခုလုံးကို လုပ်ဆောင်သည်။
:::

## အရည်အသွေးမြင့်

ကင်မရာက မြင်သလို အလင်းကို လိုက်သော ပုံအတွက် {{ui:Mode}} › {{ui:High quality (path traced)}} ကို ရွေးပါ-

- အလင်းသည် မျက်နှာပြင်များကြား ပြန်ခုန်သဖြင့် ပြတင်းမှ သို့မဟုတ် မီးမှ အလင်းထိုးသော အခန်းသည် ပတ်လည်အနှံ့ လင်းပြီး အရောင်များသည် အနီးရှိ အရာများဆီသို့ ပျံ့သည်၊
- မှန်သည် အမှန်တကယ် မှန်ဖြစ်သည်- အလင်းသည် ၎င်းကို ဖြတ်၍ ကွေ့ဝင်ပြီး မော်ဒယ်ကို ပြန်ထင်ပြသည်၊
- သတ္တုနှင့် ပွတ်ထားသော မျက်နှာပြင်များသည် မော်ဒယ်၏ အခြားအပိုင်းများကို ပြန်ထင်ပြသည်၊
- အလင်းပြားများသည် ပြားအဖြစ် လင်းပြီး အရိပ်ပျော့ပျောင်းသည်။

{{ui:Fast}} ထက် သိသိသာသာ နှေးသည်- pixel တစ်ခုစီ၏ အလင်းကို pass တိုင်း ထပ်လိုက်လုပ်ရသည်။ ပုံသည် ကြမ်းတမ်းစွာ စတင်ပြီး sample များ စုလာသည်နှင့်အမျှ ရှင်းလာသည်၊ ထို့ကြောင့် အရွယ်အစားသေးသေး ({{ui:The view's size}}၊ {{ui:Draft}}) ဖြင့် စတင်ပြီး {{ui:Time limit}} ကို ရွေးပါ- အချိန်ကုန်သည်နှင့် ထိအချိန်အထိ ပုံကို ထားမည်။ {{ui:Stop}} ကလည်း ထိုအတိုင်း ထားသည်။ ပထမ pass သည် browser က path tracer ကို ပြင်ဆင်နေစဉ် စောင့်သည်။

ဘရောက်ဇာတွင် WebGPU ရှိပါက path tracer သည် CadCraft ကိုယ်ပိုင်ဖြစ်ပြီး ဂရပ်ဖစ်ကတ်ပေါ်တွင် လည်ပတ်သည်၊ ပုံအောက်ရှိ လိုင်းက {{ui:Path traced on the graphics card (WebGPU)}} ဟု ပြသည်။ {{ui:Stop}} သို့မဟုတ် အချိန်ကန့်သတ်ချက်ပြီးနောက် {{ui:Resume}} သည် sample အားလုံးပြည့်သည်အထိ တူညီသောပုံဖြင့် ဆက်လုပ်သည်၊ ဆက်တင် ပြောင်းခြင်း သို့မဟုတ် {{ui:Render}} ကို ထပ်နှိပ်ခြင်းက အစမှ ပြန်စသည်။ WebGPU မရှိပါက ပုံကို WebGL ဖြင့် path trace လုပ်ပြီး (လိုင်းက ထိုသို့ ပြောသည်) {{ui:Resume}} ကို မပေးပါ။

:::linux
Linux ပေါ်ရှိ Firefox နှင့် Chrome အများစုတွင် WebGPU မရှိသေးသဖြင့် အရည်အသွေးမြင့်သည် ထိုနေရာတွင် WebGL ကို သုံးသည်။
:::

ဤ mode တွင် အနားများကို မဆွဲပါ၊ ကြိုတင်ပြင်ဆင်ထားသော texture များသည် ၎င်းတို့၏ အရောင်နှင့် ကြမ်းမှုကို ပြသော်လည်း ထိုအဖုအထစ်များကို မပြပါ (node ဖြင့် ပြုလုပ်ထားသော [ပစ္စည်း](topic:shading#in-high-quality-pictures) သည် ၎င်း၏ normal နှင့် အဖုအထစ်များကို ပြသည်)၊ ပုံမစမီ section ဖြတ်ချက်ကို မော်ဒယ်ပေါ်တွင် ပြုလုပ်သည်။

{{ui:Denoise (clears the grain left after the samples)}} သည် မူလအတိုင်း ဖွင့်ထားသည်- ပုံပြီးသည့်အခါ သို့မဟုတ် ရပ်သည့်အခါ ကျန်ရှိသော ကြမ်းတမ်းမှုကို ဤအတွက် ပြုလုပ်ထားသော neural network (Intel Open Image Denoise ၏ ထုတ်ပြန်ထားသော network၊ သင့်ကွန်ပျူတာပေါ်တွင် လည်ပတ်သည်- ဂရပ်ဖစ်ကတ်ပေါ်တွင်၊ မဟုတ်လျှင် processor ပေါ်တွင်) ဖြင့် ရှင်းသည်။ sample နည်းသော ပုံသည် သန့်စင်စွာ ထွက်လာသည်၊ {{ui:Show}} › {{ui:The picture before denoising}} သည် ၎င်းကို ရေးဆွဲထားသည့်အတိုင်း ပြသည်။

## မြင်ကွင်းအတွင်း ရေးဆွဲရန်

{{ui:Render}} workspace သည် path tracer ကို မြင်ကွင်းထဲတွင် တိုက်ရိုက် လည်ပတ်စေသည်- orbit လုပ်ပါ၊ မော်ဒယ်ကို တည်းဖြတ်ပါ သို့မဟုတ် မီးတစ်ခုကို ပြောင်းပါ၊ ၎င်းက ချက်ချင်း ပြန်စသည်။ {{ui:Region}}: စတုဂံကို ဆွဲပါ၊ ထိုအပိုင်းသာ ရေးဆွဲမည်; {{ui:Whole view}} က ပြန်သွားသည်။ {{ui:Focus}}: ထင်ရှားစေလိုသော နေရာကို နှိပ်ပါ၊ field depth က ထိုနေရာတွင် အာရုံစိုက်သည်။ {{ui:Detail}} က မြင်ကွင်း၏ pixel မည်မျှကို ရေးဆွဲမည်ကို သတ်မှတ်သည် (နည်းလျှင် ပိုမြန်သည်)။ {{ui:Pause}} က ရပ်ပြီး ဆက်သည်။ WebGPU လိုအပ်သည်- မရှိပါက workspace က ထိုသို့ ပြောပြီး {{ui:Export}} › {{ui:Render a picture…}} သည် ဆက်လုပ်နိုင်သည်။

## WebGPU ဖြင့် ကောင်းကင်များနှင့် မီးပရိုဖိုင်များ

WebGPU ဖြင့် အရည်အသွေးမြင့်တွင် ကောင်းကင် နှစ်ခု ထပ်ရှိသည်-

- {{ui:Physical sky}} သည် နေ၏ အမြင့်မှ နေ့ရောင်ခြည်ကို တွက်သည်- အထက်တွင် နက်ပြာ၊ ခေါင်းတွင် ဖြူရော်ရော် ဘောင်၊ နေနိမ့်လာသည်နှင့်အမျှ ပိုနွေးပြီး ပိုမှိန်သော နေ။ {{ui:Haze}} သည် ရှင်းလင်းသော နေ့ (2) မှ မှိုင်းသော နေ့ (10) အထိ သွားသည်။
- {{ui:Sky picture (HDRI)}} သည် အမှန်တကယ် နေရာ၏ panorama ပုံဖြင့် မော်ဒယ်ကို လင်းစေသည်။ {{ui:Choose a picture…}} က equirectangular `.hdr` သို့မဟုတ် `.exr` ဖိုင်ကို ယူသည်; {{ui:Turn}} က မော်ဒယ်ပတ်လည် လှည့်ပြီး {{ui:Picture brightness}} က ပိုလင်း သို့မဟုတ် ပိုမှောင်စေသည်။ ပုံတွင် ကိုယ်ပိုင်နေ ပါသဖြင့် မော်ဒယ်၏ နေကို ထပ်မထည့်ပါ။ ၎င်းသည် စာမျက်နှာဖွင့်ထားစဉ်သာ သိမ်းထားသည်: ပြန်ဖွင့်ပြီးနောက် ထပ်ရွေးရန်လိုသည်။

{{ui:Lamps}} စာရင်းရှိ မီးတစ်ခုစီသည် ထုတ်လုပ်သူ၏ light profile ကို ယူနိုင်သည်: {{ui:IES profile…}} သည် IES (LM-63) ဖိုင်ကို ဖတ်ပြီး ထိုအသွင်အပြင်ကဲ့သို့ အလင်းကို ပစ်ချသည် (ကျဉ်းသော downlight၊ နံရံ wash)။ ထိုအမည်ရှိ မီးတိုင်းသည် ထိုပရိုဖိုင်ကို သုံးပြီး မီးက ၎င်း၏ကိုယ်ပိုင် အလင်းအားကို ထိန်းသည်။ ပရိုဖိုင်အမည်ကို နှိပ်ပါက အသုံးပြုခြင်းကို ရပ်သည်။

ရှင်းလင်းသော မှန်ပြတင်းပေါက်များသည် ကောင်းကင်၏ အလင်းကို အခန်းထဲသို့ ရောက်စေသဖြင့် ကောင်းကင်အောက်ရှိ အတွင်းပိုင်းပုံများသည် ပိုမြန်စွာ ရှင်းလင်းသည်။

{{ui:Fast}} mode နှင့် WebGL path tracer သည် {{ui:Physical sky}} နှင့် {{ui:Sky picture (HDRI)}} ကို ရှင်းလင်းသော ကောင်းကင်အဖြစ် ပြပြီး မီးပရိုဖိုင်များကို လျစ်လျူရှုသည်။

## ကင်မရာ

{{ui:Camera}} က ပုံကို ဓာတ်ပုံကဲ့သို့ ပြင်ဆင်ပေးသည်-

- {{ui:Exposure}}: {{ui:Brightness slider}} ကို ထားပါ၊ သို့မဟုတ် {{ui:Camera settings}} ကို ရွေးပြီး ကင်မရာပေါ်ကဲ့သို့ {{ui:Aperture (f-stop)}}၊ {{ui:Shutter speed}} နှင့် {{ui:ISO}} ကို သတ်မှတ်ပါ; ၎င်းတို့ဘေးရှိ EV သည် ပုံမှန် exposure တန်ဖိုး ဖြစ်သည်။ f/16၊ 1/100 s နှင့် ISO 100 သည် နေသာသော နေ့နှင့် ကိုက်ညီသည်; မှောင်သော မြင်ကွင်းသည် ပိုကျယ်သော aperture၊ ပိုနှေးသော shutter သို့မဟုတ် ပိုမြင့်သော ISO ကို လိုသည်။ ဤအရာသည် mode အားလုံးတွင် အလုပ်လုပ်သည်။
- {{ui:Depth of field}} သည် {{ui:Focus distance (m)}} ထက် နီးသော သို့မဟုတ် ဝေးသော အရာများကို ထို f-stop ရှိ လင်ဆ်က လုပ်သကဲ့သို့ ဝါးစေသည် (မြင်ကွင်း အလယ်ရှိ အရာကို အာရုံစိုက်စေလိုလျှင် ဗလာထားပါ); {{ui:Aperture shape}} က အာရုံမပြတ်သော အရောင်ထိခိုက်မှုကို စက်ဝိုင်း သို့မဟုတ် ဓားပုံသဏ္ဌာန်ပေးသည်။
- {{ui:Two-point perspective (vertical lines stay vertical)}} သည် ကင်မရာကို ညီညာစေပြီး ပုံကို ရွှေ့သည်၊ architectural tilt-shift လင်ဆ်ကဲ့သို့၊ အဆောက်အအုံကို အပေါ် သို့မဟုတ် အောက်သို့ ကြည့်သည့်အခါ နံရံများ မစောင်းစေရန်။
- {{ui:White balance}} သည် မည်သည့်အလင်းအရောင်ကို အဖြူအဖြစ် ပြမည်ကို သတ်မှတ်သည်- နွေးသော မီးအတွက် နိမ့်ခြင်း (ဥပမာ 3000 K)၊ အရိပ်နှင့် တိမ်အုပ်သော နေ့အတွက် မြင့်ခြင်း။
- {{ui:Projection}}: {{ui:360° panorama}} သည် panorama ကြည့်ရှုသူများအတွက် ကင်မရာပတ်လည် အရာအားလုံးကို 2:1 ပုံအဖြစ် ပြုလုပ်သည်; {{ui:360° stereo panorama}} သည် headset များအတွက် ဘယ်မျက်လုံးနှင့် ညာမျက်လုံး panorama နှစ်ခုကို ဆင့်ထားသည်; {{ui:Cube map (6 faces)}} သည် 3 × 2 grid ရှိ စတုရန်း မြင်ကွင်း ခြောက်ခုကို ပြုလုပ်သည်။ အကျယ်ကို {{ui:Size}} မှ ယူသည်။

Projection၊ depth of field၊ two-point perspective နှင့် white balance သည် ဂရပ်ဖစ်ကတ်ပေါ်ရှိ path tracer (WebGPU) လိုအပ်သဖြင့် {{ui:High quality}} တွင်သာ ပြသည်။

## ပုံကို နောက်ဆုံးပြင်ရန်

{{ui:Picture}} သည် အရည်အသွေးမြင့်ပုံကို ဓာတ်ပုံကဲ့သို့ ညှိပေးသည်၊ ထိန်းချုပ်မှုတိုင်းသည် နောက်ဆုံးပုံကို ပြန် render မလုပ်ဘဲ ချက်ချင်း ပြောင်းသည်-

- {{ui:Look (view transform)}}: {{ui:ACES filmic}} (ယခင်ကဲ့သို့ ပုံ)၊ {{ui:AgX}} (ပျော့ပြော့၊ အလင်းအလွန်ပြင်းသည့်အခါ အရောင်ကို ထိန်းသည်)၊ {{ui:Filmic}} (နူးညံ့သော ဖလင်မျဉ်း) သို့မဟုတ် {{ui:Standard}} (ရိုးရှင်း၊ ပြင်းသော အလင်းသည် အဖြူသို့ ဖြတ်သည်)။
- {{ui:Contrast}} နှင့် {{ui:Highlight compression}} (အလင်းအလွန်ပြင်းသော အပိုင်းများတွင် အသေးစိတ်ကို ပြန်ထုတ်ပေးသည်)။
- {{ui:Bloom}} (ပြင်းသော အလင်းပတ်လည် နူးညံ့သော အရောင်ထွက်)၊ {{ui:Glare}} နှင့် ၎င်း၏ {{ui:Glare streaks}} (အလင်းအဖြူဆုံး အချက်များမှ ကြယ်ပွင့်ရောင်ခြည်)၊ နှင့် {{ui:Vignette}} (မှောင်သော ထောင့်များ)။
- {{ui:Colour table (.cube)…}} သည် `.cube` ဖိုင်မှ အရောင်ညှိမှုကို ၎င်း၏ {{ui:Colour table strength}} ဖြင့် သုံးသည်; ကောင်းကင်ပုံကဲ့သို့ စာမျက်နှာဖွင့်ထားစဉ်သာ သိမ်းထားသည်။

## ပုံကို သိမ်းရန်

{{ui:Save}} ဘေးရှိ {{ui:Save as}} သည် ဖိုင်ကို ရွေးသည်- {{ui:PNG}}၊ {{ui:JPEG}} သို့မဟုတ် {{ui:WebP}} ကို မျှဝေရန် (JPEG နှင့် WebP သည် browser ရေးနိုင်သော နေရာတွင်သာ)၊ နှင့် ဂရပ်ဖစ်ကတ်ပေါ်ရှိ အရည်အသွေးမြင့် render ပြီးနောက် အောက်ပါတို့ကိုလည်း-

- {{ui:PNG, 16 bits}}: အရောင်ညှိပြီးသော ပုံ၊ အရောင်အဆင့်များ ပိုနုသည်၊ ပုံနှိပ်ရန် သို့မဟုတ် နောက်ထပ်တည်းဖြတ်ရန်အတွက်။
- {{ui:EXR, every layer (32-bit float)}}: ရေးဆွဲထားသည့်အတိုင်း ပုံ (linear အလင်း၊ အရောင်ညှိမှု မရှိ) နှင့် render element နှင့် မီးအုပ်စု တိုင်းကို သီးခြား layer အဖြစ်၊ compositing ပရိုဂရမ်များအတွက်။
- {{ui:Render file (.ccrender, to grade again later)}}: ပုံကို နောက်မှ ပြန်ရောစပ်ပြီး ညှိရန် ဒိုင်ယာလော့ခ်လိုအပ်သမျှ။ {{ui:Open a render file…}} က ၎င်းကို ပြန်ယူပေးသည်၊ ရောစပ်မှုနှင့် ညှိမှုပါ၊ ပြန် render မလုပ်ဘဲ။

## render ပြီးနောက် မီးများကို ရောစပ်ရန်

{{ui:Render}} ကို မနှိပ်မီ {{ui:Light mixing (change each light's colour and brightness after the render)}} ကို ဖွင့်ပါ။ ပုံပြီးသည့်အခါ (သို့မဟုတ် ရပ်သည့်အခါ) {{ui:Mix the picture}} သည် ၎င်း၏ မီးများကို အုပ်စုဖြင့် ပြသည်: ကောင်းကင်၊ နေ၊ နှင့် အမည်ဖြင့် မီးများ (အမည်တူ မီးတိုင်းသည် အုပ်စုတစ်ခု)။ အုပ်စုတစ်ခုကို ပိတ်ပါ၊ အရောင်ပေးပါ သို့မဟုတ် ပိုလင်း သို့မဟုတ် ပိုမှောင်စေပါ၊ ပုံသည် ချက်ချင်း ပြောင်းမည်၊ ထပ် render မလုပ်ဘဲ။ {{ui:Save mix}} သည် ရောစပ်မှုကို နောက်မှ ရွေးရန် အမည်ဖြင့် သိမ်းသည်; {{ui:As rendered}} က ပုံကို ရေးဆွဲစဉ်အတိုင်း ပြန်ထားသည်။ {{ui:Save}} က ရောစပ်ထားသော ပုံကို သိမ်းသည်။

{{ui:Render elements (albedo, normals, depth, diffuse, specular, transmission, emission, IDs)}} သည် ပုံ၏ အစိတ်အပိုင်းများကိုလည်း သိမ်းသည်။ {{ui:Show}} သည် မြင်ကွင်းကို ၎င်းတို့ထဲမှ တစ်ခုသို့ ပြောင်းသည်: မျက်နှာပြင် အရောင် (albedo)၊ normal များ၊ depth၊ diffuse၊ specular နှင့် ဖြတ်သန်းသော အလင်း (တိုက်ရိုက်နှင့် သွယ်ဝိုက်ရော)၊ ထွက်လာသော အရာနှင့် ကောင်းကင်၊ နှင့် masks ပြုလုပ်ရန် အရာတစ်ခုစီ သို့မဟုတ် ပစ္စည်းတစ်ခုစီအတွက် အရောင်။

နှစ်ခုလုံးသည် ဂရပ်ဖစ်ကတ်ပေါ်တွင် layer အပိုများ ထားသည်။ အရွယ်အစားကြီးများတွင် ဂရပ်ဖစ်ကတ်တွင် နေရာမရှိနိုင်; ဒိုင်ယာလော့ခ်က ထိုသို့ ပြောပြပြီး အရွယ်အစားသေးသေးက အလုပ်လုပ်သည်။

## render တန်းစီစာရင်း

အရည်အသွေးမြင့် ပြင်ဆင်ပြီးနောက် {{ui:Render queue}} အောက်ရှိ {{ui:Add this picture to the queue}} သည် ပုံကို ယခု သတ်မှတ်ထားသည့်အတိုင်း ထားသည်; ဗီဒီယို ဒိုင်ယာလော့ခ်ရှိ {{ui:Add this animation to the queue}} သည် animation တစ်ခုလုံးကို ဖရိန်တစ်ခုချင်း path traced လုပ်ရန် အတူတူ ပြုလုပ်သည်။ {{ui:Start the queue}} က ၎င်းတို့ကို ဤကွန်ပျူတာပေါ်တွင် တစ်ခုပြီးတစ်ခု ရေးဆွဲပြီး ပြီးသွားသော တစ်ခုစီ၏ ဘေးရှိ {{ui:Save}} က ဒေါင်းလုဒ်ဆွဲသည်။ စာမျက်နှာပိတ်လျှင် တန်းစီစာရင်း ကျန်နေသည်- မော်ဒယ်တူကို ပြန်ဖွင့်လျှင် ရပ်ခဲ့သည့်နေရာမှ ဆက်သည်။ တန်းစီစာရင်းသည် WebGPU လိုအပ်သည်။

## မြုပ်၊ မီးခိုး၊ noise နှင့် caustics

ဤအရာများသည် {{ui:Fog, smoke and noise}} တွင် ရှိပြီး ဂရပ်ဖစ်ကတ်ပေါ်ရှိ {{ui:High quality}} တွင် အလုပ်လုပ်သည်; အခြား engine များတွင် ၎င်းတို့ မပါ။

- {{ui:Fog and haze}} သည် နေ၊ ကောင်းကင်နှင့် မီးများက လင်းစေသော မှုန်ကုပ်ဖြင့် အမြင့်အထိ လေကို ဖြည့်သည်။ {{ui:How far you can see, in meters}} က ထူမှုကို သတ်မှတ်သည် (100 m ခန့်သည် ပေါ့ပါးသော မှုန်ကုပ်၊ 20 m သည် ထူထဲသော မြုပ်); {{ui:Fog height above the ground, in meters}} က ၎င်း ဆုံးသည့်နေရာ; {{ui:Light shafts}} က မှုန်ကုပ်သည် အလင်းဆီသို့ ဘယ်လောက် တောက်ပသည်ကို သတ်မှတ်သည်။ နေရောင်သည် မြုပ်၏ အပေါ်ဆုံးတွင် ထွက်သဖြင့် ပြတင်းပေါက် သို့မဟုတ် အဆောက်အအုံများကြား နေ ဝင်လာသည့်နေရာတွင် အလင်းတိုင်များအဖြစ် မြင်ရသည်။
- {{ui:Smoke or cloud}} က မြုပ်ကဲ့သို့ လင်းထားသော မီးခိုး သို့မဟုတ် တိမ် volume တစ်ခုထည့်သည်။ {{ui:Kind}} သည် {{ui:Cloud}}၊ {{ui:Smoke column}} သို့မဟုတ် {{ui:From a volume file (.ccvol)}} (CadCraft ကိုယ်ပိုင် grid ဖော်မတ်) တစ်ခုဖြစ်သည်။ {{ui:Detail}} နှင့် {{ui:Variation}} က ပြုလုပ်ထားသော တိမ် သို့မဟုတ် ကော်လံကို ပြောင်းသည်၊ {{ui:Size of its longest side, in meters (0 = the size of the model)}}၊ {{ui:Move X (m)}}၊ {{ui:Move Y (m)}}၊ {{ui:Move Z (m)}} နှင့် {{ui:Turn}} က နေရာချသည် (မော်ဒယ်အလယ်မှ စတင်သည်)၊ {{ui:Thickness}} က ပိုသိပ်စေသည်၊ {{ui:Forward glow}} က အလင်းဆီသို့ ပိုတောက်စေသည်၊ {{ui:Color}} က အရောင်ညှိသည်။ volume ဖိုင်ကို ကောင်းကင်ပုံကဲ့သို့ စာမျက်နှာဖွင့်ထားစဉ်သာ သိမ်းထားသည်။
- {{ui:Stop early where the picture is clean (adaptive sampling)}} သည် တည်ငြိမ်ပြီးသော pixel များအတွက် sample ပိုမပေးဘဲ ကျန်ပုံသည် ပိုမြန်ပြီးသည်။ {{ui:Noise to accept}} က pixel ရပ်သည့်အခါ ကျန်သော ကြမ်းတမ်းမှု ပမာဏ ဖြစ်သည်။ ပုံအောက်ရှိ လိုင်းက pixel တစ်ခုလျှင် ပျမ်းမျှ sample မည်မျှရသည်ကို ပြသည်။
- {{ui:Caustics (light bent by glass or bounced by mirrors)}} သည် မီးနှင့် နေမှ အလင်းကို ခြေရာခံသဖြင့် မှန်ဘောလုံး အောက်ရှိ တောက်ပသော အစက် သို့မဟုတ် မှန်ထောင့်မှ နံရံပေါ်ရှိ အလင်းသည် ကြမ်းတမ်းမှုမရှိဘဲ သန့်စွာ ထွက်လာသည်။ fog၊ smoke၊ {{ui:Mix the lights after the render}} သို့မဟုတ် render element များ ဖွင့်ထားစဉ် ပိတ်ထားသည်၊ ပုံများအတွက် ဖန်တီးထားပြီး 360° ပုံများ၊ animation များ သို့မဟုတ် Render workspace အတွက် မဟုတ်ပါ။

## ဘယ်လောက်ကြာသလဲ

ပုံကို သင့်ကွန်ပျူတာပေါ်တွင်၊ ၎င်း၏ ဂရပ်ဖစ်ကတ်က ပြုလုပ်သည်; ဘာမျှ upload မလုပ်ပါ။ ကြာချိန်သည် ထိုကတ်ပေါ် မူတည်သည်။ အချိန်သည် pass နှင့် pixel များနှင့်အမျှ တိုးသည်: {{ui:Best}} တွင် {{ui:Draft}} ထက် pass 16 ဆ ရှိပြီး 4K ပုံသည် Full HD ထက် pixel ခန့် လေးဆရှိသည်။ ဂရပ်ဖစ်ကတ်မရှိသော ကွန်ပျူတာသည်လည်း render လုပ်နိုင်သော်လည်း ပိုနှေးသည်။

:::note
ဒိုင်ယာလော့ခ်က browser က ပုံများ render မလုပ်နိုင်ကြောင်း ပြောပါက browser တွင် WebGL 2 မရှိပါ။ ၎င်းကို အပ်ဒိတ်လုပ်ပါ၊ သို့မဟုတ် ၎င်း၏ ဆက်တင်တွင် hardware acceleration ကို ဖွင့်ပါ။
:::
