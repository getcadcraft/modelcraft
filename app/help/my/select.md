{{ui:Select}} ({{key:Space}}) သည် ModelCraft စတင်သော ကိရိယာဖြစ်ပြီး {{key:Esc}} ကို နှိပ်လျှင် ပြန်ရောက်သွားသော ကိရိယာ ဖြစ်သည်။ ရွေးထားသော အရာများ အပြာရောင် ပြောင်းသွားပြီး၊ ညာဘက်ရှိ {{ui:Entity info}} တွင် ၎င်းတို့ ဘာလဲဆိုသည် ပြသသည်။

## နှိပ်ခြင်း

| ဤသို့ လုပ်ပါ | ရွေးချယ်သည် |
|---|---|
| မျက်နှာ သို့မဟုတ် အစွန်းကို နှိပ်ပါ | ထိုမျက်နှာ သို့မဟုတ် အစွန်း |
| group သို့မဟုတ် component ကို နှိပ်ပါ | group သို့မဟုတ် component တစ်ခုလုံး |
| မျက်နှာကို နှစ်ကြိမ်နှိပ်ပါ | မျက်နှာနှင့် ၎င်း၏ အစွန်းများ |
| အစွန်းကို နှစ်ကြိမ်နှိပ်ပါ | အစွန်းနှင့် ၎င်း၏ နှစ်ဘက်ရှိ မျက်နှာများ |
| group သို့မဟုတ် component ကို နှစ်ကြိမ်နှိပ်ပါ | တည်းဖြတ်ရန် ဖွင့်သည် (see [Groups and components](topic:groups-components)) |
| မျက်နှာ သို့မဟုတ် အစွန်းကို သုံးကြိမ်နှိပ်ပါ | ၎င်းနှင့် ဆက်စပ်သော အရာအားလုံး- အရာဝတ္ထု တစ်ခုလုံး |
| အလွတ်နေရာကို နှိပ်ပါ | ဘာမှ မရွေးပါ (ရွေးချယ်မှု ရှင်းသည်) |
| group တည်းဖြတ်နေစဉ် အလွတ်နေရာကို နှစ်ကြိမ်နှိပ်ပါ | group ကို ပိတ်သည် |

အစွန်းများသည် မျက်နှာများထက် ထိရန် ပိုလွယ်သည်- ညွှန်ပြစက်သည် အစွန်းနှင့် ပစ်ဇယ်အနည်းငယ်အတွင်း ရှိသောအခါ နှိပ်ချက်က အစွန်းကို ယူသည်။

## ဘောင် ဆွဲခြင်း

- **ဘယ်မှ ညာသို့** ဆွဲလျှင် အစင်းကြောင်း ဘောင်တစ်ခု ဆွဲသည်- **window** ရွေးချယ်မှု။ ဘောင်အတွင်း လုံးဝရှိသော အရာများသာ ရွေးသည်။
- **ညာမှ ဘယ်သို့** ဆွဲလျှင် အစင်းပြတ် ဘောင်တစ်ခု ဆွဲသည်- **crossing** ရွေးချယ်မှု။ ဘောင်ထိသမျှ အရာကို ရွေးသည်၊ မျက်နှာတစ်ခုကို ဘောင်က လုံးဝ အတွင်းမှာ ရှိနေသောအခါ ရွေးသည်။

group သို့မဟုတ် component တစ်ခုကို အရာတစ်ခုအဖြစ် ရေတွက်သည်- window ဘောင်တွင် ၎င်းအားလုံး ပါရမည်၊ crossing တွင်မူ ထိရုံ လုံလောက်သည်။

## ထည့်ခြင်းနှင့် ဖယ်ခြင်း

နှိပ်ခြင်း သို့မဟုတ် ဆွဲခြင်းလုပ်စဉ် key တစ်ခုကို ဖိထားပါ-

| Key | အကျိုးသက်ရောက်မှု |
|---|---|
| {{key:Shift}} | ပြောင်းသည်- ရွေးမထားသည်ကို ထည့်၊ ရွေးထားသည်ကို ဖယ် |
| {{key:Mod}} | ထည့်သည် |
| {{key:Shift}} နှင့် {{key:Mod}} အတူ | ဖယ်သည် |

မော်ဒယ်ထဲရှိ အရာအားလုံး (သို့မဟုတ် တည်းဖြတ်နေသော group ထဲရှိ အရာအားလုံး) ကို ရွေးရန် {{key:Mod+A}} ကို နှိပ်ပါ။

## ရွေးချယ်မှု ရှင်းရန်

{{key:Esc}} ကို နှိပ်ပါ ({{ui:Select}} ကို ကိရိယာအဖြစ် သုံးထားစဉ်)၊ သို့မဟုတ် အလွတ်နေရာကို နှိပ်ပါ။

## ရွေးထားသော အရာများ ဖျက်ရန်

{{key:Delete}} သို့မဟုတ် {{key:Backspace}} ကို နှိပ်ပါ။ ရွေးထားသော မျက်နှာများ၊ အစွန်းများ၊ group များနှင့် guide များကို တစ်ဆင့်တည်းဖြင့် ဖယ်ရှားသည်; {{key:Mod+Z}} ဖြင့် ပြန်ယူနိုင်သည်။

အစွန်းတစ်ခုကို ဖျက်လျှင် ၎င်းလိုအပ်သော မျက်နှာများကို ဖျက်သည်၊ သို့သော် အစွန်းသည် ပြားချပ်တူညီသော မျက်နှာနှစ်ခုကြားရှိ ခြားထားသည့် အစွန်းသာ ဖြစ်လျှင် မျက်နှာနှစ်ခု တစ်ခုတည်း ဖြစ်သွားသည်။ မျက်နှာတစ်ခုကို ဖျက်လျှင် ၎င်း၏ အစွန်းများ ကျန်ခဲ့သည်။ See [Erase and clean up](topic:erase).

## group အတွင်း ရွေးရန်

group ကို နှိပ်လျှင် group တစ်ခုလုံး ရွေးသည်။ အတွင်းရှိ မျက်နှာကို ရွေးရန် group ကို နှစ်ကြိမ်နှိပ်ပြီး ဖွင့်ကာ နှိပ်ပါ။ group ဖွင့်ထားစဉ် နှိပ်ချက်များသည် အတွင်းရှိ အရာများသို့သာ ရောက်သည်; အခြားအရာများ မှိန်သွားသည်။ ဘာမှ မရွေးထားစဉ် {{key:Esc}} ကို နှိပ်ပါ၊ သို့မဟုတ် အလွတ်နေရာကို နှစ်ကြိမ်နှိပ်ပြီး ပိတ်ပါ။

ဘယ်ဘက်ရှိ {{ui:Outliner}} သည် group နှင့် component များကို နာမည်ဖြင့် ရွေးသည်၊ အခြားအရာများနောက်တွင် ဖုံးနေသောအခါ အသုံးဝင်သည်။
