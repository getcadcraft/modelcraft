{{ui:Print stage}} က သင့်ပရင့် bed ပေါ်တွင် အရာများကို နေရာချပေးပြီး၊ slice လုပ်ကာ ပရင့်ထုတ်စက်သို့ ပို့ပေးသည်။ ဖိုင်ကို အရင် export လုပ်ရန် မလိုပါ။ ၎င်းသည် 3D Print add-on အတွက် ဖြစ်ပြီး မူလအရ ဖွင့်ထားသည်။

:::note
ဤနည်းဖြင့် အစစ်အမှန် ပရင့်ထုတ်စက်တွင် ပရင့်ထုတ်ဖူးခြင်း မရှိသေးပါ။ Slicer အသစ်ဖြစ်သည်: ပထမပရင့်၏ ပထမအလွှာများကို စောင့်ကြည့်ပါ၊ ပို့မီ အလွှာ preview ကို သုံးပါ။
:::

## သင်လုပ်မည့်အရာ

မော်ဒယ်ကို bed ပေါ် တင်ပါ၊ ကိုက်ညီမှု စစ်ပါ၊ slice လုပ်ထားသော အလွှာများကို ကြည့်ပါ၊ ထို့နောက် ပရင့်ထုတ်စက်သို့ ပို့ပါ သို့မဟုတ် G-code ကို သိမ်းပါ။

## အဆင့်များ

1. Toolbar ရှိ {{ui:Print stage}} ကို နှိပ်ပါ။ view အပေါ်တွင် card တစ်ခု ဖွင့်လာပြီး bed ကို အစက်မျဉ်းဖြင့် ပြသည်။
2. **Add from the Library** အောက်တွင် ရှာဖွေရေးကွက်ထဲ အမည်ရိုက်ပါ၊ {{ui:Search}} ကို နှိပ်ပြီး ရလဒ်တစ်ခုပေါ်တွင် {{ui:Add}} ကို နှိပ်ပါ။ အရာသည် အရွယ်အပြည့်ဖြင့် bed ပေါ် ရောက်လာသည်၊ သို့မဟုတ် ကိုက်ညီရန် လျှော့ထားသည်။ သင် ဆွဲပြီးသား သို့မဟုတ် သွင်းပြီးသား၊ view တွင် မြင်ရသော အရာများသည်လည်း bed ပေါ်တွင် ရှိသည်။
3. **On the bed** အောက်တွင် အရာတစ်ခုချင်းစီ၏ အရွယ်အစားကို စစ်ပါ။ **Off the bed** ဟု အမှတ်အသားပြုထားသော အရာကို ရွှေ့ရန် လိုသည်။ view တွင် ရွှေ့၊ လှည့်၊ အရွယ်ပြောင်းရန် ပုံမှန်ကိရိယာများကို သုံးပါ။
4. အရာများကို ဖြန့်ကျက်ရန် {{ui:Arrange on the bed}} ကို နှိပ်ပါ၊ သို့မဟုတ် ကိုက်ညီအောင် လျှော့ရန် {{ui:Fit all on the bed}} ကို နှိပ်ပါ။
5. **Your printer** အောက်တွင် **Bed** အရွယ် သို့မဟုတ် ပရင့်ထုတ်စက် profile တစ်ခုကို ရွေးပါ။
6. **Print settings** အောက်တွင် **Material**, **Quality** နှင့် **Infill %** ကို ရွေးပါ၊ ပုံသဏ္ဍာန်က လိုအပ်ပါက **Add supports under overhangs** ကို အမှန်ခြစ်ပါ။
7. {{ui:Preview layers}} ကို နှိပ်ပြီး **Layer** slider ကို ရွှေ့ကာ slice လုပ်ထားသော အလွှာများကို ကြည့်ပါ။ နောက်မှ stage သို့မဟုတ် ဆက်တင်များ ပြောင်းပါက {{ui:Preview layers}} ကို ထပ်နှိပ်ပါ။
8. **Connection** အောက်တွင် {{ui:USB cable}}, {{ui:Klipper (Moonraker)}}, {{ui:OctoPrint}} သို့မဟုတ် {{ui:PrusaLink}} ကို ရွေးပါ။ USB အတွက် {{ui:Connect}} ကို နှိပ်ပါ။ network ပရင့်အတွက် **Address** (နှင့် မေးပါက **API key**) ရိုက်ထည့်ပြီး {{ui:Test the connection}} ကို နှိပ်ပါ။
9. {{ui:Send to 3D printer}} ကို နှိပ်ပါ။ card က bed ရှင်းလင်းပြီး မှန်ကန်သော material တင်ပြီးပြီလားဟု မေးပြီး အချိန်၊ material နှင့် အပူချိန်များကို ပြသည်။ ပို့ရန် အတည်ပြုပါ။

ပရင့်စက် စတင်နေကြောင်း မက်ဆေ့ချ်ရလာမည်။ {{ui:Stop the print}} က အပူပေးစက်၊ fan နှင့် motor များကို ပိတ်သည်။ ဖိုင်တစ်ခုသာ လိုချင်ပါက {{ui:Save the G-code instead}} ကို နှိပ်ပါ။

## မှတ်ချက်များ

- USB အတွက် ကွန်ပျူတာပေါ်ရှိ Chrome သို့မဟုတ် Edge လိုအပ်ပြီး ပရင့် ပြီးသည်အထိ စာမျက်နှာ ဖွင့်ထားရမည်။ ပိတ်လိုက်ပါက stream ရပ်သွားမည်။
- Network ပရင့်သည် ဤဆိုက်ကို ခွင့်ပြုရမည် (Moonraker တွင် `cors_domains` ထဲ ထည့်ပါ; OctoPrint တွင် CORS ကို ဖွင့်ပြီး API key ကို ကူးပါ)။ သင့် browser က သင့် network ပေါ်ရှိ စက်များသို့ ဝင်ရန် ခွင့်တောင်းနိုင်သည်။
- သင်၏ နှိပ်ချက်မရှိဘဲ ဘာမျှ ချိတ်ဆက်ခြင်း သို့မဟုတ် ပို့ခြင်း မဖြစ်ပါ။
- Slicer စာရင်းသည် **Slicer** အောက်တွင် ရှိသည်။ {{ui:CadCraft basic (included, fastest)}} ကို built in ဖြင့် ထည့်ထားသည်။ Kiri:Moto, PrusaSlicer, OrcaSlicer နှင့် Bambu Lab P2S တို့သည် ကိုယ်ပိုင် add-on များဖြစ်ပြီး card မှ သို့မဟုတ် {{ui:Settings}} › {{ui:Add-ons}} အောက်တွင် ဖွင့်နိုင်သည်။ PrusaSlicer နှင့် OrcaSlicer တို့သည် သင့်ကိုယ်ပိုင် မိတ္တူကို သုံးပြီး ကွန်ပျူတာပေါ်ရှိ CadCraft Studio မှ အလုပ်လုပ်သည်။
- Closed solid မဟုတ်သော အပိုင်းများကို ထုတ်ချန်ထားပြီး card က ထိုအရာ၏ ဘယ်လောက်ပါဝင်သည်ကို ပြောသည်။
- Resin ပရင့်ထုတ်စက်များအတွက် [resin ပရင့်ထုတ်စက်အတွက် slice ပြုလုပ်ခြင်း](topic:resin-printing) ကို ကြည့်ပါ။ မော်ဒယ်ကို အရင် စစ်ဆေးရန် သို့မဟုတ် ပြင်ရန် [Supports, wall thickness, hollowing နှင့် repair](topic:print-tools) ကို ကြည့်ပါ။
