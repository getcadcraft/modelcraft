## သင် သိရှိရမည့်အရာများ

မော်ဒယ်တစ်ခုကို လူများစွာ တစ်ပြိုင်နက် အလုပ်လုပ်သည့်အခါ ဘာဖြစ်သလဲ။ CadCraft Studio သည် Live TeamWork session ကို စတင်ပြီး ဝင်ရောက်သည် (Share၊ Join); ဤစာမျက်နှာသည် မော်ဒယ်ကိုယ်တိုင် အကြောင်း ဖြစ်သည်။

## ကိုယ်ပိုင် group တွင် အလုပ်လုပ်ခြင်း

လူတိုင်းသည် မော်ဒယ်တစ်ခုတည်းကို တည်းဖြတ်ပြီး သင့်ကိုယ်ပိုင် ပြောင်းလဲမှုများ ချက်ချင်း ပေါ်သည်။ ပြောင်းလဲမှုများ ပေါင်းပုံသည် သင် ပြောင်းသည့်အရာပေါ် မူတည်သည်:

- **ချထားပြီးသော group နှင့် component များကို ရွှေ့ခြင်း၊ အမည်ပေးခြင်း၊ အရောင်ခြယ်ခြင်း သို့မဟုတ် ဖျောက်ခြင်း** သည် ပေါင်းသည်: group နှစ်ခုကို ရွှေ့သော လူနှစ်ဦးစလုံး၏ ရွှေ့မှုများ ရှိနေသည်။
- **group တစ်ခု၏ အတွင်းရှိ ဂျီသြမေတြီ** (ယင်း၏ edges နှင့် faces: ဆွဲခြင်း၊ push/pull၊ ဖျက်ခြင်း) သည် တစ်ခုတည်း ဖြစ်သည်။ လူနှစ်ဦးက group တစ်ခုတည်းကို တစ်ပြိုင်နက် ပုံသွင်းသောအခါ ဒုတိယ ပြောင်းလဲမှုကို ပြန်ယူပြီး status bar က ထိုသို့ ပြောသည်။ အခြား group များ တစ်ခုနှင့် တစ်ခု မပိတ်ဆို့ပါ။
- **Loose ဂျီသြမေတြီ** (group တစ်ခုအတွင်း မရှိသော) သည် မော်ဒယ်၏ ကိုယ်ပိုင် group ဖြစ်သည်: တစ်ယောက်တည်းသာ တစ်ချိန်တည်း ပုံသွင်းနိုင်သည်။

ထို့ကြောင့် အလုပ်ကို ဘယ် group တွင် ဘယ်သူလုပ်မည်ကို သဘောတူပါ၊ သို့မဟုတ် စတင်မီ လူတစ်ဦးစီ၏ အပိုင်းအတွက် group တစ်ခုစီ ပြုလုပ်ပါ။ လမ်းညွှန်များ၊ အတိုင်းအတာများနှင့် section planes များသည် တစ်ခုချင်းစီ ပေါင်းသည်; scenes၊ tags၊ storeys နှင့် ပုံဆွဲ axes များသည် နောက်ဆုံး ပြောင်းလဲသူထံ ရောက်သည်။

## တစ်ဦးကိုတစ်ဦး မြင်ခြင်း

session တွင် ပါဝင်သူတိုင်းတွင် ကိုယ်ပိုင် အရောင် ရှိသည်။ လူတစ်ဦးစီ၏ ညွှန်ပြချက်ကို ၎င်းတို့၏ အရောင်ဖြင့် မြား အဖြစ် နာမည်နှင့်အတူ မြင်ရပြီး၊ သင်ကြည့်နေသော မြင်ကွင်း၏ အနက်အတိုင်း၊ ၎င်းတို့ ရွေးထားသည့်အရာပတ်လည် ၎င်းတို့၏ အရောင်ဖြင့် အစင်းကြောင်း box တစ်ခု ပေါ်သည်။

ညွှန်ပြချက်များ၊ နာမည်များနှင့် ရွေးချယ်မှုများသည် session အတွက်သာ ဖြစ်သည်: ဖိုင်တွင် ဘယ်တော့မျှ မသိမ်းပါ၊ မည်သူ၏ undo တွင်မျှ မဝင်ပါ။ ၎င်းတို့သည် လူတစ်ဦးစီ ရောက်နေသော နေရာသို့ ချောမွေ့စွာ ရွေ့သဖြင့် ဆက်သွယ်မှု နှေးသော်လည်း ချောမွေ့နေဆဲ ဖြစ်သည်။

## သင့်ကိုယ်ပိုင် အလုပ်ကို undo လုပ်ခြင်း

{{key:Mod+Z}} က သင့်ကိုယ်ပိုင် နောက်ဆုံး အဆင့်ကို undo လုပ်ပြီး အခြားသူများ၏ အရာကို မထိပါ။ ထို့နောက် တစ်စုံတစ်ဦးက တူညီသော အရာကို ပြောင်းခဲ့လျှင် ဘာမျှ undo မဖြစ်ပါ၊ status bar က ဘယ်သူ ဖြစ်သည်ကို ပြောသည်။

## Browser မှ ဝင်ခြင်း

Studio မရှိသော အဖွဲ့ဝင်တစ်ဦးသည် host ၏ ကုဒ်အောက်ရှိ ပုံကို ဖုန်း၊ tablet သို့မဟုတ် ကွန်ပျူတာဖြင့် တူညီသော ကွန်ရက်ပေါ်မှ စကင်ဖတ်နိုင်သည်။ ModelCraft သည် browser တွင် ဖွင့်ပြီး host က ခွင့်ပြုသည်နှင့် host ၏ မော်ဒယ်ဖြင့် ပြည့်သွားသည်။ invite link သည် အခြား ကွန်ရက်မှ ဝင်ခွင့် ပေးနိုင်သည်: host တွင် app အတွက် Team Cloud Plan seat လိုအပ်ပြီး အခြားသူများ အခမဲ့ ဝင်သည်၊ link သည် host ၏ session ဖွင့်နေသည့်အချိန်တွင်သာ အလုပ်လုပ်သည်။

## Session ပြီးဆုံးချိန်

host သာ မော်ဒယ်ကို သိမ်းသည်။ အခြားသူများအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားရှိသည်: ထိန်းထားလိုလျှင် သိမ်းပါ။
