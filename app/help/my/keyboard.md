ဤများသည် ModelCraft စတင်သည့် တွန်း-ဆွဲ ကီးများ ဖြစ်သည်။ အခြားပုံစံအတွက်၊ အောက်ရှိ [Modeler keys](topic:keyboard#modeler-keys) နှင့် [ModelCraft settings](topic:settings) ကို ကြည့်ပါ။

ဖြတ်လမ်းများသည် 3D မြင်ကွင်း သို့မဟုတ် ကိရိယာဘား ခလုတ်တစ်ခုက အာရုံစိုက်ထားသောအခါ အလုပ်လုပ်သည်။ ကြားမှ ပန်းချပ်ထဲရှိ အကွက်တစ်ခုကို ရိုက်ထားလျှင် သို့မဟုတ် {{ui:Style}} ရှိ စာရင်းကို ပြောင်းလျှင် ပထမ 3D မြင်ကွင်းကို နှိပ်ပါ၊ သို့မဟုတ် သင့်ကီးများသည် ထိုအကွက်သို့ ရောက်သွားမည်။ ကီးများကို ကွန်ပျူတာတစ်ခုစီတွင် မည်သို့ ရေးသည်ကို [Keys, mice and trackpads](common:keys) တွင် ကြည့်ပါ။

## Esc

{{key:Esc}} ကို နှိပ်တိုင်း အဆင့်တစ်ခုစီ ပြန်ထွက်သည်:

1. ကိရိယာ လုပ်နေဆဲ အရာကို ပယ်ဖျက်သည် (ဆွဲနေသော မျဉ်း၊ တွန်း/ဆွဲခြင်း၊ ရွှေ့ခြင်း)။ အားလုံး မူလအတိုင်း ပြန်သွားသည်။
2. {{ui:Select}} သို့ ပြောင်းသည်။
3. ရွေးချယ်မှုကို ရှင်းသည်။
4. တည်းဖြတ်နေသော အုပ်စုကို ပိတ်သည်။

ဇာတ်ခုံများ ဖွင့်နေလျှင်လည်း ရပ်သည်။ တန်ဖိုးအကွက်တွင် {{key:Esc}} က သင်ရိုက်ထားသည်ကို ရှင်းပြီး မြင်ကွင်းသို့ ပြန်သွားသည်။

## ကိရိယာ အလုပ်လုပ်နေစဉ်

| ကီး | လုပ်ဆောင်ချက် |
|---|---|
| ဂဏန်း တစ်ခု သို့မဟုတ် `. , - ' " [ < * /` အနက် တစ်ခု | တန်ဖိုးအကွက်တွင် ရိုက်ခြင်း စတင်သည် |
| {{key:Enter}} | တန်ဖိုးအကွက်တွင် ရိုက်ထားသည်ကို အသုံးပြုသည် |
| {{key:Right}} | အနီ ဝင်ရိုးသို့ သော့ခတ်သည် (ဖြုတ်ရန် ထပ်နှိပ်ပါ) |
| {{key:Left}} | အစိမ်း ဝင်ရိုးသို့ သော့ခတ်သည် |
| {{key:Up}} | အပြာ ဝင်ရိုးသို့ သော့ခတ်သည် |
| {{key:Down}} | ပထမနှိပ်မှုမတိုင်မီ နောက်ဆုံး ညွှန်ပြခဲ့သော အနားနှင့် အပြိုင် သော့ခတ်သည် |
| {{key:Shift}} ကို ဖိထား | ကပ်နေသော ဦးတည်ချက်ကို ဖိထားစဉ် ကိုင်ထားသည် |
| {{key:Ctrl}}၊ {{key:Mod}} သို့မဟုတ် {{key:Alt}} (Move) | ရွှေ့ခြင်းနှင့် ကူးခြင်းကြား ပြောင်းသည် |

မြှားကီး သော့ခတ်ခြင်းများသည် {{ui:Line}}၊ {{ui:Rectangle}}၊ {{ui:Circle}}၊ {{ui:Polygon}}၊ {{ui:Move}}၊ {{ui:Scale}} နှင့် {{ui:Tape}} (အမှတ်မှ တိုင်းသောအခါ) တွင် ပထမနှိပ်မှုပြီးနောက် အလုပ်လုပ်သည်။ {{ui:Push/pull}} သည် အမြဲ မျက်နှာ၏ ဦးတည်ချက်အတိုင်း ရွှေ့ပြီး သော့ခတ်ခြင်း မရှိပါ။ {{ui:Rotate}} တွင် မြှားကီးများက ပထမနှိပ်မှုပြီးနောက် "Locked" မက်ဆေ့ချ်ကို ပြသော်လည်း လှည့်ထောင့်ကို မပြောင်းပါ။

## အခြားအချိန်များတွင် မြှားကီးများ

ကိရိယာ တစ်ခုခု လုပ်နေခြင်း မရှိသောအခါ မြှားကီးများက ကင်မရာကို ရွှေ့သည်:

| ကီး | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | လှည့်ကြည့်ရန် (Orbit) |
| မြှားနှင့်အတူ {{key:Shift}} | ရွှေ့ကြည့်ရန် (Pan) |

| {{key:Shift}} + {{key:Mod}} + နှိပ်ခြင်း | {{ui:Select}}: ရွေးချယ်မှုမှ ဖယ်သည် |

## ထရက်ပက်ဒ်

နှစ်ချောင်းပွတ်ခြင်းက ဘာလုပ်သည်ဆိုသည်မှာ {{ui:Settings}} › {{ui:ModelCraft}} › Scrolling အပေါ် မူတည်သည်:

| လက်ဟန် | ထရက်ပက်ဒ် (သို့မဟုတ် တွက်ချက်ထားသော) | မောက်စ် ဘီးလ် |
|---|---|---|
| နှစ်ချောင်း ပွတ်ခြင်း | လှည့်ကြည့်ရန် | ညွှန်ပြချက်ဆီသို့ ချဲ့/ချုံ့ |
| {{key:Shift}} + နှစ်ချောင်း ပွတ်ခြင်း | ရွှေ့ကြည့်ရန် | ချဲ့/ချုံ့ |
| ညှစ်ခြင်း (Pinch) | ညွှန်ပြချက်ဆီသို့ ချဲ့/ချုံ့ | ညွှန်ပြချက်ဆီသို့ ချဲ့/ချုံ့ |
| နှစ်ချောင်း နှိပ်ဆွဲခြင်း (ဒုတိယနှိပ်မှု ကိုင်ထား) | ရွှေ့ကြည့်ရန် | ရွှေ့ကြည့်ရန် |

Copy၊ paste၊ undo၊ save နှင့် open သည် အပေါ်တွင် ဖော်ပြထားသော ကီးများကို ဆက်သုံးသည်။ ရိုက်ထားသော တန်ဖိုးများ၊ တန်ဖိုးအကွက်နှင့် {{ui:Push/pull}} သည် ပုံစံနှစ်မျိုးလုံးတွင် တူညီစွာ အလုပ်လုပ်သည်။

## တို့စ်မျက်နှာပြင်

| လက်ဟန် | လုပ်ဆောင်ချက် |
|---|---|
| ထိခြင်း | လက်ရှိကိရိယာဖြင့် နှိပ်ခြင်း |
| နှစ်ကြိမ် ထိခြင်း | နှစ်ကြိမ် နှိပ်ခြင်း |
| ဖိ၊ ဆွဲ၊ လွှတ် | မောက်စ်ဖြင့် ဖိ၊ ဆွဲ၊ လွှတ်ခြင်းနှင့် တူသည် |
| လက်ချောင်းနှစ်ချောင်း- ညှစ်ခြင်း | ချဲ့/ချုံ့ |
| လက်ချောင်းနှစ်ချောင်း- အတူရွှေ့ခြင်း | ရွှေ့ကြည့်ရန် (Settings › ModelCraft › Touch screen က Orbit ဖြစ်အောင် ပြောင်းနိုင်သည်) |
| လက်ချောင်းသုံးချောင်း- အတူရွှေ့ခြင်း | လှည့်ကြည့်ရန် (လက်ချောင်းနှစ်ချောင်းက လှည့်ကြည့်သောအခါ ရွှေ့ကြည့်ရန်) |
| လက်ချောင်းတစ်ချောင်း ငြိမ်ငြိမ် ထိန်းထားခြင်း | Enter ကဲ့သို့ ကိရိယာကို ပြီးစီးစေသည်; ဘာမျှ မဖြစ်နေသောအခါ ဆွဲလျှင် လှည့်ကြည့်ရန် |
| တစ်ချောင်းလက်ဟန် တစ်ခုအတွင်း ဒုတိယလက်ချောင်း | ထိုလုပ်ဆောင်ချက်ကို ပယ်ဖျက်သည် |
| {{ui:Orbit}} ကိရိယာ၊ ထို့နောက် လက်ချောင်းတစ်ချောင်း ဆွဲခြင်း | လှည့်ကြည့်ရန် |

တို့စ်မျက်နှာပြင်ပေါ်တွင် တန်ဖိုးရိုက်ရန် အောက်ရှိ တန်ဖိုးအကွက်ကို ထိပြီး ရိုက်ကာ ကီးဘုတ်၏ Enter (သို့မဟုတ် Go) ကီးကို နှိပ်ပါ။

## Move ရှိရာနေရာ

Move သည် {{ui:Move}} ကိရိယာ၊ ကီး {{key:M}} တွင် ရှိသည်: ရွှေ့မည့်အရာကို ရွေး၊ အခြေအမှတ်ကို နှိပ်၊ ထို့နောက် ဒုတိယအမှတ် သို့မဟုတ် အကွာအဝေးကို ရိုက်ပါ။ See [Move, copy and make arrays](topic:move-copy)။
