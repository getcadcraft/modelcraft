အရောင်များက မော်ဒယ်၏ အပိုင်းများကို ခွဲခြားရာတွင် ကူညီပြီး **ပစ္စည်းများ** (အုတ်၊ နံရံဖုံးပြား၊ ခေါင်မိုး၊ သစ်သား၊ ကျောက်၊ ကြွေပြား၊ ကွန်ကရစ်၊ ကပ်ခြယ်၊ မြက်၊ မှန်၊ သတ္တု) က သင်တည်ဆောက်ထားသော ပစ္စည်းနှင့် ဆင်တူစေသည်။ နှစ်ခုလုံး တူညီစွာ သုတ်ဆေးသည်။

## အရောင်ရွေးရန်

ညာဘက်ရှိ {{ui:Colors}} အပိုင်းတွင် တစ်ကြောင်းလိုက် တစ်သားတည်းအရောင်များ၊ {{ui:Default}} (မျဉ်းဖြတ်ထားသော အရောင်: အရောင်မရှိ) နှင့် အခြားအရောင်အတွက် {{ui:+}} swatch ကို ပြသည်။ တစ်ခုကို နှိပ်ပြီး လက်ရှိအရောင် ဖြစ်စေပါ။ Paint tool သည် ထိုအရောင်ဖြင့် စတင်သည်။

## သုတ်ဆေးခြင်း

1. {{key:B}} ({{ui:Paint}}) ကို နှိပ်ပါ၊ သို့မဟုတ် တစ်ခုမှ မရွေးထားဘဲ အရောင်တစ်ခုကို နှိပ်ပါ။ (တစ်ခုခု ရွေးထားစဉ် အရောင်ကို နှိပ်လျှင် ရွေးထားသည်များကို ချက်ချင်း သုတ်သည်။)
2. မျက်နှာပြင်တစ်ခုကို နှိပ်၍ သုတ်ပါ။
3. အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်တစ်ခုကို နှိပ်လျှင် ထိုမိတ္တူကို သုတ်သည်: ကိုယ်ပိုင်အရောင်မရှိသော ၎င်း၏ မျက်နှာပြင်များက ဤအရောင်ကို ယူသည်။ အတွင်းတွင် သင်သုတ်ထားသော မျက်နှာပြင်များက ၎င်းတို့၏ အရောင်ကို ထိန်းသည်။

အရာများစွာကို တစ်ပြိုင်နက် သုတ်ရန် ဦးစွာ ရွေးပြီး အရောင်တစ်ခုကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Paint}} ဖြင့် ၎င်းတို့ထဲမှ တစ်ခုခုကို နှိပ်ပါ။ ၎င်းသည် undo ခြေလှမ်းတစ်ခုတည်း ဖြစ်သည်။

| ဖိထားရန် | ထို့နောက် မျက်နှာပြင်ကို နှိပ် | ဘာကို သုတ်မလဲ |
|---|---|---|
| — | | ထိုမျက်နှာပြင် |
| {{key:Ctrl}} | | ဆက်စပ်ပြီး အရောင်တူသော မျက်နှာပြင်အားလုံး |
| {{key:Shift}} | | သင်လုပ်ဆောင်နေသော အုပ်စုအတွင်းရှိ ထိုအရောင်ရှိ မျက်နှာပြင်အားလုံး |
| {{key:Alt}} | | ဘာမျှမဟုတ်: ထိုအရောင်ကို အစားထိုးယူသည် |

မျက်နှာပြင်တစ်ခုကို အရောင်မဲ့သို့ ပြန်ထားရန် {{ui:Default}} ကို ရွေး၍ ထိုမျက်နှာပြင်ကို နှိပ်ပါ။

## ပစ္စည်းဖြင့် သုတ်ဆေးခြင်း

{{ui:Colors}} အောက်ရှိ {{ui:Materials}} အပိုင်းတွင် ပစ္စည်းစာကြည့်တိုက်ကို အမျိုးအစားအလိုက် ဖော်ပြသည်: အုတ်နှင့် block၊ နံရံဖုံးပြား၊ ခေါင်မိုး၊ သစ်သား၊ ကျောက်၊ ကြွေပြား၊ ကွန်ကရစ်၊ ကပ်ခြယ်၊ မြေ၊ မှန်နှင့် သတ္တု။ swatch ပေါ်တွင် ကာဆာတင်လိုက်လျှင် ၎င်း၏အမည်ကို ပြသည်။ တစ်ခုကို နှိပ်ပြီး အရောင်နှင့် တူညီစွာ သုတ်ပါ: {{key:B}}၊ မျက်နှာပြင်၊ အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်များကို နှိပ်ပါ; သို့မဟုတ် ဦးစွာ ရွေးပြီး ပစ္စည်းကို နှိပ်ပါ။

- **အရိပ်ထည့်** (Shaded) ပုံစံတွင် မျက်နှာပြင်များက ပစ္စည်း၏ texture ကို ပြသည်။ ဖုံးကွယ်မျဉ်း၊ wireframe နှင့် x-ray ပုံစံများတွင် ၎င်း၏အရောင်ကို ပြသည်။
- Texture များသည် မျက်နှာပြင်တစ်ခုစီတွင် **အလျားလိုက် ဖြောင့်စွာ** နှင့် **အပေါ်သို့** ပြေးသည်: အုတ်အတန်းများသည် နံရံတိုင်းတွင် ဖြောင့်နေသည်၊ ခေါင်မိုးစေ့များသည် ခေါင်မိုးစောက်တစ်လျှောက် ပြေးသည်၊ ကြမ်းပြင်ပေါ်ရှိ ဘုတ်များက အနီဝင်ရိုးကို လိုက်သည်။ ၎င်းတို့သည် အမှန်အရွယ်အစားဖြစ်သည် (အုတ်တစ်လုံး ~215 mm ရှည်), ထို့ကြောင့် အဝေးမည်မျှဖြစ်စေ မှန်ကန်ပုံရသည်။
- [ပုံရိပ်ဖော်ထုတ်ထားသော ပုံ](topic:render) တွင် ပစ္စည်းများက texture၊ roughness နှင့် မှန်နှင့် သတ္တုအတွက် ၎င်းတို့၏ တောက်ပမှုကို ထိန်းသည်။
- {{ui:Paint}} ဖြင့် {{key:Alt}}-နှိပ်ခြင်းက မျက်နှာပြင်တစ်ခု၏ ပစ္စည်းကိုလည်း ယူသည်။

Texture များကို ModelCraft ကိုယ်တိုင် ဆွဲသည်၊ ထို့ကြောင့် အော့ဖ်လိုင်းတွင် အလုပ်လုပ်ပြီး မည်သည့်အရာအတွက်မဆို အခမဲ့ သုံးနိုင်သည် (CC0)။

## ကွန်ပိုနင့်များနှင့် အရောင်များ

ကွန်ပိုနင့် **အတွင်း**ရှိ မျက်နှာပြင်တွင် သုတ်ထားသော အရောင်သည် မိတ္တူတိုင်းတွင် ပြသည်၊ ဘာလို့ဆိုသော် မိတ္တူများက အဓိပ္ပာယ်တစ်ခုတည်းကို မျှဝေသောကြောင့်ဖြစ်သည်။ ကွန်ပိုနင့်ကို ပိတ်ထားစဉ် ပြင်ပမှ **မိတ္တူ**တစ်ခုတွင် သုတ်ထားသော အရောင်သည် ထိုမိတ္တူတစ်ခုတည်းနှင့်သာ သက်ဆိုင်သည်၊ ထို့ကြောင့် ကွန်ပိုနင့်တစ်ခု၏ မိတ္တူနှစ်ခုတွင် အရောင်မတူနိုင်ပါ။ {{ui:Entity info}} သည် ရွေးထားသော မျက်နှာပြင်၊ အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်၏ အရောင်ကို ပြသည်။

## ဖိုင်များတွင် အရောင်များ

- ModelCraft ဖိုင်သည် အရောင်နှင့် ပစ္စည်းအားလုံးကို ထိန်းသည်။
- အခြားဖော်မတ်များက texture အစား ပစ္စည်း၏ **အရောင်** (အဝေးမှ အသွင်) ကို ရသည်: glTF, Collada, OBJ, DWG နှင့် DXF၊ နှင့် 3D printing စစ်ဆေးမှု။ glTF, Collada နှင့် OBJ တွင် ပစ္စည်းက ၎င်း၏အမည်ကို ထိန်းသည်၊ ဥပမာ `Material_brick-red`။
- **glTF (.glb)** နှင့် **Collada (.dae)**: အရောင်တစ်ခုစီက ပစ္စည်းတစ်ခု ဖြစ်လာသည်။ အရောင်မတူစွာ ပြသထားသော ကွန်ပိုနင့်ကို အရောင်တစ်ခုအတွက် တစ်ကြိမ်ရေးသည်။ glTF က သွင်းထားသော texture များကိုလည်း texture အဖြစ် ရေးသည်။
- **OBJ**: export လုပ်လျှင် ဖိုင်နှစ်ခု ဒေါင်းလုဒ်ဆွဲသည်: `.obj` နှင့် အရောင်ပါသော `.mtl` ပစ္စည်းဖိုင်။ တူညီသော ဖိုင်တွဲတွင် ထားပါ။ သွင်းထားသော texture များရှိလျှင် `.obj`၊ `.mtl` နှင့် ပုံများသည် `.zip` တစ်ခုတည်းအဖြစ် ရောက်လာသည်။
- **DWG** က အရောင်အတိအကျကို ထိန်းသည်; **DXF** က CAD စံအရောင် 255 ခုထဲမှ အနီးဆုံးကို သုံးသည်။
- **STL** နှင့် **PLY** တွင် အရောင်ပါသည်: STL က VisCAM / SolidView စည်းမျဉ်းဖြင့် (မဖတ်နိုင်သော ပရိုဂရမ်များက လျစ်လျူရှုသည်), PLY က point တစ်ခုစီတွင် အရောင်အဖြစ်။ ကြည့်ပါ [ဖိုင်ဖော်မတ်များ အသေးစိတ်](topic:formats)။

:::tip
မျက်နှာပြင်ရှေ့ကို [အကွာအဝေးဖယ်](topic:draw-faces) ပြီးနောက် ဘောင်ကို မီးသွေးရောင်၊ မှန်ကို အပြာရောင် သုတ်ပါ။ ၎င်းက မျက်နှာပြင်ပေါ်ရှိ ဖန်သားပြင်ကို ပုံဖော်နိုင်သည်။
:::
