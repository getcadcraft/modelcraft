[timeline](topic:animation) က ကင်မရာနှင့် အုပ်စုများ၊ ကွန်ပိုနင့်များ တစ်ခုလုံးကို ရွှေ့ပေးသည်။ **Animate** workspace က ထိုထက်ပိုပြီး key ထားနိုင်ပြီး timeline တွင် key ထားပြီးသော အရာများကို ပုံသွင်းရန်နှင့် ပြန်သုံးရန် views နှစ်ခု ထပ်ပါလာသည်။

## ဖွင့်ရန်

toolbar ရှိ workspace စာရင်းတွင် {{ui:Animate}} ကို ရွေးပါ။ timeline သည် view အောက်တွင် ဖွင့်ပြီး toolbar တွင် Animate အုပ်စုများ ({{ui:Keys}}၊ {{ui:Play}}၊ {{ui:Timeline}}) ပေါ်လာသည်။ ညာဘက်ရှိ panel တွင် playhead မှာ key ထားနိုင်သော အရာများ ပြသည်။

## ဂုဏ်သတ္တိတစ်ခုကို key ထားခြင်း

playhead မှာ panel တွင် ပါဝင်သည်များ-

- **ရွေးထားသော object**: ၎င်း၏ {{ui:Place}}၊ {{ui:Turn (°)}} နှင့် {{ui:Size}}၊ တစ်ခုစီတွင် ဂဏန်းသုံးလုံးစီ။ ဂဏန်းရိုက်ပြီး {{key:Enter}} နှိပ်ပါ- playhead မှာ key ထားပြီး object ထိုနေရာသို့ ရောက်သွားမည်။ row ဘေးရှိ diamond က လက်ရှိတန်ဖိုးကို key ထားသည်။ diamond အပြည့်ဆိုလျှင် playhead မှာ key ရှိပြီးသား ဖြစ်သည်။
- **မီးချောင်းများ**: မီးချောင်းတစ်ခုစီ၏ {{ui:Brightness (lm)}}၊ {{ui:Spread (°)}} (spot lamps) နှင့် {{ui:Colour}}။
- **ကင်မရာ**: ကင်မရာ ရွေ့နေစဉ် zoom လုပ်ရန် {{ui:Lens angle (°)}}။

{{ui:Key transform}} (သို့မဟုတ် {{key:I}}) က ရွေးထားသော အုပ်စု သို့မဟုတ် ကွန်ပိုနင့်တိုင်း၏ နေရာ၊ လှည့်မှုနှင့် အရွယ်အစားကို တစ်ပြိုင်နက် key ထားသည်။ {{ui:Key camera}} (သို့မဟုတ် {{key:K}}) က ကင်မရာကို key ထားသည်။ {{ui:Auto key}} ဖွင့်ထားလျှင် ဤနည်းဖြင့် နေရာ၊ လှည့်မှုနှင့် အရွယ်အစား key ထားသော အုပ်စုကို ရွှေ့တိုင်း key အသစ် ရရှိသည်။

လှည့်မှုများသည် X၊ ထို့နောက် Y၊ ထို့နောက် Z ပတ်လည် ထောင့်သုံးခု ဖြစ်သည်။ 180° ကျော်ပြီး key ထားသော လှည့်မှုသည် တူညီသော ဘက်သို့ ဆက်သွားသည် (190° သည် 190° ဖြစ်ကျန်ပြီး −170° မဟုတ်)၊ ထို့ကြောင့် ဘီးတစ်ခုသည် အကြိမ်များစွာ လည်နိုင်သည်။

:::tip
timeline ရှိ {{ui:Key selected}} ဖြင့် key ထားသော အုပ်စုသည် နေရာ အပြည့်အစုံ key များ ရှိသည်။ ၎င်း၏ row ရှိ curve ခလုတ်က ၎င်းကို နေရာ၊ လှည့်မှုနှင့် အရွယ်အစား curves အဖြစ် ပြောင်းပေးသည် (key တိုင်းတွင် နေရာတူညီသည်) ထို့ကြောင့် {{ui:Curves}} တွင် ပုံသွင်းနိုင်သည်။
:::

## Shape keys (morphs)

**shape key** သည် တူညီသော [mesh](topic:meshes) ၏ နောက်ထပ်ပုံသဏ္ဍာန်ဖြစ်သည်- မျက်နှာပေါ်ရှိ အပြုံး၊ တံခါး၏ ဖောင်းမှု၊ ကွေးနေသော ရွက်တစ်ရွက်။ ၎င်း၏ slider သည် mesh မူလအတိုင်း (0) မှ ထိုပုံသဏ္ဍာန် (1) အထိ ရောစပ်သည်။ key များစွာက ပေါင်းထည့်ပေးသည်။

1. Animate workspace တွင် mesh တစ်ခုကို ရွေးပါ- panel တွင် ၎င်း၏ {{ui:Shape keys}} ပြသည်။
2. {{ui:Add shape key}} ကို နှိပ်ပါ။ ModelCraft က အသစ်ထည့်သော key ကို တည်းဖြတ်နေစဉ် [Mesh workspace](topic:mesh-edit) သို့ သွားသည်- point များရွှေ့ပါ၊ extrude လုပ်ပါ၊ sculpt လုပ်ပါ- mesh ကို လိုချင်သော ပုံသဏ္ဍာန်သို့ ပြောင်းပါ။
3. {{ui:Animate}} သို့ ပြန်လာပြီး {{ui:Done}} ကို နှိပ်ပါ။ mesh သည် မူလအတိုင်း ပြန်ရောက်ပြီး key တွင် သင့်ပြောင်းလဲမှု ရှိနေသည်။

ထို့နောက် key ၏ slider ကို ဆွဲ (သို့မဟုတ် တန်ဖိုးရိုက်) ပြီး ရောစပ်ပါ။ diamond သည် playhead မှာ တန်ဖိုးကို key ထားသည်၊ ထို့ကြောင့် key တစ်ခုသည် အချိန်ကြာလာသည်နှင့်အမျှ ကြီးလာ သို့မဟုတ် မှိန်သွားနိုင်သည်။ track ရှိပြီးသားဆိုလျှင် တန်ဖိုးအသစ်တိုင်း playhead မှာ key ထားမည်။ pencil က key ၏ပုံသဏ္ဍာန်ကို ထပ်တည်းဖြတ်သည် (mesh က {{ui:Done}} မတိုင်မီ အပြည့်အစုံ ပြသည်၊ {{ui:Cancel}} က key ကို မူလအတိုင်း ထားသည်)၊ မျက်စိ အိုင်ကွန်က key ကို ပိတ်/ဖွင့်သည်၊ အမှိုက်ပုံးက ဖျက်သည်။

key ကို တည်းဖြတ်နေစဉ် ထည့်သော vertex သည် mesh ကိုယ်တိုင်နှင့် ပိုင်သည်- ပုံသဏ္ဍာန်တိုင်းတွင် သင်ထားသည့် နေရာတွင် ရှိနေသည်။

:::note
Shape keys က [modifiers](topic:modifiers) မတိုင်မီ mesh ကို ရွှေ့သည်- Subdivision modifier က ရောစပ်ထားသော ပုံသဏ္ဍာန်ကို ချောမွေ့စေသည်။ ပုံရိပ်နှင့် ဗီဒီယိုများက frame တိုင်းတွင် keys ကို ပြသည်။
:::

## Armatures: mesh ကို ကွေးစေသော bones

**armature** သည် [mesh](topic:meshes) အတွင်းရှိ bones အစုတစ်ခု ဖြစ်သည်။ bones များကို ပုံသွင်းလိုက်လျှင် mesh က လိုက်ပါသည်၊ point တစ်ခုစီသည် ၎င်း၏ **weights** ပြောသလောက် လိုက်သည်။

1. Animate workspace တွင် mesh ကို ရွေးပြီး panel ရှိ {{ui:Add an armature}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:Rig}} အုပ်စုရှိ {{ui:Add bone}})- ပထမ bone သည် mesh ၏ ခြေထောက်မှ အလယ်အထိ တက်သွားသည်။
2. bone တစ်ခုကို ရွေးထားစဉ် {{ui:Add a child bone}} က ၎င်း၏ tip မှ နောက်တစ်ခုကို ထည့်သည်။ bone တစ်ခုစီ၏ {{ui:Head}}၊ {{ui:Tip}}၊ {{ui:Roll (°)}} နှင့် မည်သည့်အရာမှ {{ui:Hangs from}} ကို panel တွင် သတ်မှတ်ပါ၊ တခြား bone မှ ချိတ်ထားသော bone သည် ၎င်းနှင့်အတူ ရွေ့သည်။ တခြားသူများကို လမ်းညွှန်ရုံသာ လုပ်သော bone အတွက် {{ui:Moves the mesh}} ကို ဖယ်ပါ။
3. {{ui:Automatic weights}} ကို နှိပ်ပါ- bone တစ်ခုစီက ၎င်းနှင့် အနီးဆုံး point များကို ထိန်းယူပြီး ထိန်းချုပ်မှုသည် mesh ပေါ် ချောချောမွေ့မွေ့ ပျံ့သွားသည်၊ ထို့ကြောင့် bone နှစ်ခုကြား point များက ၎င်းတို့ကို မျှဝေသည်။ {{ui:Nearest bones only}} က ပိုမြန်ပြီး ပိုတင်းကျပ်သော ခွဲခြမ်းမှု ဖြစ်သည်။

**Pose** bones ကို {{ui:Pose}} ({{key:P}}) ဖြင့် ပုံသွင်းပါ- bone ကို နှိပ်ပြီး ရွေးပါ၊ view ၏ ဝင်ရိုးပတ်လည် လှည့်ရန် ဆွဲပါ၊ ရွှေ့ရန် {{key:Shift}}-ဆွဲပါ။ သို့မဟုတ် {{ui:Pose}} အောက်တွင် ၎င်း၏ {{ui:Place}}၊ {{ui:Turn (°)}} နှင့် {{ui:Size}} ကို ရိုက်ပါ၊ လှည့်မှုများသည် bone ၏ ကိုယ်ပိုင်ဝင်ရိုးများတွင်၊ နားနေသည့်နေရာမှ စတင်သည်။ diamonds နှင့် {{ui:Key the whole pose}} က playhead မှာ pose ကို key ထားသည်။ bone တွင် keys ရှိပြီးသားဆိုလျှင် ၎င်းကို ပုံသွင်းသည်နှင့် ထိုနေရာတွင် key ထားမည်။ {{ui:Reset this bone}} နှင့် {{ui:Reset the pose}} က bones များကို နားနေသည့်အနေအထားသို့ ပြန်ထားသည်။

ရွေးထားသော bone အတွက် **weights ဆေးခြယ်ရန်** ({{key:W}}): mesh က နားနေစဉ် ပြသည်၊ မျက်နှာတစ်ခုစီသည် ထို bone က ဘယ်လောက်ထိန်းသည်ဆိုသည့်အတိုင်း အရောင်ခြယ်သည်- အနီသည် အကုန်၊ အပြာသည် ဘာမျှမရှိ။ ထိန်းချုပ်မှု ထည့်ရန် ဆေးပါ ({{key:Mod}} က ဖယ်ရှားသည်၊ {{key:Shift}} က ချောမွေ့စေသည်)၊ {{ui:Size (px)}} နှင့် {{ui:Strength}} က brush ကို သတ်မှတ်သည်။ {{ui:Keep each point's weights adding up to 1}} ဖွင့်ထားလျှင် bone တစ်ခုကို ပိုပေးသည့်အခါ တခြားမှ အလားတူ ယူသည်။ ဆေးချက်တစ်ကြိမ်စီသည် model ၏ undo တစ်ဆင့် ဖြစ်သည်။

{{ui:Skin}} က bones များကြား point တစ်ခု မည်သို့ရွေ့သည်ကို ရွေးသည်- {{ui:Linear (fast)}} က bones များ၏ ရွေ့မှုကို ရောစပ်ပြီး ကွေးနေသော အဆစ်ကို အနည်းငယ် ညှစ်သည်။ {{ui:Dual quaternion (keeps volume at joints)}} က point ကို အဆစ်ပတ်လည် လှည့်ပေးသဖြင့် တံတောင်ဆစ် သို့မဟုတ် ဒူးဆစ်သည် ၎င်း၏ ထူထဲမှုကို ထိန်းသည် (bone ၏ {{ui:Size}} က ထိုအခါ အသားကို မဆန့်ပါ)။

:::note
Shape keys က ဦးဆောင်သည်၊ ထို့နောက် armature၊ ထို့နောက် [modifiers](topic:modifiers) ဖြစ်သည်။ view၊ ပုံရိပ်နှင့် ဗီဒီယိုများအားလုံးက ပုံသွင်းထားသော mesh ကို ပြသည်။ mesh ၏ weights ကို ၎င်းနှင့်အတူ သိမ်းသည်၊ bones နှင့် ၎င်းတို့၏ pose ကို animation နှင့်အတူ သိမ်းသည်။
:::

## IK နှင့် constraints

**constraint** သည် ၎င်း၏ keys ပြီးနောက် bone သို့မဟုတ် အရာတစ်ခုကို စည်းမျဉ်းတစ်ခုဖြင့် ရွှေ့သည်။ အရာ (သို့မဟုတ် armature ထဲတွင် bone) ကို ရွေးပြီး {{ui:Constraints of …}} အောက်တွင် တစ်ခု ထည့်ပါ၊ အများအပြားဆိုလျှင် စာရင်းထားသော အစဉ်အတိုင်း လည်ပတ်သည် (မြှားများက ပြောင်းသည်)၊ တစ်ခုစီတွင် {{ui:How much}} (0 မှ 1၊ ၎င်း၏ diamond ဖြင့် တခြား ဂုဏ်သတ္တိကဲ့သို့ key ထားနိုင်သည်) နှင့် on/off ခလုတ် ရှိသည်။

| Constraint | ဘာအတွက် | ဘာလုပ်သလဲ |
|---|---|---|
| {{ui:Reach (IK)}} | Bones | bone နှင့် ၎င်းချိတ်ထားသော bones ({{ui:Bones in the chain}}) က ၎င်း၏ tip သည် target သို့ ရောက်အောင် ကွေးသည်။ bones နှစ်ခုနှင့် {{ui:Pole (the bend points to it)}} ရှိလျှင် တံတောင်ဆစ် သို့မဟုတ် ဒူးဆစ်က pole ဘက်သို့ ညွှန်သည်၊ ရှည်သော chains များက ချောမွေ့စွာ ကွေးသည်။ ရောက်နိုင်ခြေ အပြင်ဘက်ဆိုလျှင် chain က target ဘက်သို့ တိုက်ရိုက် ညွှန်သည်။ |
| {{ui:Look at}} | နှစ်မျိုးလုံး | {{ui:Axis that points}} က target ကို မျက်နှာမှန်အောင် လှည့်ပြီး {{ui:Axis kept up}} ကို အပေါ်နီးဆုံး ထားသည်။ |
| {{ui:Copy transforms}} | နှစ်မျိုးလုံး | target ၏ နေရာ၊ လှည့်မှု သို့မဟုတ် အရွယ်အစား၊ အမှတ်ခြစ်ထားသောအရာများကို ယူသည်။ |
| {{ui:Limits}} | နှစ်မျိုးလုံး | ကိုယ်ပိုင် နေရာ၊ လှည့်မှု (ဒီဂရီ) သို့မဟုတ် အရွယ်အစားကို ဝင်ရိုးတစ်ခုစီအလိုက် {{ui:min}} နှင့် {{ui:max}} ကြား ထားသည်၊ ဝင်ရိုးတစ်ခုကို လွတ်ထားရန် အတွဲကို ကွက်လပ်ထားပါ။ |
| {{ui:Child of}} | နှစ်မျိုးလုံး | target ကို ရွေးချိန်က နှစ်ခုစလုံး ရှိနေသော နေရာမှစ၍ ၎င်းမှ ချိတ်ထားသလို ၎င်းနှင့်အတူ ရွေ့သည်။ |
| {{ui:Follow path}} | အရာများ | [curve object](topic:curves) ပေါ် {{ui:Along the curve}} တွင် ထိုင်သည် (0 သည် အစ၊ 1 သည် အဆုံး၊ ခရီးသွားစေရန် key ထားပါ)၊ {{ui:Turn along the curve}} ဖြင့် ၎င်းနှင့်အတူ ဦးတည်သည်။ |

target သည် ဖွင့်ထားသော အုပ်စုထဲရှိ အခြားအရာတစ်ခု၊ တူညီသော armature ၏ bone တစ်ခု၊ သို့မဟုတ် သင်ရိုက်သော {{ui:A point}} ဖြစ်နိုင်သည် (အရာတစ်ခု၏ point သည် model ၏ coordinates တွင်၊ bone ၏ point သည် ၎င်း၏ mesh တွင် ရှိသည်)။ IK ခြေထောက်အတွက် ခြေဖဝါး ရောက်သင့်သော နေရာတွင် target ကို ထားပြီး target ကို key ထားပါ၊ သို့မဟုတ် {{ui:How much}} ကို key ထားပြီး keys နှင့် IK ကြား ခြေထောက်ကို လွှဲပေးပါ။

:::tip
ဖွင့်ထားသော အုပ်စုထဲရှိ လမ်းကြောင်းကို လိုက်သော အရာတစ်ခုကို ကြည့်သော အရာသည် လမ်းကြောင်းပေါ်ရှိ ၎င်းကို မြင်သည်- ModelCraft က အရာများ၏ အစဉ်မည်သို့ပင်ဖြစ်စေ targets များကို အရင်တွက်သည်။
:::

## ရူပဗေဒ- ကျခြင်း၊ ပုံ့ခြင်းနှင့် တိုက်ခြင်း

အရာများ ကျခြင်းနှင့် တစ်ခုနှင့်တစ်ခု တိုက်ခြင်းကို ပြုလုပ်ပြီး ရလဒ်ကို keys အဖြစ် ထိန်းသိမ်းပါ။

1. အုပ်စု၊ ကွန်ပိုနင့် သို့မဟုတ် mesh တစ်ခုကို ရွေးပြီး {{ui:Physics}} အောက်ရှိ ၎င်း၏ {{ui:Rigid body}} ကို သတ်မှတ်ပါ- {{ui:Falls and collides}} (ရွေ့သည်) သို့မဟုတ် {{ui:Stays put, gets in the way}} (စားပွဲ၊ နံရံ၊ ဆင်ခြေလျှောတစ်ခု)။ ကျနေသော အရာတစ်ခုကို ၎င်း၏ {{ui:Shape}} ပေးပါ- {{ui:Box (its bounds)}} သို့မဟုတ် {{ui:Ball (round its bounds)}}၊ ၎င်း၏ {{ui:Mass (kg)}}၊ {{ui:Friction}} နှင့် {{ui:Bounce}} (0 သည် မထိုး၊ 1 သည် မူလအမြင့်အတိုင်း ပြန်ခုန်)။
2. {{ui:The whole model}} အောက်တွင် {{ui:From (s)}} နှင့် {{ui:To (s)}}၊ {{ui:Gravity (m/s², down)}} နှင့် {{ui:A ground to land on}} ရှိ/မရှိ (နှင့် ၎င်း၏ အမြင့်) ကို သတ်မှတ်ပါ။
3. {{ui:Bake physics}} ကို နှိပ်ပါ (panel တွင် သို့မဟုတ် {{ui:Physics}} အုပ်စုတွင်)။ ကျနေသော အရာတိုင်းသည် အချိန်နှစ်ခုကြား frame တိုင်းတွင် နေရာ၊ လှည့်မှုနှင့် အရွယ်အစား key ရရှိသည်၊ တခြား animation ကဲ့သို့ ပြန်ဖွင့်ပါ။

ပြန် bake လုပ်လျှင် ထို keys များကို အစားထိုးသည်၊ {{ui:Remove baked keys}} က ဖယ်ရှားသည်။ အရာများသည် နားနေမှုမှ စတင်သည်၊ ၎င်းတို့၏ keys၊ curves နှင့် constraints က {{ui:From (s)}} တွင် ထားသည့် နေရာ (ထိုအချိန်မတိုင်မီ key ထားသော ရွေ့မှုသည် ကျခြင်းအထိ မဆက်ပါ)။ {{ui:Steps a frame}} ပိုများလျှင် မြင့်သော အပုံများ ပိုတည်ငြိမ်သည်၊ အဆုံးတွင် တစ်ခုခု ရွေ့နေသေးလျှင် status bar က ပြောသည်။

:::note
Shapes များသည် အရာတစ်ခုစီ၏ bounds ပတ်လည် boxes နှင့် balls ဖြစ်သည်။ box သည် ၎င်း၏ ထောင့်များ၊ အစွန်းအလယ်များနှင့် မျက်နှာအလယ်များဖြင့် ထိသည်၊ ထို့ကြောင့် boxes များသည် မျှော်လင့်သလို ပုံ့ပြီး လဲကျနိုင်သည်။ အထည်များ၊ အရည်များ၊ အရာများကြား joints နှင့် တိကျသော ပုံသဏ္ဍာန်များကို မတည်ဆောက်ရသေးပါ။
:::

## Drivers

**driver** သည် shape key ကို လက်ဖြင့်မဟုတ်ဘဲ အခြားအရာများမှ သတ်မှတ်သည်- key ၏ driver ကို ဖွင့်ပါ (ဂဏန်းတွက်စက် ခလုတ်)၊ **expression** ရေးပါ၊ ထို့နောက် ထဲရှိ အမည်တစ်ခုစီကို ဘာဖတ်ရမည်ကို ({{ui:Reads}}) ပေးပါ- စက္ကန့်ဖြင့် အချိန်၊ frame၊ နေရာ၊ X၊ Y သို့မဟုတ် Z ဝင်ရိုးတစ်လျှောက် လှည့်မှု သို့မဟုတ် အရွယ်အစား၊ မီးချောင်း၏ တောက်ပမှု၊ သို့မဟုတ် တခြား shape key။ ဥပမာ `v` က တံခါး၏ Z ပတ်လည် လှည့်မှုကို ဖတ်လျှင် `clamp(v / 90, 0, 1)` က တံခါးဖွင့်သည်နှင့်အမျှ ပုံသဏ္ဍာန်ကို ဖွင့်ပေးသည်။

Expressions တွင် ဂဏန်းများ၊ အမည်များ၊ `+ - * / % ^` နှင့် ကွင်းများ၊ `sin cos tan asin acos atan atan2 abs sqrt exp log floor ceil round sign pow min max clamp lerp smoothstep rad deg` function များနှင့် `pi` နှင့် `e` တို့ကို သုံးနိုင်သည်။ အမှားတစ်ခုကို ထောက်ပြပြီး ဘာမျှ မပြောင်းပါ။ driver ဖြင့် ထိန်းထားသော key ၏ slider က driver ၏ တန်ဖိုးကို ပြသည်၊ ဖယ်ရှားမချင်း driver က key ၏ track ထက် အနိုင်ရသည်။

## Keys ရွေးခြင်းနှင့် ပြောင်းခြင်း (Keys view)

{{ui:Keys}} က track တစ်ခုစီအတွက် row တစ်ခု ပြသည်- ကင်မရာ၊ ရွေ့နေသော အုပ်စု တစ်ခုစီ၊ ဂုဏ်သတ္တိတစ်ခုစီ ("Lamp 2 · Brightness (lm)"; ဂုဏ်သတ္တိ keys များသည် စက်ဝိုင်း ဖြစ်သည်)။

- key ကို နှိပ်ပြီး ရွေးပါ၊ {{key:Shift}}-နှိပ် သို့မဟုတ် {{key:Mod}}-နှိပ်ခြင်းဖြင့် ရွေးမှုထဲသို့ ထည့် သို့မဟုတ် ဖယ်ပါ။ rows များပေါ်တွင် {{key:Shift}}-ဆွဲခြင်းက အတွင်းရှိ key အားလုံးကို ထည့်သော ဘောင်တစ်ခု ဆွဲပေးသည်။
- ရွေးထားသော key ကို ဆွဲပါ၊ အားလုံး ရွေ့သည်။ {{key:Left}} / {{key:Right}} က frame တစ်ခု ရွှေ့သည် ({{key:Shift}}: ဆယ်ခု)။
- {{key:Mod+C}} က ရွေးထားသော keys များကို ကူးသည်၊ {{key:Mod+V}} က playhead မှ တူညီသော tracks ပေါ်သို့ ကူးထည့်သည် (ModelCraft tab အခြားတစ်ခုကလည်း ကူးထည့်နိုင်သည်)။
- {{ui:Stretch}} က playhead မှ ဘေးရှိ ဂဏန်းအလိုက် ရွေးထားသော keys များကို ခွာထုတ်သည် (2 = နှစ်ဆ ဝေးသည်၊ 0.5 က ဆွဲသိပ်သည်)။
- ease စာရင်းက ရွေးထားသော key တိုင်း နောက်သို့ မည်သို့ရွေ့သည်ကို သတ်မှတ်သည်။

## Curves ပုံသွင်းခြင်း (Curves view)

{{ui:Curves}} သည် တန်ဖိုးတစ်ခုစီ အချိန်အလိုက် ဂရပ်ဖြစ်သည်- အချိန်သည် ဘေးသို့၊ တန်ဖိုးသည် အပေါ်သို့။ ဘယ်ဘက်ရှိ စာရင်းတွင် ပြရန် curves များကို အမှတ်ခြစ်ပါ (X၊ Y နှင့် Z သည် အနီ၊ အစိမ်းနှင့် အပြာ)။

- key (လေးထောင့်) ကို နှိပ်ပြီး ရွေးပါ၊ ပိုရွေးရန် {{key:Shift}}-နှိပ်ပါ၊ သို့မဟုတ် ဘောင်တစ်ခု ဆွဲပါ။ ရွေးထားသော key ကို ဆွဲပြီး ၎င်း၏ အချိန်နှင့် တန်ဖိုးကို ပြောင်းပါ၊ ရွေးထားများစွာဆိုလျှင် ဆွဲခြင်းက အချိန်အတိုင်း ရွှေ့သည်။
- ရွေးထားသော key တွင် **handles** နှစ်ခု ပြသည်။ တစ်ခုကို ဆွဲပြီး ထိုဘက်ရှိ curve ကို ပုံသွင်းပါ။ {{ui:Handles}} က ၎င်းတို့၏ အပြုအမူကို ပြောသည်- {{ui:Automatic}} (ပတ်လည် keys များကို ဖြတ်သော ချောမွေ့သည့် curve)၊ {{ui:Pointing at the next key}}၊ {{ui:Aligned}} (နှစ်ခုက မျဉ်းဖြောင့်တစ်ကြောင်းတည်း ရှိနေသဖြင့် curve တွင် ထောင့်မရှိ) သို့မဟုတ် {{ui:Free}}။
- {{ui:From the chosen keys}} က ရွေးထားသော key တစ်ခုစီ နောက်တစ်ခုသို့ မည်သို့ရွေ့သည်ကို သတ်မှတ်သည်- {{ui:Curve (handles)}}၊ {{ui:Smooth}}၊ {{ui:Steady}}၊ {{ui:Slow in and out}} သို့မဟုတ် {{ui:Hold}}။
- {{ui:Before}} နှင့် {{ui:After}} က curve သည် ၎င်း၏ keys အပြင်ဘက်တွင် ဘာလုပ်သည်ကို သတ်မှတ်သည်- {{ui:Hold}} (ပထမ သို့မဟုတ် နောက်ဆုံးတန်ဖိုးတွင် ရှိနေသည်)၊ {{ui:Repeat}}၊ {{ui:Back and forth}} သို့မဟုတ် {{ui:Repeat and carry on}} (ထပ်တိုင်း နောက်ဆုံးပြီးသွားသော နေရာမှ စသည်- ဘီးက ဆက်လှိမ့်၊ လမ်းလျှောက်သူက ဆက်လျှောက်)။
- ဘီးက ချဲ့သည် ({{key:Mod}}- တန်ဖိုးများသာ၊ {{key:Shift}}- အချိန်သာ)၊ အလယ်ခလုတ်ဖြင့် သို့မဟုတ် {{key:Alt}} ဖြင့် ဆွဲ၍ ရွှေ့ပါ၊ {{ui:Show all}} သို့မဟုတ် {{key:Home}} က ပြထားသော curves အားလုံးကို ကိုက်ညီစေသည်။ အလွတ်နေရာကို နှိပ်ပါက playhead ထိုနေရာသို့ ရွေ့သည်။ {{key:Delete}} က ရွေးထားသော keys များကို ဖျက်သည်။

Handles များကို အချိန်အရ ဖြတ်မကျော်အောင် ထိန်းထားသဖြင့် curve သည် နောက်ပြန်မသွားပါ။

## Animations ပြန်သုံးခြင်း (Clips view)

**clip** သည် timeline ပေါ်တွင် သိမ်းထားသော animation (**action**) ကို ဖွင့်ပေးသည်။ clips များကို အစဉ်အတိုင်း ရောစပ်သည်၊ အောက်ပိုင်း rows များက အပေါ်ပိုင်းများကို အုပ်သည်၊ timeline ၏ ကိုယ်ပိုင် tracks များသည် clip အားလုံးထက် အပေါ်ဆုံးတွင် ရှိသည်။

1. အုပ်စုများနှင့် မီးချောင်းများကို ပုံမှန်အတိုင်း key ထားပြီး {{ui:Clips}} ရှိ {{ui:Make a clip}} ကို နှိပ်ကာ action အမည်ပေးပါ။ tracks များက action ဖြစ်လာပြီး clip က ၎င်းတို့ နေရာတွင် ဖွင့်သည် (ကင်မရာသည် timeline တွင် ရှိနေသည်)။
2. ထပ်သုံးလိုလျှင် action ကို ရွေးပြီး {{ui:Add clip}} ကို နှိပ်ပါ- clip အသစ်တစ်ခု playhead မှ စသည်။
3. clip ကို row တစ်လျှောက် ဆွဲ၍ ရွှေ့ပါ။ နှိပ်ပြီး {{ui:Start (s)}}၊ {{ui:Speed}} (2 = နှစ်ဆ မြန်)၊ {{ui:Repeats}}၊ {{ui:How much}} (0 မှ 1)၊ {{ui:Mix}} ({{ui:Replace}} သို့မဟုတ် ၎င်းရှေ့ရှိ clips များ၏ {{ui:Add on top}})၊ {{ui:Outside the clip}} (ဘာမျှမရှိ၊ ၎င်း၏အဆုံးကို ထိန်း သို့မဟုတ် နှစ်ဖက်အဆုံးကို ထိန်း) နှင့် {{ui:Mute}} ကို သတ်မှတ်ပါ။ မြှားများက အစဉ်ကို ပြောင်းသည်၊ အမှိုက်ပုံးက ဖယ်သည် (clip မသုံးတော့သော action သည် ၎င်းနှင့်အတူ ထွက်သွားသည်)။

{{ui:How much}} ပြည့်မှ နည်းသော clip သည် ၎င်းအောက်ရှိအရာမှ ရောစပ်သည်- ၎င်းရှေ့ရှိ clip၊ သို့မဟုတ် animation မပါဘဲ ယခုအတိုင်း ရှိနေသော မီးချောင်း သို့မဟုတ် နေရာ။
