{{ui:Render a picture…}} တွင် Mode အထက်ရှိ **Engine** ရွေးချယ်မှု ရှိသည်။ ကိုယ်ပိုင် engine နှစ်ခုသည် အမြဲရှိပြီး နေရာတိုင်းတွင် အလုပ်လုပ်သည်; add-on များက ထပ်ထည့်နိုင်ပြီး CadCraft Studio တွင် စာရင်းတွင် ဇာတ်ခင်းကို လက်ခံယူသော ပရိုဂရမ်များလည်း ပါဝင်သည်။

| Engine | ဘာလုပ်သလဲ | ဘယ်မှာ |
|---|---|---|
| Built-in: Fast | မြန်ဆန်သော still: နေရောင်၊ ပျော့ပျောင်းသော အရိပ်၊ ဖန်နှင့် သတ္တုပုံစံများ၊ စက္ကန့်ပိုင်းအတွင်း | Browser နှင့် Studio |
| Built-in: Path tracer | မျက်နှာပြင်များကြား အလင်း တုံ့ပြန်ခြင်း၊ သင်၏ graphics card သို့မဟုတ် processor ပေါ်တွင်၊ render queue နှင့် သင့်ကွန်ရက်ရှိ အခြားကွန်ပျူတာများ | Browser နှင့် Studio |
| Add-on ၏ engine | ပုံဆွဲပြီး ပုံကို ပြန်ပေးသည်: [အခြားပရိုဂရမ်ဖြင့် ပုံဆွဲခြင်း](topic:render-other-program) ကို ကြည့်ပါ | Browser (JavaScript ဖြင့် ရေးထားသော engine) သို့မဟုတ် Studio (ပရိုဂရမ် run သော engine) |
| ဇာတ်ခင်းကို လက်ခံယူသော ပရိုဂရမ် | Studio က ဇာတ်ခင်းကို ၎င်း၏ ဖိုလ်ဒါတွင် ထားပြီး ညီညွတ်အောင် ထိန်းထားသည် | Studio |
| တခြားပရိုဂရမ်တွင် ဖွင့်ရန် … | ဇာတ်ခင်းကို သိမ်းပြီး ပရိုဂရမ်တစ်ခုတွင် ဖွင့်သည်; ပြန်မလာပါ: [အခြားပရိုဂရမ်တွင် ဇာတ်ခင်း ဖွင့်ခြင်း](topic:render-open-in) ကို ကြည့်ပါ | Web က ဖိုင်ကို သိမ်းသည် |

## ရွေးချယ်မှု အလုပ်လုပ်ပုံ

- Fast သို့မဟုတ် Path tracer ကို ရွေးလျှင် Mode ပါ အလိုအလျောက် ပြောင်းသည်၊ နောက်ပြန်လည်း အတူတူ။ အခြား engine ကို မသုံးဘဲ နေသူများအတွက် dialog ၏ အခြားအရာများ မပြောင်းပါ။
- မရရှိနိုင်သော engine သည် စာရင်းတွင် ရှိနေပြီး အကြောင်းပြချက် ("not found", "needs a newer version") ဖြင့် ပြသည်; ၎င်းကို ရွေး၍ မရပါ။ Browser တွင် Studio တွင်သာ run သော engine က "saves a file" ဟု ပြသည်: {{ui:Render a picture…}} သည် ဇာတ်ခင်းနှင့် ၎င်း၏ ဆက်တင်များကို ထို ပရိုဂရမ်သို့ သယ်ဆောင်ရန် ဖိုင်တစ်ခုအဖြစ် သိမ်းပေးသည်။
- ရွေးထားသော ရွေးချယ်မှုကို ဖိုင်၏ render ဆက်တင်များနှင့်အတူ သိမ်းထားပြီး၊ နောက်ဆုံး ရွေးထားသော engine သည် ကိုယ်ပိုင်ရွေးချယ်မှု မရှိသော ဖိုင်များအတွက် စတင် engine ဖြစ်သည်။
- အခြား ပရိုဂရမ်မှ ပုံသည် ပုံကို ဘယ်ပရိုဂရမ်နှင့် ဗားရှင်းက ဆွဲခဲ့သည်ကို dialog နှင့် render queue တွင် ပြသည်။ [Render](topic:render) စာမျက်နှာ၏ ကတိများသည် **ကိုယ်ပိုင်** engine များအတွက်သာ ဖုံးလွှမ်းသည်: အခြားပရိုဂရမ်သည် အလင်း၊ အရောင်အသွေးနှင့် sampling ကို ကိုယ်ပိုင်နည်းဖြင့် လုပ်သည်၊ ထို့ကြောင့် ဇာတ်ခင်းတစ်ခုရဲ့ ပုံ နှစ်ပုံသည် ကင်မရာ၊ နေ၊ မီးချောင်းနှင့် exposure တွင် ဆင်တူသည်၊ pixel အတိအကျ မတူညီပါ။

## Engine တိုင်းကို ပေးသောအရာ

ဇာတ်ခင်းသည် အခြားပရိုဂရမ်သို့ **package** အဖြစ် သွားသည်: မော်ဒယ်ကို USD ဖိုင်အဖြစ် ([USD အဖြစ် သိမ်းခြင်း](topic:usd) က ရေးသော ဖိုင်အတိုင်း)၊ နှင့် USD importer ကို ယုံကြည်၍ မရသော အရာများ — တိကျသော material တန်ဖိုးများ၊ အလုပ်လုပ်နေသော မီးချောင်းများနှင့် ၎င်းတို့၏ ပါဝါနှင့် light profile များ၊ နေ၊ ကောင်းကင်၊ exposure နှင့် dialog က ဆွဲမည့်အတိုင်း ကင်မရာ — ပါဝင်သော ဆက်တင်ဖိုင်။ ဘယ်နေရာသို့မှ upload မလုပ်ပါ။

## Render queue

အခြားပရိုဂရမ်အတွက် ပုံ သို့မဟုတ် animation သည် ကိုယ်ပိုင်ပုံကဲ့သို့ [render queue](topic:render#the-render-queue) တွင် စောင့်နိုင်သည်; ၎င်း၏ job က ၎င်းအတွက် ဘယ် engine ဖြစ်သည်ကို မှတ်ထားသည်။ Animation တစ်ခုလုံးကို ပရိုဂရမ်သို့ တစ်ကြိမ်တည်း ပို့သည်။
