**Sculpt** workspace သည် ရွံ့နှင့်အလား brush များဖြင့် mesh ကို ပုံသွင်းသည်: မျက်နှာပြင်ပေါ်တွင် ဆွဲလိုက်လျှင် ၎င်းသည် မြင့်တက်၊ နိမ့်ကျ၊ ချောမွေ့၊ သို့မဟုတ် စက်ဝိုင်း brush အောက်တွင် pointer ကို လိုက်သည်၊ အလယ်တွင် အပြင်းဆုံးဖြစ်ပြီး ထိပ်ဖျားတွင် မရှိတော့ပါ။

## စတင်ရန်

mesh ကို ရွေးပြီး Workspace စာရင်းတွင် {{ui:Sculpt}} ကို ရွေးပါ။ အုပ်စု သို့မဟုတ် component သည် Mesh workspace ကဲ့သို့ ဦးစွာ mesh ဖြစ်လာသည်။ Brush များသည် mesh ၏ vertex များပေါ်တွင် အလုပ်လုပ်သဖြင့် vertex ပိုများသော mesh သည် ပိုနုသော ပုံသဏ္ဌာန်များ ရနိုင်သည်: ဦးစွာ ၎င်းကို subdivide လုပ်ပါ (Mesh workspace ၏ {{ui:Subdivide}}၊ သို့မဟုတ် သင် Apply လုပ်သော Subdivision surface modifier)၊ သို့မဟုတ် {{ui:Detail}} ကို ဖွင့်ပါ။

## Brush များ

| Brush | Key | ၎င်းက လုပ်သည့်အရာ |
| --- | --- | --- |
| {{ui:Draw}} | {{key:D}} | brush အောက်ရှိ မျက်နှာပြင်ကို မြှင့်တင်သည် |
| {{ui:Clay}} | {{key:C}} | ပြားသော အလွှာများ တည်ဆောက်သည်၊ အနိမ့်ပိုင်းကို အရင်ဖြည့်သည် |
| {{ui:Smooth}} | {{key:S}} | အဖုအထစ်များကို ညှိသည်; မည်သည့် brush ဖြင့်မဆို ချောမွေ့စေရန် {{key:Shift}} ကို ဖိထားပါ |
| {{ui:Grab}} | {{key:G}} | pointer နှင့်အတူ မျက်နှာပြင်ကို ဆွဲယူသည် |
| {{ui:Inflate}} | {{key:I}} | မိမိ၏ ကိုယ်ပိုင်ဦးတည်ရာအတိုင်း မျက်နှာပြင်ကို ဖောင်းစေသည် |
| {{ui:Crease}} | {{key:Shift+C}} | ထက်မြက်သော အနက်ကြောင်းတစ်ခုကို ဖြတ်သည် |
| {{ui:Pinch}} | {{key:P}} | မျက်နှာပြင်ကို brush ၏ အလယ်သို့ ဆွဲသွင်းသည် |
| {{ui:Flatten}} | {{key:T}} | မျက်နှာပြင်ကို ၎င်း၏ ပျမ်းမျှ ပြားချပ်ဆီသို့ ဖိသည် |
| {{ui:Mask}} | {{key:M}} | အခြား brush များမှ မျက်နှာပြင်ကို ကာကွယ်သော mask ကို ဆေးသည် |

ဆွဲနေစဉ် {{key:Ctrl}} ကို ဖိထားပါက ပြောင်းပြန် လုပ်နိုင်သည် (မြှင့်မည့်အစား နှိမ့်ခြင်း၊ ကြောင်းအစား တောင်ကြောင်း၊ mask ဖယ်ခြင်း) သို့မဟုတ် {{ui:Take away}} ကို ဖွင့်ပါ။

## အရွယ်အစားနှင့် အင်အား

brush ၏ အရွယ်အစားသည် မျက်နှာပြင်ပေါ်ရှိ pixel ဖြင့် ဖြစ်သဖြင့် ဘယ်လောက် zoom လုပ်လုပ် တူညီစွာ ခံစားရသည်: {{key:[}} နှင့် {{key:]}} က ၎င်းကို ပိုသေး၊ ပိုကြီးစေသည်၊ {{key:Shift+[}} နှင့် {{key:Shift+]}} က ၎င်း၏ အင်အားကို ပြောင်းသည်။ panel တွင် နှစ်ခုလုံး ပြသည်။

tablet ပေါ်ရှိ pen ဖြင့် ပိုဖိလျှင် brush ပိုကြီးပြီး ပိုအားကောင်းသည်; panel က နှစ်ခုလုံးကို ပိတ်နိုင်သည်။

## Mirror၊ mask နှင့် detail

- {{ui:Mirror X}} ({{key:X}}) သည် အနီဝင်ရိုးဖြတ်၍ နှစ်ဖက်ကို တစ်ပြိုင်နက် ပုံသွင်းသည်၊ မျက်နှာနှင့် ပုံများအတွက်။
- ပုံသွင်းနေစဉ် mask သည် ပိုမှောင်ပြသည်။ {{ui:Clear mask}} ({{key:Alt+M}}) က ၎င်းကို ဖယ်သည်၊ {{ui:Invert mask}} ({{key:Ctrl+I}}) က အခမဲ့ဖြစ်သော အရာကို mask လုပ်ပြီး mask ထားသောအရာကို လွတ်စေသည်။ mask သည် mesh နှင့်အတူ သိမ်းထားသည်။
- {{ui:Detail}} သည် ပုံသွင်းသည့်နေရာတွင် တြိဂံများ ထည့်သည်: panel တွင် သတ်မှတ်ထားသော အရွယ်အစား (မျက်နှာပြင်ပေါ် pixel) ထက် ရှည်သော အနားများကို brush အောက်တွင် ခွဲသည်။ တြိဂံ mesh လိုအပ်ပြီး ပထမဆုံး တစ်ခု ပြုလုပ်ရန် မေးမည်။

ဆွဲတိုင်း တစ်ကြိမ် undo အဆင့် ဖြစ်သည်။

:::note
Detail သည် တြိဂံများ ထည့်သာသည်; သေးငယ်လာသော တြိဂံများကို မဖယ်ပါ။ Remesh (Mesh workspace) က mesh တစ်ခုလုံးကို ထပ်ညှိသည်။
:::
