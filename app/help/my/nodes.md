**Nodes** တည်းဖြတ်ကိရိယာသည် ဘောက်စ်များကို ကြိုးဖြင့် ချိတ်ဆက်ခြင်းဖြင့် ဂျီဩမေတြီကို တည်ဆောက်သည်။ ဘောက်စ်တစ်ခုစီ (node) သည် အလုပ်သေးသေးတစ်ခုကို လုပ်သည်: နံပါတ်တစ်ခု၊ အမှတ်တစ်ခု၊ စက်ဝိုင်းတစ်ခု၊ loft တစ်ခု ဖန်တီးသည်။ တစ်ခု၏ ရလဒ်ကို နောက်တစ်ခု၏ input သို့ ချိတ်ဆက်ပြီး အစမှ နံပါတ်ကို ပြောင်းလဲလျှင် မော်ဒယ်သည် လိုက်ပြောင်းမည်။

ညာဘက် panel မှ ဖွင့်ပါ: {{ui:Nodes}} › {{ui:Nodes…}}။ graph ရှိပြီးသား ဖိုင်တစ်ခုသည် ၎င်းဖြင့် အလိုအလျောက် ဖွင့်မည်။ ၎င်းသည် 3D view အပေါ်ရှိ ဝင်းဒိုးတစ်ခု ဖြစ်သည်: ခေါင်းစဉ်ဘားကို ဆွဲ၍ ရွှေ့ပါ၊ ထောင့်ကို ဆွဲ၍ အရွယ်ပြောင်းပါ။

## ချိတ်ဆက်ခြင်း

1. ဘယ်ဘက်ရှိ စာရင်းမှ node တစ်ခုကို ရွေးပါ (ရှာဖွေရေး အကွက်တွင် ရိုက်၍ ကျဉ်းနိုင်သည်၊ <kbd>Enter</kbd> သည် ပထမ တူညီမှုကို ထည့်သည်)။ canvas အလယ်တွင် ပေါ်လာမည်။
2. node တစ်ခု၏ ညာဘက်ရှိ စက်ဝိုင်းပုံ **output** အစက်မှ အခြား node ၏ ဘယ်ဘက်ရှိ စက်ဝိုင်းပုံ **input** အစက်သို့ ဆွဲပါ။ ကိုက်ညီပါက အစက်သည် အစိမ်း ဖြစ်လာပြီး မကိုက်ညီပါက အနီ ဖြစ်သည်; အကြောင်းရင်းကို သိလိုပါက အစက်ပေါ်တွင် ညွှန်ပြပါ။
3. ဘာမျှ မချိတ်ဆက်ထားသော input သည် ရိုက်ထည့်သော တန်ဖိုးအတွက် ဘောက်စ်တစ်ခုကို ပြသည်။ နံပါတ်ကို ရိုက်ပြီး <kbd>Tab</kbd> ကို နှိပ်ပါ: ရလဒ် ပြန်တည်ဆောက်မည်။
4. node ၏ ခေါင်းစဉ်ဘားရှိ သေးငယ်သော စက်ဝိုင်းသည် ၎င်း၏ **eye** ဖြစ်သည်။ eye ဖွင့်ထားသော node သည် 3D view တွင် ဆွဲပြသည်: မျဉ်းကွေးများအတွက် လိုင်းများ၊ မျက်နှာပြင်များအတွက် အရိပ်ထည့်ထားသော ပုံ၊ အမှတ်များအတွက် အစက်များ။

node ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲ၍ ရွှေ့ပါ။ နောက်ခံကို ဆွဲ၍ ရွှေ့ကြည့်ပါ၊ wheel ကို လှည့်၍ ချဲ့/ချုံ့ပါ။ <kbd>Delete</kbd> သည် ရွေးထားသော node ကို ဖယ်ရှားသည်။ {{ui:Tidy}} သည် node များကို ကော်လံများအဖြစ် စီသည်၊ {{ui:Fit}} သည် အားလုံးကို မြင်ကွင်းထဲသို့ ယူလာသည်၊ {{ui:Undo}} နှင့် {{ui:Redo}} သည် သင့်ပြင်ဆင်မှုများကို ပြန်ဖျက်/ပြန်လုပ်သည်။

## အမျိုးအစားများနှင့် ယူနစ်များ

Port များတွင် အမျိုးအစား ရှိသည်: နံပါတ်၊ yes/no၊ အမှတ်၊ vector၊ curve၊ surface၊ mesh၊ solid၊ သို့မဟုတ် ၎င်းတို့အနက် မည်သည့်တစ်ခုအတွက်မဆို "geometry"။ အမှတ်သည် vector input သို့နှင့် ပြန်ပြီး ပေးနိုင်သည်။ နံပါတ်များတွင် ယူနစ် ပါဝင်သည်: **length** သည် မီလီမီတာ ဖြစ်ပြီး **angle** သည် ဒီဂရီ ဖြစ်သည်။ length သည် angle သို့ ပေးလို့မရပါ၊ length နှင့် length ၏ မြှောက်လဒ် (ဧရိယာ) ကိုလည်း ငြင်းပယ်သည်၊ ထို့ကြောင့် မှားသော ကြိုး ချိတ်ပါက ချိတ်ချိန်တွင် ရပ်ဆိုင်းသည်။

စတုရန်းအစက်သည် **list** ဖြစ်သည်။ list တစ်ခုသည် တန်ဖိုးတစ်ခုတည်း input သို့ ရောက်သောအခါ node သည် item တစ်ခုစီအတွက် တစ်ကြိမ်စီ လည်ပတ်ပြီး ရလဒ်သည် list ဖြစ်လာသည်။ တိုသော list သည် နောက်ဆုံး item ကို ထပ်ခါထပ်ခါ ပြုလုပ်သည်။ ဥပမာ၊ အမြင့်များ၏ **Series** ကို **Move** သို့ ချိတ်ပါက မိတ္တူ အပုံတစ်ခု ဖြစ်လာမည်။

## Solid များနှင့် Boolean များကို node အဖြစ်

**Solids** အုပ်စုသည် Surfaces panel နှင့် တူညီသော တိကျသော မျက်နှာပြင်များမှ ပိတ်ထားသော ကိုယ်ထည်များကို ဖန်တီးသည်: **Box solid**၊ **Cylinder solid** နှင့် **Sphere solid** (အရွယ်အစားများ mm ဖြင့်)၊ **Union**၊ **Subtract** နှင့် **Intersect** (ဒုတိယ solid ကို ပထမမှ ယူသည်; tolerance ဆိုသည်မှာ solid engine ၏ ထရိုင်ဂူများသည် တိကျသော မျက်နှာပြင်များမှ ဘယ်လောက်ဝေးနိုင်သည်ကို ဆိုသည်)၊ **Fillet between faces** (မျက်နှာများကို solid တွင် ၎င်းတို့၏ နံပါတ်ဖြင့်၊ ပထမဆုံးအတွက် 1; radius တစ်ခုနှင့် 0 ထက်ကြီးပါက အဆုံးတွင် radius တစ်ခု)၊ **Solid volume** (mm³) နှင့် **Solid to mesh** (ကြည့်ရန် သို့မဟုတ် ပြောင်းရန်)။ solid တွင် ကိုယ်ပိုင် port အမျိုးအစား ရှိသည်: အမှတ် သို့မဟုတ် နံပါတ်ကို solid input သို့ ချိတ်၍ မရပါ၊ အစက်သည် အနီ ဆက်နေမည်။ Boolean နှင့် Fillet node များသည် တည်းဖြတ်ကိရိယာ ပထမဆုံး ဖွင့်သည့်အချိန်တွင် တင်သော ပရိုဂရမ်၏ ကိုယ်ပိုင် solid engine ကို သုံးသည်။

## အမှားများ

မိမိ အလုပ်ကို မလုပ်နိုင်သော node သည် ၎င်း၏ အမည်အောက်တွင် အနီရောင်ဖြင့် အကြောင်းကို ပြောသည် ("The radius must be above zero.")၊ နောက်ဆက်တွဲ node များသည် စောင့်ဆိုင်းသည်။ တူညီသော စာသားသည် Problems panel တွင် Problem အဖြစ်လည်း ပေါ်သည်၊ ထို့ကြောင့် ထိုနေရာမှ ရှာနိုင်သည်။

## Node တိုင်းသည် script လိုင်းတစ်ခု

{{ui:Script}} ကို နှိပ်၍ graph ကို CraftScript အဖြစ် ကြည့်ပါ: node တစ်ခုလျှင် လိုင်းတစ်ခု၊ ဥပမာ `n3 = nd_circle(n2, n1, [0 0 1]);`။ စာသားကို တည်းဖြတ်ပြီး {{ui:Make the graph from this script}} ကို နှိပ်ပါက graph အဖြစ် ပြန်ရောက်မည်။ တူညီသော `nd_` function များသည် PartCraft ရှိ CraftScript တွင်လည်း အလုပ်လုပ်သည်၊ ထို့ကြောင့် graph ကို ထိုနေရာတွင် run၊ loop သို့မဟုတ် စမ်းသပ်နိုင်သည်။ ကျပန်းနံပါတ်များသည် အမြဲ **seed** ကို လိုအပ်သည်၊ ထို့ကြောင့် graph တူညီသည် ကွန်ပျူတာတိုင်းတွင် တူညီသော ရလဒ်ကို ပေးသည်။

## ဖိုင်နှင့်အတူ သိမ်းဆည်းခြင်း

graph ကို မော်ဒယ်ဖိုင်တွင် သိမ်းသည်။ node များသည် ကိုယ်ပိုင် မျဉ်းကွေး၊ မျက်နှာပြင်နှင့် mesh များကို ဖန်တီးသည်; မေးသည်အထိ ၎င်းတို့သည် မော်ဒယ်၏ မျက်နှာများကို မပြောင်းလဲပေ။

## Model သို့ ပြောင်းခြင်း

မျက်နှာပြင် သို့မဟုတ် mesh ဖန်တီးသော node ၏ eye ကို ဖွင့်ပြီး Nodes ဝင်းဒိုးတွင် {{ui:Bake to model}} ကို နှိပ်ပါ။ ပြသထားသော မျက်နှာပြင် သို့မဟုတ် mesh တစ်ခုစီသည် မော်ဒယ်ထဲတွင် မျက်နှာအုပ်စုတစ်ခု ဖြစ်လာပြီး မီတာဖြင့် ဖြစ်ကာ အခြားအရာများကဲ့သို့ တည်းဖြတ်နိုင်သည်။ ၎င်းသည် Undo အဆင့်တစ်ခု ဖြစ်သည်။ graph သည် ကျန်ခဲ့သော်လည်း ကူးထားသော မိတ္တူသည် မနောက်လိုက်တော့ပေ: နံပါတ်ကို ပြောင်းပြီး အသစ်အတွက် ထပ်ပြောင်းပါ။ Points နှင့် curves သည် solid မဟုတ်သောကြောင့် ချန်ထားခဲ့သည်၊ မက်ဆေ့ချ်က မည်မျှ ချန်ခဲ့သည်ကို ပြောပြသည်။
