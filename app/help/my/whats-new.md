ModelCraft 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် ပြောင်းလဲမှုများကို 0.7 နှင့် နှိုင်းယှဉ်ထားသည်။ {{ui:Render a picture…}} ဒိုင်ယာလော့ဂ်သည် မြင်ကွင်းကို အခြားပရိုဂရမ်သို့ ပို့နိုင်ပြီး၊ Surfaces panel သည် ချောမွေ့သော freeform မျက်နှာပြင်များ ဖန်တီးပေးပြီး၊ သင်ချိတ်ဆက်ထားသော အကူအညီသည် စာကြောင်းတစ်ကြောင်းဖြင့် မြင်ကွင်းတစ်ခုလုံးကို သတ်မှတ်နိုင်သည်။

## အသစ်

### ရေးဆွဲခြင်း

- **Engine ရွေးချယ်မှု။** {{ui:Render a picture…}} တွင် Mode အပေါ်တွင် **Engine** စာရင်း ရှိသည်။ ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် engine နှစ်ခု၊ Fast နှင့် Path tracer သည် မူလဖြစ်ပြီး နေရာတိုင်းတွင် အလုပ်လုပ်သည်။ အခြား ရွေးချယ်စရာများက မြင်ကွင်းကို package အဖြစ် သိမ်းသည် (မော်ဒယ်ကို USD ဖိုင်အဖြစ်၊ တိကျသော ပစ္စည်းတန်ဖိုးများ၊ ဖွင့်ထားသော မီးအလင်းများ၊ နေ၊ ကောင်းကင်၊ exposure နှင့် ကင်မရာပါသော settings ဖိုင်) အခြားပရိုဂရမ်သို့ ယူသွားရန်။ အခြားပရိုဂရမ်က ရေးဆွဲထားသော ပုံရိပ်သည် မည်သည့်ပရိုဂရမ်နှင့် ဗားရှင်းက ရေးဆွဲသည်ကို ဖော်ပြသည်။ [ပုံကို မည်သည့်ပရိုဂရမ်က ရေးဆွဲမလဲ ရွေးခြင်း](topic:render-engines) ကို ကြည့်ပါ။
- **အခြားပရိုဂရမ်တွင် ဖွင့်ခြင်း။** Engine စာရင်းက မြင်ကွင်းကို USD ဖိုင်၊ glTF ဖိုင် (`.glb`) သို့မဟုတ် Unreal project ဖိုဒါ (`.zip`) အဖြစ် သိမ်းနိုင်သည်၊ browser နှင့် CadCraft Studio နှစ်ခုစလုံးတွင်။ Studio တွင် usdview သို့မဟုတ် ကွန်ပျူတာ၏ ကိုယ်ပိုင်ပရိုဂရမ်ကို ဖိုင်အတွက် စတင်နိုင်သည်။ [မြင်ကွင်းကို အခြားပရိုဂရမ်တွင် ဖွင့်ခြင်း](topic:render-open-in) ကို ကြည့်ပါ။
- **Studio မှ game engine သို့ ပို့ခြင်း။** Studio သည် မြင်ကွင်းကို Unreal Engine project အဖြစ် ရေးပြီး ပို့တိုင်းတွင် ကိုက်ညီအောင် ထိန်းထားသည်၊ တစ်ဘက်သတ်သာ။ သင်၏ ကိုယ်ပိုင်ပြင်ဆင်မှုများသည် CadCraft ဘယ်တော့မှ မရေးသော layer တစ်ခုတွင် နေသည်။ [မြင်ကွင်းကို game engine သို့ ပို့ခြင်း](topic:render-unreal) ကို ကြည့်ပါ။
- **add-on မှ Engine များ။** add-on တစ်ခုက engine ကို စာရင်းတွင် ထည့်နိုင်သည်။ JavaScript ဖြင့်ရေးထားသည်က browser နှင့် Studio တွင် ဆွဲသည်; ပရိုဂရမ်တစ်ခုကို လည်ပတ်စေသည်ကို Studio တွင် သင်ခွင့်ပြုရမည်။ [add-on ဖြင့် ပုံကို အခြားပရိုဂရမ်ဖြင့် ဆွဲခြင်း](topic:render-other-program) နှင့် [add-on ဖြင့် render engine ထည့်ခြင်း](topic:render-engine-addons) ကို ကြည့်ပါ။
- **မြင်ကွင်းကို ဖော်ပြခြင်း။** ချိတ်ဆက်ထားသော အကူအညီသို့ "အချိန်ည၊ မိုးဖွဲ၊ ဆောင်းဦးသစ်ပင်များ၊ ပလာဇာပေါ်တွင် လူများ" ဟု ပြောပါ၊ ModelCraft က တစ်ဆင့်တည်း တည်ဆောက်မည်: နေသည် ရက်စွဲနှင့် အချိန်သို့ ရွေ့ပြီး အရိပ်များ လိုက်မည်၊ ကောင်းကင် ပြောင်းမည်၊ စိုစွတ်သော မျက်နှာပြင်များ ပေါ်လာမည်၊ သစ်ပင်များနှင့် လူများကို ဖျောက်၊ ရွှေ့ သို့မဟုတ် ဖျက်နိုင်သော tag များပေါ်ရှိ အရာဝတ္ထုအစစ်များအဖြစ် ထားမည်။ အချိန်အပိုင်း၊ ရက်စွဲ သို့မဟုတ် ရာသီ၊ နှင့် ရာသီဥတု (ကြည်လင်၊ မိုးလင်း၊ မြူ၊ မိုးဖွဲ၊ မိုး၊ မုန်တိုင်း) ကိုလည်း တစ်ခုတည်းဖြင့် အလုပ်လုပ်သည်၊ နောက်ပိုင်း တောင်းဆိုချက်က တူညီသော မြင်ကွင်းကို ပြောင်းသည်။ မြူသည် အရည်အသွေးမြင့် ပုံပေါ်တွင် ဂရပ်ဖစ်ကတ်ဖြင့် ပြသည်; အခြား engine များက ကောင်းကင်၊ အလင်းနှင့် စိုစွတ်သော မျက်နှာပြင်များကို ပြသည်။ မိုးကို ကျနေသော မျဉ်းများအဖြစ် မဆွဲပါ။

### ပစ္စည်းများ

- **ဓာတ်ပုံတစ်ပုံမှ ပစ္စည်း။** မျက်နှာပြင်တစ်ခု၏ ဓာတ်ပုံ (နံရံ၊ ကြမ်းပြင်၊ ကျောက်) ပေးလျှင် ModelCraft သည် tiling ပစ္စည်းတစ်ခု ဖန်တီးမည်: ဓာတ်ပုံတစ်ဝှန်းရှိ အလင်းကို ညီညွတ်စေပြီး၊ အစွန်းများကို ဆက်စပ်စေကာ၊ color map၊ roughness map နှင့် normal map ကို ဓာတ်ပုံမှ တွက်ထုတ်သည်။ ၎င်းသည် သင့်ကိုယ်ပိုင်ဓာတ်ပုံပေါ်ရှိ ရိုးရိုးရှင်းရှင်း ပုံရိပ်လုပ်ဆောင်မှု ဖြစ်ပြီး လေ့ကျင့်ထားသော မော်ဒယ် မပါပါ။ Roughness သည် ခန့်မှန်းချက် ဖြစ်သည်။ ရိုးရှင်း၊ စတုရန်း၊ တည့်တည့်ရိုက်ထားသော ဓာတ်ပုံက tile ကောင်းဆုံးပေးသည်; အုတ်ကဲ့သို့ ပြင်းထန်သော ပုံစံများတွင် ဆက်စပ်မှုနေရာ၌ ပျော့ပျောင်းသော ghost ပေါ်နိုင်သည်။

### မျက်နှာပြင်များ

- **Freeform မျက်နှာပြင်များ။** {{ui:Surfaces}} panel သည် NURBS မျဉ်းကွေးများနှင့် untrimmed မျက်နှာပြင်များ ဖန်တီးသည်: အမှတ်များမှ ဖြတ်သွားသော မျဉ်းကွေးများ၊ loft၊ ruled၊ extrude၊ revolve၊ ရေလမ်းတစ်ခု သို့မဟုတ် နှစ်ခုပေါ်သို့ sweep များ၊ မျဉ်းကွေးကွန်ယက်မှ မျက်နှာပြင်များ၊ အစွန်းလေးခုမှ patch များ၊ match နှင့် blend။ မျက်နှာပြင်တိုင်းကို တိကျသော မျက်နှာပြင်များပေါ်တွင် G0၊ G1 သို့မဟုတ် G2 (ကွာဟချက်၊ ထောင့်၊ ကွေးညွှတ်မှုခုန်ခြင်း) အဖြစ် တိုင်းတာပြီး၊ သင်တောင်းဆိုထားသည်ထက် ညံ့သော အစွန်းသည် **Match** ပြင်ဆင်ချက်ဖြင့် Problems panel တွင် ပေါ်သည်။ Zebra အစင်းကြောင်းများနှင့် curvature အရောင်များကို တိကျသော မျက်နှာပြင်များမှ ဆွဲသည်။ STEP နှင့် IGES ဖိုင်များ ထွက်ပြီး ဝင်သည်။ [Freeform မျက်နှာပြင်များ (NURBS)](topic:nurbs-surfaces) ကို ကြည့်ပါ။

### ဆိုဒ်နှင့် အခန်းများ

- **ဆိုဒ်ပုံကြမ်းဓာတ်ပုံကို မြေပြင်ပေါ်သို့။** {{ui:File}} › {{ui:Import a sketch photo…}} သည် လက်ရေးပုံကြမ်း၏ ဖုန်းဓာတ်ပုံကို သင်ပြောသော စကေးဖြင့် မြေပြင်ပေါ်ရှိ edge များအဖြစ် ပြောင်းပေးသည်: group တစ်ခု၊ ဘောပင်အရောင်တစ်ခုစီအတွက် tag တစ်ခုစီ။ စက္ကူကို သင့်ကွန်ပျူတာပေါ်တွင် ရှာဖွေပြီး ဖြောင့်ပေးသည်၊ ဘယ်နေရာသို့မှ မပို့ပါ။ [ဆိုဒ်အစီအစဉ်ပေါ်တွင် မော်ဒယ်ဆွဲခြင်း](topic:site-plan) ကို ကြည့်ပါ။
- **အခန်းကို ပရိဘောဂဖြင့် ပြင်ဆင်ခြင်း။** ကြမ်းပြင်တစ်ခုကို ရွေးပြီး {{ui:Organize}} › {{ui:Furnish a room…}} ကို သုံးပါ။ အိပ်ခန်း၊ ဧည့်ခန်း၊ ထမင်းစားခန်း၊ မီးဖို၊ ရေချိုးခန်း သို့မဟုတ် ရုံးခန်း ပရိဘောဂများကို နံရံများနှင့် တံခါး/ပြတင်းပေါက်များမှ ရှင်းလင်းစွာ နေရာချထားပြီး၊ စည်းမျဉ်းများဖြင့် ထားသည်၊ တစ်ဆင့်တည်းဖြင့် ဖယ်ရှားနိုင်သော group တစ်ခုအတွင်း။ ၎င်းသည် သင်ပြန်သုံးသပ်ရန် မူလ layout ဖြစ်သည်၊ ဒီဇိုင်း မဟုတ်ပါ။ [စတင်ရန် စာကြည့်တိုက်](topic:starter) ကို ကြည့်ပါ။

### 3D ပရင့်ထုတ်ခြင်း

- **စောင်းဖြတ်ခြင်း။** ပရင့်အတွက် Split သည် ၎င်း၏ ဖြတ်ချက်များကို 60 ဒီဂရီအထိ စောင်းနိုင်ပြီး အတူတူပေါင်းရန် ပိုမို မျက်နှာပြင်ရစေသည်။ Connector များသည် ဖြတ်ချက်နှင့် ထောင့်မှန်ရပ်သည်။ [ပရင့်အတွက် မော်ဒယ်ခွဲခြင်း](topic:print-split) ကို ကြည့်ပါ။
- **Problems ရှိ ပရင့်စစ်ဆေးချက်။** 3D ပရင့်စစ်ဆေးချက်၏ တွေ့ရှိချက်များသည် မော်ဒယ်ပေါ်ရှိ marker များဖြင့် Problems panel တွင် ပေါ်ပြီး၊ Repair က ထိုနေရာမှ ပြင်ပေးသည်။ [ထောက်ပံ့ချက်များ၊ နံရံထူ၊ အတွင်းပိုင်း ဖောက်ခြင်းနှင့် ပြုပြင်ခြင်း](topic:print-tools) ကို ကြည့်ပါ။

### အက်ပ်တိုင်းတွင်

- **ဘာသာစကားများ။** အကူအညီနှင့် အက်ပ်များသည် ဘာသာစကား 54 ခုဖြင့် ရောက်သည်။ ဆယ်ခုသည် အသစ်ဖြစ်သည်: လစ်သူယေးနီးယား၊ လတ်ဗီးယား၊ ဘော့စနီးယား၊ မာရသီ၊ တယ်လူဂု၊ အယ်လ်ဘေးနီးယား၊ အာဖရိကန်၊ ဖိလစ်ပိုင်၊ ဆွာဟီလီနှင့် ဥဇဘက်။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် ဘာသာပြန်မူကြမ်းများဖြစ်ပြီး ဒေသခံတစ်ဦးက ဖတ်မှ မပြည့်စုံသေး၊ အကူအညီခေါင်းစဉ်အချို့သည် အင်္ဂလိပ်ဖြင့် ဆက်ရှိနေနိုင်သည်။
- **Input ကိရိယာများ။** Trackpad၊ ဘောပင်၊ 3D mouse၊ game controller နှင့် MIDI ထိန်းချုပ်မှုများဖြင့် အက်ပ်များကို အားလုံး သို့မဟုတ် တစ်ခုအတွက် လည်ပတ်စေနိုင်သည်။
- **ကိရိယာဘား အတန်းများ။** {{ui:Settings}} › {{ui:General}} › Toolbar rows သည် Wrap (ယခင်အတိုင်း)၊ 2 rows သို့မဟုတ် 1 row ကို သတ်မှတ်သည်။ ဘားက မကိုက်ညီလျှင် ဘေးသို့ scroll လုပ်မည်၊ ပုံဆွဲခြင်း၏ နေရာကို မယူပါ။ Wrap သည် မူလဖြစ်ဆဲ။
- **Property grid။** ModelCraft ၏ မီးအလင်းအကွက်များသည် မျှဝေထားသော grid ကို သုံးသည်: ခေါင်းစဉ်များကို ခေါက်နိုင်ခြင်း၊ label နှင့် တန်ဖိုး ကော်လံများ၊ နှင့် Compact density။ `2*450` ကဲ့သို့ ရိုက်ထည့်သော ပေါင်းနှုတ်မြောက်စားများ ဆက်အလုပ်လုပ်သည်။
- **Problems။** Problems panel (app bar ရှိ သတိပေးခလုတ်) ကို အက်ပ်အားလုံးက မျှဝေသည်။ ModelCraft တွင် ပရင့်စစ်ဆေးချက်နှင့် မျက်နှာပြင် continuity သတိပေးချက်များ ပါဝင်သည်။
- **Live။** Live TeamWork session သည် ဘယ်သူ ဘယ်နေရာတွင် ရှိသည်ကို ပြသည်။ [Live TeamWork ဖြင့် အတူတကွ မော်ဒယ်ဆွဲခြင်း](topic:work-live) ကို ကြည့်ပါ။
- **Add-on များ။** Add-on များသည် အထက်ပါအတိုင်း render engine များ ထည့်နိုင်သည်။
- **သင်၏ AI ချိတ်ဆက်ခြင်း။** အက်ပ်ရှစ်ခု၏ tool contract နှင့် စစ်ဆေးမှုများ အောင်မြင်သည်၊ စုစုပေါင်း tool 454 ခုဖြင့်။ Studio အတွင်း တစ်ချက်နှိပ်ချိတ်ဆက်မှု၊ browser အကူအညီများအတွက် hosted connector၊ Studio အတွင်း သင့်ကိုယ်ပိုင် key နှင့် ထုတ်ပြန်ထားသော package တို့ကို ကတိမပေးသေးပါ။ အက်ပ်များတွင် ကိုယ်ပိုင် AI မပါပါ။ [ModelCraft ကို AI အကူအညီများနှင့် အသုံးပြုခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

## 0.8.1 တွင် ပြင်ဆင်ထားသည်

- **DWG classes အပိုင်း။** DWG ဖိုင်၏ classes အပိုင်းကို မှားသော အမျိုးအစားအဖြစ် ဖတ်ထားပြီး သွင်းချိန်တွင် ဖိုင်ကို ပျက်စေနိုင်သည်။ ယခု ModelCraft နှင့် DWG ကို ဖတ်သော အခြားအက်ပ်များတွင် မှန်ကန်စွာ ဖတ်သည်။
- **Tablet ဒေါင်လိုက်။** အလွတ် grid အမြင့်သည် canvas သို့ သွားပြီး၊ စာမျက်နှာ layout သည် 760 pixel အနည်း သို့မဟုတ် ထိုထက်ငယ်သော အကျယ်တွင် စတင်သည်။ ModelCraft ၏ style sheet တွင်လည်း ပြောင်းလဲချက် ပါသည်။
- **Studio တွင် ဘာသာစကား။** CadCraft Studio နှင့် ထုပ်ပိုးထားသော edition များသည် လည်ပတ်စဉ်ပင် ဘာသာစကား ပြောင်းနိုင်ပြီး၊ ယခင်က အင်္ဂလိပ်သာ ဖြစ်သည်။ ဤအရာကို ပလက်ဖောင်းအားလုံးတွင် မစမ်းသပ်ရသေးပါ: ဘာသာစကား မပြောင်းလျှင် ကျွန်ုပ်တို့ကို အသိပေးပါ။

## ဤဗားရှင်းတွင် မပါသေးသည်များ

- **Code-signed မဟုတ်ပါ။** Windows က SmartScreen ပြနိုင်သည်: {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ညာဘက်နှိပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store build များကို ရပ်ဆိုင်းထားပြီး iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- ရေးဆွဲချက်ကို render-engine add-on မပါဘဲ အခြားပရိုဂရမ်က ရေးဆွဲခြင်း၊ panorama သို့မဟုတ် stereo ကင်မရာများနှင့် အခြားပရိုဂရမ်မှတစ်ဆင့် ကောင်းကင်ပုံ၊ နှင့် Unreal အဆင့်ကို ဖွင့်သော plug-in တို့ ယနေ့ မရှိသေးပါ။ ဖိုင်များကို ရေးထားပြီးသည်; plug-in ကို မထုတ်ပြန်ရသေးပြီး Unreal တွင် မလည်ပတ်ရသေးပါ။
- Freeform မျက်နှာပြင်များ: G3 နှင့် class A ကို မတိုင်းတာ သို့မဟုတ် မပြဆိုရသေးပါ၊ trimming နှင့် solid များသည် နောက်ပိုင်းတွင် လာမည်။
- အခြားပရိုဂရမ်များမှ ပုံများသည် ကျွန်ုပ်တို့၏ ပုံနှင့် pixel အတိအကျ မတူပါ: ကင်မရာ၊ နေ၊ မီးအလင်းများနှင့် exposure သာ ကိုက်ညီသည်။
- Studio ရှိ ဘာသာစကားပြောင်းခြင်းအတွက် 0.8.1 ပြင်ဆင်ချက်ကို ပလက်ဖောင်းအားလုံးတွင် မစမ်းသပ်ရသေးပါ။
