{{ui:Export}} › {{ui:Live view}} သည် အက်ပ်ပေါ်တွင် ပြတင်းတစ်ခုဖွင့်ပြီး မော်ဒယ်ကို အချိန်နှင့်တပြေးညီ အသွင်အပြင်ဖြင့် ပြသသည်။ မော်ဒယ်၏ နေရာနှင့် ရက်စွဲအလိုက် ကောင်းကင်နှင့် နေ၊ နေ၏ အရိပ်များ၊ မျက်နှာများကို သင်ပေးထားသော အသွင်အပြင်နှင့် ပစ္စည်းများ၊ မီးခွက်များ၊ နံရံနှင့် ကြမ်းပြင်မှ ပြန်ကျသော အလင်းတို့ ပါဝင်သည်။ သင်လုပ်သည်များကို လိုက်ပါသည်- view ကို လှည့်လျှင် ၎င်းလည်း လှည့်သည်၊ မော်ဒယ်ကို ပြောင်းလျှင် ခဏအကြာတွင် ပြောင်းလဲမှုကို ပြသည်။ ဘာမှ အင်တာနက်သို့ တင်ခြင်း မရှိပါ။

## ဖွင့်ရန်

1. {{ui:Export}} › {{ui:Live view}} ကို ရွေးပါ။ ပြတင်းသည် ညာဘက်အောက်ထောင့်တွင် ဖွင့်သည်။
2. ၎င်း၏ ခေါင်းစဉ်ဘားကို ဆွဲ၍ ရွှေ့ပါ၊ ထောင့်ကို ဆွဲ၍ ကြီးအောင် ပြင်ပါ။
3. {{ui:New window}} က ၎င်းကို ကိုယ်ပိုင်ဝင်းဒိုးသို့ ရွှေ့သည်၊ ဒုတိယမျက်နှာပြင်အတွက်ဖြစ်သည်။ {{ui:Export}} › {{ui:Live view in a new window}} က ချက်ချင်း ထိုဝင်းဒိုးတွင် ဖွင့်သည်။ browser က pop-up ဝင်းဒိုးများကို ပိတ်ထားလျှင် ပြတင်းအဖြစ် ဖွင့်သည်။
4. {{ui:Close}} က ပိတ်သည်။

## မော်ဒယ်အတွင်း လျှောက်ရန်

1. မူလ view ကို သင်ရပ်ချင်သော နေရာသို့ လှည့်ပြီး {{ui:Walk}} ကို ရွေးပါ။ view ၏ မျက်စိချက်အောက်ရှိ ကြမ်းပြင်ပေါ်တွင် 1.6 m အမြင့်ဖြင့် ရပ်သည်။
2. live view ကို နှိပ်ပြီး {{key:W}} {{key:A}} {{key:S}} {{key:D}} သို့မဟုတ် မြား ခလုတ်များကို သုံးပါ။ ပြေးရန် {{key:Shift}} ကို ဖိထားပါ။ ပတ်ကြည့်ရန် ဆွဲပါ။
3. အမြင့် 40 cm အထိ ခြေလှမ်းများကို တက်သည် (လှေကား)၊ ထိုထက်မြင့်သည်များသည် နံရံဖြစ်သည်။ နံရံများက သင့်ကို ရပ်စေပြီး ၎င်းနှင့်အတူ ဆွဲလျှောသွားသည်။
4. {{ui:Gravity}} ပိတ်ထားလျှင် ပျံသန်းသည်၊ {{key:E}} က အပေါ်သို့၊ {{key:Q}} က အောက်သို့ သွားသည်။
5. {{key:Esc}} က လျှောက်ခြင်းကို ရပ်စေသည်။

## အပင်များ၊ ကျောက်တုံးများနှင့် လူများ ဖြန့်ချရန်

live view ၏ ဘားရှိ {{ui:Scatter}} က ပုံဘေးတွင် scatter ပြတင်းကို ဖွင့်သည်။ scatter set တစ်ခုက entourage စာကြည့်တိုက် (သစ်ပင်၊ ချုံပင်၊ မြက်၊ ပန်း၊ ကျောက်တုံး၊ လူ၊ ကား) မှ ပစ္စည်းများကို မော်ဒယ်၏ အစိတ်အပိုင်းတစ်ခုပေါ် ဖြန့်ချသည်။ ပစ္စည်းများကို live view တွင်သာ ဆွဲသည်- မော်ဒယ်ထဲတွင် geometry မဟုတ်ပါ၊ main view တွင် မပြပါ။

1. **မျက်နှာများ ဖြည့်ရန်:** ModelCraft တွင် မျက်နှာများ (သို့မဟုတ် တောင်ပြင်ကဲ့သို့ အုပ်စု) ကို ရွေးပြီး {{ui:Fill selection}} ကို ရွေးပါ။ set က ၎င်းတို့ကို ဖုံးသည်။
2. **သုတ်ရန်:** {{ui:Paint}} ကို ရွေးပြီး live view ပေါ်တွင် ဆွဲပါ။ မျက်နှာများ ရွေးထားလျှင် သုတ်ချက်သည် ၎င်းတို့ပေါ်တွင်သာ ကျသည်၊ ဘာမှ မရွေးထားလျှင် ဘရပ်ရှ်အောက်ရှိ မည်သည့်အရာပေါ်မဆို (မြေပြင်အပါအဝင်) ကျသည်။ {{ui:Brush size}} က ဘရပ်ရှ်ကို သတ်မှတ်သည်၊ {{ui:Eraser}} က သုတ်ထားသော အစက်များကို ဖယ်ရှားသည်။
3. ဖြန့်ချလိုသည်များကို အမှန်ခြစ်ပါ။ အနားရှိ နံပါတ်က ၎င်း၏ အလေးချိန်ဖြစ်သည်- 3 နှင့် 1 ဆိုလျှင် ပထမတစ်ခုအတွက် သုံးခု၊ ဒုတိယတစ်ခုအတွက် တစ်ခုစီ ထွက်သည်။

| ထိန်းချုပ်ချက် | အလုပ်လုပ်ပုံ |
|---|---|
| {{ui:Per m²}} | လက်မှတ်ရေပေါ်တစ်ပေတွင် ပစ္စည်းမည်မျှ |
| {{ui:Keep away (m)}} | အခြားအရာများနှင့် ဤအကွာအဝေးထက် မနီးရ၊ အမိုးအောက် သို့မဟုတ် စားပွဲအောက်တွင် မထားရ။ 0 ဖြင့် ပိတ်သည် |
| {{ui:Turn (°)}} | ပစ္စည်းတစ်ခုစီကို ဒေါင်လိုက်ဝင်ရိုးပတ်လည် ကျပန်း လှည့်သည့်ပမာဏ |
| {{ui:Steepest (°)}} | မျက်နှာသည် ဤထက်ပိုစောက်သော နေရာတွင် မထားရ |
| {{ui:Size}} | ပစ္စည်း၏ ကိုယ်ပိုင်အရွယ်အစား၏ factor အဖြစ် အသေးဆုံးနှင့် အကြီးဆုံး |
| {{ui:Height from, to (m)}} | ဤအမြင့်များကြားတွင်သာ (blank = မည်သည့်အမြင့်မဆို) |
| {{ui:Lean with the surface}} | 0 က ပစ္စည်းများကို ဒေါင်လိုက် ထားသည်၊ 1 က ကုန်းစောက်ပေါ်တွင် ထောင့်မတ်ထားသည် |
| {{ui:Seed}}၊ {{ui:Shuffle}} | seed တူလျှင် scatter တူသည်၊ Shuffle က အခြားတစ်ခု ရွေးသည် |

set များကို .modelcraft ဖိုင်ထဲတွင် သိမ်းပြီး ပြောင်းလဲသည့်အခါ ၎င်းတို့ဖုံးသော မျက်နှာများကို လိုက်သည်။ live view က ဆွဲနိုင်သော ပစ္စည်းအများဆုံးအရေအတွက်ကို [သင့်စက်](topic:your-machine) အဆင့်အရ သတ်မှတ်သည်- {{ui:Processor only}} အတွက် 20 000၊ {{ui:Graphics card, basic}} အတွက် 100 000၊ {{ui:Graphics card, high}} အတွက် သန်းတစ်။ ပြတင်းက သတ်မှတ်ထားသော သိပ်သည်းမှုအရ မည်မျှ နေရာချထားပြီး မည်မျှ လိုသည်ကို ပြသည်။ ဘတ်ဂျက်ပြည့်သောအခါ သို့မဟုတ် အရာဝတ္ထုများက ဖယ်ထားသောအခါ ပိုနည်းစွာ နေရာချထားသည်။ ကင်မရာနှင့် နီးသော ပစ္စည်းများကို ၎င်းအတိုင်း ဆွဲပြီး ဝေးသောပစ္စည်းများကို ၎င်းတို့၏ အရောင်ဖြင့် ရိုးရှင်းသော ပုံသဏ္ဍာန်များအဖြစ် ဆွဲသည်။

:::note
ဖြန့်ချထားသော ပစ္စည်းများသည် live view (နှင့် ၎င်း၏ လျှောက်ခြင်း၊ panorama နှင့် standalone viewer) တွင် ရှိသည်။ Render a picture သည် ၎င်းတို့ကို မဆွဲရသေးပါ။
:::

live view ၏ ဘားရှိ {{ui:Share}} က live view မှ ဖိုင်များ ပြုလုပ်သည်။ အားလုံးကို ဤကွန်ပျူတာပေါ်တွင် ပြုလုပ်သည်၊ ဘာမှ မတင်ပါ။

| ရွေးချယ်မှု | သင်ရရှိမည့်အရာ |
|---|---|
| {{ui:360° panorama}} | view ရပ်နေသော (သို့မဟုတ် လျှောက်နေသော) နေရာမှ 360° ပုံ၊ equirectangular PNG အဖြစ်၊ panorama ကြည့်ကိရိယာများနှင့် ဓာတ်ပုံဆိုဒ်အများစုက ဖွင့်နိုင်သည် |

## Bounce light

နေရောင်ရသော နံရံမှ ကြမ်းပြင်သို့ ပြန်ကျသော အလင်းနှင့် အခန်း၏ မှောင်သော အတွင်းပိုင်းကို [ပုံရိပ် ထုတ်ထားသော ပုံများ](topic:render) ပြုလုပ်သည့် path tracer တူညီသည်က တွက်ချက်သည်- မော်ဒယ်ထဲရှိ အမှတ်များတွင် သေးငယ်သော panorama တစ်ခုကို ပြုလုပ်ပြီး ကွန်ပျူတာ processor core အားလုံးပေါ်တွင် နောက်ကွယ်မှ အလုပ်လုပ်သည်။ အလုပ်လုပ်နေစဉ် အောက်ဆုံးစာကြောင်းက {{ui:Bounce light: 40 %}} ဟု ပြသည်၊ ပြီးလျှင် view က ၎င်းကို ယူသည်။ ပြောင်းလဲမှုတိုင်းနောက်တွင် ပြန်စသည်။

:::note
ဤသည်မှာ live view အတွက် ခန့်မှန်းချက်ဖြစ်ပြီး ပြုလုပ်ပြီးသော ပုံမဟုတ်ပါ။ အမှတ်များကြား အသေးစိတ်များသည် အနီးရှိ အမှတ်များ၏ bounce light ကို ရယူသည်။ ပြီးပြည့်စုံသော ပုံအတွက် [ပုံရိပ် ထုတ်ရန်](topic:render) ကို သုံးပါ။
:::

## အလင်းအားနှင့် အရောင်များ

live view သည် [ပုံရိပ် ထုတ်ရန်](topic:render) နှင့် တူညီသော အလင်းအား၊ white balance၊ contrast နှင့် view transform (ACES၊ AgX၊ filmic သို့မဟုတ် standard) ကို သုံးသည်။ ထိုနေရာတွင် သတ်မှတ်ပါက live view က လိုက်သည်။

:::note
browser များ ကွဲပြားသည်။ browser တွင် WebGPU ရှိလျှင် (Windows၊ macOS နှင့် ChromeOS ပေါ်ရှိ Chrome နှင့် Edge၊ Safari 26) live view က ၎င်းကို သုံးသည်။ အခြားနေရာများ (Linux ပေါ်ရှိ browser အများစု၊ အဟောင်း Apple စနစ်များ) တွင် WebGL 2 ကို သုံးပြီး တူညီပုံ ဖြစ်သည်။
:::
