SketchUp တွင် မော်ဒယ်လ်ပြုလုပ်ဖူးလျှင် ModelCraft သည် ရင်းနှီးမည်- မျက်နှာများနှင့် တွန်း/ဆွဲ အယူအဆတူညီခြင်း၊ tool အက္ခရာများတူညီခြင်း၊ နှိပ်စရာမလိုဘဲ ရိုက်ထည့်နိုင်သော တန်ဖိုးအကွက်၊ အနီ၊ အစိမ်းနှင့် အပြာ ဝင်ရိုးများဖြင့် inference၊ အုပ်စုများ၊ ကွန်ပိုနင့်များ၊ Outliner၊ Entity Info နှင့် scenes တို့ ရှိသည်။ ဤစာမျက်နှာသည် တိုက်ရိုက် ကူးပြောင်းနိုင်သည်များနှင့် ပိုအရေးကြီးသည်- မကူးပြောင်းနိုင်သည်များကို ဖော်ပြသည်။

## ကွာခြားချက်များ ထိခိုက်စေသည်များ

### သိမ်းခြင်းသည် ဒေါင်းလုဒ် ဖြစ်သည်

ဖွင့်ထားသော ဖိုင်ကို ထပ်ရေးသော Save မရှိ၊ နာမည်ပေးသော Save As dialog မရှိ၊ autosave မရှိ၊ backup ဖိုင် မရှိပါ။ {{ui:Save}} ({{key:Mod+S}}) က `.modelcraft` ဖိုင်အသစ်ကို အမြဲ ဒေါင်းလုဒ်လုပ်သည်၊ အများအားဖြင့် သင်၏ downloads ဖိုင်တွဲသို့။ မကြာခဏ သိမ်းပြီး ဖိုင်များကို ကိုယ်တိုင် အမည်ပြောင်း သို့မဟုတ် ရွှေ့ပါ။ [ဖိုင်ဖွင့်၊ သိမ်း၊ သွင်းနှင့် ပို့ခြင်း](topic:files) ကို ကြည့်ပါ။

### .skp ဖိုင်များကို သွင်းနိုင်သော်လည်း သိမ်းမရ

{{ui:Import}} က SketchUp ဖိုင်များကို ModelCraft ၏ ကိုယ်ပိုင် reader ဖြင့် browser အတွင်းတွင် ဖတ်သည်- အုပ်စုများ၊ ကွန်ပိုနင့်များ၊ အရောင်များ၊ မျက်နှာပေါ်ရှိ texture များ၊ tags နှင့် soft edges တို့ ပါလာသည်။ [ဖိုင်ပုံစံများ အသေးစိတ်](topic:formats#skp-files) ကို ကြည့်ပါ။ ModelCraft က `.skp` ကို မသိမ်းနိုင်ပါ၊ ပြန်သွားရန် ModelCraft မှ Collada ကို ထုတ်ပို့ပြီး SketchUp တွင် သွင်းပါ။

### right-click menu မရှိ

right-drag က pan ဖြစ်သည်၊ right-click က ဘာမျှ မလုပ်ပါ။ context menu တွင် ရှာတွေ့နိုင်သော command များသည် {{ui:Entity info}} ({{ui:Reverse face}}၊ {{ui:Edit}}၊ {{ui:Explode}}၊ {{ui:Make unique}}၊ {{ui:Make component}}) နှင့် toolbar ၏ {{ui:Organize}} အုပ်စုတွင် ရှိသည်။

### ယူနစ်များသည် status bar တွင် ရှိသည်

Model Info သို့မဟုတ် template ရွေးချယ်မှု မရှိပါ။ ယူနစ်ရွေးကိရိယာသည် အောက်ညာဘက်တွင် ရှိသည်။ မော်ဒယ်အသစ်သည် browser ၏ ဘာသာစကား ဆက်တင်အရ အမေရိကန်တွင် ပေ နှင့် လက်မ၊ နေရာအခြားတွင် မီလီမီတာဖြင့် စသည်။ ဒသမများသည် အမြဲ ကာလသိမ်း (period) သုံးသည်၊ ဥပမာ `2.5m`၊ `2,5m` မဟုတ်ပါ၊ အကြောင်းမှာ ကော်မာက တန်ဖိုးများကို အမြဲ ခွဲသည်။

### Paint သည် ကိုယ်ပိုင် ပစ္စည်းများ ရှိသည်

{{ui:Paint}} ({{key:B}}) က အရောင်တစ်ခည်းတည်းနှင့် {{ui:Materials}} အပိုင်းရှိ ပစ္စည်းများဖြင့် ဆေးသည်- အုတ်၊ siding၊ roofing၊ သစ်၊ ကျောက်နှင့် တခြားများ၊ ModelCraft က ဆွဲသည်။ ကိုယ်ပိုင် ပုံကို ပစ္စည်းအဖြစ် မတင်နိုင်သေးပါ၊ ထည့်သွင်းသော ဖိုင်များနှင့်အတူ ပါလာသော texture များကို ထိန်းသည်။ [အရောင်နှင့် ပစ္စည်းများဖြင့် ဆေးခြင်း](topic:paint) ကို ကြည့်ပါ။

### Scale သည် တူညီသည်၊ grips မရှိ

Scale က grips ပါသော ဘောက်စ်ကို မပြပါ။ မပြောင်းသော အမှတ်ကို ရွေးပါ၊ ထို့နောက် အရွယ်အစားအသစ် သို့မဟုတ် ရိုက်ထည့်သော အချိုးကိန်းကို ပေးပါ။ အရာအားလုံးဆီသို့ ညီမျှစွာ အမြဲ scale ပြုလုပ်သည်။ တစ်ဖက်တည်းသို့ ဆန့်ရန် တွန်း/ဆွဲ သို့မဟုတ် မျက်နှာကို ရွှေ့ပါ၊ သို့မဟုတ် {{ui:Entity info}} တွင် အုပ်စု၏ အကျယ်၊ နက်နှင့် အမြင့်ကို ပြန်ရိုက်ပါ၊ သို့မဟုတ် [dimension ဖြင့် resize](topic:dimensions) လုပ်ပါ။

### Rotate သည် နှိပ်သည့်နေရာမှ လေယာဉ်ကို ရွေးသည်

လက်ညှိုးတွင် ဖြတ်လမ်းကို ပြနေစဉ် မျက်နှာများနှင့် တွဲကပ်နေသော protractor မရှိပါ။ လေယာဉ်ကို ရွေးရန် မျက်နှာပေါ်ရှိ အလယ်ကို နှိပ်ပါ၊ ထိုမျက်နှာ၏ လေယာဉ်တွင် လှည့်မည်၊ သို့မဟုတ် မြေပြင်ပေါ်တွင် နှိပ်ပါ၊ ဒေါင်လိုက်ပတ်လည် လှည့်မည်။ မြားခလုတ်များက ပထမ နှိပ်ခြင်းမတိုင်မီ view ကို orbit လုပ်သည်။

### သင်ဖြတ်သွားသော အမှတ်များမှ Inference

ModelCraft သည် **သင်၏ စတင်အမှတ်** မှ ဝင်ရိုးလမ်းကြောင်းများသို့ ကပ်သည်၊ ကာဆာအောက်ရှိ အမှတ်များ၊ အစွန်းများနှင့် မျက်နှာများသို့လည်း ကပ်သည်။ ဟောက်ပြီးသော အမှတ်မှ လမ်းကြောင်းကို ခြေရာခံ **မလုပ်ပါ** (အစက်ကြောင်း "from point" inference)။ အဝေးရှိ ထောင့်နှင့် ညီရန် မြားခလုတ်ဖြင့် ဝင်ရိုးကို ခတ်ပြီး ထောင့်ပေါ် ဟောက်ပါ- ခတ်ထားသော အမှတ်သည် ၎င်းနှင့် ညီအောင် ရွေ့သည်။ သို့မဟုတ် [လမ်းညွှန်](topic:guides-measure) ထားပါ။

### Parallel သည် မစမီ ဖြတ်ခဲ့သော အစွန်းကို သုံးသည်

parallel နှင့် perpendicular inference သည် **ပထမ နှိပ်ခြင်းမတိုင်မီ** ကာဆာ နောက်ဆုံးဖြတ်ခဲ့သော အစွန်းကို သုံးသည်၊ ဆွဲနေစဉ် ဟောက်ထားသော အစွန်းများကို မသုံးပါ။ [Inference နှင့် snapping](topic:inference#parallel-and-perpendicular) ကို ကြည့်ပါ။

### အုပ်စု ကူးယူမှုများသည် ချိတ်ဆက်ထားသည်

{{ui:Move}} ဖြင့် အုပ်စုကို ကူးခြင်းသည် တူညီသော အုပ်စု၏ နေရာနှစ်ခုကို ဖန်တီးသည်၊ ထို့ကြောင့် တစ်ခုကို ပြင်လျှင် နှစ်ခုလုံး ပြောင်းသည်၊ ကွန်ပိုနင့်များကဲ့သို့ပင်။ SketchUp တွင် အုပ်စုများ သီးခြားဖြစ်သည်။ [ပြဿနာဖြေရှင်းခြင်း](topic:troubleshooting#editing-one-group-changed-another) ကို ကြည့်ပါ။

### Space သည် pan မလုပ်ပါ

{{key:Space}} က SketchUp ကဲ့သို့ {{ui:Select}} ကို ရွေးသည်။ တခြား web app အချို့တွင် Space ကို ဖိထားလျှင် pan ဖြစ်သော်လည်း ဤနေရာတွင် မဟုတ်ပါ။ right-drag ဖြင့် pan လုပ်ပါ။

### နှစ်ချောင်း scroll က zoom လုပ်သည်

trackpad တွင် {{ui:Settings}} › {{ui:ModelCraft}} › Scrolling ကို Trackpad သို့ သတ်မှတ်ပါ: လက်ချောင်းနှစ်ချောင်းက orbit၊ {{key:Shift}} နှင့် လက်ချောင်းနှစ်ချောင်းက pan၊ pinch က zoom။ [Orbit၊ pan နှင့် zoom](topic:orbit-pan-zoom#on-a-trackpad) ကို ကြည့်ပါ။

သင်၏ လက်များက SketchUp မဟုတ်ဘဲ Blender ၏ ခလုတ်များကို သိနေလျှင် {{ui:Modeler}} menu style ကို ရွေးပါ- {{key:G}}၊ {{key:R}} နှင့် {{key:S}} က ရွေးမှုပေါ်တွင် တစ်ပြိုင်နက် လုပ်သည်၊ {{key:E}} က extrude (တွန်း/ဆွဲ) လုပ်သည်၊ {{key:Shift+D}} က ပွားသည်၊ header menu bar (File၊ Edit၊ View၊ Select၊ Add၊ Object၊ Mesh) က toolbar ကို အစားထိုးသည်။ SketchUp မှ လာလျှင် {{ui:Push-pull}} style က တူညီသော tool အက္ခရာများပေါ်တွင် ကိုယ်ပိုင် menu bar ကို ပေးသည်။ [Menus၊ keys နှင့် mouse](topic:menus-keys-and-mouse) ကို ကြည့်ပါ။

### တွန်းထည့်ထားသော အထည်များသည် မဖြတ်ပါ

Push/pull သည် တူညီသော object အတွင်း နောက်ကွယ်ရှိ မျက်နှာကို ဖြတ်သည်၊ သို့သော် အထည်ခွဲနှစ်ခုကို အချင်းချင်း တွန်းထည့်လျှင် ထိုးဖောက်မသွားပါ။ Intersect Faces နှင့် Solid Tools မရှိပါ။

### ပျောက်နေသောအရာများ

လက်ဖြင့် ဆွဲခြင်း၊ Trim၊ Split နှင့် Outer Shell၊ ကိုယ်ပိုင် ပုံပစ္စည်းများ၊ extensions နှင့် စာရွက်များအတွက် layout tool တို့သည် ဤ build တွင် မပါပါ။ [မတည်ဆောက်ရသေးသော အရာ](topic:not-built-yet) က အစားထိုး လုပ်ရမည့်အရာများကို ဖော်ပြသည်။

## browser က ထိန်းသော ဖြတ်လမ်းများ

ModelCraft သည် browser တွင် လည်ပတ်သဖြင့် ဖြတ်လမ်းအချို့သည် app မဟုတ်ဘဲ browser ၏ဖြစ်သည်။ {{key:Mod+N}} က browser ဝင်းဒိုးတစ်ခု ဖွင့်သည် ({{ui:New}} ကို သုံးပါ)၊ {{key:Mod+W}} က tab ကို ပိတ်သည်။ မသိမ်းရသေးသော ပြောင်းလဲမှုများရှိလျှင် browser က ပိတ်မီ မေးသည်။ [ကီးများ၊ မောက်စ်များနှင့် trackpads](common:keys#shortcuts-the-browser-keeps) ကို ကြည့်ပါ။
