Sends from 3D Print to a **Bambu Lab P2S** through **Bambu Connect**, Bambu Lab's own program for printing from other software. It slices with your own OrcaSlicer and its P2S presets, then opens the file in Bambu Connect, where you start the print.

OrcaSlicer and Bambu Connect are separate programs that you install yourself; CadCraft ships neither.
