# ModelCraft for Linux

ModelCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio) (all eight apps in one install) from 0.5 on; there are no separate ModelCraft installers any more. Get Studio 0.6 from the [download page](https://getcadcraft.com/download#studio) or its [GitHub release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.6.0). Studio ships as a `.deb` and an AppImage.

## File types

- Opens by default: `.modelcraft` (ModelCraft model)
- Listed under "Open with": `.dae` (COLLADA model), `.obj` (OBJ model), `.glb` (glTF model), `.gltf` (glTF model), `.dwg` (DWG drawing), `.dxf` (DXF drawing)
